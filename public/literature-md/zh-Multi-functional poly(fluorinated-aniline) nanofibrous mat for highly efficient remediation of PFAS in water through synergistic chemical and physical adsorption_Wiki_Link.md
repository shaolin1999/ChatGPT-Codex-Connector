## 摘要

[[全氟和多氟烷基物质]]（[[PFAS]]）具有致癌性和环境[[持久性]]，是必须高效去除以保护环境和人类健康的污染物。尽管已有大量[[吸附|吸附剂]]被制备出来，但对于易于合成、高效且切实可行的材料仍有强烈需求。本文提出了一种表面局域化生长策略，将[[聚（氟化苯胺）]]基团功能化到[[静电纺丝]]纳米纤维上，制得[[聚（氟化苯胺）纳米纤维毡]]（[[PFA NFM]]）。与以往[[吸附剂]]不同，PFA [[纳米纤维膜|NFM]]通过一步反应实现双重功能化。这种定制的协同作用赋予PFA NFM在静态和[[动态吸附]]场景中均具有高PFAS[[吸附容量]]。与[[聚苯胺]]对照材料（[[PA NFM]]）相比，PFA NFM展现出显著加快的[[吸附动力学]]（快11–52倍）和优异的抗干扰性能。其界面衍生的[[介孔结构]]进一步促进[[物理吸附]]，并提供极高的PFAS吸附容量。通过[[傅里叶变换红外光谱|FT-IR]]、[[XPS]]、[[固态核磁共振|固态¹⁹F NMR]]和[[密度泛函理论|DFT计算]]确认了多种机制。值得注意的是，PFA NFM能够在较宽浓度范围内高效去除多种环境水体基质中的长链和[[短链PFAS]]，表明其适用于点源和非点源PFAS污染水样。此外，整体式PFA NFM在多种PFAS加标环境水中经过10次[[再生循环]]后仍保持优异[[去除效率]]。其稳健的[[可重复使用性|可回收性]]和[[重复使用性|可重复使用性]]使PFA NFM具有实际应用价值。

## 1. 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）是一类人为化合物[1]，其特征是疏水性氟化碳链和亲水性末端官能团。[[碳-氟键|碳-氟（C-F）键]]的键能高达497 kJ mol<sup>−</sup> <sup>1</sup> [2]，赋予PFAS优异的热稳定性和化学稳定性，使其在过去几十年中成为现代工业不可或缺的材料[3–5]。然而，牢固的C-F键也使PFAS成为[[持久性]]环境污染物[6,7]。自21世纪初首次在野生动物和人体中检出以来，PFAS污染的不断加剧已引起持续关注[8–10]。各国和各地区对PFAS的监管也日益严格。[[欧盟饮用水指令|欧盟《饮用水指令》]]（2020/2184）规定饮用水供应中PFAS总浓度限值为500 ng L<sup>−</sup> <sup>1</sup> [11]。在中国，国家标准[[生活饮用水卫生标准|GB 5749–2022]]《生活饮用水卫生标准》规定[[全氟辛烷磺酸]]（PFOS）和[[全氟辛酸]]（[[PFOA]]）的浓度不得超过40 ng/L [12]。同样，[[美国环境保护署]]（EPA）于2024年4月出台了新的国家饮用水法规，对五种特定PFAS设定了严格限值，其中PFOA和PFOS限值为4 ng $\bar { \mathrm { L } ^ { - 1 } } ,$ ，[[全氟壬酸|PFNA]]、[[全氟己烷磺酸|PFHxS]]、[[六氟环氧丙烷二聚酸|HFPO-DA]]（又称GenX）限值为10 ng L<sup>−</sup> <sup>1</sup> [13]。更严格的标准凸显了迫切需要有效的修复策略来去除这些持久性化合物，以保护公众健康和环境。

在[[PFAS]]修复的各种方法中，[[吸附]]因其可调控的选择性和富集能力而具有相当大的前景。目前，[[颗粒活性炭]]（GAC）和[[离子交换树脂]]（IXRs）是[[全氟和多氟烷基物质|PFAS]]修复中应用最广泛的[[吸附剂]][14,15]，但存在显著局限性：GAC需要较长的接触时间，对[[短链PFAS]]亲和力低，并且其热再生过程能耗和成本较高；IXRs难以再生且更换成本高。此外，这两种材料都面临环境水体基质中共存物质的干扰，从而降低PFAS[[去除效率]]。这些缺点推动了多种先进材料的开发，包括[[改性黏土]][16]、[[金属有机框架]]（[[MOFs]]）[17]、[[共价有机框架]]（COFs）[18]和[[β-环糊精聚合物]]（β-CDs）[19]等。然而，这些材料通常为粉末形态，这给工业规模应用带来了相当大的挑战，例如操作困难、颗粒易团聚以及需要高耗能的分离过程（如离心或过滤）[20]。此外，这些吸附剂通常严格而复杂的合成过程，如贵金属催化、高温、惰性气氛和多步骤工艺，也阻碍了其实际应用[18,21,22]。这些不足促使人们寻找简单、高效、可回收且切实可行的替代吸附剂，以体现面向可持续未来的绿色循环经济。

[[聚苯胺]]（Polyaniline, PA）是一种导电聚合物，以其低成本前驱体、环境稳定性和简便的合成方法而著称 [23]。其本征结构——沿共轭芳香主链分布着胺（-NH-）和质子化胺（=N<sup>+</sup>H-）基团——赋予其多个潜在的 [[PFAS]] [[吸附]]作用位点。具体而言，阳离子胺基可与 [[全氟和多氟烷基物质|PFAS]] 的阴离子头基（-SO<sub>3</sub><sup>-</sup> /-COO<sup>-</sup>）形成强[[静电相互作用|静电吸引]]；同时，PA 的疏水性共轭芳香主链可通过疏水效应与 PFAS 的氟化碳链相互作用。此外，已有研究证实，氟化[[吸附剂]]（如[[氟化离子交换树脂|氟化离子交换（IEX）树脂]]）可通过[[氟-氟相互作用|氟-氟（F-F）相互作用]]有效去除 PFAS，这不仅提高了选择性，还提升了[[吸附容量]]。这一优势在存在共存无机阴离子或天然有机物的竞争条件下尤为显著 [20,22,24]。受这些发现启发，聚（氟代[[苯胺]]）（[[聚（氟化苯胺）|poly(fluorinated-aniline)]], PFA）通过将 PA 的固有胺基和质子化胺基与氟化链段整合，有望成为一种用于增强 PFAS 捕获的高效吸附剂。然而，与以往报道的吸附剂类似，PA 通常以颗粒形式用于吸附应用——这种形式限制了其实际[[可重复使用性|可回收性]] [25–27]。为克服这一局限并便于其重复使用，需要一种更理想的材料形态。

[[纳米纤维膜]]（nanofibrous mats, NFMs）作为互连纳米级纤维的宏观组装体，具有多种有吸引力的特征 [28–30]。其独特的互连通道结构有利于增强分子扩散，从而提高[[吸附容量]]和传质效率。此外，作为整体式材料，NFMs 可方便地从水介质中分离，使其成为污染物去除中可回收[[吸附|吸附剂]]的理想候选材料 [31–34]。本研究首次报道了用于 [[PFAS]] 吸附的 NFM。以[[静电纺丝]] NFMs 为结构支架，通过一步[[原位化学氧化聚合]]法将 [[聚（氟化苯胺）|PFA]] 涂覆在原始纳米纤维表面。通过静态和[[动态吸附]]实验系统研究了 [[PFA NFM]] 的吸附性能。得益于其典型官能团与独特结构的协同效应，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 是去除长链和短链 [[全氟和多氟烷基物质|PFAS]] 的理想[[吸附剂]]，初始浓度范围从十亿分之几（ppb）到数百 ppb，适用于多种环境水基质——包括[[地下水]]、[[污水处理厂]]（STP）进水、STP 出水、河水和[[自来水]]。此外，PFA NFM 表现出快速的[[吸附动力学]]、优异的选择性和长期[[可重复使用性|可回收性]]。为阐明其结构–功能关系，开展了详细的结构表征——包括[[傅里叶变换红外光谱|傅里叶变换红外（FT-IR）光谱]]、X 射线光电子能谱（[[XPS]]）、[[固态核磁共振]]（NMR）波谱和[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算——以在分子水平上阐明吸附机理。

## 2.2 滤芯中[[PFOA]]的动态去除

使用自制滤芯评价[[PFA NFM]]的[[动态吸附]]性能。将[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]精确切割成直径为9 mm的圆片，总质量为$4 . 0 \pm 0 . 1$ mg，夹在两片聚乙烯筛板之间，并装填于洁净聚乙烯滤芯底部，床层高度约为1 mm$( \mathrm { F i g . } \mathrm { S 3 } ) . \mathbf { A }$ [[PFOA]]溶液$( 5 0 ~ \mu \mathrm { g } ~ \mathrm { L } ^ { - 1 } )$在1 bar恒定压力下连续泵入滤芯。流速保持稳定在$0 . 5 \pm 0 . 0 2 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$。[[空床接触时间]]（EBCT）以空床体积$( \pi \times ( 0 . 4 5 \mathrm { c m } ) ^ { 2 } \times 0 . ]$ 1 cm≈ 0.05 mL）除以流速计算，约为0.1 min。在预设出水体积间隔10、100、200、400、1000、2000、4000、6000、10 000和20 000 mL处收集出水样品，并分析残余[[全氟辛酸|PFOA]]浓度，以构建[[穿透曲线]]（体积对[[吸附容量]]）用于评价动态[[吸附]]容量。每个采样点的吸附容量按以下公式计算：

$$
q _ {i} = (C _ {0} - C _ {i}) \times \frac {V _ {i}}{m}
$$

其中$q _ { i }$为采样点i处的[[吸附容量]]$( \mathbf { m } \mathbf { g } \mathbf { \Lambda } \mathbf { g } ^ { - 1 } )$，$C _ { O }$为进水[[PFOA]]浓度（50 μg${ \mathbf { L } } ^ { - 1 } ) ,$，C<sub>i</sub>为采样点i处出水浓度，V<sub>i</sub>为该点的累计处理体积（L），m为[[吸附|吸附剂]]质量（4.0 mg）。

## 3. 结果与讨论

## 3.1 材料制备与表征

鉴于[[聚苯胺|PA]]通常通过[[苯胺]]单体的聚合形成，我们提出将苯胺与[[间氟苯胺]]共聚，作为一种简便且通用的策略来制备[[聚（氟化苯胺）|PFA]]（图S4）。由于PA分子量低且在常见有机溶剂中溶解性差，无法直接[[静电纺丝]]成[[纳米纤维膜|NFM]][35,36]。因此，选择[[聚丙烯腈纳米纤维膜|PAN NFM]]作为模板，因其具有良好的可加工性和力学性能。在合成过程中，酸性环境使[[聚丙烯腈|PAN]]纳米纤维表面带负电，同时促进苯胺类单体质子化为阳离子物种。这种相互作用增强了[[静电相互作用|静电吸引]]，有利于通过[[表面限域自由基聚合]]形成PA和PFA。宏观上，观察到从白色（原始PAN NFM）到深绿色（PA和[[PFA NFM]]）的明显颜色变化（图S5）。

[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）图像揭示了改性过程中的显著形貌变化。原始[[聚丙烯腈|PAN]]纳米纤维表面光滑（图1a）。涂覆[[聚苯胺|PA]]和[[聚（氟化苯胺）|PFA]]后，表面明显变得更加粗糙（图1c和1e）。在PFA纳米纤维表面可观察到分散的PFA颗粒。值得注意的是，PFA纳米纤维的断裂截面清晰暴露了[[核壳结构]]，原始PAN核被均匀的PFA壳层包覆（插图见$\mathrm { F i g . ~ } 1 \mathrm { e } )$）。功能层分布在壳层（表面）可有效避免[[吸附]]位点被包埋，并使其能够更高效地接触和作用于目标[[PFAS]]分析物。[[氮气吸附-脱附测试]]表明，与原始[[聚丙烯腈纳米纤维膜|PAN NFM]]的[[BET|比表面积]]$( 1 5 . 9 \mathrm { m } ^ { 2 } / \mathrm { g }$（[[PA NFM]]）和$1 3 . 2 \mathrm { m } ^ { 2 } / \mathrm { g }$（[[PFA NFM]]）相比显著增加，原始PAN [[纳米纤维膜|NFM]]为$9 . 3 \mathrm { m } ^ { 2 } / \mathrm { g }$；孔体积方面，PA NFM为$( 0 . 0 6 ~ \mathrm { c m } ^ { 3 } / \mathrm { g }$，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]为0.04 $\mathrm { c m } ^ { 3 } / { \tt g }$，原始PAN NFM为$0 . 0 2 \mathrm { c m } ^ { 3 } / \mathrm { g }$ $( \operatorname { F i g } . 1 { \mathfrak { g } } ) .$。采用[[Barrett-Joyner-Halenda模型]]计算的NFM[[孔径分布]]见图S6和图S7。值得注意的是，与原始PAN NFM相比，改性后的NFM（包括PA NFM和PFA NFM）在10–50 nm直径范围内的孔隙比例显著更高，证实了涂覆过程成功构建了[[介孔结构|多级介孔结构]]。这一结构特征有利于底物在孔隙结构内高效扩散并形成[[物理吸附]]。[[水接触角]]测量显示不同NFM之间的表面润湿性存在显著差异（图1b、1d和1f）。值得注意的是，与本身疏水的PAN NFM相比，PA NFM的亲水性显著增强，[[接触角]]降低了$7 5 . 4 6 ^ { \circ }$。这一改善表明PA可能处于翠绿亚胺盐形式，其中亚胺$\left( - \mathbf { N } = \right)$和胺（-NH-）基团的存在，以及HCl掺杂，增加了极性和亲水性。相比之下，PFA NFM的亲水性较PA NFM显著降低，接触角增加了$5 6 . 3 7 ^ { \circ }$，这归因于氟的引入。[[XPS]]分析表征了NFM的元素组成（图1h）。PAN和PA NFM表现出碳、氮和氧的分布，而在PFA NFM中清晰检测到额外的氟信号。

## 3.2. [[PFAS]] [[吸附]]实验

在所有 [[PFAS]] 化合物中，[[PFOA]] 表现出高水溶性 $( 3 . 4 ~ \mathrm { g } ~ \mathrm { L } ^ { - 1 } )$，并且由于 [[全氟辛酸|PFOA]] 暴露与睾丸癌和肾癌之间的强相关性，已被[[国际癌症研究机构]]（IARC）列为“可能对人类致癌”。在本研究中，以 PFOA 为代表化合物，考察了 [[PFA NFM]] 和 [[PA NFM]] 的[[吸附|吸附性能]]。

## 3.2.1. [[吸附动力学]]研究

如图2a和图2b所示，与[[PA NFM]]相比，[[PFA NFM]]表现出显著更快的[[吸附动力学]]（快11–52倍），在仅30 min内即可达到平衡。动力学拟合表明，[[准二级模型]]能够很好地描述[[PFOA]]在[[聚苯胺|PA]] [[纳米纤维膜|NFM]]和[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]上的[[吸附]]过程$( R ^ { 2 } > 0 . 9 9 )$（图S8），说明[[化学吸附]]是主要的吸附机制[39]。[[聚（氟化苯胺）|PFA]] NFM表现出更高的吸附速率常数$( k _ { 2 } ) ,$、更大的初始吸附速率$\displaystyle ( h = k _ { 2 } q _ { e } ^ { 2 } ,$ mg $\mathbf { g } ^ { - 1 }$ min<sup>−</sup> <sup>1</sup>）以及更短的半[[平衡时间]]$( t _ { 1 / 2 } = 1 / k _ { 2 } q _ { e }$，min），优于PA NFM（表S2）。这种动力学增强可能源于PFA NFM与[[全氟辛酸|PFOA]]之间的[[氟-氟相互作用|氟-氟（F-F）相互作用]]，该作用促进了PFOA快速接近[[吸附剂]]表面，并随后与PA基团产生协同相互作用。

## 3.2.2. [[吸附等温线]]与[[热力学研究]]

[[Langmuir模型|Langmuir]]和[[Freundlich模型]]的等温线拟合曲线以及298 K下[[PFOA]]在[[PFA NFM]]和[[PA NFM]]上[[吸附]]的相应实验参数分别如图2c和表1所示。对于[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]，[[Langmuir等温线模型|Langmuir模型]]拟合略优（更高的$R ^ { 2 } ) _ { ☉ }$），而[[聚苯胺|PA]] [[纳米纤维膜|NFM]]则呈相反趋势。然而，对等温线的进一步线性回归分析（图S9和表S3）表明，与Langmuir模型相比，[[Freundlich等温线模型|Freundlich模型]]实际上对两种[[吸附剂]]均提供了更优的整体拟合性能（更高的$R ^ { 2 }$值）。为更深入地了解吸附机制，我们采用了结合Langmuir和Freundlich模型特征的[[Redlich-Peterson等温线]]。持续较高的$R ^ { 2 }$值（图2d，表1）表明，[[全氟辛酸|PFOA]]在这些NFM上的吸附可能通过一种同时涉及[[单层化学吸附]]和[[多层物理吸附]]的复杂机制进行。值得注意的是，Langmuir模型预测的298 K下最大平衡容量分别达到[[聚（氟化苯胺）|PFA]] NFM的1236 mg/g和PA NFM的1082 mg/g，优于此前报道的吸附剂[21, 40–65]（图2e）。在Freundlich模型分析中，参数n反映吸附剂对PFOA的亲和力。在298 K下计算得到的两种材料的1/n值均介于0和1之间，表明PFOA在PFA NFM和PA NFM上的吸附过程均较为有利。

对[[PFA NFM]]在283–313 K范围内的[[热力学研究]]表明，[[吸附]]自发性随温度升高而增强$( \mathrm { F i g . ~ } \mathrm { S 1 0 a { - } b } ,$表1，表S4）。线性[[van't Hoff方程|van't Hoff图]]$( { l n } { K } ^ { \bar { O } }$对1/$T , R ^ { 2 } { = } 0 . 9 9 7 1$，图S10c）可用于确定[[焓变]]$\left( \boldsymbol { \varDelta H } ^ { O } = \right.$ 34.3 kJ/mol）和[[熵变]]$( \Delta S ^ { O } ~ = ~ 0 . 1 8 \mathrm { { k J / m o l { \cdot } K ) } }$。随温度升高而越来越负的$\varDelta G ^ { O }$值（-16.6至−22.0 kJ/mol）表明在较高温度下自发性更强，这与[[吸热吸附]]机制一致。正的$\varDelta S ^ { O }$表明吸附过程中界面无序度增加，而$\Delta H ^ { O } >$ 0则证实了[[PFAS]]结合到[[纳米纤维膜|NFM]]表面的[[熵驱动]]特性[66]。

## 3.2.4. 再生与[[可重复使用性]]

为评估 [[PFA NFM]] 在实际条件下消除 [[PFAS]] 的能力，在存在潜在干扰物质的条件下进行了[[吸附]]测试（文本 S6）。如图 2f 所示，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 在含有多种干扰物质（包括[[无机盐]]和[[有机污染物]]）的水溶液中仍表现出持续的 [[PFOA]] [[吸附容量]]，表明其对 [[全氟辛酸|PFOA]] 具有优异的选择性。相比之下，当其他干扰物质存在时，[[PA NFM]] 的吸附容量出现一定程度的下降。该对比实验表明，[[聚（氟化苯胺）|PFA]] 中合理设计的[[氟官能团|含氟官能团]]通过与 PFOA 分子的特异性相互作用，促成了这种优异的选择性。也就是说，[[F⋯F相互作用|F⋅⋅⋅F 相互作用]]是一种辅助性的、增强选择性的作用力，使 PFA [[纳米纤维膜|NFM]] 区别于 [[聚苯胺|PA]] NFM，特别是在 [[全氟和多氟烷基物质|PFAS]] 捕获的动力学和选择性方面。

如图 2g 所示，[[PFA NFM]] [[吸附|吸附剂]]可通过 1% 氨水/乙腈洗脱高效再生（图 S11），[[解吸效率]]达到 90.9%，并可重复用于连续的 [[PFOA]] 吸附循环（文本 S7）。值得注意的是，即使经过 10 次循环，[[吸附容量]]仍保持在高水平（约 85%），展示了其长循环寿命，并进一步凸显了 [[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 的高稳定性。为了进一步确认 [[聚（氟化苯胺）|PFA]] [[纳米纤维膜|NFM]] 在 10 次吸附-解吸循环后的结构稳定性，对循环后的材料进行了表征。再生 PFA NFM 的 [[SEM]] 图像、[[FTIR]] 和 [[XPS]] 谱图（图 S12）与新鲜材料相比，在形貌、特征官能团或元素组成方面均未出现明显变化，证实了其在重复使用过程中优异的机械和结构稳定性，并有效排除了与材料降解相关的潜在二次环境风险。

值得注意的是，所提出的 [[PFA NFM]] [[吸附]]-再生系统实现了将大体积水中的低浓度 [[PFAS]] 高效富集并分离至小体积有机废液中。对于后续含 [[全氟和多氟烷基物质|PFAS]] 有机废液的处置，[[高温焚烧]]、[[超临界水氧化]]和[[有机相光催化氧化]]是实现 PFAS 在有机溶剂中有效降解和[[矿化]]的有前景的方法。此类破坏性技术的实施将避免单纯的相转移问题，并实现更全面的 PFAS 污染水体修复工作流程，尽管这些后处理策略的整合仍有待在未来的工作中探索。

## 3.2.5. [[动态吸附]]研究

凭借超薄厚度和整体式结构特征，[[纳米纤维膜|NFM]] 可以便捷地组装成[[固定床柱]]。这种构型产生较低的水力压降并允许溶液快速渗透，非常适合连续动态流动处理。描述[[吸附容量]]与进料溶液体积之间关系的[[穿透曲线]]如图 2h 所示。最初，存在大量可用[[活性位点]]，导致[[吸附]]容量随进料体积增加而稳步上升。随着这些活性位点逐渐被占据，吸附过程逐步接近平衡，[[饱和处理体积]]达到约 200 L。在此条件下，测得的吸附容量为 1190 mg/g，显著超过其他已报道[[吸附剂]] [67–69]，凸显了 [[PFA NFM]] 的优越性能。

## 3.3. [[吸附|吸附机理]]

为探究[[吸附|吸附机理]]，对吸附 [[PFOA]] 后的 [[PA NFM]] 和 [[PFA NFM]] 进行了一系列表征。

如图3a所示，-C––O伸缩振动峰的强度在 $1 7 3 0 \mathrm { c m } ^ { - 1 }$ [[PA NFM]] 和 [[PFA NFM]] 在[[吸附]] [[PFOA]] 后均出现增强。这一增强归因于所吸附 [[全氟辛酸|PFOA]] 中 -COOH 基团的存在。不对称/对称 COO<sup>-</sup> 伸缩振动在 $1 6 6 9 / 1 3 8 7 \mathrm { c m } ^ { - 1 }$ ([[聚苯胺|PA]] [[纳米纤维膜|NFM]]@PFOA) 和 $1 6 7 4 / 1 3 8 6 \mathrm { c m } ^ { - 1 }$ ([[聚（氟化苯胺）纳米纤维毡|PFA NFM]]@PFOA)表明，PFOA主要以[[去质子化]]形式存在，提示[[离子交换]]是主要的吸附机制。此外，特征性的-C-$\mathrm { N ^ { + } } .$ 拉伸振动在 $1 2 4 8 \mathrm { c m } ^ { - 1 } \left( \mathrm { P A N F M } \right)$ 和 $1 2 5 4 ~ \mathrm { c m } ^ { - 1 }$ （[[聚（氟化苯胺）|PFA]] NFM）二者均经历了 $. 1 2 { - } 1 8 \mathrm { c m } ^ { - 1 }$ 红移至 $1 2 3 6 ~ \mathrm { c m } ^ { - 1 }$ PFOA 吸附后，表明带正电的氮中心与 PFOA 羧酸根之间存在强[[静电相互作用]]。新峰的出现位于 $1 2 0 3 / 1 2 0 4 \mathrm { c m } ^ { - 1 }$ ，以及上方峰强度的增加 $1 1 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ 也表明两种材料对 PFOA 均具有有效吸附。值得注意的是，上述峰的显著红移 $1 1 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ 后 PFOA 吸附意味着苯环在吸附过程中也可能发挥关键作用，可能与目标分子形成 [[C–H⋯F相互作用|C–H⋅⋅⋅F]]/[[F–π相互作用|F–π 相互作用]]。

进行了<sup>19</sup>F固体核磁共振波谱测试，以更深入地了解[[PFA NFM]]与[[PFOA]]之间的相互作用。如图3j所示，[[全氟辛酸|PFOA]][[吸附]]后，[[聚（氟化苯胺）|PFA]]的氟信号出现了显著的高场位移（−10.94至−12.13 ppm）。这一观察结果为PFA与PFOA之间存在特异性F⋅⋅⋅F相互作用提供了佐证。此类相互作用可能通过电子密度重新分布或构象调整，增加PFA中氟原子的[[核磁屏蔽效应]]。

系统开展了[[密度泛函理论|DFT计算]]，以进一步阐明[[PFOA]]在[[PA NFM]]和[[PFA NFM]]上的[[吸附]]机制。有关计算方法的详细信息见Text S8（支持信息）。如图4所示，构建了两种不同的吸附模型。模型1描述的是[[全氟辛酸|PFOA]]的−COOH基团接近[[聚苯胺|PA]]和[[聚（氟化苯胺）|PFA]]的−N<sup>+</sup>H=基团的吸附构型。相比之下，模型2表示PFOA的−COOH基团朝向PA和PFA [[纳米纤维膜|NFMs]]的−NH−基团的构型。利用基于[[Hirshfeld划分]]的[[独立梯度模型]]（IGMH）分析评估了分子间相互作用的性质，其中相互作用云的颜色强度反映分子间作用力的强弱[72]（即越蓝的区域表示相互作用越强，如图S13所示）。根据PA（图4a）和PFA（图4b）的IGMH结果，无论PFOA的−COOH基团是接近−N<sup>+</sup>H=基团（模型1）还是−NH−基团（模型2），PFOA的阴离子头基与胺位点之间的[[静电相互作用|静电吸引]]都是两种材料的主要分子间作用力。由于PA具有离域π共轭结构，其正电荷可以分布在整个骨架中，这一点也通过图S14中的[[静电势]]（ESP）分析得到了进一步验证，只是极值点有所不同。除静电吸引外，多重[[氢键]]相互作用（如N–H⋅⋅⋅F和[[C–H⋯F相互作用|C–H⋅⋅⋅F]]）进一步促进了PFOA的结合。对于PFA而言，除了静电吸引和氢键外，氟化骨架还在氟化骨架与PFOA的全氟烷基链之间引入了额外且显著的F⋅⋅⋅F相互作用，作为一种独特而有利的结合力。计算得到的PFOA在PA NFM上的[[吸附能]]（模型1为−8.21 kcal/mol，模型2为−4.52 kcal/mol）和在[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]上的吸附能（模型1为−8.55 kcal/mol，模型2为−4.78 kcal/mol）相当，氟化对应物仅表现出微弱增加。这一适度差异表明，在PA主链中引入氟原子并不会显著增强固有[[吸附容量]]，这与实验结果一致。相反，氟化的主要作用可能是改善NFM的[[吸附动力学]]和抗干扰性能。此外，PA和PFA的分子轨道计算显示，两种材料具有相近的[[HOMO-LUMO能隙|HOMO−LUMO能隙]]，表明PFA增强的吸附性能主要归因于F官能团（图S15）。

此外，经计算，最大[[吸附容量]]为每个 [[聚（氟化苯胺）|PFA]] 单元[[吸附]] 3–4 个 [[PFOA]] 分子。为更深入理解 [[PFA NFM]] 异常高的 [[PFAS]] 吸附容量，我们模拟了 [[全氟辛酸|PFOA]] 在 PFA 单元上的吸附过程，并逐步增加 PFOA 分子数量（GIF 1、GIF 2 和 GIF 3）。随着吸附 1–4 个 PFOA 分子，[[吸附能]]变得更负（表 S5），证实了由化学-[[物理吸附]]机制协同驱动的有利[[多层吸附]] [73]。[[独立梯度模型|IGMH]] 结果直观地证实了相邻 PFOA 分子之间存在多种[[非共价分子间作用力]]，包括占主导地位的 F-F 相互作用。这些强分子间作用力可有效驱动 PFOA 分子在预吸附分子层上持续堆叠和稳定聚集，最终形成稳定的[[多层物理吸附]]。此外，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 固有的[[介孔结构]]（具有合适的孔径）为这些过程提供了必要的空间条件。

## 3.4. 在添加 [[PFAS]] 的环境水样中的应用

为评价 [[PFA NFM]] 的实际可行性，采用五种水样进行验证，包括[[地下水]]、[[污水处理厂进水]]、[[污水处理厂出水]]、[[贾鲁河|贾鲁河水]]和[[自来水]]，均添加了 14 种代表性 [[PFAS]] 的混合物。水样的详细信息见支持信息文本 S9。使用前，每个样品均经 0.45 μm [[尼龙膜]]过滤以去除颗粒物。如 ${ \mathrm { F i g . ~ } } S 1 6 ,$ 所示，过滤后全部 14 种 [[全氟和多氟烷基物质|PFAS]] 的回收率为 92.1% 至 106.7% $( \mathrm { R S D } \leq 4 . 6 \% )$，证实尼龙滤膜在本实验条件下未造成明显的 PFAS [[吸附]]。14 种 PFAS 的结构如图 S17 所示。采用[[动态吸附]]和静态吸附两种吸附模式。

如图5a、图S18和表S6所示，在[[静态吸附模式]]下，[[PFA NFM]]对超低浓度和低浓度下的长链及[[短链PFAS]]均表现出优异的[[去除效率]]，去除率全部超过90%。在中浓度和高浓度下，由于[[吸附]]位点趋于饱和，部分短链[[PFAS]]的去除效率略有下降，但仍达到73%以上，而[[长链PFAS]]的去除效率则保持在85%以上。在[[动态吸附模式]]下（图5b、图S19、表S7），在超低浓度下，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]]对全部14种[[全氟和多氟烷基物质|PFAS]]实现了几乎完全的去除，去除率均超过93%。在低浓度下，除[[污水处理厂进水]]中短链PFAS的去除效率略低（仍＞80%）外，[[聚（氟化苯胺）|PFA]]在其他水样中对PFAS的去除效率均在90%以上。对于中、高浓度PFAS水样，由于吸附位点有限，去除效率略有下降，但仍保持在71%以上。这一差异反映出该[[吸附剂]]更倾向于优先吸附长链PFAS，然后再吸附短链PFAS。当吸附位点不足时，短链PFAS的吸附速率会降低。值得注意的是，这些测试中仅使用了4 mg膜材料；增加膜用量将进一步提高去除效率。

## 4. 结论

总之，本研究制备了一种简单、高效且可重复使用的[[吸附|吸附剂]]，用于去除水中的 [[PFAS]]。本工作凸显了经合理设计、具有定制结构和功能性的 [[纳米纤维膜|NFM]] 在实际应用中广谱去除多种 [[全氟和多氟烷基物质|PFAS]] 的潜力。虽然 [[PA NFM]] 表现出高效的 PFAS 去除性能，但 [[PFA NFM]] 展现了显著快速的[[吸附动力学]]（在仅 30 min 内达到平衡）和优异的抗干扰性能，凸显了 F 官能团在介导与 PFAS 相互作用中的关键作用。此外，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 固有的[[介孔结构]]促进了疏水性 PFAS 的聚集，形成稳定的[[多层吸附]]。[[化学-物理协同吸附机制]]，加之有利的多孔微环境，赋予 [[聚（氟化苯胺）|PFA]] NFM 异常高的 [[PFOA]] [[吸附容量]]（1236 mg ${ \bf g } ^ { - 1 } )$

为对这一新型功能材料的性能进行基准评价，我们与文献报道的各种 [[PFAS]] [[吸附|吸附剂]]进行了系统比较（表 2）。与包括 [[MOFs]]、聚合物、[[氧化石墨烯]]和衍生碳在内的多种材料相比，[[PFA NFM]] 在去除 [[全氟和多氟烷基物质|PFAS]] 方面显然非常高效。此外，大多数其他材料需要苛刻的合成条件，如高温、氮气保护和贵金属催化。相比之下，[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 的合成相对简单，可实现规模化生产。并且，其非粉末形态使其能够在低能耗条件下直接再生和运行。值得注意的是，其[[可重复使用性]]优于所有其他已报道材料。最重要的是，几乎所有替代材料都缺乏在实际应用场景下的性能验证。[[聚（氟化苯胺）|PFA]] [[纳米纤维膜|NFM]] 在从[[工业废水处理]]到[[地下水修复]]的各种水样中，跨越超低浓度到高浓度范围，均表现出优异的实际应用可行性，从而产生更广泛的环境影响。当然，PFA NFM 在复杂真实水环境中的长期运行稳定性、持续抗干扰性能以及大规模工程适用性，仍需在未来的研究中进一步系统探索和现场规模验证。

此外，尽管 [[PFA NFM]] 展现出良好的 [[PFAS]] 捕获性能，但当前工作仍存在若干局限性需要指出。第一，其对更广泛范围的 [[全氟和多氟烷基物质|PFAS]] 同系物及新兴氟化替代品的[[去除效率]]尚未得到充分系统评估，值得进一步深入研究。第二，目前的验证仅限于水环境基质；其在更复杂的样品（如[[垃圾渗滤液]]和[[高盐废水]]）中的可行性仍有待确认。因此，在未来的工作中，我们将进一步拓展研究范围，以涵盖多种传统和新兴 PFAS 污染物，并优化膜表面以增强其在高盐水中的抗干扰能力。

## 环境意义

[[PFAS|PFASs]] 因其极强的[[持久性]]、[[生物累积性]]和[[毒性]]，构成严重的环境和健康风险。尽管[[吸附]]技术为 [[全氟和多氟烷基物质|PFAS]] 去除提供了潜力，但传统材料（如[[颗粒活性炭]]和[[离子交换树脂]]）以及多种新开发的[[吸附剂]]仍面临关键局限，包括粉末形态不实用、合成过程复杂且条件苛刻，以及在实际条件下效能下降等问题。本研究引入了一种用于 PFASs 去除的 [[PFA NFM]]。[[聚（氟化苯胺）纳米纤维毡|PFA NFM]] 兼具简便的合成方法、优异的性能和稳健的[[可重复使用性|可回收性]]，为大规模应用于应对 PFASs 污染提供了一种突破性解决方案。
