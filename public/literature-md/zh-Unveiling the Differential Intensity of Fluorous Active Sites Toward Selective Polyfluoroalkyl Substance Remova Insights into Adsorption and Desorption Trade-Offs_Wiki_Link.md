摘要：设计用于去除[[全氟和多氟烷基物质]]（PFAS）的[[选择性吸附]]位点，并将其与[[吸附剂再生|高效再生策略]]相结合，仍是一项关键但尚未得到充分研究的挑战。现有技术优先关注[[吸附容量]]，而对再生的可持续性重视不足；针对这一问题，我们构建了一种具有定制[[亲氟活性位点|亲氟结合位点]]的[[含氟水凝胶|氟化水凝胶]]，通过 PFAS 的[[疏水性]] [[碳氟键|C−F]] 末端对其进行靶向[[吸附]]。该设计在真实水体基质（如[[自来水]]和[[湖水]]）中、环境相关浓度（1 μg L<sup>−1</sup>）下实现了超过 90% 的 PFAS [[去除效率]]，并表现出对[[背景竞争离子]]和[[天然有机质]]的强[[抗干扰能力]]。[[吸附选择性|选择性]]与 PFAS 链长高度相关（[[F9 含氟水凝胶|F9]] > [[F12 含氟水凝胶|F12]] > [[F6 含氟水凝胶|F6]]），其驱动力来自稳定的[[吸附构型]]（C−F···F−C 与 C−H···F−C）以及 −29.06 kcal mol<sup>−1</sup> 的有利[[吸附能]]。借助可控的[[非共价氟氟相互作用|非共价 F···F 相互作用]]，该[[水凝胶]]实现了[[解吸|高效解吸]]（使用 1% [[氯化钠|NaCl]]、1% NH Cl 或 0.5% $\mathrm { N H } _ { 4 } \mathrm { O H - N H } _ { 4 } \mathrm { C l } )$，[[解吸效率]]为 60−80%，且未发生[[结构降解]]。使用 50% [[甲醇]]实现了完全再生（恢复率 >92%），支持重复使用五个循环，且性能下降极小。在连续运行中，使用 1% NaCl 实现了 PFAS 的 10 倍富集，而使用 50% 甲醇则实现了显著更高的 51 倍富集。与传统[[活性炭]]和[[吸附树脂|树脂]]相比，这两种方法均使[[洗脱液]]消耗量降低了 20−50%。总体而言，平衡 PFAS 吸附与解吸之间的权衡可显著减少[[环境足迹]]并降低运行成本，为 [[PFAS修复|PFAS 修复]]提供一种可持续策略。

## ■ 引言

[[全氟和多氟烷基物质]]（PFAS）是一类以[[防水性能|防水]]和[[防油性能]]著称的人造化学品，但它们对人类健康和环境构成了重大风险。<sup>1−3</sup> PFAS 造成的污染使市政部门和工业界承担高昂的治理费用，同时也增加了监管合规负担。<sup>4,5</sup> 这一状况推动了开发经济可负担处理方案的热潮。在现有的多种处理方法中，[[吸附法]]因其操作简便、[[吸附选择性|选择性]]可调以及富集能力强，已被证明是去除实际水体基质中 PFAS 的有效方法。<sup>6,7</sup> [[吸附]]过程的效率主要取决于能否构建对目标[[吸附质]]具有高亲和力的[[活性位点]]。传统的 PFAS 吸附策略侧重于构建[[静电相互作用|静电作用]]位点（如[[氨基]]或[[季铵基团]]）、<sup>8,9</sup> [[氢键作用]]位点（如[[羟基]]或[[羧基]]）<sup>1,10</sup> 以及[[疏水效应|疏水作用]]位点（如[[长链烷基]]或[[芳香基团]]）。<sup>11,12</sup> 然而，这些传统方法往往缺乏专门用于[[选择性吸附]] PFAS 的功能性活性位点，因此容易受到水相化学条件变化的影响，例如 [[pH]]、[[离子强度]]和[[有机质]]。<sup>7,10,13</sup> 此外，与其他有机化合物不同，PFAS 的[[解吸]]通常需要使用含有大量盐和[[有机溶剂]]的[[洗脱液]]，<sup>10,14,15</sup> 这意味着[[吸附位点]]设计不合理可能导致[[洗脱]]液用量较大。因此，合理设计吸附位点，在提高选择性的同时实现高效且可规模化的解吸，对于推动可持续水处理方案的发展至关重要。

近期研究强调，[[有机含氟分子]]之间的 [[非共价氟氟相互作用|C−F···F−C 相互作用]]（如非共价 [[氟–氟相互作用|F···F 相互作用]]）是一种具有前景的 [[全氟和多氟烷基物质|PFAS]] 去除策略。<sup>16−18</sup> [[吸附剂]]中的[[含氟链]]与 PFAS 的含氟尾链具有相近的[[电负性]]，根据“[[相似相溶原理|相似相溶]]”原理，有利于形成较强的 [[氟氟相互作用|F···F 相互作用]]。<sup>19,20</sup> 目前，研究人员已开发出多种[[含氟吸附剂]]，包括[[氟化框架材料]]、<sup>1,16,21</sup> [[氟化无机材料]]<sup>22−24</sup> 和[[氟化有机材料]]。<sup>25,26</sup> 这些[[吸附]]剂具有以 [[碳氟键|C−F 键]]封端的区域，<sup>27,28</sup> 可形成高度亲氟的环境，并提高[[吸附位点可及性|亲氟位点的可及性]]。通过最大限度地减少与非[[氟化]]物质的相互作用，这些吸附剂能够降低复杂水体基质中[[共存污染物]]的[[竞争吸附]]，使 PFAS [[去除效率]]提高 10−90%。<sup>29</sup> 现有研究主要关注 PFAS 在[[氟化吸附剂]]上的吸附性能，突出表明引入[[亲氟活性位点|氟相位点]]是实现[[选择性吸附]]的有效策略。然而，支配氟相位点[[吸附选择性|选择性]]吸附的内在机制尚未得到充分探究。

具体而言，[[亲氟活性位点|含氟活性位点]]的强度差异对 [[全氟和多氟烷基物质|PFAS]] [[选择性吸附]]效率的影响仍不明确。尤其是，PFAS 与[[氟亲和位点|含氟位点]]之间的有效[[配位结构]]及其对[[分子间相互作用]]的影响，尚未得到充分阐明。<sup>29</sup> 此外，理解含氟位点的[[解吸]]行为对于开发高效且可重复使用的[[含氟吸附剂|亲氟吸附剂]]至关重要，但这一领域的研究仍然有限。近期研究表明，[[氟–氟相互作用|F···F 相互作用]]弱于[[共价键]]（其[[键能]]大于 150 kJ mol<sup>−1</sup>），<sup>30,31</sup> 但在概念上与[[氢键]]相似。<sup>32,33</sup> 与 PFAS 和[[活性炭]]或[[吸附树脂|树脂]]之间较强的[[静电相互作用|静电]]或[[疏水相互作用]]不同，<sup>14</sup> 强度适中的 [[氟氟相互作用|F···F 相互作用]]可能有利于 PFAS 解吸，从而有望减少对高浓度盐溶液或[[有机溶剂]]的需求。然而，利用 [[非共价氟氟相互作用|F···F 相互作用]]平衡[[吸附选择性|选择性]][[吸附]]与高效解吸的潜力尚未得到充分探索，需要进一步研究以明确其在亲氟[[吸附剂]]设计中的作用。

本研究通过策略性设计，制备了[[亲氟活性位点|含氟活性位点]]（[[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]]）可精确调节的[[含氟水凝胶|氟化水凝胶]]，以应对 [[全氟和多氟烷基物质|PFAS]] 去除中的关键挑战，包括通过控制 [[碳氟键|C−F]] 区域的空间排列，针对[[直链PFAS同系物|直链 PFAS 同系物]]定制[[结构特异性]]，以及理解支配 PFAS [[吸附选择性|选择性]]和[[可逆性]]的[[分子间相互作用|分子相互作用]]。我们采用包括 <sup>19</sup>F [[魔角旋转]]（MAS）[[核磁共振光谱|核磁共振]]（[[核磁共振波谱|NMR]]）光谱、[[傅里叶变换红外光谱|傅里叶变换红外]]（[[FTIR]]）光谱、[[X射线光电子能谱|X 射线光电子能谱]]（[[X 射线光电子能谱|XPS]]）和[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算在内的综合表征方法，系统阐明了[[氟亲和位点|含氟位点]]强度与 PFAS [[吸附效率]]之间的[[构效关系]]。值得注意的是，我们的研究结果表明，[[氟–氟相互作用|F···F 相互作用]]的非共价本质有助于实现[[吸附剂再生|节能再生]]，通过尽可能减少[[有机溶剂]]用量或仅使用盐溶液即可实现有效[[解吸]]。这一双重策略推进了选择性 PFAS [[吸附剂]]的设计，并使可持续的大规模应用成为可能。

## ■ 结果与讨论

合成与表征。本研究采用结构相似但氟链长度不同的单体（如 [[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]]）合成[[含氟水凝胶]]，以调控其与 [[全氟和多氟烷基物质|PFAS]] 之间的[[氟氟疏水相互作用|氟−氟疏水相互作用]]。<sup>41</sup> 通过[[一锅法]][[自由基]]共聚策略（图 1a 和 S1），将这些单体整合到[[纤维素]]衍生的[[聚合物网络]]中，兼顾荧光性能与[[力学性能|机械强度]]。压缩应力−应变曲线（图 S2）证实，[[水凝胶]]具有良好的机械稳定性，抗压强度超过 1.0 MPa，这对实际应用至关重要。为单独考察含氟网络结构对 PFAS [[吸附]]的影响，在合成过程中将 [[F6氟化水凝胶|F6]]、[[F9氟化水凝胶|F9]] 和 [[F12氟化水凝胶|F12 水凝胶]]的氟含量统一至相同水平。合成后的[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）[[结合能]]量色散 X 射线光谱（[[能量色散 X 射线能谱|EDS]]）分析证实，所有类型水凝胶的氟保留量均一致（16−17%）（图 1b 和 S3，表 S2）。此外，元素线扫描和面分布分析（C、N、O 和 F）显示，各元素在空间上分布均匀（图 1c 和 S4），证实含氟单体无缝整合于共聚基体中。

此外，对[[含氟水凝胶]]的结构和表面性质进行了全面表征。[[BET]] 分析证实其具有介孔结构，孔径范围为 2−25 nm（图 1d 和 S5），而 [[SEM]] 成像显示其具有相互连通的微米级通道（直径为 2−5 μm；图 1e−g 和 S6）。这种结合介孔与微米级网络的分级多孔结构，共同促进了高效的水渗透和污染物传质，并优化了[[吸附位点可及性|吸附位点的可及性]]。水[[接触角]]测量表明，[[水凝胶]]具有显著的[[疏水性]]，[[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]] 的接触角分别为 108.9°、119.8° 和 118.2°（图 1e−g），这归因于氟碳基团固有的疏水性和低极化率。<sup>42,43</sup> 通过零电荷点测量（[[pH]] ∼ 6.0；图 S7）进行的表面电荷分析表明，在中性条件下，水凝胶表面呈净负电荷，这源于氟的高[[电负性]]。<sup>21</sup> 这种带负电的表面可能通过促进[[背景离子]]的电荷屏蔽作用，减弱其与带负电 [[全氟和多氟烷基物质|PFAS]] 之间的[[静电排斥]]，后续[[吸附]]试验中也观察到了这一现象。

关键在于，[[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]] 的氟含量统一至相同水平（基于 [[SEM]]−[[能量色散 X 射线能谱|EDS]] 数据，为 16−17%），确保了其孔隙均匀性、润湿性和表面电荷具有可比性，从而能够系统评估不同单体对 [[全氟和多氟烷基物质|PFAS]] 亲和力的特异性影响。这些经过定制的性质，即分级[[孔隙结构]]、亲氟[[疏水性]]和可调控的表面电荷，共同奠定了[[水凝胶]]高效捕获 PFAS 的基础，兼顾结构稳健性与[[选择性吸附]]功能。这种结构均一性凸显了合成方案的精确性，以及[[亲水性]][[纤维素]]骨架与疏水性[[含氟链|含氟链段]]之间的协同相容性，为定制 PFAS [[吸附机制]]奠定了基础。

[[几何构型]]，使亲氟接触和[[电子密度重叠]]最大化，[[分子静电势分析|ESP 分析]]证实了这一点。[[F6 含氟水凝胶|F6]] 和 [[F12 含氟水凝胶|F12]] 所不具备的这种结构一致性，使 [[全氟辛烷磺酸|PFOS]] 的[[全氟烷基链]]能够与 [[F9 含氟水凝胶|F9]] [[亲氟吸附位点|氟亲和位点]]形成稳定的线性排列，从而最大限度地减少[[空间位阻]]冲突并增强[[结合特异性]]。理论计算进一步解释了其对[[支链异构体|支链]]或[[短链PFAS|短链 PFAS]] 亲和力较差的原因，即这些分子会破坏这种优化的几何构型。这些发现强调，[[吸附]]效能不仅取决于氟含量，还取决于聚合物氟碳结构单元与 [[全氟和多氟烷基物质|PFAS]] 分子结构之间精确的空间匹配，为未来设计用于复杂 PFAS 混合物的[[选择性吸附剂]]提供了指导。

为验证所提出的[[吸附机制]]，开展了 [[分子动力学模拟|MD 模拟]]，以模拟在与实验相关的摩尔比下 [[全氟辛烷磺酸|PFOS]] 与[[含氟聚合物]]（[[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]]）之间的动态相互作用（图 4b 和 S24）。时间分辨快照（图 S25−S27）显示，PFOS 迅速[[吸附]]到聚合物链上，并在纳秒内形成稳定的[[聚集体]]。[[均方位移分析|MSD 分析]]量化了 PFOS 的迁移能力（图 4c），表明 PFOS 在 [[F6氟化水凝胶|F6]] 体系中的扩散最快 $( 1 . 2 \times 1 0 ^ { - 1 0 } \ \mathrm { c m } ^ { 2 } \ s ^ { - 1 } )$，而在 [[F9氟化水凝胶|F9]] 和 [[F12氟化水凝胶|F12]] 中的[[扩散速率]]较慢且相近 $( 0 . 5 { - } 0 . 7 \times 1 0 ^ { - 1 0 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } ;$；图 4d），与实验测得的结合强度呈负相关。这一动力学排序与[[吸附容量]]的变化趋势一致，证实了 [[F6-PFOS 复合体系|F6-PFOS]] 相互作用较弱，而 [[九氟单体F9|F9]] 和 [[十二氟单体F12|F12]] 体系中的[[亲氟相互作用]]均较强。[[径向分布函数|RDF 分析]]进一步解析了氟原子间的空间相互作用：在 0.32 和 0.64 nm 处出现的明显峰（图 4e）证实，短程（<1 nm）F···F 偶极−偶极作用力是初始吸附后的关键稳定因素，<sup>3,76</sup>而长程（1−100 nm）[[疏水效应]]主导了 PFOS 捕获的初始步骤。<sup>77,78</sup>[[F9-PFOS 复合体系|F9-PFOS]] 的 RDF 峰强度更高，尤其是在 0.32 和 0.64 nm 处，凸显了其优异的亲氟特异性，这归因于最优的氟原子间距及其与 PFOS [[全氟烷基链]]的匹配排列。这些模拟将实验与计算结果统一起来，详细揭示了一种[[分层吸附机制]]：首先通过[[疏水相互作用|疏水作用]]在表面快速富集，随后由[[氟–氟相互作用|氟相相互作用]]驱动稳定化。这些结果不仅合理解释了 F9 性能更优的原因，还为设计具有定制氟结构的聚合物提供了动态框架，以提高对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附选择性|选择性]]并改善[[结合动力学]]。

为阐明 [[全氟辛烷磺酸|PFOS]] 与[[含氟水凝胶]]体系（[[F6 含氟水凝胶|F6]]、[[F9 含氟水凝胶|F9]] 和 [[F12 含氟水凝胶|F12]]）之间的相互作用机制，我们开展了基于 [[Hirshfeld 分区]]的 [[基于 Hirshfeld 分区的独立梯度模型|IGMH 分析]]，揭示了对 [[全氟和多氟烷基物质|PFAS]] [[吸附]]至关重要的不同[[非共价相互作用]]。<sup>79,80</sup> IGMH [[等值面]]和[[散点图]]在[[亲氟活性位点|含氟位点]]与 PFOS [[全氟碳链|全氟碳尾链]]之间呈现出显著的绿色峰和区域，表明 [[氟–氟相互作用|F···F 相互作用]]和[[范德华力]]占主导地位（图 4f−h 和 S28）。值得注意的是，[[F6-PFOS 复合体系|F6-PFOS]]、[[F9-PFOS 复合体系|F9-PFOS]] 和 [[F12-PFOS 复合体系|F12-PFOS]] 体系中的数据均聚集在负 sign(λ )ρ 区域（<0.75），证实了 F···F 相互作用相较于其他作用力的主导地位。以静电势（ESP）着色的分子间范德华表面穿透图进一步揭示了分子层面的驱动力：<sup>81</sup> PFOS 的 [[碳氟键|C−F]] 链呈现低至正的电势，与 [[F6氟化水凝胶|F6]]、[[F9氟化水凝胶|F9]] 和 [[F12氟化水凝胶|F12]] 中含氟区域的负电势形成对比（图 S29），从而产生有利的[[静电互补性]]，增强吸附。相反，[[水凝胶]]中 C−H 区域的正电势引发了[[静电排斥作用|排斥作用]]，如 [[十二氟单体F12|F12]] 中所观察到的现象（图 S30），凸显了非[[氟化]]基团的不利作用。这些发现共同强调，[[吸附效率]]取决于[[亲氟吸附位点|氟亲和活性位点]]的密度和[[吸附位点可及性|可及性]]，而线性 PFAS 分子能够以最佳排列方式最大限度地增强 [[氟氟相互作用|F···F 相互作用]]。[[九氟单体F9|F9]] 通过延长全氟链并尽量降低 C−H 含量而表现出优异性能，体现了富氟且不含 C−H 的结构对于实现高亲和力 PFAS 捕获的重要性。这一兼顾[[亲氟性]]与[[空间位阻]]相容性的设计范式，为开发针对 PFAS 等[[持久性污染物]]的下一代水凝胶提供了策略蓝图。

[[亲氟吸附位点|氟亲和位点]][[吸附剂再生|再生]]过程研究。为实现负载 [[全氟和多氟烷基物质|PFAS]] 的[[含氟水凝胶]]中[[氟亲和位点]]的[[解吸|高效解吸]]与再生，选择能够破坏占主导地位的 [[氟–氟相互作用|F···F 相互作用]]的[[洗脱剂]]至关重要。尽管[[有机溶剂]]（如 [[甲醇|MeOH]]）能够有效削弱[[疏水效应|疏水作用]]和[[氢键作用]]，而盐溶液主要破坏[[静电相互作用]]，<sup>10,58</sup> 但以往针对氟亲和特异性解吸的研究仍然较少。

此处，使用 [[F9 含氟水凝胶|F9 水凝胶]]对常见[[洗脱剂]]（1% [[氯化钠|NaCl]]、1% NH Cl、0.5% $\mathrm { N H _ { 4 } O H - N H _ { 4 } C l } _ { \mathrm { \Omega } }$ 和 [[甲醇|MeOH]] 混合物）（例如，1% [[氯化钠甲醇混合洗脱剂|NaCl−MeOH 混合物]]、100% MeOH、50% MeOH）<sup>14</sup>进行系统评估，发现其性能存在显著差异。盐溶液类[[洗脱]]剂（例如，1% NaCl、1% $\mathrm { N H _ { 4 } C l , }$ 和 0.5% NH OH− $\mathrm { N H } _ { 4 } \mathrm { C l } )$在五次循环中对 [[全氟和多氟烷基物质|PFAS]] 的[[解吸效率]]下降了 30−40%，而含 MeOH 的溶液（例如，1% NaCl−MeOH 混合物、50% MeOH 和 100% MeOH）则保持了 >92% 的效率（图 S31），这归因于其更强的[[亲氟相互作用]]破坏能力和位点[[吸附剂再生|再生]]能力。[[循环吸附测试]]也呈现出相同趋势：经盐溶液洗脱的 [[F9氟化水凝胶|F9]] 在五次循环后效率下降了 20−40%，而采用 MeOH 维持性能的体系仍保留了约 90% 的[[吸附能力]]（图 5a）。值得注意的是，[[含氟水凝胶]]的表现优于传统[[吸附剂]]（[[活性炭]]、[[吸附树脂|树脂]]），即使在较低[[有机溶剂]]浓度下也能实现[[解吸|高效解吸]]（50% MeOH，而其他[[吸附]]剂为 70−100%；图 5b、表 S9）。基于 1% NaCl 或 50% MeOH 在[[批量吸附试验|批量试验]]中的良好表现及其在长期应用中的实际可行性，[[柱洗脱|柱洗脱研究]]采用了这两种洗脱剂。具体而言，50% MeOH 在 12 [[床体积|BV]] 内实现了 80% 的[[回收率]]和 51 倍的 PFAS 富集，而使用 1% NaCl 时的回收效率为 50%，[[富集倍数]]为 10 倍（图 5c−e）。MeOH 的高效性与溶剂用量的减少相结合，显然能够降低[[环境足迹]]和运行成本，推动规模化应用。这种优异性能在传统吸附剂的[[柱实验]]中很少见。13,14

此前报道的[[吸附树脂|树脂]]（例如，[[PFA300 树脂|PFA300]]、[[Dow Marathon A 树脂|Dow Marathon A]]、[[XAD4 树脂|XAD4]] 等）需要较高浓度的 [[氯化钠|NaCl]] 和 [[甲醇|MeOH]]［例如，5−10% [[氯化钠甲醇混合洗脱剂|NaCl−MeOH]]（V/V = 3/7）或 100% MeOH］才能[[吸附剂再生|再生]]并达到相近的[[回收率]]。<sup>82,83</sup>[[全氟和多氟烷基物质|PFAS]] 与[[活性炭]]之间的强相互作用阻碍了其在常规条件下使用[[有机溶剂]]进行再生。<sup>82,84</sup>相比之下，[[含氟水凝胶]]中适度的 PFAS−[[吸附剂]]相互作用有利于[[解吸]]，凸显出[[亲氟吸附位点|亲氟位点]]的构建能够平衡[[吸附]]与解吸。关键的是，[[F9 含氟水凝胶|F9]] 表现出优异的[[循环稳定性]]，[[SEM]] 图像和[[元素分析]]（图 S32−34、表 S10）证实，无论使用何种[[洗脱剂]]，经过多次循环后，其[[孔隙结构]]仍保持完整，[[表面组成]]（C、N、O 和 F）仍保持均匀。这些结果共同表明，[[氟化水凝胶|含氟水凝胶]]是一类可持续的高性能 PFAS 管理材料，能够兼顾高效捕获、经济再生和[[结构稳定性]]。

## ■ 环境意义

本研究提出了一种[[含氟水凝胶|氟化水凝胶]]平台，该平台经设计具有在结构上与 [[全氟和多氟烷基物质|PFAS]] 分子相匹配的[[亲氟吸附位点|富氟位点]]，能够通过占主导作用的 [[氟氟相互作用|C−F·· F−C 相互作用]]实现[[选择性吸附]]。该[[水凝胶]]在复杂[[环境基质]]（[[自来水]]、[[湖水]]）中表现出稳定的性能，能够稳定捕获 PFAS，并在多次[[吸附剂再生|再生]]循环后保持[[结构完整性]]。使用盐水（[[解吸效率|解吸率]]为 60−80%）或 50% [[甲醇|MeOH]]（[[解吸]]率 >92%）进行再生可破坏[[亲氟相互作用]]，从而实现高效重复利用，同时[[吸附容量]]损失极小（五次循环后保留约 90%），且[[富集倍数]]较高（盐水为 10 倍，MeOH 为 51 倍），这对于其在[[水处理系统]]中的规模化应用至关重要。其与[[连续流运行]]的兼容性、在 12 [[床体积|BV]] 内达到平衡的能力，以及较低的溶剂需求（50% MeOH，而传统[[吸附剂]]为 70-100%），凸显了其在成本、环境影响以及与现有基础设施整合方面的实际优势。

[[亲氟功能化吸附剂]]为去除 [[全氟和多氟烷基物质|PFAS]] 提供了一种有前景的策略。然而，[[分散性]]有限、[[吸附容量]]中等以及深度去除不足等挑战，凸显了采用综合策略的必要性。未来的研究可着重于引入[[氢键位点]]或[[阳离子位点]]，以提高对极性/[[阴离子型全氟和多氟烷基物质|阴离子型 PFAS]] 的亲和力；将[[亲氟性]]与[[疏水相互作用]]或 [[π-π 相互作用|π−π 相互作用]]相结合，以拓宽适用范围；以及优化[[孔隙结构]]，以增强[[痕量污染物]]对[[吸附位点可及性|吸附位点的可及性]]。与此同时，[[吸附剂再生|再生]]过程中产生的浓缩 PFAS [[洗脱液]]（$( \mu \ g \ L ^ { - 1 }$ 至 mg $\mathrm { L } ^ { - 1 } \bar { ) }$）也值得关注。这些液流可采用[[高级氧化]]（例如 [[紫外光活化过硫酸盐技术|UV/过硫酸盐]]、[[光催化]]）<sup>85,86</sup>或[[还原工艺]]（例如 [[紫外光碘化钾还原技术|UV/KI]]、[[紫外光亚硫酸盐还原技术|UV/亚硫酸盐]]）<sup>86,87</sup>进行处理，通过[[自由基]]或[[水合电子]]介导的 [[碳氟键断裂|C−F 键断裂]]，实现超过 90% 的[[脱氟率]]。弥合实验室结果与实际应用之间的差距，不仅需要这些提升性能的改性措施，还需要可规模化的合成方法、现场验证，以及针对不同 PFAS 化学特性和[[共存污染物]]开发的[[多功能吸附剂]]。因此，将分子层面的设计与环境应用的实用性相结合，为 PFAS 控制提供了一条可持续的发展路径。
