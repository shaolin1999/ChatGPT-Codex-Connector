# 采用[[聚合诱导微相分离]]方法制备用于捕获 [[全氟和多氟烷基物质|PFAS]] 的[[阴离子交换微球|阴离子交换微珠]]

查看更新

引用本文：[[RSC Applied Polymers|RSC Appl. Polym.]], 2026, 4, 1596

[[Ali Arshad]], <sup>a</sup> [[Jongho Back]], <sup>a</sup> [[Katharine A. Faber]], <sup>b</sup> [[William A. Arnold]], \*<sup>b</sup> [[Philippe Bühlmann]] \*<sup>a</sup> 和 [[Marc A. Hillmyer]] \*<sup>a</sup>

[[全氟和多氟烷基物质]]（PFAS）兼具[[疏水性]]、[[疏油性]]以及化学和[[热稳定性]]，因此被用于多种消费品，包括[[不粘涂层]]、包装材料、化妆品和消防泡沫。这些性质也导致其对人体产生毒性，并使其在环境中积累。目前已有多种方法用于去除环境中的 PFAS 污染物，其中一种常用技术是通过[[离子交换]]进行去除。[[聚合诱导微相分离]]（polymerization-induced microphase separation，PIMS）能够合成用于捕获 PFAS 的[[阴离子交换微球|阴离子交换微珠]]，其在[[机械性能]]稳健的[[交联网络]]内具有[[双连续形貌]]、可调的[[畴间距]]和高[[表面可及性]]。采用基于[[聚己内酯嵌段聚4-乙烯基苄氯|聚(ε-己内酯)-b-聚(4-乙烯基苄氯)]]的[[大分子链转移剂]]、[[苯乙烯]]和[[二乙烯基苯]]合成了[[微球|微珠]]。通过[[蚀刻]]去除[[聚己内酯|聚(ε-己内酯)]]组分并对[[聚4-乙烯基苄氯|聚(4-乙烯基苄氯)]]进行[[季铵化]]，获得了[[阴离子交换]]微珠，测得其[[离子交换容量]]为 1.00 ± 0.05 mmol g<sup>−1</sup>。采用[[准二级动力学模型|准二级动力学]]分析，评估了短链（[[三氟乙酸]] [TFA] 和[[全氟丁酸]] [PFBA]）及长链（[[全氟辛酸]] [PFOA]）PFAS 的去除速率。与 [[Amberlite IRA 900树脂|Amberlite IRA 900]] 完整树脂相比，[[季铵化微珠PB-Q|季铵化微珠]]（[[PB-Q]]）对 TFA 和 PFBA 的[[初始吸附速率]]分别为其 2.9 倍和 2.3 倍。相比之下，[[Amberlite IRA 900|IRA 900]] 完整树脂对 PFOA 的初始[[吸附速率]]为 [[季铵化微球PB-Q|PB-Q]] 的 1.7 倍。[[Langmuir吸附等温线模型|Langmuir 等温线]]分析表明，尽管 [[Amberlite IRA 900阴离子交换树脂|IRA 900]] 的[[吸附容量]]更大，但所有 PFAS 对 PB-Q 的[[吸附亲和力|亲和力]]均显著高于对 IRA 900 的亲和力，这表明 PB-Q 在去除低浓度 PFAS 方面更为有效。使用[[甲醇]]与 1 M ${ \mathsf { N a C l } } _ { ( \mathsf { a q } ) }$ 按 1: 1 y/y 配制的混合液处理负载 PFAS 的 PB-Q 微珠，实现了 100% 的 PFAS [[解吸]]。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是一类人为合成的化学物质，其特征是具有高度氟化的碳链和末端[[官能团]]。<sup>1,2</sup> PFAS 的两个主要类别分别具有[[羧酸端基]]，称为[[全氟和多氟羧酸]]（PFCAs），或具有[[磺酸端基]]，称为[[全氟和多氟烷基磺酸]]（PFSAs）。碳原子数 <8 的 PFCAs 和碳原子数 <6 的 PFSAs 被称为短链 PFAS，而碳原子数分别为 ≥8 和 ≥6 的则被视为长链 PFAS。<sup>3</sup> PFAS 兼具[[疏水性]]和[[疏油性]]，因此具有独特的性质，适用于多种消费品，包括防污服装、[[水性消防泡沫]]、不粘锅、化妆品和食品包装。<sup>4</sup> 然而，PFAS 中 [[碳氟键|C–F 键]]的高度[[化学稳定性]]和[[热稳定性]]使其能够发生[[生物累积]]，并在空气、水和土壤中持久存在。<sup>5–8</sup> 此外，PFAS 与多种健康问题有关，包括[[致癌性]]，以及[[发育毒性]]、[[遗传毒性]]、[[肝脏毒性]]、[[生殖毒性]]、[[免疫毒性]]、[[细胞毒性]]、[[神经毒性]]和[[激素毒性]]。<sup>9,10</sup> 因此，[[美国环境保护署]]已针对饮用水中部分 PFAS 的允许含量制定了限值。<sup>11,12</sup>

使用固态介质进行[[吸附]]是从水中捕获 [[全氟和多氟烷基物质|PFAS]] 的一种常见且实用的方法。由于许多 PFAS 具有[[两亲性]]，其[[吸附机制]]较为复杂。一方面，[[全氟和多氟羧酸|PFCAs]] 和 [[全氟和多氟烷基磺酸|PFSAs]] 的[[亲水头基]]因其较低的 $\mathsf { p } K _ { \mathbf { a } }$ 值，在中性 [[pH]] 下处于[[去质子化]]状态。

另一方面，[[全氟和多氟烷基物质|PFAS]] 还具有疏水且疏油的尾链，其尺寸决定了[[范德华相互作用]]的程度。<sup>13,14</sup> PFAS 的[[吸附]]通常依赖于化学相互作用、[[静电相互作用]]、[[氢键]]和范德华相互作用的共同作用。<sup>15–17</sup> 多种材料已被提出并用于去除受污染水体系中的 PFAS，包括[[活性炭|颗粒状/粉末状活性炭]]、[[离子交换树脂]]、[[颗粒状环糊精基树脂]]、[[金属有机框架|金属–有机框架]]、[[沸石|无机沸石]]和[[介孔有机硅]]。<sup>18–21</sup> 其中，[[阴离子交换树脂]]是去除 [[全氟和多氟羧酸|PFCAs]] 和 [[全氟和多氟烷基磺酸|PFSAs]] 的一类有前景的[[吸附剂]]，因为这些树脂上固定的[[阳离子官能团]]与 PFCAs 和 PFSAs 的[[阴离子头基]]之间存在强静电相互作用。这些[[离子相互作用]]通常还伴随着其[[氟化尾链]]与树脂基体之间的[[疏水相互作用]]。

[[阴离子交换树脂]]通常是以[[苯乙烯]]或[[丙烯酸酯]]为基础的聚合物网络，一般通过常规[[悬浮聚合]]方法制备。<sup>22,23</sup> 精确控制[[孔径]]对于调节 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]行为至关重要，但在这类材料中实现这一点可能具有挑战性。<sup>24,25</sup> 这些材料大多需要多步合成，并要求在稀溶液条件下进行，这阻碍了其规模化生产。然而，[[聚合诱导微相分离]]（polymerization-induced microphase separation，PIMS）通过在单一步骤中将聚合与[[纳米结构]]形貌的形成相结合，克服了这些局限。这种方法可在[[机械性能|力学性能]]稳健的[[交联网络]]中形成具有可控[[相区尺寸]]和[[可接近表面积]]的[[双连续形貌]]。<sup>26</sup> 我们采用悬浮聚合制备适用于[[填充床]]应用的均匀[[微球]]。结构的精确可控性、永久电荷功能性以及可规模化生产的特点，使 PIMS 成为合成用于去除 PFAS 的[[强碱性阴离子交换微球]]的一种有吸引力的选择。PIMS 使用[[大分子链转移剂]]（macro-CTA），通过单体和[[交联剂]]的[[可逆加成断裂链转移聚合|可逆加成–断裂链转移]]（RAFT）聚合进行[[扩链]]。在聚合过程中，macro-CTA 与所形成的[[交联]]网络之间的不相容性会产生[[相分离]]区域，从而形成双连续形貌。<sup>27</sup> 该技术已被用于制备具有多种用途的材料，包括[[聚合物电解质]]、[[介孔材料]]、[[分离膜]]以及用于 [[3D打印|3D 打印]]的墨水。<sup>28–32</sup> 通过在悬浮聚合方法中采用 PIMS 策略，已成功制备出具有[[介孔结构]]的[[阴离子交换]]树脂，且这些材料能够有效吸附[[阴离子染料]]。<sup>33</sup>

本文报道了采用 [[聚合诱导微相分离|PIMS]] 合成用于去除 [[全氟和多氟烷基物质|PFAS]] 的[[阴离子交换微球]]。首先通过 ε-己内酯（CL）的开环聚合（[[开环聚合|ROP]]），随后通过 4-乙烯基苄氯（VBC）的 [[可逆加成断裂链转移聚合|RAFT 聚合]]，合成了双嵌段 [[大分子链转移剂|macro-CTA]]。按照我们此前报道的方法，采用[[悬浮RAFT聚合|悬浮 RAFT 聚合]]，使双嵌段 macro-CTA 与[[苯乙烯]]和[[二乙烯基苯]]进行[[扩链]]，获得[[微球]]。<sup>33</sup> 随后分别对[[聚己内酯|聚（ε-己内酯）]]（PCL）和[[聚4-乙烯基苄氯|聚（4-乙烯基苄氯）]]（[[聚氯甲基苯乙烯|PVBC]]）嵌段进行[[刻蚀]]和[[季铵化]]处理，得到[[阴离子交换]]微球。采用三种不同的 PFAS 测试其 PFAS [[吸附]]性能：[[三氟乙酸]]（TFA）、[[全氟丁酸]]（PFBA）和[[全氟辛酸]]（PFOA）。由于常用的商业[[阴离子交换树脂]] [[Amberlite IRA 900|IRA 900]] 与我们合成的材料在结构上相似，因此将其用作比较对照。测定了[[吸附动力学]]和[[吸附等温线]]，并采用[[准二级动力学模型|准二级动力学]]、[[颗粒内扩散]]、[[Langmuir吸附等温线模型|Langmuir]] 和 [[Freundlich吸附等温线模型|Freundlich 模型]]对数据进行拟合。最后，还证实了 PFAS 可从阴[[离子交换]]微球中成功[[解吸]]。本研究为制备能够吸附 PFAS 的离子交换材料提供了一条新的合成路线。该合成方法也适用于具有特定[[离子交换容量]]和[[离子交换动力学]]特性的其他材料。

## 2. 材料与方法

## 2.1. 材料

除非另有说明，所有化学品均购自商业渠道，并按收到时的状态直接使用。ε-己内酯（TCI）以氢化钙（Sigma-Aldrich）为干燥剂，经减压蒸馏纯化。[[苯乙烯]]（Sigma-Aldrich）、4-乙烯基苄氯（VBC；90%，Sigma-Aldrich）、[[二乙烯基苯]]（工业级，Sigma Aldrich）和[[乙二醇]]（Fisher Scientific）在使用前均通过短碱性氧化铝（Sigma-Aldrich）柱处理。聚乙烯醇（PVA，15–23 kg mol<sup>−1</sup>，[[水解]]度为 87–89%）购自 Sigma-Aldrich。磷酸二苯酯（[[磷酸二苯酯|DPP]]，Sigma-Aldrich）、4-二甲氨基吡啶（DMAP，Sigma-Aldrich）、二异丙基碳二亚胺（DIC，Oakland Chemical）、偶氮二异丁腈（[[偶氮二异丁腈|AIBN]]，Sigma-Aldrich）和过氧化二月桂酰（Sigma-Aldrich）均未经进一步纯化即使用。用于[[蚀刻]]和[[季铵化]]的[[三氟乙酸]]（TFA，98%，Sigma-Aldrich）和[[三甲胺]]（TMA，45% H O 溶液，Sigma-Aldrich）均按收到时的状态直接使用。去离子水使用 Milli-Q PLUS 试剂级水过滤系统纯化至电阻率为 18.2 MΩ cm（Millipore，USA），并用于电导滴定。[[羟基化DDMAT|DDMAT-OH]]、[[聚己内酯大分子链转移剂|PCL-CTA]] 和 [[PCL-b-PVBC-CTA]] 按照 SI 中给出的实验方案合成（[[核磁共振|NMR]] 谱图见图 S1–S4）。在 [[全氟和多氟烷基物质|PFAS]] [[吸附]]实验中，TFA（98%，Sigma-Aldrich）和[[全氟辛酸]]（PFOA，95%，Sigma Aldrich）以酸形式使用。[[全氟丁酸]]（PFBA）以其盐形式，即七氟丁酸钠（98%，Oakwood Chemical）使用。批次吸附和等温线实验中的 PFAS 溶液均使用去离子水配制。市售 [[Amberlite IRA 900树脂|Amberlite IRA 900]]（Cl<sup>−</sup> 型，Sigma-Aldrich）[[阴离子交换树脂]]珠以完整和破碎两种形式用于 PFAS 吸附实验中的对比。为获得破碎的 [[Amberlite IRA 900|IRA 900]]，使用瓷研钵和研杵将完整树脂珠研碎，并通过 180 目（90 µm）和 300 目（50 µm）钢筛筛分。[[Amberlite IRA 900阴离子交换树脂|IRA 900]] 是一种[[大孔强碱性I型阴离子交换树脂|大孔强碱性 I 型阴离子交换树脂]]，广泛应用于工业脱盐和有机物去除。<sup>34</sup>它是苯乙烯和二乙烯基苯的共聚物，带有三甲基铵甲基（–CH – $\mathbf { N } ^ { + } ( \mathrm { C H } _ { 3 } ) _ { 3 } )$ [[官能团]]。

## 2.2. 仪器设备

质子核磁共振（<sup>1</sup>H-[[核磁共振|NMR]]）谱采用 400 MHz Bruker Avance III HD 波谱仪在氘代氯仿（CDCl ）中采集。氟核磁共振 $\mathbf { \binom { 1 9 } { F - N M R } }$ 谱采用配备 5 mm [[三共振低温探头]]的 600 MHz Bruker Avance Neo 波谱仪采集。所有 NMR 谱均使用 MestReNova 软件进行处理和分析。以四氢呋喃（THF，Sigma-Aldrich）为流动相，使用配备 Wyatt Dawn 多角度光散射检测器和 Wyatt Optilab 示差折光检测器的 Wyatt Waters SEC 仪采集尺寸排阻色谱（SEC）图。衰减全反射–傅里叶变换红外（ATR-[[FTIR]]）光谱使用 Agilent Cary 630 [[傅里叶变换红外光谱|FTIR 光谱]]仪采集。在采集 FTIR 光谱之前，使用研钵和研杵将[[微球]]研磨成细粉。将微球镀上 2 nm 厚的铂层后，使用 Hitachi SU8230 场发射[[SEM|扫描电子显微镜]]采集[[扫描电子显微镜]]（SEM）图像。使用 AmScope 数码显微镜拍摄微球图像，并使用 ImageJ 软件测量[[粒径]]分布。氮气[[吸附等温线]]使用 Quantachrome autosorb iQ 气体[[吸附]]分析仪测定，采用带球泡的 9 mm 样品管，每个样品使用 70–90 mg 微球。所有样品均在室温下脱气 24 h 后再采集数据。使用 ASiQwin 软件处理数据，采用 Brunauer–Emmett–Teller（[[BET]]）模型计算[[比表面积]]，采用淬火固体[[DFT|密度泛函理论]]（QSDFT）模型计算[[孔径分布]]。

[[热重分析]]（TGA）使用 TA Instrument TGA Q500 在氮气气氛下进行，升温速率为 $5 ~ \mathrm { { ^ { o } C } ~ m i n ^ { - 1 } }$。[[小角X射线散射|小角 X 射线散射]]（SAXS）数据在[[先进光子源]]（Argonne，IL）的 [[杜邦–西北大学–陶氏协作使用团队|DND-CAT]] 5ID-D [[同步辐射光束线|光束线]]上采集，光子波长为 $\lambda = 0 . 7 2 9 3$ Å，使用 Rayonix MX170-HS 检测器，曝光时间为 0.2 s。将[[微球]]填入 Tzero DSC 样品盘中进行表征，并从所得数据中扣除样品盘（空白）的 SAXS 数据。在[[离子交换容量]]实验中，使用配备 HI76310 电导率探头、HI7662 温度探头和 Cole Palmer [[pH]] 电极的 Hanna Instruments 多参数台式测量仪 HI2550 测量电导率和 pH。

## 2.3. 实验方法

2.3.1. 含 [[聚己内酯嵌段聚4-乙烯基苄氯|PCL-b-PVBC]] 的[[微球]]（[[未刻蚀微球PB-S|PB-S]]）的合成。为通过[[悬浮RAFT聚合|悬浮 RAFT 聚合]]合成微球，将 500 mL 浓度为 0.5 M 的 $\mathrm { { N a C l } _ { ( a q ) } }$ 溶液和 2.2 g PVA 加入 ChemGlass 反应容器（CG-1920-01）中。将反应器盖（CG-1940-01）安装到反应器主体上，并将三叶玻璃搅拌轴（CG-2079-A-01）连接至 Heidolph 顶置式搅拌器。将反应容器浸入油浴中，在以 300 rpm 搅拌的同时将溶液温度升至 $7 0 ~ ^ { \circ } \mathrm { C }$，以确保 PVA 完全溶解。随后将水溶液冷却至室温，并通入氩气吹扫 20 min。

与此同时，将 6 g [[PCL-b-PVBC-CTA]] 溶解于玻璃小瓶中的 14 g [[苯乙烯]] : [[二乙烯基苯]]（摩尔比为 2 : 1）中，并向小瓶中加入 44 mg 过氧化月桂酰和 2 mL 甲苯。过氧化月桂酰用作[[悬浮聚合]]中的 [[可逆加成断裂链转移聚合|RAFT 聚合]][[引发剂]]，PVA 用作表面活性剂。向溶液中鼓入氩气 10 min 以脱气。在使用顶置式机械搅拌器以 600 rpm 持续搅拌的条件下，用注射器将有机混合物逐滴加入水溶液中。随后，将反应悬浮液的温度升至 90 $^ { \circ } \mathrm { C } ,$，并以 600 rpm 的恒定速率继续搅拌 20 h。将反应悬浮液冷却至室温，通过真空过滤回收黄色[[微球|微珠]]，随后用水和[[甲醇]]（MeOH）洗涤数次。将回收的微珠置于真空烘箱中，在 $5 0 ~ ^ { \circ } \mathrm { C }$ 下干燥过夜。

2.3.2. $$

$$

## 3. 结果与讨论

## 3.1. [[阴离子交换微球]]的制备

采用 [[聚己内酯嵌段聚4-乙烯基苄氯|PCL-b-PVBC]] [[二嵌段共聚物|二嵌段聚合物]]合成[[阴离子交换微球]]。由于 [[聚己内酯|PCL]] 嵌段在酸性和碱性条件下易于降解，因此选择其作为[[牺牲嵌段]]以形成[[介孔]]。<sup>47</sup> 如先前报道所述，[[聚4-乙烯基苄氯|PVBC]] 嵌段用作前体，通过聚合后在[[苄位碳]]上进行[[季铵化]]，在孔壁上引入[[正电荷]]。<sup>33,37</sup> 首先，通过[[酯化反应]]，使用[[乙二醇]]对 [[2-(十二烷基硫代羰基硫基)-2-甲基丙酸]]（DDMAT）进行[[端基修饰]]（图 1）。随后，以所得 [[羟基化DDMAT|DDMAT-OH]] 为[[引发剂]]，[[磷酸二苯酯|DPP]] 为[[酸催化剂]]，通过 [[开环聚合|ROP]] 制备 PCL [[均聚物]]（[[聚己内酯大分子链转移剂|PCL-CTA]]）。<sup>48</sup> 然后，以 [[偶氮二异丁腈|AIBN]] 为引发剂，通过 [[可逆加成断裂链转移聚合|RAFT 聚合]]从 PCL-CTA 上生长出 [[聚氯甲基苯乙烯|PVBC]] 嵌段，得到 [[PCL-b-PVBC-CTA]]。

采用[[悬浮RAFT聚合|悬浮 RAFT 聚合]]合成[[微球|微珠]]（图 1）。我们选择 [[PCL-b-PVBC-CTA]] 的投料质量分数为 30 wt%，[[苯乙烯]]和[[二乙烯基苯]]（摩尔比为 2 : 1）的投料质量分数为 70 wt%，目标是在完成所有[[聚合后改性]]步骤后，使[[电荷密度]]达到 1 mmol $\mathrm { g } ^ { - 1 }$（假设所有[[苄氯基团]]均以 100% 的[[转化率]]转化为[[季铵基团]]）。微珠的尺寸取决于[[悬浮聚合]]过程中的搅拌速率，<sup>33</sup> 因此，搅拌速率保持在 600 rpm。

[[微球|微珠]]的[[刻蚀]]和[[季铵化]]分两个独立步骤进行（图 1）。碱性条件已被用于[[蚀刻|刻蚀]] $\mathbf { P C L } ;$ 然而，我们观察到，在我们专门配制的微珠中，[[聚己内酯|PCL]] 的刻蚀相当缓慢且不完全，这一点由以下物质的存在所证实： $\scriptstyle \mathrm { C = } \mathbf { O }$ PCL 在 1730 处的[[伸缩振动|伸缩振动峰]] $\mathrm { c m } ^ { - 1 }$ （图 S7）。残留的 PCL 增加了微珠的总重量，从而降低了单位质量的[[离子交换容量]]（IEC）。此外，[[聚4-乙烯基苄氯|PVBC]] 中的 [[碳氯键|C–Cl 键]]在碱性条件下可发生[[水解]]，这可由以下强度的降低表明： $\mathrm { C H } _ { 2 } .$ –Cl [[摇摆振动|摇摆振动峰]]位于 1264 $\mathrm { c m } ^ { - 1 }$ （图 S7）。C–Cl 键的损失减少了可用的季铵化位点数量，也导致 IEC 降低。因此，我们优化了 PCL 的刻蚀条件，并使用了[[三氟乙酸]]（TFA）与 [[甲醇|MeOH]] 按 1 : 1（v/v）混合的溶液。<sup>35</sup> 图 2 展示了合成所得微球（[[未刻蚀微球PB-S|PB-S]]）、刻蚀后的微球（[[刻蚀微球PB-E|PB-E]]）和季铵化后的微球（[[PB-Q]]）的 [[衰减全反射傅里叶变换红外光谱|ATR-FTIR 光谱]]。使用 TFA 消除了副反应，这可由以下特征的缺失看出： PB-E 的 [[傅里叶变换红外光谱|FTIR 光谱]]中 [[聚氯甲基苯乙烯|PVBC]] 的 $\mathrm { C H } _ { 2 } \mathrm { - C l }$ 摇摆振动信号强度的变化。同时，PCL 的 $\mathrm { C } { = } \mathrm { \bf { O } }$ 伸缩振动峰消失，表明 PCL 已被完全刻蚀。

在第二步中，用[[三甲胺]]（TMA）处理 [[刻蚀微球PB-E|PB-E]]，使 Cl 被 TMA 取代，生成相应的[[季铵阳离子|季铵离子]] $\left( - \mathbf { C H } _ { 2 } \mathbf { - N } ^ { + } ( \mathbf { C H } _ { 3 } ) _ { 3 } \right)$ 。我们使用 TMA，以获得[[空间位阻]]较小的小尺寸季铵阳离子。<sup>49</sup> 在 [[PB-Q]] 的 [[衰减全反射傅里叶变换红外光谱|ATR-FTIR 光谱]]（图 2）中，1264 cm<sup>−1</sup> 处的 $\mathrm { C H } _ { 2 } \mathrm { - C l }$ [[摇摆振动|摇摆振动峰]]消失，并在 $1 2 2 0 ~ \mathrm { { c m } ^ { - 1 } }$ 处出现了 [[碳氮键伸缩振动|C–N 伸缩振动峰]]，与完全[[季铵化]]相一致。

## 3.4. [[吸附动力学]]

我们观察到，正如预期，[[未刻蚀微球PB-S|PB-S]] 和 [[刻蚀微球PB-E|PB-E]] 对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]很少或几乎没有（图 S12），而 PFAS 在 [[PB-Q]] 和 [[Amberlite IRA 900|IRA 900]] 上的吸附是一个随时间变化的过程（图 5）。储备溶液中 PFAS 与 [[季铵化微珠PB-Q|PB-Q]] 和 [[Amberlite IRA 900树脂|IRA 900]] [[微球]]中[[正电荷]]的摩尔比大于 1。使用式 (1) 和 (2) 对 [[季铵化微球PB-Q|PB-Q]] 和 [[Amberlite IRA 900阴离子交换树脂|IRA 900]] 的数据进行拟合，以评估[[吸附动力学]]。对于 [[三氟乙酸|TFA]] 和 [[全氟丁酸|PFBA]]，PB-Q 和完整 IRA 900 分别在 5 h 和 10 h 达到吸附饱和。对于 [[全氟辛酸|PFOA]]，PB-Q 的饱和时间为 40 h，而完整 IRA 900 在 96 h 内未达到饱和。对于 PFBA 和 PFOA，与直接使用 IRA 900 微球相比，将 IRA 900 微球破碎后能够更快地达到饱和（例如，对于 PFOA，破碎的 IRA 900 在 6 h 达到饱和，而完整 IRA 900 微球则需 4 d）。我们推测，动力学加快是由于[[粒径]]减小，从而改善了 PFAS 向更多暴露的结合位点的传质。使用[[准二级动力学模型]]（图 5）和[[准一级动力学模型]]（图 S13）对动力学数据进行了拟合。准二级和准一级模型的拟合参数分别列于表 1 和表 S3。两种模型均给出了较好的拟合结果，但数据分析采用了准二级模型拟合，因为该模型已广泛用于描述 PFAS 在[[离子交换]]材料上的吸附动力学。<sup>39,40,53,54</sup>

## 3.5. [[吸附等温线]]

图 6(a–c) 展示了 TFA、PFBA 和 PFOA 在 PB-Q 上吸附的 Langmuir 和 Freundlich 等温线。Langmuir 等温线（以实线表示）给出的 PB-Q 对 TFA、PFBA 和 PFOA 的吸附容量分别为 0.180、0.410 和 1.20 mmol $\mathrm { g } ^ { - 1 }$（表 3）。这些数值与表 1 中动力学实验得到的 $q _ { \mathrm { e } }$ 值相近，表明微球在动力学实验的时间范围内已达到其全部吸附容量，因为在时间更长的等温吸附实验中，PB-Q 并未吸附更多的 PFAS。由于微球的 IEC 为 1.00 mmol $\mathbf { g } ^ { - 1 } :$，若假设仅发生离子交换过程，则预计微球上吸附的 PFAS 为 1.00 mmol $\mathrm { g } ^ { - 1 }$。然而，PFOA 的吸附容量高于 IEC，表明离子交换和范德华相互作用均参与了长链 PFAS 在 PB-Q 上的吸附。另一方面，TFA 和 PFBA 的 $q _ { \mathrm { m } }$ 值均低于 PB-Q 的 IEC。这种差异可能由阴离子交换竞争或 PFAS 无法接近功能位点等因素造成。

图 6(d–f) 展示了使用完整 IRA 900 时的吸附等温线。完整 IRA 900 对 PFAS 的吸附容量高于准二级动力学模型得到的数值（表 1）。这种吸附容量上的差异可由 PFAS 对完整 IRA 900 的弱亲和力来解释（由 Langmuir 模型中的 $K _ { \mathrm { L } }$ 和 Freundlich 模型中的 n 表征；表 3 和 S4）。在短时间尺度的动力学实验中，吸附容量较低；然而，在长时间尺度的等温吸附实验中，尽管完整 IRA 900 对 PFAS 的亲和力较低，仍有更多 PFAS 分子能够吸附到其上。未测定粉碎后 IRA 900 的等温线，但我们假设，在平衡状态下，完整微球与粉碎后 IRA 900 的等温线在误差范围内应相同。

对 [[PB-Q]] 与 [[Amberlite IRA 900|IRA 900]] 的 [[Langmuir吸附等温线|Langmuir 吸附等温线]]进行比较表明，[[季铵化微珠PB-Q|PB-Q]] 对[[短链全氟和多氟烷基物质|短链 PFAS]]（[[三氟乙酸|TFA]] 和 [[全氟丁酸|PFBA]]）和[[长链全氟和多氟烷基物质|长链 PFAS]]（[[全氟辛酸|PFOA]]）的[[吸附亲和力|亲和力]]均强于 [[Amberlite IRA 900树脂|IRA 900]]。尽管 PFOA 在 [[季铵化微球PB-Q|PB-Q]] 中的[[初始吸附速率]]低于在 [[Amberlite IRA 900阴离子交换树脂|IRA 900]] 中的初始[[吸附速率]]，但在平衡状态下，PB-Q 对 TFA、PFBA 和 PFOA 的[[去除效率]]更高。例如，根据 390 L mmol<sup>−1</sup> 的 $K _ { \mathrm { L } }$ 值和 [[Langmuir吸附等温线模型|Langmuir 等温线]]方程可知，在样品大量过量的条件下，当样品中 PFOA 浓度为 $2 . 6 \times 1 0 ^ { - 6 }$ M（1.1 ppm）时，PB-Q [[微球]]达到半饱和状态。相比之下，完整 IRA 900 达到半饱和状态所需的 PFOA 浓度为 56 × ${ { 1 0 } ^ { - 6 } }$ M（23 ppm）。TFA 的[[半饱和点]]也呈现类似的比值（PB-Q 和完整 IRA 900 分别为 19 ppm 和 238 ppm）。有趣的是，与完整 IRA 900 相比，PB-Q 对 PFBA 的亲和力提升最为显著，二者的半饱和点分别为 19 ppm 和 $1 . 5 \times 1 0 ^ { 3 }$ ppm。

[[吸附亲和力|亲和力]]的差异可能源于多种因素。首先，[[全氟和多氟烷基物质|PFAS]] 的[[去除效率]]与[[吸附剂]]的[[孔径]]密切相关，研究发现，最佳孔径为 PFAS [[分子尺寸]]的 2.5–4 倍。<sup>24</sup>因此，[[Amberlite IRA 900|IRA 900]] 的较[[大孔]]径（50 nm）可能会减少 PFAS 分子与[[吸附位点]]之间的有效接触，并削弱[[静电相互作用]]，从而对其与 PFAS 分子的亲和力产生不利影响。其次，[[PB-Q]] 具有带[[正电荷]]的线性链，能够与 PFAS 分子有效相互作用，而 [[Amberlite IRA 900树脂|IRA 900]] 的[[带电基团]]则位于孔壁上。[[季铵化微珠PB-Q|PB-Q]] 和 [[Amberlite IRA 900阴离子交换树脂|IRA 900]] 含有相同的[[官能团]]，但其 PFAS [[吸附容量]]不同。IRA 900 每克所含的正电荷数量为 [[季铵化微球PB-Q|PB-Q]] 的 3.5 倍。然而，IRA 900 和 PB-Q 中已[[吸附]]的 [[全氟辛酸|PFOA]] 分子与可用电荷的比值相近。

## 3.6. [[全氟和多氟烷基物质|PFAS]] [[解吸]]

与完整的 [[Amberlite IRA 900|IRA 900]] 相比，在针对三种不同 [[全氟和多氟烷基物质|PFAS]] 化合物的测试中，这些[[微球]]表现出更优的 PFAS [[吸附]]性能。具体而言，它们表现出更高的单位[[正电荷]] PFAS [[吸附量]]、更强的[[吸附亲和力|吸附质–吸附剂亲和力]]，以及更快的[[初始吸附速率]]，但 [[全氟辛酸|PFOA]] 除外，其[[吸附速率]]低于完整的 [[Amberlite IRA 900树脂|IRA 900]]。尽管本研究测试的 [[PB-Q]] 树脂尚未针对[[离子交换容量]]进行严格优化，但 [[聚合诱导微相分离|PIMS]] 合成方法的一项关键优势在于能够调节 IEC 以及包括[[孔径]]在内的其他关键材料参数。未来的研究可通过对[[季铵化聚合物]]的设计和[[分子量]]进行细致的迭代优化，提高 [[季铵化微珠PB-Q|PB-Q]] 的[[离子交换]]容量。由于这些化学和形貌因素会显著影响 PFAS 向[[多孔基体]]内部的[[扩散]]，进而影响初始吸附速率，因此，在本研究已证实的 PFAS 对 [[季铵化微球PB-Q|PB-Q]] 的强亲和力基础上，[[孔结构]]优化可能进一步提高[[季铵化微球]]对[[长链全氟和多氟烷基物质|长链 PFAS]] 的吸附性能。利用 PIMS 优化[[季铵化]]微球的[[化学结构]]，同时考察其对多种 PFAS 的去除性能并评估其可重复使用性，是将这种微球合成策略应用于可规模化[[水处理]]的关键一步。

文献中已报道多种不同浓度的溶液体系可用于从使用后的[[离子交换树脂]]中[[解吸]] [[全氟和多氟烷基物质|PFAS]]，包括 $\mathrm { { N a C l } _ { ( a q ) } , \Delta K C l _ { ( a q ) } , \Delta N H _ { 4 } C l _ { ( a q ) } , }$ $\mathrm { N a O H } _ { \mathrm { ( a q ) } } ,$ [[甲醇]]（MeOH）和[[乙醇]]。<sup>55,56</sup> 图 8 展示了使用水、甲醇、1 M $\mathrm { N a C l } _ { \mathrm { ( a q ) } } ,$ 以及甲醇与 1 M $\mathrm { { N a C l } _ { ( a q ) } . }$ 按 1 : 1 v/v 配制的混合液从 [[PB-Q]] 中解吸 PFAS 的情况。对于上述每种[[溶剂]]，均在每 16 mL 溶剂中加入 10 mg 负载 PFAS 的[[微球]]。使用水时，[[三氟乙酸|TFA]]、[[全氟丁酸|PFBA]] 和 [[全氟辛酸|PFOA]] 的[[解吸率]]分别为 13%、6% 和 1%。MeOH 表现出类似的解吸趋势，TFA、PFBA 和 PFOA 的解吸率分别为 11%、10% 和 8%。1 M $\mathrm { { N a C l } _ { ( a q ) } }$ 溶液对 TFA、PFBA 和 PFOA 的解吸率分别为 100%、84% 和 22%。使用甲醇与 1 M $\mathrm { { N a C l } _ { ( a q ) } . }$ 水溶液按 1 : 1 v/v 配制的溶液，实现了全部三种 PFAS 的完全解吸。这种组合可能发挥了[[协同作用]]，其中甲醇削弱了 PFAS 与微球之间的[[范德华相互作用]]，而 [[氯化钠|NaCl]] 则提供了高浓度的 $\mathrm { C l ^ { - } }$，通过[[竞争性阴离子交换]]置换 PFAS。这些 PFAS 解吸数据与已报道的能够实现高效解吸的溶液体系（盐与[[有机溶剂]]的组合）一致。<sup>41</sup> 这表明，[[季铵化微珠PB-Q|PB-Q]] 捕获的 PFAS 可以被回收，以进行后续处理/销毁。
