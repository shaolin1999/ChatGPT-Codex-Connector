## 摘 要

[[全氟和多氟烷基物质]]（PFAS）因其持久性而造成的[[水污染]]构成了一项重大的环境挑战。本研究评估了通过[[绿色合成]]制备的带正电荷的 [[β-环糊精聚合物]]（β-CDP<sup>+</sup>）对水中[[全氟丁酸]]（PFBA）和[[全氟辛酸]]（PFOA）的去除效果，二者分别代表短链和[[长链全氟和多氟烷基物质|长链 PFAS]]。采用[[阴离子染料]][[甲基橙]]（MO）和[[酸性红1|酸性红 1]]（AR1）作为替代物，以优化 PFAS 的[[吸附]]条件。在 15–50 mg/L 的浓度范围内，β-CDP<sup>+</sup> 对所有污染物均表现出较高的[[去除效率]]（>90%），并在 30 min 内达到平衡。MO、AR1、PFOA 和 PFBA 的[[最大吸附容量]] $\left( \mathrm { Q } _ { \mathrm { m } } \right)$ 分别达到 335 mg/g、384 mg/g、405 mg/g 和 378 mg/g。在存在[[竞争性阴离子]]的情况下，PFBA 和 PFOA 的[[污染物去除效率|去除率]]仍保持在 80% 以上，表明 β-CDP<sup>+</sup> 具有同时去除 PFAS、[[天然有机物|NOM]] 和阴离子染料的潜力。较高的 [[斯皮尔曼秩相关系数|Spearman's ρ]] 值（>0.9）[[验证]]了使用 MO 和 AR1 作为替代物的可行性，反映出它们与 PFAS 具有相似的吸附趋势。[[吸附剂]]的性能取决于[[甲基丙烯酸]]以外的[[缩水甘油基三甲基氯化铵]]（[[甲基丙烯以外的缩水甘油基三甲基氯化铵|GTMAC]]）负载量和[[吸附剂投加量]]，最佳条件为 [[β-环糊精|β-CD]]:[[甲基丙烯酸缩水甘油酯三甲基氯化铵|GTMAC]] [[摩尔比]] 1:5、吸附剂投加量 0.5 g/L 和 [[pH值|pH]] 7。吸附遵循 [[Langmuir吸附等温线模型|Langmuir]] 等温模型 $\mathrm { ( R ^ { 2 } > 0 . 9 8 ) }$ 和准二级动力学模型 $( \mathbb { R } ^ { 2 } > 0 . 9 )$ 。该聚合物在五次循环中仍保持其[[吸附性能]]，损失极小，展示了一种去除[[新兴污染物]]的可持续策略。

## 1. 引言

[[全氟和多氟烷基物质]]（PFASs）是一大类合成化学品，因其优异的化学稳定性、疏水疏油性和耐热性，被广泛应用于[[表面活性剂]]、[[润滑剂]]、[[消防泡沫]]、[[涂层剂]]、不粘锅和食品包装等工业及日常产品中 [1,2]。尽管这些化合物在环境中的浓度相对较低，但由于其难以降解，并会在环境和生物体内累积，进而危害健康，因此被认为是[[持久性环境污染物]]，通常被称为“永久化学品” [3]。此外，[[地下水]]、[[地表水]]和[[垃圾填埋场渗滤液]]等水源中的 PFAS 污染，因其广泛存在及潜在的不良健康影响，已成为全球亟待解决的问题 [4,5]。为应对 PFAS 问题，研究人员探索了多种水处理技术，包括[[光降解]] [6]、[[高级氧化工艺]] [7]、[[臭氧氧化]] [6]、[[膜过滤]] [8,9]、[[泡沫分离]] [10] 和[[吸附]] [11,12]。然而，其中许多方法能耗高、成本高、会产生有毒副产物，或无法去除[[短链全氟和多氟烷基物质|短链 PFAS]]，限制了其大规模应用的可行性。在这些方法中，吸附因其[[去除效率]]高、成本低、操作简便以及能够处理复杂废水基质等优势，成为最高效且环境友好的方法之一 [13]。近年来，研究人员已开发出众多材料，用作去除水和废水中 PFAS 的[[吸附剂]]。[[颗粒活性炭]]（GAC）是处理 PFAS 污染水体最常用的吸附剂之一；然而，它对[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS）等[[长链全氟和多氟烷基物质|长链 PFAS]] 的去除更为有效，对短链 PFAS（即 <C6）的[[污染物去除效率|去除效率]]则较低 [14–16]。[[阴离子交换树脂|阴离子交换（AE）树脂]]对短链 PFAS 具有更强的[[吸附亲和力|亲和力]]、更高的[[吸附容量]]和更快的[[吸附动力学]]，因此其性能优于 GAC，但[[天然有机质]]（[[天然有机物|NOM]]）或[[无机离子]]可能会影响其性能 [17]。因此，亟需开发具有定制表面性质和多功能[[吸附活性位点|活性位点]]的新型吸附剂，使其对 PFAS 具有高[[吸附选择性|选择性]]，或在同时去除多种 PFAS 时表现出更高的吸附容量。

[[β-环糊精]]（β-CD）是一种源自[[淀粉]]的无毒[[环状低聚糖]]，由七个[[葡萄糖]]单元通过 [[α-1,4-糖苷键]]连接而成，形成截锥形结构 [18]。近年来，[[β-环糊精聚合物|β-CD 基聚合物]]（β-CDP）作为一类具有前景的[[吸附剂]]受到了广泛关注。其独特结构具有[[疏水性内腔]]，能够与[[有机污染物]]发生[[主–客体相互作用]]，而富含[[羟基]]（-OH）的[[亲水性外表面]]则有助于捕获污染物，并为进一步[[功能化]]提供丰富的[[吸附活性位点|活性位点]] [19]。然而，带负电荷的污染物，尤其是[[短链全氟和多氟烷基物质|短链 PFAS]]，与中性 β-CDP 的相互作用较弱，因此需要通过[[化学改性]]引入带正电荷的官能团，以提高[[吸附性能]] [20,21]。例如，[[Wang]] 等人首先用[[苯乙烯基团]]对 β-CD 进行改性，随后与[[阳离子甲基丙烯酸酯共聚物]]进行聚合，合成了一种 $\scriptstyle S _ { \mathrm { B E T } }$ 为 237 m<sup>2</sup> g<sup>−</sup> <sup>1</sup> 的多孔[[阳离子β-环糊精聚合物|阳离子 β-CD 聚合物]]。所得 β-CD 聚合物基[[吸附]]剂对纳米级[[超纯水]]中的短链和[[长链全氟和多氟烷基物质|长链 PFAS]] 均表现出 100% 的[[去除效率]] [22]。尽管吸附剂的[[孔隙率]]和高[[BET|比表面积]]对于有效去除 [[全氟和多氟烷基物质|PFAS]] 至关重要，但一个主要局限在于，大多数多孔 β-CD 基材料均采用[[有机溶剂]]合成。这种方法对环境可持续性构成了挑战。因此，迫切需要在环境友好（绿色）条件下开发能够对短链和长链 PFAS 均保持高[[吸附容量]]的 β-CD 基聚合物。最近，[[Li]] 等人开发了一种[[阳离子纳米纤维素]]，这是一种来源丰富的[[生物聚合物]]，其 $\pmb { S } _ { \mathrm { B E T } }$ 为 50.12 $\mathbf { m } ^ { 2 } \ : \mathbf { g } ^ { - 1 }$，用于去除[[地下水]]中的短链和长链 PFAS。然而，由于[[电荷密度]]较低且[[活性位点]]数量不足，其对短链 PFAS 的[[污染物去除效率|去除效率]]受到限制 [23]。此外，如前所述，新兴水处理方法种类繁多，例如[[催化氧化]] [24]、[[光催化]] [25]、[[电化学降解]] [26] 和[[膜基系统]] [27]；然而，这些方法往往面临能耗高、[[膜污染]]、[[吸附选择性|选择性]]有限以及对短链 PFAS 处理效果不佳等挑战。将本研究的 β-CDP<sup>+</sup> 吸附策略置于这一更广泛的背景下，可以凸显其互补优势，即合成简单、具有潜在的环境友好性、对短链和长链 PFAS 均具有较强[[吸附亲和力|亲和力]]，以及能够同时去除染料、[[天然有机物|NOM]] 和 PFAS。这使 β-CD 基吸附剂成为不断发展的先进[[水净化]]技术领域中具有前景的材料。表 1 汇总了以往利用 β-CD 聚合物和其他[[阳离子吸附剂]]增强 PFAS 吸附的研究，并比较了它们的性能。

本研究在[[水相合成|绿色水相条件]]下合成了一种具有高[[电荷密度]]的[[阳离子β-环糊精聚合物|带正电季铵化 β-环糊精聚合物]]，表明高电荷[[吸附剂]]能够显著提高[[短链全氟和多氟烷基物质|短链 PFAS]] 的去除效果。尽管 [[β-环糊精聚合物|β-CD 基聚合物]]在去除[[有机微污染物]]方面已展现出潜力 [19]，但其在 [[全氟和多氟烷基物质|PFAS]] 捕获中的应用仍很少得到探索，且通过系统调控其[[表面电荷]]以靶向[[阴离子污染物]]的研究也较为有限。此外，此前采用染料–PFAS 共暴露方法或以染料作为替代物开展的 PFAS 去除研究，主要集中于其他类别的[[吸附]]剂 [29,30]，在环糊精基体系中的应用较少。为弥补这一空白，我们通过引入[[季铵官能团]]，在绿色水相条件下合成了电荷密度可控的带正电 [[β-环糊精|β-CD]] 聚合物（β-CDP<sup>+</sup>）。该改性旨在增强其与 PFAS 的[[静电相互作用]]，同时利用[[甲基橙]]（MO）和[[酸性红1|酸性红 1]]（AR1）等染料的吸附行为，作为预测 PFAS [[吸附性能]]的工具。采用 X 射线衍射（[[XRD]]）分析、傅里叶变换红外（[[傅里叶变换红外光谱|FT-IR]]）光谱、[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）、[[Zeta电位|Zeta 电位]]分析、[[热重分析]]（TGA）以及 Brunauer Emmett Teller（[[BET]]）测定对所制备的聚合物进行表征，以确定其结构和物理化学性质。针对短链（[[全氟丁酸|PFBA]]）和长链（[[全氟辛酸|PFOA]]）PFAS 的去除，系统评估了溶液 [[pH值|pH]]、[[吸附剂投加量]]、污染物浓度、[[吸附等温线]]、动力学和[[吸附剂可重复使用性|可重复使用性]]等关键参数。研究结果表明，[[电荷调控]]的 β-CD 聚合物为开发用于[[废水处理]]和[[水净化]]的高性能、可持续吸附剂提供了一条可行途径。

## 2. 材料与方法

## 2.1. 材料

[[β-环糊精]]（β-CD，≥97%）、合成用[[环氧氯丙烷]]（EP ≥99%）、[[缩水甘油基三甲基氯化铵]]（[[甲基丙烯以外的缩水甘油基三甲基氯化铵|GTMAC]]，≥90%）、[[氢氧化钠]]（NaOH，≥98%）和[[硝酸]] $\mathrm { ( H N O _ { 3 } , }$ 70%）均购自 [[Sigma-Aldrich]]，未经进一步纯化即使用。

[[甲基橙]]（MO）、[[酸性红1|酸性红 1]]（AR1）、[[全氟辛酸]]（PFOA）和[[全氟丁酸]]（PFBA）也购自 [[Sigma-Aldrich|Sigma Aldrich]]，其物理化学性质汇总于表 2。所有溶液均使用[[去离子水|去离子（DI）水]]配制。

## 2.2. [[β-环糊精聚合物|β-CDP]]<sup>+</sup> 的制备流程

${ \mathrm { \ p - C D P ^ { + } } }$ 参照先前确立的方法并稍作修改，在温和、节能的条件下，完全于水介质中通过[[缩聚反应]]合成 [34]。${ \mathrm { \ p - C D P ^ { + } } }$ 的具体合成步骤如下。

## 3.1. [[β-环糊精聚合物|β-CDP]]<sup>+</sup> 的表征

## 3.3. [[吸附等温线]]

[[吸附]]研究对于理[[解吸]]附过程的性质，以及定量分析 ${ \mathrm { \beta - C D P ^ { + } } }$ 对[[有机污染物]]的[[最大吸附容量]]至关重要。如图 $7 , \mathsf { \beta \mathrm { \beta \mathrm { - } C D P ^ { + } } }$ 所示，其对所有研究污染物，即 [[甲基橙|MO]]、[[酸性红1|AR1]]、[[全氟辛酸|PFOA]] 和 [[全氟丁酸|PFBA]]，均表现出较高的[[吸附容量]]，[[平衡吸附容量]] $\mathrm { ( Q _ { e } ) }$ 分别为 335、384、405 和 378 mg/g。PFOA 的吸附容量最高，这是因为作为一种[[长链全氟和多氟烷基物质|长链 PFAS]]，它同时受益于与 $\mathsf { \beta { \mathrm { - } } C D P ^ { + } }$ 之间的[[静电相互作用|静电作用]]和[[疏水相互作用|疏水作用]]，这两种作用协同增强了吸附。这一趋势与 [[Li]] 等人的研究结果一致，该研究报道了[[阳离子纳米纤维素]]对短链和长链 [[全氟和多氟烷基物质|PFAS]] 的去除 [23]。PFBA 的吸附容量较低（378 mg/g），但这一数值仍显著高于先前研究报道的数值 [40–43]。通过将实验数据拟合至[[吸附等温线模型|等温线模型]]，可以为优化吸附系统、有效去除水溶液中的污染物提供依据。这些研究还揭示了[[吸附质]]分子如何与[[吸附剂]]表面相互作用并覆盖其表面。

## 3.5. [[全氟和多氟烷基物质|PFAS]] 在 $\beta { \mathrm { - } } C D P ^ { + }$ 上的[[吸附机制]]

根据[[吸附等温线]]（第 3.3 节）和[[吸附动力学]]（第 $3 . 4 ) ,$ 节），该[[吸附]]过程符合物理化学单分子层机制，其中，对所有研究污染物的吸附均以[[物理吸附]]为主。尽管许多研究将准二级（[[准二级吸附动力学模型|PSO]]）动力学模型与[[化学吸附]]联系起来，但应谨慎解读这种关联，因为 PSO 模型描述的是[[吸附速率]]行为，其本身并不能提供化学键形成的直接证据 [48,49]。因此，区分物理吸附与化学吸附需要补充证据。这包括通过光谱和[[表面表征|表面表征分析]]（即 [[FTIR]]、[[BET]]、[[CHN元素分析|CHN 元素分析]]等）识别[[表面官能团]]或结合环境的潜在变化，同时还需考虑[[吸附剂]]和[[吸附质]]的化学结构及其相互作用的性质，如[[静电吸引作用|静电吸引]]、[[氢键]]和[[疏水相互作用]]。在本研究中，物理吸附主要归因于 ${ \mathrm { \ p - C D P ^ { + } } }$ 表面带正电的[[铵基团]]与 [[全氟和多氟烷基物质|PFAS]] 和染料的阴离子头基之间的[[静电相互作用|静电吸引]]。此外，PFAS 的[[全氟化尾链]]与 [[β-环糊精空腔|β-CD 疏水空腔]]之间的疏水相互作用也有助于物理吸附过程。由于合成的 ${ \mathrm { \ p - C D P ^ { + } } }$ 为[[非多孔材料]]且[[比表面积]]较低，所观察到的快速吸附很可能由其外表面高密度的带正电位点驱动。在非多孔材料中，吸附主要发生在外表面，强静电作用力可迅速将阴离子型 PFAS 和染料吸引至聚合物，从而加快吸附动力学。如图 S2 所示，${ \mathrm { \ p - C D P ^ { + } } }$ 吸附 [[全氟辛酸|PFOA]] 后的 [[傅里叶变换红外光谱|FTIR]] 光谱中未观察到新峰或显著的[[红外光谱峰位偏移|峰位偏移]]，表明没有形成新的[[共价键]]，并支持物理吸附占主导地位的判断。总体而言，静电吸引似乎是本研究中去除[[阴离子污染物]]的主要驱动力。然而，[[长链全氟和多氟烷基物质|长链 PFAS]] 所表现出的快速去除和较高[[吸附容量]]表明，疏水相互作用也发挥着关键作用。此外，如[[竞争吸附]]部分（第 3.2.3 节）的图 6 所示，${ \mathrm { \ p - C D P ^ { + } } }$ 可同时吸附 PFAS、[[天然有机物|NOM]] 和[[阴离子染料]]，表明其具有较强的吸附能力，并有望有效去除实际废水系统中的 PFAS。然而，[[腐殖酸|HA]] 的存在会降低对 [[全氟丁酸|PFBA]] 的吸附容量，因为 HA 的[[分子尺寸]]更大、[[电荷分布]]更强，因此具有更强的竞争能力 [50]。PFBA 的吸附也几乎完全依赖这些静电位点。相比之下，它们对 PFOA 的抑制作用很小，因为即使静电

## 3.6. [[吸附剂可重复使用性|可重复使用性]]

[[吸附剂可重复使用性|可重复使用性]]是评价[[吸附剂]]的一项关键指标，尤其是在考虑实际环境应用时。本研究使用 $0 . 0 3 \mathrm { M H N O _ { 3 } }$ 作为负载 [[甲基橙|MO]] 的 ${ \mathrm { \ p - C D P ^ { + } } }$ 的[[解吸剂|解吸溶剂]]。[[解吸试验]]通过将 0.05 g 使用后的[[吸附]]剂加入 5 mL 0.03 M [[硝酸|HNO₃]] 溶液中，并使其接触 30 min 来进行。MO 完全[[解吸]]后，通过[[离心分离|离心]]收集吸附剂。随后，将干燥后的 ${ \mathrm { \ p - C D P ^ { + } } }$ 加入 100 mL MO 溶液（50 mg/L）中，进行后续吸附试验。对于 ${ \mathrm { \ p - C D P ^ { + } } }$ 吸附 [[全氟辛酸|PFOA]] 后的可重复使用性，将负载 PFOA 的吸附剂分散于 50 mL [[氯化钠与甲醇混合溶液|NaCl/甲醇溶液]]中，以该溶液作为解吸剂，振荡 12 h。随后，将回收的吸附剂加入 PFOA 溶液（20 mg/L）中，进行后续[[吸附循环]]。如图 10a 所示，MO [[去除效率]]在前三次循环中仅略有降低，第五次循环后仅下降了 4.3%。然而，第六次循环时[[污染物去除效率|去除效率]]下降了 10%，且第六次循环后的[[解吸效率|解吸率]]超过 95%。此外，对吸附 MO 前后的 ${ \mathrm { \ p - C D P ^ { + } } }$ 进行 [[傅里叶变换红外光谱|FT-IR]] 分析（图 10b）表明，${ \mathrm { \ p - C D P ^ { + } } }$ 在六次吸附循环后仍保持其结构，仅峰强度略有降低。同样，PFOA 吸附在前四次循环中表现出较高的可重复使用性，随后在第五次循环中去除效率下降了 14%。在解吸方面，[[β-环糊精聚合物|β-CDP]]<sup>+</sup> 在多达五次循环中均表现出超过 90% 的解吸效率。${ \mathrm { \ p - C D P ^ { + } } }$ 简便的[[吸附剂再生|再生过程]]和良好的可重复使用性凸显了其在去除废水中[[阴离子污染物]]方面的实际应用潜力。

## 4. 结论

本研究合成了先进的环境友好型电荷可调 ${ \mathrm { \ p - C D P ^ { + } } }$ 聚合物，并评估了其对 [[甲基橙|MO]]、[[酸性红1|AR1]]、[[全氟辛酸|PFOA]] 和 [[全氟丁酸|PFBA]] 的[[吸附效率]]。[[吸附]]实验表明，所合成的 ${ \mathrm { \ p - C D P ^ { + } } }$ 对 MO（335 mg/g）、AR1（384 mg/g）、PFOA（405 mg/g）和 PFBA（378 mg/g）均实现了显著较高的[[最大吸附容量]] $\left( \mathrm { Q } _ { \mathrm { m } } \right)$，在 60 min 的[[平衡时间]]内，[[去除效率]]均超过 90%。染料被用作优化吸附条件的替代物，并且由于其优异的正 [[斯皮尔曼秩相关系数|Spearman's ρ]] 值 $( > \rho = 0 . 9 )$，有望用于反映短链和[[长链全氟和多氟烷基物质|长链 PFAS]] 的吸附行为。引入 [[甲基丙烯以外的缩水甘油基三甲基氯化铵|GTMAC]] 作为[[阳离子改性剂]]有效提高了 [[β-环糊精聚合物|β-CD 聚合物]]的[[电荷密度]]，从而显著去除了所研究的污染物，尤其是 $\mathrm { P F B A , }$，这是一种以高迁移性和吸附难度大而著称的[[短链全氟和多氟烷基物质|短链 PFAS]]。优化研究确定，[[β-环糊精|β-CD]] 与 [[甲基丙烯酸缩水甘油酯三甲基氯化铵|GTMAC]] 的[[摩尔比]]为 1:5、[[pH值|pH]] 为 7、[[吸附剂用量]]为 $0 . 5 ~ \mathrm { g } / \mathrm { L }$ 时，可为高效去除[[阴离子污染物]]提供最佳条件。鉴于其合成条件较为温和、设备要求简单、能量投入较低、可循环使用多达 5 次，且所依赖的前体易于广泛获取，${ \mathrm { \beta - C D P ^ { + } } }$ 可通过简单且可规模化的工艺生产。此外，其快速的[[吸附动力学]]、不受 [[酸碱度|pH]] 影响的性能，以及即使在 [[天然有机物|NOM]] 存在时仍保持较高的 [[全氟和多氟烷基物质|PFAS]] [[污染物去除效率|去除效率]]，凸显了其强大的实际应用潜力：既可作为[[离子交换树脂]]和[[活性炭]]的经济高效替代材料，也可用于[[废水深度处理|深度处理]]步骤，以去除实际水体基质中的阴离子 PFAS 类物质。$\mathsf { \beta { \mathrm { - } } C D P ^ { + } }$ 聚合物的成功开发与应用，凸显了创新性、可持续解决方案对于应对环境污染的重要意义。
