# 单-6-氨基-6-脱氧-α-、β-、[[γ-环糊精]][[盐酸]]盐的简便合成及其在[[分子识别]]、[[手性分离]]和[[药物递送]]中的应用

[[Weihua Tang]]<sup>1</sup> & [[Siu-Choon Ng]]<sup>2</sup>

<sup>1</sup>新加坡国立大学化学系，新加坡 117543，新加坡。<sup>2</sup>南洋理工大学化学与生物分子工程学部，工学院，新加坡 627833，新加坡。通讯应寄至 W.T.（weihuatang@alumi.nus.edu.sg）或 S.-C.N.（ngsc@ntu.edu.sg）。

2008 年 4 月 3 日在线发表；doi:10.1038/nprot.2008.37

本文描述了一种合成[[单-6-氨基-6-脱氧-环糊精盐酸盐]] $( C D - N H _ { 3 } C l )$ 的实验方案，适用于 $\alpha \mathrm { \cdot , ~ } \beta \mathrm { \cdot }$ 和 [[γ-环糊精]]。这些结构最简单、水溶性高的[[阳离子环糊精]]可广泛用于[[分子识别]]、[[手性分离]]和[[药物递送]]研究。以市售化学品为原料，$C D - N H _ { 3 } C l$ 通过四步合成：（i）利用[[对甲苯磺酰氯]]对[[环糊精]]进行选择性[[对甲苯磺酰化|甲苯磺酰化]]，得到[[单-6-（对甲苯磺酰基）-6-脱氧环糊精]]（[[单-6-(对甲苯磺酰基)-6-脱氧-环糊精|Ts-CD]]）；（ii）用[[叠氮化钠]]对 Ts-CD 进行[[叠氮取代]]，得到[[单-6-叠氮基-6-脱氧-环糊精]] $( C D - N _ { 3 } ) ;$；（iii）用[[三苯基膦]]还原 $C D - N _ { 3 }$，随后水解制备[[单-6-氨基-6-脱氧-环糊精]] $( C D - N H _ { 2 } ) ;$；（iv）用[[盐酸]]处理 $C D \mathbf { - } N H _ { 2 }$，以良好收率得到标题化合物 $\mathbb { C D - N H } _ { 3 } \mathbb { C l }$。整个方案约需 2 周。

## 引言

![](<../2.SCI_MD/Facile synthesis of mono-6-amino-6-deoxy-α-, β-, γ-cyclodextrin hydrochlorides for molecular recognition, chiral separation and drug deliver/images/96acbcdfe9d54e305e56abaaa2337edb53edb012fdfc1027d3735f546053e555.jpg>)

作为一类[[大环低聚糖]]，[[环糊精]]（CDs）天然存在为 α-、β- 和 [[γ-环糊精|γ-CD]]，分别由六个、七个和八个 [[D-吡喃葡萄糖]]单元组成。CD 具有疏水性内腔和亲水性外表面，其形状类似于截锥体。关于 CDs 的广泛研究兴趣源于它们能够在溶液和固态中与多种无机/有机分子形成[[包合物]]<sup>1</sup>，和/或与客体分子建立离子相互作用<sup>1,2</sup>。CDs 及其衍生物不仅作为[[分子识别]]的优良受体<sup>2</sup>被深入研究，还作为[[手性分离]]的良好选择剂<sup>3</sup>和[[药物递送]]的合适载体<sup>4</sup>得到广泛研究。在所有这些应用中，CD（主体）与客体分子之间形成包合物和/或离子相互作用。当形成包合物时，客体分子通过弱相互作用（如[[氢键]]、[[静电相互作用]]和[[范德华力]]）恰当地嵌入 CD 的空腔中。这种空间匹配被认为是调控络合过程的最重要因素<sup>4,5</sup>。因此，包合物的稳定性关键取决于客体分子与 CD 的分子结构，包括尺寸、形状、刚性、极性和空间位阻<sup>4–9</sup>。

为提高 [[环糊精|CD]] 作为特定客体分子主体的性能，天然 CD 已被广泛修饰，以提高其对每种客体分子的[[立体选择性]]以及 CD 在水中的溶解度<sup>10</sup>。[[带电环糊精|带电 CD]] 便是一个例子，可为实际应用提供额外的离子相互作用<sup>11</sup>。为了合成结构最简单的阳离子 [[β-环糊精|β-CD]]（[[单-6-氨基-6-脱氧-β-环糊精盐酸盐]]，$\beta \mathrm { - C D - N H } _ { 3 } \mathrm { C l } )$（见图 1），已报道了两种方法：一种是对一个伯羟基进行[[对甲苯磺酰化|甲苯磺酰化]]，并在压力下用氨置换 $( 1 0 ^ { 6 } \mathrm { N } \mathrm { m } ^ { - 2 } )$，于室温反应 18 h $( \sim 2 5 ^ { \circ } \mathrm { C } ) ^ { 1 2 }$；另一种是先用[[叠氮取代]] CD 甲苯磺酸酯，再用 Pd/C [[氢化]] $1 2 \ \mathrm { h } ^ { 1 3 }$。这两种方法产率低且反应不完全，因此不适合大规模生产。

最近，Ng 及其同事报道了这一阳离子 [[环糊精|CD]] 家族的简便合成方法，涵盖 α-、β- 和 [[γ-环糊精|γ-CD]]（图 1），

分四步完成（图 2 和 $3 ) ^ { 1 4 , 1 5 }$）。这些分子在[[分子识别]]<sup>13</sup>和[[手性分离]]<sup>14,15</sup>方面均表现出良好性能。我们对 $\mathrm { C D - N H } _ { 3 } \mathrm { C l }$ 的创新合成在于使用[[三苯基膦]]还原 $\mathrm { C D - N } _ { 3 }$，随后水解得到 [[环糊精|CD]]-NH。随后用[[稀盐酸]]处理 CD-$\mathrm { \cdot N H } _ { 2 }$，即可得到目标的高度水溶性阳离子 CD（见图 3）。这些步骤几乎定量完成，产率≥90%。本文所述方案也可通过使用 CD 的仲甲苯磺酸酯<sup>10</sup>，用于合成[[单-2-铵基-2-脱氧-环糊精氯化物]]<sup>16</sup>。

本文报道的方案在从 [[单-6-(对甲苯磺酰基)-6-脱氧-环糊精|Ts-CD]] 到 [[环糊精|CD]]-$\mathrm { \cdot N H } _ { 3 } \mathrm { C l }$ 的合成步骤中易于放大。例外的是 Ts-[[α-环糊精|α-CD]] 和 Ts-[[γ-环糊精|γ-CD]] 的合成；它们只能采用图 2 中的方法合成。对于 Ts-[[β-环糊精|β-CD]] 的合成，可采用另一种两步法，通过使用[[咪唑]]<sup>17</sup>获得更高产率且更易操作。

[[环糊精|CD]]-NH 和 $\mathrm { C D - N H } _ { 3 } \mathrm { C l }$ 还可作为制备大量 CD 衍生物的重要中间体。

## 在[[手性分离]]中的应用

所合成的 $\mathsf { C D - N H } _ { 3 } \mathsf { C l }$ 通过 [[毛细管电泳|CE]] 对阴离子分析物的手性拆分能力如图 8 所示。使用 20 mM $\beta { \mathrm { - } } \mathsf { C D - N H } _ { 3 } \mathsf { C l }$ 在 50 mM [[磷酸盐缓冲液]]（pH 6.0）中，于 $2 5 ^ { \circ } \complement$ 条件下，八对阴离子型和两性分析物的标准混合物在单次运行中于 35 min 内实现基线分离。储备混合溶液 $( 5 0 \mu \mathfrak { g } \mathfrak { m } ^ { \lfloor - 1 } )$ 使用 50/50（体积比）[[甲醇]]/水混合溶液配制，并用 0.45 μm 注射器式 [[Millipore 膜]]过滤。

图 8 中的缩写在下方列出：Dns-Aca，丹磺酰-DL-α-氨基辛酸环己铵盐；Dns Aba，丹磺酰-DL-α-氨基正丁酸哌啶鎓盐；2-NHMA A，2-萘甲氧基乙酸；3-PLA，DL-3-苯基乳酸；Dns-Glu，丹磺酰-DL-谷氨酸双（环己铵）盐；3-H-4-M MA，3-羟基-4-甲氧基扁桃酸；MA，DL-扁桃酸；4-H-3-M MA，4-羟基-3-甲氧基扁桃酸。
