[[Carl von Nägeli]] 于 1858 年首次利用[[荧光显微镜|偏光显微镜]]发现了[[纤维素原纤]]的有序排列，<sup>23</sup> 这一发现后来于 1926 年通过[[苎麻]]的 [[X射线衍射|X 射线衍射]]（[[XRD]]）图谱得到证实。<sup>24</sup> 这距 1913 年首次记录[[纤维素]][[晶体衍射|衍射]]图谱已过去十多年，而该技术本身在一年前才被发现。<sup>25–27</sup> 1926 年的论文提出了纤维素的聚合物性质，但其中采用的是 1,1 和 4,4 连接，而非如今已知的 1,4 连接。随后很快对连接方式进行了修正，并对[[晶胞]]轴作出了修改。由此得到的结构具有正确的基本性质，但仍留下晶胞中两条分子链是平行还是反平行堆积的问题未解决。另一个留待 2000 年代才解答的问题是 C6–OH 可旋转基团的取向。纤维素分子聚集形成具有明确形状、尺寸和晶体同质异晶形态的晶体原纤。<sup>26</sup> 这些晶体结构的性质、它们与周围分子的相互作用，以及它们进一步组装成高阶结构以形成细长纤维的过程，深刻影响着纤维素材料的整体性能。因此，理解[[纤维素结晶度]]是最重要的必要条件之一，因为[[结晶度]]会影响纤维素的物理、机械、化学和形态性质及其与周围环境的表面相互作用，从而影响其在包括但不限于生物医学、纺织和电子等广泛应用中的使用。<sup>28–34</sup>

[[结晶度指数]]（CI）常用于衡量[[纤维素]]材料中结晶组分的相对含量，并用于定量表征其在各种物理化学和生物处理后的变化。<sup>8,31,35–40</sup> 该参数建立在材料的两相模型之上——即结晶相和无定形相。这可能是、也可能不是最正确的理解。另一种思路则是基于样品中晶体的尺寸而非完美程度来考虑[[结晶度]]。较小的[[微晶]]在一定程度上更像无定形材料，因为与大微晶相比，它们具有更大比例的表面分子，因而反应活性更快。实际情况可能并非仅存在无定形和结晶两个截然不同的相，而是分子有序度呈现更为连续的变异。在天然沉积的纤维素结构中，这种观点不太具有吸引力，因为一般认为生物合成机制会以高度重复的方式生成原纤维。

[[结晶度指数|CI]]（常称为 CrI）就是所存在结晶相的百分比。在天然[[纤维素]]中，非结晶或无定形材料被认为位于纤维素基元纤维的表面以及[[结晶区]]之间，如图 1A 所示。结晶区沿基元纤维轴间断的主要证据是“[[聚合度]]趋于平稳”。<sup>41</sup> 也就是说，在 80 °C 的 2 N HCl 中水解会迅速降低分子量，直至其不再快速下降。此外，[[微晶]]长度远小于初始分子量。<sup>42</sup> 一些 [[核磁共振|NMR]] 研究表明，纤维素微晶上的表面分子与内部分子具有不同的结构细节，并且根据[[分子动力学|计算分子动力学]]研究，表面分子预计有序度较低。

已有多种技术被用于测定 [[结晶度指数|CI]]，包括 [[X射线衍射|X 射线衍射]]（[[XRD]]）、<sup>21,26,36,43–51</sup> [[核磁共振]]（NMR）波谱、<sup>44,52–5</sup> [[傅里叶变换]]（[[FTIR]]）[[红外光谱]]、<sup>44,45,49,55,58,59</sup> [[拉曼光谱]]、<sup>55,60</sup> 和频发生（[[和频产生|SFG]]）[[振动光谱]]、<sup>61,62</sup> [[差示扫描量热法]]（DSC）<sup>63</sup> 以及酶促[[纤维素结合模块]]（CBMs）。<sup>64</sup> 然而，所有这些技术的一个共同特点是，[[木质纤维素生物质]]中各组分的[[晶体无序]]性和复杂的异质性导致大多数现有[[纤维素结晶度]]估算方法在解释上存在问题。<sup>26,60</sup>

已发现[[纤维素]]中的无定形与结晶结构决定其化学及酶促反应动力学。<sup>65–67</sup> 因此，[[结晶度指数]]（CI）的测定对于确定纤维素结构至关重要，进而有助于设计实验条件，以实现不同应用中最终产品所需性能。鉴于此，本综述评估了现有的[[纤维素结晶度]]测定技术，并确立了 [[XRD]]、[[核磁共振|NMR]]、[[红外光谱|IR]]、[[拉曼光谱|Raman]]、[[和频产生|SFG]] 光谱、[[差示扫描量热法|DSC]] 热谱图及 [[碳水化合物结合模块|CBM]] 方法的基本指导原则及其在纤维素结构表征中的应用。第一部分对每种技术进行单独分析，包括工作原理、能力与局限性。后一部分对这些技术进行全面比较，并阐述不存在测定纤维素[[结晶度]]的绝对方法这一观点。文中还讨论了[[晶体衍射|衍射]]图谱与光谱技术互补以测定纤维素结晶度的做法。在所有情况下，本综述均介绍基本原理以及不同技术在纤维素结晶度测定中的应用。这些使能技术可以帮助我们更好地评价纤维素材料的结构，但若未经审慎操作与注意，它们在应用中亦存在局限与缺陷。

## 2. [[X射线衍射|X 射线衍射]]（[[XRD]]）

## 2.1. [[XRD]] 基本原理

晶体产生[[晶体衍射|衍射]]的现象基于如下概念：晶体实际上是在三个维度上对一个小几何单元进行无限重复。一个小的平行六面体，即[[晶胞]]，包含所有原子及其三维排布，使得晶体可通过简单平移沿三个线性轴生成。晶胞内部并不要求具有完整的原子或分子。对于许多结晶物质而言，原子和分子仅在晶胞重复时才形成完整整体。例如，在图 1B 中，由白色、红色和绿色线条标示的晶胞，可以从纸面上剪下，并沿晶胞边界线移动以生成晶体的其余部分。简单的无机或金属晶胞可能仅在晶胞角处具有原子，但有机分子通常不可能具有如此简单的排布。多年来，这些晶胞已按若干约定加以描述，其中涉及晶胞原点处各轴之间夹角为钝角还是锐角，以及在[[纤维素]]这类聚合物情形下，x、y、z 中哪个轴应对应于分子轴。本综述将 z 轴（c [[晶胞尺寸]]）视为分子轴，另外两个轴中较短者为 $x ,$，且三个轴均由“右手定则”相互关联。晶体对称性亦发挥作用；本文所用的[[三斜P1晶胞|三斜 P1 晶胞]]即 [[Nishiyama]] 等针对[[纤维素I|纤维素 I]]α 所发表者。<sup>68</sup> 纯纤维素其余[[空间群]]均为单斜 $P 2 _ { 1 }$（P112 表示唯一 c 轴），其中钝角单斜角 γ 位于 a 轴与 b 轴之间。

在[[晶体衍射|衍射]]晶体结构研究的最初几十年中，人们并未正确理解聚合物能够容纳在衍射数据所显示的小[[晶胞]]中。例如，[[纤维素]]晶胞的最长尺寸约为一个纳米，而葡萄糖分子的聚合物长度会是其许多倍。这一难题通过理解得到解决：沿分子轴观测到的[[晶胞尺寸]]是主要重复单元，且由于分子末端极少，实验中检测不到分子末端的额外 H 原子和 OH 基团。

一旦确立了[[晶胞]]的正确[[背景]]，就可以讨论[[晶面]]的概念。这些晶面有助于辨识[[晶体衍射|衍射]]图样上的各个峰。例如，(200) 晶面在 a 轴二分之一长度处与之相交；“200”中的“2”表示二分之一的倒数。另外两个“[[米勒指数]]”的倒数为无穷大，表明 (200) 晶面永不与 b 轴或 c 轴相交。[[纤维素]]晶体学中另一个重要晶面通常是 (110) 晶面，它在距晶胞原点一个单位处与 a 轴相交。它还沿负方向在距原点一个单位处与 b 轴相交（图 2）。(110) 与 (1\(\overline{1}\)0) 晶面等价，但惯例是将负米勒指数标注在 b 项上。纤维素中另一个重要晶面 (110) 示于图 2。

[[X射线衍射|X 射线衍射]]（[[XRD]]）是一种用于表征晶体材料的强大非侵入性分析技术，能够提供结构（分子结构的三维空间表征）、物相、晶体取向、[[结晶度]]以及其他结构参数（如平均晶粒尺寸、应变和晶体缺陷）的信息。XRD 技术最早的应用使用多色 X 射线，产生了“模糊”的[[晶体衍射|衍射]]图样。<sup>27</sup> 该问题后来通过使用单色光源得以解决，从而在所谓的“图 2 中的反射面”处产生清晰的衍射峰。尽管这些峰来源于衍射面，但[[晶面]]的[[米勒指数]]写在圆括号中，而衍射图样中的峰并不使用圆括号。然而，这一约定常被忽视。清晰的 XRD 峰由单色 X 射线束的相干干涉产生，这些 X 射线被样品中周期性晶格面上的原子散射。<sup>69</sup> [[晶胞]]内的原子位置对峰强度有贡献——通常称为晶格变换和分子变换。同样重要的是要注意，观察到的衍射图样是两种变换——晶格变换和分子变换——的组合。因此，强度包含有关相对原子位置的信息，从而包含这些晶格位置上分子形状的信息。只有晶体晶格才能具有进而拥有米勒指数的晶面；对非晶材料的米勒指数进行指称从来都是不恰当的。

同样，在[[XRD|X射线衍射]]研究的最初四十年中，X射线峰是在照相胶片上检测的。如果样品是一束排列整齐的纤维，记录的图案是一个二维阵列（“纤维图案”），它能提供更多关于结构的信息。例如，参见[[Nishiyama]]、[[Langan]]和[[Chanzy]]以及Langan、Nishiyama和Chanzy发表的[[海鞘]][[纤维素]]或高度结晶[[纤维素II]]的[[晶体衍射|衍射]]图案。<sup>56,70</sup> 然而，对于许多样品，尤其是[[纳米纤维素]]和[[木浆]]，使用粉末衍射更为方便。不幸的是，这会导致大量信息损失，尤其是因为要获得准确的结构分析，尽可能多地捕捉强度是至关重要的。我们综述中的[[X射线衍射|XRD]]部分聚焦于使用[[X射线衍射仪|粉末衍射仪]]的粉末衍射，这与平板或二维衍射研究不同。（各种类型的二维数据可以通过软件转换为粉末衍射仪典型的一维数据。）

自[[XRD]]被发现以来，其非侵入性和相对易得性使其成为研究[[纤维素]]材料[[结晶度]]的普遍技术。<sup>2,15,64,71–77</sup> 纤维素的[[晶体衍射|衍射]]图案显示出若干强度，通常叠加在一个宽的[[背景]]上。“宽背景”由环境散射（空气散射、样品架、[[散粒噪声]]<sup>78</sup>等）组成。此外，进入背景的还有[[拉曼散射|非弹性散射]]或[[康普顿散射]]，以及透过去除Kβ辐射的滤光片的其他波长。然而，[[X射线衍射|XRD]]要求一定的临界[[微晶尺寸]]，才能将固体中的某个部分视为结晶态，其中衍射图中峰的宽度已知与[[微晶]]的横向宽度成反比。<sup>79,80</sup> 因此，在纤维素材料中，微晶尺寸越小，结晶峰越宽。<sup>69</sup> 材料的表面也会影响XRD分析中的结晶度。尽管表面原子具有更大的迁移率，并且与微晶主体相比有序度较低，但在XRD测量中它们仍被记为结晶材料。对于[[结晶区]]域内太小而无法被检测为分子无序区域的微小缺陷，情况也是如此。

因此，此时值得指出的是，如果无序材料的尺度足够小，并非所有无序都能对[[纤维素]]样品进行准确测定。

如前所述，[[结晶度指数]]（crystallinity index，CI）已被用于描述[[纤维素]]中结晶材料的相对含量。其计算方式为材料中结晶部分相对于[[结晶区]]与[[无定形区]]面积总和的贡献。<sup>55</sup> 已提出多种 [[XRD]] 技术来测定 CI。就此而言，由于缺乏标准方法，比较文献中[[纤维素结晶度]]数据具有挑战性。然而，用于研究纤维素[[结晶度]]最广泛应用的 [[X射线衍射|XRD]] 方法是 [[Segal 峰高法]]、[[峰拟合法]]（也称为[[峰解卷积]]法）和[[无定形扣除法]]。<sup>15,71</sup> 不过，目前有大量 Rietveld 结晶度研究工作正在进行，这一方法非常有吸引力，因为它能够以物理上相关的方式考虑[[晶体衍射|衍射]]图案中的所有输入因素。尽管在学术上令人满意，但需指出，[[Rietveld 法|Rietveld 方法]]已被广泛应用于无机材料（如陶瓷和金属），这些材料能形成更好的晶体并提供更多的衍射数据。即使在应用于这些形成更大晶体的材料时，关于 ${ \mathrm { f i t } } ,$ 的“准确性”以及由此进行的峰强度计算也确实存在问题。每种方法背后的理论含义及其局限性将在以下各节中讨论。比较不同技术将阐明 CI 值如何随不同方法而变化，并有助于理解用于测量纤维素材料 CI 的最简单且应用最广泛的 XRD 方法。

2.1.1. [[Segal 峰高法]]。[[Segal峰高法|Segal 峰高法]]由 Segal 及其同事开发，用于测量[[棉纤维素]] I 在化学或机械处理后的结晶含量变化。<sup>50</sup> 该方法是为了利用当时相对较新的 [[X射线粉末衍射|X 射线粉末衍射]]仪快速比较[[纤维素]]样品的[[结晶度]]而开发的。<sup>36,81</sup> 位于散射角 $2 \theta = 2 2 ^ { \circ }$ 至 231 之间的 200 峰高度代表结晶组分和无定形组分的总和，而在这一经验方法中，仅无定形组分由位于 110 峰和 200 峰之间约 181 处的最小强度表示，如图 4A 所示。其理由是，在 $: 2 \theta = 1 8 ^ { \circ }$ 处预计没有显著的晶格峰，因此所有强度必定来自[[无定形散射]]。Segal 经过充分[[球磨]]的棉样品在同一点处具有最大值，因此该处的所有强度都被归因于无定形含量。图 4C 所示的无定形散射在进入 200 峰下方时并未大幅降低，因此净结晶材料由 200 峰高度 $\left( I _ { 2 0 0 } \right)$ 减去 $1 8 ^ { \circ }$ $\left( I _ { \mathbf { A M } } \right)$ 处的强度来表示。因此，用本综述的命名法表示的 Segal 等人的方程为

[[Segal峰高法|Segal 法]]的一个主要优点是简单。它可以方便地用于早期[[晶体衍射|衍射]]仪输出的纸带图谱；不需要计算机（当时也没有计算机可用）。然而，文献中对 Segal 法存在大量批评。尽管该方法简单，一些研究者仍会误用 Segal 法，将 110/110 峰%（图 4A）的高度当作无定形部分的代表，但实际上必须使用的是谷底高度。当然，这并非 Segal 的过错。该方法的一个主要内在缺陷是，它假定 $1 8 ^ { \circ }$ 点（现代研究发现在 18.61 附近更接近最小值）处的全部强度都来自[[无定形散射]]，而没有一部分来自因[[纤维素]][[微晶尺寸]]较小而产生的宽峰重叠。由于峰重叠，完美但尺寸较小的晶体（例如尺寸与棉花[[微晶]]相似）的计算谱图也只能得到 90% 的[[结晶度]]；而且实验样品永远不会给出 0% 的结晶度值，因为 $I _ { 2 0 0 }$ 和 $I _ { \mathbf { A M } }$ 必须完全相同。另一个很少被提及的假设缺陷是，样品可能因制样方式以及在 X 射线束中的放置方式而存在微晶的非随机取向。[[微晶择优取向]]的情况会使某一特定[[晶面]]相对于入射 X 射线束具有特定取向，从而夸大了这些强度，并在结晶度相同的情况下改变 $I _ { 2 0 0 }$ 与 $I _ { \mathbf { A M } }$ 的比值。[[择优取向]]在[[细菌纤维素]]以及以不同方式干燥的[[纳米纤维素样品]]中尤其常见。

高端[[晶体衍射|衍射]]仪通常配有[[旋转样品台]]，以帮助实现[[微晶]]取向的随机化，但它们一般不能解决所有此类问题。例如，被切成很短长度的纤维样品仍倾向于平躺在样品台平面内。旋转样品可以确保谱图不受纤维二次取向的影响。纤维将在 360° 范围内均匀分布。然而，仍可能出现第三种取向，即微晶可能绕其长轴以特定方向旋转。旋转样品台无法解决第一种或第三种[[择优取向]]问题。尽管如此，对所有样品进行旋转仍是良好做法，因为光束尺寸可能会采样到本应随机的样品中的某些区域，但局部取向效应仍可能发生。这种方法不仅适用于 [[Segal峰高法|Segal 法]]，也适用于所有粉末 [[XRD]] 方法。当然，样品的完整表征应包括关于择优取向程度的信息。无论如何，如果不加以考虑，此类效应可能产生无效的[[结晶度]]测量结果，而 Segal 法难以应对这些效应。

[[Segal峰高法|Segal 法]]是经验性的，其初衷并非用于比较不同性质的样品，而是用于量化同一组样品之间的差异。<sup>15,71</sup> 因此，Segal 法更适合用于研究样品在不同处理条件下[[结晶度]]的相对变化，而不适合用于估算[[纤维素]]材料中结晶度和无定形部分的绝对值。<sup>2</sup>

2.1.2. [[峰拟合]]、[[峰面积]]或[[峰解卷积]]方法。峰解卷积通过拟合[[XRD]]图谱中的可见峰，并外加一个（或多个）宽峰来解释无定形材料，从而解释观测到的图谱，如图4B所示。<sup>82</sup> 有时会根据已知[[晶胞尺寸]]，在预期位置插入[[高斯函数|高斯]]、<sup>83</sup> [[沃伊特函数|沃伊特]]、<sup>84</sup> 或[[洛伦兹函数|洛伦兹]]<sup>85</sup> 峰。在使用曲线拟合软件对峰参数进行优化时，它们的总和会被调整以匹配实验图谱。

在使用[[高斯函数|高斯]]和[[沃伊特函数|沃伊特]]拟合函数时，通常考虑多达五个[[晶面指数]]为110、110、012/102、% 200和004的结晶峰。110、110和200指数的峰在大多数[[纤维素]]样品中清晰可见，而012/102重叠反射可能表现为肩峰；然而，对于某些样品，这些峰可能彼此重叠，无法如此清晰地分辨，$e . g .$ ，[[漂白桉木]]。<sup>84</sup> 另一个[[晶体衍射|衍射]]峰通常在约34.51处可见，呈较宽的峰，指数为004，尽管它是由几个相邻峰复合而成。沃伊特（常为伪沃伊特）函数已被用于拟合纤维素样品衍射图中产生的五个峰。图4B是这种拟合的典型示例。然而，当使用[[洛伦兹函数|洛伦兹]]拟合函数时，可能会使用四个指数为110、110、200和004的结晶峰，% 因为012/102难以分辨，在衍射图中表现为肩峰。[[结晶度指数]]由所有结晶[[峰面积]]与总面积的比值计算得出，公式为

$$
\mathrm{CI} = \frac {A _ {\mathrm{cr}}}{A _ {\text { sample }}} = \frac {\left(\int_ {2 \theta_ {1}} ^ {2 \theta_ {2}} I _ {\mathrm{cr}} \mathrm{d} 2 \theta\right)}{\left(\int_ {2 \theta_ {1}} ^ {2 \theta_ {2}} I _ {\text { sample }} \mathrm{d} 2 \theta\right)}\tag{2}
$$

其中[[结晶度指数|CI]]为[[结晶度]]指数，$A _ { \mathrm { c r } }$ 为所有结晶峰的面积，$A _ { \mathrm { s a m p l e } }$ 为样品总面积，$I _ { \mathrm { c r } }$ 为结晶峰强度的积分和，$I _ { \mathrm { s a m p l e } }$ 为所有[[晶体衍射|衍射]]空间强度之和。无定形贡献通常通过在$1 8 ^ { \circ }$ 与$2 1 ^ { \circ }$ 之间的某个位置插入一个非常宽的峰来建模，可在通用[[峰拟合]]软件或更专门用于[[XRD]]工作的软件中选择多种方式之一。在一项重要工作中，[[Nishiyama]]等$a l . ^ { 8 6 }$ 研究了[[球磨]]后的多种[[纤维素]]及相关分子的衍射，并发现它们之间存在极大的相似性。他们为无定形贡献建立了一个[[傅里叶级数]]表达式，并用[[MATLAB]]软件进行了精修。该表达式随后用于[[PeakFit]]软件进行[[纤维素结晶度]]研究。

由于比[[Segal 峰高法|Segal法]]考虑了更多峰，[[峰拟合]]方法的一个可能优势是它可以更安全地用于比较不同样品的[[结晶度指数]]。有人担忧[[峰面积]]法并未考虑所有导致峰宽化的因素，包括[[晶体无序]]、[[微晶尺寸]]和晶体内[[非均匀应变]]。<sup>84</sup> 其他研究表明[[微晶]]尺寸是主导因素。<sup>87</sup> 另一个问题是，由于[[纤维素]]强度非常宽且峰相互重叠，图谱无法分解为许多狭窄的[[晶体衍射|衍射]]贡献。<sup>84,88,89</sup>

2.1.3 [[无定形扣除法]]。该方法由 [[Ruland]] 提出，通过从待测样品的[[晶体衍射|衍射]]图谱中扣除标准材料[[无定形区]]域的衍射，来测定[[纤维素]]样品的[[结晶度]]。<sup>84</sup> [[无定形标准]]的选择应使其与样品的结晶贡献相匹配。图 4C 是无定形[[扣除法]]用于测定[[纤维素结晶度]]的典型示例，其中以[[球磨无定形标准样品]]作为参比。调整无定形组分的标度，使无定形图谱与实验图谱在 $1 8 ^ { \circ }$ 点处的强度相等，该点由 Segal 指定为 $I _ { \mathbf { A M } }$

然而，如果所选[[无定形标准]]物的强度与实验无定形贡献不匹配，部分研究者允许拟合结果在某些散射角处略微超过实验强度，以改善拟合效果。测量无定形贡献下的面积与样品的总面积，[[结晶度]]则通过以下公式计算

$$
\mathrm{CI} = 1 - \frac {A _ {\mathrm{am}}}{A _ {\text { sample }}} = 1 - \frac {\left(\int_ {2 \theta_ {1}} ^ {2 \theta_ {2}} I _ {\mathrm{am}} \mathrm{d} 2 \theta\right)}{\left(\int_ {2 \theta_ {1}} ^ {2 \theta_ {2}} s _ {\text { sample }} \mathrm{d} 2 \theta\right)}\tag{3}
$$

其中，[[结晶度指数|CI]] 为[[结晶度]]指数，$A _ { \mathrm { a m } }$ 为所有无定形峰的面积，$A _ { \mathrm { s a m p l e } }$ 为样品的总面积，$I _ { \mathrm { a m } }$ 为无定形峰强度的积分和，$I _ { \mathrm { s a m p l e } }$ 为样品中所有[[晶体衍射|衍射]]空间强度的总和。

计算面积时使用从 $2 \theta _ { 1 } \sim 1 3 ^ { \circ }$ 到 $2 \theta _ { 2 } \sim 5 0 ^ { \circ }$ 的宽散射角范围。理想[[无定形标准]]品的选择非常困难，这限制了该方法的应用。<sup>15</sup> 此外，[[无定形扣除法]]与 [[Segal峰高法|Segal 法]]具有相同的局限性，原因在于将强度分配给无定形部分时未考虑重叠峰的存在。尽管如此，[[球磨]][[纤维素]]、[[再生纤维素]]以及[[木聚糖]]或[[木质素]]粉末仍被广泛用作若干标准品，以拟合实测的[[无定形区]]域。<sup>40,51</sup> 如图 4C 所示，251 2y 以上的实验数据被视为无定形，但 004 峰附近的点除外。对解卷积结果和无定形扣除结果都应进行的一项检验是，仅绘制由被视为结晶材料的部分所得出的图谱。在此，无定形[[扣除法]]即为从实验图谱中减去无定形部分，而对于解卷积法，则为各 2y 步长处所有结晶峰之和。如果数据已经过[[环境背景]]校正，那么从图谱中移除无定形数据后，应得到一个可与给定尺寸[[微晶]]的理想图谱进行比较的理想图谱。或者，也可以采用所选方法对计算得到的理想图谱进行分析，以检验其是否为 100% 结晶。

2.1.4. [[Rietveld 法]]。[[Rietveld法|Rietveld 法]]<sup>91</sup> 是测定[[纤维素结晶度]]的另一种方法。尽管该方法最初旨在确定无法生长出足够大单晶的材料中的原子位置，但它具备相应的工具来补偿多相（结晶相与无定形相）以及样品织构（如[[微晶尺寸]]和[[择优取向]]等方面）的影响。应用这些工具可以给出样品与理想结构之间差异的报告。分析从一个理想 [[XRD]] 图谱开始，该图谱基于此前对足够相似结构的 x、y、z [[原子坐标]]的可靠确定。<sup>91,92</sup> 理解 Rietveld 分析的理想方式是，分析者面对的是一个计算得到的理想[[晶体衍射|衍射]]图谱。该图谱最初被定义为具有无限尺寸且完全有序的晶体、随机取向的球形颗粒，以及与样品相近的[[晶胞参数]]和原子坐标。将实验图谱置于同一 2y 坐标轴上，并通过可变参数的[[最小二乘拟合]]对计算图谱进行调整。例如，[[晶胞]]参数必须进行变化，因为众所周知，否则峰位置（尤其是[[纤维素]]）不会完全准确。<sup>93</sup> 当然，图谱的高度需要按比例调整以匹配实验数据，而且即使已扣除空白扫描以去除[[环境背景]]，仍可能需要额外的[[二次背景校正]]。[[微晶]]尺寸在一级近似下通过 [[Scherrer方程|Scherrer 方程]]与峰宽相关，是另一个显而易见的变量。<sup>80</sup>

图 5 中有几点启示。该图以蓝色示出了在 Rietveld 计算开始时可能展示给用户的理想图谱。第一点是，蓝色图谱中有许多小峰，当晶粒尺寸被减小以匹配实验图谱时，这些小峰会变得模糊。另一点是，峰强度较低的图谱并不一定意味着晶体完整性方面的结晶度较低；但在本例中，60 Å 图谱上的 200 峰需要九倍于 1000 Å 图谱的入射光子数，才能达到与后者相同的高度。

不同的 Rietveld 软件程序在免费和商业产品中被广泛使用，它们处理无定形相的理念各不相同。一种策略使用同一材料的极小型晶体作为模型。对于[[纤维素]]而言，目前看来，[[纤维素I|纤维素 I]] 的小晶体并不是最佳方法。相反，[[纤维素II|纤维素 II]] 和[[纤维素IV|纤维素 IV]] 结构都被使用。二者各有其合理性。纤维素 II 模型得到如下事实的支持：由 12 Å 晶粒计算得到的图谱（图 5）与被视为无定形模型的[[球磨]]或快速再生样品之间的相似性。这并非随意选择。无定形样品与纤维素 II 共享 O6 的主要取向，并且将无定形材料浸泡在水中可以生成纤维素 II。<sup>94</sup> 此外，[[纳米纤维素样品]]中可能存在在[[晶体衍射|衍射]]图谱上不可见的纤维素 II。然而，如果在精修过程中允许模型晶体的尺寸变化，它可以增大到 30 Å，表明存在纤维素 II。纤维素 IV 模型则得到[[初生细胞壁]]常由该[[同质异晶体]]组成这一发现的支持。另一种方法是使用不同的函数，得到类似球磨或[[再生纤维素]]的图谱，或者根据需要加入一个额外的任意宽峰。<sup>92</sup> 这是当前研究的前沿领域。

对织构（[[微晶尺寸]]与取向）的正确分析也会影响[[纤维素]]样品的[[结晶度指数]]（晶相与无定形相的百分比）。<sup>95</sup> [[Rietveld 法]]通过使用曲线拟合方法来优化[[结晶度]]指数测量，其中它也考虑了所有变量，包括较低强度的峰。因此，Rietveld 是一种完整的[[峰面积]]拟合法，不受上述简单方法的限制。值得注意的是，该方法在结晶度更高的无机和金属材料中已十分成熟。更关键的是，即使这些材料的图谱似乎相对缺乏明显的无定形[[背景]]，为这些结晶度更高的材料获得准确的[[晶体衍射|衍射]]数据拟合所涉及的问题也早已为人们所知。就衍射图谱而言，[[峰拟合]]本身充满困难，尤其是在考虑[[信噪比]]和背景时。这是一个在文献中已被指出但在分析中常被忽视的问题。另一个问题在于，对于使用哪个参数来量化拟合程度缺乏共识，并且对常用参数（如 [[R因子|R 因子]]）的小数值进行过度解读可能导致错误结论。在此方法中，在数据库中拥有可靠的结构测定结果十分关键，而如果在使用这些数据库结构时不够谨慎，就很容易出错，例如对天然纤维素使用了错误的[[同质异晶体]]，以及木质植物材料相对于结晶度更高的纤维素形式可能出现[[晶格畸变]]（表现为峰位移动）。过度依赖精修模型与实验数据之间的良好拟合可能导致错误结论。

然而，Rietveld 分析的精度已通过[[纤维素]]精细结构 Rietveld 分析（[[纤维素精细结构Rietveld分析|Cellulose Rietveld Analysis for Fine Structure]], CRAFS）软件得到改善，该软件使用晶体学模型以及一种计算算法，其变量仅包含在信息量有限的情况下被认为对纤维素研究最为实用的参数。另一个优势是，CRAFS 以及其他一些 Rietveld 软件还可以处理二维数据，而如上所述，二维纤维图谱能够比本文讨论的一维图谱提供更多的信息。<sup>95,96</sup> 二维图谱的优势在参考文献 90 中得以展示，该文献比较了一维和二维计算图谱。二维图谱上的斑点分布在不同层线上，因此能够更好地分辨，从而提供更多独立的[[晶体衍射|衍射]]数据点。该研究还比较了不同尺寸的理想[[微晶]]及其经过能量最小化和[[分子动力学]]研究后失去严格周期有序性的对应物的一维图谱。通过这种方法可以观察到，许多此前被归因于[[背景散射]]或[[无定形纤维素]]的衍射峰，实际上来自相邻的晶态峰。<sup>47,92</sup> 然而，由于 [[Rietveld 法|Rietveld 方法]]能够考虑所有晶态峰，因此尚不能断言它能够对广泛的纤维素[[同质异晶体]]给出最准确、最可靠的[[结晶度指数]]值。不过，从原理上讲，如果采用更好的标准，并考虑到在更规整材料中遇到的陷阱，该方法具有很大的潜力。可以公允地说，与更高度结晶的材料相比，该方法在纤维素中的应用仍处于起步阶段，仍需要大量工作来确保采用稳健的方法，而不过度依赖错误的潜在假设。

Rietveld 测定中最大的问题是实验数据量有限。基于图 6b 中的结构，对[[纤维素]][[原子坐标]]的变化进行拟合是徒劳的，因此必须使用[[晶粒尺寸各向异性]]的简化模型。与[[单晶衍射]]研究不同，对于纤维素[[晶体衍射|衍射]]图谱的 Rietveld 工作而言，数据量与可变参数之比并未得到明确界定。

计算得到的[[纤维素结晶度]]还可能受样品取向的影响，这可以通过使用不同[[晶体衍射|衍射]]仪几何构型测量同一样品以及前述样品旋转来评估。例如，研究发现，当中密度[[轻木]]样品以不同几何构型测量时，[[对称透射几何构型]]得到的[[结晶度指数]]为48%，而使用同一样品的[[对称反射几何构型]]时，测得的[[结晶度]]指数几乎为100%。<sup>2</sup> 这是由于样品200反射发生了最佳散射，导致散射图谱贡献被高估。<sup>105</sup> 因此，对称透射几何构型对轻木产生了更高的Segal结晶度指数。另一个问题是“[[环境背景]]”的存在，它与样品无关，并倾向于与低强度区域产生的[[无定形散射]]衍射图谱重叠。因此，必须将[[背景]]与无定形散射分离，以获得更可靠且有意义的结晶度指数值。<sup>39</sup>

尽管不同技术会导致[[纤维素]]样品[[结晶度指数]]不同，但当样品间[[结晶度]]指数的相对差异较大时，已报道样品之间存在良好的线性相关性 $\left( r ^ { 2 } \ \ge \ 0 . 9 \right)$。<sup>71</sup> 当测量单一组样品时，[[Segal 峰高法|Segal法]]与其他方法表现出线性相关；然而，当测量多种样品时，线性关系消失。<sup>71</sup> 这被认为是因为Segal法是一种用于研究单一样品组内相对变化的经验方法。与Segal法相比，[[峰拟合法]]得到的结晶度值较低，因为如果拟合界限过于严格，[[峰拟合]]法可能产生不切实际的无定形贡献。如果无法使用合适的标准无定形模型，[[无定形扣除法]]也会基于错误假设得出结晶度指数，因为即使标准模型与样品在所选散射角的某些区域强度不匹配，标准模型的强度也不能超过样品强度。<sup>71</sup> 为克服这一局限，有时会采用无定形拟合，允许标准模型与样品强度之间存在不匹配。但由于无定形模型、散射角、[[背景]]校正和扣除等多种因素，无定形拟合模型不能用于确定绝对值，即无法判断样品是否为100%结晶。

[[Rietveld 法|Rietveld 方法]]正在成为通过 [[XRD]] 测量[[纤维素]]样品[[结晶度指数]]的一种有用工具。[[CRAFS 软件]]分析二维[[晶体衍射|衍射]]图，并生成若干数据，如[[晶胞参数]]、[[微晶尺寸]]、结晶指数/强度和[[微晶]]取向。该方法可以克服另外三种技术存在的两个主要局限，即[[衍射峰重叠]]和[[微晶择优取向]]。<sup>95</sup> 精度得以提高，是因为 Rietveld 软件通常可以针对纤维素的[[择优取向]]调整模型图样，并且一些软件还可以补偿[[各向异性微晶]]（它们沿不同轴具有不同尺寸）。这使得 [[Rietveld方法|Rietveld 方法]]所得[[结晶度]]的测定结果可能比 [[Segal 峰高法|Segal 高度法]]、[[峰拟合法|峰解卷积法]]和[[无定形扣除法]]更为可靠。然而，其应用仍存在问题，[[无定形标准]]品的选择会显著改变结果。不同无定形样品的散射各不相同，因此单一、不变的标准品可能会导致结晶度指数估计不正确，因为待测样品中的无定形性质是未知的。显然，适当选择纤维素的标准晶体同质异像体也是获得对衍射数据准确拟合的前提。对于大多数研究较充分的无机材料而言，Rietveld 分析已是标准方法，但在[[纤维素结晶度]]测定领域仍处于起步阶段，应当谨慎开展。保持谨慎的一种方式是在若干次单独精修中引入变量，而不是试图在一次精修中同时精修所有变量。单个变量往往会趋向不合理的数值，因此在判断精修是否成功时应对其进行监测。

影响上述所有方法的另一个因素是不同 2θ 角下照射到样品上的辐射强度。已观察到计算谱线是平滑的，而实验谱线包含由光子计数统计产生的噪声。当样品受到高强度光束照射时，例如旋转阳极靶或[[同步辐射]]，或者使用常规[[晶体衍射|衍射]]仪在每一步进行更长时间计数时，数据中的噪声可以降低。光子计数的标准偏差（噪声）与所计光子数（强度）的平方根成正比。图 7 中获得非常平滑实验数据的高计数，是使用配备现代探测器的常规实验室衍射仪在半小时内完成的。此外，使用固定狭缝衍射仪这一标准数据采集方法，可能产生具有相当显著曲率的[[背景]]，如图 7A 所示。相比之下，可变狭缝使辐射以不同强度照射样品，从而产生几乎水平的背景（图 7B）。研究人员还应确保所选的 Rietveld 软件已针对狭缝类型进行编程，并通过扣除空白扫描来减少[[环境背景]]的影响。

[[XRD|X射线衍射]]（[[X射线衍射|XRD]]）技术已被广泛用于测定[[纤维素结晶度]]，但如果不遵循完全相同的测量和分析方案，使用这些方法比较不同样品的[[结晶度]]仍然非常具有挑战性。要实现[[纤维素]]结晶度的完整定量和最佳评估，必须考虑非晶区和[[结晶区]]的所有[[晶体衍射|衍射]]峰。[[择优取向]]的存在可以通过使用不同的样品取向来确认，尽管原则上并非必须，因为 Rietveld 软件可以包含择优取向校正。虽然任何 XRD 技术都可以提供单组样品的[[相对结晶度]]指数，但使用 [[Rietveld 法|Rietveld 方法]]测定和比较不同组样品的数值可能更为有益，因为只要正确应用并提供足够的数据，该方法就有能力产生可靠的结果。

## 3. [[核磁共振]]（NMR）

[[核磁共振]]（NMR）是测量[[纤维素]]和[[纳米纤维素]][[结晶度]]的广泛使用工具之一。<sup>106–112</sup> 该技术利用了许多不同类型的仪器设备来表征[[纤维素结晶度指数]]。<sup>110</sup> 通过 NMR 测量的[[结晶度指数]]可以比 [[差示扫描量热法|DSC]] 或 [[FTIR]] 获得的数据更有意义，因为 NMR 能够检测多种构象，而 DSC 和 [[傅里叶变换红外光谱|FTIR]] 技术无法确定二级结构或结构域运动。在这个意义上，通过 NMR 进行的结晶度测量与纤维素的离散结构具有更有意义的关联。

## 3.1. [[核磁共振|NMR]] 基本原理

[[核磁共振]]基于原子核的磁性质。当某些原子的原子核置于强磁场中时，共振现象会在电磁谱的特征频率（[[拉莫尔频率]]）处发生。<sup>28</sup> 某些原子的原子核对周围原子施加的磁场屏蔽的细微变化非常敏感。<sup>28</sup> 当原子核附近的外部磁场被改变时，电子中会出现特征性但细微的变化。<sup>113</sup> 这些发生的细微变化被称为“[[化学位移]]”，并提供关于分子的关键信息。所获得的信息表明了原子核类型的特征以及原子在分子中的位置。<sup>28,113</sup> 当施加强度为 $B _ { 0 }$ 的恒定磁场时，磁性核自旋的[[极化]]分裂为两个能态（2I + 1）（图 8A）。<sup>28</sup> I 是磁自旋数，I = 1/2 来自原子核，其中质子数与中子数之和为奇数，例如 <sup>1</sup>H 和 <sup>13</sup>C。其中一个态具有与 $B _ { 0 }$ 场相同的磁矩，另一个态具有与 $B _ { 0 }$ 场相反的动量。<sup>114</sup> 平行于外部磁场的磁矩具有较低能量（m = +1/2）。相反，反平行排列的磁矩具有较高能量（m = 1/2）。<sup>114</sup> 在磁场 $B _ { 0 } ,$ 存在下，原子核以由拉莫尔频率 $\omega _ { 0 } = 1 \mathbf { \vec { B } } _ { 0 }$ 定义的角速度绕外加场进动（图 8B）。<sup>115,116</sup> 常数 U 被称为[[磁旋比]]，对不同原子核具有唯一的值。<sup>116</sup> 当频率为（n）的电磁波辐照体系时，进动中的原子核可以通过吸收能量在两个能态之间发生跃迁。<sup>28</sup> 处于较低能态（m = +1/2）的原子核被提升到较高能态（m = 1/2）。由于进动共振 $( \nu = \omega _ { 0 } )$ 与所施加辐射的频率，该跃迁过程被定义为核磁共振（NMR）。<sup>116</sup> 基于 NMR 的基本原理，当使用具有特定频率的磁旋比对样品进行脉冲以使其处于高能态时，样品中的原子核可以给出用于分析谱图的独特信号。典型 NMR 仪器的示意图如图 8C 所示。

## 3.2. [[核磁共振|NMR]] 用于测量[[纤维素]]的[[结晶度]]

[[纤维素]]因其结晶性而表现出有限的溶解度和复杂的化学键。因此，[[核磁共振|NMR]] 除了可提供关于键合、官能团和化学环境的信息外，还可用于研究纤维素的[[结晶度]]。$^ { 1 3 } \mathrm { C }$ [[交叉极化魔角旋转|CP/MAS NMR]] 是交叉[[极化]]、[[魔角旋转]]和大功率去耦三种技术的综合。<sup>119</sup> 交叉极化通过将磁化从质子转移至碳，来提高 $^ { 1 3 } \mathrm { C }$ 强度（该强度因天然丰度低和[[磁旋比]]低而较弱）。[[质子–碳极化]]（CP）方法的采用已被发现能够通过提高 $^ { 1 3 } \mathrm { C }$ 灵敏度并消除偶极相互作用，来解决弱信号问题。此外，魔角旋转（MAS）使样品围绕所谓的魔角旋转，已解决固体样品在磁场中的各向异性问题。<sup>28</sup> 利用 $^ { 1 3 } \mathrm { C }$ CP/MAS 固态 NMR，可以分析来自不同工艺的纤维素，如[[硫酸盐浆]]、低 DP 酸水解纤维素以及表现出高度结晶结构的[[海鞘]]提取样品。这些材料已被 NMR 广泛研究，其结晶度通过计算[[化学位移]]的变化来测定。<sup>52,120–122</sup>

多种不同的 [[核磁共振|NMR]] 技术被用于研究[[纤维素结晶度]]。然而，最广泛使用的 NMR 方法之一是采用 $^ { 1 3 } \mathrm { C }$ [[交叉极化魔角旋转|CP/MAS NMR]] 波谱对[[纤维素]]分子进行 [[C4 峰]]分离。<sup>54,120,121,123,124</sup> 在这种情况下，C4 峰的双峰代表 $^ { 1 3 } \mathrm { C }$ 谱图中的两种不同信号，并且每个峰分别归属于各纤维素结构。其中一个位于约 89 ppm 的峰，指示[[微晶]]内部有序纤维素结构中的 C4 碳；另一个位于约 84 ppm 的峰，揭示[[无定形纤维素]]的性质。<sup>120,121</sup> 无定形纤维素已通过纤维素的无定形 C4 区域进行归属。<sup>52</sup> 其原因是，纤维素微晶的表面材料在[[无定形区]]表现为更尖锐的双峰，而沉积在纤维素微晶上的[[木聚糖]]则在 82.1 ppm 处表现为一个峰。<sup>125,126</sup> 此外，据报道，结晶[[甘露聚糖]]也在该区域共振。<sup>127</sup> [[纤维素结晶度指数]]（[[结晶度指数|CI]]）可通过将位于 75 的结晶峰（约 89 ppm）面积除以 C4 峰总面积获得，其中约 89 ppm 和约 84 ppm 信号分别代表[[结晶区]]和无定形（无序）区。[[结晶度]]指数（CrI）以百分比表示，可根据以下方程，通过计算这些信号下方积分面积之和得到

$$
\mathrm{CrI} = \frac {a}{a + b} \times 100 \%\tag{4}
$$

其中 a 为[[结晶区]]的积分面积，b 为[[无定形区]]的积分面积。[[Mustapha]] 等人通过 <sup>13</sup>C-[[交叉极化魔角旋转|CP/MAS NMR]] 研究了来自[[纤维素]]浆、[[再生纤维素]]浆和[[细菌纤维素]]的纤维素样品。<sup>128</sup> 对未处理甘蔗渣 C4 区的谱图解卷积表明，结晶区在 90 ppm 处具有较窄的 a 拟合，在 86 ppm 处具有 b 拟合，在 89 ppm 处具有 a + b 的混合拟合，并在 88 ppm 处存在[[次晶区]]。<sup>129</sup> 无定形区则由一个强的特征双峰确定，其两个峰位于 84 和 85 ppm。<sup>130</sup>

不同[[纤维素]]样品的<sup>13</sup>C-[[交叉极化魔角旋转|CP/MAS NMR]]谱已通过不同多晶型物[[化学位移]]的谱图分析用于理解[[纤维素结晶度]]，如图9A所示。<sup>131</sup>

## 3.3. 使用 [[核磁共振|NMR]] 测量[[纤维素结晶度]]的其他方法

[[结晶度指数]]也可以由[[平均横向微原纤尺寸]]（L）或[[微晶尺寸]]确定，因为它取决于 [[核磁共振|NMR]] 谱中 C4 信号的峰强度，使用以下公式：

$$
\mathrm{CrI} = \left(\frac {n - 2}{n}\right) ^ {2}\tag{6}
$$

$$
L = 0. 5 7 n\tag{7}
$$

其中 [[结晶度指数|CrI]] 为[[结晶度]]指数，[[平均横向微原纤尺寸]]为 $L ,$，0.57 表示平均链间距离（单位：nm），n 表示每条链微原纤的侧面数，(n  2) 为葡萄糖单元总数。<sup>136</sup>

另一种基于$^ { 1 3 } \mathrm { C }$ [[核磁共振|NMR]] 波谱的方法是从原始信号中扣除[[无定形纤维素]]标准谱。<sup>137</sup> 在该方法中，先制备完全无定形的[[纤维素]]样品，以估计纤维素[[无定形区]]域可能产生的信号。通过从原始信号中减去无定形纤维素的面积，即可获得该样品中结晶纤维素的含量。扣除之后，对无定形纤维素谱施加一个比例因子，以消除残差谱中的负信号，如图 9（B 和 C）所示。[[结晶度指数|CI]] 最终通过计算结晶贡献面积与总面积之比获得。<sup>131</sup> 图 9（B 和 C）展示了用于计算[[纤维素结晶度]]的[[扣除法]]。测量了 [[α-纤维素|a-纤维素]]谱（图 9B（a））和 100% 无定形纤维素谱（图 9B（b）），并通过从 a-纤维素中减去无定形值来计算结晶分数（图 9C（c））。扣除后，位于约 84 ppm 处的一个小强度峰表明，无定形区域中存在的有序[[微晶]]已被归一化。<sup>138</sup> 位于 89 ppm 处的峰代表内部[[结晶区]]的微晶。计算这两个峰下的面积，并使用公式（4）计算[[结晶度]]指数。

研究确定，无定形 C4 碳很可能位于距结晶 C4 碳约不到 1 nm 的距离内，并且这些无定形 C4 碳并非仅局限于微纤丝表面。<sup>139</sup> [[Fernandes]] 等人发表了相互矛盾的 [[核磁共振|NMR]] 自旋扩散结果，这些结果似乎支持从[[云杉木材]]中分离出的[[纤维素微纤丝]]的[[核–壳模型]]，其中核比壳更加有序。<sup>140,141</sup>

## 3.4. 不同 [[核磁共振|NMR]] 方法的比较

峰分离技术的一个主要问题在于，它只处理 C4 碳信号以及两种自旋态之间的能量分离。该信号强烈依赖于[[木质素]]和[[半纤维素]]的含量以及外部磁场强度，而后者相对较弱。<sup>131</sup> 残留木质素和半[[纤维素]]的存在会导致$^ { 1 3 } \mathrm { C }$ [[核磁共振|NMR]] 谱中出现重叠峰，这使得在明确使用 [[C4峰分离技术|C4 峰分离技术]]时，更难将信号分离为有序峰和无序峰。具体而言，NMR 技术依赖于[[微晶]]的尺寸，因为只有位于微晶内部的纤维素才被视为结晶态。<sup>44,52</sup> 微晶越大，NMR 峰就越强。

此外，[[玻尔兹曼热能|环境玻尔兹曼热能]]（E B kT）足以将大量原子核提升到较不利的高能态。<sup>115</sup> 例如，[[玻尔兹曼分布]]预测，在$B _ { 0 } = 1 . 4 ~ \mathrm { T }$磁场中，一百万氢原子核中只有少数几个能够对 [[核磁共振|NMR]] 信号作出贡献。这解释了 NMR 灵敏度的局限性。因此，NMR 需要较大的样品量（对大多数分子量而言通常超过 100 mg）。<sup>28,122</sup> NMR 测量还会产生相对较弱的信号，需要在足够长的采样时间内平均以获得足够的[[信噪比]]来生成谱图。在测量[[纤维素结晶度指数]]方面，[[扣除法]]比[[C4峰分离技术|峰分离法]]具有一些优势，因为该方法可用于测定多种材料的这一参数。

## 4. [[振动光谱|振动光谱方法]]

除了[[XRD]]和[[核磁共振|NMR]]等广泛用于[[纤维素]]结构表征的分析技术外，[[振动光谱|振动光谱方法]]（[[红外光谱|红外]]和[[拉曼光谱|拉曼]]）也有助于研究类纤维素聚合物的结构和性质。<sup>142–146</sup> 振动光谱的获得是由于分子在特定频率下吸收或发射电磁辐射，这些频率与分子的能态相对应，而能态是限制在特定化学键坐标中的电子波的量子力学状态。<sup>28</sup> 然而，产生红外和拉曼强度的机制存在一些根本性差异。前者依赖于原子之间已有的偶极，后者则是由于辐射诱导产生的偶极。

## 4.1. [[振动光谱]]基本原理

[[红外光谱|红外]]和[[拉曼光谱]]中观察到的特征谱带源于分子振动，其基本原理可通过将双原子化学键与[[简谐振子模型]]进行类比来推导（图10A）。<sup>117</sup> 在该模型中，化学键可视为一根弹簧，其两端连接着质量分别为$m _ { 1 }$和$m _ { 2 }$的两个原子，二者相距$d ,$，弹簧常数为k。[[胡克定律]]可用于表达平衡键距附近的化学势。<sup>106</sup> 求解[[薛定谔波动方程]]后，参与该化学键的电子的波函数给出分立的振动能级，表示为

$$
E _ {v} = \frac {h}{2 \pi} \left(\frac {k}{\mu}\right) ^ {\frac {1}{2}} \left(v + \frac {1}{2}\right)\tag{8}
$$

其中h为[[普朗克常数]]，m为[[约化质量]]$( m _ { 1 } m _ { 2 } / ( m _ { 1 } +$ $m _ { 2 } ) )$，v为[[振动量子数]]，k为弹簧常数。该方程将两个原子（或分子片段）之间的力常数、相互作用原子（或分子片段）的质量以及振动频率联系起来。28,147

[[红外光谱]]测量的是电磁辐射束（通常为激光）的强度，通过观察辐射的吸收来实现，其特定的振荡辐射频率与某一特定[[简正振动模式]]（即分子的振动偶极）的固有频率相匹配。光谱通过绘制强度（吸光度或透射率）对波数或频率的图获得，波数或频率与基态和激发振动态之间的能量（E）差成正比，主要从v = 0态到$\nu = 1$态，可表示为

$$
\omega_ {\mathrm{IR}} = E _ {\nu = 1} - E _ {\nu = 0}\tag{9}
$$

其中 $\omega _ { \mathrm { I R } }$ 是[[红外光谱|红外]]光子的能量，等于两个振动能级 $\nu = 1$ 与 $\nu = 0 .$ 之间的能量差。要使能量通过吸收从红外光子转移到分子上，分子振动必须引起[[偶极矩|分子偶极矩]]或官能团的净变化。<sup>28,148</sup> 早期使用色散型仪器获取红外光谱。然而，近年来[[傅里叶变换红外光谱仪]]已取代色散型仪器，因为它们极大地改善了红外光谱的采集。该方法基于以下思想：两束光之间的辐射干涉产生[[干涉图]]，这是一种随两束光之间光程差变化而产生的信号。光源产生的辐射经干涉仪后通过样品，再到达检测器。信号放大后，数据由[[模数转换器]]转换为数字形式，并传输到计算机进行[[傅里叶变换]]，这是一种距离域和频率域可以相互转换的方法。<sup>147</sup> [[FTIR]] 光谱仪的基本组成部分如图 10B 所示。

图 10 （A）双原子分子的振动能态以及红外吸收和拉曼散射所涉及的电子跃迁。双原子分子可以模拟为两个质量（m 和 m ）通过劲度系数为 $k ^ { 1 1 7 }$ 的弹簧连接（根据参考文献 117 重绘）。（B）典型红外仪器的简化示意图。（C）拉曼光谱仪装置

由于激发电子在被激发到虚拟电子态后倾向于回到基电子态，其中大多数在[[弹性散射]]中回到振动基态 $\left( \nu \ = \ 0 \right)$ ，但有一小部分在[[拉曼散射|非弹性散射]]中回到 v = 1 态。后一种情况称为[[拉曼光谱|拉曼]]散射，其中最初吸收的光子（激发）与发射的光子（散射）之间的能量差对应于振动能级差，其关系式为

$$
\omega_ {\mathrm{Raman}} = \omega_ {\mathrm{excite}} - \omega_ {\mathrm{scatter}}\tag{10}
$$

[[拉曼活性]]的基本要求是在电磁辐射散射引起的电子跃迁过程中，[[键极化率]]发生净变化。<sup>28,149</sup> [[拉曼光谱|FT-Raman]] 光谱仪的基本组成示意于图 10C。根据[[拉曼选择定则]]，[[极化]]率变化将是组成原子因分子振动而偏离平衡位置的结果。<sup>150</sup> 拉曼光谱仪由光源、[[单色器]]、样品架和检测器组成。色散拉曼光谱和[[傅里叶变换]]拉曼光谱等拉曼光谱方法在激光光源和检测方法上有所不同。通常可提供若干种具有分立单色光源的激光器，$e . g .$ ，[[氪离子激光器|氪离子]]（530.9 和 647.1 nm）、[[氦氖激光器|He:Ne]]（632.8 nm）、[[掺钕钇铝石榴石激光器|Nd:YAG]]（1064 nm 和 532 nm）、[[氩离子激光器|氩离子]]（488.0 和 514.5 nm）、[[二极管激光器]]（630 和 780 nm）等。现在也可能有覆盖从紫外（UV）到近[[红外光谱|红外]]（NIR）全范围的可调谐激光系统。FT-Raman 通常使用 1064 nm 近红外（NIR）激发激光，与可见波长激光相比，通常可减少荧光。<sup>151</sup> 这对[[纤维素]]很重要，因为荧光是可能含有[[木质素]]的植物材料中常见的问题。此外，由于纤维素具有相对较大的带隙<sup>152</sup>（远大于激光能量），它不会产生[[共振拉曼效应]]，而这种效应更常见于碳纳米管等材料。<sup>153</sup> 考虑到这一点，通常需要较长的采集时间才能获得[[信噪比]]较低的光谱。在其他聚合物中克服荧光的方法包括使用[[光漂白]]，即在激光下长时间曝光，以及使用[[过氧化氢]]对纤维素纤维进行化学漂白。<sup>154</sup> 后者可能影响材料性能，应谨慎实施。激光下的光束损伤对许多纤维也是一个问题，<sup>155</sup> 因此采集光谱时应使用显著较低的功率。

## 4.2. 使用[[红外光谱]]测量[[纤维素]]基底的[[结晶度]]

根据传统的[[两相纤维素模型]]，聚合物链中同时包含结晶（有序）区和非结晶（无序）区。借助 [[FTIR]]，已经确立了[[纤维素]]中[[氢键|羟基相互作用]]与[[结晶度]]之间的明确关系。<sup>156</sup> 利用 $1 4 2 9 ~ \mathrm { { c m } ^ { - 1 } }$ 与 $8 9 3 ~ { \mathrm { c m } } ^ { - 1 } . { } ^ { 1 5 7 }$ 处的吸收比，建立了一个经验性“[[结晶度指数]]”。如前所述，位于 $\sim 1 4 3 0 ~ \mathrm { c m } ^ { - 1 }$ 的 [[傅里叶变换红外光谱|FTIR]] 吸收带归属于不对称 CH 弯曲振动，被称为“结晶带”。另一方面，位于 $\sim 8 9 8 ~ \mathrm { c m } ^ { - 1 }$ 的 [[红外光谱|FTIR]] 吸收带归属于 $\beta \mathrm { ~ \ } ( 1 \  \ \mathrm { ~ 4 } )$ -[[糖苷键]]的 C–O–C 伸缩振动，被指定为“非结晶”吸收带。已经发现，随着 $\sim 1 4 2 9 ~ \mathrm { c m } ^ { - 1 }$ 处吸收强度的降低，结晶度下降，而 $8 9 3 ~ \mathrm { c m } ^ { - 1 }$ <sup>1</sup> 处的吸收强度则增加。<sup>158–160</sup> Nelson 和 O’Connor 引入了另一个比值指数，即“总结晶指数”，它是 B1372 $\mathrm { c m } ^ { - 1 }$ 与 $\sim 2 9 0 0 ~ \mathrm { c m } ^ { - 1 }$ 处强度之比。中心位于 $\sim 2 9 0 0 \ c m ^ { - 1 }$ 附近的谱带是 C–H 伸缩振动谱带，符合非结晶态纤维素的特征，而 $\sim 1 3 7 2 \ c m ^ { - 1 }$ 处的吸收带归属于 C–H 弯曲振动。<sup>161</sup> 已有报道指出，位于 $\sim 1 3 3 6 ~ \mathrm { c m } ^ { - 1 }$ 的谱带在结晶[[纤维素II|纤维素 II]] 与非结晶纤维素之间表现出最显著的差异。后来证明，这些谱带并非非[[结晶区]]的特征谱带。<sup>161,162</sup> 如今，这两个比值均被用于测定[[纤维素结晶度]]，其中这些指数被分别定义为

$$
\mathrm{Cr.} R _ {1} = \frac {A _ {1 3 7 2}}{A _ {2 9 0 0}}\tag{11}
$$

$$
\mathrm{Cr.} R _ {2} = \frac {A _ {1 4 3 0}}{A _ {8 9 3}}\tag{12}
$$

其中 $\mathrm { { C r } } . R _ { 1 }$ 和 $\mathrm { { C r } } . R _ { 2 }$ 分别为[[纤维素]] $A _ { 1 3 7 2 } / A _ { 2 9 0 0 }$ 和纤维素 $A _ { 1 4 3 0 } / A _ { 8 9 3 }$ 的吸收度比值，也用于测定纤维素的[[相对结晶度]]。此外，比值 $A _ { 1 3 7 0 } / A _ { 6 7 0 }$ 已被用于研究[[纤维素I|纤维素 I]] 向纤维素 $\mathrm { I I } . ^ { 1 6 3 }$ 的转变。这些测定中所用谱带的来源见表 $5 . ^ { 4 4 }$。为了计算[[纸浆]]生产后的[[结晶度]]，已提出如下方程：

$$
\text{Yield corrected crystalline cellulose (\%)} = A _ {1 3 7 0} / A _ {6 7 0}
$$

$$
\times \text {   amount   of   cellulose   } \times \text {   pulp   yield   } \times 0. 1\tag{13}
$$

其中引入乘数因子（0.1），以便为[[纤维素|结晶纤维素]]给出数值。由此可见，随着得率降低，[[纸浆]]纤维中结晶纤维素的比例增加。这归因于纸浆中[[木质素]]和[[半纤维素]]的去除。由于缺乏 100% 结晶标准物以及光谱中 OH 基团区域的分辨率较差，此类测定只能给出[[相对结晶度]]。<sup>44</sup>

[[氢键强度]]（HBI）也可用于解释[[纤维素结晶度]]的定性变化；例如，[[结晶度]]随 HBI 的增加而降低。HBI 的增加表示[[纤维素]]中某些羟基官能团之间[[氢键]]作用的增强，这是[[纤维素I|纤维素 I]] 转变为[[纤维素II|纤维素 II]] 的典型特征；尽管这代表着总[[结晶度指数]]的降低。<sup>45</sup>

## 4.3. 利用[[拉曼光谱]]测定[[纤维素]]底物的[[结晶度]]

[[拉曼光谱]]或其更先进的形式——[[傅里叶变换]]拉曼光谱（FT-Raman spectroscopy），已成为一种快速且便捷的测定[[纤维素结晶度]]的分析方法。拉曼方法的原理是利用其强度、带宽和位置受[[纤维素]][[结晶度]]影响的光谱特征。<sup>58</sup>

基于[[拉曼光谱|FT-Raman]]的[[纤维素]]I[[结晶度]]定量方法，是利用位于B1462和 $\sim 1 4 8 1 ~ \mathrm { c m } ^ { - 1 }$ （CH 弯曲振动模式）结合光谱去卷积进行测定。然而，所选谱带的强度相对较低，且去卷积过程不可避免地存在谱带拟合问题；因此人们一直在寻求一种更优的方法。<sup>55</sup> 在这种更优的方法中，[[纤维素I|纤维素 I]] 样品的结晶度是基于位于 B380 和 $\sim 1 0 9 6 ~ \mathrm { c m } ^ { - 1 } . ^ { 5 8 }$ 峰值高度通过选取峰附近最小强度波数位置（例如，B358 和 $\sim 9 4 4 ~ \mathrm { c m } ^ { - 1 }$ 对于约 380 和 $\sim 1 , 0 9 6 \ \mathrm { c m } ^ { - 1 }$ （分别对应的谱带），并在该峰下画一条水平线（从该波数位置开始）。这称为[[基线法]]，使用该方法，在其余光谱中，对于位于 $\mathrm { a t } \sim 3 8 0 \mathrm { a n d } \sim 1 0 9 6 \mathrm { c m } ^ { - 1 }$ ，能带最小值相同的数值 $( \mathrm { a t } \sim 3 5 8 \mathrm { a n d } \sim 9 4 4 \mathrm { c m } ^ { - 1 } )$ 用于绘制基线。获取峰高后，利用强度数据计算 拉曼谱带强度比，并建立了回归模型。为生成校准曲线，将纤维素样品[[球磨]]不同时长，以观察其结晶度的变化。机械处理对这些峰区的峰形和强度产生了显著影响。

## 4.4. [[和频振动光谱]]（[[和频产生|SFG]]）

另一种振动方法——[[振动光谱|SFG 振动光谱]]，是一种[[非线性光学|非线性光学现象]]，已被证明是探测界面的有效技术。<sup>166–169</sup> 它对[[非中心对称]]晶体材料、$e . g .$、[[压电晶体]]以及介质中非中心对称排列的官能团高度敏感。<sup>170,171</sup> 由于其选择性振动模式和对生物材料中[[手性分子]]的敏感性，它也被用于探测 [[DNA]] 及其他[[螺旋蛋白]]等生物分子。<sup>172</sup> 最近，研究表明它可以选择性检测[[木质纤维素生物质]]中的[[纤维素|结晶纤维素]]。<sup>61</sup>

[[振动光谱|SFG 振动光谱]]的原理依赖于和频产生的[[非线性光学|非线性光学响应]]。在此过程中，两束脉冲激光在界面处发生时间和空间上的重叠。其中一束具有固定的可见光频率 $\left( \omega _ { \mathrm { V I S } } \right)$，另一束具有可调的[[红外光谱|红外]]频率（ω<sub>IR</sub>）。于是，发出的光为两个频率之和 $\left( \omega _ { \mathrm { S F G } } \right)$，其关系由下式给出<sup>173</sup>

$$
\omega_ {\mathrm{SFG}} = \omega_ {\mathrm{VIS}} + \omega_ {\mathrm{IR}}\tag{14}
$$

当界面分子的振动频率与可调[[红外光谱|红外]]辐射的频率一致时发生共振，因此光强得到增强。将这种和频光的强度对红外频率作图，即可得到[[振动光谱]]。<sup>173</sup> [[和频产生|SFG]] 过程的示意图如图 12A 所示。当光在介质中传播时，介质分子的价电子会受到其电场 E(ω) 施加的力。所有分子电[[偶极矩]]的总和产生偶极矩，称为介质的[[极化]] P(ω)，其关系由下式给出<sup>28</sup>

$$
P (\omega) = \varepsilon_ {0} (X ^ {(1)} E (\omega) + X ^ {(2)} E (\omega) ^ {2} + X ^ {(3)} E (\omega) ^ {3} + \dots)\tag{15}
$$

其中 $\scriptstyle { \varepsilon _ { 0 } }$ 是[[真空介电常数]]，$\chi ^ { ( n ) }$ 是第 n 阶[[电极化率]]。从数学上看，χ 是一个具有 $3 ^ { n + 1 }$ 分量的张量。<sup>174</sup> 当材料用典型的[[红外光谱|红外]]或[[拉曼光谱|拉曼]]辐射源照射时，高阶 χ 项与 $\chi ^ { ( 1 ) }$ 相比极小。然而，当材料受到高强度激光束照射时，这些项变得显著。<sup>28</sup> 由于 [[和频产生|SFG]] 依赖于二阶电[[极化]]率，我们将讨论限制在二阶极化项上。电场 E(ω) 可以表示为两个余弦波之和，其关系由下式给出

$$
E (\omega) = E _ {1} \cos \omega_ {1} t + E _ {2} \cos \omega_ {2} t\tag{16}
$$

其中 $E ( \omega )$ 是电场，$E _ { 1 }$ 和 $E _ { 2 }$ 是两个分量，t 是时间。因此，二阶[[极化]]项可以表示为

$$
\begin{array}{l}P ^ {(2)} = \varepsilon_ {0} \chi^ {(2)} (E _ {1} \cos \omega_ {1} t + E _ {2} \cos \omega_ {2} t) ^ {2}\\= \varepsilon_ {0} \chi^ {(2)} \big (E _ {1} ^ {2} \cos^ {2} \omega_ {1} t + 2 E _ {1} E _ {2} \cos (\omega_ {1} t)\\\times \cos (\omega_ {2} t) + E _ {2} ^ {2} \cos^ {2} \omega_ {2} t \big)\\= \varepsilon_ {0} \chi^ {(2)} \left(E _ {1} ^ {2} \frac {(1 + \cos 2 \omega_ {1} t)}{2} + 2 E _ {1} E _ {2} \right.\\\times \frac {\cos (\omega_ {1} + \omega_ {2}) t + \cos (\omega_ {1} - \omega_ {2}) t}{2} + E _ {2} ^ {2} \frac {(1 + \cos 2 \omega_ {2} t)}{2}\left. \right)\\= \varepsilon_ {0} \chi^ {(2)} \left(\frac {1}{2} \big (E _ {1} ^ {2} + E _ {2} ^ {2} \big) + \frac {1}{2} \big (E _ {1} ^ {2} \cos 2 \omega_ {1} t + E _ {2} ^ {2} \cos 2 \omega_ {2} t\right)\\+ E _ {1} E _ {2} \cos (\omega_ {1} + \omega_ {2}) t + E _ {1} E _ {2} \cos (\omega_ {1} - \omega_ {2}) t)\end{array}\tag{17}
$$

![](<../2.SCI_MD/Comparison and assessment of methods for cellulose crystallinity determination/images/6b380ff15b2bbb7fa2965f8d175e0ae61a104d1e80642a744a01b6359034ec15.jpg>)  
图 12 (A) SFG 系统示意图<sup>61</sup>（经参考文献 61 许可转载。版权所有 2011 American Chemical Society）。(B) SFG 过程中 $\chi _ { \mathrm { e f f } } ^ { ( 2 ) }$ 的非中心对称要求示意图。<sup>117</sup> 振动模式的方向性以棕色箭头表示（经参考文献 117 许可转载。版权所有 2013 Korean Journal of Chemical Engineering）。(C) 纤维素链中两个吡喃葡萄糖单元的示意图。具有 SFG 活性的 CH 和 OH 伸缩峰分别以绿色和粉色高亮显示（经参考文献 61 许可转载。版权所有 2011 American Chemical Society）。

两束入射激光均会产生直流场（与频率无关项，${ E _ { 1 } } ^ { 2 } + { E _ { 2 } } ^ { 2 } ) _ { : }$），两束输入光各自的简单[[二次谐波产生]]（SHG，频率为两输入频率的二倍，$2 \omega _ { 1 }$ 和 $2 \omega _ { 2 } ) ,$），[[差频产生]] $\left( \mathrm { D F G } , \ \omega _ { 1 } \textrm { -- } \ \omega _ { 2 } \right)$ 以及 [[和频产生|SFG]] $( \omega _ { 1 } ~ + ~ \omega _ { 2 } ) . ^ { 1 7 3 }$。[[振动光谱|SFG 振动光谱]]关注的是从样品发射的具有两入射光束频率之和的波，在此情况下即[[红外光谱|红外]]与可见激光束的频率之和。[[和频产生振动光谱|SFG]] 信号强度 $I ( \omega _ { \mathrm { { S F G } } } )$ 可表示为

$$
I (\omega_ {\mathrm{SFG}}) \propto | X _ {\mathrm{eff}} ^ {(2)} | ^ {2} I (\omega_ {\mathrm{IR}}) I (\omega_ {\mathrm{VIS}})\tag{18}
$$

其中 $I ( \omega _ { \mathrm { I R } } )$ 和 $I ( \omega _ { \mathrm { V I S } } )$ 分别为[[红外光谱|红外]]和可见光束的强度，$\chi _ { \mathrm { e f f } }$ 为[[有效二阶非线性极化率]]，可表示为

$$
\chi_ {\mathrm{eff}} ^ {(2)} = \frac {N \sum_ {\alpha , \beta , \gamma} \left\langle M _ {\alpha \beta} A _ {\gamma} \right\rangle}{\varepsilon_ {\mathrm{o}} \left(\omega_ {\mathrm{IR}} - \omega_ {q} - i \Gamma\right)}\tag{19}
$$

其中 N 为产生 [[和频产生|SFG]] 信号的分子的[[数密度]]，$\langle M \alpha _ { \beta } A _ { \gamma } \rangle$ 为[[红外光谱|红外]]与[[拉曼张量]]乘积的角度平均，$\omega _ { \mathbf { q } }$ 为[[简正振动模式]]的频率，G 为[[阻尼常数]]。由于该表达式包含[[红外张量]]与[[拉曼光谱|拉曼]]张量的乘积，因此振动模式必须同时具有[[拉曼活性]]和[[红外活性]]才能产生 [[和频产生振动光谱|SFG]] 信号。[[和频振动光谱|SFG]] 过程的另一条重要[[选择定则]]是，被辐照的介质不得具有[[反演对称性]]。173,175,176

如图12B所示，当振动模式（以棕色箭头表示）在空间中随机排列（a），或具有[[反演对称性]]排列（b），或分子本身具有反演对称性（c）时，均无法产生[[和频产生|SFG]]信号。使$X _ { \mathrm { e f f } } ^ { ( 2 ) }$变为非零的唯一方式是，不具有反演对称性的分子在空间中呈[[非中心对称]]排列。<sup>28,173</sup> 在[[纤维素|结晶纤维素]]中，非中心对称性存在于跨越数个数量级的长度尺度上。<sup>177</sup> 在分子层面，葡萄糖环中的碳中心（C1、C2、C3、C4和C5）具有[[手性]]。[[晶胞]]表现出非中心对称性（[[空间群]]P1和$P 2 _ { 1 } ) . ^ { 5 6 , 6 8 }$）。此外，纤维素$\mathbf { I } _ { \propto }$和$\mathrm { I _ { \beta } }$具有平行的[[葡聚糖链]]，这与[[纤维素II]]不同，后者的链呈反平行排列。<sup>178</sup> 由于纤维素I中的这些葡[[聚糖链]]是单向的，环外$\mathrm { C } _ { 6 } \mathrm { H } _ { 2 } \mathrm { O H }$侧链的CH基团以及具有链间[[氢键]]的OH基团在整个晶体或多个紧密堆积的晶体中形成[[净偶极]]。<sup>61,179</sup> 因此，在$2 9 4 5 ~ \mathrm { c m } ^ { - 1 }$和$3 3 2 0 { - } 3 2 5 0 ~ \mathrm { c m } ^ { - 1 }$处分别观察到对应于$\mathrm { C H } _ { 2 }$和OH振动模式的特征[[和频产生振动光谱|SFG]]峰。<sup>62,178</sup> 已观察到，2945 $\mathrm { c m } ^ { - 1 }$处的[[和频振动光谱|SFG]]峰强度随结晶纤维素样品呈单调但非线性的变化，<sup>97</sup> 据此开发了一种基于[[Avicel]]的校准曲线，利用[[XRD]]、[[红外光谱|IR]]和[[拉曼光谱|Raman]]技术测定木材样品中Avicel等效结晶纤维素的含量。

除上述峰以外的其他C–H和O–H由于[[非中心对称]][[选择定则]]而未被观察到。同样的原因也使得[[半纤维素]]和[[木质素]]因在生物质中随机排列而表现为[[和频产生|SFG]]非活性。<sup>61</sup> 此外，这些非中心对称晶体可以在无定形基质中以随机、中心对称或非中心对称的方式分散，这也会在$\mathrm { S F G . } ^ { 1 8 0 }$的特征长度上影响[[和频产生振动光谱|SFG]]光谱。[[和频振动光谱|SFG]]技术在探测[[纤维素晶体结构]]方面正变得越来越普遍。Huang等人（2020）利用SFG[[振动光谱]]，通过淡水藻类[[Micrasterias]]将[[纤维素酶复合物]]的形状和尺寸与[[纤维素]]的晶体尺寸关联起来。<sup>181</sup> 由于非线性散射，该方法还能够区分[[纤维素纳米晶体]]中的表面羟基和体相羟基。<sup>182</sup> SFG技术对[[纤维素微纤丝]]之间的纤丝间距离以及晶体间距离的变化也很敏感。<sup>183,184</sup> 该方法能够区分[[链极性]]，并确定纤维素微纤丝生长方向的取向（单向或双向）。<sup>28,185–187</sup> 该技术还能够区分不同的[[纤维素多晶型]]。<sup>178</sup> 此外，该技术使研究人员得以探究纤维素微纤丝的[[介观尺度组装]]。<sup>179,180</sup>

[[和频产生|SFG]] 技术可用于定量[[纤维素结晶度]]，前提是[[纤维素]]的晶态堆积模式保持基本恒定。<sup>97</sup> 目前通过 [[和频产生振动光谱|SFG]] 方法对纤维素[[结晶度]]进行定量，需要建立已知纤维素浓度与 [[和频振动光谱|SFG]] 峰强度之间的校准曲线。<sup>188,189</sup> 然而，当不同样品中结晶纤维素的堆积方式发生剧烈变化时，定量会变得困难。<sup>177,180</sup>

## 5. [[差示扫描量热法]]（DSC）

[[量热法]]测量的是当状态变量因相变、化学反应或物理变化而发生变化时所吸收或释放的热能。测量热量随温度变化的简单方程可表示为

$$
\mathrm{d} Q = m \times c \times \Delta T\tag{20}
$$

其中 ${ \mathrm { d } } Q$ 为热量变化，m 为样品质量，c 为[[比热容]]，DT 为温度变化。通常使用两种方法，即[[热流式DSC|热流式 DSC]] 和[[功率补偿式DSC|功率补偿式 DSC]]。

## 5.1. [[热流式DSC|热流式 DSC]]

在[[热流式DSC|热流式 DSC]] 系统中，参比物和样品在同一个炉体内加热，并使用两个独立的传感器测量其温度。[[吹扫气体]]可实现均匀的热分布，并排出氧气等不需要的物质。因此，样品和参比物获得相同的热传递，并测量其温度差。该温度差通过[[热流方程]]转换为热流量。<sup>190</sup> 然而，热流式 [[差示扫描量热法|DSC]] 系统存在时间常数较大的缺点。因此，它们通常不用于研究[[半结晶聚合物]]。<sup>191</sup> 简化示意图见图 13A。

## 5.2. [[功率补偿式DSC|功率补偿式 DSC]]

在[[功率补偿式DSC|功率补偿式 DSC]] 系统中，样品和参比物使用两个独立的腔室。两个独立的加热器通过[[差分功率控制器]]分别加热样品和参比物，以维持二者之间零温度差。温度随时间线性升高。因此，在功率补偿式 [[差示扫描量热法|DSC]] 系统中，能量流动速率会发生变化，以保持两个腔室温度相同。[[吹扫气体]]用于实现均匀的热分布并去除不需要的物质。功率差可通过以下方程确定

$$
\Delta P = \frac {\mathrm{d} Q _ {\text { Sample }}}{\mathrm{d} t} - \frac {\mathrm{d} Q _ {\text { Reference }}}{\mathrm{d} t} = I \times \Delta V = \frac {\mathrm{d} H}{\mathrm{d} t}\tag{21}
$$

其中 DP 为所需功率变化，dQ/dt 为样品或参比物单位时间吸收或释放的热量，I 为总电流，DV 为电压差，dH/dt 为单位时间焓变。[[功率补偿式DSC|功率补偿式 DSC]] 的简化示意图见图 13B。

两种方法都会输出热流随温度变化的曲线。根据该曲线可以推断材料性质。图 13C 展示了[[半结晶聚合物]]的一般 [[差示扫描量热法|DSC]] 输出以及可能的解读。焓变与峰下面积成正比。焓变（DH）可表示为

$$
\Delta H = K \times A\tag{22}
$$

其中 K 为[[量热常数]]，A 为曲线下面积。因此，通过测量物质的比热，[[差示扫描量热法|DSC]] 技术有助于获取热力学函数信息。<sup>191,192</sup> 测量比热的技术和原理此前已发表。<sup>193</sup> 该技术还可用于评估聚合物的热行为以及包括[[结晶度]]在内的结构信息。<sup>191,194</sup>

## 5.3. 使用 [[差示扫描量热法|DSC]] 测量[[纤维素]]的[[结晶度]]

传统上，聚合物的[[相对结晶度]]通过将 [[差示扫描量热法|DSC]] 测试中获得的样品[[熔融焓]]与完全结晶样品的熔融焓之比来确定。<sup>194,195</sup> 它可以表示为

$$
X _ {\mathrm{c}} = \frac {\Delta H _ {\mathrm{m}}}{\Delta H _ {\mathrm{m}} ^ {\circ}} \times 100 \%\tag{23}
$$

其中 $X _ { \mathrm { c } }$ 是聚合物中结晶组分的相对含量，$\Delta H _ { \mathrm { m } }$ 是聚合物样品的[[熔融焓]]，$\Delta H _ { \mathrm { m } } ^ { \mathrm { ^ { \circ } } }$ 是同种聚合物 100% 结晶样品的熔融焓。

[[纤维素]]具有明确的[[结晶区]]和[[无定形区]]混合结构，无定形区域允许水性试剂渗透到结构内部。<sup>196</sup> [[结晶域]]排列非常紧密，抵抗水分吸收。因此，有观点认为，存在于无定形区域中的游离羟基几乎承担了全部的水分吸收。基于这些考虑，Dale 提出了一种通过考虑[[脱水吸热峰]]面积来确定[[纤维素结晶度]]的方法。<sup>196</sup> 据报道，纤维素纤维通常在 273 至 400 K 之间出现一个吸热峰，该峰被归因于脱水。<sup>197</sup> 因此，作者假设纤维素脱水的吸热峰与纤维素的无定形组分相关。<sup>196</sup> 纤维素[[结晶度]]（CC%）可以通过以下公式确定

![](<../2.SCI_MD/Comparison and assessment of methods for cellulose crystallinity determination/images/467a6468f3496404ca5b0067e827406be539b2b78b55fbd3057fc021a41f8718.jpg>)  
图 13 （A）热流式 DSC 示意图，（B）功率补偿式 DSC 示意图，以及（C）半结晶聚合物的一般 DSC 输出曲线。

$$
\mathrm{CC}\tag{24}
$$

其中 $\Delta H _ { 0 }$ 是从标准[[纤维素]]中除去水分所需的热量，该标准纤维素完全无定形，并暴露在特定相对湿度下直至获得恒定重量；$\Delta { H _ { s } }$ 是使纤维素样品脱水所需的热量，该样品也已暴露在与标准样品相同的条件下。然而，需要注意的是，使用湿润的[[无定形纤维素]]可能存在问题，因为它在水分存在下会发生再结晶。此外，要建立一种使用该方法评估[[纤维素结晶度]]的通用方案，有必要了解样品[[吸附]]水蒸气时的相对湿度以及脱水前的保存技术。

[[差示扫描量热法|DSC]] 还存在其他一些局限性，因为该方法假设[[纤维素]]的非晶区完全负责水分吸收。然而，少量水分会附着在纤维素的结晶部分，这对于高[[结晶度]]样品是无法避免的。因此，该方法最适用于低结晶度纤维素样品。<sup>196</sup> 此外，[[峰面积]]测量中的基线估计也很困难。<sup>191,194,198</sup> 尽管 DSC 技术在聚合物科学家中获得了用于测定结晶度的关注，但它在纤维素研究中的应用仍然有限。其主要原因是，在常规[[半结晶聚合物]]中，可以通过熔融来测量结晶热。由于纤维素不会熔融，因此无法测量这一性质。此外，纤维素因水分引起的转变还受到样品中其他因素和其他聚合物的影响。它仅被用于探究热行为，这可以从关于用 DSC 法测定[[纤维素结晶度]]的文献调研中得到理解。<sup>199,200</sup> 需要进一步研究，以解决与 DSC 技术评估纤维素结晶度相关的局限性。

## 6. 通过[[碳水化合物结合模块]]（[[纤维素结合分子|CBM]]）测定[[纤维素结晶度]]

除获取[[纤维素]]结构形态信息外，还发展了生化途径来测定[[纤维素结晶度]]。最初，这些方法是为了定量测定经酶解处理的纤维素纤维的可及性而开发的。然而，纤维素[[结晶度]]可能不会影响酶解过程中的产率，但会影响水解动力学。<sup>201</sup> 例如，已有研究表明，拟结晶纤维素区域比[[结晶区]]域水解更快。<sup>202</sup> 不过，由于纤维素结晶度是影响纤维素可及性的关键因素之一，因此可以通过这些方法获得关于结晶纤维素部分的定性信息。

这些方法利用[[碳水化合物结合模块]]（[[纤维素结合模块|CBMs]]），它们是存在于[[碳水化合物活性酶]]中的[[多肽序列]]，对不同碳水化合物结构具有特异性结合能力。根据分子结构和[[氨基酸序列]]，CBMs 可分为 68 个家族；根据其三维结构和活性，它们又分为 A 型、B 型和 C 型。<sup>201,203</sup> [[A型CBM|A 型 CBMs]] 是表面结合型蛋白质，对[[纤维素|结晶纤维素]]具有更高的亲和力。与 A 型不同，B 型蛋白质通过与[[聚糖链]]结合而表现出对非晶纤维素区域的亲和力。然而，[[B型CBM|B 型 CBMs]] 无法识别由少于三个糖单元组成的聚糖链，而 [[C型CBM|C 型 CBMs]] 则对 1–3 个糖单元表现出结合特异性。<sup>201,203</sup>

此外，还通过将 [[纤维素结合模块|CBMs]] 与[[绿色荧光蛋白]]（GFPs）结合开发了[[融合蛋白]]，以便于直观观察[[纤维素]]形态。例如，Hong 等（2007）制备了一种此类融合蛋白，用于定量测定纤维素对纤维素酶的可及性，水解温度为 50 1C。<sup>204</sup> 类似地，Li 等（2018）设计了一种将 CBMs 与双绿色荧光蛋白结合的[[重组蛋白]]，以定量测定纤维素对纤维素酶的可及性。<sup>205</sup> Kljun 等（2011）使用 CBMs 评估棉纤维[[丝光处理]]过程中[[纤维素结晶度]]的变化（图 14A）。<sup>206</sup> 作者使用两种 [[A型CBM|A 型 CBM]] 和两种 [[B型CBM|B 型 CBM]]，并结合[[荧光成像]]，直观显示了丝光处理各阶段[[结晶度]]的变化，其结果与图 14B 所示传统 [[XRD]] 和 [[FTIR]] 技术所得结果一致。<sup>206</sup> CBMs 的结合强度通过测量[[无定形区]]的总暗色面积和[[结晶区]]的总绿色/亮色面积来计算。同时还测量了纤维总面积，并以亮色或暗色面积占纤维总面积的百分比来计算与纤维结合和未结合 CBMs 的比例。他们还根据 [[傅里叶变换红外光谱|FTIR]] 谱图估算了[[侧向有序指数]]（LOI）和[[氢键强度]]（HBI）。LOI 和 HBI 分别根据位于 1429 至 893 cm<sup>1</sup> 的吸收带强度，以及 3336 至 $1 3 3 6 ~ \mathrm { { c m } ^ { - 1 } }$ 谱带强度之比来确定。<sup>207,208</sup> 他们发现，对于 Coker 和 FM966 两种纤维，LOI 与 CBMs 在结晶纤维素上结合能力的相对强度呈现相似趋势。另一方面，HBI 随纤维样品无定形区增加而升高。如图 14C 所示，HBI 也显示出与倾向[[无定形纤维素]]区域的 [[碳水化合物结合模块|CBM]] 相对强度相似的趋势。

Guo 等（2019）构建了一种 [[碳水化合物结合模块|CBM]]-[[绿色荧光蛋白|GFP]] 导向的[[蛋白探针]]，用于定量测定[[纤维素结晶度]]。不同探针的结合浓度使用[[荧光分光光度计]]测定，探针对底物的结合能力则由相对强度通过以下方程计算<sup>209,210</sup>

$$
\text {Binding capability} (\%) = \frac {\left(\mathrm{FI} _ {\text {control}} - \mathrm{FI} _ {\text {final}}\right)}{\mathrm{FI} _ {\text {control}}} \times 100\tag{25}
$$

其中 $\mathbf { F I _ { c o n t r o l } }$ 和 $\mathbf { F I _ { f i n a l } }$ 分别表示在不存在和存在[[纤维素]]底物条件下孵育后上清液的荧光强度。作者表明，其[[融合蛋白]] CG2a（[[A型CBM|A 型 CBM]]，倾向结晶纤维素）以及 [[CBM17]] 和 [[CBM28]]（[[B型CBM|B 型 CBM]]，倾向[[无定形纤维素]]）的结合能力与 [[XRD]] [[结晶度]]数据呈正线性相关，如图 14D 所示。基于其相关方程，作者计算了代表性样品的[[纤维素结晶度]]，并报告了与 [[X射线衍射|XRD]] 测量结果相同的趋势。<sup>209</sup>

## 7. 其他方法

[[纤维素]]的若干物理化学性质，如[[比重]]、<sup>211,212</sup> [[润湿热]]、<sup>213</sup> [[水蒸气吸附]]、<sup>214</sup> [[碘吸附]]、<sup>215</sup> [[化学反应活性]]、<sup>216</sup> 及其他性质，也可用于估算纤维素聚合物中的结晶部分。以下讨论其中一些方法。

## [[比重]]

[[比重]]定义为某物质的密度与水的密度之比。由于[[纤维素]]结构受杂质和残留水分的存在、不同氧化程度以及干燥方法等因素的影响，直接测量[[无定形纤维素]]的比重可能具有挑战性。因此，可以使用已知[[结晶度]]的纤维素样品来估算未知样品的结晶度。已知[[半结晶聚合物]]的比重与其结晶度（X）之间的关系可表示如下：

$$
X = \frac {(\rho_ {\mathrm{c}} / \rho) (\rho - \rho_ {\mathrm{a}})}{(\rho_ {\mathrm{c}} - \rho_ {\mathrm{a}})}\tag{26}
$$

其中 $\rho _ { \mathrm { c } }$ 和 $\rho _ { \mathrm { a } }$ 分别为[[半结晶聚合物]]的[[结晶区]]和[[无定形区]]的[[比重]]。式（26）可转化并整理为：

$$
\frac {1}{\rho} = \frac {1}{\rho_ {\mathrm{a}}} - X \bigg [ \left(\frac {1}{\rho_ {\mathrm{a}}}\right) - \left(\frac {1}{\rho_ {\mathrm{c}}}\right) \bigg ]\tag{27}
$$

其形式类似于直线方程：

$$
V = V _ {\mathrm{a}} - K X\tag{28}
$$

其中 ${ \frac { 1 } { \rho } } = V$ 为样品的[[比容]]，$\frac { 1 } { \rho _ { \mathrm { a } } } = V _ { \mathrm { a } }$ 为[[无定形区]]的比容，且 $K = \left( \frac { 1 } { \rho _ { \mathrm { a } } } \right) - \left( \frac { 1 } { \rho _ { \mathrm { c } } } \right)$

因此，通过测量一些已知[[结晶度]][[纤维素]]样品的[[比重]]，可以获得一条直线，并计算[[结晶区]]和[[无定形区]]的比重。[[Ioelovich]] 等人（2010）使用 $\rho _ { \mathrm { c } } = 1 . 6 2 \ \mathrm { g } \mathrm { c m } ^ { - 3 }$ 和 $\rho _ { \mathrm { a } } = 1 . 4 4 \ \mathrm { g } \ \mathrm { c m } ^ { - 3 }$ 通过该法测量了[[纤维素结晶度]]。所得结果与 [[XRD]] 结果一致。<sup>211</sup>

## [[润湿热]]

前文已提及，[[纤维素—水相互作用]]归因于[[纤维素]]的[[无定形区]]。因此，与此现象相关的[[放热热量]]或[[润湿热]]（DH）与纤维素的无定形含量（Y）成正比。

$$
\Delta H = \Delta H _ {\mathrm{Am}} Y\tag{29}
$$

$$
Y = \frac {\Delta H}{\Delta H _ {\mathrm{Am}}}\tag{30}
$$

$$
X = 1 - \left(\frac {\Delta H}{\Delta H _ {\mathrm{Am}}}\right)\tag{31}
$$

其中 X 为[[纤维素]]样品中[[结晶域]]的含量，$\Delta H _ { \mathrm { A m } }$ 为[[完全无定形纤维素]]的[[润湿热]]。实验观察表明，润湿热（DH）随纤维素样品的[[最大蒸气吸附值]] $\left( { A _ { \mathrm { o } } } \right)$ 线性增加，且已报道恒定的[[比焓]] $\left( h = { \frac { \Delta H } { A _ { \mathrm { o } } } } \simeq 3 3 5 \mathrm { ~ J ~ g ^ { - 1 } ~ w a t e r } \right)$

因此，考虑到[[无定形纤维素]]的最大吸收，$\Delta H _ { \mathrm { A m } }$按如下方式确定：

$$
\Delta H _ {\mathrm{Am}} = h A _ {\mathrm{o}}\tag{32}
$$

将$\Delta H _ { \mathrm { A m } }$值代入公式（31），即可得到[[纤维素]]结晶分数。作者报告称，通过该方法得到的[[结晶度]]值高于通过[[XRD]]技术获得的值。<sup>214</sup>

## 8. 不同[[纤维素结晶度]]测量技术之间的比较

长期以来，[[纤维素结晶度]]在决定材料的物理和化学性质方面一直发挥着重要作用。因此，[[纤维素晶体结构]]的研究因其多样化的应用而受到关注。人们也已使用不同技术来测量[[纤维素结晶度指数]]，而这些技术均会给出不同的数值。本节将对这些技术进行讨论并加以比较，如图15所示。

取用来自不同来源、具有不同纯度的[[纤维素浆粕]]，并采用[[XRD]]、[[核磁共振|NMR]]、[[红外光谱|IR]]、[[拉曼光谱|Raman]]、[[和频产生|SFG]]和[[差示扫描量热法|DSC]]对其[[结晶度指数]]进行了分析。<sup>177</sup>选取[[棉短绒]]（最纯净的[[纤维素]]来源之一，其干质量中纤维素含量超过95%）、低[[聚合度]]的[[Avicel]]、[[α-纤维素|a-纤维素]]（主要为纤维素$\mathbf { I } _ { \mathrm { \{ } }  \mathbf { \Psi } _ { \mathrm { } }$[[针叶木浆粕|漂白阔叶木（HW）和针叶木（SW）浆粕]]进行比较。图15展示了使用一系列不同技术（即[[X射线衍射|XRD]]、NMR、IR、Raman和[[和频产生振动光谱|SFG]]）测量纤维素CI时所得数据的图形表示。由XRD测得的CI值采用[[峰高法|峰高（PH）法]]和[[无定形扣除法|无定形扣除（AS）法]]计算，如表6所示。对于$\bar { 1 } 3 _ { \mathrm { C } }$ NMR，CI通过无定形（80–85 ppm）和结晶（85–89 ppm）纤维素[[C4峰化学位移]]的相对强度来测量。从表6可以观察到，用于测量纤维素CI值的方法对样品显示出相同的定性趋势，即棉短绒的CI最高，a-纤维素的CI最低。然而，不同方法的绝对CI值存在差异，这限制了使用不同方法估算的CI值之间的直接定量比较。因此，使用任何技术对不同样品测得的[[纤维素结晶度指数]]只能进行定性比较。

采用[[XRD]] [[无定形扣除法|AS法]]测得的HW和SW的[[结晶度指数|CI]]值与采用[[峰高法|PH法]]测得的值非常接近。然而，对于其他[[纤维素]]来源，CI值存在较大差异，如表6所示。这是由于HW和SW纤维在2y角大于$2 5 ^ { \circ }$处具有较高的无定形[[背景]]强度，而其他纤维素来源在该区域表现出较低的强度。因此，AS法无法在高2y区域扣除无定形背景，反而实际上将差异加到了结晶部分，这导致HW和SW的CI值远高于结晶纤维素占全部质量中的真实质量分数，且高于其他样品。

## 9. 结论

自我们最初理解这种复杂且普遍存在的聚合物以来，许多报告和数十年间一直讨论着定义[[纤维素结晶度]]的重要性。理解[[纤维素]]的结构有助于进行物理改性，以制备高性能产品并提高产率。本篇综述涵盖了用于测定纤维素[[结晶度]]的不同技术，即 [[X射线衍射|X 射线衍射]]（[[XRD]]）、[[核磁共振]]（NMR）、[[傅里叶变换红外光谱|傅里叶变换红外光谱（FTIR、拉曼）]]、[[差示扫描量热法]]（DSC）、[[和频产生振动光谱]]（[[和频产生|SFG]]）、[[纤维素结合分子|纤维素结合分子（CBM）方法]]、[[比重]]以及[[润湿热]]。每种[[结晶度指数]]可能因所选分析技术而异。通常，由 NMR 获得的 CI 值低于由 XRD 测量所得值。然而，[[相对结晶度]]值和结晶度变化趋势在所有技术中是一致的。例如，[[棉短绒]]被认为几乎是完全结晶结构，根据所呈现的不同方法，其 CI 最高。此外，其他因素如[[微晶尺寸]]、[[入射光束强度]]（在 XRD 情况下）、样品来源及测试前的预处理也会影响结晶度值。就此而言，尽管为测定纤维素结晶度付出了许多努力，文献中对于测定结晶度值和研究纤维素结构的绝对技术尚无共识。这一事实表明，纤维素结晶度无法通过单一技术估算；因此，结合不同技术计算 CI 可能是最佳方法。除实验数据外，软件或计算分析的使用可能是重要工具，因为软件可被设计用于计算和预测复杂细节，并精化实验上不可能获得的数据。因此，它们可通过协助解释实验数据来补充实验发现。
