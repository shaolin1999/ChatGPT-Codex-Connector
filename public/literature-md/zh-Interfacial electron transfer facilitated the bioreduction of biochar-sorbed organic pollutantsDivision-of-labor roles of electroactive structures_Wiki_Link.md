## 摘要

[[生物炭]]（BC）固有的[[孔隙率]]和芳香结构使其能够[[吸附]]大量[[有机污染物]]。然而，[[生物炭吸附态有机污染物|BC 吸附态有机污染物]]（BSOPs）的去向和潜在反应路径在很大程度上仍未被探索。我们假设 BC 中不同的电活性结构选择性地调控[[电活性细菌]]（[[EAB]]）的转录响应，以驱动[[界面电子转移]]（[[IET]]），从而促进 BSOPs 的降解。为验证这一假设，我们研究了在 500 °C 和 900 °C 下制备的生物炭（[[BC5]]、[[BC9]]）以及采用改进 Hummer 法制备的改性生物炭（[[MBC5]]、[[MBC9]]）所吸附的 [[2,5-二氯硝基苯|2，5-二氯硝基苯]]（[[DCBN]]）在环境中典型 [[胞外电子传递|EAB]]——[[奥奈达希瓦氏菌 MR-1]] 存在下的降解情况。[[吸附态 DCBN]] 的[[还原速率常数]]与[[电子传递速率常数]]之间的强相关性证实，吸附态 DCBN 的生物还原主要由“细菌—碳”聚集体内的 IET 调控$( \mathbf { r } ^ { 2 } = 0 . 9 0 )$。在所有$\mathsf { B C } s ,$中，[[改性生物炭|MBC9]] 表现出最高的还原速率常数$( k _ { s d } = 0 . 0 1 2 \mathrm { h } ^ { - 1 } )$。在机制上，$\scriptstyle \mathbf { C = O / O - C = O }$官能团促进了 [[c 型细胞色素]]基因 [[MtrC|mtrC]] 和 [[MtrF|mtrF]] 的上调表达，而[[石墨化结构]]促进了电子向吸附态 DCBN 的传递，揭示了 IET 路径中明确的分工角色。这些发现凸显了 BC 电活性结构在塑造 EAB–BC 相互作用中的关键作用，并为 BSOPs 的反应路径提供了新的见解。

## 1. 引言

[[生物炭]]（[[BCs]]）是具有丰富芳香结构的多孔碳基颗粒，被广泛用于[[吸附]]疏水性芳香[[有机污染物]]（Lin et al., 2023; Qi et al., 2022），其主要机制是由弱分子间作用力驱动的[[分配作用]]和[[孔填充作用]]（Chen et al., 2008; Chen et al., 2012; Lian and Xing, 2017）。在这些条件下，吸附于BC上的有机污染物（[[生物炭吸附态有机污染物|BSOPs]]）并不总是保持稳态。在扰动条件下，它们可能从BCs中解吸并再次释放（Dai et al., 2019; Xu et al., 2020a），从而带来潜在的环境风险。尽管[[电化学处理]]、[[催化氧化]]和[[超临界氧化]]已被开发为用于BSOPs降解的原位技术，以降低与解吸相关的风险，但其应用受到需要外部电压、额外氧化剂或特定反应器的限制（Charinpanitkul and Tanthapanichakoon, 2011; Liu et al., 2024; Osman et al., 2023; Qin et al., 2024; Wang et al., 2024a）。因此，开发环境友好且可持续的BSOP处理策略至关重要，而这需要阐明其与周围微环境中天然组分之间的相互作用途径。

一般而言，有机化合物主要被截留在[[BCs]]的[[微孔]]或[[介孔]]中（<50 nm）（Feng et al., 2021; Gan et al., 2021），这限制了它们与大尺寸天然组分的直接相互作用（Qi et al., 2022; Redwan and Millerick, 2021; Tao et al., 2024）。然而，电子可以容易地进入微孔或介孔，并直接与[[生物炭吸附态有机污染物|BSOPs]]相互作用（Sun et al., 2017; Tao et al., 2022; Yuan et al., 2022），这一过程还受到[[生物炭|BCs]]电活性结构（例如[[氧化还原官能团]]和[[石墨化结构|石墨结构]]）的进一步介导。重要的是，依赖于电活性结构的多条电子转移途径已被证实是实现[[吸附]]态污染物反应的有效策略（Hu et al., 2024; Wang et al., 2024b; Xu et al., 2013）。例如，已有研究表明，氧化还原官能团可以通过光诱导产生活性自由基，将电子从吸附态污染物中转移出来，从而驱动其完全矿化（Wang et al., 2024b）。此外，[[石墨结构]]被指出可介导从吸附态污染物到电子受体的直接电子转移，从而导致其氧化和降解（Hu et al., 2024）。

最近的研究发现，由[[生物炭]]（[[BCs]]）介导的电活性菌（[[EAB]]）也能表现出类似的[[界面电子转移]]（[[IET]]）行为，从而可能实现[[生物炭吸附态有机污染物|结合态有机污染物]]（BSOPs）的降解（Wang et al., 2020; Xu et al., 2020b）。然而，这些研究主要从 [[电活性细菌|EAB]] 群落演变或 BC 结构变化的角度解释 BSOP 降解，并未系统阐明参与 [[胞外电子传递|IET]] 的分子组分以及 IET 通路形成的潜在机制。[[奥奈达希瓦氏菌 MR-1|希瓦氏菌 MR-1]]（Shewanella oneidensis MR-1）是 EAB 的典型物种，其依赖自身特定的[[微生物电子传递网络]]（如[[外膜]] [[c 型细胞色素]]、[[导电附属结构]]和[[可扩散电子穿梭体]]）进行[[直接电子传递]]（[[DET]]）或[[间接电子传递]]（MET）（Logan et al., 2019; Lovley and Holmes, 2022; Yin et al., 2022）。此外，已有研究报道电活性结构能够对微生物电子传递网络的选择以及 c 型细胞色素基因的转录水平施加自下而上的调控（Li et al., 2023; Zhang et al., 2020）。然而，目前仍不清楚不同的电活性结构是否会因其物理化学特性差异而对微生物转录产生选择性或优先性调控。这种转录选择性将决定 BSOP 降解过程中 IET 的组成，并可能是驱动 IET 通路形成的潜在机制。据此，我们假设不同的电活性结构能够选择性地调节转录响应，进而塑造 IET 通路的组成和 BSOP 降解效率。

因此，本研究采用在不同温度下制备并经过化学改性的 [[BCs]]，考察[[奥奈达希瓦氏菌 MR-1|希瓦氏菌 MR-1]] 对 BSOP 的生物降解。[[2,5-二氯硝基苯]]（[[DCBN]]）作为一种典型的[[氯代硝基芳香族化合物]]，被选为本研究的目标污染物。该类化合物已在多种工业废水和地下水中被检出（Ri et al., 2023），由于其持久性和毒性，对生态和人类健康构成风险（Palatucci et al., 2019）。DCBN 中的吸电子基团提高了其化学稳定性和毒性，但也使其成为适合 [[IET]] 介导生物转化的底物。对 [[生物炭|BCs]] 的结构特征进行了分析，以评估其与[[吸附态 DCBN]] 生物降解的潜在联系及其与希瓦氏菌 MR-1 的相互作用。进一步开展[[转录组]]学分析，以鉴定参与[[吸附]]态 DCBN 生物降解的关键基因，并阐明电活性结构在微生物转录响应中的选择性作用。总体而言，本研究有望为结构驱动的 [[界面电子转移|IET]] 通路及其与 BSOP 降解的关联提供新的认识，从而深化对 BC 环境与修复作用的理解。

## 2. 材料与方法

## 2.1. [[BCs]] 的合成与表征

从江苏省连云港市收集的[[油菜秸秆]]用作[[生物炭]]（BC）制备原料。将原料在[[管式炉]]中于$\Nu _ { 2 }$气氛下[[热解]] 1.5 h，升温速率为$5 ~ \mathrm { ^ { \circ } C } \ \mathrm { m i n ^ { - 1 } }$。采用 500 和$9 0 0 ~ ^ { \circ } \mathrm { C }$的[[热解温度]]分别制得两种原始生物炭，标记为 [[BC5]] 和 [[BC9]]。随后，采用[[Hummer法|改良 Hummer 法]]（MHM，支持信息，文本 S1）对原始生物炭进行处理，制得改性生物炭（[[改性生物炭|MBCs]]），分别标记为 [[MBC5]] 和 [[MBC9]]。为消除浸出液对微生物生长的影响，所有生物炭样品在微生物实验前均用去离子水冲洗十次（Yu et al., 2022）。生物炭的详细表征方法见支持信息（文本 S2）。

## 2.2. 电活性菌对[[生物炭]]上[[DCBN|吸附态 DCBN]] 的生物降解

[[S. oneidensis MR-1]] 在$3 0 ~ ^ { \circ } \mathrm { C }$下于含$5  g \mathrm { L } ^ { - 1 }$酵母浸膏、$1 0 \mathrm { g L } ^ { - 1 }$胰蛋白胨和 10 $\textrm { g L } ^ { - 1 }$ NaCl 的[[溶菌肉汤培养基|溶菌肉汤（LB）培养基]]中好氧培养。随后，通过 6000 rpm 离心收集对数生长后期的细胞。细胞沉淀经三次洗涤后，悬浮于无菌的 10 mM [[4-(2-羟乙基)-1-哌嗪乙磺酸]]（HEPES）缓冲液中备用。

[[2,5-二氯硝基苯|DCBN]] 生物降解动力学实验在 110 mL 血清瓶中进行，瓶内含 50 mL [[无机盐培养基]]，其中含有 1.50 g $\mathrm { L } ^ { - 1 }$ NH<sub>4</sub>Cl、0.10 g L<sup>-1</sup> KCl、11.35 $; \mathrm { L } ^ { - 1 } \mathrm { N a } _ { 2 } \mathrm { H P O } _ { 4 }$和 2.40 g L<sup>-1</sup> NaH<sub>2</sub>PO<sub>4</sub>。

向培养基中加入终浓度为 20 mM 的[[乳酸钠]]作为电子供体。将四种[[生物炭]]分别以$\cdot \boldsymbol { g } { \cdot } \boldsymbol { \mathrm { L } } ^ { - 1 }$的投加浓度加入培养基中。装有特定培养基的血清瓶用$\mathrm { N } _ { 2 }$吹扫至少 0.5 h 以维持厌氧气氛，然后用橡胶塞密封，并在$1 2 1 ~ ^ { \circ } \mathrm { C }$下高压蒸汽灭菌 0.5 h。在接种 [[S. oneidensis MR-1]] 前，将含有 0.52 mM [[2,5-二氯硝基苯|DCBN]] 的血清瓶先在黑暗条件下于 30 $^ \circ \mathrm { C }$和 170 rpm 振荡 96 h，以比较不同生物炭的[[吸附]]性能。随后，向血清瓶中加标高浓度 [[DCBN]]，以使生物炭的吸附容量达到饱和，并确保吸附平衡后初始水相 DCBN 保持在接近 0.26 mM。然后将 [[Shewanella oneidensis MR-1|S. oneidensis MR-1]] 以初始$\mathrm { \ O D } _ { 6 0 0 }$为 0.1 接种至血清瓶中，进行生物降解动力学测定。同步设置不含生物炭的生物对照和不接种 [[奥奈达希瓦氏菌 MR-1|S. oneidensis MR-1]] 的非生物对照，所有实验均设三个平行。另在 DCBN 浓度为 0.2 mM 条件下进行了额外的微生物降解实验，以验证[[吸附态 DCBN]] 的生物降解行为。所有批次实验中 DCBN 浓度及吸附平衡后相应水相浓度的详细信息见支持信息（表 S1）。

## 2.3. [[2,5-二氯硝基苯|DCBN]] 的分析方法

定期从每个瓶中取出液体和固体样品以测定 [[2,5-二氯硝基苯|DCBN]] 浓度。简言之，取 2 mL 含 [[BCs]] 和溶液的样品，通过 0.22 μm 尼龙滤膜过滤分离为液相和固相。收集固相，并用 3 mL 甲醇超声提取 60 min。[[DCBN]] 浓度采用配备 C18 色谱柱（5 μm，4.6 × 250 mm，Agilent $\mathrm { C o } ,$ US）的[[高效液相色谱|高效液相色谱仪]]（HPLC，1290 Infinity，Agilent Co，US）测定。流动相为甲醇/水（80:20，v/v），流速为 1.0 mL min<sup>-1</sup>。采用[[气相色谱-质谱联用|气相色谱-质谱联用仪]]（GC–MS，7890B-5977A，Agilent Co，US）分析 DCBN 降解产物。进样器和检测器温度分别设置为 $2 5 0 ~ ^ { \circ } \mathrm { C }$ 和 ${ 3 0 0 } ^ { \circ } \mathrm { C } ,$。GC–MS 的调谐模式采用[[电子电离]]（EI）模式，电离能量为 70 eV。DCBN 生物转化过程中的产物根据质荷比（m/z）进行鉴定，并与[[美国国家标准与技术研究院]]（NIST）质谱库匹配良好。

## 2.4. 动力学建模与[[还原速率常数]]计算

采用 [[Langmuir 动力学模型]]描述[[DCBN|吸附态 DCBN]] 的浓度变化（Q，mmol $\cdot g ^ { - 1 } )$（Wang et al., 2020; Xu et al., 2013）。其方程如下：

$$
\frac {\mathrm{d} C}{\mathrm{d} t} = - k _ {a} (Q _ {e} - Q) \rho C + k _ {d} \rho Q\tag{1}
$$

其中，$k _ { a }$ 表示[[吸附速率常数]] $( \mathbf { m } \mathbf { M } ^ { - 1 } { \cdot } \mathbf { h } ^ { - 1 } )$，$k _ { d }$ 为[[解吸速率常数]] $( \mathbf { h } ^ { - 1 } )$）。$Q _ { e }$ 为最大[[吸附]]容量（mmoles $g ^ { - 1 } ) , \rho$ 为 [[BCs]] 浓度 $( 1 ~ g { \cdot } \mathrm { L } ^ { - 1 } ) .$，C 表示[[DCBN|水相 DCBN]] 浓度（mM），$( Q _ { e } - Q )$ 对应空余吸附位点浓度。向混合物中加入 [[S. oneidensis MR-1]] 后，[[2,5-二氯硝基苯|DCBN]] 被生物还原，吸附平衡立即被打破。观测到的 DCBN 浓度（液相和吸附相）下降受吸附-解吸动力学与生物还原过程的共同影响。水相 DCBN 的还原常数 $( k _ { a q } )$ 和[[吸附态 DCBN]] 的还原常数 $( k _ { s d } )$ 通过定量计算与吸附-解吸过程区分开来，水相和吸附相中 DCBN 浓度分别用以下方程描述：

$$
\frac {\mathrm{d} C}{\mathrm{d} t} = - k _ {a} (Q _ {e} - Q) \rho C + k _ {d} \rho Q - k _ {a q} C\tag{2}
$$

$$
\frac {\mathrm{d} Q}{\mathrm{d} t} = k _ {a} (Q _ {e} - Q) C - k _ {d} Q - k _ {s d} Q\tag{3}
$$

$k _ { a q }$ 和 $k _ { s d }$ 通过将实测水相和[[吸附]]相浓度对式（2）和式（3）进行非线性拟合确定。动力学模型的详细计算与说明见补充信息（Text S3）。

## 2.5. 电化学分析

[[BCs]] 的[[电子供给能力]]（EDC）和[[电子接受能力]]（EAC）通过介导电化学过程在三电极体系中测定。[[电子交换容量]]（EEC）以 EDC 与 EAC 之和计算。使用涂覆 [[生物炭|BCs]] 的石墨电极与 [[S. oneidensis MR-1]] 进行[[循环伏安]]（[[循环伏安法|CV]]）测试，并根据 [[Laviron 理论]]计算[[异相电子转移速率常数]]（k<sub>s</sub>）（Laviron, 1979）。所有电化学测试均在厌氧条件下使用[[电化学工作站]]（Metrohm Autolab B.V., Switzerland）完成。详细的电化学步骤和分析见补充信息（Text S4）。

## 2.6. [[BCs]] 上活菌分布与蛋白质定量

在[[2,5-二氯硝基苯|DCBN]]生物还原24 h后，从血清瓶中取出[[生物炭|BC]]颗粒，并用无菌50 mM PBS冲洗，以清除浮游的[[S. oneidensis MR-1]]细菌。随后，使用LIVE/DEAD BacLight细菌活力检测试剂盒（L7012，Thermo Fisher Scientific Inc.，USA）对BC颗粒进行染色。利用[[共聚焦激光扫描显微镜]]（[[CLSM]]，LSM700，Carl Zeiss，Germany）观察活细菌在BC颗粒上的分布。使用[[ImageJ]]软件评估微生物表面覆盖率。同时，根据前述研究（Sun et al.，2024）所描述的[[Bradford法]]测定的蛋白浓度，估算定殖于[[BCs]]上的细菌细胞数量。

## 2.7. [[转录组分析]]

## 3.1. [[BCs]]增强[[2,5-二氯硝基苯|DCBN]]的微生物降解

在添加[[BCs]]进行[[2,5-二氯硝基苯|DCBN]]微生物还原之前，开展了[[吸附]]实验，以评估[[生物炭|BCs]]对[[DCBN]]的吸附特征参数。预吸附过程后，水相中残留的DCBN小于30%（图S1）。计算了[[吸附速率常数]]$( k _ { a } )$和[[解吸速率常数]]$( k _ { d } )$（图1a），其中[[BC9]]表现出最高的$k _ { a } .$值。相比之下，[[改性生物炭|MBCs]]的$k _ { a \cdot }$值相对较低。$k _ { a }$的差异可能源于BC疏水性、[[孔隙率]]和[[石墨化]]程度的不同，这些因素共同影响DCBN的吸附。上述吸附结果表明，本研究中所用的BCs能够有效地将DCBN保留在吸附相中。

图S2展示了活[[S. oneidensis MR-1]]、失活[[Shewanella oneidensis MR-1|S. oneidensis MR-1]]和非生物对照对[[吸附]]态[[2,5-二氯硝基苯|DCBN]]的去除效率及[[2,5-二氯苯胺|DCA]]转化情况。0.2 mM的低[[DCBN]]浓度确保了DCBN保留在吸附相中，水相中几乎检测不到DCBN。在此条件下，活[[奥奈达希瓦氏菌 MR-1|S. oneidensis MR-1]]明显还原了吸附态DCBN，而失活细胞和非生物对照的还原可忽略不计。MS谱图结果表明，DCBN被还原为2,5-二氯苯胺（[[DCA]]）（图S3），表明在S. oneidensis MR-1介导的[[生物炭|BC]]生物降解过程中发生了顺序加氢反应。在活S. oneidensis MR-1培养物中观察到的吸附态DCBN同步下降和明显的DCA转化，证实了S. oneidensis MR-1能够驱动吸附态DCBN的生物还原。

## 3.2.2. 界面相互作用与相关性分析

[[CLSM]]图像显示了活细菌在[[BCs]]上的分布，并观察到[[细菌–碳聚集体|“细菌–碳”聚集体]]的形成（图3a–h）。与[[BC5]]和[[BC9]]相比，[[改性生物炭|MBCs]]与[[S. oneidensis MR-1]]细胞表现出更紧密的接触，形成了丰富的团聚复合体。MBCs强[[亲水性]]表面促进了其与细胞膜蛋白的相互作用（Redwan and Millerick, 2021）。蛋白质浓度和微生物表面覆盖率进一步支持了这一观点，其中[[MBC5]]表现出最高值（图3i）。这些紧密聚集体对于[[吸附]]态[[2,5-二氯硝基苯|DCBN]]的生物还原十分重要，因为它们有助于缩短[[胞外电子传递|EABs]]与[[生物炭|BCs]]之间的[[IET]]距离，从而提高电子交换速率（Lu et al., 2021）。类似地，

Yang et al. (2020)报道，电子转移速率高度依赖于[[胞外电子传递|EABs]]、[[BCs]]和水铁矿之间的紧密聚集，这对微生物还原水铁矿至关重要。因此，可以推断[[细菌–碳聚集体|“细菌–碳”聚集体]]是[[吸附]]态[[2,5-二氯硝基苯|DCBN]]生物还原的主要位点。

为了探究[[细菌–碳聚集体|“细菌–碳”聚集体]]内详细的[[IET]]过程，在以不同扫描速率负载[[S. oneidensis MR-1]]的[[生物炭|BC]]涂层石墨电极上进行了[[循环伏安|CV]]测试。如图3j所示，位于约−451.3至−381.0 mV和−569.7至−475.0 mV的氧化还原峰对据推测归属于[[黄素|黄素类物质]]（Choi等，2018；Xia等，2024）。此外，在−8.5至68.6 mV和−123.6至0.16 mV还发现了其他氧化还原对，其位置接近已报道的[[c型细胞色素]]对应的峰位（Choi等，2018；Liu等，2025）。[[Laviron理论|Laviron图]]显示峰电位与对数扫描速率之间存在强相关性$( \mathbf { r } ^ { 2 } > 0 . 9 7 )$（图S6）。在扫描速率o $7 0 \mathrm { m V s ^ { - 1 } }$下，[[MBC9]]处理中黄素类物质和c型细胞色素的氧化峰与还原峰之间均观察到最小电位差$( \Delta E _ { p } )$，表明其电子转移动力学增强（Li等，2021）。基于Laviron理论，[[改性生物炭|MBC9]]处理中黄素和c型细胞色素的[[异相电子传输速率常数]]$( k _ { s } )$分别计算为0.0045 $\dot { s } ^ { 1 }$和$0 . 0 2 7 \ s ^ { - 1 } ;$——高于其他BC处理中观察到的数值。

$k _ { s }$与[[吸附]]态[[2,5-二氯硝基苯|DCBN]]还原速率之间的强相关性表明，吸附态[[DCBN]]的微生物还原在很大程度上受[[细菌–碳聚集体|“细菌–碳”聚集体]]内[[IET]]过程的控制

研究结果显示，若干参与 [[c 型细胞色素]]的基因显著上调，包括 [[MtrC|mtrC]]、[[MtrF|mtrF]]、SO\_RS20245、[[ccmA]]、[[CymA|cymA]]、SO\_RS08170 和 [[ompW]]。基于[[转录组分析]]，推测经由[[Mtr途径|金属呼吸（Mtr）途径]]的[[直接电子传递]]在 [[生物炭|BC]] 介导的 [[2,5-二氯硝基苯|DCBN]] 降解中发挥关键作用。ccmA 编码的 c 型细胞色素生物发生蛋白 CcmA 能够促进成熟 c 型细胞色素的产生（Chen et al., 2010），这是由 c 型细胞色素组成的 Mtr 途径的前提条件。[[cymA]] 编码的内膜蛋白 CymA 负责将胞内电子递送至 DmsE 和 MtrA（Bewley et al., 2012）。编码 MtrB/PioB 家族十血红素相关[[外膜]]蛋白的基因 SO\_RS20245 是 Mtr 途径中不可或缺的氧化还原组分（Schicklberger et al., 2013）。由基因 [[mtrC]] 和 [[mtrF]] 编码的十血红素 c 型细胞色素 MtrC 和 MtrF 是 Mtr 途径的末端外膜蛋白，可直接还原胞外电子受体。除 Mtr 途径外，由 SO\_RS08170 编码的 DmsE 家族十血红素 c 型细胞色素位于周质空间，介导从胞内空间到整合外膜 β-桶蛋白的电子传递（Bewley et al., 2012）。据报道，ompW 编码的外膜蛋白 OmpW 参与产电过程和氯霉素还原（Barchinger et al., 2016; Breuer et al., 2014; Li et al., 2023）。

其他编码[[延胡索酸还原酶]]细胞色素 b 亚基（SO\_RS01910，[[MBC9]] 中为 3.56 倍）、NADH:泛醌还原酶（Na（+）转运型）亚基 E（nqrE，[[BC9]] 和 [[改性生物炭|MBC9]] 中分别为 3.58 倍和 3.16 倍）以及[[甲酸脱氢酶]]-N 亚基 α（fdnG，BC9 和 MBC9 中分别为 3.87 倍和 12.09 倍）的基因也显著上调，此前研究发现这些基因参与增强 S. oneidensis 的[[胞外电子传递]]（Akutsu and Takayama, 2007; Li et al., 2023; Pealing et al., 1992; Qiu et al., 2013; Ruebush et al., 2006）。因此，上述结果表明 [[BCs]] 可能激活氧化还原酶的[[氧化还原活性]]，从而加速电子传递。

[[趋化性]]使[[电活性细菌]]能够感知不溶性电子受体（IEA）并将其运动偏向 IEA，最终导致 [[EAB]] 在 IEA 附近聚集（Harris et al., 2012; Liu et al., 2021; Starwalt-Lee et al., 2021）。本研究中还发现趋化性相关基因显著上调。编码趋化蛋白 [[CheA]]（SO\_RS09760）、[[CheW]]（SO\_RS09765）、[[CheY]]（cheY）以及含 PAS 结构域的甲基接受趋化蛋白（SO\_RS06435）的基因对于对 IEA 的行为响应是必需的（Cheng et al., 2019; Harris et al., 2012; Starwalt-Lee et al., 2021）。同时，参与[[鞭毛]]的基因也显著上调，包括编码鞭毛运动控制蛋白 ZomB（zomB）、鞭毛运动开关蛋白 FliM（fliM）、[[鞭毛组装]]蛋白 FlgT（SO\_RS15205）和鞭毛生物合成蛋白 FliR（fliR）的基因。鞭毛是趋化性的最终执行者，在先前与其他固体介质相关的研究中也观察到[[鞭毛基因]]的过表达（Sun et al., 2024; Yang et al., 2024; Zheng et al., 2021）。

在[[MBC5]]和[[BC5]]处理中也观察到类似结果，与[[c型细胞色素]]、[[电子传递酶]]、[[趋化性]]和[[鞭毛]]相关的基因显著过表达（表S6）。[[改性生物炭|MBC5]]对这些关键基因的调控作用比BC5更强。[[转录组分析]]在分子水平上揭示了细菌向MBCs迁移增强，并强调了c型细胞色素（尤其是由[[MtrC|mtrC]]和[[MtrF|mtrF]]编码的c型细胞色素）在介导MBCs与[[S. oneidensis MR-1]]相互作用中的重要作用。

对关键[[DEGs]]表达水平的分析表明，除[[电子传递酶]]相关基因外，与[[MBC9]]相比，大多数[[差异表达基因|DEGs]]在[[MBC5]]处理下均显著上调（图6）。基于各组间的比较[[转录组]]数据，C=O/O–C=O官能团水平升高被认为与这些基因的正转录调控有关。相比之下，[[改性生物炭|MBC9]]中[[IET]]相关基因的表达低于MBC5，表明以MBC9为代表的高丰度[[石墨化结构|石墨结构]]对微生物的调控作用不如C=O/O–C=O基团明显。

富集的C=O/O–C=O官能团具有[[亲水性]]和[[氧化还原活性]]，可赋予[[MBC5]]更强的[[生物相容性]]和[[电子传递能力]]。这些界面性质可能与微生物调控有关。[[导电材料]]对[[IET]]相关基因的正转录调控此前已有报道（Li et al., 2023）。类似地，[[氧化还原因子]]也被发现可调控[[趋化基因]]的表达（Tschirhart et al., 2017）。Tai et al. (2010)报道了趋化基因与[[c型细胞色素]]基因之间的显著关系。[[鞭毛基因]]的上调也促进了[[鞭毛组装]]以及[[S. oneidensis MR-1]]向[[改性生物炭|MBC5]]的快速迁移，这一过程因其亲水表面而进一步增强。最后，紧密接触和富集的C=O/O–C=O基团可提高[[Shewanella oneidensis MR-1|S. oneidensis MR-1]]的[[胞外电子释放]]需求，从而促进[[MtrC|mtrC]]和[[MtrF|mtrF]]的上调。

## 4. 结论

• [[IET]] 被确定为 [[S. oneidensis MR-1]] 直接生物还原 [[生物炭|BC]] [[DCBN|吸附态 DCBN]] 的有效途径，从而将 BC 的环境角色从污染物的庇护所转变为[[生物催化剂]]。[[EAB]] 与 BC 之间形成的紧密聚集，以及 BC 诱导的转录上调，协同增强了 [[界面电子转移|IET]] 过程，导致[[吸附态 DCBN]] 的快速生物还原。
