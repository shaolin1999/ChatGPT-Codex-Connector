## ■ 引言

[[三氟乙酸]]（TFA）属于[[全氟和多氟烷基物质]]（PFAS）中被称为[[超短链全氟烷基酸]]（[[全氟烷基酸|PFAAs]]）的亚类。TFA 是迄今环境中含量最丰富的 PFAS。<sup>1−6</sup> Neuwald 等人证实，在德国的多种[[饮用水水源]]中，TFA 占 PFAS 总质量（所分析的 46 种单体 PFAS）的 90% 以上。<sup>2</sup> Tian 等人观察到，中国两座垃圾填埋场周边空气、[[干沉降颗粒物]]和[[植物叶片]]中 TFA 和[[全氟丙酸]]（PFPrA）的浓度，比所分析的其他 21 种 PFAS 高出一个数量级。<sup>4</sup> [[Chen]] 等人测定了中国两家氟化工生产厂周边的 25 种 PFAS，涵盖 8 种不同介质（空气、各类水体、[[土壤]]、[[灰尘]]、植物叶片、[[沉积物]]），其中 TFA 的浓度始终比其他 PFAS 高出 1−2 个数量级。<sup>5</sup>

对 [[三氟乙酸|TFA]] [[环境归趋]]及其效应的第一波科学关注始于 20 世纪 90 年代中期左右，原因是在消耗[[臭氧]]层的[[氯氟烃]]（CFCs）依据 1987 年《蒙特利尔[[消耗臭氧层物质]]议定书》被逐步淘汰后，新型[[含氟制冷剂]]（[[氢氟烃]]（HFCs）和[[氢氯氟烃]]（[[氢氯氟碳化物|HCFCs]]））被引入市场。<sup>7−12</sup> 许多含氟[[制冷剂]]被称为 [[含氟气体|F-gases]]（涵盖含有 R−CF 基团、R−CF −R 基团的气体或[[无机氟化物]]）。当 F-gases 或其他[[含氟有机物]]含有耐生物化学或光化学降解的 C−CF 基团时，TFA 通常会成为其终端降解产物。近年来，由于在偏远地区观测到 TFA 浓度迅速升高，以及其在[[饮用水水源]]和[[人体血液]]中普遍存在，TFA 再次受到关注。<sup>2,13−15</sup>

自 20 世纪 90 年代以来，一直有观点认为，[[三氟乙酸|TFA]] 和其他[[短链全氟烷基酸|短链 PFAAs]] 引发的危害担忧远低于[[全氟烷基链]]更长的 [[全氟烷基酸|PFAAs]]，后者具有更强的[[生物累积|生物累积性]]，且通常[[毒性]]更高。<sup>8,9,16−23</sup> 然而，这些早期报告并未考虑 TFA 在环境中的普遍累积，尤其是已观测到的其在水资源中的累积，以及在包括[[农作物]]在内的多种植物中的[[生物蓄积|生物累积]]。尽管与[[长链全氟烷基酸|长链 PFAAs]] 相比，TFA 的[[毒理学]]数据较少，但我们认为，现有数据已足以得出以下结论：TFA 对人类和环境构成风险，并符合[[新型实体]]对[[行星边界]]构成威胁的判定标准。<sup>24−27</sup> 我们将基于 TFA 的以下特征提供证据：（1）全球暴露不断增加；（2）这种暴露不可逆，且因众多来源的排放而持续增加；进而可能（3）对人类健康和关键[[地球系统过程]]造成长期的破坏性影响。我们的分析得出结论：应在全球范围内实施政策、行业举措和创新行动，尽快减少 TFA 排放，以保护后代免受 TFA 累积可能造成的不可逆影响。

## ■ 不断增加的全球暴露

我们开展了科学文献综述，以概览不同[[环境介质]]中的平均浓度和最高浓度（完整方法和收集的数据见支持信息（SI））。简言之，我们选取了 43 项报告 [[三氟乙酸|TFA]] 浓度的研究，其时间跨度从 20 世纪 90 年代末至 21 世纪 20 年代，并分析了监测数据。总体而言，这些数据表明，TFA 暴露广泛存在且正在增加。

[[全氟和多氟烷基物质|PFAS]] 质量中超过 98% 为 [[三氟乙酸|TFA]]。<sup>32</sup>瑞士的一项研究报告称，2023 年在 564 份[[饮用水]]样品中的 560 份中检出了 TFA，69% 的样品浓度高于 $0 . 5 \ \mu \mathrm { g / L } ,$，其中有 2 份样品的 TFA 浓度高于 9 μg/L，75 份介于 1 与 $9 \mu \mathrm { g } / \mathrm { L } . ^ { 3 3 }$ 之间

如果[[土壤]]或水中存在 [[三氟乙酸|TFA]] 污染，短链和超[[短链全氟烷基酸|短链 PFAAs]] 会被[[农作物|作物]]及其他植物迅速吸收并发生[[生物累积]]，尤其是在其地上部分。<sup>34−37</sup>[[Chen]] 等人<sup>5</sup>在中国一处氟化工工业场地附近的植物中检出了高达 3800 $\mathrm { m g / k g _ { d w } }$ 的 TFA，平均[[野外生物累积因子]]为 13,000。总体而言，TFA 一直在[[针叶树]]针叶、<sup>5,38</sup>[[玉米]]、<sup>5,39</sup>各种树木的叶片 $\mathsf { s p e c i e s } , \mathsf { \breve { + } } , \mathsf { 5 }$ 以及一些[[湿地物种]]中富集。<sup>40</sup>因此，有研究报告在[[植物性食品]]<sup>41</sup>以及 $\mathrm { j u i c e } , ^ { 4 2 }$、啤酒和 $\mathsf { t e a } ^ { 3 0 }$ 等[[植物性饮料]]中发现了高浓度的 TFA，这表明摄入植物性食品和饮料可能是人类（及动物）[[暴露途径|暴露的重要途径]]。

在来自中国的[[人体血液]]中检出了 [[三氟乙酸|TFA]]，<sup>43</sup>其浓度中位数为 8.46 μg/L，与[[长链全氟烷基酸|长链 PFAAs]] 的水平相近，尽管按照监管标准，TFA 不被认为具有[[生物累积|生物累积性]]（这些标准通常指进入[[食物链]]的[[水生物种]]中的[[生物蓄积|生物累积]]，而非植物中的生物累积）。<sup>44</sup>美国的一项类似研究报告的中位数为 6 μg/L，最大值为 77 $\mu \mathrm { g / L } , ^ { 1 8 }$，其中仅 TFA 就占[[人体血清]]中检出的 39 种 [[全氟和多氟烷基物质|PFAS]] 总质量的 57%。因此，未受[[职业暴露]]的美国公民体内的 TFA 浓度，与在职业暴露工人[[血清]]中测得的具有[[生物累积性]]的传统长链 [[全氟烷基酸|PFAAs]]（如 [[全氟辛烷磺酸|PFOS]]、[[全氟己烷磺酸|PFHxS]]、[[全氟壬酸|PFNA]]、[[全氟癸酸|PFDA]]）45 的浓度相近。由于摄入量高，TFA 在人体血清中达到的水平，远高于依据其在水生物种中的低生物累积潜力所预期的水平。

## ■ 多种排放源造成的不可逆负担

由于 [[三氟乙酸|TFA]] 具有[[化学持久性|持久性]]，且因缺乏[[吸附]]作用而具有高[[环境迁移性|迁移性]]，<sup>13,52</sup>其最终归宿是地球水圈。TFA 广泛存在于所有水体中，从[[地下水]]、[[海水]]、[[冰芯]]、[[饮用水]]到[[瓶装水]]，<sup>1,2,15,30,48,53−55</sup>因此，多种形式的稀释实际上已经发生，剩下唯一具有显著稀释能力的介质是深海。同样，随着水和[[土壤]]中 TFA 浓度的升高，植物中的富集也将随 TFA 浓度的持续增加而加剧。由于 TFA 具有[[持久性]]（不发生生物转化）且缺乏挥发性（因其在水中为强酸，完全电离），其从植物组织中消除的过程有限，因此，只要有 TFA 持续输入，就可以预期植物在整个生命周期内都会通过蒸腾流从[[土壤孔隙水]]中持续被动吸收 TFA。这一理论得到了其他短链和超短链 $\mathrm { \check { P } F A A s } ^ { 3 6 }$ 相关研究结果的支持，并与 [[Zhang]] 等 $\mathrm { a l . , } ^ { 5 6 }$ 的结果一致，他们在[[小麦]]实验中未观察到 TFA 浓度达到稳态。

对于农业及其他生态系统中的 [[三氟乙酸|TFA]] 暴露，现有评估尚未达到对其他较长链 $\mathrm { P F A A s ; } ^ { 5 7 - 6 2 }$ 的评估程度；然而，随着全球排放量的增加，人类（[[血清]]）、动物和植物中的平均 TFA 浓度将不可避免地升高。TFA 降解仅有的潜在环境相关途径是对流层中的泛频光解离，以及将 TFA 转化为[[三氟甲烷|氟仿]]的生物催化转化过程 $( \mathrm { C F } _ { 3 } \mathrm { H } ) . ^ { 6 3 }$ 就 TFA 的质量损失而言，这些过程的作用可能微乎其微，因为 TFA 在迅速扩散到陆地水圈之前，很容易通过湿沉降（以及程度较低的干沉降）从大气中清除。<sup>12,48,64</sup>然而，考虑到 TFA 的高浓度，即使只有少量 TFA 转化为氟仿，也可能对大气中的氟仿浓度产生可观测的影响。<sup>63</sup>由于 TFA 的[[化学持久性|持久性]]和[[环境迁移性|迁移性]]，从水中去除 TFA 的方法成本高昂，且往往效率低下。<sup>53,65−67</sup>在某些情况下，[[臭氧]]化和氯化等常见的水净化方法也会成为 TFA 的来源，这取决于是否存在 [[化学品前体物|TFA 前体物]]。<sup>53</sup>最有效的解决方案是先通过反渗透（RO）浓缩 TFA，再采用某些高强度破坏技术。然而，与其他水处理方式相比，采用 RO 处理水，尤其是[[废水]]，成本高昂，<sup>68,69</sup>需要消耗大量能源，<sup>70</sup>且通常会造成 50% 的水量损失。<sup>71</sup>水处理必须采用 RO 这一点也与[[欧盟]]《水框架指令》第 7(3) 条相矛盾，该条规定：“成员国应确保对已确定的水体实施必要保护，以避免其水质恶化，从而降低[[饮用水]]生产所需的净化处理程度”。<sup>72</sup>针对浓缩 TFA 的破坏技术，例如焚烧 RO 浓缩液，甚至焚烧含 TFA 的生物质，都可能产生有害副产物，包括氟仿（一种强效温室气体，其 100 年尺度的 GWP 为 $\mathrm { C O } _ { 2 }$ 的 14,800 倍）。<sup>63,73</sup>

我们在上文提到，[[三氟乙酸|TFA]] 浓度升高的一个来源是用作[[制冷剂]]的[[含氟气体]]（F-gases）使用量增加；这一点值得更详细地探讨。制冷剂化学品在历史上一直存在问题。[[氯氟烃|CFCs]] 最初作为氨、[[二氧化硫]]和[[氯甲烷]]的“更安全”替代制冷剂而引入，直到后来人们发现，CFCs 的挥发性足以使其到达平流层，并释放 [[氯自由基|Cl 自由基]]，导致平流层[[臭氧]]分解，尤其是在[[南极洲]]上空。<sup>74−76</sup> 因此，CFCs 构成了与严重影响相关的[[行星边界]]威胁。<sup>77</sup> 为保护臭氧层免受难以逆转的消耗，《[[蒙特利尔议定书]]》<sup>78</sup> 要求将制冷和空调系统中使用的 CFCs 替换为 [[氢氯氟烃|HCFCs]] 和 [[氢氟烃|HFCs]]<sup>79</sup> 或[[天然制冷剂]]。[[氢氯氟碳化物|HCFCs]] 的臭氧消耗潜势低于 CFCs，而 HFCs 不具有臭氧消耗潜势；然而，HFCs 具有较高的[[全球变暖潜势]]（GWP）。<sup>79</sup> 《蒙特利尔议定书》的后续修正案和欧洲含氟气体法规旨在以低 GWP 替代品取代高 GWP 含氟气体。<sup>80</sup> 然而，拟议的替代物质——[[氢氟烯烃]]（HFOs），甚至目前正在使用的 HFCs——又加剧了这一问题，因为许多 HFOs 和 HFCs 可部分（例如 [[HFC-134a]]、[[HFC-143a]]、[[HFO-1234ze|HFC 1234ze]]、[[HCFO-1233zd]]）或完全（例如 [[HFC-227ea]]、[[HFO-1225ye(E)]]、[[HFO-1225ye(Z)]]、[[HCFO-1224yd(Z)|u-HCFC-1224yd(Z)]] 和 [[2,3,3,3-四氟丙烯|HFO-1234yf]]）转化为 TFA。<sup>81,82</sup> 据估计，仅在[[欧盟]]，2020 年 [[HFO-1234yf]] 的使用就造成了 6900 t/年的 TFA 排放，到 2050 年，排放量可能增至 47,650 t/年。<sup>81</sup> 含氟气体的这种替换可能导致未来几年 TFA 排放量增加数个数量级，<sup>81</sup> 同时，由于对流层中的 TFA 会生成更多[[三氟甲烷]]，也会相应加剧气候影响。<sup>63</sup>

[[三氟乙酸|TFA]] 的另一个主要来源是工业生产和工艺过程中的直接排放。例如，TFA 已根据[[欧盟]]关于化学品注册、评估、授权和限制的第 1907/2006 号法规（[[欧盟化学品注册、评估、授权和限制法规|REACH]]）进行注册，其在欧盟境内的制造量和/或进口至欧盟的数量为每年 100 至 1000 吨。<sup>52</sup> 此外，TFA 还用作中间体，但这种用途不要求登记生产量。[[Xie]] 等人测定了中国济南附近三家氟化工厂周边环境（[[地表水]]、[[地下水]]、空气、[[灰尘]]、[[土壤]]）中的 TFA，这些工厂生产无机氟产品、TFA 和[[含氟中间体]]。83 Xie 等人报告的地表水浓度最高达到 $2 . 6 \ \dot { \mu } \mathrm { g / L } , ^ { 8 3 }$，而近期有报道称，在法国南部一家生产 TFA 及相关 [[全氟和多氟烷基物质|PFAS]] 的工厂附近，Arias 河地表水中的浓度高达 7500 μg/L。<sup>84,85</sup>

除[[含氟气体]]和 [[三氟乙酸|TFA]] 的直接生产外，<sup>83−85</sup>还有其他多种[[前体物]]会导致 TFA 在环境中累积，包括含有 C−CF 结构单元的多类化学品，例如[[农用化学品]]、<sup>53,86−88</sup>[[药物|药品]]、<sup>53</sup>（含氟）聚合物<sup>89−91</sup>以及其他 [[全氟和多氟烷基物质|PFAS]]。<sup>13,53,92</sup>TFA 及其[[化学品前体物|前体物]]可由点源排放，例如（氟）化学工业、<sup>5,53</sup>污水处理厂、填埋场<sup>4,93,94</sup>以及曾使用[[水成膜泡沫]]（AFFFs）的场地。<sup>93,95</sup>德国环境署（[[德国联邦环境署|Umweltbundesamt]]，UBA）公布了对德国境内各来源 TFA 排放量的估算。<sup>96</sup>现有数据表明，[[制冷剂]]和[[发泡剂]]是德国最大的可量化 TFA 来源，排放量约为 2000 t/年，其次是[[农药]]，约为 457 t/年（主要为[[氟噻草胺]]、[[吡氟酰草胺]]和[[氟啶胺]]），以及[[人用药品]]，约为 29 t/年。该研究未能量化其他来源的排放，例如 TFA 的直接生产、[[杀生物剂]]、[[兽用药品]]以及产品中的含氟化学品。<sup>96</sup>曾有关于 TFA 天然来源的推测，但 Joudan 等人<sup>97</sup>的研究否定了这些推测；他们证明，只有不断增加的 TFA 人为来源才能解释近几十年来其含量的指数增长。自 20 世纪 90 年代以来就已被认识到、且正受到越来越多关注的一类 TFA 来源，是[[含氟聚合物]]热销毁产生的转化产物，<sup>98</sup>以及采用销毁方法处理 PFAS 时产生的转化产物。<sup>53,99,100</sup>各种 PFAS 销毁方法的 TFA 生成产率往往未知，因此在开发新的 PFAS 销毁方法时，应对此开展研究。<sup>16</sup>Nödler 和 Scheurer 将 TFA 称为“多来源物质”，<sup>101</sup>凸显了在水资源监测研究中确定 14,19 TFA 主要来源的困难。

## ■ 对人类健康和[[地球系统过程]]的扰乱性影响

[[三氟乙酸|TFA]] 可能对人类健康或[[地球系统过程]]产生目前尚不为人知的扰乱性影响，正如较[[长链全氟烷基酸|长链 PFAAs]] 对人类健康的影响以及 [[氯氟烃|CFCs]] 对[[臭氧]]层的影响，最初也不为更广泛的科学界和监管界所知。要认识到某种在全球范围内浓度不可逆地上升的[[新型实体]]可能构成[[行星边界]]威胁，克服这种认知缺失是最困难的环节。<sup>25</sup>既有的危害与[[风险评估]]范式无法充分描述或预见此类影响。然而，由于这些范式通常用于界定化学品在人类健康和[[生态系统健康]]方面的[[监管阈值]]，我们将以此为起点，分析 TFA 在行星尺度上造成扰乱性影响的可能性。

已知的健康与环境阈值。[[Dekant]] 和 Dekant<sup>17</sup> 在近期的一篇综述中总结了 [[三氟乙酸|TFA]] 对哺乳动物的[[毒性]]，并特别论及其对人类的毒性。[[人类健康风险评估]]所依据的多数[[毒性试验]]均为大鼠研究，其中一项为期 90 天的[[饲喂研究]]发现，每日剂量 > 1000 mg/kg 时，主要效应为轻度[[肝脏肥大]]（肝脏体积增大）。今后应开展更多与人类相关性更高的试验，以理解其[[毒性作用机制|作用机制]]，而不仅仅是满足监管对整体[[毒性终点]]的要求。目前，根据德国向[[欧洲化学品管理局]]（ECHA）提交的有关兔[[胚胎－胎仔发育毒性]]的新证据，已有意依据[[欧盟物质和混合物分类、标签和包装法规|欧盟关于物质和混合物分类、标签和包装（CLP）的第 1272/2008 号法规]]，将 TFA 及其盐类归入第 1B 类：推定的人类[[生殖毒物]]。<sup>52,102,103</sup> 如果 TFA 被归类为具有[[生殖毒性]]，可能会影响未来食品和[[饮用水]]中的阈值。2020 年，德国基于一项大鼠[[慢性毒性]]（饲喂）研究，将饮用水中 TFA 的[[健康指导值|人类健康指导值]]设定为 60 μg/L，但强调饮用水中的浓度应保持在合理可行的尽可能低的水平，并应以 10 μg/L 为目标值。<sup>104</sup> 2023 年，荷兰根据 TFA 相对于[[全氟辛酸]]（PFOA）的[[相对效力因子|效力因子]]及 PFOA 的[[饮用水限值|饮用水阈值]]，推导出 TFA 的指示性饮用水限值为 2.2 μg/L。<sup>105</sup> 考虑到近期测得德国[[饮用水水源]]中 TFA 的平均浓度和最高浓度分别为 0.9 和 12.4 μg/L，<sup>2</sup> 许多地区的饮用水浓度很可能已经超过或将在不久的将来超过 2.2 μg/L 的阈值。

根据[[欧盟物质和混合物分类、标签和包装法规|欧盟 CLP 法规]]，[[三氟乙酸|TFA]] 被归类为[[H412危害说明|对水生生物有害并具有长期持续影响]]（H412）。<sup>106</sup> 根据 [[欧盟化学品注册、评估、授权和限制法规|REACH]]，仅针对[[经口暴露|经口暴露途径]]推导了一般人群的[[毒理学]]阈值（[[衍生无效应水平]]，DNEL），并将其设定为 0.042 mg/kg/天；对于其他[[暴露途径]]，则假定不存在危害，并据此作出结论。经口暴露途径的阈值是根据一项为期 90 天的大鼠[[饲喂研究]]中观察到的效应推导得出的。<sup>52</sup> 对 TFA 的[[毒代动力学|人体毒代动力学]]评估表明，其经口摄入后可迅速吸收，进入[[肠肝循环]]，并通过血液分布至全身，包括穿过[[胎盘屏障]]。其主要[[排泄途径]]被认为是经尿液和胆汁排泄。<sup>52</sup> 尽管根据针对[[水生生物]]的监管标准，TFA 不具有[[生物蓄积|生物蓄积性]]，<sup>52</sup> 但由于其在[[饮用水]]、[[植物性食品]]和饮料等[[暴露介质]]中持续积累，体内浓度可能升高。

与最新的[[人体毒理学]]综述 17 不同，目前尚无类似的近期综述汇总[[生态毒性|（生态）毒性]]数据。我们检索了 [[ECOTOX数据库|USEPA ECOTOX 数据库]]<sup>107</sup>和 [[ECHA注册档案|ECHA 注册档案]]<sup>52</sup>，发现大多数测定 [[三氟乙酸|TFA]]（生态）[[毒性]]的研究工作开展于 20 世纪 90 年代。[[藻类]]被认为是最敏感的[[营养级]]，其中 [[莱茵衣藻属近头状藻|S. capricornutum]] 是最敏感的物种，测得的最低[[无可观察效应浓度]]（No-Observed Effect Concentration，NOEC）为 120 μg/L，该值针对 [[三氟乙酸钠|TFA 钠盐]]测定（[[Solvay]] 数据，提取自 ECOTOX 数据库中 TFA/NaTFA 的数据，并由 [[Berends]] 等人报告<sup>8,107</sup>）。其他生物的部分[[生态毒性终点]]（急性和慢性）列于补充信息表 S2，其中列出了[[生态毒理学阈值]]及其缩写。总体而言，大多数试验针对[[急性毒性]]，仅有少数研究考察了 TFA 的[[慢性毒性]]。

[[预测无效应浓度]]（predicted no-effect concentrations，PNECs）是[[环境风险评估]]中通常推导的浓度阈值，应能保护整个生态系统。这些阈值以[[生态毒性]]数据为基础，并采用根据数据丰富程度、试验持续时间（急性/慢性）以及数据质量/不确定性确定的[[外推因子]]。<sup>108</sup>对于 [[三氟乙酸|TFA]]，[[Xie]] 等人<sup>83</sup>推导出的最低 PNEC 为 0.12 μg/L，其依据是此前被证明为最敏感[[营养级]]的[[藻类]]。该 0.12 μg/L 的 PNEC 由 120 μg/L 的 [[无可观察效应浓度|NOEC]] 采用 1000 的[[不确定性因子]]推导而来，选择这一因子是因为[[同行评议]]文献中的（生态）[[毒性]]数据匮乏，且向[[海洋环境]]外推需要额外的预防性考量（通常比[[淡水环境]]多采用一个 10 倍因子）。[[ECHA注册档案|ECHA REACH 档案]]报告的淡水 PNEC 为 560 μg/L，[[海水]] PNEC 为 56 μg/L，两者均基于一项藻类研究，该研究报告的 72 h [[生长速率抑制浓度ErC10|ErC10]]（基于生长速率的 [[百分之十效应浓度|EC10]]）为 5600 μg/L。<sup>52</sup>同行评议研究中报告的 2010 年后[[地表水]]浓度，其中位数和/或平均值几乎全部已超过 Xie 等人<sup>83</sup>推导的预防性 PNEC 0.12 μg/L（表 S1，图 S2），而近期检出的部分淡水/地表水最高浓度值已超过 120 μg/L 的 NOEC 和 [[欧洲化学品管理局|ECHA]] 的 560 μg/L 的 PNEC。84,85

在[[陆生生物]]中（[[生态毒性]]研究），[[ECHA注册档案|REACH 档案]]仅对[[农作物]]进行了 [[三氟乙酸|TFA]] [[毒性试验]]。[[半数效应浓度|EC50]] 为 4.7 mg/kg [[土壤干重]]，长期 [[无可观察效应浓度|NOEC]] 为 0.83 mg/kg [[土壤]]干重。受影响的主要是植物地上部的生长。<sup>52</sup>由于具有足够高植物体内浓度的[[植物毒性]]研究稀缺，且需要纳入农作物以外的其他[[维管植物]]，因此有必要进一步开展 TFA 植物[[毒性]]试验。<sup>13</sup>然而，在农作物中测得的长期 NOEC<sup>52</sup>已与土壤 TFA [[环境背景浓度|背景浓度]]相近，并且比[[污染热点|污染热点地区]]的土壤 TFA 浓度低数个数量级（图 1，图 S4）。<sup>5,39</sup>

鉴于 [[三氟乙酸|TFA]] 的[[化学持久性|持久性]]，应将所有物种的 TFA 暴露视为慢性且终生的。然而，慢性研究仍相对匮乏，标准化试验中的慢性数据在暴露时间上受到限制，例如鱼类为 35 天、[[溞属|Daphnia]] 为 21 天、大鼠为 90 天，或

[[农作物|作物]]中的研究持续时间为36天<sup>52</sup>（表 S2，SI），这些研究不足以外推[[终生暴露]]于 [[三氟乙酸|TFA]] 可能造成的影响。因此，目前尚无研究考察实际的[[长期暴露|长期 TFA 暴露]]，而鉴于 TFA 在较长时间尺度上普遍存在且不断增加，长期暴露研究更具相关性。

与上述分析相反，其他作者<sup>109,110</sup>最近得出结论，认为 [[三氟乙酸|TFA]] 对人类和环境的风险微乎其微（即可忽略不计），其依据包括：预计到2100年，海洋中 TFA 的浓度为0.2 μg/L，而[[藻类]] [[莱茵衣藻属近头状藻|R. subcapitata]] 的[[无可观察效应浓度]]（NOEC）为2500 $\mu \mathbf { g } / \mathrm { L } , ^ { 1 0 9 , 1 1 0 }$；以及[[南开大学]]工作人员[[血清]]中 TFA 水平的中位数为8.46 μg/L，比大鼠的[[效应剂量]]低4个数量级。然而，我们并不认同这些数据足以得出风险可忽略不计的结论，因为这一结论忽略了陆地环境，在缺乏其他物种长期[[慢性暴露]]数据的情况下，仍假定已知最低的实测环境效应水平，而且未在膳食中 TFA 浓度不断增加的背景下考虑多种[[人体暴露]]途径及潜在的未知不良影响，例如对[[胚胎发育]]的影响。鉴于 TFA 的[[化学持久性|持久性]]和累积性，还可能存在当前科学尚未认识到的其他环境和健康影响。

未知的环境和健康影响。随着 [[三氟乙酸|TFA]] 在多种生态系统中累积，研究人员应关注影响[[生物地球化学过程]]的非传统暴露与影响途径。尽管[[植物吸收|植物对 TFA 的吸收]]量极高，但针对 TFA 开展并报告的[[受控吸收实验]]却很少。[[Zhang]] 等人<sup>56</sup>针对 TFA 及其他超短链和短链 [[全氟羧酸|PFCAs]] 开展了一组[[水培实验]]。在这些实验中，与其他 PFCAs 相比，根系对 TFA 的吸收极高，例如，TFA 的[[根系浓缩因子]] >1600 $\mathrm { L } / \mathrm { k g } , ^ { 5 6 ^ { - } } 2$，比类似实验中通常测得的含3−5个全氟化碳原子的 PFCAs 的根系浓缩因子高出数个数量级。<sup>111−113</sup> [[Chen]] 等人<sup>5</sup>在不同 PFCAs 的[[链长依赖性]]与基于实地测定的[[土壤-水分配系数]]（K ）之间发现了类似的模式。他们测得的 TFA（以及 [[全氟丙酸|PFPrA]]）的 $K _ { \mathrm { d } }$ 值高于预期，这与通常观察到的趋势相反，即对于 PFCAs 和 [[全氟烷基磺酸|PFSAs]]，随着[[全氟烷基链]]长从11个全氟化碳原子缩短至3个，$K _ { \mathrm { d } }$ 随之降低。<sup>114−117</sup> 这表明，需要进一步研究 TFA 的[[界面分配]]及其与[[土壤]]和植物的相互作用，并在评估其[[环境归趋]]和行为特性，尤其是其（生物）累积潜力时，将这些因素纳入考量。此类研究需要扩展至[[农业系统]]，例如，从含有较高水平 TFA 的[[农作物|作物]]向牲畜（肉和奶）及人类膳食的转移，以及 TFA 从植物经由多种[[食物网]]的转移，类似于此前针对其他 [[全氟和多氟烷基物质|PFAS]] 开展的研究。<sup>58−61</sup>

[[三氟乙酸|TFA]] 对[[土壤质量]]的直接影响直到最近才得到研究。<sup>118</sup> 已有研究报告了其对[[土壤pH|土壤 pH]]、[[微生物呼吸]]、[[细菌丰度]]和[[凋落物分解]]的影响，其中，凋落物分解在与 [[Chen]] 等人<sup>5</sup>所述[[污染热点|污染热点地区]][[土壤]]中当前 TFA 浓度相近的浓度（0.0013−2.4 mg/kg）下就受到影响。除凋落物分解外，其他影响仅在高 TFA 浓度（≥10 mg/kg）下具有[[统计学显著性]]，这可能源于[[酸度]]相关效应，因为在 10 mg/kg 及更高浓度下，pH 显著下降（试验中直接使用了酸形式的 TFA）。<sup>118</sup> [[Bott]] 和 [[Standley]] 在证明 TFA 可掺入涵盖多个[[营养级]]的[[水生生物]]体内[[蛋白质]]等[[生物分子]]之后，<sup>11</sup>又观察到淡水表层[[沉积物]]中的微生物群落将 TFA 掺入细胞的现象。119 这些持续约 1.5 至 2.5 年的实验所使用的浓度范围为 2.2 至 43 μg/L，与目前在全球水体中观测到的浓度范围重叠（表 S1、图 S2，SI），并导致 TFA 显著掺入细胞。<sup>119</sup> 另有研究指出，在浓度升高时，大气中存在的 TFA 可能影响气溶胶和云的形成，促进参与新气溶胶粒子形成的大气团簇的生成。<sup>120,121</sup> 由于未来十年 TFA 浓度可能至少增加一个数量级，因此有必要进一步研究 TFA 对[[生物地球化学过程]]的影响。

## ■ 环境意义

基于上述证据，[[三氟乙酸|TFA]] 的持续累积可被认为符合 Persson 等人所定义的[[新型实体]]构成[[行星边界]]威胁的三个条件：<sup>122,123</sup><sup>25</sup>“条件 1（C1）——污染对某一至关重要的[[地球系统过程]]产生了我们尚不知晓的扰乱效应；条件 2（C2）——直到相关影响已经或不可避免地将在全球尺度上显现时，这种扰乱效应才被发现；以及条件 3（C3）——由于全球环境中的污染水平无法轻易降低，这些影响难以逆转……”条件 1（C1）之所以得到满足，是因为许多我们尚不知晓的阈值可能被超过；其中包括[[地表水]]浓度<sup>84,85</sup>超过<sup>83</sup> [[欧洲化学品管理局|ECHA]] 规定的 560 μg/L 的 [[预测无效应浓度|PNEC]]；[[土壤]]浓度超过已确定的最低 [[无可观察效应浓度|NOEC]]（0.83 mg/kg 土壤）；<sup>52</sup>以及表明其对人体具有[[毒性]]的迹象，这些迹象已促使[[饮用水]]预防性阈值的制定。<sup>104</sup>在此前的一项研究中，此类[[健康指导值]]和监管限值的存在已被用作判定四种 [[全氟烷基酸|PFAA]] 满足 C1 的依据。<sup>27</sup>其他长期扰乱效应可能已经发生，只是我们尚不知晓，这进一步支持 C1 已得到满足的判断，尤其是考虑到目前缺乏对[[农业系统]]及多样化[[食物网]]中 TFA 暴露的研究。条件 2（C2）得到满足，是因为 TFA 已存在于全球所有[[环境介质]]中，例如其在[[维管植物]]中的持续[[生物累积]]、在北极地区的累积、在[[地下水]]中的普遍存在，以及作为 TFA 热点且最有可能产生影响的工业场所在全球各地的分布；因此，当这些影响被发现时，它们将是全球性的。由于这些效应在全球范围内显现，且在可预见的未来将不可逆转，TFA 的[[环境持久性|极端持久性]]和[[环境迁移性|迁移性]]，加之多个来源的排放，使条件 3（C3）得到满足。

尽管目前针对 [[三氟乙酸|TFA]] 的[[健康指导值]]或监管限值尚不如其他 [[全氟烷基酸|PFAA]] 那样完善，<sup>27</sup>但随着更多关于 TFA 影响的研究问世，未来几年很可能会出台新的指导值或限值。鉴于预计环境中、<sup>81</sup>食物中及人体内的 TFA 浓度将呈指数增长，问题不在于 TFA 是否会超越[[行星边界]]，而在于哪些不可逆的健康或地球系统影响将首先在行星尺度上被观测到，以及应将 TFA 排放阈值设定在何种水平，以限制此类影响的严重程度。

人为来源的 [[三氟乙酸|TFA]] 排放迅速增加，其可能带来的长期、不可逆影响应成为立即开始讨论政策、产业和创新行动的理由，以逐步淘汰那些导致 TFA 积累不断增加的大宗物质。显而易见的切入点是限制 TFA 的直接生产，更重要的是限制 TFA 前体的生产，例如 [[氢氟烯烃|HFOs]]（如 [[2,3,3,3-四氟丙烯|HFO-1234yf]]）以及[[氟噻草胺]]等[[农药]]。<sup>13,53,96</sup> 对于其他通过转化过程释放 TFA 的[[药物|药品]]、兽药产品和[[工业化学品]]，<sup>7</sup> 也应考虑逐步淘汰或替代，并遵循安全与可持续设计<sup>124</sup>和必要用途<sup>125</sup>原则，避免以危害更大的物质进行令人遗憾的替代。<sup>126</sup> 由于围绕逐步淘汰 TFA 来源的讨论及政策机制的建立可能需要一定时间，面对 TFA 积累造成的全球威胁，理性的应对方式是在不可逆影响于全球范围内显现并波及人类和环境之前迅速采取行动。逐步摆脱 TFA 及其前体，是保护子孙后代免受这一[[行星边界]]威胁的最有效方式。
