## 摘要

[[全氟和多氟烷基物质]]（PFAS）是全球[[水生环境]]中普遍存在的污染物。其结构多样性与复杂化学性质对基于[[吸附]]的修复技术构成了重大挑战。[[传统吸附剂]]通常依赖单一的主导相互作用机制，往往无法有效捕获[[水成膜泡沫]]（AFFF）基质中存在的广泛 PFAS 种类。本研究整合实验与计算方法，探究[[主客体包合]]、疏水、亲氟和[[静电相互作用]]在 PFAS 吸附中的协同作用。所考察的吸附剂是基于环糊精的聚合物，并通过不同比例的氟化、胺基和季铵[[官能团]]进行工程化改造，以促进这些相互作用。在测试材料中，氟化且经季铵改性的阳离子吸附剂在吸附短链阴离子 PFAS 方面表现出更优的性能。我们直接用该吸附剂处理了稀释的 AFFF 样品，其中含有 95 种已鉴定的不同 PFAS，总浓度最高达 1.3 mg⋅L<sup>−</sup> <sup>1</sup>，包括 55 种阴离子型、33 种两性离子型和 7 种非离子型 PFAS——这使该体系成为迄今在新型吸附剂研究背景下最为复杂且极具环境相关性的 PFAS 基质之一。据我们所知，其中 48 种 PFAS 在先前研究中未曾被纳入。我们的吸附剂在这些苛刻条件下表现出优异性能，实现了 96.6 % 的总 PFAS 质量去除率。其中包括对两性离子型 PFAS 的 88.5 % 去除率，而这些两性离子型 PFAS 占总 PFAS 质量的 24.3 %。这些两性离子型 PFAS 是更具迁移性 PFAS 的长期来源，在修复受 AFFF 影响的环境水体方面具有特别重要的环境意义。上述发现凸显了疏水、亲氟和静电相互作用在提升吸附剂性能中的关键作用。尽管环糊精的主客体化学并非主导吸附机制，但它有助于稳定 PFAS 的取向并提高总体吸附量。本研究为合理设计面向复杂水环境中高效 PFAS 修复的下一代吸附剂技术提供了有价值的见解和理论基础。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是一类合成氟化化学品，因其优异的热稳定性和化学稳定性而广泛用于各种工业和消费品中（Chen et al., 2021; Giesy and Kannan, 2001; Prevedouros et al., 2006）。PFAS 通常被称为“永久化学品”，具有强碳氟键，使其对环境降解具有高度抗性（Brendel et al., 2018; Cousins et al., 2016; Kwiatkowski et al., 2020）。其广泛使用和持久性导致其在地表水、土壤、沉积物和[[地下水]]中普遍存在（Buck et al., 2011; Giesy and Kannan, 2001; Zareitalabad et al., 2013）。PFAS 表现出高迁移性、两亲性和生物累积潜力，对人类健康和环境构成重大风险（Ahrens, 2011; Buck et al., 2011; Lyu et al., 2022; Rahman, Peldszus and Anderson, 2014）。为此，[[美国环境保护署]]（U.S. EPA）已对饮用水中的传统 PFAS（如[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS））制定了具有法律强制执行力的限值，浓度为 4 ng⋅L<sup>−</sup> <sup>1</sup>（U.S EPA, 2023）。从饮用水中去除 PFAS 最具成本效益和可扩展性的技术包括[[颗粒活性炭]]（GAC）[[吸附]]和[[离子交换树脂]]（IXs），二者分别主要依靠[[疏水相互作用|疏水作用]]和[[静电相互作用]]（Appleman et al. 2014; Carter and Farrell, 2010; Rahman, Peldszus and Anderson, 2014; Yu et al., 2009b）。这些方法已被证明对 PFOA 和 PFOS 等传统 PFAS 有效（Carter and Farrell, 2010; Du et al., 2014; McCleaf et al., 2017; Yu et al., 2009a）。然而，PFAS 因工业应用多样而产生的化学多样性，对传统处理技术构成了重大挑战（Banks et al., 2020; Buck et al., 2011; Du et al., 2014; Kucharzyk et al., 2017; Rahman Peldszus and Anderson, 2014; Ross et al., 2018）。[[水成膜泡沫]]（AFFF）是水环境介质中 PFAS 污染的主要来源，含有数千种 PFAS，其链长（通常为 4–14 个全氟化碳）、分子结构（直链或支链）、电荷状态（阴离子、阳离子、两性离子和中性）以及[[官能团]]各不相同（Barzen-Hanson et al., 2017a; Houtz and Sedlak, 2012; Place and Field, 2012）。这种复杂性限制了 GAC 和 IXs 等[[传统吸附剂]]的有效性，因为它们通常仅通过单一主导去除机制发挥作用（Carter and Farrell, 2010; Deng et al., 2011; Park et al., 2020; Yu et al., 2009a）。例如，GAC 在去除[[短链 PFAS]] 方面表现不佳，因为短链 PFAS 的疏水性较低（Appleman et al., 2014; Rahman, Peldszus and Anderson, 2014; Yu et al., 2012, 2009a）。因此，迫切需要开发新型吸附剂，使其能够对不同 PFAS 化学结构具有广泛选择性、快速[[吸附动力学]]、可扩展性、易于再生，并能抵抗[[天然有机物]]（[[天然有机质|NOM]]）等竞争物质的污染（Appleman et al., 2014; Deng et al., 2010; Ross et al., 2018; Yu et al., 2009b）。

两亲性 [[全氟和多氟烷基物质|PFAS]] 在[[吸附]]剂上的吸附涉及多种分子间相互作用（Buck et al., 2011; Higgins and Luthy, 2006; Prevedouros et al., 2005）。除了已充分确立的与氟化烷基尾部之间的[[疏水相互作用]]以及与阴离子头基之间的[[静电相互作用]]外，[[亲氟相互作用]]（Fu et al., 2024; Janji´c et al., 2020; Lobitz et al., 2025; Rahman, Peldszus and Anderson, 2014）（即氟–氟或 F–F 相互作用）代表了一种 PFAS 特有且至关重要的机制。这种非共价、具有方向性且作用距离较短的相互作用，指的是氟化分子或基团倾向于优先彼此缔合，而非与非氟化环境缔合（Arkhipov et al., 2019; Barcelo-Oliver ´ et al., 2010; Chen et al., 2015; Fu et al., 2024; He et al., 2024; Janji´c et al., 2020; Matta, 2005）。作为疏水作用力的一个专门子类，亲氟相互作用源于氟的低极化率和高电负性（Ehn ´ and Cernuˇ ˇsak, ´ 2021; Panini and Chopra, 2015; Reichenbacher, ¨ Süss and Hulliger, 2005; Varadwaj et al., 2018）。由于 PFAS 尾部具有较高的氟密度，亲氟相互作用能够实现特异性的分子吸引（Buck et al., 2011; Rocha et al., 2021; Wang et al., 2017）。尽管亲氟相互作用可能强于一般的疏水相互作用，但仅靠亲氟相互作用并不足以在[[环境相关浓度]]下有效捕集 PFAS，尤其是在复杂的[[水成膜泡沫]]（AFFF）基质中（Fu et al., 2024）。因此，在吸附剂设计中协同整合疏水、亲氟和静电功能对于最大化[[吸附容量]]、选择性和[[吸附动力学|动力学]]性能以实现高效 PFAS 去除至关重要（Fu et al., 2024; He et al., 2024; Saha, Khan and Van Bramer, 2021; Wang et al., 2017）。

基于这些原则，已开发出若干新型聚合物[[吸附]]剂，包括[[含氟聚合物]]（Fu et al., 2024; Liu et al., 2025; Pezoulas et al., 2025）、[[离子型氟化水凝胶]]（Kumarasamy et al., 2020; Manning et al., 2022）以及[[大环多孔材料|基于大环的多孔材料]]（Klemes et al., 2019; Li et al., 2018; Liao and Zhang, 2019）。其中，基于[[β-环糊精]]（β-CD）的聚合物吸附剂在去除[[全氟和多氟烷基物质|PFAS]]方面表现出卓越的前景（Ching et al., 2020; Klemes et al., 2019; Lin et al., 2024; Wang et al., 2020; Xiao et al., 2019, 2017）。本研究聚焦于通过平衡疏水、亲氟和[[静电相互作用]]，对β-CD基聚合物进行[[理性设计]]与改性，以提高从实际[[水成膜泡沫|AFFF]]污染水样中去除短链及多种PFAS的能力。以[[β-CD-DFB]]（[[十氟联苯]]）聚合物（Xiao et al., 2017）为起点，该聚合物具有高度氟化特性但应用有限，我们合成了两种新衍生物：[[β-CD-DFB聚合物|-CD-DFB-NH]]和-CD-DFB-NH-N，分别引入[[乙二胺]]和[[缩水甘油基三甲基氯化铵]]（[[GTMAC]]）（图1）。为证实[[亲氟相互作用]]的关键作用，我们还合成了一种非氟化对照聚合物（[[β-CD-DHB]]）。为阐明疏水、亲氟和静电相互作用在螯合长链和[[短链PFAS]]（定义为氟碳链n ≥ 6为长链，$3 \leq n \leq 5$为短链PFAS）中的单独及协同贡献，我们采用[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）和[[分子动力学]]（[[分子动力学模拟|MD]]）模拟。这些计算工具提供了对PFAS行为的原子级认识，并为指导吸附剂设计提供了稳健框架。尽管具有潜力，由于聚合物吸附体系的复杂性，此类建模工作仍较为有限。先前的计算研究主要集中于较简单的β-CD聚合物和[[长链PFAS]]（Choudhary et al., 2022）。在本团队前期工作基础上，本研究将建模范围扩展至分析包括[[氢键]]、色散、空间位阻、静电、疏水性和亲氟性在内的多种相互作用（Patyal and Howe, 2025）。我们的分析考虑了β-CD空腔、[[官能团]]和聚合物[[交联剂]]的贡献，为开发用于PFAS修复的下一代吸附剂提供了全面的理论基础。

## 2.2. [[吸附]]实验

批量[[吸附动力学]]实验在100 mL玻璃小瓶中进行，温度为24±1 °C，持续以400 rpm搅拌。将含有9种[[全氟和多氟烷基物质|PFAS]]的储备液（每种600 $\mu \ g { \cdot } \mathrm { L } ^ { - 1 }$）稀释至每种化合物$2 ~ { \mu \mathrm { g } } { \cdot } \mathrm { L } ^ { - 1 }$。对于稀释[[水成膜泡沫|AFFF]][[吸附]]实验，储备液在使用前稀释6,666.67倍。吸附剂投加量为$2 0 \ \mathrm { m g \cdot L ^ { - 1 } }$，包括[[活性炭|粉末活性炭]]（[[粉末活性炭|PAC]]）和[[离子交换树脂]]（IXs）作为对比。用于吸附实验的合成吸附剂粒径筛选在20–45 μm范围内。在预定时间间隔（例如1 h、6 h、12 h和24 h），采集样品并立即通过0.45 μm[[醋酸纤维素滤膜]]过滤，转移至15 mL[[聚丙烯管]]中进行分析。对照实验在不加吸附剂的条件下按相同步骤进行。所有实验均重复三次。时间t时的去除效率和[[吸附容量]]按下式计算：

$$
\text { Removal   efficiency } (\%) = \frac {C _ {0} - C _ {t}}{C _ {0}} \times 1 0 0\tag{1}
$$

$$
q _ {t} = \frac {C _ {0} - C _ {t}}{C _ {A}}\tag{2}
$$

其中$C _ { O }$表示不存在[[吸附]]剂时的初始[[全氟和多氟烷基物质|PFAS]]浓度，$C _ { t } ( \mathsf { \mu g } { \cdot } \mathsf { L } ^ { - 1 } )$为时间$\mathrm { ; C _ { A } ( m g { \cdot } L ^ { - 1 } ) }$时的PFAS浓度，是吸附剂浓度，$q _ { t } ~ ( \mathbf { m } \mathbf { g } { \cdot } \mathbf { g } ^ { - 1 } )$为时间t时每克吸附剂吸附的PFAS量。

[[吸附等温线]]实验以传统[[全氟辛酸|PFOA]]为参照，在20 mL玻璃小瓶中于$2 4 { \pm } 1 \ ^ { \circ } \mathrm { C }$和400 rpm条件下进行。[[吸附]]剂投加量为$1 0 0 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$。PFOA初始浓度设定在1至160 $\mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$范围内。平衡24小时后，过滤上清液并进行分析。对照组平行进行。所有测试均重复三次。所有样品在分析前均进行稀释，使浓度处于仪器最佳检测范围$( 5 0 0 { - } 1 0 0 0 ~ \mathrm { n g { \cdot } L ^ { - 1 } } )$内。平衡数据采用[[Langmuir模型|Langmuir]]和[[Freundlich等温线模型]]拟合（[[Freundlich模型|Freundlich]]，1907；[[Langmuir等温线模型|Langmuir]]，1918）：

$$
q _ {e} = \frac {Q _ {m} K _ {L} C _ {e}}{1 + K _ {L} C _ {e}}\tag{3}
$$

$$
q _ {e} = K _ {F} C _ {e} ^ {1 / n}\tag{4}
$$

其中$q _ { e } ( \mathbf { m } \mathbf { g } { \cdot } \mathbf { g } ^ { - 1 } )$为平衡时[[吸附]]的[[全氟和多氟烷基物质|PFAS]]量，$C _ { e }$ $( \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 } )$为平衡PFAS浓度，$Q _ { m } ~ ( \mathrm { m g } { \cdot } \mathrm { g } ^ { - 1 } )$为最大[[吸附容量]]，$K _ { L } ( \mathrm { L } { \cdot } \mathrm { m g } ^ { - 1 } )$为[[Langmuir模型|Langmuir]]常数，$K _ { F }$和n分别为与吸附容量和吸附强度相关的[[Freundlich模型|Freundlich]]常数。

抗污实验在100 mL锥形瓶中进行，磁力搅拌条件为$2 4 { \pm } 1 ~ ^ { \circ } \mathrm { C }$和400 rpm。[[吸附]]剂投加量为20 $\mathbf { m g } { \cdot } \mathbf { L } ^ { - 1 } ,$，[[全氟和多氟烷基物质|PFAS]]储备液加标至每种化合物最终浓度$2 ~ \mu \mathbf { g } { \cdot } \mathbf { L } ^ { - 1 }$。加入[[腐殖酸]]$( 2 0 \ \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$，[[Sigma-Aldrich]]）以模拟[[天然有机物|天然有机质]]（[[天然有机质|NOM]]）。平衡24小时后，样品通过0.45 μm[[醋酸纤维素滤膜]]过滤并进行分析。对照实验在不加吸附剂的条件下进行。所有实验均重复三次。再生研究在100 mL锥形瓶中于$2 4 { \pm } 1 ~ ^ { \circ } \mathrm { C }$和400 rpm条件下进行。吸附剂投加量为40 $\mathrm { { m g } \cdot L ^ { - 1 } } ,$，初始[[全氟辛酸|PFOA]]浓度为$0 . 2 \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 } .$。吸附24小时后，样品在8000 rpm下离心12 min（[[Sorvall Lrgend X1R]]，[[ThermoFisher]]，Germany）。收集上清液用于分析。[[脱附]]通过将使用过的吸附剂在[[甲醇]]中浸泡24 h进行。再生后的吸附剂重新分散并用[[超纯水]]洗涤以供重复使用。上清液采用[[高效液相色谱-四极杆飞行时间质谱仪|HPLC-QToF-MS]]分析，以定量回收的PFOA。

## 2.3. [[全氟和多氟烷基物质|PFAS]]分析

[[全氟和多氟烷基物质|PFAS]] 浓度使用[[高效液相色谱-四极杆飞行时间质谱仪]]（HPLC-QToF-MS，[[Sciex X500R]]，Framingham，MA，USA）进行定量。样品用 LC-MS 级[[超纯水]]和[[甲醇]]稀释。对于靶向分析，将每个样品 900 μL 与 894 μL LC-MS 级甲醇混合，并加入 6 μL 内标（IS）甲醇混合溶液，使内标浓度达到 $2 0 0 \ \mathrm { n g { \cdot } L } ^ { - 1 } .$ 。最终样品组成为 50% 超纯水和 50% LC-MS 级甲醇。取每个制备好的样品或标准品 500 μL，注入 [[Phenomenex Gemini C18]] 色谱柱 $( 1 0 0 \times 3 \mathrm { { m m } } .$ 3 μm 粒径）。色谱分离采用由含 20 mM [[乙酸铵]]的 LC-MS 级超纯水和甲醇组成的流动相，流速为 $6 0 0 \mu \mathrm { L } { \cdot } \mathrm { m i n } ^ { - 1 }$

## 2.4. 电子结构计算

[[β-环糊精|β-CD]] 和所选 [[全氟和多氟烷基物质|PFAS]] 的初始分子结构取自 [[PubChem]] 数据库，并使用[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）进行优化，以确定其基态电子构型（Ramos 等，2013）。计算使用 [[维也纳从头计算模拟包|Vienna Ab Initio Simulation Package]]（VASP）完成（Kresse 和 Furthmüller，1996a；b；Kresse 和 Hafner，1994）。交换关联相互作用采用 Perdew、Burke 和 Ernzerhof 发展的[[广义梯度近似]]（GGA）泛函（[[Perdew-Burke-Ernzerhof泛函|PBE]]）描述（Perdew, Burke 和 Ernzerhof，1996）。[[色散相互作用]]通过 [[DFT-D3色散校正|DFT-D3]] 校正方案引入（Grimme, Ehrlich 和 Goerigk，2011）。计算使用平面波基组能量截断值 750 eV，[[布里渊区]]在 Γ 点采样。几何优化持续进行，直到连续电子自洽步骤之间的总能量差为 $< 1 0 ^ { - 7 } ~ \mathrm { e V }$，且离子间力为 $< 0 . 0 1 ~ \mathrm { e V } { \cdot } \mathring { \mathrm { A } } ^ { - 1 }$。这些收敛标准确保 DFT 计算的优化结构能量收敛至 $2 . 0 \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 }$ 以内。对于气相模拟，$\beta { \mathrm { - C D } }$ 和 β-CD–PFAS 复合物被置于边长 25 Å 的周期性立方晶胞中心。[[短链 PFAS]] 在 15 Å 晶胞中建模，[[全氟辛酸|长链 PFAS]] 在 20 Å 晶胞中建模，以确保足够的真空间距，从而最小化与周期性镜像的相互作用。每个 β-CD–PFAS 复合物的[[结合能]] $( E _ { B i n d i n g } )$ 按下式计算：

$$
E _ {\text { Binding }} = E _ {\beta - \mathrm{CD} + \mathrm{PFAS}} - E _ {\beta - \mathrm{CD}} - E _ {\mathrm{PFAS}}\tag{5}
$$

其中 $E _ { \beta - C D + P F A S }$ 为优化后包合复合物的总能量，$E _ { \beta \mathrm { - C D } }$ 为 $\beta { \mathrm { - C D } } .$ 的能量，E 为客体 [[全氟和多氟烷基物质|PFAS]] 分子的能量。所有优化结构均通过振动频率分析确认为局域极小值。五种[[吸附]] PFAS 的振动模式频率列于表 S2–S6。需要指出，对于某些结构，在基态附近可能存在多个竞争性局域极小值，我们不保证在结构优化中已找到全局极小值。[[分子中原子量子理论]]（[[量子理论原子分子分析|QTAIM]]）

分析使用电子结构计算生成的电子密度数据进行（Bader，1985；1991）。拓扑特征，包括电子密度 $( \rho ) ,$、电子密度拉普拉斯量（∇ $^ 2 \rho ) _ { ; }$）和局域电子能量密度 $( H _ { b c p } )$（后者进一步分解为动能密度 $( G _ { b c p } )$ 和势能密度 $( V _ { b c p } ) ,$），使用 [[CRITIC2]] 代码在[[键临界点]]（BCPs）处进行评估（Otero-de-la-Roza 等，2009；Otero-de-la-Roza, Johnson 和 Luana，˜ 2014）。

## 2.5. [[分子动力学模拟]]

使用大规模原子/分子大规模并行模拟器（LAMMPS）（Thompson et al., 2022）进行了全原子[[分子动力学]]（[[分子动力学模拟|MD]]）模拟，以研究SI文本S7中描述的四种基于[[β-环糊精|β-CD]]的聚合物膜对[[全氟和多氟烷基物质|PFAS]]的[[吸附]]：[[β-CD-DHB]]、[[β-CD-DFB]]、[[β-CD-DFB-NH]]和$\beta { \mathrm { - C D - D F B - N H - N ^ { + } } }$。膜模型同时涵盖了大环和[[交联剂]]相互作用，旨在模拟真实的异质聚合物网络。初始体系包含50个离子型PFAS、其反离子以及$^ { 1 5 , 0 0 0 }$个水分子，初始构型使用[[Packmol]]生成（Martínez et al., 2009）。模拟盒尺寸为95.4 Å × 80.68 Å × 100 Å，在所有方向上施加周期性边界条件。通过将[[径向分布函数]]与更大的2$\times 2 \times 1$体系进行比较（图S1），确认盒尺寸足以消除有限尺寸效应。所有原子均使用全原子[[OPLS力场]]描述（Dodda et al., 2017; Jensen and Jorgensen, 2006; Jorgensen, Maxwell and Tirado-Rives, 1996; Jorgensen and Tirado-Rives, 1988; Lopes, Padua and Shimizu, 2008; Watkins and Jorgensen, 2001）。相应参数从[[LigPar-Gen]]网络服务器获得。

平衡过程使用[[NVT系综|NVT]]和[[NPT系综]]在298 K下进行，采用[[Nosé–Hoover恒温器]]和恒压器（Evans and Holian, 1985; Nosé and Klein, 1983; Swope et al., 1982）。压力维持在1 bar，采用半各向同性方案，其中盒尺寸仅在z方向（垂直于膜）波动，而XY尺寸保持恒定。平衡过程中，时间步长从0.01 fs逐步增加到1 fs，直到体系稳定，表现为总能量、密度和温度的波动最小。生产模拟以1 fs的时间步长运行，总时长为20 ns。原子间相互作用采用14 Å的实空间截断，长程静电作用使用[[particle-particle particle-mesh方法|particle-particle particle-mesh]]（PPPM）方法计算（Eastwood, Hockney and Lawrence, 1980）。水分子使用TIP4P/2005模型建模，并通过[[SHAKE算法]]约束（Abascal and Vega, 2005; Ryckaert, Ciccotti and Berendsen, 1977）。采用第六版[[密度衍生静电和化学电荷|密度衍生静电和化学]]（DDEC6）（Limas and Manz, 2016; 2018; Manz, 2017; Manz and Limas, 2016; Manz and Sholl, 2010; 2011; 2012）电荷分配方法，利用[[DFT]]计算的电荷密度为离子型[[全氟和多氟烷基物质|PFAS]]和聚合物膜原子分配原子电荷。PFAS[[吸附]]定义为任意PFAS原子与膜原子之间4 Å的截断距离。[[β-环糊精|β-CD]]空腔吸附定义为PFAS原子位于$\beta { \mathrm { - C D } }$几何中心6 Å范围内，而与[[交联剂]]相关的吸附则使用距[[交联]]剂原子4 Å的截断距离。

[[β-CD-DFB-NH-N⁺]] 也在所有受试[[吸附]]剂中表现出最快的[[吸附动力学]]（图 3）。大部分 [[全氟和多氟烷基物质|PFAS]] 去除发生在第一小时内，其中 [[全氟丁酸|PFBA]] 为 $9 0 . 8 \pm 0 . 5$ %，[[全氟戊酸|PFPeA]] 为 $9 1 . 8 \pm 1 . 4 \%$，[[全氟己酸|PFHxA]] 为 $9 4 . 4 \pm 0 . 1$ %，[[全氟辛酸|长链 PFAS]] 约为 100 %。第一小时后，去除效率趋于平稳。相比之下，[[β-CD-DFB]] 和 [[活性炭|PAC]] 等基准吸附剂表现出较慢的动力学，在第一小时内仅去除 40–50 % 的长链 PFAS，并在约 12 h 时实现接近完全的吸附。[[离子交换树脂]]（IXs）在初始阶段对[[短链 PFAS]] 的吸附也有限（第一小时 <50 %，6 至 12 h 之间改善甚微，PFBA 为 $( 4 9 . 4 \pm 2 . 4 $ %，PFPeA 为 53.4 ± 2.1 %，PFHxA 为 $5 9 . 4 \pm 0 . 8$ %）。到 24 h 时，IXs 对 PFBA 达到 67.3 ± 2.5 %，对 PFPeA 为 $9 6 . 3 \pm 2 . 4 \%$，对 PFHxA 为 98.5 ± 1.4 %，且对长链 PFAS 实现接近完全去除。以 PFBA 作为代表性短链阴离子 PFAS，[[β-CD-DFB-NH]]-N⁺ 在 1 小时内实现超过 90 % 的去除，在可比的污染物与吸附剂负载比下，达到或优于其他新型吸附剂（Ateia et al., 2018; Karoyo and Wilson, 2013; Klemes et al., 2019; Kumarasamy et al., 2020; Xiao et al., 2019; Yang et al., 2020）（这些吸附剂显示 50–85 % 的去除率）（表 S8）。尽管其 [[BET 比表面积]]相对较低 $( \sim 1 0 \mathrm { m } ^ { 2 } { \cdot } \mathbf { g } ^ { - 1 } )$，这一高效率凸显了阳离子基元（Ching et al., 2020; Karoyo and Wilson, 2013; Klemes et al., 2019; Kumarasamy et al., 2020; Yang et al., 2020）在有效捕获短链、可迁移且呈阴离子态的 PFAS 中的关键作用。为验证我们合成的吸附剂在多个生产批次间的一致性，我们使用模型 PFAS 化合物和三个独立制备的吸附剂批次进行了批量吸附实验。结果在吸附性能上表现出优异的可重复性（图 S12）。

等温实验证实，季铵改性显著提高了[[吸附容量]]（图 S13）。[[β-环糊精|β-CD]] [[十氟联苯|DFB]]-NH-N⁺ 的最大[[吸附]]容量为 $3 9 6 . 7 ~ \mathrm { m g } { \cdot } \mathrm { g } ^ { - 1 }$ 对于 [[全氟辛酸|PFOA]]，约高出三倍。 $\beta { \mathrm { - C D - D F B - N H _ { 2 } } }$ $( 1 2 8 . 0 \ \mathrm { m g } { \cdot } \mathbf { g } ^ { - 1 } )$ ，基于 [[Langmuir 模型]]拟合，尽管它们的 [[BET 比表面积]]相近（10.5 与 $8 . 4 ~ \mathrm { m } ^ { 2 } { \cdot } \mathrm { g } ^ { - 1 } )$ . 总之，$\beta { \mathrm { - C D - D F B - N H _ { 2 } } }$ 和 $\beta { \mathrm { - C D - D F B - N H - N ^ { + } } }$ 均增强了对[[短链 PFAS]] 的[[吸附]]，其中 [[β-CD-DFB-NH-N⁺]] 表现出更优的性能，我们将其归因于增强的[[静电相互作用]]和[[亲氟相互作用]]。与 [[活性炭|PAC]]、[[离子交换树脂|IXs]] 和商业 CD 基聚合物等[[传统吸附剂]]相比，$\beta { \mathrm { - C D - D F B - N H - N ^ { + } } }$ 展现出更快的[[吸附动力学|动力学]]、更高的容量以及[[可再生性能]]（图 S14）。此外，$\beta { \mathrm { - C D - D F B - N H - N ^ { + } } }$ 在[[腐殖酸]]存在下表现出显著的[[抗污染性能]]（图 S15）。然而，所选腐殖酸可能无法代表[[国际腐殖质学会]]建议的实际 [[天然有机物|NOM]] 或受 [[水成膜泡沫|AFFF]] 影响的[[地下水]]，因为这些基质十分复杂，未来将对其进行系统研究。下一节将通过计算模拟探讨分子层面的吸附机制。

## 3.4. [[β-环糊精|β-CD]] 空腔中 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的模拟

在真空中进行[[DFT]]计算，以分离1：1[[主客体络合]]与$\beta \mathrm { - C D } .$的基本相互作用。这一第一步分析为在[[溶剂化]]环境中考虑更复杂的竞争效应之前，提供了相对结合强度的基线。所研究的所有五种[[全氟和多氟烷基物质|PFAS]]，包括[[全氟丁酸]]（PFBA）、[[全氟丙烷磺酸]]（PFPrS）、[[全氟丁烷磺酸]]（PFBS）、[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]，均与[[β-环糊精|β-CD]]形成了热力学稳定的主客体络合物，其负（放热）[[结合能]]范围为–55.0至–92.4 kJ⋅mol<sup>–1</sup>（图S16和S17）。将我们的PFOA结合能（–71.1 kJ⋅mol<sup>–1</sup>）与在显式溶剂化体系中使用[[伞形采样]]报道的–9.2 kJ $\cdot \mathbf { m o l } ^ { - 1 }$自由能进行比较时，真空环境的重要性显而易见（Choudhary等，2022）。这一差异凸显了使主体和客体[[去溶剂化]]所需能量代价的大小。然而，所观察到的强固有亲和力强调了$\beta { \mathrm { - C D } } ^ { \prime }$作为一种有效[[吸附]]剂去除传统和新兴PFAS的潜力。络合的主要驱动力被确定为PFAS氟化链与β-CD空腔疏水内部之间的[[色散相互作用]]。[[分子中原子量子理论|QTAIM]]分析表明，普遍不存在直接[[氢键]]，在被包封的PFAS头基与$\beta \mathrm { - C D } .$的羟基之间未发现[[键临界点|BCP]]。唯一的例外是PFOS，其中发现一个表明存在弱氢键的单一BCP，位置为$\left( \rho = 0 . 0 0 9 2 \right.$ a.u.，$\nabla ^ { 2 } \rho = 0 . 0 2 7 9 \mathrm { a . u . } )$。影响结合强度的关键因素是PFAS链长。例如，将链长从C4（[[全氟羧酸|PFCA]]）增加到C8（PFCA）会增强结合，结合能变得更负（从PFBA的$- 5 5 . 0 \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 }$到PFOA的–71.1 kJ⋅mol<sup>–1</sup>）。对于[[全氟磺酸|PFSA]]也观察到类似趋势，PFOS表现出比PFBS更强的结合。这种亲和力增加归因于较长氟化尾链所提供的更强[[范德华相互作用]]，这体现在更大的色散能贡献中。这些发现与此前报道较长疏水链增强β-CD结合的研究一致（Ochoa-Herrera和Sierra-Alvarez，2008；Yu等，2009a）。

通过比较 C4 [[全氟羧酸]]（[[全氟丁酸|PFBA]]）与 C3 [[全氟磺酸]]（[[全氟丙烷磺酸|PFPrS]]），也评估了 [[全氟和多氟烷基物质|PFAS]] 头基种类的影响。PFPrS 表现出比 PFBA 略强的结合 $( - 5 7 . 2 \ \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 } )$（–55.0 $\mathbf { k J } { \cdot } \mathbf { m o l } ^ { - 1 } ) ,$），这一差异可由它们各自的范德华贡献解释。更大、更易极化的[[磺酸基]]产生了 –58.9 kJ⋅mol<sup>–1</sup> 的色散贡献，强于 PFBA 中[[羧酸基]]的 $- 5 1 . 8 \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 }$。结构分析一致表明，在评估的最稳定[[吸附]]几何构型中，全氟烷基尾部深度插入 [[β-环糊精|β-CD]] 空腔，而极性头基则朝向 $\beta { \mathrm { - C D } }$ 的富羟基边缘。对于 [[全氟辛酸|PFOA]]，色散能（–82.7 kJ⋅mol<sup>–1</sup>）超过了净[[结合能]]（–71.1 kJ⋅mol<sup>–1</sup>），表明存在排斥性相互作用，这可能是由于容纳 C7 全氟烷基链所产生的空间应变。相比之下，[[全氟辛烷磺酸|PFOS]] 表现出高度吸引性的色散能 $( - 9 8 . 6 \ \mathrm { k J \cdot m o l ^ { - 1 } } )$ 和同样强的净结合能 $( - 9 4 . 6 \ \mathrm { k J \cdot m o l ^ { - 1 } } ) .$，表明在这些吸附模式中，色散贡献超过了略微吸热的静电贡献。这一行为与其在 β-CD 空腔中的部分包合一致（图 S17）。PFOS 更长的 C8 链使其能够采取穿线构象，即 PFOS 穿过大环空腔，末端 ${ \mathrm { - C _ { 2 } F _ { 5 } } }$ 基团延伸至空腔之外。这种几何构型最大化了空腔内有利的[[色散相互作用]]，同时避免了影响 PFOA 的空间应变；PFOA 被完全包合并受到空腔内的空间限制。总体而言，结合能中观察到的趋势表明，全氟磺酸比全氟羧酸结合更强，这是因为它们具有更高的色散相互作用和更大的电荷极化。在其他聚合物吸附剂捕获 PFAS 的文献中也观察到了这一趋势（Ilango 等，2024）。虽然这些真空中的发现突出了潜在相互作用的内在潜力，但后续的 [[分子动力学模拟|MD 模拟]]对于理解这种行为如何转化为更真实、显式[[溶剂化]]体系至关重要。

## 3.5. [[β-环糊精|β-CD]] 基[[吸附]]剂上 [[全氟和多氟烷基物质|PFAS]] 吸附的模拟

对四种[[全氟和多氟烷基物质|PFAS]]（[[全氟丁酸|PFBA]]、[[全氟丁烷磺酸|PFBS]]、[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]）物种在聚合物膜基质内定位的分析表明，在所有聚合物–PFAS组合中，直接包封在$\beta { \mathrm { - C D } }$空腔内的量始终约占总[[吸附]]量的5–10 %（图4C）。[[交联剂]]区域（DHB或[[十氟联苯|DFB]]）附近的吸附略多，约为5–25 %（图4D）。除这些明确位点外，模拟轨迹显示PFAS在[[β-环糊精|β-CD]]大环外表面大量累积，尤其是环羟基和[[糖苷键]]周围，这些也成为对观测吸收量有显著贡献的额外区域。此外，PFAS分子在聚合物表面附近形成动态团簇，通常聚集成两到四个分子的聚集体。这种团簇化是PFAS这类[[两亲性分子]]的特征现象。该现象对长链同系物PFOA和PFOS尤为显著。这种行为与协同吸附机制一致，即吸附剂表面促进[[半胶束]]结构的形成。这种聚集的[[吸附动力学|动力学]]很可能具有浓度依赖性。我们的模拟表明，初始的PFAS结合会形成局部有利的疏水或静电屏蔽环境，从而促进进一步聚集。这与表面活性剂文献中记载的半胶束形成一致（Dong et al., 2021; Groenendijk and van Wunnik, 2021）。通过比较[[β-CD-DHB]]与[[β-CD-DFB]]，考察了[[交联]]剂氟化对PFAS吸收的影响。与实验结果一致，[[分子动力学|MD]]模拟预测β-CD-DFB具有更高的PFAS吸收量，这归因于DFB交联剂更强的疏水性和与PFAS之间有利的[[亲氟相互作用]]。[[径向分布函数]]（RDFs）分析支持这种双重机制。水氧原子与交联剂原子之间的RDF显示，DFB氟原子周围的水排空程度高于DHB氢原子，表明其疏水性更强（图S18）。此外，PFAS尾部氟原子与交联剂原子之间的RDF显示，其与DFB氟原子的结合比与DHB氢原子更强、更近，突出了亲氟相互作用的作用（图S19）。PFAS原子与β-CD环羟基之间的RDF在两种聚合物中相似，且PFAS尾部比头基表现出更强的相互作用（图S20）。这表明吸收量的差异主要由交联剂性质驱动，而非β-CD本身。

在 $\mathrm { N H } _ { 2 }$ 中引入 $\beta \mathrm { - C D - D F B }$ 连接基进一步提高了 [[全氟和多氟烷基物质|PFAS]] 的摄取量。这一增强源于多重贡献。首先，[[径向分布函数|RDF]] 显示 $\mathrm { N H } _ { 2 }$ 氮原子与 PFAS 尾部氟之间的相互作用比与头基氧之间更强、更近，表明尾部优先缔合可能由色散力驱动（图 S21A）。此外，$\mathrm { N H } _ { 2 }$ 连接基改变了 [[β-环糊精|β-CD]] 大环周围的局部溶剂环境：水氧原子与 $\beta { \mathrm { - C D } }$ 边缘羟基氧之间的 RDF 显示，$\beta { \mathrm { - C D - D F B - N H _ { 2 } } }$ 中的水排除程度高于 [[β-CD-DHB]] 或 [[β-CD-DFB]]（图 S22）。这种扰动可能降低 PFAS [[吸附]]的能垒。然而，$\mathrm { N H } _ { 2 }$ 基团偶尔会[[自包合]]进入 β-CD 空腔，部分堵塞空腔，从而减少空腔特异性的 PFAS 结合。尽管如此，总摄取量仍有所增加，表明直接 $\mathrm { N H _ { 2 } } { \cdot } \mathrm { P F A S }$ 相互作用和溶剂重构的益处超过了空腔可及性的损失。PFAS 摄取增强最显著的是 $\beta { \mathrm { - C D - D F B - N H - N ^ { + } } }$，其引入了[[季铵基团]]。这一改善主要归因于阳离子 $\mathrm { N } ^ { + }$ 位点与阴离子 PFAS 头基之间的强静电吸引。RDF 证实了这一点，显示 $\mathrm { N } ^ { + }$ 氮原子与 PFAS 头基氧原子之间的峰显著更高、距离更近，而不是与尾部氟原子（图 S21B）。与 NH 基团不同，体积较大的 $\mathrm { N } ^ { + }$ 基团不会自包合进入 β-CD 空腔。相反，它定位在 $\beta { \mathrm { - C D } }$ 外部和 [[十氟联苯|DFB]] 区域附近，完全避开了空腔。季铵基的这种排布方式，结合[[静电相互作用]]，解释了与其他聚合物变体相比增加的空腔特异性和[[交联剂]]相关 PFAS 摄取。尽管 $\mathrm { N } ^ { + }$ 基团可能被认为会破坏[[水化壳层]]，但 RDF 显示其水结构性质与 $\mathrm { N H } _ { 2 }$ 连接基相当（图 S22）。因此，$\beta { \mathrm { - C D - D F B - N H _ { 2 } { \cdot } N ^ { + } } }$ 对 PFAS 的摄取是由强静电相互作用、有利的[[色散相互作用]]、[[疏水效应]]和[[亲氟相互作用]]的协同组合所驱动。

总之，我们的 [[分子动力学模拟|MD 模拟]]揭示了 [[全氟和多氟烷基物质|PFAS]] [[吸附]]中势能与[[吸附动力学|动力学]]行为之间的关键区别。尽管在无限稀释条件下 [[DFT]] 计算确定 [[β-环糊精|β-CD]] 空腔是能量上最有利的 1:1 结合位点，但在真实的[[溶剂化]]体系中，其作用被发现是有限的。我们的 [[分子动力学|MD]] 模拟表明，PFAS 的总摄取并非由直接的[[主客体络合]]控制，而是由分布在整个聚合物网络中的涌现疏水聚集体和团簇控制。这一发现重新诠释了吸附机制，强调了更广泛的聚合物结构在有效捕获 PFAS 中的关键作用。

## 3.6. 稀释 [[水成膜泡沫|AFFF]] [[吸附]]

我们进一步证明了[[β-CD-DFB-NH-N⁺]]与[[β-CD-DFB-NH]]之间独特而多样的协同结合机制，以及[[水成膜泡沫|AFFF]]中存在的复杂[[全氟和多氟烷基物质|PFAS]]化学组成（图S23和S24）。共定量检测到95种不同的PFAS，总质量浓度最高达$\cdot \ - 1 . 3 \ \mathrm { m g } { \cdot } \mathrm { L } ^ { - 1 }$，其中包括55种阴离子型、33种两性离子型和7种[[非离子型PFAS]]（详情见表S9–S11）。AFFF加标样品通过将一种基于[[电化学氟化]]（ECF）的3 M AFFF配方稀释至[[环境相关浓度]]制备。已知AFFF配方中含有高出数倍的[[碳氢表面活性剂]]（Garcia等，2019），这些物质可能与PFAS[[竞争吸附]]。实际[[地下水]]基质（如无机阴离子组成）的影响将在未来进行研究。总体而言，[[β-CD-DFB聚合物|-CD-DFB-NH-N]]去除了96种检出PFAS中$9 6 . 3 \% \pm 0 . 2 3$%（按质量分数计），而$\beta { \mathrm { - C D - D F B - N H _ { 2 } } } ( { \mathrm { F i g . ~ } } 5 ) .$的去除率为80.8%。尽管该稀释配方尚未被其他[[吸附]]剂直接测试，但其组成中含有毫克级的PFAS以及具有竞争性的碳氢表面活性剂，这表明当应用于总PFAS浓度显著更低的受AFFF影响样品时，其性能可能达到甚至超过商品化和新开发的吸附剂（Dixit等，2022；Li等，2021；Pezoulas等，2025；Tajdini等，2025；Wang等，2020）。

[[阴离子型PFAS]]约占总[[全氟和多氟烷基物质|PFAS]]质量的75%，可被[[β-CD-DFB-NH-N⁺]]有效去除，12小时后55种化合物中有51种实现接近完全去除，对应的总质量去除率为$9 9 . 6 ~ \% \pm \ : 0 . 0 4 ~ \%$（图5）。对于大多数阴离子型PFAS同系物系列，未观察到对全氟碳链长的明显依赖性（Li等，2021；Wang等，2020）；相反，几乎实现了100%的去除。这与我们在[[超纯水]]中九种PFAS混合物中的发现一致，但与典型趋势不同——通常较[[长链PFAS]]由于疏水性更强而表现出与[[吸附]]剂更强的[[疏水相互作用]]（Gagliano等，2020）。[[β-CD-DFB-NH]]-N⁺的优异性能归因于疏水、亲氟和[[静电相互作用]]的协同效应，这些作用共同提高了其对PFAS的亲和力。值得注意的是，亲氟和静电相互作用的存在弥补了[[短链PFAS]]（如C3–C5）疏水性降低的不足。然而，两种短链羧酸类PFAS——[[全氟丁酸|PFBA]]$( 6 9 . 6 ~ \pm ~ 0 . 5 ~ \% )$和[[全氟戊酸|PFPeA]]$( 8 9 . 4 \ : \pm \ : 0 . 3 \ : \ : \% )$——是例外（图S24），这可能是由于[[碳氢表面活性剂]]（Garcia等，2019）和其他PFAS的竞争所致。在这些情况下，较弱的亲氟和静电相互作用不足以抵消与较短链长相关的疏水相互作用减弱。$\beta { \mathrm { - C D - D F B - N H _ { 2 } } }$对阴离子型PFAS的总体去除效率为86.2%（图5）。对于[[全氟羧酸|PFCA]]和[[全氟磺酸|K-PFSA]]，观察到显著的[[链长依赖性]]（图S25）。这两种吸附剂的比较突显了[[阳离子官能团]]在[[竞争吸附]]环境中去除阴离子型PFAS的关键作用。

![](<../2.SCI_MD/Adsorption of per- and polyfluoroalkyl substances (PFAS) by quaternary ammonium and fluorine-functionalized macrocyclic sorbents A comprehensive experimental and simulation study/images/21bd2a799e8047cd8b97eb7c93d827159f6a946166838045b2bb616677a608aa.jpg>)  
图 5. 接触 12 h 后，β-CD-DFB-NH（上图）和 β-CD-DFB-NH-N<sup>+</sup>（下图）对稀释 AFFF 样品中各 PFAS 的吸附效率。PFAS 化合物按电荷分组：两性离子型（9 个同系物系列）、非离子型（3 个同系物系列）和阴离子型（10 个同系物系列）。汇总图展示了每一 PFAS 类别的总体去除效率以及总 PFAS 去除率。误差棒表示三次平行测量的标准偏差。

[[两性离子PFAS]]占[[全氟和多氟烷基物质|PFAS]]总质量的24.3%，由于其电荷状态可变，且额外的脂肪烃链与全氟碳链段相比疏水性降低，因此处理尤为困难（图5）。尽管如此，[[β-CD-DFB-NH-N⁺]]仍实现了88.5 ± 0.7 %的平均去除效率，达到或优于 $\beta \mathrm { - C D - D F B - N H _ { 2 } \ ( 6 7 . 8 \ \pm \ 1 . 1 \ \% ) }$ 以及其他[[商业吸附剂]]（Dixit et al., 2022; Li et al., 2021; Pezoulas et al., 2025; Tajdini et al., 2025）。几种含有六个全氟碳原子的两性离子PFAS，常见于[[水成膜泡沫|AFFF]]及受AFFF影响的环境介质中，在本研究中以相对较高的浓度存在。例如，[[AmPr-FHxSA]]，一种主要的基于[[电化学氟化|ECF]]的前体，在 ${ \sim } 4 2 ~ \mu \mathrm { g } { \cdot } \mathrm { L } ^ { - 1 }$ 从原始浓度稀释超过6000倍后 $1 { - } 1 0 \ g { \cdot } \mathrm { L } ^ { - 1 }$ 浓度（Yan et al., 2024）。[[β-CD-DFB-NH]]-N⁺ 和 [[β-CD-DFB]]-NH 的去除效率分别为 87.3 ± 1.3 % 和 95.8 ± 0.1 %（图 S23 和 S24）。其他含量较高的两性离子 PFAS 包括 [[SPrAmPr-FHxSA]]（约 23 µg⋅L<sup>−</sup> <sup>1</sup>）， [[diOHPrAm-MeOHPr-FHxSAPrS]]（约 32 $\mathbf { \mu } \mathbf { g } { \cdot } \mathbf { L } ^ { - 1 } )$ ，[[SPrAmPr-FPeSAPrS]] $( { \sim } 2 8 ~ \mu \mathrm { g } { \cdot } \mathrm { L } ^ { - 1 } )$ ，[[SPrAmPr-FHxSAPrS]]（约 24 µg⋅L<sup>−</sup> <sup>1</sup>），以及 [[diOHPrAm-MeOHPr-FHxSA]]（约 91 µg⋅L<sup>−</sup> <sup>1</sup>）。[[β-环糊精|β-CD]]-[[十氟联苯|DFB]]-NH-N⁺ 在 12 h 后对这些化合物的平均去除率超过 95 %（图 5）。两性离子 PFAS 的[[吸附]]行为受全氟碳链长度、电荷状态和[[官能团]]的影响。同系物系列如 [[SPrAmPr-FASAPrS]] 和 [[S-OHPrAmPr-FASAA]]，含有一个正电荷官能团和两个负电荷官能团（净负电荷），其吸附行为与阴离子 PFAS 相似。对于 SPrAmPr-FASAPrS，β[[β-CD-DFB聚合物|-CD-DFB-NH-N]]⁺ 在 C3–C8 范围内实现超过 98 % 的去除率，且无[[链长依赖性]]（图 5 与 S26A）。相比之下，β-CD-DFB-NH 的去除效率与链长呈正相关（图 S26B）。净中性电荷的同系物系列，[[氟调聚磺酰胺|AmPr-FASAs]] 和 SPrAmPr-FASAs，表现出强烈的链长依赖性（图 S27）。短链化合物（C3–C5）的去除效果较差（图 S23 与 S24，β-CD-DFB-NH-N⁺ 约为 60 %，约 36 %） 对于β-CD-DFB-NH<sub>2</sub>），这可能是由于疏水与[[亲氟相互作用]]不足所致，凸显了去除短链两性离子PFAS所面临的广泛报道的挑战。对于[[diOHPr-Am-MeOHPr-FASA]]和[[DiMeA-MeOHPr-FASAPrS]]，尽管带有净负电荷，其吸附仍表现出链长依赖性（图S28），这与典型[[阴离子型PFAS|阴离子PFAS]]的行为不同。在这些同系物系列中，β-CD-DFB-NH-N⁺始终优于β-CD-DFB-NH。

在[[非离子型PFAS]]（即中性[[全氟和多氟烷基物质|PFAS]]）中，大多数长链磺酰胺衍生物均被有效去除（去除率约100%）。例外是[[全氟丁烷磺酰胺|FBSA]]，其在[[β-CD-DFB-NH-N⁺]]上的去除效率较低，为81.2 ± 2.0 %（图5和S24）。Me/EtFASAs、Me/EtFA-SAAs和[[氟调聚磺酰胺|FASAs]]是初级[[电化学氟化|ECF]]基化合物[[生物转化]]过程中形成的[[PFAS前体|次级ECF基前体]]（Ma和Olivares，2025；Yan等，2024）。这些中间体在[[水生环境]]中末端[[全氟磺酸|PFSA]]的形成中发挥重要作用（Ma和Olivares，2025；Yan等，2024），且与[[两性离子PFAS]]相比更难[[吸附]]（Ching等，2020；Wang等，2020）。尽管在我们稀释的[[水成膜泡沫|AFFF]]样品中丰度较低，但在存在高浓度初级前体和[[碳氢表面活性剂|烃类表面活性剂]]的[[竞争吸附]]条件下，它们仍能被高效去除，这表明[[β-CD-DFB-NH]]-N⁺能够在[[环境相关浓度]]下有效去除这些化合物。

综上所述，[[β-CD-DFB-NH-N⁺]]在模拟[[水成膜泡沫|AFFF]]污染[[地下水]]中对广泛的[[全氟和多氟烷基物质|PFAS]]化合物表现出优异的[[吸附]]性能。这种有效性归因于静电、疏水和[[亲氟相互作用]]的均衡贡献。然而，短链非[[阴离子型PFAS|阴离子PFAS]]的去除仍然是一项重大挑战，原因在于这些相互作用的强度有限。未来工作应着重增强这些机制，并探索额外的亲和策略，以改善对短链、可迁移、非阴离子PFAS的捕获。

## 4. 结论

本研究将实验与计算方法相结合，以全面理解用于[[全氟和多氟烷基物质|PFAS]]去除的[[大环多孔吸附剂]]。我们考察了[[主客体包合]]、疏水、亲氟和[[静电相互作用]]在多种PFAS化合物[[吸附]]中的协同贡献。据我们所知，这种功能组合在基于[[β-环糊精|β-CD]]的聚合物中尚未见报道，并解决了早期材料所观察到的局限性（Ching等，2020；Lin等，2024；Wang等，2020；Xiao等，2017）。通过这种均衡的相互作用设计，我们所得聚合物（例如，[[β-CD-DFB-NH]]-N<sup>+</sup>）展现出广谱适用性，并对具有挑战性的PFAS物种表现出优异性能。这些新型吸附剂（包括我们的设计）的潜在应用可延伸至[[短链PFAS]]的处理（Lenka等，2024；Rahman、Peldszus和Anderson，2014；Yu等，2025）、[[PFAS前体]]（Barzen-Hanson等，2017b；Jacob、Barzen-Hanson和Helbling，2021；Thompson等，2023）、[[半导体废水]]中的新兴PFAS（Chen等，2024；Jacob、Barzen-Hanson和Helbling，2021；Jacob和Helbling，2023；Qiao等，2025），以及多种PFAS物种共存的遗留[[污染场地修复|污染场地的修复]]（Appleman等，2014；Meegoda等，2020；Place和Field，2012）。在此类复杂场景中，[[传统吸附剂]]（如[[颗粒活性炭|GAC]]或[[离子交换树脂|IXs]]）以及此前开发的新型吸附剂可能因依赖单一相互作用机制而力不从心（Deng等，2010；Kumarasamy等，2020；Manning等，2022；Yu等，2009b；Zhang等，2016）。我们的[[理性设计]]旨在克服这些限制，使吸附剂能够应对全谱PFAS污染物。

从实际角度出发，我们承认当前材料的[[粒径分布]]较小（20–45 μm），可能限制其在[[固定床柱式应用|柱式系统]]中的直接应用。为解决这一问题，我们正在进行的研究专注于开发适用于柱式部署的[[颗粒状吸附剂]]。此外，使用[[氟化吸附剂]]处理类似的[[全氟和多氟烷基物质|PFAS]]化合物引发了人们对[[环境可持续性]]及这些材料整体生命周期的重大关切。我们认同，[[毒性与安全性评估]]对未来商业应用至关重要。为降低这些风险，必须实施有效的[[废物管理|废物管理策略]]，并遵守约束氟化[[吸附]]剂处置的[[监管框架]]。

展望未来，下一代[[吸附]]剂的设计还应纳入若干关键特性：简便且[[可规模化合成|可规模化的合成方法]]；可调的[[孔径]]和[[BET|比表面积]]以优化[[吸附动力学]]；与[[生物修复|生物修复策略]]整合所需的潜在[[生物相容性]]；以及适用于大规模[[固定床柱式应用]]的可定制颗粒形态。
