# 各向异性[[颗粒沉积动力学]]的 [[石英晶体微天平|QCM]]‑D 研究：流体力学滑移机制的证据

[[Zbigniew Adamczyk]],\* [[Agata Pomorska]], [[Marta Sadowska]], [[Małgorzata Nattich-Rak]], [[Maria Morga]], [[Teresa Basinska]], [[Damian Mickiewicz]], and [[Mariusz Gadzinowski]]

摘要：利用[[石英晶体微天平|石英微天平]]（QCM）技术，研究了呈[[长椭球体|长椭球]]形的带正电聚合物微粒在[[二氧化硅]]和金传感器上的[[颗粒沉积动力学|沉积动力学]]。同时，对质量与椭球颗粒相同的球形带正电聚合物颗粒进行了参照测量。首先，测量了不同泛频下频率和带宽随时间的变化。结果表明，所有泛频下这些信号的比值均接近 1。这些结果被转换为频率偏移随颗粒覆盖度的依赖关系，其中覆盖度通过[[原子力显微镜]]直接测定，并基于流体力学模型进行理论解释。考虑颗粒相对于周围振荡流动的滑移后，理论结果与实验取得了定量一致。相比之下，与刚性接触模型相关的理论结果被证明是不适用的。将由 QCM 方法得到的颗粒沉积动力学与按照[[随机顺序吸附]]方法进行的理论模拟进行了比较。由此可以评估 QCM 技术用于获取各向异性颗粒正确沉积动力学的可行性。文中提出，在解释 QCM 动力学结果时，应考虑流体力学滑移效应。该结论同样适用于针对生物颗粒，尤其是[[病毒]]所获得的结果。

## 引言

颗粒沉积研究可提供有关颗粒与界面相互作用以及黏附强度的基本信息，这对于胶体科学、生物物理学、医学、土壤化学等领域至关重要。这些知识可用于控制和优化各种实际过程，例如过滤、浮选、保护涂层形成、催化以及微电子学：纳米和微结构材料的生产，如窄带光学滤波器、光子带隙材料、波导以及其他电光或磁光器件。

还值得指出的是，从模型胶体体系获得的结果可用于正确解释大分子[[吸附]]现象，包括参与血栓形成、人工器官失效、斑块形成等的[[蛋白质]]分子。

应当考虑到，许多胶体颗粒的形状明显偏离球形，往往近似于[[长椭球体|长椭球]]或圆柱体，例如[[多壁碳纳米管]]<sup>1,2</sup>、[[二氧化硅]]颗粒<sup>3−6</sup>、聚合物微粒<sup>7−9</sup>、聚合物大离子（聚电解质）<sup>10−13</sup>，以及 [[DNA]] 片段<sup>14−16</sup>、[[病毒]]<sup>17−19</sup>和[[细菌]]<sup>2</sup> <sup>0,21</sup>等生物颗粒。

鉴于其重要性，纳米颗粒和微米颗粒的[[吸附动力学]]已通过多种力显微镜（[[原子力显微镜|AFM]]）、<sup>23−25</sup> [[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）、<sup>25−28</sup> [[椭偏仪]]、<sup>29−31</sup> [[反射计]]、<sup>32,33</sup> [[表面等离子体共振]]<sup>34</sup> 以及电动方法<sup>35,36</sup> 得到广泛研究。然而，这些技术无法提供有关颗粒与基底表面之间粘附接触强度的有效信息。在这方面，[[石英晶体微天平]]（QCM）方法表现出显著优势，能够在流动条件下对纳米和微米颗粒进行精确的原位沉积/[[脱附]]动力学测量。<sup>37−51</sup> 然而，这些研究几乎只集中于[[球形颗粒]]。

在文献 43 中，研究了经硅烷功能化的[[二氧化硅]]颗粒从其乙醇悬浮液中的沉积。观察到频率偏移随倍频数系统性地增加，而耗散偏移则随倍频数降低。这些初步结果被转换为频率偏移对由 [[SEM]] 得到的颗粒表面浓度的依赖关系。结果表明，所有倍频下这些依赖关系的斜率均大于利用 [[Sauerbrey方程|Sauerbrey 方程]]计算的[[干覆盖度]]所对应的参考线斜率。

利用 [[石英晶体微天平|QCM]] 方法，Olsson 等 $\mathrm { a l . } ^ { 4 1 }$ 研究了直径为 1 μm 的[[二氧化硅]]颗粒在裸露、生物素化以及链霉亲和素包覆的二氧化硅传感器上的沉积。对于裸露二氧化硅传感器，仅在倍频数低于 9 且离子强度超过 0.05 M 时观察到负频率偏移。对于链霉亲和素包覆的二氧化硅，频率偏移为强负值，并随倍频数线性减小。这些结果借助耦合共振模型进行了解释，该模型考虑了附着在传感器上的颗粒的阻尼振荡。

Tarnapolsky 和 Freger<sup>49</sup> 对[[聚苯乙烯]]和[[二氧化硅]]微米颗粒在金传感器和二氧化硅传感器上的沉积进行了详尽测量。实验数据表示为频率和带宽偏移对倍频数的依赖关系。直径为 1 μm 的聚苯乙烯颗粒在金传感器上的沉积产生负频率偏移，但相同颗粒在二氧化硅传感器上产生的正频率偏移随倍频数而减小。这一行为被解释为：二氧化硅颗粒/二氧化硅传感器（两者均带负电荷）之间的低粘附力使颗粒能够发生振荡运动。另一方面，对于相同二氧化硅颗粒在带正电传感器上的沉积，频率偏移为负值，这与假设沉积颗粒在停滞流体层中振荡的模型一致。

在参考文献50中，对尺寸分别为67、140、360和810 nm的带正电脒基颗粒的[[颗粒沉积动力学|沉积动力学]]进行了研究，实验在 $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ 通过[[石英晶体微天平]]（QCM）研究了传感器的性能。将主要频率偏移随时间的变化关系转换为 QCM 覆盖度。 $\Gamma _ { \mathrm { Q } }$ 使用 [[Sauerbrey方程|Sauerbrey 方程]]，并与基于随机顺序（[[随机顺序吸附|RSA]]）方法的理论计算结果进行了比较。结果证实，QCM 覆盖率显著大于由非原位 [[原子力显微镜|AFM]] 测量得到的干燥[[干覆盖度|颗粒覆盖率]]（记为 Γ）。因此， $\Gamma _ { \mathrm { Q } } / \Gamma$ ratio 达到 10 对于该 $^ { 6 7 }$ 纳米直径颗粒以及一次泛频（在短时间极限内）的频移与惯性质量成比例。然而，对于 810 nm 直径颗粒，频移绝对值随泛频次数迅速减小，导致 QCM 覆盖率远小于颗粒层的惯性质量。这一效应被归因于粘附强度相对于流体动力的不足，从而使颗粒能够发生摇摆运动，但并未发生[[脱附]]。

针对非[[球形颗粒]]的 [[石英晶体微天平|QCM]] 研究较少。在参考文献 47 和 48 中，研究了[[脂质体]]在二氧化钛传感器上的沉积，并通过格子 Boltzmann 数值模拟进行了理论解释。预测表明，负频率偏移应随颗粒覆盖度以及被模拟为尺寸等于 78 nm 的[[扁球体]]的脂质体轴比增大而减小。这些理论计算使得能够建立一种在原位条件下测定脂质体纵横比的独特方法。

关于细长形状的胶体颗粒，文献中报道的实验很少。在文献 52 中，作者利用 [[石英晶体微天平|QCM]] 研究了尺寸为 1100 × 250 nm（长径比约等于 4.5）的子弹状[[二氧化硅]]颗粒在二氧化硅传感器上的沉积。在较宽的 [[pH]] 范围内，颗粒与传感器均表现出负的 $\dot { \zeta }$ 电位，这导致沉积效率相当低，其特征为频率位移仅为 −30 Hz。然而，文献 52 并未尝试对这些结果进行解释。

由于实验结果的不足，本工作的主要目标是确定[[球形颗粒]]在固/电解质界面沉积的机理，重点在于评估 [[石英晶体微天平|QCM]] 技术用于获得定量动力学结果的适用性。为了提高实验的可靠性，使用了表面带正电的单分散聚合物颗粒，这使得它们能够在带负电的[[二氧化硅]]和金传感器上发生不可逆[[吸附]]。将 QCM 一次数据与 [[原子力显微镜|AFM]] 测量结果进行了对比，后者提供了颗粒绝对覆盖率随沉积时间变化的函数。这使得能够依据考虑了促进颗粒滑动运动的流体动力学滑移效应的理论模型，对 QCM 结果进行定量解释。

可以预期，所获得的结果可作为有用的参考体系，用于定量解释[[蛋白质]]和[[病毒]]的[[吸附]]/[[脱附]]现象<sup>51,53,54</sup>，并用于评估刚性与软粘附模型的有效性。

方法。[[石英晶体微天平|QCM]]测量依据参考文献50所述的标准程序，使用[[Q-Sense]] QCM仪器（[[Biolin Scientific]]，瑞典斯德哥尔摩）进行。首先，在受控离子强度和[[pH]]的纯电解质（[[氯化钠|NaCl]]）中获得稳定基线。然后，以固定流速将受控浓度的颗粒悬浮液注入流动池。经过规定时间后，开始解吸运行，即将相同pH和离子强度的纯电解质溶液注入流动池。

颗粒的[[颗粒沉积动力学|沉积动力学]]采用[[原子力显微镜|AFM]]方法独立测定，如$\mathrm { r e f . } ^ { 5 0 }$所述。因此，[[石英晶体微天平|QCM]][[吸附]]运行在规定的时间间隔后停止，将传感器从悬浮液中取出，并在环境条件下使用配备[[SMENA SFC050L]]扫描头的[[NT-MDT Solver BIO]]设备进行AFM成像。单位面积颗粒数（通常为$1 \mu \mathrm { m } ^ { 2 } )$，下文记作$N ,$）通过随机选取传感器上若干等面积区域直接计数确定，颗粒总数超过2000个。

平板的$\zeta$电位通过[[流动电位]]测量确定，测量程序依据参考文献36所述，并应用考虑表面电导校正的[[Smoluchowski公式]]。

因此，图3a所示结果证实了由方程3预测的、适用于自由浮力颗粒层的趋势，即$- \Delta f / \hat { n } _ { 0 } ^ { 1 / 2 }$对所有泛音（在同一沉积时间下）应保持恒定。此外，根据方程$^ { 6 , }$，对于自由浮力颗粒，归一化频率与带宽位移之比Δf̅应保持恒定并接近于1，这确实在图3b中观察到。

然而，要对理论预测进行定量检验，需要知道颗粒质量覆盖度$\Gamma = \Nu _ { m _ { \mathrm { p } } }$（通常称为[[干覆盖度]]）随沉积时间的变化。如支持信息所示，在较短沉积时间下，表面阻塞效应可忽略，覆盖度为时间的线性函数，明确给出为$\mathrm { { b y } } ^ { 6 2 }$

$$
\Gamma = N m _ {\mathrm{p}} = k _ {\mathrm{c}} c _ {\mathrm{b}} t\tag{7}
$$

其中$k _ { \mathrm { c } }$为[[传质速率常数]]，$c _ { \mathrm { b } }$为[[体相颗粒的质量浓度]]。

因此，对在不同悬浮液流速下、使用$\mathrm { S i O } _ { 2 }$与[[金基底|Au传感器]]开展的每次实验，其[[传质速率常数]]是通过对传感器多个区域上[[吸附]]颗粒层进行非原位[[原子力显微镜|AFM]]成像来确定的。对于[[球形颗粒|球状颗粒]]、离子强度为$_ { 0 . 0 1 }$ M时所获得的实验结果如图4a所示，展示了泛频1和11下$- \Delta f / n _ { 0 } ^ { 1 / 2 }$随由式7计算所得[[干覆盖度|颗粒覆盖率]]的变化关系。可见，所有情况下的实验数据都能由线性关系很好近似，且这两个极限泛频之间差异最小（泛频3−9的结果介于这些极限值之间，为清晰起见未在图4a中示出）。

实验结果能够被适用于[[中性浮力颗粒]]作滑动运动的理论模型充分反映（图4a中的绿色实线），其中归一化频移根据以下关系式计算：

$$
- \Delta f / n _ {0} ^ {1 / 2} = \frac {9}{4} \frac {\rho_ {\mathrm{f}}}{C _ {\mathrm{s}} \rho_ {\mathrm{p}}} [ 1 - F _ {3} (h / b) ] F _ {8} (0) \overline {{\delta}} _ {1} \Gamma\tag{8}
$$

这些计算中使用了以下参数：$\rho _ { \mathrm { f } } =$ 1.0 kg $\mathrm { m } ^ { - 3 } , \tilde { \rho _ { \mathrm { p } } } = 1 . 0 6 \mathrm { k g } \mathrm { m } ^ { - 3 } , F _ { 3 } \big ( h / b \big ) = 0 . 5 7$（在支持信息中针对h/$\ b \ = \ 0 . 0 2$计算）、$F _ { 8 } ( 0 ) \ = \ 1$ .14（适用于相互接触珠串）以及$\overline { { \delta } } _ { 1 } = 2 . 1 6$。值得指出的是，除上述数据外，这些计算中没有使用其他可调参数。相比之下，针对刚性接触所预测的结果（如图$^ { 4 } \mathbf { a } ,$中虚线所示），其归一化频移由下式给出：

$$
- \Delta f / n _ {0} ^ {1 / 2} = \frac {1}{C _ {\mathrm{s}}} \left(n _ {0} ^ {1 / 2} + \frac {9}{4} \frac {\rho_ {\mathrm{f}}}{\rho_ {\mathrm{p}}} F _ {8} (0) \bar {\delta_ {1}}\right) \Gamma\tag{9}
$$

多次显著高估了实验数据。对于[[球形颗粒]]$( \mathbf { A } \breve { 3 } 6 0 )$所获得的类似实验结果如图4b所示。与之前对球状颗粒的观察相同，所有泛频（1−11）下实验数据都能由线性关系很好近似，其中第一至第五泛频对应的斜率相似，而在更大的泛频下，$\mathrm { o f } - \Delta f / n _ { 0 } ^ { 1 / 2 }$随覆盖率的变化关系具有小得多的斜率。同样，泛频1−5的实验结果与由适用于[[中性浮力颗粒]]的理论模型、使用式8所得结果一致（图4b中的绿色线），其中使用了以下参数：$\rho _ { \mathrm { f } } = 1 . 0 \mathrm { k g } \mathrm { m } ^ { - 3 } \rho _ { \mathrm { p } } = 1 . 0 6$ kg m<sup>−3</sup>、$F _ { 3 } ( \Breve { h } / \hat { b } ) = 0 . 5 2 , F _ { 8 } ( 0 ) = 1 . 7 \dot { 0 } ,$和$\overline { { \delta } } _ { 1 } = 1 . 3 2 .$。与球状颗粒的情况相同，针对刚性颗粒接触、由式9计算所预测的结果显著高估了实验数据。图4b中较大泛频（7−11）下实验数据与理论结果之间的显著偏差，最有可能是如参考文献49所建议的那样，源于[[弹性范德华力]]的出现，这些力阻尼了颗粒的振荡运动。

由式8可以推知，[[球形颗粒|球状颗粒]]的[[干覆盖度|干覆盖率]]可以利用对所有泛频均成立的线性关系由[[石英晶体微天平|QCM]]信号计算得出：

$$
\Gamma = C _ {\mathrm{ss}} (- \Delta f / n _ {0} ^ {1 / 2})\tag{10}
$$

其中

$$
C _ {\mathrm{ss}} = \frac {4 \rho_ {\mathrm{p}} b}{9 \rho_ {\mathrm{f}} [ 1 - F _ {3} (h / b) ] F _ {8} (0) \delta_ {1}} C _ {\mathrm{s}}\tag{11}
$$

是适用于[[中性浮力颗粒]]模型的修正Sauerbrey常数。

应当指出，式11中的$F _ { 3 } { \big ( } h / b { \big ) }$函数可以很好地由支持信息中给出的解析插值近似。

然而，需要说明的是，若$\delta _ { \mathrm { 1 } } / b > 1$，则式10预期能给出精确结果。

为了评估式10的有效性，将主要[[石英晶体微天平|QCM]]动力学曲线，即频移随沉积时间的变化关系（见图2），转换为[[干覆盖度|干覆盖率]]随时间的变化关系，并示于图5中。

由此可见，以第一至第十一泛音平均计算得到的覆盖率（图 5 中实线）与由 [[原子力显微镜|AFM]] 得到的实验数据吻合，AFM 虽然仅在离散时间间隔内直接给出[[干覆盖度|颗粒覆盖率]]（这些结果在图 5 中以点表示）。[[石英晶体微天平|QCM]] 结果还与基于混合 [[随机顺序吸附|RSA]] 方法（Supporting Information）的理论计算进行了对比，该方法以精确方式考虑了本体颗粒传输与经由受阻塞效应控制的颗粒层进行的表面传输之间的耦合。在该方法范围内导出的动力学方程经过数值积分，明确给出了颗粒干质量随[[吸附]]时间的依赖关系。该方法此前已被用于定量解释不同基底上的纳米[[颗粒沉积动力学]]。<sup>54</sup> 从图 5 中可以观察到，[[随机顺序吸附模型|RSA]] 结果在整个沉积时间范围内均与 QCM 和 AFM 实验数据一致。因此，这些结果证实，可以在考虑流体动力学滑移效应的理论模型框架内，对用于各向异性颗粒的 QCM 测量结果进行定量解释。

## ■ 结论

结合[[石英晶体微天平]]（QCM）技术与 [[原子力显微镜|AFM]] 测量，定量测定了带正电的[[椭球形微粒]]在带相反电荷的[[二氧化硅]]和金传感器上的[[颗粒沉积动力学|沉积动力学]]。

观察到不同泛音的归一化频率和带宽位移是等价的，使得二者之比在整个沉积时间内接近 1。归一化频率位移被转换为与颗粒质量覆盖率的关系，而该覆盖率由 [[原子力显微镜|AFM]] 确定。以这种方式表示的结果是定量的，并依据适用于[[中性浮力颗粒]]的[[流体动力学模型]]进行了解释，该模型预测了显著的滑移效应。在这种类似[[润滑接触]]的情形下，即使[[间隙宽度]]仅为颗粒尺寸的 1%，[[石英晶体微天平|QCM]] 信号也比刚性接触所预期的信号小很多倍。

考虑流体动力学滑移效应，推导出一个修正的类 [[Sauerbrey方程|Sauerbrey 方程]]，从而能够根据用泛音数平方根归一化的频率位移计算绝对[[干覆盖度|颗粒覆盖率]]。研究表明，由该方程预测的 [[石英晶体微天平|QCM]] 覆盖率与 [[原子力显微镜|AFM]] 数据以及由 [[随机顺序吸附|RSA]] 模型得到的理论结果一致。

可以预期，流体动力学滑移效应对于纳米颗粒尺寸的溶质也可能发挥重要作用，这些溶质包括[[病毒衣壳]]和[[蛋白质]]，其分子具有不规则形状特征。这种分子形貌可能降低黏附强度，尤其是对于具有显著粗糙度的传感器，从而使得溶质能够在平衡位置附近发生滑动运动。由于在这些情况下，[[间隙宽度]]与特征分子尺寸之比可能超过 0.1，因此与刚性接触相比，[[石英晶体微天平|QCM]] 信号预计将出现数倍的降低。
