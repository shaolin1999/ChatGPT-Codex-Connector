# [[纳米限域]]下[[金属有机框架|MOF]]介导的级联光反应用于[[全氟和多氟烷基物质]]的[[脱氟]]

[[Jingjing Tang]]<sup>1,2,4</sup>, [[Xiang Zhang]]<sup>1,2,4</sup>, [[Jie Li]]<sup>3</sup>, [[Hongchao Li]] <sup>2</sup>, [[Yuqian Jia]]<sup>1</sup>, [[Wanyi Fu]] <sup>3</sup>, [[Weiming Zhang]] <sup>1,3</sup>, [[Jieshu Qian]] <sup>1,3</sup> & [[Bingcai Pan]] <sup>3</sup>

通过断裂强[[碳-氟键|C-F键]]实现[[全氟和多氟烷基物质]]（PFAS）的[[多相催化]]降解，为缓解其对生态系统和人类健康的全球性威胁提供了一种稳健且可持续的途径。然而，当前的[[还原]]或[[氧化]]方法通常仅能实现PFAS的部分降解，生成往往更难降解的短链中间体，从而导致[[脱氟]]效率有限。在本研究中，我们通过将[[MIL-125-NH2(Ti)|MIL-125-NH (Ti)]]封装在[[石墨烯气凝胶]]（[[GA]]）基体中，开发了一种[[纳米限域]][[光催化]]体系。机理研究表明，MIL-125-NH (Ti)/GA复合材料在[[紫外光照射]]下可同时产生还原性[[水合电子]]（e <sup>–</sup>）和氧化性[[羟基自由基]]（HO<sup>•</sup>），从而在单一体系中实现集成的[[级联还原-氧化反应]]。有趣的是，GA的纳米限域效应使对不同链长PFAS的[[吸附|吸附亲和力]]提高了30%以上，并使C-F键能最多降低10.8%。这些[[动力学]]和[[热力学优势]]共同实现了高[[脱氟率]]，即在12小时内，[[全氟辛酸]]（[[PFOA]]）为90.2%，[[全氟己酸]]（PFHxA）为65.3%，[[全氟丁酸]]（PFBA）为51.8%，这些在常规多相催化体系中通常难以达到。我们的研究结果为应对全球PFAS挑战的先进多相体系开辟了途径。

在过去几十年中，[[碳-氟键|C-F键]]固有的[[化学稳定性]]使[[全氟和多氟烷基物质|PFAS]]作为[[全疏性表面活性剂]]在许多工业过程和消费品中得到广泛应用，但不幸的是，其已在全球范围内造成强烈的环境持久性，从地球偏远的北极地区到城市雨水<sup>1,2</sup>。通过[[生物累积]]，即使是低水平的PFAS也可能导致不良健康效应，包括[[肝损伤]]、[[胆固醇升高]]、[[免疫应答]]受损、多种[[癌症]]等<sup>3–5</sup>。近年来，针对高效去除PFAS的物理和化学技术研究兴趣激增<sup>6–14</sup>。其中，化学方法因其旨在通过分解PFAS的分子结构而永久消除PFAS而具有吸引力<sup>7,9</sup>。然而，实现水中PFAS的近乎完全[[脱氟]]仍然具有挑战性，这在很大程度上是因为随着降解进行，中间体的化学势降低而化学[[稳定性]]增加<sup>15</sup>。

当前化学消除策略主要依赖[[氧化]]和[[还原]]<sup>15–23</sup>。氧化方法利用强氧化性物种，如HO<sup>•</sup>和[[硫酸根自由基]] $( { \mathsf { S O } } _ { 4 } ^ { \bullet - } )$ 攻击 [[C-C键|C-C]] 键，从而导致[[链缩短路径]]<sup>17</sup>。一般而言，这些自由基无法有效断裂键能高达 $4 8 5 \mathrm { k J } { \cdot } \mathsf { m o l } ^ { - 1 2 4 }$ . 此外，氟原子周围高电子云密度的强屏蔽效应使得随着链长变短，进一步的C-C断裂更加困难<sup>15</sup>。相比之下，还原方法，例如采用 $\mathsf { U V / s u l f i t e } ^ { 1 6 , 2 1 } , \mathsf { U V / I } ^ { 1 8 , 1 9 }$ ，或者 $\mathrm { U V / i n d o l e ^ { 2 0 , 2 5 } }$ 抱歉，我注意到你的请求信息不完整——初始指令要求翻译“论文 Markdown 正文”，但你实际提供的待翻译内容仅为：

科学家已通过调控催化结构和性质，开发了多种[[多相催化]]体系，以满足目标反应的需求<sup>32–35</sup>。设计将物理富集与顺序[[还原]]和[[氧化]]相结合的多相体系，有望实现高效的 [[全氟和多氟烷基物质|PFAS]] [[脱氟]]，但这类方法目前仍鲜有探索。生物体系通过在限域酶环境中进行反应，表现出优异的效率和选择性<sup>36,37</sup>。特别是，氧化和还原等不相容反应可以通过[[酶活性位点]]的空间分隔和互不干扰的反应路径，以级联方式进行。这一自然策略启发了合成[[级联反应]]体系的开发，以提高效率和选择性<sup>38</sup>。例如，一种[[仿生yolk–shell复合材料|仿生 yolk–shell 复合材料]]在 N 掺杂碳壳中具有原子分散的 $\mathsf { F e } _ { 1 }$ 位点，在 yolk 核中具有 $\mathrm { P d } _ { 1 }$ 位点，可同时催化硝基芳烃加氢和烯烃环氧化反应。该设计可直接利用全水电解原位生成的 ${ \bf O } _ { 2 }$ 和 H，从而以高反应活性和选择性级联合成氨基醇<sup>39</sup>。在另一项研究中，封装在[[层状MOF壳|层状 MOF 壳]]内的多酶体系将[[葡萄糖氧化酶]]和[[辣根过氧化物酶]]在空间上分离，其催化效率比游离酶提高了 5.8 至 13.5 倍<sup>40</sup>。这些进展为设计旨在增强 PFAS 降解和脱氟的限域级联催化体系提供了有益借鉴。

在本研究中，我们通过将 MIL-$1 2 5 \mathrm { \cdot N H } _ { 2 } ( \mathrm { T i } )$ 封装在 [[GA]] 基质中来验证上述概念（图 1a）。此前研究表明，$\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } )$ 在[[紫外光照射]]下可产生[[还原]]性 $\mathbf { e _ { a q } } ^ { }$ 和部分猝灭的 $\mathbf { H O } ^ { \bullet 1 5 }$ <sup>5</sup>。虽然还原和[[氧化]]均参与了 [[全氟和多氟烷基物质|PFAS]] 降解，但在 450 W [[紫外光]]照射 24 h 下，[[PFOA]] 的[[脱氟率]]仍被限制为 66.7%，这在很大程度上是由于反应中间体与[[反应物种|活性物种]]之间的分子碰撞不足。酶催化体系的启示表明，合理设计[[纳米限域]]结构可以从[[动力学]]和[[热力学]]角度富集这些中间体，并调控其与活性物种的反应。有趣的是，所得 $\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { G A }$ 纳米复合材料能够实现纳米限域级联还原–氧化反应，从而高效降解 PFAS 并[[脱氟]]，即在 400 W 紫外光照射 12 h 内，[[全氟辛酸|PFOA]] 完全降解且脱氟率约为 90.2%，显著高于非限域类似物的约 58.4%。该体系在 12 h 内还实现了 [[全氟己酸|PFHxA]] 65.3% 和 [[全氟丁酸|PFBA]] 51.8% 的基准脱氟率。我们的工作为设计[[多相催化]]体系提供了一种策略，即利用纳米限域和[[级联反应]]高效降解含有强于典型 C–C 键的化学键的污染物。

我们进一步利用超高效液相色谱系统联用高分辨率 [[Q Exactive Focus Orbitrap串联质谱仪|Q Exactive Focus Orbitrap 串联质谱仪]]（UHPLC-MS/MS）分析了两个体系中的[[脱氟]]中间体，结果汇总于补充表 4 和补充图 8–12。需要说明的是，在整个 12 h 反应过程中，取样间隔为每 2 h 一次，此处仅描述反应 6 h 时获取的样品结果，因为它们包含了较为全面的典型脱氟中间体。

在 $\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { G A } / \mathsf { U V }$ 体系中，检测到两类中间产物，即一类[[链缩短]]的[[全氟羧酸]]，包括[[全氟庚酸]] $( \mathrm { P F H p A } , n = 7 ) , \mathrm { P F H x A } , n = 6 ,$ [[全氟戊酸]]（PFPeA，n = 5）和 [[全氟丁酸|PFBA]]（n = 4），以及另一类由十二种代表性分子组成、含 6–8 个碳的[[氟调聚羧酸]]（[[含氟调聚羧酸|FTCA]]）。此外，反应结束后我们在体系中加入 [[氢氧化钠|NaOH]]，使产物转化为其钠盐形式再进行检测。在 $\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { G A } ,$ 反应 12 h 后采集的样品中，检测到[[全氟丙酸]]（PFPA，n = 3）和[[三氟乙酸]]（TFA，$n = 2 )$）产物，如补充图 $1 2 ^ { \ 6 4 }$ 所示。这些结果证实了短链酸（如 PFPA/TFA）的形成，若不进行 NaOH 处理，它们最初可能无法被检测到。链缩短的全氟羧酸和 FTCA 的同时检出，表明[[链缩短路径]]与 H/F 交换路径在该体系中共存。

在相同反应时间的 MIL-125-NH（Ti）/UV 体系中，同样可以观察到这两类中间产物。然而，仔细比较发现，[[全氟丁酸|PFBA]] 分子以及十二种 [[含氟调聚羧酸|FTCA]] 中的五种（[[PFOA]]-4H、$\mathsf { C } _ { 5 } \mathsf { F } _ { 1 1 } { \cdot } ( \mathsf { C H } _ { 2 } ) _ { 2 } { \cdot } \mathsf { C O O }$：[[全氟己酸|PFHxA]]-nH $\mathbf { C } _ { 3 } \mathbf { F } _ { 7 } \mathbf { \bar { C } } _ { 2 } \mathbf { H } _ { \mathrm { n } } \mathbf { \cdot C O O } , \ n = 1 \mathbf { \cdot } 4 )$）未被检测到。这些结果证实了[[链缩短路径]]和 H/F 交换路径的存在，但表明其反应进程滞后于[[纳米限域]]体系。需要指出的是，即使反应时间延长至 24 h，$\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { U V }$ 体系的[[脱氟率]]仅提高至 62.5%，且随反应时间进一步延长而不再增加。这一分析得出两条关键信息：其一，[[GA]] 纳米限域加速了 [[全氟辛酸|PFOA]] 的[[脱氟]]，而未改变脱氟机制；其二，[[石墨烯气凝胶|GA]] 纳米限域使得这些在传统非限域多相体系中难以降解的[[链缩短]][[全氟羧酸]]和 [[氟调聚羧酸|FTCA]] 能够进一步脱氟，这一点将在后文所述短链 [[全氟和多氟烷基物质|PFAS]] 降解实验中进一步证实。

上述实验结果揭示了 MIL $. 1 2 5 \small { \cdot } \mathrm { N H } _ { 2 } ( \mathrm { T i } ) / \mathrm { G A } / \mathrm { U V }$ 体系源于 [[纳米限域|GA 纳米限域]]的优异[[脱氟]]性能。要进一步理解 [[GA]] 纳米限域如何影响催化剂与目标污染物尤其是降解中间产物之间的相互作用，需要[[理论计算]]。因此，我们对两个体系中 [[PFOA]] 及其代表性[[链缩短]]中间产物 [[全氟丁酸|PFBA]] 的[[吸附能]]和 C–E [[C-F键解离能|键解离能]]开展了一系列[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算。MIL-$1 2 5 \mathrm { \cdot N H } _ { 2 } ( \mathrm { T i } )$ 簇的结构以及由石墨烯层形成的纳米限域如补充图 13 所示。对于具有 [[石墨烯气凝胶|GA]] 纳米限域的簇结构，纳米限域的尺度依据前述亚纳米模型设定<sup>65</sup>，并通过 DFT 计算进行优化。DFT 计算的细节见[[补充方法|补充方法 2]]。

Supplementary Fig. 14 表明，[[纳米限域|GA 纳米限域]]通过降低目标污染物的[[吸附能]]，显著增强了复合催化剂对目标污染物的[[吸附|吸附亲和力]] $( E _ { \mathrm { a d s } } ) _ { \perp }$，即 [[PFOA]] 从 -3.84 eV 降至 -5.14 eV，[[全氟丁酸|PFBA]] 从 -1.87 eV 降至 -2.59 eV。为验证这一点，在分别处理高浓度（250 mg·L<sup>-1</sup>）[[全氟辛酸|PFOA]]/PFBA 溶液后，对 MIL-$1 2 5 \mathrm { \cdot N H } _ { 2 } ( \mathrm { T i } )$ 和 [[MIL-125-NH2(Ti)|MIL-125-NH (Ti)/GA]] 进行了 [[XPS]] 实验。Supplementary Fig. 15 显示，在吸附 PFOA 或 PFBA 后，MIL-125-NH (Ti)/[[GA]] 样品的 F 1 s 信号明显强于非限域的 MIL-125-NH (Ti) 样品。这些结果表明，从[[动力学]]角度看，[[石墨烯气凝胶|GA]] 纳米限域通过促进目标 [[全氟和多氟烷基物质|PFAS]] 污染物及其[[降解中间体]]的吸附，影响了 PFAS 的[[脱氟]]反应。

Supplementary Figs. 16, 17 中的进一步计算表明，[[纳米限域|GA 纳米限域]]还降低了 [[PFOA]] 和 [[全氟丁酸|PFBA]] 的 [[C-F键解离能|C-F 键解离能]] $( E _ { \mathrm { C \cdot F } } )$。对于 [[全氟辛酸|PFOA]]，$\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } )$ 的[[吸附]]使 $E _ { \mathrm { C - F } }$ 略微降低了 $2 . 5 \cdot 3 . 9$ kcal·mol<sup>-1</sup>。有趣的是，$\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { G A }$ 提供的纳米限域使 $E _ { \mathrm { C - F } }$ 进一步降低了 5.7 - 7.5 kcal·mol<sup>-1</sup>，与非限域体系相比降低了 5.4 - 7.1%。对于 PFBA，[[MIL-125-NH2(Ti)|MIL-125-NH (Ti)]] 对 PFBA 的吸附使 $E _ { \mathrm { C - F } } .$ 降低了 0.6 - 3.3 kcal·mol<sup>-1</sup>。MIL-125-NH (Ti)/[[GA]] 纳米限域使受限域 PFBA 分子的 $E _ { \mathrm { C - F } }$ 更显著地降低了 $7 . 4 \cdot 1 1 . 9$ kcal·mol<sup>-1</sup>，与非限域体系相比降低了 6.8–10.8%。显然，从[[热力学]]角度看，[[石墨烯气凝胶|GA]] 纳米限域还通过促进目标 [[全氟和多氟烷基物质|PFAS]] 污染物及其[[降解中间体]]的 C-F 键断裂，影响了 PFAS 的[[脱氟]]反应。

为进一步证实上述理论结果，我们还研究了不同体系对包括 [[全氟己酸|PFHxA]] 和 [[全氟丁酸|PFBA]] 在内的短链 [[全氟和多氟烷基物质|PFAS]] 的性能，结果见 Supplementary Fig. 18。毫不意外，[[MIL-125-NH2(Ti)|MIL-125-NH (Ti)]]/UV 体系在 12 h 内对 PFHxA 只能实现 22.3% 的[[脱氟率]]，对 PFBA 只能实现 16.6% 的[[脱氟]]率。相比之下，在其余条件相同的情况下，MIL-125-NH (Ti)/[[GA]]/UV 体系对 PFHxA 可实现 65.3% 的脱氟率，对 PFBA 可实现 51.8% 的脱氟率。这些结果对未来的[[多相脱氟]]研究具有启发意义，因为在[[均相体系|多相水相体系]]中，短链 PFAS 的高效脱氟此前鲜有报道。

## Discussion

值得注意的是，开放的$\mathsf { M I L } { \cdot } \mathsf { 1 2 5 } { \cdot } \mathsf { N H _ { 2 } } ( \mathsf { T i } ) / \mathsf { U V }$体系最近已被记载为[[PFOA]]降解的标志性[[非均相体系]]，其[[脱氟]]效率（24 h）与本研究相似，即在450 W[[紫外灯|汞灯]]下为66.7%<sup>15</sup>，而在400 W汞灯下为62.5%。其脱氟机理也得到了详细考察和阐述，即该体系中同时生成了$\mathbf { e _ { a q } } ^ { }$和HO<sup>•</sup>，二者均对[[全氟辛酸|PFOA]]的降解有所贡献，其中${ \bf e _ { a q } } ^ { \phantom { \dagger } }$起主要作用。具体而言，[[MIL-125-NH2(Ti)|MIL-125-NH (Ti)]]在光照下产生e<sup>−</sup>和[[空穴|h⁺]]，其中e<sup>−</sup>进一步溶剂化形成$\mathbf { e _ { a q } } ^ { }$<sup>–</sup>。同时，[[葡萄糖]]可作为牺牲剂对$\boldsymbol { \mathsf { h } } ^ { + }$进行部分猝灭，因为[[金属有机框架|MOF]]的高度多孔结构阻止了完全猝灭<sup>66–68</sup>。剩余的h⁺与${ \sf H } _ { 2 } { \sf O }$作用生成HO<sup>•</sup>。这些结论与本研究的结果一致。

在开放的[[MIL-125-NH2(Ti)|MIL-125-NH (Ti)]]/UV体系降解[[PFOA]]的过程中，同时识别出了[[链缩短]]和H/F交换两条途径<sup>15</sup>。降解始于原有[[全氟辛酸阴离子|PFOA阴离子]]被$\mathbf { e _ { a q } } ^ { }$[[还原]]，生成关键中间体$\mathrm { C _ { 7 } F _ { 1 5 } C O O ^ { \cdot 2 - } \ ( P F O A { \cdot } l e ) }$。在链缩短途径中，[[PFOA-1e]]随后经历[[脱羧]]、[[羟基化]]、消除和水解反应，即所谓的[[DHEH过程]]，形成链缩短的[[全氟羧酸]]（PFCA）产物。在H/F交换途径中，[[全氟辛酸|PFOA]]-1e发生[[自旋中心转移]]，使α位的C–F键断裂，释放F⁻并生成${ \bf C } _ { 6 } { \sf F } _ { 1 3 } { \bf C } { \sf F } ^ { \cdot } { \bf C } { \bf O } { \bf O } ^ { - }$。随后在$\mathbf { C _ { 6 } F _ { 1 3 } C F T O O ^ { - } }$上发生[[加氢反应]]，形成[[氟调聚物]][[PFOA-1H]]。进一步的H/F交换可在PFOA-1H上继续发生，通过类似机理生成氟化程度更低的[[氟调聚羧酸]]（[[含氟调聚羧酸|FTCA]]）。然而，随着H/F交换的进行，[[C-F键解离能|键解离能]]$( E _ { \mathrm { C \cdot F } } )$逐渐增大，使得进一步发生H/F交换变得越来越困难。这解释了为什么在此前研究和本研究中均未观察到氢取代数大于四的氟调聚物中间体。在这两条途径进行的过程中，HO<sup>•</sup>的作用被认为是通过从C–H键中夺取H，将FTCA转化为不饱和中间体，这些中间体随后经历进一步断裂反应，生成缩短的$\mathsf { P F C A } ^ { 2 9 }$。因此，${ \bf e _ { a q } } ^ { - }$和HO<sup>•</sup>这两种[[反应物种|活性物种]]对于PFOA及其他PFCA中间体的高效链缩短都至关重要。

尽管如此，使用传统开放体系实现[[PFOA]]的[[脱氟率]]超过70%仍然具有挑战性，即使这些体系能够同时产生[[还原]]性和[[氧化]]性物种。此外，[[非均相体系]]对碳链更短的[[全氟和多氟烷基物质]]（PFAS）的高效[[脱氟]]也鲜有报道。可能存在以下几个原因：（1）[[链缩短]]的[[全氟羧酸]]（PFCA）和[[氟调聚羧酸]]（[[含氟调聚羧酸|FTCA]]）在化学上比[[全氟辛酸|PFOA]]更稳定，因此中间体的进一步脱氟在[[热力学]]上变得更加困难；（2）链缩短的PFCA具有更高的亲水性，因此它们更倾向于留在溶液中，而不是靠近[[反应物种]]集中的非均相催化剂附近<sup>32</sup>，这使得进一步降解在[[动力学]]上也更加困难；（3）尽管${ \bf e _ { a q } }$<sup>–</sup>和HO<sup>•</sup>活性物种对降解反应有所贡献，但它们也可能相互反应，即发生[[自猝灭]]，从而降低脱氟反应的效率。

有趣的是，[[纳米限域]]的 [[MIL-125-NH2(Ti)|MIL-125-NH (Ti)/GA]]/UV 体系在 12 h 内对 [[PFOA]] 的基准[[脱氟率]]为 90.2%，对 [[全氟己酸|PFHxA]] 为 65.3%，对 [[全氟丁酸|PFBA]] 为 51.8%（补充图 18）。这些数值不仅远高于其非限域类似体系，而且代表了多相体系中目前最先进的[[脱氟]]效率。基于 [[GA]] 纳米限域并未改变降解路径这一事实以及上述实验和理论结果，我们提出了以下原因来解释该纳米限域体系脱氟效率显著提升的机制。首先，[[石墨烯气凝胶|GA]] 基底增强了复合催化剂的[[光电化学性能]]，从而为后续目标反应产生更多[[反应物种|活性物种]]。其次，纳米限域使得 [[全氟辛酸|PFOA]] 及其[[降解中间体]]（即[[链缩短]]的 [[全氟羧酸|PFCA]] 和 [[含氟调聚羧酸|FTCA]]）得以富集，而这些物质通常难以被约束在催化剂附近。这种富集既通过[[空间限域]]实现，也通过将这些分子的[[吸附能]]降低 30% 以上来实现，从而为进一步的降解反应提供了[[动力学优势]]。第三，纳米限域还通过将 PFOA、尤其是其降解中间体的 [[C-F键解离能|C-F 键解离能]]最多降低 10.8%，为反应提供了[[热力学优势]]。第四，纳米限域引起的污染物富集比活性物种的富集具有更积极的影响，从而使目标污染物与活性物种之间的反应相对于[[自猝灭]]反应获得了显著的[[动力学]]优势。因此，由于活性物种自猝灭而造成的脱氟效率损失应得到缓解。上述原因的组合与相互作用为纳米限域下的脱氟反应创造了有利条件。开放体系与纳米限域体系中 PFOA 降解过程的对比见图 5。

[[纳米限域|GA 纳米限域]]对不同链长 [[全氟和多氟烷基物质|PFAS]] 降解和[[脱氟]]的增强也可归因于物理和化学因素的共同作用。从物理角度看，纳米限域促进了 PFAS 及其[[降解中间体]]的富集，这一点得到了图 3a、补充图 14 和 15 中[[吸附动力学]]、[[XPS]] F 1s 以及 [[DFT]] [[吸附能]]计算实验结果的支撑。这种富集为目标污染物与[[反应物种|活性物种]]之间的反应提供了显著的[[动力学优势]]。从化学角度看，一方面，[[GA]] 通过促进活性物种（如 ${ \bf e _ { a q } } ^ { - }$ ）的生成来增强 [[金属有机框架|MOF]] [[光催化]]作用，这一点由图 3d、e 和图 4a–d 中的[[光电化学表征]]和 [[电子顺磁共振|EPR]] 结果所证明。另一方面，[[石墨烯气凝胶|GA]] 纳米限域通过降低 [[C-F键解离能|C-F 键解离能]]为脱氟反应引入了关键的[[热力学优势]]，这一点由补充图 16、17 中的 [[密度泛函理论|DFT]] 计算所揭示。总体而言，GA 纳米限域在物理和化学两个方面都对脱氟反应带来了根本性改变。

总之，我们通过[[纳米限域]]下的[[级联反应]]（即顺序进行的[[还原]]与[[氧化]]反应）完成了概念验证，从[[动力学]]和[[热力学]]两方面调控 [[全氟和多氟烷基物质|PFAS]] 的降解。所得纳米限域体系实现了 PFAS 的高效[[脱氟]]降解，12 h 内 [[PFOA]] 的 [[deF%]] 约为 90.2%，[[全氟己酸|PFHxA]] 为 65.3%，[[全氟丁酸|PFBA]] 为 51.8%。此外，该体系在[[循环催化|循环催化反应]]中表现出良好的[[可重复使用性]]和[[稳定性]]（补充图 19），并在弱酸性条件下具有良好的 [[pH适应性|pH 适应性]]（补充图 20）。我们认为，本研究通过动力学和热力学因素的调控，为有效降解和脱氟 PFAS 的[[多相催化]]体系提供了一种概念性设计。我们希望未来能有更多研究以纳米限域为策略，实现用于高效[[水体修复]]的级联反应。

## 方法

## 化学品与材料

[[氧化石墨烯|单层氧化石墨烯]]（GO）粉末样品（> 99 wt.%，厚度 0.5 - 3.0 nm）购自[[苏州碳丰石墨烯科技有限公司]]（中国）。[[2-氨基对苯二甲酸]]（H ATA）、[[PFOA]] 购自[[上海麦克林生化科技有限公司]]（中国）。[[钛酸四异丙酯]] $\mathrm { ( C _ { 1 2 } H _ { 2 8 } O _ { 4 } T i ) }$ 、[[乙醇|EtOH]]、[[甲醇|MeOH]]、[[葡萄糖]] $\mathrm { ( C _ { 6 } H _ { 1 2 } O _ { 6 } ) }$ 、[[NBT]]、[[硫酸钠]] $( \mathsf { N a } _ { 2 } \mathsf { S O } _ { 4 } )$ 和[[氢氧化钠]]（NaOH）购自[[阿拉丁工业公司]]（中国）。[[乙二胺]]（EDA）、[[N,N-二甲基甲酰胺|N, N-二甲基甲酰胺]]（DMF）、[[高氯酸]]、[[硝酸]] $\left( \mathsf { H N O } _ { 3 } \right)$ 和[[盐酸]]（HCl）购自[[国药集团化学试剂有限公司]]（中国）。[[5,5-二甲基-1-吡咯啉 N-氧化物|DMPO]] 购自[[默克生命科学技术有限公司]]。所有试剂均为分析纯，未经进一步纯化直接使用。本研究中的所有溶液均使用[[超纯水]]（18.2 MΩ·cm）配制，超纯水由净化系统（UPT-II-10T，[[Ulupure]]，中国）制备。

## 催化剂制备

[[GA]] 基底按照此前报道的方法通过一步[[还原]]制备<sup>69</sup>。在典型合成中，将 60 mg [[氧化石墨烯|GO]] 和 0.06 mL [[乙二胺|EDA]] 加入 20 mL [[超纯水]]中，超声处理 30 min 后，在 100 mL [[聚四氟乙烯内衬高压釜]]中于 180°C [[水热处理]] 5 h。冷却至室温后，得到[[水凝胶]]，并将其浸泡于 15% [[乙醇|EtOH]] 溶液中 24 h 以去除残留前驱体。[[冷冻干燥]] 24 h 后得到 [[石墨烯气凝胶|GA]]。

$\mathsf { M I L } { \cdot } 1 2 5 { \cdot } \mathsf { N H } _ { 2 } ( \mathsf { T i } ) / \mathsf { G A }$ 的制备按照此前报道的水热法进行<sup>58</sup>。通常，将 6.0 mmol [[2-氨基对苯二甲酸]]和 3.0 mmol [[钛酸四异丙酯]]加入 [[N,N-二甲基甲酰胺|DMF]]（25 mL）与 [[甲醇|MeOH]]（25 mL）的混合溶液中，随后加入 60 mg [[GA]]。混合物在环境条件下搅拌 60 min，然后转移至 100 mL [[聚四氟乙烯内衬高压釜]]中。在 $1 5 0 ^ { \circ } \mathrm { C }$ 下加热 24 h 并冷却至室温后，样品分别用 DMF 和 MeOH 洗涤三次。[[冷冻干燥]] 24 h 后，得到 [[MIL-125-NH2(Ti)|MIL-125-NH (Ti)/GA]] 样品。作为对比，MIL-125-NH (Ti) 样品按照相同过程制备，但不加入 [[石墨烯气凝胶|GA]]。

## [[催化脱氟实验]]

本研究中所有催化实验均至少重复三次，并报告带有标准偏差作为[[误差棒]]的平均值。催化实验在配备 8 个[[石英烧杯]]（100 mL）的 [[GHX-V反应器|GHX-V 反应器]]（[[Jiapeng Technology]]，上海，中国）中，于[[紫外灯|高压汞灯]]（400 W）照射下进行。灯与石英烧杯之间的距离为 5 cm。在典型的催化实验中，将 50 mL 含有 $2 . 5 \mathrm { g } { \cdot } \mathrm { L } ^ { \cdot 1 }$ 催化剂和不同量[[葡萄糖]]的 1.0 mg·L<sup>-1</sup> [[PFOA]] 水溶液在黑暗中搅拌 60 min，以达到[[吸附-脱附平衡]]。葡萄糖浓度分别变化为 0.05、0.1、0.2 和 0.5 M。随后，在室温下开启[[紫外光]]源以启动催化反应，初始 [[pH]] 为 5.0，并通过 ${ \mathsf { H N O } } _ { 3 }$ 或 [[氢氧化钠|NaOH]] 溶液进行调节。在整个反应期间，溶液的 pH 维持在 5.0 - 6.5 范围内。所有[[光催化]]降解反应均在环境空气条件下进行，未预先除氧，且均在[[水相]]中进行。
