# [[聚乙烯亚胺功能化纤维素微晶]]在环境相关条件下快速去除[[全氟和多氟烷基物质|多氟和全氟烷基物质]]

摘要：[[全氟和多氟烷基物质]]（PFAS）广泛存在于许多消费品中，其[[环境持久性|持久性]]给环境带来了严峻挑战。目前，常规[[水处理]]方法无法去除 PFAS，而其他新提出的材料/技术在实际条件下应用时也面临挑战。本研究报道了[[聚乙烯亚胺功能化纤维素微晶]]（[[聚乙烯亚胺|PEI]]-f-[[纤维素微晶|CMC]]），该材料在与 PFAS 在自然环境中实际[[环境赋存|赋存]]水平相关的浓度（即 <1000 ng/L）下，表现出近乎瞬时且高效的 PFAS 去除能力。在湖水以及共同投加了另外两种[[天然有机质]]的溶液中，证实了 PEI-f-[[羧甲基纤维素|CMC]] 对不同类别的 22 种 PFAS（即传统羧酸类和[[全氟烷基磺酸类|磺酸类 PFAS]]、新兴羧酸类和磺酸类 PFAS，以及 [[PFAS前体|PFAS 前体]]）的选择性去除效能。在连续八次用于去除 PFAS 的[[吸附]]/再生循环中，PEI-f-CMC 的性能得以保持。PEI-f-CMC 对 PFAS 具有独特的快速[[吸附动力学]]和高[[吸附活性]]，展现出作为 PFAS 控制替代[[吸附剂]]的巨大应用潜力。

## ■ 引言

[[全氟和多氟烷基物质|多氟和全氟烷基物质]]（PFAS）是一大类有机化合物，在过去七十年中被广泛用作[[含氟聚合物]]生产过程中的[[加工助剂]]，以及消费品应用中的[[表面活性剂]]（例如纺织品、家具和纸制品的[[表面涂层]]）。<sup>1−3</sup> 这些化合物的分子结构具有一条（或多条）[[脂肪链]]，其中全部（即全氟）或部分（即多氟）氢原子被氟原子取代，使其至少含有一个[[全氟烷基]]结构单元 $\left( \mathbf { C } _ { n } \mathbf { F } _ { 2 n + 1 } \right)$。近年来，PFAS 在水环境中的[[环境赋存|赋存]]、[[环境归趋|归趋]]和去除已被文献报道为一个关键的新兴环境问题。<sup>4−7</sup> 因此，[[美国环境保护署]]发布了[[饮用水]]中[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（[[全氟辛烷磺酸盐|PFOS]]）合计浓度为 70 ng/L 的[[饮用水健康建议值|健康建议值]]。<sup>8</sup> 然而，[[氯代多氟醚磺酸盐]]（F53B）和 [[ADONA]] 等新兴 PFAS 作为含氟[[聚合物]]工业中 PFOS 和 PFOA 的含氟替代品，如今在环境中被检出的频率正不断增加。<sup>9</sup>

研究最多的 [[全氟和多氟烷基物质|PFAS]] 去除技术是在不同[[碳质材料]]（例如，[[颗粒活性炭]]（GAC）、[[粉末活性炭]]（PAC）和[[碳纳米管]]（CNT））及[[阴离子交换树脂]]（AIX）上的[[吸附]]（例如，Merino 等人，<sup>10</sup> Du 等人<sup>11</sup>及其中的参考文献），因为这些技术操作简单且能耗极低。PFAS 吸附的两种主要机制是[[疏水相互作用]]和[[静电相互作用]]。11 因此，淡水中共存的[[天然有机质]]（NOM）已被证明会对 PFAS 的[[吸附效率]]产生不利影响。<sup>12−14</sup>因此，开发具有高亲和力并能快速去除 PFAS 的[[选择性吸附剂]]，对于克服这一新兴环境与健康问题至关重要。

[[纤维素]]价格低廉、可再生、环境友好，是自然界中含量最丰富的[[聚合物]]。<sup>15</sup>[[功能化纤维素微晶]]（[[纤维素微晶|CMC]]）已被用于去除各类水中污染物（例如，金属、染料、有机物、[[无机阴离子]]和[[放射性核素]]）的试验。<sup>16</sup>在这些[[功能化基团]]中，[[聚乙烯亚胺]]（PEI）由于具有大量可在较宽 [[pH]] 范围内轻易[[质子化]]的[[伯胺]]和[[仲胺]]位点，<sup>21</sup>在[[吸附]][[重金属]]、<sup>17</sup>[[阴离子染料]]<sup>18</sup>和[[挥发性有机化合物]]<sup>19,20</sup>方面表现优异。在本研究中，我们探索了[[聚乙烯亚胺功能化纤维素微晶]]（PEI-f-[[羧甲基纤维素|CMC]]，示意图 S1）对 [[全氟和多氟烷基物质|PFAS]] 的快速、选择性捕获，其浓度与天然水体中的实际[[环境赋存|赋存]]浓度相当。

## ■ 材料与方法

## ■ 结果与讨论

当 [[全氟辛酸|PFOA]] 初始浓度为 1 μg/L 时，[[聚乙烯亚胺功能化纤维素微晶|PEI-f-CMC]] 几乎可瞬时去除 PFOA，并在约 15 min 内达到[[吸附平衡]]，仅在最初的 100 s 内[[去除率]]就达到 70−80%（图 1）。当 PFOA 初始浓度升高至 100 μg/L 时，也观察到了类似趋势（[[吸附平衡时间|平衡时间]] = 20−25 min）。相比之下，据报道，当初始浓度处于 $5 { - } 5 0 0 0 ~ \mu \mathrm { g / L . } ^ { 2 3 , 2 4 }$ 范围内时，PFOA 和 [[全氟辛烷磺酸|PFOS]] 在 [[颗粒活性炭|GAC]] [[Calgon Filtersorb300]]（F300）和 [[Calgon Filtersorb400]]（F400）上的[[吸附]]在 5−30 d 后达到平衡。GAC 对 [[全氟和多氟烷基物质|PFAS]] 的缓慢去除归因于其微孔特性（即[[孔径]] < 2 nm）。近期，Xiao 等人<sup>25</sup>报道了在低 PFOA 浓度条件下使用 [[β-环糊精聚合物]]选择性去除 PFOA $( \mathrm { [ P F O A ] _ { i } } = \mathrm { i } ^ { - } \mu \mathrm { g / L } )$ ）。然而，其缺点之一是在低初始浓度下去除缓慢，1 h 后 PFOA 去除率仅为 $1 1 \pm 1 0 \%$，平衡时间为 15−24 h。尽管其他研究报道的吸附平衡时间小于 48 h，但这些研究未纳入比较，因为其采用的 PFAS 初始浓度为每升数百毫克，是环境相关浓度的 $1 ~ \times ~ 1 0 ^ { 5 }$ 至 $1 \ \times \ 1 0 ^ { 7 }$ 倍。

无论背景水体组成如何，[[全氟和多氟烷基物质|PFAS]] 在 [[聚乙烯亚胺功能化纤维素微晶|PEI-f-CMC]] 上的[[吸附]]均呈现出两种一致的趋势。首先，PFAS 的[[去除效率]]与其[[碳链长度|链长]]呈正相关 $( \mathrm { C } = 4 { - } 1 2 )$。其次，[[全氟烷基磺酸类|磺酸类 PFAS]]（PFSA）的[[去除率|去除效率]]高于相同链长的[[全氟烷基羧酸类|羧酸类 PFAS]]（PFCA）。在 PFAS 于 $\mathrm { G A C } , ^ { 2 9 }$ 氟化石墨烯片层<sup>34</sup>和[[金属有机框架|金属−有机框架]]<sup>35</sup>上的吸附中，也观察到了类似趋势。此外，还观察到多氟化合物（如 4:2 FTS 和 6:2 FTS）的去除效率高于相同链长的[[全氟化合物]]（图 3）。近期一项关于 [[颗粒活性炭|GAC]] 去除不同类别 PFAS 的研究也报告，多氟化合物的去除率高于具有相同碳原子数的全氟化合物。<sup>36</sup> 因此，未来研究应阐明这一现象的影响因素。

[[吸附剂]]的再生性能是实际应用中的重要考量因素之一。<sup>37,38</sup> 本研究将 [[聚乙烯亚胺功能化纤维素微晶|PEI-f-CMC]]（50 mg）与 50 mL [[全氟辛酸|PFOA]] 溶液（1 g/L）混合 2 h。随后，通过离心（10 000 rpm）收集使用后的[[吸附]]剂，并在 50 mL 甲醇中进行 PFOA 解吸。在连续八次去除 PFOA 的吸附/解吸循环中，[[聚乙烯亚胺|PEI]]-f-[[纤维素微晶|CMC]] 的性能保持稳定（图 4）。这些结果表明，PEI-f-[[羧甲基纤维素|CMC]] 易于再生且再生能力强，是一种具有应用前景的 [[全氟和多氟烷基物质|PFAS]] 吸附剂。
