# 题目：用于无短链和[[短链全氟和多氟烷基物质|超短链PFAS]]饮用水的[[沸石]][[动态羟基循环]]

摘要：[[全氟和多氟烷基物质]]（PFAS）危机正向（超）短链同系物转移，这凸显了设计具有[[亲水性|亲水功能]][[吸附]]剂的紧迫性。然而，当前的官能团固定化改性方法难以兼顾效率与[[再生]]性能，限制了人们获取经济实惠的无（超）短链PFAS饮用水。在此，我们提出一种非固定化的[[动态羟基循环]]策略，仅利用水循环驱动[[沸石|商用沸石]]的吸附—再生过程，从而高效且可持续地从饮用水中去除多种（超）短链PFAS（C-F数目：1–6）。增强的[[纳米孔]]可及性以及“[[限域水|沸石骨架限域水]]”双结合模式的形成，使该改性沸石成为已报道的容量最高的吸附剂之一 $( 2 3 3 . 8 2 \mathrm { - } 7 3 3 . 1 3 \mathrm { m g } \mathrm { g } ^ { - 1 } )$ 。值得注意的是，该方法为现有[[全规模家用净水器|净水器]]提供了一种潜在的低成本原位升级路径，有望通过179天的全规模净化，为欠发达地区提供健康饮用水。

## 引言

[[全氟和多氟烷基物质]]（PFASs），常被称为“[[永久性化学品]]”，在各个领域被广泛使用，使其在日常生活中无处不在<sup>1</sup>。PFASs 在环境中的持续累积，加上越来越多的证据表明即使在超痕量暴露水平下也会对人体产生有害影响，促使[[欧洲议会和理事会]]（EPC）于 2021 年将饮用水中所有 PFASs 的最高限值设定为 500 ng L<sup>-1</sup><sup>2,3</sup>。尽管传统长链 PFASs（链长 > 7），例如[[全氟辛酸]]（PFOA），近年来已被逐步淘汰，但超短链 PFASs（链长 < 4）和短链 PFASs（链长 = 4–7）已取而代之，目前在饮用水中占据主导地位<sup>4-6</sup>。然而，越来越多的证据表明，（超）短链 PFASs 可能表现出与长链 PFASs 相似甚至更强的生物毒性<sup>5,7</sup>。更严峻的现实是，传统水处理方法（如[[混凝]]和[[高级氧化]]）无法有效去除（超）短链 PFASs，导致人们在不知不觉中通过自来水暴露于超过安全限值的 PFAS 水平<sup>4,5</sup>。因此，迫切需要在用水终端采用先进的水净化技术（如[[反渗透]]）。然而，即使在发达国家，也只有约 40% 的人口能够负担这些昂贵的解决方案<sup>8</sup>。

[[吸附|吸附过程]]通过固液传质方法为去除 [[全氟和多氟烷基物质|PFASs]] 提供了一种经济有效的手段，从而能够实现经济可行的饮用水终端净化。然而，吸附技术在净化（超）短链 PFASs 方面仍面临重大局限：1）传统[[疏水相互作用|疏水传质机制]]导致吸附剂对[[亲水性]]（超）短链 PFASs 的吸附亲和力随链长缩短而显著下降，从而造成去除效率降低甚至为负<sup>4,9</sup>。为解决这一问题，当前方法侧重于接枝亲水性官能团（如 -OH 或 -NH2）<sup>10,11</sup>。但这又引入了第二个局限：2）亲水性官能团容易降解，在 PFAS 吸附剂的后处理（如[[煅烧|热处理]]）过程中失活。尽管已付出大量努力，目前提出的方案往往只能在效率（如 [[β-环糊精聚合物]]、[[中空共价有机框架]]、[[磁性氟化聚合物]]和[[金属有机框架]]）或可重复使用性（如[[电化学]]和[[微波]]）其中一方面进行优化<sup>10-17</sup>，从而导致整个吸附-[[再生]]生命周期成本增加。因此，提供经济实惠的无（超）短链 PFASs 饮用水的关键在于解决吸附效率与可重复使用性之间固有的权衡矛盾。

我们提出一种基于[[沸石|商业沸石]]中[[动态羟基循环]]的非固定化改性策略，用于(超)短链[[全氟和多氟烷基物质|PFASs]]的[[吸附]]与[[再生]]。与替代性增强策略不同，本文所描述的方法仅需在传统吸附-再生过程中引入一种无需试剂、低成本的[[水蒸气扩散技术]]，即可在多种商业沸石中实现[[Si-OH]]和[[限域水]]-羟基网络的动态循环（图1a和1b）。该非固定化策略有效改善了(超)短链PFASs在[[纳米孔|纳米孔道]]内的传质过程，并建立了“沸石骨架-限域水”双结合模式，从而实现了目前报道的最高吸附容量和稳定的循环利用性能。更重要的是，该方案可直接用于实际饮用水中(超)短链PFASs的净化，并通过一台[[全规模家用净水器|全尺寸家用净水器]]在182天内得到验证。

## 结果

## [[动态羟基循环]]过程的设计

设计动态[[吸附|吸附过程]]的重大挑战在于确定一种能够兼顾效率与可重复使用性的非固定化增强介质。高效率要求提供特异性结合位点，使吸附剂能够在复杂环境体系中捕集浓度低至百亿分之一的(超)短链[[全氟和多氟烷基物质|PFASs]]。同时，适当的可重复使用性使增强介质能够通过非化学键与吸附剂结合，便于功能化与[[再生|去功能化]]的循环，同时保持结构稳定性。

[[沸石]]作为一种常用[[吸附]]剂，通过其Si-O骨架对[[全氟和多氟烷基物质|PFASs]]的[[C-F链]]产生[[疏水相互作用|疏水作用]]，但缺乏亲水作用模式<sup>18</sup>。能够满足上述要求且与沸石骨架相容的最有前景的增强介质之一，是[[限域水]]。由于表面张力作用，液态水分子需要超过80 MPa的压力才能进入[[纳米孔|疏水性纳米孔道]]，从而在沸石内形成空腔<sup>19</sup>。然而，如果水分子通过界面相互作用预先限域在沸石纳米孔道内，它们便有可能形成非固定化亲水位点，用于(超)短链PFAS的特异性原位结合<sup>20</sup>。此外，限域水与纳米孔壁之间为非化学键结合，可仅用水通过扩散和[[煅烧|热处理]]过程实现绿色、低成本的循环功能化与[[再生|去功能化]]。基于这一概念，我们设计了一种利用[[动态羟基循环]]的吸附-再生方案。该过程包括将水蒸气扩散引入传统吸附-热“构建-利用-去除”[[动态羟基循环机制|动态羟基循环]]之中（图1a和1b）。

为验证[[动态羟基循环机制|动态羟基循环方案]]的可行性并确定最优[[沸石]]基底，我们考察了一系列孔径（0.52–1.12 nm）和表面[[亲水性]]（Si/Al 比：25–600，补充图 1 和表 1）系统性变化的商用沸石，在[[动态羟基循环]]中对 9 种[[全氟和多氟烷基物质|（超）短链 PFAS]]（C-F 数 = 1–6，补充表 2）的[[吸附|吸附效率]]。值得注意的是，我们观察到所有商用沸石的去除效率均有所提高（4%–88%→31%–100%），证实了动态羟基循环策略的广泛适用性（图 1c）。在所测试的沸石中，具有适中孔径（0.56–0.74 nm，[[BEA晶体|BEA 晶体]]）和高疏水性（Si/Al 比 ≥ 200）的沸石对所有[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 均实现了最优去除效率（> 61%）。这些结果验证了动态羟基循环可提高吸附效率的基本假设。

## [[动态羟基循环]]过程的演示

基于最优的 [[沸石|β200 沸石]]（[[BEA晶体|BEA 晶体]]，Si/Al 比 = 200），我们进一步阐明了[[动态羟基循环|羟基“构建–利用–去除”循环]]过程中结构修饰和[[吸附]]性能的变化。首先，我们对原始 β200 进行[[煅烧|热处理]]，以模拟[[再生]]沸石（D-β200）的结构。在 $8 0 0 ^ { \circ } \mathrm { C } .$ 下煅烧后，D-β200 沸石[[傅里叶变换红外光谱|红外光谱]]中的 [[Si-OH]] 特征峰 $( 9 5 4 ~ \mathrm { { \ c m ^ { - 1 } } ) }$ 消失，表明高温诱导了邻位羟基缩合（图 2a 和补充图 3），并降低了表面极性（[[Zeta电位|ζ 电位]]：-43.3 mV→-16.6 mV，补充图 2）。尽管发生了这些变化，D-β200 仍保留了完好的 [[Si-O-Si]] 骨架 $( 1 0 8 2 \mathrm { c m } ^ { - 1 } \mathrm { a n d } 8 0 0 \mathrm { c m } ^ { - 1 } )$ 1，并在热处理条件下仍保持其 [[X射线衍射|X 射线衍射]]晶面（图 2b）。D-β200 的[[透射电子显微镜|高分辨透射电子显微镜]]图像和孔径分析证实，其颗粒形貌和微孔结构均得以保留（1.894 nm 对比 1.971 nm，图 2c 和补充表 3）。

为了构建羟基基团，将 D-[[沸石|β200]] 置于高湿度（90%-100%）环境中以制备 [[S-D-β200]]，通过[[水蒸气扩散技术|蒸汽扩散法]]促进[[受限水|受限水结构]]的自组装。该构建过程后，S-D-β200 的[[傅里叶变换红外光谱|红外光谱]]中出现了[[限域水|受限水氢键网络]] $( 3 7 5 0 \ \mathrm { c m } ^ { - 1 } { - } 3 0 0 0 \ \mathrm { c m } ^ { - 1 } )$ 和 [[Si-OH]]（954 cm<sup>-1</sup>）的特征峰，为受限水的成功负载及不稳定 [[Si-O-Si]] 键的再水合提供了证据（[[Zeta电位|ζ 电位]]：-16.6 mV→-41.6 mV，补充图 2 和 3）。这些结果表明，水蒸气封装形成了受限水 β200 [[纳米孔]]，并通过水分子的化学转移实现了沸石表面[[亲水性]]/疏水性（Si-OH 和 Si-O-Si）的有序调控（补充图 3）。水平衡控制（W-β200，图 2a）未显示特征峰，表明水分子被限制在纳米孔内而未附着于表面。进一步采用 $2 \mathrm { D } ^ { 1 } \mathrm { H } \mathrm { - } ^ { 1 } \mathrm { H }$ 单/双量子[[魔角旋转核磁共振|魔角旋转（MAS）核磁共振（NMR）波谱]]研究了受限水[[氢键|氢键网络]]及其结合 $\mathrm { s t a t e } ^ { 2 1 }$。在 S-D-β200 中，受限水表现为通道内的水分子链（δ=1.04 ppm）和交叉处的水簇（δ=5.54 ppm），并与 Si-OH（δ=2.13 ppm）和 Al-OH（δ=1.73 ppm、7.72 ppm）基团相互作用 $( \mathrm { F i g . } 2 \mathrm { d } ) ^ { 2 2 }$。在质子-质子邻近性方面，仅水簇表现出对角峰（11.08，5.54），而涉及其他质子的相互作用则表现为非对角峰（(6.58，5.54)；(7.27，5.54)；(7.67，5.54)）。这些结果证实，受限水以非固定方式修饰了沸石空腔环境，并在通道交叉处形成了水簇的亲水中心（补充图 4）。

非固定化[[限域水|受限水氢键网络]]的成功构建促使我们对 [[S-D-β200]] 进行[[吸附|吸附效率]]测试。S-D-[[沸石|β200]] 对所有[[全氟和多氟烷基物质|（超）短链 PFAS]] 均表现出快速、不可逆的吸附，2 小时内达到平衡（补充图 5）。与原始 β200 相比，我们同时观察到平衡吸附容量的增加和吸附速率的降低（补充表 4），表明在限速步骤中发生了增强吸附行为，例如[[颗粒内扩散]]<sup>23</sup>。S-D-β200 对所有[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 的最大吸附容量是 β200 的 1.41–2.26 倍（补充图 6 和表 5），表明可利用吸附位点有所增加。S-D-β200 中的羟基（[[受限水]]和 [[Si-OH]]）对于提供结合位点至关重要（补充图 7），其中受限水团簇提供了更多吸附位点，以选择性地结合 PFAS 的亲水头基，导致去离子化（δ=9.00 ppm，（14.98，5.98））和部分水合 [[Brönsted酸位点|Brönsted 酸位点]]的重新暴露（δ=2.91 ppm，图 2e）<sup>22</sup>。同时，受限水的屏蔽效应也有助于削弱（超）短链 PFAS 与 S-D-β200 之间的[[静电排斥]]，以及其他 $\mathrm { P F A S s } ^ { 2 4 }$ 。值得注意的是，S-D-β200 的吸附容量超过了当前报道的最优吸附剂（图 2f 和补充表 6），例如 [[NU-1000]]<sup>25</sup>，并且与最新的电辅助吸附材料（即 P(A)、P(A98F2) 和 P(A39T53F8)）相比，显示出比较优势（例如制备成本和能耗）<sup>26</sup>。此外，S-D-β200 在暴露于模拟环境水样（[[腐殖酸]]=2 mg L<sup>-1</sup>，NaCl=20 mg L<sup>-1</sup>）时，对（超）短链 PFAS（20 μg L<sup>-1</sup>）表现出适当的选择性，仅下降 0%–10.9%（补充图 8），表明其具有实际应用潜力。

为启动下一个[[动态羟基循环|羟基循环]]并降解 [[全氟和多氟烷基物质|PFAS]]，饱和的 [[S-D-β200]] 在 $8 0 0 ~ ^ { \circ } \mathrm { C } .$ 再次通过[[煅烧|热处理]]进行煅烧。使用模拟环境水样（[[腐殖酸]]=2 mg L<sup>-1</sup>，NaCl=20 mg L<sup>-1</sup>）进行了四次完整的[[动态羟基循环机制|动态羟基循环]]，S-D-[[沸石|β200]] 对[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 的[[吸附|吸附容量]]恢复了 94.3%–101.3%（补充图 9）。这些结果表明，高温（800 ℃）煅烧可有效去除[[受限水]]和 [[Si-OH]] 的羟基（图 2a 和补充图 2），同时完全降解 PFAS<sup>27</sup>，从而打破环境中持久性 PFAS 的循环。此外，循环后进一步确认了 β200 的 [[Si-O-Si]] 骨架稳定性、[[XRD]] 晶面和孔结构（图 2a、2b 和补充表 3），而[[BET|比表面积]]略有增加（12.5%）则促进了吸附容量的提升。

综上所述，所提出的循环[[吸附|吸附-再生]]方案能够动态调控[[受限水]]的[[氢键|氢键网络]]，并通过非固定化组合策略解决了效率与可重复使用性之间的固有矛盾。除已展示的最优结构（即 [[沸石|β200]]）外，其他具有不同孔径和表面[[亲水性]]的沸石在该过程中也表现出类似的[[动态羟基循环]]（补充图 10），这为实施[[动态羟基循环机制|动态羟基循环]]策略并应对更复杂的污染问题提供了更广泛的可能性。

## 增强[[吸附]]机制

[[S-D-β200]] [[吸附|吸附容量]]的提高主要归因于[[受限水|受限水结构]]的引入，如前一节所详述。为进一步阐明[[限域水|受限水]]吸附行为，我们构建了具有 BEA 结构（Si/Al 比：200）的“体相水-受限水-[[沸石]]”三相全原子模型。该模型使我们能够展示在有无受限水条件下循环吸附前后的结构差异（补充图 11）。我们量化了[[全氟和多氟烷基物质|（超）短链 PFAS]] 从体相水进入 β200 和 S-D-β200 直通道的[[吸附自由能]]（即[[平均力势]]，PMF）<sup>21</sup>，揭示了传质能量景观中的特征性两阶段转变（图 3a、3b 及补充图 12-15）。阶段（1）涉及 PFAS 分子在沸石上的表面吸附固定，其中[[疏水相互作用]]驱动 [[C-F链|C-F 链]]转移至沸石骨架上（窗口 #10 至 #3）。在此阶段，[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 的吸附自由能显著下降（例如，β200 中[[全氟庚酸]]（PFHpA）为 -10.70 kcal mol<sup>-</sup> <sup>1</sup> → -26.14 kcal mol<sup>-1</sup>，图 3a），而[[亲水性]]同系物（例如[[三氟乙酸]]（TFA））从该过程中获益较少（图 3c）。阶段（2）涉及（超）短链 PFAS 经历孔道扩散过程，在此过程中 C-F 链沿通道进一步前进，而亲水头端仍暴露于水中（窗口 #3 至 #0）。与第一阶段不同，沸石骨架与（超）短链 PFAS 之间相互作用所获得的能量不足以抵消显著的[[脱水惩罚]]（例如，PFHpA 为 23.72 至 3.81，补充图 16），导致[[纳米孔|纳米通道]]内的非自发扩散（例如，β200 中 PFHpA 为 -26.14 kcal mol<sup>-1</sup> → 0 kcal mol<sup>-1</sup>）。有趣的是，（超）短链 PFAS 链长所诱导的孔吸附能垒在不同范围内表现出明显差异（图 3c）；例如，当链长增加（链长 ≥ 4）时，相互作用能随之升高（即[[全氟丁烷磺酸]]（PFBS）→ PFHpA），而当链长减小（链长 ≤ 5）时，[[空间位阻|空间位阻效应]]变得不那么显著（即[[全氟戊酸]]（PFPeA）→ TFA）。

经循环[[吸附]]方案增强后（图3b），引入[[受限水]]降低了[[脱水惩罚]]（例如[[全氟庚酸|PFHpA]]的7.93对1.83，补充图16）和表面[[结合能]]态（PFHpA的-11.40 kcal mol<sup>-1</sup>对-26.14 kcal mol<sup>-1</sup>），从而使整体固-液传质能更加平缓。因此，模拟结果表明，[[S-D-β200]]中所有（超）短链[[全氟和多氟烷基物质|PFAS]]的[[纳米孔]]可及性均得到增强，这与实验结果一致，实验显示纳米孔占有率从0.5%提高到22%（图3d和3e）<sup>25</sup>。此外，这种增强普遍改善了PFAS的传质状态，无论链长和官能团如何（图3c和补充图12-15）。这一结果不同于先前研究所表明的由[[限域水|受限水]]主导的亲水结合模式<sup>20</sup>，提示在S-D-[[沸石|β200]]孔吸附过程中存在其他协同结合机制（如沸石骨架）。

为进一步阐明 [[S-D-β200]] [[纳米孔]]中的相互作用模式，研究了[[全氟和多氟烷基物质|（超）短链 PFAS]] 的应力模式。[[平均非共价相互作用]]和热涨落分析表明，[[受限水]]与[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 的亲水头基 $\left( \mathrm { i . e . , - C O O ^ { - } o r - S O _ { 3 } ^ { - } } \right)$ 之间存在稳定的[[氢键|氢键相互作用]]（蓝色等值面，图 3f 和补充图 17）。同时，[[独立梯度模型]]分析表明，[[C-F链|C-F 链]]位于[[沸石]] a- 和 b- 直通道中，并通过[[范德华力]]与沸石骨架结合（绿色等值面，图 3g 和补充图 18）。这些发现证实，（超）短链 PFAS 同时与沸石骨架和[[限域水|受限水]]结合，形成独特的双重结合模式，这与 S-D-β200 的[[魔角旋转核磁共振|二维核磁共振分析]]结果一致（图 2e 和补充图 19）。此前研究表明，长链 PFAS 在 $\beta$ 沸石纳米通道内的紧密排列以及交叉处的氢键配对，是其适宜选择性[[吸附]]的基础<sup>21</sup>。在本工作中，通过非固定化的受限水结构，（超）短链 PFAS 无需亲水头基配对即可实现稳定吸附，进一步拓展了沸石的应用潜力。此外，我们通过 $\delta \mathrm { g }$ 指数、[[径向分布函数]]（G(r)）和[[配位数]]（N(r)）量化了沸石骨架和受限水对 PFAS 的相互作用强度（图 3h 和补充图 20）。有趣的是，受限水相互作用强度（G(r)）与链长（例如，C3 > C4）和官能团 $( \mathrm { e . g . , - C O O ^ { - } { > - } { S O _ { 3 } } ^ { - } ) }$ 呈负相关。相比之下，与沸石骨架的相互作用强度（δg）与链长 $( { \mathrm { e . g . , C 4 } } > { \mathrm { C } } 3 )$ 和官能团 $( \mathrm { e . g . , - C O O ^ { - } { < - } S O _ { 3 } ^ { - } ) }$ 呈正相关。这两种结合模式之间的差异可能是 S-D-β200 增强的孔吸附过程不对 PFAS 结构产生特异性响应的潜在原因。进一步的[[DFT|密度泛函理论]]分析证明了这一点，其结果表明，（超）短链 PFAS 在通过向沸石骨架和受限水供电子（0.389 e–0.457 e）实现双重结合后，其[[结合能]]变化趋势与[[平均力势]]（PMF）一致（图 3c 和补充图 21–23）。同时，我们进一步将[[分子动力学|分子动力学模型]]扩展到平衡态（补充图 24–25）。结果表明，双重结合模式在 S-D-β200 吸附（超）短链 PFAS 中起主导作用，尤其是对链长小于 6 的 PFAS（孔吸附比例：71.1–83.0%）。在接近饱和的 S-D-β200 纳米孔中，（超）短链 PFAS 的疏水尾端被沸石通道结合，而亲水头基则汇聚于受限水簇处，并携带阳离子以消除[[静电排斥]]（电荷补偿率：92.0–101.6%）。

## 全规模应用

在我们的方案中，[[动态羟基循环机制]]能够在现有家用[[全规模家用净水器|净水器]]中直接安装 [[S-D-β200]]，为与[[全氟和多氟烷基物质|（超）短链 PFAS]] 相关的危机提供一种低成本且可就地实施的解决方案。在一项概念验证实验中，我们将一台全尺寸三级家用净水器末级的[[压缩活性炭]]（CAC）[[吸附]]柱替换为定制设计的 S-D-[[沸石|β200]] 吸附柱（图 4a、4b 及补充图 26）。在连续 182 天的时间里开展了全过程模拟实验，模拟真实家庭用水模式（8 L day<sup>-1</sup>，图 4c）<sup>28</sup>，并使用各研究报道的饮用水中[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 的最高浓度（补充表 7）<sup>29,30</sup>。在这一全尺寸模拟中（补充图 27），动态羟基净水器对（超）短链 PFAS 的平均去除效率为 73%–95%，优于商用净水器的性能（44%–90%），并展现出作为最高效[[反渗透净水器]]（75%–99%）可行替代方案的潜力<sup>31</sup>。动态羟基净水器在约 6 个月（179 天）内有效降低了实际饮用水中（超）短链 PFAS 的浓度，使其达到拟议的 [[欧洲议会和理事会|EPC]] 健康标准（基于所报道一般丰度水平的 90% 估算为 450 ng L<sup>-1</sup>）<sup>5,6</sup>。这一降低显著缓解了与使用商用净水器相关的 PFAS 暴露潜在风险（0 天，图 4d）。值得注意的是，该评估结果是在最高 PFAS 负荷下获得的，并且对其去除[[溶解性有机物]]和[[重金属]]等其他净化能力没有影响（补充表 8），表明其有潜力有效满足大多数饮用水处理需求。此外，所提出的[[动态羟基循环]]机制在传统吸附-[[脱附]]过程中仅引入水作为强化介质（图 1a 和 1b），并具有良好的可重复使用性（补充图 9），显著降低了吸附过程的总体成本。

## 讨论

我们开发的循环[[吸附]]策略利用[[沸石]]中羟基的动态循环，打破了实际饮用水中[[全氟和多氟烷基物质|（超）短链 PFAS]] 的“永久循环”，并通过一系列商用沸石（典型代表为 β200）进行了展示。实验和计算结果明确证明，成功构建的非固定羟基促进了传质并在孔道吸附中建立了双结合模式。因此，[[S-D-β200]] 对[[短链全氟和多氟烷基物质|（超）短链 PFAS]]（C-F 数：1–6）的吸附容量达到 233.82 至 733.13 mg g<sup>-1</sup>。仅依赖水的无试剂改性有效保持了沸石晶体结构的稳定性，在模拟共污染体系中确保了适宜的选择性和[[再生]]能力。更重要的是，利用 S-D-β200 的全尺寸[[全规模家用净水器|净水器]]可以在连续运行约 6 个月内，将环境相关最高水平的（超）短链 PFAS 污染降低到符合 [[欧洲议会和理事会|EPC]] 健康标准的水平。因此，我们的研究结果为获得经济可负担、不含（超）短链 PFAS 的饮用水提供了重要机会，尤其对欠发达地区的个体而言。

## [[动态羟基循环]]

为模拟[[再生]][[沸石]]的结构，商业沸石按如下方式进行[[煅烧|热处理]]。首先，将商业沸石在超纯水中于室温搅拌4 h，重复三次，然后在[[鼓风干燥箱]]中于70 ℃干燥12 h，再在[[真空干燥箱]]中于-1.0 MPa、$1 0 5 ~ ^ { \circ } \mathrm { C }$下干燥6 h，最后在[[马弗炉]]（[[Thermo Scientific]]，美国）中于$8 0 0 ~ ^ { \circ } \mathrm { C }$煅烧6 h $( 1 0 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 } )$。脱官能化沸石在其名称前添加$" \mathrm { D } \cdot "$，例如$\mathrm { ^ { 6 6 } D - } \beta 2 0 0 ^ { \mathrm { 9 } }$。

$$

其中 $r _ { i j }$ 为粒子间距离，σ 为最小势能半径，ε 为势阱深度。

对于[[范德华相互作用]]，采用 10 Å 的截断距离。采用 [[粒子-粒子-粒子-网格方法|particleparticle-particle-mesh 方法]]计算长程库仑相互作用，其收敛容差为 $1 0 ^ { - 4 }$ kcal $\mathrm { m o l ^ { - 1 } }$。所有模拟均在 NVT 条件下进行，使用 [[Nose-Hoover 恒温器]]将温度维持在 303 K。在运行模拟之前，对体系进行了能量最小化。随后，使用 1 fs 时间步进行 1 ns 的平衡。

## [[平均力势]]（PMF）计算

为进一步获得[[全氟和多氟烷基物质|（超）短链 PFAS]] 进入[[纳米孔]][[吸附]]路径的结合自由能变化，使用[[伞形采样|伞形采样方法]]计算 [[平均力势|PMF]]<sup>39-41</sup>。[[短链全氟和多氟烷基物质|（超）短链 PFAS]] 从体相水吸附到[[沸石]]纳米孔的过程被划分为平均 11 个反应窗口，每个窗口沿 Z 轴间隔 2 Å。体系达到平衡后，采用带谐波势的引导[[分子动力学]]技术（弹簧常数为 25 kcal mol $\cdot \mathrm { \AA } ^ { - 1 }$ ，牵引速度为 0.001 Å $\mathbf { f } \mathbf { s } ^ { - 1 } )$ ）将（超）短链 PFAS 拖入指定反应窗口。随后，使用低弹簧常数（2 kcal $( \mathrm { m o l } \times \mathrm { \AA } ) ^ { - 1 } )$ ）的谐波势使（超）短链 PFAS 在该反应窗口稳定 300 ps 的平衡时间。然后继续模拟 100 ps，每 100 fs 记录一次 PFAS 反应坐标。反应坐标数据通过[[加权直方图分析法|加权直方图分析]]转化为 PMF 自由能<sup>41</sup>：

$$
\mathrm{W} _ {\text { w   i   n   d   o   w }} = - \mathrm{K} _ {\mathrm{b}} \times \mathrm{T} \times \ln \mathrm{P} _ {\text { w   i   n   d   o   w }}\tag{6}
$$

其中 $\mathrm { K } _ { \mathrm { b } }$ 为[[玻尔兹曼常数]]，T 为温度，$\mathrm { P } _ { \mathrm { w i n d o w } }$ 为在观测窗口找到[[全氟和多氟烷基物质|（超）短链 PFAS]] 的概率。

## [[平均非共价相互作用]]（aNCI）计算

采用Wu等人<sup>42</sup>提出的[[平均非共价相互作用|aNCI]]方法分析动态体系中（超）短链[[全氟和多氟烷基物质|PFAS]]的[[非共价相互作用|平均非共价相互作用]]。aNCI方法的原理是通过[[约化密度梯度]]（RDG）函数等值面展示弱相互作用区域，然后将sign(λ2)rho函数以不同颜色投影到RDG等值面上，以显示弱相互作用的类型<sup>43</sup>。用于计算RDG和sign(λ2)rho函数的电子密度、电子密度梯度及电子密度Hessian矩阵，通过对多帧轨迹结构进行平均得到<sup>43</sup>。蓝色、绿色和红色分别代表[[氢键]]、[[范德华相互作用]]和[[位阻效应]]。平均RDG采用如下式（7）计算：

$$
\overline {{\mathrm{RDG(v)}}} = \frac {1}{2 (3 \pi^ {2}) ^ {1 / 3}} \frac {| \nabla \rho (\mathrm{r}) |}{\overline {{\rho (\mathrm{r})}} ^ {4 / 3}}\tag{7}
$$

其中，$\rho ( \boldsymbol { \gamma } )$为平均电子密度，$\nabla \rho ( \boldsymbol { r } )$为平均电子密度梯度。此外，平均[[约化密度梯度|RDG]]方法定义了[[热涨落指数]]（TFI）以表征不同区域弱相互作用的稳定性<sup>42</sup>。TFI以不同颜色映射到平均RDG等值面上，可通过颜色判断其他区域弱相互作用的稳定性<sup>43</sup>。等值面越蓝表示相互作用越稳定，越红表示越不稳定。TFI采用式（8）计算：

$$
\mathrm{TFI} = \frac {\operatorname{std} \left(\left\{\rho_ {\mathrm{i} (r)} \right\}\right)}{\operatorname{avg} \left(\left\{\rho_ {\mathrm{i} (r)} \right\}\right)}\tag{8}
$$

其中，avg({ρi(r)})和std（$\{ \mathsf { \rho } _ { 1 ( r ) } \} )$）分别为整条轨迹电子密度的均值和方差。用于[[平均非共价相互作用|aNCI]]分析的最优结构由[[分子动力学模拟]]获得。固定（超）短链[[全氟和多氟烷基物质|PFAS]]分子，进行1 ns的平衡模拟。aNCI分析采用最后2000帧轨迹的结构。所有aNCI和[[热涨落指数|TFI]]计算均使用[[Multiwfn|Multiwfn软件包]]（3.8版）完成。

## [[独立梯度模型]]（IGM）计算

本研究采用Hénon等人<sup>44</sup>提出的[[独立梯度模型|IGM]]方法分析（超）短链[[全氟和多氟烷基物质|PFAS]]与[[沸石]]骨架之间的相互作用。在IGM分析中，常用$\delta \mathbf { g } ^ { \mathrm { i n t e r } }$等值面可视化相互作用区域。同时，通常将sign(λ2)ρ函数以不同颜色映射到等值面上，以直观表征相互作用的性质。sign(λ2)ρ表示sign(λ2)（电子密度Hessian矩阵的第二大本征值$\rho ,$的符号）与$\rho .$的乘积。相互作用区域的$\rho$通常与相互作用强度正相关，而sign(λ2)能够区分相互作用是吸引型还是排斥型<sup>45</sup>。IGM分析的配色判据与[[平均非共价相互作用|aNCI]]一致。δg<sup>inter</sup>采用式（9）、（10）和（11）计算：

$$
\mathrm{g} ^ {\text { inter }} (r) = \left| \sum_ {\mathrm{A}} \sum_ {\mathrm{i} \in \mathrm{A}} \nabla \rho_ {\mathrm{i}} ^ {\text { free }} (r) \right|\tag{9}
$$

$$
\mathrm{g} ^ {\text { IGM,inter }} (\mathrm{r}) = \sum_ {\mathrm{A}} \left| \sum_ {\mathrm{i} \in \mathrm{A}} \nabla \rho_ {\mathrm{i}} ^ {\text { free }} (\mathrm{r}) \right|\tag{10}
$$

$$
\delta \mathrm{g} ^ {\text { inter }} (\mathrm{r}) = \mathrm{g} ^ {\text { IGM,inter }} (\mathrm{r}) - \mathrm{g} ^ {\text { inter }} (\mathrm{r})\tag{11}
$$

其中，$\boldsymbol { \mathrm { g } } ^ { \mathrm { i n t e r } }$为所有碎片密度梯度叠加的大小，$\mathbf { g } ^ { \mathrm { I G M , i n t e r } }$为所有碎片密度梯度大小之和，A遍历所有片段，i遍历相应片段中的所有原子。[[独立梯度模型|IGM]]计算使用[[Multiwfn|Multiwfn软件包]]（3.8版）完成。

## [[径向分布函数]]（RDF）计算

为了探究[[受限水]]与[[全氟和多氟烷基物质|（超）短链 PFAS]] 之间相互作用的强度，计算了它们原子对之间的 [[径向分布函数|RDF]]<sup>46,47</sup>。RDF 利用式（12）估计给定距离处一对原子的密度：

$$
\mathrm{G} (r) = \mathrm{V} \rho (r) / 4 \mathrm{N} \pi r ^ {2} \Delta r\tag{12}
$$

其中，V 为系统体积，$\rho ( r )$ 为在 r 至 r+∆r 壳层范围内找到的原子对数量，N 为所选原子对的总数。[[径向分布函数|G(r)]] 峰表示该原子对出现的频率，可用于推断两个原子之间的相互作用强度。

## [[配位数]]计算

[[配位数]]表示所选原子各球形配位范围内相应分子的数量<sup>46,47</sup>。具体而言，在球坐标中对 [[径向分布函数|G(r)]] 进行积分，并以 RDF 的第一个极小值作为积分上限，即可得到相应分子的配位数。计算配位数的具体式（13）如下。

$$
\mathrm{N} (r ^ {\prime}) = 4 \pi \rho \int_ {0} ^ {r ^ {\prime}} \mathrm{G} (r) r ^ {2} \mathrm{d} r\tag{13}
$$

其中，$r ^ { \prime }$ 为溶剂层的截断距离，$\rho$ 为系统密度，[[径向分布函数|G(r)]] 为所选原子对的径向分布函数。

## [[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算

[[DFT]] 计算采用 [[Material Studio]] 的 [[DMol3]] 模块进行。采用 [[Perdew-Burke-Ernzerhof 泛函|Perdew-Burke-Ernzerhof（PBE）泛函]]的[[广义梯度近似]]（GGA）方法描述核与电子之间的相互作用。所有计算均包含[[自旋极化]]及 [[DFT 半芯赝势]]。对于[[吸附]]而言，考虑[[范德华力]]至关重要。因此，采用 [[Tkatchenko-Scheffler 方法|Tkatchenko-Scheffler（TS）方法]]进行 [[DFT-D 校正]]。采用[[双数值加极化函数|双数值加极化（DNP）函数]]作为基组。力和能量收敛标准分别设置为 0.002 Ha $\mathrm { \AA } ^ { - 1 }$ 和 $1 0 ^ { - 5 }$ Ha。优化完成后，按式（14）计算[[结合能]]（ΔE）。

$$
\Delta \mathrm{E} = 2 7. 2 1 2 \times (\mathrm{E} _ {\text { total }} - \mathrm{E} _ {1} - \mathrm{E} _ {2})\tag{14}
$$

其中，Etotal 为优化后体系的能量；E1 为 [[S-D-β200]] 的能量；E2 为[[全氟和多氟烷基物质|（超）短链 PFAS]] 的能量。

## 全规模水净化

本研究构建了一台全规模[[全规模家用净水器|净水器]]，以评价 [[S-D-β200]] 对饮用水中[[全氟和多氟烷基物质|（超）短链 PFAS]] 的去除效率。该全规模净水器采用三级处理工艺（尺寸：36 cm×33 cm×13 cm），包括[[聚丙烯]]（PP）棉过滤（过滤精度：1 μm，尺寸：25.4 $\mathrm { c m } { \times } 6$ cm，[[安徽乐透水净化科技有限公司]]，中国）、[[颗粒活性炭]]（尺寸：25 cm×7 cm，安徽乐透水净化科技有限公司，中国）以及[[受限水强化沸石]]（即 S-D-[[沸石|β200]]，尺寸：25 cm×7 cm）。同时测试了一台商用家用净水器作为对照，其包括 PP 棉过滤、颗粒活性炭和[[压缩活性炭]]。

全尺寸[[全规模家用净水器|净水器]]的实验运行模式基于普通四口之家的取水规律，如图4c所示。每天在早餐、午餐和晚餐时段分别进行0.5 h、2 h和1.5 h的饮用水处理。进水流量控制在$2 ~ \mathrm { L } ~ \mathrm { h } ^ { - 1 }$，以获得4人每天8 L的推荐饮水量<sup>28</sup>。此外，每天凌晨进行10 min[[反冲洗]]，以防止[[吸附]]柱堵塞和[[生物膜]]形成。为防止[[纳米沸石|纳米沸石颗粒]]在吸附柱中造成过大压降，全尺寸净水器中使用了[[β200 球形沸石|商用β200球形沸石]]（粒径：0.4–0.9 mm，[[大连卓然环保科技有限公司]]，中国）。
