## 摘 要

[[β-环糊精]]（β-[[环糊精|CD]]）是一类具有[[生物相容性]]的大环候选分子，可用于制备具有增强功能的各种复合材料。而无毒且可生物降解的[[柠檬酸|柠檬酸（CA）]]是构筑多级先进结构的理想[[交联|交联剂]]。CA上的[[羧基]]和[[羟基]]可作为“结构桥梁”，并提高β-CD的溶解度，从而构建出具有优异复杂结构和目标功能的[[柠檬酸交联β-环糊精|CA交联β-CD材料]]。本文中，我们直接将[[接枝改性|接枝]]复合材料划分为有机材料和无机材料两大类。特别是，根据其制备方法、独特特性的优势以及在环境和生物医学领域中的可能应用（如污染物[[吸附]]、[[传感器]]和生物医学应用），对若干代表性复合材料进行了详细列举和分析。

## 1. 引言

[[环糊精]]（Cyclodextrins，CD）通常由可再生的天然材料制备，是一类由重复的 [[D-(+)-吡喃葡萄糖]]单元通过 [[α-1,4-糖苷键]]连接而成的[[大环低聚物]]（图 1）（Liu et al., 2022; Liu, Zhou, Lu, & Zhou, 2020）。从 CD 的结构骨架来看，对其[[羟基]]进行修饰是改善其物理化学性质的首选途径，由此可得到多种功能性 CD 衍生物。此外，作为一种重要的主体分子，CD 能够在溶液和固相中络合适宜的客体分子（通常是疏水性且尺寸匹配的客体），形成[[主客体包合物]]（Liu, Cao, et al., 2022; Prochowicz, Kornowicz, & Lewinski, ´ 2017），从而在[[药物递送]]（Castillo Cruz, Flores Colon, ´ Rabelo Fernandez, Vivas-Mejia, & Barletta, 2022; Hu, Tang, & Chu, 2014; Peng, Liu, Feng, & Yuan, 2017; Pivato et al., 2021; Saha, Roy, & Roy, 2017; Webber Langer, 2017）、[[分子识别受体]]（Ghosh Nau, 2012; Stricker, Fritz, Peterlechner, Doltsinis, & Ravoo, 2016）、[[立体选择性有机合成]]与催化（Macaev & Boldescu, 2015）、[[自修复材料]]（Nakahata, Takashima, Yamaguchi, & Harada, 2011; Villalobos, Huang, & Peinemann, 2017; Xie, Yu, Wang, & Li, 2022）、[[传感器]]（Alam & Deen, 2020; Chen et al., 2022）和[[吸附剂]]（García-Padial, Martínez-Oharriz, ´ Isasi, & Zornoza, 2017; Morin-Crini et al., 2018）等领域获得广泛应用。在 CD 分子中（图 1），由七个葡萄糖单元组成且具有 0.62 nm [[疏水空腔|内疏水空腔]]的 [[β-环糊精|β-CD]] 最具代表性，也是研究最多的种类，这是因为其在学术研究和工业应用中成本较低（Liu, Cao, et al., 2022; Liu, Wang, Duan, Wang, & Zhou, 2022）。然而，β-CD 及其他 CD 表面缺乏[[羧基]]，这使得它们难以拓展新的、更有效的修饰策略，例如与带有氨基的分子或材料结合。因此，利用特定试剂进行[[接枝改性|接枝修饰]]，已引起人们对 CD 化学更广泛的关注。

许多化合物可用于[[接枝改性|接枝修饰]]，而[[柠檬酸|柠檬酸（CA）]]作为一种[[三羧酸]]化合物，因其天然无毒、反应活性强且易于获得等独特优势，成为一种非常有竞争力的选择。特别是，CA 几乎能够与所有碳水化合物键合，例如，CA 的[[羧基]]可与 [[β-环糊精|β-CD]] 上的 C<sub>6</sub>-OH 形成[[酯键]]。因此，CA 在天然[[交联]]领域具有重要地位。由 CA 交联 β-[[环糊精|CD]] 构成的功能材料的研究与开发在过去三十年间蓬勃发展，研究时间线图、每年研究数量汇总以及实际应用如图 2 所示。

关于 [[柠檬酸|CA]] [[交联]] [[β-环糊精|β-CD]] 制备方法的详细讨论、分析和总结，对于指导其在环境和生物医学等具有吸引力的应用中的进展已变得越来越迫切。在此，我们希望系统综述 CA 交联 β-[[环糊精|CD]]，探讨其合成设计策略以及面向目标应用的功能基团。

我们首先介绍了[[β-环糊精|β-CD]]及其衍生物的结构与性质，并回顾了以[[柠檬酸|柠檬酸（CA）]]作为[[交联]]β-[[环糊精|CD]]改性剂的相关研究。随后，对CA交联环糊精（CD）的制备方法进行了深入讨论和分析。β-CD/CA的类型总结见表1。[[柠檬酸交联β-环糊精|CA交联β-CD]]还广泛用于[[金属离子吸附|吸附染料加工过程中产生的金属离子]]（Sun et al., 2022; Yan & Li, 2021），以及去除溶液中的[[亚甲基蓝]]（Dogan, Satilmis, & Uyar, 2019; Jiang et al., 2021; Mpatani et al., 2020; Tang et al., 2019; Zhao, Zhao, Zhu, Huang, & Hu, 2008）、[[吖啶橙]]（Yang et al., 2022）、[[甲基紫]]（Lamia Moulahcene et al., 2023）和[[苯酚]]（Zhou et al., 2018）。有趣的是，最近的研究表明，CA交联β-CD还可用于[[放射性元素去除|去除放射性元素]]，减少核工业污染（Li et al., 2019）。此外，在生物医学领域，CA交联β-CD因其多孔特性可用作[[药物载体]]（Birck et al., 2016; Ghorpade et al., 2018; Hernandez-Montelongo et al., 2014; Moulahcene et al., 2015）。更进一步，我们还专门设有一节讨论CA交联β-CD复合材料的制备，这些材料可与其他物质结合，用于特定应用并表现出优异的性能，例如在[[吸附]]和[[药物递送]]方面。最后，提出了该领域未来研究与开发面临的挑战，以引起人们对CA交联β-CD领域的关注。

## 2. [[柠檬酸交联β-环糊精|CA交联β-CD]]的制备

众所周知，[[β-环糊精|β-CD]]的改性和功能化具有环境友好、成本低且化学稳定性好的特点（Jiang et al., 2019; Morin-Crini et al., 2021）。β-[[环糊精|CD]]结构骨架上存在多个可进一步改性的反应位点（图1），例如，β-CD具有特殊的锥形空腔结构，其中C-2和C-3位的仲[[羟基]]位于空腔较宽的一端，而环状分子内部的非极性氢和类醚氧基团位于C-3和C-5位。C-6伯羟基位于空腔较窄的一端，可与其他物质进行改性和[[接枝改性|接枝]]。诸如[[柠檬酸|CA]]等功能基团主要通过C-2/3/6位羟基的反应引入β-CD结构中。有关合成方法和策略的详细分析与讨论将在本节中呈现。

## 2.1. 通过催化剂制备[[β-环糊精|β-CD/CA]]

[[柠檬酸交联β-环糊精|CA交联β-CD]]通常通过[[酯化反应|酯化缩合反应]]制备（Li et al., 2019）。例如，将[[柠檬酸|CA]]、[[β-环糊精|β-CD]]和常用催化剂—— ${ \mathrm { - K H } } _ { 2 } { \mathrm { P O } } _ { 4 }$ 加入[[去离子水]]中，并在沸水中充分混合。将该混合物加热数小时后冷却，得到粗复合产物。经去离子水多次洗涤、[[萃取]][[过滤]]，最后[[冷冻干燥]]过夜，得到β-[[环糊精|CD]]/CA最终产物（图2，表1）。

## 2.2. 温控制备[[β-环糊精|β-CD/CA]]

作为一种有趣[[交联|交联剂]]，[[柠檬酸|CA]]可在高温下（例如160 ℃–180 ℃）形成[[酸酐]]，随后与[[β-环糊精|β-CD]]上的[[羟基]]发生[[酯化反应]]，从而进一步引发β-[[环糊精|CD]]的复杂聚合（图3，表1）。

## 3. [[β-环糊精|β-CD/CA]]基非均相复合材料的制备

基于[[β-环糊精|β-CD/CA]]的非均相复合材料通常可根据所涉及物种的数量（如二元和三元体系）、聚合物结构的形状与构象（如线型、网状和多支化结构）以及[[接枝改性|接枝材料]]（如有机和无机材料）进行分类。由于大多数相关报道的复合材料为三元体系，且对这些结构的描述较为笼统，本节中我们不采用上述前两种分类方法。因此，我们在此直接将接枝材料分为有机类型和无机类型，并对代表性材料进行详细分析。

## 3.1. 有机复合杂化材料

[[β-环糊精|β-CD/CA]] [[接枝改性|接枝]]的有机材料通常利用 [[柠檬酸|CA]] 的[[羧基]]与 β-[[环糊精|CD]] 结构以及这些有机材料的[[含氧基团]]进行[[交联]]。这种交联形式类似于串联交联，不仅发生在 β-CD 与有机材料之间，也发生在 β-CD 自身之间以及有机材料自身之间。通过 CA 的特殊交联作用，以多种形式成功实现了有机材料的交联，包括但不限于醇基聚合物、[[纤维素]]和[[壳聚糖]]。

## 3.1.1. [[β-环糊精|β-CD/CA]] [[接枝改性|接枝]]醇基聚合物的制备

3.1.1.1. [[PVA-1799]]（[[聚乙烯醇]]-1799）。除了复杂的温度控制外，通过添加额外助剂，[[柠檬酸|CA]] [[交联]] [[β-环糊精|β-CD]] 以形成聚合物结构也可以实现。将 PVA-1799 作为助剂加入含有 β-[[环糊精|CD]] 和 CA 的混合反应体系中，也是一种可行的选择（Zhao 等，2008）。例如，将 β-CD、CA、${ \mathrm { N a H } } _ { 2 } { \mathrm { P O } } _ { 4 } ,$ 和 PVA-1799 的混合物首先溶解在[[去离子水]]中。值得一提的是，反应保持在高温下进行。在这些条件下蒸发过程中产生的水使反应得以持续进行。最终产物 β-CD/CA-PVA-1799（图 4，表 1）经直接干燥并通过[[过滤]]获得。有趣的是，经 CA 交联的 β-CD 部分能够保持其原有的结构形态、空腔和包封性能。含有[[酯基]]和[[羧基]]的特殊聚合物结构可能有利于[[吸附]]。

图 3. 加热条件下 β-CD/CA 的合成机理。

在 [[柠檬酸|CA]] 的辅助下，[[β-环糊精|β-CD]] 也可以与 [[聚乙烯醇|PVA]] 结合制备[[β-CD 纳米海绵|纳米海绵]]（Martwong 等，2021）。与 β-[[环糊精|CD]]/CA-[[PVA-1799]] 的合成过程不同，其催化剂为 ${ \mathrm { N a } } _ { 2 } { \mathrm { H P O } } _ { 2 } ,$，并在真空和更高温度（180 ℃）下进行[[交联]]。随后最终研磨得到复合材料 β-CD/CA-PVA（表 1）。

3.1.1.2. [[PEG-400]]（[[聚乙二醇]] 400）。在加入专用改性剂时，[[β-环糊精|β-CD/CA]] 可被功能化为[[水不溶性β-CD聚合物|水不溶性 β-CD 聚合物]]（β-CDP）（Zhao et al., 2009），其中 PEG-400 可作为改性剂的候选物。该聚合物以 [[柠檬酸|CA]] 水合物为[[交联|交联剂]]、PEG 为改性剂，通过[[缩聚反应]]成功合成为水不溶性 β-CDP。CA 的用量影响产率和总酸性基团，PEG 的用量影响 β-CDP 的产率和 β-[[环糊精|CD]] 含量。因此，有必要探索适当的 CA 和 PEG 用量对聚合物性能的影响。水不溶性[[吸附]]材料可通过缩合法制备。奇怪的是，原始材料是水溶性的，但最终产物 β-CD/CA-PEG-400（表 1）不溶于水。文献综述（Kirmic Cosgun & Ceylan Tuncaboylu,

2021）表明，[[环糊精|CD]] 与 [[聚乙二醇|PEG]] 形成[[包合物]]，即基于 CD 的互锁结构，如[[假聚轮烷|假（聚）轮烷]]。CD 分子与[[氢键]]共同形成具有[[疏水相互作用]]的网络，使聚合物不溶于水。

## 3.1.2. [[β-环糊精|β-CD/CA]] [[接枝改性|接枝]]天然生物物质的制备

3.1.2.1. [[纤维素]]。由于具有令人关注的[[生物可降解性]]、低成本和[[药物递送]]应用前景（Ahmad et al., 2022; Narayanaswamy & Torchilin, 2019; Sun, Song, Wang, Hu, & Wu, 2020），[[纤维素基水凝胶]]已引起全球研究者的关注（Du et al., 2019; Nascimento et al., 2018; Zhong et al., 2021）。然而，常用的纤维素[[水凝胶]]主要用于负载亲水性药物，难以负载和释放疏水性药物，这大大缩小了其生物医学应用范围（Andrade et al., 2022; Sun, Wang, & Yan, 2017）。为解决这一问题，可将具有[[疏水空腔]]的 [[β-环糊精|β-CD]] 引入纤维素及其衍生物中，以 [[柠檬酸|CA]] 为强[[交联|交联剂]]制备 β-[[环糊精|CD]] [[接枝改性|接枝]]纤维素凝胶（Gupta et al., 2020）。

3.1.2.2. [[羟乙基纤维素]]（HEC）。HEC 是一种具有代表性的绿色可再生[[纤维素衍生物|水溶性纤维素衍生物]]，其内部含有大量[[羟基|活性羟基]]，可为 [[柠檬酸|CA]] 提供足够的[[交联]]位点，并有利于 [[β-环糊精|β-CD]] 在[[水凝胶膜]]中的[[接枝改性|接枝]]（Chu et al., 2020; Shi et al., 2020; Yang, Guo, Sun, & Wang, 2016）。（Sampatrao Ghorpade et al., 2018）[[β-CD-HEC 水凝胶膜]]的制备如（图 5）所示。文中还列出了该结构的几种交联类型。从机理探索来看，其主要通过[[酯化交联]]制备。其较大的[[溶胀度|溶胀率]]和[[交联度]]使其有利于[[药物递送]]应用。

3.1.2.3. [[羟丙基甲基纤维素]]（[[羟丙甲纤维素|HPMC]]）。HPMC 由天然[[纤维素]]经[[碱处理]]、[[醚化]]、[[中和反应]]以及洗涤和干燥制得。它具有可再生、可生物降解、可食用等特性，广泛用于制药和食品包装领域（Arboleya & Wilde, 2005; Ding, Zhang, & Li, 2015; Ghadermazi, Hamdipour, Sadeghi, Ghadermazi, & Khosrowshahi Asl, 2019; Wang et al., 2022; Zhang et al., 2013）。与其他[[纤维素衍生物]]相比，HPMC 具有[[增稠]]和溶胀特性，其良好的[[成膜性能]]已成功用于[[药物递送]]（de Souza & Petri, 2018; Hu et al., 2018; Joshi, 2011; Zhang et al., 2017）。由于纤维素[[水凝胶]]的局限性，用于递送疏水性物质的 HPMC 也受到相同因素的影响，并可通过[[接枝改性|接枝]] [[β-环糊精|β-CD]] 加以改善。[[交联|交联剂]]有许多候选物，如[[正硅酸四乙酯]]（TEOS）和[[丁二胺]]，但由于其毒性，这些试剂不适合用于交联可递送药物的水凝胶。因此，在制备 β-[[环糊精|CD]] 接枝 HPMC 的[[水凝胶膜]]时，交联剂 [[柠檬酸|CA]] 仍是首选（Ghorpade et al., 2016）。例如，将含有 β-CD、CA、[[次磷酸钠]]（SHP）和 HPMC 的水溶液一起搅拌，放置过夜，然后干燥得到固化复合膜 β-CD/CA-HPMC 1（图 6）。此外，调整 CA 和 SHP 的浓度以促进交联结构密度，经[[冷冻干燥]]后形成凝胶 β-CD/CA-HPMC 2（表 1）（de Souza Petri, 2018）。

3.1.2.4. [[羧甲基纤维素]]（CMC）。作为自然界中最丰富的[[纤维素]]，亲水性 CMC 是纤维素经[[羧甲基化]]得到的[[阴离子水溶性多糖]]，具有良好的[[生物相容性]]、[[生物可降解性]]和强[[保水性]]，是制备生物相容性[[水凝胶]]的理想材料（Li et al., 2021; Nie, Liu, Zhan, & Guo, 2004; Rahman et al., 2021; Wang et al., 2016）。特别是，[[羧基]]和[[羟基]]的存在使基于 CMC 的水凝胶具有强[[吸附]]性（Demitri et al., 2008）。[[β-环糊精|β-CD/CA]]-CMC（表 1）复合材料的制备非常直接，如图 7 所示（Ghorpade et al., 2017）。图中标出了 [[柠檬酸|CA]]、[[环糊精|CD]] 和纤维素可能的[[接枝改性|接枝]]方式和[[交联]]类型，这与 β-CD [[羟乙基纤维素|HEC]] 的制备非常相似。通常，CA 在水凝胶形成中具有重要作用，因为它影响这些聚合物与 CD 的接枝能力以及接枝程度。合成过程始终影响着可能的应用和适用目标。该材料水凝胶的[[溶胀度|溶胀率]]和载药能力取决于 β-CD 的存在。合成过程中加入 CA 会生成[[酸酐]]，酸酐与羟基发生[[酯化反应]]，成功交联后聚合物周围存在游离羟基，提供了额外的活性位点。CA 的加入还对水凝胶的[[溶胀性能]]有更好的影响。

3.1.2.5. [[松木屑]]（PS）。一些天然材料由于其结构问题而在应用中受到限制，同时也常通过专门的功能化改性来提升其实际性能并拓宽其应用领域。例如，[[柠檬酸|CA]] [[交联]]的 [[β-环糊精|β-CD]] 可以改性松木屑，而松木屑本身可作为[[活性炭]]等[[天然吸附剂]]使用。因此，改性后的松木屑可以进一步[[吸附]]污染物质（He, Huang, & Huang, 2010; Zhu, Fan, & Zhang, 2008）。与其他试剂相比，具有[[生物相容性]]的 CA 再次成为首选的交联剂，从而促进了由此所得复合材料具有更好的吸附效果和无毒应用（Gong, Jin, Chen, Chen, & Liu, 2006）。用 CA 和 β-[[环糊精|CD]] 对木屑进行详细改性非常方便且简单，如图 8 所示（Zhou et al., 2014）。CA 和松木刨花与 CD 之间可能的[[接枝改性|接枝]]方式、交联类型如图 8 所示。木屑经漂洗、干燥、再在 NaOH 中煮沸预处理后，将干燥木屑进一步与 CA、β-CD 和 [[次磷酸钠|SHP]] 在加热（100 ℃）条件下混合，最终得到干燥复合物 β-CD/CA-PS（表 1）。由于具有 β-CD 基团，所得松木屑对[[苯胺]]等芳香族客体的吸附变得更加有效。β-CD/CA-PS 的表征表明其结构多孔且复杂。它可能在吸附方面具有良好的性能。从 [[SEM]] 表征来看，β-CD/CA-PS 具有粗糙表面并含有大量微孔结构，在苯胺吸附中表现出更好的结果。苯胺作为一种高毒性物质，对环境污染非常严重。探索优良[[吸附剂]]十分必要。在吸附过程中，[[化学吸附]]和[[物理吸附]]都是可能的吸附机制。另一种材料，即由 β-CD/CA 与[[天然芳香族聚合物]][[木质素]]结合合成的[[水凝胶]]，是一种绿色材料（Petitjean, Lamberto, Zornoza, & Isasi, 2022），对[[酚类化合物]]具有高保留能力。

3.1.2.6. [[壳聚糖|壳聚糖（CS）]]。作为由[[甲壳素]][[脱乙酰化]]产生的[[阳离子多糖]]，CS 常用于生物医学应用，例如通过与 [[环糊精|CD]] 制备复杂复合材料进行[[药物递送]]。因此，如[[姜黄素]]这类不溶性药物可以被封装在 [[柠檬酸|CA]] [[交联]]复合体系——[[β-环糊精|β-CD/CA]]-CS-cur 中的 β-CD 基团内（Karpkird et al., 2020），如图 9 和表 1 所示。通过[[离子凝胶技术]]使阳离子型壳聚糖与含姜黄素的阴离子型柠檬酸交联 CD 相互作用，这种由姜黄素与柠檬酸 CD 形成的[[包合物]]可以进一步被壳聚糖包封。具体而言，姜黄素首先与 CD 结合形成包合物 β-CD/CA-cur，然后引入壳聚糖以制备[[纳米颗粒]] β-CD/CA-CS-cur（Abdelbasir et al., 2021；Karpkird, Khunsakorn, Noptheeranuphap, & Midpanon, 2018；Liu et al., 2016）。值得注意的是，制备过程应控制 pH 值。

## 3.2. [[有机-无机复合材料]]的构建

## 3.2.1. [[β-环糊精|β-CD/CA]][[接枝改性|接枝]]金属及其衍生物的制备

3.2.1.1. [[过氧化锌]] $( Z n O _ { 2 } ) .$ 。随着近年来绿色合成材料的迅速兴起，通过将金属材料引入$\beta { \mathrm { - C D / C A } }$中，改性材料备受关注。例如，可以利用$\mathrm { Z n O _ { 2 } }$获得[[β-环糊精|β-CD/CA]]-ZnO<sub>2</sub>复合材料（图11，表1），该材料具有[[生物相容性]]，可用于快速去除[[过氧化氢]]（Pirouzmand et al., 2020）。从$\beta { \mathrm { - C D / C A / - Z n O _ { 2 } } }$复合材料的结构来看，存在许多[[羧基]]以及$\mathrm { Z n O _ { 2 } }$与β-[[环糊精|CD]]之间的[[共轭]]。羧基是非常有效的[[吸附]]位点。它们使吸附某些物质变得更加容易。

![](<../2.SCI_MD/Citric acid cross-linked β-cyclodextrinsA review of preparation and environmentalbiomedical application/images/f68643b12a663d724715a97be33e45f2c9f7842efff04b356fda31a07047a574.jpg>)  
图11. β-CD/CA-ZnO<sub>2</sub>的合成

3.2.1.2. 氧化铁 $( F e _ { 3 } O _ { 4 } ) .$ 。磁性$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$[[纳米颗粒]]基材料可以被磁力收集，在复合材料中引入磁性$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$纳米颗粒可以使材料在使用后易于回收（Salahuddin, El-Daly, El Sharkawy, & Nasr, 2020）。因此，这种引入具有进一步发展的巨大潜力。例如，已有报道将磁性$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$纳米颗粒与[[氧化石墨烯纳米片|GO纳米片]]（GON）和[[β-环糊精|β-CD/CA]]复合（Jiang et al., 2021）。$\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$纳米颗粒经[[3-三乙氧基硅基丙胺]]（APTES）改性，生成黑色固体$\mathrm { A P T E S  – F e } _ { 3 } \mathrm { O } _ { 4 } ,$，其进一步与β-[[环糊精|CD]]/[[柠檬酸|CA]]、[[3-(3-二甲氨基丙基)-1-乙基碳二亚胺盐酸盐|EDC]]、[[N-羟基琥珀酰亚胺|NHS]]和GON反应，得到最终产物β-CD/$\mathrm { C A } { \cdot } \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$-GON（表1）复合材料，如图12所示。有趣的是，$\mathrm { \beta - C D / C A - F e _ { 3 } O _ { 4 } \mathrm { - } G O N }$复合材料的结构特征表明，其表面出现了大量活性位点，可用于未来[[吸附]]特定分子。

此外，金属离子也可以加入[[β-环糊精|β-CD/CA]]体系中以形成复合材料。例如，铁和钴（Pirouzmand, Nikzad Kojanag, Hosseini-Yazdi, & Aghabeigy, 2021）可以通过[[超声辅助方法]]，借助氧原子与[[柠檬酸|CA]]结合而被引入，从而获得[[环糊精|CD]]杂化复合材料。特别是，这种络合材料对[[过氧化氢]]的[[催化去除]]具有很高的效率。

3.2.1.3. 钌（[[钌|Ru]]）。为防止[[纳米颗粒]]（NPs）聚集，常采用具有特殊纳米结构的聚合物形成受限空腔，而[[环糊精|环糊精（CD）]]也可用于控制金属纳米颗粒在水性胶体悬浮液中的分散（Herbois et al., 2015）。因此，将CD与具有催化活性的Ru结合，形成[[β-环糊精|β-CD/CA]]–Ru（表1），如图13所示。该复合材料的成功合成表明，β-CD/[[柠檬酸|CA]]聚合物可作为某些NPs的载体，起到[[固定化剂]]的作用。此类复合材料的亲水性可拓宽这些NPs在水相多相催化中的应用（Rudy Herbois et al., 2012）。类似地，β-CD/CA与[[零价铁]]（Fe）纳米颗粒[[交联]]形成的β-CD/CA–Fe可用作[[硝基芳烃]]快速[[声化学还原]]的催化剂，提高反应过程速率（Shukla et al., 2022）。β-CD/CA聚合物的作用同样是载体，并获得催化剂的性能。

## 3.2.2. [[β-环糊精|β-CD/CA]][[接枝改性|接枝]]无机非金属材料的制备

3.2.2.1. $S i O _ { 2 } .$ 表面富含[[硅醇基团]]的[[二氧化硅]]易于[[化学改性]]以制备新材料（Aguado, Arsuaga, Arencibia, Lindo, & Gascon, ´ 2009）。二氧化硅的[[有机官能团功能化]]变得非常重要，将[[环糊精|CD]]与二氧化硅结合以获得功能化性能，有望得到具有所需性能的复合材料。例如，如表1所示，制备了[[β-环糊精|β-CD]]/ ${ \mathrm { C A } } { \cdot } { \mathrm { S i O } } _ { 2 }$ 复合材料（Carvalho et al., 2012），主要采用[[单一回流法]]。初始将二氧化硅、β-CD、[[柠檬酸|CA]]和[[二甲苯]]混合，通过改变回流时间得到粗产物。该材料表面含有大量[[含氧基团]]，目前是许多[[吸附剂]]的活性结合位点，可能在[[吸附]]方面具有更广泛的应用。

3.2.2.2. [[硅藻土]]（DA）。DA主要来源于形成[[硅化壳]]的[[二氧化硅]]，具有[[高孔隙率]]及稳定的化学性质，通常需要改性以更好地改善其相应性能（Song, Chai, Zhu, Li, & Liang, 2019）。将[[β-环糊精|β-CD]][[接枝改性|接枝]]到硅藻土表面对于提升此类复合材料的理化性能具有高度可行性。例如，利用[[柠檬酸|CA]]将β-[[环糊精|CD]]与DA[[交联]]，可通过[[水热法]]获得β-CD/CA-DA复合材料（Shi et al., 2021）。随着β-CD和CA的引入，该材料具有较大的[[BET|比表面积]]和[[孔隙率]]。

3.2.2.3. [[粘土]]。作为一种[[天然纳米材料]]，粘土材料价格低廉、储量丰富，并且非常环保。与 [[β-环糊精|β-CD]] 作为[[接枝改性|接枝材料]]结合可以拓展其应用。例如，将[[均离子粘土]]（Sa-Na<sup>+</sup>）分别加入 [[柠檬酸|CA]] 和 ${ \mathrm { N a } } _ { 2 } { \mathrm { H P O } } _ { 4 } ,$ 的混合物中。将 β-[[环糊精|CD]] 加入混合物并进行超声处理。在 $1 0 0 ~ ^ { \circ } \mathrm { C }$ 干燥后，所得残渣在 $1 8 0 ~ ^ { \circ } \mathrm { C }$ 加热，然后在室温下冷却。粗产物经纯化、干燥后得到 β-CD/CA-[[均离子黏土|HC]]（Tcheumi et al., 2019）。其接枝形式是将 β-CD 固定在粘土表面。这与其他复合材料略有不同。β-CD 并不与粘土反应，而只是被保持在其表面之上。大多数 β-CD 接枝是通过[[羟基]]反应或形成包合作用实现的。在另一个例子中，将接枝材料替换为[[膨润土]]后，合成方法变得更加简单：将 CA、β-CD、$\mathrm { N a H _ { 2 } P O _ { 4 } } ,$ 和膨润土在水中混合加热，即可得到 β-CD/CA BNC（Heydari & Sheibani, 2015）（图 14）。

## 4 [[柠檬酸交联β-环糊精|CA交联β-CD]]复合材料的应用

## 4.1 环境检测

[[β-环糊精|β-CD]]的一个特殊特征是其[[疏水空腔]]，可以追踪一系列具有适当极性的客体分子，形成[[包合物]]（Morin-Crini & Crini, 2013）。此外，β-[[环糊精|CD]]外缘的[[羟基|活性羟基]]（-OH）基团可被其他官能团识别，从而赋予β-CD特定性能。因此，[[柠檬酸交联β-环糊精|CA交联β-CD]]可以增强其[[吸附]]功能。[[羧基]]（-COO-）基团不仅作为连接基，还为[[重金属离子]]提供额外吸附位点（Sun et al., 2019; Zhao et al., 2015; Zhao et al., 2016），而空腔有助于捕获非极性有机污染物（Alsbaiee et al., 2015）。[[柠檬酸|CA]]作为[[交联|交联剂]]，富含羧基并具有相对较多的官能团，CD是一种多羟基物质。因此，两者交联时发生[[酯化反应]]，生成的[[酯基]]以及未反应的羧基和羟基都是活性位点。在吸附领域具有很大的应用潜力。关于CA交联β-CD聚合物去除重金属离子和放射性物质的研究已大幅增加，特别是在从水溶液中去除元素铀方面，表明β-CD/CA是铀[[废水处理]]的可靠材料。

## 4.1.1 离子污染物

由[[柠檬酸交联β-环糊精|CA交联β-CD]]制成的聚合物可与多种金属阳离子形成配合物，因此被用于去除废水中的[[重金属离子]]。例如（Huang et al., 2018），通过分析[[吸附剂]]用量、[[吸附]]离子浓度、吸附温度、溶液pH和吸附时间等一系列重要因素，全面研究了[[β-环糊精|β-CD/CA]]共聚物对铜离子的吸附性能。[[柠檬酸|CA]]中的[[羧基]]可以连接到[[环糊精|CD]]上，也可以作为吸附重金属的活性位点。吸附剂的空腔可以通过主客体包封捕获污染物分子。有趣的是，当吸附剂用量为$0 . 5 ~ \& ,$，铜离子溶液初始浓度为600 mg L<sup>−</sup> <sup>1</sup>，pH为7时，该β-CD/CA对铜离子的最大吸附容量为$1 8 . 1 5 \mathrm { m g } \mathrm { g } ^ { - 1 }$，吸附时间为24 h，吸附温度为30 ℃。此外，等温吸附模型分析得出，β-CD/CA对铜离子的吸附遵循[[Freundlich模型]]，表明多层吸附占主导地位。

除了直接使用[[柠檬酸|柠檬酸（CA）]]作为[[交联|交联剂]][[接枝改性|接枝]][[环糊精|环糊精（CD）]]片段之外，其他功能结构也可以与 CA 协同，将不同的 CD 单元连接成先进材料。例如（Alsbaiee et al., 2015），通过用 CA 和 [[β-环糊精|β-CD]] 改性[[壳聚糖|壳聚糖（CS）]]原料，制备了一种不同的[[吸附剂]]，用于提高[[重金属离子]]的去除效果。特别是，不同的 CS 与 CA 比例也会影响去除率，表明 ${ \mathsf { C o } } ^ { \mathrm { I I } }$ 离子的最高去除率出现在 1/3 的比例下。此外，当复合材料的粒径在 20 至 80 nm 范围内时，Cs 和 [[纳米复合材料|β-CD/CA-Cs 1 纳米复合材料]]在最优环境下对 ${ \mathsf { C o } } ^ { \mathrm { I I } }$ 的最大[[吸附]]量分别为 6.90 和 43.95。如图 15 所示，所制备的复合材料还具有[[可再生性]]，可成为[[废水处理]]的良好选择（Abdelbasir et al., 2021）。壳聚糖和 CA 以 CA 作为交联剂，通过[[酯基]]和[[酰胺键]]交联形成[[纳米颗粒]]，随后将 CD 接枝到 Cs-Cit 纳米颗粒上。[[三聚磷酸钠|TPP]] 桥接了 Cs-Cit 和 β-CD。吸附机制主要归因于 ${ \mathsf { C o } } ^ { \mathrm { I I } }$ 与官能团之间的[[静电吸引]]。离子检测也可以通过[[传感器]]实现，例如表面与 ${ \mathrm { \beta - C D / C A } } ,$ 交联的[[羟基磷灰石|天然羟基磷灰石]]，可作为 [[铅|Pb（II）]]检测器，用于灵敏检测各种生活用水中的铅（Tchoffo et al., 2021）。所制备的传感器在环境检测与保护中具有广阔的应用前景。

## 4.1.2. [[有机染料]]

合成的 [[β-环糊精|β-CDP]] 是一种不溶于水的特殊[[吸附剂]]。β-[[环糊精|CD]] 的空腔使其能够[[吸附]]织物上的[[有机染料]]。染料种类繁多，[[亚甲基蓝|亚甲基蓝（MB）]]是一种常见的[[阳离子染料]]，可用于纺织应用。例如，制备了 [[水不溶性β-CD聚合物|β-CDP]] 用于吸附 MB，特别是通过延长反应时间，MB 的浓度先下降，而吸附量迅速增加，但最终吸附逐渐减慢，表明 [[柠檬酸|CA]] [[交联]]的 β-CDP 对 MB 的吸附具有良好的敏感性。合成吸附剂 β-CDP 保持了 β-CD 的原有空腔，被吸附染料 MB 的分子尺寸可以与 β-CD 形成[[包合物]]，并且吸附剂中的[[羧基]]和[[酯基]]呈酸性，从而对 MB 产生更好的吸附效果（Zhao et al., 2009）。

此外，在另一个使用[[硅胶]]和 [[β-环糊精|β-CD]] 的[[杂化二氧化硅-CD 材料]]实例中，讨论了 pH 对染料[[吸附]]的影响。并通过[[吸附动力学]]进一步确定了吸附效率，约 3–4 小时后达到吸附平衡，此时 90% 的 [[亚甲基蓝|MB]] 已被去除。[[吸附等温线]]测试得到的较高相关系数 r<sup>2</sup> 表明，[[Langmuir 模型]]最适于解释杂化[[二氧化硅]]-[[环糊精|CD]] 复合材料吸附 MB 的机制（Carvalho et al., 2012）。

此外，[[β-环糊精|β-CD/CA]]-[[壳聚糖|CS]] 2 表明，在 β-[[环糊精|CD]]/[[柠檬酸|CA]] 浓度为 20 wt%时，β-CD/CA 增强的 Cs [[吸附剂]]对[[活性蓝 49]] 的最佳[[吸附]]容量为 500 mg $\mathbf { g } ^ { - 1 }$。其吸附过程如图 16 所示（Zhao et al., 2018）。同时，该复合材料还可用于吸附[[活性黄 176|活性黄]] $^ { 1 7 6 , }$、[[活性蓝 14]]、[[活性黑 5|活性黑]] $^ { 5 , }$ 和[[活性红 141]] 等染料。该柱可使用[[氢氧化钠]]溶液进行再生，经过六次吸附-[[脱附]]循环后，去除率仍可达 80%。以 CA 为[[交联|交联剂]]还可使 [[聚丙烯非织造布|PP 非织造布]]与 β-CD 结合，该材料同样可吸附阳离子污染物，并对[[碱性蓝 3]] 具有良好的吸附性能（Haji, Khajeh Mehrizi, & Sarani, 2021）。改性后的 β-CD/CA 不仅能吸附织物上的染料分子，还能增强织物的特殊性能。例如，将 β-CD/CA 与纳米 $\cdot \mathrm { T i O } _ { 2 }$（[[纳米二氧化钛|NTO]]）结合并与[[真丝织物]]交联后，可改善其[[光催化性能]]和[[抗菌性能]]（Kiel & Poverenov, 2023），并具有较高的[[折皱回复角|干折皱回复角]]和湿折皱回复角（Zare, 2021）。研究发现，用生物基[[聚对苯二甲酸丙二醇酯]]（PTT）与 β-CD/CA 交联的聚合物对[[大肠杆菌]]的[[杀菌率]]可达 90.75%，这些环保织物在抗菌应用方面极具前景（Zhang et al., 2021）。使用[[微胶囊]]和 β-CD/CA 进行交联同样可以增强织物性能（Ben Abdelkader, Azizi, Bordes, Majdoub, & Chevalier, 2021），提高织物的[[耐水洗程度]]和[[拉伸强度]]。

## 4.1.3. [[农药]]的去除

[[阳离子型有机污染物]]（如染料和[[农药]]）主要具有水溶性，容易污染水源，对生物和非生物物种造成严重问题（Junthip, 2019）。去除农药污染物的方法有很多，例如物理方法，如[[离子交换]]（Burns, Hayes, & Stacey, 1973; Cocenza, de Moraes, Beppu, & Fraceto, 2012; Humbert, Gallard, Suty, & Crou´e, 2008; Leite, dos Reis, Robaina, Pacheco, & Cassella, 2013; Santos, Schaule, Alves, & Madeira, 2013）、[[过滤]]（Cocenza et al., 2012; Santos et al., 2013）和[[吸附]]（Leite et $\mathrm { a l . , }$ 2013），生物方法，$\mathrm { e . g . , }$ [[真菌分解]]（Zayats et al., 2013），以及化学方法，如[[电化学处理]]（Dhaouadi & Adhoum, 2009; Zayats et al., 2013）和[[萃取]]（Dhaouadi & Adhoum, 2009）。[[柠檬酸|CA]] [[交联]]的 [[β-环糊精|β-CD]] 聚合物在该领域具有特殊性能，例如已被用于从水溶液中去除[[百草枯|百草枯（PQ）]]。研究发现，最终反应产率为 70.2%，离子交换容量为 3.92 mmol $\mathbf { g } ^ { - 1 }$，β-[[环糊精|CD]] 的活性含量经[[分光光度法]]测定为 0.29 mmol $\mathbf { g } ^ { - 1 }$，并且所制备的聚合物在吸附 PQ 后发生溶胀。

通过使用 [[β-CD 纳米海绵]][[吸附]]，可以实现从水中去除这些危险污染物。在另一个实例中，[[纳米海绵]]材料是在 [[聚乙烯醇|PVA]] 存在条件下，通过 [[β-环糊精|β-CD]] 与 [[柠檬酸|CA]] [[交联]]生成的，产率为 60.2%，如图 17 所示（Martwong et al., 2021）。分析表明，当 -COOH 基团含量为 3.14 mmol ${ \mathbf g } ^ { - 1 }$ 时，β-[[环糊精|CD]] 浓度为 0.335 mmol ${ \mathbf g } ^ { - 1 }$，[[溶胀度|溶胀率]]为 96.4%，在 [[百草枯|PQ]] 初始浓度为 25 mg L 时，PQ 去除率可达 94.5%。此外，当[[BET|比表面积]]为 $0 . 1 7 6 6 \ \mathrm { m } ^ { 2 } \ \bar { \mathrm { g } } ^ { - 1 }$、[[孔体积]]为 $5 . 2 \times 1 0 ^ { - 4 }$ $\mathrm { c m } ^ { 3 } \ \mathrm { g } ^ { - 1 }$ 时，经再生实验测定，可以实现较高的去除率。PVA 的加入可以降低阴离子特性，但 PVA 的长链和交联结构可以提高[[氢键]]吸附能力。因此，PVA 对新型 β-CD 纳米海绵的制备十分重要，该材料可进一步开发用于去除[[农药]]。

由于 [[β-环糊精|β-CD]] 内部具有特殊的空腔骨架和通道，金属离子可以通过[[离子交换]]被[[吸附]]，并可用于制备检测各种有机化合物和金属离子的[[传感器]]。以 [[柠檬酸|CA]] 作为[[交联|交联剂]]（Heydari & Sheibani, 2015），在[[蒙脱石|蒙脱石（MMT）]]表面聚合 β-[[环糊精|CD]]，制备出一种复合材料，该材料是一种[[电化学传感器]]，可以测定 [[百草枯|PQ]] 含量。新型有机 MMT 修饰的[[玻碳电极]]（GCE）的峰电流是原始材料黏土 GCE 峰电流的 11 倍，该技术已成功应用于 PQ 的测定。

## 4.1.4. 放射性物质

核工业排放的大量[[放射性废水]]对人类社会的危害极大。元素铀是废水中的主要污染物，因此拥有新型高效[[吸附]]材料和技术来处理[[放射性污染]]废水非常重要。特别是，合成的[[β-环糊精|β-CD/CA]]聚合物能够从水溶液中去除铀，因为[[柠檬酸|CA]]中的官能团可以提供吸附位点（Li等，2019）。在pH 4.0时，最高吸附量为92.2 mg $\mathbf { g } ^ { - 1 }$。

利用[[β-环糊精|β-CD/CA]]和[[多糖]][[交联]]制备的新型[[水凝胶]]基质可以[[吸附]]芳香族化合物（Petitjean & Isasi，2021），在化学[[废水处理]]中具有广阔的应用前景，并可进一步研究用于含有芳香族化合物的更复杂体系。

## 4.2.1. [[药物载体]]

[[β-环糊精|β-CD]]衍生物已被用作[[阿霉素]]的[[药物载体]]，能够提高药物敏感性并增强阿霉素的细胞活性。因此，采用绿色合成方法合成了[[柠檬酸|CA]][[交联]]的β-[[环糊精|CD]]聚合物。它们在药物释放后更容易通过肾脏排泄从体内清除，在药物载体领域得到了更广泛的应用。

在另一个实例中，由[[壳聚糖|CS]]和[[柠檬酸交联β-环糊精|CA交联β-CD]]组成的新型载体被制备为[[姜黄素]]的[[药物载体]]。姜黄素可与[[β-环糊精|β-CD]]形成[[包合物]]，随后[[主客体包合物]]被CS包裹。将含姜黄素的[[柠檬酸|CA]][[交联]]β-[[环糊精|CD]]包封到壳聚糖中，使姜黄素能够延长释放时间。该复合物（Karpkird等，2020）不仅可以提高姜黄素的水溶性，还可以通过延长释放时间改善对[[前列腺癌细胞]]的治疗效果，如图18所示。还深入研究了pH和β-CD浓度对负载效率的影响，发现最稳定的[[纳米颗粒|NPs]]在pH为4时形成。在β-CD浓度为30 mg mL<sup>−</sup> <sup>1</sup>时，[[ζ电位|zeta电位]]降低，表明CS与[[水不溶性β-CD聚合物|β-CDP]]之间的离子排斥作用减弱。并且在特定时间形成了NPs聚集，导致大量游离姜黄素释放。

[[多孔二氧化硅]]作为纯材料或复合材料被广泛用于生物医学中的药物释放。[[β-环糊精|β-CD]]-Si 的药物传输性能通过 [[柠檬酸|CA]] [[交联]] β-[[环糊精|CD]] 与多孔[[二氧化硅]]的功能化修饰进行了测试，该材料可作为[[环丙沙星]]和[[泼尼松龙]]的载体（Hernandez-Montelongo et al., 2014）。此外，CA 交联 β-CD 还可制备用于先进生物医学领域的[[水凝胶]]。有趣的是，水凝胶可以通过物理、化学和辐射交联由聚合物制备（Ghorpade, Dias, Mali, & Mulla, 2019）。由于[[吸附]]行为，凝胶未来也具有生物医学应用潜力。

以 [[柠檬酸|CA]] 作为 [[β-环糊精|β-CD]] 和[[缩水甘油基三甲基氯化铵|缩水甘油基三甲基氯化铵（GTMAC）]]的[[交联|交联剂]]，合成的 -[[环糊精|CD]]/CA-GTMAC 可填充到多孔纺织支架中，该支架可储存药物并用于[[药物递送]]应用（Junthip, Tabary, Leclercq, & Martel, 2015）。由于[[天然沸石]]具有大孔结构，因此可作为药物递送载体。将 [[水不溶性β-CD聚合物|β-CDP]]/CA 改性并与天然沸石联合使用，可以实现[[布洛芬]]的负载和释放（Jahangard, Baghbanian, & Khaksarmaghami, 2022），这非常有应用前景。另一种药物[[萃取]]剂是由 β-CD/CA-[[聚乙烯醇|PVA]]-CuO 制备的[[纳米纤维吸附剂]]，可同时从生物体液中萃取[[抗抑郁药]]（Kharazmi, Hosseini, & Ebrahimzadeh, 2023）。

## 5. 结论

总之，本综述总结了 [[柠檬酸|CA]] [[交联]] [[β-环糊精|β-CD]] 复合材料在合成与应用方面的最新进展。$\mathrm { \beta - C D , }$ 作为一种具有独特结构的大环分子，常与其他材料复合以实现许多有趣的应用，而 CA 无毒、无害、廉价且易得，是优良的交联剂，CA 交联 β-[[环糊精|CD]] 具有广泛的应用前景。β-CD 的空腔和 CA 上的羧酸均可用于污染物的[[吸附]]。我们认为，吸附材料的设计应认真考虑集成材料的物理化学性质、吸附结合位点以及吸附场景。在环境和生物医学领域的应用中，CA 和 β-CD 的无毒、无害特性得到充分发挥，并在材料设计时充分考虑[[生物相容性]]、生物降解性和力学性能。该体系的进一步拓展可以通过以下方式实现。

其次，在环境相关领域，目前的研究主要集中在检测和[[吸附]]方面，而对降解的关注较少。但有害物质的降解同样非常重要，因此可以将该体系与[[光催化降解]]和[[电催化降解]]相结合，这可能带来特殊的发现。此外，放射性物质的吸附也是一个具有前景的应用方向。利用 [[β-环糊精|β-CD/CA]] [[交联]]制备的新型[[水凝胶]]基质在化学[[废水处理]]中具有良好应用前景，并可进一步研究用于含芳香族化合物的更复杂体系。

第三，作为一种[[水凝胶]]材料，绿色合成方法一直非常重要。[[β-环糊精|β-CD/CA]] 合成的水凝胶是一种绿色材料，对[[酚类化合物]]具有高保留率，基于 β-[[环糊精|CD]]/[[柠檬酸|CA]] 的水凝胶对其他污染物的[[吸附]]还可以进一步研究。水凝胶材料也可用于[[绝缘涂层]]和[[荧光涂层]]等领域，其应用还可以进一步拓展。

第四，在医药领域，另一种药物[[萃取]]剂可以同时从生物体液中提取[[抗抑郁药]]。其在杀菌剂和除草剂方面的潜在应用也值得进一步开发。

第五，在电化学领域，提高 [[β-环糊精|β-CD/CA]] 的水溶性可用作[[硅电极]]的黏结剂，这也为 β-[[环糊精|CD]]/[[柠檬酸|CA]] 的应用拓展了新的思路。

[[β-环糊精|β-CD/CA]]体系在结构方面还有进一步发展的可能。可以用其他多元酸结构如CTCA或乳酸替代[[柠檬酸|CA]]，而β-[[环糊精|CD]]则可以替换为分子量更大的[[γ-环糊精|γ-CD]]或功能化环糊精衍生物，例如[[羟丙基β-CD]]、[[羧甲基β-CD]]、二乙烯三胺-β-CD等。此外，反应催化剂也有进一步开发的空间。针对目标复合材料，比较不同策略和反应条件非常有趣。在另一个例子中， $\mathrm { N a H _ { 2 } P O _ { 3 } }$ 也可以用作催化剂，通过[[酯化反应]]对 CAβ-CD 进行类似的 CA 引导[[交联]]反应。替代 $\mathrm { K H _ { 2 } P O _ { 4 } }$ 通过 [[次磷酸钠|SHP]] $\mathrm { N a H _ { 2 } P O _ { 3 } }$ 由于催化剂的性能取决于众多反应因素，包括但不限于热力学问题，我们认为未来仍需开展大量研究工作。这些措施可能有助于相关性能的提升。

我们相信，这篇综述能够引起相关领域更多研究者的关注，并有助于发掘该领域中更多的机遇。
