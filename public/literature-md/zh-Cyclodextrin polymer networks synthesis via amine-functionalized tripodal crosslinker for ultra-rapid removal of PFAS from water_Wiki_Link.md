# 通过胺官能化[[TriPod交联剂|三足交联剂]]合成[[环糊精]]聚合物网络用于超快速去除水中[[全氟和多氟烷基物质|PFAS]]

Monu Verma<sup>1</sup>, Youngmin Hong<sup>1</sup>, Krishna Pal Singh<sup>2</sup>, Vinod Kumar<sup>3,4</sup>, Shu-Yuan Pan<sup>5</sup>, Cong Li<sup>6</sup>, Gyandshwar Kumar Rao<sup>7</sup>, Manisha Nanda<sup>8</sup>, Sanjay Kumar Arora<sup>9</sup> & Hyunook Kim<sup>1</sup>

在此，我们开发了一种以三足胺[[交联]]的[[环糊精|β-环糊精]]（[[β-环糊精|β-CD]]）基聚合物，以证明其对短链和长链[[全氟和多氟烷基物质]]（PFASs）均具有优异[[吸附]]性能的协同效应。[[吸附动力学|动力学]]研究表明，在2 min内即可实现快速吸附（在1 µg L<sup>−1</sup>下，除[[全氟丁酸|PFBA]]外，九种PFASs的吸附率约为100%；在$2 0 0 \mu \ g \mathsf { L } ^ { - 1 }$下各自吸附率>86%）。[[吸附等温线|等温线]]结果显示其具有优异的吸附亲和力和容量，对[[全氟丁烷磺酸|PFBS]]的$K _ { \mathsf { L } } = 0 . 3 1 0 \pm 0 . 1 8 0 \mathsf { L } \mathsf { m g } ^ { - 1 }$ $q _ { \mathrm { m } } { = } 2 4 6 . 2 0 \pm 1 4 . 8 0 \mathrm { m g \ y ^ { - 1 } }$，对[[全氟辛烷磺酸|PFOS]]的$K _ { \mathrm { L } } = 0 . 9 8 0 \pm 0 . 2 6 0 \mathrm { L m g ^ { - 1 } } , q _ { \mathrm { m } } = 5 8 7 . 1 0 \pm 5 4 . 5 0 \mathrm { m g } \mathrm { Q ^ { - 1 } }$，显著优于传统[[活性炭]]和[[树脂]]。该吸附剂在加标PFASs的[[工业废水]]中表现有效，去除效率为55–100%，且不受共存污染物的影响。吸附机理证实了β-CD空腔内疏水包合作用与[[胺基]][[静电相互作用]]的联合作用。总体而言，这项工作展示了一种针对PFAS污染水和[[废水处理]]的先进分子设计策略。

[[全氟和多氟烷基物质]]（PFASs）是一类高度稳定的氟化化合物，广泛用于各种商业和工业应用，包括防水纺织品、[[半导体制造]]、消防活动、化妆品、食品包装和不粘炊具涂层<sup>1,2</sup>。其广泛使用归因于其独特的物理化学性质，如高表面活性、两亲性（兼具亲水和疏水）、以及优异的化学和热稳定性<sup>2–4</sup>。然而，其普遍存在已导致全球水资源污染。此外，其[[生物累积性]]、毒性以及在环境中的持久性，即使在低慢性暴露水平下，也引起了科学界的重大关注，推动了预防和减轻PFAS污染的努力<sup>1,5,6</sup>。在不同PFASs中，长链[[全氟羧酸]]（PFCAs）和[[全氟磺酸]]（PFSAs）是广泛检测到的一类，监管工作主要集中于长链PFASs，如[[全氟辛酸|八碳全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（[[全氟辛磺酸|PFOS]]）。这些长链PFASs具有更高的毒性且抗降解。因此，为响应对长链PFASs的监管限制，短链衍生物，如[[全氟丁酸|四碳全氟丁酸]]（PFBA）和[[全氟丁烷磺酸]]（[[全氟丁磺酸|PFBS]]），已被引入作为许多过程的替代品。然而，新兴研究揭示，这些短链PFASs同样具有毒性问题，表现出更大的环境迁移性，并且与长链对应物相比，显示出更强的抗降解和去除能力<sup>7,8</sup>。因此，开发针对PFASs，特别是短链变体的有效处理和修复策略，是紧迫的科学和环境优先事项。

[[吸附]]是处理受 [[全氟和多氟烷基物质|PFAS]] 污染水体最有前景的方法之一<sup>4,9</sup>。在不同类型的传统吸附剂中，[[活性炭]]（ACs）在全规模吸附过程中应用最为普遍<sup>10,11</sup>。然而，它们对 PFASs 的亲和力为中至低等，尤其是对短链 PFASs，并且表现出受扩散限制的缓慢[[吸附动力学]]<sup>12–14</sup>。使用阴离子交换（AE）[[树脂]]已将这些缺点降至最低，但其存在由溶解性[[天然有机物]]（[[天然有机质|NOM]]）和无机成分引起的污染问题，这些物质在水体中普遍存在，使其成为成本高且效率低的解决方案<sup>12,15</sup>。这些挑战凸显了开发其他先进吸附剂的迫切需求，例如[[壳聚糖珠]]<sup>16</sup>、[[环糊精]]聚合物<sup>1,17–19</sup>、[[金属有机框架]]（MOF）<sup>20,21</sup>和[[共价有机框架]]（COF）<sup>3,22</sup>，以有效去除痕量浓度（μg L<sup>−1</sup>）下的短链和长链 PFASs。然而，仍需要开发新的吸附剂以在同一浓度下快速去除 PFASs。

基于[[环糊精|β-环糊精]]（[[β-环糊精|β-CD]]）的不溶性聚合物网络已成为去除[[全氟和多氟烷基物质|PFASs]]的高效[[吸附]]剂<sup>1,4,17–19</sup>。β-CD是无毒、可商业化获得的大环低聚糖，由七个葡萄糖亚基组成，已被广泛研究用于通过吸附和[[膜分离]]过程去除[[有机微污染物]]<sup>23</sup>。β-CD的独特结构具有疏水性内腔，可与许多有机微污染物形成[[主客体包合物]]，包括尺寸和形状合适的PFASs<sup>4,24–27</sup>。对于1:1主客体复合物，即β-CD-[[全氟辛酸|PFOA]]和β-CD-[[全氟辛烷磺酸|PFOS]]，β-CD分别表现出$5 . 0 \times 1 0 ^ { 5 }$和$7 . 0 \times 1 0 ^ { 5 } \mathrm { M } ^ { - 1 }$的强缔合常数<sup>1</sup><sup>28</sup>。有趣的是，这些基于β-CD的[[交联]]吸附剂表现出更高的吸附亲和力、对PFASs的靶向选择性以及快速[[吸附动力学]]，其[[速率常数]]比未交联的CDs和[[活性炭|ACs]]高15–200倍。这些性质高度依赖于交联链段和交联剂类型。它们调节吸附剂对不同PFASs的吸附容量、动力学和选择性。例如，与$\operatorname { A C } s ^ { 2 9 }$相比，带有[[四氟对苯二甲腈]]（TFN）连接基的聚合物网络对阳离子和中性有机微污染物表现出优异的去除率。然而，聚合过程中引入的阴离子酚盐基团的存在导致亲和力可变，主要有利于中性和阳离子微污染物，而对阴离子物种（包括PFOA）的吸附较差<sup>19</sup>。然而，将TFN的腈基后聚合还原为氨基（在中性和酸性pH下保持阳离子形式）后，其选择性发生逆转，从而对有效去除阴离子微污染物（包括环境相关浓度的12种阴离子PFASs）产生更高的亲和力<sup>27</sup>。这些[[官能团]]促进了对阴离子PFASs（包括短链和支链PFASs）的吸附，而这些PFASs通常与β-CD表现出较弱的[[主客体相互作用]]。这种改善的吸附性能归因于吸附剂与目标污染物之间的互补[[静电相互作用]]。Wang等人报道了将氨基引入β-CD以合成不同尺寸的交联聚合物（[[β-CD-COFs]]），以改善结合位点，从而实现对许多阴离子PFASs（包括短链衍生物）的快速去除和高吸附容量<sup>17</sup>。合成的β-CD-COFs对四种短链和长链PFASs表现出快速动力学和高吸附容量（0.33–1.51 mmol g<sup>−1</sup>），显著优于传统[[树脂]]和ACs。迄今为止，许多研究报道了β-CD聚合物对PFASs的高吸附容量。然而，不同水参数以及[[实际废水]]系统中含有不同无机和有机杂质的废水的影响仍需研究。此外，这些聚合物还引发了关于其对短链PFASs显著吸附容量和动力学速率以及胺在与β-CD交联并为PFASs吸附提供结合位点中的相对作用的基本问题。此外，β-CD腔内主客体相互作用与氨基静电相互作用在捕获PFASs中的相对重要性尚不清楚，特别是在 聚合后修饰聚合物。

本研究在无水条件下，通过[[三(2-氨基乙基)胺]]（TREN）与[[五氟苯甲醛]]的缩合反应，随后使用[[硼氢化钠]]还原亚胺，合成了一种含有三个[[胺基]]的[[TriPod交联剂|三脚架交联剂]]。然后，通过[[亲核芳香取代反应]]将该[[交联]]剂与[[β-环糊精|β-CD]]结合，得到一种含三胺的[[β-CD-TriPod聚合物]][[吸附]]剂。对该吸附剂吸附九种[[全氟和多氟烷基物质|PFASs]]（包括短链变体）的性能进行了评估。还研究了该吸附剂在[[静电相互作用]]和[[主客体包合相互作用]]协同组合方面的表现。系统考察了一系列间歇吸附参数，包括pH、接触时间、初始浓度变化、[[再生]]和[[可重复使用性]]，以获得对选择性长链[[全氟辛烷磺酸|PFOS]]及其短链替代物，即[[全氟丁烷磺酸|PFBS]]的最佳结果。最后，研究了[[β-环糊精三脚架吸附剂|β-CD-TriPod]]吸附剂在[[天然有机物]]（[[天然有机质|NOM]]）存在下以及在实际[[工业废水]]中的吸附性能，以证明其在处理受短链和长链PFASs污染水体方面的优越能力。

## [[吸附]]剂的表征

[[β-CD-TriPod聚合物|β-CD-TriPod 聚合物]]是通过 [[TriPod交联剂|TriPod 交联剂]]与 [[β-环糊精|β-CD]] 之间的[[亲核芳香取代反应]]合成的（图 1）。利用[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）、[[核磁共振]]（NMR）和[[液相色谱-质谱联用]]（LC MS）确认了成功合成以及各种[[官能团]]的存在。[[环糊精|β-CD]]、TriPod [[交联]]剂和 [[β-环糊精三脚架吸附剂|β-CD-TriPod]] 聚合物[[吸附]]剂的 FTIR 数据如图 2a 所示。由三个芳基组成的 TriPod 交联剂在 3351 cm<sup>−1</sup>、2839 cm<sup>−1</sup>、1654 cm<sup>−1</sup>、1494 cm<sup>−1</sup> 和 1154 cm<sup>−1</sup> 处表现出明显的振动模式，分别对应于 N−H 伸缩、脂肪族 N−C 伸缩、N−H 弯曲、芳香族 C=C 伸缩和芳香族 C−F 伸缩。在 β-CD-TriPod 聚合物中，3382 cm<sup>−1</sup>、2924 cm<sup>−1</sup> 和 1024 cm<sup>−1</sup> 处出现了强谱带，分别对应于 β-CD 部分的 O−H 伸缩、脂肪族 C−H 伸缩和 C−O 伸缩。这些谱带连同来自 TriPod 交联剂的振动峰，确认了聚合物网络吸附剂的成功形成。表 S2 总结了在 β-CD-TriPod 聚合物网络中观察到的 β-CD 和 TriPod 交联剂的不同振动模式列表。合成交联剂的 H1 NMR 谱（600 MHz，[[CDCl]] ）在 δ 1.63（s，3H，NH）、2.4（t，6H，N CH2）、2.457（t，6H，NCH CH ）和 3.88（s，6H，Ar CH ）处显示信号，确认了 β-CD 成功引入 TriPod 交联剂上（图 S1）。合成三脚架交联剂的[[电喷雾电离|电喷雾电离源]]（ESI）MS 在 m/z 687.1 和 688 处显示出显著峰，支持形成了高纯度交联剂（图 S2）。这些 FTIR、NMR 和 MS 数据确认了高纯度 Tripod 交联剂和 β-CD-TriPod 吸附剂的形成。β-CD-TriPod 聚合物的[[热重分析]]（TGA）数据如图 2b 所示，展示了三步失重过程，之后在 $6 0 0 ^ { \circ } \mathrm { C } .$ 处约保留 25% 的重量。第一步失重观察至 65 °C，归因于水分损失；第二步失重在 220–390 °C 之间，可能归因于 β-CD 和 TriPod 聚合物的热分解；第三步失重归因于碳骨架的分解<sup>30</sup>。使用[[场发射扫描电子显微镜]]（FESEM）研究了所制备 β-CD-TriPod 吸附剂的形貌（图 2c、d），显示出刚性多孔型网络。如前所报道<sup>25</sup>，这种类型的结构有利于 [[全氟和多氟烷基物质|PFASs]] 的吸附。β-CD-TriPod 聚合物的[[元素映射]]如图 S3 所示，显示碳（C）、氧（O）、氮（N）和氟（F）的均匀分布。连接在 FESEM 上的[[能量色散X射线光谱|能量色散 X 射线光谱]]（EDS）以原子百分比（at%）量化[[元素组成]]，显示 C：64.87%、N：7.91%、O：21.40% 和 F：5.82%。这种元素映射和组成支持通过 β-CD 大分子与 TriPod 交联剂之间的亲核芳香取代反应成功交联，这是由于 O 元素与 N 和 F 的存在。

## pH 影响

溶液 pH 是去除 [[全氟和多氟烷基物质|PFASs]] 的关键参数，因此，我们探究了 pH 对九种 PFASs 混合物形式以及单独 [[全氟丁烷磺酸|PFBS]] 和 [[全氟辛烷磺酸|PFOS]] 在 [[β-CD-TriPod聚合物|β-CD-TriPod 聚合物]]上[[吸附]]的影响（图 3a、b）。数据表明，短链和长链 PFASs 在 pH 2、5 和 7 时的吸附效率均显著较高，但在 pH 11 时大幅降低。在 pH 2 时，去除效率分别为 66.50%、88.90%、90.20%、94.30%、93.60%、97.30%、98.50%、98.70% 和 99.70%，而在 pH 9 时分别降至 10.80%、28.50%、27%、71.80%、42.40%、67.60%、95.70%、86.70% 和 96.20%，分别对应 [[全氟丁酸|PFBA]]、[[全氟丁磺酸|PFBS]]、[[全氟己酸|PFHxA]]、[[全氟己烷磺酸|PFHxS]]、[[全氟庚酸|PFHpA]]、[[全氟辛酸|PFOA]]、[[全氟辛磺酸|PFOS]]、[[全氟壬酸|PFNA]] 和 [[全氟癸酸|PFDA]]。其中，长链 PFASs（包括 PFHxS、PFHpA、PFOA、PFOS、PFNA 和 PFDA）的吸附效率在 pH 5 时保持相对稳定，并且在 pH 7 时随 pH 增加仅略有变化。这一趋势表明，负载氨基的 [[β-环糊精三脚架吸附剂|β-CD-TriPod]] 聚合物在酸性条件下对不同 PFASs 具有强亲和力。观察到的去除效率随 pH 增加而下降的现象，可由 [[β-环糊精|β-CD]]-TriPod 聚合物吸附剂的表面化学和电荷性质以及 PFASs 的形态分布来解释。根据估算的 pK 值（其为负值或较小正值）（表 S3），本研究考察的 PFASs 在测试 pH 范围内表现出阴离子特征，而引入 [[环糊精|β-CD]] 的氨基在 pH 7 时的 [[zeta电位|zeta 电位]]为 1.45 ± 0.70。因此，这些基团在酸性溶液中被[[质子化]]，并促进了 PFASs 吸附的[[静电相互作用]]。在较低 pH 水平下，较高的正 zeta 电位提供了更强的静电相互作用，从而产生更高的去除效率。然而，随着 pH 增加（在碱性溶液中），由于 zeta 电位为负，β-CD-TriPod 聚合物表面变得更负，并且[[交联]]剂中的弱碱性[[官能团]]（−NH₂）转变为正电性较低的表面（即[[去质子化]]），导致与 PFASs 发生静电排斥，因此观察到去除效率下降<sup>4</sup>。对于单独的 PFOS 和 PFBS，在 pH 3 和 5 时几乎实现了完全去除效率，PFOS 的这一效率一直维持到 pH 9，而 PFBS 在 pH 9 时则下降至 12.40%。先前的研究报道，全氟化链与 β-CD 之间的[[疏水相互作用]]，连同静电相互作用，在线性长链 PFASs 的吸附中发挥重要作用，因此 PFOS 实现了 100% 的去除效率。然而，短链和支链 PFASs 主要通过静电相互作用被吸附，而该作用由于氨基去质子化而减弱，因此观察到 PFBS 在 pH 5.0 之后去除效率突然下降（图 3）。这些发现突显了静电相互作用在短链 PFASs 吸附中的关键作用，而静电和疏水（主客体）相互作用在长链 PFASs 吸附中均发挥作用。图 S4 仅展示了九种 PFASs 在 pH 2 和 5 时在 β-CD-TriPod 聚合物上的数据。总体而言，PFASs 经常存在于某些酸性废水（低 pH 条件）中，因此，所制备的 β-CD-TriPod 能够有效去除 PFASs，包括短链 PFASs，而这类物质传统上难以用 [[活性炭|ACs]]、[[炭质吸附剂|GAC]] 和 [[粉末活性炭|PAC]] 等常规吸附剂从水中吸附。

## 接触时间效应与[[吸附动力学]]

评估了合成的 [[β-CD-TriPod聚合物|β-CD-TriPod 聚合物]]的[[吸附]]性能，以描述九种 [[全氟和多氟烷基物质|PFASs]] 在混合物中以及单独使用 [[全氟丁烷磺酸|PFBS]] 和 [[全氟辛烷磺酸|PFOS]] 时的[[吸附动力学]]和平衡，实验在环境相关浓度 $( 1 \mu \mathrm { g L } ^ { - 1 } )$ 下进行。动力学实验结果见图 4a、b，其短时间间隔数据见图 S5 和 S6，包括平均数据和[[标准偏差]]（%）。此外，图 S7 显示了九种 PFASs 在较低浓度下短时间间隔内的吸附平衡。数据表明吸附平衡迅速，在 2 min 内即达到，目标阴离子 PFASs 的去除效率 >99%，包括链长为 4 至 10 的[[全氟磺酸盐]]（[[全氟磺酸|PFSA]]）和[[羧酸盐]]（[[全氟羧酸|PFCA]]），但 [[全氟丁酸|PFBA]] 除外，其可在 15 min 内达到平衡。此外，如图 4b 所示，[[β-环糊精三脚架吸附剂|β-CD-TriPod]] 聚合物在 $1 \mu \mathrm { g L } ^ { - 1 } ;$ 下对短链 [[全氟丁磺酸|PFBS]] 和长链 [[全氟辛磺酸|PFOS]] 单独均表现出优异的吸附亲和力，2 min 内去除效率 <99.50%。该吸附平衡时间显著短于先前报道的常规吸附剂，包括各类 ACs、GAC 和 PAC（表 S5），证实了所制备的 β-CD-TriPod 聚合物在极快去除阴离子 PFASs 方面的潜力。对于具有相同碳数（C）的 PFASs，注意到一个有趣的现象：PFBS 的去除效率（100%）高于 PFBA（75.45%）。这一差异归因于 PFBS 中磺酸头基的存在，其具有更高的电子密度，能够以更好的方式与 β-CD-TriPod 吸附剂中现有的质子化氨基相互作用<sup>17</sup>。总体而言，在环境相关浓度下从混合物或单独 PFASs 获得的结果证实，[[β-环糊精|β-CD]]-TriPod 吸附剂能够有效吸附目标 PFASs，将其残留浓度降至 25 ng L<sup>−1</sup> 以下，这显著低于[[美国EPA|美国 EPA]] 针对 PFOS 和 [[全氟辛酸|PFOA]] 设定的 70 ng g<sup>−1</sup> 健康咨询水平。早期研究也报道，长链 PFASs 比短链 PFASs 更容易被吸附，且去除效率随 PFASs 尾链长度减小而降低。这一趋势归因于包合物形成的稳定性，其取决于适合进入 [[环糊精|β-CD]] 空腔的潜在客体（PFASs 的尾链）的大小<sup>17</sup>。由于更强的[[疏水相互作用]]，β-CD 配合物的稳定常数随 PFAS 链长增加而增加。在 β-CD 与 PFASs 之间基于溶液的滴定研究中也观察到类似趋势<sup>28</sup>。此外，长链 PFASs 表现出更强的疏水性，增强了其从水溶液转移到固体吸附剂的趋势，从而提高吸附亲和力。在这种机理中，长链 PFASs 通过[[静电相互作用]]与[[质子化]]氨基相互作用，以及通过 β-CD 空腔内的疏水相互作用；而短链 PFASs，如 PFBA 和 PFBS，由于 β-CD 内腔中[[范德华相互作用]]减弱，结合效率较低。此外，长链 PFSAs 可能更有效地与相对较宽的 β-CD-TriPod 内部相互作用，因为其分子结构允许更好地整合到吸附剂的多孔网络中，如 [[场发射扫描电子显微镜|FESEM]] 所观察到的，进一步导致参与 去除效率。

## [[天然有机物|NOM]] 效应

[[天然有机物|NOM]] 是另一个重要因素，由于具有污染特性，它会显著影响水中污染物的分布和 [[活性炭|ACs]] 的[[吸附]]效率，而其对基于 [[β-环糊精|β-CD]] 的聚合物则不太敏感<sup>26</sup>。因此，在[[腐殖酸]]（HA，[[天然有机质|NOM]] 的重要组分）存在下评估了九种 [[全氟和多氟烷基物质|PFASs]] 的吸附。实验通过在水基质中取 2 $\bar { \mathsf { \Pi } } \mathrm { m g L } ^ { - 1 }$ 浓度的 HA 进行，其中每种 PFAS 的初始浓度（1 μg L<sup>−1</sup>）和 [[β-CD-TriPod聚合物|β-CD-TriPod]]（10 mg L<sup>−1</sup>）聚合物在 pH 5.0 条件下。结果如图 6a 所示，表明 HA 的存在轻微抑制了短链 PFASs 的吸附，而长链 PFASs 的吸附在水中未受到显著抑制。这种选择性干扰可能是由于 [[β-环糊精三脚架吸附剂|β-CD-TriPod]] 对长链 PFAS 具有更高的结合亲和力，其优先占据吸附位点而非短链 PFASs，而这些干扰是由 NOM 存在驱动吸附抑制所引起的<sup>35</sup>。尽管如此，这些发现清楚地证实了 [[环糊精|β-CD]]-TriPod 对 PFASs 去除的优越[[抗污染性]]和显著选择性。

## [[再生]]与稳定性

[[再生]]与[[可重复使用性]]是评估[[吸附]]剂在[[废水处理]]中经济性和实用性的关键参数。因此，通过将 50 mg [[β-CD-TriPod聚合物|β-CD-TriPod]] 分别加入 100 mL 含 $2 0 0 \mu \ g \mathrm { L } ^ { - 1 }$ [[全氟丁烷磺酸|PFBS]] 和 [[全氟辛烷磺酸|PFOS]] 的溶液中（pH 5.0），进行了连续五次[[吸附-脱附循环]]的再生与再利用实验，同时在[[甲醇]]中考察[[脱附]]性能。所得结果如图 6b 所示，表明 [[全氟丁磺酸|PFBS]] 和 [[全氟辛磺酸|PFOS]] 的效率均无显著损失，且其脱附量几乎等于吸附量。[[β-环糊精三脚架吸附剂|β-CD-TriPod]] 对 PFBS 和 PFOS 的吸附效率在第一次循环中均超过 99%，而在第五次吸附循环后分别下降至 96% 和 94%。第一次循环的脱附量超过 97%，在第五次脱附循环后，PFBS 和 PFOS 的脱附量分别维持在约 93% 和 96%。在相同实验条件下，使用 [[全氟丁酸|PFBA]]、PFBS、[[全氟辛酸|PFOA]] 和 PFOS 的混合物进行了额外的再生实验，结果如图 S9 所示。数据表明，对于长链 [[全氟和多氟烷基物质|PFASs]]（PFOA 和 PFOS），再生效率在多达五次循环中几乎保持稳定；而对于短链 PFASs（PFBA 和 PFBS），在第一次再生循环后观察到吸附效率显著降低，并在随后的四次循环中保持相对稳定。PFBA、PFBS、PFOA 和 PFOS 的吸附效率在第一次循环中分别为 63.50%、94%、97% 和 99.10%，五次循环后分别下降至 37%、63.50%、85.90% 和 93.70%。对短链 PFASs 的效率降低可能归因于其疏水性较弱，因为疏水性较弱的分子倾向于以更快的速率从吸附剂上释放。第一次循环后，长链 PFAS 分子以[[胺基]]和[[疏水空腔]]的形式更有效地竞争剩余吸附位点，并且由于其更高的疏水性，它们在短链 PFASs 之前被吸附。为了研究更快的脱附，进行了额外实验以评估 PFOS 在 10 分钟内用甲醇从 [[β-环糊精|β-CD]]-TriPod 上的快速脱附，结果如图 S10 所示。数据清楚地表明 PFOS 从 [[环糊精|β-CD]]-TriPod 吸附剂上完全脱附，证实了其与 [[颗粒活性炭|GACs]] 和 $\mathrm { P A C s } ^ { 3 6 }$ 等 [[活性炭|ACs]] 相比作为快速有效可重复使用吸附剂的潜力。

## [[吸附]]机理

最后，研究了[[吸附]]机理，以考察“长链和短链[[全氟和多氟烷基物质|PFASs]]如何与[[β-CD-TriPod聚合物|β-CD-TriPod吸附剂]]相互作用”。对于PFASs吸附，如前面各节所讨论，[[静电相互作用]]和[[疏水相互作用]]均为主要吸引力。为此，分别使用[[全氟丁烷磺酸|PFBS]]和[[全氟辛烷磺酸|PFOS]]进行了吸附平衡实验。在pH 5下，吸附物和吸附剂浓度分别选择为20 mg L<sup>−1</sup>和400 mg L<sup>−1</sup>。平衡后，将吸附剂过滤并干燥，用于[[元素映射]]、组成和[[FTIR]]分析，以分别研究PFASs吸附后的元素分布和组成以及[[官能团]]的变化。元素映射和分布如图S11和S12所示，表明除其他元素外，还新增了均匀分布的有色硫（S）元素信号点，证实了[[全氟丁磺酸|PFBS]]和[[全氟辛磺酸|PFOS]]在[[β-环糊精三脚架吸附剂|β-CD-TriPod]]吸附剂表面的吸附。在PFBS吸附的情况下（图S13），[[β-环糊精|β-CD]]-TriPod的C、N、O、F和S元素的[[元素组成]]以at%计分别为66.61%、7.0%、20.80%、5.33%和0.25%；在PFOS吸附的情况下（图S14），分别为66.04%、7.90%、18.58%、6.81%和0.67%。在元素组成中，值得注意的是，PFOS和PFBS吸附中$^ { \cdot } \mathrm { s } ^ { , }$的元素比（PFOS/PFBS）几乎等于在[[吸附等温线|等温线]]分析期间计算的其吸附容量之比，进一步支持了[[环糊精|β-CD]]-TriPod吸附剂中胺和疏水性β-CD空腔在通过静电和[[主客体包合物|主客体相互作用]]结合PFOS中的协同效应。为支持静电相互作用，比较了吸附前后的[[傅里叶变换红外光谱|FTIR]]数据（图S15），表明峰位置没有任何变化，除了在PFBS和PFOS吸附后[[胺基]]分别从3351 cm<sup>−1</sup>略微移动到3383 cm<sup>−1</sup>和3391 cm<sup>−1</sup>。此外，在PFBS吸附的情况下，在1216 cm<sup>−1</sup>处出现了一个新的S=O峰，而在PFOS吸附中为1242 cm<sup>−1</sup>，证实了PFBS仅通过静电相互作用被吸附，而PFOS则通过β-CD空腔内的疏水相互作用以及静电相互作用被吸附。此前，Wang等人报道了在短链PFBS吸附情况下与胺基的类似类型静电相互作用，而在长链PFOS吸附到含胺β-CD [[共价有机框架|COF]]上的情况下，使用[[静电势]]（ESP）计算过程同时存在静电和疏水相互作用<sup>17</sup>。正如在[[吸附动力学|动力学]]和等温线部分所讨论的，长链PFASs比短链更倾向于通过缺电子β-CD的空腔吸附；因此，PFOS可以通过疏水相互作用以及静电相互作用被吸附，而PFBS只能通过静电相互作用被吸附。

多种[[吸附]]剂的[[吸附动力学]]和吸附容量的详细比较见表S5。Yu等此前报道了[[全氟辛烷磺酸|PFOS]]在[[炭质吸附剂|GAC]]和[[粉末活性炭|PAC]]上的快速吸附，这归因于其大表面积和合适的[[孔隙率]]，可通过[[疏水相互作用]]形成[[胶束]]<sup>39</sup>。除此之外，[[β-CD-TriPod聚合物|β-CD-TriPod吸附剂]]在吸附动力学、吸附容量和亲和力方面明显表现出优越性，这可能是由于在[[β-环糊精|β-CD]]网络中引入了额外的[[静电相互作用]]，而这是增强去除短链和长链[[全氟和多氟烷基物质|PFASs]]效果的关键设计原则，使其成为一种先进的吸附剂解决方案。

总之，本研究报道了通过[[亲核芳香取代反应]]成功合成以含三个氨基的[[TriPod交联剂|三脚架交联剂]][[交联]]的[[β-环糊精|β-CD]]基[[吸附]]剂，并系统评估了其在不同浓度范围内从水中去除短链和长链[[全氟和多氟烷基物质|PFASs]]的效率。pH结果表明[[β-CD-TriPod聚合物]]在酸性条件下对PFASs具有强亲和力。[[拟二级动力学模型|PSO动力学模型]]的[[速率常数]]$( k _ { 2 } )$对于[[全氟丁烷磺酸|PFBS]]和[[全氟辛烷磺酸|PFOS]]分别为$2 1 0 . 5 0 \pm 2 2 . 1 0$和$2 7 7 . 1 0 \pm 1 6 . 1 0 \mathrm { g } \mathrm { m g } ^ { - 1 } \mathrm { h } ^ { - 1 }$，表明与先前报道的不同类型[[炭质吸附剂|GAC]]、[[粉末活性炭|PAC]]和其他吸附剂相比具有快速吸附。[[吸附等温线]]结果给出了[[Langmuir吸附等温线|Langmuir吸附容量]]，[[全氟丁磺酸|PFBS]]为$2 4 6 . 2 \bar { 0 } \pm 1 4 . 8 0 \mathrm { m g } \mathrm { g } ^ { - 1 }$，[[全氟辛磺酸|PFOS]]为$5 8 7 . 1 0 \pm 5 4 . 5 0 \mathrm { m g } \mathrm { g } ^ { - 1 }$，同时亲和系数(K)分别为0.31 ± 0.18和0.98 ± 0.26 L mg<sup>−1</sup>，强调了明确界定的[[静电相互作用]]与[[主客体包合物|主客体相互作用]]的协同组合是彻底去除PFASs的理想设计标准。通过简单[[甲醇]]洗涤进行的[[吸附-解吸]]过程在第五次循环后仍实现超过94%的吸附效率，证实了其相对较高的稳定性和[[可重复使用性]]。在真实废水基质中，效率未受其他有机和无机污染物的显著影响。吸附机理证实了静电相互作用在短链PFASs吸附中的作用，而长链PFASs的去除则通过静电和[[疏水相互作用]]共同实现。总体而言，结果表明[[β-环糊精三脚架吸附剂|β-CD-TriPod]]聚合物是PFASs修复的有效且有前景的候选材料，未来的研究将侧重于更深入地研究两性离子型、非离子型和阳离子型PFASs的去除及其在复杂[[废水处理]]系统中的相互作用。

## [[β-CD-TriPod聚合物|β-CD-TriPod吸附剂]]的合成

以含三个氨基的[[TriPod交联剂|三脚架交联剂]][[交联]]的[[β-环糊精|β-CD]]基[[吸附]]剂分两步制备：

第一步中，通过在[[三(2-氨基乙基)胺|三氟化胺]]（TREN）与[[五氟苯甲醛]]于无水条件下缩合，随后用[[硼氢化钠]]<sup>40</sup>将亚[[胺基]]团还原，制备了含三官能胺的三脚架单体[[交联]]剂。第二步中，如先前报道<sup>41</sup>，将[[TriPod交联剂|三脚架交联剂]]与[[β-环糊精|β-CD]]进行[[亲核芳香取代反应]]，得到含三个胺的[[β-CD-TriPod聚合物|β-CD-TriPod]]交联聚合物，如图1所示。为优化聚合物产率，系统评价了若干合成参数，包括[[环糊精|β-CD]]与三脚架交联剂的比例、溶剂浓度、碱的种类及碱的用量，详见Table S1。详细的合成步骤见SI。

三脚架单体[[交联]]剂的合成。第一步中，按照先前报道的方法<sup>40</sup>制备[[TriPod交联剂|三脚架交联剂]]。在氮气保护下，于室温下向[[五氟苯甲醛]]（1.764 g，9 mmol，3 equiv）的50 mL无水[[甲醇]]溶液中，于30 min内逐滴加入[[三(2-氨基乙基)胺|TREN]]（0.448 g，3 mmol，1 equiv）的30 mL无水甲醇溶液。搅拌24 h后，将溶液在冰浴中冷却，并加入少量过量的[[硼氢化钠|NaBH]]（0.454 g，12 mmol，4 equiv）。溶液再搅拌4 h，然后回流2 h。减压除去甲醇，残余物用氯仿和水萃取。收集的有机层用无水硫酸钠干燥，并在减压下蒸发。最后，使用[[二氯甲烷]]/甲醇（9.5/0.5）作为洗脱液，通过[[柱色谱]]纯化化合物，得到浅黄色固体。[[FTIR]]数据提供的峰位于3351 cm<sup>−1</sup>、2839 cm<sup>−1</sup>、1654 cm<sup>−1</sup>、1494 cm<sup>−1</sup>和1154 cm<sup>−1</sup>，分别对应于N−H伸缩振动、脂肪族N−C伸缩振动、N−H弯曲振动、芳香族C=C伸缩振动和芳香族C−F伸缩振动。[[核磁共振氢谱|1H NMR]]（600 MHz，[[CDCl]]）：δ 1.63（s，3H，NH），2.49（t，6H，N CH ），2.457（t，6H，NCH CH ），3.88（s，6H，Ar CH ）。该数据与先前报道的数据<sup>40</sup>良好一致。

[[TriPod交联剂|三脚架交联剂]]的优化合成。第二步中，向配备磁力搅拌棒的烘箱干燥的闪烁瓶中，加入适量的[[β-环糊精|β-CD]]（0.624 g，0.55 mmol，1 equiv）、TriPod[[交联]]剂（0.75 g，1.1 mmol，2 equiv）、K CO（1.520 g，11 mmol，20 equiv）和3.6 mL无水[[DMSO]]。将瓶置于预热的热搅拌板上$( 8 5 ^ { \circ } \mathrm { C } )$，并以500 rpm搅拌24 h。3 h内观察到凝胶化。将瓶冷却，粗产物经过滤、用HCl中和，然后通过在去离子$\mathrm { H } _ { 2 } \mathrm { O } \left( 2 \times 1 0 \mathrm { m L } \right)$中搅拌10 min、在[[THF]]（2 × 10 mL）中搅拌10 min、在[[二氯甲烷|CH Cl]] （1 × 10 mL）中搅拌10 min进行洗涤。将过滤后的固体装入茶包中，并用[[甲醇]]通过[[索氏提取]]活化一天。固体在真空烘箱中干燥，得到最终产物粉末。[[β-CD-TriPod聚合物]][[吸附]]剂的示意图如图1所示。

## 批式[[吸附]]实验

进行了一系列批式[[吸附]]实验，以在多位孵育器（[[DAIHAN Scientific]]，韩国）中、以200转/分钟（rpm）的振荡速率优化$2 4 ^ { \circ } \mathrm { C }$下[[全氟和多氟烷基物质|PFASs]]去除的吸附效率和容量。吸附实验的水样用0.20 μm[[醋酸纤维素注射器过滤器]]过滤后进行分析。所有实验的详细程序和条件见Text SI-3。

[[吸附]]剂的[[全氟和多氟烷基物质|PFAS]]去除效率由Eq. 1确定：

$$
\mathrm{Removal} (\%) = \frac {(C _ {0} - C _ {\mathrm{t}}) \times 100}{C _ {0}}\tag{1}
$$

其中$C _ { 0 } ( \mathrm { n g L ^ { - 1 } } )$）和$C _ { t } ( \mathrm { n g L } ^ { - 1 } )$分别为储备液和滤液中[[全氟和多氟烷基物质|PFAS]]的初始浓度和残留浓度。

结合到[[吸附]]剂上的[[全氟和多氟烷基物质|PFAS]]量使用Eq. 2确定：

$$
\text { Adsorption   capacity } \left(\mathrm{q} _ {\mathrm{t}}\right) = \frac {\left(\mathrm{C} _ {0} - \mathrm{C} _ {\mathrm{t}}\right)}{\mathrm{C} _ {\mathrm{A}}}\tag{2}
$$

其中q（mg $\mathbf { g } ^ { - 1 } )$为任意时刻[[吸附]]在固相上的[[全氟和多氟烷基物质|PFAS]]量，$\cdot ( \mathrm { h } ) ; C _ { 0 } ( \mathrm { n g L } ^ { - 1 } )$为样品中PFAS的初始浓度；$C _ { t } ( \mathrm { n g L } ^ { - 1 } )$为任意采样时间t（h）时液相中PFAS的浓度；$C _ { A } ( \mathrm { m g L ^ { - 1 } } )$为吸附剂浓度。

较高浓度的批式[[吸附动力学|动力学]]可使用[[Lagergren]]<sup>42</sup>和[[Ho]]与[[McKay]]<sup>43</sup>模型提出的非线性形式[[准一级动力学模型|准一级]]（[[拟一级动力学模型|PFO]]）和[[拟二级动力学模型|PSO模型]]描述，分别如Eqs. 3和4所示。

$$
\mathrm {q_ {t} = q_ {e} (1- e^ {- klt})}\tag{3}
$$

$$
q _ {t} = \frac {k _ {2} q _ {e} ^ {2} t}{1 + q _ {e} k _ {2} t}\tag{4}
$$

其中$q _ { t } ( \mathrm { m g g } ^ { - 1 } )$）和$q _ { e } ( \mathbf { m g g } ^ { - 1 } )$分别为时间t和平衡时[[吸附]]在固相吸附剂上的[[全氟和多氟烷基物质|PFAS]]量。$k _ { 1 } ( \mathrm { h } ^ { - 1 } )$和$k _ { 2 } \left( \mathrm { g } \mathrm { m g } ^ { - 1 } \mathrm { h } ^ { - 1 } \right.$ <sup>1</sup>）分别为[[准一级动力学模型|PFO]]和[[准二级动力学模型|PSO]]吸附[[速率常数]]。

使用非线性最小二乘回归生成了两种著名的[[吸附等温线|等温线]]模型拟合：[[Langmuir吸附模型|Langmuir]]和[[Freundlich吸附等温线]]。

[[Langmuir吸附模型|Langmuir]]。[[Langmuir吸附等温线|Langmuir等温线模型]]广泛适用于均质[[吸附]]表面，其中每个吸附位点只能结合一个吸附质。非线性形式的[[Langmuir模型]]见Eq. 5：

$$
q _ {e} = \frac {\mathrm {q_ {m} K_ {L} C_ {e}}}{1 + \mathrm {K_ {L} C_ {e}}}\tag{5}
$$

其中$q _ { e } ~ ( \mathbf { m g g } ^ { - 1 } )$为平衡时[[吸附]]的[[全氟和多氟烷基物质|PFAS]]量，$q _ { m }$（mg $\mathbf { g } ^ { - 1 } )$为平衡时吸附剂的[[最大吸附容量]]，$C _ { e }$（mg ${ \mathrm { ~ L ~ } } ^ { - 1 } )$为平衡时的残留PFAS浓度，$K _ { \mathrm { L } } \left( \mathrm { L } \operatorname { m g } ^ { - 1 } \right)$为与吸附能有关的[[Langmuir吸附模型|Langmuir]]常数。

[[Freundlich吸附模型|Freundlich]]。[[Freundlich模型|Freundlich]] 等温模型假设表面非均质，[[吸附]]热在表面上分布不均匀，且吸附位点不饱和。Freundlich 模型的非线性形式由式 6 表示。

$$
\mathrm {q_ {e} = K_ {F} C_ {e} ^ {1 / n}}\tag{6}
$$

其中 $q _ { e } ~ ( \mathbf { m g } { \mathbf { g } } ^ { - 1 } )$ 为平衡时[[吸附]]的 [[全氟和多氟烷基物质|PFAS]] 量，$C _ { e }$ $( \mathrm { m g L ^ { - 1 } } )$ 为平衡时水相中残留的 PFAS 浓度，$K _ { \mathrm { F } } \ [ ( \mathrm { m g } \mathrm { g } ^ { - 1 } ) ( \mathrm { L } \mathrm { m g } ^ { - 1 } ) ^ { 1 / n } ]$ 为 [[Freundlich吸附模型|Freundlich]] 常数，n 表示吸附强度，n 的大小反映吸附特性是良好 $( 2 < n < 1 0 )$ 、困难 $\left( 1 < n < 2 \right)$ 还是较差（n < 1）。

## β−CD-TriPod [[再生]]实验

将五十毫克 β−CD-TriPod 加入装有 [[全氟辛烷磺酸|PFOS]] 溶液（100 mL，$2 0 0 \mu \mathrm { g L } ^ { - 1 } )$ 的锥形瓶中。[[吸附]]实验在培养箱中 $\mathrm { a t } 2 4 ^ { \circ } \mathrm { C }$ 进行 6 h，搅拌速率为 200 rpm。所得悬浮液经 Whatman 滤纸过滤，残余 [[全氟和多氟烷基物质|PFAS]] 浓度通过 LC-MS 测定。随后，负载 PFASs 的 β−CD-TriPod 通过在 50 mL [[甲醇|MeOH]] 中浸泡 24 h 进行[[再生]]，并通过过滤回收。MeOH 滤液在真空下浓缩，残余固体溶于 100 mL 去离子 $_ \mathrm { H _ { 2 } O }$ 中，并通过 LC-MS 分析以确定回收的 [[全氟辛磺酸|PFOS]] 量。
