# 利用[[纳米纤维素网络|植物基纳米纤维素网络]]捕获[[胶体纳米塑料]]和[[微塑料]]

[[Ilona Leppänen]] <sup>1</sup>, [[Timo Lappalainen]]<sup>1,2</sup>, [[Tia Lohtander]]<sup>1,3</sup>, [[Christopher Jonkergouw]] <sup>4</sup>, [[Suvi Arola]] <sup>1✉</sup> & [[Tekla Tammelin]] <sup>1✉</sup>

[[微塑料]]在各种水生生物体内[[生物积累|积累]]，引发严重的健康问题，并因进入[[食物链|人类食物链]]而引起了人们对人体健康的担忧。对于最难处理的[[胶体]]组分，即使仅出于分析目的，可用的回收技术也十分有限。在此，我们展示了[[吸湿性]][[纳米纤维素网络]]如何成为理想的捕获材料，甚至能够捕获最微小的[[纳米塑料|纳米塑料颗粒]]。我们揭示，从水环境中捕集颗粒主要归因于该网络的吸湿特性，而[[纳米纤维素]]的高[[BET|比表面积]]进一步强化了这一特性。通过研究 [[pH]] 和[[离子强度]]对[[吸附|吸附行为]]的影响，我们加深了对颗粒捕获机制的理解。我们利用表面敏感方法确定纳米塑料的结合机制，并借助[[随机顺序吸附模型|随机序列吸附]]（[[随机序贯吸附模型|random sequential adsorption]]，RSA）模型解释结果。这些发现有望用于对不同水环境中的[[胶体纳米塑料]]和微塑料进行明确定量，并最终为直接在其产生地点进行现场收集提供解决方案。

[[塑料污染]]正以日益加快的速度进入环境，这是一个重大问题，在海洋环境中尤为突出<sup>1–3</sup>。据估计，每年有 880 万吨[[塑料废弃物]]最终进入海洋<sup>4</sup>。[[侵蚀作用]]导致塑料碎屑破碎，形成更小的塑料颗粒，即[[次生微塑料]]和[[纳米塑料]]<sup>5,6</sup>。用于化妆品等产品中的[[原生微塑料]]和纳米塑料颗粒可直接进入环境<sup>5,6</sup>。针对不同尺寸范围的[[微塑料]]和纳米塑料颗粒的术语仍存在争议。微塑料一词通常用于指所有尺寸的微塑料（1 µm–5 mm），而且官方并未规定微塑料尺寸的下限。直到最近，科学家才引入纳米塑料一词，用于指小于几微米的颗粒<sup>5,7,8</sup>。一些研究将纳米塑料的尺寸上限设为 1000 nm，另一些则设为 100 nm<sup>9,10</sup>。在本研究中，我们将 100 nm 的颗粒视为纳米塑料颗粒，将 ≥1 µm 的颗粒视为微塑料颗粒。纳米塑料因其尺寸小（难以捕获，可进入细胞）、[[表面积]]大（能够结合毒素等物质）以及[[胶体特性]]（定量和定性手段有限），危害尤为突出<sup>9</sup>。少数研究分析了[[鱼类]]和[[软体动物]]等水生动物体内纳米塑料的存在情况，并检测到纳米塑料且进行了定量，证实了其存在<sup>11</sup>。此外，研究表明，模型纳米塑料颗粒可在[[藻类]]细胞表面<sup>12</sup>、[[贻贝]]的多个器官中<sup>13</sup>以及幼年[[斑马鱼]]体内<sup>14,15</sup>[[生物积累|积累]]，影响其生存质量。最近的一项研究还表明，[[胎盘|人类胎盘]]中也存在纳米塑料<sup>16</sup>。目前，关于不同环境中微塑料颗粒丰度的知识已相当丰富<sup>17</sup>。近期为应对塑料问题所作的努力凸显了[[基因工程酶]][[塑料降解|降解塑料]]的能力<sup>18</sup>。这一方法也可成为微塑料管理的工具。然而，人们对纳米塑料颗粒存在情况的了解仍十分有限，主要原因是其捕获、分离和分析面临技术挑战，导致针对 1 nm–1 µm 颗粒的纳米塑料分析存在方法学空白<sup>5,8,19</sup>。迄今为止，尚无手段能够从环境样品中回收纳米塑料，以进行明确的定量或[[定性分析]]，因为现有方法基于不同的[[过滤]]和[[淘洗|淘洗技术]]，仅适用于尺寸较大的微塑料颗粒 $( \stackrel { \bullet } { \boldsymbol { \alpha } } > 5 0 ^ { \bullet } \stackrel { \bullet } { \boldsymbol { \mu } } \mathrm { m } ) ^ { \dot { 2 } 0 - 2 2 } .$ 。即使在最佳情况下，通过[[密度浮选]]以及基于迁移速度差异的方法，也只能提取直径从几微米至几十微米不等的颗粒<sup>23</sup>。这些限制使[[胶体塑料|亚微米胶体塑料颗粒]]（ø < 1 µm）的回收、定量和定性仍处于盲区<sup>5</sup>。植物来源的[[纤维素纳米原纤维]]（[[纤维素纳米原纤|CNF]]）是[[胶体]]尺度的物体，其横向尺寸为 3–10 nm，长度可达微米级。它们的[[水响应特性]]、[[自组装|自组装行为]]及其他独特性质直到最近才逐渐得到揭示<sup>24</sup>。更具体而言，它们能够有效地从[[废水]]中回收[[金离子]]等物质<sup>25</sup>，并且通常能够与[[纳米颗粒]]相互作用<sup>24</sup>。在纳米尺度材料领域，除具有[[亲水性]]且在自然界中储量丰富之外，这些组装体还具有很强的[[吸湿性]]。与……的强相互作用 水使[[纳米纤维素]]区别于许多其他在大[[BET|比表面积]]和高[[长径比]]方面具有相似性质的[[纳米材料]]26

在此，我们表明，[[纳米纤维素网络]]可用于捕获并[[定量分析]][[胶体塑料]]中即使最难处理的部分。我们通过在[[微流控装置]]中监测塑料颗粒的[[荧光强度]]，或仅使用[[纳米纤维素薄膜]]作为从[[水分散液]]中收集颗粒的元件，证实其捕获能力。在这些研究中，我们使用了具有[[阴离子]]和[[阳离子]][[表面电荷]]、[[粒径分布]]明确的模型[[聚苯乙烯]]（PS）颗粒（ø = 1.0 µm 和 ø = 100 nm，补充表 1），以揭示促进高效捕获的关键机制。我们使用粒径更大、粒径分布宽得多的[[聚乙烯]]（PE）颗粒（ø = 38–45 µm，补充表 1），证明了基于[[纳米纤维素]]的捕获过程的普适性。我们通过研究不同 [[pH值|pH 值]]和 [[氯化钠|NaCl]] 浓度下[[纳米塑料]]的结合情况，阐明环境参数对[[吸附|颗粒吸附]]行为的影响。最后，借助成熟的模型 PS [[纳米颗粒]]体系，我们提出了一种界面研究方法，将[[颗粒吸附]]数据与[[图像分析]]及[[随机顺序吸附模型]]相结合，从而能够结合[[吸附动力学|动力学信息]]定量分析纳米塑料的[[吸附量]]，并为纳米颗粒检测提供新方法。

## 结果

[[纳米纤维素水凝胶]]捕获[[纳米塑料]]和[[微塑料|微塑料颗粒]]。我们利用[[微流控分析]]结合[[荧光成像]]（图 1a、b），实时监测[[原生纤维素纳米原纤|天然 CNF]] [[水凝胶]]<sup>27</sup>的颗粒捕获能力；这是一种直观的定性方法，可用于证实[[纳米纤维素]]水凝胶捕获纳米塑料和微塑料颗粒的能力。为此，我们使用了[[荧光标记]]的[[阴离子型聚苯乙烯颗粒|阴离子型]]和[[阳离子型聚苯乙烯颗粒|阳离子型]][[聚苯乙烯纳米塑料]]及微塑料颗粒，分别简称为 [[聚苯乙烯纳米塑料颗粒|PS(ø100 nm)]] 和 [[聚苯乙烯微塑料|PS(ø1µm)]]。对于这两类粒径的颗粒，含有 [[纤维素纳米原纤|CNF]] 的[[微流控捕获阱]]中的[[荧光强度]]均随每一轮颗粒循环而增加（图 1c、d；带正电的 1 µm 颗粒见补充图 1、补充视频 1；带负电的颗粒见补充图 2）。与[[阳离子]]型微塑料体系相比，带正电的纳米塑料体系随时间累积的荧光强度高出多达 70%（图 1c、d）。带负电的颗粒也呈现相同趋势，但其总体荧光累积程度（补充图 2 和 3）低于带正电的颗粒（图 1c、d，补充图 3）。通过分析 [[纤维素纳米原纤水凝胶|CNF 水凝胶]]内部累积荧光的分布（补充图 3a），我们发现，与微塑料相比，纳米塑料能够[[渗透]]至水凝胶更深处（补充图 3b）。一般而言，单个微塑料颗粒的荧光强度显著高于单个纳米塑料颗粒，因此，我们的结果表明，[[纤维素纳米原纤维|CNF]] 水凝胶捕获纳米塑料颗粒的能力远高于其捕获微塑料颗粒的能力。

[[吸湿性]][[纳米纤维素]]组装体表现出涉及[[毛细作用]]和[[扩散]]的特殊[[水传输|水传输性质]]<sup>26</sup>。在水流的辅助下，尺寸较小的[[纳米塑料]]和[[微塑料]]似乎被输送至 [[纤维素纳米原纤维水凝胶网络|CNF 水凝胶网络]]内部。此外，[[多孔网络]]较大的[[表面积]]增强了[[内聚作用]]，有利于截留颗粒<sup>28</sup>。[[纤维素纳米原纤|CNF]] 整体带负电荷也促进了带正电颗粒的积聚，但并不阻碍带负电颗粒的积聚。

利用[[纳米纤维素薄膜|自支撑纳米纤维素薄膜]]捕获[[纳米塑料]]和[[微塑料|微塑料颗粒]]。我们采用[[荧光光谱法]]评估了[[自支撑纳米纤维素薄膜]]收集纳米塑料和微塑料颗粒的能力。该方法可直接定量测定从[[水分散液]]中回收的塑料颗粒数量（补充图 4）。通过使用带[[阴离子]]或[[阳离子]]电荷的[[聚苯乙烯纳米塑料]]和微塑料颗粒（简称为 [[聚苯乙烯纳米塑料颗粒|PS(ø100 nm)]] 和 [[聚苯乙烯微塑料|PS(ø1µm)]]），我们试图进一步阐明其捕获机制，即除[[纳米纤维素网络]]的[[吸湿性]]外，[[静电相互作用]]是否也发挥作用。此外，我们还采用了尺寸更大的[[阴离子型聚苯乙烯颗粒|阴离子型]][[聚乙烯]]颗粒，简称为 [[聚乙烯微塑料|PE(ø38–45µm)]]，以证明[[纳米纤维素]]体系并不具有颗粒特异性。我们使用了[[原生纤维素纳米原纤|原生 CNF]]<sup>27</sup> 和 [[TEMPO氧化纤维素纳米原纤维|TEMPO 氧化 CNF]]<sup>29</sup>（补充图 5）——这两种品级因一种称为[[角质化]]（hornification）的现象而具有不同的水响应倾向<sup>30</sup>。由于[[原生纤维素纳米原纤维|原生 CNF]] 的[[阴离子电荷]]含量较低（0.04 mmol g<sup>−1</sup>），其在干燥时往往会损失[[活性表面积]]，而 [[TEMPO氧化纤维素纳米原纤|TEMPO-CNF]] 的电荷含量显著更高（1.3 mmol g<sup>−1</sup>），可防止角质化，因此保留了[[水响应特性]]。我们采用[[聚合物]]态[[再生纤维素]]（RC）和[[疏水性]][[聚苯乙烯]]（PS）薄膜作为参比材料，以详细探究形貌以及疏水/亲水平衡对捕获过程的影响。不同品级的 [[纤维素纳米原纤|CNF]] 代表原纤维状纳米[[多孔纤维素]]结构，而具有相近[[表面润湿|表面润湿行为]]的 RC 呈聚合物态，无可辨识的孔隙<sup>31</sup>（补充图 5）。此外，推测 PS 表面会因[[疏水效应]]和相似的化学结构而吸引 PS 颗粒，从而为 [[纤维素纳米原纤维|CNF]] 提供一种可行的参比。纳米[[纤维素]]薄膜单位面积捕获的聚苯乙烯微塑料和纳米塑料颗粒（PS(ø100 nm) 和 PS(ø1 µm)）数量分别见图 2a、b（补充表 2）。图 2c 中的 [[SEM]] 图像显示了薄膜与纳米塑料[[颗粒分散液|分散液]]接触后的形貌。这些结果传达了两个主要信息：(i) 在所有情况下，具有高吸湿性且带阴离子电荷的 [[TEMPO氧化纤维素纳米原纤维薄膜|TEMPO-CNF 薄膜]]均表现最佳（图 2a、b）。令人意外的是，[[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]-[[纤维素纳米原纤维薄膜|CNF 薄膜]]对阴离子型纳米塑料颗粒的[[去除效率]]最高。(ii) 在处理微塑料颗粒时，[[静电吸引|静电吸引相互作用]]似乎具有更显著的影响，因为阴离子型纤维素薄膜捕获的[[阳离子型聚苯乙烯颗粒|阳离子型]]微塑料数量多于阴离子型微塑料（图 2b）。

正如预期，由于带相反电荷的表面之间具有较大的[[吸引能]]，带正电的 [[聚苯乙烯纳米塑料颗粒|PS 纳米塑料颗粒]]会立即附着在[[阴离子型聚苯乙烯颗粒|阴离子型]] [[TEMPO氧化纤维素纳米原纤|TEMPO-CNF]] 表面，阻碍颗粒在网络内部的[[扩散]]，但并未完全阻止其扩散。在[[阴离子]]体系中，带负电表面之间的吸引能为带相反电荷表面之间吸引能的一半<sup>32</sup>，因此，阴离子型[[纳米塑料|纳米塑料颗粒]]能够更有效地进入[[纳米纤维素网络]]内部。事实上，[[TEMPO氧化纤维素纳米原纤维薄膜|TEMPO-CNF 薄膜]]捕获的阴离子型纳米塑料比[[阳离子型聚苯乙烯颗粒|阳离子型]]纳米塑料多约三分之一。[[TEMPO氧化纤维素纳米原纤维|TEMPO-CNF]] 能够高效捕获纳米塑料颗粒而不受颗粒电荷影响，这是其纳米尺度孔隙与高[[吸湿性]]共同赋予其独特[[水传输|水传输特性]]的结果。薄膜一旦与水溶液接触，就会剧烈[[溶胀]]。[[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]-[[纤维素纳米原纤|CNF]] 网络的溶胀会诱导[[毛细流]]，其强度足以将纳米塑料颗粒输送至薄膜网络内部。[[原生纤维素纳米原纤|天然 CNF]] 较大且活跃的[[表面积]]在干燥过程中会部分损失，因为与 [[TEMPO自由基|TEMPO]]-[[纤维素纳米原纤维|CNF]] 相比，这类 CNF 的[[表面电荷]]显著较低。由于单根原纤维之间缺乏排斥力，原纤维在干燥时会发生[[颗粒聚集|聚集]]，并产生严重的[[角质化]]（hornification）。角质化会导致原纤维形貌和[[BET|比表面积]]发生不可逆变化，减少原纤维网络的溶胀，从而降低体系的[[吸水能力]]<sup>30</sup>。因此，角质化解释了[[原生纤维素纳米原纤维|天然 CNF]] 薄膜的性能为何低于 TEMPO-[[纤维素纳米原纤维薄膜|CNF 薄膜]]，因为如上所述，从未干燥过的 [[纤维素纳米原纤水凝胶|CNF 水凝胶]]能够从水流中回收[[微塑料]]和纳米塑料（见图 1）。该区域的面积显著更小

与[[原生纤维素纳米原纤|原生 CNF]] 薄膜（140 cm<sup>2</sup>）相比，去除溶液中全部[[阴离子型聚苯乙烯颗粒|阴离子型]][[聚苯乙烯纳米塑料]]所需的 [[TEMPO氧化纤维素纳米原纤维薄膜|TEMPO-CNF 薄膜]]面积为 $( 3 0 \ c m ^ { 2 } )$（补充表 3）。对于[[聚乙烯微塑料|聚乙烯微塑料颗粒]]（[[聚乙烯|PE]](ø38–45 µm)），回收全部 PE 颗粒所需的 [[纤维素纳米原纤|CNF]] 和 [[TEMPO氧化纤维素纳米原纤|TEMPO-CNF]] 面积分别为 16 cm<sup>2</sup> 和 $1 7 \mathrm { c m } ^ { 2 }$（补充表 4）。尽管 PE [[颗粒分散液|分散液]]的性质更不规则（颗粒较大、[[粒径分布]]较宽，且需借助[[洗涤剂]]维持[[分散稳定性]]），[[纤维素纳米原纤维|CNF]] 和 [[TEMPO氧化纤维素纳米原纤维|TEMPO-CNF]] 网络均能够从[[水分散液]]中捕获 PE [[微塑料]]。此外，回收全部 PE 颗粒所需的面积甚至小于 [[聚苯乙烯纳米塑料颗粒|PS 颗粒]]。这清楚地证明了[[纳米纤维素]]捕获不同类型微塑料颗粒的能力。

对于[[微塑料|微塑料颗粒]]（[[聚苯乙烯微塑料|PS(ø1µm)]]），我们的结果表明，所有薄膜回收的[[阳离子型聚苯乙烯颗粒|阳离子型]]微塑料颗粒均多于[[阴离子型聚苯乙烯颗粒|阴离子型]]微塑料颗粒（图 2b，补充表 2），这表明，与纳米尺寸体系（[[聚苯乙烯纳米塑料|PS(ø100 nm)]]）相比，[[静电吸引|静电吸引相互作用]]在其捕获过程中发挥着更显著的作用。然而，由于[[表面积]]大、[[吸湿性]]高，以及颗粒可能被截留在[[多孔网络]]中，[[纳米纤维素]]基体系的性能优于[[聚合物]]体系（[[再生纤维素]]（RC）和[[聚苯乙烯]]（PS））。[[海草生态系统]]中的研究表明，[[木质纤维素]]基体系确实能够高效截留并转运海水中的微塑料（海草中约 1500 个塑料碎片 $\mathrm { k g ^ { - 1 } }$）<sup>33</sup>。在最佳情况下，我们同样源自木质[[纤维素]]的体系可收集约 200 亿个[[纳米塑料|纳米塑料颗粒]] $\mathrm { m g ^ { - 1 } }$ [[TEMPO氧化纤维素纳米原纤|TEMPO-CNF]]，这是一项显著的发现。静电吸引相互作用、大表面积或与水的相互作用均无法完全解释再生纤维素薄膜筛分颗粒的能力，因此，我们评估了[[表面相互作用|直接表面相互作用]]在捕获过程中的作用。

[[界面相互作用]]的作用——计算[[吸附]]参数的定量方法。为进一步阐明[[纳米塑料]]与结合基底之间[[表面相互作用]]的作用，我们采用[[石英晶体微天平耗散监测技术]]（[[耗散型石英晶体微天平|QCM-D]]）跟踪了[[阴离子]][[聚苯乙烯]]（PS）和[[聚乙烯]]（PE）颗粒（补充表 1）的吸附过程。通过这一方法，我们旨在排除产生[[水传输|水传输功能]]的网络[[孔隙结构]]的影响，并突出直接表面相互作用的作用。我们重点研究了粒径明确的[[胶体]]尺度[[聚苯乙烯纳米塑料颗粒|聚苯乙烯颗粒]]（[[聚苯乙烯纳米塑料|PS(ø100 nm)]]），因为纳米尺度颗粒的行为大多发生在界面处，其机制主要由界面相互作用主导。此外，我们还简要测试了[[胶体聚乙烯颗粒|胶体 PE 颗粒]]，$\mathrm { P E } ( \emptyset \ < \ 4 5 0 \mathrm { n m } )$ ），以拓宽对表面捕获机制的理解。

在自然界中，[[纳米塑料]]往往会富集诸如毒素等物质，因此从环境角度来看，纯净的颗粒并不存在<sup>12</sup>。因此，我们比较了经稳定处理或纯化的[[聚苯乙烯纳米塑料颗粒|聚苯乙烯颗粒]] [[聚苯乙烯纳米塑料|PS(ø100 nm)]]，这些颗粒的表面均带有净负电荷（补充表 1）。我们的结果表明，在模型条件下（[[pH]] 6.8，10 mM [[磷酸盐缓冲液]]），[[聚苯乙烯|PS]](ø100 nm) 颗粒——包括经稳定处理和纯化的颗粒——均[[吸附]]于[[原生纤维素纳米原纤|原生 CNF]]、[[再生纤维素]]（RC）和聚苯乙烯（PS）上，$( \Delta f _ { \mathrm { R C } }$ ≫ $\Delta f _ { \mathrm { C N F } } > \Delta f _ { \mathrm { P S } } )$（图 3a 和补充图 6a、c），而在 [[TEMPO氧化纤维素纳米原纤|TEMPO-CNF]] 上未检测到吸附。这一结果表明，[[阴离子]]区域之间的[[静电排斥]]阻止了纳米塑料颗粒直接结合于具有高阴离子性的 [[TEMPO氧化纤维素纳米原纤维|TEMPO-CNF]]。随后，通过改变[[纳米颗粒]][[颗粒分散液|分散液]]的 [[pH值|pH]] 和[[离子强度]]，模拟了[[废水]]和[[洗衣废水]]等环境条件的影响。在 pH 8 时，吸附行为与模型条件（pH 6.8，10 mM 磷酸盐缓冲液）下相似，而在 pH 10 时，检测到 [[纤维素纳米原纤|CNF]] 和 RC 上的吸附略有减少（补充图 7）。在 [[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]-[[纤维素纳米原纤维|CNF]] 上未检测到吸附。芬兰废水的 pH 限值范围为 6–11。然而，由于经过中和处理，废水的 pH 通常接近中性，而这似乎也是最有利于[[颗粒吸附]]的条件<sup>34</sup>。未经稀释的[[洗涤剂|洗衣洗涤剂]]往往具有较高的 pH 值（pH 9–12）。但在使用过程中，它们被水大幅稀释，使其 pH 降至接近自来水的 pH（pH 7.3–8.4）。由此可以得出结论，在这些条件下，pH 的变化不会改变 PS 纳米塑料在 CNF 或 [[TEMPO自由基|TEMPO]]-CNF 表面的吸附行为。随着离子强度增加（40 mM 和 200 mM），[[胶体纳米塑料|胶体纳米塑料颗粒]]在两种[[纳米纤维素]]表面上的吸附均有所增加（补充图 8），表明一旦静电排斥被有效[[静电屏蔽|屏蔽]]，CNF 和 TEMPO-CNF 表面便能够结合[[胶体]] PS 纳米塑料颗粒，表现出更强的胶体纳米塑料吸附和去除能力。

[[纳米塑料|纳米塑料颗粒]]的[[吸附|吸附行为]]似乎与[[纤维素]]的[[两亲性]]有关<sup>39</sup>，尤其是在体系的[[静电排斥|静电排斥作用]]相对较弱时（[[原生纤维素纳米原纤|天然 CNF]] 和[[再生纤维素]]）。研究表明，纤维素材料由于[[结构各向异性]]而表现出不同的表面性质<sup>40</sup>。[[后退接触角]]和[[前进接触角]]的值介于 11° 与 37° 之间，表明纤维素同时具有疏水区域和亲水区域<sup>41</sup>。研究表明，纤维素表面的不同[[润湿行为]]与[[晶面取向|晶面的取向]]相关。只有在强排斥力不占主导地位且[[毛细力]]未辅助捕获过程时，决定纳米塑料颗粒结合的机制才基于表面吸引相互作用。

综上所述，我们提出了一种通用且用途广泛的[[纳米纤维素]]基方案，其收集和结合[[微塑料]]与[[纳米塑料|纳米塑料颗粒]]的效率不依赖于任何特定的物理或化学相互作用。相反，从[[水分散液]]中截留颗粒是[[纳米纤维素网络]]所具有的双重协同特性的结果：高[[吸湿性]]与高[[活性表面积]]相结合。这些特性赋予了该材料操作上的优势，使[[胶体塑料|胶体塑料颗粒]]无论尺寸、[[表面化学性质]]或塑料类型如何，均可借助该网络涉及[[毛细力]]和[[扩散]]的独特[[水传输|水传输特性]]，被输送并捕获于[[纤维素]]网络内部。颗粒一旦进入网络，较大的[[表面积]]和有利的[[表面相互作用]]便会增强颗粒与材料表面之间的[[内聚作用]]，从而实现高效捕获。我们汇集了各实验装置的主要发现及其对应的捕获材料和颗粒类型，以总结实验结果（表 2–4）。我们表明，通过将表面敏感方法与纳米显微技术、[[图像分析]]和建模相结合，能够定量评估纳米塑料颗粒在界面处的行为。此类纳米塑料[[吸附|颗粒吸附]]数据此前尚未被采集，而这些数据对于设计用于[[定量分析]]的材料，以及用于从[[废水]]到纳米塑料和微塑料产生场所等不同环境中收集和回收这些颗粒的材料至关重要。纳米纤维素来源于天然资源，具有可再生、无毒的特点，这些都是设计下一代功能材料、减少对合成同类材料依赖时的关键考量。如今，纳米纤维素可通过多种方式制备和改性，形成[[水凝胶]]、[[自支撑薄膜]]以及[[多孔气凝胶]]和[[冷冻凝胶]]，这使其成为未来许多可发挥高吸湿性优势的解决方案的理想材料<sup>24,42</sup>。

## 方法

[[聚苯乙烯纳米塑料颗粒|聚苯乙烯颗粒]]。采用不同尺寸（ø = 100 nm 和 ø = 1 um）和[[表面电荷]]（[[阳离子型聚苯乙烯颗粒|阳离子型]]和[[阴离子型聚苯乙烯颗粒|阴离子型]]）的[[荧光标记]][[聚苯乙烯]]（PS）颗粒（[[Sigma Aldrich]] 的 L9902、L9904、L4655 和 L9654），分析 [[纤维素纳米原纤水凝胶|CNF 水凝胶]]和[[自支撑薄膜]]对[[微塑料]]和[[纳米塑料]]的捕获能力，并揭示其捕获机制。纳米塑料颗粒称为[[阴离子]]型（−）/[[阳离子]]型（+）[[聚苯乙烯纳米塑料|PS(ø100 nm)]]，微塑料颗粒称为阴离子型（−）/阳离子型（+）[[聚苯乙烯微塑料|PS(ø1µm)]]。

[[石英晶体微天平耗散监测技术|QCM-D]] 实验采用[[胶体]]纳米级[[聚苯乙烯]]（PS）颗粒（[[Sigma Aldrich]] 的 LB1）（ø = 100 nm，即 [[聚苯乙烯纳米塑料|PS(ø100 nm)]]）。这些颗粒以稳定形式使用（即按供应商提供的原样使用），或按照供应商的方案进行纯化，以去除大部分[[稳定剂]]。稳定形式的颗粒代表[[纳米塑料]]的原始状态。

Co.]]，Newton，MA）对洗涤后的 TEMPO 氧化纸浆进行两次原纤化处理。最终[[固含量]]为 1 wt%。

在 [[扫描电子显微镜成像|SEM 成像]]中，与一般成像方法一样，图像被裁剪在矩形边界内。当通过矩形裁剪窗口观察空间图案时，会产生若干[[边缘效应|边缘缺陷]]。其中一种边缘缺陷是[[尺寸依赖性抽样偏差]]。[[Miles]] 讨论了[[加抽样]]（plus-sampling，接受任何与裁剪窗口相交的对象）和[[减抽样]]（minus-sampling，仅接受完全位于裁剪窗口内的对象）<sup>51</sup>。在本研究中，由于图像中的[[颗粒尺寸]]相同，因此未尝试确定[[粒径分布]]。因此，尺寸依赖性抽样偏差在我们的分析中并不构成问题。颗粒的实际尺寸（μm）与其[[像素尺寸]]之间的关系通过 [[SEM]] 图像中的[[比例尺]]获得。[[扫描电子显微镜|SEM]] 图像质量良好；背景变化较小，明亮的对象（颗粒）在深色背景中清晰可辨。因此，无需进行[[图像预处理]]，首个[[图像处理]]操作是[[图像分割|分割]]。由于背景变化较小，因此可以使用[[全局阈值]]。本研究采用的[[阈值分割|阈值分割方法]]基于[[图像直方图|直方图]]形状信息。阈值选在直方图中显著峰的下降部分（见补充图 12）。其目的是识别单个 [[聚苯乙烯纳米塑料颗粒|PS 纳米塑料颗粒]]及其中心，从而确定颗粒总数。在大多数 SEM 图像中，颗粒彼此分离，或仅形成[[颗粒团簇|小团簇]]。然而，在某些情况下，颗粒具有很强的成簇倾向（标示出已识别颗粒的 SEM 图像示例见补充图 11）。因此，[[图像分析]]的下一步根据图像归入上述哪一类别而采用两种不同的方法。当颗粒主要彼此分离时，根据其面积（我们已知每幅图像中的[[颗粒直径]]）和形状（圆形对象），从阈值分割后的图像中识别颗粒。观察到的团簇大小被假定为三个颗粒。对于团簇较大且颗粒主要存在于团簇中的样品，无法可靠地识别单个颗粒。在这种情况下，先确定每个团簇的面积，再计算达到相同面积所需的颗粒数量。最后，通过在原始 SEM 图像上绘制标记来呈现已识别的颗粒（见补充图 11、12）。

颗粒的[[最大吸附量|理论最大吸附量]]——采用 [[随机序贯吸附模型|RSA 模型]]拟合。我们采用随机序贯[[吸附]]（[[随机顺序吸附模型|random sequential adsorption]]，RSA）模型评估[[超薄膜]]的[[最大吸附容量]]。超薄膜的厚度远低于 100 nm。因此，[[聚苯乙烯纳米塑料颗粒|PS 颗粒]]无法穿透该膜。如果目的是确定超薄膜表面能够容纳的 [[聚苯乙烯|PS]] 颗粒的最大数量，则该问题可简化为平面内[[圆盘堆积问题|圆盘的堆积问题]]。颗粒在固体平坦表面上的吸附通常是一个[[不可逆吸附|不可逆过程]]，本研究中的 [[石英晶体微天平耗散监测技术|QCM-D]] 测量也证实了这一点（补充图 6）。此外，颗粒通常不会相互叠加吸附，而是形成[[单层吸附|单层]]（补充图 10）。基本 RSA 模型假设圆盘之间仅存在[[空间位阻排斥|空间位阻排斥作用]]。对于尺寸相同的圆盘，当[[表面覆盖率]] θ 为 0.547 时达到饱和。如果体系中存在不同尺寸的圆盘（直径不同的颗粒），则可达到更高的表面覆盖率 θ。本研究中所有颗粒的尺寸均相同。如果观察面积为 1 mm<sup>2</sup>，且 PS 颗粒的尺寸相同，则颗粒覆盖的最大面积为 0.547 mm<sup>2</sup>。在这种情况下，1 mm<sup>2</sup> 的面积可容纳 5.76 × 10<sup>7</sup> 个[[有效直径]]为 $d _ { \mathrm { e f f } } = 1 . 1 d _ { \mathrm { a b s } } = 1 1 0 \mathrm { n m } ^ { 5 2 }$ 的圆（PS 颗粒）（有效直径还将颗粒[[双电层]]和[[水合壳层]]的估算值考虑在内）。单个颗粒的[[颗粒横截面积|横截面积]]使用 $A _ { \mathrm { p a r t i c l e } } = \pi ( d _ { \mathrm { e f f } } / 2 ) ^ { 2 }$ 计算。此外，RSA 模型假设颗粒在整个吸附过程中以相同速率撞击表面<sup>53</sup>。因此，浓度 c 必须足够高，才能在[[吸附饱和|饱和状态]]下形成单层。如果颗粒数量不足，吸附过程可能在达到饱和表面覆盖率之前停止。表 1 显示，吸附在 [[再生纤维素|RC]] 上的[[最大表面质量密度]] $( { \cal { I } } _ { \mathrm { m a x } } )$ −2 <sub>fi</sub> nm)。当 [[QCM-D传感器|QCM-D 传感器]]直径为 9 mm 时，传感器表面约有 \~1200 ng 的纯化 [[聚苯乙烯纳米塑料|PS(ø100 nm)]]。这相当于 PS(ø100 nm) 的约 0.2%（将 100,000 ng cm<sup>−3</sup> 的 PS(ø100 nm) [[颗粒分散液|分散液]]以 0.1 ml min<sup>−1</sup> 的[[流速]]通入 [[耗散型石英晶体微天平|QCM-D]] 腔室约 1 h）。因此，我们可以假设[[纳米塑料|纳米塑料颗粒]]在整个吸附过程中以相同速率撞击表面，并且满足使用 RSA 模型的要求。在我们的体系中，RSA 的所有主要原理均适用，因此，纳米塑料[[颗粒吸附|颗粒的吸附]]行为可以用随机序贯吸附（RSA）模型描述<sup>36</sup>。

$$
\frac {\mathrm{d} N (t)}{\mathrm{d} t} = k _ {\mathrm{a}} c ^ {\prime} B (\theta) - k _ {\mathrm{d}} \theta\tag{2}
$$

$$
B (\theta) = 1 - 4 \theta + \frac {6 \sqrt {3}}{\pi} \theta^ {2} + \left(\frac {4 0}{\pi \sqrt {3}} - \frac {1 7 6}{3 \pi^ {2}}\right) \theta^ {3}.\tag{3}
$$

$$
\theta = \frac {\Gamma a}{m},\tag{4}
$$

其中，a 为单个颗粒的[[颗粒占据面积|占据面积]] $( \mathsf { c m } ^ { 2 } )$，m 为单个[[颗粒质量|颗粒的质量]] [ng]，Γ 为[[吸附质量|单位面积的吸附质量]]（ng cm<sup>−2</sup>）。方程（3）适用于 $\theta ^ {  } 0 . 3 ^ { 3 6 , 5 4 }$。在较高的[[表面覆盖率]]下，动力学可用 $\mathrm { E q . ~ } ( 5 ) ^ { 5 4 } ,$ 近似描述。在接近[[堵塞极限]]时，$( \theta _ { \infty } = 0 . 5 4 7 ) \ K _ { 0 }$ 约为 8.98。

$$
B (\theta) = K _ {0} \left(\theta - \theta\right) ^ {3}\tag{5}
$$

$$
\frac {\mathrm{d} \Gamma (t)}{\mathrm{d} t} = k _ {\mathrm{a}} c \left(1 - 4 \Gamma \frac {a}{m} + \frac {6 \sqrt {3}}{\pi} \left(\Gamma \frac {a}{m}\right) ^ {2} + \left(\frac {4 0}{\pi \sqrt {3}} - \frac {1 7 6}{3 \pi^ {2}}\right) \left(\Gamma \frac {a}{m}\right) ^ {3}\right).\tag{6}
$$
