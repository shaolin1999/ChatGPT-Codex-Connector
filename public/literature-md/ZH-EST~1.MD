## ■ 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）是一大类氟化化学品，因其固有的热稳定性和化学稳定性而被广泛用于工业过程和消费品中。<sup>1−3</sup> 长期暴露于 PFAS 与不良健康效应相关，我们对这些效应的毒理学认识正在迅速发展。<sup>4−6</sup> 广泛使用和环境持久性已导致与 PFAS 污染相关的重大健康和环境危机。<sup>7</sup> 2024 年，[[美国环境保护署]]为饮用水中六种 PFAS 制定了[[最大污染物水平]]（MCLs），水平范围为 4.0 至 10.0 ng/L。<sup>8</sup> 这些 MCLs 只是 PFAS 监管的开始，因为目前认为总体上有超过 15,000 种 PFAS 物质<sup>9,10</sup>，在一系列应用和地理区域中使用。<sup>2,11,12</sup> 随着全球 PFAS 限值的建立，显然需要认真努力以实现受污染水和土壤系统的环境修复。

处理 [[PFAS]] 污染水的主要策略之一是通过[[活性炭]]和[[离子交换树脂]]等材料进行[[吸附]]。<sup>13−15</sup> 这些基于富集的策略利用静电和[[疏水相互作用]]，成功结合并去除水中的 [[全氟和多氟烷基物质|PFAS]]。<sup>16,17</sup> 水体系的复杂性以及 PFAS 分子结构的多样性会导致[[吸附剂|吸附材料]]效能出现显著差异。因此，开发对多种 PFAS 物种具有亲和力的吸附剂既重要又具有挑战性。

[[碳点]]（[[CD|CDs]]）是一类碳基纳米材料，<sup>18,19</sup> 因其成本低、合成简便且表面化学性质可控，已成为一种潜在且有前景的 [[PFAS]] [[吸附剂|吸附材料]]。<sup>20,21</sup> CDs 的[[高比表面积]]和[[胶体稳定性]]使其优于其他有前景的碳质材料，如[[颗粒活性炭]]（GAC），后者可能因[[团聚]]而堵塞[[吸附]]位点。<sup>22</sup> 此外，通过选择具有目标理化性质的 CD 前驱体，可以合成出优先与特定 [[全氟和多氟烷基物质|PFAS]] 发生相互作用的 CDs。<sup>23</sup> 例如，使用富含胺基的前驱体可能转化为具有正表面电荷的 CDs，从而促进与阴离子型 PFAS 物种的相互作用。CD 前驱体的多样性以及后续功能化的潜力，为基础 PFAS 吸附研究提供了优异平台，同时也有助于开发经济高效的修复材料。

我们此前报道了以[[聚乙烯亚胺]]（PEI）合成的[[阳离子碳点]]；这些 [[碳点|PEI-CDs]] 与多种 [[PFAS]] 表现出结合作用，可能归因于 PEI 中丰富的胺基所驱动的[[静电相互作用]]。<sup>24</sup> 本文中，我们详细介绍了另外五种无定形碳点配方的合成与表征，这些配方被假设具有良好的 [[全氟和多氟烷基物质|PFAS]] 亲和力，用于与 PEI-[[CD|CDs]] 进行比较。在这些碳点合成中，我们以[[壳聚糖]]这一天然聚阳离子生物聚合物作为富胺前体，基于其[[生物相容性]]以及此前报道中在 PFAS [[吸附]]方面的有效性。<sup>25,26</sup> 使用 <sup>19</sup>F [[核磁共振波谱|NMR]] 方法评估了全部六种碳点对若干具有重要意义的单一 PFAS 物种以及一种 24 种 PFAS 混合物的亲和力。

[[十九氟核磁共振波谱|氟核磁共振波谱]]（<sup>19</sup>F [[核磁共振波谱|NMR]]）方法具有非破坏性，不需要大量样品制备，但作为理解 [[PFAS]] 体系的技术仍具有巨大潜力。<sup>27−33</sup> [[核磁共振波谱法|NMR]] 常规用于[[药物发现]]应用中的[[配体结合]]筛选，并且可以方便地扩展到监测 [[全氟和多氟烷基物质|PFAS]] 与[[吸附剂]]之间的相互作用。<sup>34−37</sup> 此前工作已使用 <sup>19</sup>F NMR 对溶液中的 PFAS 进行定量<sup>31,38</sup> 和理解，<sup>39</sup> 探测聚合物[[吸附]]剂与 PFAS 之间的相互作用，<sup>30,32</sup> 以及表征 PFAS 与 [[β-环糊精]]的结合。<sup>27,28,33</sup> <sup>19</sup>F 核对化学环境变化非常敏感，这些变化可通过峰强度和/或[[化学位移]]的变化反映出来。<sup>34,40</sup> 这些可观测参数<sup>35,41,42</sup> 以及其他参数<sup>43−45</sup> 可用于揭示溶液中 PFAS 与吸附剂相互作用的关键信息，而这些信息通常难以通过其他技术获得。

在本工作中，我们将用于[[药物发现]]的既定 [[核磁共振波谱|NMR]] 方案扩展到 [[CD]]-[[PFAS]] 体系，以最终对六种[[碳点]]对 [[全氟和多氟烷基物质|PFAS]] 的亲和力进行排序，并阐明关键结合信息。<sup>24,37,42,44</sup> 我们采用三种主要方法来理解 CD-PFAS 相互作用：使用一维 <sup>19</sup>F [[核磁共振波谱法|NMR]] 进行 $\mathrm { K _ { d } }$ 测定，以及使用 [[Carr-Purcell-Meiboom-Gill脉冲序列|Carr−Purcell−Meiboom−Gill]]（[[Carr–Purcell–Meiboom–Gill脉冲序列|CPMG]]）脉冲序列的两种方法。在对碳点性能进行充分分析之后，利用数据对六种碳点配方的相对效能进行排序，从而确定一种特别有前景的 PFAS [[吸附剂|吸附材料]]。尽管基于修复 PFAS 的需求，最优碳点的身份和性能十分重要，但基于 NMR 的分析与排序方法将适用于碳点这一具体应用之外的更广泛场景。它将 <sup>19</sup>F NMR 确立为一种快速考察新型 PFAS [[吸附]]材料可行性的潜在方法，从而促进其他开发替代性 PFAS 亲和材料团队的工作。

## 材料

[[壳聚糖]]（[[Sigma-Aldrich]]，低[[分子量]]）、[[聚乙烯亚胺]]（[[Thermo Scientific]]，支化，分子量 10,000，99%）、[[柠檬酸]]（Sigma-Aldrich，99.5%）、[[赖氨酸|L-赖氨酸]]（Sigma-Aldrich，≥ 98.0%）、[[乙酸]]（[[VWR Chemicals]]，冰醋酸）、[[苹果酸]]（[[Acros Organics]]，99+%）、[[甲酸]]（[[Fisher Scientific]]，88%）、[[β-环糊精]]（Sigma-Aldrich，≥ 97.5%）、[[全氟辛酸]]（Sigma-Aldrich，95%）、十七氟辛烷磺酸（[[ChemCruz]]，≥ 95.0%）、D O（[[Cambridge Isotopes]]）、[[三氟乙酸钠]]（Sigma-Aldrich，98%）和 Native [[PFAS]] 参考标准品（[[AccuStandard]]，M-8327−10X）均按接收状态使用，未进行额外纯化。

## [[碳点]]纳米颗粒的合成

[[碳点]]（[[CD|CDs]]）采用氮源（[[壳聚糖]]、[[赖氨酸|L-赖氨酸]]或 [[聚乙烯亚胺|PEI 10K]]）和羧酸源（[[乙酸]]、[[苹果酸]]、[[柠檬酸]]或[[甲酸]]）按所报道的比例和条件合成（表 1）。[[壳聚糖基碳点|基于壳聚糖的 CDs]] 使用低[[分子量]]壳[[聚糖]]（0.1 g）和所报道比例的其他试剂合成。对于 CLAA 1:1:1、CLAA 10:1:10、CLFA 1:1:1 和 Chitosan CDs，试剂溶解于 9.9 mL MQ H₂O 和 0.1 mL 相应羧酸源中。对于 CLMA 1:1:1，所有试剂溶解于 10 mL MQ H₂O 中。[[PEI CDs]] 使用聚乙烯亚胺 10K（1.0 g）和柠檬酸（0.25 g）溶解于 10 mL MQ H₂O 中合成。CLAA 10:1:10、CLMA 1:1:1、CLFA 1:1:1 和 PEI CDs 使用 [[CEM Discover SP 微波仪]]合成，而 Chitosan CDs 在圆底烧瓶中回流合成。合成后，所有产物使用 0.2 μm [[Captiva 再生纤维素注射器过滤器]]过滤，以去除块状碳残留物。产物进一步使用 Spectra/Por 3 3.5 kDa MWCO [[透析]]管透析纯化 24 h，并在 2 h、4 h 及过夜前换水。纯化后的溶液[[冷冻干燥]] 72 h，得到干燥粉末。

## [[PFAS]] 暴露

储备 [[CD]] 水溶液（20 mg/mL）和 [[PFOA]]/[[PFOS]] 溶液（200 mg/L）在使用前分别[[超声处理]] 10 min，用于 [[PFAS]] 暴露实验。暴露实验中 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的最终浓度为 $5 \ \mathrm { m g / L } ,$，该浓度被选为在合理扫描次数下，使用 $^ { 1 9 } \mathrm { F }$ [[核磁共振波谱|NMR]] 具有良好[[信噪比]]的最低浓度。所有所得溶液的 pH 使用 0.1−0.4 M HCl 调节至 4，样品在室温下以 105 rpm 振荡 72 h，然后进行 $^ { 1 9 } \mathrm { F }$ [[核磁共振波谱法|NMR]] 实验。在本文工作中，[[碳点|CD]] 性能以众所周知的分子亲和剂 [[β-环糊精]]为基准进行比较。

## [[ζ-电位]]

在有和没有 [[PFAS]]（[[PFOA]] 或 [[PFOS]]）的情况下，使用 [[Malvern Zetasizer Advance Pro Red]] 测定 [[CD|CDs]] 和 [[β-环糊精]]（1 mg/mL）的[[流体力学直径]] $\left( D _ { \mathrm { h } } \right)$ 和 $\zeta \cdot$-电位。对每种 [[碳点|CD]]/[[全氟和多氟烷基物质|PFAS]] 组合测量了 $D _ { \mathrm { h } }$ 和 [[ζ-电位]]的三次分析重复，并报告平均值。使用[[非配对t检验|非配对 t 检验]]比较含有和不含有 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] 的样品之间的 $D _ { \mathrm { h } }$ 和 ζ-电位值。

## $\mathsf { K } _ { \mathsf { d } }$ 测定

测定[[解离常数]] $\mathrm { ( K _ { d } ) }$ 值，以衡量 [[CD|CDs]] 对 [[PFAS]] 的结合亲和性。在考察 [[PFOA]] 亲和性的实验中，样品制备为使 [[碳点|CDs]] 或 [[β-环糊精]]的最终浓度为 0.25、0.5、1.5、3.5 和 6.5 $\mathbf { g } / \mathrm { L } .$。由于 [[聚乙烯亚胺|PEI]]-CD 具有高亲和性，还按其先前报道进行了更低 PEI-CD 浓度的附加实验。<sup>24</sup> 在考察 [[PFOS]] 亲和性的实验中，样品制备为使 CDs 或 β-[[环糊精]]的最终浓度为：CLAA 10:1:10（0.5、1.0、10 和 50 mg/L）、[[PEI CDs]]（0.05、0.1、1.0、2.5 和 5 mg/L）以及 β-环糊精（0.1、0.5、1.0 和 5.0 mg/L）。

## Q<sup>bind</sup>、$\mathsf { p } _ { \mathsf { b } } ,$ 和 $\mathsf { T } _ { 2 }$ 测定

$\mathrm { Q } ^ { \mathrm { b i n d } }$ 和 $\mathtt { p _ { b } }$ 值是用于亲和性排序的附加指标。在考察 24 种 [[PFAS]] 混合物中 [[CD]] 亲和性的实验中，[[碳点|CD]] 样品制备为使 CDs 的最终浓度为 0.5、1.5 和 3.5 g/L，混合物中每种 [[全氟和多氟烷基物质|PFAS]] 物种的浓度为 5 mg/L。

## [[核磁共振波谱|NMR]] 实验

## 确定 $\mathsf { K } _ { \mathrm { d } } , \mathsf { Q } ^ { \mathrm { b i n d } } , \mathsf { P } _ { \mathrm { b } } ,$ 和 $\mathsf { T } _ { 2 }$ 值的数据分析

[[结合曲线]]通过各浓度下 [[PFOA]] 或 [[PFOS]] 核磁共振峰的平均高度建立。假设峰高与溶液中游离 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的浓度成正比。因此，这些高度被用于近似结合的 [[PFAS]] 分数 $( \mathrm { \bar { 1 } } { - } \mathrm { H } _ { \mathrm { f r e e } } / \mathrm { H } _ { 0 } )$，并对 [[CD|CDs]]:[[全氟和多氟烷基物质|PFAS]] 质量比 $\mathbf { \Psi } ( \mathbf { M } )$ 作图。近似 $\mathrm { K _ { d } }$ 值通过 GraphPad Prism $8 \ \left( \mathrm { e q \ 1 } \right)$ 进行非线性最佳拟合获得。使用基于二次方程的结合公式，可在整个滴定过程中同时考虑 PFAS 和 [[碳点|CDs]] 的浓度。

$$
\begin{array}{l} \mathrm {f_ {b}} = 1 - \frac {\mathrm {H_ {avg,free}}}{\mathrm {H_ {avg,0}}} \\ = \frac {1}{2} \alpha \left(\mathrm{M} + 1 + \frac {\mathrm {K_ {d}}}{[ \text {PFAS} ]} \right. \\ \left. - \sqrt {\left(\mathrm{M} + 1 + \frac {\mathrm {K_ {d}}}{[ \text {PFAS} ]}\right) ^ {2} - 4 \mathrm{M}}\right) \end{array}\tag{1}
$$

初始拟合按式 1 原文使用，但不含 α 因子；然而所得拟合效果不理想。为改善拟合，引入额外的 α 项来模拟[[最大潜在信号变化]]，这与先前使用其他分析方法的研究一致。<sup>46</sup> 该因子仅在明确说明时才会被纳入。

$$

$$

## 结果与讨论

设计了一系列六种[[阳离子碳点]]（[[碳点|carbon dots]], [[CD|CDs]]），使用不同前驱体和反应条件，以评估其作为潜在[[PFAS]][[吸附剂|吸附材料]]的性能（图1）。基于前期工作，CDs因其易于合成、无毒性以及良好的初始性能，是[[全氟和多氟烷基物质|PFAS]][[吸附]]材料的有前景候选者。<sup>24,47</sup>鉴于合成CDs的潜在参数范围广泛，本工作重点关注使用具有胺类特征的经济高效前驱体。在这六种CDs中，五种为[[壳聚糖]]基CDs，一种为[[聚乙烯亚胺|PEI]]基CD。PEI基CDs此前已合成，纳入本文用于比较和进一步考察。选择壳[[聚糖]]作为富含胺基的天然生物聚合物，以替代PEI，从而获得更好的[[生物降解性]]和[[生物相容性]]。<sup>25,26</sup>壳聚糖基CDs配方上的变化旨在优化胺类特征，同时获得尺寸小且呈阳离子性的CDs。壳聚糖在水中的溶解需要酸性条件；本研究使用了不同酸，以探究羧酸基团数量是否会影响CD性能。这些CDs通过[[水热反应]]合成，所有前驱体均可在胺基与羧基/羟基之间发生[[缩合反应]]，形成无定形CDs。所得CDs均表现出[[胶体稳定性]]、小尺寸以及高度正的$\zeta -$电位（表1）。

## 基于 [[核磁共振波谱|NMR]] 的评价

测定[[主客体相互作用]][[结合常数]]的一种传统技术是基于滴定的 [[核磁共振波谱|NMR]] 方法，其中信号[[化学位移]]或强度的变化可指示结合或缔合。<sup>34−36,42,45</sup> 在整个滴定过程中监测这些变化，并可将其拟合到[[结合曲线]]上，以获得亲和力和定量信息。<sup>35,42</sup> 使用 <sup>19</sup>F [[核磁共振波谱法|NMR]] 非常适合该体系，因为唯一检测到的核来自 [[PFAS]]，可实现直接监测而不受干扰或无需大量样品制备。为初步定量 [[CD]] 对 [[PFOA]] 的亲和力，我们记录了 [[全氟辛酸|PFOA]] 在 [[碳点|CD]] 浓度递增时的 $^ { 1 9 } \mathrm { F }$ NMR 谱（图 4a），并与 $\beta \mathrm { \cdot }$ -[[环糊精]]进行比较。每个 CD 浓度下所有峰的平均高度用于估计 PFOA [[结合分数]]（f），并建立结合曲线以提取 $\mathrm { K _ { d } }$ 值（图 4b）。根据先前针对 [[PEI CDs|PEI CD]] 与 PFOA 并侧重于确定相互作用时间尺度的实验，在 CD 与 PFOA 混合 72 h 后采集谱图。<sup>24</sup> 虽然大部分相互作用发生在谱图采集时间内，仍使用 72 h 以确保达到平衡。此外，PFOA 和 CD 浓度保持为基于质量的单位（mg/L），而非使用标准 $\mathrm { K _ { d } }$ 单位摩尔浓度。[[全氟和多氟烷基物质|PFAS]] [[污染物]]浓度和[[吸附剂|吸附材料]]投加量通常以 mg/L 讨论，因此优先保持现场典型单位。这一约定还最大限度地减少了为估算 CD 摩尔质量而纳入各种难以测量的 CD 性质假设（如密度）的需要。

在CD滴定过程中监测PFOA信号时，[CD]的增加导致PFOA信号逐渐衰减，表明CD与PFOA之间存在相互作用。具体来说，峰高有所下降，同时伴随峰宽增加，这可能是由于检测期间自由态与结合态之间的相互转化所致。<sup>34,48,49</sup>对于某些CD，观察到峰高下降与峰宽增加并存，这导致即使峰高明显下降，峰积分绝对值在不同[CD]下仍可能保持恒定。因此，在结合曲线中采用峰高而非更传统使用的峰积分来估计结合分数。对于壳聚糖基$\mathrm { C D } s ,$，化学位移未出现与CD浓度相关的显著变化。然而，PEI $\mathrm { C D } s ^ { 2 4 }$的化学位移如前所报道发生了变化。不同CD之间化学位移变化不一致，进一步表明峰高是在所有CD中监测的一致特征。NMR结合滴定过程中的另一个潜在观察结果是出现对应于结合物种的新峰。对于壳聚糖-CDs，未出现对应于结合PFAS的新峰，但由于壳聚糖-CD尺寸较大，该峰可能被展宽至超出检测范围。对于PEI CDs，在高[PEI CD]浓度下确实出现了对应于结合PFOA的峰。<sup>24</sup>

所得[[吸附剂]]材料的$\mathrm { K _ { d } }$值（图4e）使用图4d所示的结合模型进行拟合。最初的$\mathrm { K _ { d } }$值使用未包含所示附加α因子的结合模型进行拟合；然而，这导致了不一致的拟合结果，如$\mathbb { R } ^ { 2 }$值所示，且[[95%置信区间]]较大（SI第S2节）。拟合不一致可能源于[[CD]]的物理化学差异——由于不同的潜在结合机制、$\mathrm { T } _ { 2 }$弛豫时间或其他不均匀性，每种[[碳点|CD]]对[[PFOA]]信号的影响可能不同，从而导致最大信号衰减程度不同。<sup>50−52</sup>因此，引入了附加α因子以考虑不同CD之间最大信号响应的差异。该因子表示当几乎所有[[全氟辛酸|PFOA]]分子都与CD结合时，或该CD的最大结合容量时，所能产生的最大可能响应。为突出引入α因子的益处，[[β-环糊精]]的$\mathrm { K _ { d } }$从4.9 g/L（未含α）转变为411 mg/L（含α），与已发表文献值398 mg/L相符。<sup>33</sup>在各种CD中，[[PEI CDs]]表现出最高的亲和力$\mathrm { ( K _ { d } } = 8 . 0$ mg/L），其次是CLAA 10:1:10 $\left( \mathrm { K _ { d } } ^ { - } = 6 7 . 4 ~ \mathrm { m g / L } \right)$）。除一种CD（CLAA 1:1:1）外，其余所有CD对PFOA的亲和力均高于基准β-[[环糊精]]，表明这些CD与其他高性能[[吸附]]剂材料表现相当。

虽然用于理解亲和力的[[结合曲线]]方法是定量的，但结合亲和力主要应被视为本文所考虑[[吸附剂]]之间进行比较的一个指标。由于获取结合亲和力的各体系间确切实验条件存在差异，采用一种将[[吸附]]剂彼此排序的基准方法，可确保在相关条件下对亲和力形成最佳理解。此外，由于每种材料在整个滴定过程中 [[PFOA]] 信号的变化方式不同，它们很可能处于略有不同的交换区间。通常，用于量化亲和力和评估结合的指标（[[化学位移]]、峰积分、峰宽）取决于交换区间。<sup>34</sup> 然而，由于优先考虑使用实际浓度范围，我们无法调整浓度并强制特定交换区间，从而为定量提供理想的观测指标，如化学位移或峰积分。因此，使用平均峰高将峰变化简化为单一变量，以监测与 [[全氟辛酸|PFOA]] 的相互作用。此外，[[碳点]]很可能不会以 1:1 的比例结合 PFOA，因为碳点可能具有多个 [[PFAS]] [[结合位点]]。在数学上纳入多位点结合的最简单方法是引入一个额外的 n 项，用于表示等效且彼此不相互作用的结合位点。<sup>29</sup> 然而，引入额外的拟合参数导致出现三个高度相关的变量 $( n , \mathrm { K } _ { \mathrm { d } } , \alpha )$，并且未能得到唯一解；n 值可以变化，并能在不同的 $\mathrm { K _ { d } }$ 值下获得良好拟合。因此，本文结果未纳入表示位点数的额外 n 项，而是依赖 1:1 假设。不过，该方法仍提供了一种途径，可在一定碳点浓度范围内量化 [[核磁共振波谱|NMR]] 信号变化，从而揭示碳点对 PFOA 的亲和力。为增强可信度并进一步理解碳点对 [[全氟和多氟烷基物质|PFAS]] 的亲和力，我们采用了基于不同原理的其他 [[核磁共振波谱法|NMR]] 分析方法来验证性能排序。$\mathtt { B y }$ 通过使用多种方法，我们希望展示一组在不同限制条件下运行的实验，并在总体上提供一种广泛适用的方法，用于比较各种材料对 PFAS 的亲和力。

## 基于 [[Carr-Purcell-Meiboom-Gill脉冲序列|CPMG]] 的排序

在 [[核磁共振波谱|NMR]] 中，横向弛豫或 $\mathrm { T } _ { 2 }$ 弛豫是指垂直于外加磁场的磁化强度逐渐失相的过程。<sup>49,52</sup> 驱动 $\mathrm { T } _ { 2 }$ 弛豫的主要机制之一是分子运动或翻滚，而后者又与[[分子量]]相关。<sup>34,51,52</sup> $\mathrm { T } _ { 2 }$ 弛豫主要通过信号宽度来观察，其中 $\mathrm { \ddot { T } } _ { 2 }$ 弛豫速率 $( 1 / \mathrm { T } _ { 2 } \bar { ) }$ 转化为最终 [[核磁共振波谱法|NMR]] 信号的[[半峰全宽]]。因此，快速翻滚的小分子具有较长的 $\mathrm { T } _ { 2 }$ 弛豫时间和尖锐的峰，而翻滚较慢的较高分子量分子（包括[[蛋白质]]、纳米颗粒和大分子）则具有较短的 $\mathrm { T } _ { 2 }$ 时间和展宽的峰。

$\mathrm { T } _ { 2 }$ 弛豫实验利用自由分子与结合分子之间弛豫性质的差异来检测结合。通常采用 [[Carr-Purcell-Meiboom-Gill脉冲序列|Carr−Purcell−Meiboom−Gill]]（[[Carr–Purcell–Meiboom–Gill脉冲序列|CPMG]]）脉冲序列，该序列由一个硬 90° 激发脉冲后接一系列 $1 8 0 ^ { \circ }$ [[自旋回波|自旋−回波]]重聚焦脉冲组成。<sup>53,54</sup> 如果某分子的弛豫性质在重聚焦脉冲期间发生改变（例如发生结合），该分子的信号将无法被重聚焦，从而被滤除。<sup>36</sup> 在本研究中，$1 8 0 ^ { \circ }$ 脉冲将重聚焦自由 [[PFOA]] 的信号，同时滤除任何与 [[CD]] 结合的 [[全氟辛酸|PFOA]] 信号，最终得到的信号强度仅对应自由 PFOA。

为了解决不同[[碳点]]配方在尺寸和性质上的差异可能影响图 4e 所示 $\mathrm { K _ { d } }$ 绝对值的问题，还采用基于 [[Carr-Purcell-Meiboom-Gill脉冲序列|CPMG]] 的方法评估了 [[PFAS]] 结合，比较了 125 ms [[Carr–Purcell–Meiboom–Gill脉冲序列|CPMG]] 延迟与无延迟谱图之间的信号强度。该实验在有 [[CD]] 和无 CD 条件下分别进行；以“比值之比”的形式比较信号强度，从而定义一个可量化的因子 $\mathrm { Q } ^ { \mathrm { b i n d } }$，用于评估结合（图 5b）。<sup>37</sup> 较低的 $\mathrm { Q } ^ { \mathrm { b i n d } }$ 值表示引入 CPMG 延迟后信号强度变化更大，表明结合更强。在低[[吸附剂]]浓度下，$( 0 . 5 ~ \mathrm { g / L } ) ,$ 只有 [[β-环糊精]]表现出强结合，而在高[[吸附]]剂浓度（3.5 g/L）下，除 [[PEI CDs]] 外，所有 CDs 和 β-[[环糊精]]均表现出强结合。在 CDs 中，CLAA 10:1:10 在高浓度下表现出最强结合，与 $\mathrm { K _ { d } }$ 测量结果一致。值得关注的是，[[聚乙烯亚胺|PEI]] CDs 在两种浓度下均未表现出强结合，这与 $\mathrm { K _ { d } }$ 测量结果不同。这里需要指出，$\mathrm { Q } ^ { \mathrm { b i n d } }$ 测量未考虑[[旋转相关时间|旋转翻滚时间]] $( \tau _ { \mathrm { c } } )$；由于 PEI CDs 明显小于任何[[壳聚糖基碳点|基于壳聚糖的 CDs]]（表 1 最右列），这可能导致 PEI CDs 的信号降低较小，从而得到较大的 Q<sup>bind</sup> 值。因此，该方法可能最适合用于比较具有相似[[分子量]]的吸附剂；但它只需每个吸附剂进行两次实验即可提供亲和力信息，能够快速获得结果。尽管结果获取迅速，但如果吸附剂的分子量或尺寸存在显著差异，不建议使用该方法。

在每种 [[CD]] 和 [[β-环糊精]]存在下，计算了 [[PFOA]] 的 $\mathrm { T } _ { 2 }$ 弛豫时间，以进一步了解 [[碳点|CDs]] 与 [[全氟辛酸|PFOA]] 之间发生的相互作用（表 S1）。应当指出，此处报告的 $\mathrm { T } _ { 2 }$ 值是表观 T 值，有时记作 ${ \bar { \mathrm { T } } } _ { 2 } ^ { * }$ 或 $\mathrm { T } _ { 2 , \mathrm { e f f } }$，它反映所观测到的 $\mathrm { T } _ { 2 }$，并包含来自交换或其他磁场不均匀性的贡献。$\mathrm { T } _ { 2 }$ 时间在低和高 CD 浓度下测定，以监测浓度间的变化。我们假设随着 CD 浓度增加，$\mathrm { T } _ { 2 }$ 会缩短，因为更多的 PFOA 与缓慢翻滚的 CDs 结合。事实上，与纯 PFOA 相比，在任何浓度下 CDs 存在时 PFOA 的 $\mathrm { T } _ { 2 }$ 都降低了。此外，对于所有[[壳聚糖基碳点|基于壳聚糖的 CDs]] 和 $\beta { \mathrm { - C D } }$，随着[[吸附剂]]浓度增加，$\mathrm { T } _ { 2 }$ 均出现下降，表明更多 PFOA 发生结合。在这些情况下 $\bar { \mathrm { T } _ { 2 } }$ 对浓度的依赖性还表明 快速或中等交换状态。在快速和中等交换状态下，观测到的 $\mathrm { T } _ { 2 }$ 是游离 PFOA 的 $\mathrm { T } _ { 2 }$ 与结合态 PFOA 的 $\mathrm { T } _ { 2 } . ^ { 4 8 , 4 9 }$ 按群体加权的平均值。因此，$\mathrm { i f }$ 结合态 PFOA 的群体比例越大，我们就会看到 $\mathrm { T } _ { 2 } .$ 相应降低。伴随结合出现的 T 降低，可能源于 PFOA 在 CDs 上密集堆积而导致其运动受限，和/或与缓慢翻转的 CD 结合所致。

## 24 种 [[PFAS]] 混合物

基于这些[[环糊精]]（[[CD|CDs]]）如何[[吸附]][[PFOA]]及其在该吸附过程中相对性能的深入认识，同一系列六种环糊精被用于测试含有24种$\mathrm { P F A S } ,$的混合物，其中包括[[美国EPA方法8327]]中发布的适用于地表水、地下水和废水的物质。<sup>55</sup> $^ { 1 9 } \mathrm { F }$ [[核磁共振波谱|NMR]]混合物谱图的一般区域根据先前$^ { 1 9 } \mathrm { F }$ [[核磁共振波谱法|NMR]]研究进行归属。<sup>24</sup> 在三种不同环糊精浓度下监测了各区域峰积分的变化（图8a）。总体而言，五种不同的[[壳聚糖基碳点|壳聚糖基环糊精]]表现相似，在不同浓度下具有可比的信号强度变化。与内部$\mathrm { C F } _ { 2 }$和磺酸基α-氟相对应的区域在[[壳聚糖]]基环糊精中表现出最显著的变化，表明其更倾向于较长链的[[全氟烷基磺酸盐]]（PFSAs）。一个显著差异在于CLAA 10:1:10，它是唯一一种能够引起与[[PFBA|全氟丁酸]]（PFBA）相对应峰的[[化学位移]]变化（Δδ）的壳[[聚糖]]基环糊精， 如图 8b 中的虚线所示。

[[PEI CDs]]在24种[[PFAS]]混合物中的表现与[[壳聚糖]]基[[CD|CDs]]略有不同。首先，[[碳点|PEI CDs]]引起了显著的峰展宽，导致与壳[[聚糖]]基CDs相比，在峰高下降相似或更大的情况下，积分百分比变化较低。在最高CD浓度下，[[聚乙烯亚胺|PEI]] CDs对 $\mathrm { C F } _ { 2 }$ 最接近 $\mathrm { C F } _ { 3 }$ 与[[壳聚糖基碳点|基于壳聚糖的碳点]]相比，这些基团具有更多的含氧官能团；这可能表明其对较短链分子具有更高的亲和力。如同 CLAA $1 0 { : } 1 { : } 1 0 ,$ PEI CDs 在高浓度下诱导了 [[PFBA]] 的 [[化学位移|Δδ]]。PEI CDs 以及在较小程度上的 CLAA 10:1:10，在约 −83 ppm 处产生了一个宽峰，这可能表明 CF 基团形成了胶束/半胶束。<sup>30</sup> 这种效应在仅含 [[PFOA]] 时并不存在，并且可能在总 [[全氟和多氟烷基物质|PFAS]] 浓度较高时出现。总体而言，所有 CDs 对混合物中 PFSA 的亲和力似乎都高于其他 PFAS，而基于壳聚糖的 CDs 可能对较长链 PFAS 具有更高的亲和力，而 PEI CDs 则可能 对短链PFAS具有更高的亲和力。24种PFAS混合物实验证实，PEI碳点和CLAA 10:1:10是该组中表现最好的碳点，在混合物中具有最广的亲和力范围，并且当[[全氟辛酸|PFOA]]单独存在时，对其具有最高的定量亲和力。

## 对[[PFOS]]的亲和力

基于[[PEI CDs]]和CLAA 10:1:10在24种[[PFAS]]混合物中对[[PFOA]]表现出的高亲和力及良好结果，选择它们进行与[[PFOS]]的进一步亲和力分析。 $\mathrm { K _ { d } , Q ^ { b i n \bf { \dot { d } } } }$ ，并且 $\mathtt { p _ { b } }$ 重复上述方法以评估 [[全氟辛烷磺酸|PFOS]] 亲和性，并且 $\beta \mathrm { - }$ [[环糊精]]被纳入作为对照。 $\mathrm { K _ { d } }$ 值经α因子校正后同样指示 ${ \mathrm { K } } _ { \mathrm { d } } \mathbf { s }$ 用于 [[聚乙烯亚胺|PEI]] $\mathrm { C D s } ,$ CLAA 10:1:10，以及 $\beta \mathrm { - }$ 环糊精，分别为 0.22 mg/L、0.20 mg/L 和 0.41 mg/L。这些值均显著低于 [[全氟辛酸|PFOA]] 的值，表明其对 PFOS 的亲和力高于 PFOA，这与在 24 种 [[全氟和多氟烷基物质|PFAS]] 混合物中观察到的环糊精对 PFSA 较高的亲和力一致。

使用基于[[Carr-Purcell-Meiboom-Gill脉冲序列|CPMG]]的方法时，在[[PEI CDs]]和CLAA 10:1:10中加入[[CPMG方法|CPMG延迟]]后，信号强度没有差异，$\mathrm { Q } ^ { \mathrm { b i n d } }$值为1，且无p值。应当指出，[[PFOS]]信号强度被[[CD|CDs]]衰减，但[[Carr–Purcell–Meiboom–Gill脉冲序列|CPMG]]延迟对[[碳点|CD]]+[[全氟辛烷磺酸|PFOS]]信号的影响与对纯PFOS信号的影响没有任何不同。这表明在延迟时间范围内，PFOS并未在自由态与结合态之间发生交换，并且CD与PFOS的相互作用处于慢交换状态。<sup>48</sup>在慢交换状态下，通过CD滴定监测PFOS信号下降可能是评估PFOS亲和力的最准确方法，因为观察到的信号反映的是自由PFOS群体。这一点通过在两种不同浓度下纯PFOS和含CDs的PFOS具有相似的$\mathrm { T } _ { 2 }$值得到证实（表S2）。通常，在慢交换状态下，可以观察到分别对应于自由态和结合态物种的独立信号。然而，我们认为假设的结合态PFOS信号很可能因展宽而超出观测范围，原因是 与大[[环糊精]]的结合较弱，或结合态浓度低于可检测限。

[[β-环糊精]]的情况则不同，其对 [[PFOS]] 表现出与 [[PFOA]] 相似的趋势，且行为更符合快—中间交换区间。其 $\mathrm { Q } ^ { \mathrm { b i n d } }$ 和 $\mathtt { p _ { b } }$ 值与 [[全氟辛酸|PFOA]] 相近（表 S3）；然而，β-[[环糊精]]用于 [[全氟辛烷磺酸|PFOS]] 时的浓度为 1 mg/L，而用于 PFOA 时为 3.5 g/L（两者 [[PFAS]] 均为 5 mg/L），表明其对 PFOS 的亲和力高于 PFOA。[[吸附剂|吸附材料]]通常对 [[全氟烷基磺酸盐|PFSAs]] 的亲和力高于[[全氟烷基羧酸]]（PFCAs），因此尽管定量 $\mathrm { K _ { d } }$ 值相近，但 [[CD|CDs]] 所表现出的慢交换表明其与 PFOS 的相互作用强于 β-环糊精，进一步凸显了 [[碳点|CDs]] 作为一类具有高 [[全氟和多氟烷基物质|PFAS]] 亲和力的可调控[[吸附]]材料的潜力。

## ■ 结论

在此，我们描述了一系列实验，用于对新型[[吸附剂]]纳米材料与[[PFAS]]的亲和力进行排序，并与[[β-环糊精]]进行基准比较。[[聚乙烯亚胺|PEI]][[碳点]]对[[PFOA]]的亲和力显著高于任何[[壳聚糖基碳点]]或β-[[环糊精]]，并在含多种分子的24种[[全氟和多氟烷基物质|PFAS]]混合物中表现良好。该流程凸显了利用$^ { 1 9 } \mathrm { F }$ [[核磁共振波谱|NMR]]理解与PFAS相互作用并快速筛选[[吸附]]材料有效性的能力——且仅需极少的样品制备。我们重点介绍了基于不同[[核磁共振波谱法|NMR]]原理的多种评估吸附的方法，并对这些材料对PFAS的亲和力提供了一致性视角。通过结合多种方法，我们可以更深入地理解碳点和β-环糊精如何与[[全氟辛酸|PFOA]]及[[PFOS]]相互作用，包括相对平行分子之间的差异。虽然碳点对[[全氟辛烷磺酸|PFOS]]的亲和力明显强于PFOA，但数据并不支持它们在结合碳点方式上存在显著差异。$\dot { \mathrm { C F } _ { 3 } }$与α-氟原子分别代表分子两端，在与碳点$\left( \Delta \delta , \mathrm { T } _ { 2 } \right)$结合时表现相似，这表明结合取向可能不是亲和力差异的主要驱动因素。总体而言，这些数据清楚地表明了碳点用于PFAS吸附的潜力。此外，所建立的NMR方案和分析方法将适用于任何其他正在开发的用于PFAS修复的吸附材料，为新材料的潜在有效性提供定量且快速的洞察。
