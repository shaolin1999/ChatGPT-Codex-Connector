## 1. 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）由于在不同工业中的广泛应用及其在自然环境中的显著持久性，在[[土壤]]、水体、牲畜和作物中被广泛检出并持续累积。<sup>1,2</sup> 人类接触 [[全氟烷基酸|PFAS]] 化合物被认为是不可避免的，其中长链[[全氟烷基羧酸|全氟烷基羧酸盐]]（[[PFCA]]）和[[全氟烷基磺酸|磺酸盐]]（[[PFSA]]）因其比短链同类物更强的持久性、[[生物累积|生物累积潜力]]和毒性，在全球范围内受到更多关注。<sup>3,4</sup> 同时，短链 PFAS 可能从土壤迁移到植物中，并沿食物链传递，对生态环境构成潜在风险。<sup>3−5</sup> 因此，揭示 PFCA/PFSA 分子与土壤组分相互作用的详细机制，对于加深我们理解长链和短链 PFAS 在自然环境中的环境归趋具有重要意义。

[[土壤]]中最常见的[[黏土矿物]]（如[[蒙脱石]]，MMT）对 [[PFAS]] 表现出较强的[[吸附]]能力，这主要由[[静电相互作用]]、[[氢键]]和[[疏水相互作用]]驱动。<sup>6,7</sup> 以往的批量吸附实验结果表明，由于[[硅氧烷表面]]上的疏水相互作用，[[全氟辛烷磺酸|PFOS]] 在[[高岭石]]和[[叶蜡石]]上的吸附增强，<sup>8,9</sup> 而 [[PFSA]] 在高岭石和[[赤铁矿]]上的吸附也涉及[[羟基]]位点上的静电相互作用和氢键。<sup>10−12</sup> 通过[[中子散射|中子散射实验]]进一步说明了静电相互作用的重要性，即 [[PFOA]] 对带正电荷的[[氧化铝]]的亲和力高于对带负电荷的[[二氧化硅]]的亲和力。<sup>13</sup> [[红外光谱]]和 [[X射线衍射|X 射线衍射]]研究表明，PFOS 在 MMT 上存在双重吸附机制：[[外球络合]]和[[内层吸附|层间嵌入]]，而这种层间吸附在高岭石中不会发生。<sup>14</sup> 因此，[[全氟和多氟烷基物质|PFAS]] 的吸附行为主要受分子结构控制，其中极性头基决定静电相互作用，[[碳氟链|C−F 链]]调节疏水相互作用。<sup>15</sup> 然而，当静电或疏水相互作用被广泛用于简单而笼统地解释所有现象时，还不足以揭示不同体系中具有不同头基或链长的 [[全氟烷基酸|PFAS]] 吸附的详细或新颖机制。

在自然[[土壤]]环境中，[[腐殖酸|胡敏酸]]（HA）等有机质通常与土壤矿物结合，这可能改变矿物的物理化学性质。<sup>16</sup> [[PFAS]] 在土壤中的累积往往随[[有机碳]]含量的增加而增加，<sup>17</sup> 这强调了有机质在控制 [[全氟和多氟烷基物质|PFAS]] 迁移和归趋方面的重要性。HA 可通过促进[[疏水相互作用]]的疏水域促进 [[全氟烷基酸|PFAS]] [[吸附]]，例如 HA 增强 [[全氟辛烷磺酸|PFOS]] 在[[针铁矿]]上的吸附，<sup>18</sup> 因此，HA 甚至被提议作为 $\mathrm { P F A S . } ^ { 1 9 }$ 的潜在环境汇。还观察到，水相中溶解性 HA 的浓度可通过 HA 有机官能团与 PFAS 分子之间的络合作用抑制 PFAS 的保留。<sup>20</sup> 在结合 [[衰减全反射傅里叶变换红外光谱|ATR FTIR 光谱]]、[[Zeta电位|zeta 电位测量]]和[[锕系元素X射线吸收精细结构光谱|近边 X 射线吸收精细结构光谱]]分析的批量实验中，HA 对 PFOS 在[[高岭石]]和 [[蒙脱石|MMT]] 上吸附的抑制作用主要归因于矿物表面的竞争吸附和增强的[[静电排斥]]。<sup>14</sup> 关于 PFAS 官能团和链长对其在矿物上吸附影响的一般趋势已被观察到，但矿物分子相互作用背后的详细机制仍不明确，尤其是在有机质存在的情况下。这一知识空白还因光谱表征技术的局限性而加剧，这些技术缺乏在矿物-有机界面上分辨 PFAS 分子取向、配位环境和扩散动力学所需的空间分辨率，特别是在环境相关浓度下。<sup>21,22</sup>

[[分子动力学]]（[[分子动力学模拟|MD]]）模拟通过捕捉分子运动并提供原子级视角，为研究[[PFAS]][[吸附]]机制提供了显著优势。<sup>23,24</sup> 这些模拟已被广泛用于探究[[全氟和多氟烷基物质|PFAS]]分子尺寸、盐度、配位阳离子类型、矿物结构及性质对[[黏土矿物]]上吸附行为的影响。<sup>25,26</sup> 例如，先前的MD模拟表明，短链和长链[[全氟烷基酸|PFAS]]均优先吸附在[[高岭石]]的[[羟基]]表面上。<sup>27</sup> MD模拟揭示，[[叶蜡石]]固有的疏水性可促进中链和长链PFAS化合物的吸附，而[[伊利石]]和[[蒙脱石|MMT]]中$\mathrm { C a } ^ { 2 + }$的存在则通过[[钙桥接|阳离子桥联效应]]调控6:2氟调聚物[[全氟烷基磺酸|磺酸盐]]的吸附。<sup>15</sup> 此外，MD模拟还解释了[[腐殖酸|HA]]抑制[[全氟辛烷磺酸|PFOS]]在$\mathrm { S i O } _ { 2 }$表面上吸附的原因，主要是由于HA的极性官能团与PFOS阴离子之间的位点竞争。<sup>28</sup> 然而，对于MMT-HA混合体系中各种PFAS化合物的主导分子相互作用，以及HA对PFAS吸附行为影响的详细机制，目前仍不明确。

本研究旨在通过[[吸附]]实验、[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算和[[分子动力学|MD]]模拟，阐明具有不同末端官能团和[[碳氟链|全氟烷基链]]长的[[PFAS]]在[[蒙脱石|MMT]]和MMT-[[腐殖酸|HA]]表面上的分子级界面构型及相互作用机制。系统分析并比较了有HA和无HA条件下MMT-[[全氟和多氟烷基物质|PFAS]]体系中的[[吸附百分比]]、[[相互作用能]]、[[溶剂可及表面积]]（SASA）、[[径向分布函数]]（RDF）和[[扩散系数]]。对吸附机制进行了研究，以揭示[[全氟烷基酸|PFAS]]在矿物-有机界面行为的基础性认识。本研究的分子层面见解将提升我们对PFAS及结构类似污染物在[[土壤]]环境归趋方面的预测能力。

## 2. 材料与方法

## 2.1. 材料

混合[[PFAS]]标准溶液（EPA-533PAR，溶于甲醇）和13种同位素标记内标混合物（MPFAC-C-ES，甲醇基）购自[[Wellington Laboratories]]（加拿大不列颠哥伦比亚省圭尔夫）。对六种[[全氟和多氟烷基物质|PFAS]]化合物——[[PFBS]]、[[全氟己烷磺酸|PFHxS]]、[[PFHpS]]、[[PFPeA]]、[[全氟庚酸|PFHpA]]和[[PFOA]]——进行分析。钙基[[蒙脱石|MMT]]（STx-1b）购自[[美国黏土矿物学会]]。[[腐殖酸|商业腐殖酸]]（钠盐，[[Aldrich Co.]]）按照Silva的方法进行纯化。<sup>29</sup> MMT-HA复合物按照先前描述的方法制备。<sup>30</sup>

## 2.2. [[吸附]]实验

将悬浮液与 10 mM NaNO 背景电解质混合，得到最终体积为 20 mL、[[蒙脱石|MMT]]/MMT-[[腐殖酸|HA]] 复合物浓度为 $2 ~ \mathrm { ~ g ~ L ~ } ^ { - 1 }$ 的体系，其中背景电解质代表[[淡水环境]]。<sup>31</sup> 通过逐滴加入稀 NaOH 或 HCl，将溶液 pH 调节至 7.0 b。每种 [[PFAS]] 的加标浓度为 $2 5 0 \mathrm { \stackrel { \cdot } { n } g \ L ^ { - 1 } } .$ ，这与自然水体中的 [[全氟和多氟烷基物质|PFAS]] 水平密切相关。<sup>32</sup> 例如，在中国、加拿大、美国的河流水中，[[PFOA]] 和 [[全氟己烷磺酸|PFHxS]] 的浓度范围分别为 0.2 至 297.5 ng $\mathrm { L } ^ { - 1 }$ 和 0.15 至 260.0 ng ${ \mathrm { ~ L ~ } } ^ { - 1 } ,$ ，$\mathsf { e t c } . ^ { 3 3 - 3 6 }$ 在连续振荡 48 h 后，分析水相中残留的 [[全氟烷基酸|PFAS]]，所有实验均进行两次平行测定。目标 PFAS 采用 [[超高效液相色谱|UPLC]]（[[Waters ACQUITY UPLC I-Class|ACQUITY I-Class]]，Waters）与 [[三重四极杆质谱仪|Xevo TQ-XS 三重四极杆质谱仪]]联用进行定量。

## 2.3. [[PFAS]] 检测与分析方法

将悬浮液在 4000 × g 下离心 15 min，然后用 0.25 μm 尼龙滤膜过滤上清液。随后，向 18 mL 滤液中加入 5 ng 同位素标记内标，并振荡 30 min 以使溶液均质化。使用装有 150 mg [[Oasis WAX 萃取柱|弱阴离子交换吸附剂]]的 Oasis WAX 萃取柱萃取水相中的 [[PFAS]]，并用 5 mL 正己烷和 5 mL 碱性甲醇（0.1% NH OH）从萃取柱上洗脱目标化合物。萃取液经浓缩、过滤后，于 $\mathrm { a t } - 2 0 \ ^ { \circ } \mathrm { C }$ 条件下保存待分析。内标的最终浓度为 10 ng/mL，用于定量相应的 [[全氟和多氟烷基物质|PFAS]] 化合物。目标 [[全氟烷基酸|PFAS]] 采用[[超高效液相色谱]]（UPLC）与 [[三重四极杆质谱仪|Xevo TQ-XS 三重四极杆质谱仪]]（[[Waters ACQUITY UPLC I-Class]]）联用进行分析。PFAS 的代表性色谱图和实验细节见支持信息（图 S1 和文本 S1）。

对 [[PFAS]] 和 [[腐殖酸|HA]] 在 [[蒙脱石|MMT]]（001）表面的平衡[[吸附]]构型、[[溶剂可及表面积|SASA]]、[[径向分布函数|RDF]]、[[配位数]]（CN）、[[扩散系数]]及[[相互作用能]] $\left( E _ { \mathrm { i n t } } \right)$ 进行了分析，以阐明其空间分布和界面行为。更详细的方法学描述见 Text S4。为评估模拟是否达到平衡，分析了 MMT-[[全氟和多氟烷基物质|PFAS]] 和 MMT-HA-[[全氟烷基酸|PFAS]] 体系随时间变化的势能和温度曲线（Figures S4 和 S7 以及 Text S5）。

[[吸附]]机制通过 [[Cambridge Serial Total Energy Package]]（CASTEP）的[[密度泛函理论|密度泛函理论计算]]加以阐明。相互作用强度通过吸附能进行量化，界面电荷重分布通过[[电子密度差图]]进行可视化。此外，基于前分子密度近似的[[独立梯度模型]]（IGM）被用于可视化吸附质与矿物表面之间的非共价相互作用。<sup>52−54</sup> 全面的计算细节汇编于支持信息（Text S6）。

## 3.2. 平衡[[吸附]]构型

[[PFCA]]-[[蒙脱石|MMT]]和[[全氟烷基羧酸|PFCA]]-MMT-[[腐殖酸|HA]]体系的平衡[[吸附]]构型如图3所示。所有PFCA化合物在MMT表面均呈现稳定的倾斜吸附取向，其中PFCA-MMT体系的平均倾斜角与C−F链长呈负相关，主要分布于40°至60°之间（图S8a）。相比之下，[[PFSA]]化合物的倾斜角范围为40°至$\bar { 5 0 ^ { \circ } }$（图S8b），总体上低于PFCA。此前研究报道[[PFAS]]在[[叶蜡石]]表面和蒙脱石表面呈水平取向，<sup>9,25</sup>而本研究观察到倾斜取向。这种差异可能源于模型设置和体系组成的不同。在先前Willemsen的模型工作中，$\mathrm { C a } ^ { 2 + }$离子被随机分布在水相中，以考察其对[[全氟和多氟烷基物质|PFAS]]吸附的一般影响。<sup>25</sup>与此不同，本研究中${ \mathrm { C a } } ^ { 2 \mp }$离子被明确置于MMT表面的双三角形环上方，以补偿其固有负电荷，而只有Na<sup>+</sup>阳离子随机分散在本体溶液中以模拟背景电解质条件，其中结构性Ca<sup>2+</sup>离子能够捕获对取向具有强烈影响的分子间聚集和协同吸附效应。<sup>58,59</sup>另一种可能的解释是，叶蜡石与C−F链之间的[[疏水相互作用]]远强于此处MMT与C−F链之间的疏水相互作用。

此外，在[[蒙脱石|MMT]]和MMT-[[腐殖酸|HA]]表面上均观察到[[PFAS]]聚集，这可能源于不同[[全氟和多氟烷基物质|PFAS]]分子中C−F尾部之间的[[疏水相互作用]]（图S9−S11），并可能是[[全氟烷基酸|PFAS]]的另一条重要[[吸附]]途径。<sup>60,61</sup>在HA存在下，短链[[PFSA]]表现出更小的倾斜角，而长链PFAS则表现出更大的倾斜角。另一方面，长链PFAS的较大倾斜角需要更多空间来吸附长链[[全氟烷基磺酸|PFSA]]，这种空间限制部分解释了HA对PFSA吸附的抑制作用。短链和长链PFAS之间观察到的不同倾斜取向，可能源于与聚集以及与HA相互作用相关的分子体积和[[空间位阻]]差异。[[PFOA]]的[[羧基]]氧和[[PFHpS]]的[[磺酰基]]氧比PFAS的F原子更靠近MMT表面（图S12），证实了PFAS的倾斜吸附。

[[水桥相互作用]]很可能是一种普遍存在的[[外球络合|外界层吸附]]机制，尤其对于有机分子在矿物表面和[[腐殖酸]]上的[[吸附]]而言。<sup>62−41</sup> 为评估[[水桥]]相互作用在 [[PFAS]] 吸附中的作用，随机选取了一个代表性分子，并对其与 [[全氟和多氟烷基物质|PFAS]] 和表面均在 3.5 Å 范围内的水分子参与[[氢键]]的情况进行了定量统计（图 4a）。氢键判据设定为供体与受体之间的最大距离 3.5 Å、最小角度 120°。<sup>12</sup> 对每一种 [[PFCA]] 或 [[PFSA]]，参与的水分子数和氢键数均随 [[全氟烷基酸|PFAS]] 在 [[蒙脱石|MMT]] 上的链长增加而增加（图 4b,c）。在 [[全氟烷基羧酸|PFCA]] 与 [[全氟烷基磺酸|PFSA]] 基团之间进行比较时，MMT 体系中 PFSA 的氢键数量通常高于 PFCA，这与倾斜角结果一致。PFAS 氢键的变化与我们的吸附实验结果中[[吸附百分比]]随 [[碳氟链|C−F 链]]长增加而增大相一致，表明水桥氢键也促进了 PFAS 的界面稳定，尤其是长链 PFAS。以往研究更多关注[[疏水相互作用]]和直接氢键在 PFAS 吸附到[[高岭石]]、[[叶蜡石]]和[[赤铁矿]]表面过程中的贡献。<sup>9,10,12,27,65</sup> 我们的计算结果证明，在 PFAS 于[[黏土矿物]]上的外界层吸附中，必须考虑水桥相互作用的作用。<sup>65</sup>

## 3.4. [[相互作用能]]与[[扩散系数]]

[[相互作用能]]是表征[[PFAS]]结合强度并解释[[吸附]]行为的另一重要因素。如图8a−c所示，短、中、长链[[PFSA]]与[[蒙脱石|MMT]]的相互作用能分别为−6667.9、−6080.9和−4822.2 kJ/mol，而相应[[PFCA]]的相互作用能分别为−6353.7、−4848.4和−4242.1 kJ/mol。比较具有相同C−F链长的[[全氟烷基磺酸|PFSA]]与[[全氟烷基羧酸|PFCA]]可知，PFSA与MMT的相互作用能比PFCA更负，表明PFSA对MMT表面具有比PFCA更强的亲和力。此外，还对代表性[[PFPeA]]和[[PFBS]]进行了[[DFT]]计算，以量化其结合强度。[[全氟丁烷磺酸|PFBS]]（−127.9 kJ/mol）相对于[[全氟戊酸|PFPeA]]（−85.0 kJ/mol）表现出的显著热力学偏好可通过[[电荷密度差分|电荷密度差分分析]]（图S15）加以解释，该分析表明，与[[羧基]]类似物相比，[[磺酰基]]部分在$\mathrm { C a } ^ { 2 + } { - } \mathrm { O }$界面处驱动了更优的电子积累和[[Hirshfeld电荷|Hirshfeld电荷转移]]。这表明磺酰基对表面具有更强的结合亲和力。 $\mathrm { C a } ^ { 2 + }$ 比羧基更强。磺酰基还表现出比羧基更大的静电活性（文本 S7 和图 S16）。我们的计算结果与 PFSAs 相对于 PFCAs 更高的[[吸附百分比]]一致，并得到先前研究的支持，即 [[全氟辛烷磺酸|PFOS]] 在[[二氧化硅]]上的吸附强于 [[PFOA]]。<sup>54</sup>

此外，头部基团相互作用分别占短链、中链和长链[[PFAS]]在[[蒙脱石|MMT]]及MMT-[[腐殖酸|HA]]上[[吸附]]总[[相互作用能]]的84.7−94.3%、81.9−91.7%和80.2−94.4%。因此，[[全氟和多氟烷基物质|PFAS]]主要通过头部基团与MMT/MMT-HA发生相互作用，且由于[[磺酰基]]对矿物表面具有更高的亲和力，[[PFSA]]表现出比[[PFCA]]更强的亲和性。值得注意的是，[[全氟烷基羧酸|PFCA]]和[[全氟烷基磺酸|PFSA]]的相互作用能均随链长增加而降低（图8a−c），这与长链[[全氟烷基酸|PFAS]]吸附量更高的现象（图2）不一致。对于计算中相互作用能随链长增加而降低的一种解释是，长链PFSA在MMT表面吸附时受到[[空间位阻]]影响。<sup>11</sup> 或者，尽管存在$\mathrm { C a } ^ { 2 + }$桥接，另一种吸附途径可能对PFAS在矿物表面稳定化的贡献被低估。[[疏水相互作用]]以及通过[[水桥]]接形成的[[外球络合|外层络合]]作用，随PFAS链长的增加而增强，可能 为 PFAS 随链长增加而增强的吸附提供了更好的解释。 $\mathrm { C - F }$ 链（图4c）比 $\mathsf { C a } ^ { 2 + }$ -桥接效应单独作用。具体而言，[[碳氟链|全氟烷基链]]的延长增加了[[疏水表面]]积，<sup>70,71</sup> 从而通过疏水相互作用增强了热力学驱动力。总体而言， $\mathrm { \mathop { C a } } ^ { 2 + }$ 桥接是PFAS在MMT上吸附的主要途径，但疏水相互作用以及经由[[水桥相互作用]]形成的外层络合也不应被忽视。

[[腐殖酸|HA]]的存在不仅会影响[[相互作用能]]，还会影响[[PFAS]]在[[蒙脱石|MMT]]矿物表面的[[扩散系数]]。如图$^ { 8 , }$所示，HA主要通过位点竞争和[[静电排斥]]降低[[全氟和多氟烷基物质|PFAS]]与MMT之间的相互作用能。<sup>14</sup>HA的存在提高了短链[[全氟烷基酸|PFAS]]的扩散系数（图8d−f和表S6），对中链PFAS影响较小，并降低长链PFAS的扩散。扩散的变化表明，HA可能通过[[静电相互作用|静电排斥]]增强短链PFAS的迁移性，而HA有可能降低长链PFAS的迁移性。先前研究报告称，HA抑制[[PFOA]]和[[全氟辛烷磺酸|PFOS]]的迁移，且对长链PFAS的阻滞效应比其短链同系物更为显著。<sup>69,72,73</sup>遗憾的是，在我们的实验结果中未观察到对长链[[吸附]]的促进作用，因为多种因素控制着PFAS的吸附行为。在此，HA的静电排斥、[[空间位阻]]以及对${ \mathrm { C a } } ^ { 2 + }$结合位点的竞争可能共同主导并抑制了PFAS的吸附。

## 4. 环境意义

阐明控制 [[PFAS]] 与[[黏土矿物]]及[[天然有机质]]相互作用的分子层面机制，对于准确预测其环境归趋和开发修复技术至关重要。本研究结合[[吸附]]实验与[[分子动力学模拟]]，为含或不含 [[腐殖酸|HA]] 的 [[蒙脱石|MMT]] 体系中 [[全氟和多氟烷基物质|PFAS]] 的吸附与迁移性提供了新见解。本研究表明，[[全氟烷基酸|PFAS]] 的界面结构随其头基类型和链长而具有结构依赖性。[[PFSA]] 表现出比 [[PFCA]] 更强的吸附亲和力和[[相互作用能]]，表明其在以矿物为主导的表面环境（尤其是天然[[土壤]]）中具有更大的累积潜力。此外，尽管所有 PFAS 均可通过矿物表面的 ${ \mathrm { C a } } ^ { 2 + }$ 桥接发生普遍吸附，但[[疏水相互作用]]和通过[[水桥]]形成的[[外球络合]]仍是 PFAS 吸附的重要途径。长链 PFAS 具有更强的疏水相互作用和分子间聚集，以及与矿物表面位点的[[水桥相互作用]]，这解释了为何长链 PFAS 的迁移能力低于短链 PFAS，并倾向于在土壤中累积。值得注意的是，HA 的存在可通过多种途径削弱 PFAS 的吸附，例如[[静电排斥]]、[[空间位阻]]、打断 PFAS 聚集以及对 ${ \mathrm { C a } } ^ { 2 + }$ 结合位点的竞争。可以预期，尽管 HA 可能为某些 PFAS 化合物提供有限的吸附位点，但自然环境中高浓度有机质仍会抑制 PFAS 在矿物表面的吸附，并促进其向水环境迁移。尤其是 [[全氟烷基羧酸|PFCA]] 和短链 PFAS 在富含有机质的基质中表现出更强的迁移性和地下水污染潜力。总体而言，这些发现深化了对具有不同头基或链长的 PFAS 不同吸附行为的分子层面认识，增进了我们对 PFAS 在复杂土壤体系中迁移与滞留的理解。
