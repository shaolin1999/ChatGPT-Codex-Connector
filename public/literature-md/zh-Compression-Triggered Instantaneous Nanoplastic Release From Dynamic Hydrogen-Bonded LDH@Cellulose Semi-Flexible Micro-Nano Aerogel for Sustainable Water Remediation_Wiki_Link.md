## 摘要

[[纳米塑料|纳米塑料（NPs）]]污染是当代最持久的环境危机之一，亟需突破性材料技术实现有效修复。本研究通过动态[[氢键]]与[[配位络合|配位相互作用]]，设计了一种半柔性微纳结构的氮改性[[纤维素纳米纤维]]@[[层状双金属氢氧化物]]（[[N-CNF@LDH]]）复合[[气凝胶]]，以实现纳米塑料的高效去除。其中，LDH纳米花簇均匀锚定于氮改性[[纤维素]]蜂窝骨架上。在动态氢键作用下，结构在撤除外力后于新的平衡位置发生自发重组，从而在花簇内部产生可逆的开合运动。该设计通过可逆的花瓣间通道开启实现超高纳米塑料[[吸附]]（3648 mg⋅g<sup>−1</sup>），而压缩触发的花瓣收缩则实现瞬时释放（10 s内释放率达96%），其[[脱附]]动力学速率较传统吸附剂高出近三个数量级。此外，动态网络使[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]能够通过氢键组装实现快速结构重构，100次循环后仍保持80.4%的纳米塑料吸附容量和95.2%的形状恢复率。该材料在多种真实水体体系中展现出优异的纳米塑料去除性能，同时兼具成本效益，突破了环境修复中容量与再生之间的根本性矛盾。

## 1 引言

全球工业化的快速推进正推动塑料消费呈指数级增长[1]，而不完善的废物管理体系已导致全球水体中累积超过25万公吨塑料碎片[2]。在持续的紫外辐射和机械磨损作用下，这些塑料碎片逐渐分解为直径小于1 m的塑料颗粒（[[纳米塑料|NPs]]），最终转化为具有环境持久性和长距离迁移潜力的新兴污染物[3]。由于絮凝-沉淀等传统污水处理技术对纳米塑料的去除效率通常不足30%，大量此类颗粒持续进入自然水生系统。近期研究报道，全球典型水体中纳米塑料浓度范围为0.004至558 mg⋅L<sup>−1</sup>，显著超过

[[美国环境保护署]]（U.S. EPA）[4]。这些[[纳米塑料]]可在水生生物体内累积，并通过食物网的放大效应引发一系列生态链式反应。新兴的毒理学证据表明，纳米塑料能够穿透血脑屏障，并在肝脏和肾脏等器官中优先蓄积，蓄积效率超过60% [5, 6]。其毒性机制主要涉及诱导线粒体膜电位去极化以及[[活性氧物种]]（reactive oxygen species，ROS）的爆发，从而导致DNA损伤和器官功能障碍。值得注意的是，[[吸附]]在纳米塑料表面的增塑剂及其他化学物质与颗粒本身表现出协同毒性，进一步加剧其生物危害[7]。由于纳米塑料具有较高的环境持久性和生物累积潜力，已被[[联合国环境规划署]]（United Nations Environment Programme，UNEP）列为优先控制污染物[8]。近年来，开发高效的纳米塑料去除技术已成为环境修复领域的研究热点。

在众多修复策略中，[[吸附]]技术因其高效性、可调控性和成本效益而成为去除[[纳米塑料]]最有前景的方法之一[9]。该技术的一个关键优势在于，能够通过物理截留与化学键合的协同作用，有效捕获水体中的痕量纳米塑料。研究人员通过精确调控多种分子间相互作用（包括π-π堆积、[[静电相互作用]]和[[氢键]]），开发了一系列新型功能化多孔吸附体系，其中包括[[金属有机框架]]（MOFs）[10]、[[层状双金属氢氧化物]]（LDHs）[11, 12]、[[共价有机框架]]（COFs）[13]以及生物基[[气凝胶]][14, 15]。这些材料具备分级孔结构和丰富的表面功能结合位点，显著提升了对纳米塑料的吸附能力，吸附容量可达200至2000 mg·g<sup>−1</sup>。

然而，提高[[吸附]]容量往往会导致[[脱附]]难度增加。与常规小分子吸附不同，纳米颗粒（[[纳米塑料|NPs]]）相对较大的粒径使其容易通过物理限域被截留在吸附剂材料的刚性网络内。同时，纳米颗粒表面官能团与材料吸附位点之间的多重化学相互作用进一步阻碍了[[解吸|脱附]]过程 [16]。例如，Zandieh 等 [17] 报道，即使采用[[尿素]]溶剂处理，氨基[[纤维素]][[气凝胶]]中纳米颗粒的脱附率也仅达到 50%。在另一项研究中，Deng 等 [14, 15] 必须采用在二甲基甲酰胺中长时间浸泡的方式才能实现甲壳素泡沫中纳米颗粒的完全去除，而 Zhang 等 [18] 则依靠氯仿溶解来再生负载纳米颗粒的 [[金属有机框架|MOF]] 材料。这些结果表明，尽管溶剂辅助脱附技术能够有效提取被截留在刚性网络中的纳米颗粒，但其对苛刻化学试剂和耗时程序的依赖不仅导致高能耗，还可能对材料造成结构损伤并产生二次污染 [19, 20]。这种吸附与脱附性能之间的不平衡极大地限制了吸附剂材料的实际应用。因此，开发兼具高吸附容量、快速脱附动力学和长期稳定性的新型材料具有重要的实际意义。

前期研究表明，镍铁[[层状双金属氢氧化物]]（NiFe-LDH）具有高正电荷层板和优异的结构可调性，是去除纳米颗粒的理想[[吸附]]剂 [11, 12]。针对上述挑战，本研究通过动态[[氢键]]和离子配位构建了一种半柔性微纳结构 N 改性[[纤维素纳米纤维]]@LDH（[[N-CNF@LDH]]）复合[[气凝胶]]（图 1a），有效克服了传统吸附剂在高吸附容量与快速[[脱附]]效率之间的权衡。在吸附过程中，LDH 表面的 $\mathrm { N i ^ { 2 + } / F e ^ { 3 + } }$ 位点与 [[N-CNF]] 骨架的 ${ \mathrm { - N H } } _ { 2 } / { \mathrm { - O H } }$ 基团通过配位和氢键网络表现出协同效应，同时复合表面显著增强的正电荷密度进一步提高了对纳米颗粒的吸附能力。同时，独特的半柔性结构通过花瓣状单元之间可逆的开闭通道持续暴露新的吸附位点，实现了 3648 mg⋅g<sup>−1</sup> 的高吸附容量（图 1b）[10, 13, 14, 21–26]。在[[机械压缩]]条件下，该材料在 10 s 内实现 96% 的纳米颗粒[[解吸|脱附]]，比传统溶剂脱附方法快近三个数量级，且不使用腐蚀性试剂，避免了二次污染（图 1c）。值得注意的是，[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]] 内可逆的氢键网络使其在脱附后能够快速[[自修复]]，将其微观结构恢复至初始状态，并在 100 次循环后保持超过 80.4% 的吸附容量。这项工作为开发高效、可持续的环境修复材料提供了新策略，展示了在污染控制领域的巨大应用潜力。

## 2 结果与讨论

## 2.1 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的制备与微观结构表征

[[N-CNF@LDH]]复合[[气凝胶]]通过在N改性[[纤维素纳米纤维]]（[[N-CNF]]）表面原位生长[[层状双金属氢氧化物]]（NiFe-LDH）制备而成，其详细制备过程与反应机理如图2a和图S1所示。首先，通过[[纤维素]]纳米纤维（CNF）表面的羧基与[[聚乙烯亚胺]]（[[支化聚乙烯亚胺|PEI]]）的氨基之间的原位[[酰胺化反应]]，构建了富含氮官能团的柔性蜂窝结构N-CNF气凝胶载体（图2a步骤I；宏观外观见图S2）[27]。在反应体系中，CNF表面的羧基被[[三羟甲基丙烷三丙烯酸酯]]（TMPTAP）活化，形成更具亲电性的中间体。随后，PEI分子链上丰富的伯氨基作为强亲核试剂，进攻被活化的羧基碳原子。最终，通过分子内重排与脱水在CNF与PEI之间形成稳定的[[酰胺键]]（─CO─NH─），从而将PEI共价接枝到CNF骨架上，形成N-CNF气凝胶[28]。接着，将N-CNF气凝胶浸入$\mathrm { N i } ^ { 2 + } / \mathrm { F e } ^ { 2 + }$混合金属盐前驱体溶液中，其表面丰富的氨基通过配位键和[[氢键]]锚定金属离子（图2a步骤II）。在NiFe-LDH生长过程中，N-CNF表面丰富的氨基和羟基的孤对电子作为电子供体（Lewis碱），与溶液中的$\mathrm { N i } ^ { 2 + }$和$\mathrm { F e } ^ { 2 + }$离子（Lewis酸）发生预配位，从而将金属离子牢固固定在纤维骨架上，并为后续异相成核提供位点[29]。LDH晶体生长后，LDH层间的羟基可进一步与N-CNF上的氨基和羟基形成氢键，由此建立广泛的金属配位/氢键[[交联]]网络，形成稳定的[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]复合材料。在整个过程中，NiFe-LDH晶体在N-CNF的柔性蜂窝骨架上自主生长并形成纳米花簇，最终构建出具有半柔性微纳结构的N-[[CNF@LDH]]复合气凝胶[30]。

## 2.2 样品的组成与结构表征

利用[[透射电子显微镜]]（TEM）对 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的微观结构进行了系统表征。分析结果表明，[[N-CNF@LDH]] 复合材料具有独特的三维多孔结构，由垂直交织的纳米花簇组成（图 3a）。这种结构不仅有效增大了材料的[[BET|比表面积]]，而且有利于活性[[吸附]]位点的充分暴露，从而实现污染物分子的快速传质[34]。[[高分辨透射电子显微镜]]（[[HRTEM]]）表征清晰显示，[[N-CNF]] 与 [[层状双金属氢氧化物|NiFe-LDH]] 组分之间形成了明确的异质界面（图 3b）。进一步的晶格分辨分析显示出清晰的晶格条纹，其晶面间距为 0.230 nm（图 3c），与 NiFe-LDH（[[JCPDS 40–0215]]）的（015）晶面标准衍射数据完全吻合[35]。这些结果证实了 NiFe-LDH 在 [[纤维素纳米纤维|N-CNF]] [[气凝胶]]载体上的成功生长及其高结晶度。

[[XRD|X射线衍射]]（[[X射线衍射|XRD]]）图谱（图3d）表明，[[N-CNF@LDH]]和[[CNF@LDH]]均表现出纯[[层状双金属氢氧化物|NiFe-LDH]]在$2 \theta = 1 1 . 2 ^ { \circ }$（003晶面）、22.4<sup>◦</sup>（006晶面）、34.7<sup>◦</sup>（012晶面）和39.4<sup>◦</sup>（015晶面）处的特征衍射峰，同时仍保留23.3<sup>◦</sup>处[[纤维素]]（200）晶面的衍射峰。这些特征证实了复合[[气凝胶]]中层状NiFe-LDH和结晶纤维素的结构完整性[11]。有所不同的是，[[纤维素纳米纤维|CNF]]@LDH在23.2<sup>◦</sup>处表现出对应纤维素（002）晶面的强衍射峰，而不是[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]中观察到的对应原始NiFe-LDH（006）晶面的衍射峰。这可能归因于氮改性导致LDH纳米片在CNF和[[N-CNF]]表面上生长模式不同，与[[SEM]]表征观察到的结果一致。进一步分析表明，与纯NiFe-LDH相比，N-CNF@LDH的（006）衍射峰向高角度偏移了0.3<sup>◦</sup>。根据[[布拉格定律]]，这一偏移对应层间距从0.404 nm减小至0.398 nm。这种结构变化主要归因于N-CNF表面氨基与NiFe-LDH层中羟基之间的强[[氢键]]作用[36]，从而增强了材料内部的界面结合强度。

采用傅里叶变换红外（[[FTIR]]）光谱分析N改性对[[纤维素纳米纤维|CNF]]的表面改性效果以及[[层状双金属氢氧化物|NiFe-LDH]]与[[N-CNF]]之间的界面相互作用。如图3e所示，N改性的N-CNF在1520 cm<sup>−1</sup>处出现新的N-H弯曲振动峰，同时-OH伸缩振动峰从原始CNF的3579 cm<sup>−1</sup>偏移至3482 cm<sup>−1</sup>。这些光谱变化为[[支化聚乙烯亚胺|PEI]]分子成功接枝到CNF表面提供了明确证据[37]。同时，[[N-CNF@LDH]]和[[CNF@LDH]]均在2238 cm<sup>−1</sup>处表现出特征-C≡N伸缩振动峰，并在1387 cm<sup>−1</sup>处表现出层间碳酸根$\left( \mathrm { C O } _ { 3 } { } ^ { 2 - } \right)$的明显不对称振动峰[38]，这些与纯NiFe-LDH的光谱特征一致。特别是，与纯N-CNF在3482 cm<sup>−1</sup>处的峰相比，[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]中的O-H/N-H振动峰红移至3448 cm<sup>−1</sup>。这一现象可归因于[[聚乙烯亚胺|PEI]]分子链上的氨基、CNF表面的羟基以及NiFe-LDH层中的羟基之间发生的强[[氢键]]相互作用[39, 40]。

为定量[[纤维素]]基体中[[层状双金属氢氧化物|NiFe-LDH]]的负载量，我们采用[[热重分析]]（TGA）对复合[[气凝胶]]进行了系统表征[41]。TGA结果（图3f；表S3）表明，[[N-CNF@LDH]]中NiFe-LDH的负载量达到49.7 wt.%，与[[CNF@LDH]]（35.8 wt.%）相比显著提高了38.8%。这一提升直接证实了N改性有效改善了纤维素载体对NiFe-LDH纳米花簇的锚定能力，这主要可归因于[[支化聚乙烯亚胺|PEI]]引入的含氮官能团与NiFe-LDH组分之间的强相互作用[42]。

利用[[XPS|X射线光电子能谱]]（[[X射线光电子能谱|XPS]]）系统研究了纯[[层状双金属氢氧化物|NiFe-LDH]]、N修饰前后的[[纤维素]]样品（[[纤维素纳米纤维|CNF]]和[[N-CNF]]）及其相应NiFe-LDH复合[[气凝胶]]的元素组成和化学键合状态。全谱扫描结果（图S7）和元素分布数据（图3g；表S4）表明，原始CNF仅表现出C 1s和O 1s的特征峰，而[[支化聚乙烯亚胺|PEI]]修饰的N-CNF中出现了明显的N 1s峰，氮含量达到14.5 at.%。这一结果证实了[[聚乙烯亚胺|PEI]]成功接枝到CNF表面[37]，与[[傅里叶变换红外光谱|FTIR光谱]]中观察到的特征氨基吸收峰一致（图3e）。此外，[[N-CNF@LDH]]复合气凝胶中的Ni/Fe原子比（2:1）与纯NiFe-LDH高度一致，而总金属含量（27.2 at.%）介于纯NiFe-LDH（33.3 at.%）和未修饰[[CNF@LDH]]样品（18.9 at.%）之间。这些发现表明，PEI修饰不仅实现了CNF的N功能化，还显著增强了NiFe-LDH在纤维素基底上的负载能力，从而为改善[[吸附]]性能奠定了材料基础。

进一步利用[[X射线光电子能谱|高分辨XPS光谱]]分析了N 1s光谱（图3h）和M 2p光谱（Ni和Fe，图3i,j）。[[N-CNF]]的N 1s光谱在399.3 eV处呈现单一特征峰，归属于N─H键[43]。[[层状双金属氢氧化物|NiFe-LDH]]生长后，[[N-CNF@LDH]]的N 1s光谱中在401.7 eV处出现一个新峰，对应于N-金属（N-M）配位[44]。相应地，在[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]的Ni 2p光谱853.1 eV处和Fe 2p光谱710.3 eV处也观察到M-N配位的特征峰[45]。这些结果表明，Ni/Fe金属离子与[[支化聚乙烯亚胺|PEI]]的氨基之间形成了稳定的N-M配位结构。与纯NiFe-LDH和[[CNF@LDH]]相比，[[纤维素纳米纤维|N-CNF]]@LDH中N 1s轨道表现出0.4 eV的正位移（从399.1到399.5 eV），而Ni 2p和Fe 2p轨道表现出0.4 eV的负位移。该结合能位移的幅度$( \Delta E = 0 . 4 ~ \mathrm { e V } )$大于未修饰CNF@LDH体系中观察到的幅度$( \Delta E = 0 . 2 { \mathrm { ~ e V } } ) _ { \mathrm { { ; } } }$表明氮修饰有效增强了界面电子相互作用，并促进了从NiFe-LDH到N-CNF基质的更高效电子转移。这种电子重排导致金属位点电子密度降低，并在N-CNF@LDH复合[[气凝胶]]表面形成缺电子中心，从而为增强材料与[[纳米塑料|NPs]]表面含氧官能团之间的结合能力创造了有利条件[44, 46]。

## 2.3 [[纳米塑料|NPs]][[吸附]]-[[脱附]]性能评价

本研究采用表面带负电且均匀分散的300 nm[[聚苯乙烯]]（PS）颗粒作为模型[[纳米塑料|NPs]]（图S8）[47, 48]。在$2 5 ~ ^ { \circ } \mathrm { C }$下系统研究了[[层状双金属氢氧化物|LDH]]、[[纤维素纳米纤维|CNF]]、[[N-CNF]]及其复合[[气凝胶]]对NPs的[[吸附]]性能（图4a）。[[吸附等温线]]分析结合模型拟合（图S9；表S5）表明，NPs在各材料上的吸附行为与[[Sips模型]]高度一致$( R ^ { 2 } = 0 . 9 9 )$，表明其吸附机制可能涉及非线性多层吸附行为[49]。

如图 4a 所示，纯 [[纤维素纳米纤维|CNF]] 对 [[纳米塑料|NPs]] 表现出一定的[[吸附]]能力，[[最大吸附容量]] $( Q _ { \mathrm { e , m a x } } )$ 为 346 $\mathbf { m } \mathbf { g } { \cdot } \mathbf { g } ^ { - 1 }$。经 N 修饰后，[[N-CNF]] 对 NPs 的吸附容量提高了 4.2 倍，达到 1456 mg⋅g<sup>−1</sup>。当与 [[层状双金属氢氧化物|LDH]] 复合时，所制备的 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]对 NPs 的吸附容量显著增加，达到 3648 mg⋅g<sup>−1</sup>。有趣的是，[[N-CNF@LDH]] 复合[[气凝胶]]中 LDH 的质量比例约为 49.7 wt.%（由 [[热重分析|TGA]] 测定，图 2f），但该复合气凝胶对 NPs 的吸附容量却比纯 LDH 纳米片（3329 mg⋅g<sup>−1</sup>）高 10%。这一现象表明，NPs 在 N-[[CNF@LDH]] 复合气凝胶上的吸附行为不仅取决于 LDH 的本征吸附特性，还与 N-CNF 和 LDH 共同构建的半柔性微纳结构密切相关（[[SEM]]，图 $2 \mathsf { b } _ { 3 } )$ [50]）。具体而言，由 N-CNF 的三维柔性蜂窝网络和 LDH 纳米花簇组成的分级孔系统同时提供了传质通道功能和结构响应特性。该系统不仅促进 NPs 的快速传输，还能在吸附过程中通过诱导花瓣状结构的可逆开合，显著提高材料对 NPs 的吸附容量 [51]。同时，这种半柔性微纳结构所产生的[[空间限域效应]]进一步加强了材料与 NPs 之间的界面相互作用，从而提高了对 NPs 的整体吸附容量。传质优化与限域增强双重机制的协同作用，使 N-CNF@LDH 复合气凝胶表现出远超单一组分的吸附性能。

[[吸附动力学]]研究进一步验证了这种半柔性微纳结构的优势。在 [[纳米塑料|NPs]] [[吸附]]的最初 150 min 内，[[N-CNF@LDH]] 表现出最快的吸附动力学行为（图 S10）。动力学分析结果（图 4b；图 S10、S11 和表 S6）表明，[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的[[准一级吸附速率常数]]（k = 0.018 min<sup>−1</sup>）是纯 [[纤维素纳米纤维|CNF]] [[气凝胶]]的 4.5 倍 $( k _ { 1 } = 0 . 0 0 4 \ \mathrm { m i n ^ { - 1 } } )$，是纯 [[层状双金属氢氧化物|LDH]] 纳米片的 1.5 倍 $( k _ { 1 } = 0 . 0 1 2 \ \mathrm { m i n ^ { - 1 } } )$。值得注意的是，与不含 N 修饰的 [[CNF@LDH]] 相比，[[N-CNF]]@LDH 的吸附速率提高了 3.6 倍 $( k _ { 1 } = 0 . 0 0 5 \ \mathrm { m i n ^ { - 1 } } )$，证实 N 修饰通过协同提高材料表面正电性和增加活性位点密度，有效增强了 NPs 吸附性能 [52]。

为综合评价 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的实际应用性能，我们系统研究了其在不同环境条件下对 [[纳米塑料|NPs]] 的[[吸附]]行为。pH 依赖性实验结果（图 4c）显示，在强酸性至中性范围内（pH = 1–7），[[N-CNF@LDH]] 对 NPs 的吸附容量始终保持在[[最大吸附容量]]的 95% 以上。结合 [[Zeta电位|Zeta 电位分析]]（图 S12），进一步分析表明，材料表面丰富的羟基经质子化后形成高正电荷密度（+62.5–59.2 mV），使其能够在较宽的 pH 范围内（1–7）高效吸附带负电的 NPs [53]。在碱性条件下（pH > 7），羟基的去质子化导致材料表面正电荷密度下降（+39.9–23.2 mV），但 [[N-CNF]]@[[层状双金属氢氧化物|LDH]] 仍保持超过 2672 mg⋅g<sup>−1</sup> 的吸附容量，显示出其在实际应用中优异的 pH 耐受性。

我们进一步考察了水体富营养化程度（以[[腐殖酸]]（humic acid, HA）浓度作为指标）对 [[N-CNF@LDH]] [[吸附]][[纳米塑料|纳米塑料（NPs）]]性能的影响[54]。图4d显示，在1–25 mg⋅L<sup>−1</sup>的宽HA浓度范围内，[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]对NPs的去除率保持在参比条件下78%以上，最高可达98%，表明该材料具有优异的抗富营养化干扰能力。此外，在$\mathrm { C l } ^ { - } , \mathrm { C O } _ { 3 } 2 ^ { - }$和$\mathrm { S O _ { 4 } } ^ { 2 - } \ \mathrm { ( F i g u r e \ 4 e ) } .$等常见阴离子共存条件下，NPs的去除率仍保持在初始值的83–95%的较高水平[55]。即使在${ \mathrm { C r } } ^ { 3 + } , { \mathrm { C u } } ^ { 2 + }$$\mathrm { P b } ^ { 2 + }$等常见重金属离子共存条件下，[[N-CNF]]@[[层状双金属氢氧化物|LDH]]对NPs的吸附容量仍保持在其[[最大吸附容量]]的91%以上（图S13）[56]。这进一步说明该材料对共存无机阴离子和重金属离子具有良好的抗干扰性能。在覆盖自来水、地表水（湖水和河水）以及工业废水的多种实际水体测试中（图4f），[[纤维素纳米纤维|N-CNF]]@LDH对NPs的吸附容量稳定保持在其最大吸附容量的89%以上，充分证明了该材料在实际应用中的可靠性。为模拟真实运行工况，我们进一步设计了动态吸附实验，将N-[[CNF@LDH]]固定在流动柱反应器中，使含NPs的模拟废水连续通过。实验结果（图S14）表明，运行1 h后出水浊度显著下降。此外，在12次吸附-[[脱附]]循环实验中，N-CNF@LDH对NPs表现出优异的吸附与[[解吸|脱附]]性能，吸附容量始终保持在初始最优吸附容量的91%以上。[[SEM]]图像显示，经过12次吸附-脱附循环后，材料仍保持良好的[[介孔结构|有序介孔结构]]，未见明显堵塞迹象（图S15）。这些结果不仅验证了该材料在流动体系中连续捕获NPs的能力，也证实了其长期稳定性，为其在实际水处理工程中的应用提供了有力支持[57]。此外，吸附测试（图S16）证实，N-CNF@LDH[[气凝胶]]不仅对[[聚苯乙烯|PS NPs]]（100–1000 nm）具有优异的吸附容量（>1500 mg⋅g<sup>−1</sup>），对[[聚丙烯]]（PP）、[[聚乙烯]]（PE）、[[聚对苯二甲酸乙二醇酯]]（PET）和[[聚甲基丙烯酸甲酯]]（PMMA）NPs（约300 nm）也同样表现出优异吸附能力，突出了其在NPs修复中的广泛适用性。经过10次吸附-脱附循环后，其对PMMA的吸附效率仍保持在原始效率的93%以上，证实了其优异的可重复使用性，并支持了所提出水修复策略的普适有效性。

为探究 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的可重复使用潜力，我们采用[[机械压缩|机械压缩方法]]研究了该复合[[气凝胶]]对 [[纳米塑料|NPs]] 的[[解吸]]行为与速率。实验中，将[[吸附]] NPs 至饱和的复合气凝胶材料完全浸入溶液中，再通过周期性机械压缩-回弹作用促进 NPs 解吸（第 S1.7 节）。系统测试表明，增大压缩应力可显著提高解吸效率，并确定 5 N 为在保持材料完整性的同时实现最大解吸速率的最优压力。实验结果（图 4g；图 S17 和 S18）表明，在该 5 N 最优压力和 15 mm/min 恒定压缩速率下，该机械压缩解吸方法在仅 10 s 内即可实现 96.2% 的 NPs 解吸率。动力学拟合分析显示，材料的解吸速率常数（k）达到 $3 . 2 6 \times 1 0 ^ { - 4 } { \cdot } \mathrm { s ^ { - 1 } }$ 。与传统溶剂浸泡法相比，机械压缩方法将解吸速率提高了 575 倍，提升幅度接近三个数量级（图 4g，插图）。

利用 [[SEM]] 表征（图 4h-j）和结构示意图（图 4k），我们进一步分析了 [[纳米塑料|NPs]] 的[[吸附]]-[[解吸]]过程。当 NPs 进入 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]体系时，它们首先被快速吸附在复合[[气凝胶]]团簇状结构的表面，随后逐渐迁移至结构内部的狭缝孔中。随着 NPs 在复合气凝胶中持续累积，[[N-CNF@LDH]] 的半柔性微纳结构发生膨胀，从而有效扩大了 NPs 的捕获空间。在外部[[机械压缩]]作用下，NPs 被迅速释放并解吸，同时 [[N-CNF]]@[[层状双金属氢氧化物|LDH]] 的微观结构完全恢复至初始状态。整个吸附-解吸过程表现出高度可逆的结构行为和吸附性能。

## 2.4 [[N-CNF@LDH]] [[气凝胶]]的循环再生性能及 [[纳米塑料|NPs]] 去除机制

为评估 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]的循环再生性能，我们对该复合[[气凝胶]]进行了 100 次连续的 [[纳米塑料|NPs]] [[吸附]]-[[脱附]]循环测试。测试结果（图 5a、b；图 S19）表明，经过 50 次循环后，[[N-CNF@LDH]] 仍保留其初始吸附容量的 93.3%，同时表现出 84.6% 的压缩应力保持率和 95.7% 的形变恢复率。当循环次数增加到 100 次时，[[N-CNF]]@[[层状双金属氢氧化物|LDH]] 的吸附容量仍保持在较高水平，为其初始值的 80.4%，应力保持率和回弹率分别为 82.3% 和 95.2%。通过水下压缩应变应力循环测试（图 S20）评估了该材料在实际水体环境中的应用性能。在 80% 应变下经过 100 次压缩释放循环后，[[纤维素纳米纤维|N-CNF]]@LDH 气凝胶表现出可忽略的塑性形变和 92% 的平均水下回弹率，这为该材料在实际压缩[[解吸|脱附]]应用中的长期循环稳定性提供了关键的力学保障。这些结果，结合其在宽 pH 范围内优异的化学稳定性以及在长期水浸泡过程中优异的结构耐久性（图 S21–S23），充分证明 N-[[CNF@LDH]] 复合气凝胶具有全面的循环稳定性和结构可恢复性。这种涵盖[[机械压缩]]、耐化学腐蚀以及长期水暴露稳定性的多维稳定性特征，为其在实际水处理场景中的可靠长期应用奠定了坚实基础。

为阐明[[N-CNF@LDH]]在长期循环过程中结构稳定性的演变规律，我们采用多种表征手段，包括[[SEM]]（图S24）、[[XPS]]（图S25）和[[XRD]]（图5c），系统研究了该复合[[气凝胶]]在100次循环中的结构稳定性演变。[[扫描电子显微镜|SEM]]分析结果表明，从材料初始状态到100次循环后，[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]的微纳多孔结构形貌基本保持不变，[[层状双金属氢氧化物|LDH]]纳米花簇在[[N-CNF]]基底上的均匀分布未受循环次数影响。此外，再生后的[[纤维素纳米纤维|N-CNF]]@LDH仍保持完整的3D多孔网络结构，未出现明显团聚或结构坍塌。同时，[[能量色散X射线光谱|EDS元素分布图]]显示，Fe、Ni、C和O等元素在整个材料中仍均匀分布，其相应原子百分比（表S8）无显著变化，也未出现碳含量局部异常升高（表明无[[纳米塑料|NPs]]积累）。[[X射线光电子能谱|XPS]]分析（图S25和表S9）进一步支持上述结果，Fe 2p和Ni 2p谱图的峰位和强度均未发生显著偏移或变化，且其原子百分比保持稳定。[[X射线衍射|XRD]]测试结果进一步从晶体层面证实了该结构的稳定性，不同循环次数下LDH相特征衍射峰的位置和相对强度基本一致，表明LDH晶体结构在整个过程中保持完整。同时，XRD图谱中位于16.5°处对应[[纤维素]]（110）晶面的衍射峰宽度随循环次数增加略有宽化，这一变化主要归因于循环过程中纤维素分子链的局部结构重排和晶格畸变效应[58]。尽管如此，N-[[CNF@LDH]]的整体结构仍保持优异的稳定性。与先前报道的NPs[[吸附]]材料[10, 13, 14, 21–26]相比，N-CNF@LDH复合气凝胶不仅表现出3648 mg⋅g<sup>−1</sup>的超高吸附容量，而且制备成本经济，低于\$0.25⋅g<sup>−1</sup>（表S10和S11）。更重要的是，N-CNF@LDH独特的半柔性微纳结构能够有效发挥作用，确保材料在100次循环使用后仍保持稳定的吸附性能（图5d）。

为了更深入地理解[[N-CNF@LDH]]复合[[气凝胶]]对[[纳米塑料|NPs]]的[[吸附]]机制，我们采用多尺度表征技术进行了系统研究。[[Zeta电位]]分析（图5e）表明，纯[[纤维素纳米纤维|CNF]]表面带负电荷（-21 mV），因而与同样带负电荷的NPs之间存在静电排斥作用。经N修饰后，[[N-CNF]]的[[ζ电位|Zeta电位]]转变为+25 mV。这种表面电荷变化有效克服了最初的静电排斥，同时新引入的含N官能团为后续与带正电荷的[[层状双金属氢氧化物|LDH]]结合提供了丰富的活性位点。N-CNF与LDH通过[[氢键]]和N─M配位键结合后，两组分之间的界面电子转移使复合气凝胶的Zeta电位提高至+59 mV，增强了复合气凝胶对NPs的[[静电吸引|静电吸附能力]][59]。

相比之下，未改性的[[CNF@LDH]]复合[[气凝胶]]由于内部[[纤维素纳米纤维|CNF]]与[[层状双金属氢氧化物|LDH]]之间的界面相互作用较弱，其[[Zeta电位]]仅为+39 mV。因此，该复合气凝胶对[[纳米塑料|NPs]]的[[吸附]]性能远低于[[N-CNF@LDH]]体系。[[傅里叶变换红外光谱|FTIR光谱]]分析在分子水平上揭示了NPs与[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]之间的相互作用机制（图5f；图S26）。如图所示，吸附NPs后，[[N-CNF]]@LDH的O-H伸缩振动峰从3500 cm<sup>-1</sup>红移$9 2 ~ \mathrm { c m ^ { - 1 } }$至$3 4 0 8 ~ \mathrm { c m ^ { - 1 } }$ cm<sup>-1</sup>。这一变化表明N-CNF@LDH上的羟基与NPs的含氧官能团之间形成了强[[氢键]]相互作用[60]。此外，在520–800 cm<sup>−1</sup>范围内观察到M─O/M─N键振动强度明显降低，这可归因于N-CNF@LDH上的金属活性位点与NPs含氧官能团之间的[[配位作用]][61, 62]。

[[XPS]]分析进一步从电子结构角度验证了上述机理。在高分辨Fe 2p谱图（图5g）和Ni 2p谱图（图S27）中，M-N和M-O特征峰的结合能向低值方向偏移了0.7 eV。同时，在N 1s谱图（图5h）中，M-N配位峰的相对含量从27.4%增加到31.3%，并伴随0.3 eV的结合能偏移。这些谱图变化共同证实了[[纳米塑料|NPs]]与[[N-CNF@LDH]]表面金属[[吸附]]位点之间形成了稳定的[[配位络合|配位相互作用]][63]。进一步分析发现，N 1s谱图（图5h）中的N-H特征峰从399.5 eV偏移至399.8 eV，这一变化可能源于NPs中苯环的π电子体系通过共轭效应吸引N原子的电子云，从而降低了N原子的电子密度[64]。类似地，O 1s [[X射线光电子能谱|XPS]]谱图（图5i）的分析表明，NPs吸附后[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]表面C═O键的相对含量从20.2%显著增加到57.9%，同时结合能正向偏移0.7 eV。这一显著的电子结构变化不仅证实了NPs的含氧官能团与材料表面之间形成了稳定的化学连接，还表明NPs中芳香环π体系对C═O键中的O原子具有强吸电子效应[65]。此外，[[FTIR]]（图5f）和XPS（图5g-i；图S27）表征结果显示，经过[[机械压缩]][[脱附]]处理后，[[解吸|脱附]]再生后的[[N-CNF]]@[[层状双金属氢氧化物|LDH]]内部的[[氢键|氢键网络]]和金属配位键能够完全恢复至初始结构状态，这一特性有效保证了材料循环使用过程中吸附位点的[[可再生性]]。上述系列表征结果共同证实了[[纤维素纳米纤维|N-CNF]]@LDH复合[[气凝胶]]在长期循环使用中具有可靠的结构耐久性。

基于以上综合分析，[[N-CNF@LDH]]复合[[气凝胶]]对[[纳米塑料|NPs]]的[[吸附]]-[[脱附]]行为归因于多种物理化学相互作用的协同效应（图5j）。在吸附阶段，[[层状双金属氢氧化物|LDH]]表面暴露的$\mathrm { N i ^ { 2 + } / F e ^ { 3 + } }$金属活性位点与NPs之间发生[[配位络合]]作用，为吸附过程提供了主要结合位点。同时，分布在[[N-CNF]]骨架和LDH纳米花簇表面的丰富氨基（-NH ）和羟基（-OH）官能团通过构建多重[[氢键|氢键网络]]增强了对NPs的结合力。此外，由[[纤维素纳米纤维|N-CNF]]和LDH形成的复合材料增强的正电特性使其能够通过[[静电吸引]]更高效地捕获带负电的NPs。配位络合、氢键和静电吸引的多重协同作用促进了大量NPs吸附到[[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH]]表面，同时诱导N-[[CNF@LDH]]半柔性微纳结构的扩张和打开。这一结构变化过程不断暴露新的吸附位点并扩大材料内部孔容，从而显著提高材料对NPs的吸附容量。在压缩诱导[[解吸|脱附]]与再生阶段，N-CNF@LDH材料发生可控变形，促使其表面吸附的NPs快速释放。同时，N-CNF@LDH内部预先构建的可逆氢键网络能够在NPs脱附后迅速启动结构[[自修复|自修复机制]]，使材料恢复至初始状态。这一特性为N-CNF@LDH复合气凝胶的长期循环稳定性提供了坚实可靠的结构支撑。

## 3 结论

综上所述，我们通过动态[[氢键]]与离子配位成功构建了一种半柔性微纳结构 [[氮改性纤维素纳米纤维@层状双金属氢氧化物复合气凝胶|N-CNF@LDH 复合气凝胶]]。这种双重相互作用使 [[层状双金属氢氧化物|LDH]] 纳米花在[[纤维素]]基体中实现均匀分散，并建立起具有分级结构且协同增强的半柔性多级结构网络。在[[吸附]]过程中，[[N-CNF@LDH]] 通过 LDH 表面金属活性位点 $( \mathrm { N i ^ { 2 + } } / \mathrm { F e ^ { 3 + } } )$ 与 [[N-CNF]] 骨架官能团 $\mathrm { ( - N H } _ { 2 } / \mathrm { - }$ OH）之间的配位与氢键协同作用，以及增强的表面正电荷效应，显著提升了对 [[纳米塑料|NPs]] 的捕获能力。[[纤维素纳米纤维|N-CNF]]@LDH 的半柔性微纳结构通过可逆的花瓣间通道开合不断暴露新的吸附位点，从而在吸附过程中产生独特的溶胀效应，使吸附容量逐步提升至 3648 mg⋅g<sup>−1</sup> 的突出水平。而在[[脱附]]方面，N-[[CNF@LDH]] 在[[机械压缩]]下表现出 NPs 的快速释放，10 s 内[[解吸|脱附]]率达到 96%，其脱附动力学速率比传统吸附剂快近三个数量级。N-CNF@LDH 中的动态氢键网络展现出优异的[[自修复|自修复性能]]，能够在 NPs 脱附后快速实现结构重建，并恢复至初始微观结构状态。这种基于动态氢键相互作用的[[形状记忆|智能形状记忆特性]]赋予 N-CNF@LDH 出色的循环稳定性，表现为在连续 100 次吸附-脱附循环后仍保持初始吸附容量的 80.4%，形状恢复率达 95.2%。在实际应用测试中，这种成本效益高的材料在宽 pH 范围（1-11）、高离子强度条件以及多种复杂水体环境中均保持稳定的 NPs 去除率（> 89%），充分证实了其在环境修复应用中的巨大潜力。

## 4.2 表征与测试

使用 [[场发射扫描电子显微镜|Hitachi S-3400 场发射扫描电子显微镜]]对微观结构形貌进行表征。77 K 下的[[BET|比表面积]]和[[孔径分布]]参数通过 [[Advanced Gas Adsorption and Micropore Analyzer]]（[[BSD Instrument]]，BSD-660MG）测定。晶体结构分析采用 [[Rigaku Ultima IV]] [[X 射线衍射|X 射线衍射仪]]，[[Cu Kα 辐射]] $( \lambda = 0 . 1 5 4 0 6 ~ \mathrm { n m } )$ ，工作电压为 40 kV，扫描范围为 $5 ^ { \circ }$ 至 $7 0 ^ { \circ }$（2θ）。化学结构表征使用 [[Thermo Fisher Nicolet IS50]] [[傅里叶变换红外光谱|傅里叶变换红外光谱仪]]，分辨率为 $4 ~ \mathrm { c m ^ { - 1 } }$ ，扫描次数为 32 次。表面元素组成和化学态采用 [[Thermo Fisher Nexsa G2]] [[X 射线光电子能谱|X 射线光电子能谱仪]]分析，结合能以 284.8 eV 处的 [[C 1s 峰]]进行校正。溶液浓度定量使用 [[Agilent Cary 100]] [[紫外-可见分光光度计]]完成，检测波长由标准曲线法确定。胶体体系的表面电位通过 使用 [[Brookhaven NanoBrook Omni]] [[Zeta 电位|Zeta 电位分析仪]]测量，[[聚苯乙烯悬浮液]]和[[木质纤维素分散体]]均保持在 $2 5 \pm 0 . 5 ^ { \circ } \mathrm { C }$ 温度下。浸出的 $\mathrm { N i } ^ { 2 + }$ 和 Fe<sup>2+</sup> 的浓度采用[[电感耦合等离子体发射光谱法]]测定，仪器为 [[ICP-OES|ICP-5000 型同时式 ICP-OES]]，样品在 [[氢氟酸|HF]] 介质中消解后进行测试。热稳定性测试在 [[Mettler Toledo TGA 5500]] [[热重分析|热重分析仪]]上进行，样品质量为 5.0 mg，氮气气氛下以 $1 0 ^ { \circ } \mathrm { C } { \cdot } \mathrm { m i n } ^ { - 1 }$ 的速率从 25 ℃ 升温至 800<sup>◦</sup>C。[[水凝胶]]的力学性能使用 [[Shimadzu AGS-X]] 2 kN [[万能试验机]]评价，其中圆柱形试样（Φ20 × 20 mm）以 15 $\mathrm { m m } { \cdot } \mathbf { s } ^ { - 1 }$ <sub>⋅</sub> <sup>−</sup>1 的速率进行[[单轴压缩试验]]。[[气凝胶]]的表观体积密度和[[孔隙率]]根据以下公式计算。[[表观密度]] $( \rho _ { \mathrm { a } } , \mathbf { g } { \cdot } \mathrm { c m } ^ { - 3 } )$ 根据质量与体积之比确定。气凝胶的孔隙率（P） 使用以下方程计算：[66]

$$
P = (1 - \rho_ {a} / \rho_ {s}) \times 100
$$

其中，$\rho _ { \mathrm { a } }$ 和 $\rho _ { \mathrm { s } }$ 分别表示[[气凝胶]]的[[表观密度]]和[[羧甲基纤维素纳米纤维]]骨架的[[骨架密度]] $( \rho _ { \mathrm { s } } = 1 . 6 0 \mathrm { g } { \cdot } \mathrm { c m } ^ { - 3 } )$。所有实验数据均使用 [[Origin|Origin 2024]] 软件进行统计处理。
