# 一种被忽视的树脂组合物可有效捕获并释放各种[[全氟和多氟烷基物质|PFAS]]，包括具有挑战性的短链结构

[[Xiping Kan]] <sup>a</sup>, [[Sizhuo Zhang]] <sup>b</sup> , [[Swagotom Sarkar]] <sup>a</sup> , [[Jinyong Liu]] <sup>b</sup> , [[Mei Sun]] a,\*

<sup>a</sup> 北卡罗来纳大学夏洛特分校土木与环境工程系，夏洛特，北卡罗来纳州，28223，美国

## 亮点

• 一种自制[[聚苯乙烯]]-[[三乙胺]]（PS-NEt<sup>+</sup>）树脂对[[全氟和多氟烷基物质|PFAS]]表现出高亲和力。

• PS-NEt<sub>3</sub><sup>+</sup>可在各种水基质中有效捕获短链及未知[[全氟和多氟烷基物质|PFAS]]。

• PS-NEt<sub>3</sub><sup>+</sup>和[[PFA694E]]在[[被动采样器]]应用中优于典型[[吸附剂]]（[[WAX]]和[[HLB]]）。

• 3/1的PS-NEt<sup>+</sup>/[[PFA694E]][[吸附剂混合物|混合物]]可增强在环境水体和污染水体中的[[全氟和多氟烷基物质|PFAS]]捕获。

• 使用[[甲醇]]和[[乙酸铵]][[洗脱]]可实现准确的[[全氟和多氟烷基物质|PFAS]]定量及[[吸附剂]]重复使用。

## 摘要

由于缺乏对广泛结构多样性（尤其是高迁移性的[[短链PFAS]]）具有高亲和力的有效[[吸附剂]]，通过[[吸附]]从水中捕获[[全氟和多氟烷基物质]]（PFAS）仍然至关重要且充满挑战。这一局限性也对PFAS[[被动采样器]]的性能构成了挑战。在此，我们报道了一种自制的具有[[聚苯乙烯]]和[[三乙胺]]结构的[[阴离子交换树脂]]（PS-NEt<sup>+</sup>），该树脂在捕获和释放PFAS方面极为有效。在多种基质中捕获各类传统和新兴PFAS时，PS-NEt<sup>+</sup>的表现优于商用基准产品，并且在存在无机[[竞争离子]]的情况下对短链PFAS表现出特别高的亲和力（>85%的吸附率）。在无机和有机竞争物同时存在的高污染场景中，PS-NEt<sup>+</sup>在低吸附剂用量（30 mg/L）下对广谱PFAS（包括未知结构）也表现出优异的吸附能力。PS-NEt<sup>+</sup>与一种商用树脂按75/25比例混合后，进一步提高了对[[EPA Method 1633|USEPA方法1633]]中40种PFAS分析物的捕获效果。使用含[[乙酸铵]]的[[甲醇]][[洗脱]]时，该[[吸附剂混合物|混合物]]的中位[[再生]][[回收率]]达到97%。该混合物对PFAS的高亲和力和选择性使其成为被动采样器的理想[[接收相]]，克服了以往被动采样研究中吸附容量有限和吸附剂早期穿透这一长期挑战。此外，尽管此前研究认为具有长链或不对称胺结构的树脂在PFAS捕获方面更为优越，但PS-NEt<sup>+</sup>出人意料的高性能对这一主流假设提出了挑战，并为PFAS吸附剂的选择开辟了新途径。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）已在全球范围内的饮用水、地表水和[[地下水]]中被检出（Ackerman Grunfeld et al., 2024; Sadia et al., 2023）。理解 PFAS 出现情况和多样性的需求日益增长，凸显了 PFAS 监测的重要性。被动采样提供了一种经济可行的选择，用于追踪时间加权平均浓度，这些浓度代表数周甚至超过一年的平均状况（[[Dunn]] et al., 2024; Fialova´ et al., 2024; [[Ghorbani Gorji]] et al., 2024），因此比[[即时采样|瞬时采样]]（grab sampling）更能反映长期污染情况（[[Wang]] et al., 2017）。此外，[[被动采样器]]的[[接收相]]可以富集 PFAS，从而减少运输和储存所需的样品体积。然而，由于缺乏对广泛 PFAS 结构具有选择性的有效接收相[[吸附剂]]，被动采样在 PFAS 中的应用一直受到限制。

通过[[吸附]]将 [[全氟和多氟烷基物质|PFAS]] 从水环境中隔离到[[接收相]]中，是不同[[被动采样器]]设计中的关键过程，包括[[极性有机化合物整合采样器]]（POCIS）、[[扩散梯度薄膜]]（DGT）采样器和管式采样器。[[HLB|亲水亲脂平衡（HLB）聚合物]]和[[WAX|弱阴离子交换（WAX）聚合物]]是最常用的[[吸附剂]]（Barber et al., 2023; [[Dunn]] et al., 2023; Kaserzon et al., 2012; [[Yan]] et al., 2023）（[[Fang]] et al., 2021b; [[Ghorbani Gorji]] et al., 2023）。例如，Gobelius et al.（2019）发现，在饮用水中使用 POCIS 和复合样品测定 PFAS 具有良好一致性，且对于[[短链PFAS|短链 PFAS]]，[[弱阴离子交换树脂|WAX]] 的性能优于 [[亲水亲油平衡吸附剂|HLB]]；Fang et al.（2021b）报告了使用带有 WAX 接收相的 DGT 采样器成功采集 12 种 PFAS；Mackie et al.（2024）评价了在污水出水中含有 HLB 或 WAX 吸附剂的微孔聚乙烯管式被动采样器。然而，HLB 和 WAX 设计用于捕获广谱有机化合物，因此它们对 PFAS 的低选择性可能导致灵敏度有限和过早饱和等问题。此外，现有被动采样器的验证仅集中于少数 PFAS（5–10 种传统 PFAS），吸附剂用量高达每采样器 600 mg（Dunn et al., 2023; Kaserzon et al., 2012; [[Wang]] et al., 2017）。

许多[[吸附剂]]，如[[颗粒活性炭]]（granular activated carbon，GAC）和[[阴离子交换树脂]]（anionexchange resins，AER），能有效捕获疏水性 [[全氟和多氟烷基物质|PFAS]]，但对亲水性[[短链PFAS|短链 PFAS]] 的亲和力有限（[[Fang]] et al., 2021a; Liu and Sun, 2021）。带有[[季铵基团]]的 AER 对 PFAS 表现出更优异的亲和力，可能是一种有前景的被动采样替代[[吸附]]剂，但此类应用尚未见报道。近期研究表明，[[吸附剂氨化]]可改善 PFAS 吸附（Jiang et al., 2025; [[Min]] and [[Wang]], 2023; [[Yang]] et al., 2024）。然而，在存在竞争组分时，短链 PFAS 的摄取仍面临挑战（Jiang et al., 2025），除非使用较大吸附剂剂量（如 500 mg/L）（Min and Wang, 2023; Yang et al., 2024）。此外，现有关于季铵功能化吸附剂的研究仅关注有限数量的 PFAS 结构（约 10 种，大多为传统化合物）。然而，PFAS 是一个具有多种官能团（非离子型、阴离子型和两性离子型）的庞大家族。因此，需要进一步研究确定季铵吸附剂是否既能相对于其他水体组分选择性富集 PFAS，又能适用于理化性质差异很大的多种 PFAS，尤其是在低剂量、符合实际场地条件的被动采样应用中。

从负载[[吸附剂]]中释放 [[全氟和多氟烷基物质|PFAS]]，对于测定[[被动采样器]]捕获的时间加权平均浓度至关重要。既往研究通常使用 6–10 mL 纯[[甲醇]]（有时加入氨）[[洗脱]] PFAS（[[Dunn]] et al., 2023; [[Fang]] et al., 2021b; [[Ghorbani Gorji]] et al., 2023）。然而，所得 PFAS [[回收率]]可能较低（[[磺酸基类]]为 38%−53%）（Fang et al., 2021b）或未见报道（Dunn et al., 2023; Ghorbani Gorji et al., 2023），这凸显了评估和改进 PFAS 洗脱方法的必要性。最近一项研究表明，比甲醇更疏水的溶剂可从 [[阴离子交换树脂|AER]] 中获得更高回收率（[[Graham]] et al., 2024）。

此外，通常需要相对较大的[[提取剂]]体积（例如，25–86 mL [[洗脱|提取剂]]/25 mg-[[阴离子交换树脂|AER]]）和较长接触时间（例如 24 h）来促进 [[全氟和多氟烷基物质|PFAS]] 从 AER 中释放（Ateia et al., 2019; Gao et al., 2017; [[Graham]] et al., 2024; Vakili et al., 2024）；然而，这些条件会降低被动采样应用的检测限并延长分析时间。总体而言，关于提取方案的研究仍然有限，在优化和验证[[被动采样器]]性能方面存在信息空白。

本研究旨在解决上述问题，实现被动采样中广谱 [[全氟和多氟烷基物质|PFAS]] 的高效捕获。合成了一种季铵型 [[阴离子交换树脂|AER]]，并评估其作为 PFAS 被动采样[[接收相]]的潜力。以四种[[吸附剂|商业吸附剂]]为对照，在低至 25 mg/L 的剂量下，在多种场景中评估其捕获传统和新兴 PFAS 的性能。将性能最佳的[[吸附]]剂以[[吸附剂混合物|混合物]]形式进一步用于优化提取方案，并在环境基质中进行验证。本研究提供以下认识：（1）与传统吸附剂相比，季铵 AER 在环境和污染基质中螯合多种 PFAS 的有效性；（2）提取方案对 PFAS [[回收率]]的影响；（3）所提出的摄取和释放方法对不同 PFAS 结构在被动采样实践中的可行性。

## 2. 材料与方法

## 2.1. 材料

## 2.1.1. 化学品

本研究最终测试了 [[EPA Method 1633]] 中的全部 40 种 [[全氟和多氟烷基物质|PFAS]]。早期测试则根据结构多样性以及成本/可获得性，选用其中部分 PFAS 进行加标，具体见表 1。关于 PFAS 及其他化学品的详细信息见支持信息（SI）第 SI-1 节。

## 2.1.2. [[吸附剂]]

本研究合成了一种以[[聚苯乙烯]]为骨架、带[[三乙胺]]侧链的季铵型[[阴离子交换树脂]]，记作 PS-NEt<sup>+</sup>。将 PS-NEt<sup>+</sup> 对 [[全氟和多氟烷基物质|PFAS]] 的亲和力与四种商品化[[吸附剂]]作为基准进行比较：[[颗粒活性炭]] [[Filtrasorb 400]] 和 PFAS 特异性阴[[离子交换]]树脂 [[PFA694E]]（作为 PFAS 去除中常用的[[吸附]]剂），以及此前用作[[被动采样器|被动采样器接收相]]的[[固相萃取]]（SPE）聚合物 [[HLB]] 和 [[WAX]]。有关吸附剂性质和制备的更多信息见 SI 第 SI-2 节。

## 2.1.3. 水基质

本研究用于评价上述[[吸附剂]]对 [[全氟和多氟烷基物质|PFAS]] 吸收性能的水基质包括三种相对清洁的基质（[[超纯水]]、[[环境溪水]]和[[地下水]]）和两种受污染基质（基质 1 和基质 2），后者作为最不利条件下的测试基质。基质 1 为受[[污水处理厂]]出水影响的溪水，基质 2 为受燃料卡车火灾事故及[[水成膜泡沫|水成膜泡沫（AFFF）]]施用影响的溪水。详细的采样信息和水质特征见 SI-3 和表 S2。

## 2.2. 方法

## 2.2.1. [[全氟和多氟烷基物质|PFAS]] 吸收测试

首先在多种水基质中进行吸收测试，以筛选性能最佳的[[吸附剂]]。随后，在[[超纯水]]中确定两种性能最佳[[吸附]]剂的最佳混合比例。优化后的[[吸附剂混合物|混合物]]进一步在环境基质和受污染基质中进行测试。每次测试中，将水基质与 25–60 mg/L 吸附剂在室温下以 150 rpm 的转速置于轨道摇床上混合。3–7 天后采集水样，经 0.45 µm [[聚丙烯滤膜]]过滤，并分析 [[全氟和多氟烷基物质|PFAS]] 浓度。尽管并非所有吸附剂在 3–7 天内都能与所有 PFAS 达到平衡，但该时间范围是动力学[[被动采样器]]野外部署的典型周期。所有实验均在[[高密度聚乙烯瓶]]中进行，并设置两个平行样。在不加吸附剂的对照测试中，于相同条件下与吸收测试同时进行，以校正 PFAS 在容器及其他实验器具（如滤膜）上的损失。由于此类损失难以避免，尤其是对[[长链PFAS|长链 PFAS]] 而言，因此吸附剂所吸附的 PFAS 百分比采用对照测试中吸附后的浓度而非吸附前的初始浓度来确定（式（1），其中 $\mathrm { C _ { t } }$ 和 $\mathrm { C _ { c } }$ 分别表示吸附后吸附剂测试和对照测试中的水相 PFAS 浓度）。

## 2.2.2. [[全氟和多氟烷基物质|PFAS]] [[洗脱]]优化

使用从筛选测试中确定的最佳[[吸附剂]]（PS-NEt<sub>3</sub><sup>+</sup> 与 [[PFA694E]] 的[[吸附剂混合物|混合物]]）对 [[全氟和多氟烷基物质|PFAS]] [[洗脱]]进行了优化。负载 PFAS 的[[吸附]]剂通过将 5 g/L 吸附剂悬浮于含有 $1 0 \mu \mathrm { g } / \mathrm { L }$ PFAS 的加标[[超纯水]]中 24 h 制备。随后使用不同溶剂（[[1-丁醇]]和[[甲醇]]）、添加剂[[[氢氧化铵]] $\mathrm { ( N H } _ { 4 } \mathrm { O H ) }$ 和[[乙酸铵]] $\mathrm { ( N H } _ { 4 } \mathrm { A c ) ] }$ ]、溶剂含量（70%−100% 体积比）和萃取剂体积（每 25 mg 吸附剂 2–10 mL）对负载后的吸附剂进行反萃取。为优化萃取剂组成，将 25 mg 负载 PFAS 的吸附剂与过量体积（12 mL）的萃取剂混合 48 h，以最大化 PFAS 释放。为确定所需的最小萃取剂体积，使用优化后的萃取剂（含 4% $\mathrm { N H } _ { 4 } \mathrm { A c } )$ 的 100% 甲醇）对负载 PFAS 的吸附剂进行重复萃取，以 2 mL 增量每次萃取 2 h，直至累计使用 10 mL 萃取剂。所有实验均在 15 mL [[聚丙烯离心管]]中平行进行两次。

## 2.2.3. 分析方法

[[全氟和多氟烷基物质|PFAS]] 浓度通过[[液相色谱-串联质谱]]（LC-MS/MS）测定。受污染水基质中的[[总PFAS|总 PFAS]] 吸收通过更新版总可氧化前体（TOP）测定法评估（Tsou et al., 2023）。详情见 SI-5。

## 3. 结果与讨论

## 3.1. [[吸附剂]]筛选

在[[被动采样器]]中，保护膜或[[扩散]]层可以减缓 [[全氟和多氟烷基物质|PFAS]] 吸收；然而，这种阻力主要由膜的性质而非[[吸附剂]]决定，因此对所有[[吸附]]剂产生相似的延迟。因此，本研究在完全混合的条件下评估 PFAS 吸收，以实现快速、低成本的吸附剂筛选，所得结果易于解释。在这些条件下表现出低吸收的吸附剂不太可能在被动采样器配置中成功，而高性能吸附剂将在后续研究中以被动采样器模式进行评估。

## 3.1.1. PS-NEt<sup>+</sup> 与[[吸附剂|商业基准吸附剂]]的 [[全氟和多氟烷基物质|PFAS]] 吸收比较

在 60 mg/L 低剂量下，研究了 PS-NEt<sup>+</sup> 在[[超纯水]]、[[环境溪水]]和[[地下水]]中的 [[全氟和多氟烷基物质|PFAS]] 吸收（图 1）。四种[[吸附剂|商业吸附剂]]（[[颗粒活性炭|GAC]]、[[PFA694E]]、[[WAX]] 和 [[HLB]]）用作基准。总体而言，PS-NEt<sup>+</sup>、PFA694E 和 [[弱阴离子交换树脂|WAX]] 在超纯水中对各种 PFAS 结构均有良好的捕获能力，隔离率分别为 75%−100%、69%−100% 和 84%−100%。GAC 和 [[亲水亲油平衡吸附剂|HLB]] 的吸收效率较低（分别为 48%−88% 和 4%−97%），主要原因是即使是在超纯水中，[[短链PFAS|短链 PFAS]] 也构成挑战。

在[[环境溪水]]和[[地下水]]中，与[[超纯水]]相比，所有[[吸附剂]]捕获的 [[全氟和多氟烷基物质|PFAS]] 均因[[竞争离子]]（即有机物、[[氯离子]]、[[硝酸根]]和[[硫酸根]]；表 S2）的存在而不同程度地下降。PS-NEt<sup>+</sup> 的性能在环境溪水（[[溶解性有机碳|溶解性有机碳 DOC]] 较高）中比在地下水（[[电导率]]较高）中受到的影响更大，而 [[PFA694E]] 则呈现相反趋势。尽管这两种[[吸附]]剂均为带[[氨基官能团]]的[[聚苯乙烯阴离子交换树脂]]，但其性能差异表明，不同树脂组成会导致对有机与无机竞争物的选择性不同。由于无机阴离子通过[[离子交换]]与 PFAS 吸收竞争，而 DOC 同时通过离子交换和[[疏水相互作用]]竞争，因此推断 PS-NEt<sub>3</sub><sup>+</sup> 的性能受疏水相互作用的影响大于 PFA694E，而受离子交换的影响小于 PFA694E。[[颗粒活性炭|GAC]] 在两种基质中的性能均下降，对所有测试 PFAS 的封存率均低于 60%，表明有机质和无机阴离子对其吸附 PFAS 产生了强烈竞争。

[[颗粒活性炭|GAC]] 对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]在所有基质中均未发现 [[HLB]] 性能的显著变化。然而，[[亲水亲油平衡吸附剂|HLB]] 对 $\mathrm { N _ { C F } \leq }$ 5（N = 氟化碳原子数）的 PFAS 吸收在所有基质中均不理想（0%−62%）。因此，GAC 和 HLB 被认为无法有效封存环境基质中的 PFAS。[[WAX]] 在[[环境溪水]]和[[地下水]]中对 PFAS 的吸收与[[超纯水]]中相似，仅对少数 PFAS（主要为短链结构）观察到显著下降。总体而言，[[吸附剂|含胺基吸附剂]]（PS-NEt<sub>3</sub><sup>+</sup>、[[PFA694E]] 和 [[弱阴离子交换树脂|WAX]]）在超纯水中的 PFAS 吸收中位数为 92%−97%；该中位数在地表水中降至 72%−95%，在地下水中降至 50%−94%。这些结果表明，[[氨基官能团|胺基]]可有效促进环境基质中 PFAS 的捕获。

虽然 PS-NEt<sub>3</sub><sup>+</sup>、[[PFA694E]] 和 [[WAX]] 对 [[全氟和多氟烷基物质|PFAS]] 的总体捕获效果令人满意，但三种[[吸附剂]]对环境基质中特定 PFAS 结构表现出不同的亲和力。[[短链PFAS|短链 PFAS]] $( \mathrm { N } _ { \mathrm { C F } } \leq 6 )$ 通常因疏水性较低而难以[[吸附]]；然而，PS-NEt<sub>3</sub><sup>+</sup> 在[[地下水]]中表现出最高的亲和力（85%−99%），在[[环境溪水]]中也表现出良好的亲和力（63%−93%）。PS-NEt<sup>+</sup> 表面在 [[pH]] 3 至 12 之间始终带正电；相比之下，PFA694E 和 [[弱阴离子交换树脂|WAX]] 在 pH 升高至 8 以上时转为带负电（图 S1）。在地下水（pH 8.15）和环境溪水（pH 7.89）中，PS-NEt<sup>+</sup> 具有最正的 [[ζ电位|ζ 电位]]，从而有利于其通过[[离子交换]]捕获 PFAS。这些结果表明，即使存在[[竞争离子|竞争性阴离子]]，PS-NEt<sup>+</sup> 仍能与短链 PFAS 发生强离子交换（静电）相互作用，其中对 [[PFBA]] 的捕获尤为突出（环境溪水中为 77%，地下水中为 85%），而 [[全氟丁酸|PFBA]] 是许多吸附研究中最亲水且最具挑战性的 PFAS（[[Min]] 和 [[Wang]]，2023；[[Pramanik]] 等，2024；[[Yang]] 等，2024）。

[[PFA694E]] 在[[环境溪水]]中对[[短链PFAS|短链 PFAS]] 表现出较高的捕获率（88%−100%），但在[[地下水]]中捕获率较低（46%−76%），这归因于地下水中[[竞争离子|无机阴离子]]的竞争更强，其总阴离子浓度是溪水的两倍（表 S2）。相反，[[WAX]] 在环境溪水和地下水中对短链 [[全氟和多氟烷基物质|PFAS]] 的捕获率分别仅为 18%−98% 和 17%−98%，其中对 [[PFBA]] 和 [[PFPeA]] 的捕获率在两种基质中均仅为 17%−46%。[[弱阴离子交换树脂|WAX]] 表面在 [[pH]] 约 8 时带负电（图 S1），从而削弱了[[离子交换|离子交换相互作用]]。[[HLB]] 对短链 PFAS 也表现出类似的低亲和力，这表明常用于[[被动采样器|被动采样器接收相]]的 WAX 和 [[亲水亲油平衡吸附剂|HLB]]（[[Dunn]] 等，2023；[[Yan]] 等，2023）在实际环境中捕获短链 PFAS 的效果较差。

[[长链PFAS|长链 PFAS]] $( \mathrm { N } _ { \mathrm { C F } } = 7 \mathrm { - } 8 )$ 在环境基质中对 PS-NEt<sub>3</sub><sup>+</sup>（中位数 80%）和 [[PFA694E]]（中位数 64%）的亲和力略低于[[短链PFAS|短链 PFAS]]（中位数分别为 90% 和 82%）。对于[[超长链PFAS|超长链 PFAS]] $( \ N _ { \mathrm { C F } } > 8 ) ,$，在两种环境基质中，PS-NEt<sup>+</sup> 和 PFA694E 的亲和力进一步下降。然而，这种下降仅在[[粒径]]较大的[[吸附剂]]（PS-NEt<sup>+</sup>、PFA694E 和 [[颗粒活性炭|GAC]]，直径为 150–750 µm）中观察到，而在 [[HLB]] 和 [[WAX]]（平均直径分别为 30 和 50 µm）中未出现。一种可能的解释是，高疏水性超长链 [[全氟和多氟烷基物质|PFAS]] 的摄取受到[[空间位阻|空间/能量阻碍扩散]]和[[吸附减缓]]的[[颗粒内传输]]的限制（[[Boyer]] 和 [[Singer]]，2008；[[Dixit]] 等，2019；[[Li]] 等，2003）。这些限制因[[天然有机质]]（NOM）阻碍[[孔道可达性]]而进一步加剧，在较大颗粒中比在较小颗粒中更为显著。相比之下，较小 PFAS 的摄取主要受[[离子交换]]控制，对粒径的依赖性较弱。

## 3.1.2. [[最不利情景]]下的[[吸附剂]]性能

性能最佳的[[吸附剂]]（PS-NEt<sub>3</sub><sup>+</sup>、[[PFA694E]] 和 [[WAX]]）进一步在两种污染基质中接受[[挑战测试]]：受[[废水排放]]影响的[[环境溪水|小溪水]]（基质 1）和受 [[AFFF]] 施用影响的水体（基质 2）。这些基质模拟了 [[AFFF污染源区|AFFF 污染源区]]或废水排放稀释不充分时的[[最不利情景]]。这些基质的水质特征和 [[全氟和多氟烷基物质|PFAS]] 浓度列于表 S2 和 S3。[[吸附剂投加量]]进一步降低至 30 mg/L，以避免所有[[吸附]]剂完全螯合 PFAS，从而更好地区分吸附剂性能。

PS-NEt<sup>+</sup>表现出最高的捕获效率（图 2），在基质 1 和基质 2 中的中位数分别为 92% 和 90%，其次为 [[PFA694E]]（68% 和 68%）和 [[WAX]]（70% 和 52%）。特别是，PS NEt<sub>3</sub><sup>+</sup>对所有测试 [[全氟和多氟烷基物质|PFAS]] 的螯合率均超过 65%，但 [[PFBA]]、[[PFPeA]]、[[PFTreA]] 和 4:2FTSA 除外，凸显了其卓越性能。有趣的是，尽管与[[超纯水]]相比，[[弱阴离子交换树脂|WAX]] 在环境[[环境溪水|小溪水]]和[[地下水]]中的性能受影响最小（图 1），但在[[挑战测试]]中其性能恶化最为严重。这种恶化可能归因于 WAX 的[[阴离子交换容量]]和[[粒径]]显著小于其他两种[[吸附剂]]（表 S5），导致当[[竞争物质]]以高得多的浓度存在时，其[[表面位点]]面临更严重的竞争或堵塞。这些结果表明，尽管 WAX 常被用作[[被动采样器]]中的[[接收相]]（[[Dunn]] et al., 2024; [[Yan]] et al., 2023），但它可能不适用于从污染基质中捕获 PFAS。

考虑到废水和 [[AFFF]] 中存在大量无法通过单一 [[全氟和多氟烷基物质|PFAS]] 分析捕获的 PFAS，本研究使用 [[TOP测定法|TOP 测定法]]评估了三种[[吸附剂]]对[[总PFAS|总 PFAS]] 的捕获情况。在基质 2 中，对照测试的总 PFAS 从 38.3 µg/L（90.4 nM，TOP 前）增加到 221 µg/L（528 nM，TOP 后）（图 S2），而基质 1 的变化低于 10%（表 S3）。如图 2 所示，PS-NEt<sub>3</sub><sup>+</sup> 在基质 1 和基质 2 中对总 PFAS（TOP 后）的捕获率分别为 82% 和 84%，其次为 [[PFA694E]]（分别为 77% 和 80%）。因此，可以确定 PS-NEt<sup>+</sup> 和 PFA694E 不仅能有效捕获常规定量的 PFAS，还能捕获未知 PFAS 种类，这使得[[洗脱]]后能够分析更广泛的 PFAS。

同时，[[吸附]]后两种基质中常见[[竞争离子|无机阴离子]]浓度与初始浓度相比变化极小（表 S4）。这些结果表明，主要阴离子——包括对典型 [[阴离子交换树脂|AER]] 具有极强亲和力的[[硫酸根]]（[[Min]] and [[Wang]], 2023; [[Smith]] et al., 2023）——并不是 [[全氟和多氟烷基物质|PFAS]] 在这三种[[吸附剂]][[表面位点]]上的强竞争者。所有吸附剂均部分去除了 [[溶解性有机碳|DOC]]，表明 DOC 发挥了竞争作用；然而，PS-NEt<sub>3</sub><sup>+</sup> 和 [[PFA694E]] 对 80% 的 PFAS 结构仍实现了远高于 DOC 的吸附率（分别为 65%−100% 和 31%−100% 捕获率，而 DOC 为 55%−64% 和 48%−65%），尽管大多数 PFAS 的浓度比 DOC 低 3–6 个数量级。同时，尽管 [[WAX]] 对 DOC 的去除率最低（26%−48%），但它对 PFAS 去除的阻碍却最大，如上文所述。

## 3.1.3. [[吸附剂混合物]]的优化

使用PS-NEt<sub>3</sub><sup>+</sup>与[[PFA694E]]的[[吸附剂混合物|混合物]]可能使[[被动采样器]]在不同基质中更有效地捕获多种[[全氟和多氟烷基物质|PFAS]]结构。本文比较了PS-NEt<sup>+</sup>/PFA694E混合物（[[干重比]]15:85、25:75、50:50、75:25和85:15）与100% PFA694E，以确定最佳混合比例。图3显示，在[[超纯水]]中，除[[PFOSA]]外，纯PFA694E对所有PFAS的捕获率均超过60%。随着PS-NEt<sup>+</sup>比例从15%增加到85%，PFAS[[吸附]]百分比的中位数从74%逐步提高到99%。在混合物中加入PS-NEt<sup>+</sup>促进了更多PFAS的捕获，这与PS-NEt<sup>+</sup>在环境基质中对大多数PFAS结构（尤其是[[短链PFAS]]，如[[PFBA]]和[[PFPeA]]）优于PFA694E的结论一致（图1）。当PS-NEt<sup>+</sup>超过75%时，大多数PFAS被完全捕获，且重复测试结果比使用较低PS-NEt<sup>+</sup>比例的混合物更一致（[[绝对偏差|平均绝对偏差]]<1%，而后者绝对偏差为1%−11%）。总体而言，含75% PS-NEt<sup>+</sup>的混合物表现出比含85% PS-NEt<sub>3</sub><sup>+</sup>的混合物更好的PFAS吸收（65%−100%对44%−100%）。因此，选择75% PS-NEt<sup>+</sup>和25% PFA694E的混合物作为被动采样器的[[接收相]]进行进一步测试。

## 3.1.4. [[吸收动力学]]

图4显示了75/25 PS-NEt<sup>+</sup>/PFA694E混合物及三种单一吸附剂在地下水中的PFAS吸收动力学：$\mathrm { P S - N E t } _ { 3 } ^ { + } ,$ PFA694E和WAX。外部传质控制模型比内部模型显示出更低的WRSS和更高的$\mathrm { R } ^ { 2 }$，表明膜扩散而非颗粒内扩散控制PFAS向这些吸附剂的传质。混合物的表现与PS-NEt<sup>+</sup>更为一致，而非$\mathrm { P F A 6 9 4 E } ,$，这并不意外，因为混合物由75% PS-NEt<sup>+</sup>组成。对于大多数PFAS，PS-NEt<sup>+</sup>表现出比PFA694E更快的吸收，这可能部分归因于其更小的直径。然而，对于极疏水性PFAS，PS-NEt<sup>+</sup>和PFA694E在早期阶段的吸收相似；此外，它们对疏水性PFAS的拟合外部传质系数$( \mathrm { k _ { L } } ,$（表S6）比亲水性类似物高10–100倍，这不太可能仅由膜传输引起。这表明$\mathbf { k } _ { \mathrm { L } }$可能反映了除外部传质外的界面分配或近表面可及性，其中PFA694E对大多数PFAS的界面分配弱于PS-NEt<sub>3</sub><sup>+</sup>。由于WAX直径最小，大多数PFAS在早期阶段吸收迅速；然而，其对PFBA和PFPeA的吸附极少，且PFBS和4:2 FTSA在3天后发生解吸，这都是由于疏水性更强的PFAS的强烈竞争所致。这些结果再次表明，在实际环境中使用WAX捕获短链PFAS可能存在问题。

当使用[[吸附剂混合物]]（75%/25% PS-NEt<sup>+</sup>/[[PFA694E]]）在与第3.1.2节所述相同的污染基质1中捕获[[全氟和多氟烷基物质|PFAS]]时，与使用单一[[吸附剂]]相比，PFAS吸收量有明显改善（图6a）。值得注意的是，混合物对[[PFPeA]]和4:2 [[FTSA]]的吸收量分别为52%和53%，高于纯PS-NEt<sub>3</sub><sup>+</sup>（12%和14%）或纯PFA694E（31%和46%）。混合物对[[PFBA]]的吸收量提高至32%。[[吸附]]剂混合物对PFAS吸收量的第10、第50和第90百分位数分别为52%、90%和98%，表明其相对于纯PFA694E（分别为31%、67%和85%）有显著改善，并且在这一挑战性基质中优于纯PS-NEt<sup>+</sup>（分别为13%、91%和100%）。吸附剂混合物性能增强可能归因于有机物对PS-NEt<sup>+</sup>和

[[PFA694E]][[表面位点]]的非均匀占据，从而为[[全氟和多氟烷基物质|PFAS]]（尤其是[[短链PFAS]]）留下更多可用的表面位点。随后使用优化方案（4% [[乙酸铵|NH₄Ac]][[甲醇]]溶液，分三次连续2-mL等分[[洗脱]]）对[[吸附剂混合物]]捕获的PFAS进行洗脱。PFAS的[[回收率|中位回收率]]为86%（图6b），在测试的PFAS结构中，有85%获得了良好的回收率（73%−108%）。

## 3.3.2. 在具有更广泛[[全氟和多氟烷基物质|PFAS]]结构的环境水体中

鉴于环境中已鉴定出的 [[全氟和多氟烷基物质|PFAS]] 结构多样，进一步在环境溪流水中测试了[[吸附剂混合物]]对更多 PFAS 结构（表 1）的亲和力，包括上述测试中未包含的其他 [[FASA]]、[[FASE]]、[[FTCA]] 和 [[PFEA]] 种类。该混合物再次优于 [[PFA694E]]（图 6(c) 和表 S7）。[[吸附剂]]混合物的截留中位数和平均值分别为 84% 和 78%，而 PFA694E 的截留中位数和平均值分别为 62% 和 67%。新纳入的 PFAS 也被混合物比单独使用 PFA694E 更好地捕获，表明该[[吸附]]剂混合物在捕获各种 PFAS 结构方面具有广泛适用性。与本研究中的其他测试一致，N ≤ 6 的 PFAS 被吸附剂混合物的捕获效果（21%−97%）优于 PFA694E（3.5%−74%），从而能够在被动采样过程中更好地捕获这些更具挑战性的 PFAS 结构。

[[洗脱]]方案再次成功地从[[吸附剂混合物]]中回收了各种 [[全氟和多氟烷基物质|PFAS]] 结构，[[回收率]]中位数和平均值分别为 97% 和 100%（图 6d 和表 S7）。40 种 PFAS 中有 30 种表现出可接受的回收率（59%−128%）。大多数异常值为 [[PFSA]]（[[PFOS]]、[[全氟十二烷酸|PFDS]] 和 [[全氟十二磺酸|PFDoS]]）以及多氟结构（NEt-FOSAA、[[2-(N-乙基全氟-1-辛磺酰胺基)-乙醇|NEtFOSE]]、[[2-(N-甲基全氟-1-辛磺酰胺基)-乙醇|NMeFOSE]]），回收率 < 64%。较大 N（≥ 8）的 PFAS 回收率下降归因于它们对[[吸附剂]]混合物的更强亲和力，导致洗脱效果较差。此前在[[超纯水]]中从 [[WAX]] 提取 [[全氟癸磺酸|PFDS]] 和 [[全氟癸烷磺酸|PFDoS]]（24–35%）时也报告了类似的低回收率（[[Ghorbani Gorji]] et al., 2023）。

## 3.4. [[吸附剂]]应用中的意义

尽管季铵型树脂（即强碱性[[阴离子交换树脂]]）已广泛用于水处理，但本研究中合成的一种树脂在许多场景下对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]性能优于商业基准。将自制季铵型阴[[离子交换]]树脂与商业 [[PFA694E]] 阴离子交换树脂混合后，实现了更好的 PFAS 吸附效果。本研究展示的优异 PFAS 亲和力拓展了被动采样在监测多种 PFAS 结构和未知 PFAS 前体中的应用，且[[吸附剂]]用量（25–60 mg/L）远低于以往报道。在环境水体和重度污染水体基质中，即使存在有机和无机竞争物，吸附剂性能仍保持稳定。此外，该混合吸附剂对[[短链PFAS|短链 PFAS]] 特别有效，而短链 PFAS 长期以来一直是 PFAS 吸附中的难点；同时，它也对以往被动采样研究中被忽视的许多 PFAS 类别和未知 PFAS 前体表现出良好效果。这些结果为当前 PFAS 被动采样面临的挑战（包括吸附剂早期饱和和灵敏度有限）提供了有前景的解决方案。因此，配备 PS-NEt<sup>+</sup>/PFA694E 混合吸附剂的[[被动采样器]]将实现更准确、更具成本效益的 PFAS 监测，有助于对受 PFAS 影响的环境进行更好的决策和管理。后续研究正在进行中，以进一步验证该混合吸附剂的性能，包括比较填充 PS-NEt<sup>+</sup>/PFA694E 混合吸附剂的被动采样器与传统 [[WAX]] 基采样器的表现，并评估 PFAS 在被动采样器保护层中的[[扩散]]如何影响混合吸附剂的吸附效果。

除被动采样应用外，鉴于其高亲和力和良好的[[洗脱]][[回收率]]，PS-NEt<sup>+</sup>（或 PS-NEt<sup>+</sup>/[[PFA694E]] 混合[[吸附剂]]）可作为一种有前景的替代[[吸附]]剂，用于[[固相萃取]]柱填充，以增强 [[全氟和多氟烷基物质|PFAS]] 分析方法。它还可应用于水和废水处理，以尽量减少更具挑战性的 PFAS 结构的早期穿透，从而延长树脂使用寿命并降低处理成本。然而，应合成并评估具有更大[[粒径]]的 PS-NEt<sub>3</sub><sup>+</sup>，以用于处理应用，从而缓解潜在的堵塞问题。

## 3.5. 对[[吸附剂]]合成的启示

以往研究认为，具有长链胺（例如[[三丁胺]]）的[[阴离子交换树脂]]通常优于具有短链胺（例如[[三乙胺]]）的阴[[离子交换]]树脂（[[Fang]] et al., 2021a; Jiang et al., 2025; Liu et al., 2025）。例如，尽管 [[PFA694E]] 的官能团信息未公开，但其 [[全氟和多氟烷基物质|PFAS]] 亲和力与 [[CalRes2301]] 和

[[CalRes2304]]，两种带有[[三丁胺]]基团的[[聚苯乙烯]] [[阴离子交换树脂|AER]]，以及这三种均表现出远高于 [[A520E]] 的亲和力；A520E 是一种带有[[三乙胺]]基团的聚苯乙烯 AER（[[Fang]] et al., 2021a）。此外，供应商将 [[PFA694E]] 描述为具有“复合氨基基团”，这很可能表明其氨基是不对称胺和/或碳数可变的氨基，而此前一项研究报道这些结构优于具有相似碳数对称[[氨基官能团|胺基]]团的 AER（Jiang et al., 2025）。然而，我们的结果表明，这些趋势可能并不具有普遍性。我们的对称 PS-NEt<sup>+</sup> 取得了与 PFA694E 相当、甚至更好的性能。因此，我们的发现对“长链或不对称胺固有地更优”这一流行假设提出了挑战，从而扩展了可用于开发更具 [[全氟和多氟烷基物质|PFAS]] 选择性的 AER 的官能团范围。关于胺链长度如何影响 PFAS 亲和力的更系统比较的后续研究正在进行中，以确认我们当前的观察结果，并且还需要进一步研究来阐明 [[溶解性有机碳|DOC]] 和不同价态[[竞争离子|无机阴离子]]对经短链胺官能化树脂的 PFAS 亲和力的影响。

## 4. 结论

• 季铵[[吸附剂]] PS-NEt<sub>3</sub><sup>+</sup> 在环境条件和高度污染条件下均表现出与最佳商业基准（[[PFA694E]]）相似或更好的性能，对多种 [[全氟和多氟烷基物质|PFAS]] 结构具有高亲和力，包括具有挑战性的[[短链PFAS|短链 PFAS]] 和未鉴定的 PFAS 结构。

• 在环境基质和高度污染基质中，75% PS-NEt<sup>+</sup> 与 25% [[PFA694E]] 的[[吸附剂混合物|混合物]]对多种 [[全氟和多氟烷基物质|PFAS]] 结构均表现出比纯 PFA694E 和 PS-NEt<sub>3</sub><sup>+</sup> 更好的固定效果。

• [[被动采样器]]中常见的[[接收相]] [[WAX]] 和 [[HLB]] 在各种基质中均被 PS-NEt<sup>+</sup> 和 [[PFA694E]] 超越。

• 使用含 4% NH<sub>4</sub>Ac 的 100% [[甲醇]]进行[[洗脱]]的方案，可在环境基质和高度污染基质中有效释放[[吸附剂混合物]]中的 [[全氟和多氟烷基物质|PFAS]]，从而能够准确定量所捕获的 PFAS，并实现[[吸附剂]]混合物的重复使用。
