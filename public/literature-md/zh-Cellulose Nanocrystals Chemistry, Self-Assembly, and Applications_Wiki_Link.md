## 1. 引言与研究现状

[[纤维素纤维]]或其衍生物在近150年间广泛用于日常生活中各类产品与材料。直到相对近期才被认识到的是，当[[纤维素]]纤维受到[[酸水解]]时，会产生无缺陷的棒状晶体残基。[[纤维素纳米晶体]]（[[纤维素纳米晶|CNs]]）在材料学界引起了极大的关注，且这种关注似乎并未减弱。这些[[生物高分子]]组装体之所以值得如此关注，不仅因为它们具有无与伦比的典型物理与化学性质（本综述将予以阐明），还因为其固有的[[可再生性]]和可持续性以及丰富储量。由于成本低、易得、可再生、重量轻、纳米尺度以及独特形貌，它们已作为[[纳米复合材料]]中的增强剂成为众多研究工作的对象。事实上，CNs是宏观纤维素基纤维的基本构成性高分子基元，其总体规模远超任何已知的天然或合成生物材料。纤维素和[[木质素]]等生物高分子以及在部分情况下的[[杂多糖]]提供了分层结构，用于生物工程化“生物工厂”，进而产生种类多样的植物与生物体。令人惊讶的是，直到过去几年，人们才真正关注涉及这些材料的纳米尺度现象，并由此获得了大量信息。

## 2. [[纤维素]]的结构与形态

[[纤维素]]是生物圈中产量最丰富的可再生有机材料，其年产量估计超过 $7 . 5 \times 1 0 ^ { 1 0 }$ 吨。<sup>1</sup> 纤维素广泛分布于[[高等植物]]、若干海洋动物（例如[[海鞘]]）中，在藻类、真菌、细菌、无脊椎动物乃至变形虫（原生动物）中也有少量分布，例如[[盘基网柄菌]]（Dictyostelium discoideum）。一般来说，纤维素是一种纤维状、坚韧且不溶于水的物质，在维持植物细胞壁结构方面发挥着至关重要的作用。

![](<../2.SCI_MD/Cellulose Nanocrystals Chemistry, Self-Assembly, and Applications/images/41a19c076b859518b1cef49027bc850b14d6d012edc77d36b738ff4616b79e82.jpg>)  
[[Orlando J. Rojas|Orlando Rojas]] 博士是[[北卡罗来纳州立大学]]副教授，也是[[赫尔辛基理工大学]]芬兰杰出教授。他曾任[[皇家理工学院]]（KTH）化学系物理化学高级科学家，并在[[瑞典表面化学研究所]]（YKI）工作。此前，他在[[奥本大学]]获得化学工程博士学位，并取得其他研究生学位，包括西班牙[[加泰罗尼亚理工大学]] ETSII 的造纸工程文凭，之后曾任委内瑞拉[[洛斯安第斯大学]]化学工程系教授。他在北卡罗来纳州立大学领导“胶体与界面”研究组，研究重点为表面与胶体化学以及表面活性剂和聚合物在固/液界面的[[吸附]]行为。他曾通过[[表面激光光散射]]、[[表面等离子体共振]]和[[石英晶体微天平]]方法研究吸附单分子层的黏弹性。他的工作还涉及最先进的干涉测量与双晶片表面力技术，以及[[原子力显微镜]]，以揭示纳米尺度的基本现象与相互作用。其研究组目前从事[[纳米纤维素]]结构、[[木质纤维素]][[降解]]动力学、生物传感器开发，以及天然聚合物和表面活性剂的分离、衍生化和利用等研究。他是《[[Journal of Surfactants and Detergents]]》副主编，并担任多个其他期刊的顾问委员会成员。Rojas 博士是 2009—2010 年[[American Chemical Society|美国化学会]]“[[纤维素]]与可再生材料”分会主席，并获得 2009 年[[美国化学会]]分会服务奖。他被芬兰技术与创新资助机构 [[Tekes]] 和[[芬兰科学院]]任命为 2009—2014 年芬兰杰出教授。

它于 1838 年由 [[Anselme Payen]] 首次发现并分离，<sup>2</sup> 此后，[[纤维素]]的许多物理和化学方面得到了广泛研究；事实上，关于其生物合成、组装和结构特征的发现不断涌现，并激发了众多学科中的大量研究努力。已有多篇综述发表，报道了这种迷人聚合物的知识现状。<sup>1,3-13</sup>

无论来源如何，[[纤维素]]都可以被表征为一种高分子量[[均聚物]]，由 $\beta - 1$ ,4-连接的脱水-[[D-葡萄糖]]单元组成，其中每个单元相对于其相邻单元呈螺旋状扭转 $1 8 0 ^ { \circ }$ ，重复片段通常被视为葡萄糖的二聚体，即[[纤维二糖]]（图 1）。每条纤维素链在其分子轴的两个末端具有方向性化学不对称性：一端是化学还原性官能团（即半缩醛单元），另一端带有侧基羟基，即名义上的非还原端。葡萄糖单元数或[[聚合度|聚合度（DP）]]最高可达 20 000，但也可以出现较短的纤维素链，且主要位于[[初生细胞壁]]中。

所有 -D-吡喃葡萄糖环均采用 $\mathrm { a \ ^ { 4 } C _ { 1 } }$ <sub>1</sub> [[椅式构象]]，因此，羟基位于环（赤道）平面内，而氢原子则处于垂直（轴向）位置。这种结构通过[[氢键|分子内氢键]]网络得到稳定，该网络从 O(3′)-H 羟基延伸至跨糖苷键下一个单元的 O(5) 环氧，并从 O(2)-H 羟基延伸至下一个残基的 $\mathrm { O } ( 6 ^ { \prime } )$ 羟基（图 2）。

[[羟甲基]]的三个最可能旋转位置通过确定 $\bar { ( ) 6 - C 6 }$ 键相对于 $\bar { \mathrm { O } } 5 { - } \bar { \mathrm { C } } 5 $ 和 C4-C5 键的位置来定义：如果 O6-C6 与 O5-C5 呈邻位交叉，而与 C4-C5 呈反式，则该构象称为 $^ { g t , }$ ，另外两种构象被称为 gg 和 tg（图 3）。

在自然界中，[[纤维素]]并非以孤立的单个分子形式存在，而是以单个纤维素链组装形成的纤维集合体形式存在。这是因为纤维素以单个分子形式合成，并在生物合成位点按层级顺序进行纺丝。通常，大约36个单个纤维素分子聚集形成更大的单元，称为[[基元原纤]]（protofibrils），这些原纤进一步堆积成更大的单元，称为[[微纤丝]]，并被组装成我们熟知的[[纤维素纤维]]。然而，不同来源的纤维素可能因生物合成条件的不同而呈现出不同的堆积方式。生物聚合、纺丝和[[结晶]]的联合作用发生在一个直径为30 nm的莲座状质膜复合体中（图4），并由特定的酶[[末端复合体]]（TCs）协调进行，这些复合体充当生物纺丝器。<sup>14</sup> 由于同一微纤丝中的所有纤维素链必须以相同速率由该复合体延伸，因此纤维素合成过程中的结晶与TCs驱动的链聚合密切相关。<sup>15,16</sup> TCs被认为是[[纤维素合酶复合体]]，属于[[糖基转移酶]]GT-A大家族；然而，纤维素合成与组装所涉及的反应机制仍属推测。纤维素微纤丝的结构表明，其合成与组装涉及约36个活性位点的协同活动。<sup>17</sup> 但是，不同生物中多样的纤维素结构表明该酶复合体具有模块化特征。<sup>14,18</sup> 来自纤维素活细胞成像的最新证据表明，在特定条件下，[[微管]]对纤维素沉积取向具有直接影响，但在其他条件下，微管并非纤维素定向沉积所必需（图4）。

在生物合成过程中，[[纤维素]]链聚集形成[[微纤丝]]，其横截面尺寸为2至20 nm，具体取决于纤维素来源。聚集现象主要通过[[范德华力]]以及分子内（图2）和[[氢键|分子间氢键]]发生。如果[[末端复合体|TCs]]未受干扰，它们可以无限量地生成仅有少量缺陷或[[无定形域]]的微纤丝。<sup>14,18</sup> 已提出若干微纤丝层级模型，试图描述纤维素的超分子结构，包括晶体结构、[[微晶]]尺寸与缺陷、无定形域的结构指数、原纤形成的尺寸等。这些模型的主要差异在于对微纤丝内无定形或低有序区域的组织与分布方式的描述。经过多年争论，目前普遍承认[[无定形区]]域以链位错形式分布在[[基元原纤]]的某些区段上，在这些区段中，微纤丝因纤维内部应变而发生扭曲，并进而倾斜和扭转（图5）。<sup>19</sup>

在有序区域中，[[纤维素]]链紧密堆积成[[微晶]]，这些微晶由强大且非常复杂的分子内和[[氢键|分子间氢键]]网络所稳定。纤维素中的氢键网络和分子取向可以有很大差异，从而根据其来源、提取方法或处理方式的不同，产生[[纤维素多晶型物]]或同质异晶体。<sup>1,20</sup> 已鉴定出六种可相互转化的纤维素多晶型物，即 I、II、$\mathrm { { I I I } } _ { \mathrm { I } } ,$ $\mathrm { I I I } _ { \mathrm { I I } } .$ $\mathrm { I V } _ { \mathrm { I } }$ 和 $\mathrm { I V } _ { \mathrm { I I } } ^ { \mathrm { - } }$。

天然[[纤维素]]曾被认为只有一种晶体结构，即[[纤维素 I]]，但 1984 年通过[[交叉极化魔角旋转]]（CP-MAS）技术确立了纤维素 I 存在两种亚同质异晶体的证据，分别称为 IR 和 $\begin{array} { r } { \mathrm { I } \beta , } \end{array}$。<sup>21,22</sup> 根据纤维素的来源不同，这两种[[纤维素多晶型物|多晶型物]]以不同的比例存在：IR 在来自藻类和细菌的纤维素中占主导地位，而 IR 和 I 可能同时存在于[[高等植物]]的纤维素中。然而，后一结果并非没有争议。Atalla 和 VanderHart<sup>23</sup> 报道的[[固态核磁共振|固态 NMR]] 研究表明，与来自藻类、细菌和[[海鞘]]的纤维素相比，高等植物纤维素的光谱中存在若干异常。NMR 光谱中发现的异常似乎表明，高等植物可能只含有纤维素 $\begin{array} { r } { \mathrm { I } \beta , } \end{array}$ 而非纤维素 IR，且以一种位于表面以下的畸变形式存在 $\mathrm { I } \beta$。

在 $\mathrm { I } \beta$ 和 IR 两种结构中，[[纤维素]]链均采取平行排列，但它们的[[氢键]]模式不同，这意味着晶体结构存在差异（图 6）。实际上，IR 对应于三斜 $P 1$ [[晶胞]] $( a \bar { = } 6 . 7 1 7 \ : \mathring { \mathrm { A } } , b = 5 . 9 6 2 \ : \mathring { \mathrm { A } } , c = 1 0 . 4 0 0 \ : \mathring { \mathrm { A } } , \alpha =$ $1 1 8 . 0 8 ^ { \circ } , \beta = 1 1 4 . 8 0 ^ { \circ }$ 和 $\gamma = 8 0 . 3 7 ^ { \circ } )$，每个晶胞仅含一条链，<sup>24</sup> 而 Iα 存在于[[单斜晶系|单斜]] $P 2 _ { 1 }$ 晶胞中，具有两条纤维素链 $( a = 7 . 7 8 4 \mathrm { ~ \AA ~ } , b =$ 8.201 Å，c ) 10.38 Å，${ \alpha } = \beta = 9 0 ^ { \circ }$ 和 $\gamma = 9 6 . 5 ^ { \circ } ) . ^ { 2 5 }$ IR 是一种亚稳相，可在多种介质中通过高温退火转变为热力学更稳定的 $\mathrm { I } \beta$ 相。<sup>26</sup> [[纤维素 I]]（R 和 $\beta )$）的片层以“平行向上”方式堆叠，[[羟甲基]]处于 tg 构象，使其 O6 原子指向相邻残基的 O2 羟基，从而形成第二条残基间氢键。<sup>27</sup> 如果纤维素在与氢键链片层正交的平面内发生弯曲，就会引起片层彼此之间的水平位移。<sup>28</sup> 已证明 $3 9 ^ { \circ }$ 的弯曲角足以诱导 IR 与 $\mathrm { I } \beta$ 之间的相互转化，尤其是当[[微纤丝]]中链片层的曲率被模拟为一组同心圆弧时。作为必要条件，所有由[[末端复合体]]（TCs）产生的微纤丝都必须急剧扭转，才能相对于内细胞壁表面采取平行排列。因此，在纤维素被纳入细胞壁之前，晶型很可能发生剧烈变化。这类多晶型差异最先由[[红外光谱]]<sup>29</sup> 和[[电子衍射]]<sup>30</sup> 证实，近来又通过固态 CP/MAS $^ { 1 3 } \mathrm { C }$ NMR 得到进一步确认。<sup>21</sup> 纤维素 I（R 和 $\beta )$）的晶体结构和氢键模式后来通过[[同步辐射 X 射线]]和[[中子纤维衍射]]得到更深入的研究，<sup>24,25,31</sup> 其中在[[中子衍射]]中，通过对[[氢化]]样品与[[氘化]]样品进行[[傅里叶差值分析]]，确定了参与氢键的氢原子位置。正是由于这些独特方法的可用性，才首次有可能确定纤维素晶体结构中所有原子的空间坐标。

[[纤维素 II]] 是研究第二广泛的[[纤维素多晶型物|多晶型物]]，可通过两种不同工艺获得：

(i) 通过化学再生，即将[[纤维素 I]] 溶解在溶剂中，然后在水中重新沉淀。适用于[[纤维素]]的溶剂包括：重金属-胺配合物溶液，主要是铜与氨或二胺的配合物，例如氢氧化铜的氨水溶液（称为[[铜氨试剂]] cuoxam）<sup>33</sup> 或[[铜乙二胺]]（cuen）<sup>34</sup>，氨或胺/硫氰酸盐，<sup>35</sup> 肼/硫氰酸盐，<sup>36</sup> 氯化锂/N,N-二甲基乙酰胺（LiCl/DMAc），<sup>37,38</sup> 以及 [[N-甲基吗啉-N-氧化物]]（NMMO）/水<sup>39-41</sup> 体系。

(ii) 通过[[丝光处理]]，这是一种公认的工艺，其名称来源于其发明者 [[John Mercer]]（1844 年），<sup>42</sup> 该方法包括将天然[[纤维素]]在浓[[氢氧化钠]]溶液中溶胀，并在去除溶胀剂后得到[[纤维素 II]]。其他溶胀剂，如硝酸（65%），也能将天然纤维转化为纤维素 II。<sup>43</sup> 据报道，一些非典型细菌物种可生物合成纤维素 II。<sup>44</sup>

[[纤维素 II]] 以[[单斜晶系|单斜]] $P 2 _ { 1 }$ 相存在，$( a = 8 . 1 0$ Å，b ) 9.03 Å，c ) 10.31 Å，$\alpha = \beta = 9 0 ^ { \circ }$，并且 $\gamma =$ 117.10°）。27,45,46 在转化过程中（I 到 II），羟基从 $t g$ 构象旋转到 $g t$ 构象，这明确要求[[氢键]]网络发生变化。<sup>47,48</sup> 与具有平行向上排列的[[纤维素 I]] 不同，[[纤维素]] II 中的链呈反平行排列，从而形成更稳定的结构，这使其更适合用于各种纺织品和纸张材料。纤维素 I 向纤维素 II 的转化被广泛认为是不可逆的，尽管已有关于从纤维素 II（部分）[[再生纤维素]] I 的报道。<sup>49,50</sup>

如果将[[纤维素 I]] 或 II 暴露于氨（气体或液化）或各种胺中，<sup>51</sup> 则在去除溶胀剂后形成[[纤维素 III]]。所得[[纤维素]] III 的形式取决于起始形式是 I 还是 II，从而产生纤维素 $\mathrm { I I I } _ { \mathrm { I } }$ 或 $\operatorname { I I I } .$。它们的衍射图谱除子午线强度外均相似。纤维素 III<sub>I</sub> 以[[单斜晶系|单斜]] $P 2 _ { 1 }$ 形式存在（a ) 4.450 Å，b ) 7.850 Å，$c =$ 10.31 Å，$\alpha = \beta = 9 0 ^ { \circ }$，并且 $\gamma = 1 0 5 . 1 0 ^ { \circ } )$），[[晶胞]]中含有一条链，显示出与纤维素 $\mathrm { I . } ^ { 5 2 }$ 中观察到的平行链排列。然而，[[羟甲基]]处于 $g t$ 构象，且片层间[[氢键]]网络与[[纤维素 II]] 相似。纤维素 $\mathrm { I I I } _ { \mathrm { I I } }$ 的精确结构尚未明确建立，但 [[Wada]] 等人最近报道的晶体学和光谱学研究<sup>53</sup> 表明，纤维素 $\mathrm { I I I } _ { \mathrm { I I } }$ 是纤维素的无序相。这种无序结构主要包含一种晶型，其晶胞（[[空间群]] $P 2 _ { 1 } ; a = 4 . 4 \dot { 5 }$ Å，b ) 7.64 $\mathring { \mathrm { A } } , c \doteq 1 0 . 3 6 \mathring { \mathrm { A } }$ ${ \alpha } = \beta = 9 0 ^ { \circ }$，γ ) 106.96°）由一条以反平行方式组织的链占据，此外还包含第二种结构，如 $\mathrm { C P / M A S \ ^ { 1 3 } C }$ NMR 所揭示（空间群 P2<sub>1</sub>；a ) 4.45 Å，b ) 14.64 Å，c ) 10.36 Å，R )  $\bar { = } 9 \bar { 0 ^ { \circ } } , \gamma = 9 0 . 0 5 ^ { \circ } )$）。此外，这些形式 III<sub>I</sub> 或 $\mathrm { I I I } _ { \mathrm { I I } }$ 中的任何一种，如果置于高温和潮湿环境中，都会恢复为其母体结构。

[[纤维素多晶型物|多晶型物]] $\mathrm { I V } _ { \mathrm { I } }$ 和 $\mathrm { I V } _ { \mathrm { I I } }$ 可分别通过将[[纤维素 III]]<sub>I</sub> 或 $\mathrm { I I I } ,$ 在[[甘油]]中加热至 $2 6 0 ^ { \circ } \mathrm { C }$ 来制备。<sup>54,55</sup> 与[[纤维素]] III 的情况类似，这两种形式可以回复为母体结构 I 或 II。除天然[[纤维素 I]] 外，已表明[[纤维素 IV]] 存在于若干[[初生细胞壁|植物初生细胞壁]]中。<sup>56,57</sup>

## 3. [[纤维素纳米晶体]]

20 世纪 50 年代，[[Ra¨nby]] 首次报道，通过对[[纤维素纤维]]进行受控的[[催化降解|硫酸催化降解]]，可以获得[[纤维素]]的[[胶体悬浮液]]。<sup>58-60</sup> 这项工作受到 [[Nickerson]] 和 [[Habrle]]<sup>61</sup> 研究的启发，他们观察到，将纤维素纤维在酸性溶液中煮沸所引发的[[降解]]在一定的处理时间后会达到一个极限。干燥悬浮液的[[透射电子显微镜|透射电子显微镜（TEM）]]图像首次揭示了针状颗粒聚集体的存在，而对上述棒状物的进一步[[电子衍射]]分析表明，它们具有与原始纤维相同的晶体结构。<sup>62,63</sup> 与此同时，[[Battista]]<sup>64,65</sup> 开发了由高质量木浆制备的纤维素纤维的[[盐酸]]辅助降解法，并随后进行[[超声处理]]，促成了[[微晶纤维素|微晶纤维素（MCC）]]的商业化。MCC 稳定、化学惰性且具有生理惰性，并具备有吸引力的黏合性能，为[[制药工业]]中作为片剂黏合剂、食品应用中作为质构剂和脂肪替代品，以及作为纸张和复合材料应用中的添加剂提供了重要机遇。在[[酸水解]]条件得到优化后，[[Marchessault]] 等<sup>66</sup> 证明，[[纤维素纳米晶体]]的胶体悬浮液表现出[[液晶|向列型液晶排列]]。自从发现含有[[纤维素纳米晶]]体的[[纳米复合材料]]在[[力学性能]]方面有显著改善以来，<sup>67,68</sup> 由于人们对利用[[可再生资源]]制造材料的兴趣日益增长，大量研究已转向纤维素纳米晶体复合材料。

[[纤维素纳米晶体]]常被称为[[微晶]]、[[晶须]]、纳米晶体、[[纳米颗粒]]、[[微晶粒]]或[[纳米纤维]]。此后，它们被称为“[[纤维素纳米晶]]体”（CNs）。在接下来的各节中，将综述 CNs 的分离方法及其形貌、表征、改性、[[自组装]]和应用。

## 3.1. [[纤维素纳米晶体]]的制备

从[[纤维素纤维]]中分离 [[纤维素纳米晶|CNs]] 的主要工艺基于[[酸水解]]。[[纤维素]]的无序或次晶区被优先水解，而对酸侵蚀具有更高抵抗力的[[结晶区]]则保持完整。<sup>69,70</sup> 因此，在经过使纤维素水解（导致缺陷处[[微纤丝]]被去除）的酸处理后，便产生棒状[[纤维素纳米晶体]]。所得 CNs 的形貌和[[结晶度]]与原始纤维素纤维相似；此类示例见图 7。

酸解事件的真实发生被归因于[[无定形区]]和[[结晶区]]之间水解动力学的差异。一般而言，天然[[纤维素]]的[[酸水解]]会诱导其[[聚合度|聚合度（DP）]]迅速下降至所谓的[[平衡聚合度|平衡聚合度（LODP）]]。此后，即使延长水解时间，DP 的下降也变得缓慢得多。<sup>65,71-75</sup> 人们曾认为 LODP 与酸水解前原始纤维素中沿纤维素链纵向存在的晶体尺寸相关。这一假说基于如下合理假设：无序或次晶区沿微纤维规则分布，因此它们更容易受到酸的进攻（相比之下，[[结晶]]区对进攻更不敏感）。此外，还曾假设酸水解后会生成均质的[[微晶]]。这些假设实际上已通过 [[X 射线晶体衍射]]、<sup>76</sup> [[碘染电子显微镜]]、<sup>76</sup> [[小角 X 射线衍射]]<sup>72</sup> 和[[中子纤维衍射|中子衍射]]分析<sup>77</sup> 得到证实。研究表明，纤维素酸水解得到的 LODP 值与沿纤维素链的周期性晶体尺寸具有良好的相关性。LODP 值已被证明取决于纤维素的来源，典型值包括：水解[[棉花]]为 250，<sup>64</sup> [[苎麻|苎麻纤维]]为 300，<sup>77</sup> [[漂白木浆]]为 140–200，<sup>65</sup> 高[[结晶度]]的 [[Valonia 纤维素]]则高达 6000。<sup>78</sup> 然而，对于不同纤维素来源，即使达到 LODP，通常也会观察到较宽的 DP 分布。所报道分布之间的这种差异至今仍引发激烈讨论。事实上，[[细菌纤维素]]、[[海鞘纤维素]]、[[Valonia]] 纤维素或[[棉纤维素]]的酸水解会导致分子量具有更高的[[多分散性]]，且没有任何 LODP 的证据，这可能是因为这些纤维素材料中低有序区并没有规则的分布。

目前用于制备 [[纤维素纳米晶|CN]] 的典型步骤包括：在严格控制的温度、搅拌和时间条件下，对纯[[纤维素]]材料进行强[[酸水解]]。酸的性质以及酸与[[纤维素纤维]]的比例也是影响 [[纤维素纳米晶体|CN]] 制备的重要参数。所得悬浮液随后用水稀释，并通过连续离心进行洗涤。然后对蒸馏水进行[[透析]]，以去除分散体中的任何游离酸分子。也有文献报道了过滤、<sup>79</sup> [[差速离心]]<sup>83</sup> 或[[超速离心]]（使用蔗糖梯度）<sup>84</sup> 等附加步骤。

已开发出针对[[纤维素纤维]]来源的特定水解和分离方案。最常见的来源包括[[棉花]][[纤维素]]纤维、<sup>85,86</sup> [[苎麻]]、<sup>81,87,88</sup> [[大麻]]、<sup>89</sup> [[亚麻]]、<sup>90,91</sup> [[剑麻]]、<sup>82,92</sup> [[小麦秸秆]]、<sup>93</sup> [[棕榈]]、<sup>94</sup> [[漂白针叶木]]<sup>95</sup> 和[[阔叶木]]<sup>96</sup> 浆、[[棉短绒浆]]、<sup>97,98</sup> [[微晶纤维素]]、<sup>99-102</sup> [[甜菜浆]]、<sup>103</sup> [[细菌纤维素]]<sup>104-106</sup> 以及[[海鞘纤维素]]。<sup>69,84,107</sup>

[[硫酸]]和[[盐酸]]已被广泛用于 [[纤维素纳米晶|CN]] 的制备，但[[磷酸]]<sup>108-111</sup> 和[[氢溴酸]]<sup>112</sup> 也有用于此目的的报道。如果 [[纤维素纳米晶体|CN]] 通过盐[[酸水解]]制备，其分散能力有限，其水悬浮液倾向于絮凝。<sup>113</sup> 另一方面，当使用硫酸作为水解剂时，它会与[[纤维素]]表面羟基反应，生成带电的[[表面硫酸酯基团]]，从而促进 CN 在水中的分散，并产生将在下文中讨论的重要性质。<sup>114</sup> 然而，引入带电硫酸基团会损害纳米晶体的[[热稳定性]]。<sup>80</sup> 此外，硫酸水解所得悬浮液与盐酸水解所得悬浮液之间在[[流变行为]]上也表现出差异。事实上，硫酸处理后的悬浮液未表现出时间依赖性黏度，而盐酸处理后的悬浮液在浓度高于 0.5%（w/v）时表现出[[触变性]]行为，在浓度低于 0.3% 时表现出[[反触变性]]行为。<sup>113</sup> 对盐酸水解生成的 CN 进行[[硫酸后处理]]已被研究，以受控方式在其表面引入[[硫酸酯基团]]。<sup>86,95</sup> 由盐酸水解生成、随后用硫酸溶液处理的 CN，其粒径与直接由硫酸水解得到的 CN 相同；然而，[[表面电荷密度]]可通过硫酸水解调节至给定值。关于颗粒形貌，在[[超声处理]]条件下，水解步骤中同时使用硫酸和盐酸似乎会生成[[球形 CN]]，而不是[[棒状纳米晶体]]。<sup>115,116</sup> 这些球形 CN 表现出更好的热稳定性，主要原因是其表面硫酸酯基团较少。<sup>116</sup>

用于获得[[纤维素纳米晶|CNs]]的水解反应中[[硫酸]]浓度与典型值约65%（质量分数）相比变化不大；但温度可在室温至70 °C之间变化，相应的水解时间根据温度可从30 min变化至过夜。在[[盐酸]]催化水解的情况下，反应通常在回流温度以及2.5至4 N的酸浓度下进行，反应时间随[[纤维素]]原料来源不同而变化。[[Bondenson]]等<sup>99,102</sup>以来源于[[挪威云杉]]（[[Picea abies]]）的[[微晶纤维素|MCC]]为纤维素起始原料，通过实验析因设计矩阵（[[响应面法]]）研究了水解条件的优化。过程中变化的因素包括MCC和硫酸的浓度、水解时间和温度以及[[超声处理]]时间。测定的响应为纤维素颗粒的[[中位尺寸]]和[[反应产率]]。作者证明，在硫酸浓度为63.5%（w/w）、时间约2 h的条件下，可获得长度在200至400 nm之间、宽度小于10 nm的[[纤维素纳米晶体|CNs]]，产率为30%（基于初始质量）。延长水解时间会导致纳米晶体长度减小并提高表面电荷。<sup>85</sup> [[Beck-Candanedo]]等<sup>96</sup>研究了反应时间和酸浆比对[[漂白针叶木]]（[[黑云杉]]，[[Picea mariana]]）[[亚硫酸盐浆]]经硫[[酸水解]]所得纳米晶体的影响。他们报道，在较长的水解时间下可得到更短且尺寸[[多分散性]]较窄的[[纳米颗粒]]。最近，[[Elazzouzi-Hafraoui]]等<sup>79</sup>研究了[[棉纤维]]经65%硫酸处理30 min并在45至$7 2 ~ ^ { \circ } \mathrm { C }$的不同温度下水解所得CNs的[[尺寸分布]]。他们证明，随着温度升高，可获得更短的晶体；但未发现对晶体宽度的明显影响。

## 3.2. [[纤维素纳米晶体]]的形貌与尺寸

[[纤维素纳米晶|CNs]]的几何尺寸（长度，L，和宽度，w）因[[纤维素]]原料来源和进行水解的条件不同而差异很大。这种差异部分归因于[[酸水解]]的[[扩散控制]]特性。对于给定来源类型，水解所得[[纤维素纳米晶体|CNs]]的尺寸不均一性可通过引入过滤、<sup>79</sup>[[差速离心]]、<sup>83</sup>或[[超速离心]]（使用蔗糖梯度）<sup>84</sup>步骤来降低。精确的形貌特征通常通过显微技术（[[透射电子显微镜|TEM]]、[[原子力显微镜|AFM]]、[[E-SEM]]、<sup>117</sup>等）或光散射技术进行研究，包括[[小角中子散射|小角中子散射（SANS）]]<sup>118</sup>以及偏振和去偏振[[动态光散射|动态光散射（DLS、DDLS）]]。<sup>119</sup> CNs的TEM图像通常显示颗粒聚集，这主要是由于负染色后制备样品时的干燥步骤所致。除聚集外，额外的仪器伪影通常也会导致对CN尺寸的高估。为克服这些问题，[[Elazzouzi-Hafraoui]]等<sup>79</sup>最近报道使用低温模式TEM（[[cryo-TEM]]）来防止聚集。

[[原子力显微镜|原子力显微镜（AFM）]]已被广泛用于在环境条件下快速提供[[纳米纤维素]]（[[纤维素纳米晶|CNs]]）的表面形貌信息，其纵向分辨率可达埃级。<sup>117,120-122</sup> 然而，在预期为其他形状的情况下，AFM形貌图可能显示出圆化的横截面轮廓；例如，[[Valonia]]的AFM成像结果与[[透射电子显微镜|TEM]]观察到的方形截面不同。这很可能是由于AFM针尖引起的基底形状扰动以及针尖展宽效应所导致的伪影。最后，据报道，AFM也是测量[[纤维素纳米晶体|CNs]][[力学性能]]和相互作用的有价值技术，例如刚度、黏附力或拉脱力。<sup>123</sup>

表1总结了来源于不同纤维素原料、并通过多种技术获得的CNs的典型几何特征。所报道的宽度通常约为几纳米，但CNs的长度跨度更大，从几十纳米到数微米不等。一个引人注目的观察结果是，CNs的长度与相应材料的极限聚合度（LODP）之间存在直接对应关系，因为人们普遍认为棒状CN由完全伸展的纤维素链段组成，并处于完全结晶排列中。

[[纤维素纳米晶|CN]] 沿晶体轴向的形态似乎也呈现不同特征，具体取决于[[纤维素纳米晶体|纳米晶体]]的来源。据报道，来自[[细菌纤维素]]<sup>121</sup> 和[[海鞘]]<sup>79</sup> 的 CN 具有带状形态，并带有扭转，其半螺距分别为 600–800 nm（[[Micrasterias denticulata]]）和 1.2–1.6 µm。然而，这些扭转特征在从[[高等植物]]中提取的 CN 中尚未被明确证实，人们认为这些 CN 是扁平的，并具有单平面轴向取向。

## 4. [[纤维素纳米晶体]]的[[化学改性]]

由于 [[纤维素纳米晶|CN]] 表面天然具有丰富的羟基，人们已尝试了不同的[[化学改性]]方法，包括酯化、醚化、氧化、硅烷化、聚合物接枝等。非共价表面改性，包括使用[[吸附]]性表面活性剂和聚合物包覆，也已被研究。所有化学功能化主要都是为了：（1）在 [[纤维素纳米晶体|CN]] 表面引入稳定的负电荷或正电荷，以获得更好的分散性（[[硫酸]]水解后得到的 CN 会引入不稳定的[[硫酸酯基团]]，这些基团在温和碱性条件下很容易被去除）；（2）调节 CN 的表面能特性以改善相容性，尤其是在[[纳米复合材料]]中与非极性或疏水性基体一起使用时。CN 化学功能化的主要挑战在于，所采用的工艺应只改变 CN 表面，同时保留其原始形态，以避免任何[[多晶型转变]]，并保持晶体的完整性。

## 4.1. 非共价表面[[化学改性]]

[[纤维素纳米晶|CNs]] 的非共价表面改性通常通过表面活性剂的[[吸附]]实现。该方法由 Heux 等人<sup>129,133</sup> 引入，他们使用的表面活性剂由带有烷基酚尾部的[[磷酸]]单酯和双酯组成。所得表面活性剂包覆的 [[纤维素纳米晶体|CNs]] 在非极性溶剂中分散性非常好。<sup>129</sup> 对 [[小角中子散射|SANS]] 数据的详细分析表明，表面活性剂分子在 CNs 表面形成了约 15 Å 的薄层。<sup>134</sup> 当这些表面改性 CNs 被引入等规[[聚丙烯]]中时，它们表现出非常好的相容性，并作为显著的成核剂，在等规聚丙烯常见 R 晶型之外，诱导了稀有 $\beta$ 晶型的形成。<sup>135,136</sup> Bondeson 等人<sup>137</sup> 也使用了一种阴离子表面活性剂来增强 CNs 在[[聚乳酸]]（PLA）中的分散。Kim 等人<sup>138</sup> 和 [[Orlando J. Rojas|Rojas]] 等人<sup>139</sup> 使用非离子表面活性剂将 CNs 分散在[[聚苯乙烯]]基复合纤维中。Zhou 等人<sup>140</sup> 最近报道了一种基于糖类两亲性嵌段共聚物吸附的 CN 表面改性新方法，十分精巧。通过模仿[[木质素]]-碳水化合物共聚物，他们将木葡聚糖寡糖-聚乙二醇-聚苯乙烯三嵌段共聚物吸附到 CNs 表面。所得 CNs 在非极性溶剂中表现出优异的分散能力。

## 4.2. [[TEMPO 介导氧化]]

[[纤维素纳米晶|CNs]] 的（[[2,2,6,6-四甲基哌啶-1-氧自由基]]）介导（或 TEMPO 介导）氧化已被用于将其表面存在的[[羟甲基]]转化为[[羧基]]形式。该氧化反应对[[伯羟基]]具有高度选择性，同时也很“绿色”且易于实施。它涉及在 [[NaBr]] 和 [[NaOCl]] 存在下使用一种稳定的氮氧自由基，即 2,2,6,6-四甲基哌啶-1-氧自由基（TEMPO）（见图 8 上方）。自 De Nooy 等人<sup>141</sup> 首次引入该技术以来，已有大量报道使用这一方法；他们表明，多糖中仅羟甲基被氧化，而[[仲羟基]]保持不变。事实上，[[纤维素纳米晶体|CNs]] 的 [[TEMPO 介导氧化]]涉及拓扑受限的反应序列，并且由于[[纤维素]]链的 [[2重螺旋轴|2 重螺旋轴]]，只有一半可及的羟甲基可以参与反应，而另一半则被埋藏在晶体颗粒内部（图 8 下方）。

[[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]介导的[[纤维素纤维]][[HCl水解]]所得[[纤维素纳米晶|CNs]]的氧化反应由[[Araki|Araki等人]]<sup>127</sup>首次报道，作为促进聚合物链接枝的中间步骤。这些作者证明，经过TEMPO介导的氧化后，[[纤维素纳米晶体|CNs]]保持了其初始的形态完整性，并在分散于水中时形成均匀悬浮液。后一观察结果的基础是新引入的[[羧基]]在CN表面赋予负电荷，从而诱导[[静电稳定]]。[[Montanari|Montanari等人]]<sup>142</sup>报道了类似的观察结果，他们还表明，在过度的[[TEMPO介导氧化]]过程中，晶体尺寸会因表面现存[[纤维素]]链的部分剥离而减小。

[[Habibi|Habibi等人]]<sup>143</sup>对来自[[被囊动物纤维素纤维]][[HCl水解]]所得[[纤维素纳米晶|CNs]]进行了[[TEMPO介导氧化]]，并表明该过程不会损害[[纤维素纳米晶体|CNs]]的形态完整性或其[[结晶度|天然结晶度]]。基于CNs的超分子结构、形态和晶体学参数，这些作者证明，通过使用特定量的主氧化剂即[[NaOCl]]，可以预测并实现不同的氧化程度（见图8底部）。当分散在水中时，[[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]氧化或羧化CN悬浮液显示出[[双折射]]图案，并且由于CN表面负电荷所赋予的[[聚阴离子]]特性而不会絮凝或沉降（见图9）。

## 4.3. 阳离子化

正电荷也可以容易地引入[[纤维素纳米晶|CNs]]表面；例如，弱或强含铵基团，如[[环氧丙基三甲基氯化铵]]（EPTMAC），可以[[接枝到]][[纤维素纳米晶体|CN]]表面。<sup>144</sup>这种表面阳离子化通过碱活化[[纤维素]]羟基对EPTMAC环氧基团部分的[[亲核加成]]进行，并形成具有意想不到[[触变凝胶]]特性的稳定CNs水悬浮液。观察到[[剪切双折射]]，但这些阳离子CNs未检测到[[液晶手性向列相]]分离，这很可能是由于悬浮液的高黏度所致。

## 4.4. 酯化、硅烷化及其他表面化学修饰

[[Sassi]] 和 [[Chanzy]] 已利用乙酸中的[[乙酸酐]]，研究了从 [[Valonia]] 和[[海鞘]]中提取的模型 [[纤维素纳米晶|CN]] 的均相与非均相[[乙酰化]]。<sup>126</sup> 他们通过 [[TEM成像|TEM 成像]]和 [[X射线衍射|X 射线衍射]]进行的超微结构研究表明，该反应通过晶体直径的减小而进行，而 [[纤维素纳米晶体|CN]] 长度仅观察到有限的缩短。据认为，该反应涉及一种[[非溶胀机制]]，仅影响定位于晶体表面的[[纤维素]]链。在均相乙酰化情况下，部分乙酰化的分子一旦具有足够溶解度，便立即分配到乙酰化介质中；而在非均相条件下，[[乙酸纤维素]]保持不溶，并包覆在未反应纤维素链的[[结晶]]核心周围。纤维素水解与羟基乙酰化同时发生也已有报道。羟基的 [[Fischer酯化|Fischer 酯化]]与无定形纤维素链的水解同时进行，已被引入为一种可行的[[一锅法反应]]方法，能够在单步过程中分离出乙酰化 CN（图 10）。<sup>145,146</sup>

![](<../2.SCI_MD/Cellulose Nanocrystals Chemistry, Self-Assembly, and Applications/images/0e7b6761d8a890fd74c4e2d819f642a9a3e87826f9457f2e7a14c9b91ac1e3c5.jpg>)  
图 10. 说明纤维素水解与羟基酯化反应活性的一锅法（串联）反应示意图。经参考文献 145 许可转载。版权 2009 美国化学会。

[[Yuan]] 等人最近开发了一种环境友好的 [[纤维素纳米晶|CN]] 表面[[乙酰化]]路线，<sup>147</sup> 该路线试剂消耗低且操作简便。该方法使用[[烯基琥珀酸酐]]（ASA）水乳液作为模板。将乳液与 [[纤维素纳米晶体|CN]] 悬浮液简单混合并[[冷冻干燥]]，所得固体加热至 105 °C。所得衍生物赋予酰化 CN 高度疏水特性，这一点十分明显，因为它们可容易地分散在介电常数 ε 差异很大的溶剂中；例如，它们不仅可分散在 ε 高达 46.45 的 [[DMSO]] 中，还可分散在 ε 低至 2.21 的 [[1,4-二氧六环]]中。[[Berlioz]] 等人<sup>148</sup> 最近报道了一种新的高效合成方法，可实现 CN 几乎完全的表面酯化，得到高[[取代度]]的 CN 酯。脂肪酸链的反应通过气相过程在干燥的 CN 上进行。[[SEM]] 和 [[X射线衍射|X 射线衍射]]分析表明，酯化从基底表面向晶体核心进行。在温和条件下，表面完全反应，而原始形貌得以保持，晶体核心保持不变。通过使具有不同脂肪链长度（C 到 $\mathrm { C _ { 1 8 } ) }$ ）的有机脂肪酰氯反应对 CN 进行酯化也已有报道，其接枝密度足够高，以至于主链为 18 个碳的脂肪酸能够在 CN 表面[[结晶]]。<sup>131</sup>

由[[海鞘]][[酸水解]]得到的[[纤维素]][[晶须]]已通过一系列[[烷基二甲基氯硅烷]]进行部分硅烷化，烷基部分的碳骨架从较短的异丙基到较长链的正丁基、正辛基和正十二烷基不等。<sup>149</sup> 研究表明，当[[取代度]]（DS）在0.6至1之间时，晶须能够容易地分散在低极性溶剂（如[[THF]]）中，形成具有[[双折射]]行为的稳定悬浮液，同时其形态完整性得以保持。然而，在高硅烷化程度（DS大于1）下，晶体核心中的链也被硅烷化，导致晶体解体，进而丧失原有形态。[[Roman]]和[[Winter]]还研究了来自[[细菌纤维素]]的[[纤维素纳米晶|CNs]]的表面三甲基硅烷化及其所得的[[醋酸丁酸纤维素]]<sup>104,150</sup>或[[聚硅氧烷]]<sup>151</sup>基[[纳米复合材料]]。最后，通过在[[甲苯]]中进行本体反应，将[[纤维素纳米晶体|CNs]]与[[N-十八烷基异氰酸酯]]偶联，也被报道可增强其在有机介质中的分散性以及与[[聚己内酯]]的相容性，从而显著提高所得纳米复合材料的刚度和延展性。<sup>92</sup>

## 4.5. 聚合物接枝

[[纤维素纳米晶|CNs]]表面的聚合物接枝主要采用两种策略，即“[[接枝到]]”（grafting-onto）和“[[接枝自]]”（grafting-from）。<sup>152</sup> “接枝到”方法是利用偶联剂将预先合成的聚合物链连接到[[纤维素]]表面的羟基上。在“接枝自”方法中，聚合物链是通过固定在基底上的引发剂引发的[[表面引发聚合|原位表面引发聚合]]形成的。

[[Ljungberg]]等人<sup>153</sup>使用“[[接枝到]]”方法将[[马来酸化聚丙烯]]（PPgMA）接枝到[[海鞘]]提取的[[纤维素纳米晶|CNs]]表面。所得接枝[[纤维素纳米晶体|纳米晶体]]在分散于[[无规聚丙烯]]中时表现出非常好的相容性和高粘附性。[[Araki|Araki等人]]<sup>127</sup>和[[Vignon]]等人<sup>154</sup>研究了在水相中通过[[碳二亚胺]]衍生物催化的[[肽偶联]]过程，将胺端基聚合物接枝到[[TEMPO介导氧化]]的CNs表面。[[Mangalam]]等人<sup>155</sup>也采用了相同方法，将[[DNA寡聚体]]接枝到CNs表面。通过[[异氰酸酯]]介导的偶联，已实现将不同分子量的[[聚己内酯]]接枝到CNs表面。<sup>87</sup> 这些作者报道其接枝密度足够高，使得接枝的PCL链能够在CNs表面[[结晶]]。[[Cao]]等人<sup>98</sup>也做了类似工作，他们报道了通过一锅法实现异氰酸酯催化的预合成[[水性聚氨酯]]聚合物的接枝。这种结晶在CN基[[纳米复合材料]]加工过程中引发了相应聚合物基体自由链的[[共结晶]]。此外，这种共结晶现象诱导了基体与填料之间形成共连续相，显著增强了界面粘附力，从而显著提高了所得纳米复合材料的机械强度。

![](<../2.SCI_MD/Cellulose Nanocrystals Chemistry, Self-Assembly, and Applications/images/81543e45c41f8883b6fe6f5279c06260906ee0392fbbff0c2133020c37d5ae52.jpg>)

将“[[接枝自]]”方法应用于 [[纤维素纳米晶|CN]] 的研究最早由 [[Habibi]] 等人报道，<sup>81</sup> 他们以[[辛酸亚锡]]（Sn(Oct)<sub>2</sub>）作为接枝剂和聚合剂，通过[[开环聚合]]（ROP）将[[聚己内酯]][[接枝到]] [[纤维素纳米晶体|CN]] 表面。同样，[[Chen]] 等人<sup>156</sup> 和 [[Lin]] 等人<sup>157</sup> 在[[微波辐照]]下进行了类似的接枝反应，以提高接枝效率。[[Pranger]] 等人<sup>100</sup> 研究了[[糠醇]]从[[纤维素]][[晶须]]表面的原位聚合。在该情形中，聚合由来自 CN 表面的磺酸残基催化。在高温下，[[磺酸基团]]发生[[脱酯化]]，并因此释放到介质中，从而原位催化聚合。[[Yi]] 等人<sup>158</sup> 和 [[Morandi]] 等人<sup>159</sup> 以 [[2-溴异丁酸乙酯]]为引发剂，通过[[原子转移自由基聚合]]（ATRP）在 CN 表面增长[[聚苯乙烯]]刷。类似地，其他乙烯基单体，主要是丙烯酸类单体，如 [[N-异丙基丙烯酰胺]]，也从 CN 表面聚合，以制备热响应性基底。<sup>160,161</sup> [[聚苯胺]]从 CN 上的接枝通过在[[盐酸]]水溶液中将苯胺原位聚合到 CN 上实现，具体是使用[[过二硫酸铵]]作为引发剂的[[氧化聚合]]。<sup>162</sup>

## 5. [[纤维素纳米晶]]的[[自组装]]与[[自组织]]

当使用[[硫酸]]作为水解剂时，它还会与 [[纤维素纳米晶|CN]] 的表面羟基发生化学反应，生成带负电的（表面）[[硫酸酯基团]]，这些基团通过静电排斥作用促进[[晶须]]在水中形成完全均匀的分散体。<sup>114</sup> 由此推断，持续去除水相应会使纳米晶倾向于采取能够使现有[[静电相互作用]]最小化的构型。事实上，（均相的）浓悬浮液会[[自组织]]成壮观的有序[[液晶]]排列，这种现象与其他棒状粒子的非絮凝悬浮液中发生的情况类似，例如[[聚四氟乙烯晶须]]、<sup>163</sup> [[烟草花叶病毒]]（TMV）、<sup>164</sup> [[DNA片段|DNA 片段]]、<sup>165</sup> 或从其他多糖（如[[甲壳素]]）中提取的[[微晶]]。<sup>166</sup>

这种[[自组织]]现象表现为：通过[[偏光光学显微镜]]观察悬浮液时，出现了“指纹”图案，这表明存在[[手性向列有序]]。<sup>114</sup> 更引人注目的发现是，这种手性向列结构可以在水分完全蒸发后得以保留，从而得到具有虹彩的 [[纤维素纳米晶|CN]] 薄膜。这些固体薄膜除了可用于对其引人注目的行为进行基础研究外，还具有许多潜在应用，例如用作装饰材料和防伪纸张的涂层材料（因为其光学特性无法通过印刷或影印复制）。<sup>167</sup>

对这些体系的研究表明，在稀浓度状态（[[各向同性相]]）下，[[纤维素纳米晶|CN]] 呈随机取向。实际上，[[偏光光学显微镜]]显示，在稀浓度下，[[纤维素纳米晶体|CN]] 表现为球状或卵球状，且初始有序畴类似于[[类晶团聚体]]（tactoids）。当 CN 浓度增加时，由于这些类晶团聚体合并形成[[各向异性相]]，体系采取[[向列相]][[液晶]]排列，其特征是 CN 棒发生单向自取向。当悬浮液达到 CN 的临界浓度时，会形成[[手性向列有序]]相，并显示出[[胆甾相液晶]]的特征线（见图 14）。在[[手性向列相]]形成的临界浓度以上，CN 水悬浮液产生[[剪切双折射]]，静置时可自发分离为上层各向同性相和下层各向异性相（图 11）。

[[各向异性相]]中的这些手性向列或胆甾结构由沿某一矢量（[[指向矢]]）排列的 [[纤维素纳米晶|CN]] 棒堆叠平面组成，各指向矢的取向绕垂直轴逐层旋转，如图 11 所示。[[纤维素纳米晶体|CN]] 在临界浓度以上发生的自诱导平行排列现象，被归因于众所周知的棒状粒子为获得向列有序而发生的熵驱动自取向现象。其起源可归因于有利的[[排除体积相互作用]]，与无序相相比，这类相互作用可带来更高的堆积熵。

![](<../2.SCI_MD/Cellulose Nanocrystals Chemistry, Self-Assembly, and Applications/images/e22ca87adf13c1682df6d966809568a5c4d8defd140afc2110d87a9289324e3b.jpg>)  
图 12.（上）Orts 等人提出的通过扭曲棒的螺旋手性相互作用实现更紧密堆积的示意图：左图，如果棒不以平行轴堆积，而是一根棒的“螺纹”嵌入相邻棒的“沟槽”，则棒间距离可减小至 D；（右）对于具有静电双层的纳米晶体，带螺纹的棒会改变周围的电双层，并在较大距离上影响堆积（经参考文献 170 许可转载。版权所有 1998 美国化学会）。（下）具有表面电荷的细菌纤维素纳米晶的示意图，显示有效粒子形状的变化：（左）在水中，表面电荷排斥延伸至长程，导致粒子表现为表观非手性的棒；（右）加入 NaC 缩短排斥范围，使有效粒子成为扭曲的棒（经参考文献 105 许可转载。版权所有 2001 美国化学会）。

这种自发[[自组装]]现象的起源被认为类似于在含[[纤维素]]的天然材料中常观察到的螺旋结构。<sup>114,168,169</sup> 由于这些悬浮液中的分子不存在任何结构手性，这种螺旋排列被假定源于一种诱导[[手性向列相]]堆积的不对称性。[[Revol]] 和 [[Marchessault]] 推测，[[纤维素纳米晶|CN]] 本身必定存在某种扭转，从而解释其手性相互作用。<sup>166</sup> 因此，由于由 [[盐酸|HCl]] 生成的不带电荷的 [[纤维素纳米晶体|CN]] 悬浮液不会产生这种[[手性向列有序]]，CN 表面离子化[[硫酸]]根基团产生的负电荷曾被认为对相稳定性至关重要，其螺旋分布也被认为是“扭转剂”。<sup>114</sup> 然而，近期对通过表面活性剂包覆<sup>129</sup> 或聚合物接枝<sup>127</sup> 实现[[空间稳定]]的 CN 悬浮液的研究，为 CN 纳米结构中的扭转提供了更多证据。事实上已经发现，即使在对 CN 进行初步[[吸附]]或接枝改性后静电排斥被屏蔽，悬浮液仍保持其手性向列有序。<sup>127,129</sup> [[Orts]] 等<sup>170</sup> 基于对水相悬浮液中 CN 的原位[[小角中子散射|小角中子散射（SANS）]]测量（在磁场和剪切取向条件下），证实了 CN 为螺旋杆状的假设（图 12，上）。更多支持性证据由 [[Araki]] 和 [[Kuga]]<sup>105</sup> 报道，他们惊奇地发现，来自[[细菌纤维素]]的 CN 在无电解质悬浮液中形成非手性[[向列相]]，而在电解质存在下，悬浮液呈现手性向列有序。这一现象被解释为 CN 发生了非平庸的形态变化，即由普通圆柱构型转变为扭转杆状，这是表面电荷被屏蔽的结果（图 12，下）。实际上，由表面电荷排斥力引起的 CN 膨胀会掩盖手性形态，使有效杆体变得笔直且光滑；这种构型允许这些杆体通过平行堆积形成向列相。加入电解质会诱导有效粒径收缩；在这种情况下，扭转形态在杆体相互排列中显现出来，并导致手性向列有序的形成（图 12 下）。

有序[[手性向列相]]及其性质（例如在 [[纤维素纳米晶|CN]] 悬浮液中所观察到的）已被证明受与胶体[[液晶]]相关的经典相平衡理论支配，例如 [[Onsager 理论]]<sup>171</sup> 或其扩展形式，如 [[Stroobants]]、[[Lekkerkerker]] 和 [[Odijk]]（SLO）理论。<sup>172</sup> 成相能力取决于若干参数，如颗粒的[[长径比]]、电荷密度和渗透压。

## 5.1. [[纤维素纳米晶|CN]] 在水介质中的[[自组装]]与[[自组织]]

[[硫酸]]化 [[纤维素纳米晶|CN]] 在无电解质水悬浮液中形成有序[[向列相]]所需的临界浓度在很大程度上取决于电荷密度，通常在 1% 至 10%（w/w）之间。由此产生的手性向列[[各向异性相]]通常表现出随 [[纤维素纳米晶体|CN]] 浓度增加而减小的螺距，可在 20 至 80 µm 之间变化。

![](<../2.SCI_MD/Cellulose Nanocrystals Chemistry, Self-Assembly, and Applications/images/3a66076c24de7c866d4b44ceb72c428ad1947dcf11432d92dea8595ba16760b1.jpg>)

[[各向同性相]]到[[各向异性相]]（[[手性向列相]]）的平衡对电解质的存在及电解质反离子的具体种类十分敏感。已经开展了关于两相共存时各向同性与各向异性相组成随电解质浓度变化的定量研究，<sup>128</sup> 以及反离子类型影响的研究。<sup>173</sup> 后一项研究发现，增加所添加电解质的量会减少各向异性相的形成。有趣的是，发现手性向列螺距减小，即随着电解质浓度增加，相变得更加高度扭转。显然，螺距减小是因为双电层厚度减小增加了[[微晶]]之间的手性相互作用。<sup>128</sup> 如前所述，[[硫酸]]化 [[纤维素纳米晶|CN]] 悬浮液的相分离也强烈依赖于其反离子的性质。<sup>173</sup> 对于无机反离子，有序相形成的临界浓度通常随着范德华半径的增加而增大，顺序为 $\mathrm { H ^ { + } < N a ^ { + } < K ^ { + } < C s ^ { + } . }$ 对于有机反离子，如 NH<sub>4</sub><sup>+</sup>、$\mathrm { ( C H _ { 3 } ) _ { 4 } N ^ { + } }$ 、(CH CH ) N<sup>+</sup>、(CH CH CH ) N<sup>+</sup>、(CH CH CH CH ) N<sup>+</sup>、(CH ) HN<sup>+</sup> 和 $( \mathrm { C H _ { 3 } C H _ { 2 } } ) _ { 3 } \mathrm { H N ^ { + } }$，临界浓度取决于疏水吸引与空间排斥的相对贡献。总体而言，该领域的大多数工作已证明，临界浓度随反离子尺寸增加而增大。还发现，反离子的化学性质也会影响稳定性、相分离的温度依赖性、手性向列螺距以及由这些悬浮液制成的干燥样品的再分散性。

据报道，从[[细菌纤维素]]经[[硫酸]]水解得到的[[纤维素纳米晶]]可自发分离出[[向列相]]。<sup>105</sup> 这一相分离事件之前会出现一种[[双折射]]玻璃态，可持续长达 7 天。然而，加入微量电解质（<1 mM NaCl）后，2 天内即发生分离，并使各向异性相转变为手性向列相。<sup>105</sup> 电解质的存在还显著减小了下层[[各向异性相]]的体积。<sup>105</sup> Hirai 等人最近对这一出乎意料的相分离以及 NaCl（高盐浓度，最高达 5 mM）的影响进行了详细研究。<sup>106</sup> 他们报道，[[手性向列相]]的体积分数在 NaCl 浓度约 1.0 mM 处出现最小值。如果 NaCl 浓度在 2.0–5.0 mM 范围内变化，则不会发生相分离，但悬浮液会完全转变为[[液晶]]态（图 13）。在 NaCl 浓度为 0 至 2.75 mM 范围内，各向异性相中有序畴的尺寸随 NaCl 浓度增加而减小。在 2.75 mM 时，仅观察到 tactoid；而在 5.0 mM 时，不再观察到手性向列畴。此外，手性向列螺距随 NaCl 浓度增加而减小，从无电解质悬浮液的 16.5 µm 降至约 0.75 mM 时的最小值 12 µm，最后在浓度最高达 2.0 mM 时急剧增大至超过 19 µm。

与电解质类似，[[Beck-Candanedo]] 等人<sup>174-176</sup> 报道了（非[[吸附]]性）大分子（如蓝色葡聚糖或离子型染料）可诱导各向异性[[硫酸]]水解[[纤维素纳米晶]]水悬浮液发生熵驱动相分离，形成[[各向同性相]]。阴离子型染料在比简单 1:1 电解质（如 NaCl）低得多的离子强度下即可诱导相分离，这可能与其多价特性和更大的水合半径有关。然而，已有研究表明，阳离子型和阴离子型染料的静电吸引与化学结合似乎会抑制[[纤维素]]纳米晶悬浮液中的相分离。<sup>174</sup> 还已证明，当阴离子型染料连接到葡聚糖等非吸附性大分子上时，可获得各向同性–各向同性–向列三相平衡。这种特殊行为在中性蓝色葡聚糖中也被观察到；产生三相平衡所需的葡聚糖浓度似乎受到其分子量或电荷密度的强烈影响。<sup>176</sup> 这些悬浮液相行为的机制似乎同时受排斥性静电作用和吸引性熵力支配：阴离子型染料的存在提高了体系的离子强度，而在低离子强度下，需要更大量的纤维素纳米晶才能达到发生相分离所需的临界纤维素浓度，从而使相平衡移动到各向同性–[[手性向列相]]共存区域。在较高离子强度下，棒之间的静电排斥被充分屏蔽，从而允许来自葡聚糖大分子的耗尽吸引作用并产生相分离。<sup>175</sup>

[[纤维素纳米晶体]]（[[纤维素纳米晶|CNs]]）表面电荷的性质与密度也被报道会影响[[手性向列相]]的形成。通过使用后[[硫酸]]化的 [[盐酸|HCl]] 水解 CNs（其硫含量比直接 $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 } – \mathrm { h y }$ 水解的 CNs 低约三分之一），[[Araki]] 等人<sup>86</sup> 报道了明显不同的行为。实际上，后磺化悬浮液形成了具有交叉影线图案的[[双折射]]玻璃态相（图 14），而不是直接硫酸化 CNs 所特有的指示手性[[向列相]]的指纹图案（图 14）。有趣的是，后硫酸化 CNs 的高粘度悬浮液并未产生手性向列相，这很可能是由于其电荷含量较低。

通过 [[TEMPO 介导氧化]]制备的[[羧基]]化 [[纤维素纳米晶|CNs]] 已被证明可在水中形成强烈[[双折射]]的均匀分散体。这种[[剪切双折射]]并非均匀分布在整个体系中，而是由不同尺寸和颜色的畴组成，表明 [[纤维素纳米晶体|CNs]] 内部存在局部畴取向，但从未以[[类晶团聚体]]或指纹图案的形式达到[[手性向列有序]]。进一步有序化的缺失被归因于 CNs 长度的高[[多分散性]]（这些 CNs 通过 [[盐酸|HCl]] 酸预水解从被囊动物中获得）以及悬浮液的高粘度。<sup>143</sup> 然而，当羧基化 CNs 由[[棉纤维]]制备时，观察到 CNs 长度多分散性降低，因此这些悬浮液在浓度为 5%（w/w）或更高时达到了螺距为 7 µm 的[[手性向列相|手性向列有序]]。此外，当 [[聚乙二醇|PEG]] [[接枝到]] CNs 表面时，所得 PEG 接枝 CNs 通过类似于未改性 CNs 的相分离形成了手性向列介晶相，但指纹图案的间距减小（约为 4.0 µm）。<sup>127</sup> 而且，与先前发现不同的是，PEG 接枝 CNs 即使在高固含量下也表现出显著增强的分散稳定性，并能够从[[冷冻干燥]]状态重新分散到水或氯仿中。由于电粘效应减弱，它们在高离子强度下也表现出强稳定性，并且在加入高达 2 M NaCl 的电解质后未观察到聚集。

对于阳离子型[[环氧丙基三甲基氯化铵]]接枝 [[纤维素纳米晶|CNs]] 的悬浮液，也观察到了[[剪切双折射]]，但未检测到[[液晶手性向列相]]分离，这很可能是因为该相由于悬浮液的高粘度而受到抑制。<sup>144</sup>

## 5.2. [[纤维素纳米晶|CNs]] 在有机介质中的[[自组装]]与[[自组织]]

Heux 等人<sup>129</sup>首次描述了 [[纤维素纳米晶|CN]] 在非极性溶剂中的自有序现象。在他们的初步研究中，使用表面活性剂涂层来分散 [[纤维素纳米晶体|CN]]，从而获得手性向列结构。然而，发现手性向列结构的螺距约为 4 µm，与水悬浮液的情况（螺距在 20 至 80 µm 之间）相比，该值过小。此外，可以实现更高的 CN 浓度，最高可达 36%。这些结果被归因于表面活性剂涂层施加的[[空间稳定]]作用。事实上，这种稳定作用屏蔽了静电排斥，从而诱导棒状颗粒之间更强的手性相互作用，最终允许更高的堆积密度。同一研究组最近对该[[手性向列相]]的结构进行了详细考察。<sup>177,178</sup>他们研究了从[[棉纤维]]中提取的 CN 的[[长径比]]与其在[[环己烷]]等非极性溶剂中分散性之间的相关性。观察到自发相分离形成手性向列中间相的临界浓度高于在水中的临界浓度。对于这些亲有机性悬浮液，无法与 [[Onsager 理论]]建立关联，因为实验临界浓度远低于预测值，这可能是由于非极性介质中棒状颗粒之间存在吸引相互作用。这些强相互作用还导致手性向列螺距减小至约 2 µm 或更小。此外，用高长径比 CN 制备的悬浮液未显示出任何相分离，而是在高浓度下产生了各向异性凝胶相。<sup>177</sup>相反，对于由[[木葡聚糖低聚糖-聚（乙二醇）-聚苯乙烯三嵌段共聚物]]稳定的 CN 在[[甲苯]]中的悬浮液，其手性向列螺距要大得多（约为 17 µm）。<sup>140</sup>

## 5.3. [[纤维素纳米晶|CN]] 在外场作用下的[[自组装]]与[[自组织]]

水悬浮液中的非絮凝[[纤维素纳米晶|CN]]在外部场（无论是磁场还是电场）作用下可发生取向。由于[[纤维素]]具有负的[[抗磁各向异性]]，它们在磁场作用下可以取向。尽管纤维素每个分子重复单元的抗磁[[各向异性相]]对较弱，但纤维素棒状纳米晶既长又重，因此与[[DNA]]或[[烟草花叶病毒|TMV]]等其他粒子相比，其总抗磁各向异性相当大。<sup>179,180</sup> Sugiyama等<sup>180</sup>首次证明，从[[海鞘]]中提取的[[结晶]]纤维素稀水悬浮液在7 T磁场作用下能够取向。所得薄膜中晶体以其长轴垂直于磁场方向排列。在[[胆甾相]]轴变得平行于磁场的情况下，可以实现[[纤维素纳米晶体|CN]]的整体宏观取向，而并非使手性向列结构解旋。Fleming等证明，[[液晶]]态CN悬浮液在NMR谱仪磁场中的取向有助于解释加入该悬浮液的蛋白质的NMR谱。<sup>181</sup> 最近，Kimura等<sup>132</sup>表明，通过施加缓慢旋转的强磁场，可以使CN悬浮液的手性向列行为解旋。Kvien和Oksman尝试利用强磁场在聚合物基体（如[[聚乙烯醇]]）中对CN进行取向，以获得单向增强[[纳米复合材料]]，有趣的是，结果表明纳米复合材料的动态模量在取向方向上高于横向方向。<sup>182</sup>

从[[苎麻|苎麻纤维]]和[[海鞘]]中提取的[[纤维素纳米晶|CN]]水悬浮液在[[交变电场|交流电场]]下干燥后，薄膜中沿场矢量方向表现出高度取向。<sup>183</sup> 来自苎麻纤维的[[纤维素纳米晶体|CN]]在[[环己烷]]中的[[胶体悬浮液]]也已在交流电场$\mathrm { f i e l d } ^ { 1 \breve { 8 } 4 }$中取向，这由[[透射电子显微镜|TEM]]和[[电子衍射]]所揭示。此外，这些悬浮液在[[正交尼科尔棱镜]]下用偏振光观察时表现出[[双折射]]，其大小可随场强增加而增大。它们还显示出干涉牛顿色，类似于[[热致液晶]]薄膜所得现象，该干涉图样在约2 kV/cm处达到饱和平台。这一引人注目的结果是在CN浓度低于各向同性/[[向列相]]转变时获得的，从而排除了电场与可能存在的[[各向异性相]]之间的任何协同效应。<sup>184</sup>

## 5.4. [[纤维素纳米晶|CN]]在固体薄膜中的[[自组装]]与[[自组织]]

[[Revol]] 等<sup>167,185</sup>利用 [[纤维素纳米晶|CN]] 悬浮液能够形成[[手性向列相|溶致手性向列有序]]的能力，通过简单控制水平表面上悬浮水分的蒸发，制备出具有独特且可调光学性质的虹彩固体[[纤维素]]薄膜。从这些悬浮液获得的[[液晶]]有序在固体薄膜中得以保留，干燥薄膜中的手性向列螺距与可见光波长处于同一长度尺度。这一独特体系被描述为一种干涉器件，具有在特定波长范围内反射圆偏振光的能力。由于反射光的波长决定了其光谱色或本色，薄膜的感知颜色取决于[[胆甾相]]有序的螺距和光的入射角。此类薄膜的微观结构对干燥条件非常敏感。此外，反射偏振光的感知颜色是“可调的”，因为最终螺距可以根据加工变量（如 [[纤维素纳米晶体|CN]] 的[[长径比]]和电解质含量）而变化。在环境条件下制备的薄膜通常呈现多畴（多型）结构，不同手性向列畴的螺旋轴指向不同方向。事实上，[[Roman]] 和 Gray<sup>186,187</sup> 首次报道了令人信服的证据，表明[[抛物线焦锥结构|抛物线焦锥（PFC）结构]]（一种对称的焦锥缺陷形式，其中线缺陷来自一对相互垂直、反平行且共焦的抛物线）被捕获在这些[[自组装]]固体薄膜中（见图 15）。

## 6. [[纤维素纳米晶体]]在[[纳米复合材料]]中的应用

自 Favier 等人首次报道将 [[纤维素纳米晶|CN]] 用作[[聚（苯乙烯-共聚-丙烯酸丁酯）]]（poly(S-co-BuA)）基[[纳米复合材料]]中的增强填料以来，<sup>68</sup> [[纤维素纳米晶体|CN]] 因其极具吸引力的本征性质而在纳米复合材料领域引起了广泛关注，这些性质包括纳米尺度尺寸、高[[BET|比表面积]]、独特形貌、低密度（据估计，纯[[结晶]][[纤维素 I]]α 的密度为 1.61 g/cm<sup>3188</sup>）以及机械强度。此外，它们易于（化学）改性、来源广泛、可再生且可生物[[降解]]。CN 已被引入多种聚合物基体中，包括[[聚硅氧烷]]、<sup>151</sup> 聚磺酸酯、<sup>189</sup> [[聚己内酯]]、<sup>81,87,190</sup> 苯乙烯-丙烯酸丁酯胶乳、<sup>191</sup> [[聚氧乙烯]]、<sup>192-195</sup> 聚（苯乙烯-共聚-丙烯酸丁酯）（poly(S-co-BuA)）、<sup>68</sup> [[醋酸丁酸纤维素]]、<sup>104,196</sup> [[羧甲基纤维素]]、<sup>197</sup> [[聚乙烯醇]]、<sup>198</sup> [[聚醋酸乙烯酯]]、<sup>82,97</sup> [[聚（乙烯-醋酸乙烯酯）]]（EVA）、<sup>199</sup> 环氧化物、<sup>70</sup> [[聚乙烯]]、<sup>131</sup> [[聚丙烯]]、<sup>136</sup> [[聚氯乙烯]]、<sup>200-203</sup> [[聚氨酯]]<sup>204</sup> 以及[[水性聚氨酯]]。<sup>98</sup> 其引入生物聚合物的情况也有报道，例如[[淀粉|淀粉基聚合物]]、<sup>69,89,90,205-208</sup> [[大豆蛋白]]、<sup>209</sup> [[壳聚糖]]、<sup>130</sup> 或[[再生纤维素]]，<sup>210</sup> 以及类生物聚合物[[聚乳酸]]、<sup>137,211-213</sup> [[聚羟基辛酸酯]]<sup>214,215</sup> 和[[聚羟基丁酸酯]]。<sup>216</sup>

## 6.1. [[纳米复合材料]]加工

加工技术对复合材料的最终性能具有重要影响。所采用的技术应考虑 [[纤维素纳米晶|CN]] 的本征性质、其界面特性（无论是否改性）、聚合物基体的性质（溶解性、分散性和[[降解]]性）以及所需的最终性能，如几何形状。

## 6.1.1. [[浇铸-蒸发加工]]

[[浇铸-蒸发]]一直是将[[纤维素]][[晶须]]从水性分散体转移到有机聚合物基体中的主要技术。纳米复合薄膜通过溶液浇铸形成，即仅让溶剂蒸发即可。[[纤维素纳米晶|CN]] 在聚合物基体以及加工溶剂中的良好分散性，是制备具有显著机械增强效果的聚合物/晶须[[纳米复合材料]]的先决条件。未经表面改性的 [[纤维素纳米晶体|CN]] 本征地具有强相互作用，据报道极难分散。此外，当 CN 分散体在纳米复合材料加工前被干燥时，这一问题会更加严重，这通常意味着 CN 的干燥和再分散而无团聚具有挑战性。

由于 [[纤维素纳米晶|CN]] 具有亲水特性，含有 [[纤维素纳米晶体|CN]] 的最简单聚合物体系均为水基体系。通常将 CN 的未干燥水分散体直接与聚合物水溶液或分散体混合。然而，这类体系用途有限，仅适用于水溶性或可水分散的聚合物，例如胶乳。已有报道将聚合物水溶液（中等强度[[氢键]]作用，溶于与水互溶的助溶剂如 [[THF]]）与 CN 水悬浮液结合。<sup>217</sup> 对未经表面改性的 CN，已探索使用极性溶剂，最常用的为 [[N,N-二甲基甲酰胺]]（DMF）。<sup>218</sup> 与水不混溶且极性较低的溶剂，如[[甲苯]]，也被广泛使用。但缺点是，该过程需要进行溶剂交换步骤。由于丙酮与水互溶，它通常作为载体将 CN 从水相转移至有机溶剂中。通过[[冷冻干燥]]并将[[海鞘]]来源的 CN 再分散于甲苯中，将这些填料引入[[无规聚丙烯]]中，但出现了严重的团聚。<sup>153</sup> 然而，当使用[[甲酸]]再分散干燥 CN 时，获得了非常令人满意的分散效果。<sup>219</sup> 冷冻干燥的 CN 可成功再分散于含有少量水（0.1%）的偶极非质子溶剂（如 [[DMSO]] 和 DMF）中，并可通过[[浇铸-蒸发]]技术由这些悬浮液制得薄膜。<sup>220</sup> 更近期，van den Berg 等人<sup>221</sup> 研究了限制经[[盐酸]]或[[硫酸]]水解由海鞘提取的 CN 在一系列极性质子和非质子有机溶剂中分散性的因素。由 HCl 制备的 CN 通常具有明显的团聚倾向，干燥后无法在极性非质子溶剂中分散。只有甲酸和[[间甲酚]]等质子溶剂被证明能有效破坏团聚 CN 中的氢键，从而分散由盐酸或硫[[酸水解]]生成的两种 CN（图 16）。

## 6.1.2. [[溶胶-凝胶法]]

Capadona 等人最近报道了一种通用的加工方法，即通过分散良好的 [[纤维素纳米晶|CN]] [[自组装]]形成三维模板，然后用所选聚合物填充该模板。<sup>222-224</sup> 第一步（图 17 左，a 和 b）是通过[[溶胶-凝胶法|溶胶/凝胶过程]]形成 [[纤维素纳米晶体|CN]] 模板，该过程包括形成均匀的含水[[晶须]]分散液，随后通过与水混溶性溶剂（通常为丙酮）进行溶剂交换实现凝胶化。第二步（图 17 左，d 和 e）中，将凝胶浸入聚合物溶液中，以基体聚合物填充 CN 模板（图 17）。应当指出，聚合物溶剂必须与凝胶溶剂混溶，并且绝不能使 CN 重新分散。

## 6.1.3. 其他加工方法

已尝试使用双螺杆挤出作为制备 [[纤维素纳米晶|CN]] 基[[纳米复合材料]]的加工方法。<sup>225</sup> 该过程包括在挤出过程中将涂覆有表面活性剂<sup>226</sup>或[[聚乙烯醇]]<sup>211</sup>的 [[纤维素纳米晶体|CN]] 水分散液泵入熔融聚合物（即[[聚乳酸]]，PLA）中。然而，此类体系不幸地表现出相容性不足。[[淀粉]]与 CN 纳米复合材料已通过挤出法加工。<sup>227</sup> 此外，用长链分子改性的 CN 的挤出似乎更为容易，并且可在无溶剂条件下加工，尤其是当接枝链能够在加工温度下熔融时。最近报道了一个实例，其中脂肪酸接枝的 CN 与低密度[[聚乙烯]]成功挤出。<sup>131</sup> 具有长 [[聚己内酯|PCL]] 链的 PCL 接枝 CN 在经受压缩和注射成型时表现出良好的热成型性。<sup>156</sup>

静电纤维纺丝或静电纺丝是一种通用方法，通过静电力作用制造直径从数微米到 100 nm 或更小的纤维，已成为聚合物基体中 [[纤维素纳米晶|CN]] 的一种替代加工方法。然而，正如在[[浇铸-蒸发]]技术中所观察到的那样，[[纤维素纳米晶体|CN]] 的分散可能具有挑战性。已有报道，以水为溶剂，在水溶性聚合物如 $\breve { \mathrm { P E O } } ^ { 2 2 8 }$ 和 $\mathrm { P V A } ^ { 2 2 9 , 2 3 0 }$ 中静电纺丝 CN，可获得纳米尺度直径的纤维。另一种制备 CN 静电纺丝阵列的技术探索了采用间接、隔离式“核-壳”静电纺丝方法的途径，其中[[硫酸]]化 CN 的水分散液构成被[[纤维素]]“壳”包围的离散“核”组分。<sup>231</sup> 纺丝过程中发生的各种并发现象，尤其是在用 CN 加载聚合物悬浮液时，使其难以控制，也难以在操作条件与所制备微米或[[纳米纤维]]的性能之间建立明确的相关性。实际上，诸如电压、纺丝尖端与收集器之间的距离、纺丝溶液的性质（电导率、粘度、密度、表面张力等）及其流速等加工参数，都会显著影响纺丝过程的结果。

在有机介质中对含有 [[纤维素纳米晶|CN]] 的聚合物溶液进行静电纺丝有多种方法：已报道的几种成功方法包括表面活性剂包覆<sup>139</sup>和聚合物接枝<sup>230,232</sup>，以使 [[纤维素纳米晶体|CN]] 分散在溶解于 [[THF]] 的[[聚苯乙烯]]以及溶解于 [[N,N-二甲基甲酰胺|DMF]]-二氯甲烷的[[聚己内酯]]中。在静电纺丝 PL $\mathbf { A } . ^ { 2 3 3 }$ 的情况下，也研究了极性溶剂（如 DMF）的使用。

层层沉积技术也被报道用于制备基于 [[纤维素纳米晶|CN]] 的多层复合材料。<sup>234,235</sup>

## 6.2. [[纤维素纳米晶|CN]] 基复合材料的[[力学性能]]

[[纤维素纳米晶|CN]] 的纳米尺度尺寸和极具吸引力的[[力学性能]]使其成为改善目标基体材料力学性能的理想候选者。事实上，[[纤维素纳米晶体|CN]] 的轴向杨氏模量在理论上比钢更强，并且与 Kevlar 相似。对于 CN 而言，天然[[纤维素]]完美晶体的杨氏模量理论值估计为 167.5 $\mathrm { G P a . ^ { 2 3 6 } }$。最近，利用拉曼光谱技术测量了来自[[海鞘]]和[[棉花]]的天然纤维素晶体的弹性模量，所得值分别为 143 $\mathrm { G } \mathrm { \check { P } a } ^ { 2 3 7 }$ 和 105 $\mathrm { G P a } , ^ { 2 3 8 }$。

Favier 等人首次报道了从[[海鞘]]中提取的 [[纤维素纳米晶|CN]] 对聚（S-co-BuA）的增强效果。<sup>67,68</sup>他们证明，即使在较低的 [[纤维素纳米晶体|CN]] 添加量下，通过动态力学分析测得，在玻璃-橡胶转变温度范围以上，储能模量也有显著提高（见图 18）。

研究表明，[[纤维素纳米晶|CN]] 对[[纳米复合材料]][[力学性能]]的影响超出了传统经典模型对填料增强纳米复合材料的常规预测，例如，这一点本可通过 Halpin-Kardos 模型体现出来。<sup>239</sup>这种效应部分被解释为形成了由[[氢键]]粘结在一起的刚性渗流填料网络。<sup>240</sup>该网络的存在后来通过对含有导电聚吡咯包覆 [[纤维素纳米晶体|CN]] 的纳米复合材料进行的电学测量得到了证实。<sup>241</sup>

渗流是一种统计几何模型，可应用于任何包含能够相互混合组分的随机多相材料。<sup>242</sup>通过改变连接数量，该方法可实现从一组不连通物体到无限连通状态的转变。渗流阈值被定义为分隔这两种状态的临界体积分数。体积阈值取决于多个变量，主要是颗粒形状 $( \mathrm { s i z e } ^ { 2 4 3 }$ 和[[长径比]]<sup>244</sup>）、它们的取向<sup>245</sup>以及颗粒间相互作用。<sup>246</sup>

因此，为了研究[[纤维素纳米晶|CNs]]的增强效应，必须引入一个包含典型复合材料中三相的模型：基体、填料逾渗网络和非逾渗填料。通过扩展Takayanagi等人的唯象串并联模型，<sup>247</sup> Ouali等人<sup>248</sup>提出了一种考虑填料拓扑排列及其相互作用的构型。在该方法中，复合材料的弹性拉伸模量$G ^ { \prime }$由以下公式给出：

$$
G ^ {\prime} = \frac {(1 - 2 \psi + \psi X _ {\mathrm{r}}) G _ {\mathrm{s}} ^ {\prime} G _ {\mathrm{r}} ^ {\prime} + (1 - X _ {\mathrm{r}}) \psi G _ {\mathrm{r}} ^ {\prime 2}}{(1 - X _ {\mathrm{r}}) G _ {\mathrm{r}} ^ {\prime} + (X _ {\mathrm{r}} - \psi) G _ {\mathrm{s}} ^ {\prime}}
$$

下标s和r分别指软相（聚合物）和刚性相（[[纤维素纳米晶|CNs]]）。可调参数ψ对应于逾渗刚性相的体积分数，b为临界逾渗指数。ψ可写为

$$
\begin{array}{l l} \psi = 0 & \text { for } \quad X _ {\mathrm{r}} <   X _ {\mathrm{c}} \\ \psi = X _ {\mathrm{r}} \left(\frac {X _ {\mathrm{r}} - X _ {\mathrm{c}}}{1 - X _ {\mathrm{c}}}\right) ^ {b} & \text { for } \quad X _ {\mathrm{r}} > X _ {\mathrm{c}} \end{array}
$$

其中，对于三维网络，$b = 0 . 4$；${ } ^ { 2 4 2 } \ X _ { \mathrm { r } }$为[[纤维素纳米晶|CNs]]的体积分数，X为达到几何逾渗所需的临界逾渗体积分数（逾渗阈值）。为计算$\dot { X _ { \mathrm { c } } } ,$，Favier等$\mathrm { a l . } ^ { 2 4 9 }$利用针对圆柱形粒子的统计逾渗理论并考虑其[[长径比]]，建立了如下关系式：$\bar { X _ { \mathrm { c } } } = \bar { 0 . 7 } / A$其中A为[[纤维素纳米晶体|CNs]]的长径比，即其长度与宽度之比（L/w）。

在温度足够高、可假定聚合物基体刚度为零$( G _ { s } ^ { \bar { \prime } } \approx 0 )$的条件下，计算得到的复合材料刚度仅为逾渗填料网络与逾渗填料相体积分数的结果：

$$
G _ {\mathrm{c}} ^ {\prime} = \psi G _ {r} ^ {\prime}
$$

该模型在Favier体系中给出了令人满意的结果，并且最近在[[纳米复合材料]]中，预测的逾渗模型值与实验数据之间获得了极好的相关性，如图$1 9 . ^ { 2 2 4 }$所示。关于[[纤维素纳米晶|CN]]基复合材料中这一逾渗现象的详细信息已由Aziz Samir等人报道。<sup>250</sup>

复合材料的[[力学性能]]主要受确保或干扰逾渗网络形成的因素影响，例如[[纤维素纳米晶|CNs]]的尺寸及其界面相互作用（[[纤维素纳米晶体|CNs]]之间或与基体之间）。因此，可以通过改变[[纳米颗粒]]的表面化学来调控这一逾渗网络。此外，已有报道表明加工方法也会影响力学性能。

## 6.2.1. [[纤维素纳米晶|CNs]]的形貌与尺寸

由于[[纤维素纳米晶|CNs]]的几何[[长径比]]决定逾渗阈值，因此尺寸对[[力学性能]]具有重要影响。显然，高长径比的[[纤维素纳米晶体|CNs]]具有最佳增强效果，因为达到逾渗所需用量更少。但后一结论取决于[[纤维素纤维]]的来源以及CN制备过程中的水解条件，如前文所述（见下文）。

## 6.2.2. 加工方法

诸如加工速率和体系粘度等条件，会影响逾渗结构被胶结或承受外加应力的能力。[[溶胶-凝胶加工]]方法似乎能提供最高的[[力学性能]]，因为在加入聚合物溶液之前，逾渗网络已经形成，并且[[纤维素纳米晶|CN]]接触点处产生了强相互作用。[[浇铸-蒸发]]技术在力学性能方面也能给出令人满意的结果。在这类缓慢的加工过程中，[[纤维素纳米晶体|CN]]有足够的时间相互连接并形成逾渗网络。这种连接能力还与布朗运动以及悬浮液中CN的重排有关，而这一过程发生在体系粘度直到过程结束都保持较低的情况下。相比之下，热压或挤出过程中出现的高聚合物熔体粘度会强烈限制随机运动，从而阻碍CN之间的相互连接。挤出或成型过程中由诱导剪切应力引起的CN可能取向也会影响网络的形成。Hajji等<sup>251</sup>研究了加工方法对CN基[[纳米复合材料]]力学性能的影响，并按增强效率从低到高对其进行了分类：挤出 < 热压 < 蒸发。

## 6.2.3. 界面相互作用

[[力学性能|机械性能]]增强的起源在于由[[氢键]]连接的[[纤维素纳米晶|CN]]之间形成的刚性网络。任何因素，如聚合物基体的性质和[[纤维素纳米晶体|CN]]的表面能，都会影响网络的形成，并将对所得复合材料的机械性能产生重大影响。必须达成所有可能发生的竞争（如基体/CN和CN/CN相互作用）之间的折中相互作用，才能获得最佳的机械性能。<sup>252</sup> 如果CN与基体之间的相容性非常差，CN通常会被从基体中剥离出来，导致机械性能灾难性地下降。令人惊讶的是，CN与主体聚合物之间非常好的相容性倾向于降低复合材料的弹性模量，尤其是在通过浇铸法制备[[纳米复合材料]]时。这种行为很可能是由于CN的迁移性受限，它们倾向于与聚合物链强烈相互作用，而不是彼此延伸以相互连接并形成网络。这种行为的一个例子已经在用棉籽短绒中提取的CN增强的[[甘油]]增塑[[淀粉]]中得到了明确证实。<sup>207</sup> 然而，在聚合物基体中，当通过[[溶胶-凝胶加工]]方法在加入聚合物溶液之前就形成逾渗网络时，这种情况似乎不会发生。另一方面，强烈的基体/CN相互作用似乎会增强非线性机械性能，尤其是当CN用长链分子（如表面活性剂、<sup>135,153</sup> [[N-十八烷基异氰酸酯]]、<sup>92</sup> 脂肪酸<sup>131</sup> 或聚合物链<sup>87,98</sup>）进行[[化学改性]]时的极限应变。事实上，例如当CN被接枝上高分子量[[聚己内酯|PCL]]，然后加入PCL基体中时，与填充未改性$\mathrm { C N s . ^ { 8 7 } }$的对照样品相比，最终纳米复合材料显示出更低的模量，但断裂应变显著更高。这种行为清楚地反映了受限的CN/CN相互作用导致模量下降，以及由于接枝链与基体之间通过链缠结和可能的[[共结晶]]形成的逾渗网络所产生的高CN/基体相容性。类似地，[[Cao]]等人<sup>98</sup>报道了在基于完全无定形聚合物（即[[聚氨酯]]）的纳米复合材料中发生了链缠结和共[[结晶]]，其中CN在同一锅法过程中被接枝上了相同的聚合物。

## 6.3. [[纤维素纳米晶|CN]]基复合材料的[[热性能]]

令人惊讶的是，该领域的大多数研究报告称，将[[纤维素纳米晶|CN]]添加到聚合物基体中似乎不会影响玻璃-橡胶转变温度，$T _ { \mathrm { g } } ,$，无论主体聚合物的性质、[[纤维素纳米晶体|CN]]的来源或加工条件如何。<sup>250,253</sup> 这一观察结果似乎与CN具有高[[BET|比表面积]]的事实相矛盾。文献中报道了少数情况，其中将CN作为填料添加到[[纳米复合材料]]中影响了$T _ { \mathrm { g } } .$。这种效应尤其在湿敏体系中表现出来，<sup>97</sup>与水分的增塑效应有关，并且还与CN与基体之间的强烈相互作用有关。

就半[[结晶]]聚合物而言，已有报道指出，未改性 [[纤维素纳米晶|CN]] 的加入对[[纳米复合材料]]的熔融温度 $( T _ { \mathrm { m } } )$ 没有影响，正如在增塑[[淀粉]]、<sup>107,254</sup> 聚环氧乙烷、<sup>195,255</sup> [[醋酸丁酸纤维素]]、<sup>104,150</sup> [[聚己内酯]]增强聚合物<sup>81,87</sup> 等体系中所显示的那样。然而，当在纳米复合材料中使用[[化学改性]] [[纤维素纳米晶体|CN]] 时，观察到 $\dot { T _ { \mathrm { m } } }$ 发生了变化。据报道，化学改性 CN 与基体之间的强相互作用是这一 $T _ { \mathrm { m } }$ 变化的来源。此外，CN 可以在半结晶聚合物中充当成核剂，从而显著提高所得纳米复合材料的[[结晶度]]。<sup>87,135</sup> 这种效应主要受 CN 与基体相容性的支配，而相容性又取决于表面化学因素。在 CN 增强纳米复合材料中已报道了横晶现象。<sup>256</sup> 最近，[[Cao]] 等人<sup>98</sup> 研究了将化学改性 CN（接枝与基体相同的聚合物）作为填料用于完全无定形[[聚氨酯]]的情况。他们观察到部分结晶，以及纳米复合材料从类弹性体材料向类热塑性材料的转变。这种不寻常的行为与接枝链和聚合物基体链之间发生的链缠结有关。

## 7. 结论与展望

过去几年里，[[纤维素纳米晶体]]所激发的研究广度、多样性和丰富程度令人惊叹，但在当前关注生物质和生物能源的氛围下，这并非完全出乎意料。本综述试图为迄今为止所取得的引人入胜的科学与工程发现和进展提供一个广阔视野，以期激发人们对其内在吸引人特性的更大兴趣。这些非凡的纳米尺度实体适用于大量化学转化，因此已被加以操控，提供了一系列丰富的新材料和可供进一步转化的平台。例如，它们的多元醇特性使其能够锚定大量非天然化学官能团，从而调节其亲水/亲脂平衡，改变其聚集和层级组织，并赋予光学、电学或磁学可调性。[[纤维素纳米晶]]体在材料应用方面的总体范围几乎无限；此外，控制其生物合成途径（例如控制[[结晶度]]）的可能性，为鼓励将其用作生物能源技术中便捷的能量资源打开了新的窗口。目前，该领域尚处于起步阶段，为化学、生物、物理和工程学界提供了几乎无穷无尽的新进展和发现机会。
