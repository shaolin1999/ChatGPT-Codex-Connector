# 通过[[水凝胶|溶剂化水凝胶]]的结构解析预测其[[流变性能]]

在线发表日期：2026年3月11日

[[Nathan D. Rosenmann]]  <sup>1</sup>，[[Lauren M. Irie]]  <sup>1</sup>，[[Joanna Korpanty]]<sup>2</sup>，[[Eric W. Roth]]  <sup>3</sup>，[[Reiner Bleher]]  <sup>1,3</sup>，[[Nehal Nupnar]]  <sup>4</sup>，[[Kathleen Wood]]<sup>5</sup>，[[Yu Chen]]  <sup>2</sup>，[[Brent S. Sumerlin]]<sup>6</sup>，[[Steven J. Weigand]]  <sup>7</sup>，[[Michael J. A. Hore]]  <sup>4</sup>，[[Jitendra P. Mata]]  <sup>5,8</sup> & [[Nathan C. Gianneschi]]  <sup>1,2,9</sup>

[[水凝胶]]是一类广泛应用的材料，其用途涵盖[[药物递送系统]]、[[隐形眼镜]]和[[组织工程支架]]等领域。然而，要观察其预测宏观性能所必需的[[纳米尺度溶液相结构]]，往往需要对体系施加相当大的扰动。尽管研究表明，作为典型水凝胶材料的[[甲基纤维素]]可以用[[半柔性生物聚合物网络模型]]来描述，但在[[流变性能]]随浓度变化的预测以及[[高阶结构特征]]的观测方面，仍存在明显的不一致之处。本文通过[[液相透射电子显微镜]]以高时空分辨率对溶剂化水凝胶进行成像，从而避免[[脱溶剂化]]和[[剪切伪影]]。结合散射和[[SEM|扫描电子显微镜]]的佐证，我们观察到甲基[[纤维素]]水凝胶形成了具有[[持续长度|高持续长度]]和[[原纤维束|微米尺度原纤维束]]的网络，并以[[层级组装]]方式排列，从而能够更准确地预测宏观流变行为。此外，在[[羟丙基甲基纤维素]]和[[羟丙基纤维素]]中也观察到了网络结构。这些跨多个长度尺度的观测结果使我们能够更清晰地理解纳米尺度结构如何影响微尺度结构及宏观行为，有助于建立更准确的水凝胶材料[[结构-性能关系|结构–性能关系]]。

在[[纤维素衍生物]]中表现出[[低临界溶解温度]]（LCST）行为的[[多糖]]已被用作[[化妆品]]、[[食品包装]]、[[组织培养]]以及多种[[制药应用]]中的添加剂<sup>1–4</sup>。尽管用途广泛，但由多糖形成的[[水凝胶]]网络结构及其对性能的影响仍存在争议<sup>5</sup>。由于其在低[[聚合物浓度]]下具有高黏度，并在生物和制药领域得到应用，在高于LCST时发生凝胶转变的多糖中，有两种聚合物已成为研究重点：[[甲基纤维素]]（MC）和[[羟丙基甲基纤维素]]（HPMC）<sup>1,4,6–13</sup>。对加热MC溶液的[[流变学]]研究表明，稀MC水凝胶表现出的[[储能模量]]高于[[半柔性聚合物凝胶]]的预期值<sup>10,11,14</sup>。

为了阐明这一观察结果的结构起源，研究重点放在了对快速[[玻璃化]]并加热的 [[甲基纤维素|MC]] 凝胶进行[[低温透射电子显微镜]]（[[冷冻透射电子显微镜|cryo-TEM]]）分析上。这些实验将 MC [[水凝胶]]描述为由高度柔韧的 15–20 nm [[原纤维]]组成，这些原[[纤维组装]]成随机互连的网络<sup>7</sup>。后来对 [[羟丙基甲基纤维素|HPMC]] 凝胶也进行了类似观察，尽管 [[冷冻透射电镜|cryo-TEM]] 分析指向一种互连程度较低的网络，该网络由直径相似但长度更短的高度柔韧原纤维组成<sup>6</sup>。然而，对热敏材料进行 cryo-[[透射电子显微镜|TEM]] 研究本身存在困难，因为在玻璃化之前无法精确控制温度，并且在吸干步骤中的剪切会导致网络破坏<sup>8,15</sup>。基于这些 cryo-TEM 发现以及[[体相散射]]研究结果，MC 水凝胶被描述为由柔韧的纳米级原纤维组装成疏松的随机网络，且没有进一步的[[层级组装|分级结构]]<sup>7,10,11</sup>。

[[流变学]]研究已确认，[[甲基纤维素|MC]] 与其他[[原纤维]]凝胶（包括组织和细胞外基质）一样，遵循[[半柔性生物聚合物网络理论模型]]，该模型指出[[储能模量]]（G′）与浓度（c）的[[标度关系]]为 $c ^ { 2 . 5 } \left( \mathrm { r e f s . 1 6 , 1 7 } \right)$。然而，大量流变学研究报道的[[标度因子]]低至 c<sup>1.3</sup>，高至 c<sup>3</sup>，导致储能模量与预测值相差一个数量级<sup>1,9,18</sup>。此外，使用[[光散射]]以及超小角和中子小角散射（[[USANS]] 和 [[SANS]]）的研究表明，MC 网络包含 1–5 µm 的“富原纤维”畴<sup>8</sup>。这些发现表明，凝胶中存在着会显著影响 MC [[流变性能]]的[[层级组装|分级结构]]，而这些结构此前一直被忽视<sup>8</sup>。鉴于[[原纤维水凝胶]]的[[力学性能]]高度依赖于组成原纤维的柔韧性、直径和排列方式，以最小的样品制备伪影观察天然[[纤维素]]原纤维网络结构对于预测和调控流变性能至关重要<sup>17,19,20</sup>。

在本研究中，我们利用[[变温液相透射电子显微镜|变温（VT）液相透射电子显微镜]]（[[液相透射电子显微镜|VT-LCTEM]]）来阐明 [[甲基纤维素|MC]] [[水凝胶]]在溶液相中受热触发的形成过程和形貌<sup>15,21–25</sup>。这些研究与[[变温小角散射|溶液相 VT 小角散射]]测量相互印证，表明 MC 凝胶由微米尺度的[[原纤维束]]组成，其[[持久长度|持续长度]] $( l _ { \mathrm { p } } { \approx } 3 . 5 \mu \mathrm { m } )$ 高于此前通过 [[SANS]] 确定或可由 [[低温透射电子显微镜|cryo-TEM]] 观察到的单个[[原纤维]] $( l _ { \mathrm { p } } { \approx } 3 0$ nm）<sup>9</sup>。在其他基于[[多糖]]的水凝胶中也观察到了类似结果，这为理解这些材料的一般[[层级组装|分级结构]]提供了见解。简言之，本研究以高时空分辨率对溶胀态原纤维网络的形貌、组装和形成过程提供了有价值的认识，揭示了此前未被考虑的结构分级，并将该结构与所观察到的[[流变性能]]联系起来。

## 通过 [[低温透射电子显微镜|cryo-TEM]]、[[SAXS]] 和[[多糖]]凝胶[[流变学]]确认先前的观察结果

[[低温透射电子显微镜]]（[[冷冻透射电子显微镜|cryo-TEM]]）、[[小角X射线散射|小角 X 射线散射]]（[[SAXS]]）和[[流变学]]被用于佐证此前文献中对纤维状 [[甲基纤维素|MC]] 凝胶的描述（图 1）。现有假说认为，不同 [[低临界溶解温度|LCST]] [[多糖]]之间[[流变性能|流变学性质]]的差异源于其[[化学结构]]和相对[[官能团]]组成的变化，而这些变化进而影响[[纤维组装]]和[[纤维-纤维相互作用|纤维–纤维相互作用]]（图 1a–e）。[[冷冻透射电镜|cryo-TEM]] 显示 MC [[原纤维]]（聚合物链束）的平均直径为 $1 8 . 6 \pm 2 \ : \mathrm { n m }$ ，与先前的研究结果一致<sup>11,26,27</sup>。类似地，[[羟丙基甲基纤维素|HPMC]] 原纤维的平均直径被测定为 $1 6 . 5 \pm 4 \ : \mathrm { n m }$ ，也与文献值一致<sup>6</sup>。还对[[羟丙基纤维素]]（HPC）凝胶进行了 cryo-[[透射电子显微镜|TEM]] 观察，但由于其对比度较低，难以对直径作出确切判断。尽管如此，cryo-TEM 显微照片显示出 HPC 原纤维片段，其直径约为 4 nm（图 1e，黄色箭头，以及补充表 1）。将加热后的 MC 储备溶液冷却至 $2 5 ^ { \circ } \mathrm { C }$ 并保持 30 min，cryo-TEM 观察到 MC 原纤维网络完全重新溶解，样品外观与未加热对照相同（补充图 1）。接下来，我们通过 [[VT-SAXS]] 考察了 0.2 wt% MC 溶液（图 1f）。在 $2 5 ^ { \circ } \mathrm { C } _ { \iota }$ 时，SAXS 数据如预期那样没有散射特征。在 $6 5 ^ { \circ } \mathrm { C }$ 测得的 SAXS 图样被拟合为具有[[多分散半径的半柔性圆柱模型]]。对于 0.2 wt% MC 溶液，该拟合得到直径为 18.1 nm 的原纤维，[[多分散指数]]为 0.18（图 1d）。冷却样品导致散射特征消失，表明原纤维重新溶解。这些发现与先前报道一致，证实了直径约 20 nm 原纤维的存在<sup>7,10,11,14</sup>。为评估 MC 的[[热触发凝胶化行为]]，我们对不同浓度的 MC 储备溶液进行了流变学测量，浓度范围从 0.2 wt% 到 2.0 wt%（图 1g 和补充图 2）。为了考察流变学性质在不同 LCST 多糖之间的变化情况，我们还对不同浓度的 HPMC 储备溶液（范围从 0.5 wt% 到 2.6 wt%）以及不同浓度的 HPC 储备溶液（范围从 2 wt% 到 20 wt%）进行了相同的流变学测量（分别为补充图 3 和补充图 4）。尽管具有相似的化学结构，所得[[水凝胶]]却表现出不同的流变学性质，并且即便在更高的[[聚合物浓度]]下，通常也无法获得相似的性质（补充图 5）。提高聚合物浓度会导致测得[[储能模量]]增加。此外，随后冷却加热凝胶时生成的[[滞后曲线]]表明凝胶化具有[[热可逆性]]。

## 通过 [[液相透射电子显微镜|VT-LCTEM]] 观察 [[甲基纤维素|MC]] 的凝胶化过程

在通过先前建立的方法确认了[[甲基纤维素|MC]]的热触发组装之后，我们接下来利用[[液相透射电子显微镜|VT-LCTEM]]考察了该凝胶的溶液相行为（图2）。 $\mathbf { A t } 2 5 ^ { \circ } \mathbf { C } ,$ ，未观察到可见结构（图2a及补充图1a）。随后对[[液体池]]进行加热 $\mathsf { t o } 6 5 ^ { \circ } \mathrm { C }$ 以 $5 ^ { \circ } \mathsf { C } \mathsf { m i n } ^ { - 1 }$ 并在成像前保持该温度30分钟。与[[冷冻透射电镜]]观察结果不同的是，变温液相透射电镜揭示了排列整齐的纤维束（图2b）。冷却至 $2 5 ^ { \circ } \mathrm { C }$ 并在不进行成像的情况下保持样品 30 分钟，我们观察到 MC [[原纤维]]沿其[[成核]]主轴进一步聚集在一起，形成了直径为 1–2 µm 的[[原纤维束|纤维状束]]（图 2c–f）。这些观察结果与流变数据中观察到的大滞后现象一致，即原纤维在冷却时并不会立即溶解于溶液中，而是需要较长的冷却时间或更低的温度，才能完全转变回分散的聚合物相<sup>15,23,24</sup>。

我们接下来旨在以高时间分辨率实时研究纤维网络的组装过程（图3）。在加热前，首先在25 °C下对[[液体池]]成像，以确认不存在纤维结构（图3a）。在将液体池保持$6 5 ^ { \circ } \mathrm { C }$后，我们开始对样品连续成像，揭示纤维束在15分钟后[[成核]]（图3b）。在纤维网络内对单根纤维进行了视频观察，显示其在约10分钟内径向向外扩展并沿平行于成核事件的方向伸长（补充视频1；更多显微照片和视频见补充图6–8及补充视频2和3）。随着纤维沿扩展束的轴线生长，网络持续增大。主要生长方向沿纤维中心轴，其次为径向生长，而垂直于这些轴的方向生长最慢。[[液相透射电子显微镜|VT-LCTEM]]显微照片显示，[[甲基纤维素|MC]][[纤维组装]]成直径为1–2 µm的[[原纤维束|纤维状束]]。 向所有方向取向（图 3c,d）。在连续成像之后，于该温度下拍摄最终网络结构的图像（图 3d），并将液体样品室冷却至 $2 5 ^ { \circ } \mathrm { C } .$ 。我们在冷却液体样品室时观察到纤维束边缘[[原纤维]]的部分溶解，其中可见它们从网络上断裂下来时的散开现象（图 3e,f）。我们注意到，在这些时间尺度上并未观察到这些结构的完全溶解，这与本体[[流变学]]数据一致，后者表明溶解速率（回到溶液相）在室温以下大幅增加，而本研究所用的当前 VT-[[LCTEM]] 样品杆无法达到该温度区间（即液体样品室不能被冷却）。这些显微照片表明，[[纤维状束]]由直径为 19.3 ± 3.1 nm 的原纤维组成，与先前的[[冷冻透射电镜]]（[[低温透射电子显微镜|cryo-TEM]]）和 [[SAXS]] 测量以及先前的 [[SANS]] 测量结果一致<sup>7,8,10,11,28</sup>（图 3g）。为确认样品完整性，我们对成像后的液体样品室进行了[[微区傅里叶变换红外光谱]]（[[Micro-FTIR光谱|micro-FTIR]]）分析 芯片（补充图 9）。针对 [[羟丙基甲基纤维素|HPMC]] 尝试了 VT-LCTEM 实验，该材料对[[电子束]]表现出极高的敏感性，即使在低[[电子通量]]条件下也会发生损伤 $( < 0 . 2 \mathrm { e } ^ { - } \mathring { \mathbf { A } } ^ { - 2 } \mathbf { S } ^ { - 1 } ;$ 补充图 10）。

## [[变温小角散射|VT-SANS]] 和 [[小角中子散射|VT-USANS]] 用于确认跨尺度[[分级网络结构|层级网络结构]]

接下来，我们通过 [[变温小角散射|VT-SANS]] 和 [[小角中子散射|VT-USANS]] 研究了 [[甲基纤维素|MC]] 和 [[羟丙基甲基纤维素|HPMC]] [[水凝胶]]。我们还通过 [[VT-SAXS]] 考察了 [[羟丙基纤维素|HPC]] 水凝胶。[[USANS]] 用于考察更大长度尺度（>100 nm）的特征。事实上，先前的 [[超小角中子散射|USANS]] 实验已表明，在 [[低临界溶解温度|LCST]] 以上，MC 溶液含有 1–5 µm 的[[富原纤维畴|富纤丝区域]]，尽管这尚未得到进一步研究<sup>8</sup>。因此，通过利用 [[SANS]] 和 USANS 的完整 q 范围进行[[体相散射]]实验，可以探测从 1 nm 到 20 µm 的长度尺度。

对于所有样品，在$2 5 ^ { \circ } \mathrm { C }$处观测到的散射强度均可忽略。加热至$6 5 ^ { \circ } \mathrm { C }$后，[[甲基纤维素|MC]]和[[羟丙基甲基纤维素|HPMC]]溶液的散射强度显著增加。我们首先将[[SAXS]]和[[SANS]]数据拟合到具有多分散半径的[[多分散半径的半柔性圆柱模型|柔性圆柱模型]]$( \mathsf { F C P R } ) ^ { 6 , 8 , 1 1 }$。1.2 wt% MC样品的结果与先前文献一致，平均直径为21.4 nm（图4a、补充图13和14以及补充表5和$7 ) ^ { 6 , 8 , 1 1 }$<sup>1</sup>。如假设所述，[[USANS]]数据揭示了在[[低临界溶解温度|LCST]]以上存在微尺度结构，其中1.2 wt% MC样品遵循$q ^ { - 1 . 7 7 } ,$的[[幂律]]，幂律指数给出了物体的[[分形维数]]。相比之下，0.2 wt% MC样品遵循$\stackrel { - } { q } ^ { - 2 . 3 5 }$的幂律，这可能表明形成了柔性的、类分形物体。这一观察结果与[[液相透射电子显微镜|VT-LCTEM]]一致，后者显示[[原纤维束|纤维状束]]从中心点辐射并沿随机方向延伸<sup>29</sup>（图3b、d和补充图11和12）。1.2 wt% MC观察到的较低斜率值（斜率1.77）可能表明其结构比0.2 wt%样品观察到的斜率值（斜率2.35）更刚性和细长，并与低q处的柔性圆柱模型一致（参考文献30,31）。在更高浓度下，在$q \approx 0 . 0 0 0 2 7 mathring { \mathbf { A } } ^ { - 1 }$<sup>1</sup>和$q \approx 0 . 0 0 0 1 \mathring { \mathbf { A } } ^ { - 1 }$之间的低q区域出现一个小的相关峰，这表明存在微尺度束<sup>8</sup>（图4a、补充图13和14以及补充表6和7）。为了理解该特征对应的内容，我们通过寻找[[小角中子散射|USANS]]数据中该隆起的最大值来确定分形维数，并发现[[纤维状束]]的直径为3.53 µm。

## [[冷冻干燥]] [[低临界溶解温度|LCST]] [[多糖]]以通过 [[SEM]] 观察层级结构

随后，我们采用了一种互补的成像方法，旨在通过尽量减小对整体网络结构的扰动来保留完全形成的[[水凝胶]]网络结构，并通过[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）对结果进行成像（图 5）。该方法的更多细节见补充图 18，其灵感来源于 [[Zierold]] 及其同事最初开发的方案，他们曾成功制备低温保存组织的切片用于电子显微镜表征，且伪影极少<sup>34,35</sup>。

[[冷冻干燥]][[多糖水凝胶]]的 [[SEM]] 显微照片证实了[[分级网络结构|层级网络结构]]，因为每种凝胶都由脱水[[原纤维束|纤维状束]]组成，这些束的尺寸远大于在[[冷冻透射电镜]]（[[低温透射电子显微镜|cryo-TEM]]）显微照片中观察到的约 20 nm 的[[原纤维|纳米级原纤维]]（图 1c–e 和图 5）。对于 0.2 wt% [[甲基纤维素|MC]] 冷冻干燥[[水凝胶]]，[[扫描电子显微镜|SEM]] 显微照片显示其由约 15 nm 直径的原纤维组成约 300 nm 直径的束（图 5a）。类似地，对于 1.2 wt% MC 冷冻干燥水凝胶，SEM 显微照片显示约 650 nm 直径的束（图 5b）。2.0 wt% [[羟丙基甲基纤维素|HPMC]] 冷冻干燥水凝胶的 SEM 显微照片显示约 107 nm 直径的束（图 5c）。我们注意到，所有这些[[纤维状束]]还具有不同的柔韧性，这一点将在讨论部分进一步阐述。这些 SEM 显微照片表明，尽管 [[冷冻透射电子显微镜|cryo-TEM]] 能够提供对纳米尺度结构的关键认识，但样品制备会引入较差的温度控制和印迹引起的[[剪切力]]，从而对所关注的更大尺度特征造成显著扭曲。相反，冷冻干燥 SEM 制备方法由于样品沉积后立即[[玻璃化]]，限制了热量损失并避免了印迹引起的剪切力，因此有希望用于观察层级（微米尺度）特征。然而，由于冷冻干燥过程需要[[升华]]玻璃态冰，原纤维和水凝胶本身会失去大量水分。通过比较 MC 的[[液相透射电子显微镜|液相 VT-LCTEM]] 显微照片（图 3c）与 0.2 wt% MC 的冷冻干燥 SEM（图 5a）、MC 的 [[变温小角散射|VT-USANS]]（图 4a）与 1.2 wt% 的冷冻干燥 SEM（图 5b）以及 HPMC 的 [[小角中子散射|VT-USANS]]（图 4c）与 2.0 wt% HPMC 的冷冻干燥 SEM（图 5c），我们可以通过考察所观察到的纤维状束直径的减小来估算脱水过程的影响。我们注意到，MC 的纤维状束收缩约 81.5%，而 HPMC 的纤维状束收缩约 94%，这是因为这些凝胶具有更高的水组成<sup>6,8,9</sup>。为了更具普遍性，我们还纳入了 15.0 wt% [[羟丙基纤维素|HPC]] 的冷冻干燥 SEM 数据，我们预测其结构与 HPMC 水凝胶相似（图 5d）。此外，冷冻干燥 SEM 显微照片中观察到的纤维状束直径之间的相对差异，与此前在相同样品的 VT-[[USANS]] 中观察到的趋势一致（分别为图 4a、c，图 5b 和图 5c）。我们注意到，在将 HPC 的冷冻干燥 SEM（图 5d）结果与 [[SAXS]] 数据（图 4d）进行比较时，两种技术提取的直径非常相似。我们将此归因于 [[小角X射线散射|SAXS]] 数据反映了原纤维的溶胀状态，其中 HPC 原纤维由于水含量较低且不存在结构层级而收缩较少。

## 讨论

在[[半柔性生物聚合物网络]]中，[[储能模量]]（G′）通过关系式 $G ^ { \prime } \propto c ^ { 2 . 5 }$ 表现出对浓度（c）的依赖性（参考文献 9、11、16、17）。尽管这一[[标度律]]已在众多先前研究中被引用<sup>1,9,11</sup>，但仍有大量针对 [[甲基纤维素|MC]] 纤维状凝胶的[[流变学]]研究实例表明，$G ^ { \prime }$ 的标度介于 c<sup>1.3</sup> 与 c<sup>3</sup> 之间（参考文献 1、9、18）。虽然这些差异被归因于实验条件，但我们的电子显微镜观察为我们提供了额外的依据，以主张有必要将[[持久长度]] $( l _ { \mathfrak { p } } )$ 重新纳入 $G ^ { \prime }$ 的确定中（补充图 19）。此外，若允许持久长度或浓度的标度指数显著偏离所提出的值，将意味着该系统不再符合同一理论模型。$l _ { \mathsf { p } } ^ { } .$ 通常描述聚合物或聚合物[[原纤维]]的柔性，其中较高的 $l _ { \mathsf { p } }$ 表明更高的刚性程度。尽管流变学数据通常被拟合为 $G ^ { \prime } \propto A c ^ { n }$ ，其中 $n \approx 2 . 5$ ，但原始理论方程可以更准确地用关系式 $G ^ { \prime } \propto l _ { \mathrm { p } } ^ { 2 } c ^ { 2 . 5 }$ 描述（参考文献 16）。由于 $G ^ { \prime } \propto l _ { \mathbf { p } } ^ { 2 }$ ，电子显微照片中观察到的纤维状[[原纤维束]]的刚性将极大影响由此产生的[[流变性能]]，正如该模型所提出的那样。为了估算 $l _ { \mathsf { p } } ,$ ，我们对 [[LCTEM]] 和 [[SEM]] 获得的电子显微数据进行了图像分析，使用的是 [[NeuronJ]]，一个常用于半柔性聚合物和[[淀粉样纤维]]图像分析的 [[ImageJ]] 插件<sup>36</sup>。随后，我们将追踪结果输入开源软件 [[Easyworm]]，以确定 $l _ { \mathsf { p } } .$ 。我们发现 $l _ { \mathsf { p } ( \mathsf { c r y o - T E M } ) } \approx 3 6 6 \mathsf { n m } , l _ { \mathsf { p } ( \mathsf { S E M } ) } \approx 2 . 4 \mu \mathsf { m }$ 和 $l _ { \mathsf { p } ( \mathsf { L C T E M } ) } \approx 3 . 5 \mu \mathsf { m }$ ，其结果与淀粉样纤维和[[纤维素纤维]]的预期相似<sup>37–39</sup>。我们注意到，由于各技术所探测的长度尺度不同，实验确定的 $l _ { \mathsf { p } }$ 在冷冻 [[透射电子显微镜|TEM]] 中对应纳米级原纤维，而在 [[液相透射电子显微镜|LCTEM]] 和[[冷冻干燥]] [[扫描电子显微镜|SEM]] 中对应原纤维束。关于用于测量和计算 $l _ { \mathfrak { p } } ,$ 的方法以及针对 [[羟丙基甲基纤维素|HPMC]] 和 [[羟丙基纤维素|HPC]] 计算得到的各种 $l _ { \mathsf { p } }$ 的详细讨论，可参见补充图 20–26 和补充表 12）。鉴于 LCTEM 能够在高温下观察天然溶剂化 MC 原纤维，我们推测通过 LCTEM 数据图像分析确定的 $l _ { \mathsf { p } }$ 应比由 [[SANS]] 或冷冻 TEM 确定的数值更能反映体相流变行为，因为 [[Small angle neutron scattering|SANS]] 运行在不正确的长度尺度上，而冷冻 TEM 会破坏网络。我们注意到，由于冷冻干燥 SEM 对天然网络的破坏远小于冷冻 TEM，因此通过 SEM 数据图像分析确定的 $l _ { \mathsf { p } }$ 也能提供可靠的估计。因此，我们可以计算 G′，以评估经不同表征技术确定的 $l _ { \mathsf { p } }$ 的重要性，并将所得函数与在 80 °C 下对 MC、HPMC 和 HPC [[水凝胶]]进行的[[振荡剪切流变]]数据进行比较（图 6a）。

## 结论

根据我们的观察，[[甲基纤维素|MC]] [[原纤维]]以及 [[羟丙基甲基纤维素|HPMC]] 和 [[羟丙基纤维素|HPC]] 原纤维的柔韧性低于先前描述，并且其排列方式偏离理论预测<sup>1,6,9,11</sup>。[[LCTEM]] 结果表明，纤维状[[水凝胶]]组装成[[层级组装|分级结构]]，尽管先前模型假设原纤维在[[随机缠结网络]]中表现出较低的[[持久长度|持续长度]]<sup>16,17</sup>。我们通过 [[液相透射电子显微镜|LCTEM]] 观察到原纤维排列成半柔性[[原纤维束|纤维状束]]，而不是 [[低温透射电子显微镜|cryo-TEM]] 所观察到的随机缠结原纤维结构，这表明 MC 原纤维之间的相互作用导致了比先前测量更高的[[持续长度]]<sup>9</sup>。这些持续长度无法通过 [[SANS]] 观察到，因为该技术无法探测大于 400 nm 的特征。事实上，[[Small angle neutron scattering|SANS]] 和 [[冷冻透射电子显微镜|cryo-TEM]] 都偏向于较小的长度尺度，在此尺度下无法充分表征水凝胶网络内部的高阶特征，从而阻碍了从结构特征精确推导[[力学性能]]<sup>19,40–42</sup>。相比之下，通过结合 VT-LCTEM、[[冷冻干燥]] [[SEM]]、[[小角光散射|SALS]] 和 [[变温小角散射|VT-USANS]] 在更长长度尺度上考察这些材料所获得的见解，揭示了这些材料的[[分级网络结构]]（图 6b）。此外，尽管 HPMC 遵循类似的分级组装路径，但其他[[纤维素衍生物]]（如 HPC）并非如此。至关重要的是，这些材料使得能够考察可观测持续长度与[[储能模量]]之间的关系。我们的前提是，如果[[半柔性生物聚合物网络模型]]具有普适性，那么能够直接测量各类凝胶其他物理参数（包括[[网孔尺寸]]）的方法，将有助于更好地直接从结构预测性能。正在进行的工作重点是确定是否能够以类似方式测量其他参数，从而使凝胶的真实物理特性能够用作预测力学性能的输入，为模拟提供信息并指导模型发展。

## Methods

## Sample preparation

Stock solutions of MC at various concentrations were prepared following procedures described previously in the literature<sup>7,10,11</sup> (Fig. 1). In brief, the mass of MC powder was added to half of the desired volume of water that had been heated to $7 0 ^ { \circ } \mathbf { C } .$ The solution was stirred continuously for 10 min without additional heating before the remaining volume and the solution was stirred for an additional 10 min. The solution was then transferred to an ice bath and stirred for an additional \~10 min before being placed in ${ \bf 1 4 ^ { \circ } C }$ refrigerator overnight. Similar procedures were done to prepare stock solutions of HPMC and HPC.

## Cryo-TEM imaging

A bulk solution (15 ml) of 0.2 wt% MC solution was heated in a $6 5 ^ { \circ } \mathrm { C }$ oven for at least 30 min before sample preparation. Copper TEM grids (200 mesh) with a lacey carbon support layer were plasma treated before vitrification using a PELCO easiGlow glow-discharge cleaning system. Four microlitres of gelled 0.2 wt% MC solution was vitrified using a Vitrobot Mark IV (Thermo Fischer Scientific). The Vitrobot was set to a temperature of 60 °C and humidity of 100%. The samples were prepared for vitrification by using a blot force of 1, wait time of 3 s and blot time of 5.5 s. Cryo-TEM experiments were performed on a JEOL 1230 (JEOL) operated at 120 keV. Micrographs were recorded on Gatan Orius 831 bottom-mounted charge-coupled device (CCD) camera (Gatan) using Gatan Digital Micrograph image acquisition software (Roper Technologies). Identical procedures were utilized to vitrify 2.0 wt% HPMC and 15.0 wt% HPC for cryo-TEM experiments performed on a JEOL 1400 (JEOL) operated at 120 keV. Micrographs were recorded on a 2k x 2k Gatan OneView-IS CCD camera (Gatan) using Gatan Digital Micrograph image acquisition software (Roper Technologies).

## X-ray scattering analysis

SAXS experiments were conducted at the 5-ID-D beamline of the Dupont-Northwestern-Dow Collaborative Access Team (DND-CAT) at the Advanced Photon Source at Argonne National Laboratory. Samples of 0.2 wt% and 1.0 wt% MC in water were prepared and loaded into 1.5-mm quartz capillaries for VT-SAXS. The capillaries were then sealed with epoxy to prevent solvent evaporation before data acquisition. Capillaries were loaded into a VT multicapillary holder. The samples were heated to $6 5 ^ { \circ } \mathrm { C }$ at a rate of 1 °C min<sup>−1</sup>, held for 30 min and then cooled to $2 5 ^ { \circ } \mathrm { C }$ at a rate of ${ \bf 1 } ^ { \circ } \mathbf { C }$ min<sup>−1</sup> while acquiring scattering patterns throughout the entire process. Two-dimensional scattering patterns were obtained from 10-s exposure using a Rayonix MX170-HS CCD area detector using a 0.5-s exposure time to X-rays with a wavelength of λ = 1.2398 Å and a sample-to-detector distance of 8.5 m. Similar experiments were performed on solutions of 10.0 wt% HPC, where the solutions were heated to $6 5 ^ { \circ } \mathrm { C }$ at a rate of $1 ^ { \circ } \mathrm { C } \mathsf { m i n } ^ { - 1 }$ and held for 30 min, and then scattering patterns were acquired. The two-dimensional data were azimuthally averaged to yield one-dimensional scattering patterns as intensity versus q. Incoherent background scattering was measured by acquiring scattering patterns for a water-loaded capillary in the absence of MC or HPC. This background scattering was subtracted from the experimental data, after which the resulting scattering patterns were uploaded to SasView. Selected scattering patterns of heated MC and HPC were then fitted using a semiflexible cylinder model with polydisperse radii.

## LCTEM imaging

A Protochips Poseidon Select Heating holder was used to collect LCTEM data. The lines of the holder were prefilled with water in all LCTEM experiments. LCTEM chips with 50-nm-thick, 200 ×50 µm window SiN membranes were cleaned in acetone followed by methanol, dried and subsequently glow discharged in a PELCO easiGlow glow discharge unit for 5 min. Next, 0.5 µl of 0.2 wt% MC solution was pipetted manually onto the bottom chip, and then the liquid cell was assembled with the windows (50 × 200 µm) aligned perpendicularly to result in a 50 × 50 µm

LCTEM viewing area. The lines of the holder were then sealed off without external flow. All TEM alignments, beam settings, electron flux settings and calibrations were conducted before the liquid-cell experiments. VT-LCTEM experiments were performed using a JEM-ARM300F (JEOL) operated at 300 keV. Micrographs were recorded on a $2 \mathsf { k } \times 2 \mathsf { k }$ Gatan OneView-IS CCD camera (Gatan) using Gatan Digital Micrograph image acquisition software (Roper Technologies). The electron flux in LCTEM experiments was calculated from the beam current corresponding to each aperture, measured using a Faraday holder under vacuum, and the diameter of the beam incident on the sample. To limit electron-beam-induced radiolytic damage, three snapshots were taken, each acquired with a flux o $\cdot 0 . 2 \mathrm { e } ^ { - \hat { \mathbf { A } } ^ { - 2 } } \mathbf { S } ^ { - 1 }$ <sup>1</sup>. For video acquisition, Camtasia Studio 2018 was used to record the screen at ten frames per second (TechSmith). To induce gelation of MC, the liquid cell was heated to 65 °C at a rate of 5 °C min<sup>−1</sup> and maintained at that temperature.

## Freeze-dried SEM imaging

Bulk solutions (25 ml) of 0.2 wt% MC, 1.2 wt% MC, 2.0 wt% HPMC and 15.0 wt% HPC were heated in an oven held at $6 5 ^ { \circ } \mathrm { C }$ for at least 30 min before sample preparation. Copper TEM grids (200 mesh) with an amorphous carbon support layer were plasma treated before vitrification using a PELCO easiGlow glow-discharge cleaning system. Four microlitres of the gelled solutions were vitrified using a Vitrobot Mark IV (Thermo Fischer Scientific). The Vitrobot was set to a temperature of $6 0 ^ { \circ } \mathrm { C }$ and humidity of 100%. Following vitrification, the samples were taken to the Hitachi HD2300 STEM operated at 200 keV where the sample was heated from $- 1 8 0 ^ { \circ } \mathbf { C } \mathbf { t } \mathbf { o } - 9 0 ^ { \circ } \mathbf { C }$ at a rate o $\mathsf { f } 5 ^ { \circ } \mathsf { C } \mathsf { m i n } ^ { - 1 } \mathsf { t }$ o sublimate the vitreous ice away under high vacuum. Once all the ice was sublimated away, a secondary electron detector was used to confirm the sample’s quality. The secondary electron detector was necessary due to the sample thickness exceeding a couple hundred nanometres. Following imaging, the sample was then heated from $- 9 0 { } ^ { \circ } \mathrm { C }$ to 25 °C at a rate of $5 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 }$ and then taken to be coated with a 5-nm layer of osmium coating. Osmium coating was achieved with an osmium plasma coater using an osmium tetroxide source. The osmium-coated samples were then brought to the Hitachi S-4800 SEM operated at 2 keV and the JEOL JSM-7900FLV SEM operated at 5 keV or 2 keV, where the emission current was varied from 110.6 µA to 63.2 µA, depending on the sensitivity of the gel to the electron beam.

## Neutron scattering and analysis

USANS and SANS experiments were performed on the Kookaburra and Quokka beamlines, respectively, at the Australian Center for Neutron Scattering at the Australian Nuclear Science and Technology Organization<sup>43,44</sup>. USANS measurements were performed over a q range of $\bar { 3 } . 5 \times 1 0 ^ { - 5 } \mathring { \mathsf { A } } ^ { - 1 } \mathsf { t o } 0 . 0 0 8 \mathring { \mathsf { A } } ^ { - 1 }$ , using a long wavelength of 4.74 Å (high flux mode). SANS measurements were performed using three configurations, with sample to detector distances of 20 m, 12 m and 1.3 m. To achieve the lowest q, focusing lenses with a neutron wavelength of 8.1 Å were used when the detector was at 20 m. At 12 m and 1.3 m, 5 Å neutrons were used. $\mathbf { A t } 2 5 ^ { \circ } \mathbf { C }$ , no useful scattering was collected using the lowest q configuration as the structures do not scatter at the larger lengthscales, and only the 12-m and 1.3-m data were merged into a single data file. At higher temperatures, data from all three configurations were merged. All polysaccharide solutions, 0.2 wt% MC, 1.2 wt% MC and 2.0 wt% HPMC in ${ \bf D } _ { 2 } { \bf O } ,$ , were loaded into 2-mm demountable cells and analysed at $2 5 ^ { \circ } \mathrm { C }$ and $6 5 ^ { \circ } \mathrm { C } ,$ , then again at $2 5 ^ { \circ } \mathrm { C } .$ Empty and ${ \bf D } _ { 2 } { \bf O } \cdot$ -filled cells were used for background scattering correction. USANS raw data were reduced and normalized to an absolute scale (slit-smeared data) using an in-house developed Python script in Gumtree software<sup>43</sup>. SANS data were reduced using standard procedures as described previously<sup>44,45</sup>. Desmeared USANS data were then merged with SANS data. Scattering patterns were then uploaded to SasView, and selected patterns were fitted to the power law and the semiflexible cylinder model with polydisperse radii.

## Light scattering analysis

SALS measurements were performed on an in-house instrument (Case Western Reserve University)<sup>46</sup>. MC solutions (0.2 wt% polymer) were degassed in a low-pressure chamber for 1 h to remove any potential gas bubbles, loaded into a quartz cuvette and heated to $6 5 ^ { \circ } \mathrm { C }$ in a temperature-controlled cuvette holder (PIKE Technologies) The solutions were held at $6 5 ^ { \circ } \mathrm { C }$ for 20 min before SALS was performed. The 1.2 wt% MC solutions were not measured by SALS owing to multiple scattering events from the translucent solution that preclude quantitative analysis. The cuvette was placed a distance $l _ { 1 } = 1 5$ mm from a focusing lens and illuminated with a $1 \lambda = 6 2 5$ nm laser. Scattered light was collected by the focusing lens, passed through a beam stop aperture and focused on a second lens a distance $l _ { 2 } = 7 0$ mm from the beam stop. Scattered light intensity was recorded using a CMOS camera (Basler acA800-510 µm). The scattering pattern was azimuthally averaged and corrected for background scattering from the cuvette and pure solvent. The scattering vector Q was calculated as $\mathbf { Q } = \left( 4 \pi n / \lambda \right)$ sin(θ/2), where n = 1.33 is the refractive index of the solvent. The scattering angle was determined from the pixel position on the CMOS detector p , the effective focal length of the second lens $( q _ { 2 } = 2 5 . 4 3 \ : \mathrm { m m } )$ $l _ { 1 }$ and l as $\theta { = } p _ { i } l _ { 2 } / q _ { 2 } l _ { 1 }$ . SALS data were fitted to an empirical Guinier– Porod model, which is a shape-independent model that provides the fractal dimension and average radius of gyration $( R _ { \mathrm { g } } )$ for small-angle scattering measurements<sup>47</sup>.

## Micro-FTIR spectroscopy

Following LCTEM imaging, the liquid cells were disassembled, and the separated chips were allowed to dry completely. Micro-FTIR was performed on dried chips using a Thermo Nicolet Nexus 870 Micro-FTIR Spectrometer. A total of 500 scans were collected a $2 5 ^ { \circ } \mathrm { C }$ on the dried sample on the 50 × 200 µm window SiN membranes of the separated liquid-cell chips over the 4,000 to 800 cm<sup>−1</sup> range with a 2-cm<sup>−1</sup> resolution using a 532-nm laser excitation source.

## Oscillatory shear rheology

Rheology experiments were performed on bulk stock polysaccharide solutions (20 ml) using the concentric cylinder configuration (15 mm, gap 1 mm, immersed height 42 mm) on an Anton Paar MCR302 rheometer (Anton Paar) with Peltier temperature control. To prevent dehydration of the solutions, a thin layer of silicon oil (Sigma-Aldrich, density $0 . 9 6 7 \mathrm { g } \mathrm { m l } ^ { - 1 }$ , boiling point ${ \bf \Sigma } { \bf > } { \bf 1 4 0 ^ { \circ } C ) }$ was floated over the top of the solution. The storage modulus (G′) and loss modulus (G″) were measured as functions of temperature. These temperature ramp tests were conducted by performing temperature sweeps at a heating or cooling rate of 1 °C min<sup>−1</sup> in strain-controlled mode with a strain amplitude of 5% and a frequency of 1 rad s<sup>−1</sup>. We note that a strain of 5% is within the linear regime of the solutions being studied here. All gel points are reported during the heating of the solutions and were measured at least three times for each reported concentration.
