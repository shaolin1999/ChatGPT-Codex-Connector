[[纤维素|天然植物纤维素]]具有固有的[[超分子结构]]。因此，可将其分离为不同类型的[[纳米纤维素]]，并将其用作[[纳米材料|可再生纳米材料]]的构筑单元。纤维素的结构还允许对其进行[[纤维素端基修饰|端部修饰]]，即仅在纤维素链或纳米纤维素颗粒的一端发生化学反应。端部修饰所需的前提条件数十年前就已为人所知。然而，由于这一问题涉及严峻的合成与分析挑战，包括[[还原性端基|纤维素还原端]]不利的[[反应活性]]以及新引入[[官能团]]的低丰度，直至最近才出现了不同的反应方法。本综述全面阐述了与[[纤维素纳米晶]]端部修饰相关的科学基础与挑战。此外，我们还介绍了如何将纤维素纳米晶端部的[[化学修饰]]应用于[[定向组装]]，从而为构建新材料提供诸多可能性，例如[[响应性液晶模板]]以及具有定制相互作用的[[复合材料]]。

## 1. 引言

对[[蛋白质]]、[[脱氧核糖核酸|DNA]]/[[核糖核酸|RNA]] 和[[脂质]]等天然化合物进行合成剪裁，为[[材料科学]]开辟了广阔的新研究与技术发展领域。<sup>[1]</sup> 通过[[化学修饰]]来更好地控制天然单元的组装，尤其是纳米尺度上的组装，已在许多情况下被证明是一种可行的方法。<sup>[2]</sup> 对于[[淀粉]]和[[纤维素]]等天然来源的[[碳水化合物聚合物]]，传统的合成工具与目标则一直处于相对粗放的框架之内。种类繁多的工业淀粉和[[纤维素衍生物]]正被用作[[热塑性塑料]]、[[黏度调节剂]]和[[黏结剂]]等。<sup>[3–6]</sup>

与大规模生产形成对照的是，本世纪见证了源自[[多糖|天然多糖]]的纳米尺度物体的兴起。<sup>[7,</sup> <sup>8]</sup> 这一发展在[[纤维素]]领域尤为显著，纤维素被誉为一类新型[[纳米材料]]，即[[纳米纤维素]]的来源。<sup>[9,10]</sup> 事实上，过去十年间，从[[植物纤维|植物基纤维]]中[[自上而下法|自上而下]]分离[[纤维素纳米纤维]]（CNFs）<sup>[11]</sup> 和[[纤维素纳米晶|纤维素纳米晶体]]（[[纤维素纳米晶体|CNCs]]）<sup>[14]</sup> 的技术取得了巨大进展，全球已涌现出多个半工业化生产基地（见支持信息（SI），表 S1）。同样，工业界<sup>[15]</sup> 和学术界<sup>[10]</sup> 均已探索纳米纤维素的应用。尽管 CNFs 和 CNCs 的组装已得到研究，并被用于复杂材料的构筑，<sup>[10]</sup> 但通过特定改性实现[[定向组装]]的途径仍然有限。控制纳米纤维素[[自组装]]的一种可能方式，是在其表面进行不具[[拓扑化学]]特异性的小分子或大分子修饰，以影响它们之间的相互作用。<sup>[16–19]</sup> 近年来，纳米纤维素研究中出现了利用纤维素链方向性的趋势。[[端基功能化|端基改性]]利用了纤维素的[[还原性端基|还原端]]单元，以及[[纤维素I|天然纤维素 I]] 晶体中[[分子链平行排列|分子链的平行排列]]，<sup>[20]</sup> 这种排列决定了所有[[还原端基]]（REGs）均位于 CNC 或 CNF 的同一末端（图 1）。

由于[[变旋作用|变旋现象]]——[[Lowry]]<sup>[21]</sup> 于 20 世纪初发现的一种现象——[[葡萄糖]]常见的[[半缩醛]]环状形式与开链醛形式处于平衡状态（图 1d）。[[端基功能化|端基改性]]即利用具有[[反应活性]]的[[醛基]]，在[[纤维素]]链末端引入[[官能团|官能基团]]。尤其对于[[纳米纤维素]]，这种[[纤维素端基修饰|端基改性]]能够利用颗粒的不对称性，实现奇特的组装结构。<sup>[22]</sup> 端基改性的 [[纤维素纳米晶|CNCs]] 可被视为类似于[[表面活性剂]]或[[嵌段共聚物]]的 [[Janus纳米颗粒|Janus 型纳米颗粒]]。

## 2. [[纳米纤维素|纳米纤维素材料]]研究的现状

“[[纳米纤维素]]”一词通常指通过[[自上而下法|自上而下]]的方法从[[植物纤维]]中分离得到的[[各向异性]]一维[[纤维素]]物体，其中除纤维素以外的大部分组分均被去除。此外，某些细菌也能通过[[自下而上法|自下而上]]的方式合成纳米纤维素。这类纳米纤维素因纯度高而尤其适用于[[生物医学]]领域。<sup>[25]</sup>

[[植物纤维]]由[[纤维素微原纤维]]构成：这些细长的[[半结晶结构|半结晶]]丝状结构具有纳米级直径，长度可达数微米（图 1a）。<sup>[26,27]</sup> 分离这些微原纤维即可得到 [[纤维素纳米纤维|CNFs]]（图 1a,c）。这一过程通过机械力使纤维解体来实现，并辅以适当的预处理，例如 [[TEMPO介导氧化|TEMPO 介导的氧化]]或[[酶处理|纤维素特异性酶处理]]。<sup>[28,</sup> <sup>29]</sup> 另一方面，如果使用[[酸水解|强酸水解]][[纤维素微原纤]]维的[[非晶区|非结晶区域]]，纤维便会分解为 [[纤维素纳米晶|CNCs]]（图 1a,b）。<sup>[14,24]</sup> 这些刚性棒状结晶[[纤维素]]的典型尺寸为 50–350 nm × 5–20 nm（长度 × 宽度）。<sup>[30]</sup>

在几乎所有领域的基础研究中，[[纤维素纳米晶|CNCs]] 都是比 [[纤维素纳米纤维|CNFs]] 更受关注的研究对象。由于长度较大且具有柔性，CNFs 在相对较低的浓度（通常为 0.5–1.5 wt %）下便会形成[[凝胶]]。<sup>[31,32]</sup> [[纤维素纳米晶体|CNCs]] 则通常在较高浓度（约 5–10 wt %）下形成[[手性向列型液晶]]（[[液晶|LCs]]）。<sup>[33]</sup> CNCs 形成特定的手性向列型 LCs 的倾向于 1992 年被发现，<sup>[34]</sup> 至今仍是 CNC 基材料的主要研究方向之一。<sup>[35–38]</sup>

在应用方面，[[纤维素纳米纤维|CNFs]] 已被设想用作[[复合材料]]中的增强组分<sup>[39]</sup>，以及单独用于构建称为[[纳米纸]]的[[非织造网络]]。<sup>[40]</sup> 另一个主要应用方向是[[水凝胶]]基材料，<sup>[31]</sup> 尤其是在[[生物医学]]领域。<sup>[41]</sup> 另一方面，[[纤维素纳米晶|CNCs]] 已用于高端应用，包括[[手性模板]]<sup>[36,42,</sup> <sup>43]</sup>和[[刺激响应材料]]。<sup>[44–47]</sup> 这种区分绝非严格界限，而是源于其固有性质。[[纤维素纳米晶体|CNCs]] 的化学特征和形貌均更为明确，能够形成稳定、具有流动性的[[水分散体]]，而 CNFs 则更不均一，并且通常还含有其他植物源[[多糖]]。因此，CNCs 的物理化学性质通常比 CNFs 的更容易解释。由于 CNCs 的[[凝胶化浓度]]较低且化学组成更均一，其改性领域的发展也比 CNFs 更为成熟。<sup>[17]</sup> 例如，CNCs 常被用作[[接枝聚合]]的基底，通过接枝[[聚合]]可将这些纳米颗粒转变为[[毛状棒状纳米结构|毛状棒结构]]。<sup>[19]</sup> 值得注意的是，已发表的[[纳米纤维素]][[纤维素端基修饰|端部改性]]方法并非大多数，而是全部以 CNCs 为对象。虽然从原理上说，CNFs 也应能够进行类似改性，但至少据我们所知，迄今尚未见相关报道。因此，在当前的研究环境中，CNCs 是精细改性技术的首选基底，也是[[纤维素]]事实上的纳米尺度构筑单元。

## 3. [[纤维素]]结构分析的历史背景

在应用于材料相关研究之前，[[纤维素端基修饰|端基修饰]]已被用于[[纤维素]]结构分析，从而加深了人们对其不同晶型的[[超分子结构]]、[[纤维素生物合成]]及[[酶促降解]]的理解。贯穿整个20世纪的[[XRD|X射线衍射]]研究确立了[[纤维素I|天然纤维素 I]] 晶体的[[分子链平行排列|平行取向]]。<sup>[48–50]</sup> 然而，Hieta 及其同事于1984年开展的[[电子显微镜]]研究首次在一种藻类（[[缬草藻属|Valonia]]）中直观观察到了天然纤维素 I 链的平行取向；他们先用 [[亚氯酸钠|NaClO]] [[选择性氧化]][[还原性端基]]（[[还原端基|REGs]]），随后用[[银纳米颗粒]]（Ag<sup>0</sup>NPs）对其进行标记。<sup>[51]</sup> Kuga 和 Brown（1988）利用[[氨基硫脲]]与[[醛基]]的特异性连接，针对[[苎麻]]和[[细菌纤维素]]优化了这一标记方法，使[[银蛋白复合物]]能够以[[拓扑化学]]方式附着，为 Ag<sup>0</sup>NPs 提供[[成核位点]]。<sup>[52]</sup> 该方法有效阐明了纤维素 I 和 $\mathrm { I _ { \{ \} } } ,$ 中固有的平行向上堆积方式，为早期显微研究提供了支持。将[[银染技术]]与[[微衍射倾转电子晶体学|微衍射倾转电子晶体学分析]]以及从[[非还原性端基]]（NREGs）开始的选择性酶促降解相结合，进一步为纤维素生物合成过程中[[纤维素合酶复合物]]的作用提供了证据（图 2 a）。<sup>[20]</sup> Sugiyama 及其同事展示了一个用于电子显微镜观察的[[多糖]] REG 标记的重要实例。<sup>[53,54]</sup> 他们利用[[生物素–链霉亲和素结合]]，将[[金纳米颗粒]]（Au<sup>0</sup>NPs）连接到 REGs 上。通过这种方式，作者得以直观观察到[[纤维素II|纤维素 II]] 晶型的[[分子链反平行排列|反平行特性]]（图 2b）——这是文献中的一项重要成果，因为纤维素 II 的反平行取向数十年来一直引发纤维素研究领域的热烈讨论。

除[[金属纳米颗粒]]外，通过[[还原胺化]]连接的荧光[[邻氨基苯甲酸]]也被用作[[纤维素]] [[还原性端基|REG]] 标记，以研究[[纤维二糖水解酶|还原端特异性纤维二糖水解酶]]的作用。<sup>[55,56]</sup>

大多数用于靶向[[纤维素]] [[还原性端基|REGs]] 的合成策略，均基于利用[[醛基]]反应性的成熟化学方法。

[[纤维素端基修饰|REG 修饰]]机制的效率和选择性已在[[碳水化合物分析]]和[[生物偶联]]中得到广泛验证。然而，[[空间位阻]]和[[变旋]]程度对[[纤维素]] [[还原性端基|REGs]] 的修饰构成了明确的限制。因此，在讨论纤维素端基修饰的材料应用前景之前，我们将详细阐述用于靶向 [[还原端基|REGs]] 的主要机制和反应条件，随后论述[[变旋作用|变旋现象]]。

[[纤维素纳米晶|CNC]] 的[[纤维素端基修饰|端基修饰]]仅通过非[[均相反应|均相]]（分散态）反应进行，即修饰仅限于表面可接近的反应位点。因此，[[纤维素纳米晶体|CNC]] 的表面化学对反应选择性和总体[[转化率]]起着至关重要的作用。在大多数关于 CNC 端基修饰的研究中，CNC 通过 $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ [[水解]]分离获得（见 SI，表 S2），该过程使纳米晶表面部分被带电的[[硫酸]]半酯基团取代 $\left( - \mathrm { O S O _ { 3 } } ^ { - } \right) . ^ { [ 6 3 ] }$ 然而，目前尚无关于硫酸半酯在 CNC 表面优先分布位置的确切分析结果，尽管对经 $\mathrm { H } _ { 3 } \mathrm { P O } _ { 4 }$ 水解所得 CNC 的 NMR 研究已证实，$\mathrm { P O } _ { 4 }$ 酯优先在 C2 和/或 C3 位发生取代。<sup>[64]</sup> 一般而言，表面[[电荷]]有助于 CNC 在水性介质中的胶体稳定，防止聚集。除物理尺寸外，CNC 的表面化学还与其（木质）[[纤维素]]来源有关。即使仅有痕量的表面杂质，$\mathrm { e . g . }$，来自[[半纤维素]]或[[木质素]]的残留物，也会对 [[还原性端基|REG]] 特异性反应产生不利影响，因此必须进行萃取等彻底的表面纯化处理。<sup>[65]</sup>

## 4.2. [[还原胺化]]

[[还原胺化]]（RA）是合成 [[N-糖缀合物]]的首选方法，<sup>[84]</sup>并已成为构建复杂糖类基结构的有力工具，例如以[[多糖]]的 [[还原性端基|REGs]]<sup>[85]</sup>或其他[[羰基]]<sup>[86]</sup>为起点。其化学过程简单，涉及两个易于在水中进行的主要步骤（图 4）：羰基与胺（18 或 28）之间形成[[亚胺]]（3），以及亚胺的[[选择性还原]]，生成稳定的胺（4）。

使用[[氢化物还原剂]]进行的[[直接还原胺化]]主要应用于[[纤维素]] [[还原性端基|REGs]]（表 1），<sup>[87–90]</sup> 通过将[[亚胺]]形成与还原合并于[[一锅法|一锅反应]]中，规避了亚胺可能存在的不稳定性。<sup>[91]</sup> 然而，这种直接方法需要谨慎选择还原剂并精确控制反应条件，因为还原剂对亚胺相对于醛的[[还原选择性]]决定了整体反应的选择性和[[产率]]。<sup>[92]</sup> 作为一种常用还原剂，[[氰基硼氢化钠]]可在 [[pH]] 6–8 下[[选择性还原]]亚胺，<sup>[84]</sup> 但该体系的毒性使其高效性和可控性黯然失色。<sup>[93]</sup> 作为无毒替代品，[[三乙酰氧基硼氢化钠]]（STAB-H）<sup>[94,95]</sup> 和 [[2-甲基吡啶-硼烷]]（2-Pc）<sup>[96,</sup> <sup>97]</sup> 已成功应用于[[碳水化合物]]，可在温和的水相和非水相条件下实现选择性还原。为确定 [[纤维素纳米晶|CNC]] [[还原端基|REGs]] [[还原胺化]]的适宜条件，[[Arcot]] 等人系统比较了 NaBH CN、STAB-H 和 2-Pc 在不同 pH 水溶液中的使用效果。<sup>[87]</sup> 结果表明，三种还原剂均在 pH 9.2 时获得最高[[转化率]]，彼此差异很小，该 pH 对应于胺的 $\mathsf { p } K _ { \mathrm { a } }$。

## 4.4. [[Knoevenagel缩合|Knoevenagel 缩合]]

[[Heise]] 等人最近证明，[[碳酸氢盐]]催化的 [[1,3-二羰基化合物]]与醛在水中的[[缩合反应]]可应用于 [[纤维素纳米晶|CNCs]] 的 [[还原性端基|REGs]]。<sup>[75]</sup> 这种所谓的 [[Knoevenagel缩合|Knoevenagel 缩合]]背后的化学原理已得到充分确立。<sup>[112]</sup> 将其应用于 [[纤维素纳米晶体|CNCs]]，可提供一条温和的水相[[一锅法]]路径，用于制备[[纳米纤维素]] [[C-糖缀合物]]（图 4，7）。在弱碱性条件下进攻 [[还原端基|REG]] 的活性物种是[[烯醇负离子]]，由[[二羰基化合物]]的酸性 α-碳[[去质子化]]产生。初始缩合之后，发生[[脱水反应|脱水]]并伴随[[环化反应|环化]]，生成 [[C-糖苷]]中间体，该中间体最终经历[[逆Claisen羟醛反应|逆 Claisen 羟醛反应]]，形成新的 [[C-糖苷酮]]。<sup>[113]</sup> 应用于[[单糖]]和[[二糖]]时，Knoevenagel 缩合表现出优异的[[产率]]和[[立体选择性]]（例如，[[纤维二糖|D-纤维二糖]]与[[乙酰丙酮]]在 90 8C 下反应 12 h，[[转化率]]为 93 %，产物为 100% [[β-异头体]]）。<sup>[113,114]</sup> 此外，该机理可推广至更复杂的化合物，如 [[C-糖脂]]，<sup>[115]</sup> 或者可在后续改性中选择性地靶向新形成的[[糖苷酮]]。已有研究提出，后一方面对于控制立体选择性尤其有益，例如用于后续的[[芳基肼连接反应]]，<sup>[116]</sup> 同时，糖苷酮固定的闭环构象也有助于防止[[变旋]]。

在与[[葡萄糖]]或[[纤维二糖]]所用条件相近的条件下，<sup>[113]</sup> 使用[[乙酰丙酮]]对 [[纤维素纳米晶|CNC]] [[还原性端基|REGs]] 进行改性，<sup>[75]</sup> 在 80 8C 下反应 48 h 后，[[还原端基|还原端]][[转化率]]最高为 12.5 mol%。与小分子糖相比，[[纤维素纳米晶体|CNC]] REGs 的转化率显著较低，其原因可能在于[[变旋]]以及对高[[结晶度|结晶性]]基底表面进行改性的复杂性。根据[[单糖]]研究所提供的认识，REG 改性的[[反应动力学]]由变旋决定。<sup>[21]</sup> 为了理解这种[[互变异构平衡]]如何影响还原端特异性反应，第 5 节将以经典的单糖研究为例，讨论其原理。

## 5. [[还原性端基|还原端基]]的[[变旋]]

[[半缩醛]]与醛之间的[[互变异构平衡]]通常有利于醛形式。然而，对于[[还原糖]]，当 γ-或 δ-位（C1,C5 或 C1,C4）存在相邻的 OH 基团时，情况就会发生变化。<sup>[117,118]</sup> 因此，开链醛通过[[酸碱催化]]的[[质子转移]]，很容易形成[[五元环]]或[[六元环]]的 α-和 [[β-异头体]]。其中，半缩醛被认为是被动的互变异构形态，<sup>[119,</sup> <sup>120]</sup> 而[[开环反应|开环]]则被认为是[[限速步骤]]。<sup>[121]</sup>

[[单糖]]的[[变旋]]已得到广泛研究，大量研究表明，其速率和[[互变异构体]]组成随糖的结构和溶液条件（即温度、[[pH]] 和溶剂类型）而变化。<sup>[122]</sup>

温度的影响十分明显，主要影响[[变旋动力学]]，这一点已在水<sup>[123]</sup>和水–[[共溶剂]]混合物中得到广泛证实。<sup>[124,125]</sup> 然而，即使在高温水中，游离醛的平衡比例仍然很低（例如，在 80 °C 时，[[葡萄糖]]醛式的比例为 0.02%<sup>[123]</sup>）。此外，温度还会影响水中的[[异头体比例]]，这与 [[α-异头体]]和 [[β-异头体]]相互转化过程中的[[放热反应]]有关。<sup>[125]</sup>

涉及溶剂体系和催化作用时，机理理论与观测结果变得更加复杂。溶剂结构决定了构象的稳定化，例如有利于[[葡萄糖]]的[[吡喃糖|吡喃糖形式]]（在水中）或[[呋喃糖|呋喃糖形式]]（在[[二甲基亚砜]]中）。<sup>[117]</sup> 此外，水或其他[[酸碱催化]]剂的存在决定了[[变旋]]的活化机理。这既可以是[[溶剂催化]]，即水直接参与[[环状过渡态]]的形成，也可以基于催化剂的[[质子转移]]。<sup>[117,</sup> <sup>124,125]</sup> 关于水如何促进变旋，存在多种假说，其中包括 [[Silva]] 等人提出的一个水分子参与[[协同反应]]的机理（图 5）。<sup>[126]</sup> 实验数据表明，在不添加催化剂的情况下，非水[[共溶剂]]浓度的增加会降低变旋速率。<sup>[124,</sup> <sup>125]</sup> 酸碱催化对变旋的总体影响已得到广泛研究，早期贡献包括 [[Lowry]]<sup>[21]</sup> 和 [[Brønsted]]<sup>[127]</sup> 的工作。酸和碱均能有效促进变旋，且其[[催化活性]]随[[酸碱强度]]的增加而提高。研究发现，碱的[[催化效率]]通常高于其[[共轭酸]]。<sup>[122]</sup> 然而，由于电离形成的[[糖负离子]]本身也具有催化活性，研究它们在水溶液中的催化速率较为复杂。<sup>[128]</sup> 苯酚–吡啶混合物在非水介质中的催化作用引出了这样一种假设：有机酸和有机碱通过协同机理同时发挥作用，使质子转移能够在无水条件下进行。<sup>[129]</sup>

除催化效应外，溶液 [[pH]] 还会根据 [[α-异头体]]与 [[β-异头体]]之间的 pK 差异，决定异头体平衡的位置。这种 pH 依赖性已在[[葡萄糖]]（碱性 pH 下偏向 β-异头体）<sup>[130]</sup>及其他醛糖中得到证实。<sup>[131]</sup>

现在，我们如何将关于[[单糖]][[变旋]]的知识应用于[[纤维素]]这样的复杂[[多糖]]？尤其是在非[[均相反应|均相]]反应中，纤维素结晶区域内由[[氢键]]维持的层级有序结构，很可能影响末端以 β-D-(1→4) 键连接的 AGUs 在水中的构象稳定化及水合作用。假设天然纤维素链完全溶剂化，还原性羟基周围水分子的堆积方式可能与其在[[葡萄糖]]周围的排列方式相当，这一点早在 1958 年的研究中就已提出。<sup>[132,</sup> <sup>133]</sup> 只有糖苷键会迫使末端 AGU 相对于相邻单元发生扭曲，使其构象能够在水分子晶格中得到稳定，并与水分子形成氢键。<sup>[133,</sup> <sup>134]</sup> 在结晶纤维素中，分子链堆积成平面片层，<sup>[135]</sup> 且所有羟基，包括 [[还原性端基|REGs]] 的羟基，均参与氢键形成。这一因素可能对[[变旋动力学]]产生显著影响，并使异头中心需要被活化和释放。参与氢键形成是否会影响纤维素 [[还原端基|REGs]] 的整体可及性，目前尚不清楚，仍需对此开展进一步研究。例如，应系统研究水以外的催化剂对变旋的[[催化效率]]。<sup>[129]</sup>

## 6. [[端基功能化|端基改性]]的材料学视角

将[[醛基]]特异性反应机制应用于 [[纤维素纳米晶|CNCs]]，为纳米工程开辟了新途径。尽管以[[拓扑化学]]可控方式对 [[纤维素纳米晶体|CNCs]] 的 [[还原性端基|REGs]] 进行改性的实例仍然有限，现有研究已带来了引人入胜的发现，并为构建新型功能界面铺平了道路。此外，选择性[[端基功能化]]为发展更为成熟的均匀改性提供了一种替代方案，同时保留了纳米晶独特的表面化学特性。因此，本章着重介绍[[纤维素端基修饰|端基改性]]在先进材料应用中的非凡潜力。

## 6.1. 界面工程

Kitaoka 及其同事率先利用[[纤维素]]链固有的[[各向异性]]来设计功能性[[自组装]]单分子层（SAMs）（图 6a）。<sup>[81]</sup> 他们的方法既简单又具有开创性，利用了经[[拓扑化学]][[巯基化]]的纤维素与金基底之间的自发偶联。其中，巯基化通过在 80 % NMMO 溶液中进行 [[氨基硫脲|TSC]] 连接反应来实现。该衍生物与金的偶联使纤维素链发生定向固定，由于采用了拓扑化学巯基化，[[纤维素I|天然纤维素 I]] 晶体中的平行堆积结构得以重现。在后续研究中，该团队从[[碳水化合物]]–细胞相互作用的角度，证明了由纤维素及其甲基衍生物制备的 SAMs 的生物功能性；这种功能性被归因于特定的表面形貌等因素。<sup>[83,</sup> <sup>136]</sup> 此外，巯基化甲基纤维素还赋予金表面热响应润湿特性，这是因为改性纤维素在高于其低临界溶解温度（LCST）的温度下表现出可逆[[凝胶]]化行为。<sup>[82]</sup> 该团队还以含有 TSC 纤维素的新型 NMMO/HAuCl 氧化还原体系为起始体系，建立了糖修饰 Au<sup>0</sup>NPs 的[[一锅法|一锅合成方法]]。<sup>[137]</sup>

Lokanathan 等人首次将[[纤维素]]–金 SAMs 的概念拓展至 [[纤维素纳米晶|CNCs]]，展示了末端[[巯基化]]纳米晶体在金表面的[[定向组装]]（图 6 b）。<sup>[87]</sup> 他们采用[[还原胺化]]这一新的合成方法实现了 [[还原性端基|REG]] 巯基化。利用耗散型石英晶体微天平（[[耗散型石英晶体微天平|QCM-D]]）的表面敏感方法，提供了 S@Au 键具有一定柔性的证据，从而证明了其纤毛仿生行为。在 2014 年的后续工作中，他们进一步完善了末端基团巯基化 [[纤维素纳米晶体|CNCs]] 的合成路线，通过更温和的[[酸性亚氯酸盐氧化]]以及随后的碳二[[亚胺]]催化的 6-氨基-1-己硫醇偶联，成功实现了 [[还原端基|REGs]] 的功能化。<sup>[88]</sup>

除固体界面外，[[还原性端基|REG]] 改性还被用于调控 [[纤维素纳米晶|CNCs]] 在液–液界面上的组装，例如在 Pickering [[乳液]]（PEs）中的组装。事实上，所有胶体尺寸的颗粒都会[[吸附]]到[[油–水界面]]，以使能量最小化。<sup>[138]</sup>“调控”一词是指使亲水性 [[纤维素纳米晶体|CNCs]] 与油相相容——通常通过非选择性表面疏水化实现<sup>[139,</sup> <sup>140]</sup>——从而提高 CNC–界面组装体的稳定性，进而使 CNCs 能够用于油包水（w/o）PEs。在 w/o PEs 领域，Du 等人旨在通过末端特异性偶联硬脂酸 $\left( \mathbf { C } _ { 1 8 } \right)$ 制备两亲性 CNCs，具体采用两步法：1）用肼活化 [[还原端基|REGs]]；2）在 THF 中通过 [[1-乙基-3-(3-二甲氨基丙基)碳二亚胺|EDC]]/[[N-羟基琥珀酰亚胺|NHS]] 偶联，将硬脂酸连接到经肼改性的 REGs 上。<sup>[80]</sup>此外，改性 CNCs 还表现出“按需破乳功能”：在 [[pH]] < 4 时，酸敏感的腙键断裂，释放烷基链，从而触发破乳（图 7）。

Tang 等人采用“[[接枝到法|接枝到]]”（grafting-to）法制备了类似[[表面活性剂]]的两亲性 [[纤维素纳米晶|CNC]]–g-聚苯乙烯纳米颗粒，以增强水包油（o/w）[[乳液]]的稳定性。<sup>[110]</sup>他们以胺封端的聚苯乙烯为起始物，尝试在 DMF 中通过[[还原胺化]]进行[[拓扑化学]]接枝。然而，尚不清楚[[变旋|变旋作用]]是如何被催化的，这表明聚苯乙烯可能[[吸附]]在 [[纤维素纳米晶体|CNC]] 表面，而非与 [[还原性端基|REGs]] [[共价连接]]。

## 6.2. Janus 型胶体

Janus 胶体通常被归类为纳米或微米尺度的颗粒，其表面呈现至少两种截然不同的物理化学性质。这包括例如两亲性<sup>[141]</sup>或偶极性<sup>[142]</sup>胶体以及 Janus 微[[凝胶]]。<sup>[143]</sup>以固体纳米颗粒为起始物，已通过例如 Pickering [[乳液]]实现非对称改性，从而能够开展一系列相选择性化学反应。<sup>[144,</sup> <sup>145]</sup>由于其[[各向异性]]，Janus 型胶体在三维[[自组装]][[纳米结构]]的设计中广受关注。以 [[纤维素纳米晶|CNCs]] 为起始物，已有两种合成 Janus 型纳米棒的主要路线得到报道：1）[[聚合]]物接枝；2）[[生物分子]]偶联。

早在 1979 年关于[[纤维素]]-g-聚苯乙烯共聚物的早期研究中，Taga 和 Inagaki 就已发现，纤维素的 [[还原性端基|REG]] 可作为[[聚合]]物接枝位点。<sup>[146]</sup> 此后，研究者通过将预先制备的聚合物连接到纤维素上（[[接枝到法|接枝到]]法，grafting-to），或将自由基引发剂连接至 [[还原端基|REG]]，从而实现表面引发聚合（接枝自法，grafting-from），实现了纤维素上针对 REG 的特异性聚合物接枝。在这两种情况下，REG 特异性接枝均需要采用第 4 节所讨论的某一种[[醛基]]特异性反应机制。Sipahi-Sag˘lam 等人以 [[纤维素纳米晶|CNC]] 为起始材料，采用了这两种接枝途径。<sup>[77]</sup> 其接枝到法首先通过与 4-[[肼基]]苯甲酸反应活化 REG，随后在 [[1-乙基-3-(3-二甲氨基丙基)碳二亚胺|EDC]] 催化下连接氨基封端的[[聚乙二醇]]链。接枝自法则通过将偶氮引发剂固定于 REG 上实现，随后该引发剂可引发[[拓扑化学]]自由基聚合（FRP）。

自由基[[聚合]]技术已被广泛用于从 [[纤维素纳米晶|CNC]] 表面均匀[[接枝聚合]]物，包括 FRP 和表面引发原子转移自由基聚合（SI-ATRP）。<sup>[19,</sup> <sup>147]</sup> ATRP 是一种可控自由基聚合（CRP）方法，与其他技术相比具有显著优势，例如[[官能团]]耐受性，以及对摩尔质量和聚合物链结构的控制能力。在理想条件下，ATRP 可使聚合物链以线性、时间可控的方式增长。<sup>[148]</sup>

Zoppe 等人开发了一种通用且耐水的方法，通过 SI-ATRP 从经引发剂修饰的 [[纤维素纳米晶|CNC]] [[还原性端基|REG]] 上[[接枝聚合]]物，并将该方法应用于三种不同的[[聚合]]物（温敏性聚(N-异丙基丙烯[[酰胺]])（PNIPAM）、阳离子型聚([甲基丙烯酰氧基乙基]三甲基氯化铵)（PMETAC）和阴离子型聚(4-[[乙烯基]]苯磺酸钠)（PSSNa））。<sup>[103]</sup> 他们首先使用 [[亚氯酸钠|NaClO]] 氧化 [[还原端基|REG]]，随后在水中进行碳二[[亚胺]]催化的酰胺化反应，将 ATRP 引发剂选择性地偶联至 [[纤维素纳米晶体|CNC]] 的 REG。然而，该修饰并未严格局限于 REG，导致聚合物链在纳米晶体表面呈非选择性分布，这一点通过 Cryo-EM 和 Au<sup>0</sup>NP 标记得以可视化（图 8a）。这种“斑块状”分布可能与表面杂质或具有额外[[羰基]]和/或[[羧基]]的氧化位点有关，这再次强调了 CNC 表面化学对反应选择性的重要性（第 4 节）。

在其于 2018 年开展的后续研究中，Zoppe 及其同事研究了斑块状 [[纤维素纳米晶|CNC]]-PNIPAM 接枝物随温度变化的可逆[[自组装]]行为及[[液晶]]性质。<sup>[104]</sup> 通过偏光显微镜观察（图 8b），他们表明，这些 [[纤维素纳米晶体|CNC]] 接枝物在低于 PNIPAM 的 LCST 时形成 LC 相，而在加热至 LCST 以上时，LC 相可逆地消失，表明其转变为各向同性相。有趣的是，在均匀接枝 PNIPAM 的 CNC 中未观察到这种双折射的可逆开启与关闭。基于这些发现，作者预见，斑块状 CNC-[[聚合]]物接枝物可用作 LC 温度开关，例如应用于传感器或智能包装材料。此外，这些发现表明，取决于所[[接枝聚合]]物的性质，端部接枝可显著影响 CNC 在水介质中胆甾相 LC 内的稳定性。<sup>[104]</sup> 当接枝有例如可溶于有机溶剂的聚苯乙烯时，这一效应可能体现为 [[还原性端基|REG]] 功能化 CNC 在非水液体环境中的[[空间位阻]]稳定作用。

Lin 等人提供了明确但属定性的证据，证明端部系接 [[纤维素纳米晶|CNC]] 的端部特异性修饰及其 Janus 型行为。<sup>[22]</sup> 他们采用了与 [[Arcot]] 等人的方法相似的两步路线（端基羧化和[[酰胺]]形成），<sup>[88]</sup> 将两种具有已知 LCST 的热响应性 Jeffamine<sup>U</sup> 聚醚胺连接至 [[纤维素纳米晶体|CNC]] 的 [[还原性端基|REG]]。这使其在高于聚醚胺 LCST 的温度下形成可逆的星形组装体（图 9a），并通过 TEM 成像和小角中子散射（SANS）得到证实。SANS 用于研究 LCST 以上的颗粒组装体，以及 LCST 以下聚醚的伸展链构象。动态光散射（DLS）结果也支持上述结论，表明在温度从 LCST 以下至 LCST 以上可逆循环时，流体动力学直径发生可逆变化（伴有一定滞后）。这两种方法均基于[[纤维素端基修饰|端部修饰]] CNC 的物理化学行为变化，为端部特异性修饰提供了具有指示性但间接的证据。

[[Villares]] 等人采用另一种利用[[生物素–链霉亲和素结合]]的方法，描述了类似的[[星形超分子复合物]]（图 9b）。<sup>[105]</sup> 具有不同[[间隔臂]]长度的[[生物素]]残基以反应性[[酰肼]]（[[生物素酰胺基己酸酰肼|(+)-生物素酰胺基己酸酰肼]]（HC-Biot））或 NH 端基化合物（[[生物素化聚乙二醇胺|biotin-dPEG-NH]]（[[聚乙二醇|PEG]]-Biot））的形式，通过[[拓扑化学反应]]连接到[[被囊动物纤维素纳米晶体|被囊动物 CNCs]]（t-[[纤维素纳米晶|CNCs]]）上。后一种方法依次采用[[酸性亚氯酸盐氧化]]和 [[1-乙基-3-(3-二甲氨基丙基)碳二亚胺|EDC]]/[[N-羟基琥珀酰亚胺|NHS]] [[酰胺]]化。对于接枝 PEG 的生物素连接臂，其与具有四个结合位点的[[链霉亲和素]]结合后，形成了规则的[[星形纤维素纳米晶体–生物素–链霉亲和素组装体|星形 t-CNC-g-生物素–链霉亲和素组装体]]（图 9b）。然而，对于较短的 HC-Biot 连接臂，并未观察到这种几何构型，表明间隔臂长度起着决定性作用。在链霉亲和素包覆的金表面上开展的 [[耗散型石英晶体微天平|QCM-D]] 结合研究支持了这一推测。因此，生物素化 t-[[纤维素纳米晶体|CNCs]] 要垂直结合于[[蛋白质]]包覆的金表面，间隔臂必须达到一定的最小长度（即含有七个重复单元的[[寡聚乙二醇|寡聚乙二醇链]]），但这种结合也受到 t-CNCs 固有特性（例如[[电荷]]、[[长径比]]）的影响。

将[[生物分子]]或（生物）[[活性位点]]连接到[[纤维素]]表面的总体理念已被广泛论述，旨在设计[[生物界面]]、[[药物递送系统]]和[[三维生物杂化纳米结构]]。<sup>[149,150]</sup> [[Karaaslan]] 等人以 [[纤维素纳米晶|CNCs]] 的[[还原性端基|还原端]]为靶点，通过 [[铜催化叠氮–炔点击反应|Cu 催化的叠氮–炔点击反应]]，将一种可形成[[胶束]]的[[蛋白质]]（[[β-酪蛋白|b-酪蛋白]]）连接到[[叠氮基]]改性的 [[纤维素纳米晶体|CNCs]] 上，旨在构建能够[[定向自组装]]的[[不对称多糖–蛋白质杂化纳米颗粒]]。<sup>[79]</sup> 然而，他们观察到的是具有不同排列方式的组装体，并未直接证实[[蛋白质偶联]]仅限于 [[还原端基|REGs]]。

[[Imlimthan]] 等人报道了生物活性[[端基功能化|端基改性]] [[纤维素纳米晶|CNCs]] 的一个应用实例，并在体外和体内评估了其用于诊断剂和治疗剂[[靶向递送]]的潜力。<sup>[109]</sup> 作者通过用[[肼基]]改性的诊断用[[放射性核素]]（[[1,4,7,10-四氮杂环十二烷-1,4,7,10-四乙酸|DOTA]] = 1,4,7,10-四氮杂环十二烷-1,4,7,10-四乙酸）标记 [[还原性端基|REGs]]，开发了[[核成像探针]]，这些探针在[[细胞模型]]中表现出良好的[[生物相容性]]。在后续研究中，作者在 DOTA 标记的基础上进一步引入[[荧光染料]]（[[花菁5|花菁 5]]），从而能够通过[[核成像]]和[[光学成像]]系统研究纳米颗粒在体内的[[生物分布]]。<sup>[151]</sup>

## 6.3. [[纳米复合材料]]

[[纤维素纳米纤维|CNFs]] 和 [[纤维素纳米晶|CNCs]] 均已被广泛研究用作[[聚合物复合材料]]的高性能[[生物基增强材料]]。<sup>[152]</sup> 然而，此类[[纳米复合材料]]在技术应用中的一个关键问题是其工业化制造能力，而这在许多情况下取决于 [[纤维素纳米晶体|CNCs]] 在目标[[聚合]]物中有限的[[分散性]]，尤其是当 CNCs 以干燥形式提供时。<sup>[153]</sup> 与[[乳液]]中的[[油–水界面]]类似，利用能够使[[纳米填料]]与[[聚合物基体]]相容的基团对纳米晶体表面进行改性，已显著改善 CNC 的分布、[[分散稳定性]]以及[[纤维素–聚合物界面相互作用]]，这些均可提升纳米[[复合材料]]的[[力学性能]]。<sup>[154,</sup> <sup>155]</sup> 然而，在许多情况下，[[表面改性]] CNCs 所实现的增强效果低于预期，这可能是因为 CNCs 之间以及 CNCs 与基体之间的相互作用减弱，从而削弱了[[应力传递|应力传递路径]]。<sup>[156]</sup> 使用[[物理吸附]]的[[相容剂]]时也观察到了类似结果。例如，[[Dufresne]] 等人表明，在将 [[聚氧化乙烯吸附纤维素纳米晶体|PEO-CNCs]] 与[[聚合物共混]]之前，先在 CNC 表面[[吸附]][[聚氧化乙烯]]（PEO-CNCs），可以显著改善 CNCs 在[[聚乙烯]]中的分散性。<sup>[157]</sup> 然而，这些纳米复合材料的力学特性几乎没有改善。另一方面，[[Meesorn]] 等人证明，在 CNCs 上吸附少量[[两亲性聚乙烯醇]]有助于其在不同基体中的分散，并能显著提升力学性能，这可能是因为[[氢键|氢键相互作用]]得以保留。<sup>[149–151,158]</sup> 仅部分修饰有（[[共价连接]]的）相容剂的 CNCs 可能具有类似的物理化学特征，即相较于未改性的 CNCs，分散性有所提高，同时通过大量氢键与周围环境相互作用的能力未受削弱。

## 7.1. 直接方法——[[电子显微镜]]

为确认 [[还原性端基|REG]] 改性，必须引入尺寸足够大且导电性足够高的[[官能团]]，以产生足够的衬度变化，供显微镜检测，而低分子量的（无机）有机化合物通常无法满足这一要求。事实上，连接[[金属纳米颗粒]]可被视为通过显微镜观察 [[还原端基|REG]] 改性的经典方法（图 2）。最近，Lokanathan 等人先使用巯基封端的伯胺进行[[还原胺化]]，再用硼氢化物还原 ${ \bf A g N O } _ { 3 }$，从而将 Ag<sup>0</sup>NPs 引入 REG。<sup>[87]</sup>

虽然结合标记的[[电子显微镜]]能够提供该现象的具体图像，在视觉上颇具吸引力，但它无法真正证实特定的 [[还原性端基|REG]] 连接化学反应，也无法对其进行准确量化。

## 7.2. 直接方法——NMR 波谱法

本文讨论的几乎所有现代 [[还原性端基|REG]] 改性均使用 [[纤维素纳米晶|CNCs]]，而 [[纤维素纳米晶体|CNCs]] 形成的是颗粒悬浮液，而非分子溶液。因此，溶液态 NMR 波谱法无法直接用于常见分子溶剂中的 CNCs。虽然固态 <sup>13</sup>C 交叉极化魔角旋转（CP MAS）NMR 波谱法已成为测定样品[[结晶度]]的非常有用的方法，<sup>[170–172]</sup>但其分辨率和信噪比仍不足以用于确认 [[还原端基|REG]] 改性。另一方面，如果已经建立了可靠的化学反应方法，那么经其他定量方法校准的 ${ } ^ { \stackrel { - } { 1 3 } } \mathrm { C }$ CP MAS 未来可能成为一种便捷且相对快速的 REG 改性监测技术。

由于 $T _ { 1 }$ 弛豫速率短得多且 $T _ { 2 }$ 值更长，溶液态 NMR 光谱中的脉冲重复更快，分辨率也更高。然而，[[纤维素]]并不容易溶解，且所需的全氘代纤维素溶剂很难获得。<sup>[173]</sup> 用于溶解纤维素的常见离子液体，如乙酸 1-乙基-3-甲基咪唑鎓，其缺点是许多共振信号与纤维素主链的共振信号重叠。其纤维素溶液的黏度也很高，导致溶解性差和信号展宽。乙酸二烷基咪唑鎓类离子液体是溶解纤维素最有效且研究最多的离子液体，但已知它们也会与[[还原性端基|纤维素还原端]]发生反应。<sup>[174,</sup> <sup>175]</sup> 幸运的是，乙酸四烷基膦鎓盐以其 [D ]DMSO 电解质的形式存在时，对纤维素具有很强的溶解能力。<sup>[175]</sup> 它们属于热稳定性和化学稳定性最高的离子液体阳离子类别之一，且迄今尚未发现其与纤维素 [[还原端基|REGs]] 发生反应。虽然已有四烷基膦鎓叶立德被分离出来，但这只有通过相应的卤化物盐与正丁基锂等极强的无机碱反应才能实现。这使得相对于主体 AGUs 定量测定 REGs 成为可能，前提是摩尔质量足够低，使 REG 信号的丰度足以进行具有一定准确度的定量。<sup>[75,</sup> <sup>176]</sup> 在可能的乙酸四烷基膦鎓同系物中，乙酸四丁基膦鎓 $( [ \mathrm { P } _ { 4 4 4 4 } ] [ \mathrm { O A c } ] )$ 在 20:80 wt% 的 $\mathrm { [ P _ { 4 4 4 4 } ] [ O A c ] / [ D _ { 6 } ] D M S O }$ 组成下，能够溶解至少 5 wt % 的纤维素。在 $6 5 ^ { \circ } \mathrm { C } .$ 下，当纤维素含量为 5 wt % 时，[[纳米纤维素]]可获得优异的分辨率。<sup>[75,</sup> <sup>177,178]</sup> 其分辨率足以记录一系列二维相关实验，从而对纤维素及化学改性纤维素的共振信号进行归属。$T _ { 2 }$ 值通常足够长，<sup>[177]</sup> 因而能够开展有机化学中常用的大多数溶液态 NMR 实验。应用扩散编辑是避开烷基频率区中 $[ \mathrm { P _ { 4 4 4 4 } } ] [ \mathrm { O A c } ]$ 共振信号重叠问题的一项关键实验。<sup>[177]</sup> 这可以滤除扩散较快的物种，即 $[ \mathrm { P _ { 4 4 4 4 } } ] [ \mathrm { O A c } ]$，并保留扩散较慢的物种，即[[聚合]]物物种。事实上，利用该技术已能够确认并定量测定通过 [[Knoevenagel缩合|Knoevenagel 缩合]]（第 4.4 节）引入的 REG 改性。<sup>[75]</sup> 该反应也在[[纤维二糖]]上进行，以制备用于 NMR 信号归属的模型化合物。缩合产物的关键共振信号与 $[ \mathrm { P _ { 4 4 4 4 } } ] [ \mathrm { O A c } ]$ 信号重叠，因此对改性 [[纤维素纳米晶|CNC]] 产物应用了扩散编辑，从而得以确认该反应并进行粗略定量（图 13）。通过对 <sup>1</sup>H NMR 和扩散编辑 <sup>1</sup>H NMR 谱中所引入的[[羰基]]甲基信号进行解卷积，并与纤维素主链信号进行比较，可以获得较为准确的 REG [[转化率]]值。

目前，液态 NMR 用于 [[还原性端基|REG]] 改性分析的一个缺点是，为满足有机化学家当前要求的标准，需要额外开展共振峰归属工作。然而，如果引入的[[官能团]]相对简单 $\mathrm { ( e . g . }$，<sup>1</sup>H NMR 谱中低于 3 ppm 的甲基），扩散编辑就是一种能够快速确认反应的实验，结合谱峰解卷积，甚至可以给出粗略的定量结果。从长远来看，采用[[纤维二糖]]作为 [[还原端基|REG]] 模型具有相当大的价值，因为这样可以更有把握地确定反应的区域选择性。另一个缺点是缺乏可供研究使用的商业化电解质溶液。不过，随着该方法逐渐成熟，这种情况很可能会改变。

当某种[[官能团]]的取代度（DS）足够高时，[[纤维素]]样品可能溶于常见的全氘代分子溶剂中。这需要通过衍生化步骤充分破坏纤维素的晶体结构，因此不应将其视为一种直接分析方法。不过，纤维素样品经全乙酰化处理的一个具体案例值得关注。该研究对 [[还原性端基|REGs]] 的共振峰进行了归属，并证明了 [[还原端基|REG]]“异头”乙酸酯基团的选择性[[脱乙酰化]]。<sup>[179]</sup> 不同的纤维素样品——棉、亚[[硫酸]]盐浆和再生纤维素——经[[水解]]达到其极限[[聚合度]]（LODP，$\mathrm { D P _ { N } = }$ 23–68），随后进行全乙酰化。研究采用谱带选择性 TOCSY 和其他二维相关技术来识别 REG 自旋系统。随后用苄胺处理样品，以选择性脱除 REG 异头乙酸酯基团的乙酰基。由于该方法能够使[[聚合]]物高度溶剂化，从而提高分辨率，因此可能有助于改善 REGs 的定量分析。

## 7.3. 间接方法——衍生化及剩余 [[还原性端基|REGs]] 的定量

“[[还原糖]]”这一术语以及由此而来的 [[还原性端基|REG]]，源于某些金属离子在其存在下会被还原这一事实，这构成了几种用于鉴定还原糖的实验室检测方法的基础。例如，Benedict 试验涉及将 $\mathrm { { C u S O } _ { 4 } \ ( C u ^ { \mathrm { { I I } } } }$，蓝色溶液）还原为 $\mathrm { C u } _ { 2 } \mathrm { O }$（Cu<sup>I</sup>，红色沉淀）。然而，如今已发展出更现代的方法，用于定量测定[[纤维素]]和[[纳米纤维素]]中的 [[还原端基|REGs]]。其中一些方法基于对还原后的金属物种进行光度定量，或在 REG 反应后对生成的酸进行电位滴定。其他方法则基于连接带标记的 REG 化合物，这些化合物在可见光或紫外区域具有吸收或荧光，可用于直接光度定量。因此，针对 REGs 的定量以及某些改性反应后剩余 REGs 的定量，一些具体方法已得到一定程度的评估。

尽管 [[还原性端基|REGs]] 的丰度较低，但已有研究采用滴定法进行测定，所得数值接近 [[纤维素纳米晶|CNCs]] 的预期值。Tang 等人采用两种不同的化学方法处理后，通过电位滴定定量测定 [[还原端基|REGs]]。<sup>[110]</sup> 第一种方法是经典的“羟胺法”，即使 REG [[醛基]]与盐酸羟胺反应，生成肟（图 14），且每个 REG 生成一摩尔 HCl。随后用 NaOH 滴定所生成的 HCl，得到 REG 值为 24.5 mmo $\mathbf { g } ^ { - 1 } \left( \mathrm { D P _ { N } } = 2 5 2 \right)$ 对于由……制得的 [[纤维素纳米晶体|CNCs]] $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ 漂白针叶木[[硫酸]]盐浆的[[水解]]。第二种方法需要通过[[酸性亚氯酸盐氧化]]将 REGs 转化为[[羧酸]]（图 14）。随后用 NaOH 对这些羧酸进行电导滴定，以定量测定被氧化的 REGs 的数量。该方法得到的 REG 值为 31.1 mmolg<sup>@</sup> ${ ^ 1 } \ ( \mathrm { D P _ { N } } = 1 9 8 )$ 对于相同的 CNCs。随后，采用效率更高的羟胺法，定量测定将胺端基聚苯乙烯[[接枝到法|接枝到]] REGs 后剩余的 REGs，结果表明，醛基含量从 24.5 降至 11.4 mmo $\mathbf { g } ^ { - 1 }$

[[Risteen]] 等人<sup>[104]</sup>和 [[Velleste]] 等人<sup>[56]</sup>采用了“2,2’-联喹啉-4,4’-二甲酸盐（[[二喹啉甲酸|BCA]]）法”，<sup>[180]</sup>该方法基于将 $\mathrm { { C u } ^ { \mathrm { { I I } } } }$ 还原为 Cu<sup>I</sup>，随后在 560 nm 处通过分光光度法，以 Cu<sup>I</sup> 联喹啉-4,4’-二甲酸盐 $( \mathrm { [ C u ^ { I } ( B C A ) _ { 2 } ] ^ { 3 - } } )$ 配合物的形式对其进行定量（图 14）。Risteen 等人测得，来自 [[美国农业部林务局|USDA Forest Service]] 下属 [[美国林产品实验室|Forest Products Laboratory]]、由漂白针叶木溶解浆制得的商业 [[纤维素纳米晶|CNCs]]（表 S1），其 [[还原性端基|REGs]] 含量为 18.2 mmo $\mathbf { g } ^ { - 1 }$ $( \mathrm { D P _ { N } } = 3 3 9 )$。<sup>[104]</sup>Velleste 等人测得，经磷酸再生的 Avicel [[pH|PH]]-101（50 mm，[[Fluka]]）微晶[[纤维素]]（MCC）的 [[还原端基|REGs]] 含量为 $2 9 . 7 \mu \mathrm { m o l } \mathrm { g } ^ { - 1 }$ $\mathrm { ( D P _ { N } = }$ 208)。<sup>[56]</sup>还分析了源自 Nata de Coco（[[CHAOKOH]] 糖浆椰果，[[Theppadungporn Coconut Co., Ltd]]，泰国）的细菌[[纳米纤维素]]（BCN），测得其 REGs 含量为 2.8 mmo $\mathbf { g } ^ { - 1 }$ $( \mathrm { D P _ { N } } = 2 2 0 5 )$

[[Velleste]] 等人还采用了一种用于比较的标记方法，即“[[邻氨基苯甲酸]]（AA）法”，在[[还原胺化]]条件下直接标记 [[还原性端基|REGs]]（图 14）。<sup>[56]</sup> 在这种情况下，他们先直接标记 [[还原端基|REGs]]，再测量标记化合物的荧光发射（在 330 和 425 nm 处）。为此，他们采用高剂量[[纤维素]][[酶处理]] $( 2 0 \mathrm { \ F P U { g } ^ { - 1 } } T .$ reesei 纤维素酶，在 $2 5 ^ { \circ } \mathrm { C }$ 下过夜），使不溶性样品溶解，以便在衍生化和离心后进行溶液态定量。还使用该方法分析了 BCN，测得 REGs 的值为 $4 . 9 \mu \mathrm { m o l } \mathrm { g } ^ { - 1 }$ $( \mathrm { D P _ { N } } = 1 2 6 0 )$。采用这两种方法分析了一系列其他纸浆基和棉基基材，所得比值表明，对于较高摩尔质量（MM）的纤维素，AA 法的结果平均高估至 1.43 倍。然而，对于摩尔质量较低的 MCC，两种方法的结果相差 1.2 倍，AA 法的结果较高。

另一种基于直接标记和定量的方法是“Purpald<sup>U</sup> 法”，<sup>[182]</sup>该方法利用醛与 4-氨基-3-[[肼基]]-5-巯基-1,2,4-三唑（Purpald<sup>U</sup>）偶联生成中间体，经温和氧化剂氧化后，可通过分光光度法（570 nm）进行定量。[[Criado]] 等人使用该方法对商用产品中的 [[还原性端基|REGs]] 进行定量 $\mathrm { C N C s } ,$ 源自 $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ 漂白针叶木[[硫酸]]盐浆（加拿大 [[FPInnovations|FPInnovationsQ]] 中试工厂）的[[水解]]。<sup>[183]</sup> 他们测定的数值为 $2 0 \pm 4 ~ \mu \mathrm { m o l } \mathrm { g } ^ { - 1 }$ [[还原端基|REGs]] 的 $( \mathrm { D P _ { N } } = 3 0 9 \pm 6 2 )$ . 该方法进一步用于定量测定 [[纤维素纳米晶|CNC]] 悬浮液经 γ 辐照后[[醛基]]含量的增加，以更好地理解其抗氧化性能。

## 7.4. 方法比较与结论

对这些方法的直接比较清楚表明，在确认、定量和评估任何 [[还原性端基|REG]] 改性方法的适用性时，始终应结合使用互补的分析方法（表 2）。迄今为止，唯一具有足够分辨率、能够区分 [[还原端基|REG]] 化学物种的直接方法，是在离子液体电解质中进行的溶液态 NMR 光谱分析。<sup>[75,177]</sup> 尽管针对每一种新[[官能团]]验证该方法所需的工作流程可能十分繁琐，但从长远来看，应用该方法很可能具有相当大的价值。由于溶液态 NMR 分析是表征新合成有机分子的常规手段，我们预计，该方法及其采用离子液体的相关工作流程将迅速发展。然而，也应采用间接方法，尤其是用于 REG 定量的方法，因为这些方法有望给出准确的数值。

## 8. 结论与展望

由于[[纤维素]]链具有方向性，可以通过[[拓扑化学反应]]靶向修饰处于开链醛形式的[[还原性端基|还原端基]]（[[还原端基|REG]]），这也使 [[纤维素纳米晶|CNC]] 等天然[[纳米纤维素]]对象的[[纤维素端基修饰|端部改性]]成为可能。我们认为，本综述问世之时正处于一个分水岭：可及性、已确立的反应机理和表征等许多基础性挑战已至少得到部分解决，而首批材料应用也正在萌芽。模板组装、[[各向异性]]响应结构，以及结合界面工程的智能[[复合材料]]，均属于已经触手可及的概念。依据端部改性原理设计的各向异性两亲性颗粒，如 Janus 棒，可用作下一代纳米机器的组件。从更宏观的角度看，在对可再生生物基[[纳米材料]]进行升级、使其适应即将到来的十年时，这些问题十分重要，尤其是考虑到纳米纤维素的工业化生产——这一前景在过去十年中一直缓慢走向成熟（见支持信息）。不应仅将生物基材料视为“可再生”或“可持续”的材料，还可以在[[材料科学]]中引入通用的模块化概念，利用其原有生物合成结构的某些特征。
