## 摘要

解决[[氟质量平衡]]不闭合的问题仍是[[全氟和多氟烷基物质]]（PFAS）评估中的核心挑战，这主要是由于复杂水体基质中的超短链物种和化学组成尚未解析的化合物未得到充分表征。本研究开发了一种综合分析框架，将[[靶向分析]]、[[超短链PFAS|超短链 PFAS]] 定量、[[可提取有机氟]]（EOF）测定以及基于[[傅里叶变换离子回旋共振质谱|超高分辨率傅里叶变换离子回旋共振质谱]]（[[氟调聚物类PFAS|FT]]-ICR MS）的筛查相结合。该方法能够可靠地表征高基质负荷的环境样品，并将 PFAS 的覆盖范围扩展至常规靶向分析之外。在所研究的各类基质中，[[垃圾填埋场渗滤液]]和[[城市污水]]中分别暂定鉴定出多达 57 个和 53 个[[含氟分子式]]，而结构鉴定率仍然较低（0.3–0.9%），表明仍有相当大比例的[[有机氟]]尚未得到解析。整合[[超短链全氟和多氟烷基物质|超短链 PFAS]] 靶向分析与[[非靶向筛查]]结果后，EOF 中可解释部分的比例显著提高，在[[垃圾填埋场]]渗滤液中最高达到 85%。超[[短链PFAS|短链 PFAS]] 对 EOF 的贡献为 20–34%，而非靶向筛查表明，[[膜浓缩液]]中特定 PFAS 相关化学类别的[[污染物富集|富集]]具有基质依赖性。这些发现表明，将超短链 PFAS 分析与[[高分辨率非靶向筛查]]相结合，能够更明确地界定[[有机氟化合物|有机氟]]总体组成，并推动复杂水系统中氟[[质量平衡]]问题的解决。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）因其极强的[[环境持久性|持久性]]、广泛的存在及[[毒性|潜在毒性]]，构成了全球性环境挑战（Bangma et al., 2022; Chohan et al., 2021; Ryu et al., 2024; Wang et al., 2017）。尽管 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 等传统化合物已受到严格监管，但它们仅占迅速扩展的 PFAS [[化学空间]]的一小部分，该空间包含数千种前体物和新兴替代物（Schymanski et al., 2023）。这种[[结构多样性]]从根本上限制了常规靶向监测的能力，使其只能涵盖一小部分分析物，并导致 PFAS 总负荷被严重低估，这一现象常被称为“[[PFAS 冰山]]”（Forster et al., 2023; Ruyle et al., 2025）。

[[可提取有机氟]]（EOF）分析已成为一种补充性的总体指标，通过[[燃烧离子色谱法]]提供[[有机氟]]总量的测定值。其在监管中的重要性日益提升，例如[[欧盟]]在修订后的《[[欧盟饮用水指令|饮用水指令]]》中将“[[全氟和多氟烷基物质总量|PFAS 总量]]”阈值设为 0.5 µg/L，这反映了向基于总负荷的管理方式的转变。然而，EOF 本质上不具选择性，且无法提供分子层面的信息。研究报告显示，受污染水体中的靶向 [[全氟和多氟烷基物质|PFAS]] 通常占 EOF 的 <10%（Forster et al., 2023; Ruyle et al., 2025），表明[[氟质量平衡]]存在显著缺口，并提示大多数[[有机氟化合物|有机氟]]物种的化学身份仍未得到解析，其毒理学性质也仍不明确。

阐明这一尚未解析的组分需要先进的[[非靶向筛查]]（NTS）。[[Orbitrap 质谱|Orbitrap]] 和[[四极杆飞行时间质谱|四极杆飞行时间]]（QToF）仪器等[[高分辨质谱]]（HRMS）平台凭借较高的[[质量准确度]]和 [[串联质谱|MS/MS]] 功能，显著拓展了[[可疑物筛查]]能力。然而，在高度复杂的环境基质中，其分辨本领可能不足以完全分离间距极小的同量异位特征，尤其是在[[天然有机质]]存在的情况下。这可能使前体离子选择复杂化，并给[[分子式指认]]和同位素解析带来歧义（Andra et al., 2017; Koelmel et al., 2020; Nason et al., 2021）。[[傅里叶变换离子回旋共振质谱]]（[[氟调聚物类PFAS|FT]]-ICR MS）通过超高分辨本领（> 1000,000）和亚 ppm 级质量准确度克服了这些局限，能够分离质量差异 < 0.001 Da 的特征，并揭示精细同位素结构（Cioni et al., 2024; D'Agostino and Mabury, 2014; Fu et al., 2025; Smith et al., 2018; Young et al., 2022）。这些能力为表征复杂环境混合物提供了更强的分子层面约束，并拓展了可检测的 [[全氟和多氟烷基物质|PFAS]] 相关[[化学空间]]。尽管取得了这些进展，将[[靶向分析|靶向 PFAS 分析]]、[[总氟]][[质量平衡]]和超高分辨率 NTS 明确结合，以更好地约束[[氟质量平衡]]的整合工作流程仍然有限。这一点在高浓度废水基质中尤为明显，其复杂组成和多样的[[含氟化合物|含氟物质]]输入给鉴定和定量均带来了挑战。因此，不同含氟物种的组成及其对整体[[有机氟]]库的相对贡献仍缺乏充分约束。

为填补这一关键空白，本研究构建了一个综合分析框架，将靶向 [[液相色谱质谱联用|LC-MS]] 分析、[[超短链PFAS|超短链 PFAS]]（C2–C3）定量、[[可提取有机氟|EOF]] 测定与基于 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 的[[非靶向筛查]]相结合，以研究五种具有代表性的复杂水基质中的[[有机氟]]组成：[[市政污水出水|市政污水处理出水]]、[[地下水]][[纳滤]]（NF）浓缩液、处理后污水[[反渗透]]（RO）浓缩液、[[工业废水]]和[[垃圾填埋场渗滤液]]。研究目标为：（1）定量测定目标 [[全氟和多氟烷基物质|PFAS]]、[[超短链全氟和多氟烷基物质|超短链 PFAS]] 和 EOF，以更好地约束不同基质中的[[氟质量平衡]]；（2）应用基于 [[氟调聚物类PFAS|FT]]-ICR MS 的非靶向筛查，表征此前尚未解析的[[有机氟化合物|有机氟]]特征，并评估其对 EOF 的潜在贡献；（3）评估有机氟组成随基质变化的差异，以增进对复杂水系统中 PFAS 赋存、来源和转化的理解。通过整合互补的分析方法，本研究更准确地界定了复杂水体中的有机氟库，并推进了氟[[质量平衡]]作为 PFAS 评估工具的应用。

## 2. 材料与方法

## 2.1. 化学品与试剂

天然及[[同位素标记]]的 [[全氟和多氟烷基物质|PFAS]] 标准品购自 Wellington Laboratories（加拿大安大略省）（表 S1）。[[液相色谱质谱联用|LC-MS]] 级[[甲醇]]、[[乙腈]]、[[甲酸]]和[[乙酸铵]]购自 VWR（宾夕法尼亚州 Radnor）。高纯度无机试剂（[[碳酸钠]]、[[氟化钠]]、氢氧化铵、氢氧化钠、硝酸）由 Fisher Scientific（宾夕法尼亚州 Pittsburgh）提供。填充有[[石墨化炭黑]]的[[弱阴离子交换|弱阴离子交换柱]]（[[弱阴离子交换与石墨化炭黑复合固相萃取柱|WAX–GCB]]）购自 Phenomenex（加利福尼亚州 Torrance）。所有实验均使用 Milli-Q 水（18.2 MΩ⋅cm，Millipore）。

## 2.2. 样品采集与制备

选取五种复杂水基质，以涵盖不同的[[有机氟]]组成和[[基质复杂性|基质复杂程度]]，用于评估该分析框架：[[市政污水出水|市政污水处理出水]]、[[电子工业废水]]、[[垃圾填埋场渗滤液]]，以及分别来自[[地下水]]和[[市政污水处理出水]]（采用[[活性污泥法|常规活性污泥处理]]）处理膜单元的[[纳滤浓缩液]]与[[反渗透浓缩液]]。样品采集于预先清洗的 [[高密度聚乙烯|HDPE]] 瓶中，经 0.70 μm [[玻璃纤维滤膜]]（Whatman）过滤，并在 4 ◦C 下保存直至分析。理化参数（pH、DOC、主要阴离子、金属离子）列于表 S2。

分析流程示意图见图 1。每个样品分为两份子样，分别用于：（1）[[超短链PFAS|超短链 PFAS]]（C2-C3）的[[直接进样分析]]；（2）[[固相萃取]]（SPE），随后进行目标 [[全氟和多氟烷基物质|PFAS]] 定量、[[可提取有机氟|EOF]] 分析和 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 筛查。使用硝酸将样品（500 mL）酸化至 pH 5，以提高 PFAS 在 [[弱阴离子交换|WAX 吸附剂]]上的保留。SPE 按照先前研究（Forster et al., 2023）中的方法进行：依次用 10 mL 含 0.3% $\mathrm { N H } _ { 4 } \mathrm { O H }$ 的[[甲醇]]溶液、10 mL 甲醇和 10 mL 水进行活化 $\mathrm { ( p H } < 5 ) ;$ 样品上样；用 10 mL 含 0.1% $\mathrm { N H _ { 4 } O H }$ 的水溶液淋洗；在氮气下干燥 10 min；用 10 mL 含 0.3% $\mathrm { N H } _ { 4 } \mathrm { O H }$ 的甲醇溶液洗脱。洗脱液在氮气下浓缩至 1 mL。

## 2.3. [[全氟和多氟烷基物质|PFAS]] [[靶向分析]]

## 2.3.1. [[超短链PFAS|超短链 PFAS]]（C2–C3）

采用[[离子色谱质谱联用|离子色谱耦合 Orbitrap MS]]（IC-MS；Thermo）对[[三氟乙酸]]（TFA）和[[全氟丙酸]]（PFPrA）进行定量。使用 Dionex IonPac AS19–4 µm 色谱柱（2 × 250 mm），在 $3 0 ~ ^ { \circ } \mathrm { C }$ 条件下，以 20 mM 氢氧根溶液为[[淋洗液]]、0.25 mL/min 的流速进行[[等度洗脱|等度分离]]。[[Orbitrap 质谱|Orbitrap]] 在负离子 [[电喷雾电离|ESI]] [[全扫描模式]]（m/z 60–600）下运行。使用标记[[全氟丁酸]] $( ^ { 1 3 } \mathrm { C } \mathrm { \cdot } \mathrm { P F B A } )$ 作为内标。方法定量限（MQLs）分别为 0.1 µg/L（TFA）和 0.05 µg/L（PFPrA）。

## 2.3.2. [[长链全氟和多氟烷基物质|长链 PFAS]]（C4–C14）

采用配备[[电喷雾电离|电喷雾电离源]]的 [[高效液相色谱串联质谱|HPLC–MS/MS]]（Shimadzu 8050）对 35 种 [[全氟和多氟烷基物质|PFAS]] 进行定量。使用 Waters BEH C18 色谱柱（2.1 × 100 mm，1.7 µm）并配合 [[PFAS 延迟柱]]（Restek）进行分离。分析前，向提取液中加入[[同位素标记内标]]。定量采用[[内标校准法]]；当无法获得对应的标记标准品时，使用结构相似且[[色谱保留行为|保留行为]]相近的 PFAS 作为[[替代标准物]]。色谱条件和 [[多反应监测|MRM]] 离子对列于表 S3。

本研究为开展比较分析，将 [[全氟和多氟烷基物质|PFAS]] 操作性地划分为传统类和新兴类。[[传统PFAS|传统 PFAS]] 指常规监测且历来受到监管的化合物，包括长链[[全氟烷基羧酸]]（PFCAs，C8+）、[[全氟烷基磺酸]]（PFSAs，C6+）、基于 [[全氟辛烷磺酰氟|POSF]] 的[[磺酰胺类化合物|磺酰胺类]]，以及已广泛使用的[[氟调聚物类PFAS|基于氟调聚物的 PFAS]]（如 [[氟调聚物磺酸|FTS]]）。[[新兴PFAS|新兴 PFAS]] 指在常规靶向监测框架中较少被持续纳入的化合物，如[[醚类PFAS|醚类 PFAS]]、部分[[氟调聚物]]衍生物（如 53FTA、62FTAB），以及[[短链全氟烷基羧酸|短链 PFCAs]] 和 PFSAs。这一分类依据历史监管重点和环境监测实践，而非仅依据分子结构（Brase et al., 2021; Kudzin et al., 2026）。

## 2.4. 使用 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 进行非[[靶向分析]]

采用配备 18 T 超导磁体和动态谐调 ICR 池（ParaCell®）的 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] timsMRMS（Bruker，德国不来梅）分析 [[固相萃取|SPE]] 提取液。使用[[电喷雾电离|电喷雾离子源]]在[[负离子模式]]下对样品进行电离。离子源和传输参数设置如下：干燥气 $2 0 0 ^ { \circ } \mathrm { C }$、流量 4.0 L/min，雾化气压力 1 bar，毛细管电压 4500 V，四极杆低质量截止值 m/z 250，传输频率 6 MHz，飞行时间 0.6 ms。在 2ω 模式下采集质谱，质量范围为 m/z 150–1500，并根据样品采用 0.02 s 或 0.05 s 的离子累积时间。每次分析累加 100 次扫描。啁啾激发设置为 30%。模拟信号以 8 M 个数据点进行数字化，经切趾处理和补零后，得到 2.237 s 的瞬态信号，在 m/z 200 处的分辨率为 1.6 M。外部校准使用 1 µg/L 调谐混合物（G1696−85,000，Agilent technologies）；内部校准使用覆盖整个质量范围的 15–20 个高丰度峰。保留满足 $S / \mathrm { N } \geq 6$ 的峰。

## 2.4.1. [[可疑物筛查]]工作流程

通过计算去质子化质量、同位素分布模式及预测 pKa 值（ChemAxon），对 [[全氟和多氟烷基物质|PFAS]] 可疑物清单（CompTox Chemicals Dashboard）进行筛选，以排除不可电离的物种（Dudasova et al., 2024）。采用四阶段优先级筛选流程：(1) 精确质量匹配（± 0.5 ppm）；(2) [[同位素体]]核验，针对 $^ { 1 3 } \mathrm { C } , { } ^ { 3 4 } \mathrm { S } ,$ $^ { 3 7 } \mathrm { C l } \left( \pm \ : 0 . 5 \right.$ ppm；理论丰度的 25 - 200%）；(3) 确认基于 $\mathrm { C F } _ { 2 } .$ 的[[同系物]]系列，排除无同系物系列成员的候选物；(4) 根据质量误差、酸性 pKa 和信号强度进行排序。该工作流程可最大限度地减少[[假阳性]]，并提高[[复杂基质]]中类 PFAS 物种归属的置信度。

## 2.4.2. [[分子式归属]]

使用 DataAnalysis（ver. 6.2，Bruker），按照 Fu et al. 的方法，在严格的化学约束条件下进行[[分子式归属]]（Fu et al., 2025）：(1) 元素限制：$\mathrm { C } _ { 1 - 4 0 } , \mathrm { F } _ { 0 - 4 0 } , \mathrm { N } _ { 0 - 5 } , \mathrm { S } _ { 0 - 3 }$ <sub>3</sub>，$\mathrm { { P } } _ { 0 - 1 }$，卤素变体；$\left( 2 \right) \mathrm { N } + \boldsymbol { \mathrm { S } } + \boldsymbol { \mathrm { P } } \leq 5 ; \left( 3 \right) 0 . 3 \leq \left( \mathrm { H } + \mathrm { X } \right) / \mathrm { C } \leq 2 . 2 \boldsymbol { \mathrm { 5 } }$ 和 $0 < 0 / \mathrm { C } \le 1 . 2 ( \mathrm { C } \ge 5 ) ;$ (H + X)/C ≤ 4 以及 $0 \leq 0 / \mathrm { C } \leq 1 . 2 \left( \mathrm { C } \leq 4 \right) ,$，其中 $\mathbf { X } = \mathbf { C l } + \mathbf { B r } + \mathbf { I } + \mathbf { F } ; ( 4 ) 0 < 0 / \mathbf { C } \le 0 . 7 5 , 0 \le \mathbf { D B E } \le 5 , - 1 0 \le \mathbf { D B E } \cdot 0 \le 1 0 ;$ (5) 质量误差 ≤ 0.3 ppm。进一步利用同位素一致性、Kendrick [[质量亏损]]（[[Kendrick质量亏损分析|KMD]]）分析（以 $\mathrm { ( C F _ { 2 } }$ 为基准）以及质量差网络对推定的 [[全氟和多氟烷基物质|PFAS]] 分子式进行评估，以评价结构关联性（图 S1）（Young et al., 2022; Fu et al., 2025）。

## 2.5. [[可提取有机氟|EOF]] 分析与[[氟质量平衡]]

参照 Forster et al. 的方法，采用[[燃烧离子色谱法]]（CIC）定量 [[可提取有机氟|EOF]]（Forster et al., 2023）。将 100 µL [[固相萃取|SPE]] 提取液置于陶瓷舟中，干燥后在 $9 0 0 ^ { \circ } \mathrm { C }$ 下燃烧，将[[有机氟]]转化为氟化氢（HF）。用[[碳酸钠]]溶液吸收燃烧产物，并采用 [[氟化钠|NaF]] 标准品进行[[外标校准法|外标校准]]，通过[[离子色谱法]]定量氟离子。使用[[有机氟化合物|有机氟]]标准品（[[全氟丁酸|PFBA]]、[[全氟己酸|PFHxA]]、[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]]）验证整个 CIC 流程的性能。EOF 值代表提取组分的氟含量，未进行 SPE 回收率校正，以避免不同 [[全氟和多氟烷基物质|PFAS]] 类别间的系统性不确定性。

[[氟质量平衡]]通过以下方式估算：(1) 根据分子中的 F 含量，将目标 [[全氟和多氟烷基物质|PFAS]] 浓度换算为氟当量值；(2) 使用基于替代物的相对响应方法，对暂定鉴定的 PFAS 进行[[半定量分析|半定量]]，其中以结构相似且浓度已知的目标 PFAS 为参照，换算 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 信号强度。(3) 对通过[[直接进样]]定量的 [[超短链全氟和多氟烷基物质|C2-C3 PFAS]]，采用各化合物特异性的 [[固相萃取|SPE]] 回收率进行校正，以纳入基于 SPE 的[[质量平衡]]。已鉴定氟总量按目标 PFAS、暂定鉴定的 PFAS 及经校正的[[超短链PFAS|超短链 PFAS]] 所贡献氟量之和计算。

## 3. 结果与讨论

## 3.1. [[可提取有机氟|EOF]] 的赋存及基质间差异

[[可提取有机氟|EOF]] 普遍存在于所研究的全部五种水基质中，浓度范围为 1.5–16.5 μg F/L（图 2）。这一分布反映了[[有机氟|含氟有机物]]在不同类型基质中的广泛存在，但在缺乏相应进水数据的情况下，无法定量评估其环境负荷或[[污染物富集|富集]]程度。

![](<../2.SCI_MD/Unveiling the hidden organofluorine burden An integrated analytical framework to improve fluorine mass balance in complex waters/images/c936a8c6856da351ba4f8aae82be30798f05f506449a7d674bc2da4d1d5b1cd6.jpg>)  
图 2. 五种代表性复杂水基质中可提取有机氟（EOF）的比较：市政污水处理出水（WW）、纳滤浓缩液（NF）、工业废水（IW）、反渗透浓缩液（RO）和垃圾填埋场渗滤液（Lea），以平均值 ± SD 表示。

在所研究的基质中，[[垃圾填埋场渗滤液]]（Lea）是[[有机氟]]的主要储库，其平均 [[可提取有机氟|EOF]] 浓度为 16.5 μg F/L。该值约为[[市政污水出水|市政污水处理出水]]（[[市政污水|WW]]，1.5 μg F/L）的 11 倍，凸显了[[垃圾填埋场]]作为高强度[[点源污染|点源]]的作用。渗滤液中 [[全氟和多氟烷基物质|PFAS]] 的积累可能由[[含氟聚合物]]的纸张、[[纺织工业|纺织]]品和地毯的弃置，以及固体废物的长期[[浸出]]所驱动（D'Eon et al., 2009; Yuan et al., 2016; Timshina et al., 2021; Coffin et al., 2023）。即使未与当地具体数据进行直接比较，该数值的量级仍凸显了在排放或回流之前对渗滤液进行[[废水深度处理|深度处理]]的迫切必要性。

[[膜处理]]产生的浓缩液中观测到了较高的 [[可提取有机氟|EOF]] 浓度。[[纳滤浓缩液|NF 浓缩液]] $( 2 . 4 \pm 0 . 3$ μg F/L）和 [[反渗透浓缩液|RO 浓缩液]] $( 3 . 4 \pm 0 . 5 \mu \mathbf { g } \mathrm { F / L } )$ 的浓度水平均显著高于典型背景来源。例如，与文献数据的比较表明，[[自来水]]可作为洁净进水的潜在替代参照，其 EOF 水平通常较低（例如，上海和斯德哥尔摩为 0.20–0.72 μg F/L）（Jiao et al., 2023; He et al., 2024）。[[纳滤|NF]] 浓缩液中观测到的浓度约为这些自来水基线水平的 3–10 倍。[[膜浓缩液]]流中观测到的浓度升高是[[污染物截留]]和[[污染物富集|富集]]的预期结果。膜技术在保障[[饮用水安全]]的同时，也将隐性的[[含氟化合物|含氟物质]]负荷有效集中到高浓度废物流中。这些浓缩液较高的[[电导率]]和 [[总有机碳|TOC]] 水平（表 S2）进一步印证了这种富集，而这种富集会带来潜在的[[二次污染]]风险，其污染强度超过常规[[污水处理]]出水（Tow et al., 2021; Ali et al., 2024）。

[[工业废水]]（IW）的 [[可提取有机氟|EOF]] 浓度为 $2 . 8 \pm 0 . 5 \mu \mathrm { g } \mathrm { F / L } .$。为理解这一结果的背景，区分不同工业类型至关重要。文献报道，直接来自 [[全氟和多氟烷基物质|PFAS]] 生产设施的废水中 EOF 水平极高，范围为 100 至 27,000 μg F/L（Forster et al., 2023）。相比之下，本研究中观测到的浓度显著较低（2.8 μg F/L），表明所采样设施很可能代表一般工业活动（例如[[金属电镀]]、[[纺织工业|纺织]]或综合工业园区），而非初级[[氟化工|氟化工生产]]（Jia et al., 2025）。尽管如此，IW 中的 EOF 仍接近[[市政污水出水]] $( 1 . 5 \pm 0 . 2 \mu \mathbf { g } \ : \mathrm { F / L } )$ 的两倍，表明存在明显的工业输入，抬高了基线[[氟负荷]]。

[[市政污水出水]] $( \mathrm { W W } , 1 . 5 \pm 0 . 2 \mu \mathrm { g } \mathrm { F / L } )$ 被用作基线基质。该浓度略高于美国[[市政污水]]出水的报道值（0.36–0.78 μg F/L），但处于相近的数量级（Ruyle et al., 2025）。这一观测浓度可能反映了[[工业废水]]接入[[市政污水管网]]的情况或含 [[全氟和多氟烷基物质|PFAS]] 家用产品使用模式的区域差异。

总体而言，这些显著但存在差异的 [[可提取有机氟|EOF]] 负荷，尤其是[[垃圾填埋场渗滤液|渗滤液]]中的极高负荷以及[[膜浓缩液]]中的[[污染物富集|富集]]，引出了一个关于其化学组成的根本问题。这些[[总氟]]值与典型目标 [[全氟和多氟烷基物质|PFAS]] 浓度之间的差异，使得开展后续章节所详述的全面谱分析成为必要。

将[[新兴PFAS|新兴 PFAS]] 纳入[[质量平衡]]显著缩小了 [[EOF质量平衡缺口|EOF 缺口]]，尤其是在 [[纳滤浓缩液|NF 浓缩液]]和[[垃圾填埋场渗滤液]]中，替代化学物质分别占[[有机氟]]总量的 19% 和 31%。这种[[污染物富集|富集]]凸显了工艺残留物化学特征的演变，其中隐性替代物的[[质量负荷]]已开始与传统污染物相当，甚至超过后者。这一模式与当前向替代性 [[全氟和多氟烷基物质|PFAS]] 结构的转变，以及[[迁移性|高迁移性]]、[[耐氧化性|耐氧化]]物种在水环境中的优先[[环境持久性|持久存在]]相一致（Zhang et al., 2024; Qiao et al., 2025; Kudzin et al., 2026）。

然而，即使同时计入传统和新兴物种，所有基质中仍有相当大比例的 [[可提取有机氟|EOF]] 无法得到解释（58–95%）（图 3b）。这一持续存在的缺口表明，[[EOF质量平衡缺口|质量平衡缺口]]反映了[[靶向分析|常规靶向方法]]未能涵盖的广泛[[含氟化合物]]。这一未解释组分的普遍存在表明，这些隐性贡献物是复杂水体中[[有机氟]]库的系统性组成部分，可能包括前体衍生物种、非常规 [[全氟和多氟烷基物质|PFAS]] 结构，以及此前已被确定为导致 EOF [[质量平衡闭合]]不足的多种[[转化产物]]（Zhang et al., 2021; Larsson et al., 2026）。

总体而言，图 3b 在常规 [[全氟和多氟烷基物质监测|PFAS 监测]]与[[有机氟]]总负荷之间建立了定量联系，同时也揭示了其固有局限。除本研究所考虑的靶向 [[全氟和多氟烷基物质|PFAS]] 外，[[三氟乙酸|TFA]] 等[[超短链PFAS|超短链 PFAS]] 构成了一类独特且在定量上具有重要意义的[[含氟化合物|含氟物质]]，其与常规 PFAS 指纹在很大程度上仍相互脱离。这些观察结果连同占比可观的未解释 [[可提取有机氟|EOF]] 组分，促使我们将[[超短链全氟和多氟烷基物质|超短链 PFAS]] 研究与[[高分辨率非靶向筛查]]相结合，以解析复杂环境基质中导致 EOF [[质量平衡闭合]]不足的隐性含氟[[化学空间]]。

3.3. [[超短链PFAS|超短链 PFAS]]（C2–C3）：弥合 [[EOF质量平衡缺口|EOF 缺口]]的另一部分

尽管靶向 C4-C14 [[全氟和多氟烷基物质|PFAS]] 在不同基质之间表现出显著的异质性，但纳入[[超短链PFAS|超短链 PFAS]]（C2-C3）从根本上重塑了污染格局（表 S4，图 4）。在所有受调查样品中，[[三氟乙酸|TFA]] 均为已鉴定物种中含量占主导地位的物种，其浓度从[[市政污水出水|市政污水处理出水]]（[[市政污水|WW]]）中的 $1 8 3 0 \pm 1 3 0 ~ \mathrm { n g / L }$ 到[[垃圾填埋场渗滤液]]（Lea）中高达 13,061 ± 836 ng/L 不等。同样，渗滤液中的 [[全氟丙酸|PFPrA]] 浓度最高达到 $5 7 7 6 \pm 1 4 2$ ng/L。值得注意的是，[[市政污水处理出水|WW]] 中仅 TFA 的浓度（1830 ng/L）就约为所有靶向 C4–C14 PFAS 总负荷（92 ng/L）的 20 倍，凸显了水环境中一个庞大且经常被忽视的[[有机氟]]储库（Brunn et al., 2023; Arp et al., 2024）。

[[三氟乙酸|TFA]] 可能来自多种来源，包括含氟前体经[[光氧化]]在大气中形成，以及[[含氟药物]]、[[农药]]和其他材料的降解。因此，废水中观测到的 TFA 水平可能反映了随基质而异的混合输入，而非单一主导来源。

纳入超短链物种显著提高了[[氟质量平衡]]的[[质量平衡闭合|闭合程度]]（图 4）。这些化合物（绿色区段）在多种基质中构成了 [[可提取有机氟|EOF]] 中已识别的最大组分，约占氟总量的 21–34%。这一贡献在 [[反渗透浓缩液|RO 浓缩液]]、市政和[[工业废水]]（[[市政污水|WW]]、IW）中尤为显著，其中绿色区段远超过传统（灰色）和新兴（红色）[[全氟和多氟烷基物质|PFAS]] 的累计贡献。[[纳滤|NF]]（2646 ng/L）和 [[反渗透|RO]]（5949 ng/L）浓缩液中大量存在的 C2–C3 酸，凸显了它们可被[[深度处理|深度处理工艺]]截留并浓缩，从而形成需要采用专门[[破坏性处理技术]]的[[污染物富集|富集]]废物流（Tow et al., 2021; Safulko et al., 2023; Griffin et al., 2024）。

然而，即使将传统、新兴和超短链物种纳入考量，所有水体类型中仍存在持续未能解释的 [[EOF质量平衡缺口|EOF 缺口]]（蓝色区段），其比例约为 32% 至 75%（图 4）。这一未被解释的氟组分在市政废水（[[市政污水|WW]]，\~75%）和工业出水（[[工业废水|IW]]，\~59%）中占比最高。尽管已纳入 35 种目标 [[全氟和多氟烷基物质|PFAS]] 和超短链酸，这种未能解释的[[有机氟]]仍普遍存在，表明其中存在多种当前[[靶向分析|常规靶向方法]]无法捕获的[[含氟化合物]]。这一庞大的隐性储库可能包含新型[[醚类PFAS|醚类 PFAS]]、[[PFAS前体|阳离子前体]]和复杂[[转化产物]]，直接促使后续开展[[高分辨率非靶向筛查]]，以解析剩余[[有机氟化合物|有机氟]]库的分子身份。

## 3.4. 基于 [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 的[[高分辨率非靶向筛查]]

在富含 [[天然有机质|NOM]] 的环境样品中，可靠识别 [[全氟和多氟烷基物质|PFAS]] 相关特征信号面临[[基质干扰]]以及近等质量背景离子频繁出现的挑战。本研究采用了整合[[质量亏损筛选]]、[[质谱分辨能力|亚 mDa 级分辨能力]]、[[同位素验证]]和 [[Kendrick质量亏损分析|KMD 分析]]的多层次证据链，使[[可疑物筛查]]和[[非靶向筛查]]从孤立的特征匹配转向具有化学依据且符合家族一致性的识别（图 5）（Schymanski et al., 2014; Charbonnet et al., 2022）。

最初的挑战在于以 [[天然有机质|NOM]] 为主的背景具有极高的复杂性。如图 5a 所示，大多数检测到的特征信号（灰点）分布在一个宽广的[[质量亏损]]空间中，这是非均一 NOM 的典型特征。相比之下，氟独特的原子质量亏损 $( ^ { 1 9 } \mathrm { { F } = 1 8 . 9 9 8 4 \mathrm { { D a } ) } }$ 可作为物理筛选依据。通过应用靶向[[质量亏损窗口]]，我们划定了一个独特的富氟区域，在有效抑制 NOM 来源信号的同时，优先[[污染物富集|富集]][[传统PFAS|传统 PFAS]]（红点）和可疑特征信号（蓝点）。值得注意的是，[[分子式指认|已指认分子式]]的特征信号（绿点）紧密聚集在该区域内，表明其具有较强的内部一致性。[[化学空间|化学搜索空间]]的这一关键缩减，使识别流程能够优先关注化学上合理的 [[全氟和多氟烷基物质|PFAS]] 候选物，而无需面对 NOM 基质的全部复杂性。

图 5b 展示了这一同量异位掩蔽难题：目标 6:2 FTS 同位素离子（m/z 428.96368，<sup>34</sup>S）两侧各有一个背景离子，与其间隔仅为 \~1.0–1.1 mDa。在分辨本领 < 100,000 的常规 HRMS 仪器中，这些信号会合并，导致峰形失真和错误的质量指认（Smith et al., 2018; Young et al., 2022; Fu et al., 2025）。因此，18T FT-ICR MS 的超高分辨本领 $( \mathrm { R } > 5 0 0 , 0 0 0 )$ 所赋予的 mDa 尺度峰分辨能力，对于从化学上无关的背景特征中区分真实 PFAS 信号至关重要，为高置信度检出提供了物理基础。

为提高鉴定置信度，将同位素证据作为独立的验证依据进行评估。如图 5c 所示，对于 $\mathrm { C _ { 8 } H _ { 4 } F _ { 1 3 } O _ { 3 } S . }$，实验测得的[[轮廓质谱|轮廓谱]]（黑色）与理论分布（红色）几乎完全重合。同时分辨出质量差极小的 $^ { 1 3 } \mathrm { C }$ [[同位素体]]和硫特异性 $^ { 3 4 } { \sf S }$ 峰，使偶然质量匹配的可能性降至接近于零。尤其对于磺酸化或含[[磺酰基]]的 [[全氟和多氟烷基物质|PFAS]]，[[硫同位素]]的确认至关重要，因为仅凭[[单同位素质量]]无法可靠推断硫的存在（Xu et al., 2022; Dombrowski et al., 2025）。这种同位素一致性将暂定匹配转化为化学上自洽的指认。在条件允许时，还评估了更高阶同位素体 $( \mathrm { e } . 8 \cdot , { } ^ { 1 3 } \mathrm { C } _ { 2 } , { } ^ { 3 3 } \mathrm { S } )$，但它们往往难以与[[背景噪声]]区分；因此，[[同位素验证]]主要基于可检测到的[[同位素模式]]。

最后，使用 [[Kendrick质量亏损分析|KMD]]（以 CF2 为基准）分析，将各个候选物置于 [[全氟和多氟烷基物质|PFAS]] [[化学空间]]中加以考察。如图 5d 所示，所指认的分子式（绿色）并非表现为孤立或随机的特征，而是构成了已知 PFAS 家族的连贯延伸，包括 [[全氟烷基羧酸|PFCAs]]、[[全氟烷基磺酸|PFSAs]] 和[[部分氢化全氟烷基羧酸类似物|部分氢化类似物]]（H-PFCAs）。这种家族层面的连续性提供了重要的合理性筛选依据：符合明确[[同系物]]趋势的特征被优先考虑，而偏离这些趋势的特征则被视为可能的[[假阳性]]，优先级相应降低。

经基于 [[Kendrick质量亏损分析|KMD]] 的筛选后，进一步使用[[分子网络分析|基于质量差的分子网络分析]]对保留的候选物进行评估。

## 3.5. 不同水基质中鉴定产出的比较分析

[[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 的应用揭示了庞大且异质的分子特征空间，原始特征数量从 [[工业废水|IW]] 中的 7927 个到[[垃圾填埋场渗滤液]]（Lea）中的 29,742 个不等（表 S5）。尽管通过数据筛选提取了数千个类 [[全氟和多氟烷基物质|PFAS]] 信号（3764–8310 个），[[结构注释]]产出率仍然极低（[[可疑物筛查|疑似物筛查]]产出率：0.3%–0.9%；[[分子式指认]]产出率：0.2%–0.6%）。这一巨大差距量化了尚未解析的 PFAS 特征，即一个超出现有结构库和鉴定工作流程覆盖范围的庞大含氟特征集合。[[垃圾填埋场]]渗滤液（Lea）中观察到的最低产出率（0.3%）进一步凸显了垃圾填埋系统固有的极端化学复杂性和强烈的转化过程。

为进一步表征不同基质中的 [[全氟和多氟烷基物质|PFAS]] [[化学空间]]，将通过[[可疑物筛查|疑似物筛查]]和[[分子式指认]]所鉴定的分子式进行整合，并按[[元素组成]]分类（图 6a）。在所有基质中，[[CHOF类分子式|CHOF 型分子式]]均在检出的 PFAS 集合中占主导地位，在 [[纳滤|NF]] 和 [[工业废水|IW]] 样品中尤为突出。这些含氧分子式通常与[[全氟烷基羧酸盐]]及相关[[氧化产物]]有关，后者代表了水环境中的[[终端转化产物]]。

相比之下，废水（[[市政污水|WW]]）和 [[反渗透浓缩液|RO 浓缩液]]表现出更高的[[杂原子]]多样性，其中 [[CHONF类分子式|CHONF]] 和 [[CHOSF类分子式|CHOSF]] 分子式的比例更高。此类组成通常与源自[[氟调聚物]]的前体、[[磺酰胺衍生物]]及其他工业 [[PFAS中间体|PFAS 中间体]]有关，表明人为来源的贡献更大（Evich et al., 2022）。[[反渗透|RO]] 浓缩液呈现出尤为独特的模式，其 CHONF 和 [[CHONSF类分子式|CHONSF]] 分子式的相对丰度在所研究基质中最高，这可能反映了膜浓缩过程中[[PFAS前体|前体相关 PFAS]] 物种及 [[全氟和多氟烷基物质|PFAS]] 中间体的[[污染物富集|富集]]。此外，在废水、RO 浓缩液和[[垃圾填埋场渗滤液]]中观察到了含 P 的[[含氟分子式]]，表明可能存在特殊用途的[[含氟添加剂]]，或在垃圾填埋环境中积累的工业化合物。

由于仅凭分子式无法确定结构类别，因此根据[[结构注释|数据库注释]]获得的结构信息，对疑似 [[全氟和多氟烷基物质|PFAS]] 命中物进行了进一步分类（图 6b）。该分类揭示了 PFAS 结构组成随基质而变化的明显差异。然而，由于这些注释基于 [[非靶向分析鉴定置信等级|Level 3/4 鉴定]]，所得类别应被视为指示性的组成分组，而非确定的结构归属（Charbonnet et al., 2022）。在废水样品中，[[降解产物]]在已鉴定氟中占主导地位，其氟贡献量占相当大的部分（265 ng F/L）。这一模式表明，[[污水处理|废水处理]]和[[环境降解]]过程中发生的转化过程，在塑造[[市政污水出水|市政污水处理出水]]中的 PFAS 组成方面发挥着重要作用。

## 3.6. 不同水基质间的[[氟质量平衡]]比较

为评估已鉴定的 [[全氟和多氟烷基物质|PFAS]] 能在多大程度上解释所研究基质中的 [[可提取有机氟|EOF]]，通过整合[[靶向分析|靶向 PFAS 分析]]、[[超短链PFAS|超短链 PFAS]] 定量和[[非靶向筛查]]结果，开展了[[氟质量平衡|氟质量平衡分析]]（图 7）。这种逐步整合展示了随着分析覆盖范围不断扩大，从[[传统PFAS|传统 PFAS]] 扩展至新兴化合物及 NTS 鉴定的物种，如何提高对[[有机氟]]组分的解析程度。

![](<../2.SCI_MD/Unveiling the hidden organofluorine burden An integrated analytical framework to improve fluorine mass balance in complex waters/images/822f78c6480bc0abcf4ebb947f5c51c0ce6fab85c3c422145ac8a924555f5371.jpg>)  
图 7. 五种受研究水基质中 EOF 质量平衡的逐步闭合。堆叠柱表示不同 PFAS 类别所解释的总 EOF 的相对百分比（%），包括靶向分析的传统及新兴 PFAS、超短链（C2–C3）PFAS，以及 NTS 鉴定的组分（疑似 PFAS 和分子式指认的 PFAS）。疑似 PFAS 类别是指通过疑似物筛查鉴定的、具有结构注释的物种，而分子式指认的 PFAS 则表示通过分子式指认识别的含氟分子式。质量平衡中的剩余缺口标记为未解释氟。柱状图各区段内的数字表示各类别对总 EOF 的百分比贡献。

在所有基质中，[[传统PFAS|传统 PFAS]] 对总 [[可提取有机氟|EOF]] 的贡献均相对较小，仅占氟质量的 2–11%。这一观察结果凸显了主要关注既往受监管 [[全氟和多氟烷基物质|PFAS]] 的常规监测策略的局限性。相比之下，纳入 [[非靶向筛查|NTS]] 鉴定的物种显著改善了[[氟质量平衡]]。例如，在 [[反渗透浓缩液|RO 浓缩液]]中，纳入疑似 PFAS（16%）和[[分子式指认]]的 PFAS（6%）显著提高了已解释氟的比例，使未解释的缺口降至 37%。其中许多化合物被鉴定为与前体相关的结构或[[两性离子|两性离子结构]]，表明深度[[膜处理]]工艺可能会优先浓缩非[[传统全氟和多氟烷基物质|传统 PFAS]] 物种。

[[垃圾填埋场渗滤液]]（Lea）的[[氟质量平衡]][[质量平衡闭合|闭合程度]]最高，其中未解释部分降至 15%。这种相对较高的闭合效率主要源于[[新兴PFAS|新兴 PFAS]]（31%）和[[超短链PFAS|超短链 PFAS]]（25%）的大量贡献。这种分布与[[垃圾填埋场]]环境作为长期转化体系的作用相一致，在此类环境中，多种 [[PFAS前体|PFAS 前体]]可能降解为各种短链及新兴[[含氟化合物]]。

尽管取得了这些改进，[[工业废水]]（IW）和[[市政污水]]（[[市政污水出水|WW]]）中仍有相当比例的氟未得到解析，其中分别有 49% 和 47% 的 [[可提取有机氟|EOF]] 未得到解释。这些未解析部分可能共同来源于[[非PFAS有机氟化合物|非 PFAS 有机氟化合物]]（例如[[含氟药物]]和[[农药]]）、尚未鉴定的 [[全氟和多氟烷基物质|PFAS]] 相关结构、缺乏[[参考标准品]]的[[转化产物]]、[[无机氟物种]]（例如 BF<sub>4</sub><sup>-</sup>、PF<sub>6</sub><sup>-</sup>），以及与[[复杂基质]]中高极性或[[低丰度化合物]]相关的分析局限性（Hammel et al., 2022; Spaan et al., 2023; Ruyle et al., 2025）。需要指出的是，EOF 是对可提取[[有机氟]]的总体测量指标，因此不应将未解析部分仅解释为尚未鉴定的 PFAS。

总体而言，图 7 表明，将[[超短链PFAS|超短链 PFAS]] 分析与高分辨率 [[非靶向筛查|NTS]] 相结合，可显著提高不同水体基质中[[氟质量平衡]]的[[质量平衡闭合|闭合程度]]。然而，[[环境有机氟]]中仍有相当一部分的结构尚未得到解析。这些发现表明，仅依赖[[传统PFAS|传统 PFAS]] 监测会遗漏某些基质中存在的大部分氟，尤其是在[[深度处理浓缩液]]和[[垃圾填埋场渗滤液]]中，这凸显了扩充 [[全氟和多氟烷基物质数据库|PFAS 数据库]]和持续发展[[高分辨率分析|高分辨率分析方法]]的重要性。

## 3.7. 局限性与分析注意事项

尽管本研究对复杂水体基质中的[[有机氟]]组成进行了全面表征，但仍需承认存在若干局限性。

首先，本研究采用[[案例研究设计]]，利用五种具有代表性的基质，评估该分析框架对不同[[有机氟]]组成和[[基质复杂性|基质复杂程度]]的适用性。因此，这些结果反映的是特定基质中的分析性能，而非对[[空间变异性|空间或时间变异性]]，或过程相关的[[污染物富集|富集]]与去除情况的全面评估。

其次，将通过[[直接进样]]定量的[[超短链PFAS|超短链 PFAS]]（C2–C3）与基于 [[固相萃取|SPE]] 的 [[可提取有机氟|EOF]] 测定相结合，会引入[[方法学不确定性]]。[[色谱保留行为|保留行为]]的差异，尤其是 [[弱阴离子交换|WAX 吸附剂]]对 [[三氟乙酸|TFA]] 等[[高极性化合物]]的捕集能力有限，可能导致在将这些测量结果与可提取氟组分相对应时出现一定程度的低估。此外，使用 <sup>13</sup>C-[[全氟丁酸|PFBA]] 作为[[替代内标]]，以及缺乏[[超短链全氟和多氟烷基物质|超短链 PFAS]] 的[[同位素标记标准品|化合物特异性标记标准品]]，可能会给定量带来额外的

不确定性。

第三，[[氟质量平衡]]部分依赖于基于[[替代响应因子]]对非靶向 [[全氟和多氟烷基物质|PFAS]] 候选物进行的[[半定量分析|半定量]]。该方法假定未知化合物与结构相似的参考 PFAS 具有相近的[[电离效率]]和[[分析响应]]。然而，不同 PFAS 类别的[[电喷雾电离]]行为存在差异，可能使非靶向特征的氟贡献估算产生不确定性。

因此，本文给出的[[氟质量平衡]]应被理解为对[[有机氟]]总量的约束性估算，而非精确的[[质量闭合]]。除尚未解析的含氟物种的存在外，剩余氟缺口中的一部分还可能反映方法学局限性，尤其是对[[高极性化合物]]的保留不完全。

## 4. 结论

本研究建立了一个集成[[多平台分析|多平台分析框架]]，将[[傅里叶变换离子回旋共振质谱|超高分辨率 FT-ICR MS]]、[[超短链PFAS|超短链 PFAS]] [[定量分析]]与[[可提取有机氟]]（EOF）测量相结合，以弥合复杂水环境中总体氟指标与 [[全氟和多氟烷基物质|PFAS]] 分子层面表征之间的差距。主要研究结果如下：

(1) [[傅里叶变换离子回旋共振质谱|FT-ICR MS]] 的应用将可检测的 [[全氟和多氟烷基物质|PFAS]] 相关[[化学空间]]拓展至常规[[靶向分析]]范围之外。研究观察到数百种[[含氟分子式]]，且与废水基质相比，[[垃圾填埋场渗滤液]]中的组成多样性更高。通过采用包括亚 mDa 级[[质量准确度]]、[[同位素模式]]和 [[Kendrick质量亏损分析|Kendrick 质量亏损分析]]在内的多重约束，支持了在分子式层面对这些含氟特征信号进行归属。

(2) 整合[[超短链PFAS|超短链 PFAS]] 分析与[[非靶向筛查]]结果，显著提高了所有基质中 [[可提取有机氟|EOF]] 的可解释比例。在[[垃圾填埋场渗滤液]]中，通过结合靶向 [[全氟和多氟烷基物质|PFAS]]、超短链物种以及经初步表征的含氟特征信号，可解释高达 85% 的 EOF，凸显了将分析覆盖范围拓展至常规目标物清单之外的重要性。

(3) [[超短链全氟和多氟烷基物质|超短链（C2–C3）PFAS]] 被确定为[[有机氟]]库的主要贡献者，占废水和[[工业废水|工业排放废水]]中 [[可提取有机氟|EOF]] 的 20–34%。它们在 [[反渗透|RO]]（31%）和 [[纳滤|NF]]（27%）浓缩液中的较高占比表明，[[膜处理|膜处理过程]]能够有效[[污染物富集|富集]][[迁移性|高迁移性]]和[[亲水性]]物种，同时也凸显了[[浓缩液管理]]所面临的挑战。

(4) 尽管进行了[[高分辨率分析|高分辨率表征]]，仍有不可忽视比例的 [[可提取有机氟|EOF]] 尚未得到解析，其比例从[[垃圾填埋场渗滤液]]中的 15% 到[[工业废水]]中的 49% 不等。这表明还存在其他[[有机氟]]物种，例如高极性、聚合物类或[[低丰度化合物]]，当前分析方法尚无法涵盖这些物种。

总体而言，本研究表明，要提高[[氟质量平衡]]的解析程度，需要整合超出常规 [[全氟和多氟烷基物质|PFAS]] [[靶向分析]]范围的互补分析策略。所提出的框架为更全面地表征复杂水体中的[[有机氟]]提供了一种可迁移的方法，并为制定更有效的[[含氟污染物]]监测与管理策略提供了支持。
