# [[人工智能|AI]] 驱动的[[生物炭工程]]用于去除水中[[新兴污染物]]：性能、机制与环境视角

![](<../2.SCI_MD/AI-driven biochar engineering for emerging pollutants removal from water performance, mechanisms, and environmental perspectives/images/3ce1c42a53a58bb293f71e32d76cabd14e356259a1c0ea43acfd1d7a32a97b2e.jpg>)

[[Ojima Z. Wada]]<sup>1</sup>、[[Gordon McKay]]<sup>2</sup>、[[Tareq Al‑Ansari]]<sup>1,2</sup> 和 [[Khaled A. Mahmoud]]<sup>1\*</sup>

## 摘要

[[新兴污染物]]（EPs）在全球水体中的广泛存在构成了重大环境威胁，而常规处理技术无法充分应对。本综述全面分析了基于[[生物炭]]的系统作为可持续解决方案的潜力，勾勒出一条从基础[[材料科学]]到先进[[数据驱动工程]]的发展路径。我们通过分级框架对这些解决方案进行批判性评估：从高度依赖[[物理吸附]]机制的第 1 级（[[原始生物炭]]）开始，进而讨论通过[[活化]]和/或[[杂原子掺杂]]增强表面性质的第 2 级（[[改性生物炭]]），最终探讨引入[[纳米颗粒]]和[[石墨烯]]等材料的第 3 级（[[先进复合材料]]），这类材料可提供包括[[化学吸附]]和[[光催化]]在内的更优去除机制。本综述重点关注[[人工智能]]（AI）的变革性作用，AI 能够实现[[预测建模]]与优化，从而加速定制化[[吸附剂|高性能吸附剂]]的设计。除性能外，本综述还深入探讨了规模化应用的关键问题，详细分析了决定实际部署的经济权衡以及环境与[[生态毒性]]方面的考量。我们展示了这种分级方法如何针对难以处理的 EPs 提供定向解决方案，例如用于去除[[全氟和多氟烷基物质]]的[[阳离子复合材料]]，以及通过工程化设计的表面[[孔隙结构]]实现[[微塑料]]和[[纳米塑料]]的物理捕获。最终，我们倡导一种由 AI 指导的策略：在有效的情况下优先采用可持续的原始生物炭，并将先进复合材料作为最后手段进行策略性部署。本文最后提出了未来研究路线图，强调需要标准化且稳健的数据集、[[绿色合成|绿色合成规程]]和严格的[[安全性评估]]，以确保负责任地开发这些下一代[[水处理]]技术。

## 亮点

• [[生物炭]]是一种高度可调的平台，其工程化形态能够通过多种机制去除[[新兴污染物]]。

• 提出了一个由[[混合机器学习]]驱动的框架，用于指导从原料选择到污染物[[选择性]]去除的全过程。

• 尽管性能优越，但与[[原始生物炭]]相比，[[先进复合材料]]因成本和[[生态毒性]]而面临规模化应用障碍。

## 1 引言

全球水资源的完整性正日益受到[[新兴污染物]]（emerging pollutants，EPs）的威胁。EPs 是一类种类繁多且不断增多的人为化合物，对[[水生生态系统]]和人类健康构成重大风险。这些物质包括[[药品和个人护理产品]]（PPCPs）、[[全氟和多氟烷基物质]]（PFAS）等[[持久性有机污染物]]（POPs）、[[农药]]以及[[工程纳米颗粒]]（ENPs），如今已在世界各地的[[地表水]]、[[地下水]]，甚至经过处理的[[饮用水]]中被检出（Wada and Olawade 2025）。它们的广泛存在，是工业、农业和市政来源持续排放（图 1），以及常规给水和[[污水处理厂]]（WWTPs）无法有效去除这些物质共同作用的直接结果（Muambo et al.

2024; Israel et al. 2024）。标准处理工艺链往往无法去除这些[[难降解化合物]]，它们以[[痕量浓度]]持续存在 $( \boldsymbol { \mathrm { n g } } \mathrm { L } ^ { - 1 } \boldsymbol { \mathrm { t o } } \mu \mathrm { g } \mathrm { L } ^ { - 1 } )$，并可能导致[[内分泌干扰]]、[[抗微生物药物耐药性]]扩散以及[[食物网]]内[[生物累积]]等严重的长期后果（Li et al. 2024d; Narain Singh et al. 2025）。

全球所有水文系统，包括[[地表水]]、[[地下水]]和[[饮用水]]资源中，均已检出 [[新兴污染物|EPs]]。例如，中国[[太湖]]近期的监测数据表明，[[全氟和多氟烷基物质|PFAS]] 同系物，特别是[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS），造成了持续污染；在长达十年的监测期内，二者的年均浓度范围分别为 21.7 至 25.4 ng $\mathrm { L } ^ { - 1 }$ 和 9.7 至 26.5 ng $\mathrm { L } ^ { - 1 }$（Ma et al. 2024a）。另一项针对波兰市场在售瓶装水的调查发现，在所分析的 72 份样品中，约 35% 含有可定量检出的[[双酚A|双酚 A]]（BPA），这是一种[[内分泌干扰化合物]]（Wątor et al. 2024）。在南美洲，河流系统中 [[药品和个人护理产品|PPCPs]] 的浓度已高达 270,000 ng $\mathrm { L } ^ { - 1 }$（Soriano et al. 2024），而欧洲地表水中已记录到高达 45,000 ng L<sup>−1</sup> 的[[表面活性剂]]浓度（Assoumani et al. 2024）。除化学污染物外，EPs 的生物学层面也日益令人担忧；在中东地区医院环境中，从淋浴软管和洗手水龙头采集的水样中，超过 25% 检出了[[抗生素耐药生物]]和[[抗生素耐药基因|耐药基因]]（ARGs）（Gholipour et al. 2024）。这些来自全球的证据凸显，迫切需要开发先进、适应性强且可规模化的处理策略，以应对 EPs 的化学和生物多样性。必须引导 [[污水处理厂|WWTPs]] 针对其特定污染物类别，定制[[吸附剂]]和处理工艺配置。

基于[[吸附]]的技术因其操作简便、适用范围广，已成为一种极具前景的 [[新兴污染物|EPs]] 去除策略。然而，吸附材料领域存在根本性的权衡，由此形成了一系列优缺点相互冲突的解决方案。

这一谱系的一端是高性能先进材料。[[石墨烯]]等[[二维材料]]的理论[[BET|比表面积]]为 $\bar { 2 } 6 3 \bar { 0 } \ \mathrm { ~ m } ^ { 2 } \ \mathrm { ~ g } ^ { - 1 }$，而 [[MXene|MXenes]] $( \mathbf { M } _ { \mathrm { n + 1 } } \mathbf { X } _ { \mathrm { n } } \mathbf { T } _ { \mathrm { x } } )$ 具有独特且可灵活调控的[[表面化学性质]]，二者均展现出卓越的污染物捕获能力（Alazmi et al. 2016; Algaradah 2024）。同样，各类[[工程纳米颗粒]]（例如 [[氧化锌|ZnO]]、$\mathrm { F e _ { 3 } O _ { 4 } ) }$ 和[[金属有机框架]]（MOFs）具有优异的[[吸附容量]]及多种去除机制，包括[[化学吸附]]、[[光催化]]和[[抗微生物作用]]（Hlongwane et al. 2019; Alrefaee et al. 2024）。

尽管这些材料在技术性能上表现出色，但其广泛应用受到若干关键缺陷的严重制约。[[生产成本]]往往高得令人却步；例如，[[氧化锌纳米颗粒|ZnO 纳米颗粒]]的成本估计约为每吨 \$190,400 USD per ton (Yashni et al. 2021), Cu/ Zn bimetallic nanoparticles at \$569,000 美元（Noman et al. 2019），而 [[MXene|MXenes]] 的成本则高达每吨 \$20.33 百万美元（Zaed et al. 2024）。此外，其合成过程通常能耗较高，依赖昂贵或危险的[[前驱体]]（例如用于 MXene [[刻蚀]]的[[氢氟酸]]），并且[[纳米颗粒流失]]及其对生态系统的长期影响引发了重大的环境与[[生态毒理学]]担忧（Olawade et al. 2024b）。

另一端则是[[生物炭]]，即通过废弃[[生物质]]的[[热化学转化]]制得的[[含碳材料]]（Liu et al. 2022）。生物炭体现了[[循环经济]]的原则，将[[农业残余物]]、[[林业废弃物]]，甚至[[市政生物固体]]转化为有价值的产品（Samuel Olugbenga et al. 2024）。其主要优势在于高度的可持续性和低成本，估计[[生产成本]]约为 \$144 美元/吨（Pandit et al. 2018），比许多先进[[纳米材料]]低数个数量级。然而，[[原始生物炭]]的性能往往较为一般。其去除机制通常以[[物理吸附]]（例如[[孔隙填充]]、[[疏水相互作用]]）为主，这些机制可能缺乏[[选择性]]，且对高持久性或极性 [[新兴污染物|EPs]] 的去除效果较差（Dong et al. 2023）。

尽管已有大量综述分别探讨了用于[[水处理]]的[[生物炭]]的合成、改性和应用，但仍缺乏一套将材料选择与实际实施相结合、涵盖“从设计到部署”全过程的综合路线图。本综述通过提出分级部署策略来填补这一关键空白，将材料划分为三个层级：第 1 级（[[原始生物炭]]）、第 2 级（[[改性生物炭]]）和第 3 级（[[生物炭复合材料|先进生物炭复合材料]]）。这一分类依据[[新兴污染物]]的复杂性、处理目标和资源约束来指导材料选择。除性能评估外，本研究还独特地融入了 [[人工智能|AI]] 引导的工程设计，阐明[[预测建模]]如何加速开发具有优化性能的定制[[吸附剂]]。此外，我们还提供了全面的规模化可行性评估，整合[[技术经济分析]]（TEA）、[[生命周期评价]]（LCA）以及[[生态毒理学]]方面的权衡，并通过具有明确[[系统边界]]和[[功能单位]]的实际案例情景加以具体阐释。最终，本研究为研究人员提供了一套一站式蓝图，指导其从基础原理出发，以负责任且有效的方式部署下一代生物炭技术。

## 2 [[生物炭]]：用于去除 [[新兴污染物|EPs]] 的可调控基础材料（第 1 级）

[[生物炭]]作为 [[新兴污染物|EPs]] 的独立[[吸附剂]]以及[[先进复合材料]]基础平台的有效性，源于其固有且高度可调的物理化学性质。原料组成和[[热解]]条件是使生物炭能够针对特定应用进行设计的关键决定因素。最佳转化参数（如温度为 $4 0 0 { - } 7 0 0 \ { ^ { \circ } C } _ { \mathrm { ~ } }$、[[升温速率]]为 $5 { - } 3 0 \ ^ { \circ } \mathrm { C } \ \operatorname* { m i n } ^ { - 1 } ;$、[[停留时间]]为 20–120 min，以及[[载气流量]]为 50–150 [[机器学习|mL]] $\operatorname* { m i n } ^ { - 1 }$（Leng et al. 2021））以及功率低至 385 W 的[[微波]]等节能替代方式（Liu et al. 2025c），对于形成所需的物理化学特性（如[[BET|比表面积]]、[[孔隙结构]]和[[表面官能团]]特性）至关重要（Gwenzi et al. 2017; Mariyam et al. 2025）。这种固有的可调性直接影响材料通过多种机制去除 EP 的能力，这些机制包括[[静电相互作用]]、[[π–π电子供体–受体相互作用|π–π 电子供体–受体（EDA）相互作用]]、[[氢键|氢键作用]]、[[疏水分配]]、[[孔隙填充]]和[[离子交换]] （图 2）（Li et al. 2025b）。这些机制的效能，尤其是[[静电吸引]]和氢键等对 [[pH]] 敏感的相互作用，也受环境条件的制约，这凸显了针对特定[[水体基质]]进行定制化设计的重要性（Rajapaksha et al. 2016）。

## 2.1 原料和[[热解]]条件对 [[新兴污染物|EP]] 去除的影响

温度和[[升温速率]]是决定[[生物炭]]最终结构和化学性质的最关键参数（Fan et al. 2021; Li et al. 2024c）。更高的[[热解温度]] $( \mathbf { e . g . } , > 7 0 0 ^ { \circ } \mathbf { C } )$ 促进更大程度的[[碳化]]和[[芳构化]]（图 3），从而形成[[石墨化程度]]更高、更稳定的结构，并增大[[BET|比表面积]]和增强[[疏水性]]（Ma et al. 2019）。例如，在较低温度下制备的[[木材生物炭]]具有显著较低的表面 $\mathbf { a r e a { - } } 1 0 \dot { 4 } 1 . 6 \mathbf { m } ^ { 2 } \mathbf { g } ^ { - 1 }$ 在 $9 0 0 ^ { \circ } \mathrm { C }$ 与……相比 $3 \ \mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 }$ 在 $4 5 0 ~ ^ { \circ } \mathrm { C }$ (Mohan et  al. 2012; Machado et  al. 2025)。[[高温生物炭]]是通过 [[π–π相互作用|π–π 相互作用]]和[[疏水分配]][[吸附]]非极性[[有机污染物]]的理想材料 (Choi et  al. 2020)。相反，较低温度 $( \mathrm { e . g . , 4 0 0 - 6 0 0 ~ ^ { \circ } C } )$ 保留更多原生含氧[[官能团]]（– OH、–COOH），这些官能团可增强表面亲水性，并为吸附极性污染物以及后续化学功能化或[[纳米颗粒]]锚定提供[[活性位点]]（Clurman et al. 2020）。升温速率影响停留 挥发性化合物的[[停留时间]]，影响次生炭的形成和最终产率。

[[生物质]]原料的选择从根本上决定了[[生物炭]]的固有特性。[[木质纤维素]]原料（如[[木材]]、[[玉米秸秆]]、稻壳）富含[[纤维素]]、[[半纤维素]]和[[木质素]]（Abolore et al. 2024），经[[热解]]后可生成[[碳含量]]高、结构稳定且通常具有发达[[孔隙结构]]的生物炭（Gotore et al. 2024）。相比之下，源自动物粪便、[[污水污泥]]、骨或微生物生物质的原料通常富含更多蛋白质和矿物质。尽管这些原料可能因[[灰分|灰分含量]]较高而生成[[BET|比表面积]]较低的生物炭（Piccirillo et al. $2 0 1 7 ;$ Achieng et al. 2019），但它们具有显著优势，能够提供内源性[[杂原子掺杂]] $( \mathrm { e . g . } ,$ 来自蛋白质的氮和硫）和固有的矿物催化剂（如来自[[污泥]]的铁、钙、镁），从而为特定化学相互作用或催化过程形成[[活性位点]]（Yin et al. 2020; Yang et al. 2023）。在制备用作可充电电池系统负极材料的硬碳时，通常采用树脂衍生碳和乙炔黑等原料（Yang et al. 2025b）。

为更清楚地阐明这些关系，表 1 根据原料来源将[[生物炭]]分为三大类：（1）[[木材]]和[[纤维素]]基生物炭，（2）[[生物固体]]或[[污泥衍生生物炭]]，以及（3）骨基生物炭。总体而言，木材和纤维素基生物炭的[[BET|比表面积]]最高（在较高[[热解温度]]下通常超过 $1 0 0 0 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$ $\mathrm { o f } \geq 9 0 0 ^ { \circ } \mathrm { C } )$，这是因为[[木质纤维素]]组分的挥发促进了[[孔隙发育]]（Machado et al. 2025）。相比之下，[[污泥]]生物炭由于[[灰分]]和矿物质含量较高，往往表现出较低的[[比表面积]] $( \mathrm { t y p i c a l l y } < \mathrm { 1 0 0 ~ m } ^ { 2 } ~ \mathrm { g } ^ { - 1 } )$，但即使比表面积有限，其固有的杂原子和金属氧化物仍可促进催化[[吸附]]（Regkouzas and Diamadopoulos 2019）。骨基生物炭由富含钙和磷酸盐的基质制成，由于其无机结构致密，需要更高的[[热解]]温度 $\left( \geq 7 0 0 - 1 0 0 0 \ ^ { \circ } \mathrm { C } \right)$ 才能获得相当的[[孔隙度]]（Piccirillo et al. 2017）。

尽管存在这些差异，表 1 表明，[[BET|比表面积]]并非决定[[吸附]]效率的唯一因素，一些[[比表面积]]较低的[[生物炭]]仍可通过化学键合、络合或[[离子交换]]机制实现显著的 [[新兴污染物|EP]] 去除效果，凸显了[[原始生物炭]]体系多样化的功能潜力（Mohan et al. 2012）。

## 2.2 用于强化水中 [[新兴污染物|EP]] 修复的[[改性生物炭]]（层级 2）

在初步合成之后，可采用一系列改性技术，进一步对[[生物炭]]平台进行工程化调控，以满足特定应用需求。这些策略可根据其对表面/[[孔隙结构]]和[[表面化学性质]]的影响进行大致分类。如图 4 所示，[[活化]]方法旨在大幅提高[[BET|比表面积]]并调控[[孔径分布]]（Hu et al. 2020），而表面化学工程方法则改变生物炭表面的电子性质和功能特性（Li et al. 2025b）。

[[化学活化]]涉及使用化学试剂浸渍[[生物质]]或[[生物炭]]，例如 $\mathrm { H _ { 3 } P O _ { 4 } }$ 或在热处理之前或期间使用 [[氢氧化钾|KOH]]。 $\mathrm { H _ { 3 } P O _ { 4 } }$ 起到脱水剂和模板的作用，形成具有更高[[微孔]]隙率的高度多孔结构，并留下有助于金属结合的磷酸基[[官能团]]（Chu et al. 2018）。高温下的 [[氢氧化钾活化|KOH 活化]]会形成[[熔盐]]，[[刻蚀]]碳骨架，从而产生超高[[BET|比表面积]]，据报道其数值超过 3300 $\mathrm { m } ^ { \mathrm { 2 } } \mathrm { g } ^ { - 1 }$ ，以及以微孔为主、非常适合捕获小分子污染物的结构（Dou et al. 2022）。 $\mathrm { Z n C l } _ { 2 }$ 也是一种高效的[[活化]]剂；其热分解可促进大量孔隙的形成，使[[玉米芯]]生物炭的[[比表面积]]从 \~ 6 增至 1201 $\mathrm { { \dot { m } } ^ { 2 } ~ g ^ { - 1 } }$ 在 $7 0 0 ^ { \circ } \mathrm { C }$ (Varela et al. 2024).

物理[[活化]]提供了一种无需化学试剂的替代方案。蒸汽活化利用高温水蒸气使部分碳气化，从而形成并拓宽孔隙（Shi et al. 2022a）。球磨是一种机械方法，可通过破碎颗粒增大表面积，还可通过新形成的表面与大气中的氧发生反应，引入含氧[[官能团]]（Lyu et al. 2018; Zhuang et al. 2021）。

[[杂原子掺杂]]是指有意将非碳元素（如 N、S、P 和 B）引入碳晶格中（Chen et al. 2023; Li et al. 2024b）。氮掺杂尤为有效，因为氮的电负性会造成电荷差异和[[结构缺陷]]，这些部位可作为[[吸附]]（通过增强的 [[π–π电子供体–受体相互作用|π–π 电子给体–受体相互作用]]和[[氢键|氢键作用]]）及催化反应的[[活性位点]]（Guo et al. 2016; Li et al. 2025b）。

[[共热解]]是一种适用性极广的途径，可通过两种或多种原料的热共转化，实现[[生物炭]]的同步[[活化]]与[[杂原子掺杂]]。[[前驱体]]之间的协同相互作用使碳基体能够在无需外加活化剂的情况下实现原位改性。例如，[[木质纤维素]][[生物质]]提供芳香碳骨架，而富含氮或金属的原料（如藻类、[[污水污泥]]或金属盐）则在[[热解]]过程中提供 N、S、Fe 或 Mn 等掺杂元素，从而制备出具有定制[[表面官能团]]和催化位点的生物炭（Liu et al. 2021; Qin et al. 2023）。这种内在共掺杂可改善电子转移，增强氧化剂［如过一硫酸盐（PMS）］的活化，并减少单金属改性常伴随的金属浸出（Diao et al.

## 3.1 [[全氟和多氟烷基物质|PFAS]]

Yang et al.（2024）的研究就是一个例证，他们制备了具有卓越[[选择性]]和渗透性的 [[MXene]]-[[纤维素]]纳米纤维膜。他们优化后的 MXC-3-L 膜对刚果红的截留率达到 > 99%，并能有效去除 [[全氟和多氟烷基物质|PFAS]]，其渗透率较商用聚酰胺膜提高近八倍。同样，[[生物炭]]-[[纳米颗粒]]杂化材料在基于 Fenton 反应的降解、催化臭氧氧化和电催化方面展现出应用前景，显著促进了[[持久性有机污染物]]的分解（Ahmaruzzaman 2021; Nidheesh et al. 2024; Li et al. 2025a）。本节探讨这些协同相互作用如何拓展 [[新兴污染物|EPs]] 的去除途径，并列举针对 PFAS、[[微塑料]]、[[药物]]、[[内分泌干扰]]物、[[农药]]、新兴病原体和新兴无机金属等主要 EPs 的复合材料实例。本节最后总结了对应于三个生物炭层级的污染物特异性设计原则，重点阐述如何调控结构、化学和功能属性，以最大限度地提高对各类新兴污染物的去除效率（表 3）。

尽管[[生物炭]]作为 [[全氟和多氟烷基物质|PFAS]] [[吸附剂]]具有应用前景，但通过有针对性的复合改性，其[[吸附容量]]和去除效率仍可得到显著提升。一种主要方法是将阳离子聚合物，尤其是聚乙烯亚胺（PEI），引入生物炭表面或功能化[[纳米颗粒]]上。这种改性引入了高密度的带正电荷的胺[[官能团]] $\left( \mathrm { - N H _ { 2 } } ^ { + } \right)$ 。这些[[胺基]]可与 PFAS 分子中带负电荷的磺酸根 $( - \mathrm { S O _ { 3 } } ^ { - } )$ 或羧酸根（–COO<sup>−</sup>）头基产生强[[静电相互作用]]，从而显著增强[[吸附]]（Smaili and Ng 2023）。例如，Lee et al.（2023）报道，使用 PEI 包覆的超顺磁性[[氧化铁]]纳米晶体（IONCs）时，[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的吸附容量分别高达 18.3 mmol $\mathbf { g } ^ { - 1 } )$ 和 88.8 mmol $\mathbf { g } ^ { - 1 } )$，远超传统[[活性炭]]的性能。构建生物炭-磁性纳米颗粒复合材料，尤其是使用 PEI 等阳离子聚合物进行功能化的复合材料，可带来双重优势：较高的 PFAS 吸附容量和便捷的磁分离能力，从而实现吸附剂的高效回收与再利用。Li et al（2022）使用经 PEI 改性的植物源仿生纳米框架进一步验证了这一原理，其对 PFOA 和 PFOS 的吸附容量达到 3529 至 4151 mg $\mathbf { g } ^ { - 1 }$，表现突出。这凸显了生物炭作为先进多功能复合材料基础组分的潜力。Lu et al.（2024）使用壳聚糖改性的氨基驱动型 GO 复合材料，在 120 min 内实现了对一种 PFAS 替代物——对全氟壬烯氧基苯磺酸钠——95.4% 的去除率，进一步证明了静电相互作用和胺基功能化的重要性。除静电相互作用外，“氟相相互作用”（fluorous interactions）这一概念也为提高 PFAS 去除效果提供了另一条有前景的途径。正如 Tan et al.（2021）和 He et al.（2024）所探讨的，含氟吸附剂组分（如含全氟聚醚（PFPE）的两亲性嵌段共聚物）与 PFAS 分子的全氟烷基尾链之间具有较强的亲和力，可显著提高[[选择性]]，并减轻共存污染物的竞争效应。即使在胎牛血清等复杂基质中，该方法也已实现超过 90% 的 PFOA 去除率。[[孔径]]与污染物尺寸的匹配也至关重要，例如，在去除 PFOA 时，[[污泥]]生物炭中 3–6 nm 的介孔比木质生物炭中 1.5 nm 的较小孔隙更为有效（Skjennum et al. 2024）。

对于 [[全氟和多氟烷基物质|PFAS]] 等特定污染物，由于其 pKa 值较低（[[全氟辛烷磺酸|PFOS]] 为 −3.27，[[全氟辛酸|PFOA]] 为 −0.2），在整个 [[pH]] 范围内均保持负电荷（Zhang 等 2019），[[疏水相互作用]]通常比静电作用占据更主导的地位。C–F 区域具有强[[疏水性]]，与亲水性的 –COOH 和 $- \mathrm { S O _ { 3 } H }$ 末端基团形成对比，使其能够通过疏水相互作用实现[[吸附]]，并克服静电排斥（Guo 等 2017；Hassan 等 2020；Behnami 等 2024）。这一机制对长链 PFAS 化合物尤为有效，而短链 PFAS 则要求吸附材料具有更强的疏水性（Zaggia 等 2016）。

## 3.2 [[药物]]

尽管[[生物炭]]和[[活性炭]]等传统[[吸附剂]]能够去除水中的 PhACs，但其效能往往有限，尤其是在多种[[药物]]竞争可用[[吸附]]位点的复杂混合物中（Całus-Makowska 等 2024）。例如，研究还表明，向生物炭中添加氧化铜（CuO）能够增强其对某些药物的[[化学吸附]]，如[[环丙沙星]]、[[双氯芬酸]]和卡马西平（CBZ），这表明金属氧化物可通过增加[[活性位点]]来调节生物炭的表面性质，从而提高污染物去除效果（Liang 等 2020；Xue 等 2022）。除增强复杂体系中的吸附效果外，[[生物炭基复合材料|生物炭复合材料]]还有利于后续再生和重复使用。例如，Wurzer 等（2019）证明，Fe-[[生物炭复合材料]]在水热处理过程中能够促进由十种药物（包括抗生素、杀真菌剂和抗抑郁药）组成的混合物的降解。与[[原始生物炭]]相比，这使完全去污所需的处理温度降低，凸显了其在提高再生性能和降低能耗方面的潜力（Wurzer 等 2019，2020）。工程化生物炭复合材料也为增强包括 CBZ 在内的难降解 PhACs 的去除提供了一条有前景的途径（Zhang 等 2023）。将生物炭与 GO 等材料复合，可增强 CBZ [[芳香环]]与类[[石墨烯]]表面之间的 [[π–π相互作用|π–π 相互作用]]，从而显著提高[[吸附容量]]。Agilandeswari 等（2024）证明，聚吡咯-氧化石墨烯-生物炭（Ppy-GO-Biochar）复合材料对 CBZ 的最大吸附容量达到 45.04 mg $\mathbf { g } ^ { - 1 }$，优于包括常规活性炭和原始生物炭在内的许多其他吸附剂，显示了生物炭与 GO [[协同作用]]的重要性。尽管碳纳米管和氧化石墨烯各自对 CBZ 均表现出较高的吸附容量（分别高达 7910 mg $\mathbf { g } ^ { - 1 }$ 和 215 mg $\mathbf { g } ^ { - 1 }$）（Oleszczuk 等 2009；Cai 和 Larese-Casanova 2014），但其高成本限制了大规模应用（Chen 等 2017a）。将少量此类材料以更具可持续性的方式整合到生物炭基体中，可在利用其优异吸附性能的同时保持成本效益。此外，除吸附外，引入能够促进[[光催化降解]]的组分还可提供一种协同处理途径。Li 等（2019）开发了一种可磁分离的 $\mathrm { F e _ { 3 } O _ { 4 } / B i O B r } .$ /生物炭复合材料，在可见光照射下实现了 95.51% 的 CBZ 光降解率，凸显了将吸附与 AOPs 相结合的潜力。

环境 [[pH]] 可能影响修复效果。关于[[磺胺甲噁唑]]（SMX）的研究凸显了 [[pH值|pH]] 依赖性[[吸附]]的复杂性：其机制从酸性条件下的[[孔隙填充]]和 $\pi ^ { + } - \pi$ EDA 相互作用，转变为碱性条件下的孔隙填充和负电荷辅助[[氢键|氢键作用]]（CAHB）（Li et al. 2023c）。在棉花轧花废弃物[[生物炭]]对磺胺吡啶的吸附中，也观察到了类似的 pH 依赖性相互作用，而其他[[药物]]则表现出不依赖于 pH 的行为（Ndoun et al. 2021）。

## 3.3  [[微塑料]]

近年来，研究开始考虑使用[[生物炭基复合材料|生物炭复合材料]]去除[[微塑料]]和[[纳米塑料]]。[[原始生物炭]]，尤其是在高[[热解温度]] $( 7 5 0 ^ { \circ } \mathrm { C } )$ 下制备的[[生物炭]]，已表现出优异的纳米塑料去除效果（> 99%），能够快速达到平衡（< 5 min），[[吸附容量]]为 $\mathbf { \bar { 4 4 . 9 \ m g 9 } ^ { - 1 } }$（Ganie et al. 2021）。其有效性也延伸到了实际应用场景，[[松木]]和甘蔗生物炭对农田径流中多种微塑料的去除率达到 86.6–92.6%（Olubusoye et al. 2024）。去除机制主要涉及物理和化学作用，包括物理截留、疏水行为和[[静电相互作用]]；显微分析表明，微塑料通过被“黏住”“捕获”和“缠结”在生物炭的多孔蜂窝状结构中而得到有效固定，对 10 µm 微球的去除率超过 95%（Wang et al. 2020; Olubusoye et al. 2024）。有趣的是，对[[BET|比表面积]]相对较低 $( \dot { 2 } 0 0 { - } 6 0 0 \ \mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 } )$ 的生物炭的研究表明，它们非常适合去除微塑料，这说明有效净水并不总是需要超高[[孔隙率]]，也支持了生物基[[吸附剂]]在经济上的可行性（Siipola et al. 2020）。

通过制备复合材料，可以显著提高去除效能。例如，[[磁性生物炭]] $\mathrm { ( F e _ { 3 } O _ { 4 } \mathrm { - } }$ [[生物炭]]）由于表面粗糙度增加以及[[表面电荷]]发生有利变化，比[[原始生物炭]]更能有效抑制塑料颗粒的迁移（Tong et al. 2020）。在 $8 5 0 ~ ^ { \circ } \mathrm { C }$ 下[[热解]]制备的铁改性磁性生物炭，主要通过表面络合机制，实现了对羧基化[[纳米塑料]]的快速去除（< 10 min），最大吸附容量高达 225.11 mg $\mathbf { g } ^ { - 1 }$（Singh et al. 2021a）。同样，Mg/Zn 改性磁性生物炭对 1 µm 聚苯乙烯微球的去除率高达 99.46%，并表现出优异的重复使用性能，在五次吸附–热解循环后仍保持 > 95% 的去除率，其中金属在热再生过程中催化了[[微塑料]]的降解（Wang et al. 2021）。尚未与生物炭结合的材料，例如对聚乙烯的去除容量高达 $1 6 5 0 ~ \mathrm { m g ~ g ^ { - 1 } }$ 的磁性碳纳米管（M-CNTs）（Tang et al. 2021），以及利用静电、[[氢键]]和 [[π–π相互作用|π–π 相互作用]]的甲壳素–氧化[[石墨烯]]（ChGO）海绵（Sun et al. 2020），可能是构建下一代[[生物炭基复合材料|生物炭复合材料]]的合适候选材料。然而，必须考虑到，碱性 [[pH]]、腐殖酸以及实际[[水体基质]]中的竞争离子等环境因素，可能对这些材料的[[吸附]]效率产生不利影响（Ganie et al. 2021; Wang et al. 2021）。

## 3.4  [[双酚A|双酚 A]]

尽管[[原始生物炭]]的 [[双酚A|BPA]] [[吸附容量]]有限，但有针对性的改性可以大幅提升其性能。研究表明，多元素掺杂具有显著效果，尤其是对[[生物炭]]进行 Fe、Mn、Cu 共掺杂，且 Ding et al. (2022) 证实，Fe–Mn–N 共掺杂生物炭的 BPA [[吸附]]容量达到 48.64 mg $\mathbf { g } ^ { - 1 }$，超过未掺杂生物炭的 11 倍。这种提升归因于[[活性位点]] $( \mathrm { F e - N _ { x } }$ 和石墨 N）的形成，以及生物炭电子云密度的改变，从而促进其与 BPA 之间更强的相互作用。另一项关键策略是构建具有分级多孔结构和高[[BET|比表面积]]的生物炭。Shi et al. (2022b) 采用胶体二氧化硅模板法与 $\mathrm { Z n C l } _ { 2 }$ [[活化]]相结合，制备了[[比表面积]]极高（高达 $2 9 4 4 ~ \mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 } )$ 的分级多孔生物炭，在较高 BPA 浓度下，其 BPA 吸附容量达到 908.8 mg $\mathbf { g } ^ { - 1 }$，凸显了最大限度增加可接近吸附位点的重要性。关键在于，这种分级[[孔隙结构]]包含相当比例的介孔，有利于 BPA 分子向[[微孔]]内部的吸附位点传输，并提高整体[[吸附动力学]]性能（Shi et al. 2022b）。值得注意的是，优化合成过程以最大限度地提高分级[[孔隙度]]，对 BPA 吸附至关重要。在 Heo et al. (2019) 的另一项研究中，据报道，生物炭负载的磁性 $\mathrm { C u Z n F e _ { 2 } O _ { 4 } }$ 复合材料的 BPA 吸附容量 $( 2 6 3 . 2 \mathrm { ~ m g ~ g ^ { - 1 } } )$ 显著高于原始 $( 1 8 5 . 2 \mathrm { m g } \mathrm { g } ^ { - 1 } )$，这是由于其具有更多孔隙和活性位点，有助于与 BPA 发生相互作用。研究发现，不同改性方式的[[协同作用]]非常有效，表明将前述最优特性相结合可以改善生物炭的性能。[[pH|溶液 pH]] 也会产生影响；在中性至弱酸性条件下，BPA 主要以分子形式存在，通常有利于吸附（Heo et al. 2019）。

## 3.5 莠去津

尽管已有研究报道，常规[[生物炭]]对阿特拉津的[[吸附]]是有效的（Tan et al. 2016; Hernandes et al. 2022），但先进的复合改性方法可显著提高阿特拉津的去除效果，且往往将吸附与降解途径相结合。一种突出策略是将生物炭与[[光催化]]材料相结合。Peng et al.（2025）采用深共熔溶剂改性的氮空位介导氮化碳，使阿特拉津的[[光催化降解]]效果提高至原来的 4.9 倍，凸显了无金属光催化剂的潜力。同样，Altendji and Hamoudi（2024）表明，$\mathrm { g { - } C _ { 3 } N _ { 4 } / T i O _ { 2 } / }$ ${ \mathrm { N i F e } } _ { 2 } { \mathrm { O } } _ { 4 }$ 复合材料，尤其是在与 PMS 联用时，可实现 97.2% 的阿特拉津转化率。钙钛矿材料，特别是纳米浇铸的 $\mathrm { L a C o O } _ { 3 } ,$，在[[活化]] PMS 方面也表现出较高的催化活性，仅需 4 min 即可使阿特拉津完全降解（Afzal et al. 2025）。除光催化外，双金属[[生物炭基复合材料|生物炭复合材料]]，特别是 Fe–Mn 体系，能够有效活化过硫酸盐（PS），通过自由基途径降解阿特拉津。Liang et al.（2024）发现，Fe–Mn 双金属生物炭的阿特拉津去除率是单金属生物炭的 2.2–2.9 倍，这归因于对 PS 的协同活化以及多种活性氧物种的生成。[[共热解]]策略也可增强生物炭的固有性质。Song et al.（2024）表明，将大型藻类与牡蛎壳共[[热解]]，可制得具有极高[[BET|比表面积]]（高达 $1 5 0 1 . 8 \ \mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 } )$ 且阿特拉津[[吸附容量]]达到 $3 4 0 . 5 ~ \mathrm { m g ~ g ^ { - 1 } }$ 的氮掺杂多孔生物炭。此外，Yang et al.（2018）发现，在 $7 0 0 ~ ^ { \circ } \mathrm { C }$ 条件下，[[玉米秸秆]]衍生生物炭胶体表现出高达 $1 3 9 . 3 ~ \mathrm { m g ~ g ^ { - 1 } }$ 的阿特拉津吸附容量。这凸显了生物炭制备方法在优化其性能方面的关键作用。下表详细列出了这些不同方法，展示了构建高效且可定制的生物炭基材料用于阿特拉津修复的潜力。

## 4 利用[[人工智能]]设计用于去除 [[新兴污染物|EP]] 的[[生物炭]]

从定制[[生物炭基复合材料|生物炭复合材料]]的实验室规模合成向其有效的大规模应用转变，是一项复杂的优化挑战。传统的[[生物炭]]设计主要依赖经验性的试错策略，其中材料选择与优化由孤立的实验指导，而非系统性预测（Zhao et al. 2025）。尽管这种方法带来了有价值的认识，但其耗时且耗费资源，并且往往无法捕捉支配 [[新兴污染物|EP]] [[吸附]]的复杂多变量相互作用，尤其是在采用[[单因素变量法|一次改变一个变量]]（OVAT）的方法调整温度和[[停留时间]]等合成参数时。为克服这些局限，[[人工智能]]（AI）和[[机器学习]]（ML）利用[[人工神经网络]]（ANNs）、[[支持向量机]]（SVMs）和[[随机森林]]（RF）等算法，对生物炭全生命周期中的复杂关系进行建模，提供了强有力的替代方案，从而加快优化进程，并实现传统方法此前无法达到的针对特定污染物的材料定制（Gupta et al. 2023）。

在对[[生物炭]]与污染物之间的复杂相互作用进行建模之前，必须首先利用 [[人工智能|AI]] 优化基础环节：[[生物炭生产]]过程本身。早期模型主要侧重于预测产率、[[元素组成]]和表面性质等关键特征（Supraja et al. 2023）。对于体系明确且数据集范围较窄的情况，[[响应面法]]（RSM）等传统统计模型已被证明非常有效。事实上，一项仅通过 17 次实验对[[棕榈仁壳生物炭]]产率进行建模的研究发现，RSM [[二次模型]] $( \mathbb { R } ^ { 2 } { = } 0 . 9 9 )$ 的表现优于 [[人工神经网络|ANN]] 模型 $( \mathrm { R } ^ { 2 } { = } 0 . 9 0 )$（Sait et al. 2025）。这表明，在优化有限的一组变量时，复杂的 [[机器学习|ML]] 模型可能并非总是必要的。然而，当处理从文献中汇集的规模更大、更多样且不完整的数据集时，传统方法难以胜任，ML 的真正优势才得以释放。通过利用数十项研究的数据，ML 可以指导新型材料的合理设计。例如，一项研究利用来自 39 种不同原料的 169 个数据点训练 [[随机森林|RF]] 和[[梯度提升回归]]（GBR）模型，以预测生物炭的[[BET|比表面积]]（[[比表面积|SSA]]）和[[总孔容]]（TPV）（Li et al. 2023b）。该模型不仅将[[热解温度]]、[[灰分|生物质灰分]]和[[挥发分]]识别为关键预测变量，还被用于优化[[生物质]]混合比例，所得到的[[生物炭复合材料|复合生物炭]]与单一原料制备的生物炭相比，SSA 和 TPV 显著提高，增幅分别超过 40% 和 85%。这种根据不同[[工艺参数]]可靠地预测和调控基本性质的能力，为采用有针对性的“通过预测进行设计”方法制备高效[[吸附剂]]奠定了关键基础。

## 4.1 污染物去除的[[预测建模]]

在能够预测[[生物炭]]内在性质的基础上，[[人工智能|AI]] 的下一个前沿领域是预测污染物去除性能。迄今为止，最全面的 [[机器学习|ML]] 应用主要集中于[[重金属]]和其他无机污染物的[[吸附]]，为 [[新兴污染物|EPs]] 研究提供了可借鉴和调整的宝贵范例。例如，一项研究利用来自 61 种不同生物炭的 528 个数据点，采用 [[随机森林|RF]]、[[支持向量回归|SVR]] 和 [[XGBoost]] 等 ML 算法预测新兴无机污染物的[[吸附容量]]（Ullah et al. 2025）。XGBoost 模型被证明最为高效 $( \mathbb { R } ^ { 2 } { = } 0 . 9 0 )$ ），并从涵盖合成条件、生物炭性质、反应条件和污染物性质的广泛输入变量中，将[[pH|反应 pH]]、生物炭[[投加量]]和[[热解温度]]识别为最关键的预测变量。然而，支配重金属去除的关键特征及其内在机制，无法直接迁移至结构多样的有机 EPs 类别。例如，关于多价阳离子金属的研究往往发现，低[[碳含量]]（< 20%）和高灰分含量的生物炭表现出最高的吸附容量（> 500 mg g<sup>−1</sup>），而表面积的影响可以忽略不计（Shanmughan et al. 2025）。这是因为去除过程主要由静电吸附、[[官能团]]络合、[[离子交换]]和沉淀等机制主导。这与许多 EPs 形成鲜明对比，对于这些污染物，较高的碳含量、较大的表面积和[[疏水性]]对 [[π–π相互作用|π–π 相互作用]]和[[孔隙填充]]等机制至关重要。

[[人工智能|AI]] 在模拟特定、备受关注的有机 [[新兴污染物|EPs]] 的去除方面也正展现出不可估量的价值，尽管这一领域的应用仍处于起步阶段，且往往依赖有限的实验室生成数据。例如，在一项针对 [[全氟辛酸|PFOA]] 去除的研究中，研究人员采用 [[人工神经网络|ANN]] 和[[自适应神经模糊推理系统]]（adaptive neuro-fuzzy inference system，ANFIS）模型，以极高的准确度预测 PFOA 在[[磁性生物炭]]上的[[吸附]] $\scriptstyle \left( \mathbb { R } ^ { 2 } > 0 . 9 9 \right)$ 。这些模型成功确定了实现超过 98% PFOA 去除率的最佳条件，但其开发仅基于包含 19 次实验的小型数据集（Saawarn et al. 2024）。类似地，ANN 和 ANFIS 模型也已被用于基于批次实验精确预测[[农药]]毒死蜱的去除（Bisaria et al. 2024）。尽管这些研究验证了 AI 的预测精度，但其对小型数据集的依赖凸显出，这一领域仍在发展，需要规模更大、更多样化的实验数据库，才能为种类繁多的 EPs 构建真正稳健且具有[[泛化能力]]的模型。除了预测批次吸附外，AI 在优化更复杂的系统和带来经济效益方面也展现出巨大潜力。一项研究利用 768 个数据点训练 ANN 模型，成功预测了污染物在固定床柱中的动态吸附（Zhao et al. 2025），展示了 AI 对模拟工业应用的连续流系统进行建模的能力。此外，将预测模型与优化算法相结合可显著节约成本。一项利用 ANN 优化 2,6-二氯苯酚[[光催化降解]]过程的研究表明，总处理成本因此降低了 16%（Alhajeri et al. 2024）。

## 4.2 在 [[新兴污染物|EP]] 去除中成功实施 [[人工智能|AI]] 的注意事项

## 4.2.1 数据检索与[[特征工程]]

任何预测模型的成功都取决于其训练数据的质量和广度。要使 [[人工智能|AI]] 有效指导用于去除 [[新兴污染物|EP]] 的[[生物炭]]设计，就需要大规模、多维度的数据集，研究通常使用数百个数据点来实现较高的准确性（Zhao et al. 2025; Shanmughan et al. 2025）。根据前文各节的数据，所需的输入变量或特征可分为五个关键类别（表 4）：（1）原料性质（如[[工业分析|工业分析组成]]、[[元素组成]]和[[生化组成]]）；（2）[[热解]]条件（温度、[[升温速率]]、[[停留时间]]）；（3）生物炭性质（如[[BET|比表面积]]、孔隙特征、[[pH]]、[[Zeta电位|zeta 电位]]、元素比）；（4）体系条件（如[[吸附剂]][[投加量]]、污染物初始浓度、溶液 [[pH值|pH]]）；以及（5）污染物性质（如分子量、pKa、log Kow、分子尺寸）。这些全面的描述符不仅使模型能够在不同 EP 类别之间进行泛化，还使其能够识别设计规则，以定制生物炭，针对[[静电吸引]]、π–π 堆积或[[疏水分配]]等特定去除机制发挥作用。这种定向构建的一个典型例子是一项使用 [[机器学习|ML]] 预测生物炭[[氮含量]]的研究（Leng et al. 2022），氮含量是通过[[胺基]]去除 [[全氟和多氟烷基物质|PFAS]] 等某些 EP 的关键性质（He et al. 2024）。该研究使用了一个由 64 种不同原料制得的 400 个生物炭样品组成的大型数据集，以涵盖原料元素组成、工业分析组成、生化组成以及热解条件的 14 个输入变量，训练了一个多目标 [[梯度提升回归|GBR]] 模型（Leng et al. 2022）。该模型成功预测了氮含量 $( \mathbb { R } ^ { 2 }$ 在 0.90–0.95 范围内），并确定[[生物质]]氮含量和[[灰分|灰分含量]]是影响最大的因素，为[[富氮生物炭]]的工程化制备提供了明确的方案。

## 4.2.2 [[数据预处理]]

鉴于数据集通常汇集自不同的文献来源，多步骤[[预处理]]流程对于确保一致性和防止错误至关重要。例如，必须核实组成数据的报告基准；[[工业分析]]应统一为[[干基]]（其中[[挥发分]] + [[灰分]] + [[固定碳]] ≈ 100%），[[元素组成]]则应统一为[[干燥无灰基]]（其中 $\mathsf { C } + \mathrm { H } + \mathsf { N } + \mathsf { S } + \mathrm { O }$ ≈ 100%）（Li et al. 2023b）。若未能统一这些报告标准，甚至在模型训练开始之前就可能引入显著的[[系统性误差]]。此外，一项主要挑战是处理[[缺失值]]。常用方法包括直接删除不完整条目，以及[[中位数插补]]（Xie et al. 2025）等更复杂的方法，或使用 [[K近邻算法|K 近邻]]（KNN）算法（Liu et al. 2025a），根据数据集中最相似的样本推断缺失值。接下来，必须对原始数据进行转换。使用 [[LabelEncoder]] 等工具将[[类别特征]]重新编码为数值形式，同时对数值数据进行[[数据归一化|归一化]]，以防止绝对值较大的特征使模型产生偏倚（例如数百 $\mathbf { m } ^ { 2 } ~ \mathbf { g } ^ { - 1 }$ 的[[BET|比表面积]]与 < 1 的 [[氢碳原子比|H/C]] 比值）（Ullah et al. 2025）。这通常通过 [[Z-score标准化|Z-score 标准化]]或将所有变量缩放至同一范围来实现（Xie et al. 2025）。最后，可以采用 [[Box-Cox变换|Box-Cox 变换]]等方法来稳定方差并处理不服从[[正态分布]]的数据，从而提高模型的拟合效果和预测准确性（Liu et al. 2025a）。

[[数据清洗]]和标准化完成后，下一阶段涉及[[特征选择]]和模型构建。一个常见的误解是，输入变量越多，模型就越好；事实上，冗余或无关特征会削弱模型的[[泛化能力]]，并增加计算成本（Leng et al. 2022）。因此，通常采用迭代式特征选择过程。[[皮尔逊相关系数]]（Pearson Correlation Coefficient，PCC）分析等技术用于识别并剔除彼此高度相关的变量（[[多重共线性]]）（Liu et al. 2025a）。随后，通常将经过筛选的数据集划分为两部分，其中 80–90% 用于训练模型，其余部分用于测试模型在未见数据上的表现。

## 模型开发与解释。

[[数据预处理]]后，一个关键步骤是选择合适的 [[机器学习|ML]] 模型。模型的选择取决于数据集的规模和复杂程度，但研究一致表明，与单一模型（[[支持向量回归|SVR]]、[[支持向量机|SVM]]、[[核岭回归|KRR]] 和 GRP）及[[深度学习]]（[[卷积神经网络|CNN]]、[[人工神经网络|ANN]] 和 [[长短期记忆网络|LSTM]]）方法相比，基于树的[[集成学习|集成模型]]（[[随机森林|RF]]、[[梯度提升回归|GBR]]、[[XGBoost]]、[[LightGBM]] 和 [[CatBoost]]）对于[[生物炭]]表格数据尤为有效（Liu et al. 2025a; Ullah et al. 2025）（图 6A）。这些集成模型将多个“[[弱学习器]]”组合为一个强模型，其表现更佳的原因有多个：Leng et al.（2024）发现，RF 对[[氮官能团]]的预测更好 $( \mathrm { R } ^ { 2 } { = } 0 . 9 1 { - } 0 . 9 7 )$，这归因于其抵抗[[过拟合]]的能力以及对噪声数据的稳健性；Zhou et al.（2024）和 Liu et al.（2025b）表明，XGBoost 和 CatBoost 在精度与[[泛化能力]]之间实现了最佳平衡，由于其内置的[[正则化]]机制和处理缺失数据的能力，产率和表面积的测试 $\mathbb { R } ^ { 2 }$ 值最高可达 0.92–0.97。另一方面，CNN 和 LSTM 等深度学习模型在应用于有限数据集时表现欠佳 $( \bar { \mathrm { R } } ^ { 2 } < 0 . 3 )$，这证实了此类架构需要规模大得多的高维数据才能发挥效用（Liu et al. 2025a）。SVR 等其他模型适用于小规模非线性样本（Xie et al. 2025）。近年来，[[自动化机器学习|自动化 ML]] 框架（如 [[H2O AutoML]]、[[AutoGluon]]、[[FLAML]]）开始涌现，用于简化[[超参数调优]]和[[模型选择]]，预测准确率接近 $\mathrm { R } ^ { 2 } { = } 0 . 9 2$（Wang et al. 2025b）。综合来看，这些发现表明，对于当前规模的生物炭数据，基于集成的方法仍然最为可靠，而自动化 ML 和混合深度学习流程有望用于未来的大规模预测框架。

最后也是最重要的一步是[[模型解释]]，即将模型的预测转化为具有科学意义的见解。首先使用[[决定系数]] $( \mathbb { R } ^ { 2 } )$、[[均方根误差]]（RMSE）和[[平均绝对误差]]（MAE）等统计指标对模型性能进行量化（Ullah et al. 2025）。除准确性外，还使用 [[SHAP]]（SHapley Additive exPlanations，SHapley 加性解释）和[[部分依赖图]]（PDPs）等工具来理解模型的行为（Xie et al. 2025）。这些方法对[[特征重要性]]进行排序，揭示哪些输入变量对[[吸附容量]]的影响最为显著。这一过程通常是迭代进行的；在后续的模型构建轮次中，可以移除被识别为重要性较低的特征，以构建更高效、更稳健的预测工具。图 6B 提供了一个面向 [[新兴污染物|EP]] 去除的[[生物炭工程]]设计框架，该框架改编自 Leng et al.（2025）提出的利用[[生物炭]][[吸附]]金属的框架。该框架是首批整合三个模型的框架之一，建立了从原始[[生物质]]和[[热解]]条件到最终 EP 去除性能的直接联系，从而实现定向设计与优化。

## 4.3 [[人工智能|AI]] 驱动的[[生物炭工程]]的未来展望与关键研究方向

尽管潜力巨大，将 [[人工智能|AI]] 成功应用于[[生物炭]]基 [[新兴污染物|EP]] 去除技术的设计仍面临诸多挑战，而这些挑战也界定了未来的研究方向。首要瓶颈是数据的稀缺性与异质性。任何 [[机器学习|ML]] 模型的预测能力从根本上取决于其训练数据的质量、数量和多样性（Zhao et al. 2025; Ullah et al. 2025）。尽管已有成功的模型使用了数百个数据点，但仍存在一个重大障碍：文献缺乏标准化的数据报告方式，导致数据汇总困难且不可靠（Kumari et al. 2024）。为构建推动该领域发展所需的稳健且具有[[泛化能力]]的模型，未来研究必须以整个研究共同体的协作为基础，建立一个遵循标准化数据报告模板的开源数据库。这将确保所有关键变量（例如，从原料组成到污染物性质和系统条件）都得到一致记录，从而形成开发强大且可靠的预测工具所必需的高质量数据集。

第二个主要挑战是弥合实验室与中试之间的差距。目前可用于训练 [[人工智能|AI]] 模型的绝大多数数据均来自在理想化实验室条件下开展的小规模批次实验（Xie et al. 2025; Shanmughan et al. 2025; Leng et al. 2025）。例如，一项研究中，[[随机森林|RF]] 模型在实验室规模下的预测准确率 $( \mathbb { R } ^ { 2 }$ 最高达 0.87），显著高于中试规模下的预测准确率 $( \mathrm { R } ^ { 2 }$ 最高达 0.65）（Cheng et al. 2020）。尽管这些条件对于理解基本原理至关重要，但它们无法反映实际[[水处理]]过程的复杂性，后者通常涉及连续流系统和动态变化的进水浓度。因此，仅使用批次实验数据训练的模型在预测更大规模下的性能时，其实用性可能有限。因此，需要协同开展研究，通过连续流柱实验和中试规模系统生成全面的数据集。最后，由于侧重于单一污染物体系，当前模型在实际场景中的迁移应用能力有限。废水始终是多种共存污染物组成的复杂混合物，其中竞争或协同[[吸附]]效应可能显著改变[[生物炭]]的性能，而单一 [[新兴污染物|EP]] 模型无法捕捉这些变化（Satyam and Patra 2024）。未来研究必须更加注重通过复杂多污染物基质实验生成数据，以训练能够处理这些相互作用的模型。这将有助于开发更先进的 AI 工具，用于设计既高效又具有高[[选择性]]的生物炭[[吸附剂]]。

## 5 用于去除 [[新兴污染物|EP]] 的[[生物炭基复合材料|生物炭复合材料]]的规模化：环境与经济考量

尽管前面各节已展示了工程化[[生物炭]]的优异性能，但其实际应用最终取决于现实条件下的规模化能力和可行性。目前已证实，规模化生产质量稳定的生物炭是可行的，从实验室规模到 100 kg 的[[生产规模]]均可获得性质相近的生物炭。然而，成功应用需要对相关经济与环境权衡进行全面评估（Mašek et al. 2018）。为开展这一分析，本节综述了[[技术经济分析]]（TEA）和[[生命周期评价]]（LCA）研究的主要发现。任何此类评估的核心都是明确定义的[[系统边界]]，例如图 7 所示的“[[从摇篮到坟墓]]”框架，以及一致的[[功能单位]]。在本综述中，功能单位被定义为“生产 1 吨适用于[[水处理]]的生物炭材料”。因此，本节重点讨论[[原始生物炭]]和[[生物炭复合材料|复合生物炭]]系统的经济考量、环境足迹及[[生态毒理学]]问题。最后，专设一个小节讨论[[吸附剂]]再生与寿命终结管理。

## 5.1 经济考量

Campion et al.（2023）开展的一项全面[[系统综述]]表明，[[生物炭生产]]的[[盈利能力]]高度依赖具体情境，受到地理位置、[[原料可获得性]]、[[生产规模]]、[[工艺参数]]和市场定价的影响。在[[从摇篮到坟墓]]的[[系统边界]]内，当[[热能]]和[[合成气]]等副产品得到[[副产品增值利用|增值利用]]时，这些变量共同决定了[[生物炭]]能否在全生命周期内获得良好的回报。例如，一项评估在厄瓜多尔产生[[藜麦]]和[[羽扇豆]]废弃残余物的工业中整合生物炭生产与供热可行性的研究发现，[[炭化|炭化过程]]产生的热量超过了去除[[皂苷]]所需的热能（Salgado et al. 2018）。为阐明这些动态关系，[[技术经济分析|技术经济研究]]考察了不同地点、原料和工艺情景下的生物炭系统。

## 5.1.1 情景 1：随地点变化的成本差异

由于[[原料可获得性]]、[[劳动力成本]]和[[能源需求]]存在差异，[[全球北方]]与[[全球南方]]的[[生产成本]]和[[经济可行性]]显著不同。亚洲的研究报告称，[[生物炭生产]]在售价低于 200 USD/吨时即可盈利。例如，Hu et al.（2024）报告称，中国以[[猪粪]]为原料的大规模[[生物炭]]生产（年产能 8000 吨）在售价为 154 USD/吨时，实现了具有可行性的[[内部收益率]]（11%），[[投资回收期]]为 4.6 年，而且只有当生物炭价格超过 116 USD/吨时，[[净现值]]才为正。同样，Pandit et al.（2018）估计，以尼泊尔[[农业残余物]]为原料生产的生物炭，其[[最低售价]]（MSP）为 144 USD/吨，反映出较低的投入成本和分散式小规模运营的特点。

## 5.1.2 情景 2：基于原料的权衡

原料类型对[[生物炭]]的[[生产成本]]和生命周期表现均有显著影响。[[污泥]]和粪便基生物炭往往更具经济优势，因为其原料获取成本很低或为零，许多污[[水处理]]公用事业单位和畜牧场出于废物管理目的免费提供这些残余物（Rajabi Hamedani et al. 2019）。相比之下，作物残余物和木质[[生物质]]具有竞争性的市场价值（可用作土壤改良剂或燃料），从而推高了采购成本。

定量而言，在 400–700 °C 下[[热解]]制得的[[污泥]][[生物炭]]，其 [[最低售价|MSP]] 为每吨 700–1000 USD，而在相近操作条件下，作物源和[[木材]]源生物炭的 MSP 最高可达每吨 1400 USD（图 8B）。污泥的成本优势部分源于其较高的[[灰分|灰分含量]]所带来的较高炭产率。如图 8C 所示，在 700 °C 下，污泥生物炭的年产量达到 18.7 kt，而作物残余物和木质[[生物质]]制得的生物炭年产量分别为 16.8 kt 和 14.8 kt（Cheng et al. 2020）。尽管污泥需要更多的干燥能耗，从而提高其全球变暖潜势（GWP），但较低的原料成本和较高的产率往往能在技术经济权衡中抵消这一不利影响（Rajabi Hamedani et al. 2019; Karadirek et al. 2025）。

当大型农场或农工企业将自身产生的残余物重新用作原料时，便无需外部采购，从而进一步降低[[生产成本]]，并提高全生命周期净效益。整合可再生能源干燥技术，尤其是太阳能干燥，为成本优化提供了额外机会（Bennamoun 2012）。一项以椰枣树[[生物质]]为原料的[[技术经济分析|技术经济研究]]表明，将干燥能源由常规能源改为太阳能后，每吨[[生物炭]]的利润由 450 USD 增至 480 USD，而每吨生物炭的生产成本则由 1060 USD 降至 1040 USD（Shaheen et al. 2022）。此类可再生能源整合在海湾地区等炎热、太阳辐照强的地区尤为可行。

此外，即使将[[污泥]][[热解]]的干燥阶段考虑在内，其生命周期成本仍低于其他废物管理方案。加拿大的一项案例研究发现，与焚烧或厌氧消化相比，[[污水污泥]]热解的每吨生命周期成本至少降低了 27%（Zhuang et al. 2022）。因此，将免费或低成本原料与太阳能或余热干燥相结合，可显著改善[[从摇篮到坟墓]]边界内[[生物炭]]系统的经济表现，尤其是在可再生能源丰富的地区。

## 5.1.4 情景 4：将先进材料整合到[[生物炭]]基体中

将先进材料（例如[[纳米颗粒]]、[[石墨烯]]、[[MXene|MXenes]]、[[金属有机框架|MOFs]]）引入[[生物炭]]基体，可大幅提升性能，但也会增加总体成本。通过激光诱导石墨化生产的石墨烯成本为每千克 549–1018 EUR，相当于每吨\~600,000–1,100,000 USD（Jin 2024），而 MXenes 的平均成本为每吨 2033 万 USD（Zaed et al. 2024）。相比之下，纳米颗粒复合材料的成本介于生物合成 Cu/Zn 的每吨 569,000 USD（Noman et al. 2019）与 $\mathrm { T i O } _ { 2 } .$–壳聚糖的每吨 37,000 USD（Meramo-Hurtado and González-Delgado 2020）之间。同样，据报道，使用橙皮和二水合乙酸锌生物合成 [[氧化锌纳米颗粒|ZnO 纳米颗粒]]的成本约为每吨 190,400 USD，其中超过 70% 的[[生产成本]]归因于乙酸锌[[前驱体]]（Yashni et al. 2021）。MOFs 的生产成本取决于合成路线和金属来源，可高达每吨 70,000 USD（Peng et al. 2024）。

将少量此类材料与[[生物炭]]混合，可在保留先进功能的同时大幅降低材料总成本（图 9）。例如，由 90% 生物炭（144 美元/吨）和 10% [[MXene|MXenes]]（2033 万美元/吨）组成的复合材料，其成本约为 203 万美元/吨，与纯 MXene 相比降低了 18 倍（Pandit et al. 2018; Zaed et al. 2024）。因此，杂化可实现[[吸附剂|高性能吸附剂]]的规模化生产，且相较于相应的纯材料，其经济和环境负担更低。

## 5.2 环境考量

大规模部署[[生物炭]]系统在温室气体（GHG）减排和碳封存方面具有可观潜力。理论上，将所有可用的植物[[生物质]]转化为富碳炭，可从大气中移除多达 90 Gt $\mathrm { C O } _ { 2 }$，约相当于光合作用[[固定碳]]量的四分之一（Wang et al. 2013）。除碳捕集外，大规模[[生物炭生产]]还有助于在[[热解]]过程中降解 [[新兴污染物|EP]]。例如，含有 [[全氟和多氟烷基物质|PFAS]]、[[微塑料]]和 [[药品和个人护理产品|PPCPs]] 的市政污[[水处理]][[生物固体]]在热解后实现了 > 99% 的去除率（Keller et al. 2024）。在[[从摇篮到坟墓]]的框架下，其环境影响取决于生产范围、原料类型、热解规模与技术以及先进材料的引入等因素。因此，本节分析了四种不同情景。

## 5.2.1 情景 1：现场（分散式）与集中式[[生物炭生产]]

[[生物炭生产]]的环境影响在很大程度上取决于分散化程度，以及原料来源、加工设施和应用地点之间的距离。阿联酋一项关于椰枣树[[生物炭]]的生命周期研究发现，原料运输（54.6 km）和向[[污水处理厂]]配送产品（39.1 km）是电离辐射影响的主要贡献来源（40%）（Shaheen et al. 2022）。敏感性分析表明，将原料和产品的运输距离分别缩短至 20 km 和 10 km，可使全球变暖潜势（GWP）从 1.53 降至 1.29 kg $\mathrm { C O } _ { 2 } - \mathrm { e q } \mathrm { k g } ^ { - 1 }$。同样，一项覆盖中国全国的评估（图 8B）显示，[[生物质]]运输是第三大碳排放来源（4.09 × 107 吨 $\mathrm { C O } _ { 2 } - \mathrm { e q } )$，对所有环境影响类别均有显著贡献（Yang et al. 2021）。

相比之下，农场内或区域性[[热解]]中心可大幅减轻物流相关负担。[[太湖]]农场网络模式便是一个例证：农民在 $5 0 0 ^ { \circ } \mathrm { C } ,$ 将水稻、小麦和蘑菇残余物转化为[[生物炭]]，产率达到 25–35%，同时利用现场产生的沼气维持热解和农场供暖（Wang et al. 2013）。这一闭环系统实现了近乎能源自给自足，消除了运输相关的 GHG 排放，并改善了养分循环（图 10）。因此，尽管集中式热解设施可能实现规模经济，但运输产生的排放和[[能源需求]]往往会抵消其效益。

## 5.2.2 情景 2：[[热解]]设备的影响

[[生物炭生产]]的环境效益在很大程度上受到[[热解]]设备设计与效率的影响。在[[从摇篮到坟墓]]的评估中，能够完全回收联产品（生物油、[[合成气]]和热量）的系统，其表现显著优于传统配置。生物油和合成气的[[副产品增值利用|增值利用]]能够抵消化石燃料消耗，并大幅降低生命周期排放；然而，在传统土窑或砖窑中，由于设备限制，这些产物往往被直接排放或通过火炬燃烧处理（Zhu et al. 2022）。例如，橙皮在 $7 4 0 ~ ^ { \circ } \mathrm { C }$ 下热解产生了 50% 的焦油、28% 的[[生物炭]]和 22% 的合成气，这些产物均有助于系统内部的能量回收（Negro et al. 2017）。实地对比研究表明，采用部分气体再循环的家用 DK-T5 炉灶实现了 −318±174 kg $\mathrm { C O } _ { 2 } \ \mathsf { - e q \ t } ^ { - 1 }$ [[生物质]]的排放水平，而未进行能量回收的村级砖窑减排幅度较小，为 −229 ± 91 kg $\mathrm { C O } _ { 2 }$ -eq $\mathrm { t } ^ { - 1 }$（Mohammadi et al. 2017）。相比之下，集成热交换器的大型 BigChar 2200 装置达到了 −360±144 kg $\mathrm { C O } _ { 2 } \ \mathrm { - e q \ t ^ { - 1 } } ,$，表明高效利用气体和热量决定了环境绩效。

设备设计也会影响一次排放强度。商用双螺旋输送式装置处理 380 kg $\mathrm { h } ^ { \dot { - } 1 }$ 的木质[[生物质]]，生产了 63 kg $\mathrm { h } ^ { - 1 }$ 的[[生物炭]]，功率消耗为 4.5 kW，但排放了 160 g CO、120 g 丙烷、51 $\bf \Pi _ { g } \ N O _ { x } ,$ 和 43 $\textrm { g S O } _ { 2 } \hslash ^ { - 1 }$，以及 380 $\bar { \bf g } \mathrm { \bf ~ h } ^ { - 1 }$ 的颗粒物（Severy et al. 2018）。采用双箱室[[热解]]炉等先进设计可显著减少这些排放；在 500 °C 下处理 1.5 kg 油棕叶 30 min，所得全球变暖潜势（GWP）为 1.35 kg $\mathrm { C O _ { 2 } } – \mathrm { e q } \ \mathrm { k g ^ { - 1 } }$，比常规热解低 21%，比自然堆肥低 53%（Bindar et al. 2024）。总体而言，这些结果证实，整合能量再循环与排放控制系统可使 GWP 降低多达 40%，从而将热解从简单的[[炭化|炭化过程]]转变为闭环废弃物能源化平台。

## 5.2.3 情景 3：原料特异性环境动态

原料类型使能源效率、干燥需求与碳封存之间产生权衡。[[污泥]]和粪便[[生物炭]]的原料通常含水率较高（\~ 80%），[[固定碳]]比例较低，导致能源消耗更大，并对 GWP 产生正贡献（Zhuang et al. 2022; Li et al. 2024a）。[[生命周期评价]]（LCA）对比数据表明，污泥系统通常仍为净正排放源，而[[木质纤维素]][[生物质]]（含水率 ≈ 20%）因[[碳含量]]较高且可协同回收能量，能够实现净负 GWP（Cheng et al. 2020）。在 400、550 和 $7 0 0 ~ ^ { \circ } \mathrm { C } ,$ 下，升高温度可增强木质[[纤维素]]炭中的碳稳定化，提高生物炭中保留的碳量 $( \mathrm { k g ~ C ~ k g ^ { - 1 } }$ 炭），并使 GWP 值逐步降低（Cheng et al. 2020）。

图 8D 比较了木材源与粪便源生物炭的环境货币估值，表明在 Stepwise 2006 和 Ecotax02 模型下，木材生物炭的估值为 −224 至 −423 EUR $\mathbf { t } ^ { - 1 }$，而粪便生物炭由于干燥能耗较高，估值范围为 −29 至 +25 EUR $\mathrm { t } ^ { - 1 }$（Rajabi Hamedani et al. 2019）。图 8E 同样表明，柳木生物炭的 GWP $( - 2 0 6 3 \mathrm { k g } \mathrm { C O _ { 2 } }$ -eq $\mathbf { t } ^ { - 1 } )$ 远优于猪粪生物炭（−472 kg $\mathrm { C O } _ { 2 }$ $- \mathrm { e q ~ t } ^ { - 1 } )$，证实了在回收能源联产品时，木质纤维素原料能够带来更优的环境回报（Rajabi Hamedani et al. 2019）。因此，从摇篮到坟墓的角度来看，固有含水率较低且碳密度较高的原料可构建最具可持续性的生物炭系统。

## 5.2.4 情景 4：使用先进材料的环境影响

将[[生物炭]]与[[纳米颗粒]]、[[MXene|MXenes]]、[[石墨烯]]或 [[金属有机框架|MOFs]] 等先进材料相结合，虽然能够增强[[吸附]]性能，但这些添加剂会显著改变其生命周期足迹。MXenes 的生产涉及使用 HF 或 LiF–HCl 蚀刻[[前驱体]]，导致较高的酸化潜势和人体毒性指标（Alyasi et al. 2024）。同样，通过溶胶–凝胶法或水热法合成纳米颗粒的能源强度较高（Mpongwana and Rathilal 2022），并会产生包括乙醇和丙醇在内的溶剂排放（Meramo et al. 2018）。[[生命周期评价|LCA]] 估算表明，通过火焰喷雾[[热解]]法合成 $\mathbf { A } \mathbf { g }$ 纳米颗粒（AgNP）的影响为 1951 kg $\mathrm { C O _ { 2 } \mathrm { - e q \ k g ^ { - 1 } \ A g N P s } }$（Temizel-Sekeryan and Hicks 2020），而新兴的绿色路线则大幅降低了这一影响。Han et al.（2025）报告称，利用叶片提取物或细菌还原进行生物基 AgNP 合成，可将 GWP 降至 472–534 kg $\mathrm { C O _ { 2 } \ - e q \ k g ^ { - 1 } }$，约为传统方法的三分之一；以再生银替代开采银，还可进一步降低 28–74%（Han et al. 2025）。

金属氧化物[[纳米颗粒]]也表现出类似的改善，尤其是广泛用于增强[[生物炭]]基体[[光催化]]性能的 ${ \mathrm { T i O } } _ { 2 } ,$。Rodríguez-Rojas et al.（2024）比较了传统氯化物路线 $\mathrm { T i O } _ { 2 }$ 合成方法与一种绿色水相路线，后者使用 Cymbopogon citratus（柠檬草）提取物作为还原剂和稳定剂。绿色方法实现了更高的产率（92% 对比 74%）、更短的[[反应时间]]（3 h 对比 3.25 h）和更低的[[生产成本]]（83.6 对比 88.88 单位），从而减少了能源使用和 GHG 排放。关键在于，该方法避免了氯化物路线中产生的盐酸等有毒副产物，从而消除了酸化和[[生态毒性]]方面的顾虑（Rodríguez-Rojas et al. 2024）。将此类[[绿色合成]]的纳米颗粒整合到[[生物炭基复合材料|生物炭复合材料]]中，可在保留功能性的同时显著降低环境影响强度。

## 5.3 再生与重复使用性能

寿命终期管理是[[吸附剂]]整体 [[技术经济分析|TEA]] 和 [[生命周期评价|LCA]] 中的一个关键因素，有效再生可带来显著的经济和环境效益。例如，[[活性炭]]的再生成本估计为 $\Phi 0 . 7 0 \mathrm { - } \Phi 0 . 8 5 \mathrm { ~ U S D ~ k g ^ { - 1 } }$，显著低于其[[生产成本]] \$0.70–\$1.50 USD $\mathrm { k g ^ { - 1 } }$（Harry Marsh and Francisco Rodriguez-Reinoso 2012）。这一成本节约原则在工程化材料中体现得更为突出；一项针对[[废水处理]]用 Fe [[改性生物炭]]系统的分析发现，引入三个再生循环可使每日 $\mathrm { C O } _ { 2 }$ 减排量从 \~36,000 增加至 \~38,000 kg $\mathrm { C O } _ { 2 } \mathsf { - e q d a y } ^ { - 1 }$，并且与传统化学处理相比，可大幅降低成本，降幅达 $5 6 , 6 8 0 \mathrm { U S D \ d a y ^ { - 1 } }$（Zhang et al. 2025）。然而，与活性炭一样，[[生物炭]]和[[纳米材料]]通常会在 3–5 个循环后因[[活性位点]]堵塞、孔隙坍塌或表面氧化而出现性能损失（Singh et al. 2021b; Yan et al. 2022）。性能衰减的程度在很大程度上取决于[[吸附]]机制；以[[物理吸附]]为主的材料往往比以[[化学吸附]]为主的材料更易有效再生，因为后者的污染物与表面之间的化学键难以断裂（Baaloudj et al. 2025）。

再生方法的选择高度依赖于[[吸附剂]]材料和污染物。溶剂洗涤（例如使用乙腈）等传统方法

可实现较高的解吸率（> 95%），但仅将污染物转移至新的液相中，仍需进一步处理（Acevedo-García et al. 2020）。对于金属掺杂[[生物炭]]，碱再生（0.1 M NaOH）可在性能恢复效率与材料完整性之间取得良好平衡，而酸处理往往会腐蚀催化位点，降低金属离子[[吸附容量|吸附量]]（Yan et al. 2022）。热[[活化]]过硫酸盐再生已成为一种稳定可靠且可规模化应用的选择，能够在五个循环中保持 \~ 98–99% 的效率，同时降解残留污染物并最大限度地减少化学品消耗（Baaloudj et al. 2025）。相比之下，热再生可增大生物炭的[[BET|比表面积]]并产生新的[[活性位点]]，使[[吸附]]容量提高至原来的 3.5 倍，但会伴随部分质量损失（Greiner et al. 2018）。对于磁铁矿或金属氧化物等[[纳米材料]]，溶剂解吸、[[微波]]辅助再生和超临界流体技术更为常见，但通常受到能耗高或解吸不完全的限制（Masuku et al. 2021; Pandit et al. 2025）。

电芬顿（EF）再生的最新进展代表着向循环利用迈出的重要一步。该过程集[[吸附]]、污染物降解和原位再生于一体，无需外加氧化剂。研究表明，在优化的 EF 条件下，Fe 掺杂[[生物炭]]和自催化生物炭可在 6 个循环中持续保持接近 100% 的去除效率，同时维持结构完整性并避免铁浸出（Acevedo-García et al. 2020; Puga et al. 2021）。更先进的双金属 EF 系统，如 Fe–Cu–生物炭，在 10 个循环后仍可实现 > 90% 的再生效率，同时与传统吸附–氧化系统相比，能耗降低 > 70%（Ren et al. 2025）。这些自再生 EF 系统能够同时降解已吸附的污染物并恢复催化位点，是大规模[[水处理]]应用中最具可持续性的途径。

## 5.4 [[生态毒性]]考量

尽管普遍认为 [[MXene|MXenes]] 相对安全，但其潜在的[[生态毒性]]仍是一个重大关切。在一项研究中，将 MXene 纳米片暴露于斑马鱼胚胎后，其被归类为“几乎无毒”（Rasheed et al. 2024）。然而，作者警告称，暴露于含有较高浓度 MXene 的出水可能产生神经毒性效应。研究已证实，[[纳米颗粒]]和碳纳米管对包括鱼类和水蚤在内的水生生物具有毒理学效应（Taghavi et al. 2013），并指出它们可能与氧化应激、致癌性、遗传毒性和免疫毒性等不良人体健康效应有关（Singh et al. 2024）。这些材料可能随处理后的出水释放到环境中，这一过程通常称为“流失（washout）”，尤其是纳米颗粒的流失，备受关注（Olawade et al. 2024b）。尽管赋予纳米颗粒磁性（如[[氧化铁]]纳米颗粒）为其从处理后的水中分离和回收提供了一条潜在途径，但某些磁性材料在[[水处理]]过程中容易发生氧化或其他化学转化，这可能削弱其磁响应性，进而降低其可回收性（Mpongwana and Rathilal 2022）。与某些先进材料所面临的挑战相比，[[活性炭|AC]] 和[[生物炭]]相对易于再生，这凸显了废弃物基 AC 再生的重要性（Shah et al. 2023）。

包括[[石墨烯]][[纳米颗粒]]和 GO 在内的石墨烯基材料的[[生态毒性]]正日益受到关注。尽管其抗微生物特性已得到充分证实，研究报告称，在低至 $8 5 ~ \mu \mathrm { g } \ \mathrm { m L } ^ { - 1 }$ 的浓度下，它们即可通过物理破坏和氧化应激等机制对细菌（包括革兰氏阳性菌和革兰氏阴性菌）及真菌产生毒性（Guo and Me 2014），但其释放到水生环境中会对更广泛的生物类群构成潜在风险。已有研究观察到，藻类、无脊椎动物、浮游生物和鱼类暴露于石墨烯基材料后会受到不良影响（Zhao et al. 2014; De Marchi et al. 2018）。采用动物模型的体内研究表明，石墨烯基材料的毒性高度依赖于其形态和暴露途径。例如，大鼠每周至少 5 天吸入暴露于石墨烯后，仅表现出轻微的肺毒性，对体重、血液生化指标或支气管肺泡灌洗液（BALF）中炎症因子的影响可忽略不计（Shin et al. 2015; Kim et al. 2016）。相反，通过气管内滴注给予功能化石墨烯（带有 –COOH、–COH、–NH、–F 和 –NH 基团）会诱发大鼠肺部炎症，其中带正电荷的石墨烯会使多形核白细胞显著增加，且呈剂量依赖性（Lee et al. 2017）。无论具体形态如何，GBMs 均已被证明能够诱导活性氧（ROS）生成。在低至 $1 0 ~ \mu \mathrm { g } \ \mathrm { m L } ^ { - 1 }$ 的浓度下暴露于 GO，即可在人上皮细胞中诱导氧化应激，且该效应具有剂量依赖性（Chang et al. 2011）。其他多项研究也同样报告了体外暴露于 GO 的人细胞中存在剂量依赖性的细胞毒性和免疫毒性（Guo and Mei 2014）。这些[[纳米材料]]可能通过出水和[[污泥]]从[[污水处理厂]]（WWTPs）迁移出去，这意味着它们最终必然会被释放到环境中。例如，将含有银纳米颗粒的[[污水污泥]]施用于土壤，在培养 180 天后，观察到其对土壤微生物，尤其是氨氧化细菌产生毒性作用，同时燕麦根部吸收了银（Schlich et al. 2018）。[[氧化锌|ZnO]] 等金属氧化物纳米颗粒的生态毒性也具有高度的剂量依赖性。低浓度（例如，50 mg L<sup>−1</sup>）的 ZnO 可促进水培水稻幼苗的生长，而较高浓度（超过 100 ppm）则会抑制其生长，这可能是由于 ROS 生成增加所致（Singh et al. 2018）。总体而言，浮游生物暴露于金属氧化物纳米材料后表现出很强的剂量–反应关系（Zhu et al. 2019）。

人们也对[[生物炭]]潜在的[[生态毒性]]存在担忧，这主要源于有害物质可能发生浸出，尤其是在较低[[热解温度]]下制备的生物炭。一项综合性综述指出，生物炭中的潜在污染物包括[[重金属]]、二噁英、[[全氟和多氟烷基物质|PFAS]] 和 VOCs（Xiang et al. 2021）。这些污染物的浓度受到原料和[[热解]]条件的显著影响。选择相对无害的原料并采用较高的热解温度，可通过促进这些有害化合物的分解或挥发，帮助减少其残留。例如，Godlewska et al.（2022）发现，与仅由[[污水污泥]]制备的生物炭相比，由污水[[污泥]]与植物[[生物质]][[共热解]]制备的生物炭毒性更低（Godlewska et al. 2022）。在暴露于生物炭的蚯蚓中也观察到了剂量依赖性生态毒性，这凸显了考虑施用量及其对土壤生物潜在影响的重要性（Jia et al. 2023）。除固有污染物外，还必须考虑[[生物炭复合材料|复合生物炭]]中所[[吸附]]的污染物或所引入金属的潜在毒性。Oleszczuk et al.（2013）研究了由小麦秸秆、象草、椰壳和柳条制备、含有不同浓度金属和 PAHs 的生物炭的生态毒性（Oleszczuk et al. 2013）。观察到的效应包括抑制独行菜（Lepidium sativum）根系生长、抑制微生物生长、对羊角月牙藻（Selenastrum capricornutum）产生毒性，以及导致大型溞（Daphnia magna）死亡。该研究发现，毒性与生物炭的 PAH 含量高度相关，强调了开展全面安全评估和制定适当监管指南的必要性（Oleszczuk et al. 2013）。因此，强烈建议在大规模实施任何基于生物炭的修复工艺之前，开展全面的安全性评价。

## 6 结论

[[新兴污染物]]（EPs）对全球水生系统的广泛污染，是一项紧迫的环境与公共卫生挑战，需要立即采取可规模化实施的解决方案。本综述通过提出一个实用的、分层的[[生物炭]]技术“从设计到部署”框架，对这一问题进行了批判性探讨。该框架倡导务实的方法：首先采用第 1 层级（[[原始生物炭]]），作为针对较易降解 EPs 的低成本、可持续的第一道防线；随后采用第 2 层级（[[改性生物炭]]），通过原位或非原位掺杂与[[活化]]提升性能；最终采用第 3 层级（[[先进复合材料]]），利用强大的催化机制和靶向[[化学吸附]]机制处理持久性最强的化合物。我们明确指出，[[人工智能]]（AI）是支撑这一框架的关键工具，它提供了一条预测性路径，可加快定制材料的定向构建，并推动材料开发超越传统的试错模式。关键在于，我们将这一以材料为中心的方法与全面的规模化可行性分析相结合，阐明了[[技术经济分析]]（TEA）、[[生命周期评价]]（LCA）、[[生态毒理学]]以及[[吸附剂]]再生方面的考量必须如何指导各层级技术的部署。这一综合蓝图为研究界提供了一条富有洞见和前瞻性的路线图，指导下一代[[水处理]]解决方案从基础[[材料科学]]研究走向负责任的大规模应用。
