## ■ 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）因其优异的[[表面活性]]和[[化学稳定性]]而得到广泛的工业应用。<sup>1</sup> 其中，[[全氟辛酸]]（[[PFOA]]）以极端的化学持久性和[[生物累积性]]为特征，是评估环境风险和修复效能的基准同系物。<sup>2</sup> 然而，尽管当前处理策略有所进展，<sup>3,4</sup> 在复杂工业基质中实现高效修复仍是一项艰巨挑战。<sup>5</sup> 这一点在氟化学生产、半导体刻蚀和电镀产生的高酸性废水中尤为明显，这些废水是水体PFOA污染的主要点源，占全球处理此类复杂废水总量的60%以上，包括生物处理、混凝/絮凝−沉淀、过滤、氧化处理、[[膜分离]]和非特异性[[吸附]]在内的常规处理工艺仍不足以实现PFOA的深度削减。<sup>9,10</sup> 这一局限构成了关键的技术瓶颈，凸显了开发兼顾高效率与经济可行性的新型策略的迫切需要。

[[吸附]]因其成本效益高且操作简便，仍是 [[PFAS]] 修复的首要策略。<sup>11</sup> 然而，传统[[吸附剂]]通常缺乏响应不同污染物结构和水基质条件所需的内在适应性。例如，[[活性炭]]往往受限于选择性差和再生过程能耗高；<sup>12</sup> 而[[金属有机框架]]（MOF）<sup>13</sup> 和[[共价有机框架]]（COF）<sup>14</sup> 虽然具有结构可调性，但其高昂成本阻碍了规模化应用。<sup>15</sup> 此外，[[阴离子交换树脂]]（AERs）在酸性出水中易受竞争性离子干扰，并需使用浓盐水或有机溶剂再生，从而损害可持续性（图 1A）。<sup>16</sup> 相比之下，自然界中的生物系统能够通过动态构象变化与协同非共价相互作用的协调调控，在复杂环境中实现对目标配体的高度特异性识别 $( \mathrm { F i g u r e ~ \ t B } ) . ^ { 1 7 - 1 9 }$ 受自然启发，开发具有自适应识别能力、能够在复杂工业基质中实现精准目标捕获、并可由温和刺激触发再生的吸附剂，<sup>20</sup> 已成为环境材料科学中的一个关键前沿方向。

高效去除 [[PFOA]] 需要构建一种与污染物分子结构相匹配的两亲微环境，<sup>21</sup>能够同时容纳疏水性 C−F 链和亲水性羧基端基（−COOH）。在自然界中，蛋白质−脂质组装体通过在疏水口袋中精确排布酯基（−CO−O−）基元，并利用[[疏水效应]]与非共价相互作用的协同作用，实现对两亲性代谢物的特异性识别（图 1B）。<sup>22,23</sup> 原则上，[[全氟辛酸|PFOA]] 的氟化烷基尾部通过增强的疏水作用和[[氢键]]相互作用进一步强化这种组装。<sup>24,25</sup> 与此分子设计相配合，孔道结构在缓解传质限制的同时，施加了尺寸选择性识别所需的空间[[纳米限域]]（图 1C）。<sup>26−28</sup> 在此基础上，我们提出了一种由 pH 依赖的 PFOA 形态分布调控的响应机制：PFOA−COOH 基团解离状态的改变会改变其水合状态、局部电荷分布以及与[[吸附剂]]之间的界面相互作用，从而调控 PFOA 在受限聚合物孔道与水相之间的分配。<sup>29,30</sup> 这种可逆的界面转变允许对 PFOA 结合亲和力进行精确调节，从而建立绿色且可持续的捕获−释放循环（图 1D）。

在这些设计原则指导下，我们开发了 [[AR-1]]，一种孔尺寸经调控的[[交联聚甲基丙烯酸酯]][[吸附剂]]，由[[甲基丙烯酸甲酯]]（MMA）、[[乙二醇二甲基丙烯酸酯]]（EGDMA）和[[三羟甲基丙烷三甲基丙烯酸酯]]（TRIM）构筑而成<sup>31</sup>（图 2A）。AR-1 提供了富含酯基的受限聚合物区域，在酸性条件下有利于 [[PFOA]] 的富集。<sup>32,33</sup> 在这种环境中，[[全氟辛酸|PFOA]] 可能包含更高比例的弱水合物种，从而允许其与酯氧原子形成[[氢键]]、氟化链发生疏水分配，并在[[介孔]]内实现分散辅助接触。孔道结构进一步调控 PFOA 分子的可及性和停留时间，从而提升[[吸附容量]]和选择性。在水洗过程中，PFOA 形态分布和局部溶剂化的改变削弱了这些非共价相互作用，使得无需化学添加剂即可实现再生。<sup>34,35</sup> 该设计为 [[PFAS]] 污染水体的深度净化提供了一种新策略。

## ■ 结果与讨论

## 材料设计与表征

我们设计了一种分子工程策略，用于合成一系列专为特异性捕获 [[PFOA]] 而定制的 −CO−O− 聚合物[[吸附剂]]（图 S1）。我们的模块化聚合体系采用 [[甲基丙烯酸甲酯|MMA]]、[[三羟甲基丙烷三甲基丙烯酸酯|TRIM]] 和 [[乙二醇二甲基丙烯酸酯|EGDMA]] 作为单体构筑单元。该设计的核心是将酯基基元高密度整合到[[交联]]骨架中，以构筑具有局部极性梯度特征的两亲微环境。<sup>36</sup> 关键在于，通过系统调节这些单体的化学计量比，我们确保所有变体保持一致的主链化学组成，从而排除化学异质性在机理研究中作为混杂变量的影响。

我们通过调控聚合过程中[[微相分离]]的动力学，实现了对[[介孔]]尺寸的精确设计。<sup>37</sup> 在多官能单体（[[三羟甲基丙烷三甲基丙烯酸酯|TRIM]]/[[乙二醇二甲基丙烯酸酯|EGDMA]]）快速[[交联]]形成三维网络的同时，疏水性[[致孔剂]]在固化基体中原位发生微相分离。我们确定，致孔剂的分子空间位阻和质量分数是决定这些孔尺寸的关键参数。通过精细调节致孔剂（[[二甲苯]]、[[甲苯]]和[[十二烷基苯]]）的组成和分子尺寸，我们定制了一系列[[吸附剂]]，其平均孔径分别为 4.3 nm（[[AR-1]]）、2.8 nm（AR-2）和 8.5 nm（AR-3）（表 S1−S2）。这些结果表明，孔径可调性源于致孔剂诱导的相分离区域与网络凝胶化动力学之间的协同耦合。

[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算表明，$\mathrm { P F O A } ^ { 3 8 }$ 的特征分子截面约为 1.1 nm（图 S2）。这一计算描述符为评估 [[PFOA]] 与工程化聚合物孔道之间的孔径相容性提供了分子尺度基础。理想的[[吸附]]界面需要最优的孔壁曲率，以最大化分子间范德华接触。<sup>39</sup> 实验结果进一步支持孔径匹配对有效位点利用的重要性：[[AR-1]] 获得了最高的 [[Langmuir模型|Langmuir 最大吸附容量]]（531.8 mg $\mathbf { g } ^ { - 1 } )$），显著优于受到空间位阻和扩散限制制约的 AR-2（123.9 mg $\mathbf { g } ^ { - 1 } { \dot { ) } }$）以及 AR-3（345.3 mg $\mathbf { g } ^ { - 1 } )$）（图 S3，图 2C）。然而，这种容量差异不应被视为内在亲和力更强的直接证据；相反，它主要反映可及吸附位点密度、孔可及性和限域辅助 [[全氟辛酸|PFOA]] 堆积方面的差异。AR-2 的较小孔径会限制分子扩散和内部位点接触，而 AR-3 的较大孔径则会削弱限域驱动的有序化。因此，AR-1 提供了一种优化的拓扑平衡，在保持[[纳米限域]]辅助吸收的同时，最大化可及位点利用。据此，AR-1 被选为后续研究的核心材料。

[[AR-1]] 的精确结构工程通过系统的多尺度表征得到了验证。[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）显示其具有均匀的微球形貌，平均直径约为 430 μm（图 2B）。与元素分析一致，[[能量色散X射线光谱|能量色散 X 射线光谱]]（EDX）证实其元素组成仅包含 $\mathrm { C } , \mathrm { H } ,$ 和 O（表 S3）。在孔结构方面，氮气[[吸附]]−[[脱附]]等温线勾勒出[[介孔]]结构（图 S4），其中 AR-1 表现出 455.2 $\mathbf { m } ^ { 2 } ~ \mathbf { g } ^ { - \mathrm { i } }$ 的[[BET|比表面积]]（表 S2）。值得注意的是，[[Barrett−Joyner−Halenda分析|Barrett−Joyner−Halenda]]（BJH）分析表明，AR-1、AR-2 和 AR-3 的[[孔径分布]]分别集中在 $4 . 0 , 2 . 3 ,$ 和 9.3 nm 处；相应地，它们的 [[PFOA]] [[吸附容量]]随孔结构的不同而显著差异（图 2C）。在光谱学方面，[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）分析分辨出位于 $1 7 3 5 . 6 \mathrm { c m } ^ { - 1 }$ 和 1149.4 $\mathrm { c m } ^ { - 1 }$ 的特征酯吸收带（−CO−O−）（图 2D）。高分辨率 C 1s [[X射线光电子能谱|X 射线光电子能谱]]（[[XPS]]）中的 O−C�O 峰（289.5 eV）进一步证实了这一化学官能团，表明酯功能化口袋已成功整合到[[交联]]网络中<sup>40,41</sup>（图 2E）。至关重要的是，AR-1 在酸性和碱性条件下均保持了结构完整性（图 2F）。结合[[热重分析]]所证明的超过 280 $^ { \circ } \mathrm { C } ^ { \bullet }$ 的热分解温度（图 S5），这些结果凸显了这种孔工程化聚甲基丙烯酸酯[[吸附剂]]在严苛工业环境中长期运行所具有的卓越物理化学稳健性。

## [[AR-1]] 的 [[PFOA]] 去除性能

为了应对复杂工业基质中 [[PFAS]] 分离相关的关键挑战，我们选择以低 pH 值和高 [[全氟和多氟烷基物质|PFAS]] 负荷为特征的[[电镀废水]]作为模型体系，系统评估 [[AR-1]] 的实际适用性。<sup>42</sup> 模拟废水的 pH 值使用盐酸调节至 1.0，以模拟工业排放中普遍存在的极端酸性条件。<sup>43</sup>

动力学分析表明，[[AR-1]] 与包括[[粉末活性炭|粉末活性炭（PAC）]]和[[吸附]]树脂（[[XAD-7HP]]、[[PFA694E]]）在内的商业基准材料一样，均符合[[准一级动力学模型]]，并在 10 h 内达到平衡（图 S6，表 S4）。[[PAC]]、XAD-7HP 和 PFA694E 的详细来源信息、基础材料、预处理方案及织构性质列于表 S2，以确保基准对比的可重复性。表 S4 中报告的 $q _ { \mathrm { e } }$ 值代表在固定初始 [[PFOA]] 浓度下由动力学实验拟合得到的平衡吸附量，因此应与等温线建模得到的[[吸附容量|最大吸附容量]]加以区分。平衡吸附量表现出明显的饱和行为，可用 [[Langmuir 模型]]进行经验描述。然而，这种吻合不应被解释为理想单层吸附机制的确定性证据。使用 [[Freundlich模型|Freundlich]]、[[Sips模型|Sips]]、[[Hill模型|Hill]] 和 [[Dubinin−Astakhov模型|Dubinin−Astakhov 模型]]进行的进一步非线性拟合表明，[[全氟辛酸|PFOA]] 吸附更一致地描述为一种受[[纳米限域]]调控的过程，包括初始聚合物−PFOA 缔合，随后在高负载下发生局部 PFOA−PFOA 有序化和孔填充（图 S7，表 S5，表 S6）。这一修正后的解释使宏观等温线行为与[[分子动力学]]观察到的类胶束聚集体相一致，使用不同模型得到的拟合结果汇总于表 S5 和表 S6。因此，本文报道的饱和容量指 [[Langmuir模型|Langmuir 最大吸附容量]] $( Q _ { \mathrm { m } } ) ,$ ，而非动力学 $q _ { \mathrm { e } } .$。这支持经验饱和行为和有效位点利用，而非随机表面累积。由此，AR-1 表现出 531.8 mg g<sup>−1</sup> 的饱和吸附容量（图 3A），超过 PAC $( \bar { 1 5 4 . 2 \mathrm { m g } } \mathrm { g } ^ { - 1 } )$ 和 $\mathrm { \bar { X A D } - 7 H P } \left( 2 8 7 . 2 \mathrm { m g } \mathrm { g } ^ { - 1 } \right)$ ，但仍低于 [[PFAS]] 专用商业树脂 PFA694E $( 6 8 9 . 8 ~ \mathrm { ~ m g ~ } \mathrm { ~ g ^ { - 1 } } )$（图 3B，表 S5）。这一显著提升表明，AR-1 的捕集机制超越了无序表面吸附；相反，富含酯基的纳米限域区域通过强酸性条件下的协同[[氢键]]和疏水缔合实现 PFOA 的有序富集。

从复杂基质中选择性螯合目标分析物是材料设计中的首要目标。在合成废水中，[[AR-1]]表现出优异的抗基质干扰能力。将无机离子和有机物竞争实验整合到统一比较后，AR-1在所有测试条件下均保持>96%的[[PFOA]][[去除效率|去除率]]，包括10,000倍过量的无机离子$( \mathrm { C l } ^ { - } , \mathrm { S O } _ { 4 } ^ { 2 - } , \mathrm { C O } _ { 3 } ^ { 2 - }$，以及$\mathrm { C a } ^ { 2 + } )$和浓度为[[全氟辛酸|PFOA]] 400倍的有机竞争物如[[草酸]]和[[腐殖酸]]（图3C）。相比之下，[[PAC]]、[[PFA694E]]和[[XAD-7HP]]表现出更明显的性能损失，尤其在腐殖酸存在下，表明它们更容易受到非特异性污染和竞争性[[吸附]]的影响。这些结果证实AR-1在高盐度和富含有机物的条件下仍保持对PFOA的选择性识别。相比之下，这些[[吸附剂再生|吸附剂的再生]]通常需要有机试剂或化学洗脱液，而AR-1仅通过水洗即可再生。这减少了再生过程中的化学品消耗，并降低了二次污染的潜在风险。

为进一步评估[[AR-1]]的[[吸附]]机制是否超出[[PFOA]]，我们评估了具有不同头基和氟碳链长的代表性[[PFAS]]同系物，包括[[全氟羧酸盐]]、[[全氟磺酸盐]]（图S8、图S9、表S7）。AR-1表现出明显的结构依赖性吸附趋势。长链[[全氟和多氟烷基物质|PFAS]]比短链类似物被更有效地捕获，表明氟碳链缔合和[[纳米限域|孔限域]]在稳定PFAS吸附中起重要作用（图S8）。相比之下，短链PFAS如[[PFBA]]、[[PFBS]]表现出较弱的吸附，与其较低的疏水性和较弱的限域稳定性一致（图S8）。包括[[PFHxS]]、[[PFOS]]、[[PFNS]]在内的磺化PFAS表现出与[[全氟辛酸|PFOA]]相当的吸附量。此外，长链PFAS被更有效地捕获（图S8）。这一结果表明磺酸头基也能被富含酯基的纳米限域区域所容纳，而总体亲和力由头基相互作用、链长和限域增强的氟碳缔合共同决定。我们进一步在含有代表性羧酸类、磺酸类PFAS的混合溶液中测试了PFOA去除。与单一溶质PFOA体系相比，共存PFAS的存在改变了PFOA去除，但仍保持>99%，表明对共享吸附域位的竞争有限（图S9）。这些发现表明，AR-1应被描述为对酸性、富含PFAS水体有效的[[吸附剂]]，尤其适用于长链PFAS，而非仅限于PFOA的专用材料。

为了验证这一设计策略在工业环境中的实际有效性，我们在实验室规模的批次[[吸附]]实验中测试了 [[AR-1]]，所用废水为采集自[[江苏省]]某废水处理系统的[[电镀废水]] $\mathrm { ( p H = 1 . 6 , T O C = 3 1 . 9 \ m g L ^ { - 1 } ) }$ 。需要强调的是，该[[吸附剂]]主要针对本质上呈酸性的含 [[PFAS]] 工业废水流而设计。本研究采用的酸性条件旨在再现真实工业废水的实际 pH 环境，并不意味着中性或弱酸性废水应当被人为酸化。因此，AR-1 更适用于在现有中和步骤之前处理酸性点源废水或酸性侧流，而非需要强制酸化的大体积中性水体。本实验并非现场部署、中试规模试验、[[RSSCT]] 或连续流处理测试；相反，其目的是在受控实验室条件下评估 AR-1 在实际废水基质中的性能。尽管存在以共存金属离子 $\left( \mathrm { C r } , \mathrm { Z n } , \mathrm { F e } \right)$ （表 S8）和高有机背景为特征的复杂干扰基质，AR-1 仍实现了对痕量 [[PFOA]] 的深度削减（进水： $7 6 8 . 3 \mathrm { n g L ^ { - 1 } } )$ ，[[去除效率]]超过 99%，出水浓度降至检出限以下）（图 3D）。这种纳克级痕量捕获能力显著优于商业基准材料，包括 [[XAD-7HP]]（去除率 <41%）、[[PFA694E]]（去除率 <66%）和 [[PAC]]（去除率 <32.7%）。必须指出，我们合成的 AR-1 与商业基准 XAD-7HP 完全属于同一化学家族，即非离子型脂肪族丙烯酸酯树脂。因此，AR-1 的优异性能并非来源于新的化学组成，而几乎完全源于精密设计的[[纳米限域]]。值得注意的是，尽管 XAD-7HP 的[[BET|比表面积]] $( 7 5 0 . 0 \ \mathrm { m } ^ { \mathrm { \hat { 2 } } } \ \mathrm { g } ^ { - 1 } )$ 显著高于 AR-1 $( 4 4 5 . 2 \ \mathrm { m } ^ { 2 } \ \mathrm { g } ^ { - 1 } )$ （表 S2），其 [[全氟辛酸|PFOA]] 吸附量仅为 AR-1 的 54.0%。这一差异说明 XAD-7HP 的大孔结构（约 55.0 nm）无法有效限域目标分子。相比之下，AR-1 精密控制的[[介孔]]通道（4.3 nm）可充当拓扑陷阱。在这些复杂基质中的吸附性能由这种拓扑导向的空间限域所决定，而非仅仅取决于酯官能团的存在。

## [[AR-1]] 与 [[PFOA]] 之间相互作用的研究

为揭示 [[AR-1]] 对 [[PFOA]] 高选择性的机制起源，我们构建了一个将光谱表征与量子化学计算相结合的多尺度分析框架。[[FTIR]]（图 S10A）揭示了这一识别过程的分子特征。[[全氟辛酸|PFOA]] 被摄取后，AR-1 中酯官能团化区域表现出明显的振动扰动：羰基伸缩振动（−CO−O−）从 $1 7 3 5 . 6 \mathrm { c m } ^ { - 1 }$ [[红移]]至 $1 7 3 1 . { \overset { \vartriangle } { 5 } } \operatorname { c m } ^ { - 1 } \left( \Delta \nu \right.$ $= 4 . 1 ~ \mathrm { { c m } ^ { - 1 } ) }$，而醚键 $\left( - \mathbf { C } \mathbf { - } \mathbf { O } \mathbf { - } \mathbf { C } \right)$ 则从 $1 1 4 9 . 4 ~ \mathrm { c m } ^ { - 1 } \mathrm { t o } ~ 1 1 4 2 . 5 ~ \mathrm { c m } ^ { - 1 } ~ ( \Delta \nu ^ { - } = 6 . 9 ~ \mathrm { c m } ^ { - 1 } )$ 发生位移。这些光谱位移构成了强[[氢键]]供体−受体耦合的诊断性证据，表明 PFOA 被精确容纳于酯衬结合口袋内。与此互补，[[SEM]]−[[能量色散X射线光谱|EDX]] 元素分布（图 S10B）显示氟信号与聚合物骨架之间存在高度的空间共定位，证实 PFOA 被深度内化于三维多孔基体内部，而非局限于表面[[吸附]]。

采用 [[DFT]] 计算考察了代表性含酯聚合物片段与分子态 [[PFOA]] 之间的局部相互作用模式。[[前线分子轨道|前线分子轨道（FMO）分析]]<sup>44</sup>（图 4A）揭示了 [[AR-1]] 与 [[全氟辛酸|PFOA]] 之间显著的电子互补性：AR-1 的 [[最高占据分子轨道|HOMO]] $\mathsf { \bar { ( - 7 . 8 ~ e V ) } }$ 主要分布在富电子的羰基氧区域，而 PFOA 的 [[最低未占分子轨道|LUMO]]（−1.8 eV）则集中于缺电子的羧基和末端全氟尾链。复合物形成后，体系能隙缩小至 6.1 $\operatorname { e V } ,$，有利于高效的轨道杂化，并建立起定向的供体−受体相互作用路径。关键的是，初始识别阶段受长程静电导向效应支配。[[静电势|静电势（ESP）分布]]（图 4B）显示，AR-1 的羰基氧基序产生了一个深势阱 $( \bar { V _ { \mathrm { m i n } } } = - 3 9 6 . 3 \mathrm { k c a l \ m o l ^ { - 1 } ) }$，而 PFOA 的 −COOH 头基则呈现出明显的正电势中心 $\overline { { \left( V _ { \mathrm { m a x } } \right) } } ^ { \mathrm { ~ ~ } } = \dot { + } 3 0 9 . 6$ kcal $\mathbf { m o l } ^ { - 1 } )$。由此形成的陡峭电势梯度 $\left( \Delta \mathrm { V } = 7 0 5 . 9 \mathrm { k c a l \ m o l ^ { - 1 } } \right)$ 在水相中引导 PFOA 定向迁移至活性位点，介导了从随机扩散向定向[[分子识别]]的转变。此外，几何优化构型（图 4C）揭示了一种多价协同结合机制：羰基氧原子与 PFOA 的羧基氢形成稳定的[[经典氢键]]（1.6 $\mathring { \mathrm { A } } , \ \mathring { \angle } \mathrm { O } - \mathrm { \check { H } } \mathrm { \cdots } \mathrm { O } \ = \ 1 7 0 . 9 ^ { \circ } \big )$），同时酯基 α-甲基与末端氟原子之间出现辅助性[[非经典氢键]]（2.4 Å）。这种双锚定效应与聚合物骨架的疏水限域协同作用，稳定了单一局域结合构型，其[[结合能|本征单点结合能]]为 −14.4 kcal mol<sup>−1</sup>。

热力学竞争分析（图4D）定量揭示了选择性的能量基础。[[AR-1]]对[[PFOA]]的结合亲和力在能量上显著优于其对普遍存在的无机阴离子的结合亲和力，包括${ \mathrm { S O } } _ { 4 } ^ { 2 - }$（−10.5 kcal $\mathrm { m o l } ^ { - 1 } )$ 与 $\mathrm { C l } ^ { - } \big ( - 5 . 7 $ kcal mol<sup>−1</sup>）。基于[[玻尔兹曼统计]]推导出的[[选择性系数]]表明，AR-1对[[全氟辛酸|PFOA]]的理论识别概率分别超出其对${ \mathrm { S O } } _ { 4 } ^ { 2 - }$和$\hat { \mathrm { C l } ^ { - } }$的识别概率729倍和$2 . 4 \times 1 0 ^ { 6 } ,$倍。这种热力学差异解释了AR-1在高盐度条件下仍能保持>99%[[去除效率]]的原因：它反映出简单无机离子难以同时满足富酯受限结合域对几何相容性和局域相互作用的要求。与已有[[吸附剂]]的基准对比进一步表明，AR-1的[[结合能]]（−14.4 kcal mol<sup>−1</sup>）显著优于依赖弱F−F相互作用的氟化材料（−6.7 kcal $\mathbf { m o l } ^ { - 1 } )$）、以[[疏水效应|非特异性疏水效应]]为主导的[[活性炭]]（−12.1 kcal $\mathrm { m o l } ^ { - 1 } )$），以及受酸抑制和竞争性阴离子干扰影响的[[离子交换树脂]]（−3.8 kcal $\mathbf { m o l ^ { - 1 } } )$）（图4D）。因此，AR-1通过涉及定向[[氢键]]相互作用、双氢键锚定和疏水增强的三元协同机制发挥作用，从而即便在强酸性和高盐度条件下也能实现对PFOA的高特异性捕获。

为了在分子水平上阐明[[吸附]]机制，我们将 [[PFOA]] 在 [[AR-1]] 中的富集描述为一个涉及[[分子识别]]、表面锚定和受限自组装的顺序过程。阶段 I：分子识别与锚定。该过程始于 [[全氟辛酸|PFOA]] 单体在[[氢键]]介导下快速结合到 AR-1 表面的酯位点（图 S13）。具体而言，−CO−O− 基序与 PFOA 的 −COOH 头基建立了稳定的[[氢键网络|双重氢键网络]]。这种特异性相互作用使 PFOA 相对普遍共存的阴离子（如 SO<sub>4</sub><sup>2−</sup> 和 Cl<sup>−</sup>）具有决定性的热力学竞争优优势，从而确保高选择性。阶段 II：受限自组装与致密化。表面锚定之后，[[纳米限域]]的孔环境促进吸附态 PFOA 分子的侧向致密化。在[[疏溶剂效应]]和碳氟链相互作用的驱动下，锚定的 PFOA 分子自组装成稳定的半胶束聚集体（图 S14）。我们避免将这些结构称为经典胶束，因为 MD 模拟显示在受限和富集条件下存在局部簇集，但并未独立证实本体胶束化。这些计算见解与实验动力学（图 S15）及以往文献高度一致，从而解释了 AR-1 异常高的[[吸附容量]]。[[DFT]] 计算进一步解构了这种超分子组装的能量学：头基氢键与链间 H−F 相互作用之间的协同效应产生了高达 182.1 kcal mol<sup>−1</sup> 的累积相互作用能（图 S16）。该值显著超过常规 H−O 键的能量（6.5 kcal mol<sup>−1</sup>），表明组装稳定性主要由氟介导的协同相互作用所支撑，从而证明了孔工程策略用于痕量污染物富集的有效性。

[[径向分布函数|径向分布函数（RDF）分析]]量化了 [[AR-1]] 对 [[PFOA]] 的特异性识别特征（图 5B）。位于 1.5 Å 的尖锐主峰归因于 −CO−O− 与 [[全氟辛酸|PFOA]] 的 −COOH 之间稳健的短程[[氢键]]相互作用，构成分子级选择性的结构来源。相反，跨越 3.5−7.0 Å 的宽峰特征表示以[[范德华力]]为主的长程色散吸引，驱动 PFOA 向活性区域预富集。综合来看，这些结果表明 PFOA [[吸附]]通过长程分子募集后经历短程界面锚定进行，[[傅里叶变换红外光谱|FTIR 光谱]]中 −C═O 伸缩振动的[[红移]]在实验上佐证了这一点（图 S10A）。总体上，这些发现表明 AR-1 即使在复杂水相基质中也能对 PFOA 保持高亲和力和特异性，凸显了该设计策略在选择性分离中的独特优势。

## 水触发式可持续再生

[[吸附剂]]的[[可再生性]]构成其工业可行性的决定性因素。<sup>48</sup> 常规再生方案通常涉及热再活化或有机溶剂洗脱，往往受困于过高能耗与二次污染风险。<sup>49</sup> 在 [[AR-1]] 中，再生行为主要受 [[PFOA]] 的 pH 依赖性形态分布与水合作用调控，这削弱了 [[全氟辛酸|PFOA]] 与富含酯基聚合物畴之间的界面相互作用，<sup>50</sup> 调节局部结合环境，并在温和水相条件下实现 PFOA 的可控解吸。<sup>51</sup>

计算模拟揭示，整个 [[AR-1]] 聚合物基体在酸性条件下维持一种超稳定结合态，其特征为累计体系相互作用能（代表模拟无定形胞内多分子组装体的总能量和）为 −4310.9 kcal mol<sup>−1</sup>。与此形成鲜明对比的是，这种体相亲和力在中性条件下被急剧削弱（−948.7 kcal mol<sup>−1</sup>）（图 6A）。这一能量差异建立了跨越数个数量级的陡峭热力学梯度，为解吸提供了深远的驱动力。实验验证证实了这一预测：通过中性水相洗脱即可实现近定量再生，无需化学试剂。通过仅用水即可实现快速回收，这种能量梯度驱动机制规避了常规热再生或溶剂再生方案所伴随的过高能耗惩罚与二次污染风险（图 6B）。此外，AR-1 在连续五个循环中保持了稳健的捕获性能，容量衰减可忽略不计（图 6C），证明了其结构稳定性与运行韧性。在[[固定床柱实验|动态固定床柱实验]]中，AR-1 展现出卓越的工业潜力：处理 102.0 L 进水后，仅用 0.9 L 洗脱液即实现有效柱再生（解吸效率 85.8%），富集因子达 113.3 倍（图 S17）。这一高效浓缩过程模拟了肾脏浓缩机制，能够以最低的水与能源足迹实现污染物可持续削减。

为系统阐明水基再生过程的分子机制，我们应用了[[基于 Hirshfeld 分区的独立梯度模型|基于 Hirshfeld 分区的独立梯度模型（IGMH）]]来表征主要结合位点处的相互作用。由于 [[PFOA]] 的 $\mathsf { p } K _ { \mathrm { a } }$ 仍存在争议，我们并未假定 [[全氟辛酸|PFOA]] 在 pH 1.0 下完全质子化。相反，将分子态 PFOA 与去质子化 PFOA 作为两种极限状态，以评估羧基形态如何影响 [[AR-1]] 的亲和力。计算得到的分子态 PFOA 与去质子化 PFOA 在 AR-1 主要结合位点处的[[结合能]]分别为 −30.9 和 −7.4 kcal mol<sup>−1</sup>（图 6D），表明中性 COOH 形式可通过与酯基之间的直接 COOH···O [[氢键]]显著增强局部结合。然而，去质子化 PFOA 仍通过[[纳米限域]]、氟碳链的疏水/疏溶剂相互作用以及与富酯结构域可能存在的[[离子−偶极相互作用]]，对 AR-1 表现出残余亲和力。因此，酸性条件下较高的 PFOA [[吸附]]量不应被解释为 PFOA 完全质子化的证据，而应视为限域增强吸附的协同结果；若存在部分质子化，则会进一步强化界面结合。在中性水洗条件下，由于 PFOA 向水合程度更高的羧酸根状态转变，吸附亲和力显著降低。这一转变削弱了直接的 COOH−酯[[氢键网络]]，增强了 PFOA−水相互作用，并使孔道内受限的 PFOA 聚集体失稳。同时，富酯聚合物结构域的再水化与界面重排进一步降低了局部结合亲和力。因此，[[水触发再生]]主要受 PFOA 去质子化/水合诱导的亲和力损失控制，并辅以[[吸附剂]]界面重组，而非仅由聚合物构象变化决定。IGMH 分析（图 6E）表明，PFOA 的羧基同时与 AR-1 酯基中的羰基氧和醚氧形成双重氢键受体。这种双重氢键网络确保了酸性条件下的稳定锚定，但随着 pH 升高逐渐解离，从而形成“强结合−易[[脱附]]”的协同平衡。进一步的相互作用分解表明，在酸性条件下，氢键提供稳定作用，而范德华贡献较小。当 PFOA 羧基解离后，氢键网络崩塌，转变为以范德华作用为主的弱相互作用状态（图 6F），从而大幅降低整体吸附能，并实现水驱动、环境友好的再生。这种“[[水介导再生]]”策略无需额外化学试剂，有效避免了传统再生过程的高能耗与二次污染，并为开发用于水处理的可持续、高稳定性先进吸附剂建立了新的设计范式。

## ■ 环境影响

本研究展示了一种基于限域效应的聚合物设计策略，用于在[[点源酸性工业废水|酸性工业废水]]中捕集 [[PFOA]]。[[AR-1]] 并非作为通用型 [[PFAS]] 处理材料，而是最适用于酸性点源工业废水，包括电镀、含氟化学品制造及半导体相关废水。在此类水体中，酸性、高离子强度、溶解态金属和有机物通常都会降低[[活性炭]]及常规[[离子交换树脂]]的处理效果。因此，AR-1 被提出作为一种针对已呈酸性的工业废水的精处理[[吸附剂]]，从而避免对中性废水进行大规模酸化处理。机理研究表明，AR-1 的优异性能由多尺度协同机制支撑：[[氢键]]和局部极性相互作用首先促进聚合物与 [[全氟辛酸|PFOA]] 的优先结合，而[[介孔]]限域效应随后增强 PFOA 在孔道内的停留与局部富集。凭借这种结构−功能协同作用，AR-1 在以高盐度和高有机负荷为特征的实际[[电镀废水]]中显著优于商业基准材料（[[PAC]] 和 [[XAD-7HP]]）。

从工程角度看，[[AR-1]] 主要被设想为一种可再生的填充床或滤芯式[[吸附剂]]，用于[[点源酸性工业废水]]处理，而非类似 [[PAC]] 的材料——后者需要分散、沉降和后分离。因此，本研究中的 [[粉末活性炭|PAC]] 对比旨在作为质量归一化的性能基准，而非表明二者具有相同的现场部署方式。[[固定床柱实验]]进一步支持这一部署概念，表明饱和的 AR-1 可通过水洗脱再生，并能将捕获的 [[PFOA]] 浓缩到显著更小的液体体积中。关键在于，利用 pH 调控的[[吸附]]能梯度，AR-1 实现了高效的[[水介导再生]]，获得了 113.3 倍的污染物富集因子，并建立了可持续、低能耗且无二次污染的捕获−释放循环。这一特性在环境方面十分重要，因为它最大限度地减少了二次化学品投入，并将大量受污染废水转化为小体积的 [[PFAS]] 富集再生液。然而，再生步骤并不能破坏 [[全氟辛酸|PFOA]]；因此，浓缩后的再生液应与下游破坏性处理相结合，例如[[电化学氧化]]、[[等离子体处理]]、[[热矿化]]或其他经过验证的 [[全氟和多氟烷基物质|PFAS]] 销毁技术，或通过安全处置进行管理。尽管如此，向全规模运行转化仍需要在本概念验证试验之外开展进一步验证。尽管在本文实验条件下[[腐殖酸]]和共存离子造成的容量损失可忽略不计，但实际处理流程中的[[天然有机物]]可能同时产生竞争性和物理性污染效应，包括孔道堵塞、表面覆盖、[[生物膜]]积累以及水力阻力增加。因此，未来工作应在中试规模连续流条件下评估长期穿透行为、压降变化、介质磨损、再生耐久性、预处理或反冲洗需求，以及更广泛 PFAS 混合物中的性能。总体而言，本研究验证了分子工程为克服当前吸附剂的固有局限提供了一条稳健路径，为开发用于 PFAS 修复的高选择性、可持续再生材料确立了变革性设计范式。

## ■ 方法

## 实验方法

[[吸附]]实验。吸附实验在 25 °C 下使用所配制的 [[PFOA]] 溶液进行，摇床转速为 150 rpm，并使用 12 mol L<sup>−1</sup> 盐酸将溶液 pH 调节至 1.0。所有测试样品均通过 0.22 μm 聚丙烯（PP）滤膜过滤。实验中使用的[[吸附剂]]包括 [[AR-1]]、[[粉末活性炭|粉末活性炭（PAC）]]、[[PFA694E]]（[[Purolite]]）和吸附树脂（[[XAD-7HP]]）。作为商业基准使用的 [[PAC]] 为 FUCHEN，购自中国天津市福晨化学试剂厂；CAS 号为 7440-44-0。根据供应商信息，该 PAC 为煤基[[活性炭]]。使用前，PAC 用超纯水洗涤以去除细小杂质，在 $6 0 ~ ^ { \circ } \mathrm { C }$ 下干燥 48 ${ \mathrm { h } } ,$，并储存于干燥器中。除非另有说明，所有吸附实验均在 $2 5 ~ ^ { \circ } \mathrm { C }$ 下进行，摇床转速为 150 rpm。使用盐酸将 [[全氟辛酸|PFOA]] 溶液的 pH 调节至 1.0，以模拟强[[点源酸性工业废水|酸性工业废水]]。吸附后，悬浮液在化学分析前通过 0.22-μm 聚丙烯滤膜过滤。所有实验均进行三次重复，结果以平均值 ± 标准差报告。

## [[吸附动力学]]

在动力学实验中，将 20 mg [[吸附剂]]加入 150 mL 初始浓度为 120 mg $\mathrm { L } ^ { - 1 }$ 的 [[PFOA]] 溶液中。悬浮液在 $2 5 ~ ^ { \circ } \mathrm { C }$ 和 150 rpm 条件下振荡，并在 50 h 内按预定时间间隔取样。残余 [[全氟辛酸|PFOA]] 浓度通过 [[高效液相色谱|HPLC]] 测定。[[去除效率]]使用下式计算：

$$
\text{Pollutant Removal Efficiency} = \frac {C _ {0} - C _ {t}}{C _ {0}} \times 100 \%\tag{1}
$$

式中，$C _ { 0 } \left( \mathrm { m g L ^ { - 1 } } \right)$ 表示污染物的初始浓度，$C _ { \mathrm { t } } \left( \mathrm { \bar { m } g L ^ { - 1 } } \right)$ 表示时间 t 时污染物的残余浓度。为描述[[吸附]]速率，采用[[准一级动力学模型]]对实验数据进行拟合。原始方程如下：

$$
q _ {t} = q _ {e} (1 - e ^ {- k _ {1} t})\tag{2}
$$

其中，$q _ { \mathrm { e } } \left( \mathbf { m } \mathbf { g } \mathbf { g } ^ { - 1 } \right)$ 为平衡[[吸附]]量，$q _ { \mathrm { t } } \left( \mathbf { m } \mathbf { g } \ \mathbf { g } ^ { - 1 } \right)$ 为时间 $\mathbf { t } , k _ { 1 }$ 时每克[[吸附剂]]吸附的污染物的量，$( \mathrm { m i n } ^ { - 1 } )$ 为准一级动力学的[[速率常数]]。

## [[吸附容量]]

配制浓度范围为 40 至 280 mg L<sup>−1</sup> 的 [[PFOA]] 水溶液。将 50 mg [[吸附剂]]加入 150 mL 目标溶液中，振荡 48 h。所有实验均在 $2 5 ~ ^ { \circ } \mathrm { C }$ 下进行，搅拌速率为 150 rpm。[[平衡吸附容量]]由初始与平衡 [[全氟辛酸|PFOA]] 浓度之差计算。所报告实验数据为三次重复实验的平均值。[[吸附容量]]使用下式计算：

$$
q _ {e} = \frac {(C _ {0} - C _ {e})}{m} V\tag{3}
$$

其中，$q _ { \mathrm { e } } \left( \mathbf { m } \mathbf { g } \mathbf { g } ^ { - 1 } \right)$ 为每克[[吸附剂]][[吸附]]的污染物的量，$\check { C _ { 0 } } \check { ( } \mathrm { m g } \mathrm { L } ^ { - 1 } )$ 和 $C _ { \mathrm { e } } \ ( \mathrm { m g \ L ^ { - 1 } } )$ 分别表示污染物的初始浓度和残余浓度。m（mg）为吸附剂的质量，V（mL）为污染物水溶液的体积。

将所得数据拟合至 [[Langmuir模型|Langmuir]] 和 [[Freundlich 模型]]。[[Langmuir 模型]]是一种[[吸附等温线|单层吸附等温线]]，假设[[吸附]]位点均匀分布在[[吸附剂]]表面上。[[Freundlich模型|Freundlich]] 模型描述的是用于非均质表面的经验吸附等温线，考虑了吸附过程的非均匀性。Langmuir 和 Freundlich 方程如下所示：

$$
q _ {e} = \frac {Q _ {m} K _ {L} C _ {e}}{1 + K _ {L} C _ {e}}\tag{4}
$$

$$

## [[竞争吸附]]研究

[[竞争吸附]]实验在含有多种共存离子的去离子水中进行。对照组使用不添加离子的去离子水，而实验组则分别补充 $\mathrm { C a C l _ { 2 } , N a C l , N a _ { 2 } S O _ { 4 } }$ 和 ${ \bar { \mathrm { N a H C O } } } _ { 3 } ,$，各浓度为 500 mg/L，以模拟[[电镀废水]]中通常存在的水平。每种溶液均加入浓度为 $5 0 \mu \mathrm { g } / \mathrm { L } ,$ 的 [[PFOA]]，并用盐酸将 pH 调节至 1。随后，将 20 mg [[吸附剂]]（[[AR-1]]、[[XAD-7HP]]、[[PFA694E]] 或 [[PAC]]）加入 150 mL 溶液中，振荡 24 h。所有实验均进行三次重复。报告值以三次独立重复实验的均值 ± 标准差表示。同时，实验组补充[[草酸]]和[[腐殖酸]]，浓度各为 20 mg/L，而对照组使用不添加任何添加剂。每种溶液均加入浓度为 50 $\mu \mathrm { g / L }$ 的 [[全氟辛酸|PFOA]]，并用盐酸将 pH 调节至 1。随后，将 20 mg [[吸附]]剂（AR-1、XAD-7HP、PFA694E 或 [[粉末活性炭|PAC]]）加入 150 mL 溶液中，振荡 24 h。所有实验均进行三次重复，报告值以三次独立重复实验的均值 ± 标准差表示。

## 针对结构多样 [[PFAS]] 及 [[全氟和多氟烷基物质|PFAS]] 混合物的[[吸附]]实验

为评估 [[AR-1]] 对结构多样 [[PFAS]] 的适用性，选取代表性[[全氟羧酸盐]]（[[PFBA]]、[[PFHxA]]、[[PFOA]] 和 [[PFNA]]）及[[全氟磺酸盐]]（[[PFBS]]、[[PFHxS]]、[[PFOS]] 和 [[PFNS]]）作为目标污染物。单溶质和混合组分[[吸附]]实验在与 [[全氟辛酸|PFOA]] 吸附相同的酸性条件下进行。对于单溶质体系，每种 [[全氟和多氟烷基物质|PFAS]] 溶液配制浓度为 100 μg $\dot { \mathrm { ~ L ~ } ^ { - 1 } }$。对于混合 PFAS 体系，每种 PFAS 的初始浓度也为 100 $\mu \mathrm { g ~ L ^ { - 1 } }$。简言之，将 20 mg AR-1 加入 150 mL PFAS 溶液中，并用盐酸将 pH 调节至 1.0。在 $2 5 ~ ^ { \circ } \mathrm { C }$ 下振荡 24 ${ \mathrm { h } } ,$ 后，样品经 0.22 μm [[聚丙烯膜]]过滤，并通过 UPLC/ESI-tqMS 进行定量。所有实验均进行三次重复，结果以均值 ± 标准差报告。

## [[吸附剂再生|吸附剂的再生]]

将50 mg已[[吸附]][[PFOA]]的$\operatorname { A R - 1 } ,$置于150 mL去离子水中，在$2 5 ~ ^ { \circ } \mathrm { C }$和150 rpm条件下振荡24 h。随后通过离心分离[[AR-1]]并干燥，用于下一次吸附实验。采用[[高效液相色谱|HPLC]]分析滤液中[[全氟辛酸|PFOA]]的浓度，以计算[[去除效率]]。再生样品暴露于相同浓度和体积的PFOA溶液中，[[吸附-脱附循环|吸附/脱附循环]]重复五次。将3 mL AR-1[[吸附剂]]装入内径为10 mm的色谱柱中。配制10 mg/L的PFOA溶液，并用盐酸将其pH调节至1。使用[[蠕动泵]]（BT100−2J，Longer，中国）使PFOA溶液以每小时10倍床层体积（10 $\mathrm { B V / { h } ; \Omega ^ { \mathrm { ~ 1 ~ B V } } = \Omega ^ { 3 } }$ mL）的流速通过吸附柱。所有实验均在$2 5 ~ ^ { \circ } \mathrm { C }$下进行。[[固定床实验]]作为实验室规模的吸附−[[脱附]]富集测试，使用pH 1.0的合成PFOA溶液进行。该实验旨在评价柱再生和污染物富集行为，而非代表实际[[电镀废水]]的中试规模处理。对于富集、浓缩和脱附实验，使用蠕动泵以每小时1倍床层体积的流速$\left( 1 ~ \mathrm { B V / h } ; 1 ~ \mathrm { B V } = 3 ~ \mathrm { m L } \right)$用水洗脱饱和的AR-1吸附剂。所有样品在采用高效液相色谱（HPLC）分析前均经[[聚丙烯膜|聚丙烯（PP）膜]]过滤。
