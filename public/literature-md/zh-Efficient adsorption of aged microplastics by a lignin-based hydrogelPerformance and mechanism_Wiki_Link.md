# 基于[[木质素]][[水凝胶]]对[[微塑料|老化微塑料]]的高效[[吸附]]：性能与机理

## 摘 要

[[微塑料]]在环境中的[[老化]]现象普遍存在，并对[[生态系统健康]]构成风险。因此，开发有效去除[[老化微塑料]]的策略至关重要。本研究在模拟真实水体环境中，利用 [[紫外光|UV]] 和/或 [[过氧化氢|H₂O₂]] 处理，系统考察了 1 μm 和 5 μm [[聚苯乙烯|聚苯乙烯（PS）]]微塑料在不同 [[pH]] 条件下的老化行为。结果表明，在中性和碱性条件下，[[紫外辐照|UV]]/H₂O₂ 处理使 1 μm 和 5 μm PS 微塑料发生显著老化和破碎，形成更小颗粒，且[[含氧官能团|含氧官能团数量]]增加。随后，研制了一种绿色[[木质素基水凝胶]]（[[水凝胶|LG-GH-PVA@2]]），用于高效[[吸附]][[氧化聚苯乙烯|老化 PS]]。与[[原始聚苯乙烯|原始 PS]] 相比，在 pH 7.0 时水凝胶对[[老化聚苯乙烯|老化 PS]] 的[[吸附容量]]提高了 105.5%，在 pH 3.0、7.0 和 10.0 下的[[平衡吸附容量]]分别为 347.3 ± 15.81、395.7 ± 17.65 和 427.6 ± 16.42 mg/g。开展了实验表征、[[密度泛函理论|密度泛函理论（DFT）]]计算以及基于波函数的实空间非共价相互作用可视化分析。对于原始 PS，主要吸附增强机制涉及 [[π–π 堆积]]和 [[C–H⋅⋅⋅π 相互作用]]。值得注意的是，老化 PS 表面具有更高浓度的含氧官能团和更高的极性，使[[吸附机制]]主要转变为更强的[[氢键]]和[[静电相互作用]]。更重要的是，本研究不仅深化了对微塑料环境老化行为及界面机制的认识，也为基于微塑料自演化规律开发定向修复技术提供了新策略。

## 1. 引言

作为一种[[新兴污染物]]，[[微塑料]]在环境中经历广泛的[[老化|老化过程]]，显著影响其迁移行为和[[毒理学效应]]。这些颗粒威胁[[生态系统健康]]，并直接损害海产品的安全与质量 [1–4]。在复杂水生环境中，微塑料经历多重老化过程，导致表面裂纹和孔隙的形成、[[含氧官能团]]的增加以及分子量和结晶度的降低 [5,6]。塑料碎片的物理化学变化不仅增强其持久性和毒性，还使其能够[[吸附]]多种污染物，如[[重金属]]和[[有机污染物]] [7–9]。此外，塑料碎片可通过[[食物网|水生和陆生食物网]]传输并累积有毒物质，使微塑料污染成为对生态系统完整性和人类健康最重大的威胁之一 [10,11]。

人们普遍认识到，[[微塑料|原始微塑料]]表面通常带负电，且这种[[电负性]]往往随[[老化]]而增强，使其去除更加困难，尤其是对于小于 5 μm 的颗粒 [12–14]。尽管围绕微塑料老化已开展了大量研究——涵盖[[紫外辐照]]、$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 处理、组合 $\mathrm { U V / H _ { 2 } O _ { 2 } }$ 方法以及其他老化过程 [15–18]——但目前仍缺乏系统研究，深入考察 $\mathrm { U V / H _ { 2 } O _ { 2 } }$ 协同体系在 [[pH]] 梯度下对 [[聚苯乙烯|PS]] 老化行为的调控作用，或开发相应的去除技术。在现有技术中 [19–22]，[[吸附]]因其效率高、环境相容性好以及二次污染风险低等诸多优点而受到广泛关注 [23,24]。目前的吸附去除方法主要集中于以[[老化微塑料]]为吸附剂，捕获金属离子、抗生素、染料及其他污染物 [25,26]。尽管通过吸附去除老化微塑料已引起越来越多的关注 [17,24,27,28]，但对微塑料与[[木质素基水凝胶]]在老化前后相互作用机制的系统认识仍然不足。值得注意的是，[[木质素]]作为一种天然芳香族大分子，因其来源丰富、成本低、[[生物相容性]]优良且具有可持续可获得性，被广泛用于污染物吸附材料的开发 [27–29]。此外，木质素基[[水凝胶]]具有丰富的芳香结构，其[[亲水性]]、[[疏水性]]及结构特性可通过优化原料组成和配比加以调控，无需复杂的化学改性 [30]。

[[木质素基水凝胶]]具有独特的性能，包括优异的稳定性、对酸性和碱性环境的耐受性以及良好的[[生物相容性]][31,32]。本研究以[[聚乙烯醇|聚乙烯醇（PVA）]]和[[聚乙烯亚胺|聚乙烯亚胺（PEI）]]制备了[[水凝胶|LG-GH-PVA@2]]，其中含有的强极性官能团可作为[[交联剂]]，增强水凝胶的网络结构和稳定性。此外，这些基团赋予材料[[亲水性]]，并增强水凝胶与[[微塑料|老化微塑料]]之间的[[静电作用]]和分子间相互作用[33]。在不同[[pH]]条件下开展了[[紫外辐照]]和/或$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$氧化[[老化]]实验，以考察微塑料的老化行为。系统研究了不同[[粒径]][[老化微塑料]]的表面形貌、化学组成、[[疏水性]]及$\zeta$电位，以理解老化过程的影响。[[吸附]]实验表明，[[木质素|LG]]-GH-PVA@2具有清晰的三维网络结构、丰富的芳香结构和极性官能团，在去除老化微塑料方面表现出增强的效能。开展了分子[[静电势]]（[[ESP]]）、[[结合能|结合能（E）]]以及基于独立梯度模型（[[IGMH]]）的Sheffield分子密度分析。[[密度泛函理论|密度泛函理论（DFT）]]计算表明，老化过程提高了[[聚苯乙烯|PS]]微塑料模型分子的极性，增强了其相互作用（[[氢键]]和[[静电相互作用]]），并改变了PS在木质素、PEI和PVA分子上的吸附模式。本研究不仅为微塑料的环境老化机制提供了全面认识，也为开发用于高效去除微塑料的功能化吸附材料奠定了理论基础。

## 2. 材料与方法

## 2.1. 材料与试剂

本研究使用的化学品，包括[[氯化钠|氯化钠（NaCl）]]、[[氯化镁]]$\begin{array} { r l } { { ( { \bf { M g } } { \bf { C l } } _ { 2 } ) } } & { { } } \end{array}$、[[氯化钙]]（CaCl ）、[[氯化铝]]$( \operatorname { A l C l } _ { 3 } ) _ { : }$、[[氯化铁]]（FeCl ）、[[盐酸|盐酸（HCl）]]、[[氢氧化钠|氢氧化钠（NaOH）]]、[[聚乙烯亚胺]]（PEI，分子量约10,000，99%）、[[聚乙烯醇|聚乙烯醇（PVA）]]、[[富里酸|富里酸（FA）]]、[[腐殖酸|腐殖酸（HA）]]和[[过氧化氢]]$\mathrm { ( H _ { 2 } O _ { 2 } ) } .$，均为分析纯，购自上海麦克林生化科技$\mathrm { C o . , }$有限公司。[[聚苯乙烯|聚苯乙烯微球]]悬浮液（PS，直径分别为5 µm和1 µm）作为模型[[微塑料]]，购自[[泰国石化工业公司]]。[[木质素|改性木质素（LG）]]、[[木质素基水凝胶|木质素-环氧氯丙烷-聚乙烯醇水凝胶]]（[[水凝胶|LG-GH-PVA@2]]）和木质素-[[环氧氯丙烷]]聚乙烯醇水凝胶（LE-GH-PVA）均在本实验室合成，具体制备步骤详见我们前期工作（具体制备方法见补充材料）。所有试剂均未经进一步纯化直接使用。

## 2.2. 表征

[[水凝胶]]的化学结构通过 [[FTIR]]（[[傅里叶变换红外光谱|FTIR]]−650S，上海舒利）进行表征。[[聚苯乙烯|PS]] 团聚体在[[倒置荧光显微镜]]（WFM−3680，上海宇光）下观察。[[微塑料]]样品经真空干燥后压制成片。表面形貌通过 [[SEM]]（S3400–I，[[日立]]）观察。孔结构通过 [[N₂ 吸附]]（ASAP 2460，[[麦克仪器]]）测定。表面元素组成及 C、O 的化学态通过 [[XPS]]（K-Alpha+，[[赛默飞世尔]]）使用 Al Kα 辐射分析。原始和[[老化微塑料]]的[[接触角]]使用[[光学接触角分析仪]]（OCA 30，[[Data Physics]]）测量。[[ζ电位|ζ 电位]]使用 [[Zetasizer]]（[[马尔文]]）测定。[[疏水性|孔疏水性]]通过 [[共聚焦激光扫描显微镜|CLSM]]（TCS SP8，[[徕卡]]）表征。

## 2.3. [[聚苯乙烯|PS]] [[老化]]实验

[[紫外光|UV]]/[[过氧化氢|H₂O₂]] 法将 [[聚苯乙烯|PS]] 溶液（2.0 g/L）用 0.1 M [[盐酸|HCl]]/[[氢氧化钠|NaOH]] 调节至 [[pH|pH 3.0]]、7.0 和 10.0，随后加入 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 至最终浓度 100 mg/L（0.01 wt%）。连续 [[紫外辐照|UV 照射]] 5 天后，悬浮液在指定 pH 下保持 5 天。[[老化]]后，样品经离心、蒸馏水洗涤三次，然后在 $5 5 ~ ^ { \circ } \mathrm { C }$ 下真空干燥 8 h。最终得到[[微塑料|老化微塑料]]粉末用于后续使用。氧化法仅使用 0.01/wt% H₂O₂（无 UV）。仅 UV 法使用 UV（254 nm，5.58 W/m²，10 cm）而不含 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$。对照组既不使用 H₂O₂ 也不使用 UV，仅在各 pH 下保持 PS 溶液 5 天。

## 2.4. 检测方法

为测定[[氧化聚苯乙烯|老化 PS]] 颗粒的浓度，在 215 nm 处进行[[紫外-可见分光光度分析]]。使用五个系列稀释液（1.0、5.0、10.0、20.0 和 50.0 mg/L）绘制[[标准曲线]]，得到线性回归方程 o $\mathbf { y } = - 0 . 0 2 5 3 6 + 0 . 0 2 1 2 \mathbf { x } ( \mathrm { R } ^ { 2 }$ $> 0 . 9 9 9 ) ( \mathrm { F i g . ~ S 1 } )$。该方程用于计算所有样品的浓度。[[方法检出限]]（MDL）定义为七个空白重复样标准偏差的三倍，而[[定量限]]（LOQ，10σ）测定为 0.225 μg/L。在处理过的河水中以不同浓度进行的[[加标回收实验]]得到平均回收率为 94.2% 至 98.8%（RSD < 6%）（表 S1），证实了满意的提取准确度。为评估壁[[吸附]]，在无凝胶条件下于 0 和 5 h 测量反应器和玻璃器皿中的[[老化聚苯乙烯|老化 PS]] 浓度（图 S2）。观察到的损失小于 2.5%，对质量平衡计算而言可忽略不计。此外，含有超纯水（无[[老化]] [[聚苯乙烯|PS]]）的空白对照与各批次样品同时分析，未检测到显著的 PS 信号，排除了程序性污染。

## 2.5. [[吸附]]与[[解吸]]实验

[[吸附]]实验在室温（25 ◦C）下进行，振动速度为 200 rpm。[[微塑料]]与凝胶的质量比为 1:20，吸附溶液体积为 50 mL。关于[[去除效率]]（η）、[[吸附容量]]（q）、[[平衡吸附容量]] $\left( q _ { \mathrm { e } } \right)$、[[吸附动力学]]和[[解吸]]实验条件的研究与计算的详细数学公式和全面说明，具体方法见补充材料。

## 2.6. [[吸附]]机理

使用[[尼罗红|尼罗红荧光探针法]]评价[[水凝胶]]孔道的内部[[疏水性]]。在该分析中，将合成的水凝胶样品浸入微摩尔浓度的尼罗红溶液中，使探针能够在整个凝胶网络中扩散。浸渍后，通过温和冲洗小心去除表面[[吸附]]的尼罗红分子，以尽量减少后续测量中的背景干扰。随后利用[[共聚焦激光扫描显微镜]]（CLSM）检测并定量荧光信号，从而对水凝胶内部疏水区域进行全面表征。

为探究[[老化|老化过程]]中形成的[[含氧官能团]]对物质极性以及[[吸附|吸附剂]]吸附行为和容量变化的影响，使用 [[ORCA|ORCA 5.0.1]] 版本进行了 [[DFT]] 计算[34]。计算所用的 [[聚苯乙烯|PS]]、[[氧化聚苯乙烯|老化 PS]] 及[[水凝胶]]组分的分子模型见图 S3 和 S4。模型分子及其相应吸附聚集体的几何优化采用 BLYP 泛函并结合 Grimme 的 D3 色散校正（[[BLYP-D3]]）[35]。这些计算引入类导体极化连续介质模型（[[CPCM]]）以模拟溶剂化效应，以水为溶剂，并使用 [[Def2-TZVP]] 基组[36]。为考虑基组重叠误差（[[BSSE]]），同时应用了几何反平衡（[[gCP]]）校正方法[37]。PS 模型分子及其衍生物在[[木质素]]、[[聚乙烯亚胺|PEI]] 和 [[聚乙烯醇|PVA]] 分子上的初始聚集体结构及吸附构型使用 [[Molclus]] 构建[38]。使用 [[Multiwfn]] 软件包进行 [[ESP|EPS]] 和 [[IGMH 分析]]，以定量表征并可视化分子聚集体内分子间相互作用的性质[39]。此外，通过计算[[结合能|结合能（E）]]量化了 PS 模型分子及其衍生物与木质素、PEI 和 PVA 分子之间的相互作用强度。

不同[[粒径]]、经历不同[[老化]]条件 $\mathrm { ( H _ { 2 } O _ { 2 } }$ 和/或[[紫外辐照|紫外线照射]]）并在不同 [[pH]] 水平下的样品。[[原始聚苯乙烯|原始 PS]] 的特征吸收带出现在 $6 9 5 \mathrm { c m } ^ { - 1 }$ 和 $7 5 5 \mathrm { c m } ^ { - 1 } ,$，对应于单取代苯环中 [[C–H键|C–H 键]]的面外弯曲振动。位于 841 $\mathrm { c m } ^ { - 1 }$ 的吸收峰归属于对位双取代苯中 C–H 键的面外变形。位于 $1 4 5 0 ~ \mathrm { c m } ^ { - 1 }$ 的峰与亚甲基中 C–H 弯曲振动相关，而吸收带 $\mathrm { a t } 1 4 9 5 \mathrm { c m } ^ { - 1 }$ 对应于[[芳香环|芳香 C–C 键]]伸缩振动。芳香环的 C–H 弯曲模式出现在 $1 6 0 1 ~ \mathrm { { c m } ^ { - 1 } }$ [40,41]。

在经过$\mathrm { H _ { 2 } O _ { 2 } } , \mathrm { H _ { 2 } O _ { 2 } } / \mathrm { U V }$辐照或[[pH|pH 10.0]]下的[[紫外辐照]]处理后，$1 7 2 7 \mathrm { c m } ^ { - \bar { 1 } }$处光谱峰的显著变化可归因于[[羰基|羰基（C––O）]]官能团的伸缩振动。同时，在$1 1 5 5 ~ \mathrm { c m } ^ { - 1 }$处观察到的增强信号被归因于[[C–O键|C-O键]]的伸缩振动。值得注意的是，仅暴露于紫外辐照时，各pH水平（3.0、7.0和10.0）下[[老化|老化程度]]的变化极小，这表明pH主要在H<sub>2</sub>O<sub>2</sub>存在的情况下影响氧化过程。此外，在短短五天的老化期后，1 μm [[聚苯乙烯|PS]]颗粒中C––O和[[醚基|C–O]]峰的强度略弱于5 µm颗粒，这表明较小的颗粒在初始阶段并不会老化得更快。在所有老化模式和pH条件下均检测到氧化特征，表明碱性环境深刻改变了PS[[微塑料]]的表面化学性质，从而调节其环境反应性、聚集行为及污染物相互作用潜力[40,41]。

## 3.2. [[聚苯乙烯|PS]][[老化]]前后的形貌及[[接触角]]

对[[SEM]]图像（图2a）的分析表明，原始[[聚苯乙烯|PS]]颗粒均匀、呈规则球形，但表现出明显的凹凸表面结构，尤其是在5 μm颗粒中[42]。经过五天的$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { U V }$氧化处理后，PS的降解表现出显著的[[pH]]依赖性。在碱性条件下（pH 10.0），[[羟基自由基]]引起的[[氧化降解|氧化侵蚀]]诱导了明显的破碎，生成更小的颗粒，其表面非常光滑且分散均匀，表明氧化降解程度最高。在中性pH（7.0）下，5 μm和1 μm[[微塑料]]均发生显著降解，形成形状规则的球形颗粒。在酸性条件下（pH 3.0），仅5 μm PS样品破碎为小颗粒，而1 μm PS颗粒自身未发生明显破碎。然而，它们的表面清晰显示出氧化特征，包括大量凸起微粒。据信，酸性环境中较低的降解程度可能源于[[羟基]]自由基稳定性的降低[43,44]。这些形貌变化与塑料[[老化|老化行为]]一致，证实pH通过调节自由基稳定性来影响氧化降解效率[43,44]。

基于所获得的[[SEM]]图像，对[[聚苯乙烯|PS]]的[[粒径]]变化进行了分析，如图2b和2c所示。对两种初始粒径不同的PS样品在整个[[老化|老化过程]]中的粒径分布进行了追踪。对于初始为5 μm的PS颗粒，[[pH|pH 3.0]]条件下的老化颗粒主要分布于$0 . 6 \substack { - 3 . 5 \ \mu \mathrm { m } } ,$，平均粒径为2.45 μm。在pH 7.0和pH 10.0条件下，粒径分布主要集中在0.6至1.5 μm之间，平均直径分别为1.54 μm和1.21 μm。相比之下，原始1 μm PS颗粒在pH 3.0条件下呈现以0.8–1.0 μm为中心的分布，平均粒径为0.88 μm。在pH 7.0和pH 10.0条件下，粒径主要位于0.5–0.8 μm范围内，平均值分别为0.62 μm和0.53 μm。这些结果表明，在[[紫外光|UV]]/[[过氧化氢|H₂O₂]]老化过程中，较高的pH条件会促进更大程度的粒径减小，且对于初始粒径较大的PS颗粒，这一效应更为显著[45]。此外，即使在中性条件下，明显的老化与降解仍然持续存在，表明这些过程在自然环境中很可能普遍发生。重要的是，进一步证明，即使在酸性环境中，紫外光下的[[活性氧物种]]也容易将[[微塑料]]降解为小的球形颗粒，从而增加了去除工作的难度。

## 3.4. [[聚苯乙烯|PS]][[老化]]前后的表面电荷

对[[老化]]前后的 [[聚苯乙烯|PS]] 微球 [[ζ电位|ζ 电位]]进行了分析，结果如图 4a 和 b 所示。分析表明，无论[[粒径]]为 5 μm 还是 1 μm，[[微塑料|PS 颗粒]]的 ζ 电位均受 [[pH]] 显著影响。在酸性条件（pH 3.0）下，未[[氧化聚苯乙烯|老化 PS]] 原料的 ζ 电位对于 5 μm 颗粒为 $\dot { \mathfrak { s } } - 9 . 3 \pm 0 . 5 2$ mV，对于 1 μm 颗粒为 − $1 1 . 7 \pm 0 . 4 8$ mV。然而，经过不同老化处理后，这些数值出现明显分化：[[紫外光|UV]]/[[过氧化氢|H₂O₂]] 联合处理使电位分别降至 −12.6 ± 0.42 mV 和 − $1 3 . 2 \pm 0 . 3 5 \mathrm { m V } ,$，而单独的 [[紫外辐照|UV]] 处理则使其分别升高至 2.2 ± 0.36 mV 和 $4 . 9 \pm 0 . 4 7 \mathrm { m V }$。这种变化可能归因于不同老化过程中在 PS 表面引入了类型、数量和构型各异的[[含氧官能团]]，从而改变其表面电荷特性 [48–50]。在中性（pH 7）和碱性（pH 10）条件下，所有老化处理均使 PS 表面 ζ 电位绝对值呈现一致趋势：$\mathrm { U V / H _ { 2 } O _ { 2 } } > \mathrm { H _ { 2 } O _ { 2 } } > \mathrm { U V }$ > [[原始聚苯乙烯|原始 PS]]，且所有数值均保持为负值。这表明在这些条件下，不同老化体系一致诱导 PS 表面发生显著氧化，从而增强其[[电负性|表面电负性]]。

为系统研究[[老化|老化过程]]中 [[聚苯乙烯|PS]] [[疏水性]]的演变，考察了[[接触角]]的变化及其对应趋势。如图 4c 和 4d 所示，无论是在 $_ { \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } / \mathrm { U V } }$、仅 [[过氧化氢|H₂O₂]] 还是仅 [[紫外光|UV]] 的氧化体系中，介质的 [[pH]] 均会影响[[氧化聚苯乙烯|老化 PS]] 的表面疏水性，通常导致疏水性降低。在酸性（pH 3.0）和中性（pH 7.0）条件下，初始[[粒径]]为 5 μm 和 1 μm 的 [[微塑料|PS 微塑料]]接触角仅出现较小幅度的下降，整体变化有限。相比之下，在碱性条件（pH 10.0）下，PS 颗粒的接触角下降更为明显——5 μm 颗粒从 83° 降至 71°，1 μm 颗粒从 88° 降至 78°——表明其发生了从疏水向[[亲水性|亲水]]的显著转变。作为对照，[[原始聚苯乙烯|原始 PS]] 样品在不同 pH 溶液中的接触角同样受到 pH 影响，尤其是在碱性条件下，这表明原始 PS 样品中存在固有的氧化 [51–53]。这些结果系统揭示了老化体系与 pH 对 PS 老化的协同效应，为在实际环境应用中使用[[吸附]]材料去除[[老化微塑料]]提供了重要的实验基础。

## 3.5. [[吸附]]性能

[[吸附动力学]]。与我们课题组先前发表的论文相比，[[原始聚苯乙烯|原始 PS]]（pristine [[聚苯乙烯|PS]]）在 [[pH|pH 7.0]] 下经 [[木质素基水凝胶|LG-GH-PVA@2]] [[吸附]]的[[吸附容量|平衡吸附容量]]为 192.6 mg/g [33]，而对[[氧化聚苯乙烯|老化 PS]] 的吸附实验使用同一批次制备的 [[水凝胶|LG-GH-PVA@2]]，在相同条件下进行。结果发现，[[老化聚苯乙烯|老化 PS]] 表现出显著增强的吸附性能（图 5a）。具体而言，[[老化]] PS 在 pH 3.0、7.0 和 10.0 下的[[平衡吸附容量]]分别为 347.3 ± 15.81 mg/g、395.7 ± 17.65 mg/g 和 $4 2 7 . 6 \pm 1 6 . 4 2 \mathrm { m g / g }$。值得注意的是，中性条件（pH 7.0）下的吸附容量比原始 PS 高出 105.5%。进一步利用[[拟二级动力学模型]]和[[颗粒内扩散模型]]，研究了经 $_ { \mathrm { H } _ { 2 } O _ { 2 } / \mathrm { U V } }$ 体系老化的 PS 在 [[木质素|LG]]-GH-[[聚乙烯醇|PVA]]@2 上的吸附动力学。已有研究表明，这些模型能够有效表征 PS 的吸附动力学 [33]。动力学拟合曲线及相应参数（包括相关系数 r）见图 5a–c 和表 2。结果表明，这些模型能够准确描述不同 pH 条件（pH 3.0、7.0 和 10.0）下吸附时间与吸附容量之间的关系。

利用[[颗粒内扩散模型]]（图 5c）进行的分析表明，[[氧化聚苯乙烯|老化 PS]] 在 [[木质素基水凝胶|LG-GH-PVA@2]] 上的[[吸附]]经历三个不同阶段，各阶段速率明显不同，提示存在[[吸附机制|多步吸附机制]]。第一阶段（0–42 min）以快速吸附为特征，在 [[pH|pH 3.0]]、7.0 和 10.0 下的[[扩散常数]]分别为 27.81、30.87 和 35.53 $\mathrm { m g } / \mathrm { g } { \cdot } \mathrm { m i n } ^ { 0 . 5 }$。这表明 [[聚苯乙烯|PS]] 分子在碱性条件下的初始扩散速率最高，与[[老化|老化程度]]及表面电荷变化趋势一致（图 4a）。在该阶段，PS 迅速迁移至[[水凝胶]]表面，形成局部高浓度，从而增强向内扩散的驱动力。第二阶段（42–150 min）对应 PS 从表面向内部微孔的扩散，扩散常数分别降至 18.18、25.77 和 $2 7 . 8 8 \mathrm { m g / g { \cdot } m i n } ^ { 0 . 5 }$，同时仍保持碱性 > 中性 > 酸性的顺序。第三阶段为平衡阶段，扩散速率显著降低并逐渐接近饱和。在 pH 3.0、7.0 和 10.0 下，常数分别为 2.942、3.151 和 $2 . 8 6 2 ~ \mathrm { m g / g { \cdot } m i n ^ { 0 . 5 } }$，表明吸附已接近动态平衡。各阶段的拟合线均未通过原点，反映出吸附过程的复杂性。

## 4. 结论

我们模拟了[[聚苯乙烯|PS]]在不同[[pH]]水平下于[[紫外光]]和/或$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$作用下的[[老化|老化过程]]。为应对这一挑战，开发了一种来源于竹残渣废料的生物基[[水凝胶|LG-GH-PVA@2水凝胶]]，用于高效[[吸附]][[微塑料|老化微塑料]]。值得注意的是，[[木质素基水凝胶|LG-GH-PVA@2]]水凝胶在pH 3.0、7.0和10.0下的[[吸附容量|平衡吸附容量]]分别为$3 4 7 . 3 \pm 1 5 . 8 , 3 9 5 . 7 \pm 1 7 . 6 ,$和$4 2 7 . 6 \pm 1 6 . 4$ mg/g。

此外，综合实验表征、[[DFT]]计算和非共价相互作用的实空间可视化技术表明，[[老化]][[聚苯乙烯|PS]]在[[木质素|LG]]-GH [[聚乙烯醇|PVA]]@2[[水凝胶]]上的[[吸附]]主要由[[氢键]]和[[静电相互作用]]主导。这些相互作用强于水凝胶吸附原始PS时起作用的π–π堆积和[[C–H···π相互作用|C–H⋅⋅⋅π相互作用]]。由于其生物聚合物特性，[[木质素基水凝胶|LG-GH-PVA@2]]水凝胶不仅能够高效去除[[微塑料]]，还确保与下游生物处理相兼容，从而符合[[循环生物经济]]的原则。
