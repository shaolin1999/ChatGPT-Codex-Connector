## 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）构成了一大类合成的、高度持久的有机化合物<sup>[1−3]</sup>。其卓越的化学稳定性、双疏性（amphiphobicity）和表面活性剂特性自20世纪40年代以来推动了其在工业和消费领域的广泛应用（图1a）<sup>[1,4,5]</sup>。然而，正是这些特性使PFAS对降解具有极强的抵抗力，并且毒理学和流行病学证据已将其与日益严格的环境介质中PFAS监管控制联系起来<sup>[6,7]</sup>。监管关注的范围近来已从少数遗留长链PFAS扩展至更广泛的[[短链全氟烷基酸]]（低于传统长链截断值，即[[全氟烷基羧酸|PFCA]] < C8，PFSA < C6）以及新兴的醚类类似物<sup>[8]</sup>。在多个司法管辖区，针对单个PFAS或PFAS总量的饮用水标准（拟议或已颁布）已达到ng L<sup>−1</sup>水平<sup>[6,9]</sup>。这一监管转变从根本上改变了传统水处理技术中的技术瓶颈<sup>[10]</sup>。

[[颗粒活性炭]]（GAC）及相关碳质介质因其成熟性、监管认可度以及与现有处理基础设施的兼容性，仍是 [[PFAS]] 去除的主导基线技术<sup>[11,12]</sup>。然而，其对[[短链 PFAS]] 的性能本质上有所下降。全尺度调查已报道短链 [[全氟和多氟烷基物质|PFAS]] 在 GAC 床层中更早发生穿透（例如，[[全氟己酸|PFHxA]] 约 20,000 [[床体积]]，而 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] 约 30,000）<sup>[13]</sup>。这是因为短链同系物表现出较弱的[[疏水相互作用]]、更强水合壳层以及较低的孔限域增益<sup>[8,14]</sup>，导致在含有竞争离子和[[溶解性有机物]]的真实水体基质中[[吸附]]亲和力下降并被快速置换<sup>[15,16]</sup>。这些物理化学限制日益使得以[[BET|比表面积]]驱动的吸附不足以实现持续的短链 PFAS 控制。

因此，下一代 [[PFAS]] 修复的核心解决方案可能在于工程化分子级识别，使其在竞争性、环境相关条件下仍然有效<sup>[8,15,16]</sup>。[[聚合物基吸附剂]]提供了一个可独特编程的平台来应对这一挑战。通过有意识地选择单体、[[交联]]剂和结构<sup>[17]</sup>，聚合物可以在受限微环境内空间协同定位互补的相互作用基元，包括[[静电相互作用|静电]]头基锚定、部分[[去溶剂化]]调控以及氟化尾链容纳<sup>[15,18,19]</sup>。当这些相互作用集成于单一结构域内时，它们以协同而非孤立的方式发挥作用，从而实现对[[短链 PFAS]] 的亲和力和选择性，这是单一相互作用策略无法达到的<sup>[8,15,20−23]</sup>。

在本篇小型综述中，我们以“共定位协同结合微环境”这一统一概念为主线，重点介绍[[聚合物基吸附剂]]用于[[短链 PFAS]] 去除的最新进展，并评估其全生命周期足迹。代表性聚合物家族包括环糊精基网络、[[分子印迹聚合物]]、[[水凝胶]]和[[电活性聚合物]]。这些材料依据其在多大程度上有效实施这一协同结合原则，以及此类设计如何在真实水体基质和再生约束下转化为实际性能来进行评价。重要的是，研究整合了[[生命周期评价]]，以考察选择性提升是否足以证明相应合成与运行负担的合理性，从而将分子设计与净环境效益联系起来。通过同时从机理和可持续性约束两方面审视聚合物[[吸附]]剂的发展，本综述旨在为可部署的短链 [[PFAS]] 修复系统提供可操作的设计指导。

## 数据收集

为把握 [[PFAS]] [[吸附]]剂研究不断演变的格局，开展了一项覆盖 2015 至 2025 年的结构化文献调研，重点关注近三年的出版物。相关研究从 [[Scopus]]、[[Web of Science]] 和 [[Google Scholar]] 中检索，使用的关键词包括“[[全氟和多氟烷基物质|PFAS]]”“short-chain”“adsorption”“polymer”以及特定材料类别（如“cyclodextrin polymer”“fluorogel”“[[氧化还原活性聚合物|redox-active polymer]]”“electroactive polymer”“[[导电聚合物|conductive polymer]]”）。仅纳入经[[同行评审]]、以英文发表且报告了至少一种水中[[短链 PFAS]] 的定量吸附性能（例如平衡容量或[[去除效率]]）的研究。

## [[生命周期评估]]（[[生命周期评价|LCA]]）程序

进行[[生命周期评估]]（[[生命周期评价|LCA]]），以量化和比较[[聚合物基吸附剂]]与常规[[颗粒活性炭]]（GAC）及[[阴离子交换树脂]]在 [[PFAS]] 去除方面的环境负担。功能单位为处理 1 m<sup>3</sup> 进水，使目标 [[全氟和多氟烷基物质|PFAS]] 从初始浓度降低至相关监管限值。结果还按去除的 PFAS 质量进行了归一化<sup>[24]</sup>。系统边界覆盖了从摇篮到坟墓的生命周期，包括单体/前驱体生产、聚合/活化、使用阶段再生以及报废处置或回收。环境影响使用 [[ReCiPe 2016|ReCiPe 2016 Midpoint (H)]] 进行表征（包括 [[全球增温潜势|GWP100]]、[[人体毒性]] [非癌症]、[[陆地生态毒性]]、[[海洋富营养化]]、[[颗粒物形成]]和[[化石资源稀缺性]]），并汇总为 ReCiPe Endpoint (H/A) 损害类别（人类健康、生态系统、资源）。同时，应用 [[USEtox]] 进行人体/生态毒性比较（补充文件 [25,26]）。

## [[PFAS]] [[吸附]]：挑战与设计视角

## [[PFAS]] 化学演变及其对[[吸附]]的影响

全球监管行动深刻重塑了 [[PFAS]] 的生产、使用和环境存在。[[全氟辛烷磺酸|PFOS]] 被列入[[《斯德哥尔摩公约》]]附件 B（2009 年）以及 [[全氟辛酸|PFOA]] 被列入附件 A（2019 年），加速了传统长链 [[全氟和多氟烷基物质|PFAS]] 的淘汰，并推动了向短链和醚基替代品的转变（图 2）<sup>[3,12]</sup>。在包括[[全氟烷基羧酸]]（PFCA）、[[全氟烷基磺酸]]（PFSA）、[[氟调聚物磺酸盐]]（FTS）、[[氟化胺磺酰胺]]（FASA）以及新兴醚类衍生物（如[[六氟环氧丙烷二聚酸]]，GenX）在内的主要 PFAS 家族中，决定性结构趋势是全氟烷基链段长度缩短（n ≈ 1–10），同时保留化学稳定的 C–F 主链<sup>[3,8,17]</sup>。

[[全氟和多氟烷基物质|短链PFAS]]已在[[消防泡沫]]、[[金属电镀]]、[[纺织整理]]、[[半导体光刻胶]]和[[不粘涂层]]中替代其长链同类物，因为它们在保持表面活性剂性能和热稳定性的同时降低了生物累积潜力<sup>[17,21]</sup>。然而，缩短全氟烷基尾部会从根本上改变其在水中的行为：短链同系物表现出更高的极性、更强的水合壳层和更小的空间体积<sup>[27]</sup>。因此，[[全氟己酸|PFHxA]]、[[全氟丁酸|PFBA]]和[[全氟丁烷磺酸|PFBS]]等化合物在水生环境中表现出更强的迁移性和持久性，使主要环境风险从生物累积转向广泛、慢性的低水平暴露<sup>[9,28]</sup>。从处理角度看，整体性能越来越受制于保留最弱的物种。这些趋势凸显了有必要重新思考[[吸附]]设计原则，超越为[[疏水相互作用|疏水]]性有机污染物或长链[[PFAS]]所建立的原则，尤其是在高离子强度或富含[[溶解性有机物|DOM]]的条件下。

## 碳质[[吸附]]剂作为工程基线

碳质[[吸附]]剂，包括[[颗粒活性炭|GAC]]<sup>[29]</sup>、[[粉末活性炭]]（PAC）<sup>[29,30]</sup>、[[碳纳米管]]（CNT）以及[[石墨烯基材料]]<sup>[31,32]</sup>，仍是去除[[PFAS]]最成熟的技术。其吸引力在于高[[BET|比表面积]]、成熟的制造工艺和监管熟悉度。

[[颗粒活性炭|GAC]]因其可靠性和易于改造而被广泛应用于市政饮用水、地下水修复和工业精处理<sup>[33]</sup>。对于遗留的长链[[PFAS]]（如[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]），商用GAC过滤器通常可实现> 95%的去除率，出水浓度约为10 ng L<sup>−1</sup>。然而，当面对[[全氟和多氟烷基物质|短链PFAS]]（如[[全氟丁酸|PFBA]]、[[全氟戊酸|PFPeA]]和[[六氟环氧丙烷二聚酸|GenX]]）时，[[吸附]]剂性能显著下降<sup>[34]</sup>。一项对23座饮用水处理厂的全球调查发现，在可比条件下，C4–C6短链PFAS的穿透速度比长链物种快2−4倍<sup>[11]</sup>。同样，一项追踪15种PFAS物种的两年现场研究发现，尽管初始去除率达到92%–100%，短链化合物在连续运行约一年（约29,300[[床体积]]）后即出现早期穿透<sup>[13]</sup>。这种短链限制主要源于相互作用强度和[[吸附选择性]]的耦合不足<sup>[8,14]</sup>。GAC上的吸附主要由[[疏水相互作用]]和[[微孔限域]]主导。然而，这些机制对短链PFAS的效果较差<sup>[10,35]</sup>。此外，GAC缺乏对头基的特异性识别基序，因此竞争吸附遵循亲和力排序：短链PFAS容易被长链PFAS置换，并且共存的无机离子和[[溶解性有机物|DOM]]会进一步抑制吸附，使吸附性能降低高达 [11,13]

[[粉末活性炭|PAC]] 通常用于污染事件或法规超标情况下的短期或应急 [[PFAS]] 控制<sup>[36]</sup>。对比研究表明，在接触时间为 10 min 的条件下，PAC 可去除 60%–90% 的 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]]，而在相同条件下 [[颗粒活性炭|GAC]] 仅为 20%–40%<sup>[37]</sup>。PAC 与 GAC 的主要区别在于形貌和动力学（传质），而二者对[[短链 PFAS]] 去除的机理限制是相同的<sup>[27,38]</sup>。因此，PAC 主要改善的是 [[全氟和多氟烷基物质|PFAS]] 去除动力学，但并不能逆转支配短链穿透的链长依赖性亲和层级。

[[碳纳米管|CNT]] 和[[石墨烯基材料]]代表下一代碳质[[吸附]]剂，具有超高[[BET|比表面积]]和可调控的表面化学性质<sup>[12,39]</sup>。商业化 CNT 和石墨烯衍生物对长链 [[PFAS]] 的[[吸附容量]]可超过 200 mg g<sup>−1[12,35]</sup>。然而，其应用受到成本、高离子强度下的团聚以及在复杂水体中稳定性有限的制约<sup>[31,40]</sup>。例如，随着 Cl<sup>−</sup> 浓度从 0.001 增加到 0.05 M，在低浓度（0.001–0.01 M）下可观察到竞争效应，Cl<sup>−</sup> 会降低 [[全氟和多氟烷基物质|PFAS]] 的吸附量；一旦电解质浓度超过 CNT 的[[临界混凝浓度]]（0.037 M），CNT 倾向于发生团聚，从而减少可及表面积和吸附容量。此外，主要增强[[静电相互作用]]的简单 CNT 改性往往并不理想，因为吸附会变得对 pH 敏感，容量随 pH 升高而下降<sup>[40]</sup>。因此，许多近期研究将 CNT 用于静电驱动吸附，而其对本征 PFAS 选择性的贡献有限<sup>[20,41]</sup>。尽管如此，CNT 的物理化学性质仍使其在构建 PFAS 去除系统方面具有吸引力，但选择性和水体基质适应性方面的挑战应得到认真解决。

## 面向[[短链 PFAS]] 捕获的协同分子间相互作用

从结构角度看，[[PFAS]] 提供了两个可作用的相互作用基元，即阴离子头基 $( - \mathsf { C O O } ^ { - } / - \mathsf { S O } _ { 3 } ^ { - }$ <sup>–</sup>，某些物种中还有醚氧原子），以及一个缩短的全氟尾链 $( - ( \mathsf { C F } _ { 2 } ) _ { \mathsf { n } } \mathsf { - C F } _ { 3 } \mathsf { o r - O - C F } _ { 2 } \mathsf { - } )$ 。因此，有效捕获要求[[吸附]]剂同时利用阳离子基元锚定头基，并利用[[疏水相互作用|疏水]]/氟亲和结构域容纳尾链，从而在实际基质中抵抗置换<sup>[8,14,27]</sup>。

已描述了四类特别相关的相互作用（表1）<sup>[8,15,20−23]</sup>。[[静电结合]]通过阳离子基元（如$( - \mathsf { C O O } ^ { - } / - \mathsf { S O } _ { 3 } ^ { - } )$、[[咪唑鎓]]<sup>+</sup>/[[吡啶鎓]]<sup>+</sup>和[[胍基]]）靶向阴离子头基$- N \mathsf { R } _ { 4 } ^ { + } , - N \mathsf { H } _ { 3 } ^ { + } / - N \mathsf { H } _ { 2 } ^ { + } -$，但易受背景阴离子的屏蔽和竞争影响<sup>[21,23]</sup>。[[疏水相互作用|疏水]]/色散相互作用主要通过sp<sup>2</sup>-碳/芳香族或$( - \mathsf { I C F } _ { 2 } \mathsf { J } _ { \mathsf { n } } - \mathsf { C F } _ { 3 } )$结构域与全氟化尾部$- ( C H _ { 2 } ) _ { n } -$发生作用；对于[[全氟和多氟烷基物质|短链PFAS]]，这些贡献较弱，除非通过微孔/[[微孔限域|纳米限域]]加以增强<sup>[42]</sup>。[[亲氟识别]]通过引入氟链段$( \mathsf { e . g . , ~ \mathsf { - } \Lambda ^ { \mathsf { C F } } } _ { 2 } ] _ { \mathsf { n } } \mathsf { - } / \mathsf { - } \mathsf { C F } _ { 3 } .$富集单元$\mathsf { o r } \mathsf { \Pi } - \mathsf { C } [ \mathsf { F } ] _ { \mathsf { x } } -$表面）来增强尾部容纳，从而稳定全氟烷基/全氟醚基元<sup>[22]</sup>。[[氢键]]通过供体/受体$( \mathrm { e . g . , ~ \mathsf { \_ N H } - , ~ \mathsf { \_ } { ~ O H } , ~ \mathsf { \_ C O N H - , ~ \mathsf { \_ N H C O N H - , ~ \mathsf { \_ C = O } ) } } }$提供方向性稳定，通常作为[[静电相互作用|静电]]位点旁协同的“次级把手”，用于稳定部分脱水的头基<sup>[42,43]</sup>。当这些相互作用被整合在同一[[结合域]]中时，头基锚定可以调控[[去溶剂化]]，而尾部容纳则降低对竞争性置换的敏感性。这种协同结合范式为理解为什么某些[[聚合物基吸附剂]]在实际条件下优于传统材料提供了一个统一框架。在下一节中，将根据其结构如何有效地编码并在空间上组织这些互补相互作用，以及这种组织如何转化为短链[[PFAS]]去除选择性、[[可再生性]]和环境稳健性，对代表性聚合物[[吸附]]剂进行分类。

## [[聚合物基吸附剂]]

聚合物提供了一个本质上可编程的平台，其中单体、[[交联]]剂和结构（例如嵌段、接枝、网络）可被选择用于在定制的微环境中协同定位互补作用力（表1）。这里重点介绍四类代表性的聚合物家族，它们实现了这些作用力的不同组合：[[β-环糊精]]（β-CD）聚合物<sup>[44,45]</sup>、[[分子印迹聚合物]]（MIPs）<sup>[46,47]</sup>、[[水凝胶]]<sup>[16,18]</sup>和[[电活性聚合物]]（图3）<sup>[41]</sup>。

## [[β-环糊精聚合物]]

[[β-环糊精]]（β-CD）是一种由七个葡萄糖单元组成的环状低聚糖，形成[[疏水相互作用|疏水]]性内腔和亲水性外表面（图 3a 和 b）。当聚合或[[交联]]成固态网络时，这些空腔充当固定的[[主-客体化学|主–客体口袋]]，能够选择性地结合有机分子<sup>[53]</sup>。早期以[[环氧氯丙烷]]交联的 β-CD [[吸附]]剂对 [[PFAS]]，尤其是短链化合物，亲和力有限<sup>[44]</sup>。后续工作通过引入芳香族交联剂（如[[四氟对苯二甲腈]]，TFN）来赋予富氟表面，并通过阳离子胺对网络进行后功能化以增强对阴离子型 ${ \mathsf { P F A S } } ^ { [ 5 4 ] } .$ 的[[静电相互作用|静电]]锚定，从而改善了性能。[[Dichtel]] 及其同事首次证明了 [[β-环糊精聚合物|β-CD 聚合物]]可实现亚 ppb 级去除，在环境相关条件下将 [[全氟辛酸|PFOA]] 从 1 降低至 < 10 ng ${ \mathsf { L } } ^ { - 1 }$<sup>[44]</sup>。近期 β-CD 聚合物变体展示了组合分子间相互作用的优势。经胺修饰的 [[β-环糊精共价有机框架|β-CD-COFs]] 对一系列短链和长链 [[全氟和多氟烷基物质|PFAS]] 的[[吸附容量]]达到 0.33–1.51 mmol $\mathfrak { g } ^ { - 1 }$，优于商用[[离子交换树脂]]和[[活性炭]]<sup>[55]</sup>。含季铵基团的苯乙烯化 β-CD 共聚物在约 1 µg ${ \mathsf { L } } ^ { - 1 }$ 浓度下对 [[全氟丁酸|PFBA]] 和 [[全氟戊酸|PFPeA]] 的去除率超过 99%<sup>[48]</sup>。值得注意的是，β-CD 吸附剂还表现出快速动力学和对短链物质的高亲和力。对于氟化碳数 < 4 的同系物，分配系数 $( K _ { \mathrm { d } } )$ 达到 10<sup>3</sup>–10<sup>7</sup> L kg<sup>−1</sup>，而活性炭和[[生物炭]]类似物为 $< 1 0 ^ { 6 } \ |$ kg<sup>−1</sup><sup>[56]</sup>。

[[β-环糊精|β-CD]] 材料的一个关键优势是易于再生。使用温和溶剂（水–醇混合物或稀碱）洗脱用过的环糊精网络，可在数分钟内解吸 > 50%–95% 的结合 [[PFAS]]<sup>[57]</sup>。与[[活性炭]]相比，[[β-环糊精聚合物|β-CD 聚合物]]在[[溶解性有机质]]（[[溶解性有机物|DOM]]）存在下仍能保持[[吸附]]；其纳米多孔结构限制了腐殖质污染<sup>[58]</sup>。[[Xiao]] 等<sup>[44]</sup>报道，即使存在 10 mg L<sup>–1</sup> [[腐殖酸]]，也能从湖水中去除 > 90% 的 [[全氟己酸|PFHxA]]、[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]]（ng ${ \mathsf { L } } ^ { - 1 }$ 加标）。总体而言，β-CD 聚合物可快速、选择性地去除[[短链 PFAS]]（图 4），且再生简便，并耐受天然水基质<sup>[54,58]</sup>。要将这些有前景的结果转化为稳健的现场性能，仍需解决若干差距。大多数已报道的性能依赖于 µg ${ \mathsf { L } } ^ { - 1 }$ 批量加标和简化基质，因此在 ng ${ \mathsf { L } } ^ { - 1 }$ 水平以及连续流条件下，吸附、穿透和再生仍未得到充分探索。此外，在[[交联]]网络中，空腔包合、阳离子锚定和[[亲氟相互作用|亲氟]]微区的各自贡献尚未完全理解，而使用溶剂/碱洗脱液进行再生也值得进一步优化。

## [[分子印迹聚合物]]

[[分子印迹聚合物]]（MIP）利用模板策略，创建在形状和功能上与目标分子互补的结合位点（图 3c）<sup>[46,59]</sup>。模板去除后留下的空腔通过协同的形状匹配、[[氢键]]和离子配对来识别 [[PFAS]]<sup>[50,60]</sup>。

早期针对 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 印迹的 [[分子印迹聚合物|MIP]] 对长链模板表现出高亲和力（> 600 mg g<sup>−1</sup>），但对[[短链 PFAS]] 的[[吸附]]有限（[[全氟丁酸|PFBA]] 容量约为 100 至 200 mg $\mathfrak { g } ^ { - 1 } ;$ 对短链物质的去除率仅为 14%–50%）<sup>[61,62]</sup>。空腔几何结构与较短氟化尾链之间的不匹配是造成这种选择性差距的主要原因<sup>[62]</sup>。性能提升来自若干策略。第一，使用短链模板（例如 [[六氟环氧丙烷二聚酸|GenX]]/HFPO-DA）直接印迹可提高选择性，尽管长链容量有所下降<sup>[63]</sup>。第二，功能单体调谐，例如引入磺酰胺或其他极性单体，可增强对短链磺酸盐的识别。相关进展已制备出多孔 MIP，其对 PFBA 的容量约为 230 mg $\mathfrak { g } ^ { - 1 }$，对 PFOA 的容量约为 380 mg $\mathfrak { g } ^ { - 1 }$，将短链与长链性能差距缩小至约 60%<sup>[62,64]</sup>。

[[分子印迹聚合物|MIP]] 的选择性还可以通过多模板和复合设计进行工程调控。引入第二模板可产生跨越不同链长的结合位点：以 [[全氟辛烷磺酸|PFOS]] + [[全氟丁酸|PFBA]] 为模板制备的[[生物炭]]负载 MIP，其 PFBA 和 [[全氟己酸|PFHxA]] [[吸附]]量比单一 PFOS 模板 MIP 高 30%–50%<sup>[65]</sup>。MIP 还可以引入[[亲氟相互作用|亲氟]]单体和阳离子单体（如[[三氟甲基化丙烯酸酯]]、[[乙烯基苄胺]]）以模拟 [[PFAS]] 的双重结合需求。由[[全氟苯乙烯|全氟苯乙烯衍生物]]与脲[[氢键]]供体配对制备的超薄印迹膜，对 [[全氟和多氟烷基物质|PFAS]] 相对于共离子的选择性提高了六倍<sup>[60]</sup>。

[[分子印迹聚合物|MIP]] 的再生通常较为简单，因为印迹相互作用是非共价的，使 [[PFAS]] 可以在相对温和的条件下[[脱附]]。大多数 [[全氟和多氟烷基物质|PFAS]]-MIP 通过[[甲醇]]或[[乙腈]]洗涤再生，通常加入 1%–2% [[氢氧化钠|NaOH]] 或 NH OH 以破坏离子相互作用<sup>[58]</sup>。类似地，[[全氟辛烷磺酸|PFOS]]-MIP 已在 [[固相萃取|SPE]] 柱中通过 MeOH/0.1% NaOH 洗脱反复使用<sup>[60]</sup>。

虽然大多数应用以分析富集为目标，但若干研究已展示其在实际水体中的性能。一种商用 [[Supel MIP® PFOS]] 在对地下水与河水进行预淋洗以控制[[天然有机质]]干扰后，可从中萃取痕量 [[PFAS]]<sup>[60,66]</sup>。一种[[生物炭]]-[[分子印迹聚合物|MIP]] 复合材料可从机场径流中去除最高 70% 的 [[全氟丁烷磺酸|PFBS]]、[[全氟己酸|PFHxA]] 及其他[[短链 PFAS]]，而非印迹对照的去除率不足 20%<sup>[67]</sup>。这些结果证实 MIP 能够在复杂基质中发挥作用。尽管选择性明显提升，仍需进一步工作以将 [[全氟和多氟烷基物质|PFAS]]-MIP 转化为分析富集之外的实用[[吸附]]材料<sup>[62,67,68]</sup>。文献报道的性能通常来自模板匹配体系以及柱实验/批式实验，而在混合 PFAS、富含 NOM/离子的基质以及连续流运行条件下的长期捕集与穿透行为仍缺乏充分研究。此外，印迹设计将受益于能够在空腔特异性与组成广度之间取得平衡的策略，以保持对结构多样 PFAS 的覆盖；同时，再生方案也需要优化，以尽量减少二次洗脱液用量，同时保持选择性与循环稳定性。

## [[水凝胶]]

具有水溶胀、[[交联]]聚合物网络的[[水凝胶]]基[[吸附]]材料因水合基质有利于快速传质，并且比干树脂更有效地减轻污染，正在引起人们对[[短链 PFAS]] 去除的关注（图 3d）。定制的水凝胶化学结构能够实现离子型、[[疏水相互作用|疏水]]型与[[亲氟相互作用|亲氟]]型[[结合域]]的共定位，同时保持可及的扩散通道。

在[[水凝胶]]体系中，[[氟凝胶|离子型氟凝胶]]是研究最为广泛的体系之一。这些材料包括带有氟烷基侧基和季铵基团的[[苯乙烯–二乙烯基苯]]网络，以及包含胺功能化[[吸附]]剂的[[藻酸盐]]基质<sup>[16,51,52]</sup>。协同结合基元对其性能至关重要：氟化微区溶剂化全氟烷基尾部，而阳离子位点锚定阴离子头基。在城市用水中，离子型氟凝胶在 μg ${ \mathsf { L } } ^ { - 1 }$ 浓度水平下，仅使用 1–10 mg ${ \mathsf { L } } ^ { - 1 }$ 吸附剂即可近乎定量去除包含 21 种 [[PFAS]] 的混合物（包括 [[全氟丁酸|PFBA]]、[[全氟丁烷磺酸|PFBS]]、[[全氟己酸|PFHxA]] 和 [[六氟环氧丙烷二聚酸|GenX]]），并在 < 30 min 内达到平衡，且天然溶质干扰极小<sup>[51]</sup>。混合体系说明了水凝胶设计的模块化特性。一种嵌入 [[粉末活性炭|PAC]] 的[[聚丙烯酰胺]]水凝胶复合材料在 ng ${ \mathsf { L } } ^ { - 1 }$ 浓度水平下实现了对 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] > 95% 的去除，将水凝胶的溶胀增强传质与 PAC 的吸附位点相结合<sup>[69]</sup>。

[[水凝胶]]的一个主要优势是再生简便。许多水凝胶体系中的软性非共价结合使温和洗脱条件成为可能，无需热再活化。[[氟凝胶|离子型氟凝胶]]可通过水 : [[甲醇]]（1:1）淋洗并加入 1 M [[氯化钠|NaCl]]，实现至少 3 次循环使用，每个循环可解吸 > 90% 的 [[PFAS]]，且网络降解可忽略不计<sup>[51]</sup>。水凝胶[[吸附]]材料也已在真实水体基质中进行了评价。例如，氟凝胶填充柱在存在竞争性阴离子和天然有机碳的情况下，仍可将沉淀后饮用水中的 [[全氟丁酸|PFBA]]、[[全氟丁烷磺酸|PFBS]] 和 [[六氟环氧丙烷二聚酸|GenX]] 去除至检出限以下<sup>[52]</sup>。一种囊泡状[[聚丙烯酰胺]]/[[粉末活性炭|PAC]] 水凝胶同样可从地表水中去除 > 85%–90% 的 C4–C6 [[全氟和多氟烷基物质|PFAS]]，而常规[[活性炭]]对短链组分的去除率不足 50%<sup>[70]</sup>。

[[水凝胶]]结构也表现出对可变 pH 和[[溶解性有机质]]（[[溶解性有机物|DOM]]）的耐受性。一种[[聚苯胺|聚苯胺基水凝胶]]在 pH 3–10 范围内以及 50 mg L<sup>−1</sup> [[腐殖酸]]存在下，仍保持 > 90% 的[[全氟和多氟烷基物质]]（[[PFAS]]）去除率<sup>[16,18]</sup>。得益于水溶胀、可渗透的网络结构，水凝胶[[吸附]]剂能够实现快速传质，并使协同结合基序共同定位，从而实现对[[短链 PFAS]] 的高效捕获和温和再生。未来改进应侧重于增强反复溶胀—消溶胀条件下的机械稳定性、减少功能组分降解，以及开发可规模化的再生方案。

## [[电活性聚合物]]

[[电活性聚合物]]代表了一类创新的 [[PFAS]] [[吸附]]材料，其利用电化学控制来捕获和释放污染物<sup>[71,72]</sup>。包括[[聚吡咯]]（PPy）、[[聚苯胺]]以及[[紫精]]或醌官能化骨架在内的材料能够在不同氧化态之间可逆切换，从而调节电荷及其对阴离子型 [[全氟和多氟烷基物质|PFAS]] 的亲和力（图 3e）<sup>[73−75]</sup>。

在机理上，施加电位会诱导 [[PFAS]] 阴离子[[静电相互作用|静电]][[吸附]]进入聚合物基体，并且在存在[[疏水相互作用|疏水]]和[[亲氟相互作用|亲氟]]相互作用的情况下，这种吸附往往得到增强<sup>[20,41]</sup>。在掺杂态下，[[聚吡咯|PPy]] 带有正电荷，并具有富含碳的疏水性基体，能够同时实现头基吸引和尾部分配<sup>[76]</sup>。类似地，带有[[氮氧自由基]]（N–O<sup>•</sup>）的[[氧化还原活性聚合物|氧化还原聚合物]]在温和偏压下会转变为阳离子型[[氧铵|氧铵物种]]（<sup>+</sup>N=O），已被证明能够从水中选择性电吸附[[短链 PFAS]]<sup>[41]</sup>。

纳米结构导电聚合物对广谱 [[PFAS]] 表现出特别高的[[吸附容量]]（图 4a、b）。[[Yu]] 等人制备的囊泡状 [[聚吡咯|PPy]]<sup>[77]</sup> 对 [[全氟丁酸|PFBA]] 的估算[[吸附]]容量约为 500 mg $\mathfrak { g } ^ { - 1 }$，对 [[全氟辛酸|PFOA]] 约为 509 mg $\mathfrak { g } ^ { - 1 }$，从（加标）污染地下水中去除了 12 种 [[全氟和多氟烷基物质|PFAS]]（C3–C8）中 ≥ 90% 的物质；相比之下，一种商品化树脂对短链同系物的去除率低于 50%。含有[[氮氧自由基]]和三氟甲基的氟化氧化还原共聚物表现出较强的[[短链 PFAS]] 选择性，对 PFBA 的吸附量最高可达 205.8 mg $\mathfrak { g } ^ { - 1 }$，对 [[全氟己酸|PFHxA]] 可达 860.8 mg $\mathfrak { g } ^ { - 1 }$<sup>[20]</sup>。最近，[[Kim]] 等人通过将氧化还原电渗析与电吸附相结合，实现了对超短链至长链 PFAS（例如从[[三氟乙酸]]到 [[全氟辛烷磺酸|PFOS]]）的高效去除，展示了电介导捕获的多功能性<sup>[78]</sup>。此外，[[电活性聚合物]]还可被调控以选择性捕获某些 PFAS。例如，通过调节电压，电极可以选择性靶向低于某一链长的 PFAS，从而在需要时有效地“屏蔽”较长链的 PFAS<sup>[72]</sup>。这种控制水平使电活性聚合物成为短链 PFAS 修复中最具吸引力的新兴解决方案之一。

重要的是，[[氧化还原活性聚合物|氧化还原聚合物]]可以原位再生：施加反向或中性电位可释放结合的[[PFAS]]，将其浓缩到小体积盐水中以便处置或销毁<sup>[20,41,78]</sup>。[[电子石英晶体微天平]]（EQCM）在连续循环中直接证明了[[全氟和多氟烷基物质|PFAS]]的电再生过程，并且反复再生后性能衰减极小<sup>[72]</sup>。在其他情况下，溶剂或酸洗可使[[聚吡咯|PPy]]和[[聚苯胺]]体系恢复容量。例如，[[Yu]]等人表明，pH 1的[[甲醇]]可再生多孔$\mathsf { P P y } ,$，使其至少能够进行五次[[吸附]]–[[脱附]]循环，且容量回收率>95%<sup>[77]</sup>。

[[电活性聚合物]]还提供了一条通向“捕获–销毁”一体化的途径，即浓缩后的[[PFAS]]可直接在电极表面通过[[阳极氧化]]被矿化。初步研究表明，在[[氧化还原活性聚合物|氧化还原聚合物]]电极上进行预浓缩，比在稀溶液中进行氧化更节能<sup>[41]</sup>。这些材料在复杂水体中表现出稳健性能，包括盐水和高[[溶解性有机碳]]（DOC）基质<sup>[20]</sup>。仍存在的挑战包括放大生产、电极耐久性，以及在未集成销毁环节时对[[全氟和多氟烷基物质|PFAS]]浓缩液的管理<sup>[20,78]</sup>。仅在连续流、ng L<sup>−1</sup>水平条件下验证电活性聚合物，并量化传质/动力学限制以及实际条件下的能量需求，还不够充分。尽管如此，随着高分子化学（例如稳健的氧化还原活性骨架、含氟离子液体）和电化学反应器设计的不断进步，电活性聚合物有望发挥补充作用（参见图4中的综合比较），尤其是在现场条件下高效去除短链PFAS方面。还应重视提高长期耐久性（包括防污/防垢控制）和[[再生效率]]，最好与现场销毁相结合，以尽量减少二次废物流。

## 可持续性与环境考量

[[聚合物基吸附剂]]可以对[[全氟和多氟烷基物质|短链PFAS]]提供高亲和力和选择性；然而，可持续性不能仅凭去除性能来证明。由于上述性能提升（图4）是在基质和再生约束条件下实现的，所需的[[吸附]]剂用量和重复使用次数便成为决定净影响的关键因素。因此，聚合物吸附剂的实际价值取决于这些优势能否转化为相对于现有介质（如[[颗粒活性炭]]和[[离子交换树脂]]）的净环境效益<sup>[15,27,79]</sup>。为评估这些权衡，我们在每m<sup>3</sup>处理水的基础上进行了[[生命周期评价|生命周期评价（LCA）]]<sup>[25,26,79,80]</sup>。为分离与合成相关的负担，我们聚焦于[[电活性聚合物]]（其代表相对耗能和耗试剂的合成路线，见补充表S5、S6及补充文件$2 . 1 ) ^ { [ 4 1 ] }$部分）。功能单位被定义为将$1 ~ \mathsf { m } ^ { 3 }$的[[PFAS]]污染水处理到统一的出水目标。如图5a所示，“从摇篮到坟墓”的系统边界包括聚合（单体生产、溶剂使用、电力）和后修饰（电力、氧化剂、溶剂）。组件制造和寿命终止阶段则在敏感性分析中加以处理。

以处理 1 m<sup>3</sup> 水为功能单位，聚合物路线在若干以能耗为主导的中点类别中表现出明显优于[[活性炭]]（AC）的优势（图 5b），包括[[全球增温潜势]]（GWP）降低 33.6%、[[细颗粒物]]生成 $( \mathsf { P } \mathsf { M } _ { 2 . 5 } )$ 降低 43.8%、臭氧生成（人体健康）和臭氧生成（陆地）分别降低 36.0% 和 34.6%、平流层臭氧消耗降低 20.1%。相反，由于单体、溶剂和氧化剂需求，聚合物合成在毒性和资源相关类别中引入热点问题，包括[[淡水生态毒性]]增加 40.5%、[[陆地生态毒性]]增加 22.7%、[[矿产稀缺性]]增加 167.0% 以及水消耗增加 600.0%。与营养物相关的以及某些生态毒性终点则出现分化。[[淡水富营养化]]和[[海洋富营养化]]分别降低 42.7% 和 35.1%，[[海洋生态毒性]]降低 22.9%，而淡水生态毒性仍较高，表明溶剂/氧化剂清单是主要贡献因素。

随后，将每公斤[[吸附]]剂的处理侧终点因子与每公斤 [[PFAS]] 的污染侧毒性因子对齐，通过盈亏平衡框架评估环境合理性（图 5c；[[全氟和多氟烷基物质|PFAS]] 数据来自 [[Holmquist]] 等<sup>[26]</sup>）。对于[[人体非致癌毒性]]，该聚合物对 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] 在 0.0015 kg PFAS kg<sup>−1</sup> 聚合物时即产生净效益。对于 [[全氟己酸|PFHxA]] 和 [[全氟丁烷磺酸|PFBS]]，通过选择性吸附和常规再生，可实现 1.4 和 3.5 kg kg<sup>−1</sup> 的阈值；例如，在中等基质降额下，每周期有效容量约为 0.20 kg kg<sup>−1</sup>，表明对 PFBS 大约几十个周期即可满足要求。对于[[人体致癌毒性]]，PFOA/PFOS 可实现盈亏平衡（0.462 kg kg<sup>−1</sup>），但在所测试数据集中，PFHxA/PFBS 无法实现。[[淡水生态毒性]]是所有物种的限制速率因素：193 kg kg<sup>−1</sup>（PFOA/PFOS）、8032 kg kg<sup>−1</sup>（PFHxA）和 2174 kg $\mathsf { k g } ^ { - 1 }$（PFBS）的阈值无法仅靠性能实际达到。因此，在聚合物剂量最小化、再生常规化且选择性吸附能够覆盖[[短链 PFAS]]（PFHxA、PFBS、[[六氟环氧丙烷二聚酸|GenX]]）而无需高能耗深度处理的条件下，净效益最为明显。

要缩小与 [[强碱阴离子交换树脂|AER]] 相比的[[淡水生态毒性]]差距，需要从源头实施[[绿色制造]]，包括：（i）低影响、高回收率的溶剂体系；（ii）以电氧化或 ${ \sf H } _ { 2 } { \sf O } _ { 2 } /$ 空气在带排气治理的封闭反应器中替代高影响氧化剂；以及（iii）避免卤代/硝基前体和重金属催化的单体来源选择。在系统层面，将 [[活性炭|AC]]/AER 前置用于长链 [[PFAS]] 和 [[天然有机质|NOM]] 去除，并辅以小型聚合物精处理段去除[[短链 PFAS]]，可降低每 m<sup>3</sup> 的聚合物用量，并提高有效再生循环次数，从而在尚未优化合成之前就改善 [[生命周期评价|LCA]] 表现（图 5b、c）。

综上，在合成阶段，聚合物[[吸附]]剂目前具有比 [[活性炭|AC]] 和 [[强碱阴离子交换树脂|AER]] 更高的从摇篮到坟墓负担。缩小这一差距需要制造阶段的绿色化（溶剂回收、温和氧化、替代单体来源）（图 5b）。在使用阶段，可通过混合处理流程降低环境影响，例如，部署 AC/AER 去除长链和 [[天然有机质|NOM]]，再进行有针对性且可常规再生的聚合物精处理。这些措施可由此最大限度减少用量、提高全寿命捕获量，并降低每 m<sup>3</sup> 影响。

## 展望

尽管基于聚合物的[[吸附]]剂发展迅速，但有效修复[[短链 PFAS]] 的主要障碍正日益表现为系统层面，而非纯粹的材料层面。在实际处理场景中，混合基质中的竞争吸附、富集 [[PFAS]] 二次流的管理，以及吸附剂制造和再生所带来的环境负担，共同决定了先进材料能否实现规模化应用。因此，未来的进展需要将分子层面的选择性同过程设计和可持续性约束加以整合。

## 针对混合 [[PFAS]] 基质的混合处理流程

在环境水体中，[[PFAS]] 以复杂混合物而非孤立溶质的形式存在，并与 [[溶解性有机物|DOM]]、背景电解质和其他有机污染物共存，这会重塑[[吸附]]平衡和穿透行为。在这些条件下，追求通用的单一介质解决方案往往在技术和经济上都不是最优的。更实际的策略是设计分工明确的混合处理流程，以利用不同材料的互补优势。

碳质介质可以作为稳健的前端单元，优先去除长链 [[PFAS]] 并强[[吸附]]共污染物，从而缓解位点垄断和竞争性污染效应，这些效应会不成比例地削弱[[短链 PFAS]] 的吸附<sup>[81,82]</sup>。随后，可将基于聚合物的吸附剂部署为下游精处理单元，其中[[可编程微环境]]能够实现面向头基的识别和协同结合，并在竞争条件下保持有效。这种分级结构将大量去除与超痕量精处理解耦，在提高整体韧性的同时，降低对任何单一材料类别的性能要求。

## 捕获–浓缩–销毁路径的整合

由于[[吸附]]本质上会将 [[PFAS]] 浓缩到更小体积中（废介质、再生盐水或浓缩液），关键问题便从去除转向对这些二次流的负责任管理。如果没有下游处理，吸附可能只是在重新分配 [[全氟和多氟烷基物质|PFAS]] 负担，而非消除它们。

一个新兴且有前景的方向是有意集成“捕获–浓缩–破坏”处理回路，即将分离过程与能够实现脱氟的破坏性技术明确耦合。近期研究表明，在通过[[吸附]]、泡沫分离或可再生树脂进行处理前先浓缩 [[PFAS]]，可显著提高[[电化学氧化]]（如[[硼掺杂金刚石阳极]]）和[[高级还原系统]]（如 UV/[[亚硫酸盐]]产生的[[水合电子]]）等破坏过程的能量效率与动力学<sup>[83,84]</sup>。在此背景下，[[氧化还原活性聚合物]]吸附剂尤其引人注目。这些材料能够实现可编程捕获，随后通过电驱动再生和原位氧化或还原精处理，在材料层面架起分离与破坏之间的桥梁<sup>[41]</sup>。这种集成使分子设计与 [[全氟和多氟烷基物质|PFAS]] 质量平衡的系统级闭环保持一致。

## 面向绿色聚合物制造

虽然许多聚合物[[吸附]]剂通过后功能化和溶剂密集型合成实现了高选择性，但这些步骤本身往往主导生命周期环境负担，并可能削弱净修复效益。随着性能目标接近监管限值，仅靠进一步提高吸附亲和力，已不太可能证明合成影响不成比例增加是合理的。

因此，近期的一个研究优先事项是从仅优化性能转向约束感知设计，即将[[吸附选择性]]、[[可再生性]]和[[制造足迹]]作为一个[[耦合系统]]加以评估。有前景的方向包括：通过[[闭环工艺]]尽量减少并回收溶剂和试剂；用无溶剂或最少溶剂的方法替代多步湿化学过程；以及采用可规模化的策略，如[[机械化学合成]]或[[反应挤出]]<sup>[85,86]</sup>。在材料开发早期纳入[[生命周期评价|生命周期考量]]，对于将实验室进展转化为环境友好型技术至关重要。

## 结论

[[聚合物基吸附剂]]通过对[[可编程微环境]]进行理性工程化，构建共定位、协同作用的[[结合域]]，为修复水溶性高的[[短链 PFAS]] 提供了通用平台。在本综述所考察的聚合物家族中，高性能短链 [[PFAS]] 去除始终源于互补相互作用基元的集成：[[头基锚定位点]]（[[静电相互作用|静电]]和/或[[氢键相互作用]]）和[[尾部容纳域]]（[[疏水相互作用|疏水]]或[[亲氟相互作用|亲氟]]）。这些相互作用共同降低了[[去溶剂化]]惩罚，增强亲和力，并在竞争性真实水体基质中保持选择性。

代表性研究报告的[[去除效率]]超过 90%，在复杂水体中出水浓度可达到 ng L<sup>−1</sup> 量级，同时在相对温和的化学或电化学条件下具有[[可再生性]]。然而，[[生命周期评价|生命周期评价（LCA）]]表明，这些材料的环境可行性并不仅仅取决于[[吸附]]性能。生产阶段的影响——主要由溶剂使用、功能化试剂和能耗密集型合成所主导——如果不加以审慎管理，可能接近甚至超过与 [[PFAS]] 去除相关的效益。在本文所采用的特征化框架下，与吸附剂相关物质在[[人体毒性]]和[[淡水生态毒性]]类别中的单位质量影响潜值，可能比 [[全氟和多氟烷基物质|PFAS]] 本身高出数个数量级。

本综述强调一个核心结论：[[聚合物基吸附剂|基于聚合物的 PFAS 吸附]]的净环境效益，由[[分子级选择性]]、[[运行耐久性]]以及在实际部署情景中可控的材料与过程负担共同决定。因此，未来的进展将在更大程度上依赖于将协同结合设计与[[混合处理架构]]、[[捕集—浓缩—销毁工作流程]]以及[[绿色制造]]相结合。以这种方式加以定位，聚合物[[吸附]]剂可以从高性能材料发展为可持续 [[PFAS]] 修复系统中可实际部署的组成部分。
