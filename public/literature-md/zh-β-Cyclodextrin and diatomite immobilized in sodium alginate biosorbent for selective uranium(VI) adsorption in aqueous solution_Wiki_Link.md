# 固定于[[海藻酸钠]]中的 [[β-环糊精]]和[[硅藻土]][[生物吸附剂]]用于水溶液中[[六价铀|铀(VI)]]的[[选择性吸附]]

## 摘 要

从[[海水]]等各种资源中分离和富集铀，对[[核能]]的可持续发展具有重要意义。因此，迫切需要开发一种成本低廉、易于获取、制备工艺简单且环境友好的[[吸附剂]]。本研究采用廉价的[[天然高分子材料]]（[[海藻酸钠]]）和天然[[吸附]]剂（[[β-环糊精]]和[[硅藻土]]），通过简单的方法制备了一种用于[[铀吸附]]的新型[[生物吸附剂]]——β-环糊精/海藻酸钠/[[硅藻]]土（[[CSD水凝胶|CSD]]）[[水凝胶微球]]。[[FTIR]]、[[XRD]]、[[SEM]]、[[能量色散X射线光谱|EDX]] 和 [[XPS]] 表征结果证实了 CSD 的成功制备。[[静态吸附实验]]表明，[[pH值|pH]]、[[接触时间]]、[[六价铀|U(VI)]][[初始浓度]]和温度对 CSD 的[[吸附容量]]具有显著影响。吸附过程符合[[准二级动力学模型]]和 [[Langmuir吸附等温模型|Langmuir 模型]]，[[吸附机制]]为[[化学吸附]]。在其他[[金属离子]]（Cu<sup>2+</sup>、[[镁离子|Mg]]<sup>2+</sup>、[[钙离子|Ca]]<sup>2+</sup>、[[钠离子|Na]]<sup>+</sup>、K<sup>+</sup>）存在的情况下，CSD 对铀(VI)的吸附具有明显的[[吸附选择性|选择性]]。此外，[[洗脱]]和重复使用研究表明，CSD 具有优异的[[吸附剂重复使用性|重复使用性]]能。总体而言，CSD 是一种价格低廉、制备过程绿色、高效且环境友好的生物吸附剂，对 U(VI)具有明显的选择性。其在[[海水提铀|从海水或盐湖水中富集 U(VI)]]方面具有潜在应用价值。

## 1. 引言

[[核能]]作为一种环境友好、稳定可靠的能源，已成为重点推广的新型[[清洁能源]] [1,2]。铀是[[核工业]]中不可或缺的原料。然而，全球常规铀储量约为 760 万吨，将在本世纪内耗尽，铀供应将成为一个[[能源安全]]问题 [3–5]。因此，人们需要寻找其他资源来获取铀，例如[[海水]]（铀总量约为 45 亿吨）和[[盐湖水]]。遗憾的是，海水（2.8–3.3 μg L<sup>−</sup> <sup>1</sup>）和盐湖水（300–500 μg L<sup>−</sup> <sup>1</sup>）中的铀浓度极低，导致从中提取铀十分困难 [6,7]。

[[吸附法]]因其工艺简单、[[铀吸附率]]高而成为最具前景的方法 [8,9]。为了从低浓度[[海水]]或[[盐湖水]]中高效富集铀，科学家们已开发出多种[[吸附剂]] [10–12]。然而，大多数[[吸附]]剂成本高、制备工艺复杂，不适合广泛用于从低浓度溶液中吸附[[六价铀|铀(VI)]]。因此，有必要开发一种价格低廉、制备工艺简单且能够广泛应用的吸附剂，用于[[海水提铀|从海水或盐湖水中吸附铀]]。

由[[天然高分子材料|天然聚合物]]制备的[[吸附剂]]因其易于获取且环境友好而备受关注 [13,14]。[[海藻酸钠]]（[[SA]]）是一种价格低廉、富含[[羟基|游离羟基]]和[[羧基]]的[[天然多糖]] [15,16]，能够与[[金属离子]]发生[[螯合]]或[[络合]]，作为[[吸附]]材料具有很大的潜力。然而，[[海藻酸钠水凝胶]][[机械强度]]低、[[热稳定性]]差，限制了其在[[重金属吸附]]中的应用。将海藻酸钠与其他材料结合可以提高其[[机械性能]]和热稳定性 [17]。[[β-环糊精]]（β-CD）是一种价格低廉的[[天然高分子]]材料，具有丰富的活性羟基和特殊的[[空腔结构]] [18]。[[硅藻土]]（[[DM]]）是[[硅藻]]骨骼形成的天然化石，主要由[[多孔硅质颗粒]]组成。它具有密度极低、[[孔隙结构]]高度有序、[[BET|比表面积]]大和热稳定性高等优点 [19–21]。将 β-CD 和 DM 固定在 SA 上，有助于改善[[水凝胶微球]]的机械性能、[[分散性]]和热稳定性。在本研究中，将 β-CD 和 DM 加入 SA 溶液中并充分混合。将混合物滴入[[氯化钙]]溶液中进行[[交联]]和[[固化]]，得到 β-环糊精/海藻酸钠/硅藻土（[[CSD水凝胶|CSD]]）。

本文报道了用于[[吸附]]水溶液中 [[六价铀|U(VI)]] 的[[生物吸附剂]] [[CSD水凝胶|CSD]] 的制备、表征及应用。通过考察溶液 [[pH值|pH]]、[[接触时间]]和[[初始浓度]]的影响，研究了 U(VI) 在 CSD [[复合材料]]上的吸附行为。研究了[[吸附动力学]]和[[吸附等温线]]。此外，还考察了其[[吸附剂重复使用性|重复使用性]]和[[吸附剂再生性能|再生性能]]，以评估其应用潜力。

## 2. 材料与方法

## 2.1. 材料

[[β-环糊精|β-CD]]（[[分子量]] 1134.98）购自[[上海源叶生物科技有限公司]]。[[SA]]（[[化学纯|CP]]，99.5 %）（[[海藻酸盐]]的 G/M 比值约为 0.72）购自中国医药（集团）

上海化学试剂 $\mathrm { C o . , }$ 有限公司。[[无水氯化钙]]和 [[DM]] 均购自[[国药集团化学试剂有限公司|国药集团化学试剂]] $\mathrm { C o . } _ { \cdot }$ 有限公司。[[氢氧化钠]]（NaOH）购自[[西陇化工]] $\mathrm { C o . , }$ 有限公司。上述所有化学品均为[[分析纯]]。[[海盐]]购自[[福建省盐业集团]] $\mathrm { C o . , }$ 有限公司。溶液采用[[福州大学]]制备的[[去离子水]]配制。将 $\mathrm { U O } _ { 2 } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ 溶解于[[蒸馏水]]中，配制 [[六价铀|U(VI)]] 离子储备液。

## 2.2. [[CSD水凝胶|CSD]] 的制备

将 [[DM]]（1 $g ) , \beta \mathrm { - C D } ( 3 \mathrm { g } ) ,$ 和 [[SA]]（2 g）加入 100 mL [[去离子水]]中，搅拌直至形成混合均匀的溶液。另取一个烧杯，加入 300 mL 去离子水，搅拌使 $\mathrm { C a C l } _ { 2 } ( 7$ g）溶解于水中。最后，使用[[蠕动泵]]将混合溶液以液滴形式匀速滴入 $\mathrm { C a C l } _ { 2 }$ 溶液中，液滴迅速[[固化]]，生成 [[β-环糊精|β-CD]]/[[海藻酸钠|SA]]/[[硅藻土|DM]]。

![](<../2.SCI_MD/β-Cyclodextrin and diatomite immobilized in sodium alginate biosorbent for selective uranium(VI) adsorption in aqueous solution/images/fb662639bdb45ff793c04f816fe60be648057907ea0b4a1ff4d81889530d4a65.jpg>)  
图 1. CSD 吸附剂的制备。

反应完成后，将微球在 $\mathrm { C a C l } _ { 2 }$ 溶液中浸泡 12 h，过滤取出，用[[去离子水]]洗涤，并在[[冷冻干燥机]]中[[冷冻干燥|冻干]] 48 h，最终得到干燥的 [[CSD水凝胶|CSD]]（图 1）。

## 2.3. [[吸附]]实验

将 10 [[镁离子|mg]] [[CSD水凝胶|CSD]] 加入 [[六价铀|U(VI)]] 离子溶液（200、300 mg $\mathrm { L } ^ { - 1 } )$，并加入不同的[[硝酸]]或[[氢氧化钠]]标准溶液，以调节溶液的 [[pH值|pH 值]]，在 298.15 K 下[[吸附]] 7 h 后进行 pH 测试。通过调节 U(VI) 离子溶液的[[初始浓度]]，开展初始浓度影响实验。将 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 溶液（200 mg $\mathrm { L } ^ { - 1 }$，pH 4.0–4.5）调节至不同温度，并持续搅拌 7 h，以考察温度的影响。为研究[[吸附动力学]]，将 15 mg CSD 加入 30 mL、300 mg $\mathrm { L } ^ { - 1 } \dot { \mathrm { ~ U O 2 ^ { 2 + } ~ } }$、pH 4.0–4.5 的溶液中，并定时搅拌。每项实验均重复三次，所有[[批量吸附实验]]数据均为平均值。以 [[偶氮胂III|Arsenazo-III]] 为[[络合剂]]，使用 [[紫外-可见分光光度计|UV–vis 分光光度计]]在 650 nm 处测定 U(VI) [[离子浓度]] [22]。平衡时 U(VI) 的[[吸附容量|吸附量]]由下式给出 [23]：

$$
q _ {e} = V (C _ {0} - C _ {e}) / m\tag{1}
$$

其中，$q _ { e }$（[[镁离子|mg]] ${ \bf g } ^ { - 1 } )$ 为[[吸附剂]]的[[平衡吸附容量]]；$C _ { 0 }$ 和 $C _ { e } ( \mathrm { m g } \mathrm { L } ^ { - 1 } )$ 分别为 [[六价铀|U(VI)]] 离子溶液的[[初始浓度]]和最终浓度；m（mg）为干燥[[吸附]]剂的质量，V（mL）为 U(VI) 离子溶液的体积。

## 2.4. [[吸附剂]]的表征

使用[[傅里叶变换红外光谱仪]]（[[Nicolet Magna 670]]）在 4000–400 $\mathrm { c m } ^ { - 1 }$ 范围内记录样品的 [[FTIR]] 光谱。使用 [[X射线衍射仪|X 射线衍射仪]]（[[Empyrean]]，[[PANalytical]]，荷兰），采用 [[Cu Kα辐射|Cu Kα 辐射]]记录 [[DM]] 和 [[CSD水凝胶|CSD]] 的 [[X射线衍射|X 射线衍射]]（[[XRD]]）图谱。XRD 图谱的记录范围为 10–80◦。使用[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]，[[Nova Nano 230]]）和能量色散 X 射线（[[能量色散X射线光谱|EDX]]）光谱仪研究样品的形貌和组成。使用 [[XPS]]（ESCALAB 250）分析[[铀酰离子|铀酰]]的配位机制。

## 2.5. [[铀酰离子|铀酰]]的[[选择性吸附]]

为测试 [[CSD水凝胶|CSD]] 对[[铀酰离子|铀酰]]的[[吸附选择性|选择性]]，将 $\mathrm { U O _ { 2 } ( N O _ { 3 } ) _ { 2 } } { \cdot } 6 \mathrm { H _ { 2 } O } \left( 0 . 4 6 4 8 \ \mathrm { g } \right)$ 和[[海盐]]（7.5 g）溶解于 250 mL [[去离子水]]中，得到[[模拟海水]]（铀酰[[离子浓度]]：1000 [[镁离子|mg]] $\mathbf { L } ^ { - 1 } )$。将 10 mg CSD 加入 20 mL 模拟[[海水]]（铀酰离子浓度：100、200、300 mg $\mathrm { L } ^ { - 1 } )$ 中，进行选择性实验。使用电感耦合等离子体原子发射光谱法（[[电感耦合等离子体原子发射光谱法|ICP-AES]]，Optima 8000）测定各离子的浓度 [24–26]。

## 2.6. [[吸附剂重复使用性|可重复使用性]]研究

再生实验采用 0.2 M $\mathrm { H N O } _ { 3 }$ 溶液作为[[洗脱]]剂 [27]。将 10 [[镁离子|mg]] [[CSD水凝胶|CSD]] 加入 20 mL $\mathrm { U O } _ { 2 } ^ { 2 + }$ 溶液（200 mg $\mathrm { L } ^ { - 1 } )$）中，处理 7 h，然后过滤分离[[吸附剂]]并冲洗。向[[吸附]]了铀离子的吸附材料中加入[[硝酸]]溶液，在温度为 298.15 K、转速为 150 rpm 的恒温振荡培养箱中解吸 2 h。随后，用[[蒸馏水]]充分洗涤负载后的吸附剂至中性，以供进一步重复使用。为测试吸附剂的[[吸附剂重复使用性|可重复使用性]]，进行了五次吸附/解吸循环。

## 3. 结果与讨论

## 3.1. [[XRD]] 分析

图 2 展示了裸 DM、CD/SA 和 CSD 的 XRD 图谱。与 CD/SA 相比，出现在 21.8◦、28.4◦、31.2◦ 和 35.9◦ 处的主要特征峰归属于 DM 的晶体结构，分别对应于 DM 的 [101]、[111]、[102] 和 [200] 晶面。结果表明，DM 已成功引入 CSD 中。

## 3.2. [[FTIR]] 分析

图 3 展示了 DM、CSD 和 CSD-U 的 FTIR 光谱。对于 DM，位于 1072、790、1020 和 464 $\mathrm { c m } ^ { - 1 }$ 处的特征吸收峰归属于 $s \mathrm { i } { - } 0 { - } s \mathrm { i }$ 的非对称振动、对称振动和弯曲振动 [28]。对于 CSD，位于 3287 $\mathrm { c m } ^ { - 1 }$ 处的宽吸收峰归属于 β-CD 中的 –OH 伸缩振动，位于 2933、1592、1417 和 1021 $\mathrm { c m } ^ { - 1 }$ 处的谱带分别归属于亚甲基的反对称伸缩振动、–COO<sup>−</sup> 的非对称和对称伸缩振动以及 $_ { \mathrm { C - O - C } }$ 的伸缩振动峰，而位于 1076 和 946 $\mathrm { c m } ^ { - 1 }$ 处的特征峰则来自 DM 中 $_ { \mathrm { S i - O - S i } }$ 的非对称伸缩振动和伸缩振动，以及 β-CD 中 α-1,4 糖苷键的骨架振动。吸附 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 后，CSD 在 921 $\mathrm { c m } ^ { - 1 }$ 附近出现了一个新的特征峰，该峰由 $\scriptstyle 0 = { \mathrm { U } } = 0$ 的伸缩振动引起。这一结果表明，$\mathrm { U O } _ { 2 } ^ { 2 + }$ 阳离子被吸附在 CSD 水凝胶复合材料上。

## 3.3. [[SEM]] 及元素分布映射

通过 [[SEM]] 图像表征了 [[CSD水凝胶|CSD]] [[吸附]]前后的微观结构。由图 4a 和 $\mathbf { b } ,$ 可见，吸附前 CSD [[水凝胶复合材料]]表面具有清晰的纹理。这些纹理结构有效增大了[[吸附剂]]的表面积，有利于 [[六价铀|U(VI)]] 的吸附。吸附 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 后，如图 4c 和 d 所示，可以清楚地看到微球表面变得光滑，此外，先前粗糙的孔隙被大量絮状物填满。结果证实，U(VI) 被吸附到 CSD [[水凝胶]]珠的孔隙中，并在珠体表面形成了一层絮状物。

## 3.4. [[能量色散X射线光谱|EDX]] 分析

能量色散 X 射线（[[能量色散X射线光谱|EDX]]）可用于分析样品的元素组成。图 5a 和 b 分别为 [[CSD水凝胶|CSD 复合材料]][[吸附]] [[六价铀|U(VI)]] 前后的代表性 EDX 能谱。可以清楚地观察到，吸附前的 CSD [[复合材料]]含有[[硅藻土]]的特征元素（Si），表明该复合材料已成功制备。将图 5b 与图 5a 进行比较可见，EDX 能谱中出现了一个新的 U(VI) 峰，因此 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 已成功吸附到 CSD 上。结果表明，CSD 复合材料对 U(VI) 具有良好的吸附效果。

## 3.5. [[XPS]] 分析

[[XPS]] 已被用于分析金属物种与[[吸附剂]]之间的相互作用 [29,30]。[[CSD水凝胶|CSD]] 的 [[X射线光电子能谱|XPS]] 全谱（图 S1）在约 532.27、285.36 eV 处分别显示出强烈的 O 1s 和 C 1s 峰。[[吸附]] [[六价铀|U(VI)]] 后，在约 381 eV 和 392 eV 处出现新峰，分别对应于 U4f7/2 和 U4f5/2 态的自旋–轨道分裂 [31,32]。C 1s 高分辨率谱（图 6a）区域在 284.80、286.45 和 288.15 eV 处有三个峰，分别对应于 $\mathrm { C - C , C - O } ,$ 和 $\mathrm { C = } 0 [ 3 3 ]$。负载[[铀酰离子]]后，结合能未发生显著变化，但 286.40 eV 处的峰强度增加，电子密度受到扰动，这是 $\mathsf { C a } ^ { 2 + }$ 与 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 之间发生离子交换的结果。图 6b 展示了吸附和未吸附铀酰离子的 CSD 的 O 1s XPS 谱。该区域在 531.15、532.70 eV 处有两个峰，分别对应于 $\mathrm { C } { = } 0 _ { \mathrm { { i } } }$ 和 [[羟基|O–H]] [34]。负载铀酰离子后，$\scriptstyle \mathrm { C = } 0$ 和 O–H 的结合能向较高值（531.50、532.77 eV）移动，表明由于参与铀酰离子的配位，电子密度降低（图 7）。

## 3.9. [[吸附等温线|等温线]]

为研究[[吸附]]机理，采用 [[Langmuir吸附等温模型|Langmuir]] 和 [[Freundlich吸附等温模型|Freundlich]] 等温模型研究[[吸附等温线]]。等温模型由以下方程表示 [39,40]：

$$
C _ {e} / q _ {e = 1} / q _ {m} K _ {L} + C _ {e} / q _ {m}\tag{5}
$$

$$
l g q _ {e} = l g K _ {F} + 1 / n l g C _ {e}\tag{6}
$$

其中，$C _ { e } ( \mathrm { m g L } ^ { - 1 } )$ 为 [[六价铀|U(VI)]] 离子的[[平衡浓度]]；$q _ { e }$ 和 $q _ { m } ~ ( \mathbf { m } \mathbf { g } \ \mathbf { g } ^ { - 1 } )$ 分别为[[平衡吸附容量]]和[[最大吸附容量]]；$K _ { L } ( \mathrm { L } \operatorname { m g } ^ { - 1 } )$ 为 [[Langmuir结合平衡常数|Langmuir 结合平衡常数]]；$K _ { F }$ 和 n 分别表示 [[Freundlich吸附平衡常数|Freundlich 吸附平衡常数]]。

$R _ { L }$ 是 [[Langmuir吸附等温模型|Langmuir 等温模型]]的一个重要无量纲参数，可用于评价[[吸附剂]]对 [[六价铀|U(VI)]] 离子的适用性 [41]。该方程由式 (7) 表示：

$$
R _ {L =} 1 / \left(1 + K _ {L} C _ {0}\right)\tag{7}
$$

其中，$C _ { 0 } ( \mathrm { m g } \mathrm { L } ^ { - 1 } )$ 为 [[六价铀|U(VI)]] 离子的[[初始浓度]]。$R _ { L }$ 可用于判定[[吸附]]过程为[[不利吸附]] $( R _ { L } > 1 ) _ { : }$ 2 [[线性吸附]] $( R _ { L } = 1 ) $、[[有利吸附]] $( 0 < R _ { L } < 1 )$ 和[[不可逆吸附]] $\left( R _ { L } = 0 \right) [ 4 2 ]$ ]。

图 11 展示了 Langmuir 和 Freundlich 等温模型。由这两个模型计算得到的相关数值汇总于表 2。可以看出，Langmuir 等温线与吸附数据吻合良好，表明 U(VI) 离子的吸附为单分子层吸附 [43]。此外，不同温度下的分离因子 $( R _ { L } )$ 均介于 0 和 1 之间，证实 U(VI) 在 CSD 复合凝胶珠上的吸附行为是有利的 [44,45]。

## 3.11. [[选择性吸附|选择性吸附实验]]

## 3.12. [[吸附剂重复使用性|可重复使用性]]及[[吸附剂生产成本]]

图 14 显示了当 $\mathrm { U O } _ { 2 } ^ { 2 + }$ 溶液初始浓度为 200 mg $\mathrm { L } ^ { - 1 }$ 时，再生循环次数与相应吸附容量之间的关系。可以看出，经过 5 次循环后，CSD 复合凝胶珠对 U(VI) 的吸附容量略有下降，但仍保留初始吸附容量的 86.84 %，表明 CSD 凝胶珠具有优异的可重复使用性。此外，制备 CSD 的经济成本为 2812 USD $\tan ^ { - 1 }$（补充信息，表 S1）。Zhao 等人 [46] 制备了用于从海水中吸附铀的 $\scriptstyle \mathbf { A O } .$ -HNTs 吸附剂，其吸附材料的生产成本为 4749.145 USD/吨。CSD 的生产成本比 AO-HNTs 低约 40 %。得益于低廉的原材料成本，CSD 是一种有望用于工业化海水提铀的铀吸附剂。
