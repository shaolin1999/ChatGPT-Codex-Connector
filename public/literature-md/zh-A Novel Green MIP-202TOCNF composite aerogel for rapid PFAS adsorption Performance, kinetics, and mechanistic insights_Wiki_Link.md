## 摘要

[[全氟和多氟烷基物质]]（[[PFAS]]）因其在环境中的持久性而常被称为“永久化学品”。PFAS 广泛用于日常消费品中，并最终进入空气、土壤，尤其是水体。它们可引发多种癌症并破坏水生生物。本研究主要致力于开发一种可持续的绿色[[吸附剂]]，以实现对水中 PFAS 的超快速[[吸附]]。通过[[一锅水热法]]合成了 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]，其中用 [[TEMPO 氧化纤维素纳米纤维]]（[[TOCNF]]）替代了 MIP-202 [[金属有机框架]]（[[MOF]]）中 50% 的[[天冬氨酸]]连接体。原位 MIP-202/TOCNF 复合气凝胶的结构表征表明，其[[BET|比表面积]]为 129.6 m<sup>2</sup>/g，较 MIP-202 提高了 26.7%。在环境相关条件下，该气凝胶对[[全氟辛烷磺酸]]（[[PFOS]]）和[[全氟己酸]]（[[PFHxA]]）分别在不到 10 秒和 30 秒内实现了超快速吸附。吸附结果符合[[二级动力学]]和 [[Freundlich等温模型|Freundlich 等温模型]]，PFOS 和 PFHxA 的最大[[吸附容量]]分别为 157.1 和 38.5 mg/g。通过[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算阐明了吸附机理，揭示吸附过程由[[静电作用]]与[[疏水相互作用]]的协同贡献所主导。该可持续的 MIP-202/TOCNF 复合气凝胶在四个[[再生|吸附循环]]中均保持优异性能。然而，由于[[冷冻干燥]]过程中[[介孔结构]]坍塌，四个循环后[[比表面积]]降至零。

## 1. 引言

[[PFAS]] 是[[全氟和多氟烷基物质]]，由于碳-氟键的稳定性而常被称为永久化学品 [1,2]。PFAS 的稳定性及其长达 2 至 7 年的半衰期，使其在环境中具有高度持久性 [3]。由于这些特性，它们具有广泛的应用，包括不粘炊具、防水防污服装、消防泡沫、纸张、电子产品及食品包装 [4]。在环境中，PFAS 具有高度迁移性和持久性，这使这些化学品成为致命污染物。它们在体内的生物累积可导致肝肾损伤以及人类发育问题 [5,6]。根据[[美国疾病控制与预防中心]]的数据，超过 99% 的美国人血清中可检测到五种 PFAS，检出率为 60% [1]。相比之下，Falls 等人报告称，全球超过 99% 的人血清中均可检测到 PFAS [7]。

然而，根据[[美国国家健康与营养检查调查]]（NHANES）过去二十年（1999–2020 年）的数据，由于对其生产实施严格监管，血清中 [[PFAS]] 的总浓度已出现下降 [8]。然而，传统 [[全氟和多氟烷基物质|PFAS]] 分子的新型变体正在对人类和环境构成更严重的威胁 [9]。Gao 等人报告称，在中国工业化地区接受检测的白领工人中，99% 的人血清中可检测到七种 PFAS 的浓度 [10]。

全氟烷基物质可分为[[全氟烷基酸]]、全氟烷基醚酸、全氟烷烃磺酰氟及其他类别。全氟烷基酸（PFAAs）根据所连接官能团（即[[羧酸根]]或磺酸根）进一步分为[[全氟羧酸]]（PFCAs）和[[全氟磺酸]]（PFSAs）。这些 [[PFAS]] 也可分为短链（PFCAs n ≤ 6 和 $\operatorname { P F S A s } \mathtt { n } \le 5 )$）或长链（PFCAs $\mathbf { n } \geq 7$ 和 PFSAs $\mathtt { n } \ge 6 )$），其中“n”为链中碳原子数 [11]。[[全氟和多氟烷基物质|PFAS]] 通常根据其结构中的碳原子数分类为短链 $\left( \mathtt { n } \le 6 \right)$ 或长链 $\mathbf { ( n \ge 7 ) }$。2024 年，[[美国环境保护署]]（EPA）为饮用水中六种 PFAS 分子制定了新的可执行标准。两种传统长链 PFAS 分子，即[[全氟辛烷磺酸]]（[[PFOS]]）和[[全氟辛酸]]（PFOA）的最大污染物水平（MCL）被设定为 4.0 ppt [12]。因此，这些长链 PFAS 已被逐步淘汰，并被更具迁移性且可能更持久的短链变体所取代，后者的[[吸附]]潜力更低 [13]。对于 [[全氟己烷磺酸|PFHxS]]、PFNA 和 [[GenX]]，MCL 被设定为 10 ppt [12,14]。为应对水中 PFAS 污染这一紧迫挑战，研究人员一直在开发可持续的吸附材料与技术。吸附是最成熟且研究最充分的方法，通常使用[[颗粒活性炭]]（GAC）和[[离子交换树脂]]（IX）[15]。但现有[[吸附剂]]要么[[平衡时间|吸附平衡时间]]较长，要么吸附潜力较低，尤其对短链 PFAS 而言 [16]。由于短链 PFAS 比长链 PFAS 含有更少的 CF2 单元，它们[[疏水性]]更弱。每增加一个 CF2 单元，[[分配系数]]（Kd）便增加 0.55 个对数单位，从而导致更强的[[疏水相互作用|疏水]]性 [4]。在设计新型吸附剂时，应平衡疏水性与阴离子特性，以优化对短链和长链 PFAS 的吸附。

合成[[吸附剂]]通常具有更高的[[疏水性]]和丰富的活性官能团，但在苛刻的反应条件下往往需要大量化学试剂投入，这会带来环境问题[17]。为了克服这些缺点，人们开始优先选择可持续的绿色高分子材料，例如多糖[18]。[[纤维素]]就是其中之一，它是地球上最丰富的天然聚合物，由通过[[β-1,4-糖苷键]]连接的[[葡萄糖单体]]组成，并含有伯羟基（C-6）和仲羟基（C-2、C-3）[19]。位于C-6位的伯羟基更易接近且反应活性更高，这有利于纤维素的官能化，并被用于对具有高[[BET|比表面积]]和机械稳定性的纤维素形式——[[纤维素纳米纤维]]（CNF）进行化学改性[20, 21]。TEMPO（2,2,6,6-四甲基哌啶-1-氧自由基）介导的氧化常用于将CNF的C-6位羟基转化为羧基（-COOH）。带有羧基的[[TEMPO氧化纤维素纳米纤维|TOCNF]]可用作阳离子[[吸附]]剂，如重金属和阳离子染料的吸附剂[22]。但[[PFAS]]在水中以阴离子形式存在，因此可以使用天然和合成聚合物制备复合吸附剂，以改善表面电荷、孔径和直径，从而提高[[吸附容量]][4]。

[[金属有机框架]]（MOFs）具有高度多孔性和结晶性，并具有二维或三维框架结构[23]。它们由金属离子与有机连接体或配体配位组成[24]。[[MOF]]结构中的缺陷可以通过多种方法引入，包括混合连接体法、调节剂法、刻蚀法和后合成方法，以调控MOF的性质[25]。在混合连接体法中，引入两种或多种拓扑结构不同且官能团不同的连接体，以控制它们的排列方式[26]。[[锆基MOF|锆基MOFs]]以能容忍大量缺陷而闻名。Zr-COO<sup>-</sup>键的形成是放热的，因此具有高度连接$\mathbf { Z r } _ { 6 }$簇的MOFs在[[热力学]]上更有利[26]。MOF结构可以通过[[纤维素]]加以稳定，形成具有独特功能特性的复合材料[27]。MOFs赋予材料柔性，而纤维素则赋予多孔性和活性官能团，并有助于MOFs相对于粉末状MOFs的回收，从而提高[[可重复使用性]][27]。MOF-纤维素复合材料具有广泛的环境应用。例如，Shiri等人合成了MOF-5/纤维素复合材料用于[[吸附]]废水中的阴离子染料，[[去除率]]达到96%[28]。类似地，Diab等人报道了一种生物相容性[[MIP-202]]-Zr-MOF[[吸附剂]]的合成，用于吸附废水中的染料和金属离子[29]。在另一项研究中，Efome等人制备了一种基于柔性Zr基[[MOF-808]]的膜，该膜可高效去除水中的重金属离子，保持较高的透水性，并可在处理后方便回收[30]。此外，Li等人开发了一种柔性、超[[疏水相互作用|疏水]]、功能化的纤维素[[气凝胶]]，具有高柔韧性和持久的可循环性，可用于多种选择性油水分离[31]。在另一项研究中，Borui等人采用传统回流法合成了MIP-202，MIP-202仅在极低pH（3）条件下对短链[[PFAS]]表现出优异的吸附性能，这在实际环境条件下并不可行[32]。

与传统 [[MOF]] 合成方法相比，常规方法要么使用高毒性有机连接体，要么包含有害溶剂，这不符合绿色与可持续化学原则。[[金属有机框架|MOF]] 合成过程中的另一个问题是团聚，产物通常以纳米晶粉末颗粒形式获得 [30]。[[吸附]]过程后粉末状 MOF 的回收十分困难，因为小粒径和较差的机械完整性使得从水相体系中分离不切实际，并可能导致二次污染 [31]。虽然[[纳米纤维素]]基[[气凝胶]]可以表现出高[[BET|比表面积]]，但在没有表面功能化的情况下，其对特定污染物的[[吸附能]]力往往有限，通常需要与其他活性材料结合才能实现高去除性能 [33]。然而，将 MOF 锚定到[[纤维素]]载体上或使用 [[TEMPO 氧化纤维素纳米纤维|tempo 氧化纤维素纳米纤维]]，可以克服粉末状 Zr 基 MOF 的固有局限，$\mathrm { i . e . , }$ 颗粒团聚、机械完整性差、吸附位点较少以及吸附后回收困难。此外，[[疏水性]]纤维素骨架为与 [[PFAS]] 的[[疏水相互作用]]提供了锚定位点。

在本研究中，我们旨在通过应用绿色化学原则（即使用可[[再生]]原料、更安全的溶剂和废物预防）合成一种可持续的绿色 [[MOF]] [[纤维素]][[气凝胶|复合气凝胶]]，以解决 [[PFAS修复|PFAS 修复]]方法中的关键空白。我们修改了 Diab 等人使用的方法，并以水为溶剂，将一半的有机连接体（[[天冬氨酸]]）替换为 [[TEMPO 氧化纤维素纳米纤维|tempo 氧化纤维素纳米纤维]]（[[TEMPO氧化纤维素纳米纤维|TOCNF]]），采用[[一锅水热法|一锅法]]替代传统的回流合成 [33]。我们合成了一种新型[[吸附剂]]气凝胶，该气凝胶结合了天冬氨酸上的胺基以及纤维素中糖苷骨架的强[[疏水性]]质。这种用 [[TOCNF]] 替代 50% 天冬氨酸的方式，使其能够快速[[吸附]]水中的短链和长链 [[PFAS]] 分子。此外，还开展了计算研究以进一步探索其结构与功能，这是本研究的重要补充，有助于深入了解复合气凝胶吸附 [[全氟和多氟烷基物质|PFAS]] 的机制。本研究的新发现将在以下各节中进行批判性评价。

## 2.2. [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]的合成

[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]采用原位和[[非原位合成]]方法制备。[[一锅水热法|原位合成]]（也称为一锅合成）是一种在目标基底存在下直接形成 [[MOF]] 的方法，金属前驱体、有机连接体和基底从一开始就置于同一反应容器中，从而使成核和晶体生长直接发生在基底上或基底内部，通常在溶剂热或水热条件下进行。相比之下，非[[原位合成]]则是先单独合成 [[金属有机框架|MOF]]，然后再通过单独的物理或化学步骤将其与基底结合 [35]。对于绿色 MOF（MIP-202）的合成，以[[氯化锆]]（ZrCl<sub>4</sub>）作为金属源，而氨基酸 [[L-天冬氨酸]]作为有机连接体。该反应中使用[[去离子水]]作为溶剂。将 1.975 g [[天冬氨酸|L-天冬氨酸]]在磁力搅拌下溶解于 80 mL 去离子水中，然后加入 1.27 g 无水 $\mathrm { Z r C l } _ { 4 }$。将反应混合物转移至带螺纹盖的聚四氟乙烯罐中，并在 120 ℃ 下高压釜处理 24 h。随后，将反应混合物离心，并用去离子水和乙醇洗涤沉淀，直至混合物达到中性 pH。最后，将沉淀在室温下于真空烘箱中干燥 48 h。

## 2.5. [[PFAS]] [[吸附]]实验

为优化 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]的组成，开展了初步[[吸附]]研究，并以 [[TOCNF]] 和 MIP-202 作为对照。在所有实验中，将 5 mg 每种气凝胶或粉末加入 10 mL 含 [[PFOS]]（30 mg/L）和 [[PFHxA]]（10 mg/L）的水中。选择 [[全氟辛烷磺酸|PFOS]] 和 [[全氟己酸|PFHxA]] 作为模型 [[PFAS]]，以评估对结构不同污染物的吸附性能。PFOS 代表长链[[全氟磺酸]]（PFSA），而 PFHxA 代表较短链的[[全氟羧酸]]（PFCA），从而可以评估不同链长和官能团对 [[全氟和多氟烷基物质|PFAS]] 去除的影响。所有实验均进行三次重复。吸附反应在 250 rpm 恒定振荡下进行 30 min。所有样品均经过滤，并使用上述液相色谱/质谱（[[液相色谱-质谱联用|LC/MS]]）方法进行分析。每种材料的[[吸附容量]]使用以下公式计算：

$$
\% \text{Removal} = \left(\frac {\mathrm{C} _ {0} - \mathrm{C} _ {\mathrm{e}}}{\mathrm{C} _ {0}}\right) * 100\tag{1}
$$

其中 ${ \mathrm { C } } _ { 0 }$（mg/L）为初始浓度；$\mathrm { C _ { e } }$（mg/L）为 [[PFOS]] 和 [[PFHxA]] 在平衡时的浓度。

为评估 pH 对 [[PFAS]] [[吸附]]的影响，在 pH 2–12 范围内开展了 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]吸附实验。使用 0.1 M [[氢氧化钠|NaOH]] 和 [[盐酸|HCl]] 将 pH 调节至 2、4、6、8、10 和 12。向每种混合液中加入 5 mg 气凝胶。样品以 250 rpm 振荡 30 min，用于 [[PFOS]] 和 [[PFHxA]]，随后经 [[尼龙滤膜|0.22 µm 尼龙滤膜]]过滤。吸附后浓度采用 [[液相色谱-质谱联用|LC/MS]] 分析。所有试验均设三组平行。[[吸附容量]] $\left( \mathbf { q } _ { \mathrm { e } } \right)$ 按式 2 计算。

$$
\mathrm {q_ {e}} = \frac {\left(\mathrm {C_ {o}} - \mathrm {C_ {t}}\right) \mathrm{xV}}{\mathrm{m}}\tag{2}
$$

其中，$\mathbf { q _ { e } _ { \theta } _ { \theta } _ { \theta } _ { \theta } _ { \theta } }$ 为[[气凝胶|复合气凝胶]]的[[吸附容量|平衡吸附容量]]。$\mathrm { C } _ { 0 }$（mg/L）和 $\mathrm { C _ { t } }$（mg/L）分别为时间（t）时 [[PFOS]] 和 [[PFHxA]] 的初始浓度与最终浓度。V（mL）为所用污染物（[[全氟辛烷磺酸|PFOS]] 和 [[全氟己酸|PFHxA]]）的体积，m（mg）为复合气凝胶的质量。

## 2.6. [[吸附动力学]]研究

开展动力学研究以考察接触时间对[[吸附]]过程的影响。所有吸附实验均在室温下将 5 mg [[气凝胶|复合气凝胶]]加入 10 mL 加标 [[PFAS]] 溶液中进行。[[吸附动力学]]先采用 1 mg/L，随后采用较高浓度的 [[PFOS]]（10 和 20 mg/L）及 [[PFHxA]]（5 和 10 mg/L）。反应在 250 rpm 持续振荡下进行，最长 15 min。随后使用注射器过滤器过滤溶液，并通过 [[液相色谱-质谱联用|LC/MS]] 分析。快速动力学样品（如 [[全氟辛烷磺酸|PFOS]]、[[全氟己酸|PFHxA]]）的反应时间用秒表手动控制。将预先称重的复合气凝胶加入置于配有滤膜的注射器内的 [[全氟和多氟烷基物质|PFAS]] 溶液中，手动振荡至目标接触时间。在所需时间点，立即压下注射器活塞以淬灭反应，使溶液通过滤膜并与复合气凝胶物理分离，从而终止进一步吸附。鉴于计时和过滤均为手动操作，所报告接触时间的估计不确定度约为 ±1–2 s，该值考虑了秒表反应时间及完成过滤所需的短暂间隔。[[吸附容量]]按式 2 计算，吸附数据分别采用[[准一级动力学模型|准一级]]和[[准二级动力学模型]]，按以下方程拟合：

$$
\operatorname{In} \left(\mathrm{q} _ {\mathrm{e}} - \mathrm{q} _ {\mathrm{t}}\right) = \operatorname{Inq} _ {\mathrm{e}} - \mathrm{k} _ {1} \mathrm{t}\tag{3}
$$

$$
\frac {t}{q _ {t}} = \frac {1}{k _ {2} (q _ {e}) ^ {2}} + \frac {t}{q _ {e}}\tag{4}
$$

其中，${ \bf q } _ { \mathrm { e } } ( { \bf m } { \bf g } / { \bf g } )$ 和 $\mathbf { q _ { t } }$ 分别为平衡时和时间 $\mathbf { \rho } ( \mathrm { t } ) ,$ 时的[[吸附容量]]。$\mathbf { k } _ { 1 } ( \mathbf { m i n } ^ { - 1 } )$ 和 k<sub>2</sub> $( { \bf g } . { \bf m } { \bar { \bf g } } ^ { - 1 }$ .min<sup>−</sup> <sup>1</sup>）分别为[[准一级动力学模型|准一级]]和[[准二级动力学模型|准二级]][[速率常数]]。

## 2.7. [[吸附等温线]]研究

开展[[吸附等温线]]研究以确定[[气凝胶|复合气凝胶]]对 [[PFOS]] 和 [[PFHxA]] 的最大[[吸附容量]]。所有[[吸附]]实验均在三个温度 $( 1 5 ^ { \circ } \mathrm { C } , 3 0 ^ { \circ } \mathrm { C } ,$ 和 45 ◦C）下，将 5 mg [[吸附剂]]加入 10 mL 吸附质中进行。[[全氟辛烷磺酸|PFOS]] 的吸附质初始浓度范围为 1 至 120 mg/L，[[全氟己酸|PFHxA]] 为 1 至 60 mg/L。加入吸附剂（复合气凝胶）前，所有吸附质小瓶在油浴中于各自温度下平衡，不调节 pH，然后在机械振荡器上以 250 rpm 振荡 15 min。吸附后所有溶液均经注射器过滤器过滤，其浓度由 [[液相色谱-质谱联用|LC/MS]] 测定。[[吸附平衡]]容量按式 2 计算。吸附数据采用线性和非线性 [[Langmuir 等温模型|Langmuir]] [36,37] 及 [[Freundlich 等温模型|Freundlich]] [37,38] 等温线模型，按以下方程拟合：

$$

$$
\mathbf {q} _ {\mathrm{e}} = \mathrm{K} _ {\mathrm{F}} \mathrm{C} _ {\mathrm{e}} ^ {1 / \mathrm{n}}\tag{5}
$$

$$
\frac {\mathrm{C} _ {\mathrm{e}}}{\mathrm{q} _ {\mathrm{e}}} = \frac {\mathrm{C} _ {\mathrm{e}}}{\mathrm{q} _ {\mathrm{m}}} + \frac {1}{\mathrm{q} _ {\mathrm{m}} \mathrm{K} _ {\mathrm{L}}}\tag{6}
$$

(7)

$$
\log q _ {e} = \log K _ {f} + \frac {1}{n} \log C _ {e}\tag{8}
$$

其中 $\mathrm { C _ { e } }$ （mg/L）为平衡时 [[PFOS]] 和 [[PFHxA]] 的浓度，${ \sf q _ { e } } \left( { \bf m } { \bf g } / { \bf g } \right)$ 为平衡时[[吸附剂]]所[[吸附]]的污染物量，$\mathsf { q } _ { \mathrm { m } }$ （mg/g）为[[最大单层吸附容量]]，$\mathrm { K _ { L } } \left( \mathrm { L } / \mathrm { m g } \right)$ 为 [[Langmuir 吸附常数]]，$\mathrm { K _ { F } }$ [(mg/g)(L/ $\mathbf { m g } ) ^ { 1 / \mathbf { n } } ]$ 为 [[Freundlich 吸附常数]]，n 为用于表征吸附强度的常数 [1,39]。

## 2.8. [[吸附热力学]]

通过[[吸附热力学]]研究，分析 [[PFOS]] 和 [[PFHxA]] 在 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]上[[吸附]]的[[吸附能]]与自发性。吸附实验在 15、30 和 $4 5 ~ ^ { \circ } \mathrm { C } .$ 下进行。使用 120 mg/L 的 [[全氟辛烷磺酸|PFOS]] 溶液和 20 mg/L 的 [[全氟己酸|PFHxA]] 溶液，考察温度对这些吸附质内能的影响。利用 [[Van’t Hoff 方程]]计算 [[Gibbs 自由能]]、熵和焓：

$$
\Delta G = - R T I n K _ {e} ^ {0}\tag{9}
$$

$$
\mathrm{InK} _ {\mathrm{e}} ^ {0} = \frac {\Delta S}{R} - \frac {\Delta H}{R T}\tag{10}
$$

$$
\mathrm{K} _ {\mathrm{e}} ^ {\mathrm{o}} = \frac {(1 0 0 0 . \mathrm{K} _ {\text { isotherm }} . \text { molecular   weight   of   adsorbate }) . [ \text { adsorbate } ] ^ {\mathrm{o}}}{\gamma}\tag{11}
$$

其中，R 为[[气体常数]] $( 8 . 3 1 4 \mathrm { ~ J ~ K ~ } ^ { - 1 } )$ ，[[焓|ΔH]] 为焓变（KJ mol $^ { - 1 } ) _ { : }$ ，[[吉布斯自由能|ΔG]] 为标准自由能变 $( \mathbf { k J m o l } ^ { - 1 } ) ,$ ，[[熵|ΔS]] 为熵变 $( \mathrm { J } \mathrm { m o l } ^ { - 1 } \mathrm { K } ^ { - 1 } )$ ，${ \mathrm { K } ^ { \circ } } _ { \epsilon }$ <sub>e</sub> 为[[分配系数]]。在式 11 中，γ 表示[[活度系数]]，K<sub>isotherm</sub> 表示所拟合等温线模型的 K 值，[Adsorbate]◦ 为[[吸附]]质的单位标准浓度（1 mol/L）[40]。

## 3. 计算研究

为在分子和电子层面探究 [[PFOS]] 与 [[PFHxA]] 在 [[MIP-202]] 上的[[吸附]]机制，开展了[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算。[[全氟辛烷磺酸|PFOS]] 和 [[全氟己酸|PFHxA]] 的电子结构采用 [[B3LYP 泛函]] [41] 与 [[6–31 G 基组]] [42] 计算。由于 [[PFAS]] 分子在水环境中主要以阴离子形式存在，计算针对负电荷物种在隐式溶剂条件下进行，使用 [[IEFPCM 水模型]] [43]。

对于 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]，计算采用 [[B3LYP 泛函]]与 [[LanL2DZ 基组]] [44]，以恰当地描述锆金属中心。上述所有计算均使用 [[Gaussian 16|Gaussian 16 软件]] [45] 完成，结果通过 [[GaussView 6.0|GaussView 6.0 软件]]可视化。[[PFAS]]: MIP-202 复合物的[[吸附能]]采用 [[FHI-aims 程序包]] [47] 中实现的 [[HSE06 杂化泛函]] [46] 计算。

[[吸附能]] $\mathrm { ( E _ { a d s } ) }$ 按式 13 [48] 计算如下：

$$
\mathrm{E} _ {\text { ads }} = \mathrm{E} _ {\text { complex }} - \left(\mathrm{E} _ {\text { adsorbent }} + \mathrm{E} _ {\text { adsorbate }}\right)\tag{13}
$$

其中，$\mathbf { E _ { c o m p l e x } , E _ { a d s o r b e n t } , }$ 和 $\mathrm { E _ { a d s o r b a t e } }$ 分别表示优化后复合物、孤立[[吸附剂]]和[[吸附]]质分子的总能量。

## 4.2. [[吸附]]研究

图 4(a) 表明，初始吸附实验旨在优化所合成的复合气凝胶。原始 MIP-202 去除了 90% 的 PFOS 和 87% 的 PFHxA，而原始 TOCNF 对这两种 PFAS 均未表现出显著吸附。所有原位复合气凝胶变体均优于非原位变体。原位复合气凝胶（50:50）即使在 30 和 10 mg/L 的较高浓度下，仍对 PFOS 和 PFHxA 表现出约 97% 的优异去除效率，表明 MIP-202 活性位点与 TOCNF 官能团之间达到了最佳平衡。但当这种平衡因 TOCNF 用量的增加或减少而被打破时，界面整合度下降，从而降低了所得气凝胶中吸附位点的可及性。因此，所有吸附实验均采用原位 MIP-202/TOCNF（50:50）复合气凝胶，在后续章节中将其称为原位复合气凝胶。

pH 对原位[[气凝胶|复合气凝胶]]去除 [[PFOS]] 和 [[PFHxA]] 的影响如图 4(b) 所示。[[全氟辛烷磺酸|PFOS]] 的最大[[吸附]]发生在 pH 低于 4 时，[[全氟己酸|PFHxA]] 的最大吸附发生在 pH 4 时。由于 PFOS 和 PFHxA 的 pKa 值较低（PFOS ≈ −3.27，PFHxA ≈ −0.16），在所研究的 pH 范围内二者主要以阴离子形式存在，如图 4(c 和 d) 所示。复合气凝胶的[[零电荷点]]（PZC）经测定为 4.3，表明在 pH 低于 4.3 时[[吸附剂]]表面带正电荷。因此，带正电荷的复合材料表面与带负电荷的 [[PFAS]] 分子之间形成强[[静电吸引]]，从而增强吸附。这种[[静电相互作用]]与 [[全氟和多氟烷基物质|PFAS]] 氟碳链和复合材料[[疏水相互作用|疏水]]域之间的疏水相互作用相辅相成，在酸性条件下产生最大[[吸附容量]]。当 pH 升高至 PZC 以上时，复合材料表面逐渐带更多负电荷，从而增大静电排斥力并降低吸附效率。

## 4.3.1. 前线分子轨道（FMO）分析

在水相阴离子条件下研究了[[PFOS]]和[[PFHxA]]的电子性质，这更真实地反映了它们的环境状态。如表6所示，[[全氟辛烷磺酸|PFOS]]的[[最高占据分子轨道]]（[[HOMO]]）和[[最低未占据分子轨道]]（[[LUMO]]）能量分别为−6.76和−0.095 eV，而[[全氟己酸|PFHxA]]的HOMO和[[最低未占分子轨道|LUMO]]值分别为−6.03和+0.69 eV。PFOS较低的LUMO能量表明其具有更大的极化率以及与[[吸附剂]]表面更强的相互作用倾向。相比之下，PFHxA表现出相对较弱的[[给体-受体分离]]，表明其轨道极化程度较低，与[[吸附]]剂的电子耦合较弱。PFHxA和PFOS分别表现出几乎相同的较大[[HOMO-LUMO 能隙|HOMO-LUMO能隙]]，为6.72和6.67 eV，反映了全氟化合物特有的高动力学稳定性。与之形成对比的是，[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]呈现出极小的[[HOMO-LUMO能隙|能隙]]，为0.32 eV，表明其在$\mathrm { Z r ^ { 4 + } }$节点处具有高极化率和强亲电特性。[[摩尔体积]]数据（PFHxA：122.9 cm³/mol；PFOS：189.6 cm³/mol；MIP-202：708.1 cm³/mol）为吸附提供了互补的结构视角。PFHxA的体积比PFOS小35%，预示着其通过溶液进行的Fickian扩散更快，并且更容易进入MIP-202介孔网络内较窄的孔道（经[[BET]]确认的孔径：3–20 nm）。孔填充分数，即每个分子占MIP-202簇体积的比例中PFOS为26.8%、PFHxA为17.4%，表明两种[[PFAS]]均未造成孔堵塞，并且每个簇单元可以容纳多个分子，这与实验结果中提到的多层[[Freundlich 等温模型|Freundlich]]吸附行为一致[73]。

## 4.3.4. [[静电势]]（ESP）分析

进行[[静电势]]（ESP）分析以研究[[PFAS]]分子与[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]][[吸附剂]]之间的电荷分布和[[静电互补性]]。[[PFOS]]、[[PFHxA]]和MIP-202/[[TOCNF]]复合气凝胶的ESP图（图11）为初始[[吸附]]驱动相互作用和可能的吸附活性区域提供了重要见解。对于[[全氟辛烷磺酸|PFOS]]，ESP分布显示[[磺酸基]]（-SO₃⁻）官能团周围呈现高度集中的负静电势，表明电子密度强烈定位于氧原子上。类似地，[[全氟己酸|PFHxA]]在[[羧酸根]]（-COO<sup>-</sup>）基团周围表现出负静电势。然而，由于磺酸基具有更高的吸电子能力和电荷稳定作用，PFOS中的负电势比PFHxA更为广泛且强烈离域。带负电的[[全氟和多氟烷基物质|PFAS]]头部基团与MIP-202/TOCNF复合气凝胶中正极化的$\mathrm { Z r ^ { 4 + } }$中心之间存在强烈的静电互补性，表明[[静电吸引]]是初始吸附驱动力。PFOS中观察到的更强静电极化解释了其相较于PFHxA对MIP-202/TOCNF复合气凝胶具有更高的吸附亲和力。此外，PFOS和PFHxA的[[全氟碳链|氟化尾部]]表现出相对较低的静电极性，表明氟化区域主要通过[[疏水相互作用|疏水]]和[[色散相互作用]]发挥作用，而非直接[[静电相互作用|静电吸引]]。ESP结果有力地支持了实验观察到的吸附行为，并与[[吸附能]]、[[态密度|DOS]]、[[HOMO-LUMO]]、[[非共价相互作用|NCI]]和[[电荷转移]]分析一致，共同证实PFAS在MIP-202/TOCNF复合气凝胶上的吸附由静电吸引启动，随后经历电子耦合和疏水稳定化。

[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]的[[静电势|ESP]]图显示，在$\mathrm { Z r ^ { 4 + } }$金属中心周围存在高度缺电子区域，而含氧连接基区域则表现出相对富电子特征。[[锆节点]]周围的正静电势证实了其强[[路易斯酸]]性，并突出了其作为带负电[[PFAS]]分子主要[[吸附]]位点的作用。该ESP图呈现出一个异质的两亲性表面：弥散的黄橙色区域覆盖中心[[Zr₆簇|Zr₆氧簇]]（[[亲电性]]，路易斯酸性），而蓝青色区域则定位于[[天冬氨酸]]连接基的外围-NH₂基团和未配位羧酸氧原子周围（亲核性）。绿色中性区域横跨有机C-C骨架。这种三区ESP结构，即亲电核心、亲核外围、中性骨架，恰好与两种[[全氟和多氟烷基物质|PFAS]]分子的两亲性电荷分布互补。

[[静电势|ESP]] 分析确立了 [[PFAS]] 阴离子与 [[MIP-202]] 表面之间清晰的[[静电互补性]]。在 pH 低于 4 时，[[天冬氨酸]]连接体的 -NH₂ 基团[[质子化]]为 [[铵基|-NH₃⁺]]，产生带正电的表面，该表面与 [[PFOS]]（[[磺酸基|SO₃⁻]]）和 [[PFHxA]]（[[羧酸根|COO⁻]]）的强负 ESP 瓣直接互补。[[全氟辛烷磺酸|PFOS]] 的磺酸根产生的负 ESP 区域比 [[全氟己酸|PFHxA]] 的羧酸根更大且更强，这是因为负电荷分布在三个等效的 S–O 氧上（而羧酸根为两个），并且具有永久离子特性（pKₐ ≈ −3.3 vs ≈2.5）。这预示着 PFOS 与质子化胺表面之间存在更强的长程[[静电吸引]]，与实验中在酸性 pH 下观察到的近定量去除一致。两条全氟链上呈中性至轻微正电的 ESP 与 MIP-202/[[TEMPO氧化纤维素纳米纤维|TOCNF]] 的天冬氨酸和 [[TOCNF]] 骨架的中性绿色区域互补，从而能够实现[[疏水相互作用|疏水接触]]和[[范德华力|范德华相互作用]]而不产生静电惩罚。这种 ESP 结构证实了双机制模型：头基[[静电作用]]与链骨架疏水作用在[[吸附]]界面不同空间区域同时发挥作用。

## 4.3.5. [[吸附能]]与[[热力学]]解释

使用 [[密度泛函理论|HSE06]] 泛函计算的[[吸附能]]表明，[[PFOS]] 和 [[PFHxA]] 在 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]框架上的[[吸附]]在[[热力学]]上均是有利的，其值分别为 −89.93 和 −81.86 kcal/mol（图 12）。[[全氟辛烷磺酸|PFOS]] 更负的吸附能表明其与[[吸附剂]]表面的相互作用比 [[全氟己酸|PFHxA]] 更强。PFOS 这种增强的吸附行为归因于其高度极化的磺酸根基团、更长的[[全氟碳链|氟化链]]以及更强的供体-受体相互作用能力。[[静电势|ESP]] 分析表明，PFOS 与 MIP-202/[[TOCNF]] 复合气凝胶的缺电子 $\mathrm { Z r ^ { 4 + } }$ 中心之间存在更强的[[静电互补性]]，而 [[态密度|DOS]] 和[[电荷转移]]分析证实了增强的轨道重叠和电子耦合。此外，[[非共价相互作用|NCI]] 分析揭示了 PFOS 具有更广泛的[[色散相互作用]]区域，表明其[[疏水相互作用|疏水]]稳定作用更强。这些发现共同解释了实验观察到的 PFOS 相较于 PFHxA 更优的吸附亲和力。

## 4.3.7. [[全局反应性描述符]]

如表 8 所示，[[PFOS]] 和 [[PFHxA]] 具有非常相似的[[化学硬度]]值 $( \eta = 3 . 3 3$ 和 3.36 eV）。这定量地证实了两种分子都是硬质、化学惰性物种，具有环境持久性，这在其量子力学性质中得到了体现。大的[[HOMO-LUMO能隙|能隙]]（两者均约为 6.7 eV）意味着推动电子跨越 [[HOMO-LUMO]] 势垒需要较高的活化能，这解释了两种 [[PFAS]] 对[[生物降解]]、[[光解]]和常规氧化处理的抵抗性。[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]极其柔软 $( \eta \ = \ 0 . 1 6 \ : \mathrm { e V } )$ ，其[[亲电性指数]]为 $2 5 . 9 \mathrm { e V } _ { \mathrm { i } }$ ，在所有研究物种中最高，高出十倍以上。根据 Pearson 的软硬酸碱（[[软硬酸碱理论|HSAB]]）原理，软物种倾向于通过极化率和色散作用与其他软物种相互作用，而硬物种则倾向于与硬物种发生[[静电相互作用]]。在该体系中，[[全氟和多氟烷基物质|PFAS]] 阴离子整体的硬质特性与 MIP-202/[[TOCNF]] 气凝胶的极端柔软性相结合，产生了一种[[热力学]]上有利的混合软硬相互作用：硬质、带负电的头基与气凝胶的局部硬 Lewis 酸位点结合 $\left( \mathrm { Z r ^ { 4 + } } \right.$ ，高电荷且半径小），而柔软、可极化的[[全氟碳链|全氟化链]]则通过[[色散相互作用|色散力]]与气凝胶的有机框架相互作用。这种[[吸附]]界面处的双重软硬相互作用是 MIP-202/TOCNF 复合气凝胶设计的一个关键优势。

[[PFHxA]]<sup>-</sup> 的负[[电子亲和势]]（[[电子亲和能|EA]] = −0.69 eV）证实[[羧酸根]]阴离子主动抵抗进一步接受电子。其[[吸附]]相互作用必须通过将其孤对电子（[[HOMO]]）提供给 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]的[[路易斯酸]] $\mathrm { Z r ^ { 4 + } }$ 位点，以及通过静电和[[范德华力|范德华机制]]进行。[[LUMO]] 在 [[全氟己酸|PFHxA]] 与 MIP-202/[[TOCNF]] 复合气凝胶的结合中基本不起作用。PFHxA 和 [[PFOS]] 现在显示出几乎相同的[[化学硬度|硬度]] $( \eta \approx$ $3 . 3 3 \substack { - 3 . 3 6 ~ \mathrm { e V } } )$ ，这在物理上是令人满意的。二者都是具有相似电子特征的全氟阴离子，主要区别在于链长和头基类型。这种一致性验证了我们的计算方法。[[电荷转移]]方向在化学上得到了阐明。PFHxA<sup>-</sup> 向 MIP-202 提供少量电子密度（+0.030 e⁻），而 MIP-202 向 [[全氟辛烷磺酸|PFOS]]⁻ 提供电子密度 $( - 0 . 0 7 9 \mathrm { ~ e } ^ { - } , \mathrm { ~ i . e . , ~ }$ $0 . 0 7 9 ~ \mathrm { e ^ { - } }$ 流向为 MIP-202 → PFOS。这是因为 PFOS 的[[电负性]] $\left( \chi = 3 . 4 3 \right)$ 高于 MIP-202 $( \chi = 2 . 8 8 )$ ，从而从 [[MOF]]的富氧[[最高占据分子轨道|HOMO]]沿[[全氟碳链|氟化链]]遵循[[反馈捐赠机制]]进入PFOS的近零能级[[最低未占分子轨道|LUMO]]。对于PFHxA，电负性几乎匹配（2.67 vs 2.88），导致净电荷转移极小。这意味着PFOS吸附具有比先前计算更强的轨道相互作用特征，而PFHxA吸附则纯粹由[[静电作用]]和[[范德华相互作用|范德华接触]]主导。这与这些物种HOMO与[[最低未占据分子轨道|LUMO]]之间的电荷转移分析结果完全一致。

## 4.3.8. 界面处的[[电荷转移]]

[[吸附]]界面处的[[电荷转移]]采用[[Parr-Pearson 形式体系|Parr-Pearson形式体系]]进行评价：

$$
\Delta N = - \mu / 2 \eta
$$

其中(ΔN)为[[电荷转移]]，μ为[[化学势]]（eV），η为[[化学硬度|硬度]]（eV）。如表8所示，[[PFHxA]]的$\Delta \mathrm { N } = 0 . 3 9 7 ~ \mathrm { e ^ { - } }$，[[PFOS]]的$\Delta \mathrm { N } = 0 . 5 1 5 \ \mathrm { e ^ { - } }$，[[气凝胶|复合气凝胶]]的$\Delta \mathrm { N } = 9 . 0 5 ~ \mathrm { e ^ { - } }$。

此外，[[偶极矩]]值为了解界面处的[[电荷转移]]提供了重要信息。计算得到的偶极矩汇总于表 6。[[PFOS]] 在所有实验 pH 值下均为永久阴离子。其 [[磺酸基|SO₃-]] 头部带有分布在三个氧原子上的三个等价形式负电荷（形成一个大的、集中的负电中心），而末端 [[CF₃|-CF₃]] 基团则是电子最缺乏的区域（形成一个小的正电中心）。偶极矢量横跨整个 8 碳氟化骨架，因而具有较长的空间臂，也因此具有异常大的偶极数值。[[PFHxA]] 较短的链（6 个碳）缩短了这一臂长，从而给出相应较小的偶极矩（16.62 D），但由于 [[羧酸根|-COO-]] 头部，其偶极矩仍然相当可观。

[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]的带电表面（pH < 4时[[质子化]]的[[铵基|-NH₃⁺]]）在[[吸附剂]]表面产生局部电场。具有大[[偶极矩]]的入射[[PFAS]]分子将受到使其与该电场对齐的力矩作用。其负电端（阴离子头基）被吸引向正电表面，而正电端（氟化尾链）则被排斥。[[PFOS]]的偶极矩是MIP-202/[[TOCNF]]复合气凝胶的1.86倍，经历了最强且最具方向性的静电引导，这解释了[[ESP 分析|ESP分析]]所预测的有序、头基优先的[[吸附]]取向。[[PFHxA]]的偶极矩仅为MIP-202/TOCNF复合气凝胶的1.19倍，其方向性驱动力较弱但仍然有效。

这种偶极引导的取向直接控制[[吸附动力学]]。一个由其偶极预先排列到达的分子与表面结合位点发生相互作用，而不需要高成本的旋转再取向。[[吸附]]质上的永久偶极（[[PFOS]]：25.99 D；[[PFHxA]]：16.62 D）也将在高度可极化的[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]骨架中诱导出偶极（小的[[HOMO-LUMO]]间隙，柔软，$\begin{array} { r l } { \omega } & { { } = } \end{array}$ $2 5 . 9 \ : \mathrm { e V } )$）。由于MIP-202/[[TOCNF]]复合气凝胶极易极化$( \mathtt { g a p } = 0 . 3 2 \ : \mathrm { e V } )$，且[[全氟辛烷磺酸|PFOS]]具有最大的永久偶极，PFOS-MIP-202/TOCNF复合气凝胶在所有组合中经历最强的德拜（永久偶极-诱导偶极）相互作用。这是一种额外的[[非共价稳定化]]贡献。

在[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]的[[跃迁密度矩阵|TDM]]图中，原子编号从1到73。橙色线条将不同区域标示为A（原子1–26，Zr₆无机簇 + 桥接氧）、D（原子27–73，[[天冬氨酸]]与[[TOCNF]]有机连接体）。MIP-202的TDM与两种[[PFAS]]分子都存在深刻差异。其最大TDM值为0.1753，不到[[PFHxA]]（0.3981）的一半，也显著低于[[PFOS]]（0.3081）。整个矩阵由弥散、低强度的蓝色结构主导，表明MIP-202的电子激发高度离域，没有单一原子对主导相干性，电子-空穴对广泛分布在簇中。在（x ≈ 1–2，y ≈ 1–2）处出现明亮局域点：这些原子位置对应于无机节点核心的Zr原子，显示出A-A块中最高的局域相干性。这证实Zr原子通过[[Zr-O]][[电荷转移跃迁]]（簇内d → p或[[配体到金属电荷转移|配体到金属CT]]）直接参与电子激发。在$( \mathbf { x } \approx 7 3 , \mathbf { y } \approx 7 3 ) \colon$处有一个亮点，对应末端连接体原子，证实有机外围也在D-D边界参与[[局域激发]]。D-D块（原子27–73，有机连接体）显示为均匀低强度蓝色的弥散网格状图案。这表明整个有机网络中存在许多小的相干性分布，而没有单一主导路径。这反映出多个等价的天冬氨酸连接体，各自贡献于小的、平行的激发通道。D-A和A-D非对角块整体呈现非常低但非零的强度，表明无机簇与有机连接体之间存在细微且广泛分布的[[电荷转移]]特性，这与[[HOMO]]轨道分析中识别出的Zr-O-C配位界面一致。

[[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]][[气凝胶|复合气凝胶]]的[[跃迁密度矩阵|TDM]]揭示了[[吸附]]机制中一个根本重要的事实。高度离域、低峰值强度的激发意味着MIP-202没有单一主导的电子相互作用位点。相反，它呈现出多位点、电子弥散的表面，能够通过许多平行的电子路径同时响应到来的[[PFAS]]分子。这就是多机制吸附的电子结构来源。任何接近MIP-202/[[TOCNF]]复合气凝胶的[[全氟和多氟烷基物质|PFAS]]分子，都能在[[锆节点|Zr节点]]（A-A相干性）、有机连接体（D-D相干性）或跨D-A界面诱导电子响应，具体取决于接近方式、几何构型以及PFAS头部基团。较低的TDM最大值（0.1753），加上框架极小的[[HOMO-LUMO 能隙|HOMO-LUMO能隙]]（0.32 eV）和高[[亲电性]]$\mathrm { \bf ( \omega \omega } = 2 5 . 9 \mathrm { e V } )$，证实MIP-202是一个电子学意义上的“软着陆”表面。它以最小的能量代价和最大的空间灵活性容纳到来的PFAS电子扰动。

## 4.4. 文献比较

合成的 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]的[[吸附]]性能与先前报道的用于 [[PFAS]] 去除的 [[MOF]] 基[[吸附剂]]进行了比较，如表 9 和图 15 所示。主要考察了[[平衡时间|吸附平衡时间]]和[[吸附容量]]等不同因素。[[MOF-808]]（939 mg/g）、[[DUT-5–2]]（1015 mg/g）、[[ZIF-67]]（734.7 mg/g）和 [[UiO-67]]（743 mg/g）对 [[全氟和多氟烷基物质|PFAS]] 的吸附容量较高；但它们通常需要更长的接触时间，并且往往在更高的污染物浓度下运行。而我们此前的研究 [1] 表明，吸附时间相对较短，小于 30 s 至 3 min。本研究采用绿色合成技术以及温和的反应条件和天然成分，通过用 50% [[TEMPO 氧化纤维素纳米纤维]]替代 50% [[L-天冬氨酸]]连接子，在 MIP-202 中引入一些结构缺陷，最终通过将 [[PFOS]] 和 [[PFHxA]] 的吸附时间分别缩短至 10 s 和 30 s 来诱导吸附过程。这种对 PFAS 分子的超快速吸附使本研究具有新颖性。

## 4.5. [[可重复使用性]]研究

图 16 展示了 MIP-202/TOCNF 复合气凝胶在四个吸附-解吸循环中的可重复使用性。PFOS 的去除率最初达到 100%，随后在后续循环中下降至 75%。这一下降归因于再生过程中吸附剂复合气凝胶的损失。短链 PFHxA 也观察到类似趋势，初始去除率为 100%，第 4 个循环时降至 43%。在再生和洗涤循环过程中存在显著的吸附剂损失。再生后的 MIP-202/TOCNF 复合气凝胶通过 FTIR、TGA 和 BET 比表面积分析进行表征，以评估活性官能团的潜在浸出和结构完整性。如图 S4（a）所示，回收气凝胶的官能团没有变化；所有峰均保持完整，但由于吸附位点的部分占据和轻微的结构重排，峰强度略有下降。使用后气凝胶的 TGA 分析（图 S4（b））表明，PFAS 吸附后降解曲线发生变化。在 300 至 $7 0 0 ~ ^ { \circ } \mathrm { C } .$ 之间，重量损失相对缓慢。然而，在 $> 7 5 0 ~ ^ { \circ } \mathrm { C }$ 处 10% 的重量损失代表吸附的 PFAS 分子的热解 [85]。经过四个连续循环后，比表面积下降至 $0 \mathrm { m } ^ { 2 } / \mathrm { g }$，因为气凝胶脆弱的中孔结构在冷冻干燥时因毛细管应力而坍塌。上述 DFT 方法验证了这些结果，即 MIP-202/TOCNF 复合气凝胶具有较软的结构，在多次循环后无法承受毛细管应力。

## 4.6. [[吸附]]机理

## 5. 结论

在本研究中，采用[[一锅水热法]]，以水为[[绿色溶剂]]，成功合成了一种可持续且绿色的 [[MIP-202]]/[[TEMPO氧化纤维素纳米纤维|TOCNF]] [[气凝胶|复合气凝胶]]，用于高效去除水中的短链和长链 [[PFAS]]。与原始组分和[[非原位合成]]材料相比，[[原位合成]]的复合气凝胶表现出优异的结构完整性、[[热稳定性]]和[[吸附]]性能。优化后的 50:50 组成具有最高的 [[BET比表面积|BET 比表面积]]（129.56 m²/g），并增强了 MIP-202 与 [[TEMPO 氧化纤维素纳米纤维]]之间的界面结合。吸附研究表明 [[全氟和多氟烷基物质|PFAS]] 吸附超快，在数秒内即达到[[吸附平衡]]，[[Freundlich 等温模型|Freundlich]] 等温线拟合证实了[[非均相多层吸附]]行为。[[PFOS]] 和 [[PFHxA]] 的最大[[吸附容量]]分别为 157.07 mg/g 和 38.45 mg/g，去除效率超过 99%，表明其处理性能优异。[[热力学]]研究表明吸附是自发的[[吸热过程]]，主要由[[物理吸附]]控制，而 pH 研究则突出了[[静电吸引]]和[[疏水相互作用]]对 PFAS 去除的协同贡献。重复使用性实验进一步表明其具有良好的[[再生能力]]，[[全氟辛烷磺酸|PFOS]] 在多次[[吸附-脱附循环]]中性能仅出现轻微下降，但 [[全氟己酸|PFHxA]] 的吸附量在第四次循环时显著下降，这可能是由于气凝胶结构的损失所致。计算研究有力地支持了实验观察结果，揭示 PFOS 吸附得益于[[静电相互作用]]、[[Lewis酸碱配位|Lewis 酸碱配位]]、疏水效应、[[范德华力|范德华相互作用]]和双向[[电荷转移]]机制的协同作用，而 PFHxA 吸附则主要受限于局域静电和配位相互作用。[[态密度|DOS]]、[[HOMO-LUMO]]、[[静电势|ESP]]、[[吸附能]]和 [[非共价相互作用|NCI]] 分析共同验证了实验观察到的复合气凝胶对长链 PFOS 相对于短链 PFHxA 具有更强亲和力的现象。然而，该复合气凝胶在第四次循环中 PFAS [[去除率]]显著下降。进一步表征表明，[[冷冻干燥]]后气凝胶的[[介孔结构]]发生损失，导致[[BET|比表面积]]几乎降至零。此外，与先前报道的 PFAS [[吸附剂]]的比较表明，所开发的复合材料在[[快速吸附动力学]]、优异去除效率和实际处理能力之间实现了具有竞争力的平衡。总体而言，本工作确立了绿色 MIP-202/[[TOCNF]] 复合气凝胶作为一种有前景的可持续吸附剂平台，用于 [[PFAS修复|PFAS 修复]]，并提供了基础机理见解，可为面向[[新兴污染物]]的下一代[[生物基吸附剂]]的理性设计提供指导。
