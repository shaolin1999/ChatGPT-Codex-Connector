## 摘 要

[[全氟和多氟烷基物质]]（PFASs）是一类持久性环境难题，广泛污染各类水生环境。同时去除结构多样性复杂的多种PFASs——包括短链、长链以及新兴变体——仍然是一项紧迫任务。本研究采用[[静电纺丝|静电纺丝技术]]制备了[[季铵化壳聚糖-聚乙烯醇纳米纤维膜]]（[[QCS-PVA NFsM]]）。通过调节季铵化程度（55%）、[[季铵化壳聚糖|QCS]]负载量（20 wt%）和[[交联]]时间（3 h）确立了最佳条件。本工作首次将QCS-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]]应用于[[环境水体]]中多种PFASs的同时[[吸附]]与去除，旨在优化其去除性能。QCS-PVA NFsM表现出均匀的纤维形貌、平衡的亲水性与疏水性（[[水接触角]]为84.75°，[[溶胀度]]<2 g/g）、介孔结构（6.373 m<sup>2</sup>/g），而QCS固有的正电荷促进了[[静电相互作用]]。实验验证与计算证实，静电、疏水和[[氢键|氢键相互作用]]实现了对21种PFASs的有效共同去除，包括短链、长链和新兴PFASs。与以往报道的吸附剂相比，QCS-PVA NFsM表现出更优异的共同去除性能（80.4%–99.8%），尤其将高极性[[全氟丁酸|PFBA]]和[[全氟丁基磺酸|PFBS]]的[[去除效率|去除率]]提高了近40%。吸附过程为自发且吸热，遵循[[吸附等温线|Freundlich等温线]]和[[准二级动力学模型]]。吸附平衡在0.75 h内达到，比大多数先前报道的研究（2–120 h）快约3–160倍。此外，QCS-PVA NFsM能够有效共同去除原始环境水体中的多种PFASs，并在六次重复使用循环中保持稳定性能且无需二次分离，凸显了其在环境修复中的高度实际应用价值。

## 1. 引言

[[全氟和多氟烷基物质]]（PFASs）代表一类以[[碳-氟键]]为特征的合成有机氟化合物 [1]。由于其优异的热稳定性、化学稳定性以及疏油疏水特性，PFASs 被广泛用于 200 多个工业和消费领域。在推动社会经济发展的同时，这种广泛应用也导致了广泛的环境污染，尤其是在[[环境水体]]中 [2]。PFASs 具有多种结构，包括长链、短链以及新兴替代品。这些 PFASs 的理化性质差异很大。值得注意的是，短链和新兴 PFASs 极性更强、疏水性更弱、迁移性更高。这使得它们更难通过常规水处理系统去除 [3]。因此，这导致了多种 PFASs 在各种环境水体介质中的复合污染，其在地表水和地下水等环境水体中的浓度范围为几 ng/L 到几 mg/L [2]。这种暴露可能通过人体摄入对肝脏和肾脏等重要器官造成直接或间接损害。PFASs 的结构多样性、环境持久性以及对人体健康的风险，对当代水处理中开发能够同时去除多种 PFASs 的高效材料构成了重大工程挑战。

[[环境水体]]中 [[全氟和多氟烷基物质|PFAS]] 的修复可通过多种物理、化学和生物方法实现[4]，其中[[吸附]]因其操作简便且效果显著，已发展为一种成熟且广泛应用的技术[5]。现有吸附材料包括常规吸附剂（如[[活性炭]]和[[离子交换树脂|树脂]]）[6]、[[改性沸石]][7]、[[多糖基材料]][8]、[[磁性纳米颗粒]]（MNPs）[9]、[[金属有机框架]]（MOFs）[10]和[[共价有机框架]]（COFs）[11]。活性炭和离子交换树脂等[[传统吸附剂]]通过[[疏水相互作用]]对长链 PFAS 表现出较高的吸附效率[12]。包括 MOFs、COFs 和 MNPs 在内的先进材料则具有优异的结构可调性和对多种 PFAS 的快速[[吸附动力学]][13–15]。多糖基材料（如[[壳聚糖]]、[[纤维素]]衍生物）[16–18]因固有的生物相容性和低成本而成为一种有前景的替代方案[19]，对 [[全氟辛酸|PFOA]] 和 [[全氟辛基磺酸|PFOS]] 等长链 PFAS 的[[去除效率|去除率]]可达 80%以上[8]。然而，这些材料主要依赖单一的主导机制：疏水相互作用、静电吸附或[[氢键]]。因此，尽管它们通常对长链 PFAS 表现出良好的去除效率，却难以有效处理高极性的短链和新兴 PFAS（去除效率 <50%）[19–22]。此外，粉末状或纳米级吸附剂在实际应用中还面临分离困难、易流失以及二次污染风险等问题，进一步限制了其工程应用[13,23–25]。同时，在环境相关 PFAS 浓度（ng/L 至 mg/L）下评估这些吸附剂仍存在关键空白，因为大多数研究集中于 mg/L 级的加标溶液[26]，忽视了天然水体中的[[基质效应]]。据我们所知，鲜有研究探讨吸附剂在实际环境水污染场景中的适用性[8,27,28]。因此，需要一种结构可控、易于部署的载体形式，以开发能够协同多种吸附机制的新型吸附剂，实现天然水环境中多种 PFAS 的协同高效去除。

为克服粉末状和纳米尺度[[吸附]]剂在分离与工程应用中存在的局限性，[[纳米纤维膜]]（NFsM）提供了一条可行的解决途径。NFsM 是由具有一定长径比的纳米纤维有序或无序堆叠而形成的整体膜材料。前期研究已合成了掺杂锆基[[金属有机框架]]的分层多孔 NFsM，用于去除水中的氟离子，[[去除效率]]达到 99% [29]。在我们前期工作中，[[聚多巴胺和离子液体双改性聚苯乙烯纳米纤维膜|聚多巴胺与离子液体双重修饰的聚苯乙烯纳米纤维膜]]（PDA-IL NFsM）表现出对[[环境水体]]中七大类 15 种真菌毒素的高效共吸附能力，可作为一种新型吸附剂（除极性较高的[[脱氧雪腐镰刀菌烯醇]]外，去除率均高于 88.3%）[30]。此外，功能化 NFsM 基吸附剂还被用于去除环境水体中的高极性[[非甾体抗炎药]]，对八种 NSAIDs 的共去除效率达到 90–100%，这归因于功能化所提供的多样化相互作用机制 [31]。上述结果表明，NFsM 的高度多孔结构、[[比表面积|高比表面积]]、[[孔隙率|高孔隙率]]以及低传质阻力，使其在水处理应用中具有独特优势。与粉末状和纳米尺度吸附剂相比，NFsM 可在无需额外固液分离步骤的情况下整体回收和重复使用，同时保持较高的[[吸附动力学]]性能。此外，其结构可通过化学修饰灵活调控，为引入特定功能组分提供了理想载体。

然而，仅依靠膜基底并不能解决其与高极性短链及新兴 [[全氟和多氟烷基物质|PFASs]] 相互作用较弱这一根本难题。因此，需要一种能够提供多重相互作用位点的功能组分。[[壳聚糖]]（CS）作为一种可生物降解且无毒的生物高分子，其分子主链富含氨基和羟基。这不仅为[[静电相互作用]]和[[氢键]]提供了潜在位点，还赋予其优异的化学可修饰性和环境相容性，使其成为构建[[多机制协同吸附]]体系的理想功能平台 [32]。然而，原始壳聚糖在中性水环境中的电荷密度有限，导致其静电[[吸附]]能力易受溶液条件影响，难以为高极性短链及新兴 PFASs 提供稳健的结合驱动力 [25,33]。为解决这一问题，本工作引入季铵化修饰，在壳聚糖分子链上建立永久性阳离子位点。这显著提高了材料表面的正电荷密度，从而增强了对阴离子型 PFASs 的静电吸附作用 [34,35]。此外，[[聚乙烯醇]]（PVA）分子链上丰富的羟基不仅可作为潜在的氢键供体/受体，与壳聚糖主链共同形成协同位点，从而进一步整合和协调整个膜内的多种吸附机制，而且还有助于提高 [[纳米纤维膜|NFsM]] 的力学性能和传质性能 [36,37]。

基于这些挑战和设计原则，本研究开发了一种[[季铵化壳聚糖]]-[[聚乙烯醇]]复合[[纳米纤维膜]]（[[QCS-PVA NFsM]]），作为用于多类[[全氟和多氟烷基物质|PFAS]]去除的工程化[[吸附]]材料。该体系以NFsM作为自支撑载体，在[[比表面积|高比表面积]]与可调控结构之间取得平衡，并以季铵化[[壳聚糖]]为功能核心，建立稳定、高密度的阳离子位点。与PVA的复合使得同一材料中能够同时引入[[静电相互作用]]、[[疏水相互作用]]和[[氢键]]作用。这实现了对天然水体中频繁检出或浓度较高的21种PFAS的[[多机制协同吸附]]，涵盖短链、长链及新兴PFAS。通过动力学、等温线和热力学研究，系统评价了QCS-PVA纳米纤维膜对PFAS的吸附特性。通过理论建模与实验验证相结合的方式，系统研究并验证了吸附剂与PFAS之间可能的相互作用机制。此外，将[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]]应用于实际环境水样，以评估其稳定性和对多种PFAS协同去除的应用潜力。本研究所得结果有望为探索[[环境水体]]中PFAS共去除的有效方法提供有价值的参考。

## 2.1. 化学试剂与材料

## 2.3. [[季铵化壳聚糖|QCS]]的制备与表征

[[季铵化壳聚糖|QCS]]通过酸性条件下与伯胺基团的化学反应获得，其中季铵盐被部分引入到[[壳聚糖|CS]]主链上或CS主链外，可发生季铵化。通常，将2.5 g CS粉末溶于[[乙酸|AcOH]]溶液（0.5 wt%，100 mL）中，并在$6 0 ~ ^ { \circ } \mathrm { C }$下磁力搅拌30 min，以获得均相溶液。随后，将[[2,3-环氧丙基三甲基氯化铵|GTMAC]]溶液（4.15 g GTMAC + 6.9 mL[[超纯水]]）缓慢滴入CS溶液中，并在$6 0 ~ ^ { \circ } \mathrm { C }$下磁力搅拌24 h。将溶液在4000 rpm下[[离心]]20 min以去除不溶物。通过将上清液缓慢滴入[[乙醇]]与[[丙酮]]的混合物$( V / \mathrm { V } = 1 : 1 )$中进行沉淀。收集沉淀物，用乙醇洗涤三次，并在$5 0 ~ ^ { \circ } \mathrm { C }$下干燥4天，得到QCS。合成QCS样品中GTMAC对CS伯胺基团的[[取代度]]（DS）通过改变GTMAC浓度进行调控，并依据Text S2中式（S1）通过化学滴定进行定量[39]。具体制备参数汇总于Table S2。

## 2.4. [[QCS-PVA NFsM]]的制备与表征

[[QCS-PVA NFsM]]的制备方法采用[[静电纺丝]]进行，参照我们先前的研究[40]。详细条件和步骤见补充材料Text S3。通过改变静电纺丝溶液中[[季铵化壳聚糖|QCS]]与[[聚乙烯醇|PVA]]的质量比，可以获得具有不同QCS含量的初始[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]]。具体制备条件见表S3。

初始[[QCS-PVA NFsM]]使用[[戊二醛|GA]]进行[[化学交联]]。将50 wt% GA与1 mol/L [[盐酸|HCl]]按体积比1：1混合制备[[交联]]溶液。将交联溶液置于密闭容器底部，并将[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]]悬浮于其中。将密闭容器置于$7 5 ~ ^ { \circ } \mathrm { C }$下0.5–3 h，得到[[QCS-PVA-GA NFsM]]。除化学交联外，还采用[[热交联]]对[[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]]进行热处理。根据现有工艺[40]，将初始QCS-PVA NFsM在$1 5 0 ^ { \circ } \mathrm { C }$下加热0.5 h，得到QCS-PVA-Heat NFsM。以[[去除效率]]（R）为指标，比较QCS-[[PVA-GA]] NFsM与QCS-PVA-Heat NFsM的性能差异。

此外，制备了[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]]和[[CS-PVA NFsM]]，并分别使用上述[[化学交联]]和[[热交联]]方法对初始PVA NFsM和[[壳聚糖|CS]]-PVA NFsM进行[[交联]]。PVA NFsM和CS-PVA NFsM的[[静电纺丝]]溶液制备条件见补充材料Text S4。以[[去除效率]]（R）为指标，比较PVA NFsM、CS-PVA NFsM与[[QCS-PVA NFsM]]的性能差异。

[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]]、[[CS-PVA NFsM]]和[[QCS-PVA NFsM]]的仪器表征方法详见补充材料Text S5。采用重量分析法研究PVA NFsM和[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]]的溶胀行为，并使用补充材料Text S6中提到的式（S2）至（S4）计算材料的[[溶胀率]]（[[溶胀比|SR]]）。

## 2.5.1. [[QCS-PVA NFsM]]对多种[[全氟和多氟烷基物质|PFASs]]的共[[去除效率|去除率]]

比较了 [[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]]、[[CS-PVA NFsM]] 和 [[QCS-PVA NFsM]] 对目标 [[全氟和多氟烷基物质|PFASs]] 的[[去除效率|去除率]]，以考察在制备过程中结合带正电 [[季铵化壳聚糖|QCS]] 所得到的 NFsM 是否能够有效协同去除多种 PFASs。使用 5.0 mL 含每种目标物 5 ng/mL 的工作溶液，充分浸没 10 mg PVA NFsM、[[壳聚糖|CS]]-PVA NFsM 或 [[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]]。在环境温度下[[吸附]] 0.75 h 后，采用 [[超高效液相色谱-串联质谱|UPLC-MS/MS]] 分析上清液中每种 PFAS（详见第 2.9 节），并根据文本 S7 中的式（S5）确定相应的去除效率（R）$\operatorname { E q . }$。

2.8. [[QCS-PVA NFsM]]共去除多种[[全氟和多氟烷基物质|PFASs]]的实际应用潜力评价

从两个方面评价[[QCS-PVA NFsM]]的实际应用潜力：在真实[[环境水体]]中共[[吸附]]多种目标物质的性能及其可重复使用性。为此，于2025年5月在江苏省南京市采集了[[长江]]（[[水源水]]样，经度：118.74587，纬度：32.10698）、[[玄武湖]]（[[湖水]]水样，经度：118.78837，纬度：32.06923）、[[秦淮河]]（[[生活污水]]样，经度：118.75824，纬度：32.08781）以及室内场所自来水（生活[[饮用水]]样，经度：118.77566，纬度：32.08781）的水样。每个地点采集5份样品。所有环境水样均密封于棕色[[聚丙烯]]（PP）瓶中，并在 $4 ~ { } ^ { \circ } \mathbf { C }$ 条件下保存待分析。所有水样以10,000 rpm[[离心]]10 min以去除悬浮颗粒。生活饮用水、水源水、湖水及生活污水的[[pH]]、[[浊度]]、色度、[[总有机碳]]、硝酸盐、亚硝酸盐、氨氮和[[化学需氧量]]（COD）依据[[中国饮用水标准检验方法]]（[[GB 5750-2023]]）和[[污水综合排放标准]]（GB 8978-1996）[47,48]进行分析。按照GB 5750-2023中规定的[[全氟辛酸|PFOA]]和[[全氟辛基磺酸|PFOS]]测定方法对环境水样进行前处理，并测定[[全氟和多氟烷基物质|PFASs]]的背景水平。使用[[WAX固相萃取柱]]对样品中的目标化合物进行浓缩富集，随后进行[[超高效液相色谱-串联质谱|UPLC-MS/MS]]分析。具体实验步骤见文本S11。根据检测结果，将目标化合物浓度低于[[检出限]]（LOD）的样品定义为空白水样。

## 2.8.1. [[QCS-PVA NFsM]] 的重复使用性研究

[[吸附]]剂的实际适用性关键取决于其再生潜力。为评估 [[QCS-PVA NFsM]] 的这一关键方面，进行了连续的[[吸附-脱附循环]]，以 [[全氟和多氟烷基物质|PFASs]] 的[[去除效率]]作为性能指标。制备了 5 mL 加标[[水源水]]样品，每种目标物浓度为 5 ng/mL，[[吸附实验]]按照第 2.5.1 节进行。吸附过程结束后，通过 [[超高效液相色谱-串联质谱|UPLC-MS/MS]]（第 2.9 节）定量上清液中每种 PFAS 的残留浓度，并使用 $\operatorname { E q . }$ (S5) 计算相应的去除效率 (R )。每次吸附后，用镊子将使用过的 [[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 直接从工作溶液中取出，并用文本 S12 中优化的 1.5 mL 再生溶剂振荡洗涤，每次 20 分钟。再生完成后，将 [[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 用于下一次吸附实验。QCS-PVA NFsM 的重复使用性根据在每种目标物的去除效率无统计学显著降低 $( P > 0 . 0 5 )$ 的前提下所完成的最大连续吸附-[[脱附]]循环次数进行评估。

## 2.8.2. [[QCS-PVA NFsM]] 对实际[[环境水体]]中 [[全氟和多氟烷基物质|PFASs]] [[去除效率]]的研究

## 2.10. 质量控制

为确保实验数据的准确性，本研究对所有实验设备实施了严格的污染防控措施。具体操作如下：玻璃器皿依次使用[[甲醇]]和[[超纯水]]进行超声清洗，随后置于恒温干燥箱中，在 $6 0 ~ ^ { \circ } \mathrm { C } .$ 条件下干燥。质量控制结果表明，空白对照样品（超纯水）中未检出目标污染物，所有[[全氟和多氟烷基物质|PFAS]]化合物的信号强度均低于[[检出限]]（LOD），[[信噪比]]（SNR）< 3。

为避免[[全氟和多氟烷基物质|PFASs]]在玻璃样品瓶内壁[[吸附]]造成损失[49–51]，[[吸附实验]]结束后，准确移取200 μL吸附后的上清液至预先加入800 μL[[甲醇]]的样品瓶中，涡旋混匀后用于后续进样分析。为校正因向样品瓶中加入甲醇而导致的样品中目标化合物浓度稀释，在后续实验数据分析中，相关目标化合物的[[峰面积]]均乘以相应的稀释倍数（5倍）。在每批样品进样中，每15个样品同时加入溶剂空白、过程空白和加标空白作为质量控制样品。

## 3.2. [[QCS-PVA NFsM]] 作为去除 [[全氟和多氟烷基物质|PFASs]] 的[[吸附]]剂评价

我们随后系统评估了 [[QCS-PVA NFsM]] 对水中多种 [[全氟和多氟烷基物质|PFASs]] 的[[吸附]]性能（图 2）。结果表明，纯 [[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 对弱极性[[长链 PFASs]]（如 [[全氟癸酸|PFDA]]、[[全氟十二烷酸|PFDoA]]，图 2A）的[[去除效率]]为 29.2%–72.7%，主要归因于[[疏水相互作用]]。然而，对强极性[[短链 PFASs]]（如 [[全氟丁酸|PFBA]]、[[全氟丁基磺酸|PFBS]]）的去除效率仅为 0%–8.2%。[[壳聚糖|CS]] 的引入使 [[CS-PVA NFsM]] 对长链 PFASs 的去除效率提高至 24.5%–96.2%，但对短链 PFASs 的改善有限（0%–17.7%）。季铵化改性后，[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 显著提高了所有目标 PFASs 的去除效率（82.3%–97.1%，$P ~ < ~ 0 . 0 5 )$ 尤其对短链 PFASs（去除效率从 0%–72.7% 提高到 82.3%–97.1%）。这一提升主要归因于季铵基团与阴离子 PFASs 之间的强[[静电相互作用]]。随着季铵基团[[取代度]]（DS）从 55% 增加到 75%，[[季铵化壳聚糖|QCS]]-PVA NFsM 对 PFASs 的去除效率与 DS 的升高呈负相关。提高季铵基团 DS 理应增加 QCS-PVA NFsM 所带正电荷数量，从而增强与阴离子 PFASs 的静电相互作用并促进吸附。然而，实验结果呈现相反趋势。这可能归因于 QCS DS 升高，使制备过程中[[静电纺丝]]液所带正电荷增加。过量的正电荷产生电场力，破坏纺丝液表面张力与黏度之间的平衡。因此，静电纺丝过程中[[泰勒锥]]无法稳定形成，导致射流破碎成多股或不稳定射流 [62]。这增加了纤维内部珠状缺陷，降低膜均匀性并使形貌劣化，进一步削弱去除效率（图 S3）[58,63]，尤其是对短链 PFASs，其去除效率降至 9.6%–51.6%。因此，选用 $D S = 5 5 \%$ 的 QCS 用于后续材料制备。[[化学交联]]的 QCS-PVA NFsM 由于具有良好的水稳定性和力学性能，与[[热交联]]样品相比，进一步提高了强极性 PFASs 的去除效率（从 54.0%–73.0% 提高到 81.1%–88.2%，$P < 0 . 0 5 )$ 。[[BET分析|BET 分析]]表明，[[交联]]时间从 0 h 增加到 6 h 时，[[BET|比表面积]]、[[孔体积]]和[[平均孔径]]逐渐下降，说明纳米纤维网络逐渐致密化（表 S7，图 S4A）。同时，拉伸测试表明，随着交联时间延长，机械强度增强，证实结构稳定性提高（表 S8，图 S4B）。然而，过度交联（6 h）显著降低了孔可及性和传质通道，从而限制了可供 PFAS 分子（尤其是短链 PFASs）利用的有效[[吸附位点]]。[[XPS]] 分析表明，交联引发 NFsM 表面化学重构。随着交联时间增加，含氮吸附位点逐渐被屏蔽，削弱其有效可及性（图 S5）。优化实验表明，当 QCS 负载量为 20 wt%、化学交联时间为 $^ { 3 \mathrm { h } , }$、[[吸附剂用量]]为 10 mg 时，QCS-PVA NFsM 对 21 种 PFASs 的去除效率达到 80.4%–99.8%。与现有吸附剂相比 与文献报道相比无显著差异，$P > 0 . 0 5 )$ ，同时将短链 PFASs 的去除效率提高了近 40%，展现出优异的综合吸附性能。

## 3.3. [[QCS-PVA NFsM]] 对 [[全氟和多氟烷基物质|PFASs]] 的[[吸附]]表征

基于动力学、等温线和热力学实验，进一步确定了 21 种 [[全氟和多氟烷基物质|PFASs]] 在 [[QCS-PVA NFsM]] 上的[[吸附]]行为。

## 3.3.1. [[吸附动力学]]

[[QCS-PVA NFsM]] 的[[吸附]]过程呈现典型的三阶段特征，包括初始快速吸附、随后速率下降阶段以及最终平衡阶段，并在 45 min 内达到吸附平衡。随着 [[全氟和多氟烷基物质|PFASs]] 浓度（50–200 ng/mL）的增加，[[吸附容量]] $( Q _ { s t } )$ 从 0.70 mg/g 增加到 1.82 mg/g（图 3A）。动力学分析表明，[[准二级动力学模型]] $( R ^ { 2 } = 0 . 9 9 9 2 – 0 . 9 9 9 9 )$ 比[[准一级动力学模型]] $( R ^ { 2 } =$ 0.2258–0.8844）能更准确地描述吸附行为（表 S9，图 S6–S11）。[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 对 21 种 PFASs 的理论最大吸附容量（32.10–90.83 μg/g）与实验值（31.75–90.74 μg/g）高度一致，证实了以化学吸附为主的[[单分子层吸附]]机理。此外，[[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 对各 PFAS 的吸附容量与其疏水性参数 $( \mathrm { L o g K _ { o w } ) ( \mathrm { F i g . 3 B \mathrm { - D } ) } }$ 呈正相关，表明[[疏水相互作用]]在吸附过程中发挥了重要作用。利用 [[Weber-Morris膜内扩散模型|Weber-Morris 膜内扩散模型]]进一步分析表明，吸附过程遵循两阶段扩散机制：初始阶段（0–10 min）以[[液膜扩散]] $( k _ { p 1 } ~ =$ 3.44–27.98）为主，随后是由[[颗粒内扩散]] $( k _ { p 2 } = 0 . 0 5 4 – 0 . 6 6 )$ 控制的限速阶段。扩散曲线未通过原点 $( C _ { 1 } = 2 . 7 0 - 6 1 . 9 7 , C _ { 2 } = 2 9 . 6 6 - 8 9 . 6 8 )$ ，表明吸附速率由液膜扩散和颗粒内扩散共同调控（表 S10，图 S12–S14）。

## 3.3.2. [[吸附等温线]]

接下来，使用 [[Langmuir吸附等温线模型|Langmuir]] 和 [[Freundlich吸附等温线模型|Freundlich]] [[吸附等温线]]模型对 [[QCS-PVA NFsM]] [[吸附]] [[全氟和多氟烷基物质|PFASs]] 的数据进行分析。如表 S11 所示，[[Langmuir模型|Langmuir]] 模型 $( R ^ { 2 } = 0 . 9 7 7 9  – 0 . 9 9 6 6 )$ 和 [[Freundlich模型|Freundlich]] 模型 $( R ^ { 2 } = 0 . 9 8 2 7 - 0 . 9 9 4 9 )$ 均具有较高的决定系数，表明两种模型都能有效描述吸附过程的热力学行为（图 4A、B）。使用 [[Langmuir等温线模型|Langmuir]] 模型计算得到的理论最大[[吸附容量]] $( q _ { m a x } \ = \ 4 . 0 3 \mathrm { - } 9 . 4 3 \ \mathrm { \ m g / g ) }$ 高于实验测得的最大吸附容量（1.82 mg/g）。这一差异可能归因于实验中使用的 PFAS 浓度范围未能完全覆盖[[吸附位点]]的饱和阈值。此外，[[吸附平衡常数]] $K _ { L } \le 0 . 5 0$ $( 0 < K _ { L } < 1 )$ 表明 PFASs 容易被吸附到 [[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 上。[[Freundlich等温线模型|Freundlich]] 等温线得到 $1 / n < 1$ 的值，表明吸附条件有利。此外，对 Langmuir 和 Freundlich 模型均具有良好拟合表明，多种机制在 PFASs 吸附到 [[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 上的过程中协同发挥作用。

## 3.3.3. [[吸附热力学]]

利用 [[Van't Hoff方程|Van't Hoff 方程]]对[[吸附]]过程的热力学特征进行了进一步分析。如图 4C 所示，在 277–328 K 温度范围内，吸附分配系数（lnK）与温度倒数（1/T）呈线性负相关。表 S12 列出了 [[QCS-PVA NFsM]] 对 [[全氟和多氟烷基物质|PFASs]] 吸附的热力学参数。[[吉布斯自由能变|ΔG]] 值随温度升高而降低，从 +1.11 kJ/mol 降至 −2.42 kJ/mol。当温度超过 308 K 时，ΔG 变为负值，表明高温增强了吸附过程的自发性。正的[[焓变]] $( \Delta H = 2 1 . 6 7$ kJ/mol）表明该吸附过程为吸热反应。此外，正的[[熵变]] $\left( \Delta S > 0 \right)$ 表明固-液界面体系无序度增加。对热力学参数的综合分析表明，[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 对 PFASs 的吸附是一个吸热且自发的过程，通常为熵驱动过程。

## 3.4. [[QCS-PVA NFsM]] 对 [[全氟和多氟烷基物质|PFASs]] [[吸附]]机理研究

## 3.4.1. 理论推测

通过分析[[吸附]]剂与目标物的化学结构（图 S15），提出了二者之间可能存在的吸附相互作用机制。吸附剂 [[季铵化壳聚糖|QCS]] 由[[壳聚糖]]经季铵盐改性得到，使其表面带有强正电荷 [59,67]。随着 [[pH]] 升高，[[QCS-PVA NFsM]] 的 [[Zeta电位|zeta 电位]]与溶液 pH 呈负相关（图 1E），其[[等电点]]（IEP）约为 7.2。当 pH 值为 $< 7 . 2 ,$ 时，[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 表面带正电荷，而 [[全氟和多氟烷基物质|PFASs]] 上强电负性的氟原子在水溶液中容易去质子化，使 PFASs 带负电荷。因此，推测 QCS-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 可与目标物质，尤其是[[短链 PFASs]]，形成[[静电相互作用]]。另一方面，经[[化学交联]]后，QCS-PVA NFsM 的疏水性增强，可与具有强疏水性的 PFASs 的 $\mathrm { C - F }$ 链发生[[疏水相互作用]]。此外，QCS 含有可作为[[氢键]]供体的氨基和羟基，[[交联]]后的 PVA 也含有可作为氢键供体的羟基。所研究的全部 21 种 PFASs 的分子结构中均具有氢键受体（–COO<sup>−</sup>、$- s 0 _ { 3 } ^ { - }$ 以及 C–F 链上的 F 原子）[68,69]，表明氢键可能对吸附相互作用有所贡献。

## 3.4.2. 实验验证

离子干扰实验证实，[[NaCl]]、[[氯化钙|CaCl]]<sub>2</sub> 和 $\mathrm { M g } { \bf S } { \bf O } _ { 4 }$ 的加入均显著降低了 [[QCS-PVA NFsM]] 对 [[全氟和多氟烷基物质|PFASs]] 的[[去除效率]]（P < 0.05）。其中，多价金属盐 $( \mathrm { C a C l } _ { 2 }$ 和 $\mathrm { M g } { \bf S } \mathrm { O } _ { 4 } )$ 由于形成更高的电荷密度，对静电相互作用的干扰更为显著，表明静电相互作用在吸附过程中发挥了关键作用（图 S16）。pH 依赖性实验进一步验证了这一机制：在 pH < 7.2（吸附剂等电点 IEP）条件下，QCS-PVA NFsM 表面带正电荷，对带负电的 PFASs（尤其是短链 PFASs）表现出超过 80% 的去除效率。相反，在 pH > 7.2 时，静电排斥导致去除效率显著下降（[[短链 PFASs]] 降至 9.9%–34.6%）。值得注意的是，尽管处于高 [[pH]] 条件，[[吸附]]并未被完全抑制，表明存在其他相互作用机制（图 S17）。[[疏水相互作用]]验证实验表明，随着[[甲醇]]比例增加（0%–100%），[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 对 PFASs 的去除效率下降了 69.6%–93.6%，其中[[长链 PFASs]]（较高的 $\mathrm { L o g K } _ { \mathrm { o w } }$ 值）的吸附效率下降最为显著（从 93.6%–100% 降至 0%–24.4%），证实了疏水相互作用在长链 PFASs 吸附中的主导作用。相比之下，短链 PFASs 的去除效率下降幅度较小（69.6%–82.0%），表明其吸附更依赖于[[静电相互作用]]（图 S18）。[[氢键]]竞争实验（加入 0.1 和 1 M [[尿素]]）显示，氢键破坏导致所有 PFASs 的去除效率下降（从 84.9%–99.4% 降至 18.6%–90.7%），其中短链 PFASs 的下降更为明显，表明氢键对其吸附的贡献更大（图 S19）。

综上所述，[[QCS-PVA NFsM]] 对 21 种 [[全氟和多氟烷基物质|PFASs]] 表现出协同的多机制[[吸附]]，其中高极性短链和新兴 PFASs 主要依赖静电吸引和[[氢键]]。相比之下，中等极性至弱极性长链和新兴 PFASs 的吸附主要由[[疏水相互作用]]主导，并在较小程度上辅以静电作用和氢键。

## 3.4.3. 理论计算

[[全氟和多氟烷基物质|PFASs]] 在 [[QCS-PVA NFsM]] 上的[[吸附]]机制被理论化为涉及静电、疏水和[[氢键|氢键相互作用]]，这一前提通过实验和理论方法均进行了研究。本研究进一步利用[[量子化学计算]]，以更深入地了解 [[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 与 PFASs（以 [[全氟辛酸|PFOA]] 为代表）之间的优先结合位点及其相互作用强度（图 5）[70]。首先，对 [[季铵化壳聚糖|QCS]]、[[PVA-GA]]、PFOA、QCS 吸附 PFOA 以及 [[聚乙烯醇|PVA]]-[[戊二醛|GA]] 吸附 PFOA 的结构进行了优化，结果如图 5A–E 所示。在 QCS-PFOA 复合物的优化结构（图 5D）中，PFOA 的全氟烷基链（C–F）与 QCS 的疏水性甲基 $\left( \mathrm { - C H _ { 3 } } \right)$ 之间的紧密接近，表明吸附机制由[[疏水相互作用]]驱动 [71,72]，这与我们的 [[FTIR]] 分析结果一致（图 1D）。此外，PFOA 的阴离子官能团（–COO<sup>−</sup> ）靠近 QCS 的伯胺基团（–NH–）和季铵基团 $( - \mathbf { N } ^ { + } - )$ ，表明二者之间可能通过[[静电相互作用]]发生吸附。PVA-GA-PFOA 复合物的优化结构（图 5E）表明，吸附主要是通过 PFOA 的全氟烷基链（C–F）与 PVA-GA 的甲基（-CH<sub>3</sub>）之间的紧密接触介导的，表明其以疏水相互作用机制为主。

![](<../2.SCI_MD/Quaternised chitosan-polyvinyl alcohol nanofibrous membranes adsorbent for efficient co-adsorption of multiple iperi- and polyfluoroalkyl substances in environmental water/images/8808419f8439ebbaea176284a1451ad4bbf41da6162e72efa1df8c9355d9b4ac.jpg>)  
图 5. （A）PFOA、（B）QCS、（C）乙二醛交联 PVA（PVA-GA）的结构优化图，以及（D）QCS 和（E）PVA-GA 吸附 PFOA 的结构优化图。（F）QCS 和（G）PVA-GA 吸附 PFOA 的静电势（ESP）分布图。

对 [[季铵化壳聚糖|QCS]] [[吸附]] [[全氟辛酸|PFOA]] 和 [[PVA-GA]] 吸附 PFOA 所形成的两种结构进行了[[表面静电势]]（[[静电势|ESP]]）进一步分析，结果如图 5F 和 G 所示。对于 QCS-PFOA 的 ESP 图（图 5F），QCS 结构表现出低电子密度区域，以浅红色和深红色表示，这归因于 QCS 结构中质子化氨基（–NH– 和 $- \mathbf { N } ^ { + } - \mathbf { \sigma } )$）的正电影响。因此，PFOA 的阴离子官能团（–COO<sup>−</sup>）容易与这些质子化氨基发生强[[静电相互作用]]。相反，QCS 表面的蓝色区域代表高电子密度区域，由于静电排斥，这些区域不吸附 PFOA。QCS 与 PFOA 结合的白色阴影区域对应中性 ESP 区域，这是由 QCS 所带正电荷与 PFOA 负电荷中和所致，表明静电相互作用是吸附过程的关键驱动力之一。与 QCS-PFOA 复合物相比，[[聚乙烯醇|PVA]]-[[戊二醛|GA]]-PFOA 复合物的 ESP 图（图 5G）显示出与 QCS 相比不均匀的 ESP 分布，这归因于 PVA-GA 分子中杂原子的存在所导致的非均匀电荷分布[55]。甲基（–CH）基团具有给电子诱导效应（+I 效应），可导致甲基碳原子上带有部分负电荷。因此，PVA-GA 中的 ${ \mathrm { - C H } } _ { 3 }$ 位置被确定为高电子密度区域（蓝色区域）。此外，醚键 $( { \bf R } { - } 0 { - } { \bf R } ^ { \prime } )$ 中的氧原子具有一对孤对电子，使这些位点具有较高的电负性。因此，PVA-GA 中醚键的位置被确定为高电子密度区域（蓝色区域）。此外，还进行了 [[IGMH分析|IGMH 分析]]，以分析 QCS 吸附 PFOA 和 PVA-GA 吸附 PFOA 所形成的两种结构，旨在探究除静电相互作用外，吸附剂与目标物之间是否存在其他相互作用[44]。结果如图 S21 所示。QCS 的氨基和羟基以及[[交联]] PVA 的羟基可作为[[氢键]]供体。相反，PFOA 上的羧基可作为氢键受体，与吸附剂形成氢键相互作用。总之，ESP 和 [[基于Hirshfeld分区的独立梯度模型|IGMH]] 分析从量子化学模拟的角度验证了 [[QCS-PVA NFsM]] 与 [[全氟和多氟烷基物质|PFASs]] 之间存在静电相互作用和氢键相互作用。这些结果与先前的理论分析和实验结果一致。

## 3.5. 实际应用潜力评价

## 3.5.1. [[QCS-PVA NFsM]] 的可重复使用性

在评估[[吸附]]剂的可重复使用性之前，由于再生溶剂对再生效率具有显著影响，首先对其进行了优化。对六种溶剂（[[甲醇]]、[[乙醇]]、[[乙腈]]、1% [[氢氧化钠|NaOH]] 溶液以及甲醇/乙醇混合物）的系统比较[73,74]表明，与甲醇（>6 次再生）相比，纯乙醇和乙腈（均需四次再生）表现出更优的再生效率（图 S22）。这归因于它们更高的疏水性（[[LogP]] 值分别为 −0.31 和 −0.34），能够有效破坏 [[全氟和多氟烷基物质|PFASs]] 与材料之间的[[疏水相互作用]]。然而，乙腈造成了结构损伤，包括纤维黏连和孔道坍塌（图 S23C）。尽管碱性复合溶剂通过协同削弱吸附剂与目标物之间的静电和疏水相互作用，将再生循环次数减少到三次，但 NaOH 引起了材料碎裂和剥落（图 S23D）。基于对再生效率、材料完整性和[[环境友好性]]的综合评价，选择乙醇作为最优再生溶剂。在随后的重复使用实验中，[[QCS-PVA NFsM]] 在第七次循环时仍保持了 72.7%–95.7% 的 PFAS [[去除效率]]。然而，与初始效率 85.0%–100.0% $( P < 0 . 0 5 )$ 相比，这代表显著下降，表明其实际可重复使用次数至少为六次（图 6A）。第七次重复使用时去除效率的下降主要归因于反复使用引起的纤维结构变形（表现为[[孔隙率]]降低和团聚，图 S23E），以及未完全[[脱附]]的 PFASs 对[[吸附位点]]的永久占据（第 1 次循环 PFAS 脱附效率为 92.26%–97.68%，第 2 次为 92.05%–96.87%，第 3 次为 90.44%–96.03%，第 4 次为 90.09%–95.51%，第 5 次为 87.83%–92.17%，第 6 次为 76.13%–86.21%，图 6B，图 S24）。所有可重复使用性测试均使用实际源水而非去离子水或合成水进行，其固有近中性 [[pH]]（6.88）以及共存的[[无机离子]]和[[天然有机质]]，从而直接反映实际[[环境水体]]条件。

## 3.5.2. [[QCS-PVA NFsM]] 在实际[[环境水体]]中对 [[全氟和多氟烷基物质|PFASs]] 的[[吸附|吸附去除]]

四种实际环境水样的典型理化性质见表S13。[[原水处理|原水]]、[[湖水]]和[[生活污水]]表现出较高的[[浊度]]，说明[[悬浮颗粒物]]负荷较高。此外，高浊度也导致色度升高，这归因于悬浮颗粒物对光的散射以及对颜色的吸收能力。其余样品的理化性质均在正常范围内。本研究按照[[GB 5750-2023]]中规定的[[全氟辛酸|PFOA]]和[[全氟辛基磺酸|PFOS]]测定方法，对样品中[[全氟和多氟烷基物质|PFASs]]的背景值进行了测定，并在本研究的实验条件下开展了方法学评价，包括线性范围、[[检出限]]（LOD）和[[定量限]]（LOQ）。结果见表S14，显示了环境水样中21种PFASs的LOD和LOQ，其范围分别为0.01～0.20 ng/mL和0.03～0.67 ng/mL。[[线性相关系数]]（R）≥0.9984，表明方法线性良好，适用于定量分析。对4种环境水样的分析显示，所有目标PFASs均低于各自检出限。

已有充分研究证实，[[环境水体]]中复杂的共存物质可能会干扰 [[QCS-PVA NFsM]] 对 [[全氟和多氟烷基物质|PFASs]] 的选择性去除 [75]。本研究评估了 [[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 对[[超纯水]]、[[水源水]]、[[湖水]]、[[生活污水]]和[[饮用水]]中 21 种 PFASs 的[[去除效率]]，如图 6C 所示。在超纯水中的去除效率为 86.6–98.2%。在环境水体中，去除效率分别为 84.5–98.4%（水源水）、83.1–99.1%（湖水）、80.9–99.7%（生活污水）和 82.2–96.8%（饮用水）。水源水、湖水和生活污水等环境水体具有较高的[[浊度]]和[[有机物]]含量，表明存在[[悬浮颗粒物]]和[[天然有机化合物]]。这些共存物质可能部分占据或屏蔽膜表面的[[吸附位点|活性吸附位点]]，从而削弱 PFAS 与[[吸附]]剂之间的相互作用。此外，[[无机离子]]的存在提高了溶液的[[离子强度]]，减弱了[[静电相互作用|静电吸引作用]]。值得注意的是，与[[长链 PFASs]] 相比，[[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 在实际环境水样中对[[短链 PFASs]] 的去除效率下降幅度显著更大 $( P < 0 . 0 5 )$ 。短链 PFASs 的吸附主要依靠静电相互作用和[[氢键]]，而长链 PFASs 则主要受[[疏水相互作用]]控制（第 3.4.2 节）。实际环境水样的 [[pH]] 范围为 6.35–6.88。在该 pH 范围内，吸附剂与短链 PFASs 之间的静电相互作用减弱，导致去除效率降低（图 S17）。在实际环境水样中，QCS-PVA NFsM 对 PFASs 的去除效率比超纯水中低 1.4–5.7%。然而，所有目标化合物（尤其是短链 PFASs）的去除率仍保持在 80% 以上，表明 QCS-PVA NFsM 在实际环境水体中对 PFASs 的吸附去除受复杂共存物质的影响较小。总之，观察到的去除效率下降反映的是真实的[[基质效应]]，而非[[吸附容量]]的降低。在不同环境水体中始终保持在 80% 以上的高去除效率表明，QCS-PVA NFsM 通过[[多机制协同吸附]]表现出对水体基质干扰的强耐受能力，证实了其在实际环境条件下的适用性。

## 3.6. 与现有[[吸附]]剂去除 [[全氟和多氟烷基物质|PFASs]] 的比较

为系统比较 [[QCS-PVA NFsM]] 与现有 [[全氟和多氟烷基物质|PFAS]] [[吸附]]剂的去除性能和应用特征，本研究利用 [[Web of Science]] 和[[中国知网]]（CNKI）数据库，对 2015 至 2025 年间发表的文献进行了系统检索，重点关注水体或环境水介质中 PFAS 的吸附去除，代表性结果汇总于表 S15。检索采用的关键词包括“per- and polyfluoroalkyl substances or PFAS”“water or environmental water”和“adsorption removal”。在剔除综述和专利后，现有吸附材料可归纳为六类：[[传统吸附剂]]、[[改性沸石]]、[[金属有机框架|MOFs]] 和 [[共价有机框架|COFs]]、[[多糖基材料]]、[[β-环糊精聚合物材料]]以及 [[磁性纳米颗粒|MNPs]]。文献对比分析表明，已有研究大多集中于单一或少数几种 PFAS，尤其是强疏水性长链 PFAS（如 [[全氟辛酸|PFOA]] 和 [[全氟辛基磺酸|PFOS]]），并且通常采用较高的初始浓度（一般为 mg/L 级或更高）。相比之下，针对短链或新兴 PFAS 的吸附研究仍然较少，在多种 PFAS 共存条件下实现协同去除的报道尤为缺乏。

如表 S15 所示，本研究中的 [[QCS-PVA NFsM]] 能够在环境相关浓度（0.005–0.5 mg/L）下同时去除 21 种短链、长链和新兴 [[全氟和多氟烷基物质|PFAS]]，总[[去除效率]]为 80.4%–99.8%。值得注意的是，对于强极性短链 PFAS（如 [[全氟丁酸|PFBA]] 和 [[全氟丁基磺酸|PFBS]]），[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 的去除效率比文献报道的大多数[[吸附]]材料高出近 40%。其对中等极性和弱极性 PFAS 的去除性能与 [[金属有机框架|MOFs]]、[[共价有机框架|COFs]]、[[碳材料]]以及部分[[多糖基材料|多糖基吸附剂]]相当。尽管 [[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] [[纳米纤维膜|NFsM]] 的最大[[吸附容量]]（1.82 mg/g）低于某些在高浓度条件下测试的吸附剂[76]，但在接近实际污染水平的条件下，其对多种 PFAS 的协同去除能力仍保持较高水平。

在[[吸附动力学]]方面，[[纳米纤维膜|NFsM]] 的[[比表面积|高比表面积]]和[[孔隙率|高孔隙率]]赋予 [[QCS-PVA NFsM]] 从水中[[吸附]]多种 [[全氟和多氟烷基物质|PFAS]] 时优异的[[传质速率]]。提供主要[[吸附位点]]的 [[季铵化壳聚糖|QCS]] 均匀且分散地分布于 NFsM 表面。这种形貌有利于 PFAS 与吸附位点的快速结合，使 21 种 PFAS 的[[吸附平衡时间]]（0.75 h）与 [[金属有机框架|MOFs]][10,77]、[[共价有机框架|COFs]][78–81]和 [[磁性纳米颗粒|MNPs]][9,82]（0–0.5 h）相当，并显著快于[[传统吸附剂]]（5–120 h）[6,83–86]、[[改性沸石]]（2–24 h）[7,87]、[[多糖基材料]]（2–45 h）[8,26–28,88]和 [[β-环糊精聚合物材料|β-环糊精聚合物]]（4–13 h）[89,90]。此外，与粉末状或纳米颗粒状吸附剂不同，[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 是一种整体式吸附材料，吸附完成后可直接从水体中取出，无需额外的[[磁分离]]、[[过滤]]或[[离心]]过程[83,84,86]。如表 S15 中的[[再生性能]]对比所示，QCS-[[聚乙烯醇|PVA]] NFsM 在连续六个循环后仍保持稳定的吸附性能，其可重复使用性与已报道的吸附剂相当或更优。

综上所述，基于表 S15 的系统性文献对比表明，[[QCS-PVA NFsM]] 在可去除的 [[全氟和多氟烷基物质|PFAS]] 种类范围、环境相关浓度条件下的协同去除能力、[[吸附动力学]]以及整体可操作性方面，与现有基于多糖的材料、[[金属有机框架|MOFs]]、[[共价有机框架|COFs]]、[[碳材料]]和纳米颗粒[[吸附]]剂存在显著差异，展现出良好的综合应用潜力。

## 4. 未来展望

[[QCS-PVA NFsM]] 对不同极性的 [[全氟和多氟烷基物质|PFAS]] 表现出优异的共[[吸附|吸附去除]]效率和独特性能，包括[[环境友好性]]、[[可持续性]]以及易于从水溶液中分离，使其成为值得进一步研究的候选材料。为有效利用所开发的 [[纳米纤维膜|NFsM]] 去除[[环境水体]]中的 PFAS，至少需要考虑四个方面：含高浓度 PFAS 的[[再生废液]]处置、[[废弃吸附剂]]的最终处置、材料在实际复杂水体中的长期性能及其在极端水质条件下的稳定性，以及整体经济和环境影响。实际上，仍需对材料进行进一步表面改性，以增强其对超短链、阳离子型和[[两性离子型 PFAS]] 的亲和力。

## 5. 结论

本研究采用[[静电纺丝法]]成功制备了 [[QCS-PVA NFsM]]。通过[[吸附实验]]，全面考察了 [[纳米纤维膜|NFsM]] 在不同水化学条件下去除多种 [[全氟和多氟烷基物质|PFAS]] 混合物的性能，并系统探讨了其[[吸附]]机理。借助静电、疏水和[[氢键|氢键相互作用]]，[[季铵化壳聚糖-聚乙烯醇纳米纤维膜|QCS-PVA NFsM]] 对 21 种 PFAS 的[[去除效率|去除率]]达到 80.4%–99.8%，其中对高极性 [[全氟丁酸|PFBA]] 和 [[全氟丁基磺酸|PFBS]] 的去除率提高了近 40%，克服了同时去除多种极性跨度大的 PFAS 的难题。对于高极性、短链和新兴 PFAS，[[静电相互作用]]在吸附中起重要作用；而对于中低极性、长链和新兴 PFAS，则主要受疏水和氢键作用支配。[[季铵化壳聚糖|QCS]]-[[聚乙烯醇|PVA]] NFsM 的[[多孔网络结构]]增强了[[传质速率]]，使 PFAS 吸附和去除可在 0.75 h 内完成。QCS-PVA NFsM 的一个关键优势在于其无需预处理即可直接从[[原水处理|原水]]中协同吸附 PFAS，并且可重复使用至少六个再生循环。总之，在环境相关 PFAS 浓度、不同温度、高[[离子强度]]和复杂水基质条件下开展的一系列吸附实验表明，QCS-PVA NFsM 在代表实际环境应用的条件下保持了稳定、高效的性能。该材料在水处理领域的大规模应用中展现出显著潜力，包括原水处理、[[生活污水]]处理和[[工业废水处理]]。
