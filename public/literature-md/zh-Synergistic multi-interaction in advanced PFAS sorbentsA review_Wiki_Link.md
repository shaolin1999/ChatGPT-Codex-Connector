## 摘 要

[[全氟和多氟烷基物质]]（PFAS）因其[[化学稳定性]]、结构多样性以及所处基质的复杂性，仍难以从水中去除。[[吸附]]仍是分离和富集 PFAS 最具实用性的途径之一，但不能仅凭[[最大吸附容量]]或[[去除效率]]来评价一种[[吸附剂]]，尤其当这些数值来自简化的[[批次试验]]时。本综述从机制—性质—工程的视角审视具有代表性的 [[PFAS吸附剂|PFAS 吸附剂]]。首先，我们从[[界面能]]、[[表面电荷]]、[[润湿性]]、[[孔道限域]]及 [[分子描述符|PFAS 分子描述符]]等方面，阐释[[疏水相互作用]]、[[静电相互作用]]、[[亲氟相互作用]]和[[氢键|氢键相互作用]]。随后，我们通过考察各类吸附剂适用的 PFAS 种类及运行条件，比较主要吸附剂类别，包括[[活性炭]]、[[矿物基吸附剂]]、[[环糊精聚合物]]、[[离子型含氟凝胶|离子型氟凝胶]]、[[金属有机框架|MOFs]] 和 [[共价有机框架|COFs]]，以及 [[多孔芳香框架|PAFs]] 和[[多孔聚合物网络]]。接着，讨论转向[[水体基质效应]]、[[竞争吸附|混合物竞争]]、[[吸附穿透行为|穿透行为]]、[[吸附剂再生|再生]]、[[浸出|浸出风险]]、使用寿命终结后的管理以及法规适用性。通过这种方式将分子机制与工程约束相联系，我们得以勾勒出一条发展路线，以获得具有选择性、可再生、耐基质干扰且可用于实际[[水处理]]部署的 PFAS 吸附剂。

## 1. 引言

自 20 世纪 40 年代以来，[[全氟和多氟烷基物质]]（PFAS）已广泛应用于工业、家庭和医院等领域 [1,2]。由此，根据[[分子链长|链长]]、[[头基]]和取代原子等因素，已识别出超过 14,000 种此类化学物质 [3,4]。PFAS 具有出色的[[热稳定性]]、[[耐化学性]]和[[表面活性]]，其原因在于它们含有[[键能]]高达 531.5 kJ mol<sup>-1</sup> 的强 [[碳氟键|C−F 键]] [5]。因此，尽管这种极高的[[化学稳定性]]有利于 PFAS 的各种工业应用，但它也是这些物质无法通过环境中的[[自然衰减]]过程被分解的根本原因；它们几乎不发生降解。因此，PFAS 普遍存在于水体、土壤、大气和生物体中，在几乎所有水环境中均有检出，包括[[极地冰芯]] [6]。其[[生物累积性]]进一步加剧了这些风险，使其能够沿[[食物链]]传递，并对人体健康构成严重的长期威胁，例如[[内分泌紊乱]]、[[甲状腺疾病]]、[[肝损伤]]、[[血脂升高]]、[[免疫功能下降]]、早产低体重及各种[[癌症]]，这些均对社会健康和环境构成严重风险 [7]。

监管机构已采取日益严格的规定来遏制这些风险。2024 年 4 月，[[美国环境保护署]]（EPA）针对六种 [[全氟和多氟烷基物质|PFAS]] 颁布了《[[国家一级饮用水法规]]》，将 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的[[最大污染物限值]]（MCLs）设定为极低的 0.004 ppb，并将其他 PFAS，如 [[全氟己烷磺酸|PFHxS]]、[[全氟壬酸|PFNA]] 和[[六氟环氧丙烷二聚酸]]（HFPO-DA，也称为 [[GenX]]）的上限设定为 0.01 ppb [8]。同样，[[欧盟]]将排放水溶液中允许的 PFAS 总量限制为 0.5 ppb [9]。中国已实施《[[生活饮用水卫生标准（GB 5749-2022）]]》，将 PFOA 和 PFOS 列为国家参考指标，限值分别为 0.08 和 0.04 ppb [10]。最近，法国修订了《[[法国环境法典|环境法典]]》（2025–188），限制 PFAS 在纺织品和化妆品中的使用，并走在实施全面国家禁令的前列 [11]。全球范围内禁止[[饮用水]]和废水排放中含有 PFAS 的法规日益增多，这表明亟须开发适用于各类水体、[[去除效率]]高且具有经济和工业可行性的新型修复技术。

## 2. [[吸附]]技术

基于[[吸附]]的技术是处理 [[全氟和多氟烷基物质|PFAS]] 污染水体最常用的方法 [22]。PFAS 的吸附主要受 PFAS 与[[吸附剂]]之间的[[非共价相互作用]]支配，包括[[疏水相互作用]]、[[静电相互作用]]、[[亲氟相互作用]]、[[氢键]]等 [3,23,24]。由于 PFAS 分子由含氟烷基结构和[[官能团]]组成，多种相互作用会同时发生。利用 PFAS 与吸附剂之间的各种相互作用，可将这些 PFAS 化合物选择性地富集于吸附剂表面，以实现高效去除。图 1 概述了广泛研究的具有不同官能团和[[分子链长|链长]]的 PFAS，上述 PFAS 的理化参数汇总于表 S1，包括分子量、$\mathsf { p } K _ { \mathsf { a } }$ 值和 $\mathrm { L o g K } _ { \mathrm { o w } }$ [22–26]。PFAS 的固有性质，包括链长、离子形态、链型（支链或直链）以及末端基团类型，显著影响其分子相互作用及其对吸附剂的[[吸附亲和力]] [27–29]。本节首先讨论基本相互作用机理，随后详细概述先进吸附剂的开发进展。

## 2.1. 相互作用机理

[[全氟和多氟烷基物质|PFAS]] 的[[吸附]]行为受多种[[非共价相互作用]]共同支配，从较弱的色散力到较强的[[静电吸引|静电吸引力]]，这些相互作用随具体 PFAS 种类的[[分子链长|链长]]和[[头基]]而显著变化。图 2 直观展示了 PFAS 在吸附过程中的四种主导相互作用机制，包括[[疏水相互作用]]、[[亲氟相互作用]]、[[静电相互作用]]和[[氢键|氢键作用]]。

## 2.1.1. [[疏水相互作用]]

[[疏水相互作用|疏水作用力]]相对较大，因此在许多[[吸附剂]]中，[[全氟和多氟烷基物质|PFAS]] 的大部分[[吸附位点]]均由疏水作用主导。单个疏水相互作用较弱，与热能相当，其强度随被掩埋的全氟烷基表面积增大而增加，并在[[分子聚集|聚集]]体开始形成后显著增强。含氟链中 [[碳氟键|C−F 键]]的极低极化率使其具有疏水性。疏水物种附近的水分子也通过[[氢键]]连接，而这种排列致密的水结构在能量上是不利的。因此，疏水物种倾向于相互缔合，以降低相应的自由能代价，从而减少与水分子的接触。在 PFAS 水溶液环境中，PFAS 分子倾向于在[[吸附]]剂的疏水链段上聚集。对于各类吸附剂，疏水相互作用普遍主导[[长链PFAS|长链 PFAS]] 的吸附 [30,31]。此外，[[表面能]]和[[润湿性]]（通常通过[[水接触角]]量化）是这些相互作用的关键调节因素：低表面能的疏水表面对全氟烷基尾链表现出更高的结合[[吸附亲和力|亲和力]]，而高表面能的亲水表面则可能有利于[[头基]][[配位作用|配位]]等其他锚定机制 [32–34]。

## 2.1.2. [[静电相互作用]]

[[静电相互作用]]是支配 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的核心物理化学机制，其本质是带电位点之间的库仑力。其有效强度高度依赖环境——在体相溶液中因德拜屏蔽而减弱，但在受限、低介电常数的孔隙环境中显著增强——且能够迅速建立，为高效[[吸附剂]]的设计提供了理论依据。这一机制被直接用于功能性吸附剂的设计：带有[[阳离子]][[官能团]]的材料 $( \boldsymbol { \mathrm { e . } } \boldsymbol { \mathrm { g . } } ,$ [[季铵基团]]）可通过[[静电吸引]]捕获[[阴离子PFAS|阴离子型 PFAS]]，而带负电荷的分离膜（例 $g _ { \cdot , }$ 纳滤膜）则通过[[静电排斥]]有效阻止 PFAS 渗透。PFAS 的吸附受到其电离状态的强烈调节；由于其 pKₐ 值较低，在典型环境 [[pH]] 下几乎完全以[[阴离子]]形式存在，从而显著增强了其与带正电表面之间的静电吸引 [24]。一般而言，静电作用力在不同[[分子链长|链长]]和结构的 PFAS 中所占的相对权重不同：对于[[长链PFAS|长链 PFAS]]，[[疏水相互作用]]相对更强，而对于疏水性较低的短链或支链 PFAS，则需要静电相互作用来驱动吸附 [35]。在此背景下，吸附剂的 Zeta 电位可作为预测[[静电势]]垒的指标：在给定 pH 下，Zeta 电位为正的表面对[[阴离子型PFAS|阴离子型 PFAS]] 具有较强吸引力，而 Zeta 电位为负的表面则会产生静电排斥，从而限制[[吸附效率]]。[36,37]

## 2.1.3. [[亲氟相互作用]]

[[亲氟相互作用]]通常指全氟化基团通过 C−F⋅⋅⋅F−C 接触而发生的优先缔合 [38]。氟的原子极化率较小，因此不易与许多非氟化分子发生强相互作用 [39]。由于水对全氟化表面的溶剂化能力较弱，[[吸附剂]]的氟化区域与 [[全氟和多氟烷基物质|PFAS]] 的氟烷基尾链优先缔合，以尽量减小不利的氟碳–水界面面积；这种相互的疏溶剂性在定向 C−F⋅⋅⋅F−C 接触的增强作用下，还会将共存的亲水性和亲油性竞争物质排除在氟化微环境之外 [40]。利用亲氟相互作用，即使存在竞争物质，也可显著提高 PFAS 的[[去除效率]]。

## 2.1.4. [[氢键|氢键相互作用]]

当与高电负性元素键合的氢原子核靠近另一种此类高电负性物种时，就可能形成[[氢键|原子间氢键]] [3,41,42]。氢键强度并不相同；根据特定[[官能团]]的电负性和空间排列，其通常处于 15–40 kJmol-1 的范围内 [24]。[[全氟和多氟烷基物质|PFAS]] 化合物极性官能团中的氟原子和氧原子，如[[羧酸根]]（−COO‾）和[[磺酸根]] $( - S 0 _ { 3 } ^ { - } ) ,$ 中的相应原子，均为[[氢键受体]]，可与[[吸附剂]]上的[[氢键供体]]位点形成[[氢键网络]]，这些位点包括[[羟基]]（−OH）、胺基 $\left( - \mathrm { N H } _ { 2 } \right)$ 或咪唑（−NH−）单元 [43,44]。

## 2.1.5. 综合机理框架与[[分子描述符]]

经典 DLVO 理论通过两项贡献描述颗粒与表面之间的相互作用：范德华吸引和静电双电层相互作用 [45]。然而，对于有机污染物、蛋白质和药物分子等分子[[吸附]]质，这一描述并不完整，因为分子还会受到[[疏水相互作用]]、[[Lewis酸碱相互作用|Lewis 酸碱相互作用]]、[[氢键]]和空间位阻效应的影响，而这些作用并未纳入经典的作用力平衡中 [46]。因此，扩展 DLVO（[[扩展DLVO理论|XDLVO]]）理论在经典项的基础上补充了 Lewis 酸碱贡献项。该项对 [[全氟和多氟烷基物质|PFAS]] 吸附至关重要，因为它涵盖了全氟烷基尾链的疏水吸引和[[阴离子]][[头基]]的水合排斥，这两者共同支配分子向表面的接近及其与表面的结合 [47]。

上述四种主要的[[非共价相互作用]]不足以充分解释，为何 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]行为会随着 [[pH]]、[[离子强度]]、[[润湿性|表面润湿性]]、孔隙结构及 PFAS 分子结构的变化而发生显著改变。更准确地说，PFAS 的吸附应被理解为一种界面过程，由固液界面处同时作用的吸引力与排斥力之间的动态平衡所支配。基于 [[扩展DLVO理论|XDLVO]] 理论的机理框架能够超越孤立的疏水、静电、亲氟或[[氢键|氢键相互作用]]，对整体[[吸附能]]量进行全面评估。XDLVO 理论将范德华吸引、静电双电层效应和 [[Lewis酸碱相互作用|Lewis 酸碱相互作用]]整合为统一的界面自由能曲线，为评估这种平衡提供了基础性的机理框架 [48]。尽管[[水合力]]和[[孔限域效应|限域效应]]不属于经典 XDLVO 理论的描述范围，但该理论仍能涵盖支配 PFAS 接近表面并与之初始结合的主要能量贡献。

从定量角度看，接近[[吸附剂]]表面的 [[全氟和多氟烷基物质|PFAS]] 分子与该表面之间的 [[扩展DLVO理论|XDLVO]] 相互作用自由能可表示为三个随距离变化的贡献项之和：

$$
\Delta G _ {\text { tot }} ^ {\mathrm{XDLVO}} (\mathbf {d}) = \Delta G ^ {\mathrm{LW}} (\mathbf {d}) + \Delta G ^ {\mathrm{EL}} (\mathbf {d}) + \Delta G ^ {\mathrm{AB}} (\mathbf {d})
$$

其中，d 为 [[全氟和多氟烷基物质|PFAS]] 分子与[[吸附剂]]表面之间的间距。$\Delta G ^ { \mathrm { L W } }$ 为 Lifshitz–van der Waals（色散）贡献项；$\Delta G ^ { \mathrm { E L } }$ 为静电双电层贡献项，在同号带电界面之间表现为排斥作用，并随[[离子强度]]的增加而迅速衰减；$\Delta G ^ { \mathrm { A B } }$ 为 Lewis 酸碱贡献项，涵盖[[疏水相互作用|疏水吸引]]和水合排斥，在水中以 \~1 nm 的特征长度呈指数衰减 [49]。在这三个贡献项中，$\Delta G ^ { \mathrm { A B } }$ 通常对 PFAS 起决定性作用：它是唯一能够区分水合的短链物种与疏水的长链物种的贡献项，因此与[[分子链长|链长]]依赖性选择性的联系最为直接 [45]。各组成项的详细表达式（Text S1）及一个计算示例（Text S2）见补充信息 [47]。

在这一能量框架内，[[pH]] 和[[离子强度]]等溶液相变量主要调节随距离变化的静电双电层势。例如，溶液 pH 的变化会改变[[表面电荷密度|净表面电荷密度]]，进而决定[[阴离子PFAS|阴离子型 PFAS]] [[头基]]为实现表面结合而必须克服的库仑排斥势垒高度。与此同时，离子强度升高会压缩双电层，从而减弱长程[[静电排斥]]，但也会引入背景基质[[阴离子]]的[[竞争吸附|竞争性位点占据效应]]，可能抑制总体[[吸附]]量。

在同一界面上，[[润湿性|表面润湿性]]调控短程 Lewis 酸碱作用和[[疏水相互作用|疏水作用]]的自由能分量。对于传统[[长链PFAS|长链 PFAS]]，低[[表面能]]、疏水性或氟化表面可最大化与结构水重排相关的吸引自由能，驱动其高度疏水的全氟烷基尾链自发地从体相水溶液中分配出去。然而，当这些宏观[[界面能]]分布用于结构多样的或[[新兴全氟和多氟烷基物质|新兴 PFAS]] 物种时，会受到明确的热力学约束。短链和[[支链异构体]]通常具有显著更强的水合壳层和更弱的疏水驱动力，面临难以逾越的结构性水合势垒，仅靠非特异性疏水富集无法克服这一势垒。因此，工程化孔结构必须提供经典 [[扩展DLVO理论|XDLVO]] 理论框架之外的、与限域相关的结构贡献。经定制的[[微孔]]和介孔限制了目标物种的构象自由度，并通过多点非共价结合以及空间主客体几何匹配，在局部增强吸引势。

然而，上述讨论，尤其是引入[[孔限域效应|限域效应]]和主客体匹配的必要性，凸显了将 [[扩展DLVO理论|XDLVO]] 理论应用于分子尺度时的根本局限性

[[全氟和多氟烷基物质|PFAS]] [[吸附]]。首先，[[扩展DLVO理论|XDLVO]] 将[[吸附剂]]表面和溶剂均视为连续介质，并将相互作用描述为随分离距离平滑、单调变化的函数。然而，PFAS 是尺寸仅为 0.5–2 nm 的[[分子离子]]，与相互作用范围本身相当，因此[[连续介质近似]]不再成立。此外，[[表面能]]参数 $( \bar { \gamma } ^ { \bar { \mathrm { L W } } } , \gamma ^ { + } , \gamma ^ { - } )$ 是由[[接触角]]推导得到的宏观平均值。这些数值无法表征在分子层面决定 PFAS 结合的离散[[官能团]]、[[孔道限域]]或[[化学非均一性|局部化学非均一性]]。其次，XDLVO 未明确纳入对 PFAS 捕获至关重要的若干相互作用，例如[[氢键]]、[[亲氟相互作用|亲氟性 C–F⋅⋅⋅F–C 接触]]以及[[离子交换]]。这些效应仅通过 [[Lewis酸碱相互作用|AB 项]]隐式引入，在该项中与其他短程作用贡献一并被平均化，从而丧失了其化学特异性 [50]。第三，真实的界面行为往往偏离 XDLVO 的假设。亲水表面附近的[[水合力]]呈振荡变化，而非指数衰减；[[反离子]]分布是离散的，而非弥散的；$\mathsf { C a } ^ { 2 + }$ 桥联或[[电荷调节]]等[[特异性离子效应]]则可能改变[[静电相互作用|静电作用]]能景观 [51]。总之，XDLVO 是一个不可或缺的半定量框架，可用于合理解释 [[pH]]、[[离子强度]]和[[润湿性]]如何调节[[相互作用能|相互作用能景观]]，但其基于连续介质的宏观参数，以及对具有化学特异性的相互作用的隐式处理，使其不足以可靠预测[[吸附能|绝对吸附能]]，或 PFAS 等分子吸附质在限域几何空间中的行为。

因此，超越 [[扩展DLVO理论|XDLVO]] 框架后，必须将 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]理解为一个需要 [[分子描述符|PFAS 分子描述符]]与[[吸附剂]]结构及化学性质进行多维匹配的过程。表 1 汇总了这些机制与性质之间的关系，将代表性吸附剂类别与其关键属性、最相匹配的 PFAS 分子描述符、所涉及的主导相互作用以及由此带来的工程启示相对应。

如表 1 所示，没有任何单一类别的[[吸附剂]]能够适用于所有 [[全氟和多氟烷基物质|PFAS]] 结构或所有[[水处理]]情景。疏水或低[[表面能]]区域能够有效截留[[长链PFAS|长链 PFAS]]，而短链及高度水合物种的去除通常需要更复杂的机制，例如静电增强、[[主客体识别]]、[[孔道限域]]或[[协同结合位点]]。因此，[[吸附]]剂的选择不仅应权衡[[吸附容量]]，还应考虑表面能、[[润湿性]]、[[孔道匹配]]、[[再生稳定性]]、[[浸出|浸出风险]]和[[基质耐受性]]。表 S2 将这一比较扩展至具体的代表性吸附剂，针对其目标 PFAS 的[[分子链长|链长]]、[[头基]]、[[分子支化|支化]]及[[尾链结构]]，列出了相应吸附剂的[[BET|比表面积]]、[[孔径]]、[[官能团密度]]与[[氟化密度]]、表面润湿性及[[吸附剂再生|再生]]稳定性。

## 2.2. [[吸附剂]]的开发

[[活性炭]]（AC）和[[离子交换树脂]]（IERs）长期以来一直是用于去除水体系中 [[全氟和多氟烷基物质|PFAS]] 的[[吸附剂]] [1]。然而，在实际受污染水体中，许多传统材料仍存在不足，表现为对[[短链PFAS|短链 PFAS]] 的[[吸附亲和力|亲和力]]低、[[吸附平衡|达到平衡]]缓慢，以及在其他溶质存在时选择性较差 [52,53]。具体而言，AC 主要依靠[[疏水相互作用]][[吸附]] PFAS，对[[长链PFAS|长链 PFAS]] 表现出较高的[[去除效率]]，但对[[短链全氟和多氟烷基物质|短链 PFAS]] 的去除性能则受到严重限制 [54]。相比之下，市售 IERs 主要通过[[静电相互作用]]吸附 PFAS。然而，水中存在的[[背景离子]]、有机物和[[溶解性固体]]会[[竞争吸附]]位点，常常导致 PFAS [[去除率|去除效率]]下降 [55]。这些不足推动了先进吸附剂的设计，以结合多种结合力、暴露更多[[吸附位点|结合位点]]、加快动力学过程、提高选择性并改善[[吸附剂重复使用性|可重复使用性]] [23]。通过精确设计分子结构以整合多种相互作用力，旨在创造更多[[结合位点]]、加快[[吸附动力学]]、提高[[吸附容量]]、增强[[吸附选择性]]，并改善吸附剂的可重复使用性 [3,23]。

## 2.2.1. [[碳质吸附剂]]

除[[颗粒活性炭]]（GAC）外，[[碳质吸附剂]]还包括[[生物炭]]、[[碳纳米管]]（CNTs）和[[石墨烯基材料]]。尽管用于去除 [[全氟和多氟烷基物质|PFAS]] 的新材料不断涌现，GAC 仍因其[[BET|比表面积]]大、成本相对较低且操作简单而得到广泛应用。传统 GAC 对[[短链PFAS|短链 PFAS]] 的[[吸附能]]力相对较弱，且通过单一的相互作用模式发挥作用。针对上述问题，为扩大该处理方法的应用范围，研究主要选择了[[孔结构改性]]和[[表面功能化]]两个方向。[[Shi]] 等人提出了一种在[[活性炭]][[微孔]]内原位[[限域水]]的策略。通过这种方式，限域水分子与[[短链全氟和多氟烷基物质|短链 PFAS]] 的亲水头部形成稳定的[[氢键]]，并与其疏水尾部产生波动的[[范德华力]]，从而有助于促进[[吸附]]过程；因此，[[疏水纳米孔]]中的[[传质]]和捕获均得到协同改善 [56]。

## 2.2.2. [[矿物基吸附剂]]

许多天然矿物，如[[针铁矿]]、[[二氧化硅]]和[[氧化铝]]，分布广泛，可为[[污染物固持]]提供低成本平台。然而，由于其固有的物理化学性质和带电表面，这些未经改性的[[吸附剂]]通常对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附亲和力|亲和力]]有限 [31,57]。[[Van den Bergh]] 等人发现，未经改性的[[全硅β沸石|超疏水全硅 β 沸石]]能够比 [[活性炭|AC]] 更有效地吸引 [[全氟辛酸|PFOA]] 并达到[[饱和吸附]]（370 mg $g ^ { - 1 } )$，即使存在非氟化有机竞争物，也能保持其效能。在这一框架内，PFOA 离子在疏水空腔中排列成螺旋结构，其分子链沿 a 和 b 孔道取向，[[羧酸根|羧酸根基团]]则通过[[氢键]]形成配对 [58]。后续研究证实，全硅 β 沸石能够耐受不同的[[水体基质]]条件（[[pH]] 为 4–8，存在 Na<sup>+</sup>、$\mathrm { , K ^ { + } , C a ^ { 2 + } , M g ^ { 2 + } }$ 离子，以及[[天然有机质]]、[[腐殖酸]]和[[富里酸]]），并且可通过[[热再生|热处理]]和[[溶剂再生|溶剂处理]][[吸附剂再生|再生]] [59]。[[Loganathan]] 等人利用[[分子动力学]]研究了 PFOA、[[全氟辛烷磺酸|PFOS]] 和 [[全氟己烷磺酸|PFHxS]] 混合物在[[高岭石]]上的[[吸附]]、结构构型和[[分子扩散|扩散行为]]。PFAS 分子主要通过氢键吸附于亲水性[[羟基]]基面，并倾向于在矿物界面处形成[[分子聚集|大型聚集簇]]。PFOS/PFHxS 混合物的扩散受到的限制明显大于 PFOS/PFOA 体系，这一差异可归因于末端基团，因为[[磺酸根]]与羟基表面的[[配位作用|配位]]比[[羧酸]]根更稳定 [57]。

## 2.2.3. [[聚合物基吸附剂]]

[[聚合物基吸附剂|聚合物吸附剂]]正日益受到关注，因为它们既可由[[生物降解性|可生物降解]]、可[[吸附剂再生|再生]]且低成本的原料（如[[纤维素]]和[[淀粉]]）制备，也可通过合成来实现特定的化学相互作用。

2.2.3.1. [[超分子主体|超分子主体材料]]。超分子主体是具有明确结构的[[氢键受体|受体]]，其空腔或[[结合口袋]]通过[[尺寸匹配]]、[[静电吸引]]、[[疏水相互作用|疏水效应]]、[[氢键]]或[[亲氟相互作用|亲氟性亲和作用]]识别[[客体分子]]。这使其在 [[全氟和多氟烷基物质|PFAS]] 捕获和传感方面具有吸引力，尤其是当空腔或带电位点经过调控以匹配 PFAS 的[[分子链长|链长]]和[[头基]]时 [60]。与传统多孔[[吸附剂]]相比，超分子主体可提供可编程性更高的结合环境，并且在某些情况下能够实现[[刺激响应性|刺激响应性摄取或释放]] [24]。

[[环糊精]]（CDs）及其衍生物由于对非极性化合物具有特异性[[包合作用]]，是用于 [[全氟和多氟烷基物质|PFAS]] 修复的较为优良的天然[[吸附剂]]。[[β-环糊精]]（β-CD）是一种由七个[[葡萄糖]]单元组成、呈截锥形的[[大环分子]]。这种结构的小开口边缘带有七个[[伯羟基]]，大开口含有 14 个[[仲羟基]]，使其外部具有亲水性。另一方面，空腔内部存在许多 C−H 键，因此相对疏水。因此，β-CD 可通过[[疏水相互作用|疏水效应]]以及空腔与[[客体分子]]在尺寸上的精确匹配互补性，与 PFAS 分子形成稳定的主客体包合物，从而捕获 PFAS [61]。William R. Dichtel 团队利用未改性的 β-CD 和缺电子芳香[[交联]]剂构建了一系列 β-CD 聚合物（CDPs），展现出显著的 PFAS 去除潜力 [26,61–67]。最初，Alsbaiee 等人使用四氟对苯二甲腈（TFN）合成了介孔 P-CDP，其微污染物捕获性能优于[[活性炭]]（ACs）[62]。为了增强在复杂基质中的选择性，Xiao 等人随后使用十氟联苯（DFB）开发了 DFB-CDP，该变体能够高效去除 [[全氟辛酸|PFOA]]，且不受共存[[腐殖酸]]的影响 [63]。着眼于[[静电相互作用]]，Klemes 等人通过将 TFN-CDP 的腈基还原为伯胺基，提高了其对[[阴离子PFAS|阴离子 PFAS]] 的[[吸附亲和力|亲和力]] [64]。这种结合能力的提升归因于与[[质子化]]胺基之间的静电相互作用，以及吸电子腈基被还原后交联剂酚盐的 $\mathsf { p } K _ { \mathsf { a } }$ 增大 [64]。在这些机理认识的基础上，Ching 等人研究了 PFAS 在多种 CDPs 和[[离子交换树脂]]上的[[吸附]]。他们发现，带正电的 CDPs（DEXSORB+、amine-CDP）能够快速去除[[阴离子]] PFAS，而带负电的 DEXSORB 对[[两性离子|两性离子物种]]最为有效。所有材料对[[非离子型PFAS|非离子型 PFAS]] 的去除效果均较差，表明[[静电吸引]]未能得到充分增强以促进吸附 [26]。Wang 等人引入了一种非随机交联的苯乙烯官能化 β-CD 单体体系。与上述离散单体共聚，得到了一类新型高性能[[阳离子]]甲基丙烯酸酯。新一代吸附剂在投加量仅为 1 mgL<sup>−</sup> <sup>1</sup> 时，即实现了对八种阴离子 PFAS 接近 100% 的[[去除效率|去除率]]，该投加量比此前的 CDPs 低一个数量级 [65]。

除上述 CDPs 外，有机分子笼是一类具有明确空间构型和可定制功能位点的离散[[超分子主体]]，同样展现出 [[全氟和多氟烷基物质|PFAS]] 修复潜力。He 等人构建了一种高度氟化的有机分子笼 F-Cage 2，这是一种非多孔响应性晶体，能够有效去除水溶液中的 [[全氟辛酸|PFOA]]。其出色的 PFOA 捕获能力源于协同效应，其中带正电的缺电子空腔产生[[静电吸引]]，以及以下基团之间的[[氢键|氢键作用]]：

−NH− 和 − COO‾ 基团，以及对 [[全氟辛酸|PFOA]] 的强[[亲氟相互作用|亲氟亲和力]] [68]。[[Liu]] 等人报道了一种带有十六个正电荷的 Zr 基金属有机笼，其 [[全氟辛烷磺酸|PFOS]] [[吸附容量]]高达 1603 $\mathbf { m g \  g ^ { - 1 } } .$，主要由高电荷密度[[静电相互作用|静电作用]]和[[阴离子]]交换驱动。沿四面体棱边分布的“Y”形[[结合口袋]]通过吡啶鎓环和亚苯基环上的酸性质子提供的多个 C–H⋅⋅⋅O [[氢键]]，锚定[[磺酸根|磺酸根头基]]，而被限域的 PFOS 所形成的亲氟环境进一步提高了总体[[吸附]]量 [69]。Sanchez-Lievanos 等人引入了卟啉衍生的[[阳离子]]纳米笼 $\mathrm { [ o N C ] 8 P F _ { 6 } , ~ \Delta [ C o ^ { 2 + } { \cdot } { \_ } o N C ] 8 P F _ { 6 } }$ 和 $\scriptstyle { [ \mathbf { C O } ^ { 3 + } ( \mathbf { N } \equiv \mathbf { O } ) \cdot \mathbf { o N C } ] } 8 \mathbf { P F } _ { 6 } ,$，并测试了它们对含 38 种 [[全氟和多氟烷基物质|PFAS]] 的混合物的[[吸附性能]]。将 [oNC]8PF 与 $\mathrm { [ C o ^ { 2 + } . o N C ] 8 P F _ { 6 } }$ 按 1:4 的比例混合后表现出协同效应，可同时去除复杂水样中的长链和[[短链PFAS|短链 PFAS]]。吸附主要依靠静电作用、[[疏水相互作用]]以及 PFAS 在纳米笼内的部分包合，这些材料对具有[[磺酸]]根或磺酰胺[[头基]]且碳链含五个或更多碳原子的客体表现出极高的[[吸附亲和力|亲和力]] [70]。

2.2.3.2. [[离子型含氟凝胶|离子型氟凝胶]]。离子型氟凝胶（Ionic Fluorogels，IFs）以全氟聚醚（PFPEs）与[[阳离子]]单体构成的[[交联]]网络为特征，已成为用于 [[全氟和多氟烷基物质|PFAS]] 修复的高性能[[吸附剂]]。Leibfarth 及其同事首次揭示了其协同[[吸附]]机制：季铵阳离子与 PFAS 的[[阴离子]][[头基]]之间存在强烈的[[静电吸引]]，而全氟碳尾链则通过[[亲氟相互作用|亲氟亲和力]]被选择性结合。这两种相互作用使 IFs 在复杂天然[[水体基质|水基质]]中具有高度选择性和良好的[[吸附剂再生|再生]]能力 [71]。

随着该领域的发展，后续研究着重于[[离子型含氟凝胶|离子型氟凝胶]]的[[化学稳定性]]和操作实用性。为解决长期环境应用中的降解问题，研究人员开发了新一代具有水解稳定性的 IFs，以牢固的芳基醚键取代原有的敏感连接键 [72]。Tan 等人进一步将磁性氧化铁纳米颗粒（IONPs）嵌入[[阳离子]]含氟聚合物中，以便在处理后进行快速磁分离；这些磁性[[吸附剂]]能够迅速[[吸附]] [[全氟和多氟烷基物质|PFAS]]，在 30 s 内去除 >99% 的 [[GenX]]，[[Langmuir模型|Langmuir]] 模型预测的[[吸附容量]]为 219 $\mathbf { m } { \mathbf { g } } { \cdot } { \mathbf { g } } ^ { - 1 } \ [ 7 3 ]$

另一个发展方向是可规模化制备的高容量氟凝胶平台。Yang 等人使用低分子量 PFPE 优化基质，开发了 PFPE-IEX+，其在[[饮用水]]和垃圾填埋场渗滤液中对所有类型的 [[全氟和多氟烷基物质|PFAS]] 均达到了较高的[[吸附容量]]（超过 500 mg $g ^ { - 1 } )$，目前正被考虑用于大规模[[水处理]] [74]。

近期的研究尝试还着眼于结构设计与环境适应性。[[Fu]] 等人开发了一种氟胺双位点[[水凝胶]]（[[QFgel]]），其结构与[[两亲性]] [[全氟和多氟烷基物质|PFAS]] 相似，可用于选择性[[水处理]]。通过自由基共聚，他们得以精确布置[[季铵基团]]和含氟基团，构建了一个将长程[[静电吸引]]与短程[[亲氟相互作用]]相结合的双位点平台，从而同时捕获 PFAS 的[[头基]]和 C−F 链。QFgel 的[[吸附容量]]高达 2835 $\mathbf { m } { \mathbf { g } } { \cdot } { \mathbf { g } } ^ { - 1 } ,$，且在复杂[[湖水]]中，对 17 种 PFAS 的[[去除效率|去除率]]保持在 >95.6%，其中包括传统 [[全氟烷基羧酸|PFCAs]]、[[全氟烷基磺酸|PFSAs]]，以及 [[GenX]]、[[ADONA]] 和 [[F-53B]] 等新兴类似物 [75]。与此同时，为应对[[吸附剂]]自身的环境足迹问题，Tan 等人采用非 PFAS 类含氟单体，如 2,3,4,5,6-五氟苯乙烯（PFS），替代 PFPE 链段，以消除 PFAS 二次[[浸出]]的风险。这些新一代非 PFAS 类磁性[[吸附]]剂（如 PFS-R2 + @IONPs）在含氟[[官能团]]与[[阳离子]]官能团之间保持了最佳平衡，并在实际垃圾填埋场渗滤液中的表现优于商业树脂（如 PFA694E）。便携式处理装置证实了该平台的实际应用可行性，在反复吸附–解吸循环中，其效率保持在 90% 以上，并具有良好的[[吸附剂重复使用性|重复使用性能]] [76]。

## 2.2.4. 框架[[吸附剂]]

框架[[吸附剂]]，包括 [[金属有机框架|MOFs]]、[[共价有机框架|COFs]] 及相关多孔网络，是一类有序材料，其[[孔径]]、[[表面电荷]]、连接体化学性质和[[官能团]]均可在分子或框架层面进行调控。这种可调控性为 [[全氟和多氟烷基物质|PFAS]] 的[[选择性吸附]]带来了多项优势：丰富的[[吸附位点|活性位点]]、可控的孔道环境，以及整合静电、疏水、[[氢键]]和[[亲氟相互作用]]的能力 [77]。

2.2.4.1. 金属/共价−有机框架。[[金属有机框架|MOFs]] 和 [[共价有机框架|COFs]] 是具有大[[BET|比表面积]]、有序孔道结构及可调结构单元的多孔材料 [22,78]。

[[金属有机框架|MOFs]] 是一类由无机节点和有机节点组成并形成三维多孔结构的杂化晶态纳米多孔材料 [22,25]。凭借可调控的结构、高[[BET|比表面积]]和较大的内部孔体积，MOFs 已成为去除污染物的优异平台，尤其适用于从水中高效捕获 [[全氟和多氟烷基物质|PFAS]] [22,25,79,80]。其中，锆基金属有机框架（Zr-MOFs）因其出色的水解稳定性、[[热稳定性]]和机械稳定性而尤具潜力 [81]。[[Li]] 等人评估了三种具有不同结构特征的 MOFs，即 NU-1000、UiO-66 和 ZIF-8，对采集自美国空军设施的受 [[水成膜泡沫灭火剂|AFFF]] 污染地下水样品中八类[[阴离子]]型和[[非离子型PFAS|非离子型 PFAS]] 的去除性能。在所测试的材料中，NU-1000 表现出优异的性能，对阴离子型（58%）和非离子型（99%）PFAS 均具有较高的去除能力，同时具有快速的[[吸附动力学]]（[[吸附平衡|达到平衡]]所需时间 <1 min），显著优于 UiO-66、ZIF-8 和商用 [[颗粒活性炭|GAC]]。根据该研究，预计 NU-1000 主要通过[[静电相互作用]]驱动的阴[[离子交换]]机制去除[[阴离子PFAS|阴离子型 PFAS]]；具体而言，[[去质子化]]的酸性基团会取代 $\mathrm { Z r } _ { 5 } ( \mu _ { 3 } { - } \mathrm { O } ) _ { 4 } ( \mu _ { 3 } { - } \mathrm { O H } ) _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 4 } ( \mathrm { O H } ) _ { 4 } ( \mathrm { - e C O } _ { 2 } ) _ { 8 }$ 节点上的末端[[羟基]]配体。这一行为符合 [[Pearson]] 的硬软酸碱（HSAB）理论；因此，PFAS 的硬碱[[官能团]]与硬酸 $\mathbf { Z r } _ { 6 }$ 节点发生强相互作用，同时它们与 MOFs 的芘基连接体之间发生[[疏水相互作用]]。对于非离子型 PFAS（例如全氟烷基磺酰胺，FASAs），[[吸附]]同样受 HSAB 原理驱动，涉及硬碱胺基与硬酸 $\mathbf { Z r } _ { 6 }$ 节点之间的酸碱相互作用。疏水效应进一步增强了这种相互作用，使长链和多氟化物种更易被吸附。此外，针对非离子型物种，研究提出了一种特定的去[[质子化]]机制，其中胺基使 Zr₆ 节点上的 μ₃-桥联羟基去质子化，产生强烈的静电 $\mathrm { \mu _ { 3 } - O ^ { 2 - } - N H _ { 3 } } ^ { + }$ 相互作用，从而将 PFAS 稳定在多孔结构内。[[阴离子型PFAS|阴离子型 PFAS]] 的吸附会受到[[水体基质|水基质]]中竞争离子的影响，而非离子型 PFAS 的吸附基本不受地下水地球化学条件的影响 [25]。

Liang 等人报道了一系列多孔[[配位作用|配位]]网络 [[金属有机框架|MOFs]]，包括 PCN-999、PCN-1001、PCN-1002 和 PCN-1003 [82–84]。锆基 PCN-999 具有分级多孔结构，其中含有独特的双甲酸根桥联 $\mathbf { ( } \mathbf { Z r } _ { 6 } ) _ { 2 }$ 簇，表现出高达 1089 $\mathbf { m } \mathbf { g \thinspace g } ^ { - 1 } ,$ 的优异 [[全氟辛酸|PFOA]] [[吸附容量]]。该[[吸附]]过程主要由 PFOA 的[[羧酸根|羧酸根基团]]与 PCN-999 中不饱和 $\ ( Z \mathbf { r } _ { 6 } ) _ { 2 }$ 次级构筑单元（SBUs）之间的 [[Lewis酸碱相互作用|Lewis 酸碱相互作用]]驱动，随后，这些配位的 PFOA 分子充当晶种，通过协同[[疏水相互作用]]诱导游离 PFOA [[分子聚集]] [82]。随后，研究考虑了具有未占据邻位[[羟基]]的 Zr-MOFs，具体包括非互穿的 PCN-1001 和二重互穿的 PCN-1002。互穿的 PCN-1002 表现出更好的[[化学稳定性]]以及高达 $6 3 2 \mathrm { m g } \mathrm { g } ^ { - 1 }$ 的吸附容量，其中，空闲邻位羟基位点与 PFOA 之间形成的多个[[氢键]]，以及锆氧单元与 PFOA 之间的 Lewis 酸碱配位作用，协同促进了吸附 [83]。

lli'c 等人报道了 Zr(IV)-[[羧酸]]盐 [[金属有机框架|MOFs]] 的 UiO-66 家族及其聚合物接枝复合材料，用于痕量 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]去除。其中，$\mathrm { U i O - } 6 6 { \cdot } ( \mathrm { F } ) _ { 4 } { \cdot } 0 S$ 通过将氟化的 $\mathrm { U i O } { - } 6 6 { - } ( \mathrm { F } ) _ { 4 }$ 框架与外部接枝的有机硅酸盐（OS）涂层协同整合，展现出增强的广谱 PFAS [[吸附性能]]。$\mathrm { U i O } { - } 6 6 { - } ( \mathrm { F } ) _ { 4 }$ 中的氟化有机连接体（带有四个氟取代基的 1,4-苯二甲酸根）与 PFAS 的全氟烷基链形成[[疏水相互作用]]和[[亲氟相互作用]]，对 [[全氟辛烷磺酸|PFOS]] 等长链物质的吸附尤为有效。疏水性 OS 涂层通过增强表面疏水性并使涂层与 PFAS 分子直接相互作用，进一步促进吸附。关键的是，该研究强调，吸附由表面和界面化学驱动，而非孔隙填充，因此，尽管孔隙受到空间位阻限制，$\mathrm { U i O - } 6 6 { \cdot } ( \mathrm { F } ) _ { 4 } { \cdot } \mathrm { O S }$ 仍能在环境相关浓度（ppb 水平）下有效捕获 PFAS [33]。

[[Loukopoulos]] 等人通过向 $\mathrm { Z r } _ { 6 }$ 单元中添加[[氟化单羧酸]]作为[[非结构性连接体]]，对两种含 Zr 的 [[金属有机框架|MOFs]]（[[DUT-67]] 和 [[MOF-808]]）进行了改性，所用[[单羧酸]]具体为 [[2-氟苯甲酸]]（FBA）、[[2,6-二氟苯甲酸]]（DFBA）或[[三氟乙酸]]（TFA）。对于[[长链PFAS|长链 PFAS]]，未改性的 MOF-808 对 [[全氟辛酸|PFOA]] 的[[吸附容量]]为 986 mg $\mathbf { g } ^ { - 1 }$，改性后，[[TFA-MOF-808]] 的[[吸附]]容量达到 2496 mg $\mathbf { g } ^ { - 1 }$。对于[[短链PFAS|短链 PFAS]]，TFA-MOF-808 对 [[全氟丁酸|PFBA]] 和 [[全氟己酸|PFHxA]] 的吸附容量分别达到 311 mg $\mathbf { g } ^ { - 1 }$ 和 436 mg $\mathbf { g } ^ { - 1 }$，与初始 MOF 相比提高了 33–66%。因此，TFA-MOF-808 可通过多种方式应对多种 [[全氟和多氟烷基物质|PFAS]] 污染，甚至包括传统[[吸附剂]]不适于处理的更[[长链全氟和多氟烷基物质|长链 PFAS]]。TFA-MOF-808 [[吸附性能]]的增强源于 $\mathrm { Z r } _ { 6 }$ 节点处的[[配体交换]]与 PFAS [[化学吸附]]的协同双重机制，以及氟改性疏水孔隙环境中用于捕获[[短链全氟和多氟烷基物质|短链 PFAS]] 的强[[物理吸附]]作用 [80]。

最近，[[Luo]] 等人引入了一种[[表面限域低聚物接枝技术]]，用于改性 $\mathrm { U i O } { \cdot } 6 6 { \cdot } \mathrm { N H } _ { 2 } .$。通过接枝紧密排列的[[低聚烷基叔铵]]（PAOQ）单元，他们制得了 $\mathrm { U i O } – 6 6 – L _ { 3 }$ [[吸附剂]]。$\mathrm { U i O } – 6 6 – L _ { 3 }$ 的优异性能源于协同的[[双模式吸附机制]]：[[季铵基团|阳离子季铵中心]]对[[阴离子PFAS|阴离子 PFAS]] [[头基]]提供强烈的[[静电吸引]]，而[[构象柔性]]的[[低聚烷基链]]则通过[[疏水相互作用]]和 [[σ键|σ 键]]介导的 C–H⋅⋅⋅F–C [[氢键]]捕获[[含氟尾链]]。[[DFT]] 计算表明，低聚烷基诱导的[[电子重分布]]提高了相邻铵中心的[[静电势]]。结合[[扩散势垒]]的降低，该材料在复杂[[水体基质|水基质]]中实现了[[链长依赖的选择性]]和优异的[[结构稳定性]] [85]。

除 [[锆基金属有机框架|Zr 基 MOFs]] 外，[[Grancha]] 等人还利用 [[L-组氨酸]]合成了一种[[手性生物源铜MOF|手性生物源铜 MOF]]，Cu<sup>II</sup>(S,S)-hismox 5H O，其具有固有的[[梯形纳米通道]]以及[[两亲性|疏水–亲水双重特性]]。这种两亲性结构与 [[全氟和多氟烷基物质|PFAS]] 分子在空间上良好匹配，对长链种类的[[去除效率|去除率]]可接近 100%；对于 [[全氟丁酸|PFBA]]（70%）和 [[全氟丁烷磺酸|PFBS]]（86%）等短链类似物，[[去除率|去除效率]]也较高。其协同捕获途径包括通过[[不饱和铜位点]]直接结合带负电的[[头基]]，以及通过形成[[氢键]]的[[咪唑官能团]]实现稳定。同时，[[疏水孔壁]]通过[[卤键]]和[[疏水相互作用]]的共同作用与[[含氟尾链]]结合。这种多重作用方式确保了 [[金属有机框架|MOF]] 框架对短链和[[长链PFAS|长链 PFAS]] 的高效捕获 [79]。

[[共价有机框架|COFs]] 由纯[[有机单体]]合成，由碳、氢、氧、氮等轻元素组成 [86]。这些元素通过[[有机构筑单元]]之间的[[共价键]]连接，形成延展、多孔且有序的二维和三维结构 [87]。在[[二维共价有机框架|二维 COFs]] 中，开放的[[一维通道]]与孔壁上预先排列的[[吸附位点|结合位点]]之间的协同作用有助于[[分析物传输]]，并增强[[吸附剂]]与目标物种之间的相互作用，从而提高[[吸附性能]] [88]。例如，[[Huang]] 等人开发了一种[[氟化方酰胺共价有机框架|二维氟化方酰胺 COF]]（FSQ-1），其采用的[[多功能单体]]将[[氢键供体]]（N−H）和[[氢键受体|受体]] $\scriptstyle ( \mathbf { C } = \mathbf { O } )$ 整合于[[亲氟基团]]（−CF ）附近。[[氢键]]与[[氟–碳相互作用]]的联合作用能够有效分解各类 [[全氟和多氟烷基物质|PFAS]]，如长链和短链种类、[[全氟和多氟烷基物质前体|前体]]及[[两性离子|两性离子物种]]，包括 [[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]]、[[GenX]]、[[F-53B]]、[[PFOSAmS]] 和 N-CMAmP-6:2 FOSA [43]。在另一项研究中，同一研究团队合成了[[胱胺]]接枝的[[中空COF纳米球|中空 COF 纳米球]]（[[Cys-COF]]），可在数分钟内去除 20 种[[阴离子PFAS|阴离子 PFAS]]（包括[[羧酸]]、[[磺酸]]和[[磷酸]]）的 90% 以上。由于胱胺末端氢原子的缺电子特性，功能化壳层形成了[[缺电子通道]]。这些通道通过强[[静电相互作用]]和氢键结合富电子的[[阴离子]] PFAS [44]。

此外，[[Jrad]] 等人提出了一种基于[[胍鎓]]的二维[[阳离子]] [[共价有机框架|COF]]（[[TG-PD COF]]），用于集成荧光传感与快速 [[全氟辛酸|PFOA]] [[吸附]]。均匀分布且易于接近的阳离子胍鎓基团通过[[静电相互作用|静电作用]]吸引 PFOA 的[[阴离子]][[头基]]，成为初始快速吸附及随后荧光“开启”响应的主要驱动力。该过程首先通过静电作用形成单层，随后，PFOA 簇通过疏水尾链之间的相互作用在 COF 界面[[分子聚集|聚集]]，实现了超过 2600 mg ${ \mathbf g } ^ { - 1 }$ 的较高[[吸附容量]] [89]。

[[Zadehnazari]] 等报道了基于紫精的 [[共价有机框架|COFs]]，即 MELEM-COF 和 MEL-COF，它们对 [[全氟辛酸|PFOA]] 具有出色的[[吸附能]]力。MELEM-COF 是一种容量极高、[[吸附动力学]]快速的材料，其最高[[吸附容量]]达到创纪录的 2500 mg $\mathbf { g } ^ { - 1 }$，并在 30 min 内[[吸附平衡|达到平衡]]。这一作用的首要原因是，[[阳离子]]紫精框架通过[[静电吸引]]对 PFOA 的[[阴离子]][[头基]]产生强烈吸引力。除上述[[吸附]]机制外，MELEM-COF 中还存在[[离子交换]]、偶极相互作用和[[氢键|氢键相互作用]]，将污染物保留在有序孔道中 [90]。

2.2.4.2. 多孔芳香框架。多孔芳香框架（[[多孔芳香框架|PAFs]]）是一类典型的功能化多孔聚合物体系，由多个苯环通过各种偶联反应以 C−C [[共价键]]连接而成 [91,92]。[[Liu]] 等采用具有四面体碳节点和联苯支柱的三维网络聚合物 PAF-1，构建了高性能 [[全氟辛酸|PFOA]] 捕获体系。通过在孔壁上引入具有协同作用的静电和疏水位点（NDMB = N, N-二甲基丁胺），所得 [[PAF-1-NDMB]] 的 PFOA [[饱和吸附容量]]超过 2000 mg ${ \mathbf g } ^ { - 1 }$，较原始 PAF-1 提高了 14.8 倍，并且在相同条件下约为基准 [[颗粒活性炭|GAC]] 的 24.1 倍 [32]。

[[Zhang]] 等还通过具有四面体结构的氟化烷基制备了 $\mathrm { P A F } { \cdot } \mathrm { C F } _ { 3 }$ 和 $\mathrm { P A F  – C _ { 2 } F _ { 5 } }$；二者均具有较大的[[BET|比表面积]]（超过 800 $\mathbf { m } ^ { 2 } ~ \mathbf { g } ^ { - 1 } )$ 和优异的亲氟性。在独特的 C−F⋅⋅⋅F−C 相互作用驱动下，这些框架表现出显著的[[吸附容量]]，并在去除痕量 [[全氟辛酸|PFOA]]（1 μg $\mathrm { L } ^ { - 1 } )$ 方面具有卓越效率，可将最终浓度降至 [[美国环境保护署|EPA]] 的终生健康建议限值 70 ng $\mathrm { L } ^ { - 1 }$ 以下 [93]。

在这些研究结果的基础上，[[Pezoulas]] 等系统考察了带有不同后合成功能基团的 PPN-6（也称为 PAF-1）对 [[全氟和多氟烷基物质|PFAS]] 的去除效果。这些改性使框架能够结合静电、[[氢键]]、疏水和[[亲氟相互作用]]，作用于具有不同碳骨架和[[官能团]]的 PFAS。PPN-6-FNDMB $\mathrm { ( F N D M B = \it { N , N - } d i m e t h y l - 3 , 3 , 4 , 4 , 4 - }$ 五氟丁胺）表现突出，结合[[静电吸引]]、疏水性和亲氟性，实现了 4.0 mmol $\mathbf { g } ^ { - 1 }$ 的高[[吸附容量]]，并具有快速的[[吸附动力学]]，在 30 s 内即可[[吸附平衡|达到平衡]]。在实际性能测试中，PPN-6-FNDMB 对采自美国某空军基地、受 [[水成膜泡沫灭火剂|AFFF]] 影响的地下水样品中的 21 种不同 PFAS 实现了近乎完全去除 [94]。

## 2.3. 影响 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的因素

尽管许多新近报道的[[吸附剂]]在实验室中表现良好，但它们在工业废水或天然水源等实际条件下的性能并不仅仅取决于材料的固有结构。复杂的水化学条件可通过竞争性离子、[[天然有机质]]、悬浮固体、[[pH]] 变化和共存污染物削弱[[吸附]]作用。因此，在比较吸附剂性能时，应将 [[分子描述符|PFAS 分子描述符]]与这些环境因素结合起来评估。

## 2.3.1. [[全氟和多氟烷基物质|PFAS]] 性质的作用

[[全氟和多氟烷基物质|PFAS]] 化合物的结构通过三个方面影响其[[吸附能]]力：碳[[分子链长|链长]]度、异构现象和化学官能

团。

全氟烷基链尺寸 $( - \mathrm { C } _ { \mathrm { n } } \mathrm { F } _ { 2 \mathrm { n } ^ { - } } )$ 与[[吸附能]]力之间存在正相关关系。[[长链PFAS|长链 PFAS]] 具有更多 [[碳氟键|C−F 键]]，在增强的[[疏水相互作用|疏水作用力]]下，能够在[[吸附剂]]表面更有序地排列 [25]。同时，C−F 基团数量的增加有利于其与[[吸附]]剂氟化区域之间的[[亲氟相互作用]]，并增强非极性全氟碳链与吸附剂表面之间的[[范德华力]] [94]。

氟化程度也会影响[[吸附能]]力。针对氢氧化锌絮体[[吸附]] 107 种[[阴离子PFAS|阴离子 PFAS]] 的研究发现，[[吸附效率]]与分子结构有关。氟含量高 $\left( \mathrm { F } / \mathrm { C } > 1 . 6 \right)$ 且氟原子数量多 $\left( \mathbf { e } . \mathbf { g } . , > 8 \right)$ 的 [[全氟和多氟烷基物质|PFAS]] 更易被吸附，这是因为其具有更高的疏水性和[[表面活性]]，有利于半胶束的形成。相反，含有 −H、−Cl 或醚（−O−）基团等极性基团的 PFAS 疏水性较低，在多层吸附中的稳定性也较差。某些分子（如 [[I-PFAA]]）尽管氟原子较少，却相对容易被吸附，这表明其中可能涉及更复杂的分子结构 [5]。

与具有相同 C−F 单元数量的支链类似物相比，[[直链PFAS|直链 PFAS]] 通常与[[吸附剂]]结合得更牢固。支链同系物中更强的分子内相互作用会增大空间位阻，限制分子在孔隙内的[[分子扩散|扩散]]，从而降低[[吸附位点|活性位点]]的可及性 [24,33,75]。

官能[[头基]]决定了 [[全氟和多氟烷基物质|PFAS]] 的亲水性和电荷。在碳原子数相同的情况下，[[全氟烷基磺酸|PFSAs]]（如 [[全氟辛烷磺酸|PFOS]]）的[[吸附效率]]通常高于 [[全氟烷基羧酸|PFCAs]]（如 [[全氟辛酸|PFOA]]）。尽管这一差异部分归因于 PFOS 中额外的 C−F 单元增强了其疏水性，但 [[Li]] 等人基于 [[Pearson]] 的硬软酸碱（HSAB）理论提出了一种更具决定性的机制。在这一情境下，[[阴离子PFAS|阴离子 PFAS]] 的[[官能团]]充当硬碱，而 NU-1000 的 $\mathbf { \Delta } \mathbf { Z } \mathbf { r } _ { 6 } .$ 节点充当硬酸。由于[[磺酸根]]是比[[羧酸根]]更硬的碱，因此其与硬酸 $\mathbf { \Delta } \mathbf { Z } \mathbf { r } _ { 6 } -$ 节点之间的[[静电相互作用]]更强 [25]。

从[[分子描述符]]的角度来看，[[全氟和多氟烷基物质|PFAS]] 的[[吸附亲和力]]不仅取决于[[分子链长|链长]]和[[头基]]，还取决于 F/C 比、氟密度、分子体积、极性表面积、回转半径、极化率、[[分子支化|支化]]程度和尾链构象。这些描述符共同决定了水合强度、界面分配、空间可及性以及多点结合的可能性。因此，[[吸附剂]]设计应使材料的主要结合区域与目标 PFAS 混合物的描述符相匹配，而非依赖单一的长链 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] 基准 [95]。

作为上述设计原则的佐证，多种先进[[吸附剂]]已展现出对结构多样的 [[全氟和多氟烷基物质|PFAS]] 的高效去除能力。例如，[[Grancha]] 等人开发的生物衍生 [[金属有机框架|MOF]] 对[[长链PFAS|长链 PFAS]] $\scriptstyle ( \mathbf { C } _ { 7 } - \mathbf { C } _ { 1 2 } )$ 表现出较高的[[去除效率|去除率]]（80%–100%），包括 [[全氟癸酸|PFDA]]、[[全氟十一烷酸|PFUnDA]]、[[全氟十二烷酸|PFDoDA]]、[[全氟辛烷磺酸|PFOS]] 和 8:2 FTSA，同时对短链种类也表现出良好的[[去除率]]（[[全氟丁酸|PFBA]] 为 70%，[[全氟丁烷磺酸|PFBS]] 为 86%）。这一性能源于该材料能够通过[[疏水相互作用]]稳定碳链，同时通过[[配位作用]]和[[氢键]]锁定极性[[头基]] [79]。类似地，[[Fu]] 等人开发的 [[QFgel]] 对多种 [[全氟烷基羧酸|PFCAs]]、[[全氟烷基磺酸|PFSAs]] 及其类似物（例如 [[GenX]]、[[ADONA]] 和 [[F-53B]]）的去除效率达到 >95.6%。其广谱去除性能源于协同的“静电–亲氟”双位点机制，而[[季铵基团]]与含氟基团的均匀分布使这一机制得以实现 [75]。

## 2.3.2. [[水体基质|水基质]]的作用

工程评估必须在考量 [[全氟和多氟烷基物质|PFAS]] 浓度、混合物组成、[[吸附剂]]投加量、[[接触时间]]、[[吸附穿透行为|穿透行为]]和[[吸附剂再生|再生]]性能的同时，权衡[[水体基质|水基质]]的影响。采用 mg $\mathrm { L } ^ { - 1 }$ 水平的单一 PFAS 开展的批量试验对机理筛选具有价值，但难以充分反映[[饮用水]]、地下水、垃圾填埋场渗滤液或受 [[水成膜泡沫灭火剂|AFFF]] 影响的废水中的情况；在这些水体中，PFAS 通常以 ng $\mathrm { L } ^ { - 1 }$ 至 ug $\mathrm { L } ^ { - 1 }$ 水平存在，并伴有[[天然有机质]]（NOM）、盐类和竞争性污染物。

[[水体基质|水基质]]条件，尤其是 [[pH]]、[[共存离子]]和 [[天然有机质|NOM]]，是通过改变[[静电相互作用]]和表面化学性质来调控 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的关键因素。

[[pH|溶液 pH]] 主要通过改变[[吸附剂]]的[[表面电荷]]来调控 [[全氟和多氟烷基物质|PFAS]] [[吸附]]；PFAS [[头基]]本身在环境相关 pH 范围内始终保持[[去质子化]]状态。由于大多数 [[全氟烷基羧酸|PFCAs]] 和 [[全氟烷基磺酸|PFSAs]] 的 pK<sub>a</sub> 低于 1.0，它们在环境条件下（pH 3–10）主要以[[阴离子]]形式存在。通常，酸性条件通过促进吸附剂表面基团的[[质子化]]，减弱表面与[[阴离子PFAS|阴离子型 PFAS]] 之间的[[静电排斥]]，从而有利于吸附 [96]。另一方面，碱性环境会增加 OH<sup>−</sup> 浓度；因此，[[阴离子型PFAS|阴离子型 PFAS]] 受到带负电[[吸附位点]]的排斥，难以被吸附。Lamb 等人开展了[[分子动力学模拟|原子尺度分子动力学模拟]]，观察到 PFAS 在[[石墨烯]]上的吸附行为具有 pH 依赖性。在中性条件下，PFAS 头基保持完全去质子化状态，因此受到静电排斥；由此，液相中形成[[类胶束聚集体]]，抑制了吸附。另一方面，当将头基建模为质子化的中性形式时——这代表低于头基 pK 的强酸性条件（pH < 1），而非环境相关范围——分子间排斥消失，使得大型层状聚集体得以形成，并完全结合于载体上 [96]。Luo 等人还发现，在 pH 3.0 时，纳米气泡（NBs）通过减弱静电排斥，提高了碳吸附剂对 PFAS 的吸附。相反，在 pH 11.0 时，由于 OH<sup>−</sup> 浓度更高，以及随之产生的 PFAS、[[纳米气泡|NBs]] 和吸附剂之间的排斥，吸附量较低 [97]。

[[共存离子]]对 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的影响取决于其浓度和[[离子价态|价态]]，其净效应由[[吸附剂]]的[[表面电荷]]决定。对于带正电的[[阴离子交换型吸附剂]]，共存[[阴离子]] $( \mathrm { e . g . , \ C l ^ { - } , \ N O _ { 3 } ^ { - } , \ C l O _ { 4 } ^ { - } , \ H C O _ { 3 } ^ { - } , \ C O _ { 3 } ^ { 2 - } , \ S O _ { 4 } ^ { 2 - } , \ C r O _ { 4 } ^ { 2 - } } )$ 会与 PFAS [[头基]]竞争[[阳离子]]位点，通常会降低[[吸附性能]]。对于带负电或[[疏水性吸附剂]]，阳离子 $( { \mathrm { e . g . , ~ K ^ { + } , ~ C a ~ ^ { 2 + } , ~ N \bar { a } ^ { + } , ~ M g ^ { 2 + } , ~ F \bar { e } ^ { 3 + } } } )$ 通常通过屏蔽 PFAS 与表面之间的排斥来促进吸附，而[[多价离子]]还可通过[[离子桥联作用|桥联作用]]将[[阴离子PFAS|阴离子型 PFAS]] 连接至表面位点。相反，对于带正电的吸附剂，[[离子强度]]升高反而可能屏蔽吸引场，降低吸附量 [34,97]。[[Luo]] 等人研究了离子浓度和价态的影响。他们观察到，中等 [[氯化钠|NaCl]] 浓度（1–10 mM）显著增强了 [[纳米气泡|NBs]] 辅助的[[石墨烯]]对 [[全氟辛烷磺酸|PFOS]] 的吸附。这种增强归因于 $\mathrm { N a ^ { + } }$ 离子中和了 NBs 表面的负电荷，从而减小了气泡直径并扩大了[[有效吸附面积]]，同时[[盐析效应]]降低了 PFAS 的[[溶解度]]，驱使其向 NBs 界面迁移。然而，在较高浓度（100 mM）下，过量离子破坏了 NBs 的稳定性，因而抑制了吸附。在离子价态方面，$\mathrm { F e } ^ { 3 + }$ 的表现显著优于 $\mathrm { N a ^ { + } }$ 和 $\mathsf { C a } ^ { 2 + }$。这种优异表现归因于三价离子能够有效减弱[[静电排斥]]，并通过桥联作用使[[阴离子型PFAS|阴离子型 PFAS]] 分子形成更大的[[分子聚集|聚集]]体，从而更易被捕获 [97]。

[[天然有机质|NOM]] 通常通过促使 [[全氟和多氟烷基物质|PFAS]] 竞争有限的[[吸附位点]]、[[孔隙堵塞|堵塞孔隙]]、污染表面以及改变[[疏水相互作用]]，降低其[[吸附容量]]。在 Hakimabadi 等人的研究中，[[富里酸]]的存在显著降低了[[胶体活性炭]]（CACs）对 PFAS 的[[吸附亲和力]]。这是由于 NOM 分子（通常比 PFAS 更大）堵塞了 CACs 的[[微孔]]，或直接竞争[[活性炭]]表面的[[疏水吸附位点]]。这种抑制作用对高度依赖疏水相互作用的[[长链PFAS|长链 PFAS]] 尤为显著。然而，有趣的是，尽管苯和 [[三氯乙烯|TCE]] 会竞争性地抑制 [[全氟辛烷磺酸|PFOS]] 的[[吸附]]，但它们对 [[全氟辛酸|PFOA]] 的影响可忽略不计，甚至具有促进作用，而疏水性[[柴油有机物]]则显著抑制整体吸附容量 [98]。

许多研究致力于确保[[吸附剂]]在实际水体中的性能不受[[水体基质|水基质]]影响。例如，[[PAF-1-NDMB]] 在不同水质条件下保持了出色的稳定性，在较宽的 [[pH]] 范围（2–11）内保持 100% 的 [[全氟辛酸|PFOA]] [[去除效率|去除率]]，即使存在 20 ppm [[腐殖酸]]时仍然有效。此外，在初始 PFOA 浓度为 $1 0 \ s \ \ \mathrm { o n }$ 的[[小清河]]实际受污染水样中，它在 $1 6 6 . 2 7 ~ \mu \mathrm { g } ~ \mathrm { L } ^ { - 1 }$ 内实现了 99.99% 的[[去除率]]，成功将 PFOA 浓度降至 [[美国环境保护署|US EPA]] 建议限值以下 [32]。最近，[[QFgel]] 在[[自来水]]和[[湖水]]中均保持了对 [[全氟辛烷磺酸|PFOS]]、PFOA 和 [[全氟丁烷磺酸|PFBS]] 的[[吸附容量]]；在共存[[阴离子]] $( \mathrm { C l } ^ { - } , \mathrm { N O } ^ { 3 - } , \mathrm { S O } _ { 4 } ^ { 2 - } )$ 和腐殖酸存在的情况下，其对这些化合物的去除率仍超过 94.6%，且在 pH 4–10 范围内，去除率保持在 93.5% 以上 [75]。

## 2.4. [[PFAS吸附剂|PFAS 吸附剂]]的[[工程基准评估]]

[[PFAS吸附剂|PFAS 吸附剂]]文献中长期存在的一个局限是，在未对测试条件进行标准化的情况下，跨研究比较[[吸附容量]]和[[去除效率]]。此类比较可能产生误导，因为[[最大吸附容量]] $\left( \operatorname { Q } _ { \operatorname* { m a x } } \right)$ 值通常是在较高[[初始浓度]]和较长[[接触时间]]下获得的，而实际[[水处理]]面对的是痕量水平的 [[全氟和多氟烷基物质|PFAS]]、[[多组分混合物]]以及[[连续流运行|连续流运行条件]] [99]。因此，[[工程基准评估]]必须明确区分[[吸附剂]]的理论[[吸附]]潜力与实际应用可行性。

有几个参数值得综合考虑。[[全氟和多氟烷基物质|PFAS]] [[初始浓度]]应区分 ng $\mathrm { L } ^ { - 1 }$ 的[[饮用水]]条件、$\mu \ g \mathrm { ~ L ~ } ^ { - 1 }$ 的地下水或地表水条件，以及 mg $\mathrm { L } ^ { - 1 }$ 的实验室筛选条件。混合物组成同样重要，因为针对单一化合物 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的实验无法代表受 [[水成膜泡沫灭火剂|AFFF]] 影响的水体，或含有短链、支链、[[全氟和多氟烷基物质前体|前体]]及[[新兴全氟和多氟烷基物质|新兴 PFAS]] 的工业废水。$\mathrm { p H } ,$ [[离子强度]]、[[共存离子]]、[[天然有机质|NOM]] 和实际水体类型等[[水体基质|水基质]]变量，应与其引起的[[表面电荷]]、孔隙可达性和[[竞争吸附]]变化联系起来 [100]。

除上述环境参数外，操作变量也同样重要。通过大[[吸附剂]]用量或长平衡时间实现的高[[去除效率]]，在实际应用中可能意义有限。与单点批量试验相比，柱试验、处理床体积数、空床[[接触时间]]、穿透曲线、穿透时间以及[[吸附剂再生|再生]]指标能够更真实地反映实际情况，但文献对这些指标的报告并不一致 [101]。表 S3 以报告状态矩阵的形式，列出了实际能够提取的工程相关项目，包括 [[全氟和多氟烷基物质|PFAS]] 浓度或混合物、[[水体基质]]、[[pH]]、[[共存离子]]、[[天然有机质|NOM]] 或[[腐殖酸]]、[[吸附]]剂用量或接触时间、穿透证据，以及再生或容量保持信息。

这一基准比较视角揭示了先进实验室[[吸附剂]]与实际可行的修复材料之间的差距。例如，[[疏水性吸附剂]]在[[长链PFAS|长链 PFAS]] 去除和广谱初步处理方面仍具有吸引力，而[[短链PFAS|短链 PFAS]] 通常需要静电增强、[[主客体识别]]或限域辅助结合 [56,109]。[[含氟吸附剂]]可实现高选择性，但在规模化应用之前，必须解决其[[浸出|浸出风险]]和使用寿命终结阶段的风险。非氟化材料可能更符合新兴环境法规的要求，前提是其孔隙结构和[[表面电荷]]分布能够充分弥补缺乏[[亲氟相互作用]]所带来的不足。

## 3. 观点与展望

尽管先进[[吸附剂]]在应对 [[全氟和多氟烷基物质|PFAS]] 污染方面已展现出一定潜力，但仍存在一些不足。具体而言，其[[吸附]]速率不足、长期[[吸附剂重复使用性|可重复使用性]]尚不确定、存在二次废物风险，且在实际水体系统中的验证不充分。未来工作应将材料合成、性能提升、可持续[[吸附剂再生|再生]]和后处理相结合，以弥合实验室测试与工业应用之间的差距。

## 3.1. 合成工艺的优化

[[吸附剂|吸附材料]]的精准设计需要摆脱传统的试错方法。[[分子模拟]]与

AI 驱动的筛选能够在分子水平上指导孔隙结构和功能位点分布的调控，增强[[吸附剂]]识别和捕获 [[全氟和多氟烷基物质|PFAS]] 的能力。此外，由于传统的多步合成路线能耗高、操作复杂，因此需要简化合成工艺，以降低合成成本。建议采用一步热解等直接合成方法制备[[吸附]]材料。此外，可使用乙醇-水作为制备溶剂，替代有害溶剂，在保持[[吸附性能]]的同时减少环境足迹。在原料方面，应在适用情况下优先选用[[生物炭]]、天然矿物和生物质等低成本原料，既可降低成本，也可避免向处理系统中引入额外的含氟组分。

## 3.2. [[吸附性能]]的提升

更优的[[吸附性能]]体现在三个相互关联的方面：对复杂[[水体基质]]的适应性、对痕量 [[全氟和多氟烷基物质|PFAS]] 的捕获能力，以及涵盖传统和[[新兴全氟和多氟烷基物质|新兴 PFAS]] 化合物的广谱去除能力。对基质适应性的提升归因于静电、疏水、[[氢键]]和[[亲氟相互作用]]的整合，这降低了[[吸附剂]]性能对[[pH|溶液 pH]] 和共存物质的敏感性。痕量捕获需要高[[吸附亲和力|亲和力]][[吸附位点|结合位点]]，而[[主客体识别|超分子主客体识别]]、限域增强结合或分子印迹可提供此类位点。广谱去除需要材料能够[[吸附]][[短链PFAS|短链 PFAS]]、[[支链异构体]]、替代物和[[全氟和多氟烷基物质前体|前体]]，而不仅仅是长链 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]]。通过调控[[孔径]]和局部化学环境来构建分级结构，可进一步帮助材料容纳[[短链全氟和多氟烷基物质|短链 PFAS]]，同时仍能有效结合[[长链PFAS|长链 PFAS]]。

## 3.3. 可持续性与[[吸附剂重复使用性|可重复使用性]]

分离与[[吸附剂再生|再生]]是决定能否实现大规模应用的关键。尽管许多研究包含[[吸附]]-解吸循环测试，但循环次数通常较少（3–5 次），不足以代表[[吸附剂]]的工程使用寿命。未来的评估应延长测试周期，在可行情况下最好超过 10 次循环，并同时报告再生后的容量衰减和结构完整性。有用的指标包括[[BET|比表面积]]的变化、[[官能团]]的稳定性，以及循环次数与材料寿命之间的关系，这些指标均可为实际应用提供更具定量性的依据。

传统的异位[[吸附剂再生|再生]]方法，无论是高温煅烧还是强酸/强碱洗涤，都会消耗大量能源，可能破坏材料结构，并可能残留分解不完全的产物。因此，原位再生值得更多关注，包括电化学辅助再生和光催化再生。这些方法可在温和条件下恢复[[吸附位点]]的活性，同时还可能将解吸的 [[全氟和多氟烷基物质|PFAS]] 降解或浓缩于少量再生液中，从而减轻下游处理负荷。评估任何再生策略的工程可行性，都需要权衡再生剂或能源的净消耗、解吸液体积以及二次污染风险。

## 3.4. 与其他技术的集成

[[吸附]]可以富集和分离 [[全氟和多氟烷基物质|PFAS]]，但无法将其破坏，若[[饱和吸附]]剂未得到妥善管理，就可能成为二次污染源。为降低环境风险，应将吸附与下游破坏处理相结合，形成富集–降解–[[矿化]]一体化过程。考虑到 PFAS 种类繁多，需要采用分阶段处理方法：前端利用疏水性或亲氟性介质截留[[长链PFAS|长链 PFAS]]，后端则采用化学方法处理穿透前端的[[短链PFAS|短链 PFAS]]。这种分阶段设计可发挥各技术单元的优势：吸附单元浓缩污染物，减轻后续处理负担；破坏单元则可专注于更难降解的[[短链全氟和多氟烷基物质|短链 PFAS]] 的矿化，避免中间产物积累。此外，开发原位耦合工艺可以消除吸附与降解过程之间的界限。例如，将[[吸附剂]]与[[电化学氧化]]、光催化或[[等离子体技术]]相结合，开发兼具高[[吸附容量]]和催化活性的双功能材料，可在[[吸附位点|活性位点]]上同时实现吸附与降解。综合处理工艺需要根据应用场景的要求进行设计。对于[[饮用水]]等低浓度、大水量场景，可将吸附作为主要处理单元，并收集饱和吸附剂进行集中处置；而对于消防训练区地下水或工业废水等高浓度、小水量场景，则可能更适合直接耦合高级氧化还原技术，以实现原位处理和深度氧化。

## 3.5. 环境与法规相容性

高性能 [[PFAS吸附剂|PFAS 吸附剂]]越来越依赖含氟结构域来增强[[亲氟相互作用|亲氟作用]]，并提高对短链或结构多样的 [[全氟和多氟烷基物质|PFAS]] 的捕获能力。尽管这种化学设计有效，却带来了一个不容忽视的矛盾。旨在去除含氟污染物的材料，不能在合成、运行、[[吸附剂再生|再生]]或处置过程中成为含氟污染的二次来源。

[[浸出]]是首要关注的问题。基于 PFPE 的氟凝胶、氟化 [[金属有机框架|MOF]]/[[共价有机框架|COF]]/PAF 连接体以及氟化单体，在长期连续流、强酸/强碱[[吸附剂再生|再生]]、高盐度或富含氧化剂的条件下，可能释放含氟碎片。因此，[[吸附剂]]评价不仅必须追踪目标 [[全氟和多氟烷基物质|PFAS]] 的去除情况，还必须监测总有机氟（TOF）、可提取有机氟（EOF）和可[[吸附]]有机氟（AOF），并辅以靶向 LC-MS/MS 和非靶向筛查。这种严格的质量平衡测定可确保将真正的污染物去除与仅仅重新分配含氟物质负荷的过程区分开来。

持久性与公众接受度构成第二个关注点。[[含氟吸附剂|氟化吸附剂]]在化学性质上不同于受监管的 [[全氟和多氟烷基物质|PFAS]]，其稳定性确实可以成为长期重复使用的优势。即便如此，随着全球监管从限制单一化合物转向禁止大类含氟物质，富含 [[碳氟键|C−F 键]]的材料很可能面临更严格的审查。如果材料中的含氟组分无法被明确证实已得到固定且可回收，那么即使其在实验室中表现优异，在生产、运输、现场应用或废物管理环节仍可能遭遇难以克服的阻力（例如，转向采用非 PFAS 类含氟构筑单元）。

使用寿命终结后的管理也应纳入[[吸附剂]]设计。[[饱和吸附]]剂不能仅因经过解吸就被称为可重复使用，因为[[吸附剂再生|再生]]液会富集 [[全氟和多氟烷基物质|PFAS]]，随后其本身也需要处理。可选方案包括高温焚烧、超临界水氧化、[[电化学氧化]]、等离子体处理、光催化或催化破坏，以及残余固体的安全处置。因此，研发应更加重视非氟化或低[[浸出]][[吸附]]剂、闭环再生，以及能够持续适应日益严格的 PFAS 限制要求的材料。

## 4. 结论与工程路线图

[[全氟和多氟烷基物质|PFAS]] [[吸附]]研究已从传统[[活性炭]]和[[离子交换树脂]]转向更具针对性设计的材料，包括[[超分子主体]]、[[离子型含氟凝胶|离子型氟凝胶]]、[[金属有机框架|MOFs]]、[[共价有机框架|COFs]]、[[多孔芳香框架|PAFs]] 及其他功能性多孔[[吸附剂]]。本综述通过考察界面机制、材料性质、[[分子描述符|PFAS 分子描述符]]与工程运行条件之间的关联，深化了对吸附剂性能的理解。尽管[[吸附容量]]和[[去除效率]]仍是基本指标，但若缺乏对[[基质耐受性]]、[[竞争吸附|混合物竞争]]、动力学、[[吸附穿透行为|穿透行为]]、[[吸附剂再生|再生]]能力和环境相容性的严格评价，这些指标就不足以全面表征吸附剂性能。

图 3. PFAS 吸附剂开发的工程路线图：从描述符指导的设计到符合监管要求的应用部署。

为克服阻碍实验室研究向工业应用转化的挑战，本文提出了一项分为三个战略阶段的工程路线图。短期内（1–3 年），该领域应重点关注机理量化、标准化报告、实际水体验证、绿色合成及[[浸出|浸出风险]]筛查。比较研究应以统一格式报告 [[全氟和多氟烷基物质|PFAS]] 浓度范围、混合物组成、[[pH]]、[[离子强度]]、[[天然有机质|NOM]]、[[吸附剂]]投加量、[[接触时间]]及[[吸附剂再生|再生]]条件。这一阶段能够使数据具有可比性，并揭示哪些材料在简化的实验室体系之外仍能保持性能。中期内（3–5 年），应将重点转向连续流验证、膜–[[吸附]]耦合、可规模化再生、成本分析及生命周期评价。对于更具前景的吸附剂，尤其是针对[[短链PFAS|短链 PFAS]] 或与 [[水成膜泡沫灭火剂|AFFF]] 相关的复杂混合物的吸附剂，柱实验和穿透曲线应成为常规测试。评价再生性能时，不应仅依据容量保持率，还应考察再生剂消耗量、含氟副产物、二次废物体积以及多次循环后的结构完整性。长期内（5–10 年），PFAS 处理应从单一吸附转向捕集–破坏–[[矿化]]一体化系统。吸附可作为浓缩步骤，但持久降低风险取决于能否可靠地破坏所捕集的含氟物质，或对其进行安全处置。因此，未来吸附剂的设计应面向描述符指导的捕集、耐[[水体基质]]干扰的运行、连续流应用、再生或破坏处理的兼容性以及监管认可。此类路线图有助于将先进 [[PFAS吸附剂|PFAS 吸附剂]]从具有前景的实验室材料转变为可持续[[水处理]]系统中切实发挥作用的组成部分。图 3 概述了这一分阶段路径，将描述符指导的吸附剂设计与耐基质干扰的吸附、连续流验证、再生或破坏处理的兼容性以及符合监管要求的应用相衔接。
