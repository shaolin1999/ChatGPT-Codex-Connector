# 一维 [[金属有机框架|MOF]] 衍生[[碳气凝胶]]的开发：具有[[亲氟通道|层级亲氟通道]]，用于[[全氟辛酸]]的方向性纳米[[限域催化]]降解

## 摘要

在[[电芬顿|非均相电芬顿]]（EF）体系中，[[活性氧物种]]（ROS）生成有限、[[活性位点]]暴露不足以及电子传输迟缓共同阻碍了[[全氟辛酸]]（[[PFOA]]）的降解。本文合理设计了一种具有[[亲氟通道|层级亲氟通道]]的一维（1D）Cu-[[金属有机框架|MOF]] 衍生[[碳气凝胶]]，以实现对 PFOA 的[[限域催化|方向性限域催化]]。多尺度孔结构和亲氟界面促进了 PFOA 分子的高效富集和导向传输，从而最大限度地降低了向催化活性位点的扩散阻力。限域微环境加速了界面电子转移，缩短了 ROS 与污染物之间的传质距离，促进了 [[C–F 键]]断裂，并显著提高了 PFOA [[矿化率]]。同时，一维导电框架促进电子传输，并有助于催化剂在催化过程中的结构稳定性。高温煅烧能够精确调控 Cu<sup>+</sup>/Cu<sup>2+</sup> 比例，从而有利于 [[羟基自由基|•OH]] 和 •O₂<sup>−</sup> 自由基的原位生成。值得注意的是，阴极原位生成的 •O₂<sup>−</sup> 可以引发 PFOA [[脱羧]]，实现不依赖阳极的高效单阴极降解过程。即使在复杂水体基质中，该催化剂也表现出优异性能。本研究为设计高效且耐用的全氟污染物修复催化剂提供了一种有力策略。

## 1. 引言

[[全氟烷基和多氟烷基物质]]（PFAS）是一大类合成化合物，其特征是至少含有一个全氟化脂肪族结构单元。由于其优异的化学稳定性、持久性和潜在毒性，即使在痕量水平下，PFAS 也会对人类健康和环境安全构成严重风险 [1,2]。它们在工业和消费品中的广泛使用已导致其在水、土壤和生物体中普遍存在 [3]。典型的长链 PFAS，如[[全氟辛酸]]（[[PFOA]]），在自然条件下表现出极强的抗降解性。这种顽固性源于高度[[电负性]]且强极化的 [[C–F 键]]（\~485 kJ mol<sup>−</sup> <sup>1</sup>），其中中心碳被氟原子的孤对电子紧密屏蔽，形成了对亲核进攻的强大屏障 [4]。因此，开发高效降解和矿化此类持久性有机污染物的策略具有紧迫的重要性。

[[金属有机框架]]（MOFs）是一类多孔配位聚合物，具有超高[[BET|比表面积]]、可调[[孔隙率]]和可调节纳米结构等特点，已成为环境催化领域的多功能平台 [5,6]。由于扩散长度缩短和原子利用率提高，尺寸更小的 MOF 衍生材料通常表现出更优异的催化活性 [7]。特别是，一维（1D）金属有机框架（MOFs）因其定向的质量/电子传输能力和结构稳健性而受到广泛关注。这类结构提供了连续通道，可实现快速的离子/电子转移，从而加速界面反应动力学 [8,9]。例如，Yang 等人报道了一种[[一维 Cu-MOF]]（[[DDA–Cu]]），其具有扩展的 π-d 共轭配位带和高密度氧化还原活性中心，赋予该材料高导电性和加速的电子传输动力学 [10]。此外，一维纳米结构内部的限域微环境提供了线性的各向异性传质路径，能够实现快速轴向传输，同时抑制不希望发生的横向扩散。这种限域作用延长了反应物在催化界面处的停留时间，从而加速反应动力学并抑制寄生副反应 [11]。Lu 等人报道了 [[MIL-53-COOH]] 亚纳米通道可实现碱金属离子和质子的单向超快传输，理论模拟支持其具有超高的质子迁移率 $( 1 1 . 3 \times \bar { 1 0 ^ { - 7 } } \mathrm { ~ m } ^ { 2 } { \cdot } \bar { s ^ { - 1 } } )$ 和低能垒（0.075 eV）[12]。一维 MOFs 结构的高曲率和细长几何形态提高了[[活性位点]]的密度和可及性，同时可能调控表面电子态和界面能，从而调节反应速率和活化能垒 [13]。在多相 Fenton 体系中，这些特性显著提高了[[活性氧物种]]（ROS）的利用效率，从而改善污染物的矿化。

此外，由于一维管状结构独特的限域效应，一维结构能够富集反应物，从而缩短反应物与[[活性位点]]之间的距离，加快污染物的降解。例如，我们课题组通过[[壳聚糖]]衍生的[[分子印迹]]制备了[[氮掺杂碳电极]]，形成了对[[PFOA]]具有特异性的纳米尺度反应域，缩短了[[活性氧物种|ROS]]与[[全氟辛酸|PFOA]]之间的扩散距离。结果表明，该系统在150 min内实现了96.7%的PFOA降解，展示了高选择性的PFOA去除能力[14]。类似地，Cai等人通过调节[[β-环糊精]]负载量来调控催化剂的孔道限域效应，其中限域结构最小的体系在4 min内实现了近100%的$^ { 2 , 4 , 6 }$-[[三氯苯酚]]去除，动力学常数为0.92 m<sup>−</sup> <sup>1</sup>，是非限域体系的5.1倍[15]。这些结果凸显了设计结构稳定的[[限域催化]]剂对于高效降解污染物的重要性。

尽管一维限域纳米反应器具有结构优势，但外部污染物的高效[[吸附]]和定向传质仍然是限制因素。值得注意的是，[[氟掺杂]]已被证明可以增强对[[全氟烷基和多氟烷基物质|PFAS]]（如[[PFOA]]）的亲氟性[16]。Tan等人提出了“氟–氟”相互作用机制，其中氟化区域通过协同的[[疏水效应]]和$\mathrm { ^ { 6 6 } F ^ { \mathrm { _ { 2 } F ^ { \prime \prime } } } }$亲和力选择性地结合[[全氟辛酸|PFOA]]，而亲水但疏油的C–F键则抑制碳氢化合物吸附并增强对PFAS的识别[17]。因此，功能材料中的氟化区域能够与PFAS末端全氟烷基链特异性结合，实现可控识别和富集[18]。与此同时，PFAS降解在很大程度上取决于氟掺杂构型和表面结构。Zhao等人报道，氟的引入会扰乱[[碳骨架]]中的局部电中性，重新分配相邻碳原子之间的电子密度，并增强本征氧化还原活性。定制化的氟化还可以促进$\mathrm { O } _ { 2 }$活化，并有利于*OOH[[脱附]]，从而有利于[[电芬顿|电Fenton]]体系中原位生成$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ [19]。尽管取得了这些进展，但在电Fenton条件下构建一种兼具定向传质、选择性PFAS富集和高效[[活性氧物种|ROS]]利用的亲氟[[限域催化]]环境仍然具有挑战性。

在此，我们开发了一种由一维Cu-[[金属有机框架|MOF]]衍生的亲氟[[碳气凝胶]]。通过[[定向冷冻铸造]]及随后的亲氟改性，形成了分级亲氟纳米[[一维纳米通道|限域通道]]，有利于[[PFOA]]的选择性富集和催化降解。通过整合一维限域、亲氟界面和可调的$\mathrm { C u } ^ { + } / \mathrm { C u } ^ { 2 + }$氧化还原中心，本工作建立了一种协同反应微环境，解决了长期以来[[吸附]]选择性与[[活性氧物种|ROS]]活化之间的权衡问题。值得注意的是，阴极原位生成的$\bullet 0 _ { 2 } ^ { - }$能够有效触发[[全氟辛酸|PFOA]]的[[脱羧反应]]。因此，单阴极[[电芬顿|EF]]体系可在无阳极氧化的情况下实现PFOA降解，从而阐明ROS驱动的活化途径和ROS增强机制。本工作为持久性[[全氟烷基和多氟烷基物质|PFAS]]污染物的催化矿化提供了新的概念框架。

## 2.3 [[一维 Cu-MOF]]-NTs 的制备

具体制备过程如方案 1 所示。在以往方法的基础上，进行了一些改进 [20]。[[一维 Cu-MOF]]-NTs 前驱体通过在室温搅拌下将金属离子与有机配体混合而合成。具体而言，将 [[Cu(OAc)₂]]（70 mM）和 [[H₄DOBDC]]（30 mM）分别溶解于混合溶剂（[[DMF]]:[[CH₃CN]] = 2:1，v/v）中。随后，在持续搅拌下，将 800 μL Cu(OAc)₂ 溶液逐滴加入 3 mL H₄DOBDC 溶液中。室温固化 48 h 后，析出大量浅绿色晶体。收集这些晶体，用 DMF 洗涤并干燥以备进一步使用。将 25 mL 甲醇加入 100 mL 不锈钢高压釜的内衬聚四氟乙烯中。然后在内衬聚四氟乙烯内放置一个 20 mL 小瓶，小瓶倒置。接着，将 10 mg 一维 [[Cu-MOF-NTs]] 前驱体置于小瓶底部。将高压釜在设定时间内加热至不同温度。所得产物用热 DMF 洗涤，并在 150 °C 真空干燥 18 h，得到一维 Cu-[[金属有机框架|MOF]]-NTs（三次重复制备的产率约为 60%）。

## 2.4 [[氟掺杂|F 掺杂]][[一维 Cu-MOF]]@CNF 阴极的制备

为制备 [[氟掺杂|F 掺杂]][[一维 Cu-MOF]]@CNF 阴极，将 0.19 g [[碱性木质素]]溶解于含 1 mL ${ \mathrm { N H } } _ { 3 } { \cdot } { \mathrm { H } } _ { 2 } { \mathrm { O } } ,$ 的 25 g 去离子水中，以 500 rpm 搅拌。随后，将 10 mg 一维 [[Cu-MOF-NTs]] 加入溶液中并分散。然后加入 25 g [[TOCNF]] 悬浮液（1.95 wt%，125 mg TOCNF），与溶液混合 30 min。将混合物超声处理 30 min，以确保均匀分散。将所得[[水凝胶]]（8 g）置于 $3 \times 3$ cm 模具中，采用[[定向冷冻铸造|冰模板法]]进行冷冻铸造 [21]。产物经 $\mathrm { a t } - 6 0 ~ ^ { \circ } \mathrm { C }$ [[冷冻干燥]] 48 h，得到具有取向孔结构的一维 Cu [[金属有机框架|MOF]]@CNF [[气凝胶]]。随后，将 10 g NaF 置于磁坩埚中，同时将两片气凝胶置于另一瓷坩埚中（NaF 与气凝胶的质量比约为 20:1）。将两个坩埚均放入[[管式炉]]中。将气凝胶以 3 °C/min 的速率分别加热至 700 °C、800 °C 和 $9 0 0 ~ ^ { \circ } \mathrm { C } ,$，随后煅烧 2 h，制得 F–1D Cu-MOF@CNF [[碳气凝胶]]。不同温度下碳化的材料分别记为 F–1D Cu-MOF@CNF/C-700、F–1D Cu-MOF@CNF/C-800 和 F–1D Cu-MOF@CNF/C-900。

## 3 结果与讨论

## 3.1. F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C 的表征

我们使用 [[SEM]] 考察了 F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C 合成过程中的表面形貌与微观结构（图 1a-e）。[[Cu-MOF-NTs|1D Cu-MOF-NTs]] 前驱体呈现规则的长方棱柱形貌，表面粗糙（图 1a）。经甲醇蒸气溶解-再结晶策略后，块状 1D Cu-[[金属有机框架|MOF]]-NTs 前驱体转变为由细针状纳米线组成的疏松基体（图 1b），并可清晰观察到具有高长径比的 1D Cu-MOF 纳米线管状结构（图 1c）[22]。图 1d 表明，采用[[定向冷冻铸造|冰模板法]]制备[[气凝胶]]可获得光滑、连续的蜂窝网络结构，使污染物和活性物质能够以“定向”方式迁移，同时改善材料的力学性能。上述现象的另一个可能原因是[[碱性木质素]]组分为材料内部孔道提供了结构支撑。碱性[[木质素]]分子含有丰富的活性基团，包括芳香环（苯及其衍生物）、酚羟基和醇羟基 [23]。这些结构单元通过复杂的[[交联]]形成致密网络。木质素的特性赋予材料耐高温性和刚性结构。经碳化和氟化后，其孔结构保持完整，未发生明显变化。宏观上，氟化样品仍保持良好的层状多孔结构。1D Cu-MOF-NTs 衍生材料均匀生长在气凝胶表面，白色颗粒代表经疏水处理的 [[PTFE]] 纳米颗粒，其不会损害材料的结构性能。为获得具有最优疏水性能的材料，对在三种不同温度下碳化的所有样品均进行了疏水改性。疏水处理前，[[接触角|水接触角]]为 94°。与其他两个温度下碳化的材料相比，在 $8 0 0 ~ ^ { \circ } \mathrm { C }$ 碳化的样品在疏水改性后表现出最大的接触角，展示出优异的[[超疏水性]]（图 1f）。该步骤可通过经典的“疏水-疏水”相互作用实现对 [[PFOA]] 的有效[[吸附]] [24]。

## 3.3. 影响 [[PFOA]] 降解体系的因素及性能优化分析

为确定 [[PFOA]] 主要由单一阴极降解还是由[[阴极-阳极协同降解]]，我们开展了相关实验。图 5a 展示了带[[质子交换膜]]的降解装置的物理结构。在研究阴极-阳极协同降解的实验中，该质子交换膜被移除。图 5b-d 展示了单一阴极、单一阳极以及阴极-阳极协同 $( \mathrm { P t } ,$ GCE) 条件下的[[降解效率]]。对比实验表明，阳极的存在对降解无显著影响。具体而言，在相同条件下（pH = 3），单一阴极体系的降解效率仅比阴极-阳极体系低 2.1%。值得注意的是，在使用[[惰性阳极]]（GCE）的体系中，[[全氟辛酸|PFOA]] 的降解效率与原始阳极体系中观察到的几乎相同，从而排除了阳极氧化对单一阴极体系的影响。基于这些实验验证，在不依赖阳极的情况下即可获得令人满意的降解性能。因此，后续实验仅在单一阴极降解体系中进行，以进一步研究这些条件下影响降解效率的因素。

[[Cu-Fenton反应|Cu-Fenton 反应]]体系比传统 [[Fe-Fenton反应|Fe-Fenton 体系]]更适合大规模实际应用，因为它能够在更宽的 pH 范围内更有效地降解材料 [34]。如图 5b 所示，F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 材料在[[酸性条件]]下 $\left( \mathrm { p H } \right. = \left. 2 \right.$ 和 3）的 [[PFOA]] 降解率分别达到 98.7% 和 99.5%，对应的[[一级动力学常数]]分别为 0.0108 和 $0 . 0 1 6 7 \mathrm { \ m i n } ^ { - 1 }$（图 S3）。在中性 pH 下[[降解效率]]为 78.0%，在[[碱性条件|碱性 pH]]（pH = 7–9）下降解效率为 75.0%，比优化 pH 下低 4.5%。这些结果表明，F–1D Cu-[[金属有机框架|MOF]]@CNF/C-800 材料电极在 [[电芬顿|EF]] 体系中表现出较宽的 pH 适应范围。

[[热解]]温度会影响活性铜物种和 [[氟掺杂|F 掺杂]]，并进一步影响 [[电芬顿|EF]] 体系内 [[PFOA]] 的[[降解效率]]。如 Fig. 5e 所示，在煅烧温度为 ${ 8 0 0 } ^ { \circ } \mathrm { C } ,$ 时，[[全氟辛酸|PFOA]] 降解效率达到 99%，一级动力学速率常数为 $0 . 0 8 1 \mathrm { h } ^ { - 1 }$ 。在[[碳化温度]]为 700 和 ${ 9 0 0 } ^ { \circ } \mathrm { C } ,$ 时，[[一级动力学常数]]分别为 0.013 和 $0 . 0 0 9 \mathrm { \ m i n } ^ { - 1 } ;$ ，均低于 $8 0 0 ~ ^ { \circ } \mathrm { C } .$ 时的数值。这与 [[俄歇电子能谱|AES]] 结果一致，表明在煅烧温度为 $8 0 0 ~ ^ { \circ } \mathrm { C }$ 时 Cu<sup>+</sup> 含量达到最大值（Table S1）。作为负责 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化的主要活性物种，$\mathrm { \Omega } \mathrm { C u } ^ { + }$ 促进了大量[[活性氧物种]]（ROS）的生成，从而显著提高了降解效率。在热解温度为 ${ 9 0 0 } \ { ^ { \circ } } \mathrm { C } ,$ 时，碳化过程中产生的还原性气氛（如 CO 和 H₂）促进 $\mathrm { { C u } ^ { + } }$ 进一步还原为金属 Cu $( \mathrm { C u } ^ { 0 } )$ 。Fig. 5f 显示了 PFOA 降解率随 F 掺杂浓度的变化，这与 [[X 射线光电子能谱|XPS]] 结果一致（Fig. S2g-i），碳化温度从 $7 0 0 ~ ^ { \circ } \mathrm { C }$ 升高至 $9 0 0 ~ ^ { \circ } \mathrm { C } ,$ ，相应的 F 元素含量从 2.9% 上升到 7.4%（Table S2），在 800 ℃ 碳化且 F 掺杂浓度为 4.1% 时降解效率呈现最高值。这归因于氟与碳之间[[电负性]]的差异。将高电负性氟掺杂到多孔碳材料中可调控这些区域的电子构型。这改变了碳材料的电子结构，为电催化氧化还原反应创造了更多位点，从而促进了 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$ 的生成。Fig. S4a 显示，当热解温度升高至 $9 0 0 ^ { \circ } \mathrm { C } ,$ 时，$9 0 0 ^ { \circ } \mathrm { C }$ 处的 [[强度比|ID/IG]] 比值与 800 ℃ 时相比从 1.01 增加到 2.01。这表明过量的 F 掺杂会在[[碳骨架]]中引入更高密度的缺陷，从而降低碳石墨化程度并阻碍电子传递能力。同时，Fig. S4b 所示结果表明，在 900 ℃ 下热解的样品表现出增大的[[电荷转移电阻]]，从而降低了电子转移速率，这与上述 Raman 结果一致。因此，这将降低用于生成 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 的催化氧化还原反应效率，并进一步降低 [[羟基自由基|•OH]] 产率。

为验证 [[活性氧物种|ROS]] 生成对 [[PFOA]] 降解的影响，开展了不同催化体系对 [[全氟辛酸|PFOA]] 的降解实验（Fig. 5g）。在 [[电芬顿|EF]] 体系中，F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 阴极可在 180 min 内降解 99.5% 的 PFOA。相比之下，1D Cu [[金属有机框架|MOF]]@CNF/C-800 在 EF 体系中仅表现出 70% 的 PFOA [[降解效率]]。在向 1D Cu-MOF@CNF/C-800 体系中加入一定量的 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 后，降解效率提高到 81.4%。这表明 ROS 确实提高了降解效率。

然而，[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 体系的催化活性低于 F–1D Cu-[[金属有机框架|MOF]]@CNF/C-800 体系，表明氟的引入加快了 [[PFOA]] 分子全氟尾部的[[吸附]]，从而带来更快的降解速率。为进一步评价 [[氟掺杂|F 掺杂]]前后 F–1D Cu-MOF@CNF/C-800 的性能差异，我们开展了[[电吸附测试]]。如图 5h 所示，F–1D Cu-MOF@CNF/C-800 体系对 [[全氟辛酸|PFOA]] 表现出更强的吸附能力，在 180 min 内比 1D Cu-MOF@CNF/C-800 体系提高了 25%。由于 [[C–F 键]]对 PFOA 全氟链尾部的吸附作用，PFOA 分子被快速吸附进入纳米反应空间。[[活性位点]]上产生的大量 [[活性氧物种|ROS]] 迅速攻击 $\mathrm { \bf P F O A , }$，促进其有效分解。为区分吸附与电化学氧化的贡献，还在[[开路条件]]下进行了吸附实验（图 S5a）。结果表明，在开路条件下，这些材料的[[吸附容量]]约为施加电压条件下的 50%。当施加电压时，PFOA 的去除效率显著提高，说明吸附主要起[[预富集]]步骤的作用，促进 PFOA 在催化剂表面累积，随后进行后续降解过程。

在不同[[电流密度]]下测试了电流对 [[PFOA]] [[降解效率]]的影响（图 5i）。随着电流密度增加，降解速率持续上升，表明较高电流增强了电子转移速率与 [[活性氧物种|ROS]] 的生成，同时活化了更多的催化[[活性位点]]，有利于提高降解效率。该效应在电流密度为 25 ${ \mathrm { m A / c m } } ^ { 2 }$ 时达到最大，当电流密度进一步增加至 30 mA $/ { \mathrm { c m } } ^ { 2 }$ 时开始下降。这可能是由于 4 电子 [[氧还原反应|ORR]]、H<sub>2</sub>O<sub>2</sub> 自分解和 [[羟基自由基|•OH]] 淬灭被加速，从而降低了电流效率 [16]。

[[总有机碳|TOC]] 被视为 [[PFOA]] 降解效果的关键指标。如 Fig. $^ { 6 \mathbf { a } , }$ 所示，TOC 去除率在最初 90 min 内稳步上升，但此后显著升高。这可能归因于反应物分子进入[[纳米限域反应空间]]后被激活，从而加快了反应动力学。[[羟基自由基|•OH]] 和 $\bullet \mathrm { O } _ { 2 } ^ { - }$ 的生成速率超过其消耗速率，导致它们在体系中的浓度迅速增加。最终 TOC 去除率保持在 82%。对体系中 $\mathrm { F ^ { - } }$ 浓度的进一步研究表明，[[脱氟效率]]达到 59%（Fig. 6b）。[[矿化程度]]和[[脱氟]]率未能达到预期结果的可能原因是 [[全氟辛酸|PFOA]] 仅被转化为短链化合物。$\mathtt { A }$ 需要更长的反应时间才能最终将 PFOA 转化为 $\mathrm { C O } _ { 2 }$ 和 $\mathrm { F ^ { - } }$ 。另一方面，部分 $\mathrm { F ^ { - } }$ 被[[吸附]]在电极材料内部，导致溶液中仅能检测到 59% 的 $\mathrm { F ^ { - } }$ 。此外，[[总氟质量平衡]]分析进一步证实了矿化程度与脱氟效率之间差异的原因（Fig.S6a）：在降解过程中，氟原子逐渐在可溶性氟化物、短链中间体及其他瞬时含氟物种之间重新分布。

Table 1 展示了降解 PFOA 最常见的化学方法，包括电-Fenton、光-电-Fenton、活化 PMS 体系以及阳极氧化法 [35–37,39–41]。本工作利用 1D MOFs 构建用于 PFOA 亲和的纳米限域通道。将其负载到碳气凝胶上并经 F 掺杂以构建多重亲氟通路后，99.5% 的 PFOA 可在 3 h 内被降解。相反，活化 PMS 体系在低浓度 PFOA 处理中表现出更优异的性能 [38]。虽然引入高级氧化技术可以提高降解效率，但它们需要专用电极，导致运行时间受限且操作风险升高。

## 3.5. 纳米限域对增强[[活性氧物种|ROS]]产生的贡献

[[活性氧物种|ROS]] 的生成被广泛认为是决定受限纳米反应器内电子转移反应活性的关键因素。为阐明 ROS 的演化路径，采用 [[5,5-二甲基-1-吡咯啉 N-氧化物]]（DMPO）作为 [[羟基自由基|•OH]] 和 •O<sup>−</sup> 物种的自旋捕获探针，并在 [[PFOA]] 于 F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 阴极上降解过程中通过 [[电子顺磁共振|EPR]] 光谱监测其瞬态信号。如图 7a 和 $\mathbf { b } ,$ 所示，观察到对应于 [[DMPO-•OH 加合物]]的特征 1:2:2:1 四重峰，并伴随 [[电芬顿|EF]] 操作下明显的 ${ \bf D M P O - s O _ { 2 } ^ { - } }$ 信号。为定量评估纳米限域对 ROS 生成的影响，进行了绝对定量（[[Brookfield 法]]）。F–1D Cu-[[金属有机框架|MOF]]@CNF/C-800 电极可分别产生 $4 . 1 8 4 \times 1 0 ^ { - 6 }$ 和 3.188 × $1 0 ^ { - 2 }$ M 的 •OH 和 $\bullet { \bf O } _ { 2 } ^ { - }$，分别是 F-Cu-MOF@CNF/C-800 对应物的 3.96 倍和 2.17 倍（图 7d）。鉴于两种材料具有相同的[[氟掺杂]]水平，仅在是否存在[[一维纳米通道]]上存在差异，这些结果明确表明，一维 MOF 衍生的限域通道显著增强了 ROS 生成。这种增强归因于纳米尺度微环境中局部反应物密度增加、空间限域效应增强以及 ROS 寿命延长，这些因素均抑制了自由基的快速复合。此外，还评估了 F 掺杂前后材料的[[电化学活性表面积]]（ECSA）（图 S8）。结果表明，ECSA 值分别为 $0 . { \overset { - } { 2 } } 5 \ \mathrm { c m } ^ { 2 }$ 和 0.33 cm<sup>2</sup>。尽管 F 掺杂后观察到轻微增加，但 ROS 生成的增强幅度显著大于 ECSA 的差异，进一步表明纳米限域通道在该过程中起主导作用。自由基猝灭实验进一步证实了 ROS 介导的降解机制。加入一定量的[[叔丁醇]]（TBA，•OH 猝灭剂）或[[苯醌]]（BQ，•O<sub>2</sub><sup>−</sup> 猝灭剂）显著降低了 [[全氟辛酸|PFOA]] 去除效率（图 7c）。在低猝灭剂（BQ）剂量下，PFOA 的[[降解效率]]为 80%，仅观察到轻微抑制；然而，TBA 导致的抑制明显强于 $\mathbf { B Q } ,$，加入 TBA 后，PFOA 的降解效率降至 20%。这表明 •OH 在 PFOA 分解中起主导作用。即使加入 BQ，降解效率相对于对照也仅降低了 19%，表明 •O<sup>−</sup> 起次要作用。这一现象可能与限域纳米通道提供的较低活化能垒有关，其中丰富的 •OH 自由基直接攻击 PFOA 的 $\scriptstyle \mathrm { C = } 0$ 部分以引发快速[[脱羧]]，绕过了非限域体系中通常所需的 $\bullet \mathrm { O } _ { 2 } ^ { - }$ 介导的吸电子步骤 [42]。纳米限域效应在提高 EF 体系内 PFOA 降解效率方面发挥着关键作用。在纳米限域空间内，污染物的活化能垒降低，从而能够产生大量 ROS 以攻击污染物。当电流达到最佳水平时，纳米限域空间促进电子运动，从而加速涉及两个电子的 [[氧还原反应|ORR]] 反应。该理论实验证实，纳米限域空间显著提高了 F–1D Cu-MOF@CNF/C-800 在 EF 体系中对 PFOA 的降解效率。

## 3.6. F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 在 [[电芬顿|EF]] 体系中降解 [[PFOA]] 的可能途径

为阐明 [[PFOA]] 在 [[电芬顿|EF]] 体系中的降解途径和矿化机理，采用 [[高效液相色谱-质谱联用|HPLC-MS]] 对反应中间体进行了鉴定。如图 S9 和表 S4 所示，主要产物包括短链和长链[[全氟羧酸]]，包括 CF COOH、C F COOH、C F COOH、C F COOH、C F COOH 和 $\mathrm { C _ { 6 } F _ { 1 3 } C O O H }$。较短链物种的逐步出现证实了 [[全氟辛酸|PFOA]] 降解过程中存在逐步的 C–C 键断裂 [43]。

为进一步解释这些观察结果，进行了 [[Fukui 指数]]计算，以确定 [[PFOA]] 最具反应活性的位点。Fukui f(0) 指数反映了对自由基进攻的敏感性，表明[[羧基碳]]（C8）和相邻的[[氟化碳]]（C7）具有最高的反应活性（图 8a）[44]。这支持了从羧基端引发的机理，与 [[高效液相色谱-质谱联用|HPLC-MS]] 检测到的中间体相一致。

基于这些结果，提出了一个三阶段降解机理 $( { \mathrm { F i g } } .$ 8b 和 c）。首先，[[PFOA]] 在 F–[[一维 Cu-MOF|1D Cu-MOF]]@CNF/C-800 阴极的[[亲氟纳米通道]]内富集。同时，$\mathrm { O } _ { 2 }$ 经历双电子还原生成 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } ,$，随后通过 $\mathrm { { C u } ^ { + } }$ 催化分解为 [[羟基自由基|•OH]]。限域环境缩短了 •OH/[[全氟辛酸|PFOA]] 的扩散距离，从而加速了初始降解步骤。在酸性 [[电芬顿|EF]] 条件下 $\mathrm { ( p H } = 3 )$ PFOA 发生去质子化形成 ${ \bf C } _ { 7 } { \bf F } _ { 1 5 } { \bf C } { \bf O } { \bf O } ^ { - } ;$，随后通过 •O<sub>2</sub><sup>−</sup> 进攻转化为 $\mathrm { C _ { 7 } F _ { 1 5 } C O O \bullet }$ 自由基（式 1–2）[45,46]。其次，丰富的 •OH 自由基在纳米通道内进攻 C₇F₁₅COO• 的羧基端，生成 ${ \mathrm { C } } { \mathrm { 7 F } } _ { 1 5 } \bullet$ 自由基。随后氧化生成 $\mathrm { C _ { 7 } F _ { 1 5 } O H }$（式 3–4），其迅速转化为 $\mathrm { C _ { 6 } F _ { 1 3 } C O F }$，然后在 •OH 进攻诱导的 α‑碳位逐步[[脱氟]]作用下转变为 $\mathrm { C _ { 6 } F _ { 1 3 } C O O F }$ H（式 5–6）。该步骤代表第一次[[脱羧]]事件（失去 C8），与 Fukui 预测和 [[高效液相色谱-质谱联用|HPLC-MS]] 检测到 $\mathrm { C _ { 6 } F _ { 1 3 } C O O H } .$ 完全一致。在最后阶段，$\mathrm { C _ { 6 } F _ { 1 3 } C O O H }$ 经历与 PFOA 类似的由 •OH 驱动的反复脱羧和脱氟循环，逐步生成更短的全氟物种，直至完全矿化为 CO₂ 和 $\mathrm { F ^ { - } }$（式 7）

## 4. 结论

本研究采用负载[[一维 Cu-MOF]]-NTs 阵列的 [[TOCNF 气凝胶]]支架构筑排列良好的纳米通道。随后的[[高温碳化]]在不同键合状态下引入可控量的氟，制备了具有分级[[亲氟通道]]的 F–1D Cu-[[金属有机框架|MOF]]@CNF/C-800 阴极。一维结构提供了连续的电子传输路径、扩大的传质界面和定向限域，实现了污染物的快速富集并加速了[[界面氧化还原反应]]。多级氟亲和通道促进了 [[PFOA]] 在纳米反应域中的选择性[[吸附]]，而优化的 Cu $\dot { \gamma } _ { \mathrm { C u } ^ { 2 + } }$ 比例可高效活化 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 以产生丰富的 [[活性氧物种|ROS]]。[[氟掺杂]]的一维阴极显著提高了[[吸附容量]]和 $\mathrm { O } _ { 2 }$ 转化效率。值得注意的是，构建纳米[[一维纳米通道|限域通道]]所产生的 [[羟基自由基|•OH]] 和 $\bullet \mathrm { O } _ { 2 } ^ { - }$ 分别是非氟化一维类似物的 3.96 倍和 2.17 倍。在 180 min 内，[[全氟辛酸|PFOA]] 的[[降解效率]]和[[矿化率]]分别达到 99.5% 和 82.0%。该单阴极体系在多种操作条件下均表现出稳定的降解性能，支持其实际适用性。总体而言，本工作展示了一种可行的 [[PFAS 修复]]策略，即通过整合一维结构限域与分级亲氟通道来强化 ROS 生成和污染物活化。
