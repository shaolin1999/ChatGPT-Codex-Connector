# 具有[[模量匹配|模量相容性]]和增强[[界面相互作用]]的高强高韧[[双网络水凝胶]]

## 摘要

[[双网络策略]]是制备高[[力学性能]][[水凝胶]]的经典方法。然而，[[刚性聚合物]]与[[柔性聚合物]]之间较差的[[模量匹配|模量相容性]]会导致[[刚性网络]][[应力集中]]和不可逆断裂，最终限制水凝胶的适用性。在此，我们提出一种通过调控[[聚乙烯醇]]与[[纤维素纳米纤维]]之间的[[模量]]相容性并增强其[[界面相互作用]]，制备高强高韧[[双网络水凝胶]]的策略。[[单宁酸]]的引入不仅能够降低双网络水凝胶中CNF刚性网络的模量，还能增强两个网络之间的[[非共价相互作用]]，从而改善力学性能。所得水凝胶表现出高达39.7 ± 1.7 MPa的[[拉伸强度]]和155.2 $\pm 2 . 5 \mathrm { M J } \mathrm { m } ^ { - 3 }$ 的优异[[韧性]]。此外，该双网络水凝胶还具有优异的[[断裂能]]、[[抗疲劳性]]和[[生物相容性]]。本研究为设计可用于[[生物医学应用]]的高强高韧水凝胶提供了一条切实可行的途径。

## 1 引言

[[水凝胶]]具有优异的[[生物相容性]]和可调控的功能性 [1]，有望广泛应用于[[组织工程]] [2]、[[软体致动器]] [3] 和[[可穿戴电子器件]] [4]。然而，水凝胶固有的较差[[力学性能]]仍严重制约着其实际应用 [5]。目前已提出多种增强策略来改善其力学性能，例如引入[[氢键]] [6–8]、形成[[结晶域]] [9–21]、构建[[超分子]] [22, 23]、[[双网络策略|双网络（DN）]]、[[机械拉伸]] [6, 24–26] 以及[[相分离]] [27–30]。其中，由 [[Gong]] 等人首次开发的[[双网络水凝胶]]能够同时提高强度和[[韧性]] [31]。典型的 DN 水凝胶由两个性质截然不同的[[互穿聚合物网络]]组成：刚性且[[交联]]密集、易于断裂的第一网络，以及柔软、具有[[延展性]]且交联稀疏、能够保持整体结构完整性的第二网络 [32]。在[[拉伸应力]]作用下，DN 水凝胶表现出特征性的[[颈缩]]前阶段、颈缩阶段和[[应变硬化|应变硬化阶段]]序列，在此过程中，第一网络逐渐发生[[化学键断裂]]和[[渗流式断裂]]，而第二网络持续伸展，并最终主导大[[应变]]下的硬化响应 [33]。然而，双网络之间较差的[[模量匹配|模量匹配性]]阻碍了颈缩阶段的有效[[应力传递]]，使得高应力第一网络内部断裂所释放的应力无法有效重新分配至第二网络 [34]。

这种低效的[[应力传递]]会促进[[应力集中|局部应力集中]]和不可逆的[[分子链断裂]]，这些损伤在[[循环载荷]]作用下不断累积，导致性能加速衰退且恢复能力受限 [35]。

在此，我们提出了一种可规模化制备高强高韧[[双网络水凝胶]]的策略。柔软的[[聚乙烯醇]]（PVA）和刚性的[[纤维素纳米纤维]]（CNF）均匀分布于整个双网络[[水凝胶]]中。通过引入[[单宁酸]]（TA）降低 CNF 的[[模量]]，确保双网络之间的[[模量匹配]]。此外，TA 还可同时增强水凝胶的[[界面相互作用]]。所得双网络水凝胶表现出优异的[[力学性能]]，包括高达 $3 9 . 7 \pm 1 . 7 \mathrm { { \ : M P a } }$ 的[[拉伸强度]]、155.2 $\pm 2 . 5 \mathrm { M J } \mathrm { m } ^ { - 3 }$ 的出色[[韧性]]、$1 0 0 0 \pm 2 0 \%$ 的[[极限应变]]以及 $2 6 . 2 \pm 1 . 7 \ \mathrm { k J \ m ^ { - 2 } }$ 的[[断裂能]]。此外，该水凝胶具有卓越的[[抗冲击性能]]和[[能量吸收|能量吸收能力]]。同时，该水凝胶还具有优异的[[疲劳阈值]] $( 9 1 0 . 2 \mathrm { ~ J ~ m ~ } ^ { - 2 } )$ 和[[生物相容性]]。本研究为解决合成水凝胶材料高强度与高韧性之间的矛盾提供了一条新途径。

## 2 结果与讨论

## 2.1 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]的制备

图 1a 展示了用于构建水凝胶的聚乙烯醇（PVA）、纤维素纳米纤维（CNF）和单宁酸（TA）的化学结构（图 S1 和 S2）。选择柔性 PVA 是因为其链构象、聚集态和结晶度可调 [17, 19]。刚性 CNF 能够与金属离子配位 [36–38]。两者共同构成了水凝胶中力学性质不同但相互协同的两个网络。TA 可与金属离子发生配位相互作用 [39, 40]，因此具有调节 CNF 网络力学性能的潜力。此外，PVA、CNF 和 TA 上丰富的羟基（-OH）有利于形成广泛的氢键，从而增强水凝胶内部的界面相互作用。

图 1b 示意了双网络 PVA/CNF/TA 水凝胶的制备过程。为确保三价铁离子 $\mathrm { ( F e ^ { 3 + } ) }$ 与 CNF 之间均匀交联，采用了超铺展制备策略 [41–43] 来构建 CNF 网络。PVA 与 CNF 的稀混合反应溶液能够在空气中迅速且完全地铺展于预先浸入氯化铁溶液的微滤膜表面（图 S3）。与此同时，反应溶液层立即凝胶化，这是由于 $\mathrm { F e } ^ { 3 + }$ 离子从微滤膜扩散至反应溶液层，并与 CNF 的羧基（COO<sup>−</sup>）而非 PVA 发生交联所致（图 S4 和 S5）。由此制得了由线性 PVA 和配位交联 CNF 组成的双网络。退火是改善 PVA 基水凝胶力学性能的一种有效策略 [21]。随后，对双网络 PVA/CNF 凝胶再次进行退火，以调节聚合物链的构象，使结构致密化（图 S6）。之后，将 PVA/CNF 凝胶浸入 TA 溶液中。作为低分子量聚合物，TA 能够容易地渗入网络并与 $\mathrm { F e } ^ { 3 + }$ 离子交联（图 S7 和 S8）。将所得水凝胶浸泡于大量去离子水中以去除残留 TA 分子后，成功制得了双网络 PVA/CNF/TA 水凝胶。

## 2.2 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]的[[力学性能]]

通过[[拉伸试验]]研究了 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]的[[力学性能]]。通过优化水凝胶的制备工艺和组成，我们获得了兼具优异强度 $\left( 3 9 . 7 \pm 1 . 7 \mathrm { { M P a } } \right)$、[[韧性]]（155.2 $\pm \ 2 . 5 \ \mathrm { M J \ m ^ { - 3 } } )$ 和[[拉伸应变]] $( 1 0 0 0 \pm 2 0 \% )$ 的 PVA/CNF/TA 水凝胶，同时保持了接近 70% 的[[含水量]]（图 2a,b；图 S9–S13 和表 S1–S4）。扭转拉伸后的 PVA/CNF/TA 水凝胶所呈现的大变形也证明了其出色的力学性能（图 2c）。同时，进行了[[循环加载-卸载拉伸试验]]，以评估 PVA/CNF/TA 水凝胶的[[能量耗散|能量耗散能力]]（图 2d；图 S14）。在拉伸[[应变]]逐步增大的连续循环加载过程中，水凝胶耗散的能量从应变为 50% 时的 $0 . 2 ~ \mathrm { M J ~ m } ^ { - 3 }$ 急剧增加至应变为 500% 时的 $8 . 2 \mathrm { \ M J \ m } ^ { - 3 }$，表明有效的能量耗散能够使 PVA/CNF/TA 网络增韧。此外，在固定拉伸应变为 50% 的循环加载过程中观察到了[[力学滞后]]现象（图 2e；图 S15）。第一个循环中耗散的能量为 $2 7 5 . 0 \ \mathrm { k J \ m } ^ { - 3 }$，到第 200 个循环时降至 $4 8 . 6 \mathrm { k J } \mathrm { m } ^ { - 3 }$，表明 PVA/CNF/TA 水凝胶中的[[牺牲键]]（主要为[[可逆氢键]]）在变形过程中发生了断裂。第 200 个循环中的最大应力仍保持在 1.5 MPa，表明尽管部分[[交联点]]受到损伤，该水凝胶在反复变形过程中仍能有效避免[[应力集中]]引起的[[材料失效]]。

为验证 [[单宁酸|TA]] 在[[水凝胶]]中的重要性（图 1a），对不同配方水凝胶（纯 [[聚乙烯醇|PVA]]、PVA/[[纤维素纳米纤维|CNF]]、PVA/CNF/TA 和 PVA/CNF/TA-no Fe）的[[力学性能]]进行了评估，结果见图 2a,b。PVA/[[CNF水凝胶|CNF 水凝胶]]的[[拉伸强度]]为 $3 0 . 6 \pm 2 . 0 \ \mathrm { M P a }$，[[极限应变]]为 798 $\pm \ 1 2 \% ,$，[[杨氏模量]]为 $1 0 . 0 \pm \ : 0 . 5$ MPa，[[断裂韧性]]为 $1 1 6 . 2 \pm 3 . 0 ~ \mathrm { M J } ~ \mathrm { m } ^ { - 3 }$。引入 TA 后，PVA/CNF/TA 水凝胶的拉伸强度和[[韧性]]分别提高至原来的 1.30 倍和 1.34 倍。相比之下，杨氏[[模量]]降至原来的 0.56 倍，表明 TA 在提高水凝胶的力学强度和韧性方面发挥了关键作用。将 CNF 水凝胶浸入 TA 溶液后，CNF/TA 的模量降低，表明 TA 能够减少 CNF 的[[交联点]]并增强链的柔性，从而实现[[柔性网络]]与[[刚性网络]]之间的[[模量匹配]]（图 S16）。[[原子力显微镜]]（AFM）相位图进一步证实了这一发现（图 S17）。此外，PVA/CNF/TA 水凝胶实现了最高的[[断裂能]]，达到 $2 6 . 2 \pm 1 . 7 \ \mathrm { k J \ m ^ { - 2 } }$（为纯 [[PVA水凝胶|PVA 水凝胶]]的 6.2 倍、PVA/CNF 水凝胶的 2.3 倍），凸显了材料组成设计的有效性（图 2f；图 S18）。此外，PVA/CNF/TA 水凝胶表现出最高的[[热分解温度]]，为 $2 8 5 . 3 ^ { \circ } \mathrm { C } ,$，表明多组分设计也提高了其[[热稳定性]]（图 S19）。

## 2.3 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]的力学增韧机制

为揭示其内在增韧机制，对 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]组成单元内的分子相互作用进行了细致研究。[[FTIR|傅里叶变换红外光谱]]（FT-IR）显示了 PVA/CNF 和 PVA/CNF/TA 水凝胶的特征吸收带（图 3a）。PVA/[[CNF水凝胶|CNF 水凝胶]]在 1581 cm<sup>−1</sup> 处的特征峰源于 CNF 的 C═O 伸缩振动，该峰红移至 1577 cm<sup>−1</sup>，表明 CNF 与 TA 之间形成了[[氢键]]。TA 的 C═O 伸缩振动在 PVA/CNF/TA 水凝胶中由 1701 cm<sup>−1</sup> 移至 1704 cm<sup>−1</sup>。这一蓝移表明，TA 的 C═O 基团充当[[氢键受体]]，使 C═O 键增强 [6]。TA 对羟基的影响也十分明显。-OH 伸缩振动峰由 PVA/CNF 中的 3290 cm<sup>−1</sup> 移至 PVA/CNF/TA 中的 3239 cm<sup>−1</sup>。由于氢键会降低相关力常数并引起红移 [7]，这一位移证实了 TA 诱导形成了更强的氢键。此外，PVA/CNF/TA 中更宽的 -OH 伸缩振动带表明氢键环境的分布更广，反映出引入 TA 后原有 PVA [[氢键网络]]的破坏与重组 [6]。这一观察结果与 [[XRD]] 分析一致，后者显示，加入 TA 后 PVA [[晶区尺寸]]略有减小（图 S20）。还进行了拉曼光谱分析，以揭示分子环境的变化（图 3b）。PVA/CNF/TA 中 -CH（1444 $\mathsf { c m } ^ { - 1 } )$ 和 -CH（2914 cm<sup>−1</sup>）的强度降低，表明 PVA 的[[结晶度]]下降，说明 PVA 链的规整堆积受到破坏 [6]。此外，C═O 振动强度降低表明引入 TA 后形成了氢键，这与 FT-IR 的结果相互印证。均匀的组分分布也有利于 PVA/CNF/TA 水凝胶的增强和增韧（图 S21）[13, 21]。水凝胶横截面的 EDS [[元素分布]]图显示，C、O 和 Fe 元素均匀分布于整个水凝胶中。

通常，[[双网络水凝胶|DN 水凝胶]]由一个刚性、密集[[交联]]的网络和一个柔软、疏松交联的网络组成 [32]。受到[[拉伸应力]]时，[[刚性网络]]首先承载并发生取向，随后[[柔性网络]]排列取向 [33]。为进一步探究增韧机制，研究了 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]在预设[[拉伸应变]]下的微观结构演变。如图 3c 所示，位于 19.3<sup>◦</sup> 和 22.3<sup>◦</sup> 的两个峰分别对应于 PVA 的 (101) 晶面和 CNF 的 (200) 晶面。通过分峰拟合（图 S22），得到的 PVA 和 CNF 对应的方位角（φ）曲线均在 φ = 90<sup>◦</sup> 和 270<sup>◦</sup> 处呈现两个尖锐峰（图 3d,e）。对于 PVA，取向有序参数（f）从[[应变]]为 0 时的 0.635 增加至应变为 400% 时的 0.907，并在进一步变形时保持平台。对于 CNF，f 在 0%–100% 应变范围内急剧上升。当应变超过 200% 时，f 进入平台期。该平台持续至应变达到 400%，此后 f 随应变逐渐增加（图 3f；图 S23 和表 S5）。引入 TA 后，刚性 CNF 网络的[[模量]]降低，而刚性 CNF 网络与柔性 PVA 网络之间的[[氢键]]作用显著增强。因此，更致密的 PVA 链在变形过程中优先取向并呈现显著排列，随后诱导 CNF 的二次排列取向。这种[[顺序取向机制]]有效促进了水凝胶的增强和增韧。

## 3 结论

总之，我们提出了一种制备[[双网络水凝胶]]的简便方法。[[模量匹配]]、增强的[[界面相互作用]]以及拉伸诱导的取向协同赋予[[水凝胶]]卓越的[[力学性能]]，包括优异的[[拉伸强度]]、出色的[[韧性]]和良好的[[抗冲击性能]]。此外，该水凝胶的[[生物相容性]]和可调节的功能使其成为[[可穿戴柔性应变传感器]]的有前景的候选材料。该策略为以通用且高效的方式制备高强高韧双网络水凝胶开辟了一条途径。

## 4 材料与实验方法

## 4.1 材料

购得的[[聚乙烯醇]]（PVA，分子量 14600–18600，水解度 99+%，Sigma-Aldrich）、[[纤维素纳米纤维]]（CNF，ScienceK）、[[单宁酸]]（TA，ACS 试剂，Sigma-Aldrich）和[[无水氯化铁]]（AR，99%，Macklin）均未经额外纯化而直接使用。实验所用溶剂为[[去离子水]]。

## 4.2 反应溶液的制备

将[[去离子水]]中的 [[聚乙烯醇|PVA]] 固体颗粒加热至 110<sup>◦</sup>C，并剧烈搅拌 6 h，得到 8 wt% 的 PVA 溶液。将 PVA 溶液、[[纤维素纳米纤维|CNF]] 溶液和去离子水按不同比例混合，超声处理 10 min 以去除气泡，得到 PVA/CNF 反应溶液。将 [[单宁酸|TA]] 粉末溶于去离子水中，配制成所需浓度的溶液。

## 4.3 [[聚乙烯醇|PVA]]/[[CNF水凝胶|CNF 水凝胶]]的制备

首先，将[[微滤膜]]分别预先浸入 0.3、0.5、0.7、1.0 和 1.2 m 的[[氯化铁]]（FeCl ）溶液中。并将一定量不同浓度的 FeCl 溶液逐滴滴加到微[[微孔滤膜|滤膜]]表面。随后，将 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]] 反应溶液倒在微滤膜上，在微滤膜表面形成均匀的溶液层。CNF 经 Fe<sup>3+</sup> [[离子交联]]，使含 PVA 的液层转变为薄膜。在[[水浴]]中浸泡后，该薄膜可轻易地从[[水凝胶]]表面剥离。随后，将[[水凝胶薄膜]]置于 [[聚四氟乙烯|PTFE]] 薄膜上，并在 30<sup>◦</sup>C 的空气烘箱中干燥 24 h。干燥后，将薄膜在[[去离子水]]中浸泡 30 min，随后置于 100<sup>◦</sup>C 烘箱中处理 90 min，得到 PVA/CNF [[干凝胶]]。将干凝胶浸入去离子水中，使其充分溶胀，即可获得 PVA/[[CNF水凝胶|CNF 水凝胶]]。作为对照，采用相同方法制备了 PVA、CNF 和 PVA/CNF-no Fe 水凝胶。其中，PVA 和 PVA/CNF-no Fe 水凝胶仅通过将 PVA 溶液倒入模具中干燥而获得。

## 4.4 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]] [[水凝胶]]的制备

将 [[聚乙烯醇|PVA]]/[[CNF水凝胶|CNF 水凝胶]]在 [[单宁酸|TA]] 溶液中浸泡不同时间。随后，将其浸入[[去离子水]]中，使其充分溶胀，得到 PVA/[[纤维素纳米纤维|CNF]]/TA [[水凝胶]]。作为对照，采用相同方法制备了 PVA/CNF/TA-no Fe、CNF/TA 和 PVA/TA。

## 4.5 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]]/[[单宁酸|TA]]-Casting [[水凝胶]]的制备

将 [[聚乙烯醇|PVA]]/[[纤维素纳米纤维|CNF]] 反应溶液倒入 [[聚四氟乙烯|PTFE]] 模具中，并在 30<sup>◦</sup>C 的空气烘箱中干燥 24 h。随后，将[[干凝胶]]浸入 1.0 m 的[[氯化铁]]（FeCl ）溶液中，再置于 100<sup>◦</sup>C 烘箱中处理 90 min，得到 PVA/CNF-casting 干凝胶。将干凝胶浸泡于 [[单宁酸|TA]] 溶液中，随后浸入[[去离子水]]中，使其充分溶胀，得到 PVA/CNF/TA-casting [[水凝胶]]。

## 4.14 [[纯剪切测试]]

[[水凝胶]]的[[断裂能]]通过[[纯剪切测试]]获得。对带缺口和无缺口样品进行[[单轴拉伸]]。断裂能可通过式（2）计算：

$$
\Gamma = H U (\lambda_ {c})\tag{2}
$$

其中，H 为两个夹具之间的初始距离，$\lambda _ { c }$ 为带缺口样品中裂纹开始扩展时的[[临界应变]]，$U ( \lambda _ { c } )$ 表示无缺口样品在[[应变]]为 $\lambda _ { c }$ 时[[应力-应变曲线]]下的积分面积。

## 4.15 [[疲劳测试]]

## 4.18.1 [[细胞计数试剂盒-8]]（CCK-8）测试

将[[水凝胶]]置于[[完全培养基]]（100 mg/mL）中，在 $3 7 ^ { \circ } \mathrm { C }$ 和 5% CO 条件下孵育 24 h，随后用 0.22 µm [[微孔滤膜|滤膜]]过滤，制备[[水凝胶浸提液]]。将 [[NIH-3T3细胞|NIH-3T3 细胞]]以 $4 \times 1 0 ^ { 3 } / \mathrm { w e l l }$ 的密度接种于 [[96孔板|96 孔板]]中。[[细胞贴壁]]后，将原培养基替换为 100 L 水凝胶浸提液。孵育 1、3 和 5 d 后，按照制造商说明，使用 [[细胞计数试剂盒-8|CCK-8 检测试剂盒]]（IV08-100, [[Invigentech]], USA）评估[[细胞活力]]。采用[[酶标仪]]测量 450 nm 处的[[吸光度]]。使用仅含 CCK-8 试剂和培养基的空白组进行[[基线校正]]。细胞活力通过式（3）计算：

$$
\text { Cell viability } (\%) = \frac {O D _ {\mathrm{test}} - O D _ {\mathrm{blank}}}{O D _ {\mathrm{control}} - O D _ {\mathrm{blank}}} \times 100 \%
$$

(3)

其中，$O D _ { \mathrm { t e s t } } , O D _ { \mathrm { b l a n k } }$ 和 $O D _ { \mathrm { c o n t r o l } }$ 分别表示测试组、空白组和对照组在 450 nm 处的[[吸光度]]值。

## 4.18.2 活/死细胞染色测试

## 4.19 [[应变传感器]]传感性能的表征

将[[水凝胶]]浸入 0.3 m CaCl 溶液中，并用 [[VHB 4910 胶带|4910 VHB 胶带]][[封装]]以防止水凝胶[[脱水]]，两端连接[[铜箔]]作为[[电极]]，制得[[应变传感器]]。通过将传感器固定在人体不同部位，研究其传感能力。使用 [[Keithley 6487 皮安计]]检测人体运动引起的[[电阻]]变化。[[相对电阻变化]]可通过公式（4）计算：

$$
\Delta R / R _ {0} = (R _ {r} - R _ {0}) / R _ {0}\tag{4}
$$

其中，$R _ { r }$ 为实时[[电阻]]，$R _ { 0 }$ 为无[[应变]]时的初始电阻。[[应变灵敏系数]]（GF）通过公式（5）计算：

$$
\mathrm{GF} = (\Delta R / R _ {0}) / \varepsilon\tag{5}
$$

其中，ε 表示[[应变]]。
