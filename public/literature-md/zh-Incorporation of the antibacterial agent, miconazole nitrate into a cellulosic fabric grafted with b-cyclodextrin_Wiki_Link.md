# 将[[抗菌剂]][[硝酸咪康唑]]引入[[接枝]]有 [[β-环糊精|b-环糊精]]的[[纤维素织物]]

[[Jun-hua Wang]] <sup>\*</sup>, [[Zaisheng Cai]]

中国上海，[[东华大学化学与化工学院]]，[[教育部生态纺织科学与技术重点实验室]]，20, 1620

2007 年 8 月 21 日收稿；2007 年 10 月 1 日收到修订稿；2007 年 10 月 22 日接受；2007 年 11 月 4 日在线发表

## 摘要

本研究旨在探讨将[[抗菌剂]][[硝酸咪康唑]]引入[[共价键合]]于织物纤维上的[[环糊精]]空腔中。通过与[[一氯三嗪基β-环糊精|一氯三嗪基 b-环糊精]]（MCT-[[β-环糊精|b-CD]]）反应，将 b-环糊精分子[[接枝]]到[[纤维素织物]]上。研究发现，适宜的键合反应条件为：MCT-b-CD 60–100 g/L，[[催化剂]] Na CO 50–60 g/L，反应温度 150–160 -C，反应时间 5–8 min。

采用[[紫外分光光度法]]对改性和未改性织物进行表征。采用 [[高效液相色谱法|HPLC]] 测定织物中包载的[[硝酸咪康唑]]含量，发现经 [[一氯三嗪基β-环糊精|MCT-b-CD]] 功能化的织物中硝酸咪康唑含量（0.458% w/w）远高于未改性织物（0.056% w/w）。采用[[振荡烧瓶法]]测定[[抗菌性能|抗菌能力]]，结果表明，经硝酸咪康唑[[浸渍]]后，[[一氯三嗪基β-环糊精接枝织物|MCT-b-CD 接枝织物]]的抗菌性能显著增强。即使洗涤 10 次后，整理织物仍保持 70% 以上的抗菌能力，而未改性织物的抗菌活性几乎完全丧失。

关键词：[[硝酸咪康唑]]；[[一氯三嗪基β-环糊精|一氯三嗪基 b-环糊精]]（MCT-[[β-环糊精|b-CD]]）；[[接枝]]；[[抗菌纺织品]]

## 1. 引言

[[环糊精]]是一类呈环面形状的[[环状低聚糖]]，具有[[亲水性]]外表面和[[疏水空腔|疏水性内部空腔]]，可根据[[亲脂性化合物]]的尺寸和[[分子结构]]，将大量此类化合物包载于其疏水空腔中。环糊精[[包合作用|包合]][[疏水性化合物]]的卓越能力已在多个领域得到利用，涵盖从药品到化妆品、从食品制造到日用商品等领域（Jimenez Sanchez, 1997; Nakajuma & Hirobasbi, 1984; Vaios, Karathanos, & Ioammis Mourtzinos, 2007）。在纺织领域，通过将 [[β-环糊精|b-环糊精]]永久固定于织物上而实现的[[棉织物]]新型[[表面改性|功能性表面处理]]正受到越来越多的关注（Buschmann, Denter, & Knittel, 1988; Wang & Chen, 2004, 2005）。一些文献表明，将环糊精固定于棉上不会影响[[纤维素]]的亲水性能，且[[环糊精固定化|固定化环糊精]]的空腔仍保有与其他分子形成[[包合物]]的[[络合能力]]（Buschmann, Denter, & Knittel, 1995; Lo Nostro & Frantoni, 2002）。

在我们此前的工作中，发现[[硝酸咪康唑]]与 [[β-环糊精|b-环糊精]]能够形成[[包合物]]。使用[[黏合剂]]将制备的[[包合作用|包合]]物整理到[[棉织物]]上，可以获得[[抗菌纺织品]]，但遗憾的是，处理后的织物较为僵硬。如果不使用黏合剂，而是将改性 b-[[环糊精]][[共价键合]]（[[接枝]]）到织物表面，则可能克服[[织物手感|手感]]不佳的问题。

本研究介绍了将[[一氯三嗪基β-环糊精|一氯三嗪基 b-环糊精]]（MCT-[[β-环糊精|b-CD]]）[[接枝|化学接枝]]到[[纤维素织物]]上的方法。选择 MCT-b-CD 是因为其可从商业渠道获得，且无刺激或致敏作用（Reusher &

Hinsenkorn, 1996）。它平均含有两到三个[[一氯均三嗪基]]，能够与[[亲核基团]]（如[[纤维素]]中的 [[羟基|–OH]]）形成[[共价键]]，因此是纺织品[[表面改性]]的有效工具（Denter & Schollmeyer, 1996; Lo Nostro, Frantoni, & Ridi, 2003）。选择[[硝酸咪康唑]]作为[[抗菌剂]]，是因为其具有安全、高效和[[广谱抗菌]]的特性，可发挥杀菌、消炎和止痒等作用（[[国家药典委员会|National pharmacopeia committee]], 2006）。此外，本研究还报道了将硝酸咪康唑[[包合作用|包合]]于[[接枝]]在纺织品表面的 [[β-环糊精|b-CD]] 空腔中，并随后评价了整理后纺织品的[[抗菌性能]]。

## 2.3. [[纤维素织物]]与 [[一氯三嗪基β-环糊精|MCT-b-CD]] 的[[接枝]]

[[一氯三嗪基β-环糊精|MCT-b-CD]] 是一种能够与[[亲核基团]]形成[[共价键]]的反应性[[环糊精]]。以下将 MCT-[[β-环糊精|b-CD]] 键合到[[纤维素织物]]上的方法是在 Rehmann, Yoshii, and Furuta（2003）的方法基础上建立的。

操作步骤（图 3）如下：在室温和[[磁力搅拌]]条件下，将织物试样（通常为 4 cm · 4 cm）浸入含有 [[一氯三嗪基β-环糊精|MCT-b-CD]]（80 g/L）和[[催化剂]] $\mathrm { N a } _ { 2 } \mathrm { C O } _ { 3 } \ : ( 5 0 \ : \mathrm { g / L ) }$ 的水溶液中 5 min（[[浴比]]为 1:20）。随后挤压试样以除去多余溶液，使[[轧余率]]达到 70–80%，并在[[真空干燥箱]]中于 $5 0 ~ ^ { \circ } \mathrm { C }$ 下[[真空干燥]]。为尽量减少 MCT-[[β-环糊精|b-CD]] 与空气中水分的反应，将[[浸渍]]后的试样置于烘箱中，在常压（干热）条件下于 $1 5 0 ~ { ^ \circ C }$ [[焙烘]] 3 min，以进行[[热固着反应]]。随后将所得织物用流动水洗涤 10 min，以除去所有未反应的 MCT-b-CD，并于 $6 0 ~ ^ { \circ } \mathbf { C } .$ 下真空干燥 8 h。通过测定织物试样在上述固着过程前后的质量差，估算键合到[[纤维素织物]]上的 MCT-b-CD 的量。为方便起见，下文将键合了 MCT-b-CD 的[[纤维素]]织物称为 [[一氯三嗪基β-环糊精接枝织物|MCT-b-CD-fabric]]。

## 2.4. 用[[硝酸咪康唑]][[浸渍]][[接枝]][[棉织物]]

将改性和未改性织物样品浸入含有 5%（w/v）[[硝酸咪康唑]]的[[乙醇]]溶液中，[[浴比]]为 1:10，在室温下搅拌处理 2 h，以进行[[抗菌剂]]处理。随后将样品轧压，并用 30%（v/v）[[乙醇水溶液|乙醇–水溶液]]洗涤三次，以去除织物表面[[吸附]]的抗菌剂，再用流动自来水冲洗 10 min。采用[[分光光度分析]]对改性和未改性织物以及[[浸渍]]硝酸咪康唑的样品进行表征。

## 2.5. 从织物中[[溶剂提取|提取]][[硝酸咪康唑]]

从[[浸渍]][[硝酸咪康唑]]的改性和未改性织物样品上裁取 $( 2 . 5 \mathrm { c m } \times 2 . 5 \mathrm { c m } )$ 的布片，以制备[[溶剂提取|提取]]液。将布条精确称重，剪成小片，加入[[乙醇]]（10 mL），在 $7 0 \ { } ^ { \circ } \mathrm { C }$ 下搅拌提取 10 min。使用新鲜溶剂重复提取，合并乙醇提取液并定容至 20 mL。取部分所得[[悬浮液]]，经 0.45 lm [[膜过滤器]]过滤，并采用下述 [[高效液相色谱法|HPLC]] 方法分析硝酸咪康唑。

## 2.6. 采用 [[高效液相色谱法|HPLC]] 分析[[包合作用|包合]]的[[硝酸咪康唑]]

[[高效液相色谱法|HPLC]] 仪器由 [[LabFlow 3000泵|Model LabFlow 3000 泵]]、配有 $1 0 ~ \mu \mathrm { L }$ [[定量环]]的 [[7125进样阀|Model 7125 进样阀]]，以及设定在 318 nm 的 [[975-UV可变波长检测器|Model 975-UV 可变波长 UV–vis 检测器]]组成。使用个人计算机上的 [[Borwin]] 软件完成[[数据采集]]和处理。采用 [[701注射器|Model 701 注射器]]（10 lL）进行样品进样。使用 5-lm [[Zorbax SB-CN色谱柱|Zorbax SB-CN 色谱柱]]（150 mm · 3.0 mm）进行分离，以[[甲醇]]–[[乙腈]]–水（40:25:35，v/v/v）为[[流动相]]，在 0.4 mL/min 的流速下进行[[等度洗脱]]。色谱分析在室温下进行。通过与正品[[标准物质]]进行[[共色谱分析]]，确认[[硝酸咪康唑]][[色谱峰]]的归属。采用[[外标法]]，通过对[[峰面积积分]]进行定量。

## 2.7. 负载[[硝酸咪康唑]]织物的[[抗菌性能]]

按照 [[振荡烧瓶法|Downing 振荡烧瓶法]]测定不同织物样品的[[抗菌性能]]。选取三种真菌——[[白色念珠菌]]、[[金黄色葡萄球菌]]和[[大肠杆菌]]，研究[[浸渍]]于织物中的[[硝酸咪康唑]]的抗菌性能。此外，为研究抗菌性能的持久性，还测试了[[抗菌纺织品|抗菌织物]]在 60 -C 下用 2 g/L 皂液洗涤 0、5 和 10 次后的[[耐洗性]]，每次洗涤 10 min。

## 3. 结果与讨论

## 3.1. [[一氯三嗪基β-环糊精|MCT-b-CD]] 改性织物的表征

将普通[[棉织物]]或经 [[一氯三嗪基β-环糊精|MCT-b-CD]] 功能化的织物（图 3）负载[[硝酸咪康唑]]，仔细冲洗（见第 2 节），然后进行[[分光光度分析]]（图 4）。

为避免谱线重叠并提高图的清晰度，将[[紫外光谱]]沿垂直方向错开排列。含有 5.0% [[硝酸咪康唑]]的[[乙醇]]溶液（空心圆）在 272、280 和 318 nm 处呈现出典型峰。未经处理的织物样品（方形）在 220 至 360 nm 之间几乎没有吸收。仅涂覆硝酸咪康唑的织物（菱形）在 318 nm 处出现主峰，表明硝酸咪康唑的存在。[[接枝]] [[一氯三嗪基β-环糊精|MCT-b-CD]] 后，织物（空心倒三角形）在低于 280 nm 的波长范围内表现出显著吸收，在约 230 nm 处达到最大值，这是由[[三嗪基发色团]]引起的（Lo Nostro et al., 2003）。经硝酸咪康唑处理的 MCT-[[β-环糊精|b-CD]] 接枝样品（粗线，实心圆）在较低波长处呈现出 [[一氯三嗪基β-环糊精接枝织物|MCT-b-CD 接枝织物]]的典型峰，同时硝酸咪康唑的主峰发生小幅红移，移至 322 nm（见图 4）。这一红移可归因于硝酸咪康唑所处环境的[[疏水性]]增强，并提示硝酸咪康唑与 MCT-b-CD 在织物表面形成了[[主客体包合物]]。

## 3.2. 影响织物上 [[一氯三嗪基β-环糊精|MCT-b-CD]] 结合量的因素

通过重量法测定织物上的 [[一氯三嗪基β-环糊精|MCT-b-CD]] 含量。

织物上 [[一氯三嗪基β-环糊精|MCT-b-CD]] 的结合量主要取决于 MCT-[[β-环糊精|b-CD]] 浓度、[[催化剂]]浓度、[[焙烘]]温度和焙烘时间。

水溶液中 [[一氯三嗪基β-环糊精|MCT-b-CD]] 的浓度影响其在织物上的结合量，如图 5 所示。观察到结合量随浓度增加而近似线性增加。

图 6 显示了催化剂浓度对织物上 MCT-b-CD 结合量的影响。织物的增重率随 $\mathbf { N a } _ { 2 } \mathbf { C O } _ { 3 }$ 浓度的增加而升高。但当 ${ \bf N a } _ { 2 } { \bf C O } _ { 3 }$ 浓度超过 60 $\mathrm { g } / $ L 时，增重率下降。其原因可能是 MCT-b-CD 在较高 pH 下发生水解。

温度的影响如图 7 所示。在 100 至 $1 8 0 ^ { \circ } \mathrm { C } .$ 之间，[[一氯三嗪基β-环糊精|MCT-b-CD]] 的结合量与加热温度近似成正比。然而，高温可能损伤织物，并使织物白度降低。因此，150–160 °C 是适宜的温度范围。

还研究了[[热处理]]时间。处理时间越长，织物上[[硝酸咪康唑]]的结合量越多。图 8 展示了增重率随时间延长的变化趋势。

综合上述影响因素，我们得到适宜的键合反应条件，即 [[一氯三嗪基β-环糊精|MCT-b-CD]] 60–100 g/L、$\mathbf { N a } _ { 2 } \mathbf { C O } _ { 3 }$ 50–60 g/L、反应温度 $1 5 0 { - } 1 6 0 ^ { \circ } \mathrm { C }$、反应时间 5–8 min。

## 3.3. 采用 [[高效液相色谱法|HPLC]] 分析[[浸渍]]到织物中的[[硝酸咪康唑]]含量

为了定量测定不同织物（未改性[[棉织物]]和 [[一氯三嗪基β-环糊精接枝织物|MCT-b-CD 织物]]）中实际负载的[[硝酸咪康唑]]含量，从织物试样中[[溶剂提取|提取]][[抗菌剂]]硝酸咪康唑，并采用 [[高效液相色谱法|HPLC]] 进行测定。考察了影响硝酸咪康唑从纺织材料中释放的若干参数，包括不同的液体溶剂（即[[甲醇]]、[[乙醇]]、[[乙腈]]）、采用搅拌或超声处理、提取温度和时间。在 $7 0 ^ { \circ } \mathrm { C } ,$ 下，以乙醇为溶剂，在[[磁力搅拌]]条件下对织物连续提取两次、每次 10 min，得到的硝酸咪康唑含量最高。为评估从织物中提取硝酸咪康唑的回收率，将按上述方法处理后的试样用乙醇进行索氏提取，提取时间为 6 h。纺织材料中残留的硝酸咪康唑不足总含量的 9.3%（通过索氏提取和 HPLC 分析测定），表明该方法的提取效率令人满意。在[[浸渍]]硝酸咪康唑的未改性织物中，抗菌剂浓度为 $( 0 . 0 5 6 \pm 0 . 0 1 3 ) \% \ \mathrm { ( w / w ) }$，而在 [[一氯三嗪基β-环糊精|MCT-b-CD]] 织物中测得的浓度为 $( 0 . 4 5 8 \pm 0 . 0 7 2 ) \% \ \mathrm { ( w / w ) }$。硝酸咪康唑测定结果的较大离散性可能归因于织物表面结构的不均一性。此外，根据生产商的产品规格说明，一个[[环糊精]]大环上可结合一个或多个（两个或三个）[[三嗪基]]（图 2）。由于与纺织纤维中存在的[[亲核基团]]（如[[羟基]]、[[氨基]]）发生反应的是三嗪基上的[[氯原子]]（图 3），因此[[主体分子]]与织物之间的锚定臂数量也可能有所不同。然而，与未改性织物相比，MCT-[[β-环糊精|b-CD]] 织物的抗菌剂保留能力显著增强（增至 8.2 倍）。

## 3.4. 处理后织物的[[抗菌性能]]

采用 2.4 节所述方法可获得[[抗菌纺织品|抗菌织物]]。采用[[振荡烧瓶法]]测试其[[抗菌性能|抗菌能力]]，结果如图 9 所示。

由图 9 可见，[[一氯三嗪基β-环糊精接枝织物|MCT-b-CD 织物]]的[[抗菌性能|抗菌活性]]远高于未改性织物。这一现象是由[[抗菌剂]]在织物上的存在形式不同所致。对于 [[一氯三嗪基β-环糊精|MCT-b-CD]] 织物，抗菌剂被[[包合作用|包合]]在 [[β-环糊精|b-CD]] 的空腔中。而对于未改性织物，抗菌剂通过物理[[吸附]]附着，因此容易在洗涤时从织物上脱除。由此，前者的[[抗菌耐久性]]远优于后者。即使经过 10 次洗涤，MCT-b-CD 织物的[[抗菌率]]仍保持在 70% 以上，而未改性织物的抗菌活性几乎完全丧失。此外，对[[白色念珠菌]]的抗菌活性略优于对[[金黄色葡萄球菌]]和[[大肠杆菌]]的抗菌活性。

## 4. 结论

本研究结果表明，采用 [[一氯三嗪基β-环糊精|MCT-b-CD]] 对纺织品进行整理，可提高织物材料对[[抗菌剂]][[硝酸咪康唑]]的吸收量，从而增强服装面料的[[抗菌性能]]。此外，[[β-环糊精|b-CD]] 与纺织纤维的[[共价键合|共价结合]]提高了被[[包合作用|包合]]抗菌剂的[[耐洗性|耐洗涤性能]]，延长了织物的抗菌效果。将[[环糊精]][[接枝|化学接枝]]到[[棉纤维]]上，是生产抗菌服装的一种有效策略。
