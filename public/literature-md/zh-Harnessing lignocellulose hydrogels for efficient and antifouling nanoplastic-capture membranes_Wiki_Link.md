## 摘要

[[木质纤维素]]对环境自我修复不可或缺，其固有的多级异质性可被用于实现对特定污染物的优异固定化。本研究将木质[[纤维素]]简便地解离为其组分[[纳米纤丝]]，并转化为结构可调的[[水凝胶]]，该水凝胶在捕获广泛存在的水体[[纳米塑料]]（[[纳米颗粒|NPs]]）方面表现出高效性。我们采用多尺度集成方法，揭示了[[木质纤维素水凝胶]]的拓扑结构和[[流变行为]]如何调控[[胶体纳米颗粒|胶体 NPs]] 的传输动力学。基于这一理论基础，可按需制备木质纤维素水凝胶，实现对广谱 NPs 的高效去除（>95%），同时[[水通量]]超过 70 L/m²⋅h。此外，用可重构木质纤维素水凝胶对石油基滤膜进行功能化，克服了传统[[超滤]]在捕获水体纳米颗粒方面的关键局限，即低效率、[[膜污染]]和[[二次污染]]。另外，我们提出了一种低环境风险且经济有效的废载 NPs 木质纤维素水凝胶处置策略，即将其作为增强剂和增塑剂整合到[[纸浆纤维]]中，制备高强度、耐水且热稳定的模塑制品。总之，我们的工作提出了一种可行的木质纤维素基解决方案，以应对 NPs 超滤中的关键挑战。

## 1. 引言

目前的估计表明，在一切照旧的情景下，进入水生生态系统的塑料废物量可能增至三倍（Stegmann et al., 2022），从2016年的900万至1400万吨上升至2040年估计的2300万至3700万吨/年（Lau et al., 2020）。一旦释放到环境中，塑料废物在物理、化学和生物因素的共同作用下会逐步破碎为[[微塑料]]（<5 mm），并进一步破碎为[[纳米塑料]]（[[纳米颗粒|NPs]]，<1 μm）（McDevitt et al., 2017）。NPs的固有风险因其两个关键特性而显著放大：其微小尺寸有助于穿透生物屏障（Sharma et al., 2022），以及其大[[BET|比表面积]]可促进共存污染物的[[吸附]]（Seewoo et al., 2024）。越来越多的证据证实人类广泛暴露于NPs，除在超过95%的粪便样本中检出外（Lee et al., 2025），还在人体胎盘（Lamoree et al., 2025）和大脑（Murugadoss et al., 2020）等系统性部位中被检出。这种系统性分布令人担忧，因为NPs具有诱导[[氧化应激]]（MacLeod et al., 2021）和炎症的潜力——这些是关键机制，可导致器官损伤（Li et al., 2020）。一项涵盖14个国家的调查证实了NPs在水源中的普遍存在，81%的自来水样本检测呈阳性——这一发现引发了重大的公共卫生关切（Zhou et al., 2018）。在[[自来水处理]]中应用[[超滤]]技术去除NPs受到聚合物膜固有的三方面缺陷制约：即对亚微米颗粒的截留效率不足（Liu et al., 2021; Zhang et al., 2021）、对快速污染的显著易感性且被各种NPs进一步加剧（Maeng et al., 2018; Tong et al., 2023），以及通过膜清洗和材料降解悖论性地引发[[二次污染]]（Li et al., 2025b; Zou and Lee, 2022）。这凸显了对高性能、抗污染过滤材料的迫切需求，以可持续地从自来水中捕获NPs。

[[木质纤维素]]作为一种天然过滤材料，兼具[[物理筛分]]和[[化学吸附]]功能（Cheng et al., 2024; Yu et al., 2025）。这种双重功能使其成为水净化（Xiao et al., 2025）、食品加工（Dong et al., 2025; Li et al., 2025c）和生物医学应用（Ghosal and Ghosh, 2023; Hasan et al., 2025）领域的长效解决方案。此外，通过自上而下的生物化学-物理方法对木质[[纤维素]]多尺度结构进行靶向调控，可将其定制为更理想的材料，用于高效分离多种物质（例如颗粒（Zhu et al., 2023）、分子（Lepp¨anen et al., 2022）和离子（Jiang et al., 2023）），这一过程受可调的结构-性能关系所支配。至关重要的是，将生物相容且可回收的木质纤维素材料整合到传统[[超滤]]系统中，为缓解石油基替代品所带来的[[二次污染]]和[[膜污染]]风险提供了一种有前景的解决方案（Jiang et al., 2024）。我们最近的研究展示了通过由植物源[[纳米纤维素]]制备的自支撑薄膜从水分散液中收集[[纳米塑料|NPs]]——这是一种环保的石油基膜替代方案——随后将这些负载[[纳米颗粒|NPs]]的纳米纤维素薄膜后加工为高性能纳米复合材料。该工作流程由此构建了一条连贯的“废物变财富”路径，涵盖从靶向污染物修复到木质纤维素生物质多层面升级利用的全过程。研究进一步证实，[[纳米纤丝|木质纤维素纤丝]]的拓扑结构（Marakana et al., 2021）、表面化学（Chen et al., 2024; Wang et al., 2023）和组装行为（Chen et al., 2018; Petridis and Smith, 2018）决定了其捕获NPs的功效和选择性。传统纳米薄膜过滤器通常需要高跨膜压力来驱动纳米颗粒的超滤，且其结构可调性有限、自适应性差，使其极易发生局部污染（Xiao et al., 2026）。相比之下，具有优异自适应性的[[水凝胶]]过滤器能够实现水传输，其扩散系数接近纯水的扩散系数，从而产生低水力阻力，同时通过协同筛分、扩散和[[吸附]]有效截留微米和纳米颗粒（Jiang et al., 2024）。木质纤维素纤丝具有优异的凝胶化能力，可通过物理缠结和分子间相互作用轻易形成稳定的黏弹性网络。然而，合理利用[[木质纤维素水凝胶]]构建有效、抗污染且高通量的NPs超滤系统在很大程度上仍未被探索。

在此，我们开发了一种结构可调的[[木质纤维素水凝胶]]，能够以可持续的方式实现对多种[[纳米塑料|NPs]]的高性能、抗污染和高通量[[超滤]]。将[[反应性DES|反应性低共熔溶剂]]（[[低共熔溶剂|DES]]）预处理与浓度调控相结合，可精细调控[[水凝胶|木质纤维素水凝胶]]中的拓扑网络和传输动力学，从而在保持高通量的同时实现[[纳米颗粒|NPs]]的高效拦截。将可重构且流变稳定的[[木质纤维素]]水凝胶按需组装于石油基超滤膜上，可实现增强的NPs捕获并减轻不可逆污染。此外，负载NPs的木质[[纤维素]]水凝胶可容易地从超滤膜上解离，并与[[纸浆纤维]]整合，制备兼具合成聚合物和天然聚合物优点的可模塑复合材料。我们将高强度、耐水且热稳定的复合材料制成一系列用户友好的餐具，展示了其实际应用性。总体而言，我们提出了一种涵盖收集、封装和利用的“[[闭环修复]]”策略，有效解决了传统超滤在捕获水中纳米颗粒方面的关键局限，即低效率、[[膜污染]]和[[二次污染]]（图1）。

## 2. 结果与讨论

## 2.1. 结构可调的[[木质纤维素纳米纤丝|LCNFs]]

[[木质纤维素水凝胶]]的[[尺寸排阻]]和水渗透性受其组成[[纳米纤丝|木质纤维素纤丝]]（[[木质纤维素纳米纤丝|LCNFs]]）的主要物理化学性质——即尺寸和表面化学——所支配，这些性质最终决定了组装[[水凝胶]]网络的结构。在此，我们开发了一种[[反应性DES]]体系，通过同时破坏[[氢键]]并引入带电基团，将[[木质纤维素]]解纤为结构可调的[[木质纤维素纳米纤维|LCNFs]]。如图2a所示，[[低共熔溶剂|DES]]的组分——作为氢键供体的[[四乙基氢氧化铵]]和作为受体的[[N,N'-二甲基脲]]——破坏了固有的氢键网络并水解了[[木质素-碳水化合物复合物]]，从而松解了天然木质[[纤维素]]的多级异质结构。通过引入[[静电排斥]]进一步促进了木质纤维素的解纤，该[[静电相互作用|静电排斥]]是通过[[环氧丙基三甲基氯化铵]]（GTAC）的开环反应将[[季铵基团]]接枝到其羟基上实现的。图2b表明，随着DES处理时间的延长，木质纤维素的溶胀逐渐增加。随后对DES处理后的木质纤维素进行[[机械处理]]，得到横向尺寸分别为粗、中、细的LCNFs，分别命名为LCNF-C、LCNF-M和LCNF-F。如图2c所示，LCNF-C、LCNF-M和LCNF-F的平均直径分别为210.64、60.88和8.48 nm。此外，延长DES处理时间导致LCNF横向尺寸分布变窄。[[聚合度]]从787（LCNF-C）逐渐降低至663（LCNF-M）并进一步降至612（LCNF-F），表明DES处理还能控制LCNFs的纵向尺寸（图2d）。然而，[[XRD]]数据（图S1）表明，DES处理未引起所得LCNFs结晶域或[[结晶度指数]]（50%−56%）的显著改变。总体而言，所开发的DES体系能够制备具有明确拓扑特征同时保留天然纤维素骨架的LCNFs。

除了诱导形态变化外，[[低共熔溶剂|DES]] 预处理还改变了 [[木质纤维素纳米纤丝|LCNFs]] 的化学组成和官能性。图 2e 显示，与前驱体[[木质纤维素]]相比，[[木质纤维素纳米纤维|LCNFs]] 的[[木质素]]和[[半纤维素]]含量降低，[[纤维素]]含量相应增加，表明 DES 预处理部分去除了无定形组分（尤其是木质素）。此外，随着处理时间的延长，该过程逐渐更为有效。图 2f 表明，木质素、纤维素和半纤维素的 characteristic peaks 在 [[纳米纤丝|LCNFs]] 中基本得以保留，证明经 DES 和[[机械处理|机械加工]]后木质纤维素结构保存良好。-OH 伸缩带（3000–3600 cm⁻¹）的强度随 LCNF 尺寸减小而增加，这与更高的纤丝化程度以及因此更丰富的暴露羟基相关。对 [[FTIR]] 光谱中 -OH 伸缩区的去卷积（图 S2）显示，与前驱体木质纤维素相比，LCNFs 具有更多的游离 -OH 基团和分子间[[氢键]]，而分子内氢键减少。这种氢键重构意味着解纤使木质纤维素表面在界面相互作用方面更具活性。此外，LCNFs 在 1489 和 1419 cm⁻¹ 处表现出明显的[[傅里叶变换红外光谱|红外吸收峰]]，分别归属于铵基中 N–H 的弯曲振动和 C–N 键的伸缩振动。这一结果与反应性 DES 处理将[[季铵基团]]引入木质纤维素纤丝的预测一致。[[XPS]] 光谱（图 2g）证实，LCNF-C、LCNF-M 和 LCNF-F 中氮含量依次增加，这与反应性 DES 处理的剧烈程度直接相关。高分辨 N 1 s 核心能级光谱（图 S3）定量显示，从 LCNF-C 到 LCNF-M 再到 LCNF-F，-N<sup>+</sup>(CH<sub>3</sub>)<sub>3</sub> 基团的相对原子浓度逐渐增加，同时伴生天然胺/酰胺物种。此外，LCNF-C、LCNF-M 和 LCNF-F 上 [[环氧丙基三甲基氯化铵|GTAC]] 对木质纤维素的[[取代度]]分别达到 0.075、0.134 和 0.177（表 S1），证明反应性 DES 处理中季铵化的可调性。木质纤维素经季铵基团官能化后，[[Zeta电位|zeta 电位]]从 −20.0 mV 显著转变为 34.9–44.1 mV 范围（图 2h）。相应地，[[表面电荷密度]]从 0.4 meq/g 增加到 1.29–1.78 meq/g。LCNFs 的带电表面是其组装体结构均匀性和稳定性的关键驱动因素。

## 2.3. [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]对[[纳米塑料]]的捕获

鉴于[[纳米塑料|NPs]]是普遍存在的新兴污染物，具有多样的化学性质和难降解特性，我们开展了一系列相关情景下的修复实验，以系统评估[[木质纤维素纳米纤丝|LCNF]]/[[聚偏氟乙烯|PVDF]][[复合滤膜]]的广谱捕获效率。图4e展示了在不同pH和离子条件下，过滤器对不同类型、尺寸和初始浓度的NP的[[去除效率]]。与原始PVDF膜相比，[[木质纤维素纳米纤维|LCNF]]/PVDF复合膜在去除一系列[[纳米颗粒|NPs]]方面表现出显著增强的效果，包括[[聚对苯二甲酸乙二醇酯|PET]]、[[聚苯乙烯|PS]]、[[聚甲基丙烯酸甲酯|PMMA]]、[[聚乙烯|PE]]、[[聚丙烯|PP]]和阳离子型[[氨基化聚苯乙烯|PS-NH₂]]。值得注意的是，[[纳米纤丝|LCNF]]-M/PVDF和LCNF-F/PVDF复合材料对测试的NPs均表现出约90%的高去除效率，证明了它们的广谱捕获能力。此外，不同NPs的去除效率遵循以下顺序：PET $> \mathrm { P S } > \mathrm { P M M A } > \mathrm { P E } > \mathrm { P P } > \mathrm { P S } \mathrm { - N H _ { 2 } }$。这一趋势可以通过NPs与带正电荷的LCNF[[水凝胶]]之间的[[静电相互作用]]和次级相互作用的联合效应来解释。所有带负电荷的NPs都受到LCNFs的[[静电相互作用能|静电]]吸引，从而具有高去除效率；PET具有最负的[[zeta电位]]（−42.0 mV）（表S3），表现出最高的去除率，而带正电荷的PS-NH₂（+35.9 mV）受到[[静电排斥]]，表现出最低的去除率，这与经典的电荷依赖性相互作用规律完全一致。然而，在带负电荷的NPs中，仅靠静电作用无法完全解释它们去除率的差异，因为它们的[[ζ电位|zeta电位]]相似。相反，去除效率与NPs的[[氢键]]能力呈正相关。PET富含酯基、羟基和羧基，与LCNFs形成了广泛的氢键网络，表现优于PMMA和PS；PE和PP完全缺乏氢键供体/受体，仅依赖弱[[疏水相互作用]]，因此表现出较低的去除效率。值得注意的是，[[水接触角]]与去除效率之间未观察到简单的单调相关性：高度疏水的PP（106.2◦）和PE（103.5◦）以及相对亲水的PS-NH<sub>2</sub>（69.8◦）均处于去除效率范围的低端，证实了静电和氢键相互作用而非一般疏水性主导了NPs的捕获过程。LCNF-M/PVDF和LCNF-F/PVDF膜在50–500 nm尺寸范围内对PET纳米颗粒均保持90%以上的过滤效率。相比之下，LCNF-C/PVDF膜的去除效率显著较低，为46.9%−61.4%。此外，较大的PET纳米颗粒被更有效地去除，突显了[[物理筛分]]在NPs捕获中的主导作用。LCNF-M和LCNF-F显著更高的NPs截留率可归因于它们更有利的拓扑结构，这由更小的孔径（7.8–13.5 nm，而LCNF-C为30.0 nm）和更大的[[BET|比表面积]]$( 1 4 6 . 4 - 1 5 0 . 2 ~ \mathrm { m } ^ { 2 } / \mathrm { g } ,$ vs. $1 2 0 . 4 ~ \mathrm { m ^ { 2 } / g } ) ~ ( \mathrm { F i g . ~ 3 d } ) .$所证实。这些特征形成了更曲折的纳米多孔水凝胶网络，通过[[尺寸排阻]]和[[界面截留]]的组合显著增强了NPs的截留。

[[去除效率]]对[[纳米塑料|NPs]]浓度表现出非线性依赖关系，并在某一中间值处达到峰值。这种非单调行为可归因于两种相互关联的机制：(1) 随着[[纳米颗粒|NPs]]浓度增加，跨膜压力升高，促进形成更致密的[[滤饼层]]，从而在初期提高截留率。然而，超过临界浓度后，过度积累可能导致凝胶层结构变形，从而降低截留能力；(2) 在较低浓度下，主要去除机制涉及NPs通过[[静电相互作用能|静电]]及其他非共价次级相互作用[[吸附]]到[[木质纤维素纳米纤丝|LCNFs]]的[[活性位点]]上。一旦NPs水平超过吸附容量，活性位点饱和，使过量纳米颗粒得以通过，导致去除效率下降。除NPs的固有性质外，还考察了环境条件对去除效率的影响。NPs的最佳去除出现在中性pH（7）条件下，碱性条件下的效率优于酸性条件。带负电荷的[[聚对苯二甲酸乙二醇酯|PET]]纳米颗粒在酸性条件下去除率略有降低，这可归因于[[木质纤维素纳米纤维|LCNFs]]上质子化官能团的静电屏蔽作用。[[纳米纤丝|LCNF]]/[[聚偏氟乙烯|PVDF]]复合材料即使在竞争性阴离子和阳离子（例如NO₃⁻、HCO₃⁻、SO₄²⁻、K⁺、$\mathrm { C a } ^ { 2 + } )$，浓度高达600 $\mathrm { { \ m m o l / L } } ,$）的干扰下，仍保持稳定的PET去除效率，展现出对实际NPs捕获的强大环境兼容性。与其他竞争离子相比，$S O _ { 4 } { } ^ { 2 - }$表现出相对更强的干扰效应，这是由于其通过屏蔽[[静电相互作用]]，具有更强的能力削弱带负电荷NPs与带正电荷LCNFs之间的[[界面粘附]]。值得注意的是，LCNF[[水凝胶]]在复杂环境条件下对具有多样理化性质的广泛NPs实现了高去除效率，凸显了[[物理筛分]]在NPs捕获中的主导作用。

为进一步评估[[超滤]]膜在复杂水基质中的实际适用性，考察了其在代表性[[溶解性有机物]]（例如[[牛血清白蛋白|BSA]]、[[富里酸|FA]]和[[腐殖酸|HA]]）和无机[[纳米颗粒]]（例如$S \mathrm { i O } _ { 2 } ,$、[[高岭土]]和$\mathsf { A l } _ { 2 } \mathsf { O } _ { 3 } )$）存在下的[[纳米塑料|NPs]][[去除效率]]。如Figure S12所示，溶解性有机物的存在使NPs去除效率略微降低2.3%−6.3%，表明存在 mild 抑制作用。在所测试的溶解性有机物中，HA表现出最明显的抑制作用，这可合理归因于其非均相芳香结构和丰富的含氧官能团，可能

影响 [[纳米塑料|NPs]] 的[[化学吸附|界面吸附]]与聚集行为。相比之下，无机[[纳米颗粒]]的共存总体上提高了 NPs 的表观[[去除效率]]，这可能归因于 NPs 与共存颗粒之间的[[异聚]]（heteroaggregation），从而促进[[超滤]]膜的[[尺寸排阻]]作用。此外，还在加标 NPs 的自来水、湖水和河水中测试了去除效率（图 S13）。在自来水中去除性能基本保持不变（~90%），而在湖水和河水中均观察到轻微上升。这一行为可能与这两类天然水体中复杂的共存基质有关（表 S4），其推测有助于超滤膜对 NPs 的[[物理筛分]]和化学[[吸附]]。总体而言，[[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]的引入有效解决了传统超滤膜在从自来水和天然水体中捕获广谱 NPs 方面的局限性，即效率低和易污染。

[[聚偏氟乙烯|PVDF]] 复合膜。为阐明在 [[复合滤膜|LCNF/PVDF 复合膜]]中观察到的通量下降现象，将 [[Hermia模型|Hermia 模型]]应用于实验数据（Feng et al., 2025）。该模型通过区分四种物理机制被广泛用于表征[[膜污染]]（图 5b）：[[标准堵塞]]（Ks）、[[完全堵塞]]（Kc）、[[中间堵塞]]（Ki）和[[滤饼过滤]]（Kcf）。相应的控制方程及每种机制的描述分别见 Text S1 和表 ${ \bf 5 5 , }$。如图 5c 所示，[[木质纤维素纳米纤丝|LCNF]]-M/PVDF 复合膜对含 [[纳米塑料|NPs]] 水的过滤行为在整个过滤过程中始终以 Ki 模型描述最佳，即使 [[纳米颗粒|NPs]] 浓度增加也是如此。对 Ki 模型的遵循表明，NPs 主要积累在孔入口处或[[吸附]]在孔壁上。因此，[[木质纤维素纳米纤维|LCNF]]-M/PVDF 复合膜在整个过滤期间保持了相对稳定的[[水通量]]。相比之下，[[纳米纤丝|LCNF]]-F/PVDF 复合膜对含 NPs 水的过滤动力学表现出主导机制随浓度变化的转变。在低 NPs 浓度下，其行为由 Ki 模型准确描述。随着浓度增加，主导机制依次转变为 Ks 模型，最终转变为 Kcf 模型。这种从 Ki 到 Ks 再到 Kcf 的依次转变，解释了所观察到的通量下降：NPs 对孔的部分封闭演变为通过孔壁吸附造成的内部收缩，最终在膜表面形成二次过滤层（[[滤饼层|滤饼]]），构成了主要的水力阻力。[[水凝胶]]层内 NPs 分布的对比（图 S14）进一步证实了 LCNF-M/PVDF 和 LCNF-F/PVDF 膜在面对高浓度 NPs 时表现出的不同过滤行为，这归因于它们不同的拓扑结构（图 3）。LCNF-M/PVDF 膜的[[共聚焦成像]]显示，被拦截的 NPs 在整个水凝胶中呈现弥散荧光，而 LCNF-F/PVDF 膜则在上部区域呈现集中荧光，反映出显著的 NPs 富集。这些结果共同表明，通过调控 LCNF 水凝胶中构成原纤维的形貌和表面化学性质来对其拓扑结构进行精细调控，对于实现 NPs 截留与水渗透之间有利的权衡至关重要。值得注意的是，尽管孔相关拦截路径的演变增加了水力阻力，但在 LCNF 水凝胶内由此形成的致密富 NPs 区域同时增强了 NPs 截留，从而进一步减轻了下层 PVDF 膜的不可逆污染。

我们进一步采用 [[XDLVO理论|XDLVO 理论]]（Li et al., 2025b）通过量化 [[木质纤维素纳米纤丝|LCNF]] 基质与 [[纳米塑料|NPs]] 之间的界面相互作用能，来阐明特定孔道堵塞的机制（Text S2）。Fig. 5d 揭示，在测试的浓度范围内，[[木质纤维素纳米纤维|LCNFs]] 与 [[PET纳米颗粒|PET 纳米颗粒]]之间的相互作用为净吸引。[[总相互作用能]] $( \mathbf { U } ^ { \mathrm { T O T } } )$ 主要由[[酸碱相互作用能|酸碱贡献]] $( \boldsymbol { \mathrm { U } } ^ { \mathrm { A B } } )$ 主导，[[Lifshitz-van der Waals相互作用|Lifshitz-van der Waals]] $( \mathrm { U } ^ { \mathrm { L W } } )$ 和[[静电相互作用能|静电]] $( \mathrm { U } ^ { \mathrm { \bar { E } L } } )$ 相互作用的贡献较小。$\mathrm { U } ^ { \mathrm { A B } }$ 组分可能源于特定的短程相互作用，主要是 [[纳米纤丝|LCNFs]] 表面羟基与 [[聚对苯二甲酸乙二醇酯|PET]] 上极性部分（如其酯基和 π 电子云）之间的[[氢键]]和偶极-偶极作用力。$\mathrm { U } ^ { \mathrm { A B } }$ 在介导[[界面粘附]]中的主导地位，支撑了 LCNFs 对 [[纳米颗粒|NPs]] 的广谱捕获能力。需要强调的是，LCNF-F 与 PET 之间的总体 $\check { \mathrm { U } } ^ { \mathrm { T O T } }$ 相比 LCNF-M 与 PET 之间的相应作用较弱。降低的界面相互作用增强了 PET 在 LCNF 基质内的迁移性，促进重排并导致[[标准堵塞]]机制的出现。最终，随着 NPs 浓度增加，这些动力学过程促进了 LCNF-F [[水凝胶]]中[[滤饼过滤]]行为的形成。

鉴于 [[木质纤维素纳米纤丝|LCNF]]-M/[[聚偏氟乙烯|PVDF]] 复合膜实现了优异的 [[去除效率|NPs 去除效率]]和高通量，我们进一步研究了 [[木质纤维素纳米纤维|LCNF]]-M [[水凝胶]]的浓度如何影响其过滤性能。值得注意的是，当水凝胶浓度从 1.5% 降至 0.5% 时，在 50–500 mg/L 的广泛 [[纳米塑料|NPs]] 浓度范围内，[[纳米颗粒|NPs]] 去除效率和通量均显著提高（Fig. 6a）。例如，0.5% 水凝胶在处理 100 mg/L 含 NPs 水时表现出接近完全的 99.8% 去除效率以及 71.2 L/m²⋅h 的高通量，显著优于 1.0% 和 1.5% 水凝胶（去除效率 92.8%/85.0%，通量 40.1/23.1 L/ $\mathbf { m } ^ { 2 } { \cdot } \mathbf { h }$）。水凝胶浓度与过滤性能之间的反比关系表明，较低的 [[纳米纤丝|LCNF]]-M 负载形成了更有利的拓扑结构，从而在保持高 NPs 截留的同时增强了水渗透性。Fig. 6b 描绘了由 [[CT分析|CT]] 分析得到的 0.5% 和 1.5% LCNF-M 水凝胶的孔结构及相应拓扑参数。0.5% 水凝胶表现出比 1.5% 水凝胶更高的[[孔配位数]]（8）和更低的[[孔喉比]]（2.17）（后者分别为 6 和 2.25），表明其孔网络更加互联且几何复杂性更低（Jia et al., 2024; Ren et al., 2023）。此外，0.5% 水凝胶中较小的孔和喉[[形状因子]]表明孔喉几何形状更均匀，从而降低过滤过程中的流动阻力。我们进一步使用[[Kozeny-Carman方程|修正的 Kozeny-Carman 方程]]（Qin et al., 2022）（Text S3）将 LCNF-M 水凝胶的拓扑参数与[[渗透率]]（K）关联：

$$
K = \frac {\sqrt [ 3 ]{V ^ {2}} (l + m \sqrt [ 3 ]{\psi V} + n E + h \psi) \sqrt [ 3 ]{\psi^ {5}}}{\sqrt [ 3 ]{(3 6 \pi S) ^ {2}}}\tag{1}
$$

其中 V 为[[孔体积]]；l、${ \mathrm { ~ m } } , { \mathrm { n } } ,$ 和 h 为拟合参数；ψ 为[[孔隙率]]；E 为[[欧拉数]]（图 S15）；S 为[[形状因子]]。该公式定量描述了[[渗透率]]对 $V , \psi , E ,$ 和 S 等变量的依赖性。与 1.5% [[水凝胶]]相比，0.5% 水凝胶在 V（197,644 对 $^ { 1 0 3 , 4 8 2 \mu \mathrm { m } ^ { 3 } ) }$）、ψ（98.98% 对 95.74%）和 E（−86,521 对 −18,744）上表现出显著更高的数值，但 S 更低（3.1917 对 4.2917）（图 6c）。因此，0.5% 水凝胶的 K 值（19,944）显著大于 1.5% 水凝胶的 K 值（2841），这支持了其因较低流动阻力而具有的更优过滤性能。

据此，我们构建了[[有限元模型]]以模拟[[胶体纳米颗粒|胶体 NPs]] 在 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]中的传输动力学（文本 S4），旨在将水凝胶浓度与其固有过滤性能相关联（Zhao et al., 2023）。如图 6d 所示，胶体 [[纳米塑料|NPs]] 在不同水凝胶浓度下表现出明显的界面变形模式。胶体 [[纳米颗粒|NPs]] 界面的空间无序度在穿过高浓度（1.5%）水凝胶后显著增加。该现象主要归因于高浓度水凝胶致密的三维网络，其对胶体 NPs 的扩散施加了显著的传质阻力。胶体 NPs 的非均相分布进而堵塞了水凝胶网络内的流动通道，从而增加了水力阻力并降低了通量。此外，胶体 NPs 的持续聚集限制了高浓度水凝胶中[[活性位点]]的利用，并增加了 NPs 通过优先路径泄漏的风险，从而严重损害了[[去除效率]]。图 6e 显示了不同浓度水凝胶中胶体 NPs 所受的[[曳力]]。浓水凝胶中的高粘度和强颗粒间相互作用引发了显著的湍流，其特征为大小和方向各异的有序力线紊乱，并伴有局部速度波动。这种混沌流动状态源于显著的流体阻力和嵌入胶体 NPs 的显著界面变形。在低浓度水凝胶体系中，压力驱动的流场对胶体 NPs 施加了均匀的曳力。由此产生的对流传质以定向且快速的 NPs 迁移为特征，从而协同增强了去除效率和通量。因此，流体力学分析建立了水凝胶浓度与 NPs 过滤结果之间的关联。胶体 NPs 在 [[木质纤维素纳米纤维|LCNF]] 水凝胶中的传输受外部压力与流体曳力之间相互抵消效应的支配。压力场

## 2.5. [[纳米塑料|NPs]] 的可持续管理

将 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]整合到[[超滤]]系统中，可通过省去中间膜清洗环节来减轻二次 [[纳米塑料|NPs]] 污染（Ke et al., 2025; Li et al., 2025d）。为进一步降低因随意处置载有 [[纳米颗粒|NPs]] 的材料而带来的环境风险，使用后的 [[木质纤维素纳米纤维|LCNF]] 水凝胶可通过[[模塑纸浆技术]]进行再利用，该技术能够有效包封 NPs，同时支持高附加值应用（Gong et al., 2025; Lu et al., 2025）。图 7a 展示了通过简便的[[热压工艺]]将载有 [[聚对苯二甲酸乙二醇酯|PET]] 的 [[纳米纤丝|LCNF]] 水凝胶整合到[[纸浆纤维]]中，作为增强剂和增塑剂，以生产高性能模塑纸浆产品。所得纸浆/LCNF/PET 复合材料的性能受多种键合相互作用的协同影响所支配（图 7b）。这些相互作用包括 LCNF 网络内部以及纸浆-LCNF 界面处的[[氢键]]和共价[[交联]]，并辅以 LCNF 与 [[PET纳米颗粒|PET 纳米颗粒]]之间的共价连接，这些作用共同增强了复合材料的结构完整性和[[界面粘附]]力。如图 7c 和 S16 所示，纸浆/LCNF/PET 复合材料表现出优异的力学性能（138.3 MPa，14.3 MJ⋅m⁻³），显著优于[[纸浆板]]（52.4 MPa，3.8 MJ⋅m⁻³），并超过纸浆/LCNF 复合材料（108.2 MPa，8.3 MJ⋅m⁻³）和 [[PET薄膜|PET 薄膜]]（77.2 MPa，5.6 MJ⋅m⁻³），这表明 LCNF 与 PET 纳米颗粒在增强纤维结合和应力传递方面具有显著的协同效应。模塑纸浆产品在水环境中的性能和使用寿命是其商业可行性的关键决定因素。值得注意的是，纸浆/LCNF/PET 复合材料 $( 4 8 . 5 \mathrm { \ : M P a } , 6 . 2 \mathrm { \ : M J } { \cdot } \mathrm { m } ^ { - 3 } )$ 的湿态力学强度和韧性可与纯 PET 薄膜（69.4 MPa，4.8 MJ⋅m⁻³）相媲美，并远超纸浆/LCNF 复合材料和纸浆板。这种性能提升凸显了多组分键合在湿态条件下维持氢键纤维网络完整性方面的关键作用。图 7d 比较了由纸浆/LCNF/PET 复合材料制成的食品容器与商用 PET 容器的耐热性能。当暴露于沸水中时，纸浆/LCNF/PET 复合材料容器保持了结构完整性，而传统 PET 容器则因其较差的耐热性而发生显著变形，形成鲜明对比。此外，纸浆/LCNF/PET 复合材料表现出优异的 NPs 包封效果，沸水冷却过程中（从 $1 0 0 ~ ^ { \circ } \mathrm { C }$ 至接近环境温度）NPs 的释放可忽略不计，从而表明其对人体暴露具有更优异的安全性。这一性能与 PET 容器形成鲜明对比，后者在相同的冷却循环中表现出 NPs 浸出随时间逐步增加。总之，我们证明，将载有 NPs 的 LCNF 水凝胶 incorporation 到模塑纸浆产品中，可有效增强其力学强度、耐水性和热稳定性，为再污染和增值利用的挑战提供了一种双用途解决方案。

## 3. 结论

我们的研究结果确立了[[木质纤维素水凝胶]]作为解决 [[纳米塑料|NPs]] [[超滤]]相关关键挑战（即低效率、[[膜污染]]和[[二次污染]]）的可行方案。建立了一种可持续的化学机械方法，将[[木质纤维素]]解离为全组分[[纳米纤丝]]。[[木质纤维素纳米纤丝]]可形成具有高[[BET|比表面积]]和多孔网络结构的坚固[[水凝胶]]，作为广谱 [[纳米颗粒|NPs]] 捕获的理想平台。[[胶体纳米颗粒|胶体 NPs]] 在水凝胶内的传输动力学和拦截路径由木质[[纤维素]]纳米纤丝的物理化学性质和自组装密度决定。对这些参数的精确控制能够实现高效的 NPs 截留以及高[[水通量]]。此外，将可重构木质纤维素水凝胶集成到商用石油基过滤膜上，可赋予优异的 NPs 去除性能和显著的[[抗污染性能]]。因此，该方法显著降低了膜维护和寿命终止处置过程中二次污染的潜力。此外，我们通过简便的[[热压工艺]]与[[纸浆纤维]]结合，将负载 NPs 的废弃水凝胶升级回收为高强度、耐水和热稳定的模塑产品，实现了从收集到封装再到利用的[[闭环修复]]路径。可以设想，通过定制化的绿色化学和微观结构设计，[[木质纤维素纳米组装体]]将成为一个用于收集多种微纳米颗粒和超大分子的多功能平台。

## 4.1. [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]的制备与表征

[[甘蔗渣]]（10 g）首先通过[[低共熔溶剂|反应性 DES]]（90 g）处理进行解纤，该 DES 由[[四乙基氢氧化铵]]、[[N,N'-二甲基脲|N,N’-二甲基脲]]和[[缩水甘油基三甲基氯化铵]]以摩尔比 1:2:1 组成。DES 处理在室温下机械搅拌进行 2、4 和 8 h。经 DES 处理的甘蔗渣经离心、洗涤，随后使用 Supermasscolloider（MKZA 10–15 J，Masuko Sangyo Co. Ltd.，日本）在 1500 rpm 下解纤，以制备 [[木质纤维素纳米纤丝|LCNFs]] 及其相应的[[水凝胶]]。

纤维样品的形貌通过相应的光学显微照片和 [[透射电子显微镜|TEM]] 图像，使用 [[Nano Measurer|Nano Measurer 软件]]进行表征。图像分别使用[[光学显微镜]]（Bruker CONTOURGT-K，德国）和 [[Hitachi HT-7700]] 透射电子显微镜（日本东京）获得。冻干 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]的微观结构使用[[场发射扫描电子显微镜]]（Hitachi SU8220，日本）在 15 kV 加速电压下观察。成像前，样品经溅射镀覆一层薄金以确保导电性。[[木质纤维素纳米纤维|LCNF]] 水凝胶的介孔特性$( \boldsymbol { \mathrm { e . g . } }$[[BET|比表面积]]和[[孔径分布]]）通过 [[氮气物理吸附|N₂ 物理吸附]]在 77 K 下使用 [[Micromeritics ASAP 2020|Micromeritics ASAP 2020 分析仪]]进行评估。样品使用 [[SkyScan 2211|SkyScan 2211 micro-CT 扫描仪]]（Bruker，德国）以 2.5 μm 的高分辨率进行非破坏性成像，以可视化其内部三维微观结构。

化学组成通过[[酸水解]]后[[高效液相色谱]]分析测定，遵循[[美国国家可再生能源实验室]]的标准程序。纤维样品的表面化学通过 [[X射线光电子能谱|X 射线光电子能谱]]表征，使用配备单色 Al Kα X 射线源（15 kV，5 mA）的 [[Kratos AXIS Ultra DLD|Kratos AXIS Ultra DLD 光谱仪]]（英国）。[[聚合度]]通过 [[EWNNNaCl络合物|EWNNNaCl 络合物]]的[[特性黏度]]测量确定，遵循标准方法 ISO 5351/2（1981）。晶体结构通过 [[X射线衍射|X 射线衍射]]表征，使用 [[Bruker D8 Discover|Bruker D8 Discover 衍射仪]]，Cu Kα 辐射（40 kV，30 mA）。[[结晶度指数]]根据 [[XRD]] 图谱使用 [[Segal方法|Segal 方法]]计算，如下：

$$
C r I (\%) = 1 0 0 \times [ (I _ {2 0 0} - I _ {i}) / I _ {2 0 0} ]\tag{2}
$$

其中$I _ { 2 0 0 }$为 2θ 在 22° 至$2 3 ^ { \circ } ,$之间衍射峰的最大强度，I 为无定形[[纤维素]]在 2θ 在 18° 至 19° 之间衍射峰的最小强度

[[Zeta电位|Zeta 电位]]使用 [[Zetasizer Nano ZS90]]（Malvern Instruments，英国）测量。官能团通过 [[ATR-FTIR|ATR-FTIR 光谱]]（Billerica，MA，美国）表征，光谱采集范围为 500 至$4 0 0 0 ~ \mathrm { c m ^ { - 1 } }$，分辨率为$4 ~ \mathrm { { c m } ^ { - 1 } }$。[[拉曼光谱]]和 mapping 使用 532 nm 激发激光在[[拉曼成像显微镜]]（Tescan MIRA，中国）上进行。[[流变性能]]使用 [[Haake MARS 4|Haake MARS 4 流变仪]]（Thermo Fisher Scientific，美国）评估，使用 60 mm 不锈钢平行板夹具。[[频率扫描|频率扫描测试]]在${ 2 5 ^ { \circ } \mathrm { C } }$下于[[线性粘弹区]]（1.0% 应变）内进行，角频率范围为 0.1–100 rad/s。

## 4.2. [[纳米塑料|NPs]] 过滤

[[复合滤膜]]通过将 5 mL 1% [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]涂覆在商用 [[聚偏氟乙烯|PVDF 支撑膜]]（直径：50 mm；孔径：0.45 μm）上构建，形成活性分离层。[[纳米塑料|NPs]] 悬浮液通过在 0.1 MPa 驱动压力下通过 [[木质纤维素纳米纤维|LCNF]]/PVDF 复合膜过滤进行纯化。

滤膜的 [[去除效率|NPs 去除效率]]（R，%）和[[水通量]]（J，L/m²⋅h）使用以下公式测定：

$$
\mathrm{R} = \frac {C _ {0} - C _ {\mathrm{f}}}{C _ {0}} \times 100\tag{3}
$$

$$
J = \frac {\Delta V}{A \times \Delta t}\tag{4}
$$

其中$C _ { 0 }$和$C _ { \mathrm { f } }$分别为进料液和滤液中 [[纳米塑料|NPs]] 的浓度。$\triangle V$表示渗透水体积（L），A 为有效膜面积$( 1 5 . 8 ~ \mathrm { c m } ^ { 2 } )$，$\triangle t$为渗透时间（h）。

滤膜的[[水通量恢复率]]（[[通量恢复率|FRR]]）采用以下公式评估（Li et al., 2025a）：

$$
\mathrm{FRR} = \frac {J _ {1}}{J _ {0}} \times 100 \%\tag{5}
$$

其中 $J _ { 0 }$ 为初始纯[[水通量]] $\left( \mathrm { L } / \mathrm { m } ^ { 2 } { \cdot } \mathrm { h } \right)$，J 为反冲洗或 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]重新加载程序后恢复的通量。通过将 [[Hermia模型|Hermia 模型]]与 [[XDLVO理论|XDLVO 理论]]相结合，阐明了污染机理和[[抗污染性能]]，详细方法见 Text S1 和 S2。在 [[COMSOL Multiphysics|COMSOL Multiphysics 6.3]] 中开发了[[有限元模型]]，以模拟控制 [[木质纤维素纳米纤维|LCNF]] 水凝胶中[[胶体纳米颗粒|胶体 NPs]] 传输动力学的多物理场现象。详细的控制方程、边界条件和参数设置见 Text S3。

## 4.3. [[纳米塑料|NPs]] 的表征

荧光标记的 [[纳米塑料|NPs]] 分散液按如下方式商业采购：[[聚对苯二甲酸乙二醇酯]]（PET）分散液（50、100、200、300、400 和 500 nm；带负电；2.5% w/v）购自[[江苏竹川科技有限公司]]（中国）。[[聚苯乙烯]]（PS，包括带负电和带正电）、[[聚丙烯]]（PP）、[[聚乙烯]]（PE）和[[聚甲基丙烯酸甲酯]]（PMMA）分散液（均为 100 nm，2.5% w/v）购自[[重庆竹研佳科技有限公司|重庆竹研佳科技]]$\mathrm { { C o . } }$有限公司（中国）。[[纳米颗粒|NPs]] 浓度由[[荧光分光光度计]]（RF-5301 PC，Shimadzu，日本）获取的激发和发射光谱确定。水悬浮液中 NPs 的定量使用[[流式细胞仪]]（FACS Celesta，BD，美国）进行。[[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]中 NPs 的分布使用[[激光扫描共聚焦显微镜]]（FV3000，Olympus Corporation，日本）表征，激发波长为 405 nm。有机物（[[牛血清白蛋白|BSA]]、[[富里酸|FA]] 和 [[腐殖酸|HA]]）及无机纳米颗粒$( { \mathrm { S i O } } _ { 2 } ,$[[高岭土]]和$\mathrm { { A l } _ { 2 } { O } _ { 3 } ) }$购自 [[Sigma-Aldrich]]，用于评估它们对 NPs 去除性能的影响。

## 4.4. 负载 [[纳米塑料|NPs]] 的 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]的处置

将负载 [[纳米塑料|NPs]] 的 [[木质纤维素纳米纤丝|LCNF]] [[水凝胶]]与[[未漂白甘蔗渣浆|未漂白甘蔗渣浆纤维]]按 1:5 的质量比均匀混合。将所得湿混合物转移至不锈钢模具中，并在 150 ◦C、1 MPa 下[[热压]] 2 h。随后在恒定压力下将模塑复合材料冷却至室温。[[拉伸性能|力学拉伸性能]]在配备 500 N 载荷传感器的 [[Instron 3365|Instron 3365 万能试验机]]（美国马萨诸塞州）上评估。矩形试样（20 mm × 3 mm）首先预加载至 5 N，以确保其绷紧并消除任何初始松弛。随后以 5 mm/min 的横梁位移速率进行单轴拉伸试验，标距长度为 10 mm。此外，对完全浸润的样品评估了湿态下的力学强度。
