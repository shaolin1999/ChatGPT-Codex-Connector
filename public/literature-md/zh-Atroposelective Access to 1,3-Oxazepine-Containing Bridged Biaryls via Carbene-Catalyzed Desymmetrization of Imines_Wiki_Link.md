# 通过[[卡宾]]催化的[[去对称化|亚胺去对称化]]反应[[阻转选择性]]合成含 [[1,3-氧杂吖庚因]]的[[桥联联芳基化合物]]

[[Xing Yang]],\* Liwen Wei, Yuelin Wu, Liejin Zhou, [[Xinglong Zhang]],\* and [[Yonggui Robin Chi]]\*

摘要：本文报道了利用 [[N-杂环卡宾]][[有机催化]][[阻转选择性]]合成含中环的新型[[桥联联芳基化合物]]。反应始于[[卡宾]]催化剂对氨基酚衍生的[[醛亚胺]]底物的加成。随后经氧化和[[分子内去对称化]]，以良好的产率和优异的[[对映选择性]]生成含 [[1,3-氧杂吖庚因]]的桥联联芳基化合物。这类新型桥联联芳基产物可便捷地转化为手性[[亚磷酸酯]]配体。初步的[[DFT|密度泛函理论]]计算表明，对映选择性的来源在于生成主要产物的[[过渡态]]中具有更有利的[[前线分子轨道]]相互作用。

## 引言

[[轴向手性]][[桥联联芳基化合物]]是一类重要的联芳基[[阻转异构体]]，因其广泛存在于[[天然产物]]及[[不对称催化]]中的[[手性催化剂]]/配体中（图 1a）。<sup>[1]</sup> 与普通联芳基阻转异构体相比，<sup>[2]</sup> 轴向手性桥联联芳基化合物（其中两个邻位取代基通过桥接原子相连）在结构上更为独特，且此类分子的合成仍远未充分发展，更具挑战性。主要挑战之一在于发现并构建具有合适桥联长度的构型稳定桥联联芳基体系，<sup>[3a]</sup> 否则这些阻转异构体会因在环境温度或更低温度下快速[[消旋]]而无法拆分。<sup>[3b-3f]</sup> 此外，已报道的大多数工作集中于在桥联部分引入额外的[[立体中心]]，从而获得热力学上更有利的非对映异构体阻转异构体，<sup>[4]</sup> 该策略被称为中心手性到轴向手性的[[手性传递]]。<sup>[5]</sup> 与之形成鲜明对比的是，桥联部分不含立体中心的桥联联芳基化合物的合成仍处于起步阶段（图 1b）。该领域的进展主要来源于[[手性磷酸]]<sup>[6a]</sup>-和[[过渡金属]]<sup>[6b-c]</sup>-催化的[[螺烯]][[对映选择性]]合成，<sup>[6]</sup> 而这些螺烯在结构上与轴向桥联联芳基化合物相关；直到最近，Yan 及其同事才报道了[[手性方酰胺]]催化的、经由[[邻醌甲基化物]]中间体[[阻转选择性]]构建九元[[碳酸酯]]桥联联芳基化合物的方法。<sup>[7]</sup>

[[N-杂环卡宾]]（NHCs）作为[[有机催化]]剂的应用已经促成了众多合成上有用的反应的发展。<sup>[8]</sup> 近年来，NHC 有机催化已被认为是制备[[轴手性化合物]]的一种有力工具。<sup>[9]</sup> 其中大多数工作集中于构建常见的联芳基[[阻转异构体]]；<sup>[10]</sup> 只有 Zhao 课题组的一项工作报道了一种 NHC 催化的[[级联反应]]，以获得带有手性八元[[内酯]]单元的轴手性[[桥联联芳基化合物]]。<sup>[11]</sup> 在此，我们公开了一种[[卡宾]]催化的[[亚胺]]活化方法，用于合成具有单一立体源要素的轴手性 [[1,3-氧杂氮杂䓬]]桥联联芳基化合物（图 1d）。我们的反应是通过 NHC 催化剂与由氨基醇和醛衍生的亚胺加成而引发的，最终形成 [[aza-Breslow中间体|aza-Breslow 中间体]]（I）。<sup>[12]</sup> 该 aza-Breslow 中间体的氧化生成缺电子的亚胺酰基[[唑鎓中间体]] II，<sup>[13]</sup> 该中间体最终经历[[分子内去对称化]]，以良好的产率和优异的[[对映选择性]]得到轴手性 1,3-氧杂氮杂䓬桥联联芳基产物。应当指出，与羰基化合物的活化相比，NHC 催化的亚胺活化仍远未得到充分探索。<sup>[14]</sup> Lupton<sup>[15a]</sup>、Biju<sup>[15b]</sup> 和我们课题组<sup>[15c-d]</sup> 已经报道了相关的卡宾催化形成 aza-Breslow 中间体用于亚胺[[极性反转]]和不对称反应。此外，$\mathsf { F u } ^ { [ 1 6 \mathsf { a } ] }$ 和 $\mathsf { u s } ^ { [ 1 6 \mathsf { b } ] }$ 同时实现了卡宾催化的氧化亚胺极性反转用于对映选择性 [4+2] [[环加成反应]]。本工作代表了首次成功发展氧化亚胺极性反转以获取轴手性化合物。我们预见，利用我们方法学所开发的代表性实例可以为构建具有多种应用前景的新型轴手性桥联联芳基化合物开辟新途径。

冷冻柜中存放数月后，ee值未见降低。接下来，我们在[[甲苯]]中于$7 0 ~ ^ { \circ } \mathsf { C } .$下测定了若干代表性化合物的[[旋转能垒]]。桥联联芳基2a和2z由于轴附近邻位具有相似的空间位阻，表现出几乎相同的旋转能垒（27.1 kcal/mol对27.3 kcal/mol）。

理论上，桥联联芳基5的构型稳定性高于2a，因为化合物5的邻位取代基比化合物2a更大。化合物5的[[旋转能垒]]实验测定为28.1 kcal/mol，确实高于化合物2a。对结构2a、2z和5的旋转能垒进行额外的[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算，结果与实验值高度吻合（图S1和图2b）。

为了理解所观测到的[[阻转选择性]]的来源，我们进一步对决定[[对映选择性]]的[[去对称化]]步骤进行了[[DFT]]研究，该步骤中芳环上的一个羟基选择性地进攻[[亚胺]]碳。由于我们只关注相对活化能垒的差异，为简便起见，我们考虑的是去质子化的酚氧负离子（在碱性反应条件下可逆生成）进攻亚胺碳的[[过渡态]]。考虑到由[[非共价相互作用]]（如[[N-杂环卡宾|NHC]]催化剂部分的芳环与底物苯环之间的[[π-π相互作用]]）稳定的最有利构象，决定对映选择性步骤的[[密度泛函理论|DFT]]优化过渡态结构如图3所示。[[前线分子轨道]]（FMO）分析表明，TS-major的活化能垒较低，因为在$\sigma _ { \mathsf { C - O } }$键形成时，它受益于有效的轨道重叠（其HOMO中具有一定的$\sigma _ { \mathsf { C } - \mathsf { O } }$成键特征，其LUMO中具有一定的$\sigma ^ { \star } \subset { } 0$反键特征），而TS-minor的HOMO中具有一定的$\sigma ^ { \star } \subset { } 0$反键特征，这可能表明其由于轨道重叠较差而不太有利（见SI，图S3）。此外，[[畸变-相互作用模型|畸变-相互作用]]<sup>[20a-20b]</sup>/[[活化应变模型|活化应变]]（DI-AS）模型<sup>[20b-20f]</sup>分析证实，TS-major比TS-minor具有更有利的相互作用，而两个过渡态中的畸变相似（见SI，图S4）。因此，手性[[卡宾]]催化剂部分具有非共价相互作用，其使过渡态以有利于主要产物形成的方式排布，从而与次要产物的形成相比，受益于更有利的轨道和非共价相互作用，由此实现对映选择性诱导。

## 结论

总之，我们发展了一种[[卡宾]]催化的[[醛亚胺]]活化方法，用于含[[1,3-氧杂氮杂䓬]]桥联联芳基的[[阻转选择性]]合成。由氨基酚衍生的醛[[亚胺]]在[[N-杂环卡宾|NHC]]催化剂和[[氧化剂]]的作用下，以高度[[对映选择性]]的方式发生阻转选择性[[去对称化]]反应。该反应所得的新型桥联联芳基产物含有酚羟基，并可方便地转化为手性[[亚磷酸酯]]配体。[[DFT]]计算明确指出，轨道相互作用和[[非共价相互作用]]在去对称化步骤[[过渡态]]中实现对映选择性方面的重要性，并强调了苯环6位取代基（Ar<sup>1</sup>）在提供位阻以防止轴向容易旋转、从而保持高水平对映选择性方面的作用。利用这种新型桥联联芳基骨架设计新[[手性配体]]及催化不对称反应的进一步探索正在我们实验室进行中。
