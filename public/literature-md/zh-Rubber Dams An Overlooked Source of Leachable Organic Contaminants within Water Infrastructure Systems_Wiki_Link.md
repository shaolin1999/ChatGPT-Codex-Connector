## ■ 引言

为适应和改造自然水生态环境而发展的建成基础设施，推动了社会进步与人类福祉的提升。然而，这类干预措施可能对[[受纳水体]]及相关生态系统产生一系列深远但往往未被充分认识的影响。[[水基础设施]]中使用的材料可能导致化学污染物及其[[转化产物]]（transformation products, TPs）无意中向环境扩散，从而对生态系统构成风险。<sup>1−3</sup> [[充气橡胶坝]]可作为一种适应性强且成本效益高的解决方案，用于防洪、灌溉、水力发电、地下水补给和栖息地恢复。其对多样地理与水文条件（包括季节性或临时性部署）的适应能力，加之较低的建造和维护成本，促使其得到广泛应用。全球已安装至少 6000 座[[橡胶坝|充气橡胶坝]]（图 S1），其中日本约 4000 座，<sup>4</sup> 中国超过 1000 座，<sup>5</sup> 美国超过 200 座，<sup>6</sup> 欧洲 145 座。<sup>7</sup> 鉴于缺乏统一的全球报告机制，橡胶坝的实际数量很可能超过已公布数值。尽管全面的全球估算仍属专有信息，但这些现有设施代表了数千个大型、固定的潜在化学品浸出[[点源]]。

尽管[[充气橡胶坝|橡胶坝]]具有实用性，但橡胶材料如今已被认为是化学添加剂及其工业与环境[[转化产物]]在使用寿命期间向周围[[环境释放]]的重要来源。<sup>8,9</sup> [[橡胶坝材料]]（rubber dam materials, RDMs）包括[[氯丁橡胶]]、[[三元乙丙橡胶]]、[[丁基橡胶]]或[[天然橡胶]]，通常嵌入[[聚酯]]或[[尼龙]]织物以提高抗拉强度。<sup>10</sup> RDMs 的强度、特性和长期性能在很大程度上依赖于复杂的添加剂化学体系，而这些添加剂的组成往往作为机密受到保护。其中包括[[抗氧剂]]/[[抗臭氧剂]]、[[硫化剂]]、[[促进剂]]、[[增塑剂]]和[[填料]]，用以改变机械性能、耐久性以及对紫外辐射、臭氧和[[氧化应激]]的耐受性。添加剂包括[[取代对苯二胺]]类（[[对苯二胺类抗氧剂|PPDs]]，抗氧剂/抗臭氧剂）、[[苯并噻唑]]类及其衍生物（BTHs，硫化剂）、[[六甲氧基甲基三聚氰胺]]（[[HMMM]]，[[交联剂]]）、[[2,2,4-三甲基-1,2-二氢喹啉]]（TMQ，抗氧剂）和 [[1,3-二苯胍]]（[[DPG]]，促进剂），以及许多其他物质，包括专有且尚未识别的化学品和化学类别。<sup>11,12</sup>

各种反应，加上[[光氧化]]和[[水解]]等[[风化过程]]，促进了[[橡胶坝材料]]（[[橡胶坝|RDM]]）衍生化学物质的转化和迁移，并在基础设施位置生成污染物。重要的是，通过母体添加剂生物或非生物转化形成的[[转化产物]]（TPs）通常表现出改变的理化性质和生物活性，导致与母体添加剂不同的稳定性、[[迁移性]]或[[生态毒理学]]效应增强。作为一个现已广为人知的例子，N-1,3-二甲基丁基-N′-苯基对苯二胺（[[6PPD]]）可被氧化为[[醌类产物]]（[[6PPDQ]]），由于所有[[车辆轮胎]]都使用[[N-(1,3-二甲基丁基)-N′-苯基对苯二胺|6PPD]]，该产物现已被广泛检出。<sup>13−15</sup> [[6PPD醌|6PPDQ]]表现出更高的迁移性、持久性<sup>16</sup>和毒性，可在低ng/L浓度下诱导敏感[[鲑科鱼类]]快速急性死亡<sup>17−19</sup>，并在其他鱼类中产生多种亚致死影响。<sup>20,21</sup> 近期研究记录了[[取代对苯二胺|PPDs]]及相关醌类产物（PPDQs）在[[道路径流]]、路边土壤/灰尘、沉积物和[[细颗粒物]]中的存在。<sup>22,23</sup> 毒理学风险包括[[酯酶]]活性降低和[[细胞膜损伤]]，<sup>24</sup>而机制评估则强调了PPDQs诱导细胞内[[氧化应激]]的内在能力，<sup>25</sup>突出了全面表征橡胶制品中添加剂衍生污染物的必要性。

尽管间接证据表明[[充气橡胶坝]]中使用了[[取代对苯二胺|PPDs]]等添加剂，<sup>26,27</sup>但这些化合物及其[[转化产物]]在[[橡胶坝材料]]中的具体添加剂种类、相对含量和[[浸出潜力]]在很大程度上仍然未知。这一知识空白阻碍了对这些广泛使用的水工结构进行[[生态风险评估]]和长期环境相容性评价。本研究通过使用[[高效液相色谱-高分辨质谱]]（LC-[[高分辨质谱|HRMS]]）对代表性[[橡胶坝|充气橡胶坝]]材料的提取物和浸出液进行化学组成分析，既对已知添加剂进行[[靶向分析]]，也对未知添加剂和转化产物进行疑似或[[非靶向筛查]]，以填补这一研究空白。主要目标是：（1）对橡胶添加剂进行[[靶向定量分析]]；<sup>28−30</sup> （2）采用基于HRMS的[[可疑物筛查|疑似筛查]]对相关化合物进行分析，并结合非靶向筛查以发现新型添加剂和转化产物；（3）在受控实验室条件和天然水中确定已鉴定化合物的浸出潜力；以及（4）尽可能调查橡胶添加剂及其转化产物的环境赋存和潜在暴露。这些数据有助于环境风险评估，促进更环保橡胶配方的开发，并为使用充气橡胶坝的基础设施系统提供[[水质管理]]策略参考。

## ■ 材料与方法

## 化学品

为便于阅读，本研究使用的所有化学缩写和样品缩略词的完整术语表见表 S1。共对 27 种橡胶添加剂及其[[转化产物]]（TPs）进行了目标分析，并将其分类为：(1) [[取代对苯二胺|PPDs]]，包括 [[6PPD]]、[[N-异丙基-N′-苯基-1,4-苯二胺]]（[[IPPD]]）、[[N-(1,4-二甲基戊基)-N′-苯基对苯二胺]]（[[7PPD]]）、[[N,N′-二-2-萘基对苯二胺]]（[[DNPD]]）、[[N,N′-二苯基对苯二胺]]（[[DPPD]]）、[[N,N′-二甲苯基对苯二胺]]（[[DTPD]]）；(2) [[对苯二胺类抗氧剂|PPDs]] 的转化产物（[[对苯二胺类抗氧剂转化产物|PPD TPs]]），包括相应的醌类（即 [[6PPDQ]]、[[IPPDQ]]、[[7PPDQ]]、[[DPPDQ]] 和 [[DTPDQ]]）以及其他非醌类转化产物，包括 [[4-羟基二苯胺]]（[[4-HDPA]]）、[[4-硝基二苯胺]]（[[4-NDPA]]）、[[4-亚硝基二苯胺]]（[[4s DPA]]）、[[4-氨基二苯胺]]（[[4-ADPA]]）、[[1,3-二甲基丁胺]]（[[1,3-DMBA]]）；(3) [[其他橡胶相关化学品]]（[[氧化还原活性化合物|ORACs]]），包括 [[HMMM]]、[[苯胺]]、[[1,3-二苯胍|DPG]]、[[1,3-二环己基脲]]（[[DCU]]）、[[二乙基甲苯酰胺]]（[[DEET]]）、[[苯并噻唑]]（[[BTH]]）、[[2-(4-吗啉基)苯并噻唑]]（[[2,4-MoBT]]）、[[2-氨基苯并噻唑]]（[[2-ABT]]）、[[5-甲基-1-H-苯并三唑]]（5MeBT）、[[2-羟基苯并噻唑]]（[[2-HBT]]）、[[N-环己基-1,3-苯并噻唑-2-胺]]（[[NCBA]]）。分析标准品包括[[同位素标记]]的 [[6PPD醌|6PPDQ]]（[[N-(1,3-二甲基丁基)-N′-苯基对苯二胺醌|6PPDQ]]-d 和 6PPDQ-<sup>1313</sup>C）以及其他几种标记标准品，用于同位素校正。除 4s [[二苯胺|DPA]]（92.5%）外，所有标准品纯度均 >95%；详细信息见表 S2。[[甲酸]]（FA，99%）及其他 HPLC 级溶剂，包括[[乙酸乙酯]]（ETAC）、[[乙腈]]（ACN）和[[甲醇]]（MeOH），购自 [[Fisher Scientific|Fisher]]（Fair Lawn，NJ，USA）。

## 样品采集

18 个 [[橡胶坝|RDM]] 样品应要求从两家制造商处获得，并根据其结构、层数和状态（新生产或储存约 1 年）进行分类。虽然具体组成属于专有信息，但工程标准表明，[[充气橡胶坝]]主要由[[三元乙丙橡胶]]和[[氯丁橡胶]]组成，以提供所需的耐候性、抗紫外线和耐水性。<sup>10,27</sup> 此外，它们通常设计为多层复合材料，依靠橡胶与内部合成纤维织物粘合，并可能包含诸如 PPD [[抗氧剂]]和[[三聚氰胺]]基[[粘合促进剂]]等添加剂。<sup>31,32</sup> 鉴于 [[橡胶坝材料|RDM]] 的这种多层结构（图 S2），代表性样品根据其结构类型、层数（1、2、3 或 5）以及状态（新“N”或储存“S”）进行分类和编码。材料分为织物增强橡胶（FRR-3S，n = 4；FRR-3N，n = 4；FRR-5N，n = 3）、复合橡胶（CR-2N，n = 4）和嵌入式织物增强层（EFRL-1N，n = 3；见表 S3）。RDM 样品（约 20 × 40 cm，约 5 kg）首先用去离子（DI）水进行表面擦拭，以去除表面污染物。为了更直接地与[[车辆轮胎]]橡胶样品的组成进行比较，采用预清洁的不锈钢锉刀和钻头（[[甲醇]]冲洗并风干）对橡胶的表面和横截面层进行机械磨损，以最大化用于对比化学提取的表面积。所得复合颗粒（约 5 g，粒径约 0.5 mm；橡胶碎片和嵌入的增强纤维）经涡旋混合（5 min）收集并均质化。为防止光转化和进一步氧化，样品立即转移至琥珀色玻璃瓶中，用氮气（纯度 99.99%，10 min）吹扫，并在分析前储存（23 ± 2 °C）。

作为 [[橡胶坝|RDM]] 样品的补充，还采集了[[充气橡胶坝|橡胶坝]]接触拭子和接触[[水样]]品，以评估橡胶坝部署地点的 [[橡胶坝材料|RDM]] 化学物质赋存情况。橡胶坝拭子样品采集自两座在役、已老化的橡胶坝，分别位于中国北京[[小清河]]（39.724036° N, 116.191928° E；坝袋于 2012 年安装）和美国加利福尼亚州弗里蒙特[[阿拉梅达溪]]（37.572938° N, 121.971938° W；季节性部署，坝袋于 2015 年更换）。虽然目前尚无橡胶表面采样标准操作程序，但我们的策略为此借鉴了成熟的环境表面擦拭方案。<sup>33,34</sup> 橡胶坝表面先经预清洁以去除积累的表面碎屑，并使用[[聚酯]]拭子（[[CleanFoam]]，[[Texwipe]]，Kernersville，NC，USA）按以下程序采样：（1）将每支聚酯拭子（使用前经干燥并称重）用（约 2 mL）超纯水润湿后，立即快速擦拭橡胶表面 $\left( 2 0 - 8 0 ~ \mathrm { c m } ^ { 2 } \right)$ 以促进[[水相浸出]]。（2）通过约 50 次旋转和往复擦拭确保充分接触。（3）接触后，将每支拭子用铝箔包裹并放入密封袋中。（4）在橡胶坝表面 4−6 个不同位置重复此程序。现场空白为未暴露拭子，在现场以相同方式润湿和处理；方法空白也以相同方式收集和处理，以评估背景污染。返回实验室后，将收集的聚酯拭子冷冻干燥并称重，然后储存 $\mathrm { a t } - 2 0 \ ^ { \circ } \mathrm { C }$ 以便运输和分析。为表征相关[[受纳水体]]，在中国北京小清河设施处采集了河水抓取样品（每个点位 n = 3 个重复）。采样在干燥天气期间同时于橡胶坝上游和下游约 50 m 处进行，以尽量减少近期[[道路径流]]的混杂影响。使用经预清洗的 1 L 琥珀色玻璃瓶采集表层以下水体（约 15 cm 深度），在冰上运输，并在提取前储存于 $4 ~ ^ { \circ } \mathrm { C }$。

## [[溶剂提取]]

为测定表面可利用的化学物质存量和便于数据比较，采用 [[甲醇|MeOH]] 和 [[乙酸乙酯|ETAC]] 对 [[橡胶坝材料|RDMs]] 和接触拭子进行提取，该方法参考了此前经修改的方法。<sup>35</sup> 固体/溶剂比基于[[轮胎磨损颗粒]]（TWP）研究<sup>35</sup>，并经优化以最大化可提取质量，同时避免提取液过饱和。对于每个 [[橡胶坝|RDM]]，将 50 mg 样品加入 15 mL 玻璃离心管中，并加入 5 ng [[替代标准品]] $( 6 \mathrm { P P D O } \overline { { \Omega } } \overline { { d } } _ { 5 } )$（溶于 MeOH）。使 MeOH 过夜挥发。在提取前加入替代标准品可校正程序损失和[[基质效应]]。RDM 用 5 mL MeOH 提取，涡旋（1 min）、振荡（10 min）、超声（20 min）。离心（20 min）后，用玻璃移液管将上清液转移至新的离心管。原管中的固体再分别用 5 mL MeOH 和 ETAC 各重复提取两次。合并上清液，在干燥氮气下浓缩至近干，并用甲醇重新定容至 1 mL。提取物储存于 $\mathrm { a t } - 2 0 \ ^ { \circ } \mathrm { C }$，经 0.22 μm PTFE 注射器过滤器过滤，稀释 5−10 倍（通过初步分析确定），并储存于 $\mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega } \mathrm { \Omega }$ 直至仪器分析。

## [[水相浸出]]

浸出方法与既往[[轮胎磨损颗粒|TWP]]研究及OECD #120方案一致，<sup>29,36</sup>旨在评估与水接触时的初始[[浸出潜力]]。采用两个平行的24 h批次浸出方案评估解吸与迁移，每个[[橡胶坝|RDM]]样品一式三份，使用pH 7.0的去离子水并含10 mM[[磷酸盐缓冲液]]。同时，使用当地采集的河水（塔科马附近[[Lynch Creek]]，$\mathrm { W A , U S A , p H = 7 . 4 ) }$）开展浸出研究，以评估溶液条件的影响。除组成和pH控制策略外，其他实验参数如[[固液比]]、时间、温度、接触时长和搅拌在两个场景中均保持一致。橡胶材料（150 mg）首先加入12.5 ng $6 \mathrm { P P D Q } \mathrm { - } d _ { 5 }$[[替代标准品]]（得到25 ng/L），在预清洗的500 mL琥珀色玻璃瓶中加入500 mL [[Milli-Q水]]（300 mg/L比例），加盖，并在室温下于平台摇床中$( { \sim } 2 0 \ ^ { \circ } \bar { \mathrm { C } } )$搅拌24 h（120 rpm）。搅拌后，将浸出液过滤（0.4 μm，47 mm玻璃纤维）至洁净琥珀色瓶中，并进行[[固相萃取]]（SPE）以测定溶解浓度。[[Agilent Bond Elut HLB]]小柱（6 mL，200 mg）在样品上样前进行活化（5 mL[[甲醇]]、25 mL去离子水，流速5−10 mL/min），随后上样（200 mL，流速5−10 mL/min）。上样完成后，用去离子水（10 mL）淋洗小柱，真空干燥（12 min），并用甲醇洗脱$( 4 \times 2 . 5 ~ \mathrm { m L } )$。提取物使用干燥氮气浓缩至1 mL，转移至自动进样瓶，并在仪器分析前$\mathrm { a t } - 2 0 \ ^ { \circ } \mathrm { C }$储存。所有[[水样]]均采用相同SPE方法提取。

## 质量保证与控制

在[[质量保证与质量控制]]（QA/QC）方面，样品按以下顺序运行：校准曲线样品，实验重复样依次分析，并频繁注入[[甲醇]]空白以评估残留（未观察到残留），且在序列末尾重新分析校准曲线组中的一个QC样品（观察到峰面积变异<5%）。定量时，定量离子与定性离子比值的最大容许偏差为±20%。RDM中检出的新型化合物利用具有相同基本碳骨架的参考化合物的校准曲线进行半定量（表S6）。空白包括现场空白、实验空白和实验室程序空白。在这些空白中检出若干分析物，包括HMMM、苯胺、DPG、2-ABT和NCBA。为消除假阳性，仅当RDM样品中分析物的浓度超过相应空白中最高水平的10倍时，才认为检出有效。仅当样品浓度超过空白中检出浓度的十倍时，才报告相关样品的结果。两台仪器均按制造商方案进行校准。配置5 ng $^ { 1 3 } { \mathrm { C } } _ { 6 ^ { - } }$ 6PPDQ作为仪器内标的混合进样，以校正电离效率的变化。每种分析物的校准曲线至少包含7个点，并按同位素标准品回收率归一化；$R ^ { 2 } > 0 . 9 9$（表S2）。通过向硅藻土中加标混合标准品（空白回收率，10 $\mu \mathbf { g } / \mathrm { L } , n = 3 )$）和RDM颗粒（基质回收率，20 $\mu \mathbf { g } / \mathrm { L } , n = 3 )$）评价方法回收率。方法回收率、[[检出限]]（LOD）和[[定量限]]（LOQ）列于表S7。检出浓度通过[[替代标准品]]回收率归一化（表S2），以校正程序损失和[[基质效应]]。

## 数据分析

基于质量的[[疑似物筛查]]与[[非靶向碎裂分析]]包括：（1）基于文献和[[转化产物预测]]的质量疑似物筛查；（2）对未匹配分子进行推定注释的[[伪非靶向筛查]]。数据分析使用 [[Agilent 软件]]和 Sirius<sup>37</sup> 开源软件。[[MassHunter Explorer]]（V1.0）用于[[非靶向特征提取]]和对齐，提取的特征随后通过[[重复性过滤]]和[[空白扣除]]进行优先级排序。保留重复出现频率 >50%、峰面积 >5000、鉴定得分 >70、由[[同位素分布]]构成的[[分子式指认]]，并且峰面积为溶剂空白和方法空白 3 倍以上的特征。对于疑似物筛查，我们利用[[内部筛查数据库]]，其中包括经常检出的[[添加剂化学品]]及其基于文献和既往研究预测的[[转化产物]]。[[非靶向筛查]]使用 Sirius 软件，与包含约 1100 种化合物和 1000 张谱图的内部数据库（匹配 MS、MS/MS 和保留时间）以及包含约 16,000 种化合物的 [[MassBank 数据库]]（尽可能匹配 MS、同位素模式和 MS/MS）进行匹配。已鉴定分子按照 [[Schymanski 置信水平]]进行分类。<sup>38</sup> 进一步提取和半定量使用 [[MassHunter Qualitative Analysis]]（V10.0）完成。所有潜在匹配均经人工确认，以核实其身份为[[分子离子]]而非[[源内碎片]]。[[半定量分析]]和[[统计评价]]主要限定于通过疑似物筛查鉴定的 37 种化合物。疑似物筛查化学品毒性预测来自 [[US EPA Toxicity Estimation Software Tool]]（TEST）和 ProTox $3 . 0 , ^ { 3 9 , 4 0 }$，并使用 [[Toxicological Priority Index]]（ToxPi）进行优先级排序。

## ■ 结果与讨论

## [[RDM 提取物]]的[[靶向分析]]

借鉴为[[车辆轮胎]]建立的方法，<sup>29,35</sup> [[橡胶坝材料]]首先被研磨并进行[[溶剂提取]]，以表征其化学组成并测定[[浸出潜力]]。虽然这有助于了解组成并与文献进行比较，但该处理方式并不具有环境代表性，因为[[充气橡胶坝|橡胶坝]]预计不会以这种方式发生物理降解。然而，该提取过程可评估组成和[[可浸出性]]，是后续监测和长期风险评估的必要步骤。该提取揭示了这些材料中存在多种添加剂及其 [[转化产物|TPs]]，并将其分为 [[取代对苯二胺|PPDs]]、[[对苯二胺类抗氧剂转化产物|PPD TPs]] 和 [[其他橡胶相关化学品|ORACs]] 三类（表 1）。除主要为[[尼龙]]的织物层 EFRL-1N 外，大多数所分析的橡胶添加剂及其 TPs 均被检出（图 1）。多种化合物实现了 100% 检出，包括 [[IPPD]]、[[6PPD]]、[[IPPDQ]]、[[6PPDQ]]、[[DPPDQ]]、[[4-HDPA]]、[[1,3-DMBA]]、[[4-ADPA]]、[[4s DPA]]、[[HMMM]]、[[1,3-二苯胍|DPG]]、[[DEET]]、[[2,4-MoBT]]、[[BTH]] 和 [[5-MeBT]]。虽然空白中出现了痕量的普遍存在化学品（如 [[二乙基甲苯酰胺|DEET]]、[[DPG]]），但其在 [[RDM 提取物]]中的浓度始终高出 10 倍以上，证实了它们确实来源于橡胶材料。与车辆轮胎类似，这些数据表明，工业化学品的[[复杂混合物]]（例如 [[对苯二胺类抗氧剂|PPDs]] 和其他添加剂的技术混合物）被用于制造 [[橡胶坝|RDM]]，并随着工业及环境 TPs 的形成而生成日益复杂的混合物，通常包括由单一添加剂形成多种 TPs。<sup>18</sup>

在全部添加剂中，FRR-3S 材料无论在类别上的化学多样性（图 1A）还是添加剂浓度（图 1B）方面都表现最为突出。主要受高含量 [[IPPD]]、[[6PPD]] 和[[苯胺]]以及较低程度 [[DTPD]] 的驱动，FRR 3S 中标准定量化合物的总浓度比其他橡胶材料样品高 35 至 63 倍。为了将这些化学组成与其他材料进行对比，FRR-3S 中 [[N-异丙基-N′-苯基-1,4-苯二胺|IPPD]] 和 [[N-(1,3-二甲基丁基)-N′-苯基对苯二胺|6PPD]] 的丰度（中位数分别为 1600 μg/g 和 1000 μg/g）远高于采用相同提取方法处理的[[车辆轮胎]]颗粒报告值（6PPD 为 110−260 μg/g，[[N-异丙基-N′-苯基对苯二胺|IPPD]] 为 <13 μg/g）。<sup>35</sup> 不过，这些结果与全球文献中表明特定市场存在高 IPPD 配方的报道相互印证。例如，对中国和欧洲道路及隧道粉尘的环境评估报告了 IPPD 与 6PPD 共占主导的组成特征，其中中国道路粉尘中两者中位浓度几乎相同，分别为 55 ng/g 和 52.5 ng/g。<sup>14,15</sup> 这些观察结果证实，IPPD 含量升高代表了某些橡胶应用中已确立的工业实践。IPPD 在 FFR-3S 中的丰度尤其显著，但在所有 [[橡胶坝|RDM]] 中也都相当突出：在这些 [[橡胶坝材料|RDM]] 中，IPPD 在 PPD 质量中占主导地位（占目标质量的 58−98%）（图 1C）。在 IPPD 之后，6PPD 占比第二高，为全部 PPD 质量的 1.2% 至 36%，而 FFR-3S 中 [[N,N′-二甲苯基对苯二胺|DTPD]] 的贡献较小（6.2%）。IPPD 与 6PPD 共占主导的组成特征与此前对包括 [[轮胎磨损颗粒|TWP]]、门垫和碎胶末在内的其他橡胶材料的观察不同，在那些材料中通常由 6PPD 主导 PPD 组成。<sup>29</sup> 根据《[[Vanderbilt Rubber Handbook]]》，持续承受水环境风化的重型基础设施橡胶需要独特的[[抗臭氧剂]]应用方案。<sup>42</sup> 多项环境研究报告了类似的 IPPD 与 6PPD 比值，尤其是在空气颗粒物中，<sup>43,44</sup> 甚至在电子废物粉尘中 IPPD 浓度高于 6PPD。<sup>45</sup> 目前尚不清楚这些差异是源于不同的工业配方，还是源于生产后或环境中后续老化、转化和分配过程的综合效应。低 6PPD/高 IPPD 的组成似乎表明，在这些特定 RDM 中，高含量 6PPD 并非抗氧化保护的严格要求，尽管含 6PPD 最高的材料仍表明，至少对某些 RDM 而言，6PPD 依然是首选的[[抗氧化剂]]。充气式 RDM 还可能包含高强度合成纤维织物以及[[氯丁橡胶]]、[[三元乙丙橡胶]]等[[合成橡胶]]，这些特定[[弹性体]]的性质可能为 IPPD 提供比其他 PPD 抗氧化剂更好的化学相容性和迁移动力学。归根结底，这些高浓度恰好符合重型基础设施橡胶在需要动态臭氧防护时对 IPPD 的工业偏好。<sup>14,42,46</sup> 这种有意的工业使用很可能解释了这些样品中观察到的以 IPPD 为主导的化学特征。

凭借在致死和亚致死终点均具有明确的毒性特征，<sup>20,21</sup> [[6PPDQ]] 的检出表明[[充气橡胶坝|橡胶坝]]是 [[6PPD醌|6PPDQ]] 的潜在[[点源]]。[[N-(1,3-二甲基丁基)-N′-苯基对苯二胺醌|6PPDQ]] 浓度范围为 0.02 至 3.6 μg/g，且不同材料之间存在显著差异。中位浓度从 FRR-5N 中的 0.02 μg/g 到 FRR-3S 中的 2.7 μg/g 不等，清楚表明 [[橡胶坝|RDM]] 中使用的不同 [[6PPD]] 用量控制了 6PPDQ 丰度。这些数值比在类似加工的 [[轮胎磨损颗粒|TWP]] 中所报道的 6PPDQ 浓度低约 5−12 倍，后者通常为 4 至 43 μg/g。<sup>22,29</sup> 然而，与 TWP 的分散不同，橡胶坝是一个直接安装在河道中的大型固定源，形成了明显不同的局地暴露特征。尽管 TWP 的全球质量丰度远远超过橡胶坝，但橡胶坝巨大的质量和表面积，加之其阻隔迁移并聚集鱼类的倾向，可能形成局地污染和[[暴露热点]]。标准单跨橡胶坝的重量从小型渠道的数公吨到大河中的 30 吨以上（质量相当于约 2000 条汽车轮胎）。<sup>10,27,32</sup> 根据我们的提取结果，一座保守估计为 10 吨的橡胶坝（约相当于 650 条轮胎）可能含有约 36,000 mg 的 6PPDQ。虽然完好坝体的表面质量比远低于单条轮胎或轮胎磨损颗粒，但这一 6PPDQ 库存理论上足以使 32.7 亿升水升高至[[美国EPA|美国 EPA]] [[急性水生生物筛查标准]] 11 ng/L。<sup>47</sup> 尽管这代表的是上限（最大瞬时）[[浸出潜力]]，且在实际环境条件下仅有一小部分会迁移释放，但这仍然清楚表明其具有显著的环境危害。

与母体 PPD 组成一致，[[IPPDQ]] 浓度在所有 [[对苯二胺类抗氧剂转化产物|PPD TPs]] 中均超过 [[6PPDQ]]（图 1D）。虽然其对[[幼年虹鳟]]的[[急性毒性]]远低于 [[6PPD醌|6PPDQ]]，<sup>48</sup> 但有关 [[IPPD醌|IPPDQ]] 的[[环境归趋]]及亚致死影响潜力仍知之甚少。[[苯胺]]和 [[4-ADPA]] 分别是 [[6PPD]] 的[[水解]]和[[氧化产物]]，<sup>49,50</sup> 是检出含量最高的 [[对苯二胺转化产物|PPD TPs]] 之一。苯胺的存在浓度为 2.5−110 μg/g。近期报告表明，[[N-(1,3-二甲基丁基)-N′-苯基对苯二胺|6PPD]] 并不是苯胺、[[4-氨基二苯胺|4-ADPA]] 和 [[4-HDPA]] 的唯一来源。[[IPPD]] 在臭氧暴露后也可能生成 4-ADPA 和 [[4-羟基二苯胺|4-HDPA]]，<sup>51</sup> 而另一种常见橡胶添加剂 [[1,3-二苯胍|DPG]] 是环境中苯胺污染的主要来源。<sup>52</sup> 同样，欧盟风险评估报告估计[[车辆轮胎]]中的苯胺残留量最高可达 100 μg/g。<sup>53</sup> 值得注意的是，苯胺被[[国际癌症研究机构]]列为[[可能的人类致癌物]]（2A 组），并且通常被视为[[无阈值致癌物]]。<sup>54</sup> 此外，苯胺在多个营养级上表现出显著的[[水生毒性]]，敏感终点包括低 mg/L 浓度下对藻类生长的抑制以及对鱼类和无脊椎动物的急性致死。<sup>53</sup>

在其他添加剂中，[[HMMM]] 和[[苯胺]]在目标分析物中占主导地位（>90%），这一特征似乎与[[车辆轮胎]]橡胶配方不同。<sup>55</sup> [[六甲氧基甲基三聚氰胺|HMMM]] 作为主要的[[粘合促进剂]]发挥作用，而苯胺通常不是直接添加剂，而是由基于苯胺的[[硫化促进剂]]和[[抗氧化剂]]衍生的[[转化产物]]或[[残留杂质]]。<sup>11,56</sup> 这些结果说明，与轮胎橡胶相比，[[橡胶坝|RDM]] 中橡胶添加剂及其转化产物具有独特的组成特征。在一条受道路影响的小溪中，[[六（甲氧基甲基）三聚氰胺|HMMM]] 通常与一系列[[醚化衍生物]]共同出现，<sup>30</sup> 表明在受橡胶影响的体系中 HMMM 同系物可能存在共同释放与共同出现。为捕获这些被目标分析方法遗漏的潜在衍生物，我们采用[[非目标分析]]对扩展的 HMMM 家族及 [[橡胶坝材料|RDM]] 中其他复杂组分进行全面筛查。

## [[RDM 提取物]]的疑似物与[[非目标分析]]

作为目标分析的补充，我们进行了疑似物与非目标筛查，以理解和注释 [[橡胶坝|RDM]] 中的其他化学物质。该方法初步鉴定出许多“新”化合物（即超出我们目标分析所监测的传统橡胶添加剂范围的化合物），包括相关化学物质的疑似[[转化产物]]以及一些“新”鉴定 $( \mathrm { i . e . , }$ 通过 MS/MS 推导出的暂定结构，据我们所知此前未见报道，既包括缺乏 [[CAS号|CAS 号]]的未表征结构，也包括仅在商业专利中记载的结构）。共鉴定出 83 个分子，其中 75 个被赋予暂定结构，且注释达到 [[Schymanski 置信水平]] 3 级或更高（表 2，详见图 2）。<sup>38</sup> 其他置信水平较低的已鉴定分子列于表 S8，而所有已鉴定分子的详细注释见 图 S3−S54。这些鉴定结果大多在结构上与已知橡胶添加剂相似。例如，检测到 m/z 359.2038，被归属为 $\mathrm { C _ { 1 4 } H _ { 2 7 } N _ { 6 } O _ { 5 } } ^ { + }$，镜像质量误差为 0.28 ppm，且[[同位素分布]]匹配，其与 [[HMMM]] $\left( \mathrm { C _ { 1 5 } H _ { 3 0 } N _ { 6 } O _ { 6 } } \right)$ 极为相似，仅相差一个[[甲氧基]] $\left( \mathrm { C H } _ { 3 } \mathrm { O } - \right)$ 基团（图 2A）。这一明显的 [[六甲氧基甲基三聚氰胺|HMMM]] 脱甲氧基产物，可能为[[四（甲氧基甲基）-甲基-（环氧乙烷-2-基）-三聚氰胺]]（TMOMel），此前曾在生菜中检出，<sup>57</sup> 这可能表明 [[六（甲氧基甲基）三聚氰胺|HMMM]] 在环境与生物过程中存在相似的转化途径。

为提供结构方面的信息，所有暂定鉴定且 [[Schymanski 置信水平]]达到 3 级或更高的化合物被归入六个结构与功能类别，以便于对新兴的橡胶衍生[[转化产物]]进行注释。这些类别包括与 [[HMMM]] 类似的化合物（如 [[四（甲氧基甲基）-甲基-（环氧乙烷-2-基）-三聚氰胺|TMOMel]]）、[[取代对苯二胺|PPDs]]（如 [[N-异丙基-N’-苯基-2-甲基-对苯二胺|2MIPPD]]）、[[4-ADPA]]（如 [[Butyryl-4-ADPA|Bu-4-ADPA]]）、胺类（如 [[N-甲基环己胺|NMCHA]]）和 [[2,2,4-三甲基-1,2-二氢喹啉|TMQ]]，以及其他种类，例如[[硫化促进剂]]、[[增塑剂]]、含氮杂环和酚类[[抗氧剂]]。例如，一个 m/z 255.1495 的产物显示出 185.1076 $\mathrm { ( C _ { 1 2 } H _ { 1 3 } N _ { 2 } } ^ { + } ,$ [[4-氨基二苯胺|4-ADPA]]，质量误差 = 1.62 ppm）的诊断碎片离子，表明其与 4-ADPA 相似。尽管其与 4-ADPA 的质量差 $\left( \dot { \mathrm { C } } _ { 4 } \mathrm { H } _ { 6 } \mathrm { O } \right)$ 可能归因于多个官能团，但 m/z 213.1027（C H 丢失）和 m/z 185.1073（CO 丢失）的产物离子揭示了丙基和羰基结构，从而明确其被鉴定为 butyryl-4-ADPA。若干新型 [[对苯二胺类抗氧剂|PPDs]]，如 [[N-异丙基-N′-苯基-2-甲基对苯二胺|2MIPPD]]，被暂定鉴定，其独特的 m/z 183.0923 $\left( \mathrm { C } _ { 1 2 } \mathrm { H } _ { 1 1 } \mathrm { N } _ { 2 } ^ { + } \right.$ ，质量误差 = 3.28 ppm）产物离子揭示了 4-ADPA 核心结构，而与 m/z 198.1152 离子的比较则揭示了甲基和异丙基特征。通过 SciFinder 数据库，鉴定出 N-isopropyl-N′-phenyl-2-methyl-p phenylenediamine（2MIPPD）。还鉴定出若干与 [[N,N-二环己基甲胺|DCMA]] 相似的结构（图 S6）。例如，一个 m/z 114.1277 产物通过丢失甲基（m/z 114.1287 → 98.0969）和氨基 $( m / z 9 8 . 0 9 6 9  8 3 . 0 8 4 7 )$ 基团而发生碎裂，并残留环己烷 $\left( \mathrm { C _ { 6 } H _ { 1 1 } } ^ { + } , m / z 8 3 . 0 8 5 5 \right)$ ，从而被鉴定为 N-methylcyclohexylamine（NMCHA）。NMCHA 通常作为辅助[[促进剂]]，与[[噻唑类促进剂|噻唑类]]或[[磺酰胺类促进剂|磺酰胺类]]配合使用，以调节硫化并增强[[交联]]。<sup>58</sup> 此前它曾被报道为 [[N,N′-二环己基甲胺|DCMA]] 的[[光解产物]]，并在中国广州的[[道路径流]]中被检出。<sup>59</sup> 除这些基于胺的目标物之外，扩展的可疑物筛查还揭示了一个高度氧化的 [[喹喔啉二亚胺类|QDIs]] 的独特簇（包括 [[6QDI]]、[[IQDI]]、[[N-苯基-对醌二亚胺|NPQDI]] 和 [[QDI−OH]]）。同时，特定的[[亚胺产物]]（[[6PPD-TP257]] 和 [[N-isopropylidene-TMQ-aniline|TMQ-TP331]]）以及属于 TMQ 家族的多种衍生物，包括 [[TMQ-TP307]]、[[TMQdimer]] 和母体 TMQ，均被注释。在 [[RDM 提取物]]中观察到高度氧化的 QDI、亚胺和 TMQ 物种值得注意，表明尽管具体添加剂配方存在差异，[[橡胶坝材料|RDMs]] 经历的转化途径与最近针对碎橡胶和[[车辆轮胎]]所表征的途径相似。<sup>12,60</sup> 它们的存在突出表明，这些转化产物组合的生成并不仅限于[[轮胎胎面磨损颗粒]]，而是在环境暴露下各种橡胶配方所共有的更广泛的普遍风化结果。

此外，本文比较了已鉴定化合物在多种样品类型和分子结构中的分布模式与特征（图3）。在新旧[[橡胶坝|RDM]]之间观察到明显差异。由于样品来自不同制造商，组成差异可能与配方不同或老化时间不同有关。尽管需要分析更多材料以确认这些趋势，但在新[[橡胶坝材料|RDM]]中检出若干[[HMMM]]衍生物，而在储存的（推测较旧的）样品中检出了更多PPD相关TP。已鉴定的[[六甲氧基甲基三聚氰胺|HMMM]]和PPD TP组成（图3B、C）提示可能存在[[臭氧氧化]]、[[羟基化]]、[[去甲基化]]和[[去甲氧基化]]途径，与储存过程中发生的转化一致。<sup>60,61</sup>因此，对于[[4-ADPA]]、[[4-HDPA]]、[[取代对苯二胺|PPDs]]和[[六（甲氧基甲基）三聚氰胺|HMMM]]，观察到多个共享部分化学结构的同系物，它们具有相同的[[Kendrick质量亏损]]，仅因烷基链长度不同而有所区分（图3D）。

## [[水相浸出]]

## [[充气橡胶坝|橡胶坝]]中的环境赋存

为验证材料研究的相关性，我们分析了从两座在用[[充气橡胶坝|橡胶坝]]或其附近采集的[[表面拭子]]和[[水样]]。这些样品通过[[无损表面拭子法]]采集，用于评估在用基础设施的化学组成和[[浸出潜力]]。

为模拟[[水驱动浸出]]，我们选择水湿润拭子而非[[溶剂型拭子]]，以对[[充气橡胶坝|橡胶坝]]表面可利用的化学物质进行半定量评估。在能够采样的[[橡胶坝]]中（许多橡胶坝不安全或无法接近采样），我们在橡胶坝拭子样品（浓度表示为化学物质质量/被拭取表面颗粒质量）或邻近[[水样]]中检出多种 PPD、其[[转化产物]]或其他目标添加剂（表 S11）。与[[固液比]]的预期一致，环境样品中的浓度普遍低于[[静态浸出试验]]中观察到的浓度。我们推测，表面拭取仅捕获了可浸出表面污染物总量的一部分，因此提供了保守估计。与固定体积的实验室装置相比，环境样品在动态河流系统中还表现出显著的[[稀释效应]]。<sup>70</sup> 浸出过程既取决于表面积，也取决于材料表面与环境的先前接触历史，而这些因素并未通过[[批量浸出研究]]加以评估。作为室内浸出研究的补充，橡胶拭子数据有助于初步评价坝体材料的[[面积归一化|面积归一化污染物浸出潜力]]。根据平均拭取接触面积 49 cm<sup>2</sup> 计算，从在用橡胶坝回收的颗粒面积归一化质量范围为 4700 至 47,000 mg/m<sup>2</sup>，而 [[6PPDQ]] 的面积归一化质量为 0.06−1.8 μg/m<sup>2</sup>。[[6PPD醌|6PPDQ]] 质量相对于回收颗粒总质量的中位浓度为 0.011 μg/g（范围：< LOD−0.23 μg/g，表 S11），低于通常报道的纯轮胎磨损颗粒浓度。<sup>35</sup> 鉴于[[可浸出性]]取决于拭取面积、力度和表面状况，我们建议开展更多研究以提高这些估算的准确性。

在一处正在使用的[[充气橡胶坝|充气橡胶坝设施]]中采集的[[水样]]表明存在可检测的[[环境释放]]。在该地点，[[6PPDQ]] 浓度从坝上游的 0.15 μg/L 增加至紧邻坝下游的 0.25 μg/L，尽管根据已收集的数据，我们无法得出这些结果具有统计学显著性的结论。这些浓度超过了已发表的对 [[6PPD醌|6PPDQ]] 敏感的[[鲑科鱼类]]的 24 h $\mathrm { L C } _ { 5 0 }$ 值。<sup>71,72</sup> 尽管跨坝浓度梯度提示存在[[主动浸出]]，但上游浓度的升高表明还存在其他 [[N-(1,3-二甲基丁基)-N′-苯基对苯二胺醌|6PPDQ]] 来源，可能反映了残留的[[道路径流]]或其他来源贡献，以及可能解释局部浓度变化的[[水力效应]]。<sup>18,73</sup> 需要在干燥和潮湿天气条件下进行额外样品采集，以更好地记录[[橡胶坝]]释放橡胶衍生化学物质的程度。

[[充气橡胶坝|橡胶坝]]可能释放污染物这一点，还得到更广泛化合物组合的进一步支持。除

[[6PPDQ]] 外，其他几种橡胶衍生化合物，包括 [[IPPDQ]]、[[1,3-DMBA]]、[[4-ADPA]] 和 NCBAs，仅在坝下游检出（图 S55）。[[IPPD醌|IPPDQ]] 的检出最为值得注意，并且与在 [[橡胶坝|RDM]] 材料中鉴定出的以 [[IPPD]] 为主的化学特征一致。为专门应对这一[[来源归因|来源归因挑战]]，IPPDQ 与 [[6PPD醌|6PPDQ]] 浓度之比成为一种潜在的[[诊断工具]]，可利用 [[橡胶坝材料|RDM]] 与[[车辆轮胎]]之间不同的[[添加剂谱]]。虽然轮胎衍生材料通常以较低的 IPPDQ:[[N-(1,3-二甲基丁基)-N′-苯基对苯二胺醌|6PPDQ]] 比值为特征，例如轮胎中的[[中位比值]]为 0.03，<sup>29</sup> 尽管配方存在一定的地区差异，但 RDM [[有机提取物]]和水浸出液分别表现出 179 和 29 的高 IPPDQ:6PPDQ 中位比值。值得注意的是，这一特征在下游[[受纳水体]]中得到体现，其 IPPDQ:6PPDQ 比值为 5.0（1.3 μg/L 对 0.25 μg/L），而上游站点由于未检出 IPPDQ，该比值为 0。由于不同制造商的[[专有配方]]可能存在很大差异，这些发现提供了一个初步基线，而非穷尽性的通用清单。最终，这些数据凸显出[[充气橡胶坝|橡胶坝]]是橡胶衍生污染物的[[离散点源]]；要准确界定它们在复杂[[流域]]中相对于[[道路径流]]的具体贡献，还需要未来的[[时空采样]]以及对商用 RDM 产品的广泛分析。

检测到的多种污染物对水生生态系统构成危害。例如，根据[[危害通识标准]]，[[4-HDPA]] 被认定为对鱼类剧毒，<sup>74</sup> 在[[弹性体]]膜渗滤液中表现出[[雌激素活性]]，<sup>75</sup> 并且在高于环境中观测浓度的水平下可产生[[急性毒性]]（对[[蜉蝣]] [[Neocloeon triangulifer]] 的 96 h 中位 $\mathrm { L C } _ { 5 0 }$ 为 0.34 mg/L）。<sup>76</sup> [[4-ADPA]] 被归类为对水生 $\mathrm { l i f e } , ^ { 7 7 }$ 剧毒，对鱼类具有高毒性（[[斑马鱼]] Danio rerio 96 h $\mathrm { L C } _ { 5 0 }$ 为 1.1 mg/L），可诱导固定不动（48 h $\mathrm { E C } _ { 5 0 } 0 . 2 8 \mathrm { m g / L ) }$ ），是一种[[生殖毒物]]（对[[大型溞]] Daphnia magna 的 21 天慢性[[无观测效应浓度]] ≤0.01 mg/L），<sup>78</sup> 并在浓度低至 0.01 mg $/ \mathrm { L } . ^ { 7 7 , 7 9 }$ 时对藻类和水生大型植物具有危害。同样，[[4-NDPA]] 也具有毒性，对[[黑头呆鱼]]的 96 h $\mathrm { L C } _ { 5 0 }$ 为 2.4 mg/L，对大型溞的 48 h $\operatorname { E C } _ { 5 0 }$ 为 1.0 mg/L，对[[近头状伪蹄形藻]] P. subcapitata 的 96 h $\mathrm { E C } _ { 5 0 }$ 为 27 mg/L。<sup>80</sup> 在斑马鱼中，[[2-ABT]] 可通过[[铁死亡]]引起[[氧化损伤]]，导致供氧中断和[[心脏畸形]]。<sup>81</sup> 虽然这些分析物的环境浓度常常远低于其急性 $\mathrm { L C } _ { 5 0 } \mathrm { o r E C } _ { 5 0 } ,$ ，但它们的存在可能带来生态风险。越来越多的证据还表明，长期暴露于亚致死浓度可导致[[慢性毒性]]和[[发育损害]]。<sup>82</sup> 正如[[受纳水体]]中常见的情况，这些化学物质以[[复杂混合物]]形式存在，其各自处于“无效应”水平的浓度可通过加和或协同机制联合引发不良效应。<sup>83</sup>

## ■ 环境意义

尽管[[充气橡胶坝]]因其运行灵活性和成本效益而受到重视，但它们对于局部生态系统而言是一个被低估的化学污染物来源。与[[车辆轮胎]]类似，这些结构可释放橡胶添加剂及相关[[转化产物]]的[[复杂混合物]]，包括 [[6PPDQ]]、[[4-HDPA]]、[[4-ADPA]]、[[4s DPA]]、[[4-NDPA]] 和 [[HMMM]]、[[苯胺]]、[[2,4-MoBT]]、[[2-氨基苯并噻唑|2ABT]] 和 [[2-HBT]]，以及其他暂定鉴定的化合物。虽然我们的现场采样范围有限，但在运行中坝体附近的观测表明，暴露风险并非仅仅是假设。尽管[[道路径流]]等来源可能对观测浓度有所贡献，但检测到与[[橡胶坝材料]]相关的标志物（例如 [[IPPDQ]]）表明，大型橡胶基础设施是额外的局部[[点源]]，可能对总体暴露产生贡献。其他橡胶衍生的污染物在[[橡胶坝]]材料渗滤液中含量丰富，包括 [[Butyryl-4-ADPA|Bu-4-ADPA]]、[[N-(2-羟基己-5-烯-1-基)-N'-苯基对苯二胺|HHEPPD]]、[[N-异丙基-N’-苯基-2-甲基-对苯二胺|2MIPPD]] 和 [[N-异亚丙基-N’-苯基-对苯二胺|IdPPD]]。为了更好地了解其环境风险，未来研究应开展[[时空采样]]，以明确解析污染物来源，并对这些橡胶添加剂组分进行全面毒性评估。

对初步鉴定的污染物进行优先级排序对于环境管理至关重要。由于实验终点不一致，难以直接进行风险比较，我们采用计算机模拟模型建立了一个可比较的优先级排序框架。这一统一筛选将 [[N-(4-(丙氨基)苯基)-4-(对甲苯氧基)苯胺|PrA-TOA]]、c6PPD、[[N-苯基-N'-(4-(叔戊基)苯基)-对苯二胺|tPent-DPPD]]、PhOH 和 [[N-(4-苯氨基苯基)-2-(环己叉基)丙烯酰胺|CyP-4-ADPA]] 列为最具危害性的污染物检出物（表 S12），模型预测其可能通过血脑屏障渗透对中枢神经系统产生潜在影响（表 S13）。这些高毒性化合物与大量未表征的同系物共同出现，使[[充气橡胶坝|橡胶坝]]的风险状况更加复杂，而历史上[[橡胶坝]]的风险管理更侧重水文影响，而非长期化学[[浸出潜力]]。我们强调，这种计算机模拟毒性优先级排序主要作为一种筛查工具，用于识别潜在关注化合物。尽管这些预测突出了化学物质的固有危害，但橡胶源化学品在河流生态系统中的实际生态风险最终将取决于若干环境因素，包括暴露浓度、浸出动态、持久性与[[生物可利用性]]、物种敏感性分布、环境条件以及潜在的混合物相互作用。

这些发现对正在使用或计划扩大[[充气橡胶坝|橡胶坝]]应用的地区具有参考意义。例如，在加利福尼亚干旱地区，[[橡胶坝]]在干旱期间（D2 等级）用于应急储水。强烈的太阳辐射、紫外线降解以及干旱期间的季节性干湿循环等条件，可能加速 [[6PPD]] 的转化，并在稀释水量有限时引发间歇性释放。其他因素，包括环境温度（直接影响扩散速率和转化动力学）、流动河流条件、湍流、生物膜形成、沉积物相互作用以及长期老化过程，也可能影响浸出动态。在太平洋西北地区及其他地方的多个[[流域]]，已有此类橡胶坝的拟建计划，其中部分流域同时也是对 [[6PPDQ]] 敏感物种的栖息地。因此，有必要对[[橡胶坝材料]]的化学成分和[[浸出潜力]]进行前瞻性、系统性的评估。未来工作应优先开展符合现场实际条件的长期浸出和风化实验，并结合安装地点的空间分辨采样。这些工作，连同标准化浸出协议和“更绿色”橡胶配方的开发，对于准确评估和减轻橡胶化[[水基础设施]]的环境风险至关重要。
