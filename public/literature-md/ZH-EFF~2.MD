# 通过集成[[界面工程|界面工程增强]][[碳毡]][[吸附]]与光化学过程实现污染水体中短链及新兴[[PFAS]]的高效浓缩与完全破坏

## 摘要

短链和新兴[[全氟和多氟烷基物质|全氟及多氟烷基物质]]（[[PFAS]]）因其高[[迁移性]]和[[环境持久性]]而对水安全构成重大威胁。当前仅依赖[[吸附]]或降解的策略仍然效率低下且解决方案不完整。本文提出了一种闭环“浓缩-破坏”策略，将[[界面工程|界面工程增强]]的[[聚吡咯]]（PPy）纳米结构涂层[[碳毡]]（[[聚吡咯修饰碳纤维|PPy@P-CF]]）吸附剂与$\mathrm { C u } ^ { 2 + }$介导的[[光化学破坏]]相结合。该设计的PPy@P-[[碳纤维|CF]]能够快速高效地吸附[[短链PFAS]]（C2–C4）和新兴的[[GenX]]，在300秒内达到平衡，[[最大吸附容量]]达到283.2–572.1 mg $\mathbf { g } ^ { - 1 } ,$，在相同条件下分别超过[[颗粒活性炭]]（[[椰壳活性炭|GAC]]）和碳毡（CF）21倍和5倍以上。[[动态柱实验]]表明，与GAC和CF柱相比，[[穿透体积]]提高了5倍（超过4000[[床体积]]）。此外，使用后的PPy@P-CF可通过[[溶剂洗涤]][[再生]]以实现重复使用，且$\mathrm { C u } ^ { 2 + }$介导的[[光化学降解]]通过[[配体到金属的电荷转移]]过程在5小时内实现了洗脱液中浓缩PFAS的完全[[脱氟]]。在实际应用中，一个批量PPy@P-CF模块从实际污染水体中去除了27种不同PFAS的96%以上，随后实现了完全的光化学脱氟。这种集成方法为消除持久性短链和新兴PFAS提供了一种可采用的解决方案。

## 1 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）包含超过 16 000 种合成化合物，自 20 世纪中叶以来因其独特的化学稳定性和热稳定性，已在工业和消费品领域得到广泛应用 [1–3]。强 [[碳-氟键|C–F 键]]（536 kJ mol<sup>−1</sup>）使 PFAS 具有高度持久性、[[生物累积性]]，并普遍存在于全球自然水体和[[废水]]系统中，检测浓度范围从 ng/L 到 g/L [4–7]。越来越多的流行病学证据将 PFAS 暴露与严重的健康风险联系起来，包括[[神经毒性]]、[[免疫毒性]]和[[致癌性]] [8–10]。为此，监管限值日益严格；例如，2024 年 4 月 10 日，[[美国环境保护署]]（U.S. EPA）在饮用水中制定了[[全氟辛酸]]（PFOA）的[[最大污染物水平]]为 4.0 ng $\mathrm { L } ^ { - 1 }$，[[六氟环氧丙烷二聚酸]]（HFPO-DA，商品名 [[GenX]]，一种新兴的多氟替代品）为 10.0 ng $\mathrm { L } ^ { - 1 }$ [11]。使这一挑战更加严峻的是，短链 $\left( \mathrm { C } < 6 \right)$ 和新兴 PFAS 的出现率不断上升，它们由于[[亲水性]]更强而具有更高的[[迁移性]]，并对传统去除技术表现出更强的抵抗力 [12–14]。

为应对水中 [[PFAS]] 污染，已发展出多种策略，例如[[吸附]]、[[光催化]]、[[电化学氧化]]、[[高级氧化与还原]]以及[[热化学处理]] [15–17]。其中，吸附因其操作简单且具有打破“永久化学品”循环的潜力而被最广泛采用 [18, 19]。然而，传统吸附剂（包括[[颗粒活性炭]]（[[椰壳活性炭|GAC]]）和[[离子交换树脂]]（IERs））主要对长链 [[全氟和多氟烷基物质|PFAS]]（C ≥8）有效，但对短链及新兴同系物的亲和力有限。这一局限在复杂水体基质中的超短链[[三氟乙酸]]（[[TFA]], C2）上尤为突出，原因在于其更强的[[亲水性]]、高[[迁移性]]和较小的分子尺寸 [20–22]。例如，在环境相关浓度下（[GAC] = 10 mg L<sup>−</sup>1，$[ \mathrm { P F A S } ] _ { 0 } =$ 1 g L<sup>−1</sup>），GAC 对 TFA 和[[全氟丁酸]]（[[PFBA]], C4）的[[去除效率]]低于 40%，而对 [[全氟辛酸|PFOA]]（C8）的去除效率则超过 60% [23]。因此，开发能够从真实水体系中捕获多种短链及新兴 PFAS 的高容量、快速吸附剂仍然是一个关键空白。此外，尽管吸附能够浓缩 PFAS，但并不能实现其破坏，并会产生二次废物流，例如高度污染的[[再生]]液，这带来了显著的处置挑战 [24–27]。近年来，针对物理富集的局限性，[[光催化降解]]已成为一种有前景的破坏性技术，利用光诱导活性物种（例如[[羟基自由基]] <sub>∙</sub> + $( { { \bf { e } } _ { \mathrm { { a q } } } } ^ { - } ) )$）在环境条件下将 PFAS [[矿化]] [28–30]。值得注意的是，$\mathrm { C u } ^ { 2 + }$ 介导的[[光化学破坏|光化学降解]]利用了 PFAS 羧酸根与金属中心之间的配位作用，在 [[365 nm LED]] 辐照下实现[[配体到金属的电荷转移]]（[[配体到金属电荷转移|LMCT]]）。该方法为传统催化方法提供了一种更温和且更节能的替代方案，具有低能耗和操作简单的特点 [28–30]。在此，我们提出一种将基于吸附的浓缩与光催化破坏相结合的一体化处理策略。吸附将大体积水体中的痕量 PFAS 预浓缩到小体积洗脱液中，从而实现高效且节能的光降解 [31, 32]。至关重要的是，仅辐照浓缩后的洗脱液而非整个大体积水体，该过程可在不牺牲降解性能的情况下实现显著的节能 [31, 32]。

三维（3D）柔性碳材料（如[[碳毡]]（[[碳纤维|CF]]））具有结构优势，包括互连的大孔网络、机械稳健性和可定制几何形状，使其在多种场景下的水处理应用中日益受到关注 [33, 34]。

然而，其固有的疏水性和带负电的表面限制了与[[亲水性]]且带负电的[[短链PFAS|短链 PFAS]]（如 [[TFA]] 和 [[PFBA]]）的有效相互作用。我们之前的工作表明，用[[聚吡咯]]（PPy）纳米颗粒修饰[[生物炭]]表面可以通过[[静电相互作用]]增强 [[PFAS]] [[吸附]] [35]。相反，[[全氟和多氟烷基物质|PFAS]] 去除性能的提升牺牲了生物炭的大部分孔隙（修饰后[[BET|比表面积]]（[[比表面积|SSA]]）下降 300%），这限制了 PPy 修饰生物炭的潜在[[吸附容量]]。因此，我们假设通过在[[三维碳材料]]表面包覆聚苯胺（PPy）纳米膜进行[[界面工程]]，可以同时保留其固有孔隙结构并精确调控表面化学，以增强局域电场。这种双重功能能够高效预浓缩真实污染水体中的多种 PFAS，从而促进后续对废弃吸附剂[[再生]]所得 PFAS 浓缩洗脱液的[[光催化降解]]，并推动该集成工艺在大规模水处理中的可扩展性。

在本研究中，我们通过引入[[界面工程|界面工程增强]]型[[碳纤维]]（[[碳毡|CF]]）[[吸附]]剂并耦合[[光化学破坏|光化学降解]]，解决了从污染水中去除超短链、短链和新兴 [[PFAS]] 的关键挑战。我们在 CF 上构建了 [[聚吡咯|PPy]] 纳米结构涂层（[[聚吡咯修饰碳纤维|PPy@P-CF]]；图 1a），以克服传统吸附剂对[[亲水性]]且结构复杂的 [[全氟和多氟烷基物质|PFAS]] 亲和力差的局限性。本研究的目标是高效浓缩并彻底降解污染水体中的短链和新兴 PFAS。我们开展了系统评价，包括全面的材料表征、批式和[[动态柱实验]]，以及对 27 种额外 PFAS 的评估，涵盖通过[[非靶向分析]]在实际 PFAS 污染天然水和[[废水]]中鉴定出的传统和新兴 PFAS。除优异的吸附性能外，本工作还展示了一种闭环“[[浓缩-降解策略|浓缩-销毁]]”策略：吸附后，负载 PFAS 的 PPy@P-CF 被高效[[再生]]，浓缩在洗脱液中的 PFAS 在温和条件下通过 $\mathrm { C u } ^ { 2 + }$ 介导的光化学过程被完全降解和[[脱氟]]。来自[[分子动力学模拟]]（MDS）和光谱分析的机理见解阐明了[[孔隙限域]]、静电吸引和[[界面传质]]在吸附过程中的作用。通过将高效 PFAS 浓缩与完全[[矿化]]相结合，本研究为减轻水体中持久性和[[迁移性]] PFAS 的全球负担提供了一条可采纳的技术路径。

## 2 结果与讨论

## 2.1 通过[[界面工程|界面工程增强]][[表面电场]]并保留孔隙

一种通过[[聚吡咯|PPy]]纳米涂层增强[[界面工程]]的策略被提出，用以在保持[[碳毡|CF]]多孔结构的同时强化[[表面电场]]，如图1a中[[聚吡咯修饰碳纤维|PPy@P-CF]]的案例所示。具体而言， $\mathrm { C F } _ { 7 0 0 }$ 由相互交织的[[碳纤维]]组成，表面光滑平整，形成具有丰富大孔的巢状结构（图1b）。相比之下，PPy涂层中碳纤维的表面 $\mathrm { C F } _ { 7 0 0 } \ ( \mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } { \cdot } \mathrm { C F } _ { 7 0 0 } )$ 变得明显更加粗糙，但整体形貌仍与 $\mathrm { C F } _ { 7 0 0 }$ (图1c)。此外，在 $\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 与未改性样品相比 $\mathrm { C F } _ { 7 0 0 } .$ . 这种形貌变化证实了聚[[吡咯]]（PPy）成功沉积到 $\mathrm { P _ { 1 } - C F _ { 7 0 0 } } ,$ , 这与我们先前关于[[磷掺杂]]不会改变原始碳材料形貌的发现一致 [36]。[[聚焦离子束扫描电子显微镜]]（FIB-[[SEM]]）截面分析进一步表明，碳纤维上存在厚度约为 80.2 nm 的均匀 PPy 纳米薄膜， 表明 $\mathrm { P _ { 1 } { - } C F _ { 7 0 0 } }$ 表面获得了有效且均匀的包覆（图 1c）。此外，经 PPy 纳米包覆后，$\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 中的 N 含量由 2.4% 急剧增加至 9.1%（图 1d 和图 S1）。由于 PPy 属于有机胺类聚合物，$\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 中 N 含量的增加进一步证实了在三维 CF 上成功构建了 PPy 纳米包覆层。

为进一步在分子水平上理解[[吸附]]机制，开展了[[分子动力学模拟]]（MDS）计算。如 Figure $^ { 4 \mathrm { e } , }$ 所示，[[聚吡咯|PPy]] 层降低了水-固界面处由固体吸附剂疏水性引起的排斥力，增强了 $\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 的润湿性与正电性，并促进了亲水且带负电的 [[PFBA]] 分子向吸附剂表面的传质 [15]。MDS 结果还表明，[[全氟丁酸|PFBA]] 吸附在 PPy 层 ofPPy $\phantom { 0 } { 1 } \textcircled { \scshape A } P _ { 0 . 5 } \ – \mathbf { C }  { \mathrm { F } } _ { 7 0 0 }$ 上，其羧基头基与 [[胺官能团|AFGs]] 相互作用，而其 C-F 链尾垂直于表面取向，这凸显了 AFGs 在 [[PFAS]] 结合中的重要性。相比之下，对于疏水性的 $\mathrm { C F _ { 7 0 0 } , }$ ，水-固界面严重阻碍了 PFBA 的靠近，导致其[[吸附容量]]较低（Figure S10）。为评估这一机制性认识的普适性，我们将 MDS 分析扩展至 [[全氟辛酸|PFOA]]（一种代表性的长链 [[全氟和多氟烷基物质|PFAS]]）。如 Figure 4f 所示，PFOA 也表现出类似趋势：尽管其头基同样与 $\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 } .$ 上的 AFGs 相互作用，但在与未改性的 $\mathrm { C F } _ { 7 0 0 }$ 相互作用时，它倾向于停留在水相中（Figure S11）。这种跨不同 PFAS 的一致行为证实，PPy 纳米层从根本上改变了 $\mathrm { C F } _ { 7 0 0 } .$ 的表面特性，从而有利于 PFAS 吸附。值得注意的是，与 PFBA 不同，PFOA 较长的[[全氟烷基链]]采取了与 PPy 表面平行的取向（Figure 4f），这可归因于该链与吸附剂表面之间的[[疏水相互作用]] [22]。总之，$\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 对 PFAS 表现出高吸附性能，且不受其 C-F 链长影响。短链及新兴 PFAS 固有的[[亲水性]]通常会抑制其从水相向疏水性吸附剂表面迁移。然而，PPy 纳米涂层不仅改善了吸附剂表面的亲水性，以缓解水-固界面处的传质阻力，还增强了[[表面电场]]，从而能够快速、高效地吸附这些亲水性 PFAS。

## 2.5 [[吸附]]后 [[PFAS]] 的[[光催化降解]]及其机制

[[聚吡咯修饰碳纤维|PPy@P-CF]]的高性能[[吸附容量]]实现了[[PFAS]]的高效富集，但并不能永久去除[[全氟和多氟烷基物质|PFAS]]。此外，对PFAS进行[[脱附]]以实现[[聚吡咯|PPy]]@P-[[碳毡|CF]]的[[再生]]与重复使用，也是评估其实际应用性的必要环节。基于“相似相溶$\mathrm { l i k e } ^ { \prime \prime }$原理的[[溶剂洗涤]]，是一种广泛用于再生失效[[吸附]]剂的技术[22]。然而，该过程会产生含有高浓度PFAS的有机废液，给后续处理带来巨大挑战。为此，我们开发了$\mathrm { ~ a ~ } ^ { \ast } \mathrm { C }$oncentrate-&-Destroy”策略，包括PFAS的吸附、脱附以及洗脱液中的光降解，以应对上述局限（图5a）。选取[[TFA]]、[[PFBA]]和[[GenX]]作为代表性PFAS，评估再生效率。使用0.1 mol/L [[氢氧化钠|NaOH]]水溶液/[[乙腈]]（1:999，v:v）混合溶液，无论C‒F链长如何，近100%的吸附态PFAS均可从吸附剂上洗脱。再生后的吸附剂在至少五个连续[[吸附-脱附循环]]中仍保持较高的PFAS[[去除效率]]（>95%）（图S12）。随后，收集的洗脱液（富集倍数为25）经[[365 nm LED]]照射300 min，实现了[[三氟乙酸|TFA]]、[[全氟丁酸|PFBA]]和[[六氟环氧丙烷二聚酸|GenX]]的完全降解（100%）和完全[[脱氟]]（100%）（图5b）。对降解产物的靶向分析表明，TFA和[[全氟丙酸]]（PFPrA）分别是PFBA（0–60 min）（图5c）和GenX（最长至180 min）（图5d）降解过程中的中间产物。对于超短链TFA，在120 min内未检出中间产物（图5c）。反应结束时，[[高效液相色谱-串联质谱]]（HPLC-MS/MS）色谱图中[[目标PFAS]]及含氟中间产物的完全消失，证实了三种PFAS均被彻底降解（图5c,d）。

真实水体中的多种成分，尤其是溶解性有机物和无机物，可能通过竞争光子或清除活性物种而抑制基于紫外的 [[PFAS]] 降解 [29]。尽管存在这一挑战，我们的集成方法仍成功实现了实际污染水体洗脱液中全部 27 种 [[全氟和多氟烷基物质|PFAS]]（来自靶向和[[非靶向分析]]）在 5 h 紫外照射后的完全光降解（图 6c）。该结果表明，集成[[界面工程|界面工程增强]][[碳毡]][[吸附]]与光降解策略具有广谱降解效能和较强的实际应用潜力。这种“[[浓缩-降解策略|浓缩-销毁]]”技术通过克服传统吸附技术的关键局限——即[[再生]]困难以及无法销毁 PFAS，有效打破了 PFAS 的“永久循环”。作为概念验证，本研究提出了一种集成“吸附浓缩-光化学销毁”的 PFAS 污染水体修复策略。该方法利用 [[聚吡咯修饰碳纤维|PPy@P-CF]] 吸附剂的高[[吸附容量]]和形貌可调性，随后通过光降解步骤在环境友好且操作温和的条件下实现完全[[脱氟]]。未来工作将在实际流通构型和多个运行周期中评估光降解步骤的有效性与稳健性，以严格评价该策略的可扩展性、实际适用性和长期可持续性。

## 3 结论

本研究展示了一种高效的“[[浓缩-降解策略|浓缩-销毁]]”策略，利用 3D [[聚吡咯修饰碳纤维|PPy@P-CF]] 与 [[配体到金属电荷转移|LMCT]] 光化学系统相结合，实现污染水体中超短链、短链和新兴 [[PFAS]] 的高效浓缩与彻底销毁。所设计的 $\mathrm { P P y } _ { 1 } @ \mathrm { P } _ { 0 . 5 } – \mathrm { C F } _ { 7 0 0 }$ 具有均匀、正电性的[[聚吡咯]]纳米涂层（约 80.2 nm），在保持 [[碳毡|CF]] 大孔结构的同时显著增强[[表面电场]]。该设计实现了超快[[吸附动力学]]（平衡时间 < 300 s）和优异的吸附容量，TFA 最高可达 283.2 mg $\mathbf { g } ^ { - 1 }$，PFBA 为 572.1 mg $\mathbf { g } ^ { - 1 }$，GenX 为 510.2 mg $\mathbf { g } ^ { - 1 }$，分别是 GAC 和未改性 CF 的 5.1–6.5 倍。在动态柱实验中，该材料表现出优异性能，TFA、PFBA 和 GenX 的 $\mathrm { B V } _ { 1 0 }$ 均超过 4000 BV，显示出在连续处理应用中的强大潜力。此外，PPy@P-CF 对实际污染水体基质（包括废水、地表水和地下水）中的 27 种靶向及新兴 PFAS 实现了 > 96% 的去除率。该材料在五次[[吸附]]-[[再生]]循环中还表现出优异的可重复使用性。关键的是，再生洗脱液中浓缩的 [[全氟和多氟烷基物质|PFAS]] 通过 $\mathrm { U V - L E D } / \mathrm { C u } ^ { 2 + }$ 光化学过程在 5 h 内被完全降解并[[脱氟]]，打破了 PFAS 的永久循环。机理研究表明，PPy 层改善了[[界面传质]]并促进[[静电相互作用]]，从而能够高效捕获[[亲水性]] PFAS。这种集成的“浓缩-销毁”策略不仅克服了传统吸附技术的局限，还为多种水处理场景中的 PFAS 修复提供了一种可采用的解决方案，并为下一代功能化 3D 碳材料在环境应用中的应用提供了指导。

## 4.1 化学品与材料

商业[[碳纤维]]（[[碳毡|CF]]）（厚度 0.2 cm；[[孔隙率]] 85%；灰分含量 150 ppm；密度 0.55–0.60 g/cm<sup>3</sup>；纵向拉伸强度 100–160 MPa，横向拉伸强度 20–25 MPa；热稳定性：惰性气体中 $2 7 5 0 ^ { \circ } \mathrm { C }$，空气中 380<sup>◦</sup>C）购自[[上海砺硕复合材料科技有限公司|中国上海砺硕复合材料科技有限公司]]。化学试剂和材料的完整清单见文本 S2。[[TFA]]、[[PFBA]] 和 [[GenX]] 的单标标准储备液以甲醇配制，浓度为 $1 - 5 0 ~ \mathrm { ~ g ~ } \mathrm { ~ L ~ } ^ { - 1 }$。16 种目标 [[PFAS]] 及其详细信息（如供应商和内标）列于表 S7。除非另有说明，实验过程中均使用电阻率为 18.2 MΩ⋅cm 的 [[Milli-Q 水]]。[[吸附]]性能以文献中广泛报道和使用的椰壳 [[椰壳活性炭|GAC]] 吸附剂（[[上海阿拉丁生化科技股份有限公司|中国上海阿拉丁生化科技股份有限公司]]；文本 S2）为基准进行对照。

## 4.2 [[吸附]]剂的制备与表征

[[磷掺杂碳纤维]]（P-doped [[碳毡|CF]]）通过将非磷生物质与 ${ \mathrm { K H } } _ { 2 } { \mathrm { P O } } _ { 4 }$ [[共热解]]制备，依据我们此前报道的方法，以限制 $\mathrm { F e } ^ { 3 + }$ 诱导 [[聚吡咯|PPy]] 纳米涂层的形成 [40]，并记作 $\mathrm { P } _ { m } \mathrm { - C F } _ { n } ,$，其中 m 表示 ${ \mathrm { K H } } _ { 2 } { \mathrm { P O } } _ { 4 }$ 与原始 [[碳纤维|CF]] 的不同质量比（0、0.5、1 和 2），n 表示热解温度（500–900<sup>◦</sup>C）。[[聚吡咯修饰碳纤维|PPy@P-CF]] 复合材料（1.0 cm × 1.0 cm × 0.2 cm）通过一种新型原位 ${ } ^ { \mathfrak { s } } \mathrm { F e } ^ { 3 + }$ -限域”[[氧化聚合]]法合成（图 1a），并记作 $\mathrm { P P y } _ { x } @ \mathrm { P } _ { m } \boldsymbol { \cdot }$ $\mathrm { C F } _ { n }$（其中 x 表示合成过程中[[吡咯]]单体的添加体积（0、0.5、1.0 和 2.0 mL））。P-CF 和 PPy@P-CF 的详细制备步骤见文本 S3。

所制备材料的形貌、结构和化学组成通过配备[[能量色散谱]]（EDS）的[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）、[[聚焦离子束扫描电子显微镜|FIB-SEM]]、自动化学[[吸附]]分析、[[X射线光电子能谱|X 射线光电子能谱]]（[[XPS]]）、[[傅里叶变换红外光谱|傅里叶变换红外]]（[[FTIR]]）光谱以及 [[zeta电位|zeta 电位]]分析进行表征（文本 S4）。

## 4.3 [[PFAS]] [[吸附实验]]

[[批量吸附实验]]的操作如下：将 150 mg [[聚吡咯修饰碳纤维|PPy@P-CF]] 置于 50 mL [[聚丙烯离心管]]中，与 50 mL 水溶液接触，在 180 rpm 的振荡器上于 25<sup>◦</sup>C 下进行。向离心管中加入[[吸附]]剂和去离子水后，吸附体系预平衡 2 h，随后加入指定量的 [[PFAS]] 储备液（甲醇含量 $\leq 0 . 1 \% )$ 。吸附体系的 pH 为 $6 . 5 \pm 0 . 1$，未进行调节。吸附结束后，采集 1.0 mL 悬浮液，并通过 0.22 m [[聚醚砜膜]]过滤，用于后续 [[高效液相色谱-串联质谱|HPLC-MS/MS]] 浓度分析。在单组分[[吸附动力学]]实验中，[[TFA]]、[[PFBA]] 和 [[GenX]] 的初始浓度为 100 µg $\mathrm { L } ^ { - 1 }$，代表 [[全氟和多氟烷基物质|PFAS]] 污染源点附近的环境相关浓度；在每个预定时间点（0–48 h），采集悬浮液样品进行 HPLC-MS/MS 分析。在[[吸附等温线|吸附等温线实验]]中，采用 1 至 500 mg $\mathrm { L } ^ { - 1 }$ 这一相对较高的 PFAS 浓度范围，以尽可能考察 [[聚吡咯|PPy]]@P-[[碳毡|CF]] 的[[最大吸附容量]]，并将悬浮液振荡 24 h 以达到平衡。然后采集 1.0 mL 悬浮液，并根据校准曲线范围进行稀释，再进行 HPLC-MS/MS 分析。[[穿透实验]]在自制的 PFAS 捕集柱（内径 = 12 mm）上进行（柱体及预处理细节见文本 S5）。将加标 PFAS 的水（每种 PFAS 为 $( 5 . 0 ~ \mu \mathrm { g } ~ \mathrm { L } ^ { - 1 }$）以 3.0 mL min<sup>−1</sup> 的流速泵入柱中，并按预定时间间隔收集 1.0 mL 滤液，于 4<sup>◦</sup>C 下保存，用于 HPLC-MS/MS 分析。仪器分析、质量控制和数据分析的详细内容见文本 S1。

## 4.4 [[分子动力学模拟|MDS]]

为了更深入地了解 [[聚吡咯|PPy]] 纳米涂层增强[[短链PFAS|短链 PFAS]] [[吸附]]的机制，采用 [[分子动力学模拟|MDS]] 计算对该过程进行了模拟。使用[[石墨烯]]片层来模拟疏水性 [[碳毡|CF]] 表面。[[全氟辛酸|PFOA]]、[[PFBA]] 和 PPy 使用 [[Gaussian 09]] 在 [[B3LYP]] 水平下，并采用 $6 { \cdot } 3 1 \mathrm { G } ( \mathrm { d } , \mathsf { p } )$ 基组进行参数化，以生成每个分子的[[静电势]]图。使用尺寸为 32 $\mathring { \mathrm { A } } \times 3 8 \mathring { \mathrm { A } } \times 5 9 \mathring { \mathrm { A } }$ 的较大[[超胞]]进行[[吸附实验]]，该超胞通过复制原胞构建。有关 MDS 计算的全部细节见文本 S6。

## 4.5 [[吸附]]剂[[再生]]后洗脱液中 [[PFAS]] 的[[光化学破坏|光化学降解]]

单溶质[[PFAS]]（100 g L<sup>−1</sup>）[[吸附]]后的吸附剂经洁净镊子轻易取出，并用2 mL 0.1 mol L<sup>−1</sup> [[氢氧化钠|NaOH]]水溶液/[[乙腈]]（1:999，v:v）洗脱以进行[[再生]]（文本S7）。进行了五次[[吸附-解吸循环]]，以考察[[聚吡咯修饰碳纤维|PPy@P-CF]]的再生与重复使用性能。针对吸附剂再生后[[全氟和多氟烷基物质|PFAS]]的[[光化学破坏|光化学降解]]，向洗脱液中加入1 mol三氟甲磺酸盐（Cu[OTf]），并将含高浓度PFAS（2500 µg L<sup>−1</sup>）的溶液置于365 nm[[发光二极管]]灯下照射0–300 min以降解PFAS（文本S7）。PFAS降解产物、自由基和F<sup>−</sup>浓度分别通过[[超高效液相色谱-高分辨质谱]]（UPLC-HRMS）、[[电子自旋共振]]（ESR）光谱以及连接[[离子选择电极]]的便携式多用表进行鉴定。反应路径根据上述分析结果推导得出。分析方法详见文本S8。

## 4.6 实际污染水体中[[PFAS]]的集成[[吸附]]浓缩与[[光化学破坏|光化学降解]]应用

从一处氟化工产业园区附近采集了三种实际[[PFAS]]污染水样，即[[废水|WW]]、[[地表水|SW]]和[[地下水|GW]]，这些水样受到多种目标和[[非目标PFAS]]的污染[56]。采样位置和水质参数$( { \bf e . g . , T O C , p H , C l ^ { - } , N O _ { 3 } } ^ { - }$ $\mathbf { S } \mathbf { O } _ { 4 } ^ { 2 - } , \mathbf { N } \mathbf { a } ^ { + } , \mathbf { M } \mathbf { g } ^ { 2 + } , \mathbf { C } \mathbf { a } ^ { 2 + } )$均在表S8中详细描述。我们此前的报告[56]已检测出这些水体中的[[目标PFAS|16种目标PFAS]]和11种非目标[[全氟和多氟烷基物质|PFAS]]，其前处理、目标PFAS初始浓度以及非目标PFAS的半定量浓度详见表S4和S5。对于实际PFAS污染水体的[[吸附实验]]，使用15 g [[聚吡咯修饰碳纤维|PPy@P-CF]]（10 cm × 10 cm × 0.2 cm）和10 L实际水样，其余步骤与上述批次实验相同。PFAS[[吸附]]完成后，取出吸附剂，并按照我们此前的方法[57]对实际水体进行[[固相萃取]]浓缩，随后进行[[液相色谱-串联质谱|LC-MS/MS]]和[[超高效液相色谱-高分辨质谱]]（UHPLC-HRMS）分析。使用后的吸附剂用50 mL 0.1 mol L<sup>−1</sup> [[氢氧化钠|NaOH]]水溶液/[[乙腈]]（1:999，v:v）洗脱，并加入2 mol Cu[OTf]。洗脱液中的PFAS通过[[光化学破坏|光化学降解]]处理300 min，详细实验操作如上文及文本S7所述。
