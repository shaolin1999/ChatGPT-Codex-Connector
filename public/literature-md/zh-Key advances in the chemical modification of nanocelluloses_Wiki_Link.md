# [[纳米纤维素]]化学修饰的关键进展

引用本文：[[Chem. Soc. Rev.]], 2014, 43, 1519

[[Youssef Habibi]]

收稿日期：2013 年 6 月 15 日

DOI：10.1039/c3cs60204d

[[纳米纤维素]]，包括[[纳米晶纤维素]]、[[纳米原纤化纤维素]]和[[细菌纤维素]]纳米纤维，已成为设计新型[[生物材料]]的迷人构建单元。它们来源于最丰富且可再生的[[生物聚合物]]，正吸引着极大的关注，并且在可持续发展趋势的推动下，这种关注在未来必将持续增长。这种日益增长的兴趣与其无与伦比的典型物理和化学性质密切相关。然而，由于其亲水特性，它们的应用仅限于涉及亲水或极性介质的场合，这限制了它们的开发利用。由于这些构建单元结构中存在大量[[化学官能团]]，它们为通过多种化学方法进行显著的[[表面修饰]]提供了独特的平台。这些化学修饰是调整纳米[[纤维素]]基底界面性质或调节其[[亲水–疏水平衡]]的先决条件，有时甚至是不可避免的。因此，人们开发了多种化学方法，旨在对这些纳米尺度的基底进行表面修饰，以赋予其特定性能，从而将其用途拓展至高度精细化的应用领域。本综述汇集了当前纳米纤维素研究与开发中的已有知识，并特别着重介绍了迄今为止为实现其功能化而发展的化学修饰路线。

## 1. 引言

[[纤维素]]是生物圈中产量最为丰富的可再生聚合物资源，据估计其年产量超过 $7 . 5 ~ \times ~ 1 0 ^ { 1 0 }$ 吨。这种迷人且几乎取之不尽的可持续聚合物具有卓越的化学与物理特性，使其能够以不同形式用于广泛的材料和产品。[[纤维素纤维]]作为木材、纺织品或绳索的使用可以追溯到数千年前。在工业上，近 150 年来，纤维素一直被用作基础化学原料，以获取多种产品，包括纸张、玻璃纸薄膜、炸药、纺织品、膳食纤维等。除了这些相对简单的产品实例之外，纤维素纤维还被用于更为复杂的应用，例如作为塑料基复合材料中的增强材料。然而，直到相对近期才为人所知的是，当纤维素纤维经受[[机械剪切]]或受控[[酸水解]]时，会生成细长的纤维状或无明显缺陷的棒状结晶颗粒，其至少有一个维度处于纳米尺度范围。围绕这些纤维素基质的“纳米”技术研究因其卓越的物理和化学性质而引起了极大的关注。最近已发表了若干综述<sup>1–6</sup>，证明了这些新兴可再生构建单元的重要性；关于[[纳米纤维素]]的加工、提取、表征或应用的所有细节，读者可参阅这些文献，因为本综述专门致力于其化学改性。事实上，由于其结构内存在大量[[羟丙基|羟基]]，这些构建单元代表了一个独特的平台，可用于进行显著的表面改性，并利用多种化学方法[[接枝]]大量功能性（大）分子，从而将其用途扩展到广泛的高度精密应用领域。这些化学转化大多是为了改善纳米纤维素基材料的加工性能和表现，更具体地说，是为了获得能够在非极性有机介质（溶剂和聚合物基体）中良好分散的纳米纤维素衍生物。显然，就纤维素的本质而言，大多数针对纳米纤维素进行的化学改性都是对应用于纤维素纤维的化学改性的合理延伸。然而，在进行此类化学改性时，保持纳米纤维素原始形态的完整性、避免任何多[[晶型]]转变并维持其[[晶体结构|天然晶体结构]]，比纤维素纤维的情形更具挑战性。

本综述的总体目标是在对[[纳米纤维素]]基质进行简要介绍和定义之后，描述迄今为止用于纳米[[纤维素]]功能化的若干化学改性途径。

## 2. [[纳米纤维素]]基质

[[纤维素]]被认为是植物中最重要的结构元素，并用于维持细胞结构。纤维素对细菌、真菌、藻类、变形虫甚至海洋动物等其他生物物种也很重要。它是一种普遍存在的结构聚合物，赋予细胞其力学性能。

从结构角度来看，[[纤维素]]是一种高分子量同[[多糖]]，由 [[β-1,4-脱水-D-吡喃葡萄糖]]单元组成（图 1）。这些单元并非完全处于结构平面内，而是采取[[椅式构象]]，连续的[[葡萄糖]]残基绕分子轴旋转 180° 角，[[羟丙基|羟基]]处于平伏位置。此外，每一条纤维素链在其分子轴两端具有方向不对称性：一端带有[[半缩醛基团]]，即具有化学还原性的官能团；另一端带有一个悬挂羟基，即名义上的[[非还原端]]。纤维素链的[[聚合度]]（DP）因其来源不同而变化，据估计，木材纤维素中约为 10 000 个吡喃葡萄糖单元，天然棉纤维素中约为 15 000 个。

[[纤维素]]最显著的特征之一是其每个单体带有三个[[羟丙基|羟基]]。这些羟基形成[[氢键]]的能力在纤维状和半结晶堆积的形成中起着重要作用，

这些[[氢键]]决定了这类高度内聚材料的重要物理性质。<sup>8</sup>

在自然界中，[[纤维素]]并不以孤立的单个分子形式出现，而是以单条纤维素链组装形成的纤维集合体形式存在。这是因为纤维素以单个分子形式合成，并在生物合成位点按层级顺序发生纺丝。<sup>9,10</sup> 生物聚合、纺丝和结晶的联合作用发生在一个直径 30 nm 的玫瑰花形质膜复合体中，并由作为生物喷丝头的特定酶末端复合体（TCs）协同调控。通常，大约 36 条葡聚糖链组装体通过[[范德华力]]以及[[氢键|分子内和分子间氢键]]汇聚成更大的单元，即[[基元原纤]]（原纤丝），这些单元进一步堆积成更大的[[微原纤]]，最终组装为人们熟悉的[[纤维素纤维]]。然而，不同来源的纤维素可能因生物合成条件所决定而表现出不同的堆积方式，从而产生不同的形态。<sup>11–13</sup> 此外，如果 TCs 不受干扰，它们可以生成仅具有有限数量缺陷或无定形区的[[纳米原纤化纤维素|纳米原纤]]。<sup>10,14</sup>

根据这些形态特征，[[纤维素纤维]]可沿其轴向存在于无定形区处发生横向解离，形成纳米级且高度结晶、无缺陷的棒状碎片，下文称之为[[纤维素纳米晶体]]（[[纤维素纳米晶|CNCs]]）。通过[[机械剪切]]，[[纤维素]]纤维可沿横向崩解为其亚结构纳米尺度单元（[[纳米原纤化纤维素|纳米原纤]]），从而得到纳米原纤化纤维素（NFC）。后一种纳米[[生物材料]]也可通过微生物进行生物合成，并广为人知地称为[[细菌纤维素|细菌纳米纤维素]]（[[细菌纳米纤维素|BNC]]）。

“[[纳米纤维素]]”这一名称通常指所有这些类型的纳米级[[纤维素]]基材，包括[[纤维素纳米晶|CNCs]]、[[纳米原纤化纤维素|NFCs]]和[[细菌纤维素|BNC]]。但值得指出的是，由于起始原料和加工方法的高度多样性，这些产品的术语和定义仍存在相当大的不一致，从而导致了一些误解和歧义。[[TAPPI]]作为全球制浆、造纸、包装和加工行业的领先协会，正试图通过制定《纤维素纳米材料标准术语及其定义》来规范这一现状，但该标准尚未发布。

## 2.1. [[纳米原纤化纤维素]]

正如[[Turbak]]及其同事在20世纪80年代所引入的那样，<sup>15</sup> 分离微/[[纳米原纤化纤维素]]（MFC/NFC）的工艺包括使[[纤维素纤维]]沿其长轴发生崩解。这些工艺包括简单的机械方法，有时与酶法或化学预处理相结合（其中最重要的方法将在后文描述）。[[纤维素]]纤维被崩解为其亚结构原纤，其长度为微米级，宽度为10至数百纳米，具体取决于植物细胞壁的性质。所得水悬浮液在水中表现出凝胶状特征，即使在低固含量下也具有假塑性和触变性。三种主要技术，即均质化（例如使用[[Manton-Gaulin均质机]]）、[[微流化化]]和[[微研磨]]，被广泛用于机械处理。还开发了其他方法，但这些方法仍处于非常早期的阶段，远未达到可放大的程度；例如可列举[[机械解纤|高速共混]]、<sup>16</sup> [[冷冻粉碎]]、<sup>17</sup> [[高强度超声处理]]、<sup>18–20</sup> 和[[蒸汽爆破]]。<sup>21–25</sup>

## 2.3. [[纤维素纳米晶体]]

尽管已有少数通过酶水解过程制备 [[纤维素纳米晶|CNCs]] 的报道，<sup>56–58</sup> 但从[[纤维素纤维]]中分离 [[纤维素纳米晶体|CNCs]] 的主要工艺基于[[酸水解]]，该过程会横向切断[[纤维素]]纤维。作为结构缺陷的纤维素无定形区被去除，从而诱导纤维素纤维横向裂解为棒状纳米颗粒。这一转化包括破坏微纤丝周围以及嵌入其间的无定形区，同时使结晶区段保持完整。这种裂解归因于无定形区相较结晶区具有更快的水解动力学。

总体而言，天然[[纤维素]]的[[酸水解]]会使其[[聚合度]]（DP）迅速下降至所谓的平衡聚合度（LODP），该值在较长时间内保持恒定，即使延长水解时间也是如此。<sup>59–64</sup> LODP 值被认为与水解前纤维沿纵向的晶体尺寸相关，并且还取决于纤维素的来源。据此，已记录水解棉花的 LODP 值为 250，<sup>65</sup> 苎麻纤维为 300，<sup>66</sup> 漂白木浆为 140–200，<sup>59</sup> 而高[[结晶度]]的 [[Valonia]] 纤维素则高达 6000。<sup>67</sup>

所得纳米颗粒具有与原始[[纤维素纤维]]相似的[[晶体结构]]；此类示例见图 4。

目前用于提取[[纤维素纳米晶|CNCs]]的典型方法包括在严格控制的温度、搅拌和时间条件下，对纯[[纤维素]]材料进行强[[酸水解]]。酸的性质在[[纤维素纳米晶体|CNCs]]的制备中极为重要。[[硫酸]]是制备CNCs时使用最广泛的酸，在最常报道的方案中，其浓度为64 wt%，酸与纤维素的比例为8.75–17.5 mL g<sup>1</sup>，水解在45 1C下进行25–45 min。然而，也有报道使用[[盐酸]]、<sup>72–74</sup>[[磷酸]]、<sup>75–79</sup>和[[氢溴酸]]<sup>80–82</sup>进行此类制备。但是，如果CNCs经盐酸或氢溴酸水解制备，其分散性非常有限，其水悬浮液易于絮凝。另一方面，当使用硫酸和磷酸作为水解剂时，它们会与纤维素表面[[羟丙基|羟基]]反应，生成带有硫酸酯或磷酸酯的带电表面，从而促进CNCs在水中的自发分散。这些特定的化学修饰及其所产生性质将在下文中简要讨论。

文献中报道的用于制备[[纤维素纳米晶|CNCs]]的最常见[[纤维素]]来源包括棉、<sup>83,84</sup>苎麻、<sup>85–87</sup>大麻、<sup>88</sup>亚麻、<sup>89,90</sup>剑麻、<sup>91,92</sup>小麦秸秆、<sup>93</sup>棕榈、<sup>94</sup>漂白针叶木<sup>73</sup>和阔叶木<sup>95</sup>浆、棉短绒浆、<sup>96,97</sup>微晶纤维素、<sup>98–101</sup>甜菜浆、<sup>102</sup>[[细菌纤维素]]<sup>103–105</sup>以及[[被囊动物纤维素|被囊动物]]（一种海洋生物）。<sup>106–108</sup>研究发现，[[纤维素纳米晶体|CNCs]]的几何尺寸（宽度l和长度L）会随纤维素来源材料和制备条件的不同而变化。但通常其宽度为几纳米，而长度范围从十分之几纳米到数微米。

## 3. 化学修饰

## 3.1. [[非共价表面修饰]]

[[纳米纤维素]]的非共价表面改性通常通过[[吸附]][[表面活性剂]]、带相反电荷的物质或[[聚电解质]]来实现。因此，这些与纳米[[纤维素]]基底之间的相互作用通过亲水亲和力、静电吸引、[[氢键]]或[[范德华力]]得以保证。该方法最早由 [[Heux]] 等人报道，<sup>109,110</sup>他们使用由具有[[烷基酚]]尾部的[[磷酸]]单酯和二酯组成的表面活性剂来改性 [[纤维素纳米晶|CNCs]]。表面活性剂分子在 [[纤维素纳米晶体|CNCs]] 表面形成了约 15 Å 的薄层，所得表面活性剂包覆的 CNCs 在非极性溶剂中分散性良好。<sup>110,111</sup>此外，当这些表面活性剂包覆的 CNCs 掺入[[等规聚丙烯]]（isoPP）基体时，它们表现出非常好的相容性，并作为显著的成核剂，除了常规的 α [[晶型]]外，还诱导 isoPP 形成稀有的 β 晶型。<sup>112</sup>另一种名为 [[Beycostat AB09]] 的[[乙氧基化壬基酚酸式磷酸酯]]（一种阴离子表面活性剂）也被 [[Bondeson]] 和 [[Oksman]]<sup>113</sup>用于改善 CNCs 在[[聚乳酸]]（PLA）中的分散。其他作者，即 [[Kim]] 等人<sup>114</sup>和 [[Rojas]] 等人，<sup>115</sup>报道了使用非离子表面活性剂将 CNCs 分散在[[聚苯乙烯]]基复合纤维中。受有机改性层状硅酸盐的启发，开发了一种在水溶液中进行的环保方法，通过吸附带有长烷基、苯基、缩水甘油基和二烯丙基的[[季铵盐]]对 [[TEMPO氧化|TEMPO 氧化的 CNCs]] 进行表面改性。<sup>116</sup>

[[Zhou]] 等人<sup>117</sup>提出了一种基于糖基两亲性嵌段共聚物[[吸附]]的非共价 [[纤维素纳米晶|CNC]] [[表面修饰]]新方法，该方法十分精巧。通过模拟天然的[[木质素]]-碳水化合物共聚物，他们将[[木葡聚糖寡糖-聚乙二醇-聚苯乙烯三嵌段共聚物]]吸附到 [[纤维素纳米晶体|CNC]] 表面。所得 CNC 在非极性溶剂中表现出优异的分散能力。类似地，[[Lee]] 等人<sup>118</sup>使用一种完全生物来源的 [[聚乳酸|PLA]]-碳水化合物共聚物对 [[细菌纤维素|BNC]] 进行表面改性，以使这些纳米填料与 PLA 相容。该共聚物通过碳水化合物衍生内酯与[[乳酸|丙交酯]]的无规[[开环共聚]]制备，以 Sn(OBu) 为催化剂。碳水化合物基尾部通过[[氢键]]与 [[细菌纳米纤维素|BNC]] 表面发生强烈相互作用。另一种涉及环境友好合成途径的仿生方法被开发用于制备一种高强度复合材料，该材料由自组装且纳米结构的 BNC 与[[羟乙基纤维素]]（HEC）包覆而成。这种复合材料具有类似木材或肌腱的分级组织结构，仅通过在 HEC 存在下培养细菌[[纤维素纳米纤维]]即可生成。<sup>119</sup>在此研究之前，[[Brown]] 和 [[Laborie]]<sup>120</sup>使用相同的生物工程策略制备了 [[PEO–BNC复合材料|PEO–BNC 复合材料]]。近期，通过吸附热响应性[[聚电解质]]制备了热响应性 [[纳米原纤化纤维素|NFC]]，其中聚电解质嵌段由季铵化聚（甲基丙烯酸 2-（二甲氨基）乙酯）（[[PDMAEMA]]）组成，热响应嵌段由聚（甲基丙烯酸二（乙二醇）甲醚酯）（[[PDEGMA]]）组成。该嵌段共聚物的合成通过 [[ATRP]] 实现，以 PDMAEMA 作为大分子引发剂。<sup>121</sup>由阴离子氧化 NFC 制成的薄膜通过吸附阳离子[[表面活性剂]]（即[[十六烷基三甲基溴化铵]]，CTAB）进行改性，只需将含有已知量 CTAB 的水溶液沉积在 NFC 薄膜表面即可。<sup>122</sup>表面活性剂与 NFC 之间的相互作用足够强，即使经过充分水洗后仍能保留表面活性剂。其他具有不同链长的双链阳离子表面活性剂（十六烷基三甲基-、双十二烷基-和双十六烷基溴化铵）通过溶液混合吸附在 NFC 上，并通过溶剂浇铸制成薄膜。所得薄膜的拒水性显著增强。<sup>123</sup>

![](<../2.SCI_MD/Key advances in the chemical modification of nanocelluloses/images/795838473d0d5b2bdde16fb10870342ae0c961fc48a40f592e6fa742e6813475.jpg>)  
图 5 MFC 和 PEI 薄膜的干涉色随层数的变化。（经参考文献 54 许可转载，版权（2008）美国化学会。）

通过将[[纳米纤维素]]基底（带正电或负电）与带相反电荷的物质进行静电驱动的[[层层组装|层层（LbL）组装]]来构建多层膜，是一种非常简便的定制材料方法。该过程主要基于简单的浸渍法，但也有旋涂法的报道。该方法最初应用于 [[纤维素纳米晶|CNC]]，使用[[聚（二烯丙基二甲基氯化铵）]]（poly-(DADMAC)）作为带正电的聚合物。<sup>124</sup> 随后，为获得不同性能，人们采用了多种其他聚合物。<sup>71,125–128</sup> 在这些实例中，可以着重指出 [[Wågberg|Wa¨gberg]] 等人报道的相关工作，$a l . ^ { 5 4 }$ 他们将[[羧甲基化NFC|羧甲基化 NFC]] 与 poly-(DADMAC)、[[聚（烯丙胺盐酸盐）]]（poly(AAH)）和[[聚乙烯亚胺]]（poly-(EI)）进行组装。所得多层膜由高度密实的 [[纳米原纤化纤维素|NFC]] 构成，原纤之间插层有一些[[聚电解质]]。这些薄膜呈现出不同的颜色，且颜色与薄膜厚度直接相关（图 5）。在最近一项非常有趣的工作中，[[Eronen]] 等人<sup>128</sup> 研究了阴离子型 NFC 与不同阳离子聚电解质以及与阳离子化 NFC 的 LbL 组装。这类 NFC 的自组装能力与更柔性的阳离子聚电解质体系存在显著差异，这主要是由于[[纤维素]]原纤之间存在较强的非静电亲和性。为了增强薄膜的横向有序性并简化规整的 LbL 加工过程，另一种基于去润湿现象而非垂直浸渍的方法被引入。<sup>129</sup>

通过 [[层层组装|LbL]] 沉积与 [[纳米原纤化纤维素|NFC]] 一起研究了多种[[聚电解质]]，并将其用作大分子连接剂，以静电方式促进 Ag 或 ZnO 纳米粒子的锚定，从而赋予纸制品抗菌性能。<sup>130,131</sup> 聚（N-异丙基丙烯酰胺-共聚-丙烯酸）[[微凝胶|微凝胶珠]]也与阳离子型 NFC 一起组装在 LbL 薄膜中。<sup>132</sup> 这种非共价组装使微凝胶珠在被[[吸附]]的 NFC 包裹后仍能保持其柔软的凝胶状核心，从而形成开放结构的复合薄膜。这些基于微凝胶和 NFC 的薄膜可用于在恒定室温下负载和释放一种染料，即[[异硫氰酸荧光素异构体I|异硫氰酸荧光素异构体 I]]（FITC），这似乎与完全基于合成聚电解质的体系形成对比。

## 3.2. [[磺化]]

[[纤维素纳米晶|CNC]] 的[[磺化]]发生在[[硫酸]]催化水解过程中，通过[[羟丙基|羟基]]的[[酯化|酯化反应]]实现。尽管 [[纤维素纳米晶体|CNC]] 表面存在的这些[[硫酸酯基]]会降低其热稳定性，<sup>133</sup> 但它们对于形成稳定的胶体悬浮液非常理想，这种悬浮液在受控干燥后可得到光学活性薄膜。然而，酯化程度高度依赖于水解时间、温度、酸浓度等因素，这使得对硫酸酯基数量的精确控制非常困难。同样值得注意的是，对所得酯基的定量仍然极具挑战性。<sup>134,135</sup> 为缓解这一问题，有人提出对[[盐酸]]水解生成的 CNC 进行硫酸后处理，以可控方式在其表面引入[[硫酸酯基团]]。<sup>73,84</sup> 由盐[[酸水解]]生成并随后经硫酸溶液处理的 CNC，其粒径与直接由[[硫酸水解]]得到的 CNC 相同；但表面电荷密度可以调节到硫酸水解所能达到的范围之外。需要注意的是，对硫酸水解制备的 CNC 进行[[脱磺化]]处理，也被用于调节 CNC 表面的硫酸酯含量。<sup>136,137</sup> 关于颗粒形貌，在超声条件下进行水解时，同时使用硫酸和盐酸的组合似乎会生成[[球形CNC|球形 CNC]]，而不是棒状纳米晶体。<sup>138,139</sup> 这些球形 CNC 表现出更好的热稳定性，主要原因是与仅由硫酸水解生成的 CNC 相比，其表面硫酸酯基团更少。<sup>139</sup>

对由[[纤维素纤维]][[高碘酸盐氧化]]得到的 [[2,3-二醛纤维素]]进行[[亚硫酸氢盐磺化]]，曾被用作[[纤维素]]纤维的预处理，以促进其[[机械解纤]]为[[纳米原纤化纤维素|纳米原纤]]。所得 NFC 的典型宽度为 10–60 nm，由电荷极低（0.18–0.51 mmol $\mathbf { g } ^ { - 1 } )$ 140）的[[磺化纤维素]]制备得到。尽管氧化以及随后的[[磺化]]发生在[[葡萄糖|葡萄糖单元]] 2 位和 3 位的邻位[[羟丙基|羟基]]上，并诱导[[吡喃葡萄糖环]]开环，但即使[[硫酸]]酯含量较高，NFC 仍保持了其[[晶体结构|天然晶体结构]]。因此，这种氧化磺化可被视为一种有潜力的[[绿色化学|绿色方法]]，用于促进纤维素纤维的纳米原纤化，尤其是考虑到作者声称所用[[高碘酸盐]]可以有效回收和再生。

## 3.3. [[TEMPO 介导氧化]]

([[TEMPO|2,2,6,6-四甲基哌啶-1-氧基]])介导的（或 TEMPO 介导的）[[纤维素]]氧化已被用于将[[羟甲基]]转化为其[[羧基|羧酸形式]]。该氧化反应对[[伯羟基]]具有高度选择性，同时也是一种“绿色”且易于实施的方法。通常，它涉及在 [[溴化钠|NaBr]] 和 [[次氯酸钠|NaOCl]] 存在下使用稳定的[[氮氧自由基]] TEMPO（见图 6）。自 de Nooy 等人<sup>141</sup> 引入该技术以来，已有大量报告涉及此方法的使用，他们首次证明[[多糖]]中只有羟甲基被氧化，而[[仲羟基]]不受影响。

就[[纳米原纤化纤维素]]（NFC）而言，[[TEMPO介导氧化|TEMPO 介导的氧化]]大多作为一种经济有效的化学预处理手段，在机械处理之前使用，以促进纤维的个体化。实际上，在通过破坏纤维内[[氢键|强氢键网络]]而削弱其结构潜力并软化其刚性结构之后，经 [[TEMPO氧化|TEMPO 氧化]]的[[纤维素纤维]]可以非常容易地借助上述[[机械剪切]]作用（[[机械解纤|高速共混]]、超声处理、高机械剪切等）转化为高度结晶的[[纤维素纳米纤维|单个纳米纤维]]。该方法已用于多种[[纤维素]]纤维。<sup>28,30–33,142–157</sup> [[Isogai]] 团队在该领域开展了开创性工作，最近在一篇简明综述中作了报道。158

![](<../2.SCI_MD/Key advances in the chemical modification of nanocelluloses/images/431822502c0fc471ad114670314692cdc43c92c5e4c7cbdb057cb417889766cc.jpg>)  
图 6 纤维素羟甲基基团的 TEMPO 介导氧化机理示意图。

对于最常见的 [[TEMPO]] 衍生物，报道的最佳条件为 pH 10 和 0–10 °C 的温度范围。视所用[[纤维素]]原料而定，这些操作条件通常可制得宽度为 3–20 nm、长度为数微米的[[纤维素纳米纤维]]。其他 TEMPO 类似物也经过了测试，结果表明，在木材纤维素氧化中，[[4-乙酰胺基-TEMPO]] 和 [[4-甲氧基-TEMPO]] 的效率高于 TEMPO。相比之下，使用 [[4-羟基-TEMPO]] 和 [[4-氧代-TEMPO]] 时，氧化效率最低，因此 [[纳米原纤化纤维素|NFC]] 产率也最低。<sup>159</sup> 为了限制 [[次氯酸钠|NaOCl]] 的使用，开发了一种由 TEMPO 或 4-乙酰胺基-TEMPO 催化的[[电介导氧化]]方法，不使用任何含氯氧化剂。<sup>160</sup> 使用 TEMPO 时，氧化在 pH 10 下高效进行，而使用 4-乙酰胺基-TEMPO 时，最适 pH 为 6.8。然而，与使用 NaOCl 的常规氧化相比，该氧化所需时间要长得多，约为 48 h，导致[[聚合度]]下降，但未对天然形态和[[晶型]]造成明显损害。

应当指出，[[TEMPO 介导氧化]]是作为中间步骤进行的，目的是通过[[酰胺化]]促进（大）分子实体的[[接枝]]（见第 3.8 节）。该反应也被用于在 [[纤维素纳米晶|CNC]] 表面引入稳定的负静电荷，以获得可与[[硫酸水解]]后相媲美的更好分散性。事实上，由[[纤维素纤维]]的 [[盐酸|HCl]] 水解得到的 [[纤维素纳米晶体|CNC]] 的 [[TEMPO介导氧化|TEMPO 介导氧化]]，最早由 [[Araki]] 等<sup>161</sup> 报道。作者证明，经过 [[TEMPO]] 介导氧化后，CNC 保持了其初始的形态完整性，并在水中分散时形成均相悬浮液。后一观察结果的基础是[[羧基]]的存在，它们在 CNC 表面赋予负电荷，从而诱导[[静电稳定]]。[[Montanari]] 等<sup>162</sup> 报道了类似的观察结果，他们还表明，在过度 TEMPO 介导氧化过程中，晶体尺寸会发生减小，这是由存在于表面的[[纤维素]]链发生部分剥离所致。[[Habibi]] 等<sup>163</sup> 对由[[被囊动物纤维素]]纤维 HCl 水解得到的 CNC 进行了 TEMPO 介导氧化，并表明 TEMPO 介导氧化既未损害 CNC 的形态完整性，也未损害其[[结晶度|本征结晶度]]。基于 CNC 的超分子结构、形态属性和晶体学参数，这些作者证明，通过使用特定量的初级氧化剂，即 [[次氯酸钠|NaOCl]]，可以预测并获得不同的氧化程度（图 7）。实际上，CNC 的 TEMPO 介导氧化涉及一种拓扑限域的反应序列，并且由于纤维素链的[[二重螺旋轴]]，只有一半可及的[[羟甲基]]可供反应，而另一半则被埋藏在晶体颗粒内部。值得注意的是，正如 [[Okita]] 等<sup>151</sup> 所报道，同样的计算也可适用于 NCF 的情况。当分散于水中时，[[TEMPO氧化|TEMPO 氧化]]或羧化 CNC 悬浮液表现出[[双折射]]图案，并且由于 CNC 表面负电荷所赋予的[[聚阴离子]]特性，不会絮凝或沉降。这种有趣的行为只能通过[[硫酸]]水解获得，并且通常被归因于带负电荷的[[硫酸酯基|硫酸酯基团]]的存在。

![](<../2.SCI_MD/Key advances in the chemical modification of nanocelluloses/images/84b8ed94d3c0d9e10fb7eceab58539ae707d24d7d0aacf334d3a4a723fc23b3e.jpg>)  
图 7 CNC 横截面示意图，说明晶体表面伯羟基的选择性 TEMPO 介导氧化。

除了促进 [[纳米原纤化纤维素|NFC]] 和 [[纤维素纳米晶|CNC]] 在水中的分散外，在其表面引入[[羧基|羧酸钠基团]]似乎也有利于它们在非质子有机溶剂（如 [[N,N-二甲基乙酰胺|DMAc]]、[[N,N-二甲基甲酰胺|DMF]]、[[1,3-二甲基-2-咪唑啉酮|DMI]] 和 [[N-甲基吡咯烷酮|NMP]]）中的分散，尤其是在将羧酸钠基团转化为游离羧基之后。<sup>164</sup>

## 3.4. [[酯化]]

由于其简便性与直接性，通过[[酯化|酯化反应]]对[[纳米纤维素]]表面存在的[[羟丙基|羟基]]进行改性是广泛使用的方法。在[[酯化反应]]中，纳米[[纤维素]]的[[乙酰化]]是研究最为广泛的。与[[纤维素纤维]]类似，纳米纤维素的乙酰化在少量催化剂（如[[硫酸]]或[[高氯酸]]）存在下，通过加入[[乙酸酐]]与[[乙酸]]的干燥混合物逐步进行。乙酰化根据是否存在非溶胀稀释剂而以两种主要机制进行。在所谓的“[[纤维态工艺]]”中，向反应介质中加入诸如[[甲苯]]等稀释剂，乙酰化链保持不溶，从而在不改变形态特征的情况下获得较高的乙酰化程度。在“[[均相工艺]]”中不加入稀释剂，乙酰化链一旦生成便溶解于反应介质中，因此纤维素基体在深度乙酰化并伴生溶解之前会发生显著的形态变化。这些事实首先由[[Sassi]]和[[Chanzy]]在纳米纤维素基体上得到验证，<sup>165</sup>他们研究了从[[Valonia]]和[[海鞘]]中提取的模型[[纤维素纳米晶|CNC]]的均相与非均相乙酰化。他们的超微结构研究（通过[[透射电子显微镜|TEM]]成像和[[XRD|X射线衍射]]进行）表明，反应通过晶体直径的减小进行，而仅观察到[[纤维素纳米晶体|CNC]]长度的有限缩短。这被认为反应涉及一种[[非溶胀机制]]，仅影响位于晶体表面的纤维素链。在均相乙酰化情况下，反应在乙酸中于$6 0 ~ ^ { \circ } \mathrm { C }$使用硫酸作为催化剂进行，部分乙酰化的分子一旦足够可溶，便立即分配进入乙酰化介质。在中等乙酰化程度下，CNC保持其完整性，改性仅发生在其表面。<sup>166</sup>在含有诸如甲苯等稀释剂的非均相条件下，乙酰化纤维素链保持不溶，并包覆在未反应纤维素链的结晶核心周围。同样，来自[[挪威云杉]]的[[纳米原纤化纤维素|NFC]]<sup>167</sup>或[[细菌纤维素|BNC]]<sup>168</sup>使用以甲苯为稀释剂的纤维态乙酰化方法进行了表面乙酰化。所得乙酰化NFC保持了其原纤形态，并在核心部分保留了未改变的结晶[[纤维素I]]。[[Yamamato]]等人<sup>169</sup>使用$^ { 1 3 } \mathrm { C }$ [[固态核磁共振|CP/MAS NMR]]跟踪了[[细菌纳米纤维素|BNC]]纤维态乙酰化的发生（在乙[[酸酐]]与[[乙酸戊酯]]的50/50混合物中，于20 1C下使用0.2%硫酸或0.4%高氯酸进行），并确定该反应不具有区域选择性，因为在三个羟基上均无差别地发生。当BNC在不加任何稀释剂并使用碘作为催化剂的乙酸酐中进行乙酰化时，也获得了类似的观察结果（图8）。<sup>170</sup>

[[细菌纤维素|BNC]] 纳米纤维在无任何催化剂条件下，于 $1 2 0 ~ ^ { \circ } \mathrm { C }$ 使用[[乙酸酐]]进行[[乙酰化|表面乙酰化]]处理 21 $\mathrm { h } ^ { 1 7 1 }$，或在以[[硫酸]]为催化剂但温度仅为 $3 0 ~ ^ { \circ } \mathrm { C }$ 的条件下进行。172 在这两种反应条件下，纳米纤维均未发生结构和/或形态变化。将这些乙酰化 [[细菌纳米纤维素|BNC]] 分别载入[[丙烯酸树脂]]或 [[聚乳酸|PLA]] 中，所得[[生物纳米复合材料]]除了力学性能得到改善外，还表现出相当高的透明性（[[折射率]]降低）以及与乙酰化 BNC [[疏水性]]相关的[[吸湿性|低吸湿性]]。这些观察结果得到了 [[Ifuku]] 等人的证实，<sup>173</sup> 他们表明，BNC 的乙酰化除了改善上述性能外，还使 BNC-[[三环癸烷二甲醇二甲基丙烯酸酯树脂]]复合片材的[[热膨胀系数]]从 $3 ~ \times$ ${ { 1 0 } ^ { - 6 } }$ 显著降低至低于 $1 \times 1 0 ^ { - 6 } \mathrm { K } ^ { - 1 }$

[[纤维素]]水解与[[羟丙基|羟基]][[乙酰化]]同时发生的情况也已有报道。羟基的 [[Fischer 酯化]]与无定形纤维素链的水解同时进行，已被提出为一种可行的[[一锅法反应|单罐反应]]方法，可在单步过程中分离得到乙酰化 [[纤维素纳米晶|CNCs]]（图 9 上）。<sup>176,177</sup> 正如作者所证明的，该方法可应用于获得[[纳米纤维素]]的各种酯。然而，使用这种方法对[[酯化]]度进行严格控制相当困难。在类似方法中，[[Herrick]] 等 $a l . ^ { 1 7 8 }$ 在纳米纤维素早期开发中提出，在[[机械剪切]]过程中同时进行 [[纳米原纤化纤维素|NFCs]] 的乙酰化，使用[[乙酸]]和[[乙酸酐]]的混合物并加入[[硫酸]]作为催化剂，以替代水作为加工介质。[[Huang]] 等 $a l . ^ { 1 7 9 }$ 最近开发了一种类似的一步法，旨在对[[纤维素纤维]]进行酯化和解纤。该方法包括在有机溶剂（如 [[N,N-二甲基甲酰胺|DMF]] 或 [[四氢呋喃|THF]]）中对纤维进行球磨，溶剂中含有[[酰氯]]或[[酸酐|酸酐衍生物]]等酯化剂，从而得到性能可调的 NFCs（图 9 下）。值得一提的是，乙酰化也被建议作为机械加工前获得 NFCs 的化学预处理步骤。<sup>180</sup>

[[Çetin]]等人<sup>181</sup>提出了一种以[[碳酸钾]]为碱、通过[[乙酸乙烯酯]]的[[酯交换反应]]对[[纤维素纳米晶|CNCs]]进行[[乙酰化|表面乙酰化]]的简便方法。该反应在[[N,N-二甲基甲酰胺|DMF]]中于95 ${ } ^ { \circ } \mathbf { C } ,$ 下进行，且条件温和，仅纳米晶体表面被修饰，而其尺寸和[[结晶度]]保持不变。随着反应时间延长，扩散机制控制反应速率，得到乙酰化程度更高、尺寸更小且结晶度更低的纳米晶体。还成功采用[[乙酸酐]]与[[吡啶]]作为催化剂，在DMF中于105 ℃下对[[纳米原纤化纤维素|NFCs]]进行乙酰化。在这些条件下，可在不损害NFCs形貌或[[晶体结构|天然晶体结构]]的前提下，实现对取代度的精细调控，乙酰基含量最高可达15%。

除[[乙酸]]基团外，也尝试了采用不同策略与其他基团进行的[[酯化|酯化反应]]。[[Yuan]]等人<sup>182</sup>开发了一种环境友好的[[纤维素纳米晶|CNC]]表面酯化路线，其试剂消耗低且操作简便。该方法以[[烯基琥珀酸酐]]水乳液为模板。将乳液与[[纤维素纳米晶体|CNC]]水悬浮液简单混合、冷冻干燥，然后将所得固体加热至 $1 0 5 \ ^ { \circ } \mathrm { C } .$ 。所得衍生物赋予酯化CNCs高度[[疏水性|疏水特性]]，因为它们容易分散在介电常数ε差异很大的溶剂中；例如，它们不仅能分散在ε高达46.45的[[二甲基亚砜|DMSO]]中，也能分散在ε低至2.21的[[1,4-二氧六环]]中。

已报道了[[纤维素纳米晶|CNC]]与具有不同长度脂肪链的[[酰氯|有机脂肪酰氯]]（从$\left( \mathbf { C } _ { 1 2 } \right.$到$\mathbf { C _ { 1 8 } } )$）的[[酯化|酯化反应]]。该反应以[[三乙胺]]（TEA）为催化剂和原位生成[[盐酸]]的中和剂，在回流条件下进行4 h。所达到的DS足以获得足够高的[[接枝]]密度，使主链为18个碳的脂肪酸能够在[[纤维素纳米晶体|CNC]]表面结晶。<sup>183</sup> [[细菌纤维素|BNC]][[纳米原纤化纤维素|纳米原纤]]也接受了与不同链长有机酸（如[[乙酸]]、[[己酸]]和[[十二酸]]）的[[酯化反应]]。<sup>184,185</sup> 这些酯化反应在[[吡啶]]中进行，以[[对甲苯磺酰氯]]为催化剂，并在相对较低的温度和较短的反应时间（约50 °C，2 h）下完成。除乙酸因其与己酸和十二酸相比具有更高反应活性外，反应条件未改变纳米纤维的[[结晶度]]。事实上，结果表明DS随所用有机酸碳链长度的增加而降低。同一课题组在后续工作中还证明，在上述条件下，冻干[[细菌纳米纤维素|BNC]]比从未干燥的纳米纤维更易发生有机酸酯化反应；后者经从水到甲醇再到吡啶的溶剂置换后分散在反应介质吡啶中。<sup>186</sup>

通过[[羧甲基化]]获得的[[纳米原纤化纤维素|NFC]]经[[酯交换反应]]，以[[己醇]]为反应物和反应介质，并结合[[硫酸]]作为催化剂，成功地将羧甲基取代为己基基团。<sup>187</sup> 该反应在105 °C下进行72 h，但未表现出任何区域选择性，因为所有[[羟丙基|羟基]]均被修饰。此外，也无法对DS进行控制。

[[Berlioz]]等人<sup>188</sup>报道了一种高效的无溶剂合成方法，可实现对[[细菌纤维素|BNC]]和从[[被囊动物纤维素|被囊动物]]中提取的[[纤维素纳米晶|CNC]]进行几乎完全的表面[[酯化]]，得到高度取代的[[纳米纤维素]]酯。[[棕榈酰氯]]等脂肪酸的反应在减压和160至$1 9 0 ~ ^ { \circ } \mathrm { C }$的温度范围内，对冻干或经[[超临界二氧化碳]]工艺干燥的纳米[[纤维素]]基底进行。[[SEM]]和[[XRD|X射线衍射]]分析表明，酯化从基底表面向晶体核心进行。在温和条件下，表面被完全反应，而原始形貌得以保持，晶体核心未被修饰。

[[离子液体]]（ILs）对[[纤维素纤维]]具有很强的溶剂化能力，这极易对任何[[纳米纤维素]]基底的形态特征造成严重改变。然而，Missoum等人<sup>189</sup>最近展示了使用ILs作为反应介质进行[[纳米原纤化纤维素|NFC]][[酯化]]、同时保持其原始形貌和[[晶体结构]]的可行性。使用1-丁基-3-甲基咪唑六氟[[磷酸]]盐[bmim，PF]与[[乙酸酐]]在100 °C下对NFC进行表面酯化2 h。

## 3.5. 醚化

通过[[纤维素纤维]]的[[羧甲基化]]进行醚化，目前被广泛用作一种成本效益高且效率极高的化学预处理步骤，以促进纤维的解纤，从而制备[[纳米原纤化纤维素|纳米纤化纤维素]]（NFCs）。该转化过程简单，通常先用碱金属氢氧化物（大多为氢氧化钠）水溶液活化纤维，再用一氯[[乙酸]]或其钠盐将[[羟丙基|羟基]]不加区分地转化为羧甲基基团。<sup>54,187,190–194</sup> 然而，这一过程存在许多缺点，主要与有毒卤代烃反应物的使用有关。此外，所得NFCs甚至比原始[[纤维素]]更为亲水，这在涉及非极性介质的应用中可能具有很大的局限性。

![](<../2.SCI_MD/Key advances in the chemical modification of nanocelluloses/images/23708584efee370495034daa138d0f186d8abe3c2bb6275a4cca4008be7c0800.jpg>)  
图 10 纳米纤维素表面羟基与EPTMAC的醚化反应。

醚化也被用于在[[纤维素纳米晶|CNC]]表面非常容易地引入阳离子电荷；例如，弱或强含铵基团，如环氧丙基三甲基氯化铵（EPTMAC），可以通过醚化成功[[接枝]]到[[纤维素纳米晶体|CNC]]表面（图 10）。<sup>195</sup> 这种表面阳离子化通过碱活化[[纤维素]][[羟丙基|羟基]]对EPTMAC环氧基团进行[[亲核加成]]而进行，并产生具有意想不到的触变凝胶特性的稳定CNC水悬浮液。观察到[[双折射|剪切双折射]]，但在这些阳离子CNC中未检测到液晶[[手性向列相]]分离，这很可能是由于悬浮液的高黏度所致。最近在[[纤维素纤维]][[机械剪切]]之前进行了类似反应，以在低能耗下生产[[纳米原纤化纤维素|NFCs]]。<sup>196,197</sup> 实际上，纤维素浆料在醚化反应中用EPTMAC或氯胆碱氯化物进行阳离子化，随后[[机械解纤]]，得到三甲基铵改性的NFCs。

## 3.6. 硅烷化

由[[被囊动物纤维素|被囊动物]][[酸水解]]得到的[[纤维素纳米晶|CNC]]已使用一系列烷基二甲基氯硅烷进行部分硅烷化，烷基部分的碳骨架从短碳链的异丙基到较长链的正丁基、正辛基和正十二烷基不等。<sup>198</sup> 反应在[[甲苯]]中于室温下进行，并加入等摩尔量的咪唑以中和释放的[[盐酸]]。已证明，当DS在0.6至1之间时，形态完整性得以保持的纳米晶体变得易于分散在低极性溶剂（如[[四氢呋喃|THF]]）中，形成具有[[双折射]]行为的稳定悬浮液。然而，在高硅烷化程度（DS大于1）下，由于硅烷对[[羟丙基|羟基]]的高反应活性，晶体核心中的链也被硅烷化，导致晶体解体并因此丧失原始形态（图11），因此当需要高取代度时，该程序并不适用。于是，采用了一种温和的硅烷化方案，对从薄壁细胞[[纤维素]]中提取的[[纳米原纤化纤维素|NFC]]进行异丙基二甲基氯硅烷的表面硅烷化。这些硅烷化NFC保持了与未改性样品相同的形态特征，并可分散在非极性溶剂中，形成不絮凝的稳定悬浮液。<sup>199</sup> 其悬浮液在油酸甲酯中的流变性能表现出明显的剪切变稀效应。因此，通过硅烷化，NFC获得了固有的柔韧性，结果其悬浮液表现出与聚合物溶液相当的流变行为。类似地，Anderson等人<sup>200</sup> 报道了用氯二甲基异丙基硅烷对NFC进行成功表面硅烷化。在中等DS（0.6至1之间）下，疏水化硅烷化NFC保持了形态完整性，并能够稳定油包水乳液。<sup>201</sup> 对溶剂或中和剂稍作调整的类似程序被应用于各种[[纳米纤维素]]基材，以成功[[接枝]]多种硅烷衍生物。<sup>202–205</sup>

[[纤维素纳米晶|CNCs]] 通过熔融挤出成功掺入 [[聚乳酸|PLA]] 中，并且在熔融加工后其纳米结构未发生任何改变。

还尝试了硅烷化处理，以调控预成型 [[纳米原纤化纤维素|NFC]] 基[[气凝胶]]对非极性液体的润湿性能。实际上，全氟癸基三氯硅烷<sup>209</sup>和辛基三氯硅烷<sup>193</sup>仅通过在高温下（例如高于所用硅烷沸点）的[[化学气相沉积]]法即可[[接枝]]。

最后，由于操作简单，硅烷化也被用作进一步功能化的中间步骤。氨基硅烷首先[[接枝]]到 [[纤维素纳米晶|CNCs]] 上，并作为共价连接荧光基团的反应位点。<sup>210</sup>更近期，烯烃或[[硫醇官能化硅烷]]也被共价接枝到 [[纳米原纤化纤维素|NFC]] 基薄膜上，随后通过硫醇-烯[[点击化学]]与适当基团进行点击反应（见第 3.9 节）。<sup>211</sup>

## 3.7. 氨基甲酸[[酯化]]

氨基甲酸[[酯化]]，也称为氨基甲酰化，通过[[异氰酸酯]]与[[纳米纤维素]]表面可用的[[羟丙基|羟基]]发生反应，形成氨基甲酸酯键。已有报道表明，[[纤维素纳米晶|CNCs]] 和/或 [[纳米原纤化纤维素|NFCs]] 与过量正十八烷基异氰酸酯在[[甲苯]]中、100 至 110 °C 下进行 30 min 的本体反应，且不使用任何催化剂，足以有效提高其[[疏水性]]。<sup>92,212–215</sup>对常规溶剂置换程序进行轻微调整，即在将纳米[[纤维素]]从水介质转移到甲苯时不进行干燥，以避免纳米颗粒发生强烈聚集，似乎可进一步提高[[接枝]]效率。<sup>212</sup>使用[[二月桂酸二丁基锡]]作为催化剂可进一步改善反应，使得仅需使用所需量的异氰酸酯即可，而无需过量，从而可精细调控取代度（DS）。<sup>216</sup>

蓖麻油是一种甘油三酯，其大多数脂肪酸链为蓖麻油酸，在经[[异氰酸酯]]基团官能化后，成功连接到 [[纤维素纳米晶|CNCs]] 表面。由于其分子量较大而产生的位阻效应，该反应极为缓慢，在 75 °C 下需 7 天，但尽管条件苛刻，[[纤维素纳米晶体|CNCs]] 的形貌仍得以保持。<sup>217</sup>

富含[[异氰酸酯]]的 [[纤维素纳米晶|CNCs]] 通过在 [[N,N-二甲基甲酰胺|DMF]] 中、80 °C 下将 [[纤维素纳米晶体|CNCs]] 与 1,6-六亚甲基二异氰酸酯（HDI）偶联制备。使用了两种不同的 CNC/HDI 摩尔比，以改变每个[[葡萄糖|葡萄糖单元]]上[[接枝]]链的数量。在 HDI 大量过量（每个葡萄糖单元 5 个）的情况下，发生了氨基甲酸酯基低聚物的原位接枝聚合。这些富含异氰酸酯的 CNCs 通过浇铸蒸发技术掺入到嵌段热塑性[[聚氨酯]]弹性体中。改性 CNCs 有效分散在聚氨酯基体中，并与基体硬相发生相互作用，促进与硬段的物理缔合，从而提高了刚度和尺寸稳定性。<sup>218</sup>

在一种特殊且简单的方法中，[[纤维素纳米晶|CNCs]] 在 [[N,N-二甲基甲酰胺|DMF]] 中与 3-[[异氰酸酯]]丙基三乙氧基硅烷（IPTS）偶联，随后在加水时使硅烷基团[[交联]]，得到表面覆盖一层聚倍半硅氧烷分子层的 [[纤维素纳米晶体|CNCs]]（图 12）。<sup>219</sup>

图 12 CNCs 与 3-异氰酸酯丙基三乙氧基硅烷的表面氨基甲酰化及随后的硅烷缩合。

最近，[[异氰酸酯]]介导的偶联被用于在 [[纤维素纳米晶|CNC]] 上修饰[[氢键]]型[[脲基嘧啶酮]]（UPy），方法是在 100 °C 下、[[N,N-二甲基甲酰胺|DMF]] 中，使 [[纤维素纳米晶体|CNC]] 与化学计量量的 2-(6-异氰酸基己基氨基[[羰基]]氨基)-6-甲基-4[1H]嘧啶酮反应，并使用催化量的[[二月桂酸二丁基锡]]。<sup>220</sup> 当这些 UPy 修饰的 CNC 被加入到以相同 UPy 基团官能化的[[遥爪聚（乙烯-共-丁烯）]]中时，可得到具有优异力学性能的光修复[[超分子纳米复合材料]]。另有报道利用异氰酸酯介导的偶联来促进异氰酸酯官能化聚合物的[[接枝]]（见第 3.7 节）。此外，[[硫醇基异氰酸酯]]（[[异硫氰酸酯]]）被接枝到 CNC 表面，以介导 [[pH 敏感染料]]的点击连接。<sup>221</sup>

## 3.8. [[酰胺化]]

大多数[[酰胺化]]介导的偶联都是在预氧化[[纳米纤维素]]基底的[[羧基]]上实现的。在大多数情况下，胺衍生物在纳米[[纤维素]]表面的共价连接是通过[[碳二亚胺]]介导的酰胺化反应完成的，且不改变其原有的形态和结晶属性。多种胺衍生物，如 [[4-氨基-TEMPO]]、<sup>222</sup> [[苄胺]]、[[己胺]]、[[十二胺]]和 [[Jeffamine]]<sup>223</sup>，已被连接到 [[纤维素纳米晶|CNC]] 或 [[纳米原纤化纤维素|NFC]] 上。[[N-乙基-N-(3-二甲基氨基丙基)碳二亚胺盐酸盐]]（EDAC）是文献中报道的用于纳米纤维素酰胺化最常用的碳二亚胺衍生物之一。通常加入 [[N-羟基琥珀酰亚胺]]（NHS），以防止不稳定的 [[O-酰基异脲]]中间体发生众所周知的向稳定 [[N-酰基脲]]的重排。该偶联反应可在水或 [[N,N-二甲基甲酰胺|DMF]] 中成功进行，并且已被证明具有 pH 依赖性。据报道，在涉及纳米纤维素基底的酰胺化中，适宜的 pH 范围为 7 至 10。通常这种酰胺化反应较为直接，但对于带有多个胺基和羧基的基团，例如[[荧光氨基酸]]<sup>224</sup> 以及含有 2、4、6 和 8 个氨基酸的[[色氨酸基肽]]，<sup>225</sup> 则采用两步法以避免分子间连接。

此外，该反应也被用于[[接枝]]端胺基聚合物，后文将进一步说明。

## 3.9. [[点击化学]]

[[纤维素纳米晶|CNC]] 上的“点击”方法最早由 Argyropoulos 课题组提出，<sup>82</sup> 他们尝试以精巧的方式将 [[纤维素纳米晶体|CNC]] 连接在一起。通过 [[TEMPO 介导氧化]] CNC 的[[酰胺化]]，制备了两组 CNC：一组带有[[叠氮衍生物]]，另一组带有[[炔基衍生物]]。

随后，利用叠氮化物与炔基表面活化 [[纤维素纳米晶|CNC]] 之间的 Cu(I) 催化 [[Huisgen 1,3-偶极环加成]]介导的点击反应，将纳米棒以独特的有序堆积排列方式连接在一起。Sadeghifar 等人<sup>226</sup>采用了类似的方法，而最近 Feese 等人<sup>81</sup>则利用 Cu(I) 催化的 [[Huisgen–Meldal–Sharpless 1,3-偶极环加成]]反应，将[[阳离子卟啉]]表面固定化。[[纤维素纳米晶体|CNC]] [[接枝]]卟啉对[[耻垢分枝杆菌]]和[[金黄色葡萄球菌]]的光动力灭活表现出优异的效率，但对[[大肠杆菌]]仅观察到微弱活性。类似地，利用[[铜(I) 催化的叠氮–炔环加成]]将[[咪唑鎓溴盐]]接枝到 CNC 上。<sup>227</sup>作者证明了用[[双三氟甲磺酰亚胺]]或阴离子染料交换溴阴离子的可行性。这一方法或可提供以 CNC 为支撑介质，便捷获得多种离子交换体系或催化剂的机会。

通过三步化学过程（涉及[[硫醇-烯点击反应|硫醇-烯介导的点击反应]]）进行双重荧光标记，[[纤维素纳米晶|CNC]] 被转化为[[比率型 pH 传感纳米颗粒]]。<sup>221</sup>在该过程中，先通过[[酯化]]引入胺基，随后进行硫醇-烯点击反应。该胺基随后作为反应位点，用于连接对 pH 敏感的[[琥珀酰亚胺酯染料]]。出于类似目的，通过 Cu(I) 催化的叠氮–炔环加成将 [[1,2,3-三唑-4-甲胺]]修饰到 [[纳米原纤化纤维素|NFC]] 上，从而获得 pH 响应材料。<sup>228</sup>首先，在碱性水-异丙醇混合物中于环境温度下使 NFC 与 [[1-叠氮基-2,3-环氧丙烷]]反应形成[[醚键]]，然后使叠氮基与[[炔丙胺]]发生点击反应。

Tingaut 等人<sup>211</sup>开发了一种化学策略，通过涉及[[硫醇-烯点击反应]]的不同路线对 [[纳米原纤化纤维素|NFC]] 基薄膜进行化学改性（图 13）。首先将[[硫醇官能化硅烷]]附着在 NFC 薄膜表面，然后通过光化学方式点击烯端基分子，或反之亦然。包含将烯活化 NFC 基薄膜与硅烷-硫醇点击的路线速度明显更快。在另一条路线中，先将硅烷-硫醇与烯端基分子点击在一起，再通过[[溶胶-凝胶法]]借助硅烷化[[接枝]]到 NFC 薄膜表面。

## 3.10. [[聚合物接枝]]

在[[纳米纤维素]]表面[[接枝]]聚合物刷可以通过“[[接枝到表面]]”（grafting onto）或“[[从表面接枝]]”（grafting from）方法实现。“接枝到表面”方法涉及将带有反应性端基的预先合成聚合物链连接到[[纤维素]]表面（改性后的）[[羟丙基|羟基]]上。聚合物可以在接枝前被完全表征，从而提供了控制所得材料性能的可能性。然而，位阻效应可能阻碍接枝反应期间的最佳附着，因为聚合物链必须通过已接枝刷层扩散，才能到达表面可用的反应位点；因此，使用“接枝到表面”方法通常得到不利的降低的表面接枝密度。或者，选择“从表面接枝”方法是为了提高表面聚合物刷的接枝密度，并确保它们在不同应用条件下的稳定性。在该方法中，聚合物刷可以直接以纳米纤维素表面羟基作为[[开环聚合]]（ROP）的引发位点原位生长，或者可以对表面进行改性，以引入受控聚合技术（如[[原子转移自由基聚合]]（[[ATRP]]）及其他[[自由基聚合]]技术）所需的不同引发位点。

3.10.1. [[接枝到表面]]。Ljungberg 等人<sup>229</sup>使用该方法将[[马来酸化聚丙烯]]（PPgMA，含 7.5 wt%[[马来酸酐]]基团）[[接枝]]到[[海鞘]]提取的 [[纤维素纳米晶|CNCs]] 表面。该[[酯化|酯化反应]]在[[甲苯]]中于 100 1C 下进行。所得接枝纳米晶体在分散于[[无规聚丙烯]]中时表现出非常好的相容性和高粘附性。[[Araki]] 等人<sup>161</sup>和 Vignon 等人<sup>230</sup>研究了在室温下、水中通过[[碳二亚胺]]催化的[[酰胺化]]反应，将胺端基[[聚合物接枝]]到 [[TEMPO 介导氧化]]的 [[纤维素纳米晶体|CNCs]] 表面（图 14）。所得产物在不同介质中表现出非常好的分散性，并且这种分散性被证明对介质的离子强度不敏感，因为它由接枝刷之间的空间排斥而非[[静电相互作用]]所保证。Mangalam 等人<sup>231</sup>采用相同方法将 [[DNA 寡聚物]]接枝到 CNCs 表面。Harrisson 等人<sup>232</sup>和 Azzam 等人<sup>233</sup>分别使用 [[N,N-二甲基甲酰胺|DMF]] 而非水作为反应介质，接枝胺端基[[聚苯乙烯]]（PS）或[[聚（丙烯酸叔丁酯）]]（Poly(TBA)）以及 [[Jefamine 共聚物]]，其接枝效率似乎高于水中。[[环氧端基 PEO]] 通过碱活化[[纤维素]][[羟丙基|羟基]]对环氧基团的[[亲核加成]]成功接枝到 CNCs 上，形成[[醚键]]。该反应在水性介质中于 $6 5 ~ ^ { \circ } \mathrm { C }$ 下进行 6.5 小时。PEO 接枝的 CNCs 在水中形成稳定的胶体悬浮液，保持良好分散，并且在该水性悬浮液浓缩后观察到[[手性向列相]]。<sup>234</sup>类似地，预先合成的 [[聚乳酸|PLA]] 与[[甲基丙烯酸缩水甘油酯]]的环氧端基共聚物被接枝到 [[细菌纤维素|BNC]] 表面，无论其未经改性还是经过硅烷化处理，目的是在将其掺入 PLA 之前降低其亲水性。<sup>235</sup>

![](<../2.SCI_MD/Key advances in the chemical modification of nanocelluloses/images/3c99c5ebad7e0f6ca96dab192ff0a06789003013f629606ff80cf59317beae5b.jpg>)  
图 14 在羧甲基化 CNCs 表面接枝胺端基 PEG 的流程。

通过[[异氰酸酯]]介导的偶联，已在 [[纤维素纳米晶|CNCs]] 表面实现了不同分子量[[聚己内酯]]（PCL）的[[接枝]]。<sup>85</sup> 所达到的接枝密度足够高，使得接枝的 PCL 链能够在 [[纤维素纳米晶体|CNCs]] 表面结晶。然而，为达到这样的接枝密度，反应在 $8 0 ~ ^ { \circ } \mathrm { C }$ 下进行了 7 天，并持续加入偶联剂和催化剂，同时使用大量[[甲苯]]以保证良好分散。Cao 等人也作出了类似努力，<sup>236</sup> 他们报道了以 [[N,N-二甲基甲酰胺|DMF]] 为反应介质，通过[[一锅法]]对预先合成的[[聚氨酯|水性聚氨酯聚合物]]进行异氰酸酯催化的接枝。在这两种情况下观察到的接枝链结晶，在基于 CNC 的[[生物纳米复合材料|纳米复合材料]]加工过程中引发了与相应聚合物基体中自由链的[[共结晶]]。此外，这种共结晶现象诱导了基体与填料之间共连续相的形成，从而显著增强了[[界面黏附]]，并因此大幅提高了所得纳米复合材料的力学强度。Pei 及 $a l . ^ { 2 3 7 }$ 采用相同方法制备了具有超高拉伸强度和断裂应变且模量显著提高的聚氨酯–CNC 纳米复合材料。

[[点击化学]]也被用作促进[[聚合物接枝]]到[[纳米纤维素]]上的工具。在 Benkaddour 等人报道的一个例子中，<sup>238</sup> 使用 EDC/[[N-羟基琥珀酰亚胺|NHS]] 作为活化体系，将[[炔丙胺]]的氨基与 [[纳米原纤化纤维素|NFCs]] 的[[羧基]]偶联，制备了带有烷基的 [[TEMPO氧化|TEMPO 氧化]] NFCs。同时，[[聚己内酯|PCL]] 通过两步转化为叠氮基 PCL：（i）PCL 的[[甲苯磺酰化]]（PCL-OTs）和（ii）利用[[叠氮化钠]]进行亲核取代，将 PCL-OTs 转化为叠氮基 PCL；（iii）最后，在催化量 $\mathrm { C u S O } _ { 4 } { \cdot } 5 \mathrm { H } _ { 2 } \mathrm { O }$ 和[[抗坏血酸]]存在下，将叠氮基 PCL [[接枝]]到 [[四氢呋喃|THF]] 中的烷基 NFCs 上。反应在室温、避光条件下进行 2 天。在另一项近期原创研究中，利用[[紫外光引发]]的[[硫醇-烯点击反应]]，通过[[二硫醇交联剂]]，将预先用单不饱和烃刷功能化的 $\mathrm { C N C s } ,$ 与[[聚丁二烯]]进行[[交联]]。<sup>239</sup> 在高 [[纤维素纳米晶|CNC]] 负载下，通过嵌入增强型 [[纤维素纳米晶体|CNCs]] 与橡胶态聚丁二烯的交替排列，形成了紧密堆积的[[自组装取向畴]]，从而模拟了[[生物纳米复合材料]]。

## 3.10.2. [[从表面接枝]]

[[开环聚合]]（ROP）。用于[[接枝]]和聚合环状单体（主要是内酯）的ROP最初由[[Habibi]]等$a l . , ^ { 7 0 }$应用于[[纤维素纳米晶|CNCs]]，他们以[[辛酸亚锡]]<sup>$( \mathrm { S n } ( \mathrm { O c t } ) _ { 2 } )$</sup>为催化剂，在$9 5 ~ ^ { \circ } \mathrm { C }$于[[甲苯]]中进行反应（图16）。在这些条件下，[[XRD]]和[[透射电子显微镜|TEM]]证实[[纤维素纳米晶体|CNCs]]保持了其原有的[[晶体结构]]和形貌。接枝的[[聚己内酯|PCL]]链足够长，能够在CNCs表面结晶，从而可以通过与原始PCL基体熔融共混来加工相应的$\mathbf { P C L - } g \mathbf { \bar { - } } \mathbf { C N C }$母料。<sup>240</sup>后来，Chen等$a l . ^ { 2 4 1 }$和Lin等$a l . ^ { 2 4 2 }$在不使用任何溶剂但在[[微波辐照]]下进行了类似的接枝反应，以提高接枝效率，并将PCL-g-CNCs通过热成型加入PCL基体中，从而制备出具有良好机械强度的模塑片材。为了克服金属基催化剂的使用，Labet和Thielemans<sup>243</sup>最近使用[[柠檬酸]]——一种良性且天然可得的有机酸——作为催化剂。所用反应条件处于金属催化ROP常规条件范围内，因此不会产生额外的能量成本，这是迈向真正绿色材料的重要一步，因为在聚合物中引入潜在有害的金属催化剂一直是一个持续关注的问题。

Lönnberg 等人已成功实现通过 [[开环聚合|ROP]] 在 [[纳米原纤化纤维素|NFC]] 表面[[接枝]] [[聚己内酯|PCL]]，以 [[辛酸亚锡|Sn(Oct)]] 为催化剂，并采用两种不同程序，其中（i）将 NFC 分散在单体中，反应在 95 ℃ 下无溶剂进行，<sup>244</sup> 以及（ii）反应在[[甲苯]]中进行，NCF 预先分散于其中。<sup>245</sup> 与 [[纤维素纳米晶|CNC]] 类似，两种程序中施加的条件对 NFC 均无损害，因为它们在接枝过程中保持了其天然形貌与[[结晶度]]。接枝密度以及接枝 PCL 链的长度通过改变加入体系中的催化剂与游离牺牲引发剂的用量来调控。<sup>246</sup> 尽管迁移性受限，接枝的 PCL 链仍能结晶，促使作者在后续工作中研究了所得 PCL 接枝 NFC 薄膜以双层层压板形式进行热成型的加工。随后证实了接枝 PCL 链长度与所得层压板界面韧性之间的直接相关性。与在 [[纤维素纳米晶体|CNC]] 表面接枝 PCL 时所采用的策略类似，Gofin 等 $a l . ^ { 2 4 7 }$ 已成功通过 ROP 从 CNC 表面接枝 [[PLLA]] 链，且未影响其形态特征或[[晶体结构]]（图 10）。然而，根据其结晶行为，怀疑接枝链非常短。因此，为了获得高分子量接枝 PLLA 链，Braun 等 $a l . ^ { 2 4 8 }$ 建议使用通过 [[Fischer 酯化]]途径获得的[[部分乙酰化 CNC]] 来控制接枝密度。这种精心设计的生产 PLLA 接枝 CNC 的方法用于平衡相互竞争的效应；封闭部分可用于 ROP 引发的表面[[羟丙基|羟基]]可得到共价连接于 CNC 表面的高分子量链，同时保持足够的颗粒间接触，以便在[[逾渗网络]]内实现有效的应力传递。在所有这些情况下，接枝的 PLLA 链能够与基体中游离的未键合 PLLA 链[[共结晶]]。此外，由于 [[聚乳酸|PLA]] 的两种已知立体形式（例如 [[PDLA]] 和 PLLA）能够形成具有不同热性能的[[立构复合结构]]，最近一些研究报道了使用 ROP 在 CNC 表面接枝一种立体形式，并将另一种立体形式用作基体，从而在 CNC 表面引发 [[PLA 立构复合物]]的形成。<sup>249,303</sup>

在一项特定工作中，Gofin 等<sup>250</sup> 采用 [[辛酸亚锡|Sn(Oct)]] 催化的 [[开环聚合|ROP]] 从 [[纤维素纳米晶|CNC]] 表面依次[[接枝]] [[聚己内酯|PCL]]，然后再接枝 [[PLLA]]（图 15）。尽管在金属催化 ROP 条件下反应时间较长，[[纤维素纳米晶体|CNC]] 的形态与[[晶体结构]]仍得以保持。这些接枝有 [[PCL-b-PLA 共聚物]]的 CNC 在与 PCL 和 [[聚乳酸|PLA]] 的不混溶共混物共混时，表现出独特的结晶行为和分散能力。

铜介导的可控[[自由基聚合]]。根据铜元素的氧化态及其在反应过程中的稳定性，[[铜介导聚合]]按照两种不同机理进行：（i）[[原子转移自由基聚合]]（[[ATRP]]），其中 Cu(I) 直接与卤代烷引发剂片段反应并保持稳定，这实际上在非极性或低极性溶剂中更为有利；（ii）[[单电子转移活性自由基聚合]]（SET-LRP），在极性反应介质和强配位配体存在下更为有利，此时 Cu(I) 会自发且接近定量地歧化为 Cu(0) 和 Cu(II)。随后，据认为会发生外层电子转移，并由 Cu(0) 活化休眠链。在这两种情况下，进行此类聚合时最需要关注的挑战，都是难以将足够量的非极性卤代烷引发剂固定在高度极性的[[纳米纤维素]]基底表面。

Yi 等人发表了首批利用 [[SI-ATRP]] 从 [[纤维素纳米晶|CNCs]] 表面生长聚合物刷的报道。<sup>251–253</sup> 在所有这些报道中，他们使用 [[2-溴-2-甲基丙酰溴]]（Br-MPBr）作为引发剂，并在 [[4-二甲氨基吡啶]]（DMAP）和[[三乙胺]]（TEA）存在下，于 [[四氢呋喃|THF]] 中通过[[酯化|酯化反应]]将其连接到 [[纤维素纳米晶体|CNCs]] 的[[羟丙基|羟基]]上。随后，在 Cu(I)Br 和 [[1,1,4,7,10,10-六甲基三亚乙基四胺]]（HMTETA）存在下，进行苯乙烯、[[N,N-二甲氨基乙基甲基丙烯酸酯]]（DMAEMA）或 6-[4-（4-甲氧基苯基偶氮）苯氧基]己基甲基丙烯酸酯（MMAZO）的聚合。所有得到的[[聚合物接枝]] CNCs 都表现出有趣的液晶行为，且在某些情况下具有热敏感性。例如，[[接枝]][[偶氮聚合物]]聚（MMAZO）的 CNCs 同时表现出[[热致型液晶|热致型]]和[[溶致型液晶|溶致型]]两种液晶形成方式，在 95 1C 出现[[近晶相]]到[[向列相]]的转变，在 $^ { 1 3 5 } \ { } ^ { \circ } \mathrm { C } ,$ 出现向列相到[[各向同性相]]的转变，并在 135 1C 以上表现出类似的溶致液晶相行为。它们还在[[氯苯]]中浓度高于 5.1 wt% 时表现出溶致向列相。在这些研究中，引发剂的接枝密度相对较低，这很可能与非极性引发剂难以固定在高度极性的 CNCs 表面有关。随后，Morandi 等人使用大量过量的 [[2-溴异丁酰溴]]（Br-iBBr）作为引发剂，以 CuBr/[[PMDETA]] $\left( N , N , N ^ { \prime } , N ^ { \prime } , N ^ { \prime \prime } \right)$-[[五甲基二亚乙基三胺]]）（PMDETA）为催化体系，优化了从 CNCs 表面进行 [[聚苯乙烯|PS]] 的 SI-[[ATRP]]。<sup>254</sup>

通过在甲醇-水混合物中进行铜介导的[[自由基聚合]]，从[[纤维素纳米晶|CNC]]表面[[接枝]][[聚(N-异丙基丙烯酰胺)]]<sup>255</sup>以制备热响应材料时，该过程以[[SI-SET-LRP]]方式进行。相应地，Cu(I)被迅速歧化为Cu(0)和Cu(II)，从而可通过透析简便地去除催化剂。然而，对断裂聚合物刷的分子量分析显示出较宽的尺寸分布，证明由于[[单电子转移活性自由基聚合|SET-LRP]]平衡向活性态偏移，尤其是在高引发剂负载量下，聚合增长的控制不佳。为了提高[[纤维素纳米晶体|CNC]]表面引发剂密度并更好地控制接枝链的尺寸分布，Majoinen等$a l . ^ { 2 5 6 }$提出了一种两步方法将引发剂连接到CNC基底表面。CNC首先通过[[化学气相沉积]]用[[2-溴异丁酰溴|Br-iBBr]]改性，随后在常规条件下、以[[N,N-二甲基甲酰胺|DMF]]为溶剂、在[[4-二甲氨基吡啶|DMAP]]存在下再次与同一试剂进行[[酯化|酯化反应]]（图16）。

随后，[[丙烯酸叔丁酯]]在[[N,N-二甲基甲酰胺|DMF]]中聚合，聚合后被水解为丙烯酸，并使用Cu(I)Br–[[PMDETA]]与作为牺牲引发剂的[[2-溴异丁酸乙酯]]（EBiB）共同控制聚合动力学并监测聚合物链的增长。

按照该程序，获得了结构明确的聚合物刷，具有极窄的[[多分散指数]]，同时具有高[[聚合物接枝]]密度（最高可达0.3条链每nm<sup>2</sup>）。

迄今为止，文献中仅能找到两个实例报道通过[[SI-ATRP]]从[[纳米原纤化纤维素|NFC]]表面[[接枝]]聚合物刷，即[[聚丙烯酸丁酯]]（PBA）。<sup>257,258</sup> [[ATRP]]引发剂[[2-溴异丁酰溴|Br-iBBr]]的锚定在1-甲基-2-吡咯烷酮（[[N-甲基吡咯烷酮|NMP]]）中、在[[4-二甲氨基吡啶|DMAP]]–[[三乙胺|TEA]]存在下进行，而聚合则由Cu(I)Br–[[PMDETA]]体系介导，并在高温下于[[甲苯]]中进行，$e . g . 9 0 ^ { \circ } \mathbf { C } ,$导致接枝链分子量分布较宽。关于[[细菌纤维素|BNC]]，目前仅有一篇报道，其中聚甲基丙烯酸甲酯或PBA通过SI-[[原子转移自由基聚合|ATRP]]从溴异丁基丁酰基-g-[[细菌纳米纤维素|BNC]]上生长，该材料预先通过在[[N,N-二甲基甲酰胺|DMF]]中、以DMAP催化、用Br-iBBr对BNC基膜进行[[酯化]]制备。实际上，聚合在50 °C下进行3${ \mathrm { h } } ,$，反应介质为极性很强的DMF : H O（80 : 20），并由Cu(I)Br在配体PMDETA存在下作为催化体系介导。259

[[自由基聚合]]。在1 M[[盐酸]]水溶液中，以过[[硫酸]]铵为引发剂，通过氧化聚合实现了苯胺从[[纤维素纳米晶|CNCs]]表面的原位自由基聚合，从而将聚苯胺[[接枝]]到[[纤维素纳米晶体|CNCs]]上。<sup>260</sup> 如紫外-可见分析所示，该过程可得到稳定的绿色悬浮液，其中CNCs表面包覆有处于翠绿亚胺氧化态的聚苯胺。由这些聚苯胺接枝CNCs制成的浇铸膜，其电导率接近纯导电聚合物。它们还以4–10 wt% CNCs的用量被引入形状记忆[[聚氨酯]]中，在保持[[生物纳米复合材料|纳米复合材料]]形状响应性的同时，其热性能、流变性能和电性能呈现阶梯式变化。<sup>261</sup> 同样，使用过硫酸钾（KPS）–亚硫酸氢钠（SBS）体系可有效地从CNCs表面原位接枝[[聚丙烯酰胺]]，以获得新型[[水凝胶]]。<sup>262,263</sup> 为了更好地控制聚丙烯酸的接枝密度并由此调控水凝胶性能，在用水中的KPS聚合之前，先将CNCs用γ-甲基丙烯酰氧基丙基三甲氧基硅烷改性至一定程度（DS：0.06）。<sup>264</sup>

[[纳米原纤化纤维素|NFCs]]在水溶液中通过氧化还原引发的[[自由基聚合]]进行[[接枝]]，使用不同的（甲基）丙烯酸酯类单体，但以硝酸铈铵为引发剂。该反应首先通过氧化1,2-二醇基团在[[纤维素]]主链上产生自由基，随后接枝乙烯基单体。合成过程中NFCs的纳米结构得以保留，而接枝聚合物的密度从薄涂层到完全包覆原纤的连续基体不等，从而增强了其[[疏水性]]。<sup>265</sup> 值得注意的是，该策略最早由Stenstad等人$a l . ^ { 2 6 6 }$用于在NFCs表面接枝[[甲基丙烯酸缩水甘油酯]]。

其他聚合方式。Pranger和Tannenbaum研究了[[糠醇]]（FA）从[[纤维素纳米晶|CNCs]]表面的[[原位阳离子活化聚合]]。<sup>99,267</sup> 糠醇由[[木糖]]选择性脱水得到的[[糠醛]]$\left( \mathbf { C } _ { 5 } \mathbf { H } _ { 4 } \mathbf { O } _ { 2 } \right)$ $\left( \mathbf { C } _ { 5 } \mathbf { H } _ { 1 0 } \mathbf { O } _ { 5 } \right)$经工业转化生产，被认定为重要的[[生物基构建单元]]。在该情形中，聚合由[[纤维素纳米晶体|CNCs]]表面存在的[[磺酸|磺酸残基]]催化。高温下，磺酸基团发生脱[[酯化]]，进而释放到介质中原位催化聚合。尽管未提供聚（FA）[[接枝]]的证据，但CNCs表面的[[羟丙基|羟基]]极有可能参与引发聚合，从而导致聚合物链的连接。在CNCs存在下，FA聚合为聚（FA）时发生了显著程度的[[开环反应]]，形成[[二酮|二酮结构]]，1710 cm<sup>–1</sup>[[羰基]]吸收带的出现即证明了这一点。

3.10.3. 在[[还原端基]]上的[[接枝]]。众所周知，在生物合成与沉积过程中，[[纤维素]]链在[[基元原纤]]内形成单向平行取向，从而诱导生成具有一侧为带有[[羟丙基|羟基]]悬垂基团的面（称为[[非还原端]]）以及另一侧为带有[[半缩醛]]官能团还原端基的前端面的晶体。后者可被选择性地用于化学修饰。在一项独特的工作中，Sipahi Sağlam 等<sup>268</sup>证明了在这些[[半缩醛基团]]上通过“接枝到”和“接枝自”两种方法进行[[聚合物接枝]]的可行性，如图 17 所示。

## 4. [[纳米纤维素]]作为无机材料化学合成的模板

材料科学近年来对[[层级自组装]]与有序纳米材料设计的重视，得益于可持续材料开发这一迅速兴起的趋势，已促使包括构筑单元、功能与机制在内的生物学概念以前所未有的规模进入具有先进性能材料的合成之中。在这一背景下，利用[[纳米纤维素]]形态特征及其自组织能力，这些纳米尺度颗粒已被研究作为可再生模板，用于调控无机材料的尺寸、结构与组织。其中，[[纤维素纳米晶|CNC]] 的自组织能力尤其被用来制备高度有序的材料。实际上，这些棒状颗粒的均匀水悬浮液在一定浓度下会表现出壮观[[液晶排列]]，这一现象与其他棒状颗粒稳定悬浮液中发生的情况类似，例如[[聚四氟乙烯]]晶须、<sup>269</sup> [[烟草花叶病毒]] $( \mathbf { T M V } ) ^ { 2 7 0 }$ 或 [[DNA片段|DNA 片段]]。<sup>271</sup> 当用[[偏光光学显微镜]]观察时，这种组织可通过“指纹”图案的存在来揭示。更令人着迷的是，这种[[手性向列结构]]可以在悬浮液受控干燥后得以保留，从而提供具有手性向列螺距与可见光波长处于同一长度尺度的 [[虹彩薄膜|CNC 虹彩薄膜]]。这一独特体系被描述为一种干涉器件，能够在特定波长范围内反射圆偏振光。由于反射光的波长决定了其光谱色或本征颜色，薄膜所呈现的颜色取决于胆甾相有序的螺距以及光的入射角。得益于其柔韧性、高[[孔隙率]]和高[[BET|比表面积]]，由 [[纳米原纤化纤维素|NFC]] 或 [[细菌纤维素|BNC]] 制成的多孔[[气凝胶]]也被用于模板化合成各种无机材料。纳米[[纤维素]]基底带有[[羟丙基|羟基]]官能团，可与无机金属基团 $( \mathrm { T i } ^ { 4 + } , \mathrm { Z n } ^ { 2 + } , \mathrm { A u } ^ { 2 + } , \bar { \mathrm { A g } } ^ { + } , \bar { \mathrm { S n } } ^ { 2 + } , \mathrm { F e } ^ { 2 + / 3 + }$ 等）甚至非金属阳离子如 $\mathrm { S i ^ { 4 + } }$ 发生反应。主要相互作用由[[吸附]]、[[范德华力]]和静电力以及配位/螯合键驱动。一般合成路线基于多步化学过程，包括水解、缩聚以及可能存在的无机物种成核与生长，所有过程均由纳米纤维素结构模板化或自组装。但 [[纤维素纳米晶体|CNC]] 有序被其他无机物种复制往往受到诸多因素挑战，例如化学不相容性以及前驱体快速缩合破坏 CNC 的手性向列有序。该领域采用了两种主要方法：（i）将纳米纤维素胶体悬浮液用作合成介质，并同时作为永久载体，以确保无机颗粒良好且均匀的分散，或（ii）将纳米纤维素基底用作模板，随后通过矿化将其去除。

## 4.1. 二氧化硅基材料

第一份描述使用[[纤维素纳米晶|CNCs]]作为模板制备二氧化硅基材料的报告由Dujardin等人发表。<sup>272</sup> 二氧化硅网络通过在NaOH存在下、于水中缩合四甲氧基硅烷（TMOS）前驱体的溶胶–凝胶过程生成。一种呈现向列型液晶结构的部分有序[[纤维素纳米晶体|CNCs]]悬浮液被用于模板化二氧化硅相。CNCs通过在$4 0 0 ~ ^ { \circ } \mathrm { C }$下煅烧2 h去除。由CNCs的[[手性向列相]]复制得到的中孔二氧化硅表现出直径约15 nm的圆柱形孔，这一尺寸区间通常难以通过其他模板载体和方法实现。该方法通过仔细调节反应条件得到了进一步优化。酸度和组分浓度被调整，使得二氧化硅前驱体（约四乙氧基硅烷（TEOS）或TMOS，或二者按给定比例同时加入）能够水解形成均匀混合物，而不破坏CNCs完美的[[手性向列结构|胆甾相有序]]结构。<sup>273</sup> 所得的自支撑中孔二氧化硅薄膜表现出$0 . 2 5 { - } 0 . 6 ~ \mathrm { c m } ^ { 3 } ~ \mathrm { g } ^ { - 1 }$的孔体积和300–800 m<sup>2</sup> $\mathbf { g } ^ { - 1 }$的Brunauer–Emmett–Teller（[[BET]]）[[比表面积]]，具体取决于二氧化硅负载量，更重要的是它们保留了CNCs的左旋胆甾相结构。这些薄膜在整个可见光谱范围内以不同波长反射光，并在吸水后变得完全无色（图18）。该方法已被证明非常通用，因为它已被扩展用于制备其他手性向列型中孔材料。事实上，该方法被用于制备具有长程手性和光子结构的乙烯桥联中孔有机硅柔性薄膜。但为了合成这些材料，使用[[酸水解]]而非煅烧来去除$\mathrm { C N C S } . ^ { 2 7 4 }$。此外，这些二氧化硅基中孔材料还被金属纳米颗粒修饰，包括$\mathbf { A u } , \mathbf { A g }$和Ni。在煅烧前向CNCs和二氧化硅前驱体（TMOS）的水分散体中加入少量离子化合物，可以精细调控手性向列结构的螺距。<sup>275,276</sup> 还通过[[纳米纤维素]]模板法制备了具有各种形貌和形状的二氧化硅基发光材料。事实上，使用TEOS作为二氧化硅前驱体，通过酸碱溶胶–凝胶过程，以CNC为模板制备了发蓝光的二氧化硅纳米线和纳米管，随后在不同温度下煅烧。在$6 5 0 \ { } ^ { \circ } \mathrm { C } ,$下生成了中空纳米管，其芯腔直径为4–8 nm，而在更高温度（约900 1C）下，先前被[[纤维素]]模板占据的芯区闭合，得到直径15 nm、长度可达500 nm的二氧化硅纳米线。 304

## 4.2. 二氧化钛基材料

以 [[纤维素纳米晶|CNCs]] 为模板，结合[[层层组装|层层（LbL）组装]]与溶胶–凝胶涂覆方法，获得了不同长径比的二氧化钛核–壳及中空纳米颗粒。<sup>277</sup> 在 LbL 组装中，[[纤维素纳米晶体|CNCs]] 依次包覆带正电的[[聚（二烯丙基二甲基氯化铵）]]（PDADMAC）层和带负电的二氧化钛前驱体——双（[[乳酸]]铵）二氢氧化钛（IV）（TALH）；与遇水会迅速水解的钛醇盐不同，TALH 在常温中性溶液中稳定。所得[[聚电解质]]包覆的 CNCs 在水溶液中于 $1 0 0 ~ ^ { \circ } \mathrm { C }$ 下回流 24 h，随后煅烧以获得中空二氧化钛纳米颗粒。在溶胶–凝胶合成中，以钛酸四丁酯（TBT）为前驱体在 CNCs 上包覆二氧化钛，随后将溶液在 $8 0 ~ ^ { \circ } \mathrm { C }$ 下回流 1.5 h，以确保二氧化钛壳层完全缩合。然后通过离心收集核–壳颗粒，并在 $9 0 0 ~ ^ { \circ } \mathrm { C }$ 下煅烧 10 min，以获得中空二氧化钛颗粒。在两种 技术研究中发现，CNC模板的细长形状在涂层生长过程中并未得以保持，但合成二氧化钛颗粒的长径比可通过改变涂层厚度和/或模板长径比进行调控。此外，通过控制涂层厚度并选择合适的模板，可同步调节整体颗粒形状与空腔形状。将空气稳定的双(乳酸铵)二氢氧化钛(IV)与CNC胶体悬浮液混合后，可获得自支撑复合薄膜。经煅烧后，以CNC为模板制备出具有锐钛矿结构、[[BET|比表面积]]为170–200 m<sup>2</sup> $\mathbf { g } ^ { - 1 }$ 的多孔二氧化钛。<sup>278</sup>

[[纤维素纳米晶|CNCs]] 还被用于通过溶胶–凝胶法在 $4 0 \ ^ { \circ } \mathbf { C } .$ 下使乙醇钛（IV）水解，以辅助二氧化钛纳米颗粒的合成。所得纳米球形 $_ { \mathrm { T i O } _ { 2 } - \mathrm { C N C } }$ 颗粒即使仅在低负载量的 $\mathrm { T i O } _ { 2 }$ 纳米颗粒下，也表现出明显的量子尺寸效应和较低的带隙。它们在弱紫外光照射下也表现出较高的光催化活性，其光催化效率可与纯锐钛矿型 $\mathrm { T i O } _ { 2 }$ 纳米颗粒相媲美。<sup>279</sup> 通过改变合成条件，$e . g .$ ，以四氯化钛（IV）为前驱体，并将温度升至 $4 0 \ ^ { \circ } \mathbf { C } ,$ 以上，获得了其他形貌。实际上，在 $4 0 { - } 6 0 \ { } ^ { \circ } \mathrm { C }$ 下合成的晶体呈花状形貌，而当温度升高至 $7 0 { - } 8 0 \ ^ { \circ } \mathbf { C } ,$ 时，则获得了边长为 100–200 nm 的立方纳米晶体。<sup>280</sup>

通过[[化学气相沉积]]在高[[孔隙率]][[纳米原纤化纤维素|NFC]]基[[气凝胶]]上沉积了一层非常薄的$\mathrm { T i O } _ { 2 }$（约7 nm），得到了一种新型功能材料，表现出在水超吸收态与疏水态之间的光开关行为以及良好的光催化活性。该过程简单，将NFC基气凝胶暴露于$1 9 0 ~ ^ { \circ } \mathrm { C }$的钛酸异丙酯蒸气中，压力为1–5 kPa，持续2 h。类似地，$\mathrm { T i O } _ { 2 }$也被用作疏水但亲油的涂层，以对NFC气凝胶进行疏水化处理。<sup>281</sup>所得的可漂浮、可重复使用的多孔材料对非极性液体和油类表现出高度选择性吸收。其吸收量接近气凝胶的总体积（80–90% v/v），基于质量的吸收容量为20–40%（wt/wt），具体取决于液体的密度。NFC基气凝胶还被用作模板，通过原子层沉积（ALD）制备无机中空纳米管气凝胶（图19）。

## 4.3. 碳基材料

先前描述的介孔二氧化硅–[[纤维素纳米晶|CNC]] 复合材料，在一种完全不同的方法中被用作中间模板。在该方法中，[[纤维素纳米晶体|CNC]] 作为碳源，用于制备碳基手性向列材料。实际上，在惰性气氛中对二氧化硅–CNC 手性向列复合薄膜进行受控热解，随后用 2 M 氢氧化钠去除二氧化硅，可得到手性向列介孔碳薄膜（[[BET|比表面积]]为 1460 $\mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 }$，孔体积为 1.22 cm $^ { - 3 } \mathrm { g } ^ { - 1 } )$），并表现出半导体性质。<sup>285,286</sup> 当 CNC 在包覆二氧化硅之前先被金属胺配合物离子包覆时，还可获得氮掺杂碳纳米针，其具有组织良好的石墨化层以及高比例的氮掺杂边缘面，表现出非常高的电催化活性 $\mathrm { g e l . } ^ { 2 8 7 }$ 有趣的是，通过对煅烧过程的精细控制，可以将 CNC 转化为无定形碳（从 100 到 $3 0 0 ~ ^ { \circ } \mathrm { C } )$），随后在 $1 2 0 0 \ { } ^ { \circ } { \bf C } .$ 退火后转变为针状石墨碳。在整个过程中，CNC 周围的二氧化硅壳充当坚固的纳米反应器，使核–壳纳米级针状结构保持完整（图 20）。

## 4.4. 银基材料

利用[[纤维素纳米晶|CNC]]模板，通过$\mathbf { A g N O } _ { 3 }$与HAuCl的共还原法合成了均匀的Au–Ag合金纳米颗粒。通过使用封端剂（即[[柠檬酸]]钠），将合金纳米颗粒的尺寸保持在3–7 nm范围内。然而，Ag含量的增加导致其平均直径增大。<sup>294</sup> 在[[纳米原纤化纤维素|NFC]]水悬浮液中还原水合四氯金酸盐$\left( \mathrm { H A u C l } _ { 4 } { \cdot } 3 \mathrm { H } _ { 2 } \mathrm { O } \right)$和氯化四氨钯(II) $\left( [ \mathbf { P d } ( \mathbf { N H } _ { 3 } ) _ { 4 } ] { \cdot } \mathbf { C l } _ { 2 } \right)$后，成功在[[TEMPO氧化]]的NFC表面合成了高度分散的Au和Pd双金属纳米颗粒。所得纳米颗粒的平均尺寸强烈依赖于所用Au : Pd的相对摩尔比，但保持在10 nm以下。所得Au–Pd–NFC在4-硝基苯酚水相还原为4-氨基苯酚的反应中表现出优异的催化性能，且该性能取决于Au和Pd的摩尔比（图21）。<sup>295</sup> 类似地，单独利用氧化NFC的羧酸根基团作为选择性位点，也成功原位合成了Au纳米颗粒，用于其 合成。Au-NFC 复合材料表现出优异的催化效率，在一个模型水相还原反应中，Au-NFCs 的转换频率高达传统聚合物负载 Au 纳米颗粒的 840 倍。<sup>296</sup> 最近，[[细菌纤维素|BNC]] 基纤维毡被用作模板，通过绿色途径，采用[[溶胶-凝胶法]]掺入钒纳米颗粒，制备了导电光开关杂化纳米纸。297 所得纳米纸能够光诱导可逆颜色变化。其他金属纳米颗粒或其相应氧化物也利用不同形式的[[纳米纤维素]]基模板，通过非常简单的途径制备，得到了具有定制性能的材料。其中包括镍、<sup>298</sup> 硒、<sup>299</sup> 铟锡氧化物、<sup>300</sup> 氧化锌、<sup>301</sup> 硫化镉、<sup>302</sup> 等。

## 5. 结论

[[纳米纤维素]]，包括[[纳米原纤化纤维素]]、[[纤维素纳米晶]]和[[细菌纤维素]]，目前是材料学界高度关注和研究的对象。它们不仅代表了一种储量丰富且可持续生产的独特[[生物材料]]，而且由于其固有的具有吸引力的化学功能性和物理特性，能够在众多领域中寻求新颖应用。它们可以从多种[[纤维素]]基质中获得，这些基质最终赋予纳米纤维素不同的形态特征。尽管如此，它们固有的亲水性构成了一个主要缺点，需要利用其多元醇官能团通过化学改性进行一定调整。本综述试图对重要的化学转化进行总体概述，这些转化使基于纳米纤维素的材料能够实现更多的纳米技术和功能应用。这样的概述极为相关且及时，尤其是考虑到当前推动将新型生物基化学构建模块用于开发具有定制特性的新型生物材料的势头。为了在这样一个平台内广泛理解它们的相关性，本综述涉及了若干重要的化学改性，这些改性可以产生先进材料，服务于制药、生物医学、造纸、化妆品、食品和工业修复等行业。

显然，现在比以往任何时候都更需要进一步关注创新转化路线的开发，以增强它们在其他领域的应用，因为其优势和累积效益显然极高。然而，任何转化的简便性和降低的成本都是该领域发展的强大驱动力。应当牢记，在解决[[纳米纤维素]]制造的规模化和均匀性方面，仍然存在重大的科学和技术挑战。
