## 1. 引言

[[全氟和多氟烷基物质]]（PFASs）是一类氟化有机化合物，广泛用于纺织、印刷、地毯、杀虫剂、皮革和[[水成膜泡沫]]（AFFFs）等工业和民用领域。<sup>1,2</sup> 然而，PFASs一旦进入人体，就会表现出发育毒性、免疫毒性和肝毒性。<sup>3</sup> 其中，[[全氟烷基磺酸盐]]（[[全氟磺酸|PFSAs]]）作为PFASs中常见的一类，在水环境中普遍存在。尤其是[[全氟辛烷磺酸盐]]（[[全氟辛烷磺酸|PFOS]]）受到特别关注，因为它具有高持久性、毒性和生物累积性，并自2009年起被列入《[[斯德哥尔摩公约]]》关于[[持久性有机污染物]]（POPs）的附件B中。<sup>4,5</sup> 尽管PFOS的生产和使用已在全球范围内被禁止，但仍可在

由于长链[[全氟烷基磺酸盐|PFSAs]]的限制，出现了一些替代品，如[[全氟丁烷磺酸盐]]（[[全氟丁烷磺酸|PFBS]]）、[[全氟己烷磺酸盐]]（[[全氟己烷磺酸|PFHxS]]）<sup>7</sup> 和[[氯代多氟醚磺酸盐]]（[[F53B]]）。<sup>8</sup> 例如，[[全氟辛烷磺酸|PFOS]]曾用作镀铬工业中的抑雾剂和润湿剂，<sup>9</sup> 而中国生产商使用F53B作为替代品。<sup>10</sup> PFBS由美国明尼苏达矿业制造公司（Minnesota Mining and Manufacturing）开发为表面活性剂，并且

[[全氟己烷磺酸|PFHxS]]通常存在于[[水成膜泡沫]]（AFFF）产品中。<sup>11,12</sup> 尽管与[[全氟辛烷磺酸|PFOS]]相比，其中一些替代品的生物毒性和生物累积性较低，<sup>13</sup> 但它们在生物和非生物介质中仍具有持久性。例如，[[全氟己烷磺酸盐|PFHxS]]在人体内的血清消除半衰期与[[全氟辛烷磺酸盐|PFOS]]相似甚至更长。<sup>14</sup> 此外，与长链[[全氟烷基磺酸盐|PFSA]]类似，这些物质已在[[地下水]]和[[地表水]]中以高浓度被检出，从而显示出对水生环境的潜在风险。

[[全氟烷基磺酸盐|PFSA]]具有非常稳定的物理化学性质，包括对氧化的热稳定性和化学稳定性，以及对光解、水解和生物降解的抵抗性，这归因于极强的C−F键（536 kJ/mol）。<sup>15</sup> 因此，目前从水源中去除[[全氟磺酸|PFSA]]的技术主要基于[[吸附]]和低压膜过滤。<sup>16−18</sup> 然而，[[活性炭]]（AC）和树脂等传统多孔材料结构不可控，对[[全氟和多氟烷基物质|PFAS]]的吸附速率较慢且[[吸附容量]]较低，显著限制了它们在实际[[废水]]中的应用。<sup>19</sup> 此外，[[金属有机框架]]（MOF）作为吸附剂的应用效果不佳，因为在酸性溶液中，有机配体与金属中心之间可能形成配位键。<sup>20</sup> 因此，开发能够快速去除PFSA且更高效的吸附剂仍然是一项迫切需求。

图1. COF1、COF2、COF3和COF1N的合成及其对应的高分辨率扫描电子显微镜（SEM）图像（× 10 000）。

[[共价有机框架]]（COF）是具有高度有序孔结构的晶态材料，由轻元素通过热力学控制的可逆聚合以共价方式组装而成。<sup>21</sup> 亚胺、<sup>22</sup> 肼、<sup>23</sup> 硼酸酯<sup>24</sup> 和硼氧六环<sup>25</sup> 等共价键通常被用于构筑具有多样功能和良好[[吸附]]潜力的二维和三维COF，这得益于其有序的多孔基质、高[[BET|比表面积]]和可调节的功能。迄今为止，已有若干研究证明了COF对[[全氟和多氟烷基物质|PFAS]]具有高[[吸附容量]]。例如，一种胺功能化COF可在30 min内对全氟-2-丙氧基丙酸铵实现超过200 mg/g的吸附容量，<sup>26</sup> 但未考虑实际水中共存物质的影响，且吸附机理尚不明确。一种二噁英连接型COF对[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]的吸附容量分别为261和209.5 mg/g，<sup>27</sup> 但吸附速率较慢。为应对这些挑战，研究者开发了一种多孔[[β-环糊精]]（β-CD）聚合物，并由于溶液中β-CD包合物的快速形成，<sup>29</sup> 该聚合物可在1 min内极快地去除水中的[[双酚A]]。<sup>28</sup> 然而，该β-CD基聚合物对全氟辛酸（PFOA）的吸附速率要慢得多，需超过12 h才能达到平衡。<sup>30</sup> PFOA分子的传输可能受到聚合物非均匀孔结构的阻碍。<sup>31</sup> 因此，应将聚合物基吸附剂的结构调整为有序孔结构，这或许能够实现对PFAS的快速去除速率。

在本研究中，我们通过酸催化醛亚胺缩合反应制备了四种具有有序蜂窝状晶格的[[β-环糊精|β-CD-COFs]]，并研究了它们对[[全氟辛烷磺酸|PFOS]]及其替代物（[[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]]和[[F53B]]）的[[吸附]]行为和机理。通过[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算研究了有助于吸附的相互作用。还进行了对比实验，以进一步评估所制备[[共价有机框架|COFs]]的吸附效率，同时特别研究了溶液pH的影响。还对使用后的吸附剂进行了[[再生]]和重复使用。最后，在模拟受[[水成膜泡沫|AFFF]]影响的[[废水]]和实际[[镀铬废水]]中评估了[[β-环糊精共价有机框架|β-CD-COFs]]的适用性。

## 2. 材料与方法

2.1. 化学品。[[七（6-氨基-6-脱氧）-β-环糊精]]（Am7CD）购自[[山东滨州智源生物科技有限公司]]$\mathrm { C o . , }$（中国山东）。[[对苯二甲醛]]（TPA）、[[2,5-吡啶二甲醛]]（PD）、[[4,4′-联苯二甲醛]]（BD）和[[4,4′-对三联苯二甲醛]]（TD）购自[[吉林中科研伸科技有限公司]]（中国吉林）。[[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]]和[[全氟辛烷磺酸|PFOS]]购自[[北京百灵威科技有限公司]]（中国北京），而[[F53B]]$\mathrm { \tilde { ( } C l { C _ { 6 } F _ { 1 2 } O C F _ { 2 } C \bar { F } _ { 2 } S O _ { 3 } K ) } }$获自[[中国科学院上海有机化学研究所]]。四种[[全氟烷基磺酸盐|PFSA]]的主要理化性质见表S1。超纯水使用[[Milli-Q一体化净水系统]]（Millipore）制备。所有其他化学品均为分析纯或HPLC级。

2.2. [[β-环糊精|β-CD-COFs]]的制备。通过酸催化醛亚胺缩合反应合成了β-CD-[[对苯二甲醛|TPA]]-[[共价有机框架|COF]]（COF1）、β-CD-[[2,5-吡啶二甲醛|PD]]-COF（COF1N）、β-CD-[[4,4′-联苯二甲醛|BD]]-COF（COF2）和β-CD-[[4,4′-对三联苯二甲醛|TD]]-COF（COF3）（图1）。简言之，将[[七（6-氨基-6-脱氧）-β-环糊精|Am7CD]]（12 mmol/L）与各连接分子（30 mmol/L）在乙醇/均三[[甲苯]]/N,N′-二甲基甲酰胺（体积比3/3/2）混合溶剂中于85 °C聚合3天。酸催化剂的浓度根据底物反应活性选择（图S1）。反应完成后，通过离心获得生成的原始沉淀，并用二甲基亚砜和均三甲苯洗涤以去除未反应的反应物。然后用[[甲醇]]活化收集的产物。最终[[β-环糊精共价有机框架|β-CD-COFs]]通过在$8 0 ~ ^ { \circ } \mathrm { C }$下真空干燥12 h获得，为浅黄色（COF1、COF2和COF3）或浅砖红色（COF1N）粉末。

2.3. [[β-环糊精|β-CD-COFs]]的表征。使用[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]，JSM-7001F）观察合成[[共价有机框架|COFs]]的表面形貌，并通过配备Cu Kα辐射源$\left( \lambda = 0 . 1 5 4 \right.$ nm）的[[X射线粉末衍射]]仪（[[XRD]]，D/Max2500PC）进一步分析其结构。四种COFs的[[BET|比表面积]]和[[孔径分布]]通过在77 K下的[[N₂吸附等温线]]（Autosorb iQ）测定。

2.4. [[吸附]]实验。通过一系列批量吸附测试评估 [[共价有机框架|COF1]]、COF2、COF3 和 COF1N 对 [[全氟烷基磺酸盐|PFSA]] 的去除行为。吸附实验在 50 mL 螺旋瓶中进行，瓶中含 20 mL 0.1 mmol/L 的 [[全氟磺酸|PFSA]] 溶液和 250 mg/L 的各吸附剂，pH 为 4.3。[[吸附等温线]]实验中使用的 PFSA 浓度范围为 0.05−0.65 mmol/L，而 pH 值为 4.3、5.5 和 7.3 的条件用于评估溶液 pH 对 COF 吸附效率的影响。此外，使用三种吸附剂进行比较实验，以进一步评估 COF 相较于其他材料的效率。具体而言，使用了[[粉末活性炭]]（[[活性炭|PAC]]，>100 目），其由颗粒状椰壳基活性炭（货号：926890，J&K Scientific Ltd.）制得，原始粒径范围为 8−20 目，[[BET|比表面积]]为 912.6 m<sup>2</sup>/g；还使用了[[多壁碳纳米管]]（[[碳纳米管|CNTs]]）、[[石墨烯]]（Gr）、非离子交换 Amberlite XAD-7hP 树脂（一种粒径范围为 0.25−0.85 mm 的大孔脂肪族丙烯酸聚合物），以及常见的[[阴离子交换]] Amberlite [[IRA-400]] 树脂。

为进一步评估 [[β-环糊精共价有机框架|β-CD-COF]] 从[[废水]]中去除 [[全氟烷基磺酸盐|PFSA]] 的选择性，使用了含有 2.0−392.1 $\mu \mathrm { g / L }$ 不同 [[全氟磺酸|PFSA]] 的实际[[镀铬废水]]（见支持信息（SI）），并制备了含 0.2 mmol/L 共存天然有机物和 0.1 mmol/L PFSA 的复杂混合物，以模拟受 [[水成膜泡沫|AFFF]] 影响的废水。有机化合物包括 AFFF 中存在的[[三氯乙烯]]和[[十二烷基硫酸钠]]，以及水中常见的[[甲苯]]和[[腐殖酸]]。<sup>32</sup> 还添加了氯化物、硝酸盐、硫酸盐和碳酸盐作为常见共存阴离子（0.2 mmol/L），尤其是在[[地下水]]中，同时以 [[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]]、[[全氟辛烷磺酸|PFOS]] 和 [[F53B]] 作为目标污染物。在[[吸附]]实验中，所有溶液均使用磁力搅拌器搅拌 30 min。在[[吸附动力学]]测试中，溶液搅拌 45 min。

2.5. 分析方法。[[全氟烷基磺酸盐|PFSA]] 浓度采用 LC-10ADvp HPLC 泵和 CDD 电导检测器（[[Shimadzu]]）测定，配备 TC-C18 色谱柱（4.6 mm × 250 mm 内径，粒径：5 μm；[[Agilent Technologies]]）。[[全氟丁烷磺酸|PFBS]] 和 [[全氟己烷磺酸|PFHxS]] 使用 65/35（v/v）[[甲醇]] $/ \mathrm { N a H } _ { 2 } \mathrm { P O } _ { 4 }$（0.02 mol/L）混合物作为流动相，而 [[全氟辛烷磺酸|PFOS]] 和 [[F53B]] 使用 75/25（v/v）甲醇 $/ \mathrm { N a H } _ { 2 } \mathrm { P O } _ { 4 }$（0.02 mol/L）混合物。流速恒定保持在 1.0 mL/min，液相色谱柱温为 45 ${ } ^ { \circ } \mathrm { C } ,$，每个样品的进样量为 30−40 $\mu \mathrm { L }$。

与[[共价有机框架|COF3]]相比，COF1、COF1N和COF2的[[吸附]]曲线达到了饱和状态。在吸附初期，丰富的位点可供吸附。然而，随着去除过程的进行，可用位点数量逐渐减少并趋于饱和。为定量评价吸附量，这些曲线用[[Langmuir模型]]（$\left( R ^ { 2 } \ = \ \right.$ 0.849−0.996）拟合优于[[Freundlich模型]]（$\bar { \left( \right)} R ^ { 2 } = 0 . 7 8 4 - 0 . 9 5 3 $）（表S3）。基于Langmuir拟合，COF1对[[全氟丁烷磺酸|PFBS]]的[[吸附容量]]为0.33 mmol/g，对[[全氟己烷磺酸|PFHxS]]为0.55 mmol/g，对[[全氟辛烷磺酸|PFOS]]为1.51 mmol/g，对[[F53B]]为1.19 mmol/g。此外，[[全氟辛烷磺酸盐|PFOS]]在COF1N和COF2上的吸附容量分别为0.83和1.25 mmol $/ { \bf g } ,$。然而，PFOS在COF3上的[[吸附等温线]]无法用常用模型很好地拟合（表S4）。因此，采用了Freundlich模型，该模型为经验方程，其非线性指标n可用于评价吸附位点的均一性。PFOS（n = 3.92）和[[氯代多氟醚磺酸盐|F53B]]（n = 3.48）相对较高的n值表明吸附是非线性的，可能涉及[[疏水作用]]和[[氢键]]等相互作用。鉴于两条C−F链之间的亲和性，已吸附的[[全氟烷基磺酸盐|PFSA]]分子也可能从水溶液中继续吸附其他[[全氟磺酸|PFSA]]分子。40

还进行了对比[[吸附]]实验，以评价[[共价有机框架|COF1]]与其他吸附剂的吸附效率（图4c）。与树脂、[[活性炭|PAC]]、[[多壁碳纳米管|CNTs]]和[[石墨烯|Gr]]相比，COF1在30 min内对[[全氟辛烷磺酸|PFOS]]具有更高的[[去除率]]（>97%）。此外，在已报道的吸附剂中，COF1表现出非常有竞争力的[[吸附容量]]（表S2）。据报道，[[全氟辛烷磺酸盐|PFOS]]在[[IRA-400]]上的吸附平衡在168 ${ \mathrm { h } } , ^ { 4 1 }$后达到，而COF1对PFOS表现出显著快速的吸附。此前研究发现，IRA-400上的大多数交换位点可能因[[尺寸排阻]]而无法被PFOS接近。<sup>41</sup> 因此，已报道吸附剂对PFOS较低的吸附容量与其相对COF1而言不合适的空间结构有关。

研究了溶液pH对[[共价有机框架|COF1]]去除[[全氟辛烷磺酸|PFOS]]的影响，结果如图4d所示。[[全氟辛烷磺酸盐|PFOS]]的[[去除率]]随pH升高而下降，PFOS去除率从pH 4.3时的97%降至pH 7.3时的54%。在实验条件下，PFOS以阴离子形式存在，因为其pK值为−3.27，<sup>42</sup> 而[[β-环糊精|β-CD]]的[[胺基|氨基]]<sup>a</sup>基团在酸性溶液中发生[[质子化]]。<sup>43</sup> 因此，当溶液pH为4.3时，COF1表面带正电，表明该pH值下的[[吸附容量]]可归因于带正电的COF1表面与带负电的PFOS分子之间的[[静电吸引]]。然而，当溶液pH从4.3升高至7.3时，COF1表面电荷减少，导致COF1对PFOS的去除效率下降。由于存在一些低pH值的实际酸性[[废水]]，所制备的COF1可用于有效的[[全氟烷基磺酸盐|PFSA]]去除。<sup>41</sup>

[[全氟磺酸]]（[[全氟烷基磺酸盐|PFSAs]]）在实际水体中常与其他有机污染物共存，由于[[吸附]]剂选择性较低，这进一步限制了 PFSAs 的高效去除。因此，利用模拟受 [[水成膜泡沫|AFFF]] 影响的[[废水]]（图 4e、f），评价了四种 [[共价有机框架|COFs]] 在实际环境条件下对 PFSA 吸附的选择性。COF1 和 COF1N 的选择性明显下降，但模拟废水对 COF2 和 COF3 的影响不显著。由于 COF3 表现出较差的吸附行为，选择 COF2 进行进一步的吸附研究。特别是测试了三种 [[全氟辛烷磺酸|PFOS]] 替代品，即 [[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]] 和 [[F53B]]，在 COF2 上的吸附。与去离子水中相比，模拟水中所有污染物的[[去除率]]保持稳定（图 4f），表明 COF2 对 [[全氟和多氟烷基物质|PFASs]] 具有高选择性。还使用含有 2.0−392.1 μg/L 不同 PFSAs（SI）的真实[[镀铬废水]]进一步证实了 COF2 的实际应用。在 2 min 内，超过 98% 的 [[氯代多氟醚磺酸盐|F53B]] 被去除，同时去除了 65% 的 [[全氟辛烷磺酸盐|PFOS]] 和 55% 的 [[全氟己烷磺酸盐|PFHxS]]（图 S5）。与 F53B 相比，PFOS 的去除率相对较低，这归因于废水中 PFOS 浓度显著更高。尽管存在这些差异，从[[高盐废水|高盐度废水]]中高效去除 PFSAs 支持了 [[β-环糊精|β-CD-COFs]] 在快速去除真实废水中 PFSAs 方面的巨大应用潜力。对于纳克每升和微克每升水平的低浓度 PFASs，吸附去除具有成本效益，富集后的 PFASs 可进一步通过氧化和还原方法处理。吸附与降解相结合可能是未来去除 PFASs 的有效策略。

由于所有 [[共价有机框架|COFs]] 都对 [[全氟和多氟烷基物质|PFASs]] 表现出超快[[吸附]]，我们认为 [[β-环糊精|β-CD]] 可能发挥了重要作用。[[全氟烷基磺酸盐|PFSAs]] 具有类似的分子结构，即磺酸头基和 C−F 链尾，而 β-CD 具有规则的空腔，其尺寸和结构适宜紧密吸附 PFAS 分子。对 β-CD 和 [[全氟辛烷磺酸|PFOS]] 分子范德华表面的[[静电势]]（ESP）计算（图 5a）表明，β-CD 的[[胺基|氨基]]末端和空腔相对缺电子，而羟基末端和外部相对富电子。相比之下，整个 [[全氟辛烷磺酸盐|PFOS]] 分子，尤其是其磺酸头基，是富电子的，表明 β-CD 倾向于以互补方式将 PFOS 捕获到其空腔中。[[独立梯度模型|IGM]] 分析还表明，在 PFOS 的磺酸头基与 β-CD 的氨基之间形成了强 N−H···O−S [[氢键]]，同时在 PFOS 的磺酸头基与氨基的 α、β-碳之间观察到弱氢键，并且在 PFOS 的 C−F 链与 β-CD 的醚环之间存在[[范德华相互作用]]（图 5b）。

进一步评估[[β-环糊精|β-CD]]原子对[[全氟辛烷磺酸|PFOS]]捕获的贡献表明，β-CD空腔，尤其是[[胺基|氨基]]端和β-CD中部，可以形成强相互作用，[[结合能]]$( \Delta E _ { \mathrm { b i n d i n g } } )$为−37.93 kcal/mol（图5c）。对于其他受试[[全氟和多氟烷基物质|PFASs]]也获得了类似结果（图S6−S8），四种复合物的$\Delta E _ { \mathrm { b i n d i n g } }$遵循β-CD-8S $< \beta { \mathrm { - } } \mathrm { C D } { \mathrm { - } } \mathrm { F } \bar { 5 3 } \mathrm { B } < \beta { \mathrm { - } } \mathrm { C D } { \mathrm { - } } 6 \mathrm { S } < \beta { \mathrm { - } } \mathrm { C D } { \mathrm { - } } 4 \mathrm { S }$的顺序（图S8），与其[[吸附容量]]一致。然而，β-CD-[[F53B]]和β-CD-8S的$\Delta E _ { \mathrm { b i n d i n g } }$值并未显著低于其他两种[[全氟烷基磺酸盐|PFSA]]，这主要是因为我们忽略了晶胞z轴上其他单胞的相互作用。因此，对PFASs的高[[吸附]]亲和力来源于所有这些不同相互作用的共同作用。

3.3. [[共价有机框架|COFs]]的[[再生]]与重复使用。多种策略，如热水、有机溶剂和[[高级氧化]]，已被开发用于再生一些失效[[吸附]]剂44。其中，[[溶剂再生]]表现出更好的[[脱附]]效果和更少的材料损失，而[[甲醇]]已被证明可成功再生用于吸附[[全氟烷基磺酸盐|PFSA]]的[[活性炭]]。<sup>45</sup>在此，经甲醇再生的COF1对[[全氟辛烷磺酸|PFOS]]的[[去除率]]在第二个吸附−脱附循环中从97%降至93%，并在后续循环中保持相对稳定（图S9），表明所制备的COF1具有良好的[[重复使用性|可重复使用性]]。

## 4. 结论

高效去除水体中的[[全氟和多氟烷基物质|PFASs]]是全球关注的问题，目前缺乏兼具快速[[吸附]]速率和高[[吸附容量]]的高效吸附剂。在本研究中，我们成功制备了具有合适孔结构和特定物理化学性质的精心设计的[[β-环糊精|β-CD-COFs]]，可用于快速去除水体中的[[全氟烷基磺酸盐|PFSA]]。新型[[β-环糊精共价有机框架|β-CD-COFs]]在仅2 min内即对[[全氟磺酸|PFSA]]表现出高吸附容量，且其对长链PFSA的吸附性能优于短链PFSA。特别是，β-CD-[[共价有机框架|COFs]]对模拟[[水成膜泡沫|AFFF]][[废水]]和实际[[镀铬废水]]中的PFASs也具有高且快速的吸附能力。因此，β-CD-COFs可应用于高效去除[[地表水]]、[[地下水]]及不同废水中的多种PFASs。此外，由于这些β-CD-COFs对PFASs具有快速吸附能力，它们可作为高效吸附剂用于水/废水[[样品预处理]]中低浓度PFASs的富集。PFASs在β-CD-COFs上的潜在吸附机理对其他高效吸附剂的制备具有指导意义。需要指出的是，粉末形式的β-CD-COFs在实际水/废水处理中不便回收使用，而β-CD-COFs的磁性改性和造粒有可能解决这一应用局限。进一步的研究应针对短链PFASs的有效去除以及易回收β-CD-COFs的制备开展。
