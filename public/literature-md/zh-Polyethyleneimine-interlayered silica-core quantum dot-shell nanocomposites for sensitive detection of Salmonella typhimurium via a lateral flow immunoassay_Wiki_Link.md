# [[聚乙烯亚胺]]夹层[[二氧化硅]]核-[[量子点]]壳[[纳米复合材料]]用于通过[[侧向流免疫分析]]灵敏检测[[鼠伤寒沙门氏菌]]†

[[Bo Zhang]],<sup>ad</sup> [[Xingsheng Yang]],<sup>bc</sup> [[Xiaoxian Liu]],<sup>bc</sup> [[Juan Li]], \*<sup>a</sup> [[Chongwen Wang]] \*<sup>bc</sup> 和 [[Shengqi Wang]]\*<sup>bc</sup>

收稿日期：2019 年 11 月 7 日

接收日期：2020 年 1 月 4 日

DOI：10.1039/c9ra09252h

rsc.li/rsc-advances

本文中，我们采用[[聚乙烯亚胺]]（PEI）介导的[[吸附]]方法合成了高性能的 [[二氧化硅|SiO₂]] 核-[[量子点]]（QD）壳[[纳米复合材料]]（SiO₂@PEI-QDs）。阳离子型 PEI 被用于在 $\mathsf { S i O } _ { 2 }$ 核上形成带正电的中间层，从而实现了对[[羧基化量子点]]的致密吸附以形成量子点壳层，并保持了该纳米复合材料良好的[[分散性]]。SiO₂@PEI-QDs 表现出优异的[[稳定性]]和高发光强度，并在与[[侧向流免疫分析]]（[[侧流层析|LFA]]）技术联用时，作为高性能[[荧光标记物]]用于细菌检测。基于 SiO₂@PEI-QD 的 LFA 试纸条被成功应用于快速检测牛奶样品中的[[鼠伤寒沙门氏菌]]，检测下限为每毫升 $5 \times 1 0 ^ { 2 }$ 个细胞。

[[鼠伤寒沙门氏菌]]（S. typhi）是世界范围内影响人类和动物的主要[[食源性病原体]]之一；它对公共卫生造成严重危害，导致高死亡率和高经济损失。<sup>1,2</sup> 目前检测 S. typhi 的成熟方法主要包括[[平板培养法|传统平板培养法]]、[[聚合酶链反应]]、[[脱氧核糖核酸测序|DNA 测序]]和[[酶联免疫吸附测定]]技术。<sup>2–5</sup> 然而，这些方法在细菌快速检测方面存在若干固有缺陷，例如需要繁琐的操作程序和较长的检测时间、多步骤的样品前处理、昂贵的设备以及熟练的操作人员。<sup>6</sup> 因此，必须开发一种灵敏且便捷的致病菌快速检测技术。

[[侧向流免疫分析]]（[[侧流层析|LFA]]）技术因其操作简单、分析快速、成本低以及适用于不同检测物质的灵活性等显著优势，已成为最高效的[[即时检验]]工具之一。<sup>7–9</sup> [[量子点]]（QDs）作为新型[[荧光标记物]]被用于 LFA 中，以提高检测灵敏度和定量能力，这得益于其优异的光学性能，包括[[光稳定性]]、强发光和窄[[荧光发射光谱]]峰。<sup>10–12</sup> 然而，量子点在生物分析过程中也面临若干关键问题，例如易于聚集、在复杂溶液中不稳定以及缺乏[[生物相容性]]。<sup>13</sup> 这些问题可以通过将量子点与其他载体材料（如乳胶珠、<sup>14</sup> $\mathrm { S i O } _ { 2 } , ^ { 1 5 }$ 聚合物[[微球]]<sup>16</sup> 和 $\mathrm { F e } _ { 3 } \mathrm { O _ { 4 } , } ^ { 1 7 }$）结合到单个微球或纳米球中加以克服。然而，已报道的大多数量子点复合材料的尺寸通常大于 300 nm，且其合成方法复杂，这极大地限制了它们在用于细菌检测的 LFA 系统中的应用。

在此，我们报道一种简便的[[聚乙烯亚胺]]（PEI）介导[[吸附]]策略，用以制备 PEI 夹层 $_ \mathrm { S i O } _ { 2 } – \mathrm { c o r e }$ [[量子点]]–壳层纳米材料 $\left( \mathrm { S i O } _ { 2 } @ \mathrm { P E I } { \cdot } \mathrm { Q D s } \right)$，其展现出可控尺寸、[[单分散性]]以及优异的<sup></sup>荧光性能。PEI 被用于在 $\mathrm { \ S i O } _ { 2 }$ 纳米粒子表面形成带正电的薄夹层，不仅能够实现 CdSe/ZnS-MPA 量子点作为量子点壳层的致密吸附，而且能够维持纳米结构在溶液中的[[稳定性]]。我们的结果揭示了 [[二氧化硅|SiO]] @PEI-QDs 的性能与稳定性，并证明所提出的[[纳米复合材料]]可作为基于量子点的侧流免疫层析试纸条的先进<sup></sup>[[荧光标记物|荧光纳米标签]]。用于检测[[鼠伤寒沙门氏菌|伤寒沙门菌]]的 [[SiO2@PEI-QDs|SiO @PEI-QD]] 基侧流免疫层析试纸条的灵敏度经测定低至每毫升 $5 \times 1 0 ^ { 2 }$ 个细胞。据我们所知，该工作是<sup></sup>首次将高性能 SiO -量子点纳米复合材料用作基于侧流免疫层析的细菌检测<sup></sup>荧光标记物。

所制备的 [[二氧化硅|SiO₂]]@[[聚乙烯亚胺|PEI]]-[[量子点|QDs]] 由三部分组成：$\mathrm { S i O } _ { 2 }$ 尺寸为 150 nm 的[[纳米颗粒]]作为亲水性支撑核心，以提供良好的[[分散性]]；一层薄薄的 PEI 作为正电性连接层；以及致密的[[羧基]]化 QDs 形成 QDs 壳层，以产生高发光强度和用于[[抗体偶联]]的表面位点。在此，我们选择尺寸为 150 nm 的 $\mathrm { S i O } _ { 2 }$ 纳米颗粒作为核心材料，是因为其尺寸均匀、纳米结构均一、制备简便，并且在复杂溶液中具有高[[稳定性]]。选择 CdSe/ZnS-MPA QDs 形成 QDs 外壳，是因为 MPA 修饰壳层具有优异的<sup></sup>荧光特性和大量表面羧基，便于后续抗体偶联。<sup>18</sup>

高性能 $\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$ 具有典型[[核-壳纳米结构]]的材料分三步制备，如方案1a所示。首先，单分散 $\mathrm { S i O } _ { 2 }$ [[纳米颗粒|NPs]] 依据改良的 [[Stöber方法|Stöber 方法]]合成，作为稳定核心。其次，[[聚乙烯亚胺|PEI]] 包覆的 $\mathrm { S i O } _ { 2 }$ 纳米颗粒（NPs） $\left( \mathrm { S i O } _ { 2 } \textcircled { \mathrm { 2 } } \mathrm { P E I } \right)$ 将 10 mg 的样品分散于 $\mathrm { S i O } _ { 2 }$ NPs 在超声处理下于 PEI 水溶液（0.5%，v/v）中分散 30 分钟，期间[[阳离子聚合物]] PEI 迅速[[自组装]]到带负电的 $\mathrm { S i O } _ { 2 }$ 表面。<sup>19–21</sup> $\mathbf { S i O } _ { 2 } ( \mathbf { \widehat { a } } ) \mathbf { P } \mathbf { E } \mathbf { I }$ 通过离心收集纳米颗粒，然后将其分散在5 mL去离子水中。最后，将1 mL所制备的[[二氧化硅|SiO]]@PEI纳米颗粒加入100 mL[[羧基]]功能化的CdSe/ZnS[[量子点]]溶液（0.1 nM）中，超声处理1 h，通过[[静电相互作用]]形成SiO@PEI-QDs。所得SiO@PEI-QDs通过离心收集，然后储存于10 mL去离子水中备用。

[[透射电子显微镜]]（TEM）分析用于验证合成[[纳米复合材料]]的形貌。如 Fig. $^ { \mathrm { S 1 a , \dagger } }$ 所示，制备的 $\mathrm { S i O } _ { 2 }$ [[纳米颗粒|NPs]] 显示出均匀的 150 nm 尺寸和良好的[[分散性]]。获得的商用 CdSe/ZnS-MPA [[量子点|QDs]] 的 TEM 图像见 Fig. S1b.† CdSe/ZnS-MPA QDs 的平均粒径约为 12 nm。通过超声处理将 $\mathrm { S i O } _ { 2 }$ 用 [[聚乙烯亚胺|PEI]] 包覆后，所得 [[二氧化硅|SiO]] @PEI NPs 仍表现出良好的分散性（Fig. 1a）。所获得其中一颗 NPs 的[[高分辨透射电子显微镜|高分辨 TEM]]（HRTEM）图像清楚表明，PEI 层厚度约为 8 nm（Fig. 1c）。Fig. 1b 和 d 显示了所制备 $\mathbf { S i O } _ { 2 } ( \mathbf { \widehat { a } P E I - }$ QDs 的低倍和高倍 TEM 图像。致密的 CdSe/ZnS QDs 被均匀修饰在 SiO @PEI NPs 表面。此外，形成 QD 壳层后，纳米复合材料的平均直径从 150 nm 增加到 182 nm。[[能量色散X射线光谱|能量色散光谱]]（EDS）面扫技术用于确认 QD 包覆的 $\mathrm { S i O } _ { 2 }$ 纳米复合材料的元素组成。如图 1e 所示，在 Si 核（蓝色）周围发现了高密度的 Cd（绿色）、Se（紫色）、Zn（红色）和 S（黄色）。这一发现表明了 $\mathrm { S i O } _ { 2 } ( \widehat { \mathbf { a } } ) \mathbf { P } \mathbf { E } \mathbf { I } -$ QD 的典型核壳纳米结构。所有 TEM 和 EDS 结果均证实了 $\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$ 的成功制备。值得注意的是，支化 PEI 在水溶液中有效附着于 $\mathrm { S i O } _ { 2 }$ NPs 表面，并易于实现 $\mathrm { S i O } _ { 2 }$ NPs 的完全表面[[氨基修饰]]，这是实现 CdSe/ZnS-MPA QD 作为均匀 QD 壳层致密[[吸附]]的关键。尽管其他[[阳离子聚合物]]（如[[聚二烯丙基二甲基氯化铵|聚（二烯丙基二甲基氯化铵）]]）也可在 $\mathrm { S i O } _ { 2 }$ NPs 表面[[自组装]]以吸附 QD，但在这些情况下，反应溶液的 pH 值需要被精确控制。<sup>15</sup>

在制备免疫 [[二氧化硅|SiO]] @[[聚乙烯亚胺|PEI]]-[[量子点|QDs]] 之后，对 [[侧向流免疫分析|LFA]] 检测系统的重要条件进行了优化。首先评估了 [[侧流层析|LFA]] 试纸条的运行缓冲液，因为它直接影响 ${ \bf S i O } _ { 2 } @ { \bf P } { \bf E I - Q D }$ 纳米标签的流速以及检测线的免疫结合效率。<sup>22,23</sup> 如图 S4a 和 $^ { \mathbf { b } , \dagger }$ 所示，[[磷酸盐吐温缓冲液|PBST 缓冲液]]（10 mM，pH 7.4，1% [[吐温20|Tween 20]]）确保了 $\mathrm { S i O } _ { 2 } \textcircled { \mathrm { 2 } } \mathrm { P E I - Q D }$ -细菌复合物沿试纸条的平稳输送，并在检测线上获得了最高的[[信噪比]]（SNR）。随后我们优化了检测区包被抗体的浓度。当[[鼠伤寒沙门氏菌|伤寒沙门菌]]抗体浓度为 0.6 mg mL<sup>−1</sup> 时，获得了最高 SNR（图 S4c†）。LFA 系统的选择性和特异性在很大程度上取决于应用于 $\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$ 的特异性检测抗体。因此对伤寒沙门菌[[单克隆抗体]]的性能进行了测试。使用每毫升 ${ 1 0 } ^ { 5 }$ 个细胞的伤寒沙门菌以及五种其他常见致病菌（包括[[大肠杆菌]]（E. coli）、[[单核细胞增生李斯特菌]]（L. mono）、[[鲍曼不动杆菌]]（A. baumannii）、[[铜绿假单胞菌]]（P. aeruginosa）和[[金黄色葡萄球菌]]（S. aureus））来测试所提出方法的特异性。如图 3c 插图所示，只有伤寒沙门菌在检测线上表现出明显的荧光信号，而所有非目标细菌组在同一区域均未显示荧光信号。此外，所有试纸条上都出现了明亮的荧光质控线，表明 LFA 试纸条工作正常。记录了检测线相应的[[荧光强度]]。结果表明，基于 [[SiO2@PEI-QDs|SiO @PEI-QD]] 的试纸条对伤寒沙门菌的检测具有良好的选择性（图 3c）。此外，通过在未经处理的牛奶和自来水样品中检测伤寒沙门菌，评估了基于 SiO @PEI-QD 的试纸条的[[稳定性]]和抗干扰能力。如图 S5† 所示，牛奶组、自来水组以及 [[PBS缓冲液|PBS]] 组均产生了强荧光信号，表明所提出的试纸条能够在真实食品样品中良好工作。

我们在优化条件下评估了该方法在牛奶样品中的检测灵敏度。图4a(i)和(ii)展示了基于$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D - }$的试纸条用于检测掺有不同浓度[[伤寒沙门氏菌]]（从$\left( 1 0 ^ { 7 } \right.$个细胞/mL到0个细胞/mL）的牛奶样品的照片和荧光图像。在365 nm波长紫外激发下，检测线的红色荧光带随牛奶样品中伤寒[[沙门氏菌]]浓度的降低而变暗。空白组未观察到明显荧光信号。基于[[SiO2@PEI-QDs|SiO @PEI-QD]]的试纸条对伤寒沙门氏菌的荧光信号可视化限为${ { 1 0 } ^ { 3 } }$个细胞/mL。使用[[荧光试纸条读数仪]]记录相应的检测线[[荧光强度]]。通过将检测线对应的荧光强度对伤寒沙门氏菌浓度作图，得到[[校准曲线]]（图4b）。在$\mathbf { 1 } \times 1 0 ^ { 4 } \tan 5 \times 1 0 ^ { 2 }$个细胞/mL范围内，伤寒沙门氏菌呈现线性关系（图4b插图）。基于[[二氧化硅|SiO]] @[[聚乙烯亚胺|PEI]]-[[量子点|QD]]的试纸条的[[检出限]]（[[检测限|LOD]]）估计为$5 \times 1 0 ^ { 2 }$个细胞/mL，其中LOD定义为相对于空白信号的3 : 1阈值比。<sup>24–26</sup>这些结果表明，以SiO @PEI-QDs作为荧光标记的所提出的[[侧向流免疫分析|LFA]]试纸条在伤寒沙门氏菌检测中表现出高灵敏度和宽动态范围。作为对照，测试牛奶样品中的伤寒沙门氏菌浓度也通过传统[[平板培养法|平板计数法]]进行了确认。如图S6†所示，平板上生长的细菌菌落数与[[侧流层析|LFA]]试纸条检测结果一致，表明基于$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s } .$的试纸条具有良好的准确性。此外，所提出的基于SiO @PEI-QD的试纸条能够实现伤寒沙门氏菌的快速检测，具体可在15分钟内完成，而平板计数法通常需要$8 { - } 2 4 \ \mathrm { ~ h . ~ } ^ { 2 7 , 2 8 }$。还通过检测含不同浓度伤寒沙门氏菌的牛奶样品，考察了基于SiO @PEI-QD的LFA试纸条的重现性。对浓度为$\boldsymbol { 1 0 } ^ { 5 }$和${ { 1 0 } ^ { 3 } }$个细胞/mL的伤寒沙门氏菌样品进行了五次独立测试。如图S7†所示，所提出的方法表现出较高的重复性和可靠性。

为直接比较所提出的$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$试纸条与普通[[荧光LFA]]试纸条的检测能力，我们使用相同的[[伤寒沙门氏菌]]检测抗体制备了基于[[量子点|QD]][[纳米复合材料]]的[[侧向流免疫分析|LFA]]试纸条，但将[[二氧化硅|SiO]]@[[聚乙烯亚胺|PEI]]-QDs替换为商用QD纳米复合材料。如Fig. S8a†所示，所获得的商用QD纳米复合材料的[[透射电子显微镜|TEM]]图像显示，每个颗粒同样含有数十个QD，但其[[分散性]]和均匀性水平不及$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s } .$。如Fig. S8b†所示，该基于QD纳米复合材料的试纸条对伤寒[[沙门氏菌]]的红色荧光检测线在浓度为每毫升1$\times \ { 1 0 } ^ { 4 }$个细胞时即可被肉眼观察到。相应[[校准曲线]]如Fig. S8c†所示。相比之下，$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$试纸条对伤寒沙门氏菌检测的[[检出限|LOD]]比商用QD纳米复合材料基[[侧流层析|LFA]]试纸条低20倍。该检测方法在细菌检测方面的优异性能可归因于LFA系统中使用的先进$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$。这些纳米复合材料表现出大量QD壳层、[[单分散性]]、良好的[[稳定性]]以及高度可重复的结构。与其他近期报道的用于细菌检测的LFA方法相比，所提出的$\mathrm { S i O } _ { 2 } @ \mathrm { P E I - Q D s }$试纸条表现出更好的灵敏度（Table 1）。此外，基于SiO@PEI-QD的LFA试纸条可通过使用特异性[[单克隆抗体]]，轻松应用于其他[[病原微生物]]的快速检测。
