摘要：[[被动辐射冷却]]通过[[大气窗口|地球大气透明窗口]]直接向外辐射热量，正成为一种降低能源消耗的可持续策略。本文展示了[[透明木材生物复合材料|透明木材基生物复合材料]]涂层，作为在阳光直射下实现被动[[辐射冷却]]的环保解决方案。我们采用经 [[氧化锌纳米颗粒|ZnO 纳米颗粒]]功能化的[[木材骨架]]，随后通过[[硫醇-烯原位聚合|硫醇−烯原位聚合]]提高透明度和[[韧性|机械韧性]]，制备了微米级厚度的[[自支撑涂层]]。这些涂层兼具高[[可见光透明度]]和极高的[[中红外发射率]]（∼0.95）。将 [[纳米颗粒功能化|ZnO 功能化]]涂层施加于暴露在阳光直射下的[[硅基底]]表面时，可有效降低基底温度，降幅为 ${ \sim } 6 { - } 7 \ ^ { \circ } \mathrm { C } .$ 这主要归因于[[热辐射]]的增强，

凸显了其缓解[[太阳能电池]]及其他受阳光照射结构过热问题的潜力。此外，这些[[生物复合材料]]增强的[[力学性能]]使其能够广泛用于结构和光学应用，有望成为传统冷却技术的一种具有成本效益的生物基替代方案。

关键词：[[被动辐射冷却]]，[[热辐射]]，[[硫醇-烯反应|硫醇−烯]]，[[透明木材]]，[[大气窗口]]，[[纤维素]]，[[氧化锌]]

随着全球气温上升和城市热量增加，正在迅速增长。<sup>1,2</sup> 空调等传统冷却方法高度依赖能源密集型系统，并产生大量温室气体排放。这推动了能够降低能源消耗、促进环境可持续发展的[[被动冷却]]技术的开发。<sup>3−5</sup> [[辐射冷却]]通过使表面经由[[大气窗口|大气透明窗口]]（8−13 μm）发射热能来实现散热，因此需要进行[[太阳辐射管理]]和[[选择性热发射]]（图 S1）：在[[太阳光谱]]范围（0.28−2.5 μm）内，表面应当具有透明性（T≈1）或反射性（R→ 1），以避免太阳辐射加热。在大气透明窗口（8−13 μm）内，表面应具有强发射能力（ε≈1），而在其他波段则应保持非发射性（ε≪1）；根据 [[基尔霍夫热辐射定律|Kirchhof 定律]]，[[吸收率]]等于[[发射率]]。传统上，[[低于环境温度的辐射冷却]]——即表面温度降至[[环境温度]]以下——是通过具有高[[太阳光反射率]]和强红外发射能力的材料实现的。<sup>9−11</sup> 然而，在[[硅基吸收体]]等需要在温度低于某一限值的条件下维持太阳光[[光吸收|吸收]]的应用中，目标从实现低于环境温度的冷却转变为在保持光学性能的同时尽可能减少过热。<sup>12−14</sup> 传统[[二氧化硅基玻璃盖板]]由于其[[红外发射率]]欠佳，本身所能提供的辐射冷却能力有限。为克服这一局限，研究人员开发了[[二氧化硅光子晶体|二氧化硅基光子晶体]]<sup>15,16</sup>和[[微结构二氧化硅层]]<sup>17</sup>等先进方案。[[二氧化硅]][[光子晶体]]能够显著增强[[中红外]]热发射，与硅[[太阳能吸收体]]集成时，可使温度降低多达 $1 3 ~ ^ { \circ } \mathrm { C }$。<sup>17</sup> 同样，[[图案化二氧化硅微结构]]实现了约 $3 - 5 \mathrm { ~ ~ } ^ { \circ } \mathrm { C }$ 的温度降低。尽管改善了散热，但其制造工艺复杂、[[耐久性]]问题以及潜在的高成本等挑战依然存在，阻碍了其实用性和规模化应用。

在有机[[被动冷却材料]]中，[[纤维素]]因其固有的[[发射率|热发射率]]、丰富的储量和[[生物降解性]]而脱颖而出，成为环境友好型冷却技术中颇具吸引力的候选材料。<sup>19,20</sup> [[脱木质素木材]]和[[纤维素薄膜]]（包括反射型和透明型）通过[[光散射|散射]]太阳辐射并在[[中红外|中红外波段]]强烈发射，已成功实现冷却，降温幅度达到 $5 { - } 9 ~ ^ { \circ } \mathrm { C }$ 21−23 尽管这些材料前景可期，但机械脆弱性、规模化制备难度和[[湿度敏感性]]阻碍了其在长期冷却中的应用，限制了它们作为涂层等形式用于长期户外环境的实用性，而此类应用可涉及多种建筑及能源相关表面。为克服这些挑战，[[透明木材]]（TW）已成为一种前景可期的替代材料。<sup>24,25</sup> 将[[折射率匹配]]的[[聚合物浸渍]]到经化学处理的[[木材骨架]]中，可保留其天然[[层级结构]]，从而获得高[[机械强度]]、可调控的光学性能以及更高的[[环境稳定性]]。<sup>26,27</sup> 除光学性能外，TW 相较于玻璃还具有显著优势，其[[热导率]]低得多（0.19 W $\mathbf { m } ^ { - 1 } \mathbf { \check { K } } ^ { - 1 } )$，且[[韧性|机械韧性]]比玻璃高出 3 个数量级 $( 3 . 0 3 ~ \mathrm { \ M J . m ^ { - 3 } } ) ,$ 28。这些性能使其在[[透明辐射冷却]]和[[可持续建筑设计]]等节能应用中极具潜力。近期，Hu 等人报道了一种[[自适应辐射冷却系统]]，该系统采用 TW 作为[[力学性能|机械性能]]稳健的透明基底，并在其上覆盖基于[[钨掺杂二氧化钒]]的 [[法布里-珀罗多层涂层|Fabry−Perot 多层涂层]]。在其设计中，[[辐射冷却]]由涂层随温度变化的发射率控制，而 TW 主要用作被动支撑。<sup>29</sup> 相比之下，我们着重于将 TW 本身用作功能性冷却材料，在保持太阳光透明性的同时增强中红外发射。[[透明木材生物复合材料|TW 生物复合材料]]通常厚数百微米，独特地兼具光学透射性和高机械韧性，非常适合与[[热敏器件]]及太阳光[[光吸收|吸收]]表面集成。<sup>30,31</sup> 当作为薄膜涂层应用于[[硅基底]]上时，它们在阳光直射下使表面温度降低了 ${ \sim } 6 { - } 7 \ { } ^ { \circ } \mathrm { C }$，在保持光学功能的同时有效缓解了过热。此外，通过将 [[氧化锌|ZnO]] 等纳米颗粒引入 TW 进行功能化，可进一步增强其机械稳健性，同时保持实际应用所需的足够光学清晰度和冷却功能。

我们的研究结果表明，[[透明木材|TW]] 涂层可为降低室外环境中太阳辐射[[光吸收|吸收]]表面的温度提供一种实用且可持续的方法。

图 1a 展示了基于 TW 的辐射冷却器的制备过程，重点呈现了一种三步自上而下的制备方法。第一步，将天然桦木置于 60 °C 的柠檬酸钠 $/ \mathrm { H } _ { 2 } \mathrm { O } _ { 2 } { - } \mathrm { N a O H }$ 溶液中漂白 1−2 h，以选择性去除发色团，同时保留木材的多级结构和相当一部分木质素。所得多孔木材模板保持了机械完整性，以供进一步功能化。第二步，通过真空浸渍 ZnO 纳米溶胶，使用 ZnO 纳米颗粒对漂白木材骨架进行功能化。最后一步，将 ZnO 功能化骨架（ZnO@漂白木材）浸渍于硫醇−烯聚合物前驱体中，随后进行原位 UV 聚合。该聚合通过逐步增长机理进行，最大限度地减小固化过程中的收缩应变，并促进牢固的界面黏附（示意图 S1）。图 1b 展示了基于 TW 的辐射冷却器的工作原理。将 ZnO 功能化 TW（ZnO-TW）生物复合材料以薄膜形式覆于硅基底上，通过高效透射太阳辐射并在 8−13 μm 窗口内发射热辐射，实现被动辐射冷却。在图 1c 中，左图展示了漂白木材模板，由于发色团被去除，且其多孔纤维结构内部的折射率失配导致可见光发生强烈散射，因此呈现亮白色。右图展示了 ZnO-TW 生物复合材料，其在原位聚合后通过折射率匹配实现光学透明，同时保留了天然木材的多级结构。图 1d 中的总透射光谱比较了 ZnO-TW 生物复合材料与 1 mm 厚玻璃的光学性能。ZnO-TW 生物复合材料在 550 nm 处的透射率约为 84%，略低于玻璃。ZnO-TW 生物复合材料的这种优异透明性是通过硫醇−烯聚合物基体（n ≈ 1.54）与木材骨架之间的精确折射率匹配实现的，从而最大限度地减少界面散射并确保高效透光。<sup>27</sup>插图照片进一步展示了 ZnO-TW 生物复合材料和玻璃的清晰透明程度。

木材的微观结构决定了 [[透明木材生物复合材料|TW 生物复合材料]]的光学和[[力学性能]]。采用 [[SEM]] 对所有样品的微观结构进行了表征。图 S2a 展示了[[漂白木材]]的径向表面，可见被切开的[[木纤维胞腔]]和[[木纤维]]表面；经 [[纳米颗粒功能化|ZnO 功能化]]后，[[氧化锌纳米颗粒|球形 ZnO 纳米颗粒]]（直径约 20−40 nm，由 ImageJ 软件测量）均匀地修饰于这些表面上（图 S2b）。图 S2a 和 S2b 中的插图展示了放大的木纤维表面。在 [[透明木材|TW]] [[生物复合材料]]中，[[硫醇-烯原位聚合|原位硫醇−烯聚合]]成功保留了木材结构，且木纤维胞腔被[[聚合物基体]]完全填充（图 2）。图 2a 和 2b 展示了[[原始透明木材|原始 TW]]（pristine TW）和 [[氧化锌功能化透明木材|ZnO-TW 生物复合材料]]结构的横截面，插图进一步展示了被聚合物填充的[[木材细胞壁|细胞壁]]和胞腔空间。SEM 图像中可见聚合物与木材细胞壁之间存在一些脱粘，这可能是在使用[[超薄切片机]]对 TW 进行切片时造成的。<sup>32</sup>为验证[[聚合物浸渍|聚合物浸渗]]的均匀性，使用能量色散 X 射线光谱（EDS）对 [[氧化锌|ZnO]]-TW 生物复合材料进行了 S 和 Zn 元素映射分析（图 2c-e），结果表明木纤维胞腔和细胞壁中均存在 S 原子，证实[[聚合物前驱体]]均匀浸渗并在整个木材结构中发生聚合。此外，Zn 元素映射结果表明，ZnO 纳米颗粒均匀分布于木材结构中的细胞壁内部。[[热重分析]]（TGA）从定量上支持了这一结果，显示 ZnO 负载量约为 8%（图 S3）。这一 ZnO 负载量可能增强 ZnO-TW 生物复合材料的力学性能，部分阻挡有害的 [[长波紫外辐射|UVA 辐射]]，并选择性反射[[短波至近红外]]（SWNIR，约 0.74−2.5 μm）波段的辐射。这些方面将在后续章节中详细分析。

$$

其中，$P _ { \mathrm { r a d } }$ 为冷却器单位面积的[[热辐射功率]]，$P _ { \mathrm { a t m } }$ 为冷却器因大气入射辐射而[[光吸收|吸收]]的单位面积功率，$P _ { \mathrm { n o n r a d } }$ 表示因传导和对流而损失或获得的功率，$P _ { \mathrm { s o l a r } }$ 对应于吸收的单位面积太阳入射辐射功率。图 4d 展示了基于支持信息（第 1 节）所述计算方法估算的、不同[[环境温度]]和[[对流换热系数]]下涂覆与裸露硅表面的[[净冷却功率]]。在所有情况下，涂覆样品均表现出更高的冷却功率，这解释了图 4c 中观察到的温度降低。如图 S5 和 S6 所示，这一优势源于涂覆表面的辐射损失显著高于裸露 [[硅|Si]] 表面。由于[[大气窗口]]内的[[发射率|热发射率]]提高，这在很大程度上补偿了添加 [[透明木材|TW]] 后太阳吸收的少量增加 $( { \sim } 9 \ \breve { \mathrm { W } } \ \mathrm { m } ^ { - 2 } )$。我们还通过改变有效[[长波红外]]（LWIR）[[大气透过率]]（晴朗/潮湿/阴天）和[[对流换热]]系数，评估了其对天气条件的敏感性；详见 SI 第 1 节。如图 $\mathrm { S } 7 \mathrm { a } - \mathrm { c }$ 所示，湿度/云量以及更强的对流会缩小冷却裕量，但涂层相较于裸露 Si 仍保持温度优势。

为评估[[耐久性]]，我们通过三点弯曲试验测定了 [[透明木材生物复合材料|TW 生物复合材料]]的[[力学性能]]。所有样品的弯曲应力−应变行为见图 5 和图 S8。[[氧化锌功能化透明木材|ZnO-TW 生物复合材料]]具有最高的[[弯曲强度]] $\left( 1 5 8 \pm 1 8 \mathrm { { \ M P a } } \right)$ 和[[弯曲模量|模量]] $( 1 3 . 6 \ \bar { \pm } \ 1 . 1 $ GPa），展示了 [[纳米颗粒功能化|ZnO 功能化]]的增强作用（图 5a）。[[原始透明木材|原始 TW]] [[生物复合材料]]表现出显著的力学性能，其弯曲强度为 130 ± 31 MPa，模量为 $1 2 . 8 \pm 2 . 2 \mathrm { { \ G P a } , }$，凸显了[[木材骨架]]本身的贡献。[[漂白木材]]和 [[氧化锌功能化漂白木材|ZnO@漂白木材]]样品的弯曲强度分别为 $1 1 6 ~ \pm ~ 3 . 1$ MPa 和 $1 1 7 \ \pm \ 1 2 \ \mathrm { { \ M P a } } ,$，相应的模量分别为 $1 3 . 1 \pm 0 . 4 \mathrm { { G P a } }$ 和 $1 5 . 4 \pm 1 . 5$ GPa（图 S8）。这些数值反映了木材骨架的固有强度，在未浸渍聚合物的情况下，[[氧化锌|ZnO]] 功能化仅带来了有限的增强。相比之下，纯[[硫醇-烯聚合物|硫醇−烯聚合物]]的力学性能最低，其弯曲强度为 $3 7 . 3 \pm 7 . 6$ MPa，模量为 $3 . 2 \pm 0 . 3 \mathrm { { \ G P a } , }$，凸显了[[木材模板]]所提供的关键增强作用（图 S8）。与原始 [[透明木材|TW]] 生物复合材料相比，ZnO-TW 生物复合材料的弯曲强度提高了 21%，模量提高了 6%，[[韧性]]（[[断裂功]]）提高了约 190%，进一步证明了 ZnO 功能化作为增强手段的有效性。与传统[[钠钙玻璃|钠钙玻璃板]]（40−90 MPa）相比，TW 生物复合材料具有更高的强度（130−158 MPa），断裂时的弯曲应变可达约 1.5%，因此具有更高的韧性（断裂功）（图 5b）；原始 TW 和 ZnO-TW 生物复合材料的韧性分别为 0.70 和 ${ \sim } 1 . 3 3 \ \mathrm { ~ M J m } ^ { - 3 }$，高于钠钙玻璃 $( \sim 0 . 0 0 3 \ \mathrm { M J \ m } ^ { - 3 } )$ 28,33

这些结果凸显了[[木材模板]]与 [[纳米颗粒功能化|ZnO 功能化]]在制备具有良好[[力学性能]]的[[生物复合材料]]方面的协同作用，使其适用于透明屋顶、[[太阳能电池板覆盖层]]等同样需要结构完整性（包括强度和[[耐久性]]）的[[被动辐射冷却]]应用。表 S1 还比较了 [[透明木材|TW]] 与其他透明[[冷却系统]]的力学性能。尽管测试条件和样品厚度的差异可能影响直接比较，但高[[可见光透明度]]（约 84%）、高[[发射率|热发射率]]（约 0.95%）以及[[韧性|力学韧性]]、可规模化制备和[[环境稳定性]]的结合，凸显了其在[[热管理|可持续热管理]]应用中的潜力。此外，[[交联硫醇-烯聚合物|交联硫醇−烯聚合物]]以其 [[紫外辐射|UV]] 和[[湿度稳定性]]而著称，<sup>34</sup>而先前关于[[环氧树脂]]浸渍 TW 系统以及木材表面环氧树脂涂层的研究也报道了其长期[[户外耐久性]]。<sup>35,36</sup>

本研究提出了一种[[被动辐射冷却]]策略，采用经 [[纳米颗粒功能化|ZnO 功能化]]并浸渍[[硫醇-烯聚合物|硫醇−烯聚合物]]的 [[透明木材生物复合材料|TW 生物复合材料]]。所得材料兼具高[[可见光透明度|可见光透过率]]（∼84%）、高的[[中红外发射率]]（∼0.95）以及增强的[[机械强度]]。在户外测试中，将 [[透明木材|TW]] 涂层应用于[[硅基底]]后，在阳光直射条件下可使表面温度最多降低 $6 { - } 7 ~ ^ { \circ } \mathrm { C }$。这种冷却效应归因于较低的[[太阳光吸收率]]以及在 8−13 μm [[大气窗口]]内高效的[[热辐射]]。与依赖多层结构设计或[[纳米加工]]的传统冷却策略相比，我们的方法采用天然来源的材料和简单的加工工艺。[[氧化锌功能化透明木材|ZnO-TW 生物复合材料]]表现出优异的[[力学性能]]，其[[弯曲强度]]为 $1 5 8 \pm 1 8 . 1 \mathrm { M P a } , $，[[弯曲模量|模量]]为 $1 3 . 6 \pm 1 . 1 \mathrm { G P a } ,$，[[韧性]]（[[断裂功]]）为 $( \sim 0 . 7 0 \mathrm { ~ \ t o ~ \ } 1 . 3 3 \mathrm { ~ \ M J m } ^ { - 3 } )$，其强度和韧性均超过[[钠钙玻璃]]等传统单体材料。这种强度水平与优异的光学性能和[[户外耐久性]]相结合，使 TW 成为一种具有规模化应用潜力且环境友好的候选材料，可用于屋顶、建筑立面和[[光伏组件]]等阳光照射环境中的[[热管理|被动热管理]]。
