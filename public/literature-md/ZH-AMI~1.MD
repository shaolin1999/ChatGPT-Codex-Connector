## 摘 要

针对水果贮藏期间的微生物侵染问题，我们受[[柑橘油腺天然防御机制]]启发，开发了一种基于[[玉米醇溶蛋白]]-[[阿拉伯胶]]（[[没食子酸|GA]]）纳米颗粒的[[微生物自毁]]纳米平台[[肉桂醛]]（CIN）[[纳米乳液]]（NEs），该平台能够持续、精准地释放肉桂醛，实现水果长期保鲜。玉米醇溶蛋白-2 %阿拉伯胶纳米颗粒（[[ZGNP]]）通过[[氢键]]和[[静电相互作用]]结合，表现出优异的乳化稳定性。所制备的5 %载肉桂醛纳米乳液（5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs）表现出高[[包封率]]（91.64 %）和优异的[[缓释性能]]（贮藏30 d后，在4 ◦C下保持38.52 %，在25 ◦C下保持28.51 %），从而能够实现持续、有效的[[广谱抗菌活性]]。此外，纳米乳液与微生物的共孵育实验验证了肉桂醛的[[精准释放]]和微生物自毁。在微生物快速生长阶段，微生物分泌物对ZGNP的酶促水解引发了肉桂醛的精准智能释放，有效触发了微生物自毁过程（自毁率> 70 %），成功模拟了[[柑橘]]油腺的天然防御机制。柑橘和[[樱桃番茄]]的体内实验进一步验证了纳米乳液的精准抗菌性能。最后，将5 %C-ZGNP NEs制备成涂层用于[[水果保鲜]]，将柑橘和樱桃番茄的[[货架期]]延长了2倍。其保鲜效果总体上优于市售保鲜剂[[咪鲜胺]]。本研究设计的仿生智能纳米平台能够实现[[精油]]的持续、精准释放，有效抑制微生物侵染，从而延长水果货架期。这为开发“智能”响应型水果保鲜涂层材料提供了一种新策略。

## 1. 引言

新鲜水果因其诱人的风味和丰富的营养价值而广受喜爱，消费者需求持续上升[1]。然而，新鲜水果在贮藏和运输过程中特别容易受到微生物侵染（包括真菌和细菌），导致采后损失占水果总产量的25%–40%[2]，造成显著的经济损失。目前，[[水果保鲜]]行业严重依赖化学抗菌剂，如[[咪鲜胺]]、[[苯菌灵]]、[[山梨酸钾]]和[[二氧化硫]]。然而，长期过量使用这些化学品可能导致微生物耐药性的产生和环境污染。此外，其残留毒性还会增加人类患病风险[3,4]。因此，在环境保护和消费者健康需求的推动下，迫切需要开发一种安全、天然来源的防腐剂，以抑制水果贮藏和运输过程中的微生物侵染，从而延长[[货架期]]。

[[精油]]作为被归类为[[一般公认安全]]（GRAS）的化合物，是植物产生的挥发性次级代谢产物[5]。其中，[[肉桂醛]]（CIN）已被证实与[[芹菜脑]]、[[丁香酚]]、[[柠檬醛]]和[[百里香酚]]等其他精油相比，表现出更优异的抗菌活性[6]。已有报道表明，CIN 能够通过破坏细胞膜结构显著抑制微生物生长，从而维持果实品质[7]。因此，CIN 在延长果实[[货架期]]方面展现出可观的应用潜力。然而，其光敏性、挥发性、疏水性以及较低的[[生物相容性]]，阻碍了其持续发挥抗氧化和抗菌活性的能力[8]。为解决上述问题，一些研究尝试使用[[吐温80|吐温 80]] [9]、无机纳米颗粒[10]、多酚[11]、共混策略[12]以及[[静电纺丝]][13]对 CIN 进行封装，这些方法均有效提高了其稳定性和生物相容性。尽管如此，通过这些方法封装的精油通常通过自由扩散和压差等物理因素被动释放。需要注意的是，果实实际贮藏和运输过程中的微环境复杂且动态变化，被动释放无法根据果实微环境的变化调整精油释放量。这种缺乏[[智能响应]]释放的行为会导致活性化合物浪费和抗菌效力下降，无法实现果实的长期保鲜。如今，“智能响应”系统作为智能食品保鲜材料已经取得了实质性进展。这些材料可由温度[14]、湿度[15]和光照[16]等因素触发，并且通常针对不同应用场景设计特定的刺激响应机制，以实现活性化合物的可控释放。例如，Zhou 等（2025）设计了一种基于稀土掺杂纳米材料的光响应纳米杀菌薄膜，该薄膜在光响应过程中增强了[[活性氧]]（ROS）的产生，显著延长了草莓和鸡肉的货架期[17]。此外，Shi 等（2025）利用[[甘草酸]]和[[乳清分离蛋白]]纤维构建了一种温度响应系统，在约 45 °C 条件下表现出显著的温度响应释放特性[14]。这些智能响应系统具有显著优势。然而，仍有若干问题亟待解决：一方面，它们可能无法实现抗菌剂的长期稳定封装，导致其在响应前抗菌性能下降。另一方面，在一些智能响应系统中，抗菌剂的释放往往是非定向且不精确的。具体而言，湿度或温度等环境因素的变化会触发智能响应材料系统中的活性物质释放到果实的大部分部位，包括未感染区域。这导致杀菌精度的降低以及活性物质的浪费[18]。仍然需要开发一种能够同时解决上述两个问题的新方法。

有趣的是，我们从水果受微生物侵染的过程中获得了新方法的灵感。一方面，已有研究表明水果具有丰富的营养价值，为微生物定殖提供了理想环境[19,20]。微生物与水果接触后，会逐渐分泌[[蛋白酶]]和[[多糖酶]]，以利用充足的碳源和氮源进行繁殖[21]。例如，[[柑橘]]和[[樱桃番茄]]分别作为非跃变型和[[跃变型水果]]的代表，主要受到[[意大利青霉]]（P. italicum）、[[指状青霉]]（P. digitatum）、[[灰葡萄孢]]（[[灰葡萄孢菌|B. cinerea]]）以及多种细菌的采后侵染[22,23]。微生物通常会分泌蛋白酶、[[果胶酶]]和[[β-半乳糖苷酶]]等酶类来获取营养，从而促进其侵染过程[24–26]。另一方面，水果的油腺是储存[[精油]]的重要部位[27]。研究表明，微生物可以通过分泌蛋白酶和多糖酶降解柑橘油腺细胞壁中的[[蛋白质]]和多糖，从而触发水果的防御机制。这一过程使储存在油腺中的精油能够[[精准释放]]到水果受感染部位[28]，进而导致微生物的自我毁灭。在我们先前的研究中，我们成功将[[香芹酚]]封装在一个模拟柑橘油腺的体系中，通过仿生策略实现了长期有效的抗氧化和抗菌效果[29]。这表明通过仿生策略构建的类油腺体系在长期稳定封装精油方面具有优异潜力。然而，该体系尚未表现出与[[柑橘油腺天然防御机制|油腺天然防御机制]]中所观察到的相同精准释放行为。总体而言，尽管以往的智能释放体系和仿生体系已取得一定进展，但仍缺乏从油腺天然防御机制角度调控精油精准释放的创新策略。

因此，受微生物分泌的[[蛋白酶]]和[[多糖酶]]触发[[柑橘]]油腺[[精准释放]][[精油]]以抑制微生物生长这一天然防御机制的启发，我们考虑了是否可以用[[蛋白质]]-多糖复合物来封装强效抗菌剂[[肉桂醛]]（CIN）。该复合物既可作为有效的稳定剂，同时也能通过充当微生物侵染所需的碳源和氮源，与果实表面的营养物质形成竞争。当微生物利用蛋白质-多糖复合物时，CIN会被精准释放，从而抑制利用该复合物的微生物，巧妙地实现微生物“自毁”效应。目前，天然植物蛋白（[[大豆分离蛋白]][30]、[[豌豆蛋白]][31]和[[玉米醇溶蛋白]][32]）已在食品工业中得到有效应用。其中，玉米醇溶蛋白具有优异的界面[[吸附]]性能和乳化能力，并可被蛋白酶水解[33]。[[阿拉伯胶]]（[[没食子酸|GA]]）是一种两亲性多糖，可被[[β-半乳糖苷酶]]和蛋白酶酶解[34]，并且被广泛用于提高[[大米蛋白]]、[[乳清分离蛋白]][35]和豌豆蛋白[36]等蛋白质的乳化稳定性。基于上述内容，我们尝试开发一种由[[玉米醇溶蛋白-阿拉伯胶纳米颗粒]]稳定的CIN[[纳米乳液]]（NEs）体系，作为模拟柑橘油腺响应性精准释放精油的[[微生物自毁智能纳米平台]]。我们假设，作为[[微生物自毁]]智能纳米平台的CIN NEs，在微生物入侵期间，微生物分泌的蛋白酶和多糖酶会触发玉米醇溶蛋白-阿拉伯胶纳米颗粒解体，从而在果实感染部位智能、精准地释放CIN以抑制微生物生长。这一整个过程类似于柑橘的天然防御机制，即微生物入侵触发柑橘油腺精准释放精油，从而抑制微生物生长。

在本研究中，我们表征了[[玉米醇溶蛋白-阿拉伯胶纳米颗粒]]的理化性质和稳定性，并通过[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）和[[分子动力学]]（[[分子动力学模拟|MD]]）模拟，在分子水平上探究了[[玉米醇溶蛋白]]-[[阿拉伯胶]]纳米颗粒作为有效[[肉桂醛|CIN]]稳定剂的形成机制。此外，还考察了所制备CIN [[纳米乳液|NEs]]的理化性质、稳定性、抗菌和抗氧化活性以及缓释特性。随后，通过模拟酶消化玉米醇溶蛋白-阿拉伯胶纳米颗粒和CIN NEs后的结构形貌变化，以及CIN NEs与微生物培养物共孵育后的微生物生长特性，评估了CIN NEs体系作为[[微生物自毁智能纳米平台]]的性能。接着，在[[柑橘]]（非跃变型）和[[樱桃番茄]]（跃变型）中验证了其体内抗菌效果。最后，评价了5% NEs-P涂层对柑橘和樱桃番茄的保鲜效果。本研究将为用于[[水果保鲜]]的“[[智能响应]]型”绿色涂层材料提供潜在的新见解和新方法。

## 2. 材料与方法

## 2.1. 材料与试剂

[[玉米醇溶蛋白]]（BR，92%）和[[阿拉伯胶]]购自[[上海源叶生物科技有限公司]]（中国上海）；[[肉桂醛]]（AR，98%）和[[正己烷]]（>99%）由[[麦克林生化科技有限公司]]（中国上海）提供；成熟度相近、大小均匀、色泽良好且无机械损伤的[[柑橘]]和[[樱桃番茄]]购自本地超市（中国长沙）。其他材料清单见补充数据第1.1节。

## 2.2. [[玉米醇溶蛋白|zein]]-[[没食子酸|GA]]的制备

采用[[反溶剂沉淀法]]制备[[玉米醇溶蛋白]]纳米颗粒[37]。将玉米醇溶蛋白溶解于85%（v/v）[[乙醇]]水溶液中；随后，将玉米醇溶蛋白乙醇溶液逐渐滴加至去离子水中。然后使用旋转蒸发仪在$4 5 ^ { \circ } \mathrm { C }$条件下浓缩混合液以除去乙醇。将玉米醇溶蛋白纳米颗粒（1%，w/v）逐渐加入到浓度分别为0.1%、0.2%、0.5%、1%、2%、3%、5%和10%（w/v）的[[阿拉伯胶]]溶液中，得到不同质量比的[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|zein-GA纳米颗粒]]。所得纳米颗粒分别命名为0.1%[[没食子酸|GA]] + Zein、0.2%GA + Zein、0.5%GA + Zein、1%$\mathrm { G A } + \mathrm { Z e i n } , 2 \% \mathrm { G A } + \mathrm { Z e i n } , 3 \% \mathrm { G A } + \mathrm { Z e i n } , 5 \% \mathrm { G A } + \mathrm { Z e i n } ,$和10%GA + Zein。详细步骤见补充数据第1.2节。

## 2.3. [[玉米醇溶蛋白|zein]]-[[没食子酸|GA]]的表征

## 2.3.1. [[玉米醇溶蛋白|zein]]-[[没食子酸|GA]]的理化性质表征

使用[[Malvern Pro仪器]]（英国马尔文）测定[[玉米醇溶蛋白]]、[[阿拉伯胶]]和[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|zein-GA纳米颗粒]]的平均粒径、[[多分散指数]]（[[PDI]]）和[[zeta电位]]。[[自组装速率]]和离心稳定性参考已有方法并稍作修改进行评估[38]，见补充数据第1.3节。将样品固定在金属支架上并喷金1 min，使用[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）（德国耶拿Carl Zeiss）在5 kV加速电压下以不同放大倍数观察玉米醇溶蛋白、阿拉伯胶和zein-[[没食子酸|GA]]纳米颗粒的微观形貌。[[三相接触角]]$( \theta _ { \mathrm { o / w } } )$依据已建立的方法并稍作修改进行测定[39]。将冷冻干燥样品压制成约1 mm厚的薄片，并浸入大豆油中。随后，将2 μL去离子水注入薄片表面。平衡后，使用[[接触角]]测量仪（Kino SL250，[[KRUSS DSA100]]，德国）记录并分析液滴形貌。界面[[吸附]]性能基于[[界面张力]]和[[界面压力]]进行评估[40]，详见补充数据第1.4节。

采用[[差示扫描量热仪]]（[[差示扫描量热法|DSC]]）（[[NETZSCH DSC 3500]]）对[[玉米醇溶蛋白]]、[[没食子酸|GA]] 和玉米醇溶蛋白-[[阿拉伯胶|GA]]（2 %，w/v）纳米颗粒（[[ZGNP]]）的热力学性质进行了分析，方法参照先前研究 [41]。样品在 50 mL/min 氮气流下，以 ${ 1 0 ~ ^ { \circ } } \mathrm { C } /$ min 的速率从 40 ℃ 加热至 200 ℃。使用[[傅里叶变换红外光谱仪]]（[[傅里叶变换红外光谱|FT-IR]]）（[[Nicolet Is10]], Nicolet, USA）分析玉米醇溶蛋白、GA 和 [[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] 的结构和化学键。测试参数如下：样品与 KBr 混合，以空气为背景，在 4000 至 400 $\mathrm { c m } ^ { - 1 }$ 范围内扫描 64 次，分辨率为 $4 \mathrm { c m } ^ { - 1 }$ 。使用 [[X射线衍射仪|X 射线衍射仪]]（[[XRD]]）（[[Bruker D8 Advance]], Germany）检测晶体结构，扫描范围为 $5 ^ { \circ }$ 至 50°。通过[[荧光分光光度计]]（F-4700, Hitachi, Japan）观察玉米醇溶蛋白、$\mathrm { G A } ,$ 和 ZGNP 的[[内源荧光光谱]]。样品在 280 nm 处激发，发射光谱记录范围为 300–450 nm。

## 2.3.2. [[玉米醇溶蛋白]]-[[没食子酸|GA]] 的 [[DFT]] 和 [[分子动力学|MD]] 模拟

为研究[[玉米醇溶蛋白]]与 [[没食子酸|GA]] 之间的相互作用和稳定性，使用 [[Materials Studio]] 中的 [[DMol3]] 模块进行了 [[DFT]] 模拟。计算采用基于[[广义梯度近似]]（GGA）的 [[Perdew-Burke-Ernzerhof|Perdew-Burke-Ernzerh of（PBE）泛函]]。选择经极化函数增强的双数值原子轨道（DNP）作为基组。在几何优化过程中，能量、最大力和位移的收敛标准设置为 $\mathrm { t o } \ { \widetilde { \mathrm { t i n e } } } ^ { \prime \prime }$ 精度，数值分别为 1 × $1 0 ^ { - 5 } \mathrm { { H a } } , 2 \times 1 0 ^ { - 3 } \mathrm { { H a A ^ { - 1 } } }$ 和 $5 \times 1 0 ^ { - 3 } \mathrm { A } ,$ 。计算了[[分子静电势]]（MEP）、[[最高占据分子轨道]]（HOMO）和[[最低未占据分子轨道]]（[[最低未占分子轨道|LUMO]]），以确定[[能隙]]（Eg）[42]。

使用 [[Gromacs]] 2022.3 版本进行 [[分子动力学|MD]] 模拟。模拟在静态温度条件（300 K）和恒定压力（1 Bar）下进行，采用 [[Amber 99sb-ildn力场|Amber 99sb-ildn 力场]]。以水分子（Tip3p 水模型）作为溶剂，通过添加适量 Na<sup>+</sup> 中和体系净电荷 [43]。其他具体参数见补充数据第 1.5 节。

## 2.4. 基于 [[ZGNP]] 的 [[肉桂醛|CIN]] [[纳米乳液|NEs]] 的制备与表征

## 2.4.1. [[肉桂醛|CIN]] [[纳米乳液|NEs]] 的制备

将不同量的 [[肉桂醛|CIN]]（0.1 g、0.3 g、0.5 g、0.7 g、0.9 g）分别加入制备好的 [[ZGNP]] 分散液（10 mL）中，随后均质 2 min，再进行超声处理（300 W，10 min，冰浴）。所得 [[纳米乳液|NEs]] 分别命名为 1 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]]、3 %C-ZGNP、5 %C-ZGNP、7 %C-ZGNP 和 9 %C-ZGNP，然后于 $4 ^ { \circ } \mathrm { C }$ 储存以供进一步分析。

## 2.4.2. [[肉桂醛|CIN]] [[纳米乳液|NEs]] 的基本表征

使用 [[透射电子显微镜|TEM]]（[[JEM-1200EX]]）和 [[CLSM]]（LSM800 Carl Zeiss AG）观察 [[纳米乳液|NEs]] 的形貌。使用 [[Malvern Pro仪器|Malvern Pro 仪器]]测定 NEs 的平均粒径、[[PDI]] 和 [[Zeta 电位|zeta 电位]]。使用 [[LF-NMR]]（Bruker AVANCE III 400 M, Germany）研究 NEs 的水分子稳定性。详见补充数据第 1.6 节。

此外，还对[[纳米乳液]]的[[存储稳定性|储存稳定性]]、pH 稳定性及离子强度稳定性进行了表征。将纳米乳液于 4 °C 下储存 30 d，并使用 1 M HCl 或 NaOH 将 pH 调节至 3、5、7、9 和 11。向纳米乳液中加入不同浓度的氯化钠（0、50、100、150 和 200 mM）。基于平均粒径、[[PDI]] 和 [[Zeta 电位|zeta 电位]]的变化，评价纳米乳液的储存、pH 及离子强度稳定性。在线性黏弹性区域内对纳米乳液进行频率扫描，以观察[[剪切黏度|黏度]]变化。利用 [[傅里叶变换红外光谱|FT-IR]] 光谱分析不同比例的 [[肉桂醛|CIN]] 与 [[ZGNP]] 之间的相互作用。

## 2.4.3. [[肉桂醛|CIN]] [[纳米乳液]]的抗氧化和抗菌性能

参照 Xie 等的方法并稍作修改，通过 [[DPPH]] 和 [[ABTS]] 自由基清除能力评价[[纳米乳液]]的抗氧化能力 [29]。将纳米乳液（200 μL）（1 %C-[[ZGNP]]、3 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]]、5 %C-ZGNP、7 %C-ZGNP、9 %C-ZGNP）溶于去离子水（2 mL）中，然后与 3 mL DPPH 甲醇溶液或 5 mL ABTS 工作液混合。将混合物在 $3 7 ^ { \circ } \mathrm { C }$ 下避光孵育 20 min。孵育结束后，DPPH 在 517 nm 处、ABTS 在 734 nm 处测定[[吸光度]]。（ABTS 工作液配制：将 7 mM ABTS 与 2.45 mM 过硫酸钾溶液按 1:1（v/v）比例混合，避光孵育 12 ${ \bf h } ,$，然后用[[乙醇]]稀释至 734 nm 处吸光度为 $0 . 7 0 \pm 0 . 0 2$）。自由基清除率按下式计算：

$$
D P P H / A B T S \text { scavenging effect } (\%) = \frac {A _ {0} - A _ {1}}{A _ {0}} \times 1 0 0\tag{1}
$$

其中 $A _ { 0 }$ 和 $A _ { 1 }$ 分别表示空白对照和样品的[[吸光度]]。

通过测定[[抑菌圈]]、[[SEM]] 成像和 [[PI染色|PI 染色]]评价[[纳米乳液]]的抗真菌和抗菌活性。此外，抗真菌活性评价还包括 [[活性氧|ROS]] 积累和胞内内容物泄漏。详细步骤见补充数据第 1.7 节。

## 2.4.4. [[肉桂醛|CIN]] [[纳米乳液]]的缓释特性

使用[[紫外-可见分光光度计]]测定溶于[[正己烷]]的 [[肉桂醛|CIN]] 在 290 nm 处的[[吸光度]]，构建标准曲线。将[[纳米乳液]]（100 μL）溶于正己烷（900 μL）中，以 8000 rpm 离心 5 min。在 290 nm 处测定上清液吸光度，并根据标准曲线计算[[包封率]]（EE）。

$$
E E (\%) = \frac {M _ {a} - M _ {t}}{M _ {a}} \times 1 0 0\tag{2}
$$

其中 $M _ { \mathrm { a } } =$ 为 [[肉桂醛|CIN]] 总含量；$M _ { \mathrm { t } } =$ 为未包封 CIN 质量。

参照前人研究的方法并作适当修改，测定[[纳米乳液]]的[[保留率]]和累积释放率 [44]。使用 [[ZGNP]] 制备含 5 %（w/v）[[肉桂醛|CIN]] 的纳米乳液，以 [[吐温80|Tween 80]] 为对照组。将纳米乳液分别在 $4 ^ { \circ } \mathrm { C }$ 和 ${ 2 5 ^ { \circ } \mathrm { C } }$ 下储存 30 ${ \sf d } ,$，储存期间每 3 d 测定一次纳米乳液在 290 nm 处的[[吸光度]]。纳米乳液的预处理方法同上。保留率按公式计算，随后基于保留率确定累积释放率。

$$
\text {Retention rate} (\%) = \frac {C _ {0} - C _ {t}}{C _ {0}} \times 1 0 0\tag{3}
$$

其中 $C _ { 0 }$ 和 $C _ { \mathrm { t } }$ 分别表示 0 d 和 ${ \textsf { t d } } ,$ 时的 [[肉桂醛|CIN]] 含量。

$$
\text { Cumulative   release   rate } (\%) = \frac {R _ {0} - R _ {t}}{R _ {0}} \times 1 0 0\tag{4}
$$

将[[纳米乳液]]中 [[肉桂醛|CIN]] 在 0 d 的[[保留率]]记为 $R _ { 0 } ,$，在 t d 的保留率记为 $R _ { \mathrm { t } }$。

此外，通过测量[[抑菌圈]]评估了[[纳米乳液]]在储存30 d前后的抗菌活性。方法同补充数据第1.7节所述。

## 3.1.2. [[玉米醇溶蛋白]]-[[没食子酸|GA]]的[[DFT]]与[[分子动力学模拟|MD模拟]]分析

为了更好地理解[[ZGNP]]对[[肉桂醛|CIN]]的稳定封装潜力，我们采用[[DFT]]和[[分子动力学模拟|MD模拟]]在分子水平上分析[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]]的结构与稳定性。[[密度泛函理论|DFT]]通过模拟电子行为来分析分子结构和稳定性。对[[玉米醇溶蛋白|zein]]、$\mathrm { G A } ,$和ZGNP进行了DFT模拟，如图2G所示。[[分子静电势|MEP]]图显示，红色对应富电子区域和亲核中心，而蓝色代表缺电子区域和亲电中心。ZGNP表现出正电性和负电性区域均有所增加。与[[氢键]]合的氧原子位于红色（负电性）区域，而与氧相连的氢原子位于蓝色（正电性）区域，表明zein与[[没食子酸|GA]]之间形成了氢键。此外，[[最高占据分子轨道|HOMO]]与[[最低未占分子轨道|LUMO]]之间较大的[[能隙|Eg]]表明分子刚性更强、更稳定且反应性更低[54]。ZGNP（0.144 eV）的HOMO-[[最低未占据分子轨道|LUMO]] Eg高于zein（0.138 eV）和[[阿拉伯胶|GA]]（0.099 eV），表明其具有更高的稳定性。

采用[[分子动力学模拟|MD模拟]]进一步分析[[玉米醇溶蛋白|zein]]与[[没食子酸|GA]]相互作用中的稳定性和构象变化。如图3A–B所示，[[阿拉伯胶|GA]]的[[均方根偏差|RMSD]]在0–100 ns期间保持稳定，而zein和[[ZGNP]]在最初的0–10 ns内均表现出显著波动，且[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]]的波动幅度大于zein。这可能是由于GA与zein成功结合导致ZGNP发生结构变化所致[55]。此外，所有氨基酸残基的[[均方根涨落|RMSF]]值均保持在2 nm以下，进一步证明zein与GA之间形成了稳定复合物（图3C）。[[回转半径|Rg]]用于评估[[蛋白质]]-配体复合物的紧密度，ZGNP的整体Rg值（图3D）以及沿X、Y和Z轴的Rg值（图3E）在10 ns后均稳定在约2.1 nm，表明ZGNP保持了相对紧密且一致的结构，未发生显著膨胀或收缩。类似地，[[溶剂可及表面积|SASA]]值在10 ns后趋于稳定，仅有轻微波动，表明GA结合对zein的溶剂暴露区域影响很小（图3F）。[[吉布斯自由能景观]]（图3G）以ZGNP的RMSD和Rg值经[[主成分分析|PCA]]得到的PC1和PC2分别作为X轴和Y轴，以相对吉布斯自由能作为Z轴构建[56]。该景观表现出几乎单一且尖锐的最小能量簇，表明ZGNP在整个模拟过程中保持了高度稳定状态。这些结果与上述关于[[最高占据分子轨道|HOMO]]-[[最低未占分子轨道|LUMO]] [[能隙|Eg]]的结论一致。上述结果验证了ZGNP优异的稳定性，表明其具有长期稳定封装[[肉桂醛|CIN]]的潜力。

此外，在模拟过程中，[[氢键]]数量在0至100 ns之间持续波动，表明[[玉米醇溶蛋白|zein]]与[[没食子酸|GA]]之间存在持续的氢键相互作用（图3H）。进一步采用[[分子对接]]阐明zein与[[阿拉伯胶|GA]]的2D和3D结合结构分布（图3J–K），[[蛋白质]]内部提供了强疏水环境，并含有大量氢键位点，[[丝氨酸|Ser]]（117）、Ser（159）、[[亮氨酸|Leu]]（158）和Leu（172）被鉴定为与GA形成氢键，其中LEU贡献了最大的结合能（图3I）。这些结果验证了zein通过氢键与GA相互作用，形成稳定的复合纳米颗粒，与[[分子静电势|MEP]]图（图2G）的发现及先前研究[57]一致。

总体而言，[[玉米醇溶蛋白]]和 [[没食子酸|GA]] 主要通过[[氢键]]和[[静电相互作用]]紧密结合。[[ZGNP]] 表现出优异的理化性质、界面[[吸附]]特性和稳定性。值得指出的是，[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] 具有形成长期稳定[[纳米乳液]]的潜力，是制备[[微生物自毁智能纳米平台]]的理想基质。

## 3.2.3. 抗氧化与抗菌活性分析

[[DPPH]] 和 [[ABTS]] [[自由基清除活性]]可作为纳米乳是否保留 [[肉桂醛|CIN]] 抗氧化性能的指标。如图 4L 所示，3 %C-[[ZGNP]] 和 5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] 纳米乳均表现出显著的 DPPH（>60 %）和 ABTS（>85 %）自由基清除活性，而 7 %C-ZGNP 和 9 %C-ZGNP 纳米乳中观察到的抗氧化活性下降，可能归因于纳米乳中较高浓度下 CIN 与自由基之间的相互作用减弱 [63]。抗菌结果表明，CIN 纳米乳对真菌（[[意大利青霉|P. italicum]]、[[指状青霉|P. digitatum]] 和 [[灰葡萄孢|B. cinerea]]）和细菌（[[大肠杆菌|E. coli]] 和 [[金黄色葡萄球菌|S. aureus]]）均具有显著抑制作用（图 5A）。CIN 纳米乳（≥5 %，w/v）对三种真菌的相对抑制率超过 75 %（在 9 % 时达到 100 %）$\mathrm { ( F i g . ~ 5 B \mathrm { - } C ) } _ { : }$，且 E. coli 和 S. aureus 的[[抑菌圈]]直径（图 5D）分别超过 20 mm 和 40 mm，表明 CIN 纳米乳 $( \ge 5 \% , \mathrm { w / v } )$ 具有优异的抗菌性能 [64]。由于 5 %C-ZGNP 纳米乳兼具优异的理化 性能、稳定性及抗菌特性。

[[荧光染色]]用于评估 5 %C-[[ZGNP]] [[纳米乳液|NEs]] 处理诱导的[[细胞膜损伤]]（图 6A–E）。图像结果表明，经 5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs 处理的三种真菌同时发出红色和绿色荧光，其中红色荧光指示细胞膜损伤，绿色荧光反映 [[活性氧|ROS]] 积累。在 CK 和 ZGNP 组中未观察到荧光。同时，所有经 NEs 处理的细菌均发出红色荧光，表明细菌细胞膜完整性受到破坏，从而诱导大量细菌死亡。相比之下，CK 和 ZGNP 组发出绿色荧光，细菌存活率较高。同时，通过 [[SEM]] 观察到的微生物形态变化进一步佐证了上述结论。CK 和 ZGNP 组的表面表现为光滑完整，而 5 %C ZGNP NEs 组则出现不同程度的变形和破裂，导致微生物发生不可逆损伤。这可能归因于 [[肉桂醛|CIN]] 抑制 [[三磷酸腺苷酶|ATP 酶]]活性、破坏[[细胞分裂]]和[[生物被膜]]的能力。 形成，从而对微生物细胞膜造成损伤 [65]。

## 3.3. [[肉桂醛|CIN]] [[纳米乳液|NEs]] 作为[[微生物自毁智能纳米平台]]的表征

## 3.3.1. 5 %C-[[ZGNP]] [[纳米乳液|NEs]] 的酶触发行为

利用 [[SEM]] 和 [[CLSM]] 对 [[ZGNP]] 和 5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] [[纳米乳液|NEs]] 在体外酶消化过程中的形态变化进行了表征。随着酶浓度的增加，ZGNP 的结构逐渐崩解（图 8A 和 9A）。这可能是由于酶反应增强了 ZGNP 的排斥力，使其结构失稳，最终导致坍塌 [70]。同时，发现 5 %C-ZGNP NEs 的稳定性对酶活性敏感。[[激光扫描共聚焦显微镜|CLSM]] 图像显示，[[肉桂醛|CIN]] NEs 中液滴尺寸和不规则油滴数量显著增加（图 8B 和 9B）。这些结果表明，CIN NEs 与酶之间的相互作用导致 ZGNP 逐渐崩解，进而引起乳液破乳并随后释放大量 CIN。这与先前关于 NEs 酶响应性的研究一致 [71]，验证了 CIN NEs 的响应性释放特性。

## 3.3.2. 5 %C-[[ZGNP]] [[纳米乳液|NEs]] 的[[微生物自毁]]智能[[精准释放]]特性

如图S9A和$\mathrm { C } ,$所示，三种真菌均表现出[[蛋白酶]]活性，且该活性随培养时间的延长而增加。如图S9B和$\mathbf { D } ,$所示，所有真菌均表现出[[β-半乳糖苷酶]]活性，该活性也随培养时间的延长而增加。这些结果证实了[[意大利青霉]]、[[指状青霉]]和[[灰葡萄孢]]分泌蛋白酶和β-半乳糖苷酶的能力。利用三种真菌孢子悬浮液（意大利青霉、指状青霉和灰葡萄孢）与5 %C-[[ZGNP]] [[纳米乳液|NEs]]共孵育后生长特性的变化来反映[[微生物自毁]]现象，同时利用5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs的[[CLSM]]图像来说明[[肉桂醛|CIN]]的智能[[精准释放]]。在最初的0–4 d内，经5 %C-ZGNP NEs处理的意大利青霉（图8C）和灰葡萄孢（图8E）的[[菌丝体]]重量与CK组一样均呈现逐渐增加的趋势，且处理组的菌丝体重量始终低于CK组。这归因于NEs中CIN的稳定缓慢释放，从而产生一定程度的抗菌效果。此外，我们推测该阶段真菌产生的酶量不足以触发NEs破乳，从而阻止了大量CIN的释放。因此，经5 %C-ZGNP NEs处理的真菌仍表现出生长趋势。然而，4 d后，CK组的菌丝体重量出现爆发式增长（34.9–305.2 mg，16.4–189.3 mg），而5 %C-ZGNP NEs组未观察到显著变化（14.9–98.3 mg，9.9–14.3 mg）。这可以解释为两种真菌在4 d后进入快速生长期，${ \sf d } ,$产生并积累了足量的蛋白酶和[[多糖酶]]，破坏了处理组中ZGNP的结构，导致NEs破乳并释放大量CIN，最终抑制真菌生长。相应地，[[激光扫描共聚焦显微镜|CLSM]]图像（图8F）直观地反映了第5天NEs油相液滴的增加。由此可以进一步推断，意大利青霉或灰葡萄孢在4–5 d内积累的酶已引起NEs破乳，从而导致大量CIN的精准释放[72]。同时，5 %C-ZGNP NEs与指状青霉之间的相互作用遵循与上述类似的模式，但其快速生长期提前至2 d后开始（图8D），NEs的破乳发生在2–3 d（图8F）。3 d后，指状青霉的生长几乎停止。

对于细菌，OD 值表现出对细菌生长的明显依赖性 [47]。未处理[[大肠杆菌]]的[[对数生长期]]出现在 2 至 4 h 之间，而经 5 %C-[[ZGNP]] [[纳米乳液|NEs]] 处理组在 0–4 h 期间生长缓慢，4 h 后 OD 值显著下降（图 9C）。这表明大肠杆菌大量死亡。对于未处理[[金黄色葡萄球菌]]，其对数生长期从 2 h 持续到 8 h，同样地，5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs 处理组在 8 h 后观察到 $\mathrm { \ O D } _ { 6 0 0 }$ 值显著下降（图 9D）。这表明金黄色葡萄球菌大量死亡。细菌[[活菌计数]]的变化支持相应结论（图 9E）。5 %C-ZGNP NEs（图 9F）分别与大肠杆菌和金黄色葡萄球菌在 4 h 和 8 h 相互作用的 [[CLSM]] 图像显示油相液滴增多，表明大肠杆菌（2–4 h）或金黄色葡萄球菌（2–8 h）产生并积累的酶足以破坏 [[肉桂醛|CIN]] NEs 的稳定结构，从而导致 CIN 的[[精准释放]]。先前研究也通过酶响应性触发了抗菌剂的释放 [73]。

## 3.4. 生物安全性评价

良好的生物安全性是[[肉桂醛|CIN]] [[纳米乳液|NEs]]涂层应用于[[水果保鲜]]的基本前提。通过[[溶血试验]]和[[细胞毒性试验]]评价了5 %C-[[ZGNP]] NEs涂层的生物安全性。0.9 %生理盐水组和5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs涂层处理组的上清液透明且呈淡黄色，而水处理组则发生完全溶血，形成鲜红色浑浊溶液（图11A）。值得注意的是，浓度为2.0 mg/mL的5 %C-ZGNP NEs涂层溶血率（3.38 %）远低于5 %的可接受限值[75]。这些结果表明，5 %C-ZGNP NEs涂层对红细胞没有显著影响。此外，细胞毒性测试表明，在不同浓度的5 %C-ZGNP NEs涂层中孵育1、3和5 d后，[[NIH3T3细胞]]的活力始终保持在95 %以上（图11B）。对第1天处理的[[NIH3T3 细胞|NIH3T3]]细胞进一步进行活/死染色发现，其对细胞生长没有明显的抑制作用，也未诱导细胞凋亡（图11C）。这些结果验证了5 %C-ZGNP NEs涂层用于水果保鲜的生物安全性。

## 3.5. 保鲜效果在[[柑橘]]和[[樱桃番茄]]上的应用

在采后贮藏过程中，[[柑橘]]（非跃变型）极易受到[[意大利青霉]]（P. italicum）和[[指状青霉]]（P. digitatum）的侵染，而[[樱桃番茄]]（跃变型）则易受[[灰葡萄孢]]（[[灰葡萄孢菌|B. cinerea]]）侵染。此外，两种果实都容易受到细菌污染。5 %C-[[ZGNP]] [[纳米乳液|NEs]] 具有优异的理化性质、稳定性、抗氧化和抗菌活性以及微生物破坏[[智能响应]]能力，因此被选用于涂膜制备。具体而言，以[[果胶]]为基质制备涂膜（5 % NEs-P），不仅能使 5 %C-[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]] NEs 均匀附着于果实表面，还能保留其酶响应特性。5 % NEs-P 的酶解 [[SEM]] 结果表明，随着[[果胶酶]]活性的增加，5 % NEs-P 涂膜表面逐渐出现明显的圆形孔洞和裂纹（图 S8C–D）。这表明 5 % NEs-P 中的果胶基质同样表现出优异的酶响应特性。在微生物分泌的酶水解果胶基质和 5 %C-ZGNP NEs 后，[[肉桂醛|CIN]] 被[[精准释放]]以抑制微生物生长。将 5 %NEs-P 应用于柑橘和樱桃番茄的保鲜实验，以评估其在果实保鲜市场中实际应用的潜力。

对于[[柑橘]]而言，CK 组和[[果胶]]组分别在第 15 天和第 20 天出现可见腐烂，并在第 25 天和第 30 天表现出明显的微生物侵染（图 11D）。相比之下，[[咪鲜胺]]组和 5 %[[纳米乳液|NEs]]-P 组即使在贮藏 35 天后也几乎未出现微生物侵染。这可归因于 [[肉桂醛|CIN]] 的抗氧化和抗菌特性，抑制了微生物增殖和柑橘果皮上的[[氧化应激]][76]。值得注意的是，咪鲜胺组出现明显的脱水和皱缩，推测是由于咪鲜胺溶解了柑橘的[[蜡质层]]，导致严重失水[77]。为量化差异，进一步对[[失重率]]、[[硬度]]、[[可溶性固形物|TSS]] 和 [[可滴定酸|TA]] 进行表征，以评估 5 %NEs-P 的保鲜效果。在整个贮藏期内，5 %NEs-P 组的失重率（10.07 %）（图 11E）低于其他组。硬度（13.16 N）（图 11F）保持在较高水平。TSS 含量（12.3 %）（图 11G）和 TA 含量（0.84 %）（图 11H）均高于其他组。结果表明，5 %NEs-P 有效减缓了水分流失并抑制了果实的呼吸速率，从而维持了优异的理化品质。这可归因于 CIN NEs 涂膜优异的抗氧化和阻隔作用，抑制了柑橘的代谢和氧化。与一种用于柑橘保鲜的[[纳米纤维]]相比，5 % NEs-P 将柑橘的[[货架期]]延长了 1.75 倍[78]。

对于[[樱桃番茄]]，目视检查清晰地表明，CK和Pectin组在10 d贮藏期间受到微生物侵染，而[[咪鲜胺]]和5 %[[纳米乳液|NEs]]-P组未发生腐烂，保持了更好的外观和品质（图11I）。此外，所有组樱桃番茄的重量、[[硬度]]、[[可溶性固形物|TSS]]和[[可滴定酸|TA]]含量均出现不同程度下降，其中CK和Pectin组损失最为显著，其次是咪鲜胺组（图11J–M）。这可归因于樱桃番茄呼吸过程中水分、营养物质和有机酸的消耗[75]。5 %NEs-P组保持了优异的外观、品质和营养保留，这得益于其优越的抗氧化特性，降低了贮藏期间的呼吸速率，同时其优异的抗菌活性有效防止了微生物污染[79]。同时，本研究制备的5 %NEs-P表现出与咪鲜胺相当的保鲜能力，但保鲜果实的外观和品质更优，且具有更环保的额外优势。这些结果成功证实了[[智能响应]]型[[肉桂醛|CIN]] NEs涂层的优异性能及其在[[水果保鲜]]市场中广阔的应用潜力。

## 4. 结论

本研究受[[柑橘油腺天然防御机制]]的启发，开发了一种基于[[ZGNP]]的[[肉桂醛|CIN]] [[纳米乳液|NEs]]体系，作为[[微生物自毁智能纳米平台]]，用于CIN的[[精准释放]]和水果的长期保鲜。结果表明，[[玉米醇溶蛋白-阿拉伯胶纳米颗粒|ZGNP]]由[[没食子酸|GA]]（2 %，w/v）与[[玉米醇溶蛋白]]通过[[氢键]]和[[静电相互作用]]结合形成，具有合适的[[三相接触角]]、优异的[[界面张力]]和稳定性。此外，所制备的CIN NEs表现出优异的稳定性、缓释特性、[[生物相容性]]以及强抗菌和抗氧化能力。CIN NEs的[[微生物自毁]]和精准CIN释放机制如下：初始阶段，CIN NEs持续缓慢释放CIN；在微生物快速生长阶段，微生物释放的酶触发CIN释放，从而抑制微生物生长。保鲜实验表明，CIN NEs涂层有效将[[柑橘]]和[[樱桃番茄]]的[[货架期]]延长了2倍。总之，本研究提出了一种用于水果长期保鲜的智能纳米平台，为可持续智能食品包装的发展提供了有前景的策略。
