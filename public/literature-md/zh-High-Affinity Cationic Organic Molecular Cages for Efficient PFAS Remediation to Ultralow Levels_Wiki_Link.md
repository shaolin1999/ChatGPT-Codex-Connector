## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是自20世纪50年代以来一直用于食品包装、消防泡沫、化妆品和机械领域的一类受关注度最高的新兴[[持久性污染物]]。<sup>1−4</sup> 其在ng L<sup>−1</sup>水平即表现出的毒性已促使全球出台严格限值：[[美国环境保护局|美国]]饮用水中[[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]]限值为4 ng L<sup>−1</sup>（2023年），<sup>5</sup> 中国规定PFOA为80 ng L<sup>−1</sup>、[[全氟辛磺酸钾盐|PFOS]]为40 ng L<sup>−1</sup>（[[GB 5749-2022]]），<sup>6</sup> [[欧盟]]规定每周总PFAS耐受摄入量为8 ng kg<sup>−1</sup>。<sup>7</sup> 严格的法规凸显了PFAS污染日益加剧的严重性及其管控所面临的日益严峻的挑战。

[[全氟和多氟烷基物质|PFAS]]的有效修复受到460 kJ mol<sup>−1</sup> C−F键、表面活性剂驱动的迁移以及亚μg L<sup>−1</sup>级浓度的阻碍，这些因素同时减缓了传质和高级氧化动力学。<sup>8−11</sup>此外，不完全矿化会产生迁移性更强的短链同系物。<sup>12,13</sup>[[吸附]]因其操作简单、适用范围广以及与后续浓缩或降解过程的兼容性而被广泛研究。<sup>14,15</sup>尽管新型PFAS配方仍以阴离子磺酸盐或羧酸盐同系物为主，但其强吸电子氟产生了高度负电荷密度。<sup>16</sup>最大化阳离子电荷密度<sup>17,18</sup>而非依赖疏水效应<sup>19,20</sup>或F−F相互作用<sup>21,22</sup>的[[吸附剂]]，代表了通过静电作用去除这些普遍存在的阴离子的一种有前景的策略。多种吸附剂<sup>23,24</sup>——包括[[粒子活性炭|颗粒活性炭]]、[[离子交换树脂]]、[[多孔碳]]、[[金属有机框架]]、[[共价有机框架]]和[[多孔有机聚合物]]——已被研究用于PFAS去除。然而，仍存在若干挑战，例如对短链PFAS的亲和力弱、吸附选择性有限、[[天然有机物]]和共存离子的干扰、结合位点利用效率低，以及与[[再生]]和实际放大相关的困难。

## 2. 材料与方法

高亲和力的阳离子[[ICC3]]在单一分子笼单元中具有12个潜在[[质子化]]位点（图1），其通过两步法从原始富氮亚[[胺分子笼]][[CC3]]合成。<sup>25</sup> 首先，用[[NaBH4|NaBH]]处理CC3，形成胺分子笼，即所谓[[RCC3]]，其骨架结构因刚性亚胺双键转变为胺单键而具有柔性。<sup>32</sup> 随后，用[[盐酸]]（HCl）对RCC3进行质子化，得到阳离子ICC3分子笼。CC3、RCC3和ICC3的八面体笼结构的定量形成由<sup>1</sup>H[[核磁共振]]（NMR）（图1a）、<sup>13</sup>C NMR和[[二维扩散序谱]]（2D DOSY）分析证实（图S1−S3）。[[高分辨质谱]]（HRMS）进一步确认CC3（图S4a）和RCC3（图S4b）的分子量与预期值一致。鉴于ICC3由RCC3经HCl酸化制备，ICC3与RCC3的质谱峰位置几乎相同是预期之中的（图S4c）。如显微镜图像、[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）和[[高角环形暗场扫描透射电子显微镜]]（HAADF STEM）显微照片所示（图1b、c和S5），CC3是一种刚性微孔晶体固体，其[[Brunauer-Emmett-Teller比表面积|Brunauer−Emmett−Teller（BET）比表面积]]为$6 3 3 ~ \mathrm { m } ^ { 2 } ~ \mathrm { g } ^ { - 1 }$，孔径约为0.7 nm（图S6）。使用$\mathrm { \Delta N a B H _ { 4 } }$进行还原后修饰断裂了亚胺（C═N）键，得到具有无定形结构的柔性RCC3，[[粉末X射线衍射]]（[[PXRD]]）图谱中相应衍射峰的消失清楚地表明了这一点（图1b内插图）。同时，[[紫外-可见分光光度计|紫外−可见分光光度计]]（[[紫外-可见吸收光谱|UV−vis]]）吸收最大值发生明显的[[蓝移]]（图S7a），而[[傅里叶变换红外光谱|傅里叶变换红外光谱仪]]（[[FTIR]]）中1652 cm<sup>−1</sup>处C═N伸缩振动的特征峰消失（图S7b），证实了从C═N到C−N键的刚性到柔性成功转变。<sup>33</sup> NMR和FTIR光谱均保留了分子笼骨架的诊断性共振信号，表明整体拓扑结构保持完整。

[[质子化]]后，通过[[ζ电位]]测量量化了由此产生的[[表面电荷]]再分布。在相同初始浓度下，[[ICC3]]表现出强酸性$\mathrm { ( p H } = 3 . 1 \mathrm { ) }$，ζ电位为$+ 2 9 . 4 \pm 0 . 6$ mV（图S8a），显著高于[[CC3]]（pH = 6.4，ζ电位$= + 1 1 . 6 \pm 0 . 7 \mathrm { \ m V } )$）和[[RCC3]]（pH = 7.3，ζ电位$= + 1 3 . 3 \pm 1 . 7$ mV）。值得注意的是，ICC3的[[等电点]]为$\mathrm { p H } = 9 . 4 ,$，表明其在典型水相条件下保持强正电荷（图S8b）。[[酸碱滴定]]给出ICC3的三个表观[[pKa|pK]]值，分别为3.078、7.133和8.594。这些结果表明，ICC3在酸性条件下可被大量质子化，从而支持多个正电荷位点的存在（表S1）。图S9中的[[能量色散X射线光谱]]（EDS）面扫进一步证实了ICC3的成功改性。这种增强的正电荷有利于在水介质中[[吸附]]阴离子化合物，例如[[全氟和多氟烷基物质|PFAS]]。ICC3的所有[[核磁共振|NMR]]、[[FTIR]]、[[SEM]]和TEM分析均证实了分子笼结构的保持（图1和S4−S7）。

[[CC3]] 本质上是亲水的，这一点已由平衡[[接触角]]（CA）测试证实 $\big ( \mathrm { F i g u r e ~ \ : S 1 0 , ~ } \theta _ { \mathrm { C C 3 } } \ = \ 7 9 . 9 9 \ \pm \ 0 . 8 ^ { \circ } \big )$ 。逐步化学改性逐渐放大这一特性，使表面润湿性从中等亲水状态 $( \theta _ { \mathrm { R C C 3 } } = 6 1 . 4 8 \pm 1 . 3 8 ^ { \circ } )$ 转变为强亲水状态 $( \bar { \theta } _ { \mathrm { I C C 3 } } = 4 7 . 6 7$ $\pm 1 . 0 1 ^ { \circ } )$ ，这主要归因于 [[ICC3]] 骨架中高密度的[[仲铵阳离子]]位点。ICC3 相对更强的亲水性将增强其在水溶液中的分散性，从而有助于高效[[吸附]]和去除水中污染物。此外，对分子笼进行了 [[Geometric optimization|AM1-BCC 几何优化]]<sup>34</sup>，以评估[[可旋转键]]数量（NRot）和[[柔性指数]]（ϕ），如图 S11 所示。结果表明，CC3、[[RCC3]] 和 ICC3 几乎没有自由旋转键，这是因为刚性八面体骨架中的所有键均较强且高度定向。柔性指数分析表明，化学还原使 RCC3 的柔性 $\left( \phi = 2 5 . 9 4 6 \right)$ 相对于 CC3 $\left( \phi = 2 3 . 9 4 3 \right)$ 有所提高，这意味着 [[全氟辛酸|PFOA]] 在 RCC3 表面上的扩散能垒更低，从而更快达到吸附平衡。尽管数值变化相对较小，但该笼表现出从刚性骨架到柔性骨架的明显转变。这一观察结果表明构象自由度和结构适应性显著增强，并进一步得到 [[XRD]] 结果的支持（图 1b）。氯离子的引入使 ICC3 的计算柔性（ϕ = 24.817）相对于 RCC3 略有降低；整体笼构象基本保持不变。值得注意的是，ICC3 亲水性的改善促进了 [[全氟和多氟烷基物质|PFAS]] 分子在笼周围水相中更快速、更均匀的分布，这可能有利于[[主客体相互作用]]。

作为一种高亲和力阳离子[[吸附剂]]，[[ICC3]] 经设计具备强局域正电场、较高柔性和改善的亲水性，预期将在实验中展示其对水体系中低浓度 [[全氟和多氟烷基物质|PFAS]] 的高去除效率，从而为高性能 PFAS [[吸附]]材料的设计提供实验验证和理论指导。此外，[[热重分析]]（TGA）和[[差示扫描量热]]（[[差示扫描量热法|DSC]]）数据表明，

## 3. 结果与讨论

## 3.1. [[吸附]]性能

与 [[CC3]] 和 [[RCC3]] 相比，结构定制的阳离子型 [[ICC3]] 笼具有高柔性、丰富的[[季铵位点]]和增强的亲水性，是阴离子型 [[全氟和多氟烷基物质|PFAS]] 的理想[[吸附剂]]。值得注意的是，在 1000 ppm 中性水溶液条件下，ICC3 对[[全氟辛酸]]（PFOA）的[[吸附]]容量达到 2290 mg $\mathbf { g } ^ { - 1 }$ ，比 CC3 $( 4 0 ~ \mathrm { ~ m } \mathrm { ~ g ~ } ^ { - 1 } )$ 和 RCC3（453 mg $\mathbf { g } ^ { - 1 } )$ ）高几十倍（图 2a）。相应地，CC3、RCC3 和 ICC3 对[[全氟辛磺酸钾盐]]（[[全氟辛烷磺酸|PFOS]]）的吸附容量分别达到 1123、1163 和 1893 mg $\mathbf { g } ^ { - 1 } ,$ （图 S13）。这些结果表明，调控笼对 $\mathrm { P F A S , ~ e . g . , }$ 的亲和力、外围电荷密度、亲水性和柔性，可以将 PFAS 吸附容量提高数倍。

随后，考察了 [[ICC3]] 的[[吸附]]性能。在常见水体污染物中，[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 是研究最广泛的两种。为了进一步理解吸附机理并评估其潜在的环境适用性，在两种代表性 pH 条件下研究了吸附性能，即 pH 2.5 和 pH 7.0。选择 pH 2.5 的酸性条件是为了使 ICC3 保持高度[[质子化]]状态，而选择 pH 7.0 则更接近实际水体环境。如图 S14a 所示，在 pH 2.5 条件下，在 50−2000 ppm 的初始浓度范围内建立了 ICC3 对 PFOA 的[[吸附等温线]]。平衡数据可用 [[Langmuir模型|Langmuir]] $\mathrm { m o d e l } ^ { 3 1 }$ 作为有限结合位点行为的唯象表示进行良好描述，估算的最大吸附容量 $( q _ { \mathrm { m a x } } )$ 为 2841 mg $\mathbf { g } ^ { - 1 }$（6.86 mmol $\mathbf { g } ^ { - 1 } )$，平衡浓度为 1360 ppm $\left( R ^ { 2 } = 0 . 9 \bar { 9 } 3 5 , \right.$ 表 S2）。在相同条件下收集的 ICC3 对 PFOA 的[[吸附动力学]]曲线（图 S14b 和 S15）显示，在 2 min 内即可达到超快吸附平衡。[[准一级模型]]<sup>35</sup>给出的速率常数为 $6 . 0 9 \ \mathrm { \ m i n ^ { - 1 } }$，并且与实验数据拟合良好 $\left( R ^ { 2 } = 0 . 9 9 7 9 \right) _ { \mathrm { { z } } }$，表明 ICC3 可快速去除 PFOA。在所测试的动力学模型中，该模型与实验数据的吻合度最佳，表现为更高的相关系数、更低的拟合误差，以及计算吸附容量与实验[[平衡吸附容量]]之间更为一致。因此，在当前实验条件下，采用准一级模型作为吸附动力学的唯象描述。如图 2b 所示，进一步在 pH 7.0 下评价了 ICC3 对 PFOA 的吸附等温线。最大吸附容量达到 2983 mg $\mathbf { g } ^ { - 1 }$（7.21 mmol $\mathbf { g } ^ { - 1 } )$，略高于 pH 2.5 下观察到的结果。这一提升可能归因于 PFOA 在中性条件下更完全地[[去质子化]]，此时 PFOA 主要以阴离子形式存在。此外，吸附动力学常数达到 $6 . 4 6 \ \mathrm { m i n } ^ { - 1 } \ \left( R ^ { 2 } = 0 . 9 9 0 2 , \right.$，图 2c），也高于 pH 2.5 下得到的数值。这些结果表明，ICC3 在中性水溶液中表现出更优的吸附性能。值得注意的是，与所有此前报道的[[吸附剂]]相比，ICC3 表现出更优异的 PFOA 吸附容量（图 S16 和表 S3）。此外，pH 2.5 下 [[全氟辛磺酸钾盐|PFOS]] 的 $q _ { \mathrm { m a x } }$ 达到 3347 mg $\mathbf { g } ^ { - 1 }$（图 S17a 和表 S2），相应的速率常数高达 11.9 min<sup>−1</sup>（图 S17b）。而 pH 7.0 下 PFOS 的 $q _ { \mathrm { m a x } }$ 达到 3515 mg $\dot { \mathbf { g } } ^ { - 1 }$（图 S17c 和表 S2），相应的速率常数低至 4.02 min<sup>−1</sup>（图 S17d）。与 PFOA 不同，PFOS 是更强的酸，因此在 pH 2.5 和 pH 7.0 下均主要以阴离子形式存在。然而，在 pH 7.0 下，ICC3 质子化程度降低，削弱了其与 PFOS 之间的[[静电相互作用]]，从而影响了对 PFOS 的吸附。尽管如此，ICC3 仍表现出对 [[全氟和多氟烷基物质|PFAS]] 相当可观的吸附能力，凸显了其在环境修复应用中的良好潜力。

为进一步评价 [[ICC3]] 对带有不同末端官能团和不同链长的多种 [[全氟和多氟烷基物质|PFAS]] 污染物的[[吸附]]性能，在室温下向初始浓度为 1000 ppm 的不同 PFAS 水溶液中加入等质量的 ICC3。在 pH 2.5 和 pH 7.0 条件下，ICC3 对[[全氟庚酸]]（PFHA）和[[全氟己磺酸钾盐]]（PFHxS）的质量吸附量略低于对 [[全氟辛酸|PFOA]] 的吸附量，而对[[全氟己酸]]（PFHxA）、[[正全氟戊酸]]（PFPeA）、[[七氟丁酸]]（PFBA）和[[九氟-1-丁磺酸钾]]（PFBS）的吸附容量则明显更低（图 2d 和 S18a）。当以摩尔量表示时（图 S18b、c 和 S19），ICC3 对 PFHxA、PFPeA、PFBA 和 PFBS 吸附性能的下降与短链 PFAS 的负电荷密度高度一致（图 2e、f）。一方面，PFAS 阴离子较高的负电荷密度可促进更强的静电吸引，并使其与阳离子分子笼的结合距离更短。另一方面，电负性升高可能增大 PFAS 分子的内部偶极矩，从而促进更强的偶极−偶极相互作用。在 pH 7 下观察到的吸附容量降低也与 ICC3 的部分[[去质子化]]一致，进一步支持上述解释。这种增强的亲和力因此使 PFAS 离子能够在阳离子分子笼外围实现更高的空间堆积密度，从而提升整体吸附容量。就此而言，在链长相同的 PFAS 中，ICC3 对[[磺酸端基]]类似物表现出比[[羧酸端基]]类似物更高的亲和力，这归因于磺酸基团具有更高的电负性，并因此与高度阳离子化的 ICC3 分子笼产生更强的[[静电相互作用]]（图 2d−f、S18 和 S19）。

此外，[[ICC3]] 在 pH 2.5 和 pH 7.0 下同样表现出对短链 [[全氟和多氟烷基物质|PFAS]] 的显著[[吸附]]容量，在 pH 2.5 下分别达到 $q _ { \mathrm { m a x } } ( \mathrm { P F H A } ) = 2 1 5 2$ mg $\mathrm { g } ^ { - 1 } , \ \bar { q } _ { \mathrm { m a x } } ( \mathrm { P F H x A } ) = 1 3 4 1$ mg $\mathrm { g ^ { - 1 } , } q _ { \mathrm { m a x } } \mathrm { ( P F P e A ) } = 4 8 7 \mathrm { m g ~ g ^ { - 1 } } , q _ { \mathrm { m a x } } \mathrm { ( P F B A ) } = 1 5 7 \mathrm { m g ~ g ^ { - 1 } } ,$ $q _ { \mathrm { m a x } } \mathrm { \bar { ( P F H x S ) } } = 2 1 8 3 ~ \mathrm { m g ~ g ^ { - 1 } } .$ 和 $q _ { \mathrm { m a x } } \mathrm { ( P F B S ) } = 1 2 8 4 ~ \mathrm { m g ~ g ^ { - } }$ 1（图 S20 和表 S2）；在 pH 7.0 下分别为 $q _ { \mathrm { m a x } } ( \mathrm { P F H A } ) = 2 2 2 9$ mg $\mathrm { g ^ { - 1 } , ~ } q _ { \mathrm { m a x } } \mathrm { ( P F H x A ) } = 1 4 7 7 \mathrm { ~ m g ~ g ^ { - 1 } , ~ } q _ { \mathrm { m a x } } \mathrm { ( P F P e A ) } = 5 1 5 $ mg $\mathrm { g ^ { - 1 } , ~ } q _ { \mathrm { m a x } } ( \mathrm { P F B A } ) = 4 4 8 \mathrm { ~ m g ~ g ^ { - 1 } , ~ } q _ { \mathrm { m a x } } ( \mathrm { P F H x S } ) = 2 2 9 6 \mathrm { ~ m g ~ g ^ { - 1 } } ,$ 和 $q _ { \mathrm { m a x } } ( \mathrm { P F B S } ) \ : = \ : 1 5 4 8$ mg $\mathbf { g } ^ { - 1 }$（图 S21 和表 S2）。该结果值超过了绝大多数已报道的[[吸附剂]]（表 S4）。尽管在 pH 7.0 下由 [[Langmuir 吸附模型|Langmuir 模型]]得到的 $q _ { \mathrm { m a x } }$ 值略高于 pH 2.5 下所得值，但在 PFAS 初始浓度为 1000 ppm 时，pH 7.0 下的[[平衡吸附容量]]低于 pH 2.5 下。这一表面上的差异可能归因于不同 pH 条件下吸附平衡行为的差异。pH 的变化可影响吸附剂的[[表面电荷|表面电荷特征]]、[[吸附位点]]的可利用性以及吸附剂与 PFAS 分子之间的相互作用，从而改变[[吸附等温线]]的形状以及与给定初始浓度相对应的平衡浓度。<sup>36,37</sup> 在 pH 2.5 下，体系可能在相对较低的 PFAS 浓度下达到更高的位点占据程度，从而在所研究的浓度范围内产生更大的吸附容量。相比之下，尽管 pH 7.0 下的吸附体系表现出略高的理论 $q _ { \mathrm { m a x } }$，但其可能需要更高的 PFAS 浓度才能接近饱和，从而导致在初始浓度为 1000 ppm 时平衡吸附容量较低。因此，在单一浓度点观察到的吸附容量并不一定反映等温线模型所预测的最终吸附容量。这一观察结果凸显了 ICC3 在 PFAS 污染水体综合修复方面的独特优势。

此外，为评估 [[ICC3]] 在实际环境中对 [[全氟辛酸|PFOA]] 的选择性，在代表性阳离子 $( \mathsf { Z n } ^ { 2 + } )$ $\mathrm { C u ^ { 2 + } , \ N i ^ { 2 + } , \ C r ^ { 3 + } , \Sigma \bar { P b } ^ { 2 + } , \ C d ^ { 2 + } , \ C a ^ { 2 + } , \ M g ^ { 2 + } , \ C o ^ { 2 + } , \ M n ^ { 2 + } , \Sigma \bar { F } e ^ { 3 + } }$ $\mathsf { A l } ^ { 3 + }$ 和 ${ { \mathrm { N a } } ^ { + } } ) ,$、阴离子 $( \mathrm { S O _ { 4 } ^ { 2 - } } , \mathrm { N O _ { 3 } ^ { - } } , \mathrm { \tilde { N } O _ { 2 } ^ { - } } , \mathrm { B _ { 4 } O _ { 7 } ^ { 2 - } } , \mathrm { P O _ { 4 } ^ { 3 - } } ,$ $\mathrm { C r } _ { 2 } \mathrm { O } _ { 7 } { } ^ { 2 - } , ~ \mathrm { M n O } _ { 4 } { } ^ { - }$ 和 $\mathrm { P F } _ { 6 } ^ { - } \big ) .$ 以及表面活性剂（[[十六烷基三甲基溴化铵]]（CTAB）、[[N,N-二甲基-N-十二烷基苄基氯化铵]]（DDBAC）、[[富里酸]]（FA）、[[十二烷基硫酸钠]]（SDS）和[[十二烷基苯磺酸钠]]（SDBS））存在的条件下，开展了[[竞争吸附]]实验。图 2g 与图 S22 中的结果表明，在 pH 2.5 和 pH 7.0 条件下，绝大多数干扰离子均未削弱 ICC3 对 PFOA 的[[吸附]]性能，体现了其更高的吸附选择性。值得注意的是，在 pH 2.5 条件下，$\mathrm { F e } ^ { 3 + }$ 和 DDBAC 的存在显著提高了 PFOA 的去除率（图 S22），这可能归因于这些阳离子物种与 PFOA 之间的协同吸附效应。相反，加入十二烷基硫酸钠（SDS）或十二烷基苯磺酸钠（SDBS）则明显抑制了 PFOA 的去除。这种抑制作用主要归因于阴离子混合物的竞争吸附。在 pH 7 条件下，[[离子强度]]对 ICC3 吸附 PFOA 的影响明显弱于 pH 2.5 条件下的影响（图 2d）。这一差异可归因于中性条件下[[静电相互作用]]贡献的降低。在较低 pH 下，离子强度的增加会增强[[电荷屏蔽效应]]，并促进共存阴离子与 PFOA<sup>−</sup> 对带正电[[吸附位点]]的竞争，从而更显著地影响吸附性能。值得注意的是，在 pH 2.5 条件下观察到的 [[全氟和多氟烷基物质|PFAS]] 吸附几乎被完全抑制的现象，在 pH 7.0 条件下并未出现，SDS 的情况即为例证。这一差异可能是因为，在中性条件下，离子干扰主要削弱 PFAS 吸附，而在酸性条件下，SDS 可能优先占据或屏蔽可用的吸附位点，并改变 ICC3 的表面微环境，从而严重阻碍 PFAS 分子接近[[吸附剂]]表面。值得注意的是，FA 作为[[天然有机质]]（NOM），在 pH 2.5 条件下对 PFOA 吸附影响很小，而在 pH 7 条件下则观察到吸附容量的适度下降。这一趋势与较高 pH 下 FA [[去质子化]]程度增加相一致，从而产生更高密度的带负电官能团。由此增强的 FA 与带正电 ICC3 骨架之间的静电相互作用促进了 FA 的吸附，并加剧了对吸附位点的竞争。尽管如此，FA 的影响仍然有限，表明即使在存在环境相关天然有机质的条件下，ICC3 仍能保持有效的 PFAS 吸附性能。ICC3 的高正电荷密度有利于与这些阴离子表面活性剂中电负性更强的硫酸根和磺酸根部分形成更强的静电相互作用，从而在竞争可利用结合位点时胜过 PFOA。

## 3.2. 机理研究

为阐明 [[ICC3]] 与 [[全氟和多氟烷基物质|PFAS]] 之间的[[构效关系]]和结合相互作用，以 [[全氟辛酸|PFOA]] 为[[模型污染物]]进一步研究 ICC3 的[[吸附]]机理。如图 3a 所示，采用基于 [[Hirshfeld 分区]]的[[独立梯度模型]]（IGMH）分析 ICC3 与 PFOA 分子之间的相互作用，通过 IGMH 等值面可视化相互作用区域，并以相应的 $\delta \mathbf { g } _ { \mathrm { i n t e r } }$ 函数量化相互作用强度。<sup>29,38</sup> 首先在图 S24 中计算了 ICC3 和 PFOA 的[[分子静电势]]（MESP）分布。ICC3 分子上的蓝色区域 $\mathrm { o f - N H _ { 2 } } ^ { + } -$ 节点显示正 MESP 值，而 PFOA 上 −COO<sup>−</sup>− 节点的红色区域显示负 MESP 值。因此，ICC3 表现出与 PFOA 的潜在相互作用，使两个分子稳定结合（图 3a）。特别是红框内区域呈现出显著的弱相互作用力，证明吸附后形成离子键（由 $\mathrm { s i g n } ( \lambda _ { 2 } ) \rho < 0 )$ 定义）。此外，PFOA 分子还可进入分子笼空腔，进一步稳定吸附。PFOA 朝向分子笼所经受的相互作用能 $\left( E _ { \mathrm { i n t } } \right)$（包括[[库仑相互作用]]和 [[Lennard-Jones 势]]）在图 S25 中计算；其大的负值（−1350 kJ mol<sup>−1</sup>）表明该吸附过程是热力学有利的自发吸附过程。

进一步通过实验验证了 [[ICC3]] 与 [[全氟辛酸|PFOA]] 之间相应的[[主客体相互作用]]，以确定它们各自的结合位点。在不同摩尔比下将 PFOA [[吸附]]到 ICC3 上所得材料命名为 ICC3-PFOA-X（[[ICC3-PFOA-I]]：$M _ { \mathrm { I C C 3 } } { : } M _ { \mathrm { P F O A } } =$ 1:2，[[ICC3-PFOA-II]]：$M _ { \mathrm { I C C 3 } } { : } M _ { \mathrm { P F O A } } = 1 { : } 5 ,$ ，[[ICC3-PFOA-III]]：$M _ { \mathrm { I C C 3 } } { : } M _ { \mathrm { P F O A } } = 1 { : } 8 )$）。ICC3-PFOA-I、ICC3-PFOA-II 和 ICC3-PFOA-III 样品保持了不规则形貌（图 S26），[[PXRD]] 图谱也证实了它们的无定形特性（图 S27），但图 S28 中的 [[EDS 面扫描]]检测到其表面存在大量 F 和 O，证实 ICC3 成功吸附了 PFOA。[[拉曼光谱]]显示，随着 PFOA 负载量增加，C−F 伸缩振动特征谱带<sup>39</sup>单调增强（图 S29）。与 PFOA 中 −COOH 部分的 O−H $( 3 5 3 \hat { 9 } \ \mathrm { c m } ^ { - 1 } )$ 基团<sup>40</sup>的特征振动峰相比，ICC3-PFOA-X 的 [[FTIR]] 光谱（图 3b）出现红移，表明[[羧酸根]]发生[[去质子化]]且电子密度离域，从而能够与分子笼发生静电结合。与此同时，ICC3 在 1580 $\mathrm { c m } ^ { - 1 }$ 处的 N−H 弯曲振动模式<sup>29</sup>发生[[蓝移]]，并随着 PFOA 负载量增加逐渐消失，表明新形成的 $\mathrm { N ^ { + } { \cdots } { } O ^ { - } }$ [[离子对]]在能量上比原有的 $\mathrm { N ^ { + } { \cdots } C l ^ { - } }$ 相互作用更有利，并完全掩盖了 N−H 弯曲运动。这些 [[傅里叶变换红外光谱|FTIR]] 数据佐证了[[静电吸附]]机制。

[[固态核磁共振|固态 NMR]] <sup>19</sup>F（<sup>19</sup>F ssNMR）谱（图 3c）显示，[[全氟辛酸|PFOA]] 中与[[羧酸根]]相邻<sup>41</sup>的 F 原子（−120.5 ppm）在络合后发生低场位移（[[ICC3-PFOA-I]]：−118.0 ppm，[[ICC3-PFOA-II]]：−117.7 ppm，[[ICC3-PFOA-III]]：−117.3 ppm），表明其电子环境发生显著变化，进一步支持库仑型[[主客体相互作用]]的主导地位。与此一致的是，固态 [[核磁共振|NMR]] $^ { 1 5 } \mathrm { N }$ $( ^ { 1 5 } \mathrm { { N } }$ ssNMR）谱（图 3d）显示，[[ICC3]] 中的氮（N）核（−314.3 ppm）<sup>42</sup>发生高场位移（ICC3-PFOA-I：−322.4 ppm，ICC3-PFOA-II：−323.2 ppm），佐证了上述结论。出乎意料的是，未检测到 $^ { \mathrm { { v } } _ { \mathrm { { 1 5 } } } } \mathrm { { N } }$ ssNMR 信号，原因是 ICC3-PFOA-III 中相对于大量[[吸附]]的 PFOA，氮含量极低。

进一步通过 [[XPS]] 分析 [[ICC3]]-[[全氟辛酸|PFOA]]-X 探究[[吸附]]机制（图 3e）。在 ICC3-PFOA-X 中观察到 N 原子（属于 ICC3 骨架上的 $\mathrm { - C - N H _ { 2 } ^ { + } - }$ 基团）的峰明显向高结合能位置移动，表明 −COO<sup>−</sup> 与 $\mathrm { - C - N H _ { 2 } ^ { + } - }$ 基团之间确实存在强相互作用。原始 ICC3 中 [[N 1s]] 的 $\mathrm { p e a k s } ^ { 4 3 }$ 位于 398.00 和 400.23 eV，分别向高结合能移动了 0.56 和 0.46 eV。PFOA 的 [[O 1s]] $\mathrm { p e a k } ^ { 4 \breve { 4 } }$ 向低结合能移动最多 0.3 eV（从 531.98 到 531.68 eV），与上述结论一致（图 S30a）。[[F 1s]] 结合能<sup>45</sup>位于 688.96 eV，仅偏移 0.08 eV，排除了 F−F 相互作用（图 S30b）。这进一步提供了确凿证据，表明 ICC3 对 PFOA 的吸附通过[[静电相互作用]]进行。

从 C K 边 X 射线吸收近边结构（[[X射线吸收近边结构|XANES]]）谱图（图 3f）来看，[[ICC3]] 在 288.0 eV 处的峰代表与季铵相连的烷基碳原子 $\mathrm { N ^ { + } \left( - C - N H _ { 2 } ^ { + } - \right) } ;$ ；在 ICC3-[[全氟辛酸|PFOA]]-X 谱图中该位置未观察到峰位移，表明[[吸附]]后 ICC3 周围的局域化学环境保持不变。<sup>46</sup> [[N K 边 XANES]] 谱<sup>47</sup>在吸附前后 407.26 eV 处的恒定峰进一步证实了这一点（图 S31a）。[[C K 边 XANES]] 谱中能量为 288.6 和 293.0 eV 的共振峰归属于 PFOA 的

C═O 和 C−O。所观察到的 0.3 eV 位移归因于 [[ICC3]] 上产生的界面电场，该电场扰动了芯空穴终态能量，从而引起 [[全氟辛酸|PFOA]] 的 $\textsc { C l s } \to \pi ^ { * }$ 跃迁发生位移。[[O K 边 XANES]] 谱<sup>48</sup>中 PFOA 在 534.76 eV 处的峰被归属为 $\mathrm { \ t o \mathrm { ~ - C O O ^ { - } } }$ ，并且在 ICC3-PFOA-X 谱图中可以观察到响应表面电位的 0.18 eV 斯塔克型位移。在整个[[静电吸附]]过程中，PFOA 中 −COO<sup>−</sup> 基团的化学态保持不变（图 S31b）。[[X射线吸收近边结构|XANES]] 提供了确凿证据，表明 ICC3 与 PFOA 之间的相互作用是可逆的静电[[吸附]]，而不是离子键的形成。

采用[[分子动力学模拟|分子动力学（MD）模拟]]<sup>29</sup>来解析 [[ICC3]] 对 [[全氟辛酸|PFOA]] 的动态捕获过程。MD 过程的轨迹动画见图 S32。通过追踪 ICC3 的 N 原子与 $\mathrm { P F O A } ;$ 的 O 原子之间的径向距离来评估 ICC3 对 PFOA 的[[吸附]]能力，距离越短表明捕获能力越强。为了直观展示初始态、中间态和平衡态，图 S33 中提取了代表性快照。在平衡态（图 S34），[[径向分布函数]]显示 PFOA 中大部分 O 原子位于 ICC3 骨架上 N 原子 1.5 nm 范围内，证明形成了紧密且高亲和力的复合物。[[热重分析|TG]] 和 [[差示扫描量热|DSC]] 实验（图 S35）表明，[[ICC3-PFOA-III]] 加合物在 189 °C（PFOA 的沸点）以下没有质量损失，证实了 MD 模拟所预测的强[[主客体相互作用|主−客体相互作用]]。

在此，实验和理论结果使人们对高亲和力 [[ICC3]] 分子笼去除 [[全氟和多氟烷基物质|PFAS]] 的潜在相互作用有了更全面的理解。ICC3 对 PFAS 的高效[[吸附]]与其分子笼上带正电荷的 $\mathrm { - N H } _ { 2 } ^ { + }$ 基团与 PFAS 中带负电荷的 −COO<sup>−</sup> 部分之间的[[静电相互作用]]一致（以 [[全氟辛酸|PFOA]] 作为[[模型污染物]]）。阳离子型 −NH <sup>+</sup> 官能团作为重要的结合位点，促进 $\mathrm { N ^ { + } { \cdots } { } O ^ { - } }$ [[离子对]]的形成，并对 PFAS 的摄取有显著贡献。这种相互作用也使得 ICC3 能够通过碱处理和[[再质子化]]策略实现回收利用。除了 ICC3 的高正电荷密度之外，主要的静电相互作用还得到分子笼关键结构特征的补充，包括增强的亲水性、结构柔性以及固有的空腔结构。这些特征共同促进了 PFAS 的有效分子封装，使吸附过程在热力学上有利、具有高选择性且可逆，同时不改变 ICC3 的基本化学结构。最终，ICC3 对长链和短链 PFAS 均表现出快速且稳健的吸附能力，并在同系物中具有高吸附容量，表明其对不同链长 PFAS 修复具有广泛适用性。尽管现有证据支持[[超分子吸附机制]]，但不能完全排除吸附诱导或局部聚集的可能贡献。综合来看，这些发现为理解 ICC3 捕获 PFAS 的相互作用和[[构效关系]]提供了见解，并凸显了其在实际修复 PFAS 污染环境方面的潜力。

## 3.3. 连续修复

除了具有可观的[[吸附]]容量和快速动力学外，[[ICC3]] 改善的稳定性与可回收性也是其实际应用的关键前提。如图 4a 中的示意图所示，间接回收策略能够有效回收分子笼，从而促进其高效循环与再利用。<sup>49</sup> ICC3 吸附 [[全氟辛酸|PFOA]] 后，由碱提供的 OH<sup>−</sup> 从 ICC3 的季铵基团中夺取 H<sup>+</sup>，生成水。此时，因[[静电相互作用]]释放出的 PFOA 重新溶解在水溶液中。同时，失去氢离子的[[去质子化]] ICC3 转变回水不溶性的 [[RCC3]]，可通过离心回收。最后，用 [[盐酸|HCl]] 酸化使 ICC3 [[再生]]。在连续三个循环中，ICC3 的回收率超过 98%，并始终保留其初始 PFOA 吸附容量的 96% 以上，显示出改善的循环吸附性能（图 4b）。ICC3 吸附 PFOA 后（图 S36），引入 [[氢氧化钠|NaOH]] 诱导笼骨架中 ${ \mathrm { - N H } } _ { 2 } ^ { + } -$ 基团去[[质子化]]，得到疏水性优于母体 ICC3 的水不溶性 RCC3（−NH−）。图 4c 中的 <sup>1</sup>H [[核磁共振|NMR]] 谱证实，回收的 RCC3 保持了结构完整性。与初始 RCC3（图 S37）相比，图 4d 中的 [[EDS 面扫描]]显示回收 RCC3 表面几乎完全不存在氟（F）和氧（O），证明了 NaOH 介导间接回收的有效性。回收的 RCC3 经再酸化再生为 ICC3，随后用于循环吸附 PFOA。图 S38 中的 <sup>1</sup>H NMR 证实再生后的 ICC3 保持了分子完整性，而图 S39 中的 [[能量色散X射线光谱|EDS]] 面扫描在笼表面未检测到残留的 F 或 O，表明[[吸附剂]]得到了清洁回收。这些结果共同验证了 ICC3 的结构稳定性和可回收性，证明其适用于持续的 [[全氟和多氟烷基物质|PFAS]] 修复应用。

最后，以 [[ICC3]] 为核心[[吸附剂]]建立了连续修复系统，实现了痕量 [[全氟和多氟烷基物质|PFAS]] 污染物的可持续去除。为此，通过[[孔浸渗策略]]将 ICC3 固定在[[介孔二氧化硅]]（[[离子型有机笼|ICC3@Si]]）上，该策略同时利用了载体的高内表面积以及 ICC3 与表面 Si−OH 之间形成的多重[[氢键]]。

[[紫外-可见分光光度计|UV−vis]] 定量证实，每克[[介孔二氧化硅]]可负载 23 mg [[ICC3]]（图 S40 与表 S5）。[[总有机碳]]（TOC）测定表明，在连续水冲洗以及依次进行的碱性[[脱附]]−酸[[再生]]循环中，ICC3 的浸出极小（<1%），证明 ICC3 在二氧化硅载体上具有优异的固定稳定性（表 S6）。组装了固定床微柱（图 4e），以评估所合成的 ICC3@Si 复合材料对低至 μg·L<sup>−1</sup> 水平的痕量 [[全氟和多氟烷基物质|PFAS]] 的修复性能。将 40 mL [[全氟辛酸|PFOA]] 与 [[全氟辛烷磺酸|PFOS]] 溶液（0.01−200 ppm）以 1.0 mL min<sup>−1</sup> 的流速通过 430 mg [[离子型有机笼|ICC3@Si]]（约含 10 mg ICC3）。[[液相色谱-串联质谱|LC-MS/MS]] 分析表明，在整个浓度范围内，PFOA 的去除率 ≥ 99%（图 4f），[[全氟辛磺酸钾盐|PFOS]] 的去除率 ≥97%（图 4g）。尽管本研究实现了高去除效率，但法规符合性取决于初始 PFAS 浓度及处理后相应的残余浓度。目前 PFOA 和 PFOS 的饮用水标准通常处于 ng/L 范围，显著低于本研究考察的浓度范围。因此，还需要使用环境相关浓度和超痕量分析方法开展进一步研究，以评估其是否符合法规要求。这些结果凸显了 ICC3 在通流条件下捕获超痕量 PFAS 的显著能力，未来研究将聚焦于连续流条件下的固定床柱实验和穿透曲线分析，以评估该[[吸附剂]]的长期性能与工程适用性。

## 4. 环境意义

[[全氟和多氟烷基物质|PFAS]] 的持久性与迁移性使人们迫切需要兼具快速[[吸附]]、高容量、选择性和[[可再生性]]的处理材料。本研究表明，对有机笼进行分子水平的[[电荷工程]]，可通过可逆的[[电荷辅助识别]]促进对[[羧酸根]]和磺酸根末端 PFAS 的高效捕获。与传统[[吸附剂]]相比，[[ICC3]] 的快速吸附和有效[[再生]]有望缩短处理时间、减少吸附剂用量与二次固体废物。此外，将 ICC3 固定于[[二氧化硅]]上使其能够用于[[连续流处理]]，并在环境相关进水浓度下展现出有效的 PFAS 去除能力。尽管由于分析灵敏度限制，ng L<sup>−1</sup> 水平的出水浓度无法直接验证，但结果表明基于 ICC3 的材料有望用于高级 PFAS 精处理。仍需在复杂天然水体、长期流动系统以及更大规模处理构型中作进一步评估，以确立其实际环境性能。
