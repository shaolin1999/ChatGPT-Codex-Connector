# 一种用于锚定[[磺酸盐]]的十六阳离子[[金属有机笼]]：[[二磺酸盐]]和[[三磺酸盐]]的高阶结合及水中[[全氟磺酸盐]]的高效去除

Yawei [[Liu]], Gen Li, Xiang Zhang, Zelin Du, Tingting Zhang, Yongya Zhang,\* Roy Lavendomme,\* En-Qing Gao,\* and Dawei Zhang\*

开发能够结合[[磺酸]]根阴离子或螯合[[全氟磺酸盐]]的合成[[主体]]具有重要意义。本工作报道了一种[[三吡啶鎓]]-三羧酸配体与 $\mathsf { C p } _ { 2 } \mathsf { Z r C l } _ { 2 }$ （Cp = $\eta ^ { 5 } { \cdot } { \mathsf { C } } _ { 5 } { \mathsf { H } } _ { 5 } )$ 的自组装，得到了一个带有酸性 C−H 质子的高阳离子四面体笼（1）。该[[十六阳离子笼]]以空前的电荷区分现象结合多种磺酸根阴离子：在 [[核磁共振|NMR]] 时间尺度上，该笼与[[单磺酸盐]]呈[[快交换]]结合，而与[[二磺酸盐]]和多[[磺酸盐]]则呈[[慢交换]]结合。特别是，笼 1 实现了对二磺酸盐和[[三磺酸盐]]的高容量络合，其中最显著的情况是 1 可容纳三个二价阴离子。[[分子模拟]]表明，四面体 1 的每条棱上（共六处）存在一个“Y”形[[结合口袋]]，每个口袋能够通过[[静电相互作用|静电]]与[[氢键]]相互作用锚定一个带有至少两个磺酸根头基的[[客体]]。进一步研究表明，固态下的 1 是一种出色的[[全氟辛烷磺酸盐]]（[[全氟辛基磺酸盐|PFOS]]）[[吸附剂]]，[[最大吸附容量]]高达 $\mathbf { 1 6 0 3 \ m g \ g ^ { - 1 } }$，使其跻身最优的 [[全氟辛烷磺酸|PFOS]] [[吸附]]剂之列。此外，笼 1 在 PFOS 去除中表现出快速[[吸附动力学|动力学]]、高选择性和长循环寿命，并且还能有效吸附较短链的全氟磺酸盐。

## 1. 引言

[[磺酸]]及其盐是一类重要的化学物种，广泛存在于合成化合物和天然化合物中，<sup>[1–4]</sup> 其应用范围涵盖洗涤剂、药物以及生物功能等方面。引入磺酸根基团可以改变有机化合物的溶解性和反应活性，<sup>[4]</sup> 这在药物、<sup>[5]</sup> 染料、<sup>[6]</sup> 以及洗涤剂和表面活性剂等其他工业化学品的合成中尤为有用。<sup>[7]</sup> [[磺酸盐]]也是多种生物分子的关键组成部分，对蛋白质、酶和代谢物的功能与稳定性具有贡献。<sup>[8,9]</sup> 例如，2-巯基乙磺酸盐是产甲烷古菌中的一种关键辅酶，在产甲烷代谢途径中作为重要的中间体发挥作用。<sup>[8]</sup> 因此，开发能够结合磺酸根阴离子的合成受体或[[主体]]具有重要意义，有助于在科学研究和实际应用中拓展磺酸盐化学的范围。

在各种[[磺酸]]根阴离子中，[[全氟磺酸盐]]是[[全氟和多氟烷基物质]]（[[全氟烷基物质|PFAS]]）中的一个重要亚类。<sup>[10]</sup> 这些化合物在单一分子内兼具[[疏水性]] C–F 链和[[亲水性]]头基，并且可溶于水。PFAS 常被称为“[[永久化学品]]”，是臭名昭著的[[环境污染物]]，与包括[[肝癌]]和[[免疫系统抑制]]在内的严重健康问题相关。<sup>[11]</sup> 它们还因在环境和人体组织中的[[生物累积性]]以及远距离环境迁移潜力而受到关注。<sup>[12]</sup> 不幸的是，其广泛使用和持久存在已导致多种水源受到污染。<sup>[13]</sup> [[吸附]]是从水中去除 PFAS 最常用的方法。<sup>[14–17]</sup> 目前已研究多种[[吸附剂]]，包括[[活性炭]]、<sup>[18–20]</sup> [[离子交换树脂]]、<sup>[21–23]</sup> [[金属-有机框架|金属–有机框架]]（MOFs）、<sup>[24,25]</sup> [[共价有机框架]]（COFs）、<sup>[26–28]</sup> [[金属-有机笼|金属–有机笼]]（[[MOC|MOCs]]）<sup>[29–35]</sup> 以及[[大环超分子材料|基于大环的超分子材料]]。<sup>[36–40]</sup> 然而，这些吸附剂在不同程度上存在局限性，例如[[吸附动力学|动力学]]缓慢、容量低、对短链 PFAS 效果不佳、稳定性差或[[可回收性|可重复使用性]]有限。开发能够同时克服这些局限性的新型吸附剂具有迫切需求。

[[金属-有机笼|金属–有机笼]]（[[MOC|MOCs]]）<sup>[41–43]</sup> 是一类离散的金属超分子胶囊，由有机配体与金属离子或金属簇组装而成。其明确空腔的[[主客体化学]]使其具有广泛的应用，包括[[分子识别]]、<sup>[44]</sup> [[分离]]、<sup>[45–49]</sup> 活性物种稳定化<sup>[50]</sup> 和[[催化]]。<sup>[51–59]</sup> [[金属有机笼|MOCs]] 作为[[磺酸]][[客体]]受体的报道较为零星，<sup>[60–64]</sup> 其中四链 $\mathrm { P d } _ { 2 } \mathrm { L } _ { 4 }$ 螺旋体最为丰富。<sup>[65–71]</sup> 通过配体变换，已构建多种 $\mathrm { P d } _ { 2 } \mathrm { L } _ { 4 }$ 笼，并证明其能够通过[[氢键]]相互作用以及疏水和/或 [[π–π相互作用|π–π 相互作用]]结合单磺酸根和双磺酸根阴离子。然而，这些笼与磺酸客体的结合模式通常较为简单。对多种[[磺酸盐]]——尤其是双磺酸盐和[[三磺酸盐]]——在亲和性和结合化学计量上具有丰富变化的高阶络合，尚未见报道。此外，与 [[金属-有机框架|MOFs]] 和 [[共价有机框架|COFs]] 相比，将固态 MOCs 用作从水中捕集 [[全氟和多氟烷基物质|PFAS]] 的[[吸附剂]]是近年才出现的发展方向，目前仅有少数研究可供参考。<sup>[29–35]</sup> 用于此目的时，MOCs 的一个显著优势是其溶解性，这使得能够在分子水平上研究主客体相互作用。然而，MOCs 对 [[全氟烷基物质|PFAS]] 的[[吸附性能]]明显劣于 MOFs 和 COFs，尤其是在[[吸附容量]]和[[可回收性]]方面。

在这项工作中，我们报道了一种基于 Zr 的四面体配位笼（1），其具有高度正电荷（16+）以及空腔封闭性和结构稳定性。该笼以四个[[三吡啶鎓]]单元作为面，从而提供了一个内腔，该内腔经过精确设计，带有酸性 C−H 质子，可用于[[氢键]]相互作用。这种[[十六阳离子笼]]与多种[[磺酸]]根阴离子表现出高阶络合作用，且在结合亲和力、化学计量比和[[客体]]交换[[吸附动力学|动力学]]方面各不相同。特别是，它可以在其受限空腔内聚集两个或三个二磺酸根/三磺酸根。进一步的研究还表明，笼 1 与全氟烷基磺酸根之间存在强[[静电相互作用|静电]]和氢键相互作用，且 1 的固体形式可作为快速、选择性且高容量的[[吸附剂]]，用于从水中去除全氟磺酸根。

## 2.2. [[磺酸]]根阴离子的高阶络合

一系列脂肪族和芳香族单/多[[磺酸]]根阴离子（图2，以钠盐形式）被研究作为$\mathbf { 1 - B A r _ { F } }$的潜在[[客体]]。

我们首先探索了三种[[烷基单磺酸盐]]（G1–G3）的络合。在向$\mathbf { 1 - B A r _ { F } }$的$\mathrm { C D } _ { 3 } \mathrm { O D }$溶液中滴加G1（丁烷-1-[[磺酸盐]]）时，<sup>1</sup>H [[核磁共振|NMR]]谱图显示笼信号的逐渐位移，尤其是质子${ \mathrm { H } } _ { 2 } { \mathrm { - H } } _ { 5 }$，表明在400 MHz和298 K下，NMR时间尺度上存在[[快交换]]结合（支持信息图S33）。与游离G1相比，低浓度下G1的峰表现出显著的高场位移。随着浓度增加，这些峰经历逐渐的低场位移。这些观察结果与多芳香笼对结合[[客体]]的屏蔽效应一致。重要的是，在滴加G1后，$\mathbf { 1 - B A r _ { F } }$最初较宽的峰变得尖锐且清晰，证明了客体的稳定[[模板作用]]。使用[[BindFit]]<sup>[87]</sup>对滴定数据进行分析表明，结合最可能以1:1化学计量比发生，[[结合常数]]为$8 . 7 \times$ 10<sup>2</sup> M<sup>−1</sup>（支持信息图S33；表1）。然而，由于1与G1的外围/表面相互作用而可能存在的其他[[结合化学计量比]]也不能完全排除。将G2（己烷-1-[[磺酸]]盐）和G3（辛烷-1-磺酸盐）滴加到$\mathbf { 1 - B A r _ { F } }$中揭示了类似的结合现象（支持信息图S34和S35），且结合常数相当（表1）。结果表明，主客体络合几乎不依赖于链长，而是由磺酸根头基主导，后者使客体与笼之间产生[[静电相互作用|静电]]和[[氢键]]相互作用。

芳基二/[[三磺酸盐]][[客体]] G11（[[萘-2,7-二磺酸盐]]）、G12（[[萘-1,3,6-三磺酸盐]]）和 G13（[[8-羟基芘-1,3,6-三磺酸盐]]）也与[[主体]] 1 形成 1:1 和 1:2 的[[主客体复合物]]，并具有[[慢交换]][[吸附动力学|动力学]]（图 3c,d；支持信息图 S45，针对 G11；图 3e,f；支持信息图 S48，针对 G12；支持信息图 S49，针对 G13）。逐步[[结合常数]]显示 $K _ { \mathrm { a 1 } } / K _ { \mathrm { a 2 } } <$ 4（表 2），表明双重结合事件具有[[正协同性]]。协同性在 G11 中最为明显，其表现出相近的 $K _ { \mathrm { a 1 } }$ 和 $K _ { a 2 } \ ( 4 . 0 \mathrm { v s } 4 . 6 \times 1 0 ^ { 4 } \mathrm { M } ^ { - 1 } )$ 。

值得注意的是，1 中最多可容纳三个双阴离子[[客体]]，这由 G14（[[苯-1,3-二磺酸盐]]）和 G15（[[萘-1,5-二磺酸盐]]）观察到的 1:1、1:2 和 1:3 [[主客体复合物]]的逐步形成所证实（图 3g–j；支持信息图 S43 和 S46）。[[DOSY NMR]] 谱表明，在笼腔内结合一个、两个或三个客体的主客体复合物表现出相同的[[扩散系数]]（支持信息图 S44 和 S47）。1:3 复合化对应于腔体内六个负电荷的聚集。三个 G14 或 G15 客体的总体积估计为 486 或 618 Å<sup>3</sup>，分别占据 1 腔体体积的 45% 或 58%。比较五个基于萘的客体，G5 和 G6（异构[[单磺酸盐]]）、G11 和 G15（异构[[二磺酸盐]]）以及 G12（[[三磺酸盐]]），1 的客体结合行为（[[吸附动力学|动力学]]、亲和力和化学计量）对[[磺酸]]基团的数量和客体的几何形状十分敏感。

为深入理解结合相互作用，我们以代表性[[客体]] G14 为例，在 [[GFN2-xTB]] 理论水平上对 1 与客体形成的 1:1、1:2 和 1:3 [[主客体复合物]]进行了建模。计算结果表明，在所有这些模型中（图 4；支持信息图 S91），二[[磺酸]]客体通过离子和多重[[氢键]]相互作用结合在笼的开放棱边内。每个磺酸头基与[[吡啶鎓]]或相邻[[亚苯基]]的酸性质子形成三个 [[C-H···O氢键|C─H···O 氢键]]（H···O 距离在 2.0–2.4 Å 范围内），客体的芳基核心则嵌入 1 的空腔中。因此，四面体每条棱上的“Y”形[[结合口袋]]允许对至少带有两个磺酸基的客体分子进行多方位锚定。棱边处的结合显著缩短了该棱边周围相邻[[三吡啶鎓配体]]之间的间距，其 $\mathrm { H } _ { 5 } { \cdots } \mathrm { H } _ { 5 }$ 距离为 6.1–6.4 Å（自由笼为 8.8 Å）。因此，G14 在该棱边处充当阴离子缓冲剂，最大限度地减小了阳离子面之间的排斥，并稳定了高度阳离子化的笼。该棱边结合模型允许每个四面体笼最多容纳六个 G14 阴离子。然而，实验结果表明，G14 最多结合三个双阴离子。我们推断，空腔内已结合阴离子之间的位阻和[[静电相互作用|静电]]排斥不利于容纳超过三个客体。

## 3. 结论

总之，我们设计并合成了一种十六阳离子[[锆基金属有机笼|锆基金属–有机笼]]（1）。缺电子[[三吡啶鎓]]面板与稳定 $\mathsf { { C p } } _ { 3 } \mathsf { { Z r } } _ { 3 } \mathsf { { O } } ( \mathsf { { O H } } )$ 3 顶点的结合赋予了 1 一个高度阳离子化且稳定的框架，能够通过协同的[[静电相互作用|静电]]和[[氢键]]相互作用结合[[磺酸盐]][[客体]]。该笼表现出[[电荷选择性]]结合行为：[[单磺酸盐]]在 [[核磁共振|NMR]] 化学位移时间尺度上通过[[快交换]][[吸附动力学|动力学]]结合，而[[二磺酸盐]]和[[三磺酸盐]]则形成具有[[慢交换]]动力学的高阶配合物，在空腔内实现最多六个负电荷的聚集。值得注意的是，固态 $\mathbf { 1 - N O } _ { 3 }$ 作为[[磺酸]]类 [[全氟和多氟烷基物质|PFAS]] 修复的优异[[吸附剂]]脱颖而出，对 [[全氟辛基磺酸盐|PFOS]] 表现出 1603 mg $\mathbf { g } ^ { - 1 }$ 的显著[[吸附容量]]。[[分子模拟]]揭示了四面体边缘 $\mathbf { \Delta ^ { * } Y ^ { \gamma } }$ 形[[结合口袋]]的重要性，它们能够锚定磺酸根头基。快速的动力学、优异的选择性、对短链和长链磺酸类 [[全氟烷基物质|PFAS]] 的高效去除能力以及[[可回收性|可重复使用性]]，使 1 成为一种有前景的[[水处理材料]]。

这项工作展示了如何通过精确设计的高电荷[[金属有机笼]]（[[MOC|MOCs]]），实现对[[磺酸盐]]识别和环境修复的前所未有的控制。通过在单一空腔中实现多个阴离子的络合，本研究揭示了[[限域空间]]内电荷聚集与协同结合的新原理。同时，这也增强了[[金属-有机笼|MOCs]]处理[[持久性环境污染物]]的能力，为下一代材料应对污染挑战铺平了道路。
