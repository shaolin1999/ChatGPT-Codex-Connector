## ■ 引言

电催化[[硝酸盐电还原制氨反应|硝酸盐还原反应]]（[[一氧化氮|NO]] RR）用于氨$\left( \mathrm { N H } _ { 3 } \right)$合成通过将$\mathrm { N O _ { 3 } } ^ { - }$修复与$\mathrm { N H } _ { 3 }$回收耦合，并有潜力绕过高能耗的热合成，为可持续氮循环提供了一条有前景的途径。<sup>1−3</sup> 然而，其效率取决于$\mathrm { N O _ { 3 } } ^ { - }$活化与[[活性氢|活性氢物种]]的及时生成和有效利用之间的匹配。<sup>4−6</sup> 尽管铜（[[铜|Cu]]）基催化剂能有效活化$\mathrm { N O } _ { 3 } { } ^ { - }$，但由于活性氢供应与消耗之间随施加电位变化而失配，$\mathrm { N H } _ { 3 }$的[[法拉第效率]]（FE）在整个电位窗口内仍不理想。<sup>7−10</sup> 在低过电位下，缓慢的水解离限制了活性氢的可用性，从而使反应路径停滞在[[亚硝酸根|亚硝酸盐]]等[[中间体]]$\big ( \mathrm { N O } _ { 2 } ^ { - } \big ) . ^ { 1 1 - 1 3 }$。尽管在高过电位下活性氢可用性增强，但活性氢[[吸附]]较弱、界面氢传递效率低以及含氮中间体加氢的固有能垒较高，共同有利于[[析氢反应|析氢路径]]，导致竞争性电流消耗和[[氨|NH]]生产法拉第效率降低。<sup>14−17</sup> 因此，实现活性氢物种的同步生成、传递和利用，是突破铜基催化剂用于${ \mathrm { N O } } _ { 3 } { } ^ { - }$向$\mathrm { . N H } _ { 3 }$转化性能瓶颈的核心。

迄今为止，以[[电子调控]]为主的主流策略，包括[[合金化]]<sup>18−23</sup>和[[异质结工程]]，<sup>24−28</sup>可以分别加速水分解或优化[[中间体吸附]]，但仍无法在宽电位范围内调控[[活性氢]]行为，导致${ \mathrm { N O _ { 3 } } } ^ { - } { \cdot } { \mathrm { t o } } { \cdot } { \mathrm { N H } } _ { 3 }$转化性能提升有限。对${ \mathrm { N O } } _ { 3 } { } ^ { - }$还原为$\mathrm { N H } _ { 3 }$的有效[[选择性]]控制，需要设计一种能够动态协调活性氢生成、传输和利用的催化剂微环境。这一需求指向[[水凝胶]]，尤其是[[聚丙烯酸钠]]（[[PANa]]）水凝胶，作为一个有前景的平台，因为它们能够构建一个富水、[[氢键]]结合且动态自适应的界面

微环境，这本质上适合介导界面氢相关过程。<sup>29−31</sup> 具体而言，[[水凝胶|PANa 水凝胶]]具有三维网络、密集[[羧基|羧基官能团]]和强亲水性，可富集[[界面水]]并促进其活化以生成[[活性氢|界面活性氢]]物种。同时，这些氢物种与羧基和受限水分子共同构建了一个互连的[[氢键|氢键网络]]，通过[[Grotthuss机制|类 Grotthuss 机制]]实现快速质子耦合氢转移，确保氢在界面上的高效传输，从而维持活性氢的持续供应。<sup>32−35</sup> 与此同时，网络内的氢键位点与[[中间体|含氮中间体]]相互作用，稳定活性物种并将界面氢导向目标加氢路径，<sup>36−38</sup> 从而在统一的界面微环境内同步实现活性氢的生成、传输与利用。

作为概念验证，我们制备了一种自支撑的 [[铜|Cu]]@[[PANa]]/[[泡沫铜|CF]] 催化剂，其特点是泡沫铜负载的[[铜纳米阵列]]表面包覆了一层薄薄的 [[水凝胶|PANa 水凝胶]]。该催化剂表现出优异的 $_ \mathrm { N O } _ { 3 } \mathrm { R R }$ 性能，并保持较高的[[法拉第效率|FE]] $\mathrm { N H } _ { 3 }$ 在[[宽电位窗口]]下保持90%以上 $\left( - 0 . 1 \ \mathrm { t o } \ - 0 . 6 \ \mathrm { V } \right)$ vs [[可逆氢电极|RHE]]），在−0.3 V vs RHE时达到98%的峰值。在低过电位区域，Cu@[[聚丙烯酸钠|PANa]]/CF表现出 $\mathrm { N H } _ { 3 }$ 产率约为裸 Cu/CF 的两倍，同时具有优异的[[循环稳定性]]。机理分析表明，由 PANa 建立的[[氢键|氢键网络]]起到了主调控作用。首先，它构建了界面微环境以富集水并促进其活化，从而确保[[活性氢]]的高效生成与稳定。其次，它[[选择性]]地稳定了 $^ { * } \mathrm { N O } _ { 2 } \mathrm { H }$ [[中间体]]，直接降低了[[决速步骤]]的[[吉布斯自由能|吉布斯自由能差]] (ΔG) $( ^ { * } \mathrm { N O } _ { 2 } \to ^ { * } \mathrm { N O } _ { 2 } \mathrm { H } )$ . 这两种功能的协同作用使 $\mathrm { N O _ { 3 } } ^ { - }$ 优先遵循加氢反应 路径，从而在热力学和动力学上同时抑制副反应，实现宽电位范围内选择性的$\mathrm { N O _ { 3 } } ^ { - } \mathrm { t o } \mathrm { N H _ { 3 } }$转化。该工作确立了界面氢键微环境工程作为一种策略，用于激活催化剂表面的活性氢，从而在质子耦合的复杂催化体系中实现精准的选择性调控。

## [[氢键|氢键网络]]双重作用的计算见解

为了揭示[[铜|Cu]]@[[PANa]]/[[泡沫铜|CF]]上电催化$\mathrm { N O _ { 3 } } ^ { - }$还原为$\mathrm { N H } _ { 3 }$活性与[[选择性]]增强的原子尺度起源，我们开展了系统的[[第一性原理计算]]。[[自由能]]分析表明，两种催化剂遵循相同的逐步加氢路径（图5a、S41和S42）。相应的能量曲线确定$\ast _ { \mathrm { N O } _ { 2 } }$加氢生成$\mathrm { \mathrm { ^ { * } N O } } _ { 2 }$ H为[[决速步骤]]（图5b）。值得注意的是，该步骤在Cu@[[聚丙烯酸钠|PANa]]/CF上计算得到的$\Delta G$（0.20 eV）显著低于$\mathrm { { C u } / }$ CF（0.51 eV），证实PANa修饰有效促进了这一关键加氢过程。电子结构分析进一步揭示了其内在机制。在$\mathrm { * _ { N O _ { 2 } H } }$[[吸附]]后，[[电子局域函数]]（ELF）图显示出$\mathrm { * } _ { \mathrm { N O _ { 2 } \bar { H } } }$[[中间体]]与PANa[[羧基|羧酸根]]氧之间存在特征性的电子局域桥（图5c），为[[氢键]]的存在提供了直接的电子学证据。 键合。<sup>67,68</sup> 对于其他反应中间体，包括 $\mathrm { \ast } _ { \mathrm { N H } _ { 2 } \mathrm { O } }$ 和 ${ } ^ { * } \mathrm { N H } _ { 2 } \mathrm { O H }$（图 S43），也观察到类似特征，表明 PANa 与沿反应坐标的多个中间体之间存在广泛的[[氢键网络|氢键相互作用]]。[[电荷密度差]]（图 S44）和 [[Bader 电荷]]（图 S45）分析表明，PANa 修饰仅影响与 PANa 直接配位的 Cu 原子的电荷，而大多数其他 Cu 位点几乎不受影响。因此，Cu@PANa/CF 活性的增强并非源于金属中心的[[电子调控]]，而主要来自 PANa 构建的氢键网络，该网络稳定了关键中间体并降低了决速步骤的 [[吉布斯自由能|ΔG]]。

此外，理论计算阐明了[[析氢反应|HER]]是如何被抑制的（图S46和S47）。与[[铜|Cu]]/[[泡沫铜|CF]]相比，Cu@[[PANa]]/CF在[[界面水]]行为和[[活性氢]]管理方面实现了三重协同优化，包括更强的水[[吸附]]、促进的界面水离解以及将生成的活性氢稳定在更有利的吸附态中。具体而言，$_ { \mathrm { H } _ { 2 } \mathrm { O } }$在$\mathrm { C u ( \bar { \omega } P A N a / C F \ ( \bar { - } 1 . 1 5 \ { e V } ) }$上的吸附能显著低于在$\mathrm { C u } / \mathrm { C F } \left( - 0 . 5 0 \ : \mathrm { e V } \right)$上的吸附能，表明其捕获水分子的能力显著提高（图5d）。$_ { \mathrm { H } _ { 2 } \mathrm { O } }$在Cu@[[聚丙烯酸钠|PANa]]/CF上离解的能垒为$0 . 3 4 \ \mathrm { e V } ,$，远低于在Cu/CF上的能垒（1.14 $\mathrm { e V } )$），表明[[氢键|氢键相互作用]]可促进$_ { \mathrm { H } _ { 2 } \mathrm { O } }$离解动力学（图5e）。同时，离解氢的去向在两种催化剂之间存在根本差异（图5f）。在$\mathrm { C u } / \mathrm { C F } ,$上，H优先占据Cu空位，并具有适中的$\Delta G$用于 \[[吸附氢原子|*H]] $( \Delta \dot { G } _ { * \mathrm { H } } )$ 为 0.38 $\mathrm { e V , }$，有利于 $\mathrm { H } _ { 2 }$ 的生成，从而与 $\mathrm { N O } _ { 3 } \mathrm { R R }$ 竞争。相比之下，在 Cu@PANa/CF 上，活性氢被稳定在 PANa 的 O 位点上，使 H 耦合不利于发生 $( \Delta G _ { ^ { \scriptstyle * } \mathrm { H } } = - 1 . 8 2 \mathrm { e V } )$ 因此，界面反应路径被重新导向，不再走向活性氢复合与 $\mathrm { H } _ { 2 }$ [[脱附]]，而是促进活性氢的优先保留，以用于电催化 $\mathrm { N O } _ { 3 } \mathrm { \overline { { \Omega } } }$ 还原为 [[氨|NH]] 的后续加氢步骤。

基于这些计算，我们揭示了[[铜|Cu]]@ [[PANa]]/[[泡沫铜|CF]]高性能的原子尺度双功能机制。[[聚丙烯酸钠|PANa]]在与Cu的界面上构建的[[氢键|氢键网络]]显著降低了 $\Delta G$ 的速率决定步骤 $( ^ { * } \mathrm { N O } _ { 2 } ^ { - } \to ^ { * } \mathrm { N O } _ { 2 } \mathrm { H } )$ 通过稳定关键[[中间体]]来实现。同时，定制的界面微环境促进了水的解离以生成[[活性氢]]，同时强烈稳定活性氢并引导其优先进入 $\mathrm { N O } _ { 3 } \mathrm { \cdot }$ <sup>−</sup> 加氢路径。与[[水凝胶]]相结合的双重策略在热力学和动力学上协同抑制了[[析氢反应]]（HER），最终使活性氢能够高效且有[[选择性]]地进行转化 ${ \mathrm { N O } } _ { 3 } ^ { - }$ 转化为 [[氨|NH]]<sub>3</sub>。

## ■ 结论

总之，我们提出并验证了一种界面[[氢键|氢键网络]]赋能策略，用以提升铜催化剂在电催化中的[[选择性]] ${ \mathrm { N O } } _ { 3 } { \mathrm { ^ - } } { \mathrm { - } } { \mathrm { t o } } { \mathrm { - } } { \mathrm { N } } { \mathrm { H } } _ { 3 } .$ 通过在……上构建一个 [[PANa]] 层 $\mathbf { C u } ,$ 所得的 [[铜|Cu]]@[[聚丙烯酸钠|PANa]]/[[泡沫铜|CF]] 实现了 $\mathrm { N H } _ { 3 }$ 在[[宽电位窗口]]下[[法拉第效率|FE]]超过90%，最高达到98%。 $\mathrm { a t } - 0 . 3 \mathrm { ~ V ~ }$ vs [[可逆氢电极|RHE]]，同时提供约 2 倍更高的 $\mathrm { N H } _ { 3 }$ 产率高于裸露 $\mathrm { { C u / C F } }$ 在低过电位下。原位红外光谱揭示了积累受到抑制的 $\ast _ { \mathrm { N O } _ { 2 } }$ -相关[[中间体]]并加速中间体转化，表明存在更高效的连续加氢路径。与此一致，结合自由基捕获实验的电化学测量表明，[[水凝胶]]赋予 Cu 的界面微环境促进了[[活性氢]]的生成及其优先用于硝酸盐还原而非竞争性副反应，从而抑制了非主路径的自由基过程。[[第一性原理计算]] 进一步指出，[[氢键网络]]增强了关键中间体的稳定性，从而降低了$\Delta G$[[决速步骤]]的$\mathrm { N O } _ { 3 } \mathrm { R R } ,$，同时增强了[[界面水]]的[[吸附]]并促进其解离，进而在热力学和动力学上抑制了 [[析氢反应|HER]]。总体而言，这项工作凸显了水凝胶赋能的界面活性氢化学作为超越传统[[电子调控]]的有效策略，为多步质子耦合电催化反应中的选择性控制提供了一种可推广的方法。
