# 通过[[木质素]][[碳化聚合物点]]实现[[高熵层状氢氧化物]]的[[异质界面工程]]，用于高效[[抗生素去除|广谱抗生素去除]]

## 摘 要

利用天然具有芳香结构的[[木质素]]开发[[碳化聚合物点]]（carbonized polymer dots，[[CPDs]]），为调控[[量子态碳核]]与[[聚合物杂化壳层]]的多样化结构提供了一种可持续的蓝图。为突破纯 CPDs 的局限，构建与[[高熵层状氢氧化物]]（high-entropy layered hydroxides，[[HELHs]]）高度相容的体系，是改性 CPDs 表面结构与功能以用于[[水体修复|水修复]]的一条可行但充满挑战的方向。在此，我们报道了[[杂原子掺杂]]的[[木质素基碳化聚合物点|木质素 CPDs]]，其对 [[铁|Fe]]<sup>3+</sup> 和 [[铜|Cu]]<sup>2+</sup> 离子表现出高度敏感且具有[[选择性]]的[[结合能]]力，从而促进其与 HELHs 快速、稳定地[[配位作用|配位]]。得益于其可调控的[[电荷转移]]特性，将 CPDs [[插层]]至 HELHs 中能够增大[[层间距]]、提高[[电子电导率]]、增加暴露的[[活性位点|反应位点]]并促进[[传质]]，从而构建用于降解[[抗生素]]的高性能[[过一硫酸盐]]（peroxymonosulfate，PMS）活化剂。[[CPDs-HELHs 复合材料]]对[[磷酸氯喹]]（[[CQP]]）、[[四环素]]（TC）、[[土霉素]]（OTC）和[[卡马西平]]（CBZ）的降解率均超过 95%，并表现出优异的[[反应动力学]]、离子抗干扰能力、强劲的耐久性及实际水体适应性。机理研究表明，CPDs 有利于[[界面电子穿梭|界面直接电子穿梭]]和[[单线态氧]]的生成，从而引导以[[非自由基过程]]为主导的反应路径，进而提高[[类芬顿反应]]的[[催化剂稳定性|稳定性]]和效率，实现[[抗生素去除|广谱抗生素去除]]。本研究确立了一种可行的、通过[[异质界面工程]]实现的木质素优先原则，以推动可持续[[水净化]]，将[[生物质]]与环境领域的认识衔接至[[碳中和]]未来。

## 1. 引言

石油基循环经济的快速发展加剧了水环境中[[有机污染物]]和/或[[重金属]]的共存，对全球生态系统和人类健康构成严重威胁 [1]。开发可与多功能材料兼容的可持续[[碳化聚合物点]]（carbonized polymer dots，[[CPDs]]）已成为[[水净化|废水净化]]领域的新兴前沿 [2–4]。[[木质素]]是一种天然储量丰富的[[芳香族生物聚合物]]，具有独特的 [[π共轭结构|π 共轭结构]]和较高的碳含量（≥ 60 wt%），正日益被用于制备直径小于 10 nm 的 CPDs。这些源自[[生物质|可再生生物质]]的 CPDs 具有可调控的光电转移、快速荧光响应 [5]、生物相容性 [6] 以及[[催化活性|活性]][[表面化学]]特性（例如[[酚羟基]] [[羟基|−OH]]、[[羧基|−COOH]] 和[[羰基]]）[6,7]，可方便地进行定制以用于催化。CPDs 的发光主要源于共轭 π 域和[[表面态]]，使其能够通过荧光猝灭和/或增强途径，实现[[选择性|高选择性]]和[[灵敏度|高灵敏度]]的[[金属离子]]结合 [8–10]。[[过渡金属离子]]（例如 [[铁|Fe]]<sup>3+</sup> 和 [[铜|Cu]]<sup>2+</sup>）可与 CPDs 表面的[[含氧官能团|含氧基团]][[配位作用|配位]]，促进其与[[层状氢氧化物]]等金属基[[复合材料]]形成稳定的[[插层结构]]和/或组装体。

在[[复杂废水]]环境中（例如[[溶解性有机物]]或离子浓度较高的环境），胶体 [[CPDs]] 抗干扰能力不足是阻碍其实际应用的关键局限。值得注意的是，[[高熵层状氢氧化物]]（high-entropy layered hydroxides，[[HELHs]]）是一类具有前景的[[氧化还原催化剂]]，集成了多种金属[[活性位点|反应位点]]。利用 HELHs 的[[高熵结构]]可影响其固有的[[晶格畸变]]，从而有效调控其[[电子结构]] [11]，启动协同的[[电子转移|多路径电子转移]]，使其在[[类芬顿反应]]中表现出优异的[[催化活性]]和[[催化剂稳定性|稳定性]] [12]。HELHs 的[[多价态金属活性位点]]有望加速[[氧化剂]]（例如[[过一硫酸盐]] PMS）的高效活化，促进[[有机污染物]]的高效、广谱降解 [12,13]。然而，受限的[[传质]]通道、不可避免的[[金属偏析]]以及较低的电荷传导能力阻碍了 HELHs 的实际应用，这些问题导致活性位点分布不均，并表现出缓慢的[[吸附]]和[[电子传输]]过程 [14]。为应对这些挑战，亟需对 HELHs 的[[氧非键合态]]和晶格畸变进行调控，以抑制[[金属失活]]，通过使具有优化电子结构的[[多原子活性位点]]和[[缺陷活性位点]]均匀分布来增强结构稳定性，从而促进类芬顿反应活性 [15,16]。[[碳化聚合物点|CPDs]] 表面的含氧和含氮官能团 $( e . g . , - \mathrm { C O O H } , - \mathrm { O H }$ 和 [[氨基|–NH₂]]）能够与各种[[金属离子]]发生特异性相互作用，例如[[配位作用]]和[[静电吸引]]。CPDs 与金属离子之间的强相互作用为设计多功能[[异质界面|催化异质界面]]提供了契机。已有研究表明，CPDs 与[[催化活性金属中心]]（例如 [[铁|Fe]]、${ \mathrm { c o } }$ 和 [[镍|Ni]]）之间的强耦合可有效调控金属的电子结构，并优化其对 PMS 等氧化剂的活化能力，从而提高[[高级氧化过程]]的效率 [17,18]。CPDs 可与[[层状双氢氧化物]]中的[[金属位点]]形成 [[金属氮碳键|M-N-C 键]]，构建稳定的异质界面，促进[[电荷转移|界面电荷转移]]，并提高催化剂的稳定性和活性 [17,19]。CPDs 与金属离子之间的配位行为（诱导聚集和/或触发荧光猝灭）[20] 也揭示了界面相互作用对其性质的影响。因此，将 CPDs 引入 HELH [[复合材料]]被认为是一种重构其几何结构和物理化学性质的有前景的策略。凭借高[[电子迁移率]]和可调的[[表面官能团]]，[[生物质]]衍生 CPDs 有望兼具强效金属黏合剂和电子桥梁的双重功能，将 HELHs 结合起来，并优化界面间距和电子结构。[[CPDs-HELHs 复合材料]]的层间通道和电子调控有利于提高其在类芬顿反应中的催化活性和稳定性 [17,21]。

可见，为了在广谱[[抗生素]][[水净化|废水净化]]中实现[[催化活性|活性]]与[[催化剂稳定性|稳定性]]的最佳权衡，仍需解决可持续 [[CPDs]] 辅助[[复合材料]]的合理结构设计及其界面相互作用机制问题。在此，我们简便地制备了具有绿色发光特性的[[杂原子掺杂]][[木质素基 CPDs]]，其对 $\mathrm { F e } ^ { 3 + }$ 和 $\mathrm { { C u } ^ { 2 + } }$ 离子具有高度灵敏且[[选择性]]强的[[结合能]]力，从而促进其与 [[HELHs]] 快速、稳定地[[配位作用|配位]]，实现高效的[[类芬顿反应|类芬顿催化反应]]。由于 [[碳化聚合物点|CPDs]] 固有的[[电荷转移]]特性，将其固定于 [[高熵层状氢氧化物|HELHs]] 中不仅扩大了[[层间距]]（例如，加快[[传质]]），还增加了暴露的[[活性位点]]并提高了[[电导率]]。因此，[[CPDs-HELHs 复合材料|CPDs-HELHs]] 能够广谱降解[[磷酸氯喹]]（[[CQP]]）、[[四环素]]（TC）、[[土霉素]]（OTC）和[[卡马西平]]（CBZ），效率超过 95%（即使在 60 mg $\mathrm { L } ^ { - 1 } )$ 的高含量下，[[污染物去除率|去除率]]仍超过 80%。该体系还表现出优异的[[反应动力学]]性能和稳定性、[[抗离子干扰能力]]，以及对实际水体的强大适应性。CPDs 充当电子桥，促进界面电荷转移，从而引导 [[PMS活化|PMS 活化]]转向以非自由基为主导的路径，并优化[[抗生素去除|广谱抗生素去除]]的稳定性。本研究开创了一种切实可行的[[木质素]]优先策略，以推进可持续[[水体修复]]，同时衔接[[生物质]]驱动的[[碳中和]]环境技术。

## 2. 材料与方法

使用前，将纯化后的[[木质素]]置于 $6 0 ~ ^ { \circ } \mathrm { C }$ 的干燥箱中干燥 72 h。所有化学试剂均为分析纯，未经进一步纯化即使用（支持信息 S1.1）。通过简便的酸解处理，随后在 $2 0 0 ^ { \circ } \mathrm { C }$ 下进行 12 h 的常规水热反应，提取出具有绿色荧光的[[木质素基 CPDs]]（支持信息 S1.2）。将 2% [[CPDs]] 与金属前驱体混合于 50 mL 超纯水中，通过水热法合成[[异质结构]] [[CPDs-HELHs 复合材料]]，其中金属前驱体包括 $\mathrm { N i - , F e - , C u - , C o - , }$ 和摩尔量为 0.45 mmol 的 [[锰|Mn]] 盐。作为对照，采用相同方法，在不添加 [[碳化聚合物点|CPDs]] 的条件下制备原始 [[HELHs]]（支持信息 S1.3）。分析了 [[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs]] 的形貌、微观结构、元素组成、[[表面化学]]态及电化学性质，以评估其在类芬顿[[抗生素降解]]中的性能（支持信息 S2）。

## 3. 结果与讨论

## 3.1. [[木质素]]的基本结构与 [[CPDs]] 的理化表征

图 1a 全面展示了整体实验流程。我们首先对工业木质素进行硝酸氧化，并通过水热处理制备出发绿光的 CPDs，其具有选择性金属离子结合能力，可触发快速荧光猝灭。得益于优异的金属离子配位性能，CPDs 可在 $1 2 0 ~ ^ { \circ } \mathrm { C }$ 下经 6 h 的简便溶剂热合成过程中嵌入 HELHs 的层间，从而通过类芬顿反应实现抗生素的催化降解。已有研究发现，碳负载可重构 HELHs 的电子密度结构，并优化其表面的直接电子转移，这归因于碳的高导电性和电子活性 [2,22–24]。M-N-C 相互作用充当高速电子通道，增强界面电荷转移动力学，从而提升其本征活性。如图 1b 所示，所引入的 CPDs 作为高效电子汇，可参与稳定 HELHs，从而调控其电子结构、扩大层间距，并优化传质和电子传输性能 [21]。这些协同作用最终使其催化性能远超单独的 HELHs。

需要注意的是，[[木质素]]结构能够改变 [[CPDs]] 的[[表面态]]和 $s p ^ { 2 } / s p ^ { 3 }$ 杂化构型。通过简便的酸性氧化裂解（[[氮掺杂|N 掺杂]]）及随后的溶剂热反应，木质素转化为 [[碳化聚合物点|CPDs]] 的拟议机制如图 1c 所示。该过程始于木质素的酸解裂解，其中浓硝酸作为强效硝化剂和[[氧化剂]]，[[选择性]]地破坏单元间连接键（例如 [[β-O-4醚键|β-O-4]] 和 [[α-O-4醚键|α-O-4 醚键]]以及 [[碳碳键|C–C 键]]）。这种氧化碎裂产生了含有多种含 O 和 N 物种的木质素中间体。随后，溶剂热处理通过增强 $s p ^ { \hat { 2 } }$ 杂化和快速 π–π 堆积促进芳构化，最终促使 CPDs 碳化成核，并在其表面引入丰富的 [[碳氮键|C–N 基团]]。木质素的[[苯丙烷结构]] $( e . g . ,$，[[愈创木基]] $\mathbf { G } ,$ [[紫丁香基]] S、[[对羟基苯基单元]]，H）及其天然官能团 $( e . g . , - 0 \mathrm { C H } _ { 3 } , - 0 \mathrm { H }$ 和 [[羧基|–COOH]]）从根本上决定了 CPDs 的[[碳骨架]]和[[表面化学]]性质。这些固有结构特征直接调节 CPDs 内部的杂化状态 $( s p ^ { 2 } / s p ^ { 3 }$ 碳比例）和缺陷密度，从而影响其电子和光学性质。采用定量 $^ { 1 3 } \mathrm { P }$ NMR 光谱法测定木质素原料中[[含氧官能团|含氧基团]]的丰度。丰富的[[酚羟基]]（TP-OH，2.4013 mmo $g ^ { - 1 } )$、羧基（–COOH，1.5695 mmol ${ \mathbf g } ^ { - 1 } )$ 和[[脂肪族羟基]]（A-OH，1.503 mmol $g ^ { - 1 } )$ 赋予木质素反应[[催化活性|活性]]，使其能够将[[活性位点|反应位点]]引入 CPDs 中（图 1d）。缩合亚单元的存在表明，木质素在后续水热过程中具有结构重构的可能性。木质素的官能团分布确保了 CPDs 的表面功能性，进而决定其光物理特性。此外，木质素的平均分子量（重均 $- M _ { \mathrm { w } }$ 为 2835 g mol<sup>−</sup> <sup>1</sup>，数均 Mₙ 为 940 g mol<sup>−</sup> <sup>1</sup>）也决定了 CPDs 的最终尺寸和[[核壳结构|核壳构型]]。木质素的这种固有异质性（PDI，3.02）表明，可合成具有可调光学性质和纳米尺度的 CPDs（图 1e）。

在 [[CPDs]] 的傅里叶变换红外（[[FTIR]]）光谱（图 2a）中，位于 \~3300–3500 和 $1 6 8 0 ~ \mathrm { { c m } ^ { - 1 } }$ 归属于 O–H 伸缩振动和 $\scriptstyle \mathrm { C = } 0$ 分别对应于伸缩振动，是[[羧基]]或[[羰基]]的特征振动。它们是表征 [[碳化聚合物点|CPDs]] 表面酸性和[[金属离子]][[配位作用|配位]]能力的重要指标 $\scriptstyle ( s p ^ { 2 } \ C = \mathbf { C }$ 振动 $\mathrm { a t } \sim 1 4 6 0 ~ \mathrm { c m } ^ { - 1 }$ 和 $\mathrm { ~ C ~ - ~ } 0$ 在拉伸时， $\sim 1 2 1 5 \mathrm { c m } ^ { - 1 } )$ . CPDs 具有丰富的羧基（–COOH）和强[[供电子基团]]（[[羟基|–OH]] 和 [[氨基|–NH₂]]），这些基团源于原始[[木质素]]及后续的酸性氧化改性 [8–11,29]。[[亲水性官能团|亲水基团]]的强[[吸附]]作用显著提高了其在水介质中的[[分散性]]。因此，我们推测 [[HELHs]] 与 CPDs 之间能够形成[[氢键]]（O–H⋅⋅⋅O/N 或 N–H⋅⋅⋅O），从而有助于提高界面[[催化剂稳定性|稳定性]]。[[碳氮键|C–N]] 和 [[碳碳键|C–C 键]]的伸缩振动证实了多芳香结构的形成，以及含 N 官能团的引入 在水热碳化成核过程中 CPDs 的[[碳骨架]]。CPDs 的 X 射线光电子能谱（[[XPS]]）全谱在 \~285.0 eV（C 1 s）、400 eV（N 1 s）和 532.0 eV（O 1 s）处呈现特征峰（图 2b）。高分辨率 C 1 s 谱经解卷积分解为四个组分，分别位于 \~285.1 eV $\scriptstyle ( \mathbf { C } = \mathbf { C } / \mathbf { C } - \mathbf { C } ) ,$、285.8 eV（C–N）、286.4 eV（C–O）和 288.9 eV（C––O）[12,13]（图 S1a）。N 1 s 谱中的两个峰可拟合为 \~400.1 eV（N–(C)₃）和 401.8 eV（N–H）[6,15]（图 S1b），而 O 1 s 谱可分解为三个组分，分别位于 \~531.5 eV（C=O）、532.5 eV（[[硝基|–NO₂]]）和 533.2 eV（C–O）[16]（图 2c）。[[X射线光电子能谱|XPS]] 结果表明，含 C、N 和 O 的表面基团对其特定的光物理化学性质至关重要。

已有研究表明，荧光 [[CPDs]] 具有显著的[[金属离子]][[结合能]]力，有利于与 HELEs 形成强[[配位作用]] [19,30]。在多种金属离子存在的情况下，水溶液中的 [[碳化聚合物点|CPDs]] 表现出对 $\mathrm { F e } ^ { 3 + }$ 和 $\mathrm { C u ^ { 2 + } }$ 的双重识别能力，荧光猝灭率超过 85%，表明其具有出色的[[灵敏度]]和[[结合亲和力]]（图 2d）。随着 $\mathrm { F e } ^ { 3 + }$ 和 $\mathrm { { C u } ^ { 2 + } }$ 浓度的增加，观察到绿色发光强度减弱的剂量依赖性荧光猝灭行为。定量分析表明，对 $\mathrm { F e } ^ { 3 + }$ 离子（0–500 μM）的检测性能优异，具有线性相关性，检测限（LOD）为 0.703 μM（图 3e 和 $\mathbf { f } ) ,$，而与 ${ \mathrm { C u } } ^ { 2 + }$ 离子（100–500 μM）配位时则呈现单一线性关系（图 3h 和 i）。[[静电吸引]]和[[螯合动力学]]赋予 CPDs 对特定金属离子的显著亲和力。我们认为，$\mathrm { F e } ^ { 3 + }$ 和 $\mathrm { { C u } ^ { 2 + } }$ 离子作为[[交联]]介质，直接与[[表面官能团]]（如 [[羧基|–COOH]]、[[羟基|–OH]] 和 –NH）配位，从而促进 CPDs 随后的聚集和发光减弱。荧光强度与浓度之间优异的线性相关性源于激发态 CPDs（[[电子供体]]）与金属离子（[[电子受体]]）之间的[[电子转移]] [20]。官能团、量子尺寸效应、$s p ^ { 2 } / s p ^ { 3 }$ 杂化和表面缺陷之间的相互作用主导了[[光诱导电子转移]]和[[选择性]]光致发光猝灭。CPDs 表面丰富的含 N、O 官能团（如 $\mathrm { - c o o H , - o H }$ 和 –NH<sub>2</sub>）也有利于通过荧光猝灭形成稳定的 [[金属氧配位|M–O 配位]]，从而增大 [[HELHs]] 的[[层间距]]（图 2g）。如图 2j 所示，纯 HELEs 的微花结构由超薄氢氧化物层组装而成。多种金属元素（即 [[铁|Fe]]、[[钴|Co]]、[[锰|Mn]]、[[镍|Ni]] 和 [[铜|Cu]]）的均匀分布也证实了其与 CPDs 的选择性结合能力（图 2k）。CPDs（图 S2）和 [[高熵层状氢氧化物|HELHs]]（图 S3）的 [[XPS]] 结果证实，[[CPDs-HELHs 复合材料]]的表面结合化学发生了轻微转变。

## 3.2. [[CPDs-HELHs 复合材料]]的物理化学性质

采用 [[CPDs]] 和[[金属盐前驱体]]（如 [[铁|Fe]]、[[钴|Co]]、[[锰|Mn]]、[[镍|Ni]] 和 [[铜|Cu]]），通过[[一锅水热法]]制备了 [[CPDs-HELHs 复合材料]]。[[CPDs-HELHs复合材料|CPDs-HELHs 复合材料]]的 [[SEM]] 图像表明，其保持了由[[纳米片]]组装而成的[[花状形貌]]，表面光滑且边缘清晰（图 3a）。[[X射线衍射|X 射线衍射]]（[[XRD]]）证实，所制备的 [[HELHs]] 具有[[类水滑石结构|六方类水滑石结构]]。引入 [[碳化聚合物点|CPDs]] 后，由于[[无定形态|无定形]] CPDs 的[[掺杂量]]较低，[[高熵层状氢氧化物|HELHs]] 的[[晶体结构]]保持不变（图 3b）。[[透射电子显微镜|TEM]] 图像证实了 [[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs 复合材料]]中完整的纳米片结构，表明 CPDs 的引入并未破坏 HELHs 的晶体骨架（图 3c）[17]。与纯 HELHs（图 S4）相比，CPDs 的负载有利于通过[[原位碳化]]诱导的[[重结晶]]引导 HELHs 的[[晶格生长]] [17,25]。除[[高熵金属元素]]的清晰分布图外，C、N 和 O 元素的存在也证实了 CPDs 已负载于微米尺度的 HELHs 中（图 S5）。CPDs 作为[[碳源]]，通过[[表面官能团]]（如 [[羧基|–COOH]]、[[羟基|–OH]] 和 –NH<sub>2</sub>）与 HELHs 中的[[金属位点]][[配位作用|配位]]。这些相互作用降低了[[表面能]]，促进[[金属离子]]有序重排，从而提高了[[晶格完整性]] [31,32]。清晰的[[晶格条纹]]所对应的[[晶面间距]]分别为 \~0.201、0.219 和 0.263 nm，分别对应于 CPDs-HELHs [[复合材料]]的 (012) [21]、(015) [33] 和 (003) [31] [[晶面]]。由于 CPDs 填充了 HELHs 内部的[[晶格空位|空位]]和[[畴边界]]，[[缺陷钝化]]减轻了[[晶格畸变]]，并提高了原先无序区域的[[结构有序性]] [28]。此外，CPDs 的高[[电导率]]有助于在 TEM [[电子束照射]]下快速[[电荷耗散|耗散积累的电荷]] [34]，减少电子敏感的 HELHs 中由电子束诱导的[[晶格损伤]]和[[辐照分解]] [35]。CPDs 的 ${ \bar { s p } } ^ { 2 } .$ ‑碳结构提高了复合材料的[[热导率]]，从而减轻局部升温引起的[[晶格振动]] [36]。CPDs 与 HELHs 的 (012) 晶面之间发生[[范德华外延生长]]，促进了 HELHs 的[[定向结晶]] [37]。

[[XPS]] 全谱分析表明，[[CPDs]] 的引入使 [[HELHs]] 中金属元素的[[结合能]]发生系统性正移（图 3d），其中 [[铁|Fe]] 2p 约增加 0.2 eV（图 3e）、[[钴|Co]] 2p 约增加 0.35 eV（图 3f）、[[锰|Mn]] 2p 约增加 0.6 eV（图 3g）、[[镍|Ni]] 2p 约增加 0.05 eV（图 3h），[[铜|Cu]] 2p 约增加 0.15 eV（图 3i）。这主要源于[[界面电子重分布|界面电子重新分布]]和[[化学态]]调变 [37,38]。[[碳化聚合物点|CPDs]] 上的[[吸电子官能团]]（如 [[羧基|–COOH]] 和 –C––O）通过新形成的 [[金属—氧—碳键|M–O–C 键]]吸引来自[[金属位点]]（即 $e _ { \cdot , }$ Fe、Co、Mn、Ni 和 Cu）的[[电子云]]，降低金属原子核周围的[[电子屏蔽效应]]，从而提高[[有效核电荷]]。$\mathrm { s } p ^ { \bar { 2 } } .$ ‑碳基质（属于 $\mathrm { C P D } s ,$）的[[电导率|导电性]]进一步促进了这一[[电子转移]]过程，该基质通常充当[[电子受体]]。[[异质界面]]处金属物种的部分氧化（例如 $\mathbf { C o } ^ { 2 + }  \mathbf { C o } ^ { 3 + } )$ 可缩短 [[金属—氧键|M–O 键]]，从而增强对内层电子的[[库仑吸引]]。异质界面的电荷重新分布引发电子从碳相向[[金属氢氧化物]]转移，从而优化[[活性位点|反应位点]]的 [[d带中心|d 带中心]]，显著降低[[反应能垒]]。[[电子耗减]]、[[氧化态]]升高和[[晶格应变]]共同促成了结合能的正移。因此，如图 3j 所示，我们推测 CPDs 与 HELEs 基底之间可能通过[[范德华力]]、[[配位作用|金属配位]]、[[阳离子–π相互作用|阳离子–π 相互作用]]和[[氢键|氢键相互作用]]结合。

## 3.3. [[CPDs-HELHs复合材料|CPDs-HELHs 催化剂]]的[[抗生素降解]]性能

凭借优异的[[催化活性|活性]]、[[催化剂稳定性|稳定性]]和[[分散性]]，[[CPDs-HELHs复合材料|CPDs HELHs 复合材料]]在[[催化降解]]典型药物 [[CQP]] 方面展现出巨大潜力。随着 [[CPDs-HELHs 复合材料|CPDs-HELHs]] [[催化剂用量]]从 0 逐渐增加至 250 mg $\mathbf { L } ^ { - 1 }$，[[磷酸氯喹|CQP]] [[污染物去除率|去除率]]从 \~11% 提高至 99.9%（图 4a）。当 [[过一硫酸盐|PMS]] 浓度为 0–250 mg $\mathrm { L } ^ { - 1 }$ 时，CQP 去除率从 5% 提高至 99.9%（图 4b）。通过计算相应的[[反应动力学常数]] $( k , \operatorname* { m i n } ^ { - 1 } )$，进一步验证其[[催化性能]]，结果表明，在最佳催化剂用量为 100 mg $\mathbf { L } ^ { - 1 } \left( \mathrm { F i g } , 4 \mathbf { d } \right)$ 时可实现快速[[反应动力学]]。值得注意的是，当 PMS 用量为 200 mg $\mathrm { L } ^ { - 1 }$ 时，[[反应速率常数|k 值]]达到最大值 0.1226 min<sup>−</sup> <sup>1</sup>（图 4e），表明 [[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs]] 的[[活性位点]]接近饱和。该浓度处于已报道文献中常见的 1–3 mmol $\mathrm { L } ^ { - 1 }$ 范围内（表 S1）。[[CPDs]] 的引入使 CQP [[降解效率]]提高了 21% $( { \mathrm { F i g . ~ } } 4 \mathbf { c } ) _ { \mathrm { : } }$，而 k 常数从 0.0265 显著增加至 0.1266 $\operatorname* { m i n } ^ { - 1 } { ( \mathrm { F i g } , 4 \mathbf { f } ) } .$ ，这归因于通过 [[碳化聚合物点|CPDs]] 的[[表面化学]]增强了[[电子转移]]并促进了[[缺陷位点]]的形成。在[[共轭π结构域|共轭 π 结构域]]和特定[[杂原子官能团]]存在的情况下 $( e . g .$ 、[[石墨型氮|石墨型 N]] 和 $- \mathrm { C } { = } 0 )$ ，它们可作为反应位点，稳定地[[吸附]]并[[PMS活化|活化 PMS]]。此外，由高度有序的[[共轭碳骨架]]构成的电子高速通道有利于电子沿延伸的 $\mathsf { s p } ^ { 2 } .$ ‑碳。界面处加速的[[电子传输]]促进了 [[过一硫酸盐活化|PMS 活化]]，有助于加快整体反应动力学，从而提高[[难降解污染物]]的降解效率 [39]。浓度、[[pH]] 环境、[[共存阴离子]]及实际水体的差异，对提高[[抗生素去除]]效率构成了重大挑战。如图所示， $\mathrm { F i g } .$ . 4g 和 j，k 值达到 $0 . 1 1 2 6 \mathrm { \ m i n } ^ { - 1 }$ 在弱酸性条件下（pH 为 $5 \mathrm { - } 6 ) _ { \cdot }$ 表明略高于 [[抗生素降解]]效率高于中性环境（pH 为 7，k 为 $0 . 0 4 7 7 \ \mathrm { m i n } ^ { - 1 } )$ 。[[HELHs]] 的[[表面质子化|质子化表面]]增强了对[[阴离子型抗生素]]的[[静电吸引]]，从而提高反应物的吸附量和局部浓度。在 pH 为 11 时，CQP 去除效率降至 \~52.8%，k 值较低，为 $0 . 0 0 6 6 \ \mathrm { m i n } ^ { - 1 }$ 。酸性条件有利于 PMS 的稳定及其分解生成[[硫酸根自由基]] $( S O _ { 4 } ^ { \bullet - } )$ ，而[[质子化金属位点]]（M[[羟基|–OH]]₂<sup>+</sup>）有助于生成[[单线态氧]] $( ^ { 1 } 0 _ { 2 } )$ 。实际水体中高浓度的典型阴离子会对基于自由基的[[高级氧化过程]]（AOPs）产生严重不利影响。在高浓度（10 mM）常见阴离子 $( e . g . , \mathrm { { F } ^ { - } , \mathrm { { S O } _ { 4 } ^ { 2 - } , \mathrm { { C l } ^ { - } } } }$ 、CH COO<sup>−</sup>、H PO<sup>−</sup> 和 $H \mathrm { C O } _ { 3 } ^ { - } \bar { ) } ,$ 存在的条件下，由于[[界面电子缓冲池|界面“电子缓冲池”路径]]的作用，CQP 去除效率超过 85%（图 4h）。因此，我们推测 CPDs-[[高熵层状氢氧化物|HELHs]] 体系突出体现了[[非自由基反应路径|非自由基路径]]（例如，[[直接电子转移]]和/或单线态 氧气 $^ 1 ( ) _ { 2 } )$ 以处理[[复杂废水]]中的[[抗生素]]。即使 CQP 浓度高达 60 mg $\mathrm { L } ^ { - 1 }$，CPDs-HELHs 催化剂仍能保持 >80% 的降解效率（图 4i）。如图 4k 所示，其在实际水环境中也表现出 \~95% 的显著适应性 基质，包括[[去离子水]]、[[自来水]]和[[河水]]。值得注意的是，CPDs-HELHs 催化剂对 CQP、[[四环素|TC]]、[[土霉素|OTC]] 和 [[卡马西平|CBZ]] 具有广谱去除能力，去除效率超过 95%（图 4l）。即使在 40–100 mg $\mathrm { L } ^ { - 1 }$ 的高浓度下，仍能保持可接受的降解效率，并在 60 mg $\operatorname { L } ^ { - 1 } \left( \operatorname { F i g } . \operatorname { S 6 } \right)$ 下实现普遍超过 80% 的去除率。

此外，所制备的 [[CPDs-HELHs复合材料|CPDs-HELHs 催化剂]]即使在连续四次反应循环后，仍能保持 \~95% 的高[[降解效率]]（图 4m）。这种出色的[[催化剂稳定性|稳定性]]不仅证实了 [[CPDs-HELHs 复合材料]]的界面稳定作用和间隔作用，也凸显了 [[CPDs]] 在加速[[电子转移|电子传递]]和[[传质]]方面的功能作用。值得注意的是，[[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs]] 对广谱[[抗生素]]（如 [[CQP]]、[[四环素|TC]]、[[土霉素|OTC]] 和 [[卡马西平|CBZ]]）的[[污染物去除率|去除效率]]明显优于其他已报道的催化剂（图 4n 和表 S2），且具有更优的[[反应动力学]]性能（表 S3）。为评估降解中间产物的生物毒性，对浸泡于不同水源中的小麦幼苗的表型特征进行了为期三天的观察（图 S7）。我们发现，与纯 [[磷酸氯喹|CQP]] 溶液（20 mg $\mathrm { L } ^ { - 1 } )$ 相比，植物种子在经 [[碳化聚合物点|CPDs]]-[[HELHs]]/[[过一硫酸盐|PMS]] 处理的 CQP 溶液中呈现出良好的萌发和生长趋势。毒性评估表明，CPDs-[[高熵层状氢氧化物|HELHs]]/PMS 催化体系在降低 CQP 生物毒性方面具有有效性和可行性。通过将 CPDs 锚定于 HELEs 上，本研究实现了“稳定的高熵骨架”与“强健的[[活性位点|反应位点]]”的[[异质界面]]整合，从而通过高效[[PMS活化|活化 PMS]]，为持久且普适的[[抗生素去除]]提供支持。

开展自由基淬灭实验，以确定[[催化活性|活性]]氧物种（ROS）在 [[CPDs-HELHs 复合材料|CPDs-HELHs]]/[[过一硫酸盐|PMS]] 体系中的参与情况。采用四种具有代表性的、用量为 10 mmol $\mathrm { L } ^ { - 1 }$ 的淬灭剂，包括甲醇（MeOH）、叔丁醇 $( \mathrm { T B A } ) , p \cdot$ -苯醌（PBQ）和 L-组氨酸（L-His），分别[[选择性]]清除 $\mathrm { S O _ { 4 } ^ { * - } / ^ { \bullet } O H , \bullet _ { O H , } O _ { 2 } ^ { \bullet - } }$ 和 $^ 1 { \cal O } _ { 2 } ,$。如图 5a 所示，MeOH 的抑制作用最弱，而 PBQ 和 L-His 的抑制作用最强，表明 $S O _ { 4 } ^ { \bullet - }$ 和 <sup>•</sup>OH 的作用相对较小，而 $\mathrm { O } _ { 2 } ^ { \bullet - }$ 和 $^ 1 0 _ { 2 }$ 是 [[CQP]] 分解的主要贡献者。通过对效率和 [[反应动力学常数|k 值]]进行比较分析，推断出 ROS 的作用贡献顺序为 $( ^ { 1 } \mathrm { O } _ { 2 } > \mathrm { O } _ { 2 } ^ { \bullet - } > ^ { \bullet } \mathrm { O H } > \mathrm { S O } _ { 4 } ^ { \bullet - } )$。[[CPDs-HELHs复合材料|HELHs-CPDs 复合材料]]的高效率与高熵电子离域密切相关。引入 [[CPDs]]，作为 [[HELHs]] 离域电子体系中可调控的“电子阀门和定向通道”。通过识别目标污染物，[[碳化聚合物点|CPDs]] 上官能团的电子态引导 HELH 界面处的离域电子沿特定反应路径迁移（例如，优先[[PMS活化|活化 PMS]] 以生成 $^ 1 ( ) _ { 2 } )$。电子顺磁共振（EPR）直接证实了[[类芬顿反应]]过程中 ROS 的生成。使用 5,5-二甲基-1-吡咯啉-N-氧化物（DMPO）和 2,2,6,6-四甲基-4-哌啶酮（TEMP），捕获到强度各异的 $\cdot _ { \mathrm { O H / S O _ { 4 } } } { \bullet - }$（图 5b）、$\mathrm { O } _ { 2 } ^ { \bullet - }$（图 5c）和 $^ 1 0 _ { 2 }$（图 5d）的明显信号，这也表明四类 ROS 的反应活性存在差异。根据电化学测量结果推测，[[磷酸氯喹|CQP]] 的[[非自由基反应路径|非自由基降解]]可能通过 CPDs [[高熵层状氢氧化物|HELHs]] 与 PMS 之间的[[直接电子转移|直接电子穿梭]]进行。如图 5e 所示，我们提出，PMS [[吸附]]在 [[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs]] 上形成 PMS\* 中间体，从而提高 CPDs-HELHs 的表面电势，诱导 CQP 发生阳极氧化。开路电势的变化以及线性扫描伏安法（LSV，I-t 曲线）测试进一步支持了这一观点（图 5f）。加入 PMS 后，电势从 0.1879 V 急剧升高至 0.5854 $\mathrm { v , }$，随后在引入 CQP 后下降。这表明 CPDs-HELHs 表面形成了高电势 PMS 络合物。随后加入氧化还原电势较低的 CQP，引发氧化还原反应，使 PMS 络合物分解，导致电势明显下降 [40]。电流响应中的类似趋势进一步支持 CPDs-HELHs 可通过直接[[电子转移]]（DET）路径表现出显著的去除能力。HELHs 中的多价态金属（例如 $\mathrm { C o } ,$ [[铁|Fe]] 和 [[锰|Mn]]）可通过电子转移[[过一硫酸盐活化|活化 PMS]]，生成自由基。因此，CPDs-HELHs [[复合材料]]通过以非自由基路径（DET 和 $^ 1 0 _ { 2 } )$ 为主、较弱自由基路径为辅的协同机制活化 PMS。

如图 5g 的循环伏安（CV）曲线所示，[[CPDs-HELHs 复合材料|CPDs-HELHs]] 的电子给体能力得到增强的直接电化学证据得以呈现，而这一能力是其[[催化性能]]提升的关键。[[碳化聚合物点与高熵层状氢氧化物复合材料|CPDs-HELHs]] 的氧化峰电位 $\left( \operatorname { E } _ { O X } \right)$ 移至 0.486 $\mathrm { v , }$，低于 [[HELHs]] 的氧化峰电位（0.545 V）。这一约 60 mV 的偏移表明氧化过程的能垒降低，说明与纯 [[高熵层状氢氧化物|HELHs]] 相比，[[CPDs]]-HELHs 更易引发氧化反应。这一构效关系证实，[[碳化聚合物点|CPDs]] 能够精细调控金属配合物的氧化还原性质。CPDs-HELHs 的恒电流充放电（GCD）曲线显示，其电压窗口显著拓宽，充放电时间明显延长（图 5h），表明其具有优异的电化学[[催化剂稳定性|稳定性]]和电荷存储能力。相似的电流变化趋势也证实，所制备的 CPDs-HELHs 通过非自由基 [[直接电子转移|DET]] 途径降解 [[CQP]] 的能力相当可观。

我们介绍了 [[CQP]] 在（非）自由基攻击下，经 N-脱同系化、脱氨和夺氢等反应降解的可能路径（图 5i）[41–48]。在路径 1 中，[[磷酸氯喹|CQP]] 首先在叔胺的 N 原子处发生脱乙基反应，生成 $\mathrm { C _ { 1 6 } H _ { 2 2 } C l N _ { 3 } } .$ 由于 $1 7 ( \mathrm { N } )$ 及其相连的 16(C) 的化学双描述符（chemical dual descriptor，CDD）值为负，$\mathrm { { C } - N }$ 键容易在自由基攻击和夺氢反应下断裂，生成 $\mathrm { C } _ { 1 4 } \mathrm { H } _ { 1 5 } \mathrm { C l N } _ { 2 } .$ 随后，连接仲胺与侧链碳原子的 C − N 键断裂，生成 $\mathrm { C } _ { 9 } \mathrm { H } _ { 7 } \mathrm { C l N } _ { 2 } ,$，其喹诺里西啶环可经脱氨反应生成 C<sub>9</sub>H<sub>6</sub>ClN。在路径 2 中，CQP 经侧链脱甲基、夺氢以及侧链 11(N) 位点的键断裂，生成 $\mathrm { C } _ { 9 } \mathrm { H } _ { 7 } \mathrm { C l N } _ { 2 }$ 和 $\mathrm { C _ { 9 } H _ { 1 9 } N }$，随后进一步氧化，生成 $\mathrm { C } _ { 6 } \mathrm { H } _ { 1 5 } \mathrm { N } , \mathrm { C } _ { 9 } \mathrm { H } _ { 1 9 } \mathrm { N O }$ 和 $\mathrm { C } _ { 7 } \mathrm { H } _ { 1 5 } \mathrm { N } .$ 在路径 3 中，CQP 经脱甲基、夺氢以及侧链 11 (N) 位点的键断裂，生成 ${ \mathrm { C } } _ { 6 } { \mathrm { H } } _ { 1 5 } { \mathrm { N } } .$ 喹啉环与仲胺以及 $\mathbf { a s } ,$ 其所连接的侧链直接分离，生成 $\mathrm { C _ { 9 } H _ { 6 } C l N }$ 和 ${ \mathrm { C } } _ { 9 } { \mathrm { H } } _ { 2 2 } { \mathrm { N } } _ { 2 }$，自由基将 $\mathrm { C } _ { 9 } \mathrm { H } _ { 2 2 } \mathrm { N } _ { 2 }$ 氧化，生成 ${ \mathrm { C } } _ { 5 } { \mathrm { H } } _ { 1 1 } { \mathrm { N O } } _ { 2 } .$ 总体而言，这些中间产物可进一步分解为胺类和羧酸等低分子量化合物，最终矿化为 $\mathrm { H } _ { 2 } \mathrm { O } , \mathrm { C O } _ { 2 } ,$ NO<sub>3</sub><sup>−</sup> 和 NH<sub>4</sub><sup>+</sup>。这些令人信服的降解路径验证了性能稳健的 [[CPDs-HELHs 复合材料|CPDs-HELHs]] 在多种场景下去除 CQP 的多功能性（图 5j），包括制药废水的简便预处理、在污水处理厂（WWTPs）中作为可调控催化剂以减少污染物向地表水的排放，以及仅需极少辅助设备的使用点饮用[[水净化]]（PDW）。

## 4. 结论

从具有[[苯丙烷结构]]的可再生[[木质素]]中制备[[表面功能化]] [[CPDs]]，是在即将到来的[[碳中和]]未来缓解能源–水–材料危机的一条有吸引力的途径。利用[[氮掺杂|掺 N]] 的[[木质素基 CPDs]] 作为快速[[荧光探针]]，以[[选择性|高选择性]]和[[灵敏度|高灵敏度]]结合 $\mathrm { F e } ^ { 3 + }$ 和 $\mathrm { { C u } } ^ { 2 + }$，进而通过[[表面基团调控]]，制备出具有优化[[电子结构]]和[[通道间距|通道间距结构]]的稳健 [[碳化聚合物点|CPDs]] 稳定化 [[HELHs]] [[复合材料]]。由于其独特的[[电荷转移]]特性，将 CPDs [[插层]]至 [[高熵层状氢氧化物|HELHs]] 中可有效提高[[电子电导率]]并增大[[层间距]]。这使 [[CPDs-HELHs 复合材料|CPDs-HELHs]] 能够通过暴露的[[氧化还原位点]]和加快的[[传质|传质过程]]，高效[[PMS活化|活化 PMS]] 以分解[[抗生素]]。所制备的 [[CPDs-HELHs复合材料|CPDs-HELHs 复合材料]]实现了对 [[CQP]]、[[四环素|TC]]、[[土霉素|OTC]] 和 [[卡马西平|CBZ]] 的高效降解，[[降解效率]]为 ${ \tt o f } > 9 5 \% ,$，即使在 $6 0 \mathrm { m g L } ^ { - 1 }$ 下也超过 80%。该材料还表现出优异的[[反应动力学]]（[[反应动力学常数|k 值]]为 0.1266 $\mathbf { m i n } ^ { - 1 } ) _ { : }$，[[抗离子干扰能力]] $( e . g . , ~ \mathrm { F ^ { - } } , ~ \mathrm { S O _ { 4 } } ^ { 2 - } , ~ \mathrm { C l ^ { - } } , ~ \mathrm { C H _ { 3 } C O O ^ { - } } ,$ $\mathrm { H _ { 2 } P O _ { 4 } ^ { - } }$ 和 HCO₃<sup>−</sup>）、[[循环稳定性]]（即使经过四次循环仍具有 \~95% 的高效率），以及对实际[[水体基质]]的良好适应性（例如 [[pH]] 为 3–9、[[自来水]]和[[河水]]）。CPDs 在[[复合材料–水界面]]充当高效的[[电子促进剂]]，引导反应朝着[[非自由基反应机制|非自由基主导的机制]]方向进行（[[直接电子转移|DET]] 和 $^ 1 0 _ { 2 } )$。这种通过合理的[[异质界面工程]]将可持续[[木质素基碳化聚合物点|木质素基 CPDs]] 固定于[[层状氢氧化物]]上的[[自下而上方法]]，为复杂水环境中抗生素的广谱[[催化去除]]提供了一条有前景的途径。
