## 补充实验部分

材料。[[十六烷基三甲基溴化铵|CTAB]]、[[白藜芦醇]]（Res）、[[2-甲基咪唑]]（2-MIM）和$\mathrm { N H } _ { 3 } { \cdot } \mathrm { H } _ { 2 } \mathrm { O }$（25%–28%）购自 [[Energy Chemical]]。[[正硅酸四乙酯|TEOS]] 和[[异硫氰酸荧光素]]（FITC）购自 [[Aladdin Reagents]]。Zn$( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$（99%）购自[[西陇科学股份有限公司]]。[[碘化丙啶]]（PI）购自[[苏州宇恒生物科技有限公司]]。[[磷酸盐缓冲液]]（PBS）购自[[北京酷来搏科技有限公司]]。[[次氯酸钠|次氯酸钠溶液]]购自[[广东光华科技股份有限公司]]。[[吐温80|吐温 80]] 购自[[上海麦克林生化科技有限公司]]。[[马铃薯葡萄糖琼脂]]（PDA）和 1/2 MS 培养基购自[[青岛海博生物技术有限公司]]。去离子水由 [[Milli-Q 系统]]制备，电阻率为$2 0 ~ ^ { \circ } \mathrm { C }$。[[灰葡萄孢]]（*B. cinerea*）野生型菌株 B05.10、[[核盘菌]]（*S. sclerotiorum*）菌株 AS4 和[[烟草]]植株（*Nicotiana benthamiana*）由[[吉林大学植物科学学院]]提供。所有材料和试剂均未经进一步纯化直接使用。

方法。[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）和[[透射电子显微镜]]（TEM）图像分别由 [[JEOL JSM 6700F]] 和 [[HITACHI HT7800]] 仪器拍摄。[[HAADF]] 图像、[[能量色散光谱]]（EDS）谱图和元素分布图使用 [[JEM F200]] 和 [[JED-2300T]] 仪器在 200 kV 条件下采集。粉末 X 射线衍射（[[粉末X射线衍射|PXRD]]）图谱在 [[Rigaku Smart Lab III]] 粉末衍射仪上记录。傅里叶变换红外（[[傅里叶变换红外光谱|FT-IR]]）光谱使用 [[Vertex 80 V]] 光谱仪获得。[[热重分析]]（TGA）在 [[STA 449]] 热重分析仪上于氮气气氛下对所有样品进行。[[紫外-可见吸收光谱|紫外−可见吸收光谱]]由 [[Shimadzu UV-1800]] 分光光度计记录。[[氮气吸附-脱附等温线]]在 [[Micromeritics Gemini]] 仪器上记录。[[共聚焦激光扫描显微镜]]（CLSM）图像由 [[Leica]] 共聚焦荧光显微镜拍摄。

[[中空介孔二氧化硅纳米粒子|HMSNs]] 的制备。HMSNs 的合成按照先前报道的 [[Stöber 方法]]进行，并稍作修改。首先，将 2 mL [[正硅酸四乙酯|TEOS]] 加入含有 85.6 mL 乙醇、12 mL 蒸馏水和 2 mL [[氨水]]溶液（25%–28%）的混合溶液中，所得混合物在$3 0 ~ ^ { \circ } \mathrm { C }$下搅拌 2 h。将所得固体$\mathrm { S i O } _ { 2 } \ ( \mathrm { s S i O } _ { 2 } )$重新分散于 100 mL 去离子水中，然后逐滴加入含有 750 mg [[十六烷基三甲基溴化铵|CTAB]]、150 mL 去离子水、150 mL 乙醇和 2.2 mL 氨水的溶液。室温下搅拌 30 min 后，向混合物中快速加入 1.25 mL TEOS，随后继续搅拌 4 h，得到${ \mathrm { s S i O } } _ { 2 } @ { \mathrm { C T A B } } -$$\mathrm { S i O } _ { 2 } .$。将 500 mg$\mathrm { s S i O } _ { 2 } @ \mathrm { C T A B - S i O } _ { 2 }$分散于 100 mL 去离子水中，随后加入 1.25 g${ \mathrm { N a } } _ { 2 } { \mathrm { C O } } _ { 3 } ,$，混合物在$5 0 ~ ^ { \circ } \mathrm { C }$下搅拌 24 h 以去除$\mathrm { s S i O } _ { 2 }$。最后，将产物分散于含有 200 mL 甲醇和 12 mL [[盐酸|HCl]]（36%–38%）的溶液中，在回流条件下搅拌 24 h，得到 HMSNs。

[[FITC 标记的 Res@HMSN@ZIF-8|FITC 标记的 Res@HMSN@ZIF-8 的制备]]。[[异硫氰酸荧光素|FITC]] 标记的 [[Res@HMSN@ZIF-8]] 采用类似的步骤制备。简言之，在搅拌下将 200 $\mu \mathrm { L }$ 的 0.1% FITC 乙醇溶液（w/v）加入到 9 mL [[2-甲基咪唑|2-MIM]]（1 g）水溶液中。然后将 [[Res@HMSN]]（50 mg）分散到上述混合溶液中。最后，在 5 min 内逐滴加入 1 mL $\mathrm { Z n ( N O _ { 3 } ) _ { 2 } { \cdot } 6 H _ { 2 } O }$（100 mg）水溶液。通过离心收集 FITC 标记的 [[白藜芦醇|Res]]@[[HMSN@ZIF-8]]，并用去离子水充分洗涤。

[[沸石咪唑酯骨架-8|ZIF-8]] 纳米颗粒和 [[异硫氰酸荧光素|FITC]] 标记的 ZIF-8 纳米颗粒的制备。ZIF-8 纳米颗粒参照已发表的方法并稍作修改进行合成。<sup>1</sup> 简言之，将含有 [[2-甲基咪唑|2-MIM]]（0.24 g）的 50 mL 甲醇溶液与含有 $Z _ { \mathrm { n } } ( \mathrm { N O } _ { 3 } ) _ { 2 }$ $\mathrm { 6 H } _ { 2 } \mathrm { O }$（0.372 g）的 50 mL 甲醇溶液混合，并在超声浴中于 $2 5 ~ ^ { \circ } \mathrm { C }$ 反应 20 min，以获得 ZIF-8 纳米颗粒。FITC 标记的 ZIF-8 纳米颗粒采用[[一锅法]]制备。将含有 FITC（1 mg）的 1 mL 乙醇溶液与含有 2-MIM（6 g）的 45 mL 乙醇溶液混合。然后，在 20 min 内将含有 [[硝酸锌|Zn(NO3)2·6H2O]]（0.372 g）的 5 mL 乙醇溶液逐滴加入上述溶液中。通过离心收集 FITC 标记的 ZIF-8 纳米颗粒，并用去离子水充分洗涤。

[[异硫氰酸荧光素|FITC]] 标记的 [[中空介孔二氧化硅纳米粒子|HMSNs]] 的制备。将合成的 HMSNs（50 mg）分散在含有 [[3-氨丙基三乙氧基硅烷|APTES]] $( 1 0 0 ~ \mu \mathrm { L } )$ 的 10 mL 乙醇溶液中，并在 $2 5 ~ ^ { \circ } \mathrm { C }$ 下搅拌 48 h。<sup>2</sup> 将所得的 HMSN-NH<sub>2</sub>（50 mg）和异硫氰酸荧光素（FITC，2 mg）分散在 20 mL 无水 [[N,N-二甲基甲酰胺|DMF]] 中，并在避光条件下搅拌 12 h。将 FITC 标记的 HMSNs 用乙醇充分洗涤，并在 $4 0 ~ ^ { \circ } \mathrm { C }$ 下真空干燥 24 h。

[[Res@HMSN@ZIF-8]] 的负载量。[[Res@HMSN]]@[[沸石咪唑酯骨架-8|ZIF-8]] 的负载量参照已有文献并稍作修改进行研究。<sup>3</sup> 为测定 [[白藜芦醇|Res]]@[[HMSN@ZIF-8]] 中负载的 Res 含量，收集离心后 Res@[[中空介孔二氧化硅纳米粒子|HMSN]]@ZIF-8 的洗涤液，并用甲醇溶液稀释（V:V = 1:1）。用 [[紫外-可见吸收光谱|UV−vis 光谱]]记录溶液的吸光度，并最终根据 [[Lambert-Beer 定律]]计算 Res@HMSN@ZIF-8 的负载量。

[[Res@HMSN@ZIF-8]] 对[[烟草]]的安全性评价。为评价 [[Res@HMSN]]@[[沸石咪唑酯骨架-8|ZIF-8]] 的安全性，参照已有文献并作适当修改，研究了 [[白藜芦醇|Res]]、[[HMSN@ZIF-8]] 和 Res@[[中空介孔二氧化硅纳米粒子|HMSN]]@ZIF-8 对烟草种子萌发的影响。<sup>3,</sup> <sup>4</sup> 烟草种子分别用 75% 乙醇和 2.5% [[次氯酸钠|次氯酸钠溶液]]消毒，并用无菌水充分洗涤。随后，将无菌烟草种子（每皿 30 粒）播种在分别含有 Res、HMSN@ZIF-8 和 Res@HMSN@ZIF-8 的 1/2MS 培养基（3 mL）浸湿的无菌滤纸上。以 1/2MS 培养基处理的烟草种子作为对照组。各处理浓度与盆栽试验相同，每个处理设三次重复。所有培养皿置于[[人工气候箱]]（25±1 °C，60% 湿度）中，前 2 天避光培养，随后在自然光周期下培养。10 天后，测定各处理组的发芽率、根长、茎长、鲜重和干重。

[[实时定量PCR|实时定量 PCR]]（[[qPCR]]）检测。提取的 RNA 用 [[DNase Ⅰ]]（[[生工生物工程（上海）股份有限公司]]）处理，以去除基因组 [[DNA]] 污染。随后使用 [[Maxima Reverse Transcriptase]]（[[Thermo Fisher Scientific|Thermo Fisher Scientific Inc.]]）进行反转录。qPCR 使用 [[SGExcel FastSYBR Mixture]]（生工生物工程（上海）股份有限公司）在 [[7500 Real-Time PCR System]]（[[Applied Biosystems]]，USA）上进行。以[[烟草]]持家基因（[[蛋白磷酸酶2A|蛋白磷酸酶 2A]]，[[PP2A]]）作为内参，用于标准化各基因的表达值。5-7 qPCR 中基因的相对表达水平采用 [[∆∆Cт 法]]计算，每组每个样品包含 3 个生物学重复。8 qPCR [[引物序列]]列于表 S4。
