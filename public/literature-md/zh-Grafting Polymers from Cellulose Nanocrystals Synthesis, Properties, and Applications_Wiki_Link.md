## 1. 引言

在过去三十年间，[[纳米材料]]在材料科学领域中发挥着日益重要的作用，如今已普遍存在于我们的日常生活中。<sup>1</sup> 纳米材料因其高[[BET|比表面积]]以及特定的结构特征，展现出有趣且往往独特的力学、光学和/或电子性能，而这些性能在微米和宏观尺度的对应材料中并不具备。基于[[纤维素]]的纳米晶体和纳米原纤已成为一类应用特别广泛的构建单元，被用于结构材料以及先进功能材料。<sup>2−8</sup> 纤维素是一种由β-<sub>D</sub>-脱水吡喃葡萄糖单元组成的线性同多糖，是地球上最丰富的有机聚合物，也是未来生产生物基材料和燃料的一种有前景的可再生资源。<sup>9</sup> 纤维素广泛存在于高等植物、被囊动物、藻类、真菌、细菌、无脊椎动物和变形虫等多种生物中。在自然界中，纤维素存在于层级结构的多组分材料中，这些材料在最低层级上包含以单轴有序（半）结晶组织形式排列的单个纤维素。通过精细的解离方法，可以获得[[纤维素纳米晶|纤维素纳米晶体]]（[[纤维素纳米晶体|CNCs]]）和[[纤维素纳米原纤]]（CNFs），其性能（如[[结晶度]]、形貌、[[长径比]]和表面化学性质）<sup>10</sup> 取决于其在[[纳米复合材料|聚合物纳米复合材料]]、[[胶体液晶]]、[[水凝胶]]及多重响应材料中的应用要求。<sup>2,8,11−14</sup>

[[纤维素纳米晶|CNCs]] 是棒状纳米颗粒，可从可再生生物来源中分离得到，具有高[[结晶度]]、可调[[长径比]]以及高刚度和强度。其典型尺寸为长度从 50 nm 到超过 1 μm，宽度为 5−50 nm，具体取决于原料来源。<sup>5,10</sup> 与许多其他纳米棒不同，[[纤维素纳米晶体|CNCs]] 在生理学上似乎具有良性。<sup>15−17</sup> CNCs 通常通过[[硫酸水解|强酸催化水解]]获得，其中最常用的酸是[[硫酸]]，该过程选择性降解宏观[[纤维素]]纤维的无定形区域，而结晶区域保持完整。使用硫[[酸水解]]还会在 CNCs 表面引入阴离子[[硫酸半酯|硫酸半酯基团]]，这些基团由于[[静电排斥]]作用而对其在水中的[[胶体稳定性]]至关重要。这种效应除了通常显示的[[热稳定性]]有限之外，还可能在它们自发组装成[[手性向列相]]（又称胆甾相）[[胶体液晶]]（LC）相中发挥重要作用；有限的热稳定性表现为在高温加工时出现明显变色，并对[[纳米复合材料|聚合物纳米复合材料]]的制备构成障碍。<sup>21,22</sup> 这一问题可以通过使用[[磷酸水解]]纤维素浆来克服，该方法所得 CNCs 具有低浓度的磷酸表面基团，并在极性溶剂中兼具足够的分散性与改善的热稳定性。<sup>21</sup> CNCs 的生产在加拿大、美国、以色列和瑞典等一些国家也已发展到工业规模，尽管仍处于发展阶段。<sup>23</sup>

[[纤维素纳米晶|CNC]] 表面还含有许多羟基（−OH）基团，这使得多种类型的[[表面修饰|化学修饰]]成为可能，并催生了广泛的[[纳米材料]]，其性质和功能涵盖从[[刺激响应性]]到抗菌能力等广泛范围。<sup>8,12</sup> 此外，表面化学修饰可将原本相当亲水的 [[纤维素纳米晶体|CNC]] 转变为疏水颗粒，从而促进其在疏水介质中的应用。<sup>24−26</sup> CNC 化学修饰的主要挑战之一，是在成功进行反应的同时不损害其固有性质，尤其是尺寸、[[结晶度]]和固有力学性能。<sup>7</sup>

通过[[接枝聚合]]进行的[[表面修饰]]已被证明是一种稳健的方法，其中部分物理和化学性质可以按需定制。<sup>4,27−29</sup> 表面接枝聚合可通过“[[接枝到]]”（grafting to）、“[[接枝自]]”（grafting from）或“[[接枝穿]]”（grafting through）方法实施。接枝穿方法包括用可聚合官能团（例如[[丙烯酸]]类基团）对固体基底进行官能化，随后进行[[原位聚合]]。接枝到方法涉及将预先形成的聚合物链通过反应性端基与表面连接，而接枝自策略则关注通过[[表面引发聚合]]使聚合物链生长，既可以由含有能够引发聚合反应的官能团的基底出发，也可以将活性引发剂物种固定到基底表面。由于接枝到方法常常遇到位阻问题，接枝自方法具有聚合物接枝长度可控且聚合物链拴接密度高的优势。

由于后一种策略已被广泛用于将 [[纤维素纳米晶|CNC]] 改性为多组分胶体，以及近来用于[[单组分纳米复合材料]]（OCNs）——其中不需要聚合物基体，且最终材料通常不会遭受相分离问题——这将成为本 Perspective 的重点（图 1）。我们的目的是对从 [[纤维素纳米晶体|CNC]] [[接枝聚合|表面接枝聚合]]物这一领域提供一个简明概述，同时突出自 2008 年 [[Habibi]] 等人开创性工作<sup>30</sup>以来过去十年中的一些值得注意的贡献；他们通过[[表面引发开环聚合]]（SI-[[开环聚合|ROP]]）从 CNC 上接枝了 [[ε-己内酯]]。在以下各节中，将描述 CNC 的物理化学性质、已知的从 CNC 表面接枝聚合物的各种[[表面修饰|化学修饰]]途径以及聚合物改性 CNC（CNC-g-polymer）的应用，并将讨论该领域中已出现的机遇与挑战。

## 2. [[纤维素纳米晶|CNC]] 的形貌与表面化学

[[纤维素]]纤维的半结晶性质——其中结晶区由强[[氢键|分子间和分子内氢键]]维系——赋予了其独特的力学性能，并且是高等植物初生细胞壁中经自然选择形成的主要结构组分。<sup>9</sup> 尽管由于其无序形态，从结构角度对其了解较少，但纤维素中非结晶区（即“无定形”区）被认为在植物水分输运方面具有优势。<sup>32</sup> 纤维素纤维的这种固有结构最终使纳米级结晶区能够通过[[硫酸水解|酸催化水解]]从宏观纤维中被选择性提取出来。因此，在进一步讨论用聚合物接枝改性 [[纤维素纳米晶|CNC]] 表面的方法之前，有必要首先讨论纤维素的结构、其结晶域以及制备 $\mathrm { C N C } s ,$ 的各种提取方法，这些方法会产生显著不同的表面化学性质和反应活性。

2.1. 形态。[[纤维素]]是由 [[β-D-脱水吡喃葡萄糖]]以 β(1−4′) 糖苷（醚）键连接而成的线性同多糖聚合物的通用名称。纤维素中重复的脱水吡喃葡萄糖单元（称为 $\mathbf { A } \mathbf { G } \mathbf { U } ) ^ { 3 3 }$）是 D-葡萄糖的六元闭环椅式构象，其异头碳（C1）处于 β 位（图 2）。<sup>34</sup> 不同 AGU 之间的 β(1−4′) 糖苷键

导致链长方向上产生扭转，这可由糖苷扭转角 $\phi =$ $\mathrm { H 1 - C 1 - O 4 ^ { \prime } - C 4 ^ { \prime } }$ 和 $\psi = \dot { \mathrm { C 1 - O 4 ^ { \prime } - C 4 ^ { \prime } - H 4 ^ { \prime } } } . ^ { 3 5 }$ 来定义。必须指出，这些角的定义在文献中并未标准化，因此比较不同来源报道的数值时需要考虑所使用的角定义。<sup>35−37</sup>

虽然 AGU 的环结构被限制在 C−O 键处于平伏位置的椅式构象中，但围绕 C5−C6 键可以自由旋转，从而使[[羟甲基]]相对于葡萄糖环呈现不同构象。羟甲基相对于吡喃葡萄糖环的位置可用角 $\chi = \mathrm { O } 5 \mathrm { - } \bar { \mathrm { C } } \bar { 5 } \mathrm { - } \bar { \mathrm { C } } \bar { 6 } \mathrm { - } \mathrm { O } 6$ 和 $\breve { \chi } ^ { \prime } \ = \ \mathrm { C } 4 \mathrm { - } \mathrm { C } 5 \mathrm { - } \mathrm { C } 6 \mathrm { - } \mathrm { O } \stackrel { \cdot } { 6 } . ^ { 5 , 3 8 }$ 来描述。当这两个角分别为 ${ { 6 0 } ^ { \circ } }$（邻位交叉-邻位交叉构象，gg）、$6 0 ^ { \circ } - 1 8 0 ^ { \circ }$（邻位交叉-反式，$g t )$）和 $1 8 0 ^ { \circ } - 6 0 ^ { \circ }$（反式-邻位交叉，[[玻璃化转变温度|tg]]）时，存在三个能量极小值。<sup>5,36,37</sup> 围绕 C5−C6 键的自由旋转以及由此产生的 O6 定位自由度，使得不同的[[氢键]]模式成为可能，包括在[[纤维素]]晶体中。<sup>37,39</sup>

直到最近，人们一直认为[[纤维素]]存在七种不同的[[同质异形体|晶体同质异形体]]： $\mathrm { I } _ { \alpha } , \mathrm { I } _ { \beta } , \mathrm { I I } , \mathrm { I I I } _ { \mathrm { I } } , \mathrm { I I I } _ { \mathrm { I I } } , \mathrm { I V } _ { \mathrm { I } } ,$ 并且 $\mathrm { I V } _ { \mathrm { I I } } .$ . 虽然[[纤维素II|纤维素 II]] 是热力学上最稳定的形式，但天然纤维素曾被认为以多种多晶型存在 $\mathrm { I } _ { \alpha }$ （存在于[[细菌纤维素]]和藻类中，三斜晶胞）以及 $\mathrm { I } _ { \beta }$ （高等植物，单斜晶胞）。<sup>40,41</sup> 然而，近年来[[核磁共振波谱|固态核磁共振波谱]]研究的结果表明，天然植物纤维素在结构上具有多晶型性，并且与 $\mathrm { I } _ { \alpha }$ 和 $\mathrm { I } _ { \beta } ,$ 七组独特的集合证实了这一点。 $^ { 1 3 } \mathrm { C }$ 化学位移。<sup>42,43</sup> 其中五组信号归属于微纤丝内部的纤维素链，两组归属于表面链，这种结构复杂性源于高等植物纤维素所特有的与基质多糖之间的相互作用。尽管如此，纤维素 $\mathrm { I } _ { \alpha }$ 已被发现处于亚稳态，并且可以部分转变为 $\mathrm { I } _ { \beta }$ 通过260°C以上退火 $^ \circ \mathrm { C }$ 或 用气体和有机溶剂处理。<sup>44−46</sup>纤维素 II 通过纤维素溶解后的再结晶获得，因而达到热力学最小值。其他同质异晶体则处于纤维素链高度规整[[氢键]]网络中的局部能量最低态。尽管某些同质异晶体具有平行链排列，而另一些为反平行链排列，但所有同质异晶体都呈现出一种伪 $2 _ { 1 }$ 纤维素链因链内氢键而形成的螺旋构象 $_ { \mathrm { O 3 H - O 5 ^ { \prime } } }$ 氢键。<sup>47</sup> 因此，任何纤维素晶体结构的破坏都可预期与这种链内氢键的破坏相关联，这一事实得到纤维素溶解时能够呈现[[无规共聚物|无规]]卷曲构象的支持。<sup>48</sup> 各种纤维素多晶型物具有独特的[[XRD|X射线衍射]]特征，与其结构中的空间晶体排列相对应。<sup>9</sup> 纤维素多晶型物的晶体堆积在晶胞尺寸上有所不同，并可能在链极性上表现出差异，从而导致纤维素性质的变化， 如刚性、[[热稳定性]]、溶解性或反应活性等性质。49

[[纤维素]]链由排列在质膜上的[[纤维素合酶复合体]]合成。该纤维素合酶复合体（CSC）产生宽度为 3−4 nm 的基本纤维素原纤。<sup>50</sup> 这些 CSC 位于生长中纤丝的末端。<sup>51,52</sup> CSC 可呈现不同形态：如藻类 [[Oocytis apiculata]] 中可见具有三列有序颗粒的结构，<sup>51</sup> 被囊动物及藻类 [[Valonia]] 和 [[Erythrocladia]] 中则为其他线性复合体，<sup>53</sup> 而在高等植物以及绿藻 [[Micrasterias]] 中，已报道存在一种六聚玫瑰花结复合体，包含六个颗粒，每个颗粒具有六个纤维素合酶。<sup>53,54</sup> 原纤排列成直径可达 20 nm 的半结晶微纤。<sup>55,56</sup> 结晶区与无定形区的比例以及结晶区中 I 型与 $\mathrm { I } _ { \beta }$ 的比例取决于纤维素的来源。5,7,39,57

[[纤维素纳米晶|CNC]]通常被表示为具有平行六面体或六边形截面的带状结构（图3）；其形状和单个[[纤维素]]分子的数量随纤维素来源的不同而有很大差异。长期以来，人们认为植物和细菌中的天然纤维素微纤丝由36条链组成，但近年来[[纤维素合酶复合体|CSC]]结构表征的进展表明，18条链模型可能是更准确的描述。<sup>58</sup> 另一方面，[[核磁共振波谱|固态NMR波谱]]实验表明，初生细胞壁纤维素微纤丝至少由24条链组成，这可能是由于相邻CSC合成的多根微纤丝发生了合并。<sup>42,59</sup> 天然纤维素微纤丝中纤维素链的精确数量仍然是一个备受争议的研究课题。

要评估表面反应活性，需要考虑表面基团并不像[[纤维素纳米晶|CNC]]内部的同类基团那样受到限制。事实上，<sup>13</sup>C固态[[核磁共振|NMR]]研究表明，朝向外侧的表面链上的[[羟甲基]]表现出与[[纤维素纳米晶体|CNC]]内部[[氢键]]结合的[[伯羟基]]（[[玻璃化转变温度|tg]]）不同的构象（gg）。<sup>38,60</sup> 还可以设想，羟甲基构象改变的能力将取决于溶剂对羟甲基与晶体表面其他基团之间氢键的干扰程度。

实验观察表明，天然棉及棉类（即亚麻、苎麻、剑麻和木材）[[纤维素]]的表面−OH基团表面反应活性遵循O2 > O6 > O3的顺序，而[[Valonia ventricosa]]纤维素的表面反应活性则遵循O6 > O2 > O3的顺序，这是因为其O3H与O5′H之间存在更高程度的分子内[[氢键]]，并且更高的结晶有序性导致O2H在结晶区内部因不可及性而绝对可用性降低（图2）。<sup>61</sup> 这可以进一步证实表面[[羟甲基]]基团的gg构象，因为在该构象中不可能形成分子内O2H−O6氢键。表面反应活性还需要考虑反应机理。在活化表面羟基后，O2位点在$\mathrm { \dot { S } } _ { \mathrm { N } } 2$条件下不能发生反应，因为[[纤维素纳米晶|CNC]]晶体抑制[[瓦尔登翻转]]，只有O6位点可望发生反应。当表面醇羟基已被氯取代时也可以看到这一点。<sup>62</sup> 最后，纤维素表面−OH基团的反应活性似乎还受到反应介质的影响，即在均相溶液中，由于空间位阻原因，6位−OH基团最易于反应，并遵循$\mathrm { O 6 } > \mathrm { O 2 } > \mathrm { O 3 }$的顺序；而在非均相改性中，2位−OH基团成为反应活性最高的物种，其顺序为$\mathrm { O } 2 > \mathrm { O } 6 > \mathrm { O } 3 . ^ { 6 3 }$。

2.2. 表面化学。在固−液界面进行的化学反应不同于均相反应，因为[[吸附]]是化学反应发生的先决条件，而且如前所述，表面官能团的自由度较少。<sup>64</sup> 在了解[[纤维素]]晶体形貌和表面−OH基团反应活性的基础上，还必须认识[[纤维素纳米晶|CNC]]加工过程中影响其表面化学的因素。

迄今为止，从[[纤维素]]原料中提取[[纤维素纳米晶|CNC]]最常用的方法是[[硫酸]]催化的水解。<sup>2,3,5−7</sup> 在脱除天然材料的[[木质素]]并去除[[半纤维素]]之后，该过程通常包括将高纯度纤维素纤维暴露于55−65 wt %硫酸溶液中，在35至$7 0 ~ ^ { \circ } \mathrm { C } .$的温度范围内处理30−60 min。在此过程中，硫酸与结晶区表面的一部分−OH基团反应生成[[硫酸半酯]]，其浓度通常在150−400 mmol/kg范围内。<sup>65</sup> 经多次[[离心分离]]和对去离子水[[透析]]纯化后，这些硫酸半酯基团带负电荷，由于[[静电排斥]]作用而产生高度稳定的[[纤维素纳米晶体|CNC]]分散体。如上所述，[[硫酸水解]]得到的CNC通常表现出有限的[[热稳定性]]。<sup>21,22</sup> 硫酸半酯可以通过水解或溶剂解脱硫酸化方法去除，<sup>66,67</sup> 但这种改性是以降低分散性为代价的。

也可以采用[[盐酸]]$\mathrm { ( H C l ) } ^ { 6 8 }$或[[氢溴酸]]（HBr）<sup>69</sup>进行水解。在某些情况下，会生成表面电荷非常低的[[纤维素纳米晶|CNCs]]；这些电荷很可能来源于少量[[羧酸根基团]]（约20−30 mmol/kg）。<sup>65</sup> 相应地，通过HCl或HBr水解法生产的[[纤维素纳米晶体|CNCs]]也存在[[胶体稳定性]]低的缺点，这是因为缺乏足够的[[静电排斥力]]，从而使相邻纳米颗粒之间得以形成[[氢键]]。这种分散体聚集显然会对后续表面改性造成问题。由[[Camarero Espinosa]]等人<sup>21</sup>提出的[[磷酸水解|磷酸水解法]]可得到带有少量[[磷酸根基团]]（约11 mmol/kg）的CNCs。在这种情况下，CNC表面上的每个磷酸根基团提供两个酸性−OH基团，从而使CNCs表现出良好的胶体稳定性与[[热稳定性]]的有趣组合。

制备[[纤维素纳米晶|CNCs]]的其他方法包括[[内切葡聚糖酶]]介导的水解、<sup>70</sup> [[机械化学活化]]、[[磷酸水解|磷钨酸水解]]、<sup>71</sup> [[过硫酸铵]]（APS）氧化、<sup>72</sup> 以及[[2,2,6,6-四甲基哌啶-1-基氧基|（2,2,6,6-四甲基哌啶-1-基）氧基]]（[[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]]）介导的氧化后再进行[[空化处理]]。<sup>73</sup> 后两种方法可得到表面[[羧酸根基团]]浓度较高的功能化[[纤维素纳米晶体|CNCs]]（对于[[TEMPO]]介导的氧化约为1.12−1.74 mmol/g），<sup>73</sup> 这不仅有助于良好分散性，还提供了替代性的[[表面化学改性]]途径。<sup>24,25</sup>

无论采用何种方法制备[[纤维素纳米晶|CNCs]]，显然阴离子表面电荷可提供[[胶体稳定性]]，从而在水和极性非质子溶剂（如[[N,N-二甲基甲酰胺]]（DMF）和[[二甲基亚砜]]（DMSO））中防止一定程度的聚集。<sup>74</sup> 表面电荷还影响[[纤维素纳米晶体|CNCs]][[冷冻干燥]]的难易程度，同时它们会消耗一部分本可用于后续功能化的表面−OH基团。此外，表面电荷的反离子强烈影响干燥CNCs经[[超声处理]]后的再分散性，尤其是当材料水分含量低于4 wt%时，由于CNCs之间存在更强的分子间[[氢键]]，这种影响更为明显。<sup>75,76</sup> 因此，如果后续要进行[[表面改性反应]]，宜采用能够赋予“恰到好处”表面电荷以促进胶体稳定性的水解方案。

2.3. [[纤维素纳米晶|CNCs]][[表面化学改性]]前的预处理。表面杂质、结合水以及过量反离子的存在会对表面功能化反应的成功及其可重复性产生显著影响，尤其是在不同类型或不同批次的[[纤维素纳米晶体|CNCs]]之间。<sup>77−79</sup> 此外，许多适用于−OH基团改性的反应途径不耐受水，因此CNCs必须要么经过干燥并再分散，要么通过其他方式转移至干燥有机溶剂中。可以对CNCs进行[[冷冻干燥]]，<sup>80−85</sup> 30,83,86−89

若要对[[冷冻干燥]]的 [[纤维素纳米晶|CNCs]] 进行表面改性，通常需先用有机溶剂（如[[乙醇]]、<sup>78,79</sup> [[丙酮]]、<sup>77</sup> 或[[正戊烷]]<sup>77</sup>）洗涤纳米晶体以去除杂质。这可通过[[索氏提取]]<sup>78,79</sup> 或多次将 [[纤维素纳米晶体|CNCs]] 分散于所选溶剂中、随后[[离心分离]]的循环操作来实现。<sup>77</sup> 研究发现，此类预处理可提高接枝实验之间的可重复性。<sup>77</sup>

[[溶剂交换]]通常包括将 [[纤维素纳米晶|CNCs]] 的水分散液与水混溶性有机溶剂（通常为[[丙酮]]）混合、离心、更换溶剂，并多次重复该循环，直至溶剂更换为有机溶剂；[[表面引发聚合]]常在该有机溶剂中进行。<sup>30,87,88,90,91</sup> 例如，[[Tian]] 等比较了从[[冷冻干燥]] [[纤维素纳米晶体|CNCs]] 和经溶剂交换 CNCs 出发进行的 [[ε-己内酯]]（ε-CL）[[表面引发开环聚合]]（SI-[[开环聚合|ROP]]），观察到经溶剂交换的纳米晶体所得[[接枝密度]]高于冷冻干燥样品。<sup>86</sup> 从这些结果可以明确，[[吸附]]在 CNCs 表面的杂质通常可通过有机溶剂处理得到更好的去除。这些杂质很可能是残留[[半纤维素]]或[[木质素]]水解产生的副产物，也可能是[[单糖]]和[[寡糖]]经[[酸催化脱水]]形成的产物。<sup>2,7</sup>

## 3. 由 [[纤维素纳米晶|CNCS]] 进行的[[表面引发聚合]]

针对 [[纤维素纳米晶|CNCs]] 表面改性的许多研究工作，集中在调控其表面的物理化学特性，同时保持其形貌完整性和[[结晶度]]。<sup>24,25,92</sup> 事实上，如果所选择的官能化化学能够选择性地修饰表面或[[还原端]]基，则 [[纤维素纳米晶体|CNCs]] 的固有结晶度和晶体结构应得以保留；这一点可通过 [[X射线衍射|X 射线衍射]]研究加以验证。<sup>24,30,82,83,86,93−96</sup> 在本节中，将介绍最常用于通过“[[接枝自]]”（grafting from）方法，即表面引发和还原端基引发聚合来改性 CNCs 的方法。

[[内酯]]和[[双内酯]]，其 [[开环聚合|ROP]] 可由 −OH 基团引发。因此，它们不仅适合用于 [[纤维素纳米晶|CNCs]] 的表面改性，也适合用于[[纤维素]]纤维和纳米原纤的表面改性，因为这些材料同样具有高密度的 −OH 表面基团。在这种情况下，纤维素基材充当[[大分子引发剂]]，而该聚合过程通常被称为 [[表面引发开环聚合|SI-ROP]]。

[[CNC-g-聚酯]]。[[纤维素纳米晶|CNC]]-g-聚酯已通过从 [[纤维素纳米晶体|CNCs]] 出发的 [[ε-己内酯]]（ε-CL）、<sup>30,80−83,86,103−105</sup> [[L-丙交酯]]（ -LA）、<sup>84,85,87,88,90,91,104,106−108</sup> 和 [[D-丙交酯|-丙交酯]]（ -LA）<sup>89,105,109,110</sup> 的[[表面引发开环聚合]]（SI-[[开环聚合|ROP]]）制备。[[内酯]]和[[双内酯]]的开环聚合机理因所用体系而异，即取决于催化剂和引发剂的性质。<sup>111</sup> 该机理可以是阴离子型、阳离子型、[[单体活化型聚合|单体活化型]]或[[配位-插入聚合]]。在从 CNCs 进行的 SI-ROP 情形中，纳米晶体充当引发剂，机理仅取决于催化剂。该反应对水敏感，因为水也可能引发内酯的开环聚合。因此，通常分散纳米晶体所用的水需要尽可能通过第 2.3 节所述方法去除。

108-110.112 是（双）[[内酯]] [[表面引发开环聚合|SI-ROP]] 最常用的催化剂。反应通常在[[甲苯]]中进行，但也在[[离子液体]]（[[1-烯丙基-3-甲基咪唑氯盐]]，[AMIM]Cl<sup>113</sup>）、[[二甲基亚砜|DMSO]]<sup>108</sup> 或本体条件<sup>84</sup> 中进行过。典型条件还包括 80 至 130 °C 的温度和通常为 24 h 的反应时间。[[接枝聚合]]物也已在[[微波辐照]]下制备。<sup>81,112</sup> [[苯甲醇]]有时用作[[牺牲引发剂]]，以在溶液中生成自由聚合物，后者比接枝物更容易表征。<sup>77,108</sup> 当然，与“平行”产生的自由聚合物进行比较，只有在能够可靠假定溶液[[开环聚合]]动力学与从 [[纤维素纳米晶|CNCs]] 进行的 SI-ROP 相似时才有意义，而这一点可能成立，也可能不成立。

总体而言，从 [[纤维素纳米晶|CNCs]] 进行的 [[表面引发开环聚合|SI-ROP]] 的性质使得对[[接枝聚合]]物分子量和分散性的准确表征具有挑战性，因为必须先对聚合物进行[[脱接枝]]，才能进行完整的分子表征。大多数脱接枝方案依赖于界面[[酯键]]的水解断裂，然而本文讨论的某些聚合物链中也存在这类键。这一问题有可能通过使用可断裂锚定基团来解决，例如含[[二硫键]]<sup>114</sup> 或紫外敏感基团<sup>115</sup> 的锚定基团，类似于通过[[表面引发可控自由基聚合]]（SI-CRP）合成的聚合物改性[[纤维素]]基底所采用的方法。<sup>28</sup> 或许还可以利用聚合物-[[纤维素纳米晶体|CNC]] 界面处酯键的高键张力，这些酯键很可能比聚合物链上的酯键对水解更敏感，因此可以通过[[机械化学|机械化学手段]]（例如超声）将其断裂。<sup>116,117</sup>

[[纤维素纳米晶|CNC]]-g-聚[[噁唑啉]]。通过[[表面引发开环聚合|SI-ROP]]接枝噁唑啉遵循阳离子机理，因此不能由[[纤维素纳米晶体|CNCs]]表面的−OH基团引发；实际上，通过[[甲苯磺酰化]]对CNC表面进行改性，可将亲核性的−OH基团替换为亲电性的[[甲苯磺酰基]]部分。<sup>121</sup> 在这种情况下，[[甲苯]]磺酰化的CNCs作为[[大分子引发剂]]用于[[2-乙基-2-噁唑啉]]的SI-[[开环聚合|ROP]]。研究表明，甲苯磺酰化后，改性CNCs只需与单体混合，SI-ROP即可在[[微波辐照]]下顺利进行（约13分钟完成）。反应可通过加入冷水终止，随后用[[甲醇]]洗涤（方案3）。

3.2. [[表面引发自由基聚合]]。将[[乙烯基聚合物]][[接枝到]][[纤维素纳米晶|CNC]]表面最常用的方法之一是表面引发自由基聚合（SI-FRP）。聚合从引发剂物种的活化开始，通常通过夺氢在[[纤维素纳米晶体|CNC]]表面产生活性自由基，单体随后加成到增长链上。<sup>122</sup> 该方法能够在CNC表面便捷地生长聚合物，同时在溶液中形成游离链，即使在低单体转化率下也可获得相对较高的分子量。

已证明多种[[自由基引发剂]]可有效用于乙烯基单体的[[表面引发聚合]]。在热引发剂中，[[过硫酸钾]]（KPS）因其自由基稳定性好且与水溶液相容而被广泛用于在[[纤维素纳米晶|CNC]][[表面修饰]]聚合物链。自由基的形成始于水相中KPS[[过氧键]]在60至$7 0 ~ ^ { \circ } \dot { \mathrm { C } } .$温度范围内的[[热均裂]]。由此产生的游离[[硫酸根自由基]]能够从[[纤维素纳米晶体|CNC]]表面夺取氢原子，从而生成表面结合型引发物种（方案4）。使用该引发剂，[[2-(3-(6-甲基-4-氧代-1,4-二氢嘧啶-2-基)脲基)乙基甲基丙烯酸酯]]$\left( \mathrm { U P y M A } \right)$成功地从$\mathrm { C N C s } ,$表面聚合，得到$\mathrm { C N C - } g _ { \overline { { { \jmath } } } }$PUPyMA，其中聚合物含量为6.9 wt %。<sup>123</sup> 与原始CNC相比，UPyMA单元的存在显著提高了纳米颗粒（NPs）的乳液稳定能力，使其适用于制备[[高内相乳液]]和[[大孔水凝胶]]。另一个例子由[[Wu]]等人报道，他们使用[[丙烯酸]]（AA）作为单体。<sup>124</sup> 接枝的[[聚丙烯酸]]（PAA）链赋予CNC基[[水凝胶]]优异的[[保水性能]]，其在蒸馏水中的溶胀比为323 $\mathbf { g } / \mathbf { g }$，而在[[氯化钠]]（NaCl）溶液中的溶胀比为33 g/g。

上述 [[表面引发自由基聚合|SI-FRP]] 方法涉及在 [[纤维素纳米晶|CNCs]] 表面直接形成活性物种，并由此使聚合物链得以生长。Yang 及其同事报道了一种不同的方法，其中 [[纤维素纳米晶体|CNC]] 表面在聚合前先用活性小分子进行化学改性。<sup>137,138</sup> 通过用 [[γ-甲基丙烯酰氧基丙基硅烷]]处理，将含有末端乙烯基的化学实体共价连接到 CNCs 表面。随后，在 [[过硫酸钾|KPS]] 引发剂存在下，末端乙烯基处形成自由基物种，从而产生增长自由基，并由 $\mathbf { A } \mathbf { A } ^ { 1 3 7 }$ 或 $\mathbf { A \dot { M } ^ { 1 3 8 } }$ 单体进行聚合，直到通过再结合发生[[终止反应]]，进而促进[[交联网络]]的形成。基于所采用的高单体与表面引发剂比例<sup>137,138</sup> 以及最终单体转化率（约 99%），<sup>137</sup> 通过该方法接枝的聚合物由于高[[接枝密度]]或高分子量，在 CNC 核心周围形成了致密壳层。

Espino-Perez 等人提出通过符合绿色化学原理的反应步骤合成 [[纤维素纳米晶|CNC]]-g-[[聚苯乙烯]]。<sup>94</sup> 该方案包括对 [[纤维素纳米晶体|CNCs]] 进行[[臭氧解]]，从而在其表面形成过氧化物基团，随后在 [[过硫酸钾|KPS]] 和[[苯乙烯]]（Sty）单体存在下，于[[乙酸钠缓冲溶液]] $\big ( \mathrm { p H } = 3 . { \dot { 5 } } \big )$ 中进行自由基聚合。热活化的[[硫酸根自由基]]还原过氧化物基团，产生自由自由基，其进一步增长形成连接在表面的聚苯乙烯（PSty）链。Sty/AGU 比率经估算为 0.24，这证实了由于臭氧解处理过程中过氧化氢化效率较低，该方法在 CNCs 上的[[接枝效率]]较低。

另一种用接枝[[乙烯基聚合物]]修饰 [[纤维素纳米晶|CNCs]] 的策略由 Lee 等人提出。<sup>139</sup> [[表面引发自由基聚合|SI-FRP]] 在含有三氯乙酰基的 [[纤维素纳米晶体|CNCs]] 表面进行，以[[六羰基钼]] $( \mathrm { M o } ( \mathrm { C O } ) _ { 6 } )$ 为引发剂，以 [[2-甲基丙烯酰氧基乙基磷酰胆碱]]（MPC）和[[甲基丙烯酸硬脂酯]]（SMA）为单体，在[[乙醇]]中进行，得到 $\mathrm { C N } \dot { \mathrm { C } } { \cdot } g { \mathrm { - } } \mathrm { P } ( \mathrm { M P C } { \cdot } c o { \mathrm { - } } \mathrm { S M A } )$ ，单体转化率超过 90%。

最近，Wohlhauser 等提出了一种新的自由基策略，其中引发剂物种被共价连接到 [[纤维素纳米晶|CNC]] 表面。<sup>93</sup> 该方法保证了基底表面存在大量反应位点，尽管它并不能避免溶液中自由基的形成。在该工作中，[[聚甲基丙烯酸甲酯|PMMA]] 和[[聚甲基丙烯酸己酯]]（PHMA）通过一种简便的流程成功从 [[纤维素纳米晶体|CNC]] 接枝，该流程包括用[[二苯甲酮]]基团作为[[光引发剂]]对 CNC 进行[[表面修饰]]，随后在 [[N,N-二甲基甲酰胺|DMF]] 中于[[紫外照射]]下对甲基[[丙烯酸]]酯进行[[表面光引发自由基聚合|表面光引发 FRP]]。二苯甲酮是一种 [[Norrish II 型光引发剂]]，其从激发单线态经[[系间窜越]]至最低能量反应三线态，随后从邻近分子或界面夺取脂肪族氢，生成[[羰自由基]]和[[碳中心自由基]]。<sup>140</sup> 因此，[[表面引发自由基聚合|SI-FRP]] 由碳中心自由基引发，并且也可能形成游离（未连接）聚合物链（由单体或溶剂分子引发）。使用该方法，针对两种单体均制备了[[接枝聚合]]物含量为 80 和 90 wt% 的组合物。这是通过使用 DMF 作为溶剂并改变单体转化率实现的。与先前研究相比，CNC 表面聚合物刷的比例非常高，但鉴于该机理，也有相当数量的聚合物（相对于初始单体量，为 24 至 48 wt%）以游离（未连接）聚合物形式生成。

总体而言，通过从共价固定的反应性物种进行自由基聚合[[接枝到]] [[纤维素纳米晶|CNC]] 表面的聚合物，取决于与增长自由基相关的因素，例如表面引发剂效率、增长速率以及单体与表面引发剂之比。实际上，该领域仍需进一步研究，以更好地理解这些参数的影响。当前该领域仍存在的另一个机会是，通过连接其他常规[[自由基引发剂]]（即含偶氮引发剂）来研究 [[表面引发自由基聚合|SI-FRP]]，并随后与通过上述技术获得的聚合物刷进行比较。

3.3. [[表面引发可控自由基聚合]]。当需要对聚合物结构、组成、分子量和[[接枝密度]]进行精确控制时，SI-CRP 是一种有效的聚合物生长方式。<sup>28</sup> 一般而言，CRP 反应依赖于增长链的可逆失活，从而使[[终止反应]]最小化，由此提供一级聚合动力学和低分散性。可以实施不同的 SI-CRP 方法，其取决于与表面偶联的引发剂或所谓的[[链转移剂]]（CTA）类型，例如 [[Cu]] 介导的 SI-CRP、[[表面可逆加成-断裂链转移|表面可逆加成−断裂链转移]]（[[S-RAFT]]）或[[表面引发氮氧调控聚合]]（[[SI-NMP]]）等。方案 8 举例说明了三种最常用的 SI-CRP 技术，即[[表面引发原子转移自由基聚合]]（SI-[[ATRP]]）、[[表面引发可逆加成−断裂链转移聚合|S-RAFT]] 和 SI-NMP。在以下各节中，将对每一种技术进行简要概述。

3.3.1. 铜介导的 [[表面引发可控自由基聚合|SI-CRP]]。在所有 SI-CRP 技术中，由过渡金属配合物（尤其是 [[Cu]] 物种）介导的技术，如 [[表面引发原子转移自由基聚合|SI-ATRP]]，已成为最广泛用于从 [[纤维素纳米晶|CNCs]] [[接枝聚合]]物的方法。[[ATRP]] 中的控制源于休眠物种与增长物种之间存在动态平衡，从而降低自由基浓度并最大限度地减少[[终止反应]]。<sup>144</sup> 可逆失活通过金属配合物（大多数情况基于 [[铜|Cu]]）与增长物种之间卤素原子（Br 或 Cl）的交换实现。由于最终聚合物中残留金属对某些应用可能构成问题，随后发展出通过电子转移（A(R)GET）[[原子转移自由基聚合|ATRP]] 原位（再）生成 Cu(I) 活化剂的技术，将所需催化体系用量降低至 ppm 级。<sup>145−147</sup> 在 Cu(0) 存在下的 CRP 也有报道，并引发了关于电子转移机理模型的争论，即[[单电子转移活性自由基聚合]]（SET LRP）与[[补充活化剂和还原剂原子转移自由基聚合]]（SARA ATRP）。<sup>148−150</sup> 由于本展望旨在报道从 [[纤维素纳米晶体|CNCs]] 获得的不同结构及其相关性能，而非讨论机理，因此涉及 Cu 物种的技术统一归入“铜介导的 SI-CRP”这一总称。

在 [[纤维素纳米晶|CNC]] 上进行铜介导的 [[表面引发可控自由基聚合|SI-CRP]]，需要预先在其表面引入引发位点。这通常通过使 [[纤维素纳米晶体|CNC]] 表面的大量 −OH 官能团与 [[2-溴异丁酰溴]]（BiBB）在溶剂（[[四氢呋喃|THF]] 或 [[N,N-二甲基甲酰胺|DMF]]）中反应实现，通常在碱（[[三乙胺]]）和催化剂（[[4-二甲氨基吡啶|DMAP]]）存在下进行。<sup>141,151−161</sup> 该修饰程度可通过反应时间和引入的 BiBB 用量加以调控。<sup>162,163</sup> 通过活性引发剂与非活性“假”引发剂的组合，可控制总体[[接枝密度]]。<sup>28</sup> 多年来，发展了若干策略以改善修饰过程中 CNCs 的分散性，包括：（1）[[溶剂交换]]（而非[[冷冻干燥]]），从而避免干燥 CNCs 的再分散步骤，<sup>163,164</sup> 或（2）在 CNC [[气凝胶]]上进行 BiBB 的[[化学气相沉积]]，使 CNCs 部分疏水化，随后再进行与 BiBB 的液相反应。<sup>165−169</sup> 由此可在更低的 BiBB 过量条件下获得更高的修饰度（[[元素分析]]测定 Br 含量高达 15 wt %）。<sup>165</sup> 虽然使用较少，但也有报道通过使 −OH 官能团与经[[羰基二咪唑]]活化的 [[α-溴异丁酸]]反应来引入引发位点。<sup>170,171</sup> 在另一项研究中，提出使用 [[2-溴丙酸]]在 CNCs 表面引入活性位点，产率为 46%，元素分析测定 Br 含量为 2.86 wt %。<sup>95</sup> 该方案包括先用 [[盐酸|HCl]] 预处理原始 CNCs，再进行一步反应，将 [[Fischer 酯化]]与[[酸水解]]结合起来。

在以往的所有研究中，−OH 官能团都是在整个纳米晶体表面上以统计且均匀的方式进行修饰。最近，[[Zoppe]] 等人报道了一种方法，通过 [[纤维素纳米晶|CNC]] 的氧化及其与[[乙二胺]]的反应，随后再与 [[2-溴异丁酸 N-羟基琥珀酰亚胺酯]]反应，专门在 [[纤维素纳米晶体|CNC]] 的[[还原端]]基上引入引发位点。<sup>172</sup> 该方法将在第 3.4 节中进一步详细讨论。

[[纤维素纳米晶|CNC]] [[大分子引发剂]]已被用于多种[[苯乙烯]]类、（甲基）[[丙烯酸]]类或[[丙烯酰胺]]类单体（图 5）的 [[铜介导 SI-CRP|Cu 介导 SI-CRP]]，并针对所用不同单体对催化体系和溶剂进行了优化（见表 S1）。聚合控制可通过[[接枝聚合]]物的[[皂化]]（在酸性或碱性条件下进行）以及随后在溶液中对[[脱接枝]]聚合物的进一步分析来阐明；然而，脱接枝反应需要较长的反应时间（2 天至 3 周），并且有可能改变聚合物结构。<sup>141,152−154,163,164,170,172</sup> [[Cu]] 介导 [[表面引发可控自由基聚合|SI-CRP]] 技术的多功能性及其对许多官能团的高耐受性，使得 [[纤维素纳米晶体|CNC]] 可以被接枝上种类繁多的聚合物链，范围涵盖中性 [[聚苯乙烯|PSty]]、<sup>115,141,157,162</sup> 聚（（甲基）丙烯酸烷基酯）、<sup>158,169,170</sup> 阳离子型聚（（甲基）丙烯酸氨基烷基酯/甲基丙烯酰胺）<sup>155,172</sup> 或阴离子型聚苯乙烯磺酸盐<sup>172</sup> 以及 [[聚丙烯酸|PAA]]（通过[[聚（丙烯酸叔丁酯）]]（PtBA）的水解得到）。<sup>165,168</sup> 热敏性聚合物，如 [[聚(N-异丙基丙烯酰胺)|PNIPAM]]、<sup>153,154,163,164,172</sup> PDMAE-<sup>1</sup> [[聚（N-乙烯基己内酰胺）]]（PNVC）、<sup>161</sup> 或聚[（低聚乙二醇）甲醚丙烯酸酯]（POEGME-MA）<sup>159,160</sup> 也已通过该方法被接枝。

对中性平面基底上[[表面引发聚合]]的 [[Monte Carlo 模拟]]表明，本体聚合物往往以更快速率和更低[[分散度]]生长，但这高度依赖于引发位点的[[接枝密度]]。<sup>174</sup> 除 CuX/CuX 比例的重要性外，<sup>28,29</sup> 显然单体类型/浓度、溶剂以及本体与溶液合成的差异都在 [[铜介导 SI-CRP|Cu 介导 SI-CRP]] 的控制中发挥作用。<sup>28</sup> 因此，表面引发聚合物的聚合动力学与游离聚合物相似的假设并不总是成立。

一般而言，在更高极性溶剂（如水）中进行的 [[铜介导 SI-CRP|Cu 介导 SI-CRP]] 往往因高活化速率而产生具有更高[[分散度]]的聚合物。<sup>175</sup> 如此高的分散度意味着更高的终止速率和活性聚合物链末端的损失，因此总体控制程度较低。在较低极性溶剂或本体中以高单体浓度（例如 [[苯乙烯|Sty]]）进行的 [[Cu]] 介导 [[表面引发可控自由基聚合|SI-CRP]]，其动力学往往类似于溶液中的 [[铜|Cu]] 介导 CRP。<sup>115</sup> 当需要更复杂的结构时，这些方面是重要的考虑因素，例如来自 [[纤维素纳米晶|CNC]] 的[[嵌段共聚物刷]]，其中良好的控制和高链端保真度对成功至关重要。

尽管上述技术在从[[纤维素纳米晶|CNC]][[接枝聚合]]物领域已被广泛使用，但聚合后去除[[Cu]]残留物仍然具有挑战性，需要进一步研究。溶液聚合中使用了多种纯化方法，但当反应涉及$\mathrm { C N C s , e . g . }$、通过硅胶或中性氧化铝柱纯化时，这些方法难以应用。<sup>144</sup>溶液中$\mathrm { { C u } ( I ) }$的（再）生成部分解决了这一问题，因为反应中[[铜|Cu]]的用量大大降低。然而，对于生物医学应用而言，去除痕量Cu似乎至关重要。

[[透析]]已被用于在聚合反应后去除铜。<sup>176</sup> 在透析之前，[[Rosilo]] 等人对 [[聚(N,N-二甲氨基乙基甲基丙烯酸酯)|CNC-g-聚(N,N-二甲氨基乙基甲基丙烯酸酯)]]在不同有机溶剂（即 [[甲醇|MeOH]]、[[N,N-二甲基甲酰胺|DMF]] 和[[二氧六环]]）中进行了数次离心。<sup>167</sup> 在这两种情况下，所使用的方法可能不足以去除接枝 [[纤维素纳米晶|CNC]] 表面[[吸附]]的铜。在另一项研究中，[[Morandi]] 等人提出对[[冷冻干燥]]样品依次在[[二氯甲烷]]和[[乙醇]]中进行两次 [[索氏萃取|Soxhlet 萃取]]，以去除痕量铜。与吸附在 $\mathrm { C N C s } ,$ 表面的铜相关的蓝色通过该处理被去除。然而，在该过程之后并未对残留痕量铜进行定量分析。另一种去除铜的方法可以是将接枝 [[纤维素纳米晶体|CNC]] 与[[离子交换树脂]]一起搅拌。$^ { 1 7 7 } \mathrm { O r } ,$ 如第 3.2 节所讨论的，可以通过[[玻璃微纤维滤纸]]过滤改性 CNC 来去除颗粒。<sup>132</sup>

3.3.2. 表面 [[可逆加成−断裂链转移聚合|RAFT]] 聚合。可逆加成−断裂链转移聚合（RAFT）涉及可逆链转移过程，并在 [[链转移剂|CTA]] 以及[[自由基引发剂]]的存在下进行。这类 CTA 通常基于[[二硫代氨基甲酸酯]]、[[二硫代碳酸酯]]或[[二硫代酯]]，并含有所谓的 [[R 基团]]和 [[Z 基团]]。CTA 的作用是介导加成、断裂和链转移反应，从而整体上控制分子量和[[分散度]]。在 RAFT 聚合过程中，自由基要么与 CTA 可逆反应，要么与单体可逆反应。因此，[[S-RAFT]] 聚合通过预先将自由基引发剂或 CTA 固定到基材表面来进行。如果 CTA 附着在基材表面，它可以被系留以呈现 R 基团或 Z 基团，其中前者是最常用的。方案 9 展示了（A）两种不同的 CTA 固定策略，以及从 [[纤维素纳米晶|CNC]] 进行 [[表面可逆加成-断裂链转移|S-RAFT]] 的示例，分别使用（B）R 基团方法和（C）表面自由基与游离 CTA。

最早利用 [[S-RAFT]] 改性 [[纤维素纳米晶|CNC]] 的研究之一由 [[Zeinali]] 等人报道，其中通过 [[R 基团]]方法固定 [[链转移剂|CTA]]，接枝了 [[聚(N-异丙基丙烯酰胺)|PNIPAM]] 以及 [[聚（N-异丙基丙烯酰胺）|PNIPAM]] 和 [[聚丙烯酸|PAA]] 的[[无规共聚物]]（P([[N-异丙基丙烯酰胺|NIPAM]]-ran-[[丙烯酸|AA]])）。<sup>142</sup> CTA，即 [[2-(十二烷基硫代羰基硫代硫基)-2-甲基丙酸]]（DDMAT），在[[氯仿]]中通过 [[4-二甲氨基吡啶|DMAP]] 催化的[[酯化反应]][[接枝到]] [[纤维素纳米晶体|CNC]] 的 −OH 基团上，反应在 [[N,N′-二环己基碳二亚胺]]（DCC）存在下进行。[[元素分析]]测定的硫含量为 2.1 wt %，证实了 CTA 的成功连接。NIPAM 和 NIPAM-ran-AA 的 [[表面可逆加成-断裂链转移|S-RAFT]] 聚合在[[二氧六环]]中，使用 $^ { 2 , 2 ^ { \prime } }$-[[偶氮二异丁腈]]（AIBN）并在游离 CTA（即 DDMAT）存在下进行。作者使用不同的单体进料比获得了统计共聚物接枝，其中 CNC 杂化材料通过 [[FTIR]]、[[动态光散射]]（DLS）和[[热分析]]进行了表征。根据 [[差示扫描量热法|DSC]] 实验结果，作者得出结论：随着 AA 比例的增加，热容变化 $\left( \Delta C _ { p } \right)$ 降低。与游离（共）聚合物相比，从 CNC 接枝得到的聚合物表现出更高的 $T _ { \mathrm { g } }$，这归因于表面链受限。

[[Boujemaoui]] 等人研究了通过 [[S-RAFT]] 和[[黄原酸酯交换]]（MADIX）聚合接枝[[乙酸乙烯酯]]（VAc）。<sup>179</sup> 基于黄原酸酯的 [[链转移剂|CTA]]，即 [[2-((乙氧基硫代羰基)硫代)丙酸]]，通过 [[Steglich 酯化]]或两步法连接到 [[纤维素纳米晶|CNCs]] 上，其中后者的聚（乙酸乙烯酯）（[[聚乙酸乙烯酯|PVAc]]）接枝率较低。[[表面可逆加成-断裂链转移|S-RAFT]] 过程的动力学通过牺牲 CTA 进行监测，并展示了对分子量和分散性的良好控制。然而，对于上述所有研究，关于所连接聚合物的分子量、分散性和[[接枝密度]]仍知之甚少。

从 [[纤维素纳米晶|CNCs]] 出发的各种[[丙烯酰胺]]的 [[S-RAFT]] 也由游离大分子 [[链转移剂|CTA]] 介导，并使用[[自由基引发剂]]如[[硝酸铈(IV)铵]]（CAN）进行（方案 $9 \mathrm { C } ) . ^ { 9 \dot { 6 } , 1 8 0 }$）。在这些情况下，使用分子量在 1.4 至 2 kDa 之间的大分子 CTA 介导 $\mathbf { A M } ^ { 9 6 , 1 8 0 }$ 和 $\mathrm { D M A M } ^ { 1 8 0 }$ 从 ${ \mathrm { C N C s } } ,$ 的 [[表面可逆加成-断裂链转移|S-RAFT]] 聚合，其中表面自由基如方案 7 所示生成。[[聚丙烯酰胺|PAM]] 链从 [[纤维素纳米晶体|CNCs]] 表面断裂，并确定具有 $M _ { \mathrm { n } } = 1 4 \ : \mathrm { k D a }$ 和 $\begin{array} { r } { B = 1 . 2 8 , } \end{array}$，后者表明大分子 $\mathrm { C T A } ^ { 9 6 }$ 的参与。此外，观察到聚合物修饰的 $\mathrm { C N C s } ,$ 的 S 含量增加，这表明至少部分接枝的 PAM 链末端带有大分子 CTA 基团。

采用一种独特的方法，通过结合 [[S-RAFT]] 和 $\mathrm { S I - A T R P . } ^ { 1 7 6 }$，从双官能 [[纤维素纳米晶|CNC]] [[大分子引发剂]]接枝了聚[聚(乙二醇)乙基醚甲基[[丙烯酸]]酯]（PPEGEEMA）和 [[聚(N,N-二甲氨基乙基甲基丙烯酸酯)|PDMAEMA]]。双官能 [[纤维素纳米晶体|CNC]] 大分子引发剂是先将 CNC 表面的 −OH 基团转化为反应性胺，再分别通过与 [[α-溴代异丁酸]]（BIBA）和 [[4,4′-偶氮双(4-氰基戊酸)]]（ACVA）的连续反应，将其转化为溴代异丁酰基官能团和偶氮引发位点。随后步骤包括通过 [[表面可逆加成-断裂链转移|S-RAFT]] 聚合在改性 CNC 表面生长 PPEGEEMA 刷，再通过 [[表面引发原子转移自由基聚合|SI-ATRP]] 接枝 PDMAEMA。聚合按此顺序进行，以避免 SI-[[ATRP]] 过程可能对偶氮引发位点造成的破坏。通过 [[可逆加成−断裂链转移聚合|RAFT]] 在溶液中形成的游离 PPEGEEMA 的 $M _ { \mathrm { n } }$ 为 4.7 kDa，D̵ 为 1.2。SI-[[原子转移自由基聚合|ATRP]] 后，通过[[酸水解]]成功从 CNC 上裂解 PDMAEMA 链，根据 SI-ATRP 反应时间在 5 至 30 min 之间的不同，所得 $M _ { \mathrm { n } }$ 范围为 4.2−7.7 kDa，D̵ 为 1.2−1.3。然而，在此类条件下（64 wt % [[硫酸]]、3 h、45 $^ { \circ } \mathrm { C } )$），所报告的[[尺寸排阻色谱]]（SEC）结果很可能代表了解离的 PDMAEMA 与 PPEGEEMA 或其相应水解产物（如 [[聚甲基丙烯酸|PMAA]]）的混合物。鉴于 RAFT 过程的复杂性以及从 CNC 上开展此类聚合动力学知识的缺乏，关于 CNC 上 [[表面引发可逆加成−断裂链转移聚合|S-RAFT]] 仍有许多待研究之处。

3.3.3. 表面引发 NMP。与 [[Cu]] 介导的 [[表面引发可控自由基聚合|SI-CRP]] 类似，[[表面引发氮氧调控聚合]]（[[SI-NMP]]）在机理上依赖于失活物种对增长聚合物链的可逆活化−失活，在此情形中该失活物种为[[氮氧自由基]]。一般而言，[[烷氧基胺]]（如 [[2,2,6,6-四甲基哌啶-1-氧自由基|TEMPO]] 和 N-叔丁基-N-[1-二乙基膦酰基(2,2-二甲基丙基)]氮氧化物（DEPN））常用于 SI-NMP。[[Roeder]] 等人首次利用 SI-NMP 从 [[纤维素纳米晶|CNC]] 上[[接枝聚合]]物。<sup>143</sup> 作者首先用 [[BlocBuilder|4-(二乙氧基磷酰基)-2,2,5,5-四甲基-3-氮杂己烷-N-氧基]]（又称 BlocBuilder）对 [[纤维素纳米晶体|CNC]] 进行官能化，随后在牺牲性 BlocBuilder 引发剂存在下从 CNC 上接枝 [[PMA]] 和 [[聚甲基丙烯酸甲酯|PMMA]]（见方案 8）。所得接枝产率为 75−80 wt %。尽管多次尝试，作者仍无法从 CNC 表面裂解接枝的 [[聚丙烯酸甲酯|PMA]] 或 [[聚（甲基丙烯酸甲酯）|PMMA]]。不过，在牺牲性 BlocBuilder 存在下进行的 SI-NMP 使得可对游离聚合物进行 [[尺寸排阻色谱|SEC]] 分析。游离 PMA 的 M 值为 3.3 至 43.7 kDa，D̵ 为 1.35−1.4，而游离 PMMA 的 M 范围为 30.8−140 kDa，[[分散度]]相似，尽管单体转化率相近。这些结果表明，PMA 获得了更高的[[牺牲引发剂]]效率。

同一课题组随后采用相同方法，从$\mathrm { \dot { C } N C s . ^ { 1 8 1 } }$接枝了多种甲基[[丙烯酰胺]]，例如 [[DMAEMA]]、DEAEMA 和 N-[3-(二甲氨基)丙基]甲基丙烯酰胺（DMAPMAM）。除了[[元素分析]]和[[热分析]]外，这些 [[纤维素纳米晶|CNC]] 杂化材料还通过交叉极化魔角旋转（CP-MAS）<sup>13</sup>C [[核磁共振|NMR]] 波谱进行了表征。后一种技术表明，组成取决于反应时间，但[[接枝聚合]]物的分子量和分散性未被报道。从 [[纤维素纳米晶体|CNCs]] 上进行 DEAEMA 的 [[SI-NMP]] 获得了最高接枝率，即 65 wt%。总体而言，与溶液 NMP 相比，关于从 CNCs 进行 [[表面引发氮氧调控聚合|SI-NMP]] 的动力学知之甚少，这为该领域留下了大量研究机会。

3.4. 从 [[纤维素纳米晶|CNCs]] 的[[还原端]]基进行聚合物接枝。单根[[纤维素]]链含有化学上不同的端基，通常称为[[非还原端]]和还原端。纤维素链的方向性是[[纤维素生物合成]]机制的直接结果。<sup>58</sup> 该还原端可在多种条件下于醛和[[环状半缩醛]]之间可逆转化。因此，可以通过醛选择性反应途径修饰该还原端，获得位点特异性或“斑块状”[[纤维素纳米晶体|CNCs]]。带有端基拴系聚合物链的 CNCs，对于某些应用而言，是均匀改性 CNCs 的一种有吸引力的替代方案，在这些应用中，可以利用其自组装构建具有独特性能的结构层级，包括表面组装和[[纳米复合材料]]中的组装。<sup>8</sup> 根据端基拴系聚合物的分子量，可以将这类各向异性胶体构建单元视为在一定程度上类似于[[棒-线圈嵌段共聚物|棒−线圈嵌段共聚物]]。<sup>182</sup>

已有多种不同方法被建立，用于将小分子或引发剂连接到 [[纤维素纳米晶|CNCs]] 的[[还原端]]基上。[[Arcot]] 等人报道了一种通过在水性介质中进行[[还原胺化]]，在 [[纤维素纳米晶体|CNCs]] 的还原端引入硫醇基团的方法。<sup>183</sup> 作者使用 [[6-氨基-1-己硫醇盐酸盐]]$\mathrm { ( N H _ { 2 } ( C H _ { 2 } ) _ { 6 } S H { \cdot } H C l ) }$、还原剂（Cn，[[氰基硼氢化钠]]；Ac，[[三乙酰氧基硼氢化钠]]；或 Pc，[[2-吡啶甲硼烷配合物]]）以及不同 pH（5、7 或 9.2）值下的 CNC 水分散液，合成了硫醇化[[纤维素]]纳米晶（CNC-SH）。随后，利用[[银纳米粒子]]（AgNPs）对 CNC-SH 进行功能化，以便表征还原端基改性的成功情况，定性采用[[透射电子显微镜]]（TEM），定量采用 [[XPS]]。作者确定，在碱性条件下可获得最高的功能化产率。

同一课题组随后提出了第二种硫醇化方法，其反应时间更短、条件更温和，且改性 [[纤维素纳米晶|CNCs]] 的[[胶体稳定性]]更高。<sup>184</sup> [[Usuda]] 及其同事此前已证明，可利用[[亚氯酸钠]]$\left( \mathrm { N a C l O } _ { 2 } \right)$将[[还原端]]选择性氧化为羧酸盐，从而获得更广泛的潜在修饰化学途径。<sup>185</sup> 因此，首先使还原端与 NaClO 反应，生成羧酸根功能化的 [[纤维素纳米晶体|CNC]] 还原端（CNC−COOH）。在该氧化步骤之后，通过 [[N-羟基琥珀酰亚胺]]（NHS）和 [[N-(3-(二甲氨基)丙基)-N-乙基碳二亚胺盐酸盐]]（EDC）介导，对羧基进行了温和活化，随后用$\mathrm { N H } _ { 2 } ( \mathrm { C H } _ { 2 } ) _ { 6 }$ SH·[[盐酸|HCl]] 进行亲核取代，得到 CNC-SH。

[[Gruber]] 等人通过[[腙键]]提出了一种不同的[[还原端]]基功能化策略。<sup>186</sup> 作者使用 [[4-肼基苯甲酸]]或[[自由基引发剂]] [[4,4′-偶氮双(4-氰基戊酸二酰肼)]]和 [[4-羧基苯基偶氮甲基丙二腈]]形成腙键，从而得到苯基羧酸酯封端的 [[纤维素纳米晶|CNC]]，产率为 44.6%。对于其他引发剂，4-肼基苯甲酸的转化也获得了相似的产率。作者推测，低产率是由于还原端基的可及性较差。如果认为单个分散的 [[纤维素纳米晶体|CNC]] 由 18 条链组成，<sup>58</sup> 这将意味着在[[纤维素]] I 晶体的一端最多有 18 个还原端基。鉴于 CNC 的棒状形貌，还原端基很可能呈非均相分布。这可能导致化学反应中还原端基可及性程度不同，但这一点仍有待探索。

[[Gruber]] 及其合作者通过 [[表面引发自由基聚合|SI-FRP]] 从第 3.2 节讨论并示于表 1 中的不同偶氮引发剂接枝了 [[聚丙烯酰胺|PAM]]。<sup>186</sup> 聚合物的分子量是在将 PAM 从 [[纤维素纳米晶|CNC]] 上解接枝后，通过 [[尺寸排阻色谱|SEC]] 测量确定的。作者观察到 PAM 具有高分子量，但只有少量引发剂发生反应，生成聚合物接枝的 [[纤维素纳米晶体|CNC]]。据报道，[[表面引发聚合]]的引发剂效率非常低，例如为 5−30%。<sup>28</sup>

最近，[[Zoppe]] 等人报道了一种用含 α-溴异丁酰基的 [[表面引发原子转移自由基聚合|SI-ATRP]] 引发剂对端基进行功能化的路线。<sup>172</sup> 按照 [[Arcot]] 等人的工作，<sup>184</sup> [[还原端]]首先用 ${ \mathrm { N a C l O } } _ { 2 }$ 氧化，并进一步用[[乙二胺]]（EDA）修饰。随后，伯胺基团与 [[2-溴异丁酸 N-羟基琥珀酰亚胺酯]]（[[N-羟基琥珀酰亚胺|NHS]]-BiB）反应，得到 [[ATRP]] 引发剂功能化的还原端基。尽管作者无法用 [[FTIR]]、[[XPS]] 和[[元素分析]]等常规技术定量确认引发剂修饰反应是否成功，但他们随后通过 SI-[[原子转移自由基聚合|ATRP]] 从 [[纤维素纳米晶|CNC]] 的功能化还原端基接枝了多种聚合物。所研究的单体包括 [[N-异丙基丙烯酰胺|NIPAM]]、METAC 和 4-SS。使用[[热重分析]]（TGA）、[[傅里叶变换红外光谱|FTIR]] 和 [[X射线光电子能谱|XPS]] 对 [[纤维素纳米晶体|CNC]] 的成功接枝进行了定性分析。为了直接观察[[接枝聚合]]物对 CNC 还原端的选择性修饰，将斑片状 CNC/PMETAC 杂化材料用[[金纳米粒子]]（AuNPs）标记，并通过[[冷冻透射电镜]]（cryo-[[透射电子显微镜|TEM]]）观察（图 7）。

## 4. 通过“[[接枝自]]”策略制备的聚合物改性 [[纤维素纳米晶|CNCs]] 的新兴应用与性质

学术界和产业界对 [[纤维素纳米晶|CNCs]] 及其杂化[[纳米材料]]日益增长的兴趣，推动其在前所未有的应用中被提出。<sup>3,5,7,8,24,26,92</sup> 这些应用包括 [[Pickering 乳液]]、功能材料纳米模板、[[超级电容器]]、[[生物传感器]]、药物递送以及对映选择性催化。在此，我们将重点介绍聚合物改性 [[纤维素纳米晶体|CNCs]] 的一些新兴应用，其中[[接枝自]]策略具有高[[接枝密度]]和分子量，先验地优于其他聚合物接枝策略。在以下各节中，将讨论其在杂化[[胶体液晶]]（LC）、[[刺激响应性]]纳米杂化材料、[[纳米复合材料]]和[[水凝胶]]中的应用及其独特性质。

4.1. 自组装、杂化[[胶体液晶]]与光学性质。[[纤维素纳米晶|CNCs]] 具有形成[[手性向列相]]液晶相的神奇能力，这取决于若干因素，尤其是[[长径比]]、表面电荷密度、离子强度、外场和溶剂条件。<sup>31</sup> 在临界浓度以上，[[纤维素纳米晶体|CNCs]] 会从各向同性相转变为手性向列相（胆甾相）液晶相（图 8）。<sup>187</sup> 棒状粒子优先使其长轴沿指向矢排列。每个准层（定义为垂直于螺旋轴取的无限薄层）的指向矢在每一后续层中绕螺旋轴略微旋转。指向矢完成 360° 旋转所需的垂直距离被定义为螺距。<sup>188,189</sup> 当悬浮液在基底上干燥时，随样品浓度增加而形成的手性向列结构在溶剂完全蒸发后得以保持，从而形成螺距尺寸减小到亚微米尺度的薄膜。<sup>31</sup> 通过对干燥条件进行控制，薄膜可以在厚度上保持均匀，同时保留 $\mathrm { C N C s } .$ 190 的长程有序性。因此，该薄膜表现为光子晶体，只有与胶体螺旋具有相同手性的圆偏振光会被反射，在这种情况下为左旋圆偏振光。<sup>188</sup> 自组装 CNCs 的这些吸引人的性质带来了多种有趣的应用，例如光学加密器件、传感器、介孔手性纳米模板和安全涂层。188,189,191,192

从 ${ \mathrm { C N C s } } ,$ [[接枝聚合|表面接枝聚合]]物无疑会影响其组装行为。聚合物接枝 [[纤维素纳米晶|CNC]] 的自组装引起极大关注，因为可通过熵驱动过程获得更复杂的组装体。此外，由于 [[纤维素纳米晶体|CNC]] 的分散性可通过表面改性调节，其自组装有望在多种溶剂中实现。此类接枝 CNC 可产生基于[[胶体液晶]]组装的多种 CNC 功能材料和模板。然而，聚合物接枝 CNC 的自组装迄今尚未得到广泛探索，因为接枝链可能改变 ${ \mathrm { C N C s } } ,$ 的堆积密度，当达到一定接枝分子量和[[接枝密度]]时，它们可能表现得更像球形物体。<sup>193</sup> 不过，通过“[[接枝到]]”方法，Jean 等人表明，聚醚胺改性的 CNC 可自组装成[[手性向列相]]，尽管其临界浓度低于未改性 CNC。<sup>194</sup>

4.2. [[刺激响应性]]纳米杂化材料。生命体中的生物聚合物普遍参与动态系统，这些系统会根据周围环境条件促进结构变化。<sup>197</sup> 这些性质基于高度协同的相互作用，为微小外部变化引发的响应提供了显著的驱动力。类似的适应性行为可以通过在合成聚合物主链中引入能够响应多种外部化学（pH、离子因素或化学试剂）或物理刺激（温度、电场或磁场、光照或机械应力）的官能团来赋予（图10）。这些被称为刺激响应性聚合物或智能聚合物。通过将此类聚合物从[[纤维素纳米晶|CNC]]表面接枝，可以制备具有可逆界面性能的杂化[[纳米材料]]。

4.3. [[纳米复合材料]]。纳米复合材料是由两种或更多组分组成的材料，通常包含基体和填料，处于固态或类凝胶态，其中填料处于纳米尺度。文献中报道了多种制备[[纤维素]]纳米复合材料的加工路线，例如溶液浇铸、熔融挤出、压缩成型、注射成型、球磨，甚至沉淀法。<sup>4,5,7,203</sup> 优异的力学性能和高[[BET|比表面积]]表明，[[纤维素纳米晶|CNCs]] 可对其他聚合物材料提供良好的增强作用。[[纤维素纳米晶体|CNCs]] 的增强潜力最早由 Favier 等人报道，他们将海鞘来源的 CNCs 掺入[[苯乙烯]]（Sty）与[[丙烯酸]]丁酯（BA）的共聚物（P(Sty-co-BA)）中。<sup>204,205</sup> CNCs 的增强效应通常被解释为刚性逾渗网络的形成，在该网络中，填料纳米粒子通过[[氢键|氢键相互作用]]。<sup>5</sup> 实验证据和统计模型表明，基体、填料特性（如[[长径比]]、分散性和体积分数）以及它们之间的相互作用（填料−基体和填料−填料）都会影响纳米复合材料的力学性能。<sup>3</sup>

尽管已有报道表明未改性的 [[纤维素纳米晶|CNCs]] 在某些材料中能够提供增强作用，<sup>204−206</sup> 但 [[纤维素纳米晶体|CNC]] 表面的亲水性使其难以在聚合物基体中分散，尤其是在非极性或疏水性基体中。此外，其表面大量的 −OH 基团会通过[[氢键]]促进 CNCs 的团聚，从而限制力学增强的程度。在这方面，对 CNC 表面进行改性是建立 CNCs 与（疏水性）聚合物基体之间良好界面粘附的一种可行方法，理想情况下不会损害 CNCs 的固有性能及其填料−填料相互作用。许多研究致力于对 CNC 表面进行改性，以提高其与疏水性介质的相容性。<sup>4</sup>

一类基于聚合物改性[[纤维素纳米晶|CNC]]的新型[[纳米复合材料]]，被称为[[单组分纳米复合材料]]（OCNs）或共连续复合材料，最近开始引起关注。与传统复合材料不同，这些材料（顾名思义）仅含一种组分，即[[纤维素纳米晶体|CNC]]，其上接枝了大量聚合物链并充当“基体”。由于聚合物通过共价键连接在CNC上，这些体系通常不会像传统纳米复合材料那样遭受相分离或混合问题，同时受益于两种组分共同贡献的性能。

首个实例由Chen等报道，他们通过[[表面引发开环聚合|SI-ROP]]在[[纤维素纳米晶|CNC]]表面接枝[[聚（ε-己内酯）|PCL]]链，制备了一种可热成型材料。<sup>112</sup>接枝链的分子量未知，但根据反应时间和所采用的两种不同[[微波辐照]]功率（160和320 W），计算出[[纤维素纳米晶体|CNC]]-g-PCL中聚合物刷含量在92至96 wt %之间。此外，这些OCN的力学性能表现出非线性依赖关系，表明反应条件可能影响接枝链的数目和长度。

最近，另一项研究表明，基于[[纤维素纳米晶|CNC]]-g-[[聚甲基丙烯酸甲酯|PMMA]]的OCN材料在两种不同组成（即10和20 wt %的[[纤维素纳米晶体|CNC]]）下，其性能优于相应的传统双组分[[纳米复合材料]]。<sup>93</sup> 例如，CNC-g-[[聚（甲基丙烯酸甲酯）|PMMA]]在25 °C下的E′为3168 MPa，而10% w/w PMMA/CNC传统纳米复合材料的E′为3018 MPa。作者认为，应力传递是通过连接到CNC上的聚合物链介导的。实际上，OCN材料因其易加工特性而具有广阔前景，同时还兼具高刚度、高强度和高韧性的独特组合。<sup>93</sup>

4.4. [[水凝胶]]。水凝胶是柔软的[[交联]]三维网络，主要基于亲水性聚合物材料，能够容纳大量水或生物溶液。这类软材料具有许多潜在应用，尤其是在生物医学领域。<sup>128</sup> [[纤维素纳米晶|CNC]]的亲水特性和固有性质使其成为形成增强型或结构化水凝胶[[纳米复合材料]]的有吸引力候选材料。<sup>210</sup> 基于聚合物接枝[[纤维素纳米晶体|CNC]]的水凝胶通常表现出增强的力学性能，这是因为CNC作为多功能交联点和邻近聚合物链之间的桥接发挥着关键作用。

Zhou等人报道了在[[N,N'-亚甲基双丙烯酰胺|NMBA]]作为[[交联]]剂存在下，由[[聚丙烯酰胺|CNC-g-PAM]]合成[[水凝胶]]。<sup>128</sup> 接枝的[[纤维素纳米晶|CNC]]加速了水凝胶的形成，并提高了材料的有效交联密度。PAM与[[纤维素纳米晶体|CNC]]之间的界面相互作用得到显著改善，且增强效应通过含有6.7 wt % [[聚丙烯酸甲酯|CNC-g-PMA]]的水凝胶压缩应力提高2.5倍得到证实。随后，报道了一种三组分超分子[[纳米复合水凝胶]]，其具有高刚度、快速溶胶−凝胶转变和自修复性能。<sup>166</sup> 该体系由含甲基紫精官能团的聚乙烯醇（PVA）、CNC-g-P([[DMAEMA]]-ran-NpMA)和葫芦[8]脲（CB[8]）超分子交联组成，其中CB[8]（主体）在化学计量摩尔比下选择性地同时结合甲基紫精基和萘基客体单元（图15）。

尽管在[[纤维素纳米晶|CNC]]基[[水凝胶]]合成中使用外加[[交联]]剂是一种已知做法，但可以通过设计含有能够在三维网络中物理或化学交联的结构单元的[[纤维素纳米晶体|CNC]]基体系来避免外加交联剂。此类体系的第一个例子基于[[聚丙烯酸甲酯|CNC-g-PMA]]。<sup>138</sup> 由于[[PMA]]刷的特性，该水凝胶呈现弹性体特征，并由于独特的核/壳网络结构而具有高韧性，其中CNC作为多功能交联点，从而产生独特的力学性能。

最近，一种弹性大孔复合[[水凝胶]]通过含[[丙烯酰胺]]和凝胶化甲基[[丙烯酸]]酯的[[纤维素纳米晶|CNC]]-g-PUPyMA水相聚合制备而成。123 其[[溶胀率]]、孔径和机械强度可通过调控[[纤维素纳米晶体|CNC]]-g-PUPyMA的掺入浓度进行调节。该材料在10 min内达到70%的溶胀率，而当改性CNC浓度从0.1 wt %提高到0.5 wt %时，孔径分别由62 μm降至30 μm。在较高CNC含量下，机械强度也显著提高，当CNC-g-PUPyMA浓度从0.1 wt %变化至0.5 wt %时，约为50 kPa。此外，这些材料在体外细胞培养中表现出良好的生物相容性以及可观的细胞黏附与增殖能力。

## 5. 总结与展望

自[[Habibi]]等人2008年关于从[[纤维素纳米晶|CNCs]]进行[[ε-己内酯|ε-CL]]的[[表面引发开环聚合|SI-ROP]]开创性工作以来，<sup>30</sup> 利用[[纤维素纳米晶体|CNCs]][[表面引发聚合]]以调控其性能的科学研究已在百余篇文献中体现。大多数研究涉及以高密度聚合物刷改性CNCs的合成路线，而采用 [[接枝自|grafting from]] 技术可适当实现这一目标。纵观文献，这些方法在反应步骤数、条件和聚合物刷特性方面各有明显优缺点。

例如，[[表面引发开环聚合|SI-ROP]]的优点在于通常无需预先在[[纤维素纳米晶|CNC]]表面固定引发剂，因为SI-[[开环聚合|ROP]]可直接从[[纤维素纳米晶体|CNC]]的−OH基团进行，尽管需在干燥有机溶剂中进行。虽然关于此类聚合物接枝的分子量和分散性信息非常有限，但已有报道表明聚合物链相对较短，$e . g . , \mathrm { D P } = 1 2 . ^ { 1 0 7 }$ 相比之下，其他研究者报道了较高的聚合物含量（高达96 wt %），<sup>112</sup> 这可能暗示获得了高[[接枝密度]]、高分子量，或二者兼具。

类似地，[[表面引发自由基聚合|SI-FRP]] 也可在较高温度下使用，无需事先在 [[纤维素纳米晶|CNC]] 表面固定引发剂，但据推测，根据本体 FRP 动力学，可获得更高的分子量。此外，当期望获得高 [[聚合度|DP]] 时，尽管对分子量的控制较差，使用连接在 [[纤维素纳米晶体|CNC]] 表面的[[自由基引发剂]]可能是一种替代方案。<sup>93</sup> 由于许多研究者专注于利用 SI-FRP 来制备[[纳米复合水凝胶]]，因此关于[[接枝聚合]]物的分子量和分散性的信息仍然有限。

[[表面引发可控自由基聚合|SI-CRP]] 方法可用于生长具有可控分子量和分散性的聚合物刷，但通常需要事先将合适的引发剂或 [[链转移剂|CTA]] 连接到 [[纤维素纳米晶|CNC]] 表面。一个例外是 [[S-RAFT]] 方法，其中聚合在自由大分子 [[可逆加成−断裂链转移聚合|RAFT]] 试剂存在下进行，并由 [[硝酸铈(IV)铵|CAN]] 引发。<sup>96,180</sup> 尽管引发剂固定化是从 [[纤维素纳米晶体|CNC]] 进行 [[Cu]] 介导的 SI-CRP 的先决条件，但已有研究表明，此类引发剂可以在[[硫酸水解|硫酸水解过程]]中原位共价连接，从而制备功能化的 $\mathrm { C N C s . } ^ { 9 5 }$

在这些 [[Cu]] 介导的体系中，[[纤维素纳米晶|CNC]] 固有的表面化学性质，即[[硫酸半酯|硫酸半酯基团]]，在水介质中进行聚合时也会对聚合动力学产生影响，这是由于 [[铜|Cu]]/配体物种形成双电层所致。<sup>173</sup> 关于 [[SI-NMP]]，其合成策略较为简单：一旦 NMP 引发剂[[接枝到]] [[纤维素纳米晶体|CNC]] 表面，仅需单体和加热即可引发聚合。<sup>143,181</sup> 尽管关于聚合物接枝特性的信息仍然缺乏，但在 [[表面引发氮氧调控聚合|SI-NMP]] 过程中原位合成的自由聚合物的 M 值超过 100 kDa。<sup>143</sup> 在大多数 [[表面引发可控自由基聚合|SI-CRP]] 情况下，在适当的反应条件下可以获得分子量 >100 kDa 的聚合物。总体而言，关于从 CNC 表面裂解聚合物以准确测定其分子量和[[接枝密度]]的分析报道很少，因此与类似的溶液聚合相比，关于 CNC 上聚合物刷生长动力学仍有许多尚待理解之处。

由于其他类型平面和曲面界面上[[表面引发聚合]]的动力学通常被报道为与溶液聚合显著不同，<sup>28</sup> 这也可能适用于 [[纤维素纳米晶|CNC]] 上的聚合物刷生长，并且将在很大程度上取决于聚合技术、单体、溶剂、反应条件等。利用可裂解官能团共价连接引发剂物种<sup>28,115</sup> 以及应用新技术测定聚合物刷[[接枝密度]]<sup>211</sup> 是应对这一挑战的有前景的方法。

除了开发用于化学合成聚合物改性 [[纤维素纳米晶|CNC]] 的适当策略以及对聚合物刷生长动力学的基础研究之外，这些研究工作中的大多数都集中于通过表面功能化利用 [[纤维素纳米晶体|CNC]] 独特的热机械性能，将其作为疏水性聚合物基体中的增强填料。此类[[纳米复合材料]]主要通过溶液浇铸和各种形式的熔融加工制备。

一些工作试图通过完全去除聚合物基体组分，制备不受亲水性 [[纤维素纳米晶|CNCs]] 与疏水性聚合物共混加工限制的[[纳米复合材料]]，即所谓的一维纳米粒子（[[单组分纳米复合材料|OCNs]]）。<sup>93,112</sup> 这些体系的优势在于较少受组分相分离的影响，并且只要聚合物接枝的分子量足以使相邻杂化纳米粒子之间形成链缠结，就能提供更优异的力学性能。这方面的一个挑战是在不损害 [[纤维素纳米晶体|CNCs]] 结构完整性的前提下获得如此高分子量的聚合物接枝。由于使用[[表面引发开环聚合]]（SI-[[开环聚合|ROP]]）通常只能获得有限分子量，<sup>107</sup> 因此它可能并不适合此类应用。与[[表面引发可控自由基聚合]]（SI-CRP）相比，这一目标或许最好通过表面引发常规自由基聚合（[[表面引发自由基聚合|SI-FRP]]）技术实现，因为对聚合物接枝分散性的良好控制可能并不是那么关键。然而，仍存在许多开放性研究问题：纳米粒子间链缠结、各向异性、分子量和[[接枝密度]]之间有何关系？[[接枝聚合]]物的分散性如何影响棒状纳米物体 OCNs 的热机械性能？此外，可以设想由[[嵌段共聚物|嵌段]]或[[无规共聚物]]接枝组成的 OCNs，其具有不同的相，例如硬相和软相，可能表现出有趣的相分离行为。

从液晶（[[胶体液晶|LC]]）研究的角度来看，各向异性胶体杂化材料是阐明构筑基元性质与自组装之间关系的有用模型。在这一类别中，[[纤维素纳米晶|CNCs]] 的独特之处在于，它们在蒸发诱导自组装（EISA）过程中能够在固态下保持其手性液晶组装结构，这为制备具有长程手性有序的介孔无机固体开辟了新途径。<sup>191</sup> 这类手性材料在对映选择性分离、不对称催化和手性光学方面具有重要意义。迄今为止，此类模板过程大多局限于水性体系，这对可制备的手性介孔固体种类构成了诸多限制。此外，由于表面电荷密度、[[纤维素纳米晶体|CNC]] 手性、[[长径比]]和分散性之间复杂的相互作用，CNCs [[手性向列相]]的螺距对添加剂的存在、pH、离子强度、外场和蒸发速率都很敏感。<sup>31,212−214</sup> 这些因素常被用来调控 CNC 液晶相在溶液和自支撑薄膜中的光学性质。然而，这些手段通常不是可逆过程，而通过引入[[刺激响应性]]聚合物体系可以更好地实现可逆调控。

在这方面，通过[[接枝聚合]]物进行[[表面化学改性]]的探索尚不广泛。这可能是由于大分子层会对自组装过程造成扰动。尽管如此，模拟已表明这种影响取决于纳米棒上聚合物接枝链的堆积密度。<sup>215</sup> 因此，在[[纤维素纳米晶|CNCs]]的[[还原端]]进行选择性改性可能实现足够的堆积密度并形成[[手性向列相]]。尽管尚无此类聚合物端基改性[[纤维素纳米晶体|CNCs]]形成手性向列相的实验数据，Horsch等人报道了关于非手性端基接枝纳米棒手性向列相的理论描述。<sup>215−217</sup> 此外，如第3.4节所述，[[Zoppe]]等人提出以对称（可能使用[[纤维素]]II晶型的CNCs）和不对称CNCs（纤维素I晶型）作为新型胶体构建单元的出发点，用于自组装结构。<sup>172</sup> 而且，从合成此类聚合物改性CNCs到其自组装及应用，仍有许多研究挑战有待解决。

此外，[[纤维素纳米晶|CNC]]的[[长径比]]和聚合物与接枝链长度之比很可能在其自组装中发挥关键作用。其他问题包括：减小[[纤维素纳米晶体|CNCs]]尺寸分布的最有前景的方法是什么？[[纤维素]]晶型结构如何影响其本征手性形貌和组装？端基[[接枝聚合]]物能否使聚合物改性CNCs在没有[[硫酸半酯|硫酸半酯基团]]的情况下形成手性液晶相？它们是否会相分离成确定的形貌？这些挑战将在我们未来的研究中加以探讨，我们也鼓励该领域的其他研究者加入这一令人振奋的研究路径。总体而言，我们希望这类端基改性的聚合物改性CNCs将为基础理解各向异性胶体自组装调控过程开辟新途径，并催生一系列具有程序化手性的新型[[纳米复合材料]]和功能材料。
