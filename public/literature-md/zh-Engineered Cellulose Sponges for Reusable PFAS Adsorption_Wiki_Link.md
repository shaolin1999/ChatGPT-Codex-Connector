## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是一类合成氟碳分子，已在众多工业和商业应用中广泛用作[[防水剂]]和[[阻燃剂]]。<sup>1</sup> PFAS 的定义特征是含有一个或多个完全氟化的[[甲基]]或[[亚甲基]]碳原子，其[[链长]]和末端基团组成具有多样性。PFAS 在环境相关的 [[pH值|pH 值]]（[[pH]] 6−7）下通常以[[阴离子]]形式存在，并因同时具有[[疏水性]]氟碳区域和[[极性]]头部[[官能团]]而表现出[[两亲性]]。<sup>2,3</sup> [[碳氟键|碳−氟键]]的[[电负性]]及由此产生的高键强度赋予 PFAS 极强的抗机械、化学和[[生物降解]]能力，使其在环境系统中具有高度持久性。<sup>4</sup>

[[全氟和多氟烷基物质|PFAS]] 的[[环境持久性]]，加之其在消费品和工业产品中的广泛使用，导致其在全球水系统中被广泛检出。监测研究表明，超过 96% 的美国普通人群血清中可检测到 PFAS。<sup>5−11</sup> 已知 PFAS 还会因消除缓慢，以及在[[肾脏滤过]]和[[肠肝循环]]过程中发生[[重吸收]]而在生物系统中累积，其[[生物半衰期]]可达数年。<sup>12−15</sup> PFAS 暴露与一系列不良健康结局有关，包括[[高血压]]、[[高胆固醇血症]]、发育影响以及多种[[癌症]]。<sup>16−19</sup> 因此，开发有效的处理技术以去除水系统中的 PFAS，已成为一项日益重要的环境挑战。

在现有处理策略中，采用[[颗粒活性炭]]（GAC）进行[[吸附]]仍是[[饮用水处理|饮用水]]和[[废水处理]]系统中应用最广泛的 [[全氟和多氟烷基物质|PFAS]] 去除技术之一。PFAS 的疏水结构域与 GAC 的非[[极性]]表面及内部[[孔结构|孔隙结构]]相互作用，使其能够通过在 GAC 广阔的内[[表面积]]（通常为 500−900 $\mathrm { ~ m } ^ { 2 } \ \mathrm { g } ^ { - 1 } ) . \mathrm { } ^ { 2 0 }$ 然而，PFAS 分子向 GAC [[微孔|微孔结构]]内部[[扩散]]时所受到的[[传质限制]]可能影响[[吸附动力学]]。<sup>21</sup> 此外，吸附了 PFAS 的 GAC 的再生可能需要消耗大量能源，因为[[热再生]]过程通常需要超过 $6 0 0 ~ ^ { \circ } \mathrm { C }$ 的温度，才能有效[[解吸]]强吸附的含氟化合物。<sup>22−25</sup> 这些因素推动了对替代吸附材料的研究，以期在高效去除 PFAS 的同时，实现更具可持续性的再生策略。

因此，研究人员探索了多种用于去除 [[全氟和多氟烷基物质|PFAS]] 的新兴[[吸附]]材料，包括[[金属有机框架]]（MOFs）、[[共价有机框架]]（COFs）、[[矿物]]、[[沸石]]、[[功能化聚合物]]和[[改性离子交换树脂]]。<sup>26−37</sup> 其中许多材料引入了带正电荷的[[官能团]]，以增强其与带负电荷的 PFAS 头基之间的[[静电相互作用]]，或引入[[疏水性]]区域，以增强其与[[氟碳链]]之间的相互作用。<sup>38</sup> 尽管这些工程化[[吸附剂]]可表现出较高的[[吸附容量]]，但其应用可能受到材料成本、39 规模化能力和长期可持续性等因素的限制。

[[纤维素]]因其储量丰富、可再生以及作为结构性[[聚合反应|聚合]]物的多功能性，近年来成为一种颇具前景的[[吸附剂]]平台。<sup>40</sup> 纤维素可加工成多种结构形态，包括[[微晶]]、[[纳米纤维]]、[[水凝胶]]以及海绵等[[三维多孔骨架]]。<sup>41</sup> 这些多样的结构形态使研究人员能够调控[[表面化学|表面化学性质]]和[[孔结构]]，以适应特定的[[吸附]]应用和构型。近期已有多项研究探索了用于去除 [[全氟和多氟烷基物质|PFAS]] 的[[功能化纤维素材料]]（表 1）。<sup>42,43</sup> 例如，[[Li]] 等人证实了[[GTMAC|甲基丙烯酸缩水甘油酯三甲基氯化铵]]（GTMAC）[[改性纤维素]]纳米晶用于吸附 PFAS 的可行性，实现了快速的[[吸附动力学]]过程，并大量去除了 [[全氟辛烷磺酸|PFOS]] 和

[[全氟辛酸|PFOA]]。<sup>44</sup> [[Franco]] 等人将废弃[[苹果渣]]加工成[[纤维素纳米晶]]，并使用源自[[辣木]]（Moringa oleifera）的[[阳离子蛋白]]对其进行改性，使其表现出可测得的 PFOA [[吸附容量]]。<sup>45</sup> [[Gomri]] 等人使用[[含胺聚合物]]对[[纤维素]]纳米晶进行功能化，以增强其与 PFOA 之间的[[静电相互作用|静电吸引]]。<sup>46</sup> 类似地，[[Ateia]] 等人证实，[[聚乙烯亚胺接枝纤维素]]能够显著去除 [[全氟和多氟烷基物质|PFAS]]，并可使用[[甲醇]]进行再生（表 1）。<sup>47</sup>

总体而言，这些研究表明，[[纤维素]]基材料具有作为可调控、多功能[[吸附剂]]去除 [[全氟和多氟烷基物质|PFAS]] 的潜力。然而，大多数已报道的策略主要侧重于引入[[阳离子官能团]]，以增强其与带负电荷的 PFAS 头基之间的[[静电相互作用]]。已有研究表明，含[[氟碳链]]与非[[极性]]表面之间的[[疏水相互作用]]也对 PFAS 的[[吸附]]行为有显著贡献。<sup>48−51</sup> 相较之下，考察纤维素基底的[[疏水性]][[表面改性]]如何影响 PFAS 吸附行为的研究较少，尤其是在[[大孔]]三维纤维素基体中。此外，尽管吸附性能经常被报道，但系统评估[[改性纤维素]][[吸附剂再生]]行为的研究较少，而在考虑其于[[水处理]]系统中的实际应用时，再生行为是一个重要因素。

本研究采用阳离子亲水性、短链[[疏水性]]和长链疏水性[[硅烷]]对市售[[纤维素海绵]]进行[[表面改性]]，以评估[[表面化学|表面化学性质]]如何影响四种代表性 [[全氟和多氟烷基物质|PFAS]] 化合物的[[吸附]]行为，并与[[颗粒活性炭]]（GAC）进行比较。选择海绵作为[[吸附剂]]基体，是因为其具有高度多孔的三维结构，其中包含相互连通的[[大孔]]和[[介孔]]，能够在孔隙空间内保留空气。这些结构特征可能通过增大[[界面面积]]和提高[[吸附位点]]的可及性，影响 PFAS 的传输和吸附行为。<sup>52−54</sup> 除吸附性能外，还使用多种溶剂体系评估了改性海绵的再生行为。使用去离子（DI）水评估基准再生效果，并与使用 100% [[甲醇]]以及含 0.5 M 硝酸钾的 10% 甲醇溶液的再生效果进行比较。加入硝酸根离子是基于其在 Hofmeister 序列中的离液行为，这可能影响 PFAS 从疏水表面的[[解吸]]。<sup>55</sup> 通过考察[[表面官能化|表面功能化]]与[[再生液|再生剂]]化学性质的共同作用，本研究为如何设计兼顾 PFAS 吸附性能与[[可再生性]]的[[纤维素基吸附剂]]提供了见解。

## 2. 材料与方法

## 2.1. 材料选择

图 1 所示的硅烷分子，包括氨丙基三乙氧基硅烷（APTES）、三乙氧基辛基硅烷（C8）和三甲氧基十八烷基硅烷（C18），均购自 Sigma Millipore（美国马萨诸塞州伯灵顿）。PFAS 化合物，包括全氟辛酸（PFOA）、全氟辛烷磺酸（PFOS）、全氟丁酸（PFBA）和全氟丁烷磺酸（PFBS），也购自 Sigma。上述各 PFAS 分子的同位素标记标准品购自 Wellington Laboratories（加拿大安大略省圭尔夫）。HPLC 级甲醇、乙醇和己烷购自 VWR International（美国宾夕法尼亚州拉德诺）。市售纤维素海绵购自 3M（美国明尼苏达州梅普尔伍德）。颗粒活性炭购自 Kolar Laboratories（美国伊利诺伊州芝加哥）。

## 2.2. [[表面活化]]与改性

采用[[硅氧烷薄膜]]对[[纤维素海绵]]进行[[表面改性]]，以评估其对 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的影响。[[硅烷|硅烷分子]]已广泛应用于众多需要特定[[表面化学|表面化学性质]]的领域，并常用于[[纤维素]]的功能化。<sup>56−61</sup> 选择 [[3-氨丙基三乙氧基硅烷|APTES]] 来评估[[静电相互作用]]对 PFAS 吸附的影响，其表面[[胺基]]在环境 [[pH值|pH 值]]（6−8）下带正电荷。<sup>62</sup> 选择 [[C8硅烷|C8]] 和 [[C18硅烷|C18]] 分子，以考察疏水[[链长]]度及由此决定的[[表面疏水性]]强弱与 PFAS 吸附之间的相关性。对于每种硅烷改性，还使用经过清洗但未经改性的纤维素海绵作为对照。此外，将每种海绵的性能与市售 [[颗粒活性炭|GAC]] 进行比较，以评估其作为[[吸附剂]]的竞争力。将海绵切成 50−100 mg 的小块，并浸入含 0.5 M NaOH 的 75% 乙醇溶液中活化 3 h，以去除其[[羟基]]上的杂质。随后，将样品置于 100 °C 的真空烘箱中干燥 24 h。下文将经过清洗和预处理的海绵称为“[[活化纤维素海绵|活化海绵]]”。随后，将待改性的海绵浸入以己烷（C8、C18）或乙醇（APTES）为溶剂的 1% 硅烷溶液中，并置于振荡平台上以 120 rpm 振荡 24 h。硅烷分子与纤维素[[聚合反应|聚合]]物中的羟基发生[[缩合反应|缩合]]，形成[[共价键]]。<sup>63</sup> 随后，将海绵样品置于新鲜溶剂中超声处理 15 min，以去除非共价结合的硅烷分子，然后在 100 °C 的真空烘箱中干燥 3 h。从每种改性类型中取样进行表征。总体反应示意见图 1。

## 2.3. 材料表征

为评估[[吸附]]材料的[[表面形貌]]，使用 FEI Company Inspect S [[SEM|扫描电子显微镜]]（Hillsboro, OR, USA）通过扫描电子显微技术（[[扫描电子显微镜|SEM]]）观察各样品的图像。成像前，使用 Ladd-Hummer 6.2 溅射镀膜仪（Ladd Research, Williston, VT）在海绵表面沉积一层厚约 5 nm 的金膜。

随后，使用配备锗晶体的 Thermo Fisher Scientific Nicolet iS50R 仪器（Waltham, MA, USA）采集各类样品的[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FT-IR]]），以表征其[[表面化学|表面化学环境]]。之后，使用 Kratos Axis Ultra 165 Hybrid Photo electron Spectrometer（Wharfside, Manchester, U.K.）获取样品表面的 X 射线光[[电子能谱]]（[[XPS]]），以确定具体的[[表面元素组成]]。在每个样品表面的三个位置采集全谱和氟元素扫描谱。

为了[[解吸]]附剂[[表面积]]对[[吸附]]的影响，使用通入超纯氦气和氮气的 Micromeritics Gemini III 仪器（Norcross, Georgia, U.S.），对每个样品进行三次 Brunauer−Emmett−Teller（[[BET]]）测量，以分析各[[吸附剂]]的[[比表面积]]。

随后，使用配备圆柱形样品池的 Anton Paar Surpass3 流动 [[Zeta 电位]]仪（Graz, Austria）进行 [[Zeta 电位测量]]，以获得各材料的[[表面电荷]]。将样品切成直径 15 mm、厚度 2 mm 的圆片，然后在 1 mM 氯化钾溶液中，于 [[pH]] 2 至 10 范围内进行扫描。在每个 [[pH值|pH]] 点进行五次 Zeta 电位测量，每次提高 pH 值之间进行两次冲洗。

使用 TA Instruments Discovery [[热重分析|TGA]] 5500（New Castle, DE, U.S.）对各类样品进行热重分析（TGA），进一步确认了[[表面硅烷化]]。其中，将 5 mg 样品置于铂坩埚中，在氮气气氛（50 mL/min）下以 3 °C/min 的升温速率加热，直至达到最高温度 700 °C。

[[全氟和多氟烷基物质|PFAS]] 浓度 $( \sim 5 \mathrm { ~ m g ~ L ^ { - 1 } } )$ 高于大多数环境水体中通常存在的浓度；在这些水体中，PFAS 浓度通常为 ng $\mathrm { L } ^ { - 1 }$ 至 $\mu \ g \ L ^ { - 1 }$ 水平。有意选择这些较高浓度，是为了在接近[[吸附饱和|吸附剂饱和]]的条件下，对不同[[改性纤维素|改性纤维素材料]]的[[吸附]]行为进行受控比较。吸附研究通常采用类似的浓度范围，以评估[[吸附剂]]的相对性能，并更清晰地辨析 PFAS−[[表面相互作用]]的机制变化趋势。<sup>46,73−75</sup> 尽管这种方法能够对吸附剂性质进行比较评估，但未来工作应研究改性[[纤维素]]材料在与环境相关的 PFAS 浓度及更复杂[[水体基质]]中的性能。采用逐渐升高的 PFAS 浓度（1 μg/L 至 5 mg/L）开展了初步[[批次吸附实验]]，以确定各类海绵吸附剂的饱和浓度范围。单种 PFAS 浓度在 3 mg/L 至 5 mg/L 之间时，足以使表面达到饱和，图 S2 中的 [[全氟辛酸|PFOA]] 即为一例。在较低浓度下，PFAS 几乎被完全去除，因此[[循环吸附实验|循环研究]]未采用这些浓度，以便更好地评估海绵的[[再生能力]]。因此，所有后续实验均选用 5 mg/L 的浓度，以确保海绵达到饱和。[[批次动力学实验]]在每个采样时间点均使用独立的试管，以避免扰动吸附剂−溶液体系；然而，各海绵块[[孔结构|孔隙结构]]的不均一性可能导致结果出现变异。如图 S3 所示，在 5 mg/L 浓度下，所有纤维素样品均在数分钟内达到饱和。由饱和实验计算得到的[[速率常数]]见图 S4 和表 $\mathrm { S } 4 ^ { 7 6 }$ [[准二级动力学模型|PSO 动力学模型]]对所采集的随时间变化的数据拟合最佳，这是因为海绵中较大的[[微孔]]允许物质在基体中快速[[扩散]]，使吸附过程主要取决于纤维素[[固液界面|固−液界面]]的特性。<sup>77</sup> [[Ateia]] 等人采用[[聚乙烯亚胺|聚乙烯亚胺聚合物]]改性的[[纤维素纳米晶]]，在 PFOA 浓度为 100 ppb 时，获得的 $k _ { 2 }$ 值为 $0 . 0 0 1 ~ \mathrm { g { \cdot } \bar { m } g ^ { - 1 } } .$ min<sup>−1</sup>。他们还发现，在其实验中，<90% 的 PFAS 在接触后的最初数分钟内被其纤维素吸附剂吸附。Gomri 等人、Franco 等 $\mathrm { { a l , } }$ 和 Li 等人均报告了类似结果，即在与 PFAS 接触后的第一个小时内达到平衡。本研究中的 PSO 速率常数 $\left( k _ { 2 } \right)$ 如表 ${ \mathrm { S 4 } } ,$ 所示，与文献中用于 PFAS 吸附的其他纤维素材料的结果吻合良好。<sup>44−47</sup> [[C8硅烷|C8]] 改性海绵对[[全氟烷基羧酸盐]]（PFOA 和 [[全氟丁酸|PFBA]]）表现出最快的[[吸附动力学]]。一个有趣的发现是，不同 PFAS 的[[吸附速率]]与海绵[[表面组成]]之间似乎不存在直接相关性。

## 3.3. 循环与再生研究

为确定[[纤维素海绵]]作为 [[全氟和多氟烷基物质|PFAS]] [[吸附剂]]的有效性，开展了为期 10 天的[[循环吸附实验|循环研究]]。批次实验使用分别添加了单种 PFAS、浓度为 5 mg/L 的[[去离子水]]，孵育 24 h 后，在纯水、100% [[甲醇]]或含 0.5 M $\mathrm { K } \bar { \bf N } { \bf O } _ { 3 }$ 的 10% 甲醇中再生。每个[[吸附]]循环后，通过 [[液相色谱串联质谱|LC-MS/MS]] 定量测定吸附和回收的 PFAS 浓度。尽管环境中的大多数 PFAS 浓度通常显著更低，此处仍选择 5 mg/L 的浓度，旨在使[[纤维素]]结构内的所有[[吸附活性位点|活性位点]]完全饱和。图 5a 展示了吸附剂材料的性能，以每个批次循环中 PFAS 的[[去除率|去除百分比]]表示。总体而言，[[活化纤维素海绵|活化海绵]]和 [[C18硅烷|C18]] 改性海绵对长链和[[短链PFAS|短链 PFAS]] 均表现出最显著的去除效果，与 [[颗粒活性炭|GAC]] 相当。C18 样品的性能可能归因于[[碳含量]]增加以及由此增强的[[疏水性]]，这一点通过 [[XPS]]（图 4）和 [[傅里叶变换红外光谱|FT-IR]] 中的 [[碳氢键伸缩振动|C−H 键伸缩振动]]（图 3）进行了评估，从而促进了其与[[长链PFAS|长链 PFAS]] 之间更强的相互作用。与较长链的 [[全氟辛烷磺酸|PFOS]] 和 [[全氟辛酸|PFOA]] 相比，[[3-氨丙基三乙氧基硅烷|APTES]] 和 [[C8硅烷|C8]] 海绵对短链分子 [[全氟丁酸|PFBA]] 和 [[全氟丁烷磺酸|PFBS]] 的去除率较低。这符合预期，因为 PFBA 和 PFBS 的疏水性低于其长链对应物，因此向吸附剂界面迁移的驱动力较弱。与较长链的 PFOS 和 PFOA 相比，APTES 和 C8 海绵对短链分子 PFBA 和 PFBS 的去除率较低。考察各单种 PFAS 时，活化纤维素海绵的 PFOA 去除率 $\left( 8 4 . 3 \% \pm 4 . 9 \right)$ 在所有样品中最高。APTES 和 C8 改性表面表现出最高的 PFOS 去除率，分别为 $( 9 7 . 3 \% \pm \ : 0 . 9$ 和 $9 9 . 2 \% \pm \ 0 . 1 \Big )$，而在改性海绵中，C18 的 PFBA 去除效果最为显著 $( 9 5 . 1 7 ~ \pm$ 0.56)。PFBS 和 PFBA 在 GAC 上的吸附效果最佳，去除率分别为 93.9% ± 2.0 和 $9 6 . 3 \% \pm 1 . 6$。有趣的是，每种样品类型对特定 PFAS 均具有独特的[[吸附亲和性|亲和性]]，且这种亲和性随吸附循环增加或降低，如图 S5 所示。某些再生实验中观察到的较大[[标准差]]，可能反映了商用纤维素海绵基体内部的[[材料非均匀性|结构非均一性]]，包括通过 [[SEM]] 观察到的[[孔隙分布]]差异（图 2），以及各海绵块之间[[表面积|内部表面积]]的差异。在多种情况下，PFAS 去除率有所增加，具体包括 APTES 改性海绵对 PFOA 的去除，以及 C18 改性海绵对 PFBA 的去除（图 S5），这可能是由于 PFAS 在吸附剂表面形成[[多层吸附|多层结构]]，产生了进一步的[[氟氟相互作用|氟−氟相互作用]]，从而使后续循环中的吸附更加有利。也观察到了去除率下降的情况，例如 PFBA 在 APTES 改性海绵上的吸附。与其他 PFAS 分子相比，PFBA 的疏水性相对较低，表明其在通过[[羧酸根头基]]与纤维素结合的分子之上形成[[层状结构|层状或片层结构]]的可能性较低。此外，推测 PFBA 分子使表面可用于结合的[[胺基]]达到饱和，从而降低了海绵在后续循环中的[[吸附容量|容量]]。循环实验的吸附结果表明，在吸附剂质量相同的情况下，尽管活化海绵和 C18 改性海绵的 [[BET 比表面积]]仅为 GAC 的 1/350，它们仍可在多个使用循环中去除大量的各类 PFAS，效果与 GAC 相当。尽管 GAC 与海绵吸附剂的 [[BET]] [[比表面积]]差异显著， 表面积和[[孔结构]]的优化并非本研究的重点，但将在未来的研究中进行探讨。

[[全氟和多氟烷基物质|PFAS]] [[吸附剂]]的[[再生能力]]是新型材料广受期待的一项特性，因为它可以延长[[吸附]]剂的使用寿命并降低运行成本。<sup>24,78,79</sup> 为考察[[纤维素]]基体的 PFAS [[解吸]]性能，分别使用 [[去离子水|DI 水]]、100% [[甲醇]]以及含 0.5 M KNO 的 10% 甲醇溶液作为[[再生液]]，开展了三组[[循环吸附实验|循环研究]]。首先使用 DI 水对受 PFAS 污染的海绵和 [[颗粒活性炭|GAC]] 进行再生（图 5b），为其他再生液建立比较基准。此前已有研究利用去离子水中的[[稀释作用]]将疏水分子与材料分离，例如在[[低盐度水驱|低盐度水驱实验]]中将油从[[碳酸盐岩]]中分离。<sup>80</sup> 使用 DI 水使疏水分子从表面解吸，被认为是由于无离子条件下[[水化层|表面水化层]]的厚度较大。随着溶液中[[离子强度]]降低，吸附剂界面会形成更厚的水化层，从而削弱[[固液界面|固−液界面]]处的[[疏水相互作用]]。<sup>81</sup>

选择[[甲醇|纯甲醇]]作为候选对照[[再生液|再生溶液]]，是因为在实验室规模研究中，纯甲醇常被用于从受污染材料中[[解吸]] [[全氟和多氟烷基物质|PFAS]]，且效果良好。由于头部基团的[[极性]]，PFAS 在纯甲醇中的[[溶解度]]显著高于其在[[去离子水]]中的溶解度，预计这会使 PFAS 的[[分配行为]]从[[固液界面|固−液界面]]转向溶液主体。<sup>82</sup>图 6 比较了所有受评估解吸溶液的性能，其中未包括 [[C8硅烷|C8]] 改性。由于 [[C18硅烷|C18]] 改性的[[吸附效率]]优于 C8 [[表面改性]]，因此后续[[循环吸附实验|循环实验]]中排除了 C8 表面改性。使用纯甲醇使所有海绵表面上 [[全氟辛酸|PFOA]] 的[[回收率]]显著提高至接近 100%，而 [[颗粒活性炭|GAC]] 上的回收率提高至 38%。所有海绵样品上 [[全氟辛烷磺酸|PFOS]] 的平均回收率也提高至 91.6%，而 [[全氟丁酸|PFBA]] 和 [[全氟丁烷磺酸|PFBS]] 的回收率分别提高至 39.6% 和 59.08%。C18 疏水表面表现出最高的总体回收率，这可能是由于占主导地位的[[疏水相互作用]]受到破坏，而这类相互作用受[[溶剂组成]]变化的影响最大。GAC 样品中各类 PFAS 的回收率均略有提高，这很可能是由于 PFAS 在 100% 甲醇中的溶解度普遍提高，以及疏水相互作用的消除。Vakili 等人的一篇综合性综述根据再生策略，对数百项[[吸附剂]]研究进行了列表汇总和分类。83 他们报告称，在所有再生研究中，采用不同浓度甲醇的研究占比最高（>16%），其中使用 100% 甲醇时观察到的再生效率最高。在中试或市政规模下使用 100% 甲醇的实用性经常受到质疑，因为甲醇的成本、储存要求及其产生的废物流给终端用户带来了新的经济挑战。研究多组分再生溶液更有可能为[[吸附剂再生]]提供经济可行的方案。

因此，还选择了硝酸钾[[甲醇]]溶液（10% 甲醇中含 0.5 M $\mathrm { K N O } _ { 3 }$）作为[[再生液|再生溶液]]。此前，许多盐已被用于研究其改变分子[[溶解度]]的能力，由此建立了 Hofmeister 序列，旨在根据溶液的离子组成预测分子的[[分配行为]]。<sup>84</sup> 在 Hofmeister 序列中，根据各离子对水的液晶结构影响的程度，将其归类为促结构离子（kosmotropic，结构形成）或破结构离子（chaotropic，结构破坏）。<sup>85,86</sup> 将低成本、市场上易于获得的盐与较低浓度的甲醇配合使用，在降低[[吸附剂再生]]的经济成本方面具有显著潜力。此外，本研究主要旨在考察溶液组成如何改变 [[全氟和多氟烷基物质|PFAS]] 的溶解度。尽管已知一些常见研究用盐（如氯化钠）会降低某些 $\mathrm { P F A S } ,$ 的溶解度，但已有文献记载，其他离子能够提高[[疏水性]]分子的溶解度，并置换通过静电作用结合的 PFAS。<sup>87,88</sup> 本研究特意选择硝酸钾，是因为已知钾离子对疏水性分子的界面黏附影响甚微，而已有文献记载，硝酸根离子会在体相水中引发破结构效应，提高疏水性分子的溶解度。<sup>89−91</sup> 尽管 100% 甲醇在所有溶液中表现出最佳再生性能，但如图 6 所示，使用硝酸钾甲醇溶液时，PFAS [[回收率]]有所提高。与 [[去离子水|DI 水]]相比，除 [[颗粒活性炭|GAC]] 外，所有表面上 [[全氟辛烷磺酸|PFOS]] 和 [[全氟辛酸|PFOA]] 在硝酸钾甲醇溶液中的回收率平均约高出 20%，而[[活化纤维素海绵|活化海绵]]和 [[C18硅烷|C18]] 海绵上 [[全氟丁酸|PFBA]] 和 [[全氟丁烷磺酸|PFBS]] 的回收率仅略有增加。GAC 在 $\mathrm { \bar { K N O } } _ { 3 }$ 溶液中对 PFOS 和 PFOA 的回收率较低，与 DI 水相当，表明溶解度的提高不足以克服其与碳表面之间的相互作用。相反，GAC 在硝酸钾甲醇溶液中对 PFBA 和 PFBS 的回收率显著提高（分别从 1.88% 增至 40.05%，以及从 3.45% 增至 27.39%）。PFBS 和 PFBA 在水中的溶解度显著高于相应的长链化合物。在硝酸钾溶液中观察到的 PFAS [[解吸]]增强，可能源于[[离子强度]]效应与 Hofmeister 序列所描述的离子特异性相互作用的共同作用。提高离子强度可通过电荷屏蔽减弱带负电的 PFAS 头基与阳离子型[[官能团|表面官能团]]之间的[[静电相互作用]]，从而削弱[[吸附]]力。<sup>92</sup> 除这种非特异性的离子强度效应外，硝酸根被归类为中等破结构性[[阴离子]]，已知其能够破坏水性体系中的[[氢键]]网络。<sup>93</sup> 破结构离子通过降低非[[极性]]基团周围水分子的结构有序程度来减弱疏水效应，这可增强疏水区域的溶剂化，并降低其对疏水表面的[[吸附亲和性|亲和力]]。<sup>94</sup> 由于 PFAS 吸附通常涉及氟碳尾链与[[吸附剂]]表面非极性区域之间的相互作用，因此破坏[[疏水相互作用]]可能有助于 PFAS 在再生过程中重新分配至水相。

尽管本实验结果显示 [[全氟和多氟烷基物质|PFAS]] 的[[解吸]]量仅有小幅增加，但我们的发现为理解如何结合[[表面改性]]与低成本的复杂[[再生液|再生溶液]]来替代[[甲醇|纯甲醇]]提供了新视角。然而，仍亟需进一步研究能够调节[[表面相互作用]]动态和[[溶解度]]、以实现最佳再生效果的溶液组成。此外，已有充分认识表明，PFAS 存在于与疏水表面相伴的气−水界面处。<sup>95</sup> 然而，具有这种三界面动态特征的材料尚未得到表征。因此，未来的工作将把多孔材料与疏水改性相结合，以在材料表面产生气泡。我们将在脱气溶液存在的条件下考察全部三个界面处的相互作用，以进一步阐明 PFAS 的[[吸附]]行为。还应在更复杂的基质中，以环境相关浓度开展动力学和等温吸附研究，以更好地理解海绵的平衡[[吸附容量]]，以及离子和天然有机质对其性能的影响。最后，连续实验（例如快速小型柱试验）对于评估这些发现的实际应用价值至关重要，因此将成为我们未来研究的重点。

## 4. 结论

本研究采用市售[[纤维素海绵]]，分别以亲水性阳离子[[硅烷]]、短链[[疏水性]]硅烷和长链疏水性硅烷进行改性，评估了[[表面官能化|表面功能化]]对 [[全氟和多氟烷基物质|PFAS]] [[吸附]]与再生行为的影响。结果表明，[[纤维素]][[表面改性]]显著影响 PFAS 的吸附行为，凸显了[[表面化学|表面化学性质]]与[[吸附剂]]结构在调控 PFAS−固相相互作用中的重要性。具体而言，亲水性与疏水性表面改性的比较表明，吸附行为源于 PFAS 头基与功能化表面之间的[[静电相互作用]]，以及[[氟碳链]]与非[[极性]]区域之间的[[疏水相互作用]]的共同作用。

再生实验进一步表明，[[解吸]]行为受到[[再生液|再生剂]]组成的显著影响。尽管单独使用[[甲醇]]可从[[改性纤维素]]表面去除部分 [[全氟和多氟烷基物质|PFAS]]，但添加硝酸盐提高了多种 PFAS 化合物的再生效率，表明溶液化学性质和离子的离液效应可能影响 PFAS 从疏水界面的解吸。甲醇可能通过充当助溶剂，降低[[氟碳链]]溶剂化所伴随的疏水自由能代价，从而促进 PFAS 解吸；而硝酸根离子则通过[[离子强度]]和离液效应削弱[[吸附剂]]界面处的[[疏水相互作用]]，进而影响解吸。这些观察结果凸显了在设计可再生 PFAS [[吸附]]材料时，同时考虑吸附剂[[表面性质]]与再生剂化学性质的重要性。

尽管[[吸附]]实验是在较高的 [[全氟和多氟烷基物质|PFAS]] 浓度下进行的，以便对[[吸附剂]]性能进行比较评估，但这些结果仍有助于理解[[表面官能化|表面功能化]]策略如何影响[[纤维素]]基材料中 PFAS 的吸附与[[解吸]]行为。未来工作应研究环境相关 PFAS 浓度下的吸附性能，并进一步考察长链与短链[[硅烷]]疏水改性的协同组合，以及[[再生液|再生剂]]化学性质在促进 PFAS 解吸中的作用机制。总体而言，这些发现有助于推动可调控生物基吸附材料的持续开发，使其能够在 PFAS 处理应用中兼顾吸附性能与[[再生能力]]。
