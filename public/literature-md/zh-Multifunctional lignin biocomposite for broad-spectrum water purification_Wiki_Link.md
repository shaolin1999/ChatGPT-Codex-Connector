# 用于广谱水净化的多功能[[木质素]]生物复合材料

2025 年 8 月 21 日收稿 2025 年 12 月 6 日接受

DOI：10.1039/d5va00282f

[[Sritama Mukherjee]]，\*<sup>a</sup> [[Salvatore Lombardo]] <sup>b</sup> 与 [[Ulrica Edlund]] \*<sup>a</sup>

rsc.li/esadvances

利用多功能可持续材料去除人为废水中的[[重金属离子]]、[[PFAS]] 与[[合成染料]]，对于清洁环境和人类健康至关重要。本研究提出了一种以[[壳聚糖]]增强的可持续工程[[木质素]]基生物复合材料，该材料专为多功能性与增强材料性能而设计，并通过“绿色”且简便的水介质[[一锅法合成]]制备。所合成的颗粒材料，即[[两性离子木质素-壳聚糖复合材料]]（[[ZLC]]），被用于去除多种化学性质各异的污染物。ZLC 对 Cr( )、Cu( ) 等[[重金属]]以及四种不同的阳离子和阴离子染料表现出 80–90% 的去除率。该材料还针对五种 [[全氟和多氟烷基物质|PFAS]] 分子进行了测试，例如[[全氟磺酸]]和[[全氟羧酸]]，对[[全氟辛烷磺酸|全氟辛烷磺酸（PFOS）]]的去除率最高可达 86%。所有[[吸附]]过程均遵循[[准二级动力学模型]]和 [[Langmuir 模型]]。该材料还表现出[[抗污性能]]，证明了其在实际应用中的稳健性。最后，ZLC 针对实际出水水体基质，即瑞典[[矿区废水]]水流进行了测试。这种环境友好型材料的多功能吸附性能，加上其易于生产、成本效益高和可重复使用等特点，表明 ZLC 具有巨大潜力，能够引起工业界对简化多级过滤工艺的兴趣。

## 环境意义

[[PFAS]]、[[合成染料]]和有毒金属等[[持久性有机污染物]]向水体系统的释放，构成了日益严峻的环境问题。应对各类污染物向环境中大量排放的问题，需要可持续且多功能的技术。我们报道了一种生物来源[[吸附|吸附剂]]——功能化[[两性离子木质素-壳聚糖复合材料|木质素-壳聚糖复合材料]]（[[ZLC]]），该材料对多种污染物实现了 80–90% 的去除率，并通过多次再生循环和[[抗污性能]]保持了其性能。借助[[木质素]]和[[壳聚糖]]的天然丰富性与功能性，ZLC 代表了一个有前景的平台，可用于可扩展、可回收且环境友好的水净化，从而推动[[生物修复|可持续污染物修复]]策略的发展。

## 1 引言

随着农业、工业、能源和市政领域用水量的持续增长，以及天然淡水供应的有限性，有必要转向利用非传统水源，如废水、海水和苦咸水。安全利用这些水源需要能够从受污染水中去除几乎所有溶解组分的[[废水处理|水处理]]系统。来自人为来源的未经处理废水，例如[[矿区废水|矿区径流]]和各种工业废物流，一旦排入[[地表水]]和[[地下水]]，便会对数百万人的[[饮用水]]安全构成风险。<sup>1</sup> 各种有毒污染物的存在——如[[有机微污染物]]、[[重金属离子]]、以及[[全氟和多氟烷基物质]]（[[PFAS]]）等“[[永久化学品]]”——即使浓度很低，也可能成为与水相关疾病的主要诱因。<sup>2</sup> PFAS 因其数千种变体难以自然降解且具有广泛的工业应用而受到关注，从而导致其大量迁移至水体、土壤和野生动物中。<sup>3</sup> 该类物质的典型例子包括[[全氟羧酸|全氟烷基羧酸]]和磺酸，尤其是[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸|全氟辛烷磺酸（PFOS）]]，其生产和使用目前已在全球范围内被禁止，进而促使具有类似特性的替代性全氟和多氟烷基物质不断出现。<sup>4,5</sup> [[C–F 键]]的显著稳定性阻止了生物和非生物降解，因此尽管某些非氟化前体能够发生转化，仍会残留持久性全氟化产物，这迫使监管机构制定更严格的标准。这些情况凸显了开发“智能”材料的紧迫性，从而推动技术进步，以便从替代水源中获取清洁水。<sup>6</sup>

传统的[[废水处理|水和废水处理方法]]通常具有较高的化学品、能源和运行要求，且主要面向大规模系统。<sup>7</sup> [[吸附剂|吸附材料]]得到广泛应用，因为与传统技术相比，它们在容量、选择性、[[可再生性]]和经济性方面表现出更优的分离性能。<sup>8</sup> 聚合物衍生材料，尤其是[[生物聚合物]]，能够从技术、社会经济和环境角度大幅改善先进[[吸附]]过程。

[[木质素]]是[[木质纤维素生物质]]的主要结构组分，在陆生植物生物质的组成中起着至关重要的作用。<sup>9</sup> 木质素聚合物主要由三种[[苯丙烷亚单元]]组成：[[对羟苯基]]（H）、[[愈创木基]]（G）和[[紫丁香基]]（S），其总碳含量约占其结构的 60%。<sup>10</sup> 木质素富含[[羟基]]，这些羟基显著影响其化学和物理特性，包括反应活性、亲水性和功能性。[[壳聚糖]]是另一种生物来源聚合物，具有[[氨基多糖|氨基多糖结构]]，并因其广泛适用性而闻名。木质素和壳聚糖都允许进行多种化学修饰，这得益于它们在各种溶剂中的溶解性，从而能够在它们的芳环和羟基上引入各种官能团。<sup>11</sup> 因此，无论从环境还是化学角度看，木质素和壳聚糖都是水净化材料的有趣候选物。

设计一种对广泛污染物具有高[[吸附容量]]的多[[功能材料]]，由于常见污染物的复杂性和多样性所带来的若干因素，构成了一项重大科学挑战。污染物可以是极性的、非极性的或两亲性的，并且它们具有各种官能团，与[[吸附|吸附剂]]材料的相互作用方式不同。它们在尺寸上也差异显著，从小离子到大有机分子甚至纳米颗粒，这要求[[吸附剂]]材料的孔径能够容纳这一广泛范围。此外，实现对多种污染物的高效吸附具有挑战性，因为提高对某一类污染物的选择性可能会降低对其他污染物的效率。多功能材料可以简化[[废水处理|水处理]]工业中的多级过滤过程。一种理想的多功能吸附剂材料必须具备能够在一系列 pH 水平下有效吸引并保持阴离子、阳离子和中性物种的位点，并提供能够适应不同污染物尺寸的孔结构。从这一角度看，固定在多孔基质中的[[两性离子基团]]作为一种有前景的方法脱颖而出，使吸附剂能够同时对阴离子和阳离子实体施加[[静电相互作用]]。已有研究表明，[[两性离子膜]]能有效抑制细菌和[[蛋白质污染]]，并吸引[[重金属离子]]。<sup>12–14</sup> 一种用两性离子基团功能化的可溶性硫酸盐[[木质素]]组分表现出优异的[[抗污性能|抗蛋白质吸附性能]]。<sup>15</sup> 少数初步研究报道了[[壳聚糖]]-木质素复合材料的制备，但其在选择性去除金属或染料方面的适用性有限。<sup>16,17</sup> 能够提供有效广谱处理的材料仍然少见。

秉持这一动机，我们展示了一项概念验证研究：将[[木质素|碱木质素]]功能化以带有[[两性离子基团]]，随后用[[壳聚糖]]增强，通过简单且绿色的[[一锅合成工艺]]制备生物复合材料。功能化木质素提供了有效[[吸附]]并保持阴离子、阳离子和中性化学多样物种的[[活性位点]]，而壳聚糖增强则在一系列 pH 水平和多样环境条件下赋予机械强度和稳定性，同时协同避免[[生物污损]]，从而使其在实际应用中具有稳健性。我们开发了[[两性离子木质素]]生物复合材料$( \mathrm { Z L C } ) ,$一种多功能[[抗污性能|防污材料]]，用于捕获多种污染物，如[[重金属离子]]、阳离子和阴离子染料以及 [[PFAS]] 分子。两性离子型木质素（[[Zl|ZL]]）和 [[ZLC]] 的加工与应用如图 1 所示。

## 2 实验

## 2.1 材料

[[木质素|Kraft 木质素]]（KL）（[[Sigma-Aldrich]]）、[[3-氯-2-羟基-1-丙磺酸钠盐水合物]]（CHPSS）95%（Sigma-Aldrich）、[[缩水甘油基三甲基氯化铵]]（GTMAC）$90% (Sigma-Aldrich), and chitosan with a medium molecular weight of 190000–310000 ${ g m o l } ^ { - 1 }$ and 75–85% deacetylation (Sigma-Aldrich) were used as received. L(+)-lactic acid 95% (Acros Organics), sodium hydroxide (NaOH) (VWR chemicals), and deuterated water $\left( \mathbf { D } _ { 2 } \mathbf { O } \right)$ (VWR chemicals) were used as received. hydrochloric acid (HCl) solution (1 M) was also used. The dialysis membrane (MWCO: 500–1000 g mol−<sup>1</sup>) was bought from Spectrum Labs. Nitrate salts of cobalt, copper, cadmium, nickel, lead, zinc, and chromium oxide were purchased from Sigma-Aldrich. Eriochrome Black T (EBT) was purchased from Acros Organics, while methyl orange (MO), methylene Blue (MB) hydrate, rhodamine B (RhB), and bovine serum albumin (BSA) were purchased from Sigma-Aldrich. Water spiked with PFAS agents per<sup></sup>uorobutane sulfonic acid (PFBS), per-<sup></sup>uorohexane sulphonate (PFHxS), per<sup></sup>uorooctane sulfonic acid (PFOS), per<sup></sup>uorooctanoic acid (PFOA), and per-<sup></sup>uorohexanoic acid (PFHxA) (total concentration 50 mg $\mathbf { L } ^ { - 1 } )$ 购自斯德哥尔摩 [[IVL Svenska Miljöinstitutet]]。来自瑞典 Skellefteå [[矿区废水]]样品由 [[Boliden AB]] 提供。除非另有说明，使用来自 [[Merck Millipore]] 的[[去离子水]]。

## 2.2 方法

2.2.1 [[Zl|ZL]] 的合成。[[木质素]]两性离子修饰的[[一锅合成工艺|一锅法工艺]]由 Guo 等$a l . ^ { 1 8 }$所述过程发展而来。筛选时使用了不同的试剂比例；此处报告经发现可提供最佳结果的参数设置。首先，在 100 mL 圆底烧瓶中于 80 °C 下将 1 g KL 和 0.15 mL 2 M [[氢氧化钠|NaOH]] 混合于 30 mL 水中。将 [[3-氯-2-羟基-1-丙磺酸钠盐水合物|CHPSS]]（0.3 g）和 [[缩水甘油基三甲基氯化铵|GTMAC]]（0.4 g）分别溶解于各 10 mL 水中，并依次滴加到木质素混合物中，在搅拌下保持 4 h。将胶体溶液冷却至室温并用 [[盐酸|HCl]] 中和至 pH 7。通过[[透析]]（3–4 天）对水去除未反应试剂和盐，然后在 60 °C 下干燥。合成重复多次以验证重现性。

2.2.2 [[ZLC]] 的合成。将 KL（2 g）、[[壳聚糖]]（1 wt%）和 10 mL 水在$5 0 ~ ^ { \circ } \mathrm { C } .$下混合 4 h。随后将混合物进一步加热至$6 5 \ { } ^ { \circ } \mathrm { C } ,$，然后加入 [[3-氯-2-羟基-1-丙磺酸钠盐水合物|CHPSS]]、[[缩水甘油基三甲基氯化铵|GTMAC]] 和 [[氢氧化钠|NaOH]]，保持与上述相同的比例。将悬浮液搅拌 4 h，冷却至室温，必要时中和至 pH 7，然后[[离心]]并用水反复洗涤。

所合成的 [[Zl|ZL]] 和 [[ZLC]] 材料分别通过[[透析]]和[[离心]]洗涤进行纯化，并在$6 0 ~ ^ { \circ } \mathrm { C }$下过夜干燥。[[两性离子木质素-壳聚糖复合材料|ZLC]] 得到大颗粒材料，进一步用研钵和研杵粉碎，以获得可作为[[吸附]]介质使用的均匀粉末材料。

2.2.3 批量[[吸附]]研究与[[吸附等温线]]。通过溶解制备染料（[[甲基橙|MO]]、[[罗丹明 B|RhB]]、[[亚甲基蓝|MB]] 和 [[铬黑 T|EBT]]）及金属 $\mathrm { ( C r O _ { 3 } , ~ \ C u ( N O _ { 3 } ) _ { 2 } , ~ \ C o ( N O _ { 3 } ) _ { 2 } , ~ \ C d ( N O _ { 3 } ) _ { 2 } , }$ $\mathrm { N i } ( \mathrm { N O } _ { 3 } ) _ { 2 } , \mathrm { P b } ( \mathrm { N O } _ { 3 } ) _ { 2 } , \mathrm { Z n } ( \mathrm { N O } _ { 3 } ) _ { 2 } )$ 的储备液（1 mg mL−<sup>1</sup> 水溶液）。在典型的[[批量吸附实验]]中，将 25 mg [[Zl|ZL]]/[[ZLC]] 与 25 mL 染料/金属加标水在室温下振荡（200 rpm）。采集水样以测定处理后水中残留的染料或金属浓度，分别使用[[紫外-可见分光光度计]]或[[电感耦合等离子体发射光谱仪]]（ICPOES）进行测量，并与三次重复（n = 3）的准确度进行比较。[[吸附动力学|染料/金属吸附动力学]]通过在不同时间取出 1 mL 处理后溶液并分析等分试样来跟踪。

对于等温线测定，将 [[Zl|ZL]]/[[ZLC]]（25 mg）浸入 25 mL 浓度为 1、5、10、25、50、75 和 100 mg $\mathrm { L } ^ { - 1 }$ 的金属加标水中，pH 为 5.5，并在室温下振荡（200 rpm）24 h。然后，从处理水中收集等分试样，并用 [[紫外-可见分光光度计|UV-vis]]/[[电感耦合等离子体发射光谱仪|ICPOES]] 分析以确定加标实体的剩余浓度。涉及[[吸附]]量定量的方程在 [[补充信息|SI]] 中给出。

[[Zl|ZL]]/[[ZLC]] 对 [[牛血清白蛋白|BSA]] [[吸附]]的动力学使用 [[ThermoScientific]] 的 [[Pierce Bradford 蛋白测定试剂盒|Pierce™ Bradford 蛋白测定试剂盒]]进行测定。<sup>19</sup>

性能使用 [[电感耦合等离子体发射光谱|ICP-OES]]、[[紫外-可见分光光度计|UV-Vis]] 和 [[液相色谱-串联质谱|LC-MS/MS]] 进行定量；对材料进行了 [[SEM-EDS]]、mapping、[[X 射线衍射|XRD]]、[[傅里叶变换红外光谱|FT-IR]] 和 [[X 射线光电子能谱|XPS]] 等表征技术，以对[[吸附]]现象进行定性研究。

2.2.4 [[ZLC]] 的再生。在每个[[吸附]]循环中，将 50 mg [[两性离子木质素-壳聚糖复合材料|ZLC]] 或 [[Zl|ZL]] 浸泡在 50 mL 10 ppm [[铬|Cr(VI)]]/[[铜|Cu(II)]] 混合溶液中，收集处理水等分试样用于残留金属定量，然后将处理过的[[吸附剂]]浸泡在 1 N [[盐酸|HCl]] 中，以 200 rpm 振荡 4 h。随后，将再生后的吸附剂在[[去离子水]]中浸泡 2 h，再进行下一个金属吸附循环。

2.2.5 蛋白质[[吸附]]。将 [[Zl|ZL]]/[[ZLC]]（50 mg）浸泡在 50 mL 输入浓度为 250 mg L−<sup>1</sup> 的 [[牛血清白蛋白|BSA]] PBS 缓冲液中，在 200 rpm 恒定搅拌下持续 0–180 min，并在不同时间间隔收集等分试样。

## 2.3 仪器

2.3.1 [[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FT-IR]]）。FTIR 光谱使用配备衰减全反射晶体的 [[PerkinElmer Spectrum 100 FT-IR 光谱仪]]获得。每个光谱是 16 次累积扫描的平均值，分辨率为 $4 ~ \mathrm { c m } ^ { - 1 }$。所有光谱均使用 [[PerkinElmer Spectrum 软件]] V10.5.1 进行基线校正。

2.3.2 紫外-可见光谱（[[紫外-可见分光光度计|UV-vis]]）。吸光度测量在 [[Shimadzu UV-2550 紫外-可见分光光度计]]上进行，并记录在 200 至 700 nm 之间。

2.3.3 电感耦合等离子体-发射光谱（[[电感耦合等离子体发射光谱|ICP-OES]]）。使用 [[ThermoScientific iCAP 6500]] 上的 [[电感耦合等离子体发射光谱仪|ICP-OES]] 测定金属离子的绝对量。

2.3.4 <sup>1</sup>H-[[核磁共振波谱]]（NMR）。光谱在室温下使用 [[Bruker NMR 波谱仪]]（400 MHz）获得，并由 Bruker 软件记录。样品溶解在 ${ \bf D } _ { 2 } { \bf O }$ 中，浓度约为 20 mg mL−<sup>1</sup>。光谱使用 [[MestReNova 软件]]处理。

2.3.5 [[Zeta 电位]]（ZP）。使用 [[Malvern Zetasizer Pro]] 测定 ZP。样品溶解于[[去离子水]]中，浓度约为 2 mg mL−<sup>1</sup>，并通过 [[ZS Xplorer 软件]]进行三次平行测量以获得平均值。

2.3.6 [[热重分析]]（TGA）。采用 Mettler Toledo TGA/DSC 1 Star 系统进行 TGA，样品量约为 5–6 mg，在 30–600 °C 温度范围内评估。升温速率为 $1 0 \ \mathrm { ^ { \circ } C } \ \operatorname* { m i n } ^ { - 1 }$，氮气气氛下气体流速为 50 mL min−<sup>1</sup>。数据使用 [[Mettler Toledo STARe 软件|Mettler Toledo STARe V15.00b 软件]]分析。

2.3.7 [[流变学]]。通过 [[TA Instrument DHR-2 流变仪|TA Instrument DHR-2 型流变仪]]测定[[剪切应力]]速率。每个样品约使用 20 mL 进行测试。[[粘度]]使用 Peltier 钢制平行板（直径 25 mm）记录，间隙为 300 mm。

## 3.2 [[重金属]]的[[吸附]]

3.2.1 [[吸附动力学]]、表征与等温线。将 [[Zl|ZL]] 和 [[ZLC]] 置于加标水样中，该水样含有浓度各为 10 mg $\mathrm { L } ^ { - 1 }$ 的[[重金属]]混合物 [[镉|Cd(II)]]、[[钴|Co(II)]]、[[铬|Cr(VI)]]、[[铜|Cu(II)]]、[[镍|Ni(II)]] 和 [[锌|Zn(II)]]。[[吸附]]后的残留浓度通过 [[电感耦合等离子体发射光谱|ICP-OES]] 测定。[[两性离子木质素|ZL]] 和 [[两性离子木质素-壳聚糖复合材料|ZLC]] 均表现出对 Cr(VI) 和 Cu(II) 的亲和性，可从水中去除高达 90% 的上述离子。在研究 ZLC 的吸附动力学时，可以清楚地看到 Cr(VI) 和 Cu(II) 以其表面不同的速率被吸附（图 3a），而其他金属离子随时间未表现出任何显著降低。时间分辨数据采用准一级和[[准二级动力学模型]]进行拟合。根据 $R ^ { 2 } { \mathrm { : } }$ 的值，可以明确，对于本工作中使用的所有吸附质，准二级模型均能更好地拟合实验数据（表 S1，[[补充信息|SI]]）。[[准二级动力学]]模型假设吸附速率受[[吸附剂]]—吸附质相互作用的影响。<sup>21</sup> 为进一步理解吸附机理，应用[[颗粒内扩散模型]]以确定表面吸附与孔内扩散之间的限速步骤，相关内容讨论于图 S6（SI）。图 3b 通过元素分布图显示 Cr 和 Cu 离子以均匀方式分布在 ZLC 和 ZL 表面。吸附后，对饱和的 ZL 和 ZLC 进行 [[X 射线衍射|pXRD]] 测试（图 S7，SI），图谱 II 和 IV 中位于 $2 \theta = 1 5 { - } 3 0 ^ { \circ }$ 的宽峰表明无定形结构未发生变化，证实吸附不会对吸附剂造成任何结构改变。图谱 II 和 IV 中位于 $2 \theta = 3 8 – 4 5 ^ { \circ }$ 的宽驼峰是吸附在 ZL 和 ZLC 上的 $\mathrm { C r O } _ { 3 } / \mathrm { C r } _ { 2 } \mathrm { O } _ { 3 }$（常见特征峰位于 43.9°）和 $\mathbf { C u O / C u _ { 2 } O }$（[[氧化铜|CuO]] 特征峰位于 38.9°，$\mathrm { C u } _ { 2 } \mathrm { O }$ 位于 42.3°）的金属氧化物特征峰重叠所致，而在原始吸附剂（ 和 ）中并不存在。ZLC 在金属吸附前后的 [[傅里叶变换红外光谱|FT-IR]] 光谱如图 3c 所示。ZLC 显示出与 $- \mathrm { { S O } } _ { 3 } \mathrm { { ^ - } }$ 基团相关的特征峰，位于 1090、$^ { 1 1 7 5 , }$ 和 1126 $\mathrm { c m } ^ { - 1 }$ 处，分别归属于 S]O 伸缩振动、S–O 基团的对称和不对称伸缩振动，同时在 $1 4 2 0 ~ \mathrm { { c m } ^ { - 1 } }$ 处存在由于 –OH 弯曲振动产生的谱带；在吸附金属后的 ZLC 中，这些峰均减弱或消失。此外，源自 ZLC 的 +N(Me) 的位于 918 和 $9 6 8 ~ \mathrm { c m } ^ { - 1 }$ 处的弱谱带在载金属 ZLC 中不可见，这表明这些 N 和 S [[活性位点]]参与了金属吸附；而在 908 和 $1 1 3 8 ~ \mathrm { { c m } ^ { - 1 } }$ 处出现的新峰可归属于 Cr 和 Cu 离子的吸附。<sup>22,23</sup> 为提高吸附效率，探索 ZLC 表现最佳的 pH 范围是有意义的。pH 依赖性吸附实验表明，Cr(VI) 和 Cu(II) 的最大吸附发生在 pH 5 时（图 3d）。碱性 pH 会促进输入水样中溶解金属盐的沉淀，因此不适合作为工作条件。图 3e 展示了重金属和染料在 ZLC 上吸附的 [[Langmuir 等温模型|Langmuir]] 等温线图，以观察其对每种污染物的最大[[吸附容量]]。等温线数据也采用 [[Freundlich 等温模型|Freundlich]] 等温线进行建模，并将两种模型同时应用于 ZL 以比较吸附容量（表 1）。[[Langmuir模型|Langmuir]] 等温线在每种情况下均表现出更高的 $R ^ { 2 }$ 值；线性拟合见图 S8（SI）。

3.2.2 可重复使用性。为研究材料的可重复使用性，对 [[ZLC]] 和 [[Zl|ZL]] 进行了四个循环的金属[[吸附]]测试，每个循环后用酸再生（图 3f）。观察到 [[两性离子木质素-壳聚糖复合材料|ZLC]] 和 [[两性离子木质素|ZL]] 均保持了对 [[铬|Cr(VI)]] 的 80–90% 去除率。对于 [[铜|Cu(II)]]，到第四个循环为止，ZLC 的去除率最高为 60%，ZL 最高为 40%。两种金属去除率的差异可能是由于两种离子在[[活性位点]]上存在[[竞争吸附]]。

尽管在初步实验中测试了 [[Zl|ZL]] 对[[重金属]]的去除以检验其功能，但由于其柔软且脆弱的结构使其难以操作，因此未进一步将其用于有机染料和 [[PFAS]] 的去除。

3.2.3 实际水样测试。[[ZLC]] 进一步用于处理来自瑞典北部一处[[采矿废水|采矿场废水]]的真实废水基质。此类废水可能难以处理，因为除溶解态和悬浮态类金属外，还可能含有物理污染物，如悬浮固体、沉积物以及可能导致结垢的[[天然有机物]]。此类废水的 pH 值也会因成分和季节性波动而变化。对收集到的采矿废水（样品 1 和样品 2）进行了分析，以确定其理化参数和目标金属的浓度水平，结果发现其浓度较低（表 S2，[[补充信息|SI]]）。因此，向其中分别加标 20 ppm 的 [[铬|Cr(VI)]] 和 [[铜|Cu(II)]]。[[两性离子木质素-壳聚糖复合材料|ZLC]] 对金属去除的性能见表 2。

## 3.3 有机污染物的[[吸附]]：[[PFAS]]

3.3.1 [[ZLC]]的性能。为检验[[两性离子木质素-壳聚糖复合材料|ZLC]]从水中清除[[PFAS]]分子的能力，将100、200和500 mg $\mathrm { L } ^ { - 1 }$ 的ZLC投加量分别暴露于含有不同链长[[全氟和多氟烷基物质|PFAS]]分子混合物（即[[全氟丁烷磺酸|PFBS]]、[[全氟己酸|PFHxA]]、[[全氟己烷磺酸|PFHxS]]、[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]）的水样中，介质pH未调节，处于5–6范围内。PFAS化合物储备液按每种物质50 $\mu \textrm { g L } ^ { - 1 }$ 的浓度配制，该浓度远高于[[饮用水]]中通常检出的水平。这一较高浓度并非旨在模拟饮用水场景，而是用于代表需要修复的高度污染场地。此外，采用较高浓度可确保净化后的水仍远高于分析检测限，从而提高后处理测量的可靠性。接触24小时后，分离[[吸附|吸附剂]]，并使用[[液相色谱-串联质谱|LC-MS/MS]]分析水样以测定剩余PFAS浓度。ZLC在去除较长链PFAS分子方面表现更佳，尤其是PFOS，其去除率达80–90%（图5a）。相应的LC-MS/MS图谱见[[补充信息]]图S9。

## 3.4 有机污染物的[[吸附]]：阳离子和阴离子染料

3.4.1 [[ZLC]] 的性能。芳香族染料 [[亚甲基蓝|MB]] 和 [[罗丹明 B|RhB]] 为阳离子型，而 [[甲基橙|MO]] 和 [[铬黑 T|EBT]] 本质上是阴离子型。鉴于[[木质素]]复合材料的[[两性离子功能化|两性离子型功能化]]，对两类染料均进行了测试，[[两性离子木质素-壳聚糖复合材料|ZLC]] 对所有染料都表现出非常高的去除效率，验证了木质素生物复合材料两性离子功能化的多功能性。对每种染料分别开展了 0–180 min 的时间依赖性[[吸附]]（图 6a）。从吸光度光谱中残余峰强度随时间的变化可以看出，受试染料在该时间范围内表现出不同的吸附速率。对其动力学行为进行了建模，[[准二级动力学|准二级关系]]给出了最佳<sup></sup>t（表 S1，[[补充信息|SI]]）。废水中的染料存在于较宽的 pH 范围内，因此为研究 pH 对染料去除的影响，在 pH 3–11 范围内进行了吸附实验。随着 pH 降低进入酸性区域，阴离子染料的去除率提高（图 6b）。这是因为 ZLC 在酸性 pH 下会通过从介质中吸引最大数量的 $\mathrm { H } ^ { + }$ 离子而表现出最大的正表面电荷，从而通过静电作用吸引阴离子染料分子。ZLC 随 pH 变化的 [[Zeta 电位|zeta 电位]]测量结果验证了这一点（图 2k）。阳离子染料 MB 则观察到相反现象，其在碱性 pH 下去除率最高。[[罗丹明B|RhB]] 几乎不受 pH 变化的影响，因为随着 pH 从酸性变为碱性，它可以阳离子或两性离子形式存在。各染料随投加量变化而去除的化学结构和光学图像见图 6c。对每种染料进行了等温实验，并用 [[Langmuir 等温模型|Langmuir]] 和 [[Freundlich 等温模型|Freundlich 模型]]对数据进行了<sup></sup>合。最大[[吸附容量]]列于表 1，其线性<sup></sup>合结果见图 S10（SI）。[[Langmuir模型|Langmuir]] 等温模型给出了更高的 $R ^ { 2 }$ 值，并且对染料具有非常高的吸附量。ZLC 对 MO 和 [[铬黑T|EBT]] 的吸附容量分别高达 4166.6 和 $1 0 3 0 . 9 \mathrm { ~ m g ~ g ^ { - 1 } ~ }$，对 MB 和 RhB 分别为 192.3 和 $7 1 . 9 \mathrm { m g g } ^ { - 1 }$。这些数值表明，ZLC 对阴离子染料表现出更高的吸附效率。同时，相对较低的 $R ^ { 2 }$ 值可能表明，这些染料可能遵循其他形式的单层或多层吸附模型。

3.4.2 [[吸附]]机制。染料较高的吸收量也可部分归因于其他分子间[[吸附剂]]–吸附质相互作用，如 [[π-π 堆积|p–p 堆积]]和[[氢键]]，这源于[[木质素]]基复合材料与有机分子复杂的化学结构。<sup>26</sup> 每次染料吸附后的饱和 [[ZLC]] 均进行 [[傅里叶变换红外光谱|FT-IR]] 光谱分析，以研究其化学结构的定性变化。[[两性离子木质素-壳聚糖复合材料|ZLC]] 在染料吸附前后的 FT-IR 光谱如图 6d 所示。为便于峰位识别，还记录了每种染料在干态下的光谱（[[补充信息|SI]] 中图 S11–S14）。原始 ZLC 中约在 $3 4 0 0 ~ \mathrm { c m } ^ { - 1 }$ 处的吸收带，逻辑上归属于 O–H 伸缩振动，在吸附后的 ZLC 样品中总体表现为变宽，这是由于材料在吸附过程中吸收了水分所致。关于材料上吸附染料物种的更多信息来自光谱的中/低频区。对于染料吸附后的 ZLC 体系，出现了新峰，且既有峰因吸附而发生变化。在 [[亚甲基蓝|MB]] 吸附于 ZLC 的情况下，出现在 $1 6 6 3 \mathrm { c m } ^ { - 1 }$（归属于 MB 杂环基团中 C]C 和 C]N 振动）、1383 和 1328 $\mathrm { c m } ^ { - 1 }$（归因于杂环的 C–N、${ \mathrm { C } } { = } { } { \bf { S } } { + }$ 伸缩）、1268 $\mathrm { c m } ^ { - 1 }$（C–H 弯曲）、884 $\mathrm { c m } ^ { - 1 }$（二聚体或 H-聚集体）处的额外峰，以及 646 $\mathrm { c m } ^ { - 1 }$（g 和 d（C–S–C）基团）处的峰，证实了 MB 吸附在 $\mathrm { Z L C . } ^ { 2 7 }$ 表面上。在 [[罗丹明 B|RhB]] 吸附于 $\mathrm { z L C } ,$ 的情况下，1648 cm<sup>−1</sup> 处归属于芳环 $\mathrm { C } { = } \mathrm { C }$ 和 C]N 基团的伸缩振动峰、1340 和 $1 2 4 4 ~ \mathrm { { \ c m } ^ { - 1 } }$ 处归属于 C–C 和 C–O–C 伸缩的峰，以及 $6 8 3 ~ \mathrm { c m } ^ { - 1 }$ 处归属于芳环 C–H 面外摇摆振动的峰，证实了 [[罗丹明B|RhB]] 吸附在 ZLC 表面上。<sup>28,2</sup> 在 [[甲基橙|MO]] 吸附后的 ZLC 光谱中，在 1649 和 $1 6 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ 处出现弱谱带，分别归属于 N–H 弯曲/C]C 伸缩和 N]N 伸缩振动。1264 和 $1 2 1 5 ~ \mathrm { c m } ^ { - 1 }$ 处的峰源自脂肪胺的 C–N 伸缩，而 814 cm<sup>−1</sup> 处由 1,4-二取代（对位）苯环引起的弱谱带证实了该偶氮染料存在于 ZLC 表面。<sup>30,31</sup> 除 1654 和 1597 cm<sup>−1</sup> 处与偶氮相关的峰外，1334 和 1215 cm<sup>−1</sup> 处分别由 –${ \bf - N O } _ { 2 }$ 和 $- \mathbf { S } \mathbf { O } _ { 3 }$ 基团引起的峰证实了 [[铬黑 T|EBT]] 在 ZLC 表面上的吸附。<sup>32</sup>

## 3.5 [[蛋白质污染]]

蛋白质[[吸附]]是一种普遍存在的污染过程，对任何在现场或处理工业废水中运行的[[吸附剂]]都可能产生不良后果。因此，通过将 [[Zl|ZL]] 和 [[ZLC]] 暴露于模型蛋白（[[牛血清白蛋白]]，BSA）中，在室温下测试了它们的[[抗蛋白质性能]]，并使用 [[Pierce™ Bradford 蛋白测定法]]以时间依赖方式分析了吸附过程。根据吸光度数据计算了 BSA 随时间的吸附百分比（图 8）。观察到 BSA 分子最初与 [[两性离子木质素-壳聚糖复合材料|ZLC]] 表面有轻微相互作用，但在 60 分钟后未观察到吸附。这可能是由于 [[两性离子木质素|ZL]] 和 ZLC 表面上的正负官能团使材料非常亲水，并且这些基团之间的[[静电相互作用]]可导致其向水介质界面重新取向，形成能有效促进抗蛋白质性的[[水化层]]。<sup>33</sup>

传统材料如[[活性炭]]（GAC 和 PAC）因其效率和成本效益而在商业上占据主导地位，而[[离子交换树脂]]虽然价格昂贵，但以其选择性去除能力而闻名。这些材料伴随着高能耗、频繁更换需求以及 $\mathrm { C O } _ { 2 }$ 排放。与这些替代品相比，[[ZLC]] 具有显著优势，因为它能在广泛的 pH 范围内捕获包括 [[PFAS]]、[[重金属]]和染料在内的多种污染物，同时抗结垢。它是通过一种简单、绿色、水基的[[一锅法合成|一锅法]]在 70–80 °C 下制备的，不像活性炭需要高温活化（700–800 °C），而且由于成本低往往不再生，导致未经处理的废弃材料最终进入填埋场。[[两性离子木质素-壳聚糖复合材料|ZLC]] 主要由[[木质素]]和[[壳聚糖]]制成——这些原料易得且廉价，使其具有成本效益，并且可以多次再生。它具有热稳定性和化学稳健性，并具有高机械稳定性（与图 2 中显示的活性炭和 [[硅藻土|Celite]] 相当），因此使 ZLC 可与商用过滤材料相媲美。随着其[[吸附容量]]的进一步提高，其多功能性、易于生产和可重复使用性使其成为工业应用中可扩展、可持续的替代方案。

## 4 结论

本研究展示了一种独特多功能复合材料的制备与性能，该材料能够在广泛的 pH 范围内有效[[吸附]]阴离子、阳离子和中性且化学性质多样的污染物，同时避免[[生物污损]]，使其成为实际应用中的稳健选择。通过绿色、简单且水基的[[一锅法合成]]程序，制备了以[[壳聚糖]]提供结构增强的功能化[[木质素]]（[[ZLC]]）。材料的形态表征表明，它们为微米级颗粒状、无定形、具有机械和热稳定性，同时在广泛的 pH 范围内具有化学稳定性。经磺酰基和[[季铵基团]]改性的木质素赋予复合材料[[两性离子功能化|两性离子型功能化]]，作为吸附的[[活性位点]]。[[两性离子木质素-壳聚糖复合材料|ZLC]] 作为[[吸附剂]]进行了测试，对多种水体污染物表现出优异性能，如 Cr 和 Cu 离子、[[全氟辛烷磺酸|PFOS]] 等 [[PFAS]] 分子，以及[[合成染料]] [[亚甲基蓝|MB]]、[[甲基橙|MO]]、[[罗丹明 B|RhB]] 和 [[铬黑 T|EBT]]。该材料对[[矿区水样|来自矿区的实际水样]]也表现良好，并且可多次循环重复使用。每种情况下的吸附过程均通过 [[X 射线光电子能谱|XPS]] 和 IR 光谱进行了研究。[[XPS]] 数据证实了污染物与材料中 N 和 S 活性位点的相互作用。此外，吸附过程遵循[[准二级动力学]]和 [[Langmuir 等温模型|Langmuir]] 等温线，显示出对大量污染物的极高[[吸附容量]]。这种可持续、低成本的材料为改善全球广谱水净化系统提供了一种可行的解决方案，解决了传统处理方法的局限性。
