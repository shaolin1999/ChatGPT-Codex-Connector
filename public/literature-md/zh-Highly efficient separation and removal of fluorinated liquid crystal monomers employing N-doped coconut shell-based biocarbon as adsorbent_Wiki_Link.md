# 以氮掺杂[[椰壳]]基[[生物炭]]为[[吸附剂]]高效分离与去除[[氟化液晶单体]]

## 摘 要

[[氟化液晶单体]]（[[F-LCMs]]）已被视为[[新兴有机污染物]]。高效分离和去除水体样品中的F-[[液晶单体|LCMs]]对于保护生态环境和人类健康至关重要。然而，关于F-LCMs处理和去除的研究仍然有限。本研究以[[椰壳]]基[[多孔碳]]为原料，通过[[KOH]]和[[尿素]]一步活化与[[热解]]制备了[[氮掺杂生物炭吸附剂]]（[[N@BA]]）。结果表明，改性不仅引入了有利的官能团，还将[[BET|比表面积]]从763 m<sup>2</sup>/g提高到908 m<sup>2</sup>/g。在最佳去除条件下，N@BA对F-LCMs表现出令人满意的[[吸附]]性能，[[吸附容量|最大吸附容量]]为1.25 mg/g至1.43 mg/g，实际环境水体中F-LCMs的[[去除率]]为86.6%至91.4%，明显高于未改性碳（57.1–67.7%）和[[活性炭|商业活性炭]]（65.5–76.3%）所获得的结果。吸附机理研究表明，N@BA对F-LCMs的去除过程属于以[[化学吸附]]为主导的[[单分子层吸附]]，[[氢键]]、[[π-π堆积]]和[[疏水相互作用]]等多种作用力共同促进了吸附。令人满意的结果充分证实，N@BA是一种经济高效且可持续的[[吸附剂]]，可用于高效去除水体中的F-LCMs。

## 1. 引言

近年来，由于各类电子设备的巨大需求，[[液晶显示]]（LCD）面板正经历强劲增长[1]。然而，随着电子产品的快速迭代更新，大量LCD面板被废弃并成为[[电子垃圾]][2]。[[液晶单体]]（LCMs）因其在液态和固态之间优异的转变性能而成为LCD面板的关键组分[3]。由于不当处置，各种LCMs可从废弃LCD面板中浸出进入环境介质[4, 5]。在泄漏的LCMs中，近一半属于氟化LCMs（[[F-LCMs]]）[6]。与非氟化LCMs相比，[[氟化液晶单体|F-LCMs]]表现出更高的毒性、持久性、[[生物蓄积性]]和迁移性。近期研究证实，F-LCMs的广泛存在可导致多种不良健康效应，如癌症、炎症反应和肥胖[7,8]。尽管F-LCMs表现出明显的健康风险，但据我们所知，关于环境介质中F-LCMs及其他LCMs高效去除的研究仍然有限。因此，采取措施消减环境介质中的F-LCMs极为紧迫。

迄今为止，[[吸附]]、[[热解]]和[[降解]]是去除受损水体中有机污染物的主要技术[9–11]。其中，吸附具有吸引力，因为可使用各类[[吸附剂]]，且易于以低能耗实现大规模应用[12,13]。此外，吸附不会产生降解过程中可能遇到的有害副产物。尽管吸附具有诸多优点，但利用吸附技术去除[[F-LCMs]]或其他[[液晶单体|LCMs]]的研究仍十分有限。近期，[[氧化-吸附Fenton联合技术]]被用于削减垃圾渗滤液中的一种典型LCM，即4-[二氟(3,4,5-三氟苯氧基)甲基]−3,5-二氟-o-4′-丙基联苯[10]。该研究提供了一种减少LCMs的策略。然而，该方法仅处理了单一目标分析物。此外，[[氟化液晶单体|F-LCMs]]含有高度氟取代基团，具有较高稳定性，比其他LCMs更难去除[14]。因此，应开发新措施以高效削减F-LCMs。

高性能[[吸附剂]]是[[吸附]]技术的核心。目前，已开发出大量吸附材料，如[[活性炭]]、树脂、[[金属有机框架]]等[15–20]。其中，[[生物质衍生碳材料]]（BDCMs）因其来源广泛、价格低廉、[[BET|比表面积]]大和可再生等优点而备受关注。目前，已制备了大量BDCMs并将其用作吸附剂，用于削减多种污染物[21–24]。例如，[[椰壳]]是一种有吸引力的BDCM前体材料，因其天然特性、长期可利用性以及丰富的羟基和羧基（这些基团对吸附至关重要）[25]。

在本研究中，根据去除[[F-LCMs]]的迫切需求以及[[生物质衍生碳材料|BDCMs]]的优点，以[[椰壳基活性炭]]（[[AC@CS]]）为原料，通过[[尿素]]和[[KOH]]的协同作用制备了[[氮掺杂生物炭吸附剂]]（[[N@BA]]）。对N@BA的制备条件和去除参数进行了详细优化。在有利条件下，所得N@BA被用于快速高效地去除多种水体中的[[氟化液晶单体|F-LCMs]]。此外，还研究了所涉及的[[吸附]]行为和去除机理。

## 2. 实验

## 2.1. 化学品与材料

[[AC@CS]]（平均粒径为75 μm）购自[[平顶山绿林活性炭有限公司]]（中国河南）。本研究中使用的其他化学品见补充材料（SM）。

四种[[F-LCMs]]标准品，包括4-[二氟(3,4,5-三氟苯氧基)甲基]−3,5-二氟-4′-乙基联苯（[[DTMDEB]]，98%）、2′,3,4,5-四氟-4″-丙基-1,1′:4′,1″-三联苯（[[TePT]]，98%）、4″-乙基-2′-氟-4-丙基-1,1′:4′,1″-三联苯（[[EFPT]]，98%）和[[3,4-二氟-4'-(反式-4-丙基环己基)联苯|3,4-二氟-4′-(反式-4-丙基环己基)联苯]]（[[DPrB]]，97%），均由[[阿拉丁试剂有限公司]]（中国上海）提供。所研究[[氟化液晶单体|F-LCMs]]的化学性质汇总于SM（表S1）。将F-[[液晶单体|LCMs]]混合标准品储备液（1000 mg/L）配制于[[甲醇]]（MeOH）/[[二氯甲烷]]（v/v，1/1）中，并在−20 °C下保存，直至进一步稀释。

## 2.2. 仪器

实验所用[[管式炉]]（型号：HT1250S）购自[[鸿城智能科技有限公司]]（中国河南）。所研究 [[F-LCMs]] 的定量分析在 [[高效液相色谱|HPLC]] Ultimate 3000 系列系统上进行。用于表征 [[N@BA]] 的色谱条件及仪器详细信息汇总于 SM。

## 2.3. [[N@BA]] 的合成

将 1 g [[AC@CS]] 分散在 20 mL 去离子水中，在[[超声波浴]]中清洗 20 min，以去除掺杂在碳中的可溶性灰分，避免杂质堵塞孔隙。随后，通过过滤收集 [[椰壳基活性炭|AC@CS]]，并在 $1 0 0 ~ ^ { \circ } \mathrm { C } .$ 下干燥。之后，准确称取洁净的 AC@CS、[[KOH]] 和[[尿素]]，并按 AC@CS：[[氢氧化钾|KOH]]：尿素 = 1：3：1 的质量比混合。将混合物研磨后置于[[管式炉]]中。随后，以 5 ◦C/min 的升温速率将混合物加热至 500 ◦C，并以 100 mL/min 的速率通入氮气。该加热程序保持 1 h。之后，将混合物冷却至室温，加入一定量的 1.0 mol/L HCl 溶液以中和 KOH，然后将颗粒浸入 20 mL 去离子水中进行超声处理。20 min 后，过滤混合物，并用去离子水再次冲洗收集的颗粒，直至滤液呈中性。最后，将材料置于 70 ◦C 烘箱中干燥 2.0 h，得到 [[N@BA]]。图 1 展示了 [[氮掺杂生物炭吸附剂|N@BA]] 的制备示意图。

## 2.4. [[吸附]]行为研究

## 2.4.1. [[吸附动力学]]

为确定 [[F-LCMs]] 在 [[N@BA]] 上的[[吸附]]速率，在室温下以 150 rpm 的转速，在不同反应时间（5.0 至 40 min）内进行批量吸附实验。所有实验均在 50 mL 含有 [[氟化液晶单体|F-LCMs]]（每种分析物 200 µg/L）的溶液中进行，溶液 [[pH]] 值控制在 5.0，[[吸附剂]]用量为 50 mg。

## 2.4.2. [[吸附等温线]]

通过采用不同的 [[F-LCMs]] 初始浓度（200、400、600、800、1000、1500、2000、2500 和 3000 μg/L）考察[[吸附等温线]]。所有实验均在 50 mL 溶液中进行，[[N@BA]] 用量为 50 mg。溶液 [[pH]] 控制在 5.0，[[吸附]]在 150 rpm 下进行 25 min。

## 2.4.3. [[吸附热力学]]

在所制备[[吸附剂]]上进行了 [[F-LCMs]] 在不同温度（283、288、293、298、303、308 和 313 K）下的[[吸附热力学]]实验。所有实验均在 50 mL 含有 [[氟化液晶单体|F-LCMs]]（每种分析物 200 µg/L）的溶液中进行，温度由水浴控制。其他条件与[[吸附等温线]]研究相同。

## 2.5. 数据处理与分析

在本研究中，采用线性和非线性动力学及等温线模型对所得实验数据进行模拟，包括[[伪一级动力学模型|伪一级]]、[[伪二级动力学模型|伪二级]]、[[Elovich模型|Elovich]]、[[颗粒内扩散模型|颗粒内扩散]]、[[Langmuir吸附等温线模型|Langmuir]]、[[Freundlich吸附等温线模型|Freundlich]]、[[Temkin吸附等温线模型|Temkin]] 和 [[Dubinin-Radushkevich模型|Dubinin-Radushkevich]] 模型 [26, 27]。这些模型的详细参数汇总于表 S2。

[[N@BA]] 对所研究 [[F-LCMs]] 的[[去除率]] Re（%）和[[平衡吸附量]] $Q _ { \mathrm { e } }$（μg/g）分别根据式（1）和式（2）[28] 计算。

$$
R e\% = \frac{C_0 - C_e}{C_0}\times 100\%\tag{1}
$$

$$
Q _ {\mathrm{e}} = \left(\frac {C _ {0} - C _ {\mathrm{e}}}{m}\right) V\tag{2}
$$

其中，$C _ { 0 }$（μg/L）和 $C _ { \mathrm { e } } \ ( \mu \mathrm { g } / \mathrm { L } )$ 分别为分析物的初始浓度和平衡浓度；m（g）和 V（mL）分别为 [[N@BA]] 的质量和溶液体积。

[[焓变]]（ΔH<sup>o</sup>）、[[熵变]]（ΔS<sup>o</sup>）和[[吉布斯自由能变]]$( \Delta G ^ { 0 } )$根据式（3）—（5）进行测定[29,30]。

$$
K _ {\mathrm{c}} = \frac {Q _ {\mathrm{e}}}{C _ {\mathrm{e}}}\tag{3}
$$

$$
\Delta G ^ {0} = \Delta H ^ {0} - T \Delta S ^ {0}\tag{4}
$$

$$
\ln K _ {c} = - \frac {\Delta H ^ {o}}{R T} + \frac {\Delta S ^ {o}}{R}\tag{5}
$$

式中，$K _ { \mathrm { C } } , R$和T分别为[[平衡常数]]、[[理想气体常数]][8.314 J/(mol•K)]和温度（K）；$Q _ { \mathrm { e } }$（μg/g）和$C _ { \mathrm { e } }$（μg/L）分别为[[吸附容量]]和所研究分析物在溶液中的平衡浓度。

## 2.6. [[N@BA]]的再生研究

基于[[吸附-脱附循环]]实验研究了[[N@BA]]的[[再生性能]]。分析物[[吸附]]后，通过过滤分离[[吸附剂]]。随后，将吸附剂浸入1.5 mL[[甲醇]]中30 min，以释放保留的[[F-LCMs]]。然后过滤吸附剂，并用超纯水清洗两次。处理后，将吸附剂重新用于另一份样品中捕获[[氟化液晶单体|F-LCMs]]。重复吸附-[[脱附]]循环，直至Re%的下降幅度超过10%。

## 2.7. 真实环境水体中[[F-LCMs]]的去除

通过去除包括污水、农田水和湖水在内的多种环境水体中的分析物，评价了所制备[[N@BA]]的实用性。去除前，用尼龙滤膜（0.45 μm）过滤样品中的悬浮物，然后用0.1 mol/L HCl将[[pH]]值控制在5.0。随后，将50 mg [[氮掺杂生物炭吸附剂|N@BA]]加入50 mL样品中，在$3 5 ~ ^ { \circ } \mathrm { C }$下振荡溶液（150 rpm）25 min进行去除操作。

## 3. 结果与讨论

## 3.1. [[N@BA]]的合成

在当前工作中，使用[[KOH]]活化[[AC@CS]]，并使用[[尿素]]提高[[吸附剂]]中的氮含量。为获得制备[[N@BA]]的有利条件，依次优化了[[氢氧化钾|KOH]]用量、尿素用量、煅烧温度和煅烧时间。

通过将[[AC@CS]]、[[KOH]]与[[尿素]]的质量比从1:0:1改变至1:4:1，考察了[[氢氧化钾|KOH]]用量对Re%的影响。如$^ { 2 \mathrm { a } , }$所示，Re%随KOH用量的增加（从1:0:1至1:3:1）而升高，从1:3:1至1:4:1无显著变化。图2b显示了尿素用量对Re%的影响。变化趋势表明，尿素用量显著影响[[N@BA]]对[[F-LCMs]]的去除效果。当用量过多时，Re%下降。主要原因可能是高尿素用量下[[吸附剂]]中的微孔被破坏，导致[[BET|比表面积]]下降[31,32]。此外，通过将温度从300 ℃升高至$7 0 0 ^ { \circ } \mathrm { C }$，考察了煅烧温度对Re%的影响。如图2c所示，有利温度为$5 0 0 ^ { \circ } \mathrm { C } .$。过高的煅烧温度会导致[[吸附]]剂中孔结构坍塌，从而降低去除性能。煅烧时间是影响多孔材料吸附性能的另一个关键条件[33]。煅烧时间过短不利于有利于吸附的孔的形成。然而，过长的煅烧过程会导致孔结构坍塌。在当前研究中，考察了不同的煅烧时间（30、60、90和120 min）。图2d所示结果表明，适宜的煅烧时间为60 min。

根据上述优化，制备 [[N@BA]] 时 [[AC@CS]]、[[KOH]] 与[[尿素]]的最佳质量比、煅烧温度和煅烧时间分别为 1:3:1、$5 0 0 ~ ^ { \circ } \mathrm { C }$ 和 60 min。在最佳条件下，考察了不同批次 [[氮掺杂生物炭吸附剂|N@BA]] 的制备重现性。结果表明，Re % 的 RSD % 在 1.0 % 至 2.5 % 之间变化。优异的制备重现性有利于 N@BA 在去除 [[F-LCMs]] 中的大规模应用。

## 3.2. [[N@BA]] 的多种表征

采用[[元素分析]]技术测定了 [[N@BA]] 和 [[AC@CS]] 中的 C 和 N 含量。结果表明，[[椰壳基活性炭|AC@CS]] 中的 C 和 N 含量分别为 86.9% 和 5.7%（w/w）。[[氮掺杂生物炭吸附剂|N@BA]] 中相应的值分别为 83.1% 和 7.3%（w/w）。N 含量的增加证实了利用[[尿素]]进行的 N 掺杂过程是成功的。

## 4. 结论

在当前研究中，开发了一种经济高效、可持续且环境友好的[[吸附剂]]，用于去除多种环境水体中的 [[F-LCMs]]。以[[椰壳]]为原料制备的[[多孔碳]]在高温下经 [[KOH]] 和[[尿素]]改性。改性显著提高了所制备 [[N@BA]] 的[[BET|比表面积]]，同时引入了丰富的含氮活性基团，从而明显增强了去除性能。[[吸附]]行为研究表明，[[氮掺杂生物炭吸附剂|N@BA]] 对 [[氟化液晶单体|F-LCMs]] 的去除基于[[化学吸附]]。与其他模型相比，[[Langmuir吸附等温线模型|Langmuir]] 模型更能拟合[[吸附等温线]]，证实该吸附可归属于单分子层过程。此外，提高接触温度有利于去除效果。在多重相互作用下，所制备的 N@BA 对研究的 F-[[液晶单体|LCMs]] 表现出优异的去除性能，Re % 值为 86.6–91.4 %，高于未改性的 [[AC@CS]] 和[[活性炭|商业活性炭]]。此外，N@BA 还具有吸附过程快速、[[再生性能]]良好、成本低和绿色环保等优点。综上所述，本研究不仅为各类水体中 F-LCMs 的削减提供了实用策略，也为废弃椰壳的[[资源化利用]]探索了一条可行途径。
