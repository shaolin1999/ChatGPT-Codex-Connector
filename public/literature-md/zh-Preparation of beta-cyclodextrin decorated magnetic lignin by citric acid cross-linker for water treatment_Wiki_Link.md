## 摘 要

本研究采用一种简便方法制备了用于选择性去除[[阳离子染料]]的[[多功能吸附剂]]。为合成该[[吸附剂]]，首次通过[[柠檬酸]][[交联剂]]将[[β-环糊精]]（beta-CD）[[接枝]]到[[磁性木质素]]（ML）上，利用其空腔独特而出色的结构，该空腔具有适合捕获和[[吸附]]阳离子染料的适宜尺寸。采用多种技术对磁性吸附剂（[[β-CD@ML]]）进行了表征，包括[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）、[[XPS|X射线光电子能谱]]（[[X 射线光电子能谱|XPS]]）、[[XRD|X射线衍射]]（[[X 射线衍射|XRD]]）和[[氮气吸附-脱附分析]]。为检验β-CD@ML的性能，研究了其从水溶液中去除[[亚甲基蓝]]的吸附过程。在[[pH]] 7、β-CD@ML[[投加量]]为0.6 g L<sup>−</sup> <sup>1</sup>、污染物浓度为20 [[孔雀石绿|mg]] L<sup>−</sup> <sup>1</sup>、时间为45 min的条件下，亚甲基蓝的最佳[[去除效率|去除率]]约为97%，而在相同条件下磁性[[木质素]]对亚甲基蓝的去除率为55%。吸附过程适用的模型为[[Langmuir等温线]]，其在25 °C下显示[[吸附容量|最大吸附容量]]为80 mg g<sup>−</sup> <sup>1</sup>。还考察了β-CD@ML吸附剂的稳定性和可重复使用性，结果表明吸附效率略有下降。

## 1. 引言

工业化、不受控制的城市化、自然水资源的过度使用以及人口增长已显著影响水质（Rout et al., 2023）。[[废水处理]]可以从工业废物中回收水资源（Saravanan et al., 2021）。染料因其着色性能在皮革、造纸尤其是纺织品的制造中不可或缺。不幸的是，染料未经处理即被排放到水体环境中，导致水质恶化（Rius-Ayra et al., 2023）。染料作为一大类有机化合物的存在，引发了日益严重的环境问题（Sharma & Bhattacharya, 2017）。摄入染料可导致人类发生致癌、致突变以及大脑、肾脏、肝脏和神经系统的异常或功能障碍（Saravanan et al., 2021）。[[亚甲基蓝]]（MB）目前被广泛用作多种用途的染料。废水中MB染料的存在对人类和环境都是一个重大问题（Mosoarca et al., 2022）。

迫切需要采取行动，开发经济实惠、易获得且环境友好的技术与材料，用于去除水污染物和[[废水处理]]（Waheed et al., 2021）。由于过程简单（Amiri-Khamakani et al., 2024）、成本效益高（Heravi et al., 2024）以及[[吸附剂]]可回收（[[Zhou]] et al., 2018），[[吸附]]已成为一种常见的[[废水净化技术]]。经济且环境友好的[[生物吸附剂]]可以通过简单改性来提高其[[吸附容量]]（Osman et al., 2023）。利用[[纤维素]]、[[木质素]]、[[壳聚糖]]和[[农业废弃物]]合成[[绿色可生物降解吸附剂]]用于去除污染物，因其天然丰度、经济性、生物相容性和对环境影响小而被考虑。木质素是一种天然且结构复杂的[[芳香族可再生生物聚合物]]（Li et al., 2015）。木质素分子中[[活性位点]]的存在及其独特特性、生物相容性、[[可再生性]]、经济性和丰度，使其能够高效吸附水中的各种有机和无机污染物（Ge & Li, 2018）。[[酚羟基]]、[[羰基]]和[[甲氧基]]是木质素中的[[官能团]]。木质素在不同化学过程中的反应活性直接受这些官能团数量的影响（Katahira et al., 2018）。由于吸附速率慢且吸附容量有限，这些吸附剂的实际适用性显著降低。因此，可以对木质素进行改性，以提高其作为吸附剂的性能（Li et al., 2015）。

[[环糊精]]是易获得、环境友好且可再生的材料（Przybyla et al., 2020）。淀粉和糖的酶促分解会形成被称为环糊精的[[超分子结构]]（Farooq et al., 2023）。它们通常由通过$_ { \alpha - 1 , 4 }$[[糖苷键]]连接的[[吡喃葡萄糖单元]]组成，构成一类独特的[[环状低聚糖]]（Varan et al., 2017）。[[β-环糊精]]（beta-CD）的外表面具有[[亲水性]]，而内腔具有[[疏水性]]（Ghahramaninezhad & [[Ahmadpour]], 2022）。许多有机客体分子如果尺寸和极性合适，可以在疏水腔中形成[[客体-主体复合物]]。β-CD的亲水基团会导致环糊精在水中溶解，从而阻碍其直接用于去除污染物（Amran & Zaini, 2022）。解决这一问题有两种途径：1-通过不同[[交联剂]]进行[[接枝]]，2-通过β-CD[[交联]]剂进行交联（Verma et al., 2022）。通过将β-CD与纳米材料（包括[[氧化石墨烯]]、[[碳纳米管]]和[[金属有机框架]]）混合，已合成了多种材料。然而，制备这些纳米材料工艺复杂、成本高昂，并且需要大量有机溶剂。选择环境友好的材料对于绿色制备β-CD复合材料至关重要（[[Wei]] et al., 2023）。

Li等人（2023）合成了[[木质素]]、[[环糊精]]和[[聚乙烯亚胺]]的复合微球。在制备这些微球的过程中，木质素可稳定β-CD，而[[环氧氯丙烷]]则充当[[交联剂]]。研究了复合微球对[[2,4-二氯苯氧乙酸]]和[[双酚A]]的[[吸附容量]]。与[[活性炭]]、[[氧化石墨烯]]、[[MIL-53]]和$\mathrm { M I L } { - } 1 0 1 { - } ( \mathrm { O H } ) _ { 3 }$相比，复合微球表现出优异的[[吸附]]容量（[[Wei]] et al., 2023）。Petitjean等人（2022）在环境友好的过程中用[[柠檬酸]]连接[[黄原胶]]、[[刺槐豆胶]]和[[壳聚糖]]。β-CD和木质素的同时引入增强了对[[疏水性]]污染物的吸附容量。基于这些结果，黄原胶/β-CD/木质素基质在吸附酚类污染物方面最为有效（Petitjean et al., 2022）。近年来，使用柠檬酸作为[[交联]]剂的情况有所增加。此外，使用柠檬酸合成β-CD聚合物能够实现同时吸附（Liu et al., 2020）。绿色化学品（如柠檬酸）对于解决毒性问题或尽量减少有毒有机物质的使用至关重要（Köse et al., 2022）。

本研究的第一个假设是，可以开发一种通过[[柠檬酸]][[交联剂]]将β-CD修饰到[[磁性木质素]]（ML）上的直接方法，以提高从水环境中去除[[亚甲基蓝|MB]]的效率。因此，本研究旨在制备并探究一种含有[[环糊精]]作为环保且廉价改性剂的[[磁性生物吸附剂]]的性能。使用廉价、绿色且易得的柠檬酸将β-CD[[接枝]]到ML上，以制备多功能[[生物吸附剂]]（[[β-CD@ML]]）。现有文献中尚无使用柠檬酸将β-CD[[交联]]到磁性[[木质素]]上的先例，而且大多数使用的交联剂都是有毒的$\mathrm { ( L u ~ e t ~ a l . }$ 2019; Yang et al., 2016）。此外，该[[吸附剂]]的合成方法简单且耗时短，仅使用水作为溶剂。使用水作为溶剂是一个重要特征，因为与依赖有毒且昂贵溶剂的[[吸附]]剂相比，它可以降低生产成本。同时，该吸附剂的磁性使其在水环境中易于分离，因此非常适用于[[水处理]]过程。第二个假设是，溶液中MB的去除是由β-CD@ML与MB之间的[[静电相互作用]]、[[络合作用]]、[[氢键]]和[[π-π堆积]]驱动的。

为验证这些假设，研究了[[β-CD@ML]]的合成。本研究全面考察了[[停留时间|接触时间]]、β-CD@[[磁性木质素|ML]]用量、[[pH]]和$\mathsf { d y e } ,$浓度以及温度对污染物去除的影响。此外，还开展了[[吸附动力学]]、平衡等温线和[[热力学实验]]，以揭示[[亚甲基蓝|MB]]在β-CD@ML上的[[吸附]]机理。

## 2.2. 方法与仪器

## 2.3. [[吸附剂]]的制备

所提出的用于开发[[beta-CD@ML]]作为[[多功能吸附剂]]的方案包括两个主要步骤。每一步均在图1中详细描述。

## 2.3.1. [[磁性木质素]]的合成

[[磁性木质素]]作为[[吸附剂]]的磁核，采用Han等人（Han et al., 2022）提出的改进方法制备。将$( 7 . 5$ mmol）[[七水合硫酸亚铁|七水合硫酸亚铁（II）]]和$3 . 0 \ g \ ( 1 1 . 1 $ mmol）[[六水合氯化铁|六水合氯化铁（III）]]溶于50 mL[[规格化溶剂|去离子水]]中，并在$9 0 ^ { \circ } \mathrm { C } .$下搅拌40 min。然后，向混合物中加入1.0 g（0.1 mmol）[[木质素]]并搅拌40 min。最后一步，在搅拌下于$8 0 ^ { \circ } \mathrm { C }$向该混合物中逐滴加入5 mL[[氨水]]（28%），持续1 h。用外部磁铁收集最终的深棕色磁性木质素分散体，用去离子水洗涤，并在$6 0 ~ ^ { \circ } \mathrm { C }$下干燥过夜。

## 2.3.2. [[beta-CD@ML]]的合成

[[beta-CD@ML]]通过在[[磁性木质素]]表面以[[柠檬酸|CA]]和[[β-环糊精|beta-CD]]进行[[酯化缩聚]]过程合成。为此，将0.1 g ML与一定量的beta-CD、0.4 g $( 2$ mmol）CA以及0.24 g（1.7 mmol）$\mathrm { K H _ { 2 } P O _ { 4 } }$作为催化剂同时加入15 mL水中。获得均匀混合物后，将混合物转移至培养皿中，在140 $^ \circ \mathrm { C }$下加热2 h。随后，将该步骤所得产物冷却后用[[规格化溶剂|去离子水]]浸泡并多次洗涤进行纯化。最终，将所需磁性[[吸附剂]]在$6 0 ~ ^ { \circ } \mathrm { C }$下干燥过夜。

## 2.4. [[吸附]]过程的一般方法

在[[beta-CD@ML]]存在下去除[[亚甲基蓝|MB]]的实际实验被建立并实施，以全面考察所合成[[吸附剂]]在[[吸附]]过程中的表现。所有实验中，将[[β-CD@ML|beta-CD@ML]]加入体积为25 [[磁性木质素|mL]]的MB染料溶液中。分别考察了初始[[pH]]（3–11）、温度（25–45 ${ } ^ { \circ } \mathbf { C } ) _ { i }$）、[[初始浓度|污染物初始浓度]]（5–150 [[孔雀石绿|mg]] $\mathrm { L } ^ { - 1 } )$）、[[β-环糊精|beta-CD]]@ML[[投加量]]$( 0 . 3 { - } 1 . 2 \ \mathrm { ~ g ~ L ^ { - 1 } } )$以及[[停留时间|接触时间]]对吸附过程的影响。此外，分别使用0.1 M [[氢氧化钠|NaOH]]或[[盐酸|HCl]]调节碱性和酸性介质。经过一定时间后，使用外部磁铁收集吸附剂。然后，使用[[紫外分光光度计]]监测污染物的残留浓度。[[去除效率|R.E.]]和${ \mathsf { q } } _ { \mathrm { e } }$使用式（1）和式（2）计算。

$$
R E = \frac {\left(C _ {0} - C _ {t}\right)}{C _ {0}} \times 1 0 0\tag{1}
$$

$$
q _ {e} = \frac {(C _ {0} - C _ {e}) V}{m}\tag{2}
$$

其中，[[去除效率|R.E.]]表示污染物去除效率$( \% ) , \mathrm { C } _ { 0 }$，$\mathrm { C _ { t } }$（[[孔雀石绿|mg]] $\mathrm { L } ^ { - 1 } )$）分别表示初始时刻和t时刻的污染物浓度。[[beta-CD@ML]]的[[吸附容量]]（mg ${ \mathbf g } ^ { - 1 } )$）和平衡时污染物的残留浓度（mg $\mathrm { L } ^ { - 1 } )$）分别由$\mathsf { q _ { e } }$和$\mathrm { C } _ { \mathrm { e } } ,$表示，m表示[[β-CD@ML|beta-CD@ML]]的用量（g），V为污染物体积（L）（Yatimzade等，2024）。

## 2.5. [[吸附动力学]]

采用[[准一级动力学模型|准一级]]（PFO）和[[准二级动力学模型|准二级]]（PSO）动力学模型研究[[亚甲基蓝|MB]]在[[beta-CD@ML]]上的[[吸附动力学]]。这些模型分别由式（3）和式（4）表示。参数t（min）和$\mathbf { q } _ { \mathrm { t } } ( \mathbf { m } \mathbf { g } \mathbf { \Lambda } \mathbf { g } ^ { - 1 } )$分别表示[[停留时间|接触时间]]和t时刻的[[吸附容量]]。PFO和PSO模型中采用的速率常数分别为参数k<sub>1</sub> $( \mathrm { m i n } ^ { - 1 } )$和k<sub>2</sub> $( g$ $\mathrm { m } \bar { \mathrm { g } ^ { - 1 } } \mathrm { \dot { m } } \mathrm { i n } ^ { - 1 } ) .$（Yatimzade等，2024）。

$$
\text { Pseudo   -   first   -   order }: \ln (q _ {e} - q _ {t}) = l n q _ {e} - k _ {1} t\tag{3}
$$

$$
\text { Pseudo   -   second   -   order }: \frac {t}{q _ {t}} = \frac {1}{k _ {2} q _ {e} ^ {2}} + \frac {t}{q _ {e}}\tag{4}
$$

采用[[Weber和Morris模型]]研究[[吸附质]]分子与[[吸附剂]]之间的扩散机制（式（5））。

$$
q _ {t} = k _ {i} t ^ {0. 5} + C\tag{5}
$$

其中，截距由$\mathrm { C } ,$表示，[[颗粒内扩散模型|颗粒内扩散]]速率常数由$\mathbf { k } _ { \mathrm { i } }$（[[孔雀石绿|mg]] $( \mathbf { g } { \cdot } \mathbf { m i n } ^ { 0 . 5 } ) ^ { - 1 } )$）表示（Tanhaei等，2015）。

## 2.6. [[吸附等温线]]

采用三种广为人知的等温线模型，即[[Langmuir 等温线|Langmuir]]、[[Freundlich 等温线|Freundlich]]和[[Temkin 等温线|Temkin]]，研究[[亚甲基蓝|MB]]分子与[[beta-CD@ML]]表面之间的相互作用。这些等温线模型的线性形式由式（6）至式（8）给出：

$$
\text { Langmuir }: \frac {1}{q _ {e}} = \frac {1}{q _ {m}} + \left(\frac {1}{K _ {L} q _ {m}}\right) \left(\frac {1}{C _ {e}}\right)\tag{6}
$$

$$
\text { Freundlich }: \ln q _ {e} = \ln K _ {f} + \left(\frac {1}{n}\right) \ln C _ {e}\tag{7}
$$

[[Temkin 等温线|Temkin]]：$q _ { e } = { \frac { R T } { b _ { T } } } \ l n { a _ { T } } + { \frac { R T } { b _ { T } } } \ l n { C _ { e } }$

(8)

其中 $\begin{array} { r } { \mathfrak { q } _ { \mathrm { m } } ( \mathbf { m } \mathbf { g } \mathbf { \Lambda } \mathbf { g } ^ { - 1 } ) , \mathbb { K } _ { \mathrm { L } } ( \mathbf { L } \mathbf { \Lambda } \mathbf { m } \mathbf { g } ^ { - 1 } ) . } \end{array}$ 和 $\mathrm { K } _ { \mathrm { f } } ( ( \mathrm { m g ~ g ^ { - 1 } } ) ( \mathrm { L ~ m g ^ { - 1 } } ) ^ { 1 / \mathrm { n } } )$ 分别为[[最大单层吸附容量]]、[[Langmuir常数|Langmuir 常数]]和 [[Freundlich常数|Freundlich 常数]]。在 [[Freundlich等温线|Freundlich 模型]]中，n 表示一个无量纲常数（Yatimzade et al., 2024）。

[[Langmuir 等温线|Langmuir]] 方程的无量纲参数 $\mathrm { R _ { L } }$ 由式（9）确定：

$$
R _ {L} = \frac {1}{1 + K _ {L} C _ {0}}\tag{9}
$$

在 [[Temkin 模型]]中，$\textbf { R } ( \mathbf { J \ m o l } ^ { - 1 } \ \mathbf { K } ^ { - 1 } )$ 表示[[通用气体常数]]。参数 T、$( \mathrm { K } ) , \mathbf { a } _ { \mathrm { T } } ( \mathrm { L } \mathbf { g } ^ { - 1 } )$ 和 $ { \mathbf { b } } _ { \mathrm { T } } (  { \mathbf { J } }  { \mathbf { m o l } } ^ { - 1 } )$ 分别表示[[绝对温度]]、与最大结合能对应的[[平衡结合常数]]以及与[[吸附热]]相关的常数（[[Ahmadpour]] et al., 2023）。

## 2.7. [[吸附热力学]]

通过应用式（10）、（11）和（12），计算了 [[亚甲基蓝|MB]] 在 [[beta-CD@ML]] 上[[吸附]]的主要[[热力学参数|热力学]]参数（▵G∘、▵H∘ 和 ▵S∘）（Rahman & Raheem, 2023）。

$$
K = \frac {q _ {e} * 1 0 0 0}{C _ {e}}\tag{10}
$$

$$
\Delta G ^ {\circ} = - R T \ln K\tag{11}
$$

$$
\ln K = - \frac {\Delta H ^ {\circ}}{R T} + \frac {\Delta S ^ {\circ}}{R}\tag{12}
$$

其中 $\triangle \mathrm { G } ^ { \circ } , \triangle \mathrm { H } ^ { \circ } ,$ 和 ▵S∘ 分别为[[吉布斯自由能]]（J mol $^ { - 1 } ) ,$）、焓（J mol $^ { - 1 } )$）和熵（J mol $^ { - 1 } { \sf K } ^ { - 1 } )$）变化。参数 K 为[[平衡常数]]（Tanhaei et al., 2015）。

## 3.3. [[beta-CD@ML]]的[[吸附]]性能

## 3.3.1. 初始[[pH]]的影响

beat-CD@[[磁性木质素|ML]] 在初始溶液 [[pH]] 为 3.0 至 11.0 范围内的 [[zeta 电位]]如图 6(a)所示。如图所示，在所有测定的 pH 条件下，[[beta-CD@ML]] 的 zeta 电位在 −15 至 −28 mV 之间变化。这表明 [[β-CD@ML|beta-CD@ML]] [[吸附剂]]表面因[[羧基]][[去质子化]]而带有[[负电荷]]（[[Zhou]] et al., 2018）。如图 6(b)所示，在 [[亚甲基蓝|MB]] 溶液 $2 0 \mathrm { \ m g \ L ^ { - 1 } }$ 3、[[β-环糊精|beta-CD]]@ML [[投加量]] $0 . 6 \ \mathrm { g } \ \mathrm { L } ^ { - 1 } ;$ 以及[[停留时间|接触时间]] 45 min 的条件下，考察了不同 pH 下 beta-CD@ML 对 MB 的[[吸附]]。

在低 [[pH]] 条件下，[[阳离子染料]]分子与 $\mathrm { H ^ { + } }$ 离子竞争[[吸附剂]][[活性位点]]上的[[吸附]]。因此，在酸性条件下，[[亚甲基蓝|MB]] 的吸附量预计最低。此外，H<sup>+</sup> 离子在吸附剂表面的吸附也可能导致吸附剂表面与阳离子染料分子之间产生[[静电排斥]]（[[Khoshkho]] et al., 2021）。随着 pH 升高，溶液中 H<sup>+</sup> 离子浓度降低，使 MB 发生[[质子化]]。由于 [[beta-CD@ML]] 与 MB 之间的[[静电吸引]]作用，这种质子化增加了染料的吸附量（Lee et al., 2019）。MB 在酸性溶液中的[[去除效率]]在 pH 3 时约为 70 %，而在 pH 7 和 11 时分别提高到 97 % 和 99 %。MB 在 pH 7–11 范围内去除效率的变化可忽略不计。

## 3.3.2. [[吸附剂用量]]的影响

高效且经济的[[废水处理]]依赖于选择适当的[[吸附剂用量]]（[[Khoshkho]] et al., 2021）。通过添加不同量的[[吸附剂]]，研究了[[beta-CD@ML]]用量对[[亚甲基蓝]]去除效果的影响。 $( 0 . 3 { - } 1 . 2 \ \mathrm { g } \ \mathrm { L } ^ { - 1 } )$ to MB 溶液（20 [[孔雀石绿|mg]] $\mathrm { L } ^ { - 1 } )$ 并摇动混合物 60 分钟。结果如图 6(c) 所示。随着 [[β-CD@ML|beta-CD@ML]] 用量从 0.3 增加到 $0 . 6 \mathrm { ~ g ~ L ~ } ^ { - 1 }$ 由于空置和可用[[吸附位点]]的增加（Khoshkho et al., 2021）。[[β-环糊精|beta-CD]]@[[磁性木质素|ML]] [[吸附]]剂即使在低用量下也表现出显著的[[去除效率|去除率]]（86 %） $( 0 . 3 \mathrm { g } \mathrm { L } ^ { - 1 } )$ . 超出剂量 $\operatorname { s f } 0 . 6 \ \mathbf { g } \mathbf { L } ^ { - 1 }$ ，吸附去除效率几乎没有变化，表明已达到平衡。因此，选择[[投加量]]为 $0 . 6 \mathrm { ~ g ~ L ~ } ^ { - 1 }$ 被确定为该吸附剂的最优值。

## 3.3.3. [[停留时间|接触时间]]的影响与[[吸附动力学]]

[[亚甲基蓝|MB]] 在 [[beta-CD@ML]] 上的[[吸附动力学]]（[[初始浓度]]为 20 和 40 [[孔雀石绿|mg]] L<sup>−</sup> <sup>1</sup>）如图 7(a) 所示。对于 $\mathrm { { C } _ { 0 } = 2 0 \mathrm { { m g } L ^ { - 1 } } }$，前 15 分钟内即发生快速[[吸附]]并去除 72% 的 MB；对于 $\mathrm { C } _ { 0 } = 4 0$ mg $\mathrm { L } ^ { - 1 } .$，则在 45 分钟内达到相同[[去除效率|去除率]]。随后，对于 $\mathrm { C } _ { 0 } = 2 0 \mathrm { m g } \mathrm { L } ^ { - 1 }$，在 30 分钟后进入较慢阶段；对于 $\mathrm { C } _ { 0 } = 4 0 \mathrm { m g L } ^ { - 1 }$，则在 60 分钟后进入较慢阶段，直至达到平衡，此时超过 90% 的染料被去除。快速吸附可归因于 [[β-CD@ML|beta-CD@ML]] [[吸附剂]]表面存在大量空位[[吸附位点]]。随着吸附过程的进行，吸附速率稳步下降直至达到平衡，这可能是由于 MB 分子向 [[β-环糊精|beta-CD]]@[[磁性木质素|ML]] 体相内部的缓慢扩散所致（[[Khoshkho]] et al., 2021）。较高的初始污染物浓度（40 mg $\mathrm { L } ^ { - 1 } )$）也会增强吸附，表明[[质量扩散]]的驱动力更强（[[Wei]] et al., 2023）。

## 3.3.5. [[吸附热力学]]

当温度从 298 K 分别升高到 308 和 318 K 时，[[亚甲基蓝|MB]] 在 [[beta-CD@ML]] 上的[[吸附容量]]从 28.09 增加到 28.46 和 28.54 [[孔雀石绿|mg]] $\mathbf { g } ^ { - 1 }$（图 S6(a)）。随着温度升高，溶液黏度降低，导致 [[β-CD@ML|beta-CD@ML]] 与 MB 分子之间碰撞增多，从而增强[[吸附]]。

## 3.4. 选择性研究

图 S7(a)展示了浓度为 20 [[孔雀石绿|mg]] $\mathrm { L } ^ { \dot { - } 1 }$ 的单独溶液及等量混合物中 [[亚甲基蓝|MB]] 和[[甲基橙]]（MO）的[[去除效率]]。在[[单组分溶液]]中，MB 和 MO 的去除效率分别为 97%和 5%；在[[双组分混合物]]中，MB 从 97%下降到 95%。相比之下，与之前的单组分混合物相比，MO 没有显著变化。[[羧基]]的存在导致[[静电排斥]]，使[[酸性染料]]（如 MO）较不理想。[[阳离子染料]]（如 MB）含有氮或硫的正电离基团，可以在二元混合物中被 [[beta-CD@ML]] 高效去除。在 MB 和 MO 的双组分组合中观察到去除效率下降了 2%。当两种染料相互作用形成 [[MB-MO 复合物]]时，阳离子基团中的电子密度可能发生改变。染料之间的相互作用导致 MB-MO 复合物的形成，对[[吸附]]行为具有影响。MB 结构可能发生的变化可能影响其去除过程的效率。

先前涉及含[[羧基]]的[[环糊精基聚合物]][[吸附剂]]的研究中也得到了类似结果，这与不同染料之间的相互作用及复合物形成的影响在[[吸附]]行为中起关键作用的观点一致（[[Zhou]] et al., 2018）。选择性研究表明 [[beta-CD@ML]] 具有高选择性，使其成为去除其他带正电荷基团的有前景的方法。[[亚甲基蓝]]、[[结晶紫]]（CV）和[[孔雀石绿]]（MG）在 [[β-CD@ML|beta-CD@ML]] 上的[[去除效率]]如图 S7(b)所示。CV 和 MG 的去除效率分别为 73%和 65%，表明它们相似的分子结构促成了这些相近的数值。图 S7(c)展示了在由 MB 和 [[甲基橙|MO]] 组成的[[双组分溶液]]中去除 MB [[阳离子染料]]的图像。

## 3.5. [[离子强度]]的影响

[[吸附]]过程也会受到[[盐度]]的影响。具有不同[[离子强度]]的水溶液会直接影响水相中的吸附。本研究在[[亚甲基蓝|MB]]溶液中加入[[氯化钠|NaCl]]，以考察盐度或离子强度的影响。NaCl溶液的配制浓度范围为0.001至0.5 M。如图8(a)所示，在0.5 M NaCl浓度下，亚甲基蓝的[[去除效率]]下降了71 %。由于[[静电相互作用]]，带正电荷的阳离子MB和Na<sup>+</sup>与[[吸附剂]]中存在的[[羧酸根阴离子]]形成强键。较高浓度下$\mathrm { N a ^ { + } }$的存在会阻塞[[吸附剂结合位点]]，并与MB产生竞争。Jacob等人也报道了类似的结果（[[Lagiewka]] et al., 2023）。

## 3.7. 提出的[[吸附]]机理

[[beta-CD@ML]] [[吸附]] [[亚甲基蓝|MB]] 的机理示意如图 9(a) 所示。[[β-环糊精|beta-CD]] 单元的[[疏水空腔]]含有[[桥氧]]和氢原子。[[包合络合效应]]使 MB 分子被捕获在该空腔内部（[[Jiang]] et al., 2019）。[[柠檬酸]]的[[羧酸根阴离子]]（-COO-）（[[Huang]] et al., 2018）通过[[静电吸引]]有效吸附[[阳离子染料|阳离子 MB 染料]]，凸显了[[静电相互作用]]在吸附中的重要性。此外，染料分子中带正电的氮原子与[[木质素]]的[[羟基]]之间发生静电相互作用（[[Budnyak]] et al., 2018）。与 beta-CD（[[Lagiewka]] et al., 2023）和木质素的[[含氧官能团]]形成的[[氢键]]，以及 MB 与木质素之间的 [[π–π 堆积|π–π 相互作用]]也对吸附有所贡献（Budnyak et al., 2018）。

[[FTIR]] 光谱（图 9(b)）通过考察[[官能团]]的参与情况，为[[吸附]]机理提供了依据。与 [[beta-CD@ML]] 相比，[[β-CD@ML|beta-CD@ML]]-[[亚甲基蓝|MB]] 官能团特征峰出现明显偏移和强度降低，表明吸附过程中发生了变化。MB 吸附后 3455 $\mathrm { c m } ^ { - 1 }$ 处峰强度降低，表明吸附对[[羟基]]的 [[氧-氢伸缩振动|O–H 伸缩振动]]有影响，并可能影响络合物内部的[[氢键]]。$2 9 3 9 \mathrm { c m } ^ { - 1 }$ 处的峰没有显著变化。因此，[[葡萄糖单元]]烷基的 [[碳-氢键|C–H 键]]不参与吸附（[[Lagiewka]] et al., 2023）。1743 cm<sup>−</sup> <sup>1</sup> 处的峰强度在吸附后显著降低，这是因为[[柠檬酸]]的羧酸根基团 $( \mathbf { C } = \mathbf { O } )$ 与[[阳离子染料]]发生相互作用（[[Huang]] et al., 2018）。吸附前，[[木质素]]在 1594 $\mathrm { c m } ^ { - 1 }$ 处的峰与 [[β-环糊精|beta-CD]] 在 $1 6 3 5 ~ \mathrm { { c m } ^ { - 1 } }$ 处的强键重叠。吸附后，1635 $\mathrm { c m } ^ { - 1 }$ 处的峰强度略有降低，表明 [[碳-碳键|C–C]] 与 MB 之间存在弱相互作用。木质素峰也出现在 $1 5 9 4 ~ \mathrm { c m } ^ { - 1 }$ 处，表明[[二苯基木质素]]与 MB [[芳环]]之间存在 [[π–π 堆积|π-π 堆积效应]]。然而，由于 π 电子的强度弱于[[静电相互作用]]或氢键，其对 MB 结合的贡献很小。

[[吸附]]后，1157 $\mathrm { c m } ^ { - 1 }$ 和 $1 0 2 8 ~ \mathrm { { c m } ^ { - 1 } }$ 处的峰强度降低且变宽，表明[[木质素]] $\mathrm { C - O H }$ 基团和 [[β-环糊精|beta-CD]] [[葡萄糖环]]与 [[亚甲基蓝|MB]] 发生了相互作用。$\bar { 1 0 2 8 } \mathrm { c m } ^ { - 1 }$ 峰强度在吸附后的变化表明，MB 分子可因[[环糊精空腔]]而被插入（[[Lagiewka]] et al., 2023）。

## 3.8. 与其他[[吸附剂]]的比较

[[beta-CD@ML|beta-CD@ML 吸附剂]]对 [[亚甲基蓝|MB]] [[吸附]]的 $\mathbf { q } _ { \mathrm { m a x } }$ 为 80 [[孔雀石绿|mg]] $\mathbf { g } ^ { - 1 }$。该 $\mathbf { q } _ { \mathrm { m a x } }$ 值表明其对 MB 染料具有显著的吸附能力。将本[[吸附剂]]与表 S7 中列出的其他吸附剂进行比较，含[[环糊精]]的吸附剂（包括 [[β-CD@ML|beta-CD@ML]]）往往表现出较高的 $\mathbf { q } _ { \mathrm { m a x } }$ 值，因为不同的[[官能团]]共同促进有效吸附。

## 4. 结论

总之，本研究提出了一种环保的方法，利用[[木质素]]、[[β-环糊精]]（beta-CD）和[[柠檬酸]]这三种安全无毒的材料制备[[多功能吸附剂]]（[[beta-CD@ML]]），并考察其作为选择性去除[[阳离子染料]][[吸附剂]]的性能。采用多种光谱方法对 [[β-CD@ML|beta-CD@ML]] [[吸附]]剂进行了表征。[[BET|比表面积]]为 $\mathbf { o f } 5 . 3 7 \mathbf { m } ^ { 2 } \mathbf { g } ^ { - 1 }$ 的吸附剂在 ${ } ^ { 2 5 } \ ^ { \circ } \mathrm { C }$ 条件下表现出 80 [[孔雀石绿|mg]] g<sup>−</sup> <sup>1</sup> 的[[吸附容量|最大吸附容量]]，并在相同条件下对[[亚甲基蓝]]实现了 97% 的高[[去除效率|去除率]]，而[[磁性木质素]]的去除率仅为 55%。因此，通过结构分析，吸附剂合成的正确性得到了证实，并且第一个假设也因磁性木质素经 β-[[环糊精]]改性后对亚甲基蓝去除率的提升而得到验证。在所有模型中，[[PSO 模型]]和 [[Langmuir 等温线]]对亚甲基蓝去除过程拟合最佳。因此，该吸附过程可归属于均质表面上的[[物理吸附]]。[[热力学参数|热力学]]分析表明，该吸附为放热过程（▵H∘ > 0），并伴随随机性的增加 $\left( \triangle S ^ { \circ } > 0 \right)$。[[静电相互作用]]、[[络合作用]]、[[氢键]]和 [[π–π 堆积|π-π 堆积]]被认为是吸附过程中 beta-CD@ML 与亚甲基蓝之间相互作用的可能机制。由于证实了吸附剂与亚甲基蓝之间形成相互作用的不同机制，第二个假设也得到验证。beta-CD@ML [[生物吸附剂]]因其合成简便、使用[[绿色交联剂|绿色易得的交联剂]]、便于回收的[[磁性能]]、良好的吸附性能以及优异的[[再生能力]]，在实际[[水处理]]应用中展现出良好的潜力。
