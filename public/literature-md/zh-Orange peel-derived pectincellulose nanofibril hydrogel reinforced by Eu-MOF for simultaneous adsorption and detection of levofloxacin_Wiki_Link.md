## 摘 要

[[橙皮]]是一种富含多糖的丰富农工残留物，常被丢弃，造成资源浪费和环境负担。本文通过嵌入均匀分散的[[铕基金属有机框架]]修饰[[纤维素纳米纤丝]]（[[Eu-MOF@CNF]]），将橙皮来源[[果胶]]转化为一种力学稳健且光稳定的荧光[[水凝胶]]（[[EuCPH]]）。所得红色发光 EuCPH 能够同时实现[[左氧氟沙星]]（[[LEV]]）捕获与[[荧光传感]]。[[EuCPH-4]] 表现出 1388.6 mg ${ \mathbf g } ^ { - 1 }$ 的超高 [[Langmuir吸附等温线|Langmuir]] 容量和 0.12 μg $\mathrm { L } ^ { - 1 }$ 的低[[检出限]]（LOD）。[[吸附]]过程符合 [[Langmuir 等温线]]和[[准二级动力学]]，表明以[[化学吸附]]为主导的摄取机制。EuCPH-4 在五次循环后仍保留 83.8% 的容量，Eu 浸出可忽略不计（<8 ppb），并在十次[[固定床]]再生循环中保持稳定性能。凭借低成本的橙皮来源果胶和木材来源 [[CNF]]，EuCPH 的生产成本约为 0.02 元 $\mathbf { g } ^ { \perp } { } _ { ; }$，为[[抗生素]]监测与修复提供了一种可规模化且经济可行的水凝胶平台。

## 1. 引言

药物残留如今在水生环境中被广泛检出，其中[[氟喹诺酮类抗生素]]如[[左氧氟沙星]]（[[LEV]]）因其固有的[[生态毒性]]以及对[[耐药性]]形成的贡献而引发特别关注（Zhao et al., 2022）。在现有处理技术（[[光催化]]、[[生物降解]]、[[高级氧化]]等）中，[[吸附]]仍是最实用的选择之一，原因在于其成本低、操作简单且二次污染有限。然而，许多传统吸附剂仍面临吸附容量一般和生产成本相对较高的问题（Liu et al., 2023）。因此，迫切需要兼具高 LEV 摄取量、良好可加工性和经济可行性的新型吸附体系。

具有[[三维交联网络|三维（3D）交联网络]]的[[多糖基水凝胶]]因其亲水主链可提供丰富的官能团以及对多种污染物的强亲和力，在水处理领域引起了越来越多的关注。然而，要将这些材料转化为实用[[吸附]]剂，往往需要同时实现高位点可及性和足够的力学完整性，尤其是在重复间歇操作和[[固定床]]操作中。在这一背景下，[[橙皮]]——作为农工业副产品大量产生且通常被丢弃——提供了一种具有吸引力但仍未得到充分利用的原料。[[橙皮果胶]]（[[果胶|OPP]]）富含[[羟基]]和[[羧基]]，是一种低成本碳水化合物前体，能够容易地形成[[水凝胶]]网络，同时为进一步功能化提供多用途平台（Gao et al., 2024）。[[纤维素纳米原纤]]（[[CNF]]）具有高结晶度、本征亲水性和生物相容性，也已被广泛用作与多糖基质良好结合的纳米增强构建单元（Dorishetty et al., 2020）。因此，将OPP与[[纤维素纳米纤丝|CNF]]共组装提供了一条构建“刚性纤维/柔性链”互穿结构的合理路线，其中[[逾渗]]的[[纤维素纳米纤维|CNF]]骨架增强力学稳健性，而富含果胶的相则保留可及的键合功能。这种结构互补性对[[抗生素]]吸附（例如[[左氧氟沙星]]）尤为有利，因为必须在不牺牲循环使用和柱操作所需力学稳定性的前提下，保留高密度极性位点。

污染物去除与现场监测的持续分离限制了及时反馈控制，从而阻碍了更智能水处理工艺的发展。这一瓶颈推动了对多功能[[吸附]]剂的设计需求，以在单一集成平台中耦合高效污染物捕集与实时信号读出。[[金属有机框架]]（MOFs），尤其是[[铕基金属有机框架|铕基MOF]]（[[Eu-MOF]]），为这种集成提供了有吸引力的基础。其结晶多孔结构提供了高可及表面积和明确的传输路径，可促进快速传质和吸附。同时，$\mathrm { E u } ^ { 3 + }$中心通常表现出尖锐的红色发射、高色纯度以及对配位微环境变化的强敏感性，从而能够实现低至超痕量水平的荧光检测。这些互补特征使Eu-MOF成为[[吸附-传感]]耦合水净化的有吸引力构建单元（Ji et al., 2024）。然而，Eu-MOF在水性体系中的实际应用仍面临挑战，因为纳米尺寸晶体容易团聚，框架可能力学脆弱，并且在长期运行过程中可能发生$\mathrm { E u } ^ { 3 + }$浸出。将Eu-MOF固定到稳健的亲水支架上，为克服这些限制提供了一条可行途径。特别是，[[CNF]]提供了具有丰富表面官能团的[[逾渗]]纤维网络，能够抑制颗粒团聚、增强结构完整性，并改善与[[水凝胶]]基质的界面相容性（Kang et al., 2025）。因此，这种[[纤维素纳米原纤|CNF]]辅助锚定有望在保持Eu-MOF发光性能和可持续性的同时，提高其稳定性和可重复使用性，为集成吸附-传感水凝胶平台铺平道路。

综上所述，[[果胶|OPP]]、[[CNF]] 和 [[Eu-MOF]] 各自为构建一体化[[吸附-传感]]平台提供了不同但互补的优势。然而，将这些组分理性整合为一种统一材料，同时保持[[吸附]]位点可及性、发光稳定性和操作稳健性，仍未被充分探索。在此，我们假设将 [[橙皮果胶|OPP]] 与 [[纤维素纳米原纤|CNF]] 共组装为“刚性纤维/柔性链”网络，并将 [[铕基金属有机框架|Eu-MOF]] 固定在 [[纤维素纳米纤丝|CNF]] 骨架上，能够协同解决这些挑战，并形成一种用于 [[LEV]] 去除与传感的多功能[[水凝胶]]（[[EuCPH]]）。为验证这一假设，系统评估了 EuCPH 的[[吸附等温线]]和动力学、荧光响应与检测限，以及在批式和[[固定床]]操作下的机械强度和重复使用性，并基于生物质衍生原料进行了初步成本评估。总体而言，本工作旨在建立一种可持续且经济可行的多糖水凝胶平台，将[[抗生素]]修复与实时监测相结合。

## 2. 材料与方法

## 2.1. 材料

[[丙烯酸]]（AA，99%）和[[过硫酸钾]]（PPS，≥99%）购自[[上海阿拉丁生化科技股份有限公司]]。[[N,N′-亚甲基双丙烯酰胺|N，N′-亚甲基双丙烯酰胺]]（MBA，99.5%）购自合肥巴斯夫生物技术$\mathrm { C o . }$有限公司。[[诺氟沙星]]（NOR，≥98%）和[[金霉素]]（CTC）由[[天津希恩思生化科技有限公司]]提供。[[左氧氟沙星]]（[[LEV]]，98%）购自上海迈瑞尔化学技术$\mathrm { C o . , }$有限公司。[[四环素]]（TC）、[[磺胺嘧啶]]（SD，≥98%）、[[土霉素]]$\mathrm { ( O T C , ~ } \geq 9 8 \% )$、[[氯霉素]]（CAP，≥98%）、[[氧氟沙星]]（OFX，98%）和[[环丙沙星]]（CIP，≥98%）购自上海麦克林生化科技$\mathrm { C o . }$有限公司。[[米诺环素]]（MINO）、[[多西环素]]（DOX，98%）和 [[1,10-菲啰啉]]（98%）由江苏艾康生物医药研发$\mathrm { C o . }$有限公司提供，金霉素购自上海伊恩化学技术$\mathrm { C o . , }$有限公司。$\mathrm { \bar { \ t u } ( N O _ { 3 } ) _ { 3 } } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$（98%）购自[[上海阿达玛斯试剂有限公司]]，[[2,5-二溴对苯二甲酸]]（98%）购自上海德博生物技术$\mathrm { C o . }$有限公司。除非另有说明，所有试剂均为分析纯并直接使用。

## 2.2. [[CNF]] 的制备

将漂白木浆（10.0 g）分散于[[去离子水]]（500 mL）中，搅拌 1 h 以获得均匀浆料。将 [[TEMPO]]（1.0 mmol）和 [[NaBr]]（10 mmol）溶于去离子水（150 mL）后加入，随后在持续搅拌下逐滴加入 [[NaClO]] 溶液（50 mL）。氧化在室温下进行，并用 0.5 M NaOH 维持 [[PH|pH]] 10.0。当 NaOH 消耗停止时，加入乙醇（10 mL）终止反应。随后将氧化浆料通过[[高压均质机]]处理三次，得到半透明 [[CNF]] 悬浮液。

## 2.3. [[果胶|OPP]] 的提取

新鲜[[橙皮]]用[[去离子水]]充分冲洗，切成约 2 cm × 2 cm 的小块，并在$1 0 5 ~ ^ { \circ } \mathrm { C }$下烘至恒重。干燥后的橙皮经粉碎并过 100 目筛。[[果胶]]提取时，将橙皮粉（1.5 g）分散于去离子水（100 mL）中，在 80 ℃ 下持续搅拌加热 120 min。热混合物冷却至室温后，收集上清液并密封保存，供后续分析使用。

所制备的 [[果胶|OPP]] 的[[加标回收率|回收率]]为 21.0%，处于[[橙皮果胶]]报道的典型范围内。果胶纯度通过[[半乳糖醛酸]]（GalA）含量估算，基于 GalA 的值为 66.4%。为进一步明确碳水化合物组成，采用[[高效离子色谱]]（HPIC）对水解单糖进行了分析，结果汇总于表 S1。HPIC 鉴定出[[岩藻糖]]（Fuc）、[[鼠李糖]]（Rha）、[[阿拉伯糖]]（Ara）、[[氨基葡萄糖]]（GlcN）、[[半乳糖]]（Gal）、[[葡萄糖]]（Glc）、[[木糖]]（Xyl）、[[甘露糖]]（Man）和 GalA。除果胶糖（GalA、Rha、Ara 和 Gal）外，Glc、Xyl 和 Man 的检出表明存在少量非果胶碳水化合物残基，可能来源于共提取的[[半纤维素]]相关组分。DE 为 65.0%，将 OPP 归类为[[高甲氧基果胶]]。

[[果胶|OPP]] 的分子量通过[[凝胶渗透色谱]]（GPC）测定。果胶的[[重均分子量]] $( \mathbf { M } _ { \mathrm { w } } )$ 为 956,681 g/mol，[[数均分子量]] $\left( \mathbf { M } _ { \mathrm { n } } \right)$ 为 470,648 g/mol，[[多分散指数]]（PDI，${ \bf { M } } _ { \mathrm { { w } } } / { \bf { M } } _ { \mathrm { { n } } } )$）为 2.0330。

## 2.4. [[Eu-MOF]] 的[[水热合成]]

[[Eu-MOF]] 采用[[水热合成|水热法]]制备（Liu et al., 2025）。简言之，将 $\mathrm { E u } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$（44.6 mg）、1,10-菲咯啉（19.8 mg）和 [[2,5-二溴对苯二甲酸]]（32.4 mg）溶解于[[去离子水]]（8 mL）中，超声处理 15 min，然后转移至带聚四氟乙烯内衬的不锈钢高压釜中。混合物在 110 °C 下加热 72 h。自然冷却至室温后，收集固体，用去离子水和乙醇洗涤三次，烘干得到 [[铕基金属有机框架|Eu-MOF]] 粉末。

## 2.5. [[Eu-MOF@CNF]] 的[[氢键组装]]

将 [[Eu-MOF]] 粉末（0.01–0.15 g）分散于 [[CNF]] 悬浮液中，在避光条件下以 200 rpm 搅拌 24 h，以促进 [[铕基金属有机框架|Eu-MOF]] 与 [[纤维素纳米原纤|CNF]] 之间的[[氢键组装|氢键辅助自组装]]。所得 [[Eu-MOF@CNF]] 悬浮液的固含量为 2.0 wt%。随着 Eu-MOF 负载量增加，复合物记为 Eu-MOF@[[纤维素纳米纤丝|CNF]]-x（x = 1–8）。

## 2.6. [[EuCPH]] 的制备

[[水凝胶]]配方采用 $\mathrm { L } _ { 9 } ( 3 ^ { 4 } )$ [[正交设计]]筛选，以 [[果胶|OPP]]、[[丙烯酸]]（AA）、[[Eu-MOF@CNF]] 和 [[N,N′-亚甲基双丙烯酰胺|MBA]] 为因素（各三水平；表 S2），性能标准汇总于表 S3。最优配方包含 [[橙皮果胶|OPP]]（2.0 g）、AA（2.0 g）、[[Eu-MOF]]@[[CNF]]-x（2.5 g）、NaOH（3.0 g，5 M）、MBA（0.05 g）和 [[过硫酸钾|PPS]]（0.05 g）。所有组分超声分散 30 min 以获得均匀前驱体，转移至密封玻璃管（10 mm × 75 mm）中，在 $7 0 ^ { \circ } \mathrm { C }$ 下通过自由基聚合反应 1 h 制得水凝胶。由不同 [[铕基金属有机框架|Eu-MOF]]@[[纤维素纳米原纤|CNF]]-x 前驱体制备的样品命名为 [[EuCPH]]-x（x = 1–8）。在相同条件下制备了不含 Eu-MOF 的对照水凝胶（[[CPH]]）以及同时不含 Eu-MOF 和 [[纤维素纳米纤丝|CNF]] 的对照水凝胶（[[PH]]）。

## 2.7. 批量[[吸附]]实验

除非另有说明，[[LEV]] 的批量[[吸附]]在基线条件下进行：初始 [[左氧氟沙星|LEV]] 浓度 40 mg $\mathbf { L } ^ { - 1 }$，[[水凝胶]]用量 0.03 g，溶液体积 100 mL，$\mathrm { p H } 6 . 0 , 2 5 ^ { \circ } \mathrm { C } , 1 5 0$ rpm，接触时间 4 h。系统考察了 [[PH|pH]]（2–10）、温度 $( 1 5 - 5 5 ~ ^ { \circ } \mathrm { C } )$、初始 LEV 浓度（20–1000 mg $\mathrm { L } ^ { - 1 } )$）、接触时间（30–240 min）、水凝胶用量（0.03–0.15 g）和离子强度（[[氯化钠|NaCl]] 5–20 mmol $\mathrm { L } ^ { - 1 } )$）的影响。

## 2.8. 再生与重复使用性测试

[[水凝胶]]的可重复使用性通过[[吸附-脱附循环]]进行评价。在每次循环中，将0.03 g水凝胶加入250 mL锥形瓶中的100 mL [[LEV]]溶液$( 4 0 \mathrm { m g L } ^ { - 1 } )$中，以150 rpm振荡4 h。随后，将负载[[左氧氟沙星|LEV]]的水凝胶在0.01 M HCl（100 mL）中以150 rpm再生4 h，然后用[[去离子水]]洗涤三次。再生后的水凝胶在相同条件下用于后续循环，共进行最多五个循环。

## 2.9. [[固定床]][[吸附]]实验

[[固定床]]测试在垂直玻璃柱（内径3 cm，长度10 cm）中进行，采用上流模式，在${ } ^ { 2 5 } \ ^ { \circ } \mathrm { C }$下运行，并配备[[蠕动泵]]（图S1）。[[吸附]]剂填充至床层高度5 cm，两端各放置1 cm棉花层以确保流态均匀并防止细颗粒流失。[[LEV]]溶液$( 4 0 \mathrm { m g L } ^ { - 1 } )$以5 mL min<sup>−</sup> <sup>1</sup>的流速向上进料，定期收集流出液样品并通过[[紫外-可见分光光度法]]分析。当入口和出口浓度趋于一致时，判定达到穿透。再生时，以相同流速和温度使0.01 M HCl通过色谱柱，随后用[[去离子水]]冲洗，直至流出液[[PH|pH]]稳定在7。在多次吸附-再生循环中记录穿透曲线。

## 2.10. 表征

冷冻干燥[[水凝胶]]的表面和低温断裂截面通过[[场发射扫描电子显微镜|场发射SEM]]（JSM-6330F，JEOL，日本）在$2 5 ~ ^ { \circ } \mathrm { C } .$下观察。样品在液氮中冷冻，冷冻干燥（ZLGJ-18，华辰生物技术，中国；48 h，<10 Pa），并在成像前溅射镀覆约10 nm Au。[[透射电子显微镜|TEM]]（JEM-2100Plus，JEOL，日本）通过将稀分散液滴铸到碳涂层铜网上进行；静置30 s后，用[[去离子水]]冲洗铜网，并用0.5%（w/v）乙酸铀酰负染。[[X射线衍射|粉末XRD]]图谱在环境条件下$( 2 5 ~ ^ { \circ } \mathrm { C } )$于Ultima IV衍射仪（Rigaku，日本）上采集，使用Cu Kα辐射$( \lambda = 1 . 5 4 0 6 \mathring { \mathrm { A } } ,$ 40 kV，40 mA，$2 \Theta = 1 0 ^ { - 8 0 ^ { \circ } } )$。[[傅里叶变换红外光谱|FTIR光谱]]在室温下$( 2 5 ~ ^ { \circ } \mathrm { C } )$于Cary 600光谱仪（Agilent，美国）上记录，范围为$4 0 0 0 { \mathrm { - } } 4 0 0 \ { \mathrm { ~ c m } } ^ { - 1 }$。[[Zeta电位]]使用ZEN 3600 Zetasizer（Malvern，英国）测定。[[XPS|X射线光电子能谱]]（[[X射线光电子能谱|XPS]]）在室温下$( 2 5 ^ { \circ } \mathrm { C } )$于Thermo Scientific K-Alpha仪器上进行，光谱使用Avantage 5.99处理，以C 1 s $= 2 8 4 . 8 \ \mathrm { e V }$为参考。[[荧光光谱]]在室温下$( 2 5 ^ { \circ } \mathrm { C } )$于F-7000荧光分光光度计（Hitachi，日本）上采集。拉伸性能在Instron 5969[[万能试验机]]上于${ } ^ { 2 5 } \ ^ { \circ } \mathrm { C }$和70% RH下使用100 N力传感器测定；矩形试样（40 mm × 15 mm × 2 mm）以$5 \mathrm { { m m } \mathrm { { m i n } ^ { - 1 } } }$拉伸至断裂。

## 3. 结果与讨论

## 3.1. 概念设计与合成路线

图1示意性地描绘了EuCPH的设计理念与合成路线。首先以Eu $\mathrm { ( N O _ { 3 } ) _ { 3 } { \cdot } 6 H _ { 2 } O _ { 3 } }$、1,10-菲啰啉和2,5-二溴对苯二甲酸为原料水热合成Eu-MOF，得到高度结晶的颗粒，并因特征性$\mathrm { E u } ^ { 3 + }$ f–f跃迁而呈现强烈红色发射。同时，以漂白木浆制备的TEMPO氧化CNF被用作刚性、高长径比的骨架，以增强水凝胶框架。随后，通过表面–COOH/–OH基团与MOF配体之间密集的界面氢键相互作用，将Eu-MOF固定在CNF上，形成均匀分散的Eu-MOF@CNF，从而缓解原始MOF常见的团聚和结构脆弱问题。与此同时，OPP通过热水解从脱水橙皮中提取，提供了富含羧基和羟基的柔性多糖链，既可作为网络形成链段，也可作为高亲和吸附位点。最后，在MBA辅助下进行原位交联，将OPP与Eu-MOF@CNF框架整合，构建出三维多孔EuCPH结构。

## 3.2. 结构与物理化学表征

[[SEM]]成像追踪了[[EuCPH-4]]在整个制备过程中的微观结构演变。[[CNF]]由表面光滑、均匀的棒状纳米纤丝组成（图2a）。[[透射电子显微镜|TEM]]（图S2）进一步证实其尺寸分布较窄（长度约为95.0 nm，直径约为5.5 nm；长径比$\approx 1 7 . 3 )$），并具有典型的纤丝形态。按照[[TAPPI标准]]进行的组成分析表明，[[纤维素纳米原纤|CNF]]主要为[[纤维素]]（86.0%），并含少量[[半纤维素]]（3.9%）和[[木质素]]（0.8%）。[[电导滴定]]测得[[羧基]]含量为1.27 mmol ${ \mathbf g } ^ { - 1 }$，而高度负的[[ζ电位]]（−57.9 mV）表明其具有强静电排斥作用和良好的胶体稳定性。[[水热合成]]的[[Eu-MOF]]形成了晶面清晰的块状微晶，平均尺寸约为110 nm（图2b和S3），这是镧系MOF的典型特征（Liu et al., 2025）。将[[铕基金属有机框架|Eu-MOF]]固定到[[纤维素纳米纤丝|CNF]]上后，所得[[Eu-MOF@CNF]]显示出明显粗糙化的纤丝表面（图2c）。[[XPS]]全谱（图S4）进一步证实了Eu-MOF的成功引入。对于[[水凝胶|EuCPH-4]]，[[场发射扫描电子显微镜|SEM]]显示出相互连通、分级多孔的网络结构（图2d），而[[EDS面分布]]（图S5）显示$\mathrm { C } , 0 , \mathrm { N } $和Eu的均匀分布，证明其具有良好的微尺度整合性。与此一致，[[N₂吸附–脱附|N₂吸附–脱附测试]]（图S6）给出的[[BET|比表面积]]为$\bar { 3 7 } . 2 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$，[[平均孔径]]为7.65 nm，表明其具有有利于传质和[[吸附]]的[[介孔结构]]（Mani & Bhandari, 2022）。

## 3.3. 机械性能

[[EuCPH-4]] 的力学稳健性首先在大应变变形下进行了考察（图 3a）。[[水凝胶|EuCPH-4]] 条带在纯拉伸、纯扭转以及拉伸–扭转联合作用下均未出现可见裂纹，并可被拉伸至初始长度的约 1.5 倍，展现出高柔性和可靠的形状恢复能力（Wang, Qin, et al., 2023a）。这些宏观观察结果与单轴拉伸试验结果一致（图 3b–d）。[[EuCPH]]-4 的[[拉伸强度]]为 461.79 kPa，相较于 [[CPH]]（338.42 kPa）和 [[PH]]（276.92 kPa）分别提高了 36.5% 和 66.8%。此外，EuCPH-4 表现出最高的刚度和能量耗散能力，其[[杨氏模量]]为 371.09 kPa，[[韧性]]为 409.26 kJ m<sup>−</sup> <sup>3</sup>，而 CPH 为 329.69 kPa 和 $2 7 2 . 1 5 \mathrm { k J } \mathrm { m } ^ { - \overline { { 3 } } }$，PH 为 271.80 kPa 和 190.64 kJ m<sup>−</sup> <sup>3</sup>。

[[力学性能]]的增强源于 [[EuCPH-4]] 的多尺度结构。仅由 [[果胶|OPP]] 和[[聚丙烯酸]]构建的 [[PH]] 网络缺乏增强性纤维骨架，导致其承载和耗散能力有限。[[CNF]] 的引入（[[CPH]]）形成了[[逾渗]]纳米纤维支架，能够重新分布应力并限制聚合物链的运动，从而提高刚度和[[韧性]]。值得注意的是，在凝胶化之前将 [[Eu-MOF]] 锚定在 [[纤维素纳米原纤|CNF]] 上进一步增强了该纳米纤维骨架，强化了网络内的界面相互作用，使 [[水凝胶|EuCPH-4]] 的强度和韧性得以同时提升。

## 3.4. 对 [[LEV]] 的[[吸附]]性能

## 3.4.1. 关键[[吸附]]参数的优化

采用[[响应面法]]（RSM），以溶液 [[PH|pH]]、温度（T）和 [[LEV]] 初始浓度（C<sub>0</sub>）为自变量，优化 [[EuCPH-4]] 对 [[左氧氟沙星|LEV]] 的[[吸附]]量（表 S4）。17 次试验设计（表 S5）得到了一个优良的二次模型 $( \mathrm { R } ^ { 2 } = 0 . 9 6 5 3$ ；表 S6 中的[[方差分析]]），且预测响应值与实验值吻合良好（图 S13）。三维响应面（图 4a–c）进一步表明，主因素及其两两交互作用对吸附行为均有显著贡献（Hammoudi et al., 2019）。

温度对 [[LEV]] [[吸附]]量具有正向影响，从 15 到 55 ◦C 吸附量持续增加（图 4d），表明该吸附过程为吸热过程。与之相一致的是，van‘t Hoff 分析得到正的焓变 $( \Delta \mathrm { H } = 7 . 0 6 \ \mathrm { k J \ m o l ^ { - 1 } } )$ 和正的熵变 $( \Delta S > 0 ) _ { : }$ ，而[[吉布斯自由能]]变化在研究范围内始终为负（ΔG < 0），证实该吸附过程是自发的且由熵驱动 [18]。

[[吸附]]量同样表现出对[[PH|pH]]的钟形依赖关系，最佳pH为6（图4e）。[[EuCPH-4]] $\mathrm { ( p H _ { Z P C } ) }$ 的[[零电荷点]]为3.3（图S14）。当pH < pH 时，带正电的水凝胶表面会静电排斥阳离子型LEV，从而降低吸附量；反之，当pH > 8.15时，[[水凝胶|EuCPH-4]]和[[LEV]]均以负电荷为主，同样导致排斥。在pH $^ { 6 , }$ 附近，[[EuCPH]]-4表面带净负电荷，而[[左氧氟沙星|LEV]]主要以两性离子/部分阳离子形式存在，有利于[[静电吸引]]并使吸附达到最大（Kaur等，2022）。因此，后续实验选择pH 6。

还考察了[[吸附]]剂用量的影响。将[[EuCPH-4]]用量从0.03 g增加到0.15 g会降低平衡吸附容量（Qₑ）（图S15），这是因为溶液中[[LEV]]总量固定，而过量吸附剂引入了未占据位点（Hou等，2024）。因此，在指定条件下使用0.03 g [[水凝胶|EuCPH-4]]以确保有效利用可结合位点。

在$\mathrm { C } _ { 0 } = 2 0 { - } 1 0 0 0 \ \mathrm { m g } \mathrm { L } ^ { - 1 } \left( \mathrm { F i g . } \ 4 \mathrm { f } \right)$范围内测定的[[吸附等温线]]表现出预期的[[吸附]]量增加，随后在饱和时达到平台。[[CNF]]和[[Eu-MOF]]均发挥了积极作用：[[纤维素纳米原纤|CNF]]提供了致密的多孔骨架，促进网络内扩散，而[[铕基金属有机框架|Eu-MOF]]提供了额外的[[LEV]]吸附位点。在所评价的模型中，[[Langmuir模型]]拟合最佳$( \mathbf { R } ^ { 2 } = \mathbf { \Omega }$ 0.9515），优于[[Freundlich模型|Freundlich]] $( \mathrm { R } ^ { 2 } = 0 . 8 9 4 2 )$ 、[[Temkin模型|Temkin]] $( \mathrm { R } ^ { 2 } = $ 0.9009；图S16）和[[Dubinin–Radushkevich模型|Dubinin–Radushkevich]] $( \mathrm { R } ^ { 2 } = 0 . 8 9 4 1 ;$ 图S17）模型，表明吸附主要发生在相对均匀的位点上，以单层吸附为主（Zhang等，2025）。[[Langmuir吸附等温线|Langmuir]]理论最大容量$\left( \mathrm { Q } _ { \mathrm { m } } \right)$达到1388.6 mg g<sup>−</sup> <sup>1</sup>，与大多数已报道的[[左氧氟沙星|LEV]]吸附剂相当或更高（表1），并接近实验测得容量（1332.3 mg $g ^ { - 1 } ) .$

## 3.4.2. 可重复使用性与结构稳定性

通过五次连续[[吸附]]-解吸循环评估了 [[EuCPH-4]] 的可重复使用性（Fig. 5a）。第五次循环后，[[水凝胶|EuCPH-4]] 保持了其初始 [[LEV]] 吸附效率的 $8 3 . 8 \pm 2 . 2 \%$ ，表明其在循环操作下具有良好的可重复使用性。同时，[[电感耦合等离子体发射光谱|ICP-OES]] 测量显示所有收集的出水中 Eu 浓度均低于 8 ppb，表明 [[Eu-MOF]] 在水凝胶基质中得到了有效固定，并且二次金属释放的风险可忽略不计（Chen, Lian, et al., 2024a）。

循环后 [[EuCPH-4]] 的结构完整性通过使用后表征进一步验证。[[FTIR]] 光谱（Fig. 5b）显示谱带位置和强度基本未发生变化，表明未检测到明显的化学降解或配体损失。同样，[[XRD]] 图谱（Fig. 5c）保留了原有的衍射特征，未出现明显的峰位移或展宽，证实结晶 [[Eu-MOF]] 结构域保持完整。与此一致，[[SEM]] 观察（Fig. S20）显示，反复使用后分级多孔结构保持良好，未出现明显的孔道坍塌（Su et al., 2024）。

## 3.4.3. 离子强度的影响

## 3.4.4. [[固定床]]动态[[吸附]]

进一步在[[固定床|固定床柱]] $( \mathrm { C _ { \mathrm { i n } } } = 4 0 \mathrm { m g } \mathrm { L } ^ { - 1 } ; 5 \mathrm { m L } \mathrm { m i n } ^ { - 1 } )$ 中考察了 [[EuCPH-4]] 对 [[LEV]] 的动态去除性能，床层高度为 3–5 cm。增加床层高度延迟了穿透（Fig. S22a），这与更多活性位点和更长接触时间相一致。在固定床高为 5 cm 时，将流速从 5 提高到 10 mL $\operatorname* { m i n } ^ { - 1 }$ 同时提前了穿透和耗竭（Fig. S22b），这是由于停留时间缩短以及内部位点利用效率降低。同样，将 $\mathrm { C } _ { \mathrm { i n } }$ 从 40 提高到 60 mg $\mathrm { L } ^ { - 1 }$ （5 cm；5 mL min<sup>−</sup> <sup>1</sup>）加速了穿透和饱和（Fig. S22c），反映了在较高负载下位点占据更快（Deng et al., 2024）。

## 3.6. 机理阐明

## 3.6.1. 控制[[吸附]]的分子相互作用

[[LEV]]与[[EuCPH-4]]之间的结合相互作用通过[[FTIR]]和[[XPS]]进行了研究。在[[傅里叶变换红外光谱|FTIR光谱]]中（图7a），宽O–H伸缩带$( \sim 3 4 4 0 ~ \mathrm { c m } ^ { - 1 } )$在[[吸附]]后明显减弱，表明[[左氧氟沙星|LEV]]与[[水凝胶]]富含[[羟基]]区域之间形成了广泛的[[氢键]]。同时，$\scriptstyle \mathrm { C = } 0$伸缩带$( \sim 1 7 1 4 ~ \mathrm { c m } ^ { - 1 } )$强度的降低表明[[羧基]]参与了LEV的结合（Mpelane et al., 2022）。

[[XPS]]分析进一步证实了这些相互作用。全谱（图7b）确认了$\mathrm { C } , \mathrm { N } , { \mathrm { O } } ,$和Eu的存在，[[吸附]]后N信号增强与[[LEV]]的摄取一致，如图7c所示。在[[C 1s]]区域（图7d），$\scriptstyle \mathrm { C - O / C = 0 }$组分的轻微下移表明[[喹诺酮|喹诺酮环]]与[[EuCPH-4]]中共轭结构域之间的[[π–π堆叠|π–π相互作用]]引起了电子扰动。在[[O 1s]]光谱$\left( \mathrm { F i g . 7 e } \right)$中，C–O和C––O组分均略微向较低结合能移动（535.57 → 535.40 eV；531.43 → 531.39 eV），与[[氢键]]作用一致。此外，[[N 1s]]区域（图7f）显示–CONH/$\mathrm { - N H _ { 2 } }$物种的结合能降低，支持带负电的[[水凝胶|EuCPH-4]]与质子化[[左氧氟沙星|LEV]]之间的[[静电吸引]]。综上，这些结果表明LEV在[[EuCPH]]-4上的吸附由协同氢键、[[静电相互作用]]和π–π堆叠共同主导。

## 3.6.2. [[荧光猝灭|荧光猝灭机制]]

[[紫外-可见光谱|UV–vis光谱]]显示[[LEV]]吸收带与[[EuCPH-4]]的激发谱之间存在显著重叠（图8a），表明存在明显的[[内滤效应]]（IFE）（Rahman et al., 2023）。与此一致的是，加入[[左氧氟沙星|LEV]]后[[水凝胶|EuCPH-4]]激发窗口内的有效吸光度增加（图8b），表明激发光被部分衰减，到达$\mathrm { E u } ^ { 3 + }$中心的光子通量降低，从而降低了发射强度（图8c）。[[时间分辨光致发光]]提供了进一步的机理支持：寿命仅从10.82 ns略微变化至10.50 ns（图8d、e），排除了动态猝灭占主导的可能性（Chen, Tang, et al., 2024b）。综合来看，光谱重叠和近恒定的寿命表明LEV诱导的猝灭主要由IFE控制。

## 3.6.3. [[吸附]]-检测耦合机制

图9总结了EuCPH中吸附-检测耦合机制。在EuCPH中，OPP提供了丰富的羧基和羟基官能团，作为LEV结合的氢键/配位位点。CNF提供了机械增强骨架，维持了互连的多孔网络，促进传质，并实现Eu-MOF纳米结构域的均匀固定。因此，LEV的摄取由协同氢键、静电吸引和π–π相互作用驱动。同时，Eu-MOF在紫外激发下提供稳定的红色发射，且由于LEV吸收与EuCPH激发窗口之间的强重叠，LEV结合主要诱导IFE猝灭，在超低浓度水平产生浓度依赖性的荧光下降。总体而言，这些特性使EuCPH成为在复杂水相基质中同时进行LEV吸附和原位监测的双功能平台。

## 4. 结论

我们开发了一种源自 [[果胶|OPP]] 的双功能[[水凝胶]]（[[EuCPH]]），用于同时[[吸附]]和检测 [[LEV]]。EuCPH 通过协同[[氢键]]、[[静电吸引]]和 π–π 相互作用捕获 [[左氧氟沙星|LEV]]，实现了 $1 3 8 8 . 6 ~ \mathrm { m g ~ g ^ { - 1 } } .$ 的 [[Langmuir吸附等温线|Langmuir]] 最大容量。[[响应面分析]]进一步证实，[[PH|pH]]、温度和初始浓度显著影响吸附性能。EuCPH 还表现出良好的操作耐久性，在[[吸附-脱附循环|五次吸附-脱附循环]]后仍保留初始容量的 83.8%，并显示出可由 [[Thomas模型|Thomas]] 模型良好描述的[[固定床]]行为。重要的是，[[Eu-MOF]] 在 [[CNF]] 骨架上通过氢键辅助固定保持了稳健的红色发射，并实现了对 LEV 的选择性[[荧光传感]]，具有宽工作范围和 $0 . 1 2 ~ \mu \sigma ~ \mathrm { L } ^ { - 1 }$ 的超低检测限。总体而言，EuCPH 展示了一种可持续的“[[吸附-传感]]”平台，用于同时去除和现场监测水体中的[[抗生素]]污染物。
