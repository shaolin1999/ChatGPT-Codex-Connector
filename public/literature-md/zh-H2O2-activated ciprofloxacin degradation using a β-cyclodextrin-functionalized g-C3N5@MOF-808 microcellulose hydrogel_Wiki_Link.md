## 摘 要

本研究通过简便的[[环氧氯丙烷]]辅助[[交联]]方法合成了三维[[β-环糊精]]@[[石墨相氮化碳|g-C N]] @[[MOF-808]][[微晶纤维素水凝胶|微纤维素水凝胶]]（[[GCMH]]），并将其用于通过[[过氧化氢|H O]] 驱动的氧化降解去除水介质中的[[环丙沙星]]（CIP）。在无可见光条件下，${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$与[[金属有机框架|MOF]]-808在[[纤维素]]基质中的协同整合显著增强了[[活性氧物种]]的生成，包括<sup>•</sup>OH和O<sub>2</sub><sup>•-</sup>。利用[[XRD]]、[[FT-IR]]、[[XPS]]、[[SEM]]和[[孔隙率分析]]进行的综合表征证实了β-CD和g-C N 稳定地结合到MOF框架中，从而形成了高度可及的孔隙网络，为催化反应提供了大量活性界面。使用[[Ossila接触角分析仪]]评估的[[表面润湿性]]表现出强[[亲水性]]$( \boldsymbol { \Theta } \approx 3 2 ^ { ^ { \circ } } ) ,$，这促进了快速的水相扩散并提高了污染物可及性。优化后的GCMH在60分钟内实现了超过95%的CIP降解率，并在五次重复使用循环后保持了90%以上的活性。淬灭和[[电子自旋共振|ESR]]分析表明，H O 活化通过自由基和非自由基共同介导的氧化途径进行。此外，基于[[XGBoost]]的[[机器学习]]建模显示出良好的预测性能$( R ^ { 2 } = 0 . 5 8 5 )$，支持了实验去除效率与预测去除效率之间的一致性。这些发现凸显了GCMH系统作为一种高效、可回收且环境友好的制药废水处理平台。

## 1. 引言

[[氟喹诺酮类抗生素]]，特别是[[环丙沙星]]（CIP）的广泛使用，因其在水生生态系统中的持久性和[[生物累积]]性，已成为一个重要的环境问题。CIP $\mathrm { ( C _ { 1 7 } H _ { 1 8 } F N _ { 3 } O _ { 3 } ) }$ 是一种以[[喹诺酮母核]]和[[哌嗪|哌嗪环]]为特征的第二代氟[[喹诺酮]]类药物，具有较强的抗菌活性，但化学稳定性高，导致其在常规污水处理系统中的生物降解性较低 [1]。约 50–90% 的给药 CIP 以未代谢形式排出，使其持续进入市政水体和[[地表水]] [2]。CIP 在污水处理厂、河流甚至饮用水中频繁检出，在制药排放点附近浓度范围为 0.03 至超过 150 μg/L [3,4]。其持久性促进了[[抗生素抗性细菌]]和[[抗生素抗性基因]]的产生，对生态系统和公共健康构成风险 [5]。此外，CIP 与多价阳离子形成强螯合物，并在较宽的 pH 范围内表现出两性行为，进一步增加了其去除难度 [6]。除直接毒性（如抑制藻类光合作用和微生物代谢）外，CIP 还会改变沉积物中营养物和金属的[[吸附]]与迁移，扰乱水生营养循环 [7]。因此，有效去除 CIP 及类似药物污染物已成为环境工程中的关键优先事项。

常规污水处理工艺通常难以高效去除极性和难降解药物 [8]。生物系统对[[氟喹诺酮类抗生素|氟喹诺酮类药物]]的去除尤其无效，因为这些抗生素会抑制细菌 [[DNA旋转酶|DNA 旋转酶]]，从而抑制负责降解的微生物群落 [9]。虽然[[吸附]]和[[混凝-絮凝|混凝–絮凝]]方法被广泛使用，但它们仅将污染物转移至固相，产生需要进一步处理的二次污泥 [10]。[[活性炭]]和[[沸石]]具有较高的初始吸附容量，但其效率会因饱和与再生难题而下降 [11]。基于膜的方法，如[[纳滤]]和[[反渗透]]，可实现较高的去除率，但受到[[膜污染]]和高能耗的制约 [11]。尽管化学氧化和氯化可降解大部分有机物质，但它们往往生成有害的[[氯化副产物]] [12]。这些局限性凸显了开发先进且可持续的处理技术以有效去除废水中 [[环丙沙星|CIP]] 的必要性 [13]。

[[高级氧化过程]]（AOPs）通过产生[[活性氧物种]]（ROS），特别是[[羟基自由基]]，代表了降解持久性有机污染物的一种有前景的解决方案$( ^ { \bullet } \mathrm { O H } , \mathrm { E } ^ { \circ } = 2 . 8 \mathrm { V } ) [ 1 4 ]$ 代表性的AOPs包括$\mathrm { U V / H _ { 2 } O _ { 2 } } , \mathrm { O _ { 3 } / H _ { 2 } O _ { 2 } } ,$、[[光芬顿]]和催化氧化体系，它们可将复杂药物矿化为$\mathrm { C O } _ { 2 }$和$_ \mathrm { H _ { 2 } O }$[15]。其中，基于$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$的氧化因其环境友好、成本效益高和操作简便而尤其具有吸引力。[[过氧化氢]]可分解为水和氧气而不形成二次污染物，使其成为环境修复中的绿色氧化剂[16]。然而，$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$在环境条件下的自发分解较慢，需要催化剂促进$\mathrm { \ o { - } { 0 } }$键的均裂和自由基形成[17]。传统的[[均相芬顿体系]]$\mathrm { ( F e ^ { 2 + } / H _ { 2 } O _ { 2 } ) }$仅限于酸性条件，并会产生大量铁泥[18]。因此，近年来的研究集中于能够在温和条件下活化$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$的非均相、不依赖光的催化体系[18,19]。金属氧化物、[[钙钛矿]]和[[金属有机框架]]（MOFs）等催化剂因其较大的[[BET|比表面积]]和可调的氧化还原性能而表现出高催化性能[20]。

在各种MOFs中，[[MOF-808|MOF-808(Zr)]]因其稳健的[[锆氧簇]]以及优异的水热和化学稳定性而受到越来越多的关注[21]。该框架由六连接的$\mathrm { Z r } _ { 6 } ( \mu _ { 3 ^ { - } }$ $\mathrm { O ) } _ { 4 } ( \mu _ { 3 } – \mathrm { O H } ) _ { 4 }$次级构建单元与[[苯-1,3,5-三甲酸]]（BTC）配体[[配位作用|配位]]而成，形成具有大笼（约18 Å）的[[介孔]]结构，可促进传质[22]。锆基MOFs已被证明可通过形成[[过氧-Zr中间体]]高效活化$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$，从而在无外部辐照条件下降解染料、酚类和抗生素等有机污染物[22]。此外，[[金属有机框架|MOF]]-808中的开放金属位点可与含氧或含氮分子产生强配位作用，增强对[[环丙沙星|CIP]]的选择性[[吸附]]和催化氧化[23]。

[[β-环糊精]]（β-CD）是一种由七个α-1,4-连接[[吡喃葡萄糖]]单元组成的环状低聚糖，形成具有疏水空腔和亲水外表面的环状结构。这种独特结构使$\beta \mathrm { - C D }$能够通过[[主客体相互作用]]包合疏水性有机分子，提高其在催化位点附近的局部浓度[24]。它已被广泛用于通过[[氢键]]和[[范德华力]]捕获芳香族药物，包括[[环丙沙星]]、[[萘普生]]和[[诺氟沙星]][25]。此外，β-CD在复合体系中还可用作功能改性剂。[[纤维素]]经β-CD功能化已被证明可改善抗生素去除效果和材料[[可重复使用性]][26]，而β-CD/[[环氧氯丙烷]]（ECH）[[水凝胶]]则表现出增强的机械强度和[[亲水性]][27]。β-CD丰富的羟基可促进其与纤维素或[[金属有机框架|MOF]]框架之间的共价键或氢键作用，有助于形成适用于传质和催化降解的互连多孔网络。

除[[β-环糊精|β-CD]]之外，[[石墨相氮化碳]] $( g \mathrm { - C _ { 3 } N _ { 5 } ) }$ 因其高氮含量、扩展的π共轭体系以及适中的[[带隙]]（约2.2 eV）而成为一种有前景的[[非金属催化剂]][28]。与 $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 4 } , \mathrm { g - } \mathrm { C } _ { 3 } \mathrm { N } _ { 5 }$ 相比，其含有额外的三唑衍生的富氮结构，可改善电子离域和氧化还原活性，促进[[电荷转移]]，并即使在温和条件下也能加速[[活性氧物种|ROS]]生成[29,30]。尽管最初是为可见光[[光催化]]而开发，但近期研究表明，g-${ \mathrm { . C _ { 3 } N _ { 5 } } }$ 中的[[氮空位|表面氮空位]]和[[末端胺基]]也可在无光条件下催化 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 的分解，生成 $\cdot _ { \mathrm { O H } }$ 和 $^ 1 0 _ { 2 }$ 物种[31]。此外，将g ${ \bf \cdot C } _ { 3 } \mathrm { N } _ { 5 }$ 与金属氧化物或[[金属有机框架|MOF]]偶联可形成异质结，从而增强界面电子传输和催化稳定性[32]。因此，$g _ { - }$ $\mathrm { C } _ { 3 } \mathrm { N } _ { 5 }$ 与[[MOF-808]]的组合可提供协同自由基生成作用，而β-CD则有助于将目标污染物预富集到反应位点附近。

[[微晶纤维素]]衍生[[水凝胶]]是环境友好的三维聚合物网络，富含羟基，能够与所掺入组分形成[[氢键]]和共价连接。其[[亲水性]]确保了良好的保水性和[[活性位点]]可及性，而[[交联]]可防止催化剂浸出[33]。[[环氧氯丙烷|ECH]]是一种广泛使用的良性交联剂，可增强水凝胶网络并在水环境中提高机械稳定性[29]。与易于团聚并造成二次浑浊的悬浮催化剂相比，这些水凝胶为污染物提供了高效扩散通道，并便于催化材料的回收[34]。[[纤维素水凝胶]]与催化纳米材料的整合进一步提高了其[[可重复使用性]]和降解性能[35]。[[纤维素]]上丰富的–OH基团支持[[金属有机框架|MOF]]和[[β-环糊精|β-CD]]的均匀固定，从而生成有利于[[吸附]]与氧化协同作用的多级孔结构。

尽管[[光催化]]和[[电化学处理]]技术不断进步，许多方法仍受限于对光的依赖和较高的能耗。因此，人们对在黑暗条件下通过多种功能材料协同作用而高效运行的 H<sub>2</sub>O<sub>2</sub> 驱动异相体系越来越感兴趣。本研究开发了一种新型复合催化剂，由嵌入[[微晶纤维素水凝胶]]中的 [[石墨相氮化碳|g-C N]]@[[β-环糊精|β-CD]]@[[金属有机框架|MOF]] 808 (Zr) 组成，用于在无外部光照条件下高效降解[[环丙沙星]]。在该结构中，β-CD 增强了分子识别能力和环丙沙星的局部富集， $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 促进电子转移和自由基形成，而 [[MOF-808]]（Zr）则活化 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 经由 $_ { \mathrm { Z r - O - O } }$ 过氧化物中间体。[[水凝胶]]骨架提供了一个透水性良好、机械稳定的三维基质，能够支持组分的均匀分布与催化剂的回收。[[吸附]]、活化与氧化的协同整合预期可在无需 外部辐照。本研究系统考察了：(i) 复合水凝胶的合成与结构表征；(ii) $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化及 CIP 降解的动力学与机理；(iii) 催化剂的[[可重复使用性]]与环境安全性。研究结果为理性设计面向新兴药物污染物的可持续、非光依赖型[[高级氧化]]体系提供了有价值的见解。

本工作假设，将[[β-环糊精|β-CD]]功能化的g-$\mathrm { C } _ { 3 } \mathrm { N } _ { 5 } @ \mathrm { M O F } { \cdot } 8 0 8$整合到[[微晶纤维素水凝胶]]中，可形成一种协同[[电子转移网络]]，能够激活$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$。预计这种杂化结构将通过加速${ \mathrm { g - C } } _ { 3 } { \mathrm { N } } _ { 5 } ,$、[[锆氧簇|Zr–oxo簇]]和[[纤维素]]羟基之间的[[电荷转移]]，促进[[活性氧物种]]的生成；借助β-CD[[主客体相互作用|主客体包合作用]]在催化位点附近富集[[环丙沙星]]分子；并稳定催化中心，抵抗结构降解和金属浸出。因此，我们预期[[吸附]]、预富集和催化活化之间的协同作用将实现高效且持久的药物降解效率。

复合物的热稳定性与组成特征通过 [[热重分析|TGA]] 和 [[微分热重分析|DTG]] 分析进行评估，如图 S1a–c 所示。对于 75GCD@25MOF 复合物（图 S1a），在 $1 5 0 ~ ^ { \circ } \mathrm { C }$ 以下的初始失重（约 10.2%）对应于[[吸附]]水分和残留溶剂的脱除。在 200 至 $4 5 0 \ ^ { \circ } \mathrm { C } ,$ 之间发生了 41.9% 的主要失重，这与 [[β-环糊精|β-CD]] 和 ${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 中有机配体的分解有关 [54]，随后在高达 $6 5 0 ^ { \circ } \mathrm { C }$ 的温度范围内又失重 32.2%，归因于 [[MOF-808]] 骨架的坍塌和残留有机物的部分碳化 [54]。剩余的约 15% 残渣归属于热稳定的[[氧化锆]] [40]。原始 [[MCH]]（图 S1b）表现出两步失重：（i）200 ◦C 以下失重 19.7%，归因于[[脱水]]挥发；（ii）在 250 至 $4 0 0 ^ { \circ } \mathrm { C }$ 之间失重 31.4%，与[[纤维素]]链断裂和[[解聚]]有关 [55]。在 $5 0 0 ^ { \circ } \mathrm { C } ,$ 之后观察到逐渐的质量损失，留下约 6% 的无机残渣。相比之下，[[GCMH-7]]（图 S1c）表现出更高的耐热性，在高达 $8 0 0 ^ { \circ } \mathrm { C } .$ 的温度范围内总失重约为 73.1%。第一次失重（13.6%）发生在 $1 5 0 ~ ^ { \circ } \mathrm { C } ,$ 以下，随后是纤维素和杂化组分在 200 至 500 ◦C 之间的逐步降解（分别为 26.6% 和 21.4%）。与 MCH 相比，较低的 DTG 峰强度和更高的残余质量（约 11.5%）表明，[[GCD@MOF]] 纳米颗粒的引入通过增强[[水凝胶]]网络并延缓分解而提高了热稳定性 [56]。这些结果表明，无机 Zr–O 簇和共轭 ${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 结构域的存在加强了界面结合，并提高了复合物的热耐久性。

[[水凝胶]]的孔结构和总体[[孔隙率]]使用[[压汞孔隙度法]]进行表征，如图 S2a–b 所示。原始 [[MCH]] 呈现出跨越[[介孔]]至[[大孔]]范围的宽[[孔径分布]]，表明其具有高度开放且相互连通的三维网络。相比之下，[[GCMH-7]] 表现出更窄的孔径分布，大孔峰减弱，反映出引入 [[GCD@MOF]] 颗粒后发生了部分孔填充和结构压实。如表 S3 所示，MCH 的总孔隙率约为 28.3%，而 [[GCMH]]-7 显著降低至 8.7%。这一降低归因于 [[MOF-808]] 和 GCD 杂化物的引入，它们占据了内部空腔，并通过与[[纤维素]]链的界面[[氢键]]和[[配位作用]]增强了水凝胶框架。尽管孔体积降低，但更致密的结构增强了机械完整性，并促进了催化反应过程中的高效电荷和质量传递 [57]。这些结果证实，嵌入 GCD@[[金属有机框架|MOF]] 纳米颗粒可有效调控分级孔隙率，同时提高结构稳健性。

[[水凝胶]]的形貌与界面特征通过[[SEM]]和[[透射电子显微镜|TEM]]分析进行了考察（图3a–f）。[[GCMH-7]]的[[场发射扫描电子显微镜|FE-SEM]]图像（图3a–c）显示出由微米级和纳米级纤维网络组成的互连多孔结构，为催化剂固定提供了丰富的界面位点。截面成像（图3c）进一步证实了致密的内部形貌，表明[[GCD@MOF]]颗粒在[[纤维素]]骨架内均匀嵌入。这种紧凑结构促进了强界面粘附，从而增强了机械稳健性，并最大限度地减少了重复催化使用过程中的颗粒浸出。这种整合既支持水相环境中的高效质量扩散，也有助于维持催化活性。GCD@[[金属有机框架|MOF]]复合材料的TEM分析（图3d–f）展示了一种整合良好的杂化形貌。[[β-环糊精|β-CD]]基质作为均匀载体，用于锚定$g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$纳米片和[[MOF-808]]纳米颗粒。高分辨TEM显示出与$g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$和MOF-808晶域相对应的清晰晶格条纹，证实了各组分之间紧密的界面接触和强耦合。这种纳米尺度整合有利于电子迁移和[[界面电荷转移]]，这对于$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$活化过程中的[[活性氧物种|ROS]]生成和催化性能至关重要[58]。[[能量色散X射线光谱|EDX]]元素分布图（图S4）进一步证实了$\mathrm { C } , \mathrm { N } ,$和$^ { \mathrm { ~ O ~ } , }$的均匀分布，验证了β-CD和g $\mathrm { _ { - C _ { 3 } N _ { 5 } } }$在水凝胶中的均匀引入。尽管未清晰检测到Zr信号，但这可能是由于MOF-808颗粒在水凝胶基质中的原子分数较低且分散较深。锆物种的存在已通过[[XPS]]（Zr 3d峰位于182.3和184.7 eV）和[[热重分析|TGA]]（高温残渣）得到验证，证实了MOF-808在水凝胶网络中的成功引入和固定。

[[Freundlich模型|Freundlich]] [[吸附等温线|等温线]]模型对 [[GCMH-7]] 上 [[环丙沙星|CIP]] 的平衡[[吸附]]数据进行拟合（图 S6b 和表 S5）。[[Langmuir模型|Langmuir]] 模型的相关系数 $( \mathrm { R } ^ { 2 } = 0 . 8 6 5 )$ 高于 [[Freundlich等温线模型|Freundlich]] 模型 $( \mathrm { R } ^ { 2 } = 0 . 5 1 4 ) ,$，表明在均相[[活性位点]]上发生单层吸附。该结果支持以[[化学吸附]]为主导的吸附机理，与[[准二级动力学模型|准二级]]动力学行为以及 [[路易斯酸|Lewis]] 酸碱[[配位作用|配位]]、[[氢键]]和 [[π-π相互作用|π–π]] 堆积等特异性相互作用的参与相一致。

## 3.3. $H _ { 2 } O _ { 2 }$ 体系的[[高级氧化]]性能

在黑暗 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 ^ { - } }$ 辅助条件下，系统评价了所合成材料对 [[环丙沙星|CIP]] 降解的催化性能，如图 4a–f 所示。如图 4b 所示，原始 g-$\mathrm { C _ { 3 } N _ { 5 } , \ \beta \mathrm { - C D } } _ { \mathrm { i } }$ 和 [[MOF-808]] 在 60 min 内的降解效率均低于 40%。这种低活性归因于反应[[活性位点]]不足以及与 CIP 分子的相互作用较弱。相比之下，杂化前驱体 25GCD@75MOF 表现出显著更高的活性 $( k = 0 . 0 3 1 2 \mathrm { \ m i n } ^ { - 1 } )$，表明 ${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 的 π 共轭域与 [[金属有机框架|MOF]]-808 中 [[路易斯酸|Lewis]] 酸性 $_ { \mathrm { Z r - O } }$ 簇之间存在协同效应。这些特性共同增强了 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化。当这些杂化颗粒被引入[[纤维素水凝胶]]骨架 $\begin{array} { r l } { ( \operatorname { F i g } , } & { { } 4 \mathbf { c } ) ; } \end{array}$ 后，随着 [[GCD@MOF]] 含量的增加，降解性能进一步提高。在 [[GCMH]]-x 系列中 $( x = 1 - 7$ wt%），[[GCMH-7]] 在 45 min 内几乎实现了 CIP 的完全去除，对应的[[表观速率常数]]最高，为 $( k =$ 0.0471 min<sup>−</sup> <sup>1</sup>）。这种增强的活性归因于催化位点分散性的改善以及[[水凝胶]]内部互连亲水通道的形成。这些特征有利于活性物种的高效传质与扩散。

不同氧化剂的效果对比见图 4a。 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } /$ [[GCMH-7]] 体系相对于 [[过一硫酸盐|PMS]]/[[GCMH]]-7 和 [[过二硫酸盐|PDS]]/GCMH-7 体系表现出更优异的降解性能。更高的反应活性 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 归因于其产生[[羟基自由基]]的能力 $( { \bf \^ { o } H , E } ^ { \circ } =$ $2 . 8 \mathrm { V } )$ 通过在[[路易斯酸|路易斯酸性]]条件下的均裂键断裂 ${ \bf z } { \bf r } { - } 0$ 中心。相比之下，PMS和PDS主要产生[[硫酸根自由基]]。 $( \mathrm { S O _ { 4 } ^ { \bullet } } , \mathrm { E } ^ { \circ } = 2 . 5 \mathrm { - } 3 . 1 \ : \mathrm { V } )$ 通过 $\mathrm { o - } 0$ 键活化。尽管 SO<sup>•-</sup> 物种具有相当的氧化还原电位，但在近中性 pH 条件下其形成在动力学上较不利。此外，其较慢的电子转移速率限制了整体降解效率 [61]。因此， $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ -活化体系促进了更快的自由基生成和更高的氧化能力，从而有利于 [[环丙沙星|CIP]] 降解 [62]。[[伪一级动力学|PFO 动力学]]分析（图 4d–f）证实了[[表观速率常数]]的顺序如下：GCMH-7（0.0450 min<sup>−</sup> <sup>1</sup>）> [[GCMH-5]]（0.0266 $\operatorname* { m i n } ^ { - 1 } ) > \mathrm { G C M H } { - 3 }$ (0.0189 min<sup>−</sup> <sup>1</sup>) > [[MCH]] (0.0024 $\mathrm { m i n } ^ { - 1 } ) > \mathrm { G C M H } { - 1 }$ $( 0 . 0 0 1 6 ~ \mathrm { m i n } ^ { - 1 } )$ . 该趋势表明催化效率随 [[GCD@MOF]] 负载量的增加而提高。总体而言，这些结果证实，在[[纤维素水凝胶]]骨架中整合 $\mathrm { \beta - C D , \ g - C _ { 3 } N _ { 5 } , }$ 与 [[MOF-808]] 可增强[[活性位点]]的可及性，并促进 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化及[[界面电子转移]]。因此，所提出的体系能够通过[[吸附-氧化耦合机制|吸附–氧化耦合机制]]实现高效的 CIP 降解。

初始 [[环丙沙星|CIP]] 浓度的影响在图 5b 中进行了评估。降解效率随浓度升高而增加，直至 3 mg/L，之后略有下降。在 0.5–1 mg/L 时，60 min 内观察到 96–97% 的去除率，这得益于充足的 [[活性氧物种|ROS]] 和可及的催化位点。在 3 mg/L 时实现了约 98.8% 的最高降解效率，反映了自由基生成与利用之间的最佳平衡。即使在 5 和 10 mg/L 时，也分别保持了 98.6% 和 96.5% 的高效率。这种稳健性表明 [[GCMH-7]] 凭借其丰富的[[活性位点]]和有效的 ROS 扩散，能够耐受污染物负荷。10 mg/L 时效率的轻微下降可归因于自由基的部分自猝灭以及中间产物的竞争性[[吸附]] [63]。此外，溶液浊度和黏度的增加可能抑制[[水凝胶]]网络内的传质，降低自由基与目标分子之间的总体接触频率。这些结果证实，降解效率主要取决于自由基迁移率，而非催化剂失活。

[[GCMH-7]] 投加量在 $\mathrm { H _ { 2 } O _ { 2 ^ { - } } }$ 活化条件下对 [[环丙沙星|CIP]] 降解的影响见图 5c。将催化剂负载量从 0.5 增加到 $2 \ g / \mathrm { L }$ 时，降解效率从约 82.7% 提高到 $9 8 . 6 \% ,$，这主要是由于可及[[活性位点]]增加以及[[水凝胶]]表面与本体溶液之间的接触改善。较高的催化剂浓度促进了 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 高效分解为 [[活性氧物种|ROS]]，从而加速了氧化降解。然而，当投加量超过 ${ _ { 2 } } \ { _ { g } } / { \mathrm { L } } ,$ 时，降解效率下降，在 3 和 $5 g / \mathrm { L } ,$ 时分别降至约 73.2% 和 61.4%。这一反向趋势可归因于悬浮液中固体含量过高，导致颗粒团聚、自由基复合和浊度增加。团聚的水凝胶部分阻碍了氧化剂和 CIP 分子向催化网络内的扩散，从而限制了传质并降低了 $_ { \mathrm { Z r - O } }$ 活性中心的可及性。此外，在高催化剂浓度下，活性自由基（<sup>•</sup>OH 和 HO<sup>•</sup>）的相互猝灭进一步抑制了氧化效率。基于这些结果，2 g/L 被确定为最佳负载量。在该浓度下，[[GCMH]]-7 通过在丰富活性位点与高效 ROS 利用之间保持平衡，在 60 min 内实现了几乎完全的 CIP 去除（约 98.6%）。

为评估 [[GCMH-7]] 的环境耐受性，在[[去离子水]]、[[自来水]]、[[地表水]]和[[实际废水]]等多种水基质中评价了其降解性能（图 5d）。结果表明，[[环丙沙星|CIP]] 去除率变化极小，所有基质中的降解效率均超过 95%。这种高基质耐受性归因于[[纤维素水凝胶]]的[[亲水性]]多孔结构，即使在溶解盐和[[天然有机物]]存在的情况下，也能支持高效传质。此外，[[MOF-808]] 中的 ${ \bf z } { \bf r } { - } 0$ [[配位作用|配位]]键以及与 [[β-环糊精|β-CD]] 形成的[[氢键网络]]在复杂水环境中保持稳定，从而防止表面失活 [22]。在各种水体中保持的活性证实了 [[GCMH]]-7 的化学稳定性及其对离子干扰和竞争[[吸附]]的抵抗能力。总体而言，这些结果表明，将 GCMH-7 应用于实际废水处理而无需额外预处理步骤具有实际可行性。

还研究了典型无机阴离子 $( \mathrm { C l } ^ { - } , \mathrm { N O } _ { 3 } ^ { - } , \mathrm { S O } _ { 4 } ^ { 2 - } ,$ 和 $\mathrm { C O } _ { 3 } ^ { 2 - } )$ 以及[[腐殖酸]]对 [[环丙沙星|CIP]] 降解的影响（图 5e）。$\mathrm { C l ^ { - } }$ 和 $\mathrm { C O } _ { 3 } ^ { 2 - }$ 的存在轻微抑制了降解，这可能是由于它们与 [[活性氧物种|ROS]] 发生竞争反应，生成了反应性较低的氧化剂，如 $\mathrm { C l } ^ { \bullet }$ 和 CO<sup>•-</sup>。相比之下，$\mathrm { N O } _ { 3 } ^ { - }$ 和 $S O _ { 4 } ^ { 2 - }$ 的影响可忽略不计，表明这些离子不会显著干扰自由基生成过程。腐殖酸存在时降解效率有所降低，这主要是由于其芳香性结构会与 CIP 竞争[[吸附]]位点和活性自由基。尽管如此，即使存在腐殖酸，该体系仍保持 90% 以上的降解效率。这种耐受性归因于[[水凝胶]]的分级结构，该结构可抵抗表面污染并保持反应位点的可及性。这些结果表明，$_ { \mathrm { H _ { 2 } O _ { 2 } / G C M H } } .$ 7 体系在环境相关条件下能够有效运行。其强大的自由基生成能力、化学稳定的 $_ { \mathrm { Z r - O } }$ [[活性位点]]以及[[亲水性]]多孔结构确保了在多种水基质中的氧化性能，从而凸显了该体系在可扩展和可持续废水处理应用中的潜力。

pH 对 $\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 体系降解 [[环丙沙星|CIP]] 的影响在较宽范围内（pH 3–11）进行了考察，如图 5f 所示。在所有 pH 水平下，降解效率均保持在 90% 以上，表明该复合催化剂具有优异的氧化还原稳定性与适应性。根据图 S7，[[GCMH-7]] 的 [[zeta 电位]]从 pH 3 时的 +5.6 mV 变为 pH 11 时的 −18 mV，其 $\mathrm { \ p H _ { \mathrm { p z c } } }$ 约为 6.8。[[吸附]]实验表明，CIP 在 pH 3 时的吸附量最低，这可能是由于带正电的[[水凝胶]]与部分质子化的 CIP 分子之间存在[[静电排斥]]。随着 pH 接近中性，吸附量增加，原因是排斥作用减弱，并且 [[β-环糊精|β-CD]]、g-$\mathrm { C } _ { 3 } \mathrm { N } _ { 5 }$ 与 CIP 芳香环之间开始形成[[氢键]]和 [[π–π 相互作用]] [64]。在碱性 pH（9–11）条件下，水凝胶表面带负电，对阴离子型 CIP 物种产生轻度排斥，使吸附容量略有下降 [65]。尽管如此，总体降解效率仍保持较高水平，表明活性自由基引发的氧化作用主导了表面吸附过程。碱性条件下持续催化活性归因于碱辅助 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 分解促进了 O<sub>2</sub><sup>•</sup> 的生成，从而补充了主要的 <sup>•</sup>OH 途径。这些结果表明，虽然 pH 通过[[静电相互作用]]影响初始吸附阶段，但具有氧化还原活性的 Zr–O–H 中心和共轭 $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 结构域确保了在较宽 pH 范围内催化性能的一致性。

对于温度依赖性实验，使用恒温水浴将反应温度控制在 10、20、25、30、40 和 $5 0 ~ ^ { \circ } \mathrm { C }$，并在每次温度下使体系在加入 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ $( { \mathrm { F i g } } , 5 g ) .$ 之前达到[[吸附]]平衡。在吸附阶段，不同温度下 $\mathrm { { C } / \mathrm { { C } _ { 0 } } }$ 值的变化可以忽略不计，表明 [[环丙沙星|CIP]] 在[[水凝胶]]基质中的吸附行为主要受表面亲和力而非热动力学控制。然而，在加入 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 之后，降解效率表现出明显的温度依赖性。催化性能在低温和高温下均显著增强，其中在 10 和 ${ 5 0 ~ ^ { \circ } \mathrm { C } } ,$ 时观察到最高效的降解，而在 $2 0 ~ ^ { \circ } \mathrm { C } .$ 时记录到显著下降。这一趋势表明，$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化机制对活性物种生成与自分解之间的平衡较为敏感。在较低温度 $( 1 0 ^ { \circ } \mathrm { C } ) ,$ 下，稳定性 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 在水性介质中抑制了其非生产性分解，从而使持续生成成为可能。 $\therefore \mathrm { \Phi _ { O H } }$ 和 $^ 1 0 _ { 2 }$ 通过逐步催化活化实现。相反，升高的温度会促进分子扩散和[[界面电子转移]]，加速 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 解离并增强自由基生成动力学。近处表现较差 ${ 2 0 ~ ^ { \circ } \mathrm { C } }$ likely arises from an unfavorable balance between the activation and decomposition pathways of $\mathrm { { H _ { 2 } O _ { 2 } } , }$ 其中间产物 HO<sup>•</sup> 迅速转化为非活性物种，从而降低氧化效率。此外，20 与 $2 5 ~ ^ { \circ } \mathrm { C }$ 暗示了一种阈值式激活行为，超过该阈值后，能量势垒对于 $\mathrm { o - } 0$ 键的断裂在于 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 有效地克服，从而产生占主导地位的自由基生成。在 30 至 $5 0 ~ ^ { \circ } \mathrm { C }$ 突显了水凝胶催化剂的结构稳健性与热稳定性，从而保证了其可靠性 在变化的环境温度下运行。

## 3.6. [[GCMH-7]] 的[[可重复使用性]]和结构稳定性

[[GCMH-7]] 的[[可重复使用性]]通过以 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 为氧化剂的连续降解循环进行评估（图 S11）。每个循环后，使用过的[[水凝胶]]被收集、冲洗，并在 $6 0 ~ ^ { \circ } \mathrm { C }$ 下干燥后再利用。如图 S11b 所示，催化剂在多次循环中保持了超过 97% 的初始降解效率，展现出杂化骨架优异的耐久性和机械完整性。重复使用样品在 60 min 内对 [[环丙沙星|CIP]] 的持续快速降解表明，氧化还原[[活性位点]] $_ { ( Z \mathrm { r - } 0 }$ 团簇和 $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 域）在反复氧化反应过程中保持化学稳定且易于接近。为进一步评估水凝胶的化学稳健性，使用多种溶剂进行了再生测试，包括[[去离子水]]、乙醇、[[甲醇]]、0.1 M NaOH 和 0.1 M HCl（图 S11a）。在所有情况下，[[GCMH]]-7 均保持了超过 98% 的原始降解效率，凸显了其优异的耐溶剂性和结构回弹性。值得注意的是，经 0.1 M NaOH 再生的水凝胶表现出最高的催化活性恢复。这一增强性能归因于 OH<sup>−</sup> 的强清洗能力，它能有效去除残留有机物，并通过表面去质子化恢复 $\mathrm { Z r { - } O { - } H }$ 活性位点 [66]。此外，温和的碱性处理重新打开了[[纤维素]]基质中[[氢键]]结合的通道，改善了质量传输，并使封装的 [[GCD@MOF]]-808 颗粒重新暴露于反应界面。在所有再生处理中观察到的一致可重复使用性表明，杂化组分通过[[配位作用]]和氢键相互作用的结合被牢固固定，有效防止了洗涤和再利用过程中活性物种的浸出。这一解释进一步得到 [[FT-IR]] 分析的支持，该分析揭示了与 CIP 表面相互作用相关的特征谱带位移，表明[[化学吸附]]占主导地位。此外，[[XRD]] 和 [[XPS]] 分析（图 S12）显示，重复降解循环后结构变化极小，证实了 GCMH-7 在可持续废水处理应用中具有优异的可回收性、化学稳定性和长期催化活性。这些结论进一步得到反应后 [[SEM]] 观察的支持，观察结果表明，[[纤维素水凝胶]]的层状多孔结构在重复使用后保存完好，没有明显的结构坍塌或表面侵蚀。此外，[[热重分析|TGA]]/[[微分热重分析|DTG]] 分析（图 S12d）展示了稳定的多步分解曲线，并在高温下保留了无机残余物，表明固定的 [[MOF-808]] 域和水凝胶骨架在催化操作过程中保持了其热稳定性和组成完整性。

## 3.7. [[环丙沙星|CIP]] 降解机制

[[环丙沙星|CIP]] 在 $\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 体系中的降解机制通过[[自由基捕获实验]]、[[ESR波谱|ESR 波谱]]和[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算的结合加以阐明（图 S13a–h）。[[电子自旋共振|ESR]] 波谱直接证明了在 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化过程中生成了多种[[活性氧物种]]（ROS）。如 $\mathrm { F i g . } \ \mathsf { S 1 3 a - c , }$ 所示，鉴定到三个特征信号：[[DMPO]]-<sup>•</sup>OH（1:2:2:1 四重峰）、DMPO-O<sup>•</sup>（多重线谱）以及 $\mathrm { T E M P ^ { 1 } O _ { 2 } }$（三重峰），证实了 $\mathbf { \cdot } _ { \mathrm { O H } , \mathrm { ~ O _ { 2 } ^ { \bullet } } }$ 与 $^ 1 0 _ { 2 } .$ 的同时生成。其中，强烈的 $\mathrm { D M P O \cdot ^ { \bullet } O H }$ 与 DMPO-O<sub>2</sub><sup>•-</sup> 信号表明，$\cdot _ { \mathrm { O H } }$ 和 $\boldsymbol { 0 } _ { 2 } ^ { \bullet - }$ 是主导活性物种，而 $^ 1 0 _ { 2 }$ 则起次要辅助作用。自由基猝灭实验（图 S14）进一步支持上述发现。加入[[叔丁醇]]和[[甲醇]]显著降低了降解效率，表明 <sup>•</sup>OH 是主要氧化剂。引入[[对苯醌]]和[[叠氮化钠]]后观察到中等程度的抑制，证实 $\boldsymbol { 0 } _ { 2 } ^ { \bullet - }$ 对整体氧化也有重要贡献，而 $^ 1 0 _ { 2 }$ 仅作为次要贡献者。综合来看，这些结果表明，$\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 体系通过双自由基途径运行，其中 <sup>•</sup>OH 与 O<sub>2</sub><sup>•-</sup> 协同将 CIP 氧化为危害较小的中间产物，最终矿化为 $\mathrm { C O } _ { 2 } , \mathrm { H } _ { 2 } \mathrm { O }$ 和硝酸根离子。

为进一步揭示氧化还原动态过程，研究开展了 [[DFT]] 计算，以探索复合材料各组分的电子结构与电荷分布（图 S15a–h）。[[静电势]]（ESP）图和[[前线分子轨道]]（FMO）参数（表 S11）揭示了 $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 } ,$、[[MOF-808]] 与[[纤维素]]基质之间明显的电荷分离。计算得到的[[带隙]]能量 $\mathrm { ( E _ { g } ) }$ 遵循如下顺序：$\mathrm { g { - } C _ { 3 } N _ { 5 } \ ( 2 . 7 2 \ \mathrm { e V } ) < \beta { \mathrm { - } } C D \ ( 4 . 9 8 \ \mathrm { e V } ) < }$ [[微晶纤维素]] $( 6 . 7 9 \ \mathrm { e V } ) ,$，确定 $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 为主要电子供体，而 $\beta \mathrm { - C D }$ 和纤维素则作为介体或电子受体。在 $\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 体系中，${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 主要起到给电子平台的作用，而 [[金属有机框架|MOF]]-808 提供了 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化的主要催化位点。$g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 的富电子三嗪氮位点促进[[界面电荷转移]]，而 MOF-808 中的 $_ { \mathrm { Z r - O } }$ [[配位作用|配位]]簇则作为[[路易斯酸|路易斯酸性中心]]，[[吸附]]并活化 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 分子。ESP 分析显示最高的电荷波动 $( \Delta \mathsf { V }$ ≈ 56.6 公顷) 在 $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 5 } ,$ 与 MOF-808 相比，这表明其具有出色的电荷离域特性和较高的电子迁移率 $\left( \Delta \mathrm { V } \approx 4 1 . 3 ~ \mathrm { H a } \right)$ 和多糖网络。富电子区域（蓝色）集中在三嗪环上 ${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 和 ${ \bf z } { \bf r } { - } 0$ MOF-808团簇，而缺电子区域（粉色）出现在[[β-环糊精|β-CD]]和纤维素的富羟基结构域上。基于[[HOMO]]–[[LUMO]]能级匹配和量子化学描述符（表S11和S12）， ${ \tt g } – { \tt C } _ { 3 } \mathrm { N } _ { 5 }$ 表现出最有利的电子供体特性，而 MOF-808 则表现出与其相关的强亲电行为。 $_ { \mathrm { Z r - O } }$ 簇，支持其作为主要角色的作用 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化中心。ESP 映射进一步识别出三嗪环中的氮原子位于 $g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$ 并且 ${ \bf z } { \bf r } { - } 0$ MOF-808中的配位节点是最具电化学活性的位点。前者作为富电子中心促进电荷给予，而后者则充当原子尺度[[活性位点]]，用于 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 吸附与$\mathrm { o - } \mathrm { o }$键活化。这种电荷极化促进了电子从$g { \mathrm { - C } } _ { 3 } \mathrm { N } _ { 5 }$向界面的转移。

[[MOF-808]]，促进 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 通过[[单电子转移]]实现活化。 $g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 5 } \left( - 0 . 7 9 \right.$ eV vs. [[标准氢电极|NHE]]）在热力学上有利于将溶解氧还原为 $\mathrm { O } _ { 2 } ^ { \bullet - }$ ，而[[价带空穴]] $( \mathrm { h } ^ { + } )$ ，局限于 $\beta \mathrm { - C D }$ 和[[纤维素]]基团，支持表面[[吸附]]物的氧化 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 以生成<sup>•</sup>OH。富含羟基和[[氢键网络]]的纤维素骨架增强了[[活性氧物种|ROS]]的扩散，并延长了瞬态自由基物种的寿命，从而确保持续的反应活性。因此，这些发现证实了[[环丙沙星|CIP]]在[[GCMH-7]]上的降解通过均相（溶液相）和非均相（表面结合）自由基过程的协同氧化还原路径进行，这一点得到了通过[[DFT]]识别的[[电荷转移]]层级关系的支持（表S12）。如图7所示，层级化整合的 $g _ { - }$ $\mathrm { C } _ { 3 } \mathrm { N } _ { 5 } ,$ , [[金属有机框架|MOF]]-808 与 [[β-环糊精|β-CD]] 在[[纤维素水凝胶]]骨架中的复合构建了高效的[[电子转移网络]] 在温和操作条件下持续再生 ROS。这种稳健的结构促进了高效的 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 活化与自由基扩散，并通过[[氢键]]和[[配位作用|配位]]相互作用稳定[[活性位点]]，从而在连续降解循环中实现持续的催化性能和优异的[[可重复使用性]]。

## 3.8. [[环丙沙星|CIP]] 的可能降解途径

[[环丙沙星|CIP]] 在 $\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 体系中的降解路径通过实验研究和基于 [[DFT]] 的模拟得到了阐明（图 S17）。自由基猝灭和 [[电子自旋共振|ESR]] 分析证实，<sup>•</sup>OH 和 $^ 1 0 _ { 2 }$ 物种是导致 CIP 转化的主要氧化性自由基。在与 CIP 的芳香族[[喹诺酮|喹诺酮结构]]相互作用时，这些 [[活性氧物种|ROS]] 引发多次[[羟基化]]、[[脱烷基化]]和[[开环反应]]，生成一系列中间产物（IP1–IP24）[67–70]。路径 1（P1）起始于喹诺酮环上的亲电羟基化，生成 IP1 作为主要产物。逐步氧化和部分开环生成含氧碎片，这些碎片随后转化为小分子羧酸。路径 4（P4）通过氧化性 N-脱烷基化和[[哌嗪|哌嗪环]]修饰进行，依次生成 $\mathrm { I P } 1 4  \mathrm { I P } 1 5 $ IP16 $ \mathrm { I P 1 7 }$。这些转化涉及 $\mathrm { c - N }$ 和 $\mathrm { c - c }$ 键的断裂以及随后的脱氢，生成碎片化的酰胺和亚胺衍生物。进一步氧化将这些中间体转化为短链有机酸，如[[甲酸]]、[[乙酸]]和[[草酸]]。路径 6（P6）代表一个独特的分支，其特征是自由基诱导的喹诺酮核心断裂，生成 IP24。该路径由 $\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ 和 $^ 1 0 _ { 2 }$ 对共轭 π 体系的同时攻击引发，导致 C–C 键断裂并快速生成含氧残基。这些中间体被逐步氧化为低分子量羧酸和无机物种 $\left( \mathbf { C O _ { 2 } } , \right.$ $\mathrm { H } _ { 2 } \mathrm { O } , \mathrm { ~ F ~ }$ <sup>−</sup> 以及 $\mathrm { N O } _ { 3 } ^ { - } )$，表明母体化合物发生了显著分解。理论[[静电势]]（ESP）和前沿分子轨道（[[前线分子轨道|FMO]]）分布（图 S15a b）进一步阐明了 CIP 及其关键中间体的电子反应活性，与三种不同路径（P1、P4 和 P6）一致。CIP 的 [[HOMO]] 主要定域在喹诺酮环和[[哌嗪环]]上，表明这些富电子区域容易受到亲电性 $\cdot _ { \mathrm { O H } }$ 攻击，而 ESP 映射揭示了 –COOH 和杂环 N 位点附近存在强负电势，支持初始氧化生成 IP1（路径 1）。在涉及逐步 N-脱烷基化和哌嗪氧化的路径 4 中，[[LUMO]] 逐渐从哌嗪环（IP14–IP15）转移到氧化碎片（IP16–IP17），且 ESP 显示酰胺羰基周围负电荷密度增加，有利于 $\mathrm { c - N }$ 断裂和随后的开环。对于路径 $^ { 6 , }$，喹诺酮骨架的断裂生成 IP24，其中 HOMO 和 LUMO 均集中在羰基附近，ESP 表现出局域负电势——有利于快速氧化为短链羧酸。综合来看，这些电子跃迁揭示了一种包含三个主要阶段的降解机制：（i）$\cdot _ { \mathrm { O H } }$ 对 CIP 富电子 N 和 O 位点的亲电攻击，（ii）连续的脱烷基化和开环反应，以及（iii）完全矿化为无机物种。$\mathbf { \sigma } ^ { \bullet } \mathrm { O H }$ 和 $^ 1 0 _ { 2 }$ 的协同作用，在 GCD [[水凝胶]]网络内丰富羟基和 [[π–π 相互作用]]的促进下，实现了连续的电子转移，从而高效活化 [[过氧化氢|H O]] 并降解污染物。这些发现证实，[[GCMH-7]] 提供了一个稳定的氧化还原界面，将表面反应与孔内自由基扩散相结合，确保了高效的 CIP 转化和显著矿化。

## 3.9. 降解产物的毒性评价

利用 [[ECOSAR|ECOSAR 2.2]] 程序通过[[定量构效关系]]（QSAR）建模，系统评估了 [[环丙沙星|CIP]] 及其由 $\mathrm { H _ { 2 } O _ { 2 } / G C M H { - } } 7$ 系统产生的降解中间产物的生态毒性。对三种代表性水生生物——[[鱼类]]、[[水蚤]]和[[绿藻]]——预测了急性（LC<sub>50</sub>）和慢性（LD<sub>50</sub>）毒性谱，从而深入了解母体化合物及其转化产物对环境影响。如$\mathrm { F i g . \ 8 a - b } ,$所示，根据[[全球化学品统一分类和标签制度]]（GHS）分类，大多数降解中间产物落在“无害”区域。这表明催化氧化后生态毒性显著降低。[[层次聚类分析]]（HCA）和[[主成分分析]]（PCA）（图 S19）证实了母体 CIP 分子与其降解中间产物之间存在明显区别。CIP 分子与较高的急性和慢性毒性载荷密切相关，尤其是对鱼类物种，而主要中间产物（IP1、IP14、IP15、IP16、IP17 和 IP24）聚集在低毒性区域，表明在整个氧化过程中发生了逐步脱毒。如图 8e 所示，定量毒性矩阵和[[急慢性比值]]（ACR）显示，所有中间产物的 $\mathrm { L C } _ { 5 0 }$ 和 $\mathrm { L D } _ { 5 0 }$ 值均显著高于 CIP，反映出较弱的毒性响应。值得注意的是，IP15–IP17 的平均 ACR 值低于 55，证实其缺乏慢性持久性，且在水生系统中[[生物累积]]风险极低。总体而言，这些结果表明，$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } /$ [[GCMH-7]] 体系不仅能有效促进 CIP 降解，还能抑制有毒或持久性副产物的生成，凸显其环境安全性以及在可持续废水处理应用中的潜力。

## 4. 结论

一种多功能[[水凝胶]]催化剂（[[GCMH]]），由$g { \mathrm { - } } \mathrm { C } _ { 3 } \mathrm { N } _ { 5 } ,$ [[MOF-808]]和[[β-环糊精|β-CD]]组成，被成功合成并用于通过$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$活化氧化高效降解[[环丙沙星|CIP]]。GCMH内的协同整合提供了丰富的[[吸附]]位点并促进了[[界面电荷转移]]，从而增强了[[活性氧物种]]的生成。在最优条件下，[[GCMH-7]]在较宽pH范围内表现出优异的降解性能和出色的稳定性。动力学分析表明，CIP降解遵循[[伪一级动力学模型]]，而[[机器学习]]和[[响应面建模]]确定CIP浓度为最具影响的变量。[[电子自旋共振|ESR]]和淬灭实验证实<sup>•</sup>OH和$^ 1 0 _ { 2 }$为主要的活性物种，[[DFT]]分析进一步支持了$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$与GCMH之间增强的[[电荷转移]]相互作用。该催化剂在多次重复使用循环中保持了高活性和结构完整性。LC–MS/MS和毒性评价表明，CIP经历了[[羟基化]]、[[脱氟]]和[[开环反应]]，生成了毒性较低的中间产物。因此，$\mathrm { H } _ { 2 } \mathrm { O } _ { 2 } .$活化的[[石墨相氮化碳|g-C N]] @[[金属有机框架|MOF]]-808@β-CD水凝胶为去除水环境中的药物污染物提供了一种可持续且可重复使用的平台。
