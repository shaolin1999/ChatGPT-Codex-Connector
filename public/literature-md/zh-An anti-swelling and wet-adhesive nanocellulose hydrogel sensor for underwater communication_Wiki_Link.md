# 用于水下通信的抗溶胀湿[[黏附]][[纳米纤维素]][[水凝胶传感器]]

[[Yujie Yang]],<sup>a</sup> [[Yuzhuo Zou]],<sup>a</sup> [[Yingying Liu]], \*<sup>a</sup> [[Mengxin Hu]],<sup>a</sup> [[Yingying Long]],<sup>a</sup> [[Hongbin Liu]],\*<sup>a</sup> [[Shijie Wu]],<sup>ab</sup> [[Ling Zhang]]<sup>c</sup> 和 [[Chao Liu]]<sup>d</sup>

传统[[水凝胶传感器]]应用于水下环境时面临诸多挑战，例如吸水引起的结构损伤以及[[黏附性能]]的快速丧失，这些问题阻碍了水下传感的实现。因此，开发具有[[湿态黏附|强湿黏附性]]和[[抗溶胀性能]]的[[水凝胶]]至关重要。本研究以[[丙烯酸]]（AA）、[[单宁酸]]（TA）和[[甲基丙烯酸磺基甜菜碱]]（SBMA）的[[共聚物]]为[[柔性链]]，以[[聚多巴胺改性纤维素纳米纤维|聚多巴胺改性的纤维素纳米纤维]]（[[PCNFs]]）为[[刚性链]]，通过[[氢键]]缠结合成了[[双网络水凝胶]]。[[PCAST水凝胶|PCNF/P(AA-SBMA)@TA 水凝胶]]（[[PCAST 水凝胶]]）在溶胀15天后，[[溶胀率]]仅为38.90%，表明其具有优异的抗溶胀性能。这种优异的抗溶胀性能归因于 PCAST 水凝胶致密的[[交联网络]]；该水凝胶还表现出良好的[[力学性能]]、较高的[[传感器灵敏度|灵敏度]]，其[[应变灵敏系数]]（GF）为2.97，且在湿环境中的最大[[黏附强度]]为47.01 kPa。基于这些优点，由该水凝胶制备的可穿戴传感器能够准确捕捉空气中和水下的信号变化。与摩尔斯电码结合时，可为水下活动的安全提供保障。本研究提出了一种开发用于水下应用的抗溶胀、自[[黏附]]可穿戴传感器的新策略，在智能传感领域具有广阔前景。

电子皮肤、可穿戴人体运动监测、精准临床诊断以及智能人–

## 新概念

本文提出了一种全新概念，即通过[[疏水缔合]]与内聚[[黏附]]因素共同构建[[水凝胶]]结构，突破传统水凝胶在水下环境中面临的界面失效与信号失真瓶颈。本研究基于[[疏水聚集效应|疏水聚集]]、黏附与内聚因素的动态耦合，旨在构建分子层面的协同网络，而非简单叠加两性离子抗溶胀策略与[[儿茶酚]]黏附策略。具体而言，[[甲基丙烯酸磺基甜菜碱|SBMA]]（甲基[[丙烯酸]]磺基甜菜碱）中的[[两性离子基团]]通过[[水合层]]内的[[静电排斥]]抑制过度吸水。除黏附功能外，[[聚多巴胺|PDA]]/[[单宁酸|TA]] 固有的[[芳香环|芳香环结构]]还可通过[[间苯二酚基团]]与 SBMA 侧链或[[聚合物主链]]之间的[[动态氢键]]和[[配位相互作用]]，充当内聚[[交联]]节点。疏水聚集效应限制过度[[水合]]，并降低[[儿茶酚基团]]在水环境中氧化失活的概率，从而建立闭环协同效应：疏水聚集增强[[内聚力]]，[[儿茶酚化学]]介导黏附，两性离子调控赋予[[抗溶胀性能]]。这一整合机制实现了对[[黏附性能]]与[[结构稳定性]]的双向调控，从根本上解决了[[水下传感器]]的界面分层问题。所得[[水凝胶传感器]]表现出较高的[[传感器灵敏度|灵敏度]]系数（2.97）、超快[[响应时间]]（B200 ms）、良好的抗[[溶胀行为]]（在单一液体环境中，415 天）以及[[湿态黏附|湿态黏附性能]]（47 kPa）。这一创新为柔性水下传感器的制备提供了一种新型仿生设计策略，凸显了其在水下运动检测与水下通信系统中的巨大应用潜力。

计算机交互近年来推动柔性传感器成为材料研究的前沿领域。<sup>1–4</sup> 作为可穿戴传感的核心器件，柔性传感器将外部刺激转化为电信号，以实现信息传输，其中，[[水凝胶]]作为关键功能材料，在构建高性能柔性传感器件方面发挥着举足轻重的作用。水凝胶柔性传感器的综合性能（如[[传感器灵敏度|灵敏度]]、[[抗疲劳性]]、[[界面黏附]]性和自修复能力）已得到显著提升。尽管取得了这些进展，其在水环境中的性能仍是一个关键障碍。具体而言，信号衰减和界面[[黏附]]稳定性差等问题严重阻碍了生理信号的准确检测，进而影响了安全预警与足迹追踪等水下传感应用的可靠性。

[[水凝胶]]是一类具有[[亲水性]]三维（3D）[[交联网络|交联网络结构]]的材料，在水性环境中易于溶胀。<sup>5–8</sup> 基于这一特性，[[抗溶胀性能]]较差<sup>9–11</sup>和[[湿态黏附]]强度较弱<sup>12,13</sup>构成了两大核心技术瓶颈，限制了其在水下传感中的应用。由于含有[[亲水性聚合物]]，水凝胶在水性介质中往往会迅速吸水并发生体积溶胀。这不仅会破坏内部[[交联]]网络结构，还会导致[[界面黏附]]力骤然丧失，从而显著降低水凝胶的工作耐久性。<sup>14–16</sup>

为应对这些挑战，研究者已广泛探索[[抗溶胀水凝胶]]的合理设计，其核心策略主要着眼于消除[[水合层|水化层]]或增强[[聚合物]]分子间相互作用，这两种策略均可使[[水凝胶]]在水性环境中保持结构稳定。常见的实现方法包括引入[[疏水微区]]或[[抗溶胀填料]]，17 增强[[共价交联网络]]，以及构建[[阻隔封装层]]。<sup>18</sup> 例如，通过精确调控水凝胶网络中[[亲水链段]]与[[疏水链段]]的平衡，已制备出[[离子液体]][[交联]]的抗溶胀水凝胶。<sup>19–21</sup> [[Guan]]<sup>22</sup>利用[[疏水相互作用|疏水性分子间相互作用]]和高密度[[交联网络]]，开发了一种兼具优异[[抗溶胀性能]]、拉伸[[力学性能]]和[[导电性能]]的[[双网络离子水凝胶]]。即使连续浸泡30天，该水凝胶仍能保持完整性。在探索抗溶胀策略的同时，提高[[湿态黏附|湿态黏附性能]]也已成为研究重点，因为水引起的界面劣化会显著损害水凝胶基传感器在水性环境中的工作稳定性。

水分子的持续渗入会破坏[[水凝胶]]与基底之间的相互作用，降低界面稳定性，导致人体运动监测过程中出现信号失真（动态[[应变]]测量误差达415%）和机械失效。<sup>23–25</sup> 受[[贻贝黏附机制]]启发，研究者将[[儿茶酚]]功能化化合物（如[[单宁酸]]和[[多巴胺]]）引入水凝胶网络，通过多模式键合作用（[[氢键]]、[[π-π堆积|p–p堆积]]和[[金属配位]]）赋予其牢固的[[湿态黏附|湿态黏附性能]]。例如，[[单宁酸包覆纤维素纳米晶|单宁酸包覆的纤维素纳米晶]]（TA@CNC）已被用于制备[[化学交联]]的[[TPP水凝胶]]，该水凝胶在包括[[亲水性]][[玻璃]]和[[疏水性]][[聚四氟乙烯|PTFE]]在内的多种基底上均表现出较强的[[黏附力]]。<sup>26</sup>

[[两性离子聚合物]]作为一类互补型[[黏附]]材料逐渐受到关注，其中[[甲基丙烯酸磺基甜菜碱]]（SBMA）利用疏水烷基域和[[静电偶极阵列]]穿透[[水合层]]。[[Hu]]<sup>12</sup>利用由[[琼脂糖]]、甲基[[丙烯酸]]磺基甜菜碱和[[聚吡咯]]组成的[[三元网络水凝胶]]，通过 SBMA 的[[离子相互作用]]赋予凝胶[[水下黏附]]能力。值得注意的是，[[纤维素纳米纤维|纳米纤维素纤维]]（[[纳米纤维素|CNFs]]）已被探索用作[[增强剂]]，以改善[[力学性能]]。其自扭转形成链状结构的倾向，加之内部丰富的[[羟基]]，增强了其与[[聚合物基体]]之间的[[氢键|氢键相互作用]]。然而，现有策略主要针对单一性能指标（抗溶胀性、黏附性或[[机械强度]]），未能同时实现溶胀稳定性、抗疲劳网络结构和[[应变]]敏感性，而这三者均是实现可靠水下传感的必要前提。

因此，本研究提出了一种兼具[[抗溶胀性能]]、强润湿性和[[黏附]]性的[[离子导电水凝胶]]。其在可穿戴柔性传感器中的应用解决了[[水凝胶]]溶胀不稳定性与水下传感准确性之间长期存在的矛盾。通过简便的[[热聚合]]方法构建了 [[PCAST 水凝胶]]网络。[[聚多巴胺改性纤维素纳米纤维|聚多巴胺接枝的纳米纤维素]]通过[[氢键]]与[[单宁酸]]（TA）[[交联]]，形成[[动态网络]]，赋予水凝胶对多种基底的[[界面黏附]]能力。这两种组分的引入并非任意选择，而是针对该体系对“黏附–抗溶胀”性能的需求进行的策略性设计。[[聚多巴胺改性纳米纤维素纤维|PCNF]] 表面的[[官能团]]与 TA 具有高度的结构相容性，有利于形成高密度、[[多价氢键网络]]，并产生协同互补效应，是实现多性能耦合的最佳组合。<sup>26</sup>尽管其他[[天然聚合物]]（如[[壳聚糖]]和[[海藻酸钠]]）也具有一定的交联能力，但其官能团相对单一，且缺乏配位位点，因而无法实现机械增强、[[湿态黏附]]和[[动态交联]]的协同调控。<sup>27,28</sup>与此同时，[[丙烯酸]]（AA）和[[甲基丙烯酸磺基甜菜碱]]（SBMA）通过聚合形成链，成为内部网络的一部分，同时通过策略性掺杂 ${ \mathbb { A } } ^ { 3 ^ { + } }$ 离子，在整个基体中建立高效的离子传导通路。此外，当用作可穿戴力学传感器时，[[PCAST水凝胶|PCAST 水凝胶]]不仅能保持稳定的湿态黏附，还能实现精确的实时信号监测，从而为下一代水下人机界面开辟新的途径。

## 2. 结果与讨论

## 2.1 [[PCAST 水凝胶]]的形成与原理

开发了一种[[一锅法|一锅法合成策略]]，用于简便制备 [[PCAST 水凝胶]]。采用精确控制的[[顺序加料]]方案：(1) 在水介质中对 [[聚多巴胺改性纤维素纳米纤维|PCNF]] 进行[[均质化处理]]，随后 (2) 按化学计量比加入 [[甲基丙烯酸磺基甜菜碱|SBMA]]/[[丙烯酸|AA]] [[共聚单体]]、[[单宁酸|TA]] [[交联剂]]和 ${ \mathbb { A } } ^ { 3 ^ { + } }$ 离子调节剂。由 [[N,N′-亚甲基双丙烯酰胺|MBAA]]/[[过硫酸铵|APS]] 触发的[[自由基聚合|自由基引发聚合]]形成了[[互穿网络]]（[[互穿聚合物网络|interpenetrating network]]，IPN）结构（图 1）。该 IPN 结构将两种不同但具有协同作用的网络有机整合，其相互作用决定了[[水凝胶]]的多功能特性。通过以下方式进行[[热引发]]：

[[过硫酸铵|APS]] 的[[热引发]]与 [[N,N′-亚甲基双丙烯酰胺|MBAA]] 的[[交联]]作用共同驱动形成了作为主网络的 [[聚甲基丙烯酸磺基甜菜碱-co-丙烯酸|poly (SBMA-co-AA)]]。在此，主网络结构由 [[甲基丙烯酸磺基甜菜碱|SBMA]] 和 [[丙烯酸|AA]] 形成 P(SBMA-co-AA) 链，其中链上的[[官能团]]通过[[氢键]]与 [[单宁酸|TA]] 结构中的[[酚羟基]]相互作用。同时，[[多巴胺]]单体经氧化形成[[醌结构]]，后者与[[纤维素纳米纤维|纳米纤维素纤维]]表面的[[亲核基团]]发生化学反应。该过程将多巴胺单体锚定于 [[纳米纤维素|CNF]] 表面，随后在该表面发生[[自聚合]]。该反应涉及 [[π-π共轭|p–p 共轭]]、p–p 共轭及定向延伸，最终形成 [[聚多巴胺改性纤维素纳米纤维|PCNF]]（图 1a）。其内部含有丰富的[[羟基]]和[[氨基]]，可与相邻分子链形成大量氢键，构成次级网络骨架，进一步稳定内部网络。${ \mathbb { A } } ^ { 3 ^ { + } }$ 离子具有双重作用：一方面与[[羧酸根离子]]形成[[金属配位|金属配位键]]，另一方面充当内部导电介质，协同提升材料的整体性能。所得[[水凝胶]]被命名为 [[PCAST 水凝胶]]。为系统阐明结构与性能之间的关系，采用相同的[[一锅法]]制备了一系列 $\mathrm { P C } _ { x } \mathrm { A } _ { y } \mathrm { S T } _ { z }$ 水凝胶，其 [[聚多巴胺改性纳米纤维素纤维|PCNF]] 质量分数 (x)、${ \mathbb { A } } ^ { 3 ^ { + } }$ 浓度 (y) 和 TA 添加量 (z) 均可调。其中，由 CNF 制备的水凝胶命名为 [[CAST 水凝胶|CAST]]。

## 2.3 [[水凝胶]][[力学性能]]分析

可穿戴传感器持续、灵敏且稳定的运行依赖于具有出色力学耐久性的[[水凝胶]]，这是实际应用中的一项关键性能指标。在此，[[力学性能]]受到不同物质及其用量的影响。随着 ${ \mathbb { A } } ^ { 3 ^ { + } }$ 用量的持续增加，[[PCAST 水凝胶]]的最大[[拉伸应力]]和[[应变]]呈现先升高后降低的趋势，如图 S3 所示。当 ${ \mathbb { A } } ^ { 3 ^ { + } }$ 用量为 2.4% 时，[[PCAST水凝胶|PCAST 水凝胶]]达到的最大应力为

45.12 kPa。这一行为归因于 ${ \bf A } ^ { 1 ^ { 3 + } }$ 作为三价阳离子的双重作用：在低浓度下，它与[[聚合物]]链表面的[[官能团]]配位，从而提高内部网络的[[交联密度]]，并增强内部离子的迁移能力。因此，网络变得均匀致密，进而改善导电性和拉伸性能。相反，过量添加会破坏内部[[配位相互作用]]，引入[[网络缺陷]]，并限制离子迁移，导致应力分布不均，进而使拉伸性能和导电性在一定程度上下降。<sup>15</sup>值得注意的是，随着 [[单宁酸|TA]] 添加量的增加，最大[[拉伸应力]]和[[应变]]呈现先增强后显著衰减的趋势（图 3a），凸显了过量 TA 对[[力学性能]]的不利影响。这一行为归因于 TA 通过[[氢键]]与 [[聚甲基丙烯酸磺基甜菜碱-co-丙烯酸|poly(SBMA-co-AA)]] 链相互作用，形成单层网络结构。适量引入 TA 可优化内部网络结构，而过量添加则会导致内部应力分布不均和网络缺陷，从而降低材料的力学性能。此外，$\mathrm { P C A S T _ { 4 . 0 } }$ [[水凝胶]]表现出较高的模量，这看似偏离了常规的组分–性能关联，实际上却源于多种因素的协同耦合。${ \mathrm { A l } } ^ { 3 + } { \mathrm { - T A } }$ 网络致密化与内部氢键的共同作用，使其在宏观上表现出更高的模量。<sup>19</sup>有趣的是，[[PCNFs]] 也有助于力学增强，其最大拉伸应力呈现出类似的浓度依赖性变化趋势（图 3b）。这种协同作用源于 [[聚多巴胺改性纤维素纳米纤维|PCNFs]] 上丰富的[[羟基]]和[[氨基]]，这些基团驱动其自组装成链状聚集体；这些聚集体形成氢键网络，并与 poly([[甲基丙烯酸磺基甜菜碱|SBMA]]-co-[[丙烯酸|AA]])/TA 基体结合，构建出力学性能优异的[[双网络结构]]。综合这些结果，确定水凝胶的最佳配方为 ${ \mathbb { A } } ^ { 3 ^ { + } }$ 含量 2.4%、TA 含量 4% 和 [[聚多巴胺改性纳米纤维素纤维|PCNFs]] 含量 0.15%，将其称为 [[PCAST 水凝胶]]，其表现出优异的力学性能。

图 3c 展示了未改性的 CAST 水凝胶与儿茶酚官能化的 PCAST 水凝胶在不同环境下的拉伸性能对比。随着水凝胶应变的增加，其拉伸强度达到 72.42 kPa（为 CAST 的 1.22 倍）。更为突出的是，其弹性模量（72.52 kPa）提高了 45.42%（图 3d），表明网络得到显著增强。在压缩载荷下（70% 应变，图 3g），PCAST 水凝胶的压缩应力达到 458.19 kPa（为 CAST 的 1.4 倍），接近某些生物软组织的力学性能。这种改善源于 PCNF 改性策略：PCNFs 易于分散，并与 AA 和 SBMA 相互作用，形成多模式氢键（PCNF-AA-SBMA），从而产生能量耗散机制。这些效应的协同作用使强度与韧性达到了前所未有的平衡。

## 2.4 [[水凝胶]][[黏附]]性与溶胀性能分析

[[黏附强度]]是[[水凝胶]]实现稳定传感应用的核心性能指标，因此定量表征其[[黏附性能]]不可或缺。本实验采用[[万能拉伸试验机]]进行[[搭接剪切测试]]，测量不同条件下水凝胶与基底之间的[[黏附]]强度（图 4）。[[PCAST 水凝胶]]表现出广泛的黏附兼容性，能够牢固地黏附于[[木材]]、[[聚合物]]（[[聚对苯二甲酸乙二醇酯|PET]] 和[[乳胶]]）以及[[纤维素基基底]]，并可在无外部辅助的情况下长时间承受 200 g 载荷而不发生剥离。搭接剪切测试示意图见图 S5。其黏附性能由两个协同的设计要素共同调控：首先，[[单宁酸|TA]] 的引入构建了富含[[儿茶酚]]的界面区域，从而增强[[湿态稳定性]]（图 S6a）；其次，[[聚多巴胺改性纤维素纳米纤维|PCNF]] 最初通过表面儿茶酚介导的键合和[[机械互锁|纳米尺度机械互锁]]实现增强，但在过量添加条件下，[[纳米颗粒聚集]]和[[网络缺陷]]的形成会导致黏附性能衰减（图 4a）。具体而言，对[[丙烯酸类材料|丙烯酸类基底]]的黏附强度峰值为 29.84 kPa（最佳 [[聚多巴胺改性纳米纤维素纤维|PCNF]] 含量），而 PCNF 过量时则为 13.84 kPa。这一趋势源于 PCNF 的双重功能：固定于表面的[[儿茶酚基团]]促进多种[[界面相互作用]]，而纳米尺度的[[表面粗糙度]]则增强机械互锁。值得注意的是，水凝胶[[黏附力]]的这一变化趋势在水环境和空气环境中均保持一致（图 S6b）。[[水下黏附]]评估表明，[[PCAST水凝胶|PCAST 水凝胶]]的性能显著优于 [[CAST 水凝胶]]，其对木材、铝、铁、[[丙烯酸]]类材料和[[玻璃]]的黏附强度分别达到 47.01 kPa、34.38 kPa、32.98 kPa、29.83 kPa 和 23.91 kPa（图 4b）。PCAST 和 [[CAST水凝胶|CAST 水凝胶]]在空气中的黏附性能均大幅增强（图 S6c），共同展现出适应环境的黏附特性。这种增强效应源于 PCNEs 的加入，其儿茶酚基团使 PCAST 水凝胶能够与各种基底形成多种协同的界面相互作用，包括[[范德华力]]、<sup>34,35</sup>[[静电相互作用]]、<sup>36</sup>[[氢键]]<sup>37,38</sup>和[[金属偶联]]，<sup>39</sup>从而增强[[界面键合]]。相比之下，过量添加 PCNF 会引起聚集，且[[聚合物网络]]形成局部缺陷结构，从而导致整体黏附性能下降。[[黏附机制]]如图 4i 所示。

值得注意的是，即使在水中浸泡 7 天后，[[PCAST 水凝胶]]仍能对多种基底保持极为牢固的[[界面黏附]]，其搭接剪切性能远超对照[[水凝胶]]（图 4c）。这种[[黏附耐久性|水中黏附耐久性]]源于 [[聚多巴胺改性纤维素纳米纤维|PCNF]] 驱动的多维增强作用：[[聚多巴胺改性纳米纤维素纤维|PCNF]] 的加入增强了基底界面结合与网络协同作用，并有效阻碍水的渗透，从而在水环境中维持[[结构完整性]]。[[循环黏附测试]]（图 4d）进一步证实了其优异的[[黏附循环稳定性]]：随着循环次数增加，[[黏附力]]略有下降，直接表明该水凝胶具有显著的[[可逆黏附|可逆黏附特性]]。与不同水凝胶体系相比（图 4e），[[PCAST水凝胶|PCAST 水凝胶]]仍凭借其卓越的[[湿态黏附|湿态黏附性能]]脱颖而出，表明了该制备策略的优越性。总体而言，PCAST 水凝胶出色的[[黏附性能]]满足了可穿戴设备在双重环境（空气/水环境）中进行实时信号采集与稳定传输的关键要求。

水下传感的前提是[[水凝胶]]在水环境中保持尺寸精度。在水环境中浸泡 15 天后，[[PCAST 水凝胶]]的形状和重量仅发生轻微变化，同时保持了完整的结构形貌，未发生塌陷（图 S7），这是实现稳定水下传感应用的关键前提。对 [[PCAST水凝胶|PCAST 水凝胶]]在不同水环境中的[[抗溶胀性能|抗溶胀能力]]进行了研究（图 4f 和图 S6d），结果揭示了其显著依赖于环境的[[溶胀行为]]。PCAST 水凝胶在[[去离子水]]中的[[溶胀率]]（43.53%）显著高于其在[[人工海水]]中的溶胀率。这主要源于两种机制：首先，大量离子与 [[聚多巴胺改性纤维素纳米纤维|PCNF]] 上的[[酚羟基]]之间存在特定相互作用；其次，[[离子屏蔽效应]]改变了水凝胶的[[电荷分布]]，从而增强了其吸水能力。在碱性条件下，水凝胶的溶胀率和[[溶胀速度]]均低于[[酸性环境]]中的水平。这是因为 [[聚多巴胺改性纳米纤维素纤维|PCNF]] 的[[氧化交联]]增强了 [[聚多巴胺|PDA]]-[[纤维素纳米纤维|CNF]] [[界面锚定|界面锚定作用]]，形成了致密的[[交联]]结构，与酸性环境相比，该结构延缓了[[溶胀动力学]]过程，并抑制了[[平衡溶胀]]。

在[[力学性能]]方面，[[CAST 水凝胶|CAST]] 和 [[PCAST 水凝胶]]在水下溶胀 7 天后，其[[拉伸应力]]和[[应变]]均显著下降。[[PCAST水凝胶|PCAST 水凝胶]]的[[韧性]]降至初始值的 30.7%（图 4c），表明其具有优异的[[抗溶胀性能]]和结构稳健性。[[溶胀动力学|平衡溶胀动力学分析]]（图 4g）进一步凸显了其相较于 [[CAST水凝胶|CAST 水凝胶]]的优势：PCAST [[水凝胶]]的溶胀曲线提前 48 小时达到平衡，同时其[[平衡溶胀率]]仅为 38.90%，降低了 10.98%。这种更快达到平衡的过程和更低的[[溶胀率]]源于 [[PCNFs]] 中的[[儿茶酚|儿茶酚基团]]与 [[丙烯酸|AA]] 中的[[羧基]]之间的[[共价交联]]，该[[交联]]减小了水凝胶的[[孔径|内部孔径]]，从而限制了水分子的渗入和膨胀。尽管 PCAST 水凝胶的[[平衡溶胀]]率相对较低，其抗溶胀能力仍不及 [[Guan]] 等人报道的 AA/BA 基[[离子凝胶]] $a l . ^ { 2 2 }$ 这一差异归因于内部[[疏水单体]]的不同。然而，由于未兼顾这两种性能之间的平衡，该[[离子水凝胶]]的[[黏附性能]]相对较差。与 Qi 等人<sup>40</sup>的工作相比，水下溶胀率相差约 2%。正如他们的研究所表明的，在碱性条件下，[[聚多巴胺改性纤维素纳米纤维|PCNFs]] 的引入发挥了功能性作用。

[[微观结构]]研究揭示了显著的形貌差异：尽管 [[PCAST 水凝胶]]存在轻微吸水现象，但其吸水程度显著低于 [[CAST 水凝胶]]，且[[孔隙]]数量和尺寸的变化可忽略不计（图 4h 和图 S6e）。这种[[形貌稳定性]]直接体现了 [[PCAST水凝胶|PCAST 水凝胶]]内部网络相互作用的增强，使其能够有效抵抗水诱导的[[网络膨胀]]，并在水环境中保持[[结构完整性]]，这是实现可靠水下传感所必需的结构特征。PCAST [[水凝胶]]的[[孔径|内部孔径]]为 8.69 mm，较未溶胀时的孔径增加了 12%（0.12 倍）（图 S1）。

## 2.5 [[水凝胶]]传感性能分析

通过 ${ \mathbb { A } } ^ { 3 + }$ 进行的[[离子掺杂|工程化离子掺杂]]在 [[PCAST 水凝胶|PCAST]] 基体内建立了高效的[[电荷传输|电荷传输通道]]，仅在 2.4 wt% 的添加量下即可实现高达 $0 . 6 5 6 \mathrm { S } \mathrm { m } ^ { - 1 }$ 的电导率（图 5a 和 b）。阻抗分析证实了一种随浓度增加而增强的机制，其中可移动离子构建动态渗流网络，使电荷能够在电偏压下快速跳跃传输。作为一项有力的概念验证，该[[水凝胶]]在 LED 电路中充当可变形导体，并表现出类似力致变色的光学转换行为：[[应变|拉伸应变]]通过调节[[电阻]]使亮度瞬间熄灭，而物理断裂则立即造成电隔离。值得注意的是，将水凝胶重新连接后，LED 迅速亮起，表明其具有优异的电导率自恢复能力（图 S9）。这种可逆响应特性使 [[PCAST水凝胶|PCAST 水凝胶]]成为智能可穿戴电子器件中极具前景的候选材料。为更有说服力地展示所制备水凝胶的优异导电性，将其与文献报道的基于相同基体的其他[[复合水凝胶]]进行了对比分析。比较结果见图 S10。如图所示，PCAST 水凝胶表现出显著较高的电导率，与大多数已报道的复合水凝胶相当或更高。<sup>23,38,43,44</sup>

值得注意的是，[[PCAST 水凝胶]]器件能够在潮湿/水性环境中实现可靠的摩尔斯电码信号通信，其通信机制如图 8a 和 b 所示。将 [[PCAST水凝胶|PCAST 水凝胶]]器件贴附于手指上，通过特定的手势动作传输摩尔斯电码，其中最常见的信号为“SOS”。无论在空气中还是水下，该器件均能快速响应，准确识别并转换 S 和 O 对应的摩尔斯电码信号，并迅速输出信号（图 8c）。即使在水中长时间浸泡后，PCAST [[水凝胶]]器件仍牢固地[[黏附]]于手部，且“HELP”和“COME”对应的摩尔斯电码信号在传输过程中保持完整（图 8d 和 e），这证实其[[黏附性能]]和传感性能未受损，使其适用于水下传感应用。除基本的求救信号外，有时还需要传达复杂信息，以指示前方路况或自身状况，例如“DANGER”。这也可以在 PCAST 的作用下得到完整传输和准确表达 水凝胶，如图 8f 所示。总之，这些结果证实，PCAST 水凝胶能够实现[[湿表面黏附]]、水下传感和[[摩尔斯电码通信]]功能，使其成为水下传感领域极具前景的候选材料。

## 3. 实验部分

## 3.1 材料

[[丙烯酸]]（AA）和[[盐酸多巴胺]]购自 Aladdin Reagent, Ltd（中国上海）。[2-(甲基丙烯酰氧基)

乙基]二甲基-(3-磺丙基)氢氧化铵（也称为[[甲基丙烯酸磺基甜菜碱]]，SBMA）和 $N \mathbf { \mathcal { N } } ^ { \prime } .$ -[[N,N′-亚甲基双丙烯酰胺|亚甲基双丙烯酰胺]]（MBAA）购自上海麦克林生化 $\mathrm { C o . }$ 有限公司（中国上海）。[[纳米纤维素]]（[[纤维素纳米纤维|CNFs]]，1.27 wt%）购自天津木精灵生物科技有限公司。[[单宁酸]]（TA）购自 Rhone Reagent。[[三氯化铝]] $\left( \operatorname { A l C l } _ { 3 } \right)$ 由天津光复发展科技 $\mathrm { C o . , }$ 有限公司提供。[[过硫酸铵]]（APS）由天津风船化学试剂科技有限公司提供。为进一步纯化这些化学品，所用溶剂为[[去离子水]]（DI 水）。

## 3.2 [[聚多巴胺改性纳米纤维素纤维]]（[[PCNFs]]）的制备

首先，配制[[Tris-HCl 缓冲溶液|盐酸-Tris 缓冲溶液]] $\left( 1 \mathrm { m o l } \mathrm { L } ^ { - 1 } \right)$，以提供[[碱性环境]]。随后，将预定量的 [[纤维素纳米纤维|CNFs]] 加入烧杯中，再加入预先配制的具有 $\mathrm { p H } = 8 . 5$ 的缓冲溶液，并搅拌均匀。然后加入[[盐酸多巴胺]]（盐酸[[多巴胺]] : $\mathbf { C N F S } = \mathbf { 1 } : \mathbf { 1 } )$，随后在密封、避光条件下持续搅拌 6 h，以确保多巴胺在 [[纳米纤维素|CNF]] 表面完全聚合。反应结束后，依次用[[去离子水]]、[[无水乙醇]]和去离子水进行离心纯化（离心条件：10 000 rpm，每次 15 min）。最终得到[[聚多巴胺改性纳米纤维素纤维]]（[[PCNFs]]）。

## 3.3 [[PCAST 水凝胶]]的制备

为同时实现优异的[[抗溶胀性能]]和出色的[[湿态黏附|湿态黏附性]]，通过[[热引发]]聚合制备 [[PCAST 水凝胶]]。其合成结构包含三个功能模块：(i) [[聚多巴胺改性纤维素纳米纤维|PCNF]] 分散液（0.5–0.25 wt%），用作力学增强组分和[[黏附]]锚点；(ii) [[丙烯酸|AA]]/[[甲基丙烯酸磺基甜菜碱|SBMA]] 单体前驱体（质量比为 5 : 1），形成[[两性离子网络|两性离子网络骨架]]；(iii) $\mathsf { A l } ^ { 3 + } / \mathrm { T A }$ 配合物，建立[[动态交联]]和导电通路。具体而言，先将 [[PCNFs]] 预分散于 [[去离子水|DI 水]]中（溶液 A）。另将 AA、SBMA、$\mathbf { A l C l } _ { 3 } ,$ 和 [[单宁酸|TA]] 共同溶解于 DI 水中，制备溶液 B。将溶液 A 与 $\mathbf { B } ,$ 充分混合后，依次加入 [[N,N′-亚甲基双丙烯酰胺|MBAA]]（[[交联剂]]）和 [[过硫酸铵|APS]]（引发剂），并持续混合 2 h。对所得溶液进行超声脱泡后，将其转移至不同形状的模具中，并在烘箱中于 $6 0 ~ ^ { \circ } \mathrm { C }$ 原位聚合 4 ${ \mathrm { h } } ,$，最终得到具有出色[[机械强度]]的 [[PCAST水凝胶|PCAST 水凝胶]]。作为比较，在相同实验条件下，以未改性的 [[纤维素纳米纤维|CNFs]] 代替 [[聚多巴胺改性纳米纤维素纤维|PCNFs]] 制备对照 [[CAST 水凝胶]]，旨在单独考察[[聚多巴胺]]改性对[[水凝胶]]性能的特定影响。

## 3.4 表征

对冻干[[水凝胶]]的横截面喷镀一层薄金后，采用[[SEM|扫描电子显微镜]]（SEM，JSM-IT300LV，日本）进行表征。采用同步热分析仪评估 [[PCAST 水凝胶]]的热稳定性 $\left( \mathbf { S D T 6 5 0 } ; \mathbf { N } _ { 2 } \right.$ 气氛；速率 $2 0 ~ ^ { \circ } \mathrm { C }$ min<sup>-1</sup>；30 $^ \circ \mathrm { C }$ 至 $8 0 0 ~ ^ { \circ } \mathrm { C } ) .$。采用傅里叶变换红外（[[FTIR]]）光谱仪（FTIR-650；4000–400 $\mathrm { c m } ^ { - 1 } , 4 \ \mathrm { c m } ^ { - 1 } )$）分析 [[纤维素纳米纤维|CNFs]]、[[PCNFs]] 和水凝胶的化学结构。

## 3.5 [[力学性能]]

采用[[万能拉伸试验机]]（[[LISHI LD-24]]）评估[[水凝胶]]的[[力学性能]]。在[[拉伸测试]]中，将样品切成尺寸为 $5 0 \times 2 0 \times$ $3 \mathrm { m m } ^ { 3 }$ 的矩形，[[拉伸速率|拉伸速度]]为 50 mm min<sup>-1</sup>。在[[压缩测试]]中，将水凝胶样品制成尺寸为 15  $1 5 \times 1 5 ~ \mathrm { m m } ^ { 3 } ;$ 的长方体，压缩速度为 50 mm $\operatorname* { m i n } ^ { - 1 }$ [[杨氏模量]]由曲线的斜率确定。[[韧性]]由曲线的积分面积确定。实验重复进行三次，以确保结果的可靠性。测试结果以平均值表示。

## 3.6 [[黏附性能]]

采用[[万能拉伸试验机|万能试验机]]通过 901 [[剥离测试]]考察不同[[水凝胶]]的[[黏附强度]]。水凝胶的样品尺寸为 $1 0 \times 1 0 \times 2 ~ \mathrm { m m } ^ { 3 }$。测试前，将水凝胶样品在低压下[[黏附]]于各种基底（[[木材]]、[[铝|铝片]]、[[亚克力板]]、[[玻璃]]等）30 秒，以确保紧密接触。随后在空气或[[去离子水]]环境中测量黏附强度，测试速度为 10 mm min<sup>-1</sup>。为评估黏附稳定性，在[[循环黏附测试]]期间，每隔 15 min 对同一样品进行一次黏附强度测试。实验重复进行三次，以确保结果的可靠性。测试结果以平均值表示。

## 3.7 [[抗溶胀性能]]

为评估[[水凝胶]]的[[抗溶胀性能]]，将其浸入[[去离子水]]、[[人工海水]]、酸性和碱性溶液以及水性环境中，并测量浸泡过程中的质量变化，以观察平衡时的[[溶胀比]]。准确称量水凝胶样品 $\left( W _ { 0 } \right)$，随后在室温下将其浸入测试溶液中。每隔相同时间取出样品，吸去表面水分，再次称量（W）。当水凝胶的质量不再变化时（平衡状态），终止[[溶胀测试]]。溶胀比（d）采用式（1）计算：

$$
\delta = \frac {W - W _ {0}}{W _ {0}}\tag{1}
$$

其中，d 表示[[水凝胶]]的[[溶胀比]]。实验重复进行三次，以确保结果的可靠性。测试结果以平均值表示。

## 3.8 电学性能

[[PCAST 水凝胶]]的电导率（s）采用[[电化学阻抗谱]]（EIS，

CHI660E，Chenhua Instruments Co., Ltd.，中国）测量。本研究中的 [[电化学阻抗谱|EIS]] 测量通常采用铜箔[[电极]]（宽 10 mm；Hz：0.1 至 10<sup>5</sup>）。电导率采用式（2）计算：

$$
\sigma = \frac {L}{R \times S}\tag{2}
$$

其中，L 表示[[水凝胶]]的厚度，S 表示接触[[电极]]面积，R 表示 [[奈奎斯特图|Nyquist 图]]中水凝胶的[[电阻率|实部电阻率]]。实验重复进行三次，以确保结果的可靠性。测试结果以平均值表示。

[[相对电阻变化|相对电阻]] $\left( \Delta R / R _ { 0 } \right)$ 根据式（3）计算：

$$
\frac {\Delta R}{R _ {0}} = \frac {(R - R _ {0})}{R _ {0}}\tag{3}
$$

其中，R 表示运动过程中的[[电阻]]，$R _ { 0 }$ 表示[[水凝胶]]的[[内阻|初始内阻]]。

[[应变灵敏系数]]（GF）采用式（4）计算：

$$
\mathrm{GF} = \frac {\Delta R / R _ {0}}{\varepsilon}\tag{4}
$$

其中，e 为[[应变|拉伸应变]]中的应变程度 $\begin{array} { r } { \left( \varepsilon = \Delta L / L _ { 0 } , \right. } \end{array}$，DL 为[[水凝胶]]的[[伸长量]]，$L _ { 0 }$ 为水凝胶的初始长度）。

## 4. 结论

总之，以[[丙烯酸]]、[[甲基丙烯酸磺基甜菜碱|SBMA]]、[[PCNFs]] 和[[单宁酸]]为原料，通过[[热聚合]]成功制备了兼具[[抗溶胀性能|抗溶胀能力]]和[[高湿度黏附性能]]的[[导电水凝胶]]（[[PCAST 水凝胶]]）。其关键创新在于构建了[[亲水–疏水协同双层网络]]，利用 SBMA 的柔性[[疏水烷基链]]与 [[聚多巴胺改性纤维素纳米纤维|PCNFs]] 的刚性[[亲水性|亲水特性]]，赋予[[水凝胶]]优异的综合性能。值得注意的是，该水凝胶具有优异的[[湿态黏附|湿态黏附性能]]，最大[[黏附强度]]为 47.01 kPa，同时具有显著的抗溶胀性能。其[[平衡溶胀率]]为 38.90%，且在[[碱性环境]]中的溶胀程度低于[[酸性环境]]。后续将针对[[天然海水]]和[[模拟体液]]等[[多组分介质|复杂多组分介质]]，以及[[动态流动]]条件下的[[长期浸泡]]、[[黏附]]和[[结构稳定性]]开展进一步实验。此外，该水凝胶还表现出优异的[[导电性能]]，[[离子电导率]]为 0.656 S m<sup>-1</sup>；具有出色的[[力学强度]]，最大[[拉伸应力]]为 72.42 kPa；并具有突出的[[抗疲劳性能]]。用作[[水下传感器]]时，该水凝胶具有高[[传感器灵敏度|灵敏度]]，在 100–150% [[应变]]范围内的 [[应变灵敏系数|GF]] 为 2.97，[[响应时间]]和[[恢复时间]]分别为 202 ms 和 159 ms，且具有[[长期稳定性]]。可穿戴 [[PCAST 水凝胶传感器]]能够准确捕捉空气和水下环境中的运动信号，使其尤为适合[[水下运动监测]]应用。此外，其与

[[摩尔斯电码通信]]的集成可实现水环境中的紧急求助。本研究为开发适用于水环境的[[柔性可穿戴设备]]开辟了一条实用且创新的途径，在推动[[水环境传感]]和[[应急通信|应急通信技术]]发展方面具有巨大潜力。
