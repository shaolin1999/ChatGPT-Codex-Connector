# 用于 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 处理的超高容量多功能纳米尺度[[吸附剂]]

[[Junseok Lee]] <sup>1</sup>, [[Changwoo Kim]]<sup>2</sup>, [[Chen Liu]]<sup>3</sup>, [[Michael S. Wong]] <sup>4</sup>, [[Natalie L. Cápiro]] <sup>5</sup>, [[Kurt D. Pennell]]<sup>3</sup> 和 [[John D. Fortner]] <sup>1✉</sup>

本文以[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS）为研究对象，介绍了用于实现超高容量 [[全氟和多氟烷基物质|PFAS]] [[吸附]]以及精准、低能耗[[磁分离|（磁）分离]]的[[表面功能化]][[超顺磁性氧化铁纳米晶]]（[[IONCs]]）。随[[表面包覆层]]的不同，本文所述[[吸附容量]]显著高于以往采用[[活性炭]]、[[聚合物]]及未改性金属/[[金属氧化物]]等材料的研究结果。尤其是，带正电的[[聚乙烯亚胺]]（PEI）[[表面包覆|包覆]] [[氧化铁纳米晶体|IONCs]]，凭借静电和[[疏水相互作用]]以及较高的[[接枝密度|聚合物接枝密度]]，对 PFOA 和 PFOS 均表现出极高的吸附容量，同时在水中保持稳定，从而维持可用[[表面积]]。此外，通过一种新开发的[[耗散型石英晶体微天平]]（[[耗散监测石英晶体微天平|QCM-D]]）方法，我们实现了对界面过程的实时观测（例如[[吸附动力学]]）。通过这一方法，我们探究了不同 PFAS（PFOA 与 PFOS）[[吸附行为]]差异的潜在机制，表明 PFAS 的[[头基|官能头基]]会强烈影响分子在[[吸附剂]]界面上/处的取向。我们还评估了[[水化学|水化学条件]]，包括 [[pH]]、[[离子组成|水中离子组成]]和[[天然有机质]]，对吸附行为的影响，并通过实验室规模的[[柱实验]]展示了材料的处理性能。

[[npj Clean Water]] (2023)6:62 ; https://doi.org/10.1038/s41545-023-00263-9

## 引言

[[全氟和多氟烷基物质]]（PFAS）因其在环境中的长期持久性及对人体健康的影响而成为备受关注的污染物。数十年来，PFAS 一直被工业化生产，并用于[[消防泡沫]]、地毯、[[涂料]]和[[金属电镀]]等众多产品与工艺，导致其广泛释放到环境中<sup>1</sup>。在[[地表水]]、[[地下水]]、[[饮用水]]和[[废水]]中均已检出 PFAS，其浓度约为 10 至 2000 ng/L，具体取决于释放程度及距污染源的距离<sup>2–6</sup>。在各种 PFAS 中，包括[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS）在内的长链 C-F 化合物与多种潜在的不良健康影响有关<sup>7</sup>，因此暴露于这些物质会带来风险<sup>8</sup>。[[美国环境保护署]]（US EPA）最近将 PFOA 的[[健康建议值]]修订为 0.004 万亿分之一（ppt，ng/L），将 PFOS 的健康建议值修订为 0.02 ppt；与此同时，多个州已提出或通过了 PFAS 监管规定，其中[[最高污染物限值]]低至 10 ng/L<sup>9</sup>。

得益于强[[碳–氟键|碳–氟（C-F）键]]所赋予的独特物理化学性质<sup>10</sup>，[[全氟和多氟烷基物质|PFAS]] 在自然系统中具有很高的稳定性，通常难以通过常规化学和[[生物降解]]过程去除。迄今为止，研究人员已探索了多种用于处理水中 PFAS 的高级处理技术，包括[[电化学氧化]]<sup>11–13</sup>、[[光催化]]<sup>14,15</sup>、[[基于硫酸根自由基的高级氧化还原工艺]]<sup>16–18</sup>、[[热破坏]]<sup>19</sup>、[[生物处理]]<sup>20</sup>以及其他氧化和还原方法<sup>21,22</sup>。此外，[[电子束]]<sup>23</sup>和[[等离子体]]<sup>24,25</sup>等工艺也已得到应用，但其能量投入更高。尽管其中一些工艺在处理多种 PFAS 方面展现出潜力，但长链（或较长链）且氟饱和的 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 仍然难以被破坏，其中 PFOS 比 PFOA 更难降解<sup>26,27</sup>。

作为化学和/或生物破坏方法的替代方案，[[吸附]]<sup>28,29</sup>和[[膜分离]]<sup>30,31</sup>等[[物理分离]]工艺能够高效处理 [[全氟和多氟烷基物质|PFAS]]，且不受其碳链长度和[[官能头基|头基官能团]]类型的限制。此前已有研究报道使用多种[[吸附剂]]去除 PFAS，包括[[活性炭]]<sup>32,33</sup>、[[碳纳米管]]<sup>34</sup>、[[阴离子交换树脂]]<sup>35,36</sup>、[[聚合物]]<sup>37,38</sup>、金属和/或[[金属氧化物]]<sup>39–41</sup>。为提高去除效能，研究人员还探索了用于增强[[物理吸附]]的附加处理工艺，包括引入气泡/混合<sup>42</sup>和加热<sup>43</sup>。此外，[[杂化复合材料]]和[[有机官能化|有机官能化（改性）]]也已被证明能够增强吸附性能<sup>44</sup>。已有研究发现，视材料而定，PFAS 与吸附剂材料表面之间的[[静电相互作用]]和[[疏水相互作用]]均具有重要作用<sup>45</sup>。从这一角度来看，[[有机–无机杂化纳米复合材料]]是一类很有前景的吸附剂，既可提供高[[BET|比表面积]]和灵活的表面[[表面包覆|包覆]]平台，配备可调控的（多种）[[官能团]]，又可具有响应性内核（例如磁性内核）。

在本研究中，我们展示了经[[表面工程]]改性的[[超顺磁性氧化铁纳米晶|超顺磁性氧化铁纳米晶体]]（[[IONCs]]）有效去除水中 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的能力，并阐述了[[有机包覆层]][[官能团]]在[[吸附行为]]中的关键作用。在所评估的全部材料中，带正电荷的[[聚乙烯亚胺]]（PEI）[[表面包覆|包覆]] [[氧化铁纳米晶体|IONCs]] 凭借有利的[[分子相互作用]]和高[[接枝密度]]，对 PFOA 和 PFOS 均表现出超高的[[吸附容量]]。针对这些材料，除了开展台架规模的[[柱实验|（砂）柱研究]]外，我们还进一步探索了[[水化学|水化学条件]]对[[吸附]]性能的影响，包括[[pH|溶液 pH]]、[[离子组成]]与[[离子强度]]，以及[[天然有机质]]。我们还提出了一种创新的[[耗散型石英晶体微天平]]（[[耗散监测石英晶体微天平|QCM-D]]）方法，用于原位、实时地从基础层面表征界面 [[全氟和多氟烷基物质|PFAS]] 吸附过程。这种新方法能够对溶液化学条件以及[[吸附质]]组成和浓度变化等系统扰动提供快速、准确且连续的响应。该方法有助于从机理层面理解[[竞争吸附动力学]]，包括[[分子取向|分子（吸附质）取向]]，从而为宏观行为的观测结果提供依据。

## [[纳米晶体]][[表面包覆层]]对 [[全氟和多氟烷基物质|PFAS]] [[吸附行为]]的作用

[[Zeta电位|Zeta 电位]]，针对 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 }$ @[[25 kDa聚乙烯亚胺|PEI25k]], $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E I } 1 0 \mathsf { k } ,$ $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { C T A B } ,$ 和 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { O } \mathsf { A }$ $\begin{array} { r l } { \mathsf { i } \mathsf { s } } & { { } 5 4 . 3 \pm 1 . 3 , } \end{array}$ $5 7 . 4 \pm 1 . 5 , 2 9 . 1 \pm 4 . 9 ,$ 以及 $- 2 4 . 2 \pm 1 . 8 \mathsf { m V }$ ，分别如此（补充图 2b）。涂层分析结果，包括[[接枝密度]]和组成，见补充表 1。

在 [[pH]] 条件下开展了依赖[[表面包覆层|表面涂层]]的 [[全氟和多氟烷基物质|PFAS]] [[批量吸附试验]] $7 \pm 0 . 2 . \ \mathsf { A s }$ 如图 1 所示，带正电的 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E }$ [[纳米晶体]]（[[纳米晶|NCs]]）表现出显著高于带负电荷的[[吸附密度]] $\mathsf { F e } _ { 3 } 0 _ { 4 } @ \mathsf { O A }$ NCs。[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的[[最大吸附容量]]为 18.3 mmol $\mathsf { P F O A } \mathsf { g } ^ { - 1 }$ NC 和 88.8 mmol PFOS $\mathfrak { g } ^ { - 1 }$ NC 用于 $\mathsf { F e } _ { 3 } \mathsf { O } _ { \angle }$ @[[25 kDa聚乙烯亚胺|PEI25k]]，以及 11.9 mmol $\mathsf { P F O A g } ^ { - 1 }$ NC 和 83.5 mmol PFOS g<sup>−1</sup> NC，对于 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E l } 1 0 \mathsf { k }$ ，分别为。带负电的 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { O } \mathsf { A }$ 对 PFOA 和 PFOS 的[[吸附容量]]均显著较低（1.83 mmol $\mathsf { P F O A } \mathsf { g } ^ { - 1 }$ NC 和 6.58 mmol $\mathsf { P F O S } { \mathsf { g } } ^ { - 1 }$ NC)。如表 1 所强调的， $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E }$ 本研究所述材料展现出迄今报道的最高[[吸附]]容量之一。这不仅归因于每个颗粒上大量（与 [[聚乙烯亚胺|PEI]] 的[[胺基密度]]有关，见补充表 1）有利的[[胺基–阴离子头基相互作用|胺基–阴离子（PFAS）头基相互作用]]<sup>47,48</sup>，还得益于颗粒在水中的高稳定性，从而实现最大的[[表面积]]/位点 可利用性（补充图 2）。相比之下，尽管[[胺基]]数量相近，但观察到 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E } \mathsf { l } 2 5 \mathsf { k }$ 的吸附容量高于 $\mathsf { F e } _ { 3 } \mathsf { O } _ { \iota }$ @[[10 kDa聚乙烯亚胺|PEI10k]]。这可能是由于 PEI25k 的[[接枝密度|接枝（质量）密度]]相对较高，且其胺基与碳的比值高于 PEI10k，两种因素共同作用所致。

所有批量[[吸附等温线]]均与 [[Langmuir模型|Langmuir]] [[吸附]]模型良好吻合（补充表 2），且无论使用何种[[吸附剂]]，计算得到的 [[全氟辛酸|PFOA]] 对应吸附常数（k）均远高于 [[全氟辛烷磺酸|PFOS]]。此外，为进行比较，我们还采用 [[Freundlich吸附等温线|Freundlich 等温线]]对吸附数据进行了建模（补充表 2）。有趣的是，对于所研究的所有材料组合，均观察到 PFOS 的[[最大吸附密度]] $\left( \mathsf { Q } _ { \mathsf { m a x } } \right)$ 高于 PFOA。例如，在 Fe O @[[25 kDa聚乙烯亚胺|PEI25k]] 上，PFOA 的 k 和 $\mathsf { Q } _ { \mathsf { m a x } }$ 值分别为 657 L/mmol 和 18.3 mmol/g，而 PFOS 的相应值分别为 4.22 L/mmol 和 88.8 mmol/g。由于 PFOA 和 PFOS 具有相似的氟饱和尾链结构，这一差异表明，[[全氟和多氟烷基物质|PFAS]] 的[[头基|官能头基]]对[[吸附行为]]有所贡献。就[[官能团]]酸性而言，PFOS 的 pKa 值（<0）低于 PFOA（0.5–3.8），且其对辛醇（一种非水相模型，log ${ \sf K } _ { \sf { O W } } \bar { = } 5 . 4 3 )$ 的亲和力也高于 PFOA（log $\mathsf { K } _ { \mathsf { O W } } = \dot { 5 } . 1 1 ) ^ { 4 9 - \dot { 5 } 2 }$ 。正如其他研究者所讨论的，与胺–羧基相互作用（−21.41 kJ/mol）相比，胺–磺酸相互作用通常具有更负的焓（ΔH）值（−42.81 kJ/mol），这也可能有助于使吸附（更加）有利<sup>53,54</sup>。这些性质差异还可能影响缔合过程中的[[空间位阻]]，具体体现为吸附事件的[[分子取向|平均几何取向]]，下文将对此进一步探究和讨论。

## 通过 [[耗散型石英晶体微天平|QCM-D]] 实时分析 [[全氟和多氟烷基物质|PFAS]] [[吸附]]

为更好地理解[[吸附]]的基本动力学，我们开发了一种[[耗散监测石英晶体微天平]]（[[耗散型石英晶体微天平|QCM-D]]）技术，以实时、原位观察 [[全氟和多氟烷基物质|PFAS]] 的[[吸附行为]]。为此，我们在传感器界面上构建了一层稳定的 [[IONCs]] [[单分子层]]，由此可依次引入不同的水溶液并使其[[吸附平衡|达到平衡]]，包括改变[[水化学|水化学条件]]以及 PFAS 的浓度/类型（补充图 3）。补充图 4 展示了 [[纳米晶|NCs]] 浓度达到或超过 5 mg/L 时，[[氧化铁纳米晶体|IONC]] 沉积和传感器表面饱和（即[[单层覆盖]]）的动力学（[[频移斜率]]）。稳定后，[[超顺磁性氧化铁纳米晶|IONCs]] 在引入 PFAS 溶液时表现出相对快速的响应，并在数分钟内达到平衡。这些结果与使用 IONCs 对 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 进行的批量[[吸附等温线]]和动力学试验结果一致（补充图 5）。为进一步理解 PFAS 在 IONCs 上的[[吸附动力学]]，我们根据 QCM-D 吸附实验获得的数据计算了[[频移]]斜率 $( f _ { \mathsf { s l o p e } } )$。由于频移（Δf）与晶体表面的质量变化（Δm）成正比，因此 Δf 的变化速率等效于晶体表面的质量变化速率（即 PFAS 的附着或释放速率）<sup>55,56</sup>。因此，可通过计算频移斜率 $( f _ { \mathsf { s l o p e } } ) .$ 来确定 PFAS 的[[吸附速率]]（动力学）。如补充图 6 所示，$\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { C T A B } \mathsf { N C s }$ 的 $f _ { \mathrm { s l o p e } } ,$ 值最高，其次为 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E l } 1 0 \mathsf { k }$ 和 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E } \mathsf { I } 2 5 \mathsf { k } ,$，该值与 IONCs 的[[水动力学直径|水动力直径]]成反比。我们预计，更厚（且更致密）的 [[聚乙烯亚胺|PEI]] [[表面包覆层]]需要更长时间才能使 PFAS 充分吸附，这可能是由于[[传质限制]]所致；同时，由于[[结合位点]]相对更多，其总体[[吸附密度]]更高。

根据 [[IONCs]] 和 [[全氟和多氟烷基物质|PFAS]] 溶液流经 [[石英晶体传感器|Q 传感器]]时各自产生的[[频率偏移]]，我们利用 [[Sauerbrey方程|Sauerbrey 方程]]<sup>57</sup>，通过[[沉积质量]]确定了 [[氧化铁纳米晶体|IONCs]] 对 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的[[吸附密度]]。我们确认，在没有 [[超顺磁性氧化铁纳米晶|IONCs]] 的情况下，PFAS 不会直接附着于[[石英晶体]]传感器上（补充图 7），因此，在存在 PFAS 时观察到的任何[[频移|频率偏移]]均源于其与 IONCs 的结合。补充图 8 详细展示了具有不同[[表面包覆层|表面涂层]]（[[25 kDa聚乙烯亚胺|PEI25k]]、[[10 kDa聚乙烯亚胺|PEI10k]] 和 [[十六烷基三甲基溴化铵|CTAB]]）的 IONCs 对 PFOA 和 PFOS 的[[吸附等温线]]，其通过 [[耗散型石英晶体微天平|QCM-D]] 测得的单位 IONC 质量所[[吸附]]的质量计算得到。最初通过 [[耗散监测石英晶体微天平|QCM-D]] 计算得到的吸附[[密度]]相对低于[[批量吸附试验]]的结果。根据我们此前的研究，与某些[[聚合物]]相关联的[[吸附水]]释放时可引起[[频率]]偏移，从而使[[吸附质]]结合量的测量复杂化<sup>58</sup>。为解决这一问题，我们根据计算得到的与 IONCs 相关联的水的质量，建立了校正因子。图 2 展示了通过批量吸附法以及采用上述校正因子的 QCM-D 方法测定的 IONCs 对 PFAS 的吸附等温线。总体而言，校正后的 QCM-D 实验吸附数据（点线）在趋势和数值上均与批量吸附结果相近，这凸显了 QCM-D 作为一种强大工具，可用于实时量化和比较相对[[吸附行为]]。

## [[全氟和多氟烷基物质|PFAS]] [[官能团]]对[[吸附行为]]的关键作用

具有[[羧基]][[头基]]的 [[全氟辛酸|PFOA]] 对带正电的 [[IONCs]] 的[[亲和力]]高于 [[全氟辛烷磺酸|PFOS]]，因此其 [[Langmuir吸附常数|Langmuir 吸附常数]]（k）更高。相比之下，由于 PFOS 的[[磺酸基]]使其整体亲和力低于 PFOA，其 k 值相对较低；然而，PFOS 具有三种不同的[[共振结构]]，综合而言，这些结构使其整体相互作用更为有利。为直接探究这一点，我们通过 [[耗散型石英晶体微天平|QCM-D]] 分析，利用 [[Voigt模型|Voigt 模型]]展示了不同 [[全氟和多氟烷基物质|PFAS]] 类型所形成的 PFAS 层厚度。在除 PFAS 类型之外的所有变量（[[氧化铁纳米晶体|IONC]]、[[水化学|水化学条件]]等）均保持不变的情况下，图 4 显示，PFOA 与 PFOS [[吸附层厚度|吸附层的厚度]]相差约 5 埃 $( \mathring { \mathsf { A } } ) ,$，表明[[吸附]]态 PFAS 的取向因[[官能头基]]而异。对于这两种物质，由于磺酸基的共振结构，PFOS 在 [[超顺磁性氧化铁纳米晶|IONCs]] 表面上平均而言可能更倾向于垂直排列，而 PFOA 平均而言则更倾向于水平排列，所观察到的[[最大吸附容量|最大吸附量]]也支持这一点（即垂直取向的 PFOS 可实现更高的[[吸附密度]]）。PFOA 与 PFOS 之间[[吸附取向]]的差异，也可能通过[[空间位阻]]和/或[[活性位点]]与反应性材料表面之间的距离，导致 PFOS 相对更难降解。

## [[水化学|水化学条件]]对 [[全氟和多氟烷基物质|PFAS]] [[吸附行为]]的影响

为了解[[水化学|水化学条件]]如何影响 [[全氟和多氟烷基物质|PFAS]] 的[[吸附行为]]，我们使用 $\mathsf { F e } _ { 3 } \mathsf { O } _ { 4 } @ \mathsf { P E } \mathsf { l } 2 5 \mathsf { k }$，评估了[[pH|溶液 pH]]、[[离子强度]]和类型以及水中 [[天然有机质|NOM]] 对 PFAS [[吸附]]的影响。图 $5 \mathsf { a } ,$ b 显示，与预期一致，酸性（pH 4.0）和中性（pH 7.0）条件下的[[吸附密度]]均高于碱性条件（pH 10.0）。[[全氟辛酸|PFOA]] 在 pH 4.0、pH 7.0 和 pH 10.0 下的[[最大吸附容量]]分别为 14.7 mmol $\mathfrak { g } ^ { - 1 }$、18.3 mmol $\mathfrak { g } ^ { - 1 }$ 和 9.2 mmol $\mathfrak { g } ^ { - 1 }$，而 [[全氟辛烷磺酸|PFOS]] 的最大[[吸附容量]]分别为

[[pH]] 4.0 下的 58.8 mmol $\mathfrak { g } ^ { - 1 }$、pH 7.0 下的 83.5 mmol $\mathfrak { g } ^ { - 1 }$ 和 pH 10.0 下的 38.5 mmol $\mathfrak { g } ^ { - 1 }$。在较高 pH 下观察到的[[吸附]]量下降归因于[[ζ电位|表面 zeta 电位]]降低，从而降低了其对带负电 [[全氟和多氟烷基物质|PFAS]] 分子的[[静电亲和力]]（补充图 9）。我们还观察到，与中性 pH（pH 7）相比，较低 pH（pH 4）下的[[最大吸附容量]]有所下降。正如其他研究所报道的，酸性条件会影响 PFAS 的吸附<sup>61</sup>。在此，[[Zeta电位|zeta 电位]]的净下降（从 pH 7 降至 pH 4 时约下降 14%）可能是 pH 4 下（最大）[[吸附容量]]较低的原因之一。

还评估了[[离子强度]]和[[离子类型]]对 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的影响，采用的方法为 $\mathsf { F e } _ { 3 } \mathsf { O } _ { \angle }$ 通过在 [[pH]] 7 条件下开展[[批量吸附实验]]，考察了 @[[25 kDa聚乙烯亚胺|PEI25k]] [[纳米晶|NCs]]。此处评估了 [[氯化钠|NaCl]]、CaCl、MgCl 以及[[合成地下水]]（SGW）的影响，并与[[超纯水]]（UPW）进行了比较。合成[[地下水]]按照他人所述方法<sup>62</sup>配制，其组成汇总于补充表 3。如图 5c、d 所示，在所有受评估盐及合成地下水存在的条件下，[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的[[吸附容量]]均有所降低。观察到 PFOA 的[[最大吸附密度]]分别为 18.3、5.7、5.1、5.7 和 14.3 mmol $\mathfrak { g } ^ { - 1 }$ 对于超纯水、NaCl， $\mathsf { C a C l } _ { 2 } ,$ 分别为 MgCl 和合成地下水，以及 83.5、54.3、69.0、73.7 和 31.5 mmo $\mathsf { \bar { g } } ^ { - 1 }$ 对于超纯水、NaCl 中的 PFOS， $\mathsf { C a C l } _ { 2 } ,$ 分别为 MgCl 和合成地下水。我们观察到离子种类对 PFAS 吸附性能的竞争效应，其中，与……相比，NaCl 表现出相似或更强的抑制作用 ${ \mathsf { C a C l } } _ { 2 }$ 和 ${ \sf M g C l } _ { 2 } .$ 这是 这可能是由于[[反离子]]（此处为[[阴离子]]）对带正电的 [[IONCs]] 产生了竞争效应：在相同离子强度下，NaCl 中反离子（Cl<sup>–</sup>）的浓度高于[[二价阳离子盐]] $( \mathsf { C a C l } _ { 2 }$ 和 MgCl ）中的反离子浓度。尽管存在这些干扰，该材料在实际条件下的性能仍显著优于其他已报道的、仅在纯水条件（即最佳情形）下进行考察的[[吸附剂]]，见表 1。对于所有接受评估的[[悬浮液]]，在任何受评估条件下均未观察到 [[纳米晶体聚集|IONC 聚集]]（补充图 10），从而最大限度地减小了[[表面积]]损失这一[[混杂因素]]对性能的影响。

在存在 [[天然有机质|NOM]]（0–0.5 mg/L）的情况下，[[全氟和多氟烷基物质|PFAS]] 的[[吸附容量]]也有所下降。为量化这一过程，我们通过 [[耗散型石英晶体微天平|QCM-D]] 分析评估了[[腐殖酸]]（HA）浓度对[[吸附密度]]的影响。如补充图 11 所示，[[吸附]][[密度]]随 HA 浓度的增加而降低。HA 具有较大的[[阳离子交换容量]]，容易在[[溶液体相]]中与 PFAS 竞争 [[IONCs]] 上的带正电[[活性位点]]，其他研究者也在带负电污染物的吸附中观察到了这一现象<sup>63,64</sup>。

## [[柱实验]]中 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的[[污染物固定|固定]]

为展示其应用潜力，图 6 给出了将含 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的溶液注入填装有经 [[IONCs|IONC]] 处理的 [[Ottawa砂|Ottawa 砂]]的柱后获得的[[出水穿透曲线]]。在 PFOA [[柱实验]]中，通入含 100 µg/L PFOA 和 10 mmol/L [[氯化钠|NaCl]] 的溶液，持续通入 10 个[[孔隙体积]]（PVs），出水样品中均未检出 PFOA。为评估[[IONC处理砂|经 IONC 处理的砂]]的[[极限吸附容量]]，随后将进水 PFOA 浓度提高至 10 mg/L（被认为是极高的环境 [[全氟和多氟烷基物质|PFAS]] 浓度），在通入 \~31 PVs 后检出 PFOA。PFOA 浓度稳步上升，在通入 39 PVs 后，[[相对浓度]]（C/C ）达到 0.83，并在通入 49 PVs 时达到进水浓度 $( \mathsf { C } / \mathsf { C } _ { 0 } = 1 )$（图 6a）。整个实验过程中共截留 5.16 mg PFOA，相当于每克 [[氧化铁纳米晶体|IONC]] 截留 5.37 mmol/L PFOA（柱中 [[超顺磁性氧化铁纳米晶|IONC]] 总量为 2.34 mg），与[[批量吸附实验]]结果一致。

在 [[全氟辛烷磺酸|PFOS]] [[柱实验]]中，先通入含 100 µg/L PFOS 的 10 mmol/L [[氯化钠|NaCl]] 溶液，持续 \~10 [[孔隙体积|PVs]]，柱出水中未检测到 PFOS。与 [[全氟辛酸|PFOA]] 柱实验类似，随后将进水溶液中的 PFOS 浓度提高至 10 mg/L，在通入 \~23 PVs 后，出水中开始检测到 PFOS，其浓度持续升高，并在 39 PVs 后达到进水浓度 $( \mathsf { C } / \mathsf { C } _ { 0 } = 1 )$（图 6b）。总体而言，经 [[IONCs|IONC]] 处理的柱中共截留了 6.34 mg PFOS，相当于每 g [[氧化铁纳米晶体|IONCs]] 截留 5.18 mmol/L PFOS（柱内 [[超顺磁性氧化铁纳米晶|IONCs]] 总量为 2.45 mg），这也与批次实验结果一致。与使用洁净的 40–50 目 [[Ottawa砂|Ottawa 砂]]开展的[[对照柱实验]]相比，经 IONC 处理的柱对 PFOA 或 PFOS 的截留量（因而处理能力）提高了三个数量级以上，表明其具有作为[[原位处理工艺]]中新型[[吸附]]材料的潜力。

## 方法

## 有机（[[表面功能化|表面）功能化]] [[IONCs]] 的制备

按照先前描述的方法，通过[[铁前驱体]]的[[高温分解]]合成[[氧化铁纳米晶体]]（[[IONCs]]）<sup>65</sup>。随后采用[[探头超声]]，通过[[配体交换]]和[[包封]]方法，使用不同的[[有机表面活性剂]]对合成的[[纳米晶体]]（[[纳米晶|NCs]]）进行[[表面功能化|功能化]]<sup>66,67</sup>。使用[[支化聚乙烯亚胺|支化 PEI]]、[[十六烷基三甲基溴化铵|CTAB]] 和 [[油酸|OA]] 作为表面稳定剂。将 0.4 mL NCs 的己烷溶液与特定量的表面稳定剂加入 5 mL [[超纯水]]（18.2 MΩ·cm，Millipore）中，使用探头式超声仪（UP50H，Hielscher）在 80% 振幅和全周期模式下处理 10 min，使其混合。将溶液置于通风橱中 24 h，以去除溶液中残留的己烷。为去除过量的[[表面活性剂]]，在搅拌条件下使用超滤膜（[[纤维素]]，100 kDa MWCO，Millipore）过滤溶液，随后使用[[针式过滤器]]（0.22 μm PES，Millipore）过滤。采用电感耦合[[等离子体]]质谱法（ICP-MS，Elan DRCe，Perkin Elmer）测定水中功能化 [[超顺磁性氧化铁纳米晶|IONCs]] 的浓度。

## [[吸附等温线]]

在不同 [[pH]] 条件（4.0、7.0 和 $1 0 . 0 \pm 0 . 2 )$ 下，使用工程化 [[IONCs]]（10 mg/L [[纳米晶|NC]]）进行 [[全氟和多氟烷基物质|PFAS]] [[吸附测试]]，其中 [[全氟辛酸|PFOA]] 浓度范围为 0.01 至 0.2 mmol/L，[[全氟辛烷磺酸|PFOS]] 浓度范围为 0.01 至 0.6 mmol/L。[[吸附]]测试开始后，立即使用 ${ \mathsf { H N O } } _ { 3 }$ 和 [[氢氧化钠|NaOH]] 调节溶液 pH，并在实验过程中（4 h 后）再次调节和/或确认 pH。[[吸附平衡|达到平衡]]后（24 h 后），使用[[超速离心机]]（[[Sorvall WX 80]]，[[Thermo Scientific]]）以 50,000 rpm [[离心分离|离心]] $^ { 2 \mathsection }$，分离 [[纳米晶体|NCs]]，并通过[[超高效液相色谱仪]]（[[超高效液相色谱串联质谱法|UPLC-MS/MS]]）（[[Waters Corporation]]，Milford，MA）测定 PFAS 的剩余浓度。PFAS [[定量分析]]的详细步骤见补充信息。以 PFAS [[平衡浓度]]（mmol/L）为自变量，分别采用 [[Langmuir模型|Langmuir]] 和 [[Freundlich吸附等温线|Freundlich 吸附等温线]]拟合实测[[吸附密度]]（样品中单位质量 NCs 吸附的 PFAS 的毫摩尔数）。[[Langmuir吸附等温线|Langmuir 等温线]]由下式得到：

$$
q _ {e} = \frac {q _ {\max} k C _ {e}}{(1 + k C _ {e})}\tag{1}
$$

b

![](<../2.SCI_MD/Ultra-high capacity, multifunctional nanoscale sorbents for PFOA and PFOS treatment/images/e2900b2220c6146840daa8792d89730902a11b84cc7f910b38d381e59056209b.jpg>)  
图 6 台架规模处理效果评估。填装经 IONCs（2.9 mg）处理的 40–50 目 Ottawa 砂（80 g）的柱中，a PFOA 和 b PFOS 的出水穿透曲线。

其中，$q _ { e }$ 为[[平衡吸附密度]]（mmol/g），$q _ { \mathrm { m a x } }$ 为[[最大吸附密度]]，k 为 [[Langmuir吸附常数|Langmuir 吸附常数]]（L/mmol），$C _ { e }$ 为 [[全氟和多氟烷基物质|PFAS]] 的[[平衡浓度]]（mmol/L）。[[Freundlich吸附等温线|Freundlich 等温线]]则按下式确定：

$$
q _ {e} = K C _ {e} ^ {1 / n}\tag{2}
$$

其中，K 和 n 为 [[Freundlich吸附常数|Freundlich 吸附常数]]。在 [[pH]] 7 条件下开展[[竞争吸附|竞争吸附实验]]，[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的[[初始浓度]]均为 0.02 至 0.1 mmol/L。我们对溶液 pH 进行了两次调节，其他实验条件和步骤与单一[[吸附质]]的[[吸附等温线]]测试相同。

## [[耗散型石英晶体微天平]]（[[耗散监测石英晶体微天平|QCM-D]]）

我们使用[[耗散型石英晶体微天平]]（[[耗散监测石英晶体微天平|QCM-D]]，[[Q-sense E4]]，[[Biolin Scientific]]），测量[[二氧化硅涂层石英晶体传感器|二氧化硅涂层 Q 传感器]]（[[QSX-303]]，[[Qsense]]）的[[频率]]（f）和[[能量耗散]]（D）。通过测量晶体的[[频率偏移]]，并使用如下所示的 [[Sauerbrey方程|Sauerbrey 关系式]]，确定晶体表面单位面积上的[[沉积质量]]（Δm）：

$$
\Delta m = - \frac {C}{n} \Delta f _ {n}\tag{3}
$$

其中，C 为[[晶体常数]]（对于 5 MHz [[石英晶体]]，为 17.7 ng/(cm<sup>2</sup>·Hz)），n 为[[泛音阶数]]（1、3、5、7、9、11 和 13），$\Delta f _ { \mathrm { n } }$ 为第 n 阶[[泛音]]的[[频率偏移]]。考虑到仪器的稳定性，本研究采用[[第三阶泛音]]进行数据分析。在所有测量中，我们将[[溶液流量]]保持在 0.1 mL/min，并将仪器内部温度保持在 $2 0 . 0 ^ { \circ } \mathsf { C } .$

## 通过 [[耗散型石英晶体微天平|QCM-D]] 研究确定 [[全氟和多氟烷基物质|PFAS]] 的[[吸附行为]]

采用 [[耗散型石英晶体微天平|QCM-D]] 按照以下顺序获取实时[[频率]]变化，以确定 [[全氟和多氟烷基物质|PFAS]] 在 [[IONCs]] 上的[[吸附等温线]]。首先，将带正电的 [[氧化铁纳米晶体|IONCs]]（[[聚乙烯亚胺|PEI]] 和 [[十六烷基三甲基溴化铵|CTAB]] [[表面包覆|包覆]]）引入[[石英晶体传感器]]。如补充图 4 所示，我们通过考察较宽范围的 [[纳米晶|NC]] 浓度，确定了表面 NC 的[[表面覆盖量|最大覆盖量]]。用 NC 溶液使传感器表面[[吸附饱和]]，持续 20 min，随后通入[[超纯水]]，使其稳定并去除与 Q 传感器结合松散的 [[纳米晶体|NCs]]。稳定后，引入 PFAS 溶液，传感器上 [[超顺磁性氧化铁纳米晶|IONCs]] 所[[吸附]]的 PFAS 质量引起了额外的频率变化。吸附等温线根据沉积在 Q 传感器上的 PFAS 和 IONCs 的质量确定，这些质量通过 [[Sauerbrey方程|Sauerbrey 方程]]由频率变化计算得到。

## [[QCM-D校正因子|QCM-D 校正因子]]

为补偿水分子附着于 [[石英晶体传感器|Q 传感器]]而导致 [[耗散型石英晶体微天平|QCM-D]] 测量低估[[吸附容量]]的影响，我们对[[吸附密度]]应用了 [[QCM-D校正因子|QCM-D 校正因子]]。[[耗散监测石英晶体微天平|QCM-D]] 校正因子按如下方法计算。

$$
\mathrm{QCM} - \mathrm{D} \text { factor } = \frac {\text { Mass   of   (NCs } + \text { Water) }}{\text { Mass   of   NCs }}\tag{4}
$$

[[吸附水]]的质量通过计算 [[纳米晶核心尺寸|NC 核心尺寸]]与[[水动力学直径|流体动力学直径]]所对应的体积之差，再乘以水的[[密度]]得到。

## [[石英晶体传感器|Q 传感器]]上[[沉积层厚度|沉积层的厚度]]

通过 [[Voigt模型|Voigt 模型]]分析所记录的 Δf 和 ΔD 数据，计算[[沉积层厚度|沉积层的厚度]]<sup>68</sup>。所得厚度（δ）由下式求得。

$$
\delta = \sqrt {\frac {2 \eta_ {0}}{\omega \rho_ {0}}}\tag{5}
$$

其中，η 为[[剪切黏度]]，ω 为[[角速度]] $( \omega = 2 \pi \hbar ) ,$，$\rho$ 为[[密度]]。

## [[柱实验]]

开展[[柱实验]]，以量化动态流动条件下 [[IONCs]] 对 [[全氟辛酸|PFOA]] 或 [[全氟辛烷磺酸|PFOS]] 的[[吸附]]。将 [[氧化铁纳米晶体|IONCs]] [[悬浮液]]（20 mL，145 mg/L）与 80 g、40–50 目的 [[Ottawa砂|Ottawa 砂]]混合，并在 60 °C 下干燥 48 h。随后，将含有 \~2.9 mg [[超顺磁性氧化铁纳米晶|IONC]] 的[[IONC处理砂|经 IONC 处理的砂]]以每层 1 cm 的方式装填至[[硼硅玻璃柱]]（内径 2.5 cm × 长度 10 cm）中，用 [[一氧化碳|CO 气体]]冲洗 1 h，再以 1.0 mL/min 的流速通入[[脱气]]的[[背景电解质溶液]]（10 mmol/L [[氯化钠|NaCl]]），使其饱和。[[水饱和]]柱的[[孔隙体积]]（PV）为 \~20.5 mL。每根柱达到水饱和后，使用 [[Chrome Tech P-010]] [[等度泵]]（Apple Valley, MN），以 0.12 mL/min 的流速依次注入 3.5 PV 的 10 mmol/L [[溴化钠|NaBr]] 和 3.5 PV 的 10 mmol/L NaCl，进行[[非反应性示踪剂试验]]；该流速对应的[[孔隙水流速]]为 \~1 m/day。柱实验装置示意图见补充图 12。

为评估[[IONC处理砂|经 IONC 处理的砂]][[污染物固定|固定]] [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的能力，将含有 PFOA（100 µg/L）或 PFOS（100 µg/L）的 10 mmol/L [[氯化钠|NaCl]] 水溶液以 0.12 mL/min 的流速注入柱中。在 \~10 [[孔隙体积|PV]] 后，将进水中的 PFOA 或 PFOS 浓度从 100 µg/L 提高至 10 mg/L，以确定 [[IONCs]] 的[[最大吸附容量]]。使用 Spectra/Chrom® CF-2 [[馏分收集器]]（[[Spectrum Chemical Mfg. Corp.]], New Brunswick, NJ）连续收集出水样品，以监测 [[吸附穿透|PFAS 的穿透]]。出水样品经 0.45 µm [[GE Healthcare]] Whatman™ GD/X [[玻璃微纤维]]（GMF）[[针式过滤器]]（GE Healthcare, Chicago, IL）过滤，并稀释至适当的浓度范围，然后使用 Waters Xevo<sup>TM</sup>

[[Waters Xevo TQ-S micro|TQ-S Micro]] [[三重四极杆质谱仪]]（[[液相色谱串联质谱法|LC–MS/MS]]）进行分析，具体方法见补充信息。
