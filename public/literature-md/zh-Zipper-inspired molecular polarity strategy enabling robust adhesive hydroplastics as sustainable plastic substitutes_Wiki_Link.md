# 拉链启发的[[分子极性]]策略赋予[[水塑性塑料]]高强[[黏附性能]]，使其成为可持续塑料替代品

在线发表日期：2026年3月25日

[[Guozhuo Chen]]<sup>1</sup>, [[Chengling Huang]]<sup>1</sup>, [[Yanjuan Dong]]<sup>1</sup>, [[Yi Zheng]]<sup>1</sup>, [[Yi Chen]]<sup>1</sup>, [[Kam Chiu Tam]] <sup>2</sup> & [[Hou-Yong Yu]] <sup>1</sup>

具有[[水增塑效应]]和可编程性的[[水塑性塑料]]（hydroplastics）备受期待，但将可[[再生纤维素]]组装成兼具[[可逆黏附性]]、且可通过[[水增强效应]]提升[[力学性能]]的水塑性塑料，仍面临挑战。在此，受拉链启发，我们利用[[硫辛酸]]（thioctic acid，[[TA]]）调控分子尺度的[[分子极性|极性]]，并结合水所形成的极性失衡环境下的[[分子网络重构]]，解决了水分子难以提升水塑性塑料综合性能的问题。该方法可制备透明[[纤维素水塑性材料|纤维素水塑性塑料]]（[[透明度]]为91%），其力学性能可在[[水合–脱水循环]]后增强至203 MPa，超过大多数[[纤维素]]水塑性塑料。此外，与传统纤维素水塑性塑料不同，该水塑性塑料表现出优异的[[水诱导可逆黏附性]]（最高达37 MPa）和快速可编程性（5分钟）。这些独特的性能优势为自上而下利用纤维素制备高性能多功能水塑性塑料开辟了一条独特途径，致力于替代传统塑料并减少石油化工资源的消耗。

数十年来，人类社会与自然环境一直深受能源短缺和“[[白色污染]]”这两大世界性问题的困扰。传统[[石油基塑料]]的年产量已超过3.907亿吨，其中仅有15%得到[[回收利用]]，对环境构成了严重威胁<sup>1–4</sup>。相比之下，[[纤维素]]作为储量最丰富的可再生[[生物聚合物]]，其年生成量可高达7500亿吨<sup>5</sup>，约为塑料产量的\~2000倍。纤维素因其[[生物相容性]]、[[热稳定性]]和[[可降解性]]，被认为是石油基塑料的理想替代材料<sup>6–8</sup>。传统[[纤维素塑料]]的分子结构富含[[羟基]]，可实现[[氢键]]驱动的组装<sup>9</sup>。然而，其固有的[[结晶性]]和[[难熔性]]使其无法像传统[[热塑性塑料]]或[[热固性塑料]]那样具有优异的[[力学性能]]和[[变形加工]]性能，因而难以拓展至其他应用领域<sup>6,10–13</sup>。

近期提出了一些策略，通过引入[[增塑剂]]或[[功能改性剂]]来破坏致密的[[氢键网络]]，从而克服[[纤维素塑料]]的固有局限，使其具备[[热封性]]或水诱导的[[形状编程|形状可编程性]]<sup>14–17</sup>。尽管这些方法在[[力学性能]]（通常 <120 MPa）和形状可编程性方面取得了一定程度的改善，但往往存在能耗高（例如热加工）或编程性能受限的问题，后者依赖于水合–脱水循环过程中基于曲率变化的形状重塑<sup>18,19</sup>。因此，这些[[纤维素]]塑料在综合性能方面仍不足以与传统[[热塑性塑料]]相媲美。更为关键的是，大多数[[纤维素水塑性材料]]主要依赖可逆[[氢键]]，并将水视为增塑剂（一种用于[[溶胀]]和软化的介质），而在很大程度上忽视了具有更高稳定性和强度的[[动态共价键]]的潜力<sup>18,20,21</sup>。遗憾的是，水在这些[[水塑性塑料|水塑性材料]]中的作用仍局限于宏观的“溶胀–软化–成型”过程，未能利用其在分子层面诱导[[分子网络重构|网络重构]]的能力，例如在[[水合–脱水循环]]过程中促进[[聚合物链重排]]或[[交联]]再生<sup>18,22</sup>。因此，亟需开发一种能够同时保留[[水增塑效应|水的增塑作用]]及其增强作用的策略，以实现高性能[[再生纤维素]]水塑性材料的制备<sup>20,21</sup>。

传统[[纤维素水塑性材料]]吸水并保留大量结合水，从而表现出显著的[[溶胀|溶胀行为]]<sup>23</sup>。[[纤维素–水相互作用]]受到[[纤维素]]分子结构网络的影响<sup>20</sup>。[[纤维素链]]包含交替排列的[[分子极性|极性]]（–C[[羟基|–OH]]）和非极性（–CH₂）基团<sup>24</sup>。由于水分子具有强极性，其相互作用遵循[[偶极–偶极相互作用|偶极–偶极吸引]]原理（Keesom 效应）<sup>25</sup>。通过引入高极性基团和非极性基团，可以破坏纤维素中的[[氢键网络]]。极性环境的变化（从[[水合]]到[[脱水]]）驱动分子网络平衡的破坏。严重失衡促使[[分子链重排]]并重新组装，以达到一种独特的平衡状态，从而实现[[水塑性塑料|水塑性材料]]的增强效应。然而，对此类[[水增强效应|水诱导增强机制]]的探索仍处于起步阶段，现有策略尚未满足高强韧、多功能[[纤维素塑料]]在结构和性能方面的要求。

拉链闭合时紧密，打开时松散。在此，为应对使用水作为增强剂以及构建高强度[[纤维素水塑性材料]]所面临的挑战，我们提出了一种受拉链启发的策略，通过引入高[[分子极性|极性]]基团（[[羧基]]，-COOH）和[[动态共价键]]（[[二硫键|S-S]]）来构建[[极性梯度网络]]，从而实现[[塑化]]路径，并赋予水在[[水塑性塑料|水塑性材料]]中的增强作用。在水所营造的极性不平衡环境下，内部网络发生重构和重新[[交联]]。因此，在[[水合–脱水循环]]下，获得了具有高[[机械强度]]（203 MPa）、高[[模量]]（8 Gpa）和[[可逆黏附性]]（37 MPa）等优异性能的超强[[纤维素]]水塑性材料（[[CCMA]]）。本研究有望深化对分子尺度上[[纤维素–水相互作用]]机制的理解，并为构建高性能纤维素水塑性材料提供一种前景广阔的[[极性梯度]]策略，向减少对不可降解[[石油基塑料]]依赖的目标迈进一步。

## 结果与讨论

## [[分子极性|极性]]驱动的 [[CCMA 水塑性塑料|CCMA 水塑性材料]]的设计策略

为获得兼具超强[[力学性能]]和[[黏附性能]]的[[纤维素水塑性材料]]，我们开发了一种独特的分子设计策略。利用热诱导的 [[TA]] [[二硫杂环戊烷]]环[[开环聚合]]，通过动态 [[二硫键|S-S 键]]重组生成线性链<sup>26,27</sup>，随后将其[[接枝]]到[[纤维素]]前体（[[CCM]]，即[[肉桂基团接枝纤维素|接枝肉桂基团的纤维素]]）上（图 1a、b）。所得 [[CCMA 水塑性塑料|CCMA 水塑性材料]]可通过可规模化的[[溶液浇铸|溶液浇铸工艺]]制备（补充图 1），得到高度透明且柔韧的[[水塑性塑料|水塑性材料]]（图 1c）。通过[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）观察到平整、致密的层状横截面（图 1d 和补充图 2）。此外，[[能量色散X射线谱|EDS]]、能谱分析（[[FTIR]] 和 [[核磁共振|NMR]]）以及 [[XPS]] 证实，[[α-硫辛酸|TA]] 以共价方式整合到 [[CCMA水塑性材料|CCMA 水塑性材料]]的网络中（补充图 3–6）。关键的是，[[傅里叶变换红外光谱|FTIR 光谱]]显示 [[CCMA-2]] 的[[氢键比例]]（F）为 0.69（补充图 7 和 8），凸显了 [[硫辛酸|TA]] 在构建动态致密网络中的作用。

值得注意的是，[[热分析]]（补充图 9 和 10）进一步证实了 [[CCMA 水塑性塑料|CCMA 水塑性材料]]的稳定性，其分解产物主要为 $\mathsf { H } _ { 2 } \mathbf { O } , \mathbf { C } \mathbf { O } _ { 2 }$ 和 [[羰基|C=O]] 碎片。其气体释放特性丰富，且 [[CCMA水塑性材料|CCMA 水塑性材料]]复杂的分解行为表明其具有更为独特的功能性<sup>28</sup>。

在分子层面（图 1e、f），[[TA]] 的引入形成了一个含有多种[[分子极性|极性]]基团的网络（[[极性梯度网络]]），其中包括[[纤维素]]的[[羟基]]、[[α-硫辛酸|TA]] 的 [[羧基|-COOH]] 以及水分子。在[[偶极–偶极相互作用|偶极–偶极吸引作用]]（Keesom 效应）下，水分子与羧基等高极性区域相互作用，诱导网络在[[水合–脱水循环]]过程中发生变化（图 1g）。

因此，我们利用受拉链启发的设计策略，实现了水分子对分子网络的增强作用，从而获得了独特的性能（图 1h）。具体而言，水如同一把钥匙，通过打开并软化分子网络实现[[塑化]]。此外，在不均衡的[[分子极性|极性]]环境驱动下，水在[[脱水]]过程中使分子网络发生重排，将其转变为高度有序且稳定的状态。通过[[分子网络重排]]，可以增强 [[CCMA 水塑性塑料]]的[[力学性能]]，并实现黏附和[[形状编程]]（图 1i）。此外，与其他[[水塑性塑料]]相比，[[CCMA水塑性材料|CCMA 水塑性塑料]]在可持续塑料替代方面具有更大的潜力（图 1j 和补充表 1）。

## 建立平衡过程中的[[分子网络重排]]与 [[二硫键交联|S-S 交联]]

为进一步阐明[[拉链模型]]的机制，我们开展了更多研究。如图 3a 和补充图 20 所示，[[CCMA 水塑性塑料|CCMA 水塑性材料]]的长度和宽度在[[脱水]]过程中均收缩了约 6.7%。这种收缩现象归因于水分蒸发过程中产生的弹性[[毛细力]]，这些力产生强大的回缩力，将分子链拉至紧密接触的状态——这一过程称为物理塌缩<sup>39</sup>（图 3b）。[[羧基]]（-COOH）和[[羟基]]（-OH）区域的同步 PCMW 图像显示，显著的光谱强度变化主要发生在干燥早期阶段（图 3c 和补充图 S21，<150 s）。这表明，[[动态氢键]]演化主要发生在干燥初始阶段，且在分子链回缩过程中，羧基之间发生二聚体[[交联]]。此外，[[CCMA水塑性材料|CCMA 水塑性材料]]的蠕变应变曲线在脱水 300 秒后趋于稳定，表明内部 [[二硫键共价网络|S-S 网络]]限制了 [[CCMA]] 的无序收缩（图 3a）。因此，观察到的收缩率仅为 6.7%。此外，储能[[模量]]（E’）表明，在 $2 0 0 ^ { \circ } \mathrm { C } ,$ 时，CCMA [[水塑性塑料|水塑性材料]]仍保持着比 [[CCM 塑料|CCM 薄膜]]更高的模量，说明 [[TA]] 的存在也能在[[氢键网络]]弱化时防止结构塌缩（图 3d）。另外，Tan δ 曲线（补充图 22）显示，CCMA 在 $1 2 0 ^ { \circ } \mathrm { C }$ 与 $2 0 0 ^ { \circ } \mathrm { C }$ 之间呈现宽峰，表明 [[二硫键|S-S]] 网络限制了分子运动。此外，与常规 [[聚乙烯|PE]]（聚乙烯）塑料相比，CCMA 水塑性材料在高达 $2 0 0 ^ { \circ } \mathrm { C } ,$ 的温度下仍能保持原始尺寸，显示出其优异的[[热稳定性]]（补充图 23）。

## [[水增强效应]]下的[[力学性能]]提升与[[形状编程]]

为研究[[拉链模型]]对 [[CCMA 水塑性塑料|CCMA 水基塑料]]强度和[[韧性]]的影响，我们开展了广泛的[[力学测试]]。[[TA]] 的引入增大了[[纤维素网络]]的[[结晶区域]]<sup>41</sup>（补充图 27）、[[交联密度]]（补充表 4）、$\mathsf { F } _ { H \cdot O H }$（补充图 8）和 $\digamma _ { H \cdot C O }$（补充图 16）。因此，[[CCMA水塑性材料|CCMA 水塑性塑料]]表现出高达 177 MPa 的[[拉伸强度]]，比[[纤维素|原始纤维素]]高 52%（图 4a 和补充图 28）。然而，过量的 [[α-硫辛酸|TA]] 添加会因[[空间拥挤]]而破坏[[纤维素链]]的有序排列，导致[[分子不规则性]]降低（补充图 29 和补充表 4）。值得注意的是，这一强度处于动态变化之中。经过 10 次[[水合–脱水循环]]后，拉伸强度从 177 MPa 达到 203 MPa（图 4b），即使经过 40 次循环，仍保持[[力学稳定性]]（补充图 30）。其优异的[[力学强度]]超过了[[聚对苯二甲酸乙二醇酯]]（PET）和[[聚丙烯]]（PP）等传统塑料（图 4c，补充表 1）。

[[CCMA 水塑性塑料]]通过[[动态可逆性]]表现出优异的[[水可编程形状性能]]（图 4d）。水可使网络[[塑化]]以进行[[形状编程]]（补充图 31），而[[脱水]]则可在 5 分钟内固定特定形状。此外，[[CCMA水塑性材料|CCMA 水塑性塑料]]在不同温度下的[[吸水速率]]差异 $( 3 0 , 5 0 , 7 0 ^ { \circ } \mathrm { C } )$ 表明，水是维持其塑化状态的关键因素（补充图 32）。此外，[[CCMA]] [[水塑性塑料]]可在[[水合]]过程中被编程为复杂形状，且这些精细形态在[[水蒸发]]后保持不变（补充图 33）。

此外，由于水破坏了[[氢键网络]]，[[CCM 塑料|CCM 薄膜]]的[[湿态强度]]降至 20 MPa，而 [[CCMA 水塑性塑料]]则保持了 40–51 MPa 的优异湿态强度，同时[[伸长率]]有所提高（图 4e）。在高湿度条件下（80% 和 90% [[相对湿度|RH]]），[[CCMA水塑性材料|CCMA 水塑性塑料]]仍保持优异的[[拉伸强度]]（分别为 87.4 MPa 和 78.8 MPa）（补充图 34）。此外，[[CCMA]] [[水塑性塑料]]在长时间浸泡（14 天）过程中表现出稳定性。值得注意的是，干燥后其[[力学强度]]仍可提高至 200 MPa（图 4f，14 天）。这些现象表明，[[二硫键共价网络|S-S 共价网络]]确保 CCMA 水塑性塑料在对水不敏感（防止水引起的过度[[溶胀]]）的同时，又能对水产生响应（促进[[塑化]]和[[形状编程]]）。

重要的是，[[横向力学强度]]（图 4g，R 方向）与[[纵向强度]]（图 4b，L 方向）非常接近。纵向和横向[[力学性能]]的一致性源于[[脱水]]过程中网络在纵向和横向上的致密化（图 3a）。

为阐明这种增强现象背后的机制，我们开展了进一步测试。2D WAXD 图谱中增强的[[衍射强度]]（图 4h 和补充图 35）表明，更多的[[非晶区]]已转变为[[结晶区域|有序晶区]]。[[Hermann 取向因子]]（ƒ）的变化表明（图 4i），在反复[[水合–脱水循环]]过程中，分子链在水的诱导下[[自组装]]形成[[分子取向|高度取向]]的区域。这与 [[SEM]] 图像观察到的结果一致（补充图 36）。[[结晶度]]的变化进一步证实了这一特征（图 4j 和补充图 37）。与 [[CCM]] 相比，[[CCMA 水塑性塑料|CCMA 水塑性材料]]结晶度的提高表明，水在[[脱水]]过程中引导无序链段排列成有序晶域。此外，脱水后 $F _ { H - O H }$（补充图 38 和 39）及[[羰基峰面积比]]（图 2h）的增加也表明，分子链经历了[[塑化]]、致密化和稳定化过程。此外，在[[水合]]–脱水循环过程中，[[面内收缩]]和[[厚度方向膨胀]]使 [[CCMA水塑性材料|CCMA 水塑性材料]]的[[体积密度]]降低（图 4k）。这一现象表明，快速形成的 [[二硫键共价网络|S-S 网络]]有效防止了[[毛细力]]引起的垂直方向塌陷。因此，这些结果证实，[[水合作用|水合]]–脱水循环下的力学增强机制由[[网络致密化]]驱动，而网络致密化由内部毛细力、[[极性驱动的聚集]]以及 [[二硫键交联|S-S 再交联]]所诱导。

## [[CCMA 水塑性塑料]]的可加工性与[[可降解性]]演示

[[CCMA 水塑性塑料]]可通过[[溶液浇铸|溶液浇铸工艺]]进行大规模生产，形成大面积均匀透明的薄膜（图 6a），证实其与规模化生产工艺的兼容性。在密封应用领域，凭借优异的抗菌性能（补充图 43）、阻隔性能（补充图 44）和高[[透明度]]（图 1c），[[CCMA水塑性材料|CCMA 水塑性塑料]]可用作[[环保包装材料]]（补充图 45）。与水接触后，两片薄膜无需外加黏合剂或加热即可牢固黏结并密封（图 6b），这表明该材料有望成为[[石油基塑料]]包装的可持续、低能耗替代品。此外，与传统胶带相比，[[CCMA]] [[水塑性塑料]]在黏结过程中不会产生小尺寸颗粒（补充图 46），这充分说明了 CCMA 水塑性塑料用于包装的安全性。此外，CCMA 水塑性塑料表现出优异的修复能力。如图 6c 所示，在室温且无外加压力的条件下，仅需少量水即可有效修复断裂表面或受损基材。此外，CCMA 优异的抗紫外线性能使其在耐紫外线辐射材料领域具有很大的应用潜力（补充图 47 和补充表 6）。除静态应用外，CCMA 水塑性塑料还可用于软体机器人等动态柔性环境。图 6d–g 展示了将该材料集成到柔性界面中的效果，其中水响应特性可实现暂时性驱动。这种驱动源于 CCMA 的阻水性能，该性能使[[溶胀|局部溶胀]]和压力效应得以产生（补充图 44）。水的快速蒸发（5 分钟）通过[[二硫键|共价 S-S 键]]和[[氢键]]重排使这些运动状态稳定下来（补充图 48），从而实现柔性与刚性之间的平衡。

结合其可重编程能力和[[力学性能]]，[[CCMA 水塑性塑料]]作为传统[[石油基塑料]]的可持续替代品具有很大潜力。为展示这一点，图 6h 给出了一些经水塑形的 [[CCMA水塑性材料|CCMA 水塑性塑料]]消费品原型。此外，[[CCMA]] [[水塑性塑料]]可利用模具浇铸成特定形状（图 6i）。为更好地呈现传统塑料的形态，制备了更厚的 CCMA 水塑性塑料，并通过[[形状编程|水编程]]制成可承重挂钩和螺旋状防噎手柄（图 6j 和补充图 49）。此外，与其他[[工程塑料]]（如 [[聚丙烯|PP]] 和 [[聚乙烯|PE]] 塑料）相比，CCMA 水塑性塑料具有优异的土壤生物降解性（图 6k）。

## 不同质量比 [[CCMA 水塑性塑料]]的合成

通过在 [[N,N-二甲基乙酰胺|DMAC]]/[[氯化锂|LiCl]] 溶剂体系中搅拌溶解 [[微晶纤维素|MCC]] 来制备[[纤维素]]溶液。将 1.5 g MCC 加入 40 ml DMAC 和 3 g LiCl 中，在 $1 2 0 ^ { \circ } \mathrm { C }$ 下搅拌溶解。分别向纤维素溶液中加入相对于 MCC 为 1.3 当量的[[肉桂酰氯]]和[[吡啶]]，并在 $7 0 ^ { \circ } \mathrm { C }$ 下恒速搅拌 2 h，形成 [[CCM]] 溶液。采用[[溶液浇铸法]]形成 [[CCM 塑料|CCM]] 凝胶，然后用[[乙醇]]置换溶剂 1.5 h。风干 8 h 后得到 [[肉桂基团接枝纤维素|CCM]] 塑料。向 CCM 溶液（20 mL）中加入不同量的 [[α-硫辛酸]]（0.5、1、1.5 g），同时加入 0.5 wt% 的[[辛酸亚锡]]。含有不同质量 α-[[硫辛酸]]的 [[CCMA]] 溶液分别命名为 [[CCMA-1]]/2/3 溶液。在 $7 0 ^ { \circ } \mathrm { C }$ 下搅拌 3 小时，形成 [[CCMA 水塑性塑料|CCMA]] 溶液。通过浇铸制备 [[CCMA水塑性材料|CCMA]] 溶胶，并在室温（25 °C）下风干 8 小时，得到 CCMA [[水塑性塑料]]（CCMA-1/2/3）。

## 作为对照的 [[CCMC 塑料]]的制备

## 水蒸气透过（WVP）

将薄膜封装于一个 10 mL 样品瓶（有效面积：235 mm<sup>2</sup>）中，并在高压灭菌器内于 $1 2 0 ^ { \circ } \mathrm { C }$、110 kPa 下处理 10 min。当温度冷却至室温时，通过该体系的水蒸气透过过程几乎完成，随后称量瓶内冷凝水的质量。WVP 按下式计算<sup>42</sup>：

$$
\mathrm{WVP} = \Delta m / (t \times S \times P) \times e\tag{1}
$$

其中，Δm 为样品在时间 t（s）内的质量变化（kg），S 为测试面积（m<sup>2</sup>），e 为体系厚度（m），P 为饱和蒸气压（Pa）。

## X 射线衍射分析

$$
\mathrm{Crl} = \frac {I _ {\mathrm{ac}} - I _ {\mathrm{am}}}{I _ {\mathrm{ac}}} \times 1 0 0\tag{2}
$$

其中，$I _ { a c }$ 表示[[纤维素]]样品 [[XRD]] 衍射图谱中（020）峰的最大强度，即纤维素在 $2 0 ^ { \circ }$ 处的强度；$1 1 . \ I _ { a m }$ 表示（110）与（020）晶面之间的最低强度（Mahmud et al., 2019; Tran et al., 2020）。

## [[分子动力学模拟]]（MDS）

本研究中的所有[[分子动力学模拟]]均使用 [[Materials Studio|Materials Studio 2020]]<sup>45</sup> 软件进行，首先构建 [[CCM]] 和 [[CCMA]] 的[[分子模型]]。随后，使用 [[Forcite]] 模块<sup>46,47</sup>，以 [[COMPASS II力场|COMPASSII]]<sup>48</sup> 为[[力场]]优化分子结构，以释放体系[[内应力|内部应力]]。在[[几何优化]]过程中，[[能量收敛判据|最大能量变化收敛阈值]]、[[力收敛判据|最大力收敛阈值]]和[[位移收敛判据|最大位移收敛阈值]]分别为 0.001 kcal mol<sup>−1</sup>、0.5 kcal mol<sup>−1</sup> Å<sup>−1</sup> 和 0.015 Å。然后，在 0.0001 GPa 和 298 K 下，采用[[等温等压系综|恒压恒温系综]]（NPT）进行 140 ps 的动力学模拟，以检查[[密度涨落|密度波动]]过程，直至[[密度]]-时间曲线稳定。在 MDS 过程中，[[静电相互作用]]采用 [[Ewald求和法|Ewald 方法]]计算，[[范德华相互作用]]则采用[[基于原子的非键相互作用计算方法|基于原子的方法]]计算。动力学过程中采用精确的 [[Nosé–Hoover恒温器|Nose-Hoover]]<sup>49</sup> 控温模式和 [[Berendsen恒压器|Berendsen 控压模式]]。之后，对最终模拟结构进行 [[均方位移|MSD]]（均方位移）和 [[径向分布函数|RDF]] 分析。

[[结合能]]使用 [[Materials Studio]] 软件包中的 [[DMol³|DMol3]] 模块<sup>50–52</sup>计算，本研究选择了两个广义函数 [[PBE泛函|Perdew-Burke-Ernzerhof]] $( \mathsf { P B E } ) ^ { 5 3 - 5 5 }$。所有计算均在[[平面波基组]]框架下进行，并综合考虑计算效率与精度之间的平衡，采用[[双数值加极化基组|双数值加极化]]（DNP）基组<sup>50</sup>。在[[几何优化]]过程中，[[力收敛判据]]设为 $0 . 0 1 \mathrm { e V } \mathring { \mathbf { A } } ^ { - 1 }$，[[能量收敛判据]]设为 $1 \times 1 0 ^ { - 5 }$ Ha，以确保结构的稳定性和能量计算的准确性。结合能通过以下公式计算。

$$
E _ {b i n d i n g} = E _ {c o m p l e x} - \left(E _ {p a r t A} + E _ {p a r t B}\right)\tag{4}
$$

其中，$E _ { \mathrm { c o m p l e x } }$ 为体系中两个结构的总能量

在[[静电势]]（ESP）和[[前线分子轨道|分子前线轨道]]计算中，借助 [[Materials Studio]] 绘制了[[纤维素]]、${ \sf H } _ { 2 } { \sf O }$、[[TA]] 的初始结构。采用 [[DMol³|DMol3]] 模块中的 [[B3LYP泛函|B3LYP]] 方法和 [[6-311G(d,p)基组|6-311 G (d, p)]] 基组对各分子进行计算。所有[[几何优化]]和能量计算均使用 DMol³ 模块完成。为模拟潮湿环境，采用了以水为溶剂的[[COSMO溶剂化模型|连续溶剂化模型]]（COSMO）。局限性说明：应当承认，这些 [[DFT]] 计算模拟的是简化的[[分子模型]]。尽管它们能够提供有关相对[[结合亲和力]]的可靠定性趋势，但可能无法定量反映[[凝聚态|体相凝聚态]]的全部复杂性。

在[[偶极矩]]计算中，借助 [[Materials Studio]] 软件包绘制了 [[TA]] 的初始结构。采用 B3L $\mathbf { \boldsymbol { \Upsilon } } \mathbf { \boldsymbol { P } } ^ { 5 6 }$ 方法和 6-311 G $( \mathsf { d } , \mathsf { p } ) ^ { 5 7 }$ 基组对各分子进行计算。使用 [[Multiwfn]] 软件包分析 [[独立梯度模型|IGM]] [[等值面]]和 [[约化密度梯度|RDG]] [[散点图]]。使用 [[VMD]] 软件对分析后的数据进行可视化<sup>31,58</sup>。

## [[光学测试]]

根据 AATCC 183:2000 标准，使用 [[UV-2000F纺织品紫外线防护系数测试仪|UV-2000F 纺织品紫外线防护系数测试仪]]（[[Labsphere|美国 Labsphere 公司]]），通过以下公式计算[[紫外线防护系数]]（UPF）以及 [[长波紫外线|UVA]] 和 [[中波紫外线|UVB]] 辐射的[[紫外线阻隔率|阻隔百分比]]<sup>59</sup>：

$$
\text { UV   protection   factor(UPF) } = \frac {\int_ {2 8 0} ^ {4 0 0} E (\lambda) S (\lambda) \mathrm{d} \lambda}{\int_ {2 8 0} ^ {4 0 0} E (\lambda) S (\lambda) T (\lambda) \mathrm{d} \lambda}\tag{5}
$$

$$
\mathrm{UVAblocking} (\%) = 100 - \frac {\int_ {320} ^ {400} T (\lambda) \mathrm{d} \lambda}{\int_ {320} ^ {400} \mathrm{d} \lambda} (\%)\tag{6}
$$

$$
\mathrm{UVBblocking} (\%) = 100 - \frac {\int_ {280} ^ {320} T (\lambda) \mathrm{d} \lambda}{\int_ {280} ^ {320} \mathrm{d} \lambda} (\%)\tag{7}
$$

其中，E (λ) 为[[红斑作用光谱|相对红斑光谱效能]]，S (λ) 为[[光谱辐照度]] $( \mathsf { W } \mathsf { m } ^ { - 2 } \mathsf { n m } ^ { - 1 } )$，dλ 为[[光谱带宽|带宽]]，λ 为[[波长]]。

## [[水溶胀测试]]

裁取样品（2 cm × 2 cm），随后放入 $8 0 ^ { \circ } \mathrm { C }$ 的[[烘箱]]中烘干 8 h。干燥后，使用[[分析天平]]称量各薄膜样品的初始质量。记录后，将各样品置于[[去离子水]]中浸泡 48 h。随后，使用分析天平测量薄膜样品的质量并记录。[[吸水率]]可表示为：

$$
\text{Waterabsorption} = \frac {W _ {a} - W _ {b}}{W _ {b}} \times 100 \%\tag{8}
$$

其中，为记录的吸水后重量，$W _ { \mathrm { a } } \ W _ { \mathrm { b } }$ 为吸水前重量。

## [[化学交联密度]]

不同样品的[[化学交联密度]]（V）可根据已报道的公式表示<sup>60</sup>：

$$
V _ {e} = V _ {r o} / V _ {r f}\tag{9}
$$

$$
V _ {r o} = \frac {d / \rho_ {p}}{(d / \rho_ {p}) + (A _ {s} / \rho_ {p})}\tag{10}
$$

$$
V _ {r f} = \frac {(d - f w) / \rho_ {p}}{(d / f w) / \rho_ {p} + (A _ {s} / \rho_ {p})}\tag{11}
$$

其中，$d$ 为样品的[[溶胀]]重量，$\rho p$ 为[[生物塑料]]的[[密度]]，f 为[[纤维素薄膜]]中 [[TA]] 的[[体积分数]]，w 为 [[α-硫辛酸|TA]] 的[[质量分数]]，As 为样品吸收的[[去离子水]]量。对于特定体系，Vro 为常数。Vrf 为[[纤维素]]薄膜中[[化学交联相]]的体积分数，使用式（8–10）计算。

## [[氢键系数]]的计算

[[氢键系数]] $( \mathsf { F } _ { H - C O } )$ 通过使用 [[Gauss-Lorentz函数|Gauss-Lorentz 函数]]对[[羰基谱带]]进行[[曲线拟合]]计算得到<sup>61</sup>。

$$
F _ {H - C O} = \frac {A _ {H} / r _ {H / f}}{A _ {H} / r _ {H / f} + A _ {f}}\tag{12}
$$

其中，$A _ { f }$ 和 $A _ { H }$ 分别为游离峰和[[氢键]]结合组分的[[峰面积]]，$r _ { H / f }$ 为上述两个谱带的特征[[吸附]]比，其范围为 1.2–1.75。

$\mathsf { F } _ { H - O H }$ 的值根据式 12 计算。

$$
\mathsf {F} _ {H - O H} = (A _ {\mathrm{H}} / r _ {\mathrm{H/a}}) / (A _ {\mathrm{H}} / r _ {\mathrm{H/a}} + A _ {\mathrm{a}})\tag{13}
$$

其中，$A _ { \mathrm { a } }$ 和 $A _ { \mathrm { H } }$ 分别为游离组分和[[氢键]]结合组分的[[峰面积]]，$r _ { \mathrm { H / a } }$ 为这两个峰的[[光谱峰强度比|强度比]]
