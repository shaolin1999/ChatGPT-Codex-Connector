## 摘 要

[[活性炭|活性炭（AC）]]对[[全氟和多氟烷基物质|全氟和多氟烷基物质（PFAS）]]的修复是有效的，但[[短链全氟和多氟烷基物质|短链 PFAS]] 的[[吸附]]仍是一项关键挑战。因此，理解结构–吸附关系对于选择更优吸附剂至关重要。在此，我们通过物理活化和[[化学活化]]制备了孔径和[[表面电荷]]系统可控的[[活化生物炭]]，以揭示对短链 PFAS 有效的孔径和表面化学。结果表明，短链 PFAS 的摄取与[[亚纳米孔]]（0.56–0.85 nm）、高[[零电荷点]]（[[等电点|PZC]]）及低 [[羧基|-COOH]] 基团含量密切相关。吸附机制由[[孔填充]]主导，并受 [[π电子|π 电子]]碱性、氮和[[吡喃酮型氧]]官能团所产生的[[静电相互作用]]驱动。适度[[水蒸气活化|蒸汽活化]]同时优化了亚纳米孔径和 PZC，而更高的[[烧失率]]使孔道变宽，将选择性转向长链 PFAS。相比之下，化学活化降低了 PZC 并削弱了静电亲和力。令人意外的是，较大颗粒减缓了[[吸附-脱附动力学|吸附–脱附动力学]]，却使 [[PFBA]] 摄取相对于粉末有所提高。在多种 PFAS [[无机阴离子|阴离子]]基质中，优化后的[[生物炭]]实现了比 [[F400]] 高 5–6.5 倍的 [[全氟丁酸|PFBA]] [[分配系数]]，并且对 [[HFPO-DA]]、[[PFHxS]] 和 [[PFOA]] 保持了 1.0–10.6 倍更高的分配系数，同时具备高可回收性和重复使用稳定性。在环境相关浓度下的[[柱实验]]中，该材料在 PFBA 达到 10% 穿透前处理的水量是 F400 的 2.9 倍，同时保持了对长链 PFAS 的更好去除。通过阐明短链 PFAS 捕获所必需的孔径–表面电荷协同作用，本工作为兼具短链和长链 PFAS 亲和力的低成本吸附剂确立了设计原则。

## 1. 引言

[[全氟和多氟烷基物质|全氟和多氟烷基物质（PFAS）]]是[[持久性有机污染物]]，对人类健康和生态系统构成重大威胁 [1]。近年来，美国和欧洲的政策制定者已收紧对某些 PFAS 的排放限值，例如 [[PFOA]]、[[全氟辛烷磺酸|PFOS]]、[[PFHxS]]、[[全氟壬酸|PFNA]] 和 [[HFPO-DA]] [2]。然而，针对[[短链全氟和多氟烷基物质|短链 PFAS]] 的综合性监管限值在很大程度上仍然缺失，导致其作为替代品的使用有所增加。因此，这些物质目前已在环境中被广泛检出 [3–5]。例如，[[PFBA]] 已在明尼苏达州一处公共饮用水源中被检出，浓度高达 3.7 μg/L [6]，并在中国河流和地下水中的含量最高达 4.8 μg/L [7]。[[全氟丁酸|PFBA]] 常常属于检出浓度最高的 PFAS 之一 [8,9]。尽管短链 PFAS 通常被认为毒性低于其长链同系物 [10]，但它们的半衰期更长，且正日益普遍 [11]。研究已发现 PFBA 会在人体肺和肾组织中积累 [12,13]。

此外，[[美国环境保护署]]的毒理学报告表明，接触 [[PFBA]] 可导致甲状腺和肝脏毒性、增加肝脏重量、改变激素和胆固醇水平，并损害发育 [14]。

使用商用[[活性炭|活性炭（AC）]]去除[[短链全氟和多氟烷基物质]]（[[全氟和多氟烷基物质|PFAS]]）极具挑战性，因为在典型处理 [[pH]] 下它们具有高亲水性（例如，[[PFBA]] 在 pH 7 时 Log D<sub>OW</sub> = −1.22）[15]。它们的[[无机阴离子|阴离子]]特性以及极小的疏水骨架导致可忽略的范德华吸引力，使[[吸附]]几乎完全依赖[[静电相互作用]]。一般而言，用于 PFAS 处理的活性炭[[表面电荷]]可为中性或略带正电，从而能够对阴离子 PFAS 产生较弱的静电吸引 [16]。然而，对于短链化合物，这种吸引仍不足以实现强保留。因此，它们表现出快速[[吸附-脱附动力学|解吸动力学]]，并且容易被长链 PFAS 置换，而长链 PFAS 受益于强疏水吸附作用。这导致这些化合物快速穿透并几乎完全[[脱附|解吸]] [15]。因此，提高短链 PFAS 的吸附量、减缓其解吸动力学，同时提高长链 PFAS 的吸附能力，对于改善整体 PFAS 处理效果至关重要。

迄今为止，已有大量原始及改性碳质材料被报道用于增强[[短链全氟和多氟烷基物质|短链 PFAS]] 的[[吸附]]。实例包括[[芦苇秸秆生物炭]] [17]、金属接枝[[生物炭]]，如 [[Ca-Fe-生物炭]] [18]、[[Fe-Cu-生物炭]] [19] 和 $\mathrm { F e ^ { 3 + } }$ -生物炭 [20]，以及类金属接枝碳，如 [[Si-AC]] [21]。此外，还有金属和非金属接枝碳，包括[[聚吡咯-Fe生物炭|聚吡咯-Fe 生物炭]] [22,23]、[[DMAc-炭]] [24]、[[polyDADMAC-AC]] [25]、[[CTAB生物炭|CTAB 生物炭]] [26] 以及 Polypyrrole@F $\mathrm { { e _ { 2 } O _ { 3 } } } \cdot$ 碳布 [27]。除这些材料外，还提出了辅助技术以改善吸附，例如将水限制在纳米孔中 [11]，以及在吸附前将短链 [[全氟和多氟烷基物质|PFAS]] 与疏水试剂配对 [28]。在各种碳质吸附剂中，聚吡咯-Fe 生物炭在去除短链 PFAS 方面表现出高效率。然而，该材料往往优先吸附短链 PFAS，特别是[[全氟烷基羧酸]]（PFCAs），而其对长链[[全氟磺酸]]（PFSAs）的性能与典型[[颗粒活性炭]]（GACs）相当 [22]。此外，使用多种试剂和制备步骤可能带来比典型物理活化碳更高的制造成本，这对其放大生产构成重大挑战 [28]。因此，迫切需要开发一种既能高效去除短链 PFAS，又能同时保持对长链 PFAS 高去除能力的有效材料。

[[生物炭]]是一种低成本、具有优异性能的碳质材料 [29]。热化学转化可使生物炭具备优良的形貌、所需的[[表面电荷]]以及可调控的功能性 [30]。然而，针对复杂基质中[[短链全氟和多氟烷基物质|短链 PFAS]] 去除的生物炭改性策略仍未得到充分探索。更重要的是，将短链 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]仅归因于[[微孔]]可能过于简单化，因为传统微孔[[活性炭]]的容量有限 [15,31]。因此，确定能够实现高效短链 PFAS 捕获的精确孔径范围以及起支撑作用的表面化学性质至关重要。

在本研究中，我们采用不同的物理和[[化学活化]]方法，由[[竹子]]和[[椰壳]]制备了[[活化生物炭]]，并对其孔隙结构进行了调控，使其涵盖从不同程度的[[亚纳米孔]]到[[介孔]]，以及不同的[[表面电荷]]。我们评估了这些[[吸附]]剂在复杂 [[全氟和多氟烷基物质|PFAS]] [[无机阴离子|阴离子]]基质中去除[[短链全氟和多氟烷基物质|短链 PFAS]]（尤其是 [[PFBA]]）的性能。研究考察了[[生物炭]]性质$( \boldsymbol { \mathrm { e . } } \boldsymbol { \mathrm { g . } } ,$孔结构、表面电荷、元素含量、官能团和[[粒径效应|粒径]]）以及水相基质组成的影响，并以高性能 [[颗粒活性炭|GAC]] 为基准对其性能进行了比较。最后，为验证研究结果，开展了一项[[柱实验]]，对比了优化后碳材料与 [[F400]] 在自来水中去除 PFAS 的性能。

## 2. 材料与方法

## 2.1. 化学品与材料

本研究使用的四种[[颗粒活性炭|商用 GAC]] 和化学品的详细信息分别列于表 S1 和补充信息文本 1。商用 GAC 的选择依据是其多样化的制备方法（例如，再团聚法与[[水蒸气活化|直接蒸汽活化法]]）、表面[[孔隙率]]（例如，[[微孔]]与[[介孔]]比例不同）以及[[表面电荷]]。用于制备[[活化生物炭]]的原料[[竹子]]和[[椰壳]]生物质购自一家在线商业供应商。

## 2.2. [[活化生物炭]]的制备与表征

[[活化生物炭]]通过[[水蒸气活化|蒸汽活化]]、[[KOH活化|KOH 活化]]和$\mathrm { H _ { 3 } P O _ { 4 } }$活化方法合成。对于[[蒸汽活化]]，生物质首先在$\Nu _ { 2 }$气流下于$6 0 0 ~ ^ { \circ } \mathrm { C }$[[热解]] 2 小时（升温速率$5 ~ ^ { \circ } \mathrm { C } /$ min）。所得[[生物炭]]随后被破碎，过 10–25 目筛，并在卧式炉中于$9 0 0 ^ { \circ } \mathrm { C }$下蒸汽活化不同时间（随后再加热 2 小时），以获得不同的[[烧失率]]。根据烧失百分比，我们将蒸汽活化水平分为低（15%）、中（34–42%）和高（57%）。蒸汽活化生物炭标记为 Xy%b，其中 X 表示生物质来源（B = [[竹子]]，C = [[椰壳]]），y 表示烧失百分比。对于 KOH 活化，将椰壳粉（80–100 目）与 KOH 水溶液混合并干燥。浸渍 KOH 的生物质在$8 0 0 ~ ^ { \circ } \mathrm { C }$下于$\mathrm { N } _ { 2 } ;$热解 2 小时，然后用 1 M HCl 洗涤，再用去离子水洗涤，直至上清液 [[pH]] 达到约 7。生物质与 KOH 质量比为 1:1 和 1:2 制备的样品分别标记为 [[CK11]] 和 [[CK12]]。对于$\mathrm { H _ { 3 } P O _ { 4 } }$活化，将椰壳粉（50–60 目）在室温下浸没于$\mathrm { H _ { 3 } P O _ { 4 } }$溶液中 48 小时，干燥，然后在 500 °C 下于$\mathrm { N } _ { 2 } .$热解 1 小时。热解后，样品按照与 KOH 活化生物炭相同的程序进行洗涤和干燥。这些样品根据相应的$\mathrm { H _ { 3 } P O _ { 4 } }$浸渍剂量分别标记为 [[CP11]] 和 [[CP12]]。

所合成的[[活化生物炭]]通过 [[BET比表面积|BET 比表面积]]和[[孔径分布]]分析确定表面形貌和[[孔隙率]]，通过[[元素分析]]确定整体组成，通过酸水浸出试验并结合 [[电感耦合等离子体分析|ICP 分析]]测定可浸出无机物含量，通过 [[zeta电位|zeta 电位]]测量[[表面电荷]]，并通过 [[X射线光电子能谱|X 射线光电子能谱]]（[[XPS]]）分析表面化学组成（详见补充信息文本 2）。

## 2.3. 批量[[吸附]]实验

在典型的批量实验中，将20 mg[[吸附]]剂加入含400 mL加标[[全氟和多氟烷基物质|PFAS]]（例如[[PFBA]]、[[HFPO-DA]]、[[PFHxS]]和[[PFOA]]）水溶液的1 L聚丙烯瓶中，使每种化合物的浓度达到500 μg/L，并在室温下用机械摇床振荡7天。此前的实验证实吸附–[[脱附]]平衡在7天内即可达到。为考察单一或混合[[无机阴离子|阴离子]]的作用，向PFAS溶液中加入1 g/L的各阴离子（NaCl、${ \mathrm { N a N O } } _ { 3 } ,$ ${ \mathrm { N a H S O } } _ { 4 } ,$ 和 $\mathrm { N a _ { 2 } C O _ { 3 } ) }$）。在[[吸附等温线]]研究中，配制[[全氟辛酸|PFOA]]和[[全氟丁酸|PFBA]]的单组分溶液，浓度范围为12.5至200 mg/L。所有情况下，溶液[[pH]]均调节至7.5。在指定时间间隔，收集1 mL悬浮液，经0.22 μm尼龙滤膜过滤，并使用LC-MS/MS分析仪测定PFAS浓度。所有实验均平行进行三次，并报告平均值。PFAS分析方法、质量控制规程和数据分析方法见SI Text 3。

## 2.4. [[柱实验|柱吸附实验]]

[[全氟和多氟烷基物质|PFAS]][[吸附]]柱的制备方法为：将1.24 g吸附剂装入带有滤膜支撑的柱中（内径7 mm，柱长130 mm）。[[F400]]和[[C34%b]]的[[床体积]]（BV）分别为2.36 mL和2.42 mL。与柱连接的蠕动泵首先用甲醇和水冲洗柱子以去除背景污染物，然后在下流模式下输送加标1 μg/L [[PFBA]]、[[HFPO-DA]]、[[PFHxS]]和[[PFOA]]的自来水，[[空床接触时间|EBCT]]分别为9.9 min（F400）和10.4 min（C34%b）。处理后的出水按时间间隔收集，并通过LC-MS/MS分析。

## 3. 结果与讨论

## 3.1. [[吸附]]剂特性

碳质材料的[[孔隙率]]和表面化学性质对[[全氟和多氟烷基物质|PFAS]][[吸附]]至关重要。为评估孔隙率，我们利用N物理吸附表征了五种[[椰壳]]活性[[生物炭]]和四种商业[[颗粒活性炭|GAC]]。所有样品均显示出[[微孔]]特征，表现为在低[[相对压力]]（<0.1 P/P）下吸附等温线陡峭上升（图1a）。低气化度生物炭C15%b在低压区出现急剧吸附，随后呈现可逆的吸附–脱附等温线，证实其以微孔结构为主。中等和较高度烧失率的样品在0.1 $\mathrm { { P } / \mathrm { { P } _ { 0 } } }$以下表现出更大的吸附体积，并具有明显的滞后回线，反映微孔和更宽孔隙的发展。孔径分布（PSD）证实C15%b的孔隙主要位于0.56至1.3 nm之间（图1b）。随着水蒸气活化烧失率的增加，0.56–0.7 nm范围内的孔容先增至最大值，随后孔隙拓宽，使较大微孔（0.7–2 nm）和中孔的孔容增加。C34%b、C42%b和C57%b的孔径分布在0.56–0.7 nm范围内大致相似；但在该范围以上，增量孔容随气化强度逐步升高。相比之下，KOH活化生物炭表现出较低的亚纳米孔隙率，但其在1–1.5 nm范围内的孔径分布与C34%b和C42%b相似，而其中孔率超过所有水蒸气活化样品。商业GAC的孔径分布更接近于CK12（图S1）。根据微孔孔容，所研究碳材料的排序为C57%b > [[C42%b]] > [[C34%b]] > [[CK12]] > [[F400]] > [[HAC]] > [[I900]] > [[F300]] > [[C15%b]]。

我们推测，对[[短链全氟和多氟烷基物质|短链 PFAS]] 去除至关重要的并非所有[[微孔]]，而是某一特定微孔区间，因为较大微孔可使分子自由移动而无空间位阻，但由于大部分孔壁仍远离分子且水充满周围空间，其相互作用较弱 [32]。因此，既能避免空间位阻、又能确保最大[[静电相互作用]]的较窄孔道，可能最有利于增强[[主客体相互作用]] [33]。基于这一假设，我们比较了[[吸附]]剂在不同孔径区间内的孔容（图 1c）。除 [[C15%b]] 外，[[活化生物炭|蒸汽活化生物炭]]在 0.56–1.05 nm 范围内表现出高孔容，其中 0.56–0.65 nm 区间最为集中。这些[[生物炭]]在该区间超过[[颗粒活性炭|商用 GAC]] 和 [[CK12]]。相比之下，GAC 和 CK12 在较大微孔（1.25–2 nm）及[[介孔|中孔]]区间占优。[[C34%b]]、[[C42%b]] 和 [[C57%b]] 的亚纳米总孔容相当，且几乎是其他样品的两倍（表 S2）。

测定[[吸附]]剂的 [[等电点|PZC]] 值以评估其[[表面电荷]]（图 1d）。除 [[I900]] 外，所有[[颗粒活性炭|商用 GAC]] 在初始 [[pH]] 为 $^ { 7 , }$ 时 pH 升高极小，表明其表面略显碱性。I900 的 [[零电荷点|PZC]] 高达 9.3；尽管经过 48 h 充分洗涤并随后漂洗至洗涤水 pH 稳定，仍可能有部分灰分浸出或表面金属氧化物影响其 PZC。其他商用 GAC 和[[活化生物炭]]的灰分含量较低，因此对 PZC 和 [[全氟和多氟烷基物质|PFAS]] 吸附的影响可忽略（表 S3）。[[水蒸气活化|蒸汽活化]][[生物炭]]的 PZC 值介于 8.0–8.7 之间，显著高于再团聚 GAC。这可能与其元素组成有关。对 [[C34%b]] 的 [[XPS]] 分析显示，其表面以 [[C-C键|C–C 键]]为主（31.3%），而 $\mathrm { C - } 0 , \mathrm { C = } 0 ,$ 和 [[O-C=O基团|O-C=O 基团]]极少（图 1e）。鉴于其高总碳含量（93.1%）以及低氧（3.68%）和低氢（0.54%）含量（表 S4），该材料具有高度芳香性。因此，正表面电荷主要归因于[[芳香基面]]上的[[π电子|离域 π 电子]]，它们作为 [[Lewis碱|Lewis 碱]]并结合溶液中的质子 [34]。氮基团的贡献很小，总含量仅为 0.15%，由[[吡咯型氮|吡咯型（N-5）]]和[[季铵型氮|季铵型（N-Q）]]物种组成（图 1f）。此外，[[吡喃酮型氧]]（C=O）也可作为 Lewis 碱性位点，尽管其仅占总表面氧物种的 12.6%（图 S2a）。最高 PZC 为 8.7，出现在中等气化程度的生物炭（C34%b）中；而进一步气化由于碳含量降低和氧含量略有增加，使 PZC 略有下降。

相比之下，[[KOH活化|KOH 活化]]和 $\mathrm { H _ { 3 } P O _ { 4 } }$ 活化的[[生物炭]]表现出较强的负[[表面电荷]]，其 [[等电点|PZC]] 值分别为 5.2 和 3.1。[[CK12]] 中的氮含量和氧含量分别为 0.32% 和 9.6%，均高于[[活化生物炭|蒸汽活化生物炭]]。尽管部分 N 物种会贡献正电荷，但较高的 O 含量主导了 CK12 的表面电荷。[[Pearson相关分析|相关性分析]]表明，[[零电荷点|PZC]] 与总氧含量之间存在强负相关关系（r = −0.91）（图 S3）。在不同氧物种中，[[羧基|-COOH]] 具有最强的酸性（pKa ≈ 4.76），而 [[C-OH基团|C–OH]] 的 pKa 约为 10 [35]。由于羧基的 pKa 较低，其在中性 [[pH]] 附近会发生解离，在降低 PZC 并赋予净负表面电荷方面起主导作用。CK12 中 289 eV 处的 -COOH 峰比[[水蒸气活化|蒸汽活化]]生物炭中更为显著（图 S2b）。由于 CK12 含有更多的 -COOH 基团和更高的体相氧含量，其表面 -COOH 基团的净数量显著更高，这使其 PZC 值明显更低。这一观察结果与 Zhi 等人 [36] 的发现一致。

通过使用后的[[C34%b]]进行的孔结构分析，进一步支持了[[PFBA]]吸收与[[亚纳米孔|亚纳米孔体积]]之间的统计相关性。与较大的[[微孔]]和[[介孔|中孔]]相比，[[全氟和多氟烷基物质|PFAS]]吸收后孔结构，尤其是亚纳米孔，发生了显著变化（图3e）。亚纳米孔体积从0.308降至$0 . 1 7 8 \mathrm { c m } ^ { 3 } / \mathrm { g } ,$，而总微孔体积从0.412降至$0 . 3 3 9 \ \mathrm { c m } ^ { 3 } / \mathrm { g } .$。使用后样品的[[BET 等温线|BET等温线]]也显示，在较低[[相对压力]]下$\mathrm { N } _ { 2 }$吸收明显减少，这表明亚纳米孔在[[吸附]]过程中起着重要作用。尽管由于所用竞争性混合物的原因，这种减少不能归因于某一种特定PFAS，但统计相关性表明，较窄亚纳米孔的填充可能显著受短链PFAS驱动。

在环境相关[[pH]]值下，短链[[全氟和多氟烷基物质|PFAS]]必须克服[[传质屏障]]（如3.27–5.66 kcal/mol）才能发生[[吸附]] [11]。更宽的孔道，即使带有正电荷，也可能因[[主客体相互作用]]较弱而无法提供足够的驱动力来克服这一屏障。然而，一个足够小且带正电荷、能够实现包合的孔道，由于孔壁紧邻分子，可显著提高吸附能 [42]。因此，具有高[[等电点|PZC]]的高度[[亚纳米孔]][[生物炭]]可显著增强[[PFBA]]的吸附，而该吸附过程由[[静电相互作用]]驱动的[[孔填充]]所主导（图3f）。相比之下，[[PFOA]]更倾向于较大的[[微孔]]，其吸附主要由疏水作用、[[范德华力]]和孔填充作用驱动。

使用 [[C42%b]]（1.2–2.0、0.3–0.4 和 0.07–0.1 mm）和 [[I900]]（2.0–2.4、0.3–0.4 和 0.07–0.1 mm）考察了竞争环境中[[吸附]]剂[[粒径效应|粒径]]对 [[PFBA]] 吸附的影响。如图 4a 所示，粉末（0.07–0.1 mm）和较细颗粒（0.3–0.4 mm）实现了快速 [[全氟丁酸|PFBA]] 吸附，分别在 1 h 和 10 ${ \bf h } ,$ 内达到[[最大吸附量]]。相比之下，较大颗粒（2.0–2.4 mm）表现出较慢的动力学，需要三天才能达到最大值，表明颗粒内扩散主导吸附速率。重要的是，粒径也显著影响[[吸附容量]]。平衡后，粉末、较细颗粒和较大颗粒的最大 PFBA 吸附量分别为 15.2%、25.1% 和 31.4%。在所有情况下，吸附均先达到峰值，然后下降至表观稳态。I900 也观察到类似趋势（图 S6）。这种行为源于与长链 [[全氟和多氟烷基物质|PFAS]] 的竞争性[[吸附-脱附动力学]]。在细粉末中，短扩散路径使短链和长链 PFAS 均能快速吸附。尽管[[短链全氟和多氟烷基物质|短链 PFAS]] 在水中具有更高的固有迁移率，但浅孔确保两者的快速[[吸附动力学]]。粉末和较细颗粒中 [[HFPO-DA]]、[[PFHxS]] 和 [[PFOA]] 的快速吸附动力学如图 4b–4d 所示。由于具有更高的亲和力，长链 PFAS 如果先到达，可能会堵塞粉末和较细颗粒中的孔。相反，较大颗粒减缓扩散，有利于短链 PFAS——由于其更高的迁移率——在长链对应物之前到达并限制在[[亚纳米孔]]内。此外，粉末和较细颗粒中的[[脱附]]速率显著高于较大颗粒。因此，在给定的实验周期内，颗粒形态的高性能可能源于两个原因：(1) 长链 PFAS 几乎不堵塞孔，以及 (2) 实验时间范围内脱附有限。Park 等人 [15] 在柱测试中观察到较大颗粒对 PFBA 吸附的边际效益，尽管他们的粒径范围仅限于粉末（平均直径范围为 0.1 至 0.2 mm）。虽然短链 PFAS 的脱附在碳和树脂体系中仍然不可避免 [43]，但选择适当较大的颗粒可以将吸附-脱附平衡移向更长的[[保留时间]]，这可能有利于竞争环境中 PFBA 的净吸附。

## 3.3. 水相性质对[[短链全氟和多氟烷基物质|短链 PFAS]] [[吸附]]的影响

通过用[[全氟和多氟烷基物质|PFAS]]、PFAS-[[无机阴离子|阴离子]]和[[PFBA]]-阴离子溶液处理[[C34%b]]和[[F400]]，评估了阴离子在短链PFAS[[吸附]]中的作用。如图5a所示，在2000倍浓度的NaCl、NaNO、NaHSO和Na CO存在下，C34%b和F400的[[全氟丁酸|PFBA]]吸附性能均显著下降。C34%b和F400对PFBA的[[竞争抑制指数]]分别为0.76和0.80，表明阴离子竞争对F400中PFBA吸附的抑制作用略强。计算了PFAS的[[分配系数]]（K<sub>d</sub>），以量化不同基质中PFAS在水相和固相之间的分布。对于C34%b，PFBA在PFAS、PFAS-阴离子和PFBA-阴离子溶液中的分配系数分别为0.54、0.13和0.20。对于F400，相应值分别为0.10、0.02和0.04。C34%b的PFBA分配系数比F400高5至6.5倍。对于两种吸附剂，在所测试剂量下，阴离子对PFBA吸附的抑制作用强于竞争性长链PFAS，这与[44]报道的阴离子抑制作用一致。除PFBA外，C34%b在所有测试的PFAS中始终优于F400。其对[[HFPO-DA]]、[[PFHxS]]和[[PFOA]]的分配系数分别保持高出4.5–10.6、1.0–2.7和1.0–3.9倍，证实了在动态水基质中，与F400相比，C34%b对短链和长链PFAS均具有更大的吸附能力。

为了强调特定[[无机阴离子|阴离子]]在[[吸附]]中的作用，在单一阴离子存在下用[[全氟和多氟烷基物质|PFAS]]处理[[C34%b]]。如图5b所示，NO<sub>3</sub><sup>−</sup>的存在显著阻碍了[[PFBA]]吸附，而与其他阴离子相比，其对长链PFAS的影响最小。相反，$s 0 _ { 4 } ^ { 2 - }$显著阻碍了[[HFPO-DA]]、[[PFHxS]]和[[PFOA]]的吸附。$\mathrm { C O } _ { 3 } ^ { 2 - }$<sup>−</sup>和Cl<sup>−</sup>的影响彼此相当，对短链PFAS而言低于NO<sup>−</sup>，对长链PFAS而言低于$S O _ { 4 } ^ { 2 - }$。对于[[全氟丁酸|PFBA]]，[[硝酸根]]（NO<sup>−</sup>）表现出最强的抑制作用，这与其较小的[[水合直径]]（\~0.632 nm）[45]一致，使其能够进入并阻塞这些狭窄孔隙。然而，仅基于尺寸和[[水合能]]的解释并不充分。Cl<sup>−</sup>的水合直径和水合能与NO<sub>3</sub><sup>−</sup>几乎相同[46]，但并未在同等程度上抑制PFBA吸附。Ritt等人[47]推断，水合能与[[选择渗透|选择性渗透]]的相关性较差，使其不能作为脱水限制传输的可靠独立指标。相反，阴离子特定的[[表面电荷]]、极化率以及与碳基面的[[离子-π相互作用]]可能更具决定性。相比之下，[[硫酸根]]（SO<sub>4</sub><sup>2−</sup>）对长链PFAS的显著抑制与其kosmotropic性质一致，在吸附剂-水界面诱导[[盐析效应]]。

![](<../2.SCI_MD/Highly subnanoporous-basic activated biochar for enhanced removal of short-chain PFAS from drinking water/images/6398cd6458cbdcc85cfa378173a04da5de135aec03de2700745fe299b7eb090e.jpg>)  
图6. 活化生物炭和商业颗粒活性炭的再生性能。

使用单一组分 [[全氟和多氟烷基物质|PFAS]] 溶液评价了四种所选[[吸附]]剂的[[吸附等温线]]。等温线数据可由 [[Langmuir 模型|Langmuir]] 和 [[Freundlich 模型]]很好地描述，R<sup>2</sup> 值范围为 0.910 至 0.999（图 5c 和 d，以及表 S5）。[[C34%b]] 表现出最高的 [[PFBA]] [[吸附容量]]，为 141.8 mg/g，其次为 [[C57%b]]、[[F400]] 和 [[CK12]]。尽管 C57%b 具有显著更高的[[微孔]]体积和[[BET|比表面积]]，但其最大吸附容量低于 C34%b。这一观察再次证实，单一组分溶液中 [[全氟丁酸|PFBA]] 的吸附也与吸附剂的尺寸特异性孔隙密切相关。有趣的是，CK12 在单一组分溶液中表现出与 F400 相当的吸附容量，而在竞争环境中其 PFBA 吸附量则低得多。这一差异可能归因于在单一 PFBA 溶液中由[[孔填充]]驱动的吸附，此时由于不存在竞争物质，较弱的静电排斥并不限制吸附容量。对于 [[PFOA]]，C57%b 实现了最高的最大吸附容量（616.8 mg/g），其次为 CK12、C34%b 和 F400。单一组分溶液中最大 [[全氟辛酸|PFOA]] 吸附性能的顺序归因于吸附剂的 [[BET比表面积|BET 比表面积]]。

值得一提的是，高度[[亚纳米孔]][[生物炭]]对[[短链全氟和多氟烷基物质|短链 PFAS]] 的性能优于含有大于 1 nm [[微孔]]和[[介孔]]的[[活性炭|活性炭（AC）]]。在批处理规模研究中，该性能也与一些原始多孔有机框架或[[金属-有机框架|金属–有机框架]]相当。例如，[[共价三嗪框架]]的 [[PFBA]] [[吸附容量]]（92 mg/g）远低于该生物炭[48]。然而，带有[[季铵]]、胺或[[氟化基团]]的工程化框架实现了更高的 [[全氟丁酸|PFBA]] 容量，为 274–605 mg/g[49–51]。尽管如此，亚纳米孔活性炭的结构稳定性和较大[[粒径效应|粒径]]使其更适合直接用于现有处理系统。

## 3.4. 废弃[[生物炭]]的[[再生]]

碳质[[吸附]]剂的高可回收性对于降低水处理成本和环境影响至关重要。[[再生]]方法通常包括在惰性气体下加热、氧化或溶剂洗脱。然而，[[活性炭]]通常通过热过程再生，[[全氟和多氟烷基物质|PFAS]] 可在 600 ◦C 加热下挥发/分解 [52]。在本研究中，再生通过将使用过的吸附剂在 $6 0 0 ^ { \circ } \mathrm { C }$ 下[[热解]] 1 h，并在 $\Nu _ { 2 }$ 气流中进行。再生后，长链 PFAS 的去除性能保持稳定，但[[短链全氟和多氟烷基物质|短链 PFAS]] 的去除性能在一定程度上下降（图 6）。经过三次再生循环后，[[C34%b]] 的 [[PFBA]] [[吸附容量]]从 35.1% 降至 26.1%（降低 25.6%）。[[C57%b]] 的下降更为明显，从 26.7% 降至 14.4%（降低 46.1%）。尽管所用再生温度低于材料合成温度，但一些[[亚纳米孔]]可能扩大为较大的[[微孔]]或[[介孔|中孔]] [53]，导致 [[全氟丁酸|PFBA]] 吸附降低。C57%b 由于[[孔隙率]]过高，孔壁比 C34%b 更薄，使其在再次加热时更容易发生亚纳米孔结构改变。[[F300]] 和 [[F400]] 的 PFBA 吸附性能下降幅度分别为 26.5% 和 13.4%。F400 的性能下降幅度低得多，可能是由于其再团聚制备方法使其比直接[[活化生物炭|蒸汽活化生物炭]]具有更高的抗热再生能力。F300 的性能下降与[[水蒸气活化|蒸汽活化]][[生物炭]]相似。虽然 F300 也是一种[[再团聚颗粒活性炭]]，但其灰分含量略高，预计会在实验的前 7 天中溶出。因此，在再利用后的后续运行中，与灰分相关的吸附不再存在，导致 PFBA 吸收量降低。尽管性能有所下降，C34%b 在回收后仍表现出显著高于其他吸附剂的 PFBA 吸附能力和优异的长链 PFAS 去除效果。这证实，适度[[蒸汽活化]]的[[椰壳生物炭]]比高[[烧失率]]生物炭或商业[[颗粒活性炭]]更适合在多次循环中处理长链和短链 PFAS。

## 3.5. 环境相关 [[全氟和多氟烷基物质|PFAS]] 处理

基于批量实验中观察到的 [[PFBA]] [[吸附]]性能改善，我们假设在实际饮用水处理中，[[C34%b]] 会比商业[[颗粒活性炭]]吸附更多 [[全氟丁酸|PFBA]]，同时确保更高的长链 [[全氟和多氟烷基物质|PFAS]] [[去除率]]。为验证这一点，我们使用 C34%b 和 [[F400]] 进行了小规模[[柱实验]]。值得注意的是，[[竹基生物炭]] [[B49%b]] 在批量测试中表现出略优于 C34%b 的吸附性能。然而，我们选择[[椰壳]]基吸附剂，是因为其具有更高的[[堆密度]]，可以在相同体积内填充更多碳质量，从而获得更高的体积性能。

对于[[柱实验]]，我们使用添加了每种 [[全氟和多氟烷基物质|PFAS]]（[[PFBA]]、[[HFPO-DA]]、[[PFHxS]] 和 [[PFOA]]）1 μg/L 的自来水作为进水。水中还含有 7.1 mg/L [[总有机碳|TOC]]、17.4 mg/L Cl<sup>−</sup>、5.2 mg/L NO<sub>3</sub><sup>−</sup> 和 76.7 mg/L SO<sup>2−</sup>，[[pH]] 为 7.3，并含有背景 PFAS（详情另见文献 [54]）。选择 1 μg/L 的 [[全氟丁酸|PFBA]] 浓度，是基于前述若干饮用水源中的检出水平；其他 PFAS 也以相同浓度加标，以营造高竞争环境。我们选择了约 10 min 的标准[[空床接触时间]]，因为[[短链全氟和多氟烷基物质|短链 PFAS]]——尤其是 PFBA——在主要通过高[[微孔]]碳[[吸附]]时，在较低接触时间下极易发生早期穿透 [15]。当出水中 PFBA 浓度达到进水浓度时，终止柱实验。需要指出的是，全尺寸饮用水处理柱的运行容量取决于吸附剂性质、水质参数和 EBCT——这些都可能与本实验条件不同。因此，本研究关注的是相对趋势而非绝对值。

![](<../2.SCI_MD/Highly subnanoporous-basic activated biochar for enhanced removal of short-chain PFAS from drinking water/images/0338cc33ab034e814ad938467a9b84c2c071b35748b8e7941f38457e2fac709d.jpg>)  
图 7. 在实际饮用水基质中，四种 PFAS 在填充 (a) F400 和 (b) C34%b 的柱中的穿透曲线。红色和黑色虚线分别标示 10%（<100 ppt）和 100%（1000 ppt）穿透。

如图 7a 所示，[[PFBA]] 在 [[F400]] 上迅速穿透。10% 穿透发生在 803 [[床体积|BV]] 后（不到 6 天），完全穿透在 3743 BV（约 26 天）时达到。在此之后，出水中浓度出现超调，表明 [[全氟丁酸|PFBA]] 可能因被较长链 [[全氟和多氟烷基物质|PFAS]] 置换而发生[[脱附|解吸]]。这一穿透行为与文献趋势一致：其出现时间早于 Riegel 等 [55]、Shi 等 [11] 和 Park 等 [15] 的报道，这些研究使用了较低的进水 PFAS 浓度（0.18–0.35 μg/L）和较弱的[[无机阴离子|阴离子]]竞争；但晚于 Yu 等 [23] 的报道，该研究使用了更高的总 PFAS 投加量（5 μg/L）。尽管存在这些差异，PFAS [[吸附]]与容量的总体趋势仍与先前研究一致。

相比之下，[[C34%b]] 在 2306 [[床体积|BV]]（约 16 天）后实现 [[PFBA]] 的 10% 穿透——比 [[F400]] 长 2.9 倍——并在 7401 BV（约 51 天）时完全穿透（图 7b）。对[[穿透曲线]]积分得到，F400 的 [[全氟丁酸|PFBA]] [[吸附容量]]为 4.97 μg/g，C34%b 为 8.89 μg/g。对于 [[HFPO-DA]]、[[PFHxS]] 和 [[PFOA]]，在 F400 上的 10% 穿透分别出现在约 5733、8900 和 7925 BV，而在 C34%b 上则分别为 5766、9604 和 8294 BV。这些结果证实，C34%b 凭借其高度[[亚纳米孔]]结构，实现了比[[颗粒活性炭|商用 GAC]] 长 2.9 倍的 PFBA 穿透时间和高 1.8 倍的[[吸附]]容量，表明其对[[短链全氟和多氟烷基物质|短链 PFAS]] 尤其有效，同时在饮用水处理中也能改善长链 [[全氟和多氟烷基物质|PFAS]] 的去除。然而，两种吸附剂上 PFBA 的[[脱附|解吸]]仍不可避免，仍是未来研究的课题。此外，尽管 C34%b 的[[堆密度|堆积密度]]与 F400 相当，但其磨损倾向尚未研究，在放大应用前应予以解决。

## 4. 结论

总之，本研究实证揭示了[[亚纳米孔]]（0.56–0.85 nm）在增强短链[[全氟和多氟烷基物质|PFAS]][[吸附]]中的关键作用。我们证明，适度的[[水蒸气活化|蒸汽活化]]能最优地生成这些孔，同时产生高[[等电点]]（[[零电荷点|PZC]]）和低表面[[羧基|-COOH]]基团，从而通过由[[静电相互作用]]主导的[[孔填充]]促进吸附。此外，较大颗粒通过动力学上有利于短链PFAS相较于长链同类进入亚纳米孔，从而改善了性能。相比之下，更高的气化程度和[[化学活化]]使孔径扩大到该范围之外并降低了PZC，对短链PFAS不利，却增强了长链PFAS的去除。在批量实验和[[柱实验]]中，我们优化后的[[生物炭]]对短链和长链PFAS的去除均优于商用[[颗粒活性炭]]（GAC）。尽管这项工作为设计用于改善短链PFAS吸附的吸附剂提供了一种低成本且可规模化的方法，但[[脱附]]仍然是一个固有挑战。未来的工作应着重于进一步提高保留能力，以增强可持续性和更广泛的适用性——潜在途径是在这些孔内调控合适的功能基团。
