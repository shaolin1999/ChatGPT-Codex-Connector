## 摘 要

本研究通过[[原子转移自由基聚合]]（ATRP）及后续氟化胺功能化，成功合成了一种氟化[[多孔聚合物网络]]基[[吸附]]剂，命名为 [[PS-PPN8-F|PS-PPN-F]]，用于高效吸附水环境中的 [[全氟和多氟烷基物质|PFAS]]。多孔聚合物网络的引入使[[聚苯乙烯]]微球的[[BET|比表面积]]从约 110 m² ${ \pmb g } ^ { - 1 }$ 显著增加至 1290 m²，而氟化功能化则赋予其对 PFAS 分子的强[[亲氟作用|亲氟亲和力]]。由 [[Langmuir模型|Langmuir 模型]]得到的最大吸附容量对 [[全氟辛酸|PFOA]] 达到 588.24 mg $g ^ { - 1 }$，对短链 [[全氟丙酸|PFA]] 达到 303.03 mg $g ^ { - 1 }$，均显著高于未改性的 [[PS-PPN8|PS-PPN]]。[[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂|PS-PPN-F]] 还表现出对氟化污染物的显著选择性，对 PFOA 和 [[全氟辛基磺酸|PFOS]] 的去除效率超过 95%，同时对非氟化类似物和[[腐殖酸]]的吸附极少。[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算和[[静电势]]（ESP）分布图进一步揭示，PS-PPN-F 上的氟化区域和氨基基团为 PFAS 分子提供了能量上有利的吸附位点。[[结合能]]介于 −4.31 至 −10.62 kcal mol⁻¹ 之间，为负值，证实了由[[亲氟相互作用|亲氟作用]]、[[疏水作用]]和[[静电相互作用]]协同驱动的自发吸附。此外，该吸附剂表现出优异的再生能力，在使用 pH 9 的 70% 甲醇溶液进行的多次吸附–[[脱附]]循环中仍保持高吸附性能。上述结果表明，PS-PPN-F 是一种高效且可重复使用的吸附剂，在复杂环境水体中选择性修复 PFAS 方面具有巨大潜力。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是一大类合成有机氟化合物，其特征是强[[碳–氟键]]，这赋予了它们优异的化学稳定性、耐热性和表面活性剂性能（Evich et al., 2022）。这些特性使其在工业应用和消费品中得到广泛使用，包括消防泡沫、不粘涂层、防水纺织品和食品包装（Mendes et al., 2025）。然而，支撑其用途的同样稳定性也使PFAS在环境中具有高度持久性，因而被称为“[[永久性化学品]]”。PFAS对常规降解过程具有抗性，导致其在水体、土壤和生物群中累积（Tanzil et al., 2025）。由于PFAS的迁移性和长距离传输能力，其造成的环境污染已成为全球关注的问题。PFAS在地表水、地下水乃至北极等偏远地区频繁检出，表明其具有大气和水文扩散的能力。在水生系统中，PFAS表现出高溶解性和低挥发性，这有利于其持久存在和生物可利用性（Yun et al., 2025）。因此，它们可以进入饮用水供应系统并在食物链中累积。某些PFAS（如[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（[[全氟辛基磺酸|PFOS]]））的[[生物累积]]和[[生物放大作用]]已在城市水系统中频繁检出，包括工业废水、污水处理厂出水、河流、饮用水处理系统和自来水。最近的一项多介质传输研究报告称，制造园区废水中的总PFAS浓度为30.28–3738.51 ng/L，自来水中的总PFAS浓度为27.95–84.72 ng/L，证实了PFAS在城市水生环境中的广泛存在和持久性（Zhang et al., 2025）。因此，PFAS可以进入饮用水供应系统并在食物链中累积。PFAS暴露的毒理学影响正日益得到认识。流行病学和实验研究已将PFAS与不良健康结局联系起来，包括[[内分泌干扰]]、[[免疫毒性]]、[[发育毒性]]和某些癌症风险增加（van Gerwen et al., 2023; Lin et al., 2021）。[[美国环境保护署]]（U.S. EPA）已针对PFOA和[[全氟辛磺酸|PFOS]]提出低至4 ng/L的[[最大污染物水平]]（MCLs），反映出对接近零暴露的需求。同样，欧盟根据《[[饮用水指令]]》将饮用水中PFAS总量的限值设定为100 ng/L。一些国家采用了更为严格的预防性限值，强调了有效控制PFAS的紧迫性（London et al., 2024）。因此，从水环境中去除PFAS至关重要。

常规水处理工艺，如[[混凝]]（Gu et al., 2026）、[[沉淀]]（Ndubueze et al., 2024）和[[生物降解]]（Mekureyaw et al., 2025），由于 [[全氟和多氟烷基物质|PFAS]] 的难降解特性而在很大程度上效果不佳。高级处理技术，包括[[吸附]]（Meservey et al., 2026; Rückbeil et al., 2025）（如[[活性炭]]、[[离子交换树脂]]）、膜过滤（Masters et al., 2025; Ekande et al., 2026）（如[[纳滤]]、[[反渗透]]）以及高级氧化/还原过程（Samejo et al., 2025），已被探索并取得不同程度的成功。活性炭，包括[[颗粒活性炭]]（GAC）和[[粉末活性炭]]（PAC）形式，是用于 PFAS 去除的最广泛使用的吸附剂（Hubert et al., 2024）。其性能主要依赖于[[疏水相互作用]]和孔填充机制。GAC 对长链 PFAS（如 [[全氟辛基磺酸|PFOS]] 和 [[全氟辛酸|PFOA]]）相对有效；然而，它对短链 PFAS 表现出较差的亲和力，而短链 PFAS 由于监管替代正变得越来越普遍（Kennedy et al., 2025）。此外，水中[[天然有机物]]（NOM）会竞争吸附位点，显著降低效率（Jais et al., 2024）。需要频繁再生或更换，导致运营成本增加和二次废物产生。离子交换树脂，特别是阴离子交换树脂，通过带正电荷的官能团与带负电荷的 PFAS 分子之间的[[静电相互作用]]，已显示出对 PFAS 的更高选择性（Shahrokhi et al., 2024）。尽管与活性炭相比其性能有所改善，但这些材料会受到共存阴离子（例如硫酸根、硝酸根）和有机物的污染。此外，树脂再生通常需要浓盐或溶剂溶液，产生二次盐水废物并引发环境问题（Naidu et al., 2020）。先进纳米材料，包括[[碳纳米管]]（Bui et al., 2024）、[[石墨烯]]（Behroozi et al., 2025）、[[氧化石墨烯]]（Pla et al., 2025）和[[金属有机框架]]（MOFs）（Taghizad et al., 2025; Abouzied et al., 2026），因其高[[BET|比表面积]]和可调表面化学性质而受到关注。这些材料可以被工程化以增强与 PFAS 的特定相互作用，例如[[亲氟作用|亲氟亲和力]]或静电吸引。然而，它们的实际应用受到高合成成本、潜在毒性以及大规模生产挑战的限制。此外，水相条件下的稳定性以及材料浸出风险仍然是关键问题。基于聚合物的吸附剂，包括功能化多孔聚合物和超分子体系，由于其结构多样性和可调功能而提供有前景的替代方案（Tighe et al., 2024; Zhang et al., 2025）。然而，其中许多体系仍处于早期开发阶段，并面临与机械稳定性、再生效率和长期耐久性相关的挑战。

[[多孔聚合物网络|功能化多孔聚合物网络]]（PPNs）因其高[[BET|比表面积]]、可调[[孔隙率]]和多样的化学功能性，已成为一类用途广泛的环境修复[[吸附]]材料。PPNs通过有机构筑单元的共价连接构建而成，表现出优异的化学稳定性和热稳定性，因而特别适用于严苛条件下的吸附过程（Karmakar et al., 2026）。通过向聚合物骨架中引入特定官能团，这些材料可被设计为通过多种相互作用机制选择性捕集目标污染物（Condes et al., 2024）。功能化PPNs的关键优势之一在于其结构设计的灵活性。诸如胺基（Sekizkardes et al., 2022）、羧基（Zhou et al., 2019）、磺酸基（da Fonseca et al., 2026）和季铵基（Gao et al., 2026）等官能团，或氟亲和配体（Pezoulas et al., 2025），均可在聚合过程中或通过后合成修饰引入。这些功能性使材料能够通过[[静电相互作用|静电吸引]]、[[氢键]]、[[π–π堆积]]和[[疏水相互作用]]与污染物发生强相互作用。例如，带正电的基团可增强对包括[[全氟和多氟烷基物质|PFAS]]在内的阴离子污染物的吸附，而芳香结构域则通过π–π堆积促进与有机污染物的相互作用。在水相体系中，PPNs凭借其相互连通的多孔结构促进高效传质，展现出高吸附容量和快速动力学。与[[活性炭]]等传统吸附剂相比，PPNs可被设计为对特定污染物表现出更高的选择性，即使在存在竞争性物种（如[[天然有机物|NOM]]（Sun et al., 2025）或无机离子（Wang et al.,

## 2. 实验部分

## 2.1. 材料

苯乙烯和对二乙烯基苯购自Sigma-Aldrich，用于制备吸附剂。选择全氟和多氟烷基物质（PFAS），包括代表性的三氟乙酸（TFA，CF COOH，CAS号76–05–1）、全氟丙酸（PFA，$\mathrm { C F } _ { 3 } \mathrm { C F } _ { 2 } \mathrm { C O O H } ,$，CAS号422–64–0）、全氟丁酸（PFBA，$\mathrm { C F _ { 3 } C F _ { 2 } C F _ { 2 } C O O H }$，CAS号375–22–4）、全氟辛酸（PFOA，$\mathrm { C F } _ { 3 } ( \mathrm { C F } _ { 2 } ) _ { 6 } \mathrm { C O O H }$，CAS号335–67–1）和全氟辛烷磺酸（PFOS，$\mathrm { C F _ { 3 } ( C F _ { 2 } ) _ { 7 } S O _ { 3 } H } ,$ CAS号1763–23–1），用于测试PS-PPN-F的吸附性能。辛酸[OA，$\mathrm { C H _ { 3 } ( C H _ { 2 } ) _ { 6 } C O O H } ,$ CAS号124–07–2]、1-辛烷磺酸钠盐[OAS，$\mathrm { C H _ { 3 } ( C H _ { 2 } ) _ { 6 } C H _ { 2 } S O _ { 3 } N a \cdot H _ { 2 } O } ,$ CAS号207596–29–0]和腐殖酸（HA，CAS号1415–93–6）用于测试吸附选择性。四(4-溴苯基)甲烷[TBM，$\mathrm { C _ { 2 5 } H _ { 1 6 } B r _ { 4 } } ,$ CAS号105309–59–9]、四(三苯基膦)钯(0) $( \mathrm { P d } ( \mathrm { P P h } _ { 3 } ) _ { 4 } ,$ CAS号14221–01–3)、4,4’-联苯二硼酸（BDA，$\mathrm { ( H O ) _ { 2 } B C _ { 6 } H _ { 4 } C _ { 6 } H _ { 4 } B ( O H ) _ { 2 } } ,$ CAS号4151–80–8）、2,2’-联吡啶 $\mathrm { [ C _ { 1 0 } H _ { 8 } N _ { 2 } , }$ CAS号366–18–7]、多聚甲醛 $\mathrm { [ ( C H _ { 2 } O ) _ { n } , }$ CAS号30525–89–4]购自Acros Organics。冰醋酸 $\mathrm { [ C H _ { 3 } C O _ { 2 } H , }$ CAS号64–19–7]、磷酸 $\mathrm { [ H _ { 3 } P O _ { 4 } , }$ CAS号7664–38–2]和盐酸[HCl，CAS号7647–01–0]、2,2,3,3,4,4,4-七氟丁胺（HFBA，$\mathrm { C _ { 4 } H _ { 4 } F _ { 7 } N , }$，CAS号374–99–2）和过硫酸钾（KPS，${ \mathrm { K } } _ { 2 } { \bf S } _ { 2 } { \bf O } _ { 8 } ,$ CAS号7727–21–1）也购自Sigma-Aldrich。所有溶剂均购自Sigma-Aldrich、Alfa Aesar或Acros Organics，且未经纯化直接使用。

## 2.2. [[多孔聚合物网络|PPN]]的合成

聚合通过[[四(4-溴苯基)甲烷|TBM]]的芳基溴基团与[[4,4'-联苯二硼酸|BDA]]的硼酸基团之间的[[Suzuki-Miyaura交叉偶联]]进行，形成扩展的C-C键合芳香网络。将[[溴化四苯基甲烷|TBM]]（318 mg，0.50 mmol，1.0当量）、BDA（242 mg，1.00 mmol，2.0当量）和Pd(PPh₃)₄（58 mg，0.050 mmol）加入配备磁力搅拌子的100 mL Schlenk烧瓶中（Jeddi et al., 2024）。将烧瓶抽真空并用氮气回填三次。随后加入脱气的DMF混合溶剂（30 mL），再加入2.0 M ${ \mathrm { K } } _ { 2 } { \mathrm { C O } } _ { 3 }$水溶液（5 mL）。反应混合物通过鼓入氮气进一步脱气20 min，然后在氮气保护下于$9 0 ^ { \circ } \mathrm { C }$剧烈搅拌加热72 h。冷却至室温后，收集所得固体[[沉淀]]并过滤，依次用水和二氯甲烷洗涤，以去除无机盐、残留单体和催化剂残留物。粗产物进一步用甲醇、丙酮和THF分别索氏提取24 h。最后，产物在$1 0 0 { - } 1 1 0 ^ { \circ } \mathrm { C }$真空干燥12 h，得到联苯连接的 porous polymer network，为浅棕色至棕色粉末。

## 2.3. [[苯乙烯]]的电子转移再生活化剂（AGET）乳液[[原子转移自由基聚合|ATRP]]

[[多孔聚合物网络|PPN]]-Cl 根据先前报道的方法略作修改合成（Vatankhah et al., 2025）（方案 1a）。将 PPN、[[多聚甲醛]]、冰醋酸、磷酸和盐酸加入 150 mL 压力容器中，并在 $9 0 ^ { \circ } \mathbf { C } .$ 下搅拌 3 d。过滤混合物，收集的固体用甲醇洗涤后，在 $1 1 0 ~ ^ { \circ } \mathrm { C }$ 真空干燥，得到棕褐色粉末状 PPN-Cl。方案 1b 展示了以 PPN-Cl 作为大分子引发剂进行 AGET 乳液聚合的合成路线。[[聚苯乙烯]]微球的合成按照 [[Matyjaszewski]] 及其同事所述方法修改后进行（Min et al., 2006）。铜配合物的制备方法为：将 CuBr（0.035 mol）和 2,2’-联吡啶（0.053 mol）溶解于[[苯乙烯]]（0.25 mol）与[[对二乙烯基苯]]（0.05 mol）的混合物中，并在 $6 0 ~ ^ { \circ } \mathrm { C } .$ 下进行。随后将不同浓度的大分子引发剂 PPN-Cl 加入该混合物中。然后将混合物加入 200 mL 水中，在机械搅拌和氮气环境下脱氧 30 min，形成乳液。同时向乳液中注入 KPS 引发剂（0.44 mmol）和预先脱氧的抗坏血酸水溶液。用氮气吹扫乳液 30 min 后，将烧瓶浸入 $8 0 ^ { \circ } \mathrm { C }$ 的油浴中。聚合 24 h 后，将溶液冷却至室温并离心，得到 PPN-Cl 浓度分别为 0、2、4、6、8 和 10 wt% 的 [[PS-PPN8|PS-PPN]]-C 粉末，分别标记为 PS-PPN0、PS-PPN2、PS-PPN4、PS-PPN6、PS-PPN8 和 PS-PPN10。用去离子水洗涤三次以去除未反应组分后，PS-PPN 样品在使用前进行干燥。

## 2.4. [[PS-PPN8-F|PS-PPN-F]] 的制备

[[PS-PPN8-F|PS-PPN-F]] 采用 HFBA 制备，如方案 1b 所示。[[PS-PPN8|PS-PPN]] 的功能化按照修改后的文献方法进行（Palomo et al., 2001; Pezoulas et al., 2025; He et al., 2022）。将 HFBA（0.5 g）加入含有 [[聚苯乙烯|PS]]-[[多孔聚合物网络|PPN]]-Cl（1.2 g）的 75 mL 密封反应容器中。反应混合物在 $4 5 ^ { \circ } \mathrm { C }$ 下持续搅拌保持 3 天。反应结束后，通过过滤收集固体产物，并用甲醇（500 mL）充分淋洗。在 $5 0 ~ ^ { \circ } \mathrm { C }$ 下真空干燥，得到浅棕色粉末状 [[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂|PS-PPN-F]]，最终质量为 1.34 g。这些样品标记为 PS-PPN(number)-F，其中 number 表示 PPN-Cl 含量。形貌通过 [[Phenom G2 Pro显微镜|Phenom G2 Pro 显微镜]]的顶视[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）进行表征。氮气[[吸附]]–[[脱附]]测量在 77 K 下使用 [[Belsorp-Max分析仪|Belsorp-Max 分析仪]]进行，以测定 Brunauer–Emmett–Teller（[[BET]]）[[比表面积]]。

## 2.5. 使用 [[PS-PPN8-F|PS-PPN-F]] [[吸附]] [[全氟和多氟烷基物质|PFAS]]

采用 [[PS-PPN8-F|PS-PPN-F]] 进行[[吸附]]实验，以评价其对短链 [[全氟丙酸|PFA]] 和长链 [[全氟辛酸|PFOA]] 的吸附行为。将 PFA 和 PFOA 的储备液（20 mL）配制于去离子水中，随后稀释得到初始浓度为 0 至 1000 mg/L 的工作溶液。在[[吸附等温线]]研究中，将约 5 mg 吸附剂加入不同初始浓度的工作溶液中，并以 500 rpm 搅拌。24 h 后，从每个样品中收集 1 mL 等分试样用于分析。当至少连续三个取样间隔内最终浓度变化小于 ±5% 时，认为达到平衡。PFA 和 PFOA 的浓度采用 ExionLC AD [[超高效液相色谱]]（UPLC）系统，结合 AB Sciex QTRAP 5500 质谱仪（[[质谱法|MS]]）进行定量测定，该质谱仪配备[[电喷雾电离]]（ESI）源。分析前，对收集的样品进行预处理以去除悬浮杂质，并根据优化的样品前处理程序对 [[全氟和多氟烷基物质|PFAS]] 进行富集/提取（Zhang et al., 2025）。所制备的溶液采用超高效液相色谱系统结合[[串联三重四极杆质谱仪]]进行分析，该质谱仪在电喷雾电离负离子模式下运行。采用[[多反应监测]]对目标 PFAS 化合物进行选择性检测和定量。定量使用[[同位素标记内标]]和[[外标校准曲线]]进行。校准曲线在适当浓度范围内建立，线性良好，相关系数高于 0.99。为确保分析准确性并尽量减少可能的污染，将程序空白、溶剂空白和加标回收样品与样品同时分析。空白样品中未检出高于方法检出限的目标 PFAS。回收率和[[相对标准偏差]]均在可接受范围内，证实了分析方法的可靠性和重复性。[[平衡吸附容量]]（Q）根据浓度差和已知的 [[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂|PS-PPN-F]] 质量计算，如式（1）所述（Chen et al., 2024）。

## 3. 结果与讨论

## 3.1. [[多孔聚合物网络|PPN]]-PM-F 的表征

} 3 0 5 0 \ \mathrm { c m ^ { - 1 } }$ ，并伴有位于约 1591 和 ${ \sim } 1 4 9 5 ~ \mathrm { c m ^ { - 1 } }$ 处的明显谱带，对应于芳香环骨架振动。在 $\mathbf { o f } \sim 1 2 5 0 \ \mathrm { c m ^ { - 1 } }$ 和 ${ \sim } 8 2 4 ~ \mathrm { c m ^ { - 1 } }$ 区域内的其他峰归属于芳基醚（C–O–C）和取代苯环振动，证实了三苯基苯基单体结构的存在（Errahali et al., 2014）。对于 PPN，特征芳香族信号（包括位于 $\sim 3 0 4 5 , \sim 1 5 9 1$ 和 ${ \sim } 1 4 9 5 ~ \mathrm { c m ^ { - 1 } }$ 处的峰）得以保留，表明 π-共轭骨架得到保持。在 ${ \sim } 3 4 0 0 ~ \mathrm { c m ^ { - 1 } }$ 附近没有出现宽谱带，说明没有明显的羟基或胺基残留，证实了高度[[交联]]多孔网络的成功形成。氯化后，PPN-Cl 在 ${ \sim } 1 0 8 9 \mathrm { c m } ^ { - 1 }$ 和 ${ \sim } 6 3 1 ~ \mathrm { c m ^ { - 1 } }$ 处出现新的吸收谱带，可归属于 C–Cl 伸缩振动。这些峰的出现同时保持了芳香主链信号，清楚表明后官能化成功实现且聚合物骨架未发生结构降解。PS 的光谱显示出典型的聚苯乙烯特征，包括芳香族 C–H 伸缩振动 $( \sim 3 0 4 5 \mathrm { c m ^ { - 1 } ) }$ 、强芳香骨架振动 $( \sim 1 5 9 4 , 1 4 9 5 ,$ 和 $1 4 4 5 \mathrm { c m ^ { - 1 } } )$ ，以及约 756 和 ${ \sim } 6 9 8 ~ \mathrm { c m ^ { - 1 } }$ 处的面外 C–H 弯曲振动。此外，约 2920 和 ${ \sim } 2 8 5 0 ~ \mathrm { c m ^ { - 1 } }$ 处的谱带对应于聚合物主链的脂肪族 C–H 伸缩振动。对于 [[PS-PPN8|PS-PPN]] 复合材料（PS-PPN2、PS-PPN6、PS-PPN10），FTIR 光谱显示出 PS 和 PPN-Cl 两者的特征组合。值得注意的是，特征 PPN-Cl 峰 $( \sim 1 0 8 9 , \sim 1 0 2 2$ $\sim 8 2 9 , \mathrm { a n d } \sim 6 3 2 \mathrm { c m ^ { - 1 } } )$ 的强度随 PPN-Cl 负载量增加而逐渐增强，证实 PPN-Cl 被成功引入并均匀分散在 PS 基体中（Shen et al., 2019）。同时，PS 相关峰的持续存在表明复合物形成过程中聚合物主链保持完整。${ \sim } 2 9 2 0 { \sim } 2 8 5 0 ~ \mathrm { c m ^ { - 1 } }$ 区域的相对增强进一步反映了来自 PS 基体的脂肪族链段的贡献。氟化后，PS-PPN10-F 表现出显著的光谱变化。在 ${ \sim } 1 2 4 0 { \mathrm { - 图3a展示了不同PPN含量的PS和PS-PPN-F复合材料样品的N₂吸附–脱附等温线。所有样品均表现出随着相对压力$\left( \mathrm { P } / \mathrm { P } _ { \circ } \right)$的增加，氮气吸附量持续上升，表明存在多级孔结构。与原始PS相比，PS-PPN-F复合材料显示出显著增强的吸附容量，证实PPN的引入有效提高了材料的比表面积和孔体积。原始PS在整个压力范围内表现出最低的氮气吸附容量，表明其结构相对致密且孔隙有限。引入PPN后，吸附容量随PPN含量增加而逐步增大。与原始PS相比，PS-PPN2-F的氮气吸附量呈现中等程度的增加，表明多孔聚合物网络开始引入额外的多孔区域。当PPN含量增加到4 wt%和6 wt%时，吸附等温线显示出显著更高的吸附容量，证明成功构建了具有更大可及表面积的多级孔结构。进一步将PPN负载量提高到8 wt%和10 wt%时，氮气吸附容量显著增强。特别是PS-PPN10-F在所有样品中表现出最高的吸附体积，表明其具有最大的比表面积和孔体积。低相对压力下氮气的快速吸附表明存在丰富的微孔结构，而在中、高$\mathrm { { P } } / \mathrm { { P } } _ { \circ }$区域吸附量逐渐增加，则表明介孔和大孔特征共存。此外，高相对压力下观察到的吸附–脱附滞后现象表明介孔结构内发生了毛细管凝聚。随着PPN负载量提高，滞后回环逐渐变得更加明显，进一步证实了相互连通的介孔网络的发展。这些结果与SEM观察结果一致，即PPN含量的增加使表面形貌逐渐由光滑转变为粗糙多孔。图3b总结了不同PPN负载量下PS-PPN-F复合材料的BET比表面积。将PPN引入PS基体后，比表面积显著增加，证实成功构建了多级孔结构。原始PS由于形貌相对致密光滑，表现出最低的BET比表面积，约为$1 1 0 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$。添加2 wt% PPN-Cl后，BET比表面积急剧增加至约$4 9 5 \mathrm { \ m } ^ { 2 } \mathrm { g } ^ { - 1 }$，表明多孔PPN区域在PS基体中均匀分散，并有效引入了大量可及的微孔和介孔。当PPN-Cl含量增加到4 wt%至8 wt%时，BET比表面积进一步分别增加到约777和952 $\mathbf { m } ^ { 2 } ~ g ^ { - 1 }$。这一显著提升表明，适量引入PPN-Cl促进了相互连通多孔网络的形成，并提高了可及纳米多孔区域的密度。图3b中的示意插图进一步支持了这一解释，即低PPN-Cl负载量对应孤立的多孔区域，而较高负载量则促进多孔骨架的相互连接，从而生成连续的三维多孔通道。这种相互连通的多孔结构有利于提高孔的可及性并促进质量传输。然而，当 当 PPN-Cl 负载量进一步提高至 10 wt%时，BET 比表面积略微下降至约 $8 9 9 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 }$ 。这种降低可归因于过量 PPN 结构域在 PS 基体中的部分团聚。在高 PPN-Cl 浓度下，过度团聚可能产生更大的孔或部分塌陷的多孔结构，从而降低有效可及表面积并减少微孔的贡献。这一现象与 SEM 观察结果一致，即过量 PPN 负载导致表面更粗糙，并伴随孔隙空腔扩大和局部团聚。适度的 PPN-Cl 掺入促进了均匀分散及互连多级孔网络的形成，而过量负载则引发团聚效应，略微降低了可及表面积。因此，PS-PPN8-F 在孔网络形成与结构稳定性之间实现了平衡，从而获得最大的 BET 比表面积并可能增强吸附性能。

两种材料的[[吸附]]容量均随平衡浓度的升高而增大，表明[[全氟和多氟烷基物质|PFAS]]分子与多孔吸附剂之间存在强相互作用。值得注意的是，无论对短链[[全氟丙酸|PFA]]还是长链[[全氟辛酸|PFOA]]，[[PS-PPN8-F]]始终表现出显著高于原始[[PS-PPN8]]的吸附容量，证明氟化功能化有效提升了PFAS吸附性能。在PFA吸附方面（图4a），[[聚苯乙烯|PS]]-PPN8-F表现出最大吸附容量 $( Q _ { m } )$ 为 303.03 mg $g ^ { - 1 }$ ，高于 PS-PPN8（277.78 mg $g ^ { - 1 } )$ 对于 PFOA（全氟辛酸）吸附而言，这种增强效应变得更加显著（图 4b），其中 PS-PPN8-F 实现了显著较高的 $Q _ { m }$ 588.24 毫克 ${ \pmb g } ^ { - 1 }$ ，几乎是 PS-PPN8（322.58 mg）的两倍 $g ^ { - 1 } )$ . 这一结果表明，氟化改性显著提高了对长链PFAS分子的亲和力。与PFA相比，PFOA的更强吸附可归因于其更长的全氟烷基链 PFOA 增强了 PFAS 分子与氟化多孔表面之间的[[疏水相互作用]]和[[亲氟相互作用]]。[[Langmuir 等温线模型]]对所有吸附体系均提供了优异的拟合，相关系数（R²）范围为 0.9978 至 0.9996。这表明 PFAS 吸附主要在相对均一的吸附位点上遵循单层吸附行为。有利的 [[Langmuir模型|Langmuir]] 分离因子（a）进一步证实了吸附剂对两种 PFAS 化合物均具有高效的吸附亲和力。[[Freundlich模型|Freundlich]] 模型也显示出相当好的拟合效果，表明多孔框架上同时存在非均相吸附位点。PS-PPN8-F 的 Freundlich 常数 $K _ { F }$ 对 PFA 和 PFOA 均显著高于 PS-PPN8，证实了氟化功能化后吸附亲和力的增强。特别是，[[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂|PS-PPN-F]] 对 PFOA 吸附的 $K _ { F }$ 值达到 66.63，表明存在极强的吸附相互作用。此外，所有 Freundlich n 值均大于 1， 表明吸附行为良好。PS-PPN8-F 对 PFA（4.70）和 PFOA（3.19）的 n 值表明吸附强度较高，且 PFAS 分子与氟化多孔表面之间存在高效相互作用。PS-PPN8-F 增强的吸附性能可归因于多种协同机制。首先，[[多级孔结构]]提供了丰富的可及吸附位点，并有利于快速传质。其次，芳香骨架提供了 [[π-π 相互作用|π-π]] 和疏水相互作用。更重要的是，在多孔骨架上引入氟化基团增强了氟化吸附剂表面与 PFAS 分子之间的亲氟相互作用，显著提高了吸附亲和力，特别是对长链 PFOA。此外，吸附剂上的官能团与 PFAS 分子之间的[[静电相互作用]]可能进一步促进吸附。[[吸附等温线]]结果清楚地表明，氟化官能化有效提高了 PS-PPN8 材料的 PFAS 吸附性能。优异的 Langmuir 拟合、高吸附容量以及有利的 Freundlich 参数证实，PS-PPN8-F 具有强吸附亲和力和高度可及的孔隙吸附位点，使其成为高效去除水环境中 PFAS 的有前景的吸附剂。

## 3.3. pH 对去除效率、选择性和重复使用性的影响

图6a展示了溶液pH对PS-PPN16-F去除TFA、PFA、PFBA、PFOA和PFOS效率的影响。吸附性能强烈依赖于溶液pH，表明静电相互作用在PFAS吸附过程中发挥了重要作用。在酸性条件下（pH 3–6），PS-PPN8-F对所有PFAS化合物均表现出极高的去除效率，普遍超过95%（Chen et al., 2026）。为进一步阐明pH依赖的吸附行为，将PS和PS-PPN8-F的Zeta电位结果与PFAS物种分布一起分析（图S5）。在整个研究的pH范围内，两种材料的Zeta电位均保持为负值，但在酸性条件下负电性减弱，随pH升高而变得更加负电。此外，PS-PPN8-F的表面电位比原始PS更不负电，表明表面改性降低了对阴离子PFAS的静电排斥。就PFAS形态而言，在所研究的pH范围内，PFOS主要以阴离子形式存在，PFOA也主要以阴离子形式存在，尽管在强酸性条件下PFOA可能发生部分质子化。因此，酸性条件下PFAS去除效果的增强源于静电排斥减弱、氟化结构域与PFAS链之间有利的氟亲和相互作用以及与聚合物骨架的疏水相互作用的共同效应。在碱性条件下，更强的负表面电荷增加了静电排斥并削弱了吸附，导致去除效率降低。因此，PFAS分子在酸性条件下表现出增强的吸附亲和力。随着pH从中性升高至碱性条件（pH 7–10），去除效率逐渐下降，尤其是对TFA和PFA等短链PFAS化合物。在较高pH值下，氢氧根离子浓度增加以及吸附剂表面和PFAS分子上负电荷密度的增强，加剧了静电排斥，从而抑制了吸附。在碱性环境中，PFAS分子主要以完全解离的阴离子形式存在，这进一步削弱了其与带负电的PS基骨架之间的吸附相互作用。在所研究的PFAS化合物中，长链PFAS物种（包括PFOA和PFOS）即使在碱性条件下仍保持相对较高的去除效率。这一结果表明，疏水相互作用和氟亲和相互作用对长链PFAS分子的吸附贡献显著。PFOA和PFOS较长的氟碳链提供了更强的范德华相互作用和氟-氟亲和力，与氟化多孔表面作用更强，从而部分补偿了高pH下不利的静电排斥。图6b比较了PS-PPN8和PS-PPN8-F对PFOA、PFOS、OA、OS和HA的吸附选择性。结果清楚地表明，氟化功能化显著增强了对PFAS化合物的选择性吸附行为。PS-PPN8-F对PFOA和PFOS表现出极高的去除效率，分别达到约96%和95%。相比之下，对结构相似的非氟化化合物（包括OA和OS）的去除效率极低，保持在10%以下。此外，在自然水体中常以溶解性有机质形式存在的HA在PS-PPN16-F上也几乎没有吸附。这些结果有力地表明 氟化多孔骨架对氟化污染物而非一般疏水性有机分子具有显著的选择性。PS-PPN8-F 的高选择性吸附行为主要归因于吸附剂表面氟化基团与 PFAS 分子全氟烷基链之间强烈的亲氟相互作用。氟化官能团的引入形成了富氟界面环境，促进了有利的 F–F 相互作用，并增强了对氟化化合物的亲和力。尽管 OA 和 OS 具有与 PFOA 和 PFOS 相似的碳链长度和官能团，但由于缺乏氟化链，其与氟化多孔表面的相互作用显著减弱，导致吸附量非常有限。相比之下，原始 PS-PPN8 对 PFOA 和 PFOS 的去除效率显著较低，分别约为 54% 和 52%。有趣的是，与 PS-PPN8-F 相比，PS-PPN8 对 OA、OS 和 HA 表现出明显更高的吸附量。这一行为表明，非氟化 PS-PPN8 上的吸附主要受非选择性疏水相互作用和非特异性表面吸附控制。HA 含有丰富的芳香族和含氧官能团，可通过疏水相互作用和 π–π 相互作用与芳香族多孔骨架发生作用，从而在 PS-PPN8 上产生更高的吸附量。氟化修饰后，吸附行为从非特异性有机吸附转变为高选择性 PFAS 吸附。氟化表面显著抑制了对非氟化有机化合物和天然有机质的吸附，同时保持了对氟化污染物的极高亲和力。这种选择性对于实际 PFAS 修复非常有利，因为天然水体通常含有大量竞争性有机物质，它们可能占据吸附位点并降低去除效率。结果清楚表明，氟化官能化有效地将 PS-PPN8 转化为高度 PFAS 选择性的吸附剂。对 PFOA 和 PFOS 的优异选择性源于亲氟相互作用、疏水相互作用和层级多孔吸附位点的协同作用，同时非氟化有机化合物的吸附被有效抑制。

$$
\mathrm{E} _ {\text { ads }} = \left(\mathrm{E} _ {\text { surface }} + \mathrm{E} _ {\text { molecule }}\right) - \mathrm{E} _ {\text { system }} + \mathrm{E} _ {\text { BSSE }}\tag{6}
$$

其中$\mathrm { E _ { s y s t e m } }$表示[[吸附]]质–吸附剂复合物的总能量，而 Esurface 和 Emolecule 分别对应于孤立吸附剂表面和吸附质分子的能量。$\mathrm { E _ { B S S E } }$表示对 [[基础集叠加误差|BSSE]] 的均衡校正项。计算得到的$\mathrm { { E _ { a d s } } }$值以 eV 表示，数值越高表明吸附相互作用越强。原子电荷分布采用 [[CM5电荷模型|CM5 电荷模型]]进行评估（Marenich et al., 2012）。此外，利用 [[Multiwfn|Multiwfn 3.8]] 对电子密度进行了拓扑分析，以识别和表征[[键临界点]]（BCPs），并获得相关的[[分子中原子量子理论]]（QTAIM）参数（Lu and Chen, 2012）。优化后的分子结构使用 [[VMD]] 和 [[Chemcraft]] 进行可视化和渲染。所有计算得到的[[结合能]]（ΔE）均为负值，证实吸附过程在热力学上是有利的。结合能的大小强烈依赖于 [[全氟和多氟烷基物质|PFAS]] 结构和吸附位点，表明多种分子间相互作用对吸附行为具有协同贡献。对于乙烯基基团，[[全氟辛酸|PFOA]] 和 [[全氟辛基磺酸|PFOS]] 均观察到相对较弱的相互作用，结合能分别为$\mathbf { \delta f - 1 8 . 6 \ a n d - 2 0 . 3 \ k J \ m o l ^ { - 1 } }$。该位点的吸附主要归因于[[疏水相互作用]]以及 [[PS-PPN8-F|PS-PPN-F]] 芳香骨架与 PFAS 分子氟化碳链之间的弱 [[π–π相互作用|π–π 相互作用]]。[[全氟辛烷磺酸|PFOS]] 的结合略强于 PFOA，这可能与 [[全氟辛磺酸|PFOS]] 更大的分子尺寸和更高的疏水性有关。相比之下，含 F 基团表现出显著增强的吸附亲和力，PFOA 的结合能为 −31.7 kJ mol⁻¹，PFOS 为 −34.2 kJ $\mathrm { m o l ^ { - 1 } }$。氟化表面促进了富氟 PFAS 链与 [[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂|PS-PPN-F]] 氟化官能团之间强烈的[[亲氟相互作用]]。这些结果表明，吸附剂的氟化通过特异性 F–F 相互作用和增强的疏水缔合有效强化了 PFAS 吸附。在所有吸附位点中，氨基基团表现出最强的结合相互作用，PFOA 和 PFOS 的结合能分别达到 41.6 和 45.3 kJ mol⁻¹。在氨基位点观察到的最短相互作用距离表明，PFAS 头基中富电子氧原子与 [[PS-PPN8|PS-PPN]]-F 氨基官能团之间形成了强静电引力和[[氢键]]相互作用。与 PFOA 相比，PFOS 的更强相互作用可归因于磺酸基团更高的极性和吸电子特性，这增强了其与氨基位点的[[静电相互作用]]。[[DFT]] 结果表明，[[聚苯乙烯|PS]]-[[多孔聚合物网络|PPN]]-F 优异的吸附性能来源于疏水相互作用、[[亲氟作用|亲氟亲和力]]、氢键和静电引力的协同贡献。氨基和氟化基团在 PFAS 捕获中起主导作用，而乙烯基基团主要贡献辅助性疏水相互作用。这些发现与实验吸附结果高度一致，并进一步证实了氟化多孔聚合物网络用于选择性去除 PFAS 的有效性。计算得到的结合能顺序也与实验观察到的 pH 依赖性吸附/[[脱附]]行为高度吻合。[[密度泛函理论|DFT]] 结果表明，氨基基团为两者均提供了最强的结合位点。 PFOA 和 PFOS，其次是含氟基团和乙烯基，表明静电吸引和氢键是主要驱动力，而亲氟和疏水相互作用进一步稳定了 PFAS 吸附。实验上，PFAS 吸附在酸性至弱碱性条件下更有利，这可归因于含氨基位点的质子化以及对阴离子 PFAS 头基的静电吸引增强。相反，在碱性再生条件下，表面官能团的去质子化和氢氧根离子的存在削弱了静电吸引和氢键，从而促进了 PFAS 解吸。与 PFOA 相比，PFOS 的计算结合能更强，这也与其更强的极性以及磺酸基团与氨基位点介导的相互作用一致。因此，pH 敏感的吸附/解吸行为为 DFT 推导的相互作用顺序提供了实验证据，证实 PS-PPN-F 对 PFAS 的捕获由静电、氢键、亲氟和疏水相互作用的协同作用所控制。

## 4. 结论

通过 [[原子转移自由基聚合|ATRP]] 辅助引入[[多孔聚合物网络]]，再进行氟化胺修饰，成功合成了[[氟化多孔聚合物网络功能化聚苯乙烯微球吸附剂]]（[[PS-PPN8-F|PS-PPN-F]]）。由此形成的层级多孔结构与氟化官能团相结合，显著增强了对 [[全氟和多氟烷基物质|PFAS]] 污染物（包括 [[全氟辛酸|PFOA]] 和 [[全氟辛基磺酸|PFOS]]）的[[吸附]]性能。PPN 的引入有效提高了 [[BET比表面积|BET 比表面积]]，大幅改善了孔道可及性与传质效率。吸附研究表明，与未改性的 [[PS-PPN8|PS-PPN]] 相比，[[聚苯乙烯|PS]]-PPN-F 的吸附容量和[[吸附动力学]]均显著提升。由 [[Langmuir模型|Langmuir 模型]]得到的最大吸附容量分别为 PFOA 588.24 mg $g ^ { - 1 }$ 和 [[全氟丙酸|PFA]] 303.03 mg $g ^ { - 1 }$，表明其对长链和短链 PFAS 分子均具有强吸附亲和力。吸附性能的增强归因于层级孔隙、[[疏水相互作用]]、[[亲氟作用|亲氟亲和力]]、[[π–π相互作用|π–π 相互作用]]以及由氟化和氨基官能团引入的[[静电相互作用]]的协同贡献。酸性至弱碱性条件有利于 PFAS 吸附，而解吸实验表明，pH 9 的 70% 甲醇水溶液对 PFOA 和 [[全氟辛烷磺酸|PFOS]] 均具有最高的再生效率。此外，PS-PPN8-F 对氟化污染物表现出显著的选择性，在存在竞争离子和有机物的情况下仍能保持对 PFOA 和 [[全氟辛磺酸|PFOS]] 的高去除效率。循环实验证明其具有优异的可重复使用性，经过 15 次吸附–解吸循环后仍保持 80% 以上的吸附效率，表明其具有良好的结构稳定性和再生能力。本研究表明，PS-PPN-F 是一种用于 PFAS 修复的高效、高选择性且可重复使用的吸附剂。层级多孔结构与亲氟功能化的结合为提升 PFAS 吸附性能提供了一种有效策略。这些发现凸显了氟化多孔聚合物基吸附剂在涉及持久性氟化污染物的实际水净化和环境修复应用中具有巨大潜力。
