## 摘要

[[水系锌离子电池|水系锌离子电池（AZIBs）]]的可逆性和可持续性受到由 $\mathrm { H } _ { 2 } \mathrm { O }$ 富集的[[电双层]]（[[双电层|EDL]]）和不稳定的[[固体电解质界面]]（SEI）引起的界面问题的严重损害。本文引入微量[[生物分子]]添加剂[[透明质酸锌]]（HA-[[Zn]]），协同构建富含[[晶界]]的 SEI 和 $\mathrm { H } _ { 2 } \mathrm { O } \cdot$ 贫乏的 [[界面双电层|EDL]]，以实现稳定的[[锌负极]]。机理研究表明，HA-Zn 优先[[吸附]]在锌负极表面并重构 $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ 贫乏的 EDL，有效抑制与水相关的[[副反应]]。同时，中心[[四氧配体]]在界面处[[螯合]] $Z \mathrm { n } ^ { 2 + }$ 离子，使离子分布均匀化。这一重构界面进一步促进 HA-Zn 和 ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$ 的原位分解，生成具有丰富 $Z \mathrm { n } ^ { 2 + }$ 传导晶界的有机-无机杂化 SEI，不仅加速 $Z \mathrm { n } ^ { 2 + }$ 传输，还引导 [[Zn(101)]] 取向[[锌沉积|沉积]]。得益于包含 HA-Zn 吸附和富含晶界 SEI 的设计界面，Zn||Zn [[对称电池]]在 1 和 4 mAh⋅cm<sup>−2</sup> 下分别实现了超过 4700 小时和 1700 小时的长寿命。更为重要的是，$\mathrm { Z n } | | \boldsymbol { \mathrm { I } } _ { 2 }$ [[全电池]]在 $2 \mathrm { A } { \cdot } \mathrm { g } ^ { - 1 } .$ 下经过 15000 次以上循环后仍保持 88.67% 的[[容量保持率]]，$\mathrm { Z n } | | \mathrm { I } _ { 2 }$ [[软包电池]]（0.3 Ah）在 $0 . 5 \mathrm { A } { \cdot } \mathrm { g } ^ { - 1 }$ 下经过 3300 次循环后保持 86.34% 的容量。

## 1 引言

[[水系锌离子电池|水系锌离子电池（AZIBs）]]因其本征安全性、低成本和高理论容量（820 mAh⋅g<sup>−1</sup> 和 5855 mAh⋅cm<sup>−3</sup>）而成为大规模储能的有前景替代方案 [1–4]。然而，AZIBs 的实际应用仍受制于[[锌负极]]持续存在的问题，包括[[枝晶生长]]、[[析氢反应]]（HER）、[[锌腐蚀]]与[[钝化]] [5, 6]。这些问题的核心在于锌负极在水系电解液中的本征[[热力学不稳定性]]，以及[[电极-电解液界面]]处不受控的[[动力学行为]]，且二者相互关联并彼此加剧 [7]。具体而言，界面内富含 $\mathrm { H } _ { 2 } \mathrm { O } \cdot$ 的[[双电层]]（[[电双层|EDL]]）中的热力学不稳定性会引发寄生[[副反应]]，而界面上表现为枝晶生长的不受控动力学行为则促进这些反应并加剧热力学不稳定性，最终形成加速锌负极失效的恶性循环 [8, 9]。

在[[锌负极]]上原位构建稳定的固态电解质界面（[[固体电解质界面|SEI]]）已被广泛采用为一种实用策略，以系统调控[[电极-电解液界面]]并提升 [[水系锌离子电池|AZIBs]] 的稳定性 [10, 11]。此类原位 SEI 不仅能将 $\mathrm { Z n }$ 负极与腐蚀性水系电解液物理隔离以抑制[[副反应]]，还能引导 $Z \mathrm { n } ^ { 2 + }$ 的传输与分布，从而促进平面[[锌沉积|沉积]]。目前，原位 SEI 的形成主要借助特定不稳定[[电解液添加剂]]的自发化学反应或电化学分解来实现 [12]。该方法虽有效，但往往需要过量添加剂，从而增加体相电解液的黏度并降低[[离子电导率]]，可能减缓界面[[反应动力学]] [13]。更重要的是，尽管人们在构建具有多样组成与结构的 SEI 方面投入了越来越多的努力，但大多数已报道的原位 SEI 仍主要作为抵御水腐蚀的物理屏障，而关于实现 $Z \mathrm { n } ^ { 2 + }$ 快速穿越 SEI 的研究仍然有限 [14]，而这正是快充 AZIBs 发展所迫切需要的。现有原位 SEI 主要依赖[[快离子导体]]（例如 $\mathrm { Z n S , Z n F _ { 2 } , Z n _ { 3 } ( P O _ { 4 } ) _ { 2 } , ) }$）来促进 $Z \mathrm { n } ^ { 2 + }$ 传输 [15]。受[[锂离子电池]]中发现的启发，即 SEI [[晶界]]处的离子传输速率显著高于快离子导体中的传输速率，最近一项开创性研究构建了一种多组分富磷酸盐 SEI，其具有大量晶界，显著实现了 SEI 内的超快离子传输 [16]。因此，原位构建具有优先离子传输特性的 SEI，尤其是借助微量添加剂实现，有望对界面产生综合效应，并可能使快充 AZIBs 成为可能。

鉴于热力学与动力学失调的相互加剧，仅构建具有高[[离子电导率]]的[[固体电解质界面|SEI]]可能会加重电极-电解质界面的动态不稳定性[17]，并最终在追求超快$Z \mathrm { n } ^ { 2 + }$传输时限制循环寿命的提升。因此，提出一种协同且相互增强的策略，以同时调控SEI和[[双电层|EDL]]结构，朝向稳定、多功能界面发展。通过利用设计具有[[溶剂化]]调节特性的电解质添加剂（例如[[聚山梨酯]][18]、[[2,2,2-三氟乙酰胺]][19]和[[天冬氨酸钙]][20]），可以建立由$\mathrm { H } _ { 2 } \mathrm { O } \cdot$贫乏的[[电双层|EDL]]和[[有机-无机杂化SEI]]组成的界面，共同抑制[[副反应|寄生反应]]和[[枝晶生长]][21, 22]。具体而言，贫H₂O的[[界面双电层|EDL]]调节界面水活性，促进阳极表面的$Z \mathrm { n } ^ { 2 + }$扩散和[[去溶剂化]]，从而促进原位SEI形成[23]。反过来，所形成的SEI排斥界面处的水并增强$Z \mathrm { n } ^ { 2 + }$传导，进一步强化$\mathrm { H } _ { 2 } \mathrm { O - p o o r }$ EDL结构。然而，引入这种多层界面可能会增加阳极总阻抗，必须精确控制各功能层的性质，以确保高离子电导率和快速[[反应动力学]]。

在此，我们提出以痕量[[生物分子]][[透明质酸锌]]（HA-[[Zn]]，0.5 mM）作为功能性添加剂，协同构建富含[[晶界]]的[[固体电解质界面|SEI]]和$\mathrm { H } _ { 2 } \mathrm { O - p o o r }$ [[双电层|EDL]]，以实现优异的电池性能。理论计算和实验测试表明，由于HA-[[锌负极|Zn]]分子具有丰富的[[羟基]]和独特的[[四氧配体]]，不仅优先化学[[吸附]]于阳极表面并自发构建$\mathrm { H } _ { 2 } \mathrm { O - p o o r }$ [[电双层|EDL]]以抑制寄生[[副反应]]，还通过[[螯合]]电解质中的$Z \mathrm { n } ^ { 2 + }$使[[离子通量]]均匀化。此外，HA-Zn分解${ \mathrm { S O } _ { 4 } } ^ { 2 - }$为以离子导电的[[ZnS]]和$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 }$物种为主的[[有机-无机杂化SEI]]。值得注意的是，这种由$\mathrm { H A } – \mathrm { Z n }$诱导的SEI具有独特的丰富晶界特征，使SEI内的$Z \mathrm { n } ^ { 2 + }$传导机制从常见的单一[[晶内路径]]扩展至协同的多晶内和[[晶间路径]]，从而加速界面处的$Z \mathrm { n } ^ { 2 + }$传输，并最终诱导[[Zn(101)]]择优[[锌沉积|沉积]]（图1a）。得益于这种[[多维界面调控]]，组装的Zn||Zn[[对称电池]]在1 $\mathrm { \ m A } { \cdot } \mathrm { c m } ^ { - 2 }$、1 $\mathrm { \ n A h { \cdot } c m ^ { - 2 } }$条件下实现了4750小时的优异[[循环稳定性]]（在4 $\mathrm { \ m A } { \cdot } \mathrm { c m } ^ { - 2 }$ V $\mathbf { \ell } _ { \mathsf { I } } \mathbf { m A h } { \cdot } \mathbf { c m } ^ { - 2 } )$下为1386小时）。此外，该$\mathrm { Z n S O _ { 4 } / H A { - } Z n }$[[电解质体系]]显著提升了与$\mathrm { V O } _ { 2 }$和$\mathrm { I } _ { 2 }$[[正极]]配对的[[全电池]]性能。组装的$\mathrm { Z n } | | \mathrm { I } _ { 2 }$全电池在$\boldsymbol { \underline { { ? } } } \mathbf { A { \cdot } g ^ { - 1 } }$下经过15000次循环后表现出88.67%的大[[容量保持率]]。[[软包电池]]在3300次循环后保持86.34%的容量保持率$( 0 . 5 \mathrm { A } { \cdot } \mathrm { g } ^ { - 1 } )$

## 2.2 具有丰富[[晶界]]的快离子导电 [[固体电解质界面|SEI]]

系统研究了利用 [[透明质酸锌|HA-Zn]] 添加剂原位形成 [[固体电解质界面|SEI]] 的可行性。HA-[[Zn]] 与 $\mathrm { H } _ { 2 } \mathrm { O }$ 分子的差分电荷密度表明，HA-[[锌负极|Zn]] 与锌负极之间的[[电荷转移]] $( 0 . 5 5 { \mathrm { ~ e } } ^ { - } )$ 显著大于 $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ 与锌负极之间的电荷转移（0.029 e<sup>−</sup>）（图 2a），说明 HA-Zn 优先[[吸附]]在负极表面并具有更强的相互作用 [18, 40]。同时，HA-Zn 的 [[最低未占分子轨道|LUMO]] 能级（-0.335 eV）和 ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$（1.252 eV）均低于 $\mathrm { H } _ { 2 } \mathrm { O }$（1.694 eV）（图 2b），也低于 $\mathrm { H A } – \mathrm { Z n }$ 在 ZnSO 周围的情形（图 S25），表明在电化学过程中它们比 $\mathrm { H } _ { 2 } \mathrm { O }$ 具有更优异的电子接受能力和更高的化学反应活性 [41, 42]，继而分解并原位形成 HA-Zn 衍生的 SEI。进一步通过 [[DFT]] 计算获得了[[部分态密度]]（PDOS）[43]。值得注意的是，HA-Zn 附近的 $\mathrm { Z n S O _ { 4 } }$ 的 LUMO 显著低于其水合态（图 S26），表明 HA-Zn 促进了 ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$ 的还原与分解。此外，$\mathrm { H A { - } Z n / Z n S O _ { 4 } }$ 配合物中 HA-Zn 的 LUMO 也低于孤立 HA-Zn 分子（图 2c）。这些结果共同表明，HA-Zn 的还原分解可能立即与 $Z \mathrm { n } ^ { 2 + }$ 结合，生成 $\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 }$ 以及其他有机分解产物，这已由 [[飞行时间二次离子质谱|TOF-SIMS]] 和 [[XPS]] 证实。被还原的 ${ \mathrm { S O } _ { 4 } } ^ { 2 - }$ 也可先于 $\mathrm { H } _ { 2 } \mathrm { O } ,$ 被还原，生成 $\mathrm { S } ^ { 2 - }$ 物种，该物种随后与 $Z \mathrm { n } ^ { 2 + }$ 反应形成 [[ZnS]]，从而可能促进[[快离子导体]]的形成。

[[透射电子显微镜]]（TEM）显示出一层透明的[[固体电解质界面|SEI]]层（图S27）。[[高分辨透射电子显微镜|高分辨TEM]]进一步识别出与[[ZnS]]、$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 } , \mathrm { Z n O } , \mathrm { Z n C O } _ { 3 }$和$Z \mathrm { n } \mathrm { S O } _ { 3 }$相对应的清晰晶格条纹（图2d–f）。其中，ZnS和$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 }$是均匀分布在整个SEI层中的两种主要结晶相，而[[ZnO]]、ZnCO和${ \mathrm { Z n S O } } _ { 3 }$则零星分散在外层。同时，[[锌沉积]]的晶格条纹主要归属于[[Zn(101)]]。利用[[飞行时间二次离子质谱]]（TOF-SIMS）分析了在$Z \mathrm { n S O _ { 4 } / H A } .$-[[Zn]]电解液中循环20次后SEI层的详细组成。具体而言，随着刻蚀深度的增加，ZnN⁻和ZnS⁻信号强度逐渐增强，同时无机基团$( \mathrm { Z n O \mathrm { - } , \mathrm { S O _ { 3 } \mathrm { - } } }$、$\mathrm { C O } _ { 3 ^ { - } } , )$以及有机基团$( \mathrm { C H } _ { 3 ^ { - } } , \mathrm { C N - } )$的强度减弱（图2g；图S28和S29）。$\mathbf { A } \mathbf { r } ^ { + }$溅射[[XPS]]深度剖析证实了这一化学演变过程（图2h；图S30）。与在纯$\mathrm { Z n S O _ { 4 } }$电解液中形成的SEI不同——后者仅含有微量ZnS和$Z _ { \mathrm { { n O } , } }$，不含$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 } ,$，但含有大量[[锌硫酸氢氧化物|ZSH]]副产物（图S31）——源自$\mathrm { Z n S O _ { 4 } / H A }$-[[锌负极|Zn]]电解液的SEI表现出，随着溅射过程的推进，$\mathrm { S O } _ { 3 } { } ^ { 2 - }$和${ \mathrm { S O } _ { 4 } } ^ { 2 - }$的S 2p信号以及C-N和N-H的信号均显著降低。$Z \mathrm { n S \cdot }$⁻和ZnN⁻的存在意味着生成了ZnS和$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 }$，其相关峰保持稳定，表明ZnS和$\mathrm { Z n } _ { 3 } \mathrm { N } _ { 2 }$均存在于整个SEI中，并作为能够提供快速$Z \mathrm { n } ^ { 2 + }$传输通道的[[快离子导体]][14]。这些结果共同表明，在锌负极上形成了一种由有机顶层和无机内层组成的杂化SEI。

开展了可逆 [[锌剥离|Zn 沉积/剥离]]测试，以考察 [[透明质酸锌|HA-Zn]] 添加剂的实际效果。图 5a 展示了 [[Zn]]||[[锌负极|Zn]] [[对称电池]]在两种电解液中的循环性能。在 $\mathrm { Z n S O _ { 4 } / H A { - } Z n }$ 电解液中，于 $1 \mathrm { \ m A } { \cdot } \mathrm { c m } ^ { - 2 }$ 条件下、每个循环容量密度为 $1 \ \mathrm { m A h } { \cdot } \mathrm { c m } ^ { - 2 }$ 时，可实现超过 4750 h 的优异寿命（图 5a，插图），约为使用纯 $\mathrm { Z n S O _ { 4 } }$ 电解液电池的 40 倍，后者[[循环稳定性]]差得多，仅维持 119 h。即使在更高的容量密度 $4 \ \mathrm { m A h } { \cdot } \mathrm { c m } ^ { - 2 }$ 下，分别搭配 $4 \ \mathrm { m A } { \cdot } \mathrm { c m } ^ { - 2 }$ 和 1 $\mathrm { \ m A } { \cdot } \mathrm { c m } ^ { - 2 }$ 进行循环，$\mathrm { Z n S O _ { 4 } / H A { - } Z n }$ 电解液仍可稳定运行超过 1386 h 和 1732 h（图 5b；图 S41）。相比之下，使用纯 $\mathrm { Z n S O _ { 4 } }$ 电解液的对照电池分别在仅 83 h 和 96 h 后发生短路，主要归因于 Zn [[枝晶生长]]和[[副反应]] [49]。更值得注意的是，加入 HA-Zn 后，Zn||Zn 对称电池的[[极化]]并未加剧，且这一现象在严苛测试条件下更为明显。这些结果表明，HA-Zn 添加剂不仅降低了 $Z \mathrm { n } ^ { 2 + }$ [[去溶剂化能]]，还促进了快速的[[电荷转移|界面电荷转移]] [50]。

## 3 结论

在本工作中，我们通过在 $\mathrm { Z n S O _ { 4 } }$ 电解液中微量添加[[生物分子]] [[透明质酸锌|HA-Zn]]，全面提升了[[水系锌离子电池|水系锌离子电池（AZIBs）]]的性能。通过阐明 HA-[[Zn]] 分子中[[四氧配体]]和 −OH 基团对配位化学、[[双电层]]调控以及快离子导电 [[固体电解质界面|SEI]] 构建的深刻影响，揭示了它们的关键作用。亲锌的四氧配体与[[锌负极]]表面表现出强相互作用，促进对 $Z \mathrm { n } ^ { 2 + }$ 离子的优先[[吸附]]和[[螯合]]。吸附的 HA-Zn 层自发促进形成 $\mathrm { H } _ { 2 } \mathrm { O } \cdot$ 贫乏的双电层以及一种独特的有机-无机杂化 SEI，该 SEI 具有 $Z \mathrm { n } ^ { 2 + }$ 导电[[晶界]]，协同增强了 $Z \mathrm { n } ^ { 2 + }$ 传输动力学，并促进在 Zn（101）晶面上的定向[[锌沉积|沉积]]。令人印象深刻的是，$\mathrm { Z n S O _ { 4 } / H A }$ -Zn 体系在[[对称电池]]中有效实现了稳定性（1 mA cm<sup>−2</sup>，1 mAh cm<sup>−2</sup> 条件下 4750 h），并在 Zn||Cu 非对称电池体系中实现了 Zn 沉积-剥离的可逆性（[[库仑效率|平均库仑效率]]为 99.65%）。所组装的 $\mathrm { Z n } | | \boldsymbol { \mathrm { I } } _ { 2 }$ 和 $\mathrm { Z n } | | \mathrm { V O } _ { 2 }$ [[全电池]]
