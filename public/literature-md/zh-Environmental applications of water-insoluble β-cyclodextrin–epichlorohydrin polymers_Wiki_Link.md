## 摘 要

以[[环氧氯丙烷]]为[[交联剂]]进行[[交联反应|化学交联]]，是制备[[水不溶性]] [[β-环糊精|--环糊精]]基[[聚合反应|聚合]]物最直接的方法。[[环糊精]]（CD）分子上大量可用的 [[羟基|OH 基团]]是能够形成多种连接键的[[活性位点]]。尽管这种[[交联]]反应已有50年的历史，相关文献记载详尽，而且用于制备 CD 基网络也相对容易，但有关该反应的一些基本问题仍持续引起科学界的关注。本综述的主要目标是：（i）描述不溶性 [[环糊精–环氧氯丙烷聚合物|CD–环氧氯丙烷聚合物]]的合成与[[材料表征|表征]]；（ii）提供有关其最重要特征的有用信息；（iii）总结这些材料在环境用途方面的应用进展。具体而言，本文介绍了以吸着为导向的工艺、[[废水]]解毒、脱色以及溶液浓缩与纯化等相关环境应用。为此，本文汇集了来自270篇论文、综述、专利和书籍的大量文献数据。文中介绍了吸着过程中[[污染物]]与 CD–环氧氯丙烷聚合物之间发生的各种相互作用，并讨论了未来的研究趋势。

## 1. 引言

生活、工业和农业领域的用水意味着随之而来的[[水污染]]：任何用水活动都会产生含有不受欢迎且可能有毒的[[污染物]]的[[废水]]。如今，化学物质向环境中的排放已成为影响[[水质]]和[[土壤质量]]的严重问题。排放物中的[[痕量污染物]]会以易被动植物吸收的形式释放到环境中。随后，它们可[[生物积累|在生物体内积累]]，并通过[[食物网]]发生生物放大作用。许多污染物不仅对环境产生毒性作用，也会对人类产生毒性作用。因此，各国政府正通过出台日益严格的法律法规，持续努力保护水资源 [1]。

针对[[工业废水|工业液态废水]]，已有大量[[废水处理]]方法被报道并接受试验。这些方法包括常规处理工艺（如混凝/絮凝、活性炭[[吸附]]等）、成熟的回收技术（氧化、膜过滤），以及高级氧化工艺等新兴去除方法 [2–5]。然而，出于经济原因，许多已提出的工艺无法用于工业规模处理 [1]。例如，中小企业对于投资膜过滤或高级氧化工艺等附加处理措施并不十分积极，这不仅是因为其初始成本高，还因为其维护复杂。另一个也必须指出的问题是，工业[[废水]]的组成复杂多变，因此非常难以处理。事实上，工业部门产生的废水含有由有机和[[无机污染物]]组成的复杂混合物，其组成随时间变化。工业部门所提出和采用的去污方法无法去除全部[[污染物负荷]]。在实际应用中，通常组合使用不同工艺去除[[污染物]]，以最经济的方式达到所需[[水质]]。这是因为迄今尚无任何一种单一的[[水处理工艺]]能够同时将水中所有污染物去除至理想水平。另一个难点是处理含有低浓度分子和/或离子的废水。因此，有必要开发适合工业应用的新型处理方法，使其能够有效处理多种污染物共存的混合物中的广泛污染物，即使这些污染物的浓度极低。

近年来，大量研究致力于开发各种[[多糖基材料|基于多糖的材料]]，这些[[多糖]]可大量获取且对自然环境无害 [6–10]。[[环糊精]]（cyclodextrins，CDs）作为源自[[淀粉]]的天然分子，受到了特别关注 [11,12]。这些物质，尤其是 [[β-环糊精]]（beta-CD 或 ˇ-CD）及其衍生物，具有通过[[主客体相互作用|主–客体相互作用]]与其他分子在溶液或固态中形成[[包合物]]的显著能力 [13–18]。ˇ-CD 具有多种独特性质，且对人体无毒，因此被应用于制药、生物[[医学]]、[[生物技术]]或纺织工业，以及洗护用品、[[化妆品]]、包装材料和食品添加剂等领域 [19–23]。CDs 可直接以原始形式使用，也可经改性后使用。例如，ˇ-CD 及其商业化衍生物，如[[羟丙基-β-环糊精|羟丙基-ˇ-CD]] 和[[羧甲基-β-环糊精|羧甲基-ˇ-CD]]（通过[[烷基化]]或[[羧甲基化]]获得），广泛用于[[药物制剂]]，以提高[[药物]]的[[溶解度]]、[[稳定性]]和[[生物利用度]]。CDs 还用于改善饮料的口感和风味、溶解[[香料]]并抑制其挥发，或保护在光照或氧气作用下不稳定的组分。CDs 在工业应用和研究中的重要意义，主要在于其能够[[吸附选择性|选择性]]地与其他物质形成包合物。

[[络合|络合现象]]也已在[[分析化学]]的实际应用中得到商业化利用，尤其是在分离过程中。[[环糊精|CDs]] 已成功应用于实验室及工业规模的液相和气相[[色谱法|色谱]]；例如，CDs 在高效液相色谱的手性识别中发挥着重要作用。在环境科学中，CDs 在促进[[污染物]]溶解，以及富集和去除土壤、大气和水中的[[有机污染物]]与重金属方面，也尤其值得关注 [21,22]。新型 [[环糊精基材料|CD 基材料]]开发的一个近期趋势是，其在防治环境污染方面的实际应用开发正加速推进。天然 CDs 及其[[亲水性]]、[[疏水性]]或离子型衍生物可用于[[废水]]、含水层、空气和土壤的净化，以增强对污染物的稳定化、包封、分离和吸着作用。这主要是因为其结构中的[[疏水空腔]]能够容纳芳香族化合物和其他疏水性有机分子，提供理想的[[结合位点]]。目前，利用 CDs 去除水和废水中的（有机）污染物受到广泛关注，每年有关这一主题的论文发表数量不断增加，也反映出人们日益增长的兴趣。由于 CDs 可溶于水，因此不能直接用于分离和纯化。因此，有必要通过[[聚合反应]]制备不溶性 CD 基材料，或通过[[接枝]]将 CD 分子固定在固体载体上。文献中已有大量关于含 CD 分子的[[水不溶性]]材料的制备、[[材料表征|表征]]、性质和应用的研究。其中，通过 CD 分子与[[偶联剂]]在[[碱性介质]]中进行[[共聚合|（共）聚合]]而获得的[[交联聚合物]]，因其合成简便、[[吸着性能]]高及特有的[[吸附选择性|选择性]]而受到广泛关注。在所有已提出的反应中，使用[[环氧氯丙烷]]（EPI）作为[[交联剂]]进行[[交联反应|化学交联]]，是制备用于环境应用的水不溶性 CD 网络的最直接方法。

## 2.1. 用于去除水和[[废水]]中[[污染物]]的常规与非常规材料

目前，大多数商业系统都使用炭材料和树脂作为[[吸附剂|吸着剂]]，单独使用或用于组合工艺，以去除[[废水]]中的[[污染物]]，这是因为它们具有优异的吸着和[[螯合]]能力。然而，不出所料，高成本限制了它们的广泛应用。用于去除污染物的材料也可以源于天然。文献中提及的一些材料包括泥炭、[[壳聚糖]]、[[淀粉]]、甘蔗渣髓等农业废弃物，以及棉基材料等工业废弃产物。近年来，为开发成本更低、效果更好的[[环糊精基材料|含环糊精材料]]，研究人员已探索了多种方法；[[环糊精]]是一类重要的[[淀粉衍生物]]。

## 2.2. 为什么使用 [[β-环糊精–环氧氯丙烷聚合物|ˇ-CD–环氧氯丙烷聚合物]]作为环境用途的[[络合材料]]？

[[环糊精]]（Cyclodextrins，CDs），又称环状直链[[淀粉]]，是由 6–12 个[[葡萄糖]]单元通过 -1,4 [[糖苷键]]连接而成的[[环状低聚物]]，由酶（例如 -1,4-[[葡聚糖糖基转移酶]]）作用于淀粉而形成。根据所用[[转移酶]]、淀粉性质以及反应条件（例如是否存在沉淀剂）的不同，可生成不同类型的 CDs。典型的天然 CDs 含有六个、七个或八个葡萄糖单元，分别称为 -、-- 和 -CDs（图 3）。CDs 的结构呈甜甜圈状，其特征是葡萄糖残基采用 [[C1 构象]]，[[羟基]]沿外缘排列。由于[[吡喃葡萄糖]]单元采用[[椅式构象]]，CD 呈截锥形或环面形，而非完美的圆柱形。羟基[[官能团]]朝向锥体外侧，其中糖残基的[[伯羟基]]位于锥体的窄端，[[仲羟基]]位于较宽的一端（图 4）。

该分子的中央空腔内壁由[[葡萄糖]]残基的骨架碳原子和醚氧原子构成。因此，[[环糊精|CD]] 的外表面具有[[亲水性]]，而中央空腔则相对疏水。由于这些特征，CDs 可通过[[非共价相互作用]]将多种疏水分子或分子的部分结构包封在其空腔内，形成[[包合物|主–客体型包合物]]。[[环糊精络合|CD 络合]]是用于分析和[[络合]]目的的优选方法 [64–66]。

[[β-环糊精|--环糊精]]（ˇ-[[环糊精|CD]]，环状七聚直链[[淀粉]]）的空腔内径为 6.5 A<sup>˚</sup>，深度为 $8 \mathring { \mathsf { A } } .$，因此是研究最多、使用最频繁的环糊精。与其他 CDs 一样，$\beta -$ CD 分子最显著的特征是能够通过[[主客体相互作用|主–客体相互作用]]，与各种分子、离子和[[聚合反应|聚合]]物（包括芳香族衍生物、[[染料]]、多环芳烃、挥发性有机化合物、金属等）形成[[包合物]]（图 5）。凡是在空间结构上与 CD 空腔具有互补性（即使只是部分互补）的物质，都可能被包合。通常，$\beta \mathrm { - C D }$ 是一种较好的折中选择，因为其[[疏水空腔]]及较为柔性的大环尺寸介于 -CD 和 -CD 之间。较强的[[络合]]能力加上较低的成本（约为 5、45 和 80 US\$ per kg for ˇ-CD, -CD and $\gamma { \mathrm { - C D } }$ , respectively) explains why $\beta -$ CD 是环境研究中首选的 CD。价格还取决于产品的纯度和技术等级。

已有许多综述文章和书籍出版，对 [[环糊精|CDs]] 的结构性质、[[环糊精络合|CD 络合]]现象及 CD 的应用进行了详尽而出色的概述。由于有关 CD 的出版物数量极其庞大，参考文献 [67–88] 仅列出了包含所展示数据之原始来源的综述和专著。对 CD 的详细介绍、描述及应用感兴趣的读者，可查阅 [[CYCLOLAB Ltd.]]（匈牙利）出色的文献数据库“[[Cyclodextrin News]]”。这是一份收集所有环糊精相关出版物、专利、会议和讲座信息的期刊，并提供电子版。

[[环糊精|CDs]] 是最引人注目的[[大环分子]]之一，在化学和[[生物学]]领域具有重要的理论和实际影响。分离科学是 CDs 的一个重要应用领域。如前所述，CD 分子具有一个[[疏水空腔|疏水性非极性空腔]]，其中含有氧桥和氢原子。该空腔内部提供了一个相对疏水的环境，可将[[非极性污染物]]捕获其中。环糊精可在气相[[色谱法|色谱]]（GC）、高效液相色谱（HPLC）、超临界流体色谱（SFC）、毛细管电泳（CE）和电色谱（CEC）中用作手性选择剂。目前已认识到，由于 CDs 具有特殊的结构、化学性质、高[[反应活性]]以及对多种物质的优异[[吸附选择性|选择性]]，它们作为[[吸附剂]]也是一种值得关注且颇具吸引力的替代选择。因此，[[环糊精络合|CD 络合]]是去污技术中的优选方法。

还必须指出另一项优势。从水/[[废水]]中去除有毒[[污染物]]，对供水公司和市政部门而言仍是一项巨大挑战。供水管网和工业排放物中通常同时存在有机和[[无机污染物]]。然而，目前尚无一种水处理措施能够同时将水中的有机和无机污染物去除至理想水平。[[环糊精基聚合物]]有望成为具备这一能力的体系，因为它们即使在低痕量浓度下，也能有效去除多种污染物混合体系中的污染物，并具有较高的[[吸附容量]]和令人关注的[[吸附选择性|选择性]]，此外还具有成本低廉（材料生产在经济上可行，且使用相对廉价的化学试剂即可轻松合成）、易于回收利用（再生）或处置（焚烧）等优势。

## 3. [[水不溶性]] [[β-环糊精–环氧氯丙烷聚合物|--环糊精–环氧氯丙烷聚合物]]的合成与[[材料表征|表征]]

如前所述，天然[[环糊精]]可溶于水，因此必须先将其加工成固体形式，才能作为实用的分离和[[吸附]]基材使用。从高分子化学家的角度来看，环糊精的[[化学改性]]带来了巨大的挑战。

## 3.1. [[环糊精基材料|含环糊精的材料]]

$\beta -$ [[环糊精]]（[[β-环糊精|--CD]]）最重要且最有用的特性之一是其较高的[[反应活性|化学反应活性]]。如图 4 所示，$\beta \mathrm { - C D }$ 具有 21 个[[羟基]]，位于[[葡萄糖]]单元的 $2 \cdot , \ 3 \cdot$ 和 6 位，可进行[[化学改性|化学修饰]]。这些数量众多的 OH 基团可参与反应且具有反应活性，能够形成多种连接键。$C _ { 6 } { - } 0 \mathrm { H }$ 基团的反应活性最高，而 ${ \mathsf { C } } _ { 3 } – { \mathsf { O H } }$ 基团的反应活性最低。然而，它们之间的反应活性差异并不是非常大。此外，这种差异取决于反应条件，尤其是温度和[[碱度]]。羟基可在不同位置（[[伯羟基]]面、[[仲羟基]]面或两个面）发生[[取代反应|直接取代反应]]和/或化学修饰，从而生成适用于特定应用领域的不同衍生物（非离子型、阳离子型或阴离子型）。

含有两个或更多个通过[[共价键]]连接的 [[环糊精|CD]] 单元的产物称为[[环糊精二聚体]]和[[聚合反应|聚合]]物。聚合物可通过以下方式制备：将 CD 环[[交联]]，使含有 CD 或 [[环糊精衍生物|CD 衍生物]]的双[[官能团]]取代物聚合，或将 CD 键合至其他聚合物。图 6 展示了通过[[接枝]]、聚合和[[交联反应]]获得的含 [[β-环糊精|--CD]] 不溶性材料的三种结构示意图 [89–91]。关于[[环糊精基材料|含环糊精材料]]的制备与[[材料表征|表征]]已有大量研究，有关这些聚合物材料最重要特性的信息可参见 [[Mocanu]] 等人 [21]、[[Crini G|Crini]] 和 [[Morcellet]] [23] 以及 Crini [61] 的综述。

已有文献报道了多种将 [[β-环糊精|--CD]] 转化为能够与水溶液中[[污染物]]相互作用的衍生物的工艺，这些方法可分为两类 [21,23,89–92]。第一类涉及通过[[交联]]直接修饰 --[[环糊精|CD]]，即通过[[偶联剂]]的链将分子彼此连接，形成不溶性的[[聚合物网络|三维网络]]。可根据 CD 的类型、[[交联间隔基]]或两者之间的[[摩尔比]]来调节[[聚合反应|聚合]]物的性质。控制碱浓度、温度、[[搅拌速率]]和[[反应时间]]等实验条件，也可对所得聚合物进行精细调节。[[化学功能化]]还可将[[配体|反应性配体]]引入聚合物颗粒表面。向[[亲水性]] CD 分子中引入新基团，随后可使其化学性质发生广泛变化，进而使其具有[[离子性]]和/或[[两亲性]]。因此，可以获得在[[交联密度]]、[[BET|比表面积]]、[[孔结构]]、化学性质和[[吸附]]行为方面具有不同特征的多种材料。

第二类方法依赖于将 [[β-环糊精|ˇ-CD]] 分子通过[[共价键]]连接至预先存在的不溶性基质，例如高度[[交联]]的[[合成聚合物]] [93]、[[硅胶微珠]] [94,95]、[[沸石]] [96]、[[纤维素]]纤维 [97]、[[纺织品]] [98]、[[海藻酸盐]] [99,100] 或[[壳聚糖]] [101,102]。这种将 [[环糊精|CD]] 固定在不溶性载体上的方法，也可视为获得具有特定性质的不溶性 CD 材料的一种适宜途径。近年来，还设计了其他 [[环糊精基材料|CD 基材料]]，例如分子印迹材料、膜和[[纳米颗粒]]（表 2）[103–113]。

由于本综述无意替代详尽的专著，因此表 3 中汇总的有关 [[环糊精基材料|CD 基材料]]的一般文献仅列出最重要的来源，主要为综述。

## 3.2. 通过[[环糊精]][[交联反应|直接交联]]制备的[[不溶性聚合物]]

由于分子具有独特的结构及多官能性，[[β-环糊精|ˇ-CD]] 分子能够形成[[聚合物网络|交联网络]]。ˇ-[[环糊精|CD]] 可通过其[[羟基]]与[[偶联剂]]直接反应而[[交联]]，形成水溶性或[[水不溶性]]的[[聚合反应|聚合]]物结构。CD 在[[碱性介质]]中与[[环氧氯丙烷]]等偶联剂反应的初级产物是由各种 [[环糊精甘油醚|CD 甘油醚]]组成的非均相混合物：这并非真正的聚合物，而是[[共聚物]] [114–123]。

[[Renard]] 等人 [116,117] 表明，在避免反应混合物[[凝胶化]]的受控条件下，[[环糊精|CD]] 分子与[[环氧氯丙烷]]反应可生成具有[[超支化结构]]的[[水溶性聚合物|可溶性聚合物]]，其结构由 CD 部分、连接桥和侧链[[取代基]]（尾链）组成。通过 <sup>13</sup>C 分析确定了取代模式，并通过电喷雾电离质谱和气液[[色谱法|色谱]]–质谱联用证实了由[[聚(2-羟丙基)醚]]单元序列构成的侧链和桥的形成。有趣的是，CD 空腔保留了其形成[[络合物]]的能力，而且所得[[聚合反应|聚合]]物的[[溶解度]]远高于相应的 CD，因此已应用于制药领域，例如用于[[药物增溶]]。[[Fenyvesi]] 等人 [114] 此前也报道了类似结论。

## 3.2.1. [[水不溶性]]

## [[环糊精–环氧氯丙烷聚合物|ˇ-环糊精–环氧氯丙烷聚合物]]的合成

在 [[环糊精聚合物|CD 聚合物]]中，最常见的是由 [[环糊精|CD]] 与[[环氧氯丙烷]]（简称 EPI）反应制得的 [[环糊精–环氧氯丙烷聚合物|O-烷基化聚合物树脂]]（文献中简称为 [[环糊精-环氧氯丙烷聚合物|ECP]] 或 ECH）。EPI（1-氯-2,3-环氧丙烷）是[[多糖化学]]中最常用的[[交联剂]] [23]。它是一种含有两个反应性[[官能团]]的[[双官能交联剂]]（图 7），能够与 [[β-环糊精|ˇ-CD]] 分子成键（[[交联]]步骤），也能够与自身成键（[[聚合反应|聚合]]步骤），或同时发生这两种反应。所得 ECP 材料是一种混合物，其中的 ˇ-CD 单元通过重复的[[甘油基]]连接基团相连 [124–127]。多个 ˇ-CD 环相互连接，形成[[三维聚合物网络|三维（共）聚合物网络]]（图 8）。CD 基团之间形成的连接结构具有较强的[[极性]]。由于该网络本身高度亲水，并且在水中显著[[溶胀]]，因此这些[[共聚合|（共）聚合]]物也被称为[[凝胶]]或[[水凝胶]]（本综述将使用聚合物、凝胶或 ECP 这些术语）。

利用 [[环氧氯丙烷|EPI]] [[交联]] [[环糊精|CD]] 是一种已有充分文献记载的反应 [21,23,114,116]，也是制备 [[环糊精衍生物|CD 基衍生物]]的一种相对简便的方法。然而，尽管这种[[交联反应]]早在 60 年前就已开发出来，已广为人知，且相对容易用于制备[[水不溶性]] [[β-环糊精|--环糊精]]–环氧氯丙烷基网络，但有关该反应及其众多应用的一些基本问题仍持续引起科学界的兴趣 [1,61,128–130]。[[环糊精–环氧氯丙烷聚合物|CD–环氧氯丙烷聚合物]]的一种类似物是 [[Sephadex]]<sup>®</sup>，其中以[[葡聚糖]]代替 CD。

采用[[本体聚合]]制备[[不溶性聚合物]]时，必须将产物研磨成形状不规则的颗粒。[[微珠|球形微珠]]通常通过[[非均相聚合]]制备。在[[表面活性剂]]存在的条件下，将 [[环糊精|CD]] 的碱性溶液以微小液滴的形式分散在与水不混溶的液相中。加入[[交联剂]]后，液滴固化，形成具有所需[[粒径]]和[[粒径分布]]的[[聚合反应|聚合]]物微珠 [21,23]。

## 3.2.2. [[环糊精-环氧氯丙烷聚合物|ECP 材料]]的[[化学改性]]

对 [[环糊精-环氧氯丙烷聚合物|ECP]] 网络进行[[化学改性]]是引入特定性能、拓宽其潜在应用领域的一个值得关注的步骤。总体而言，其目的是改善[[污染物]][[吸着性能]]、提高对目标污染物的[[吸附选择性|选择性]]，以及制备不溶性[[两性聚合物]]。例如，[[环糊精–环氧氯丙烷聚合物|ECP 材料]]的[[功能化]]能够改变这类[[凝胶]]的特性，如形成[[包合物]]时的[[选择性]] [23,50,64]。通过在“所需”位置用具有相反设计特征的[[取代基]]替换一个或多个 [[羟基|OH 基团]]，可以获得[[多位点识别系统]]（然而，制备均一且经选择性衍生化的 ECP 并非易事）。利用带电功能单元进行改性，可以提高 [[环糊精|CD]] 分子对带相反电荷客体的结合亲和力。这可以解释为：由于[[疏水相互作用]]是溶液中 CD 分子形成包合物的主要驱动力之一，因此[[疏水性]]更强的客体更容易被容纳在 CD 空腔中 [1]。其他方法则着重于使 [[环氧氯丙烷|EPI]] 与 $\mathrm { N H } _ { 4 } \mathrm { O H } ;$ 等化学物质反应：这种方法能够方便且低成本地将弱碱性阴离子交换基团引入[[三维聚合物网络|聚合物网络]] [59]。

## 3.2.3. 其他[[交联剂]]

尽管 [[环氧氯丙烷|EPI]] 在化学工业中被广泛用作合成多种产品（例如环氧树脂、甘油、聚氨酯泡沫、[[表面活性剂]]、[[药物]]等）的中间体，但其主要缺点是毒性。这种[[交联剂]]既不安全，也不环保：它被认为是一种有害的环境[[污染物]]和潜在致癌物，人们不仅对环境中的 EPI 深感担忧，也十分关注其与人体接触时带来的问题。这促使许多研究者提出使用其他[[交联]]剂。然而，应当指出，材料中存在游离未反应 EPI 的可能性很小，因为 EPI 是一种[[反应活性]]很高的物质，并且在[[交联反应]]的碱性条件下会发生水解。此外，[[凝胶]]在使用前通常会经过纯化 [23]。

由于 [[环糊精|CD]] 分子连接到[[水不溶性]][[聚合反应|聚合]]物链上后，其形成[[络合物]]的能力不受影响，因此，使用 [[环氧氯丙烷|EPI]] 以外的化学品合成[[交联]] CD 也引起了广泛兴趣（表 4）[131–150]。多羧酸或柠檬酸衍生物等“环境友好型”[[交联剂]]可用于制备不溶性的 [[β-环糊精|ˇ-CD]] 基网络。研究者也提出了使用二[[异氰酸酯]]衍生物。在所有情况下，反应均发生在 CD 的[[羟基]]与交联剂的基团之间。例如，Yamasaki 等人 [146–148] 使用二异氰酸酯基交联剂制备了一系列交联环糊精颗粒。这些含有氨基甲酸酯基团的材料在环境应用方面颇具吸引力，因为它们具有高交联度、高[[BET|比表面积]]以及非均相的非[[极性]]网络。然而，还应指出，由于二异氰酸酯交联剂的[[反应活性]]较低，与 EPI 的反应温度（30–50 ◦C）相比，其反应温度必须相对较高（70–80 ◦C）。Zhao 等人 [133–135] 通过一种环境友好的合成方法，制得了以柠檬酸交联的水不溶性 --[[环糊精聚合物]]。该合成可在低于 200 ◦C 的温度下进行，无需使用任何有机溶剂或有害添加剂。

## 3.3. [[环糊精–环氧氯丙烷聚合物|ˇ-环糊精–环氧氯丙烷聚合物]]的[[材料表征|表征]]

[[Szejtli]] 及其同事此前研究了 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的结构 [17,50,73,90,114]。通过保水性、密度、[[凝胶]]床体积、[[粒径]]、机械[[稳定性]]和分子量对[[聚合反应|聚合]]物及[[共聚物]]进行了[[材料表征|表征]]。所得产物的分子质量超过 20,000 Da，并具有[[三维聚合物网络|三维网络结构]]。[[环糊精–环氧氯丙烷聚合物|ECP 凝胶]]的结构具有很强的[[亲水性]]，在水溶液中显著[[溶胀]]，且不溶于任何（有机）溶剂。这些产物在水中具有极高的溶胀能力。[[Crini G|Crini]] 研究组 [61,124–127] 表明，选择最佳合成条件对于获得具有所需特征（例如溶胀度、[[环糊精|CD]] 含量等）的产物十分重要。较高的聚合温度有利于获得较高的聚合物溶胀度。Romo 等人 [128]、Vélaz 等人 [129]、Sainz-Rozas 等人 [130] 和 [[Mohamed]] 等人 [138] 也报告了类似结论。通过改变合成条件（例如不同试剂的用量、CD/[[环氧氯丙烷|EPI]] [[摩尔比]]、NaOH 浓度、反应温度、[[反应时间]]），可以使[[水凝胶]]网络在[[BET|比表面积]]和[[孔隙率]]方面发生结构变化，并获得具有不同 CD 含量的凝胶 [124,125,138]。例如，Crini 等人 [124] 表明，改变 CD（单体 A）与 EPI（单体 B）的相对摩尔比，会使单体单元的重复结构从 A–B 型共聚物变为 A–B 型共聚物；后一类型含有本质上具有亲水性的富 EPI 区域。

这些[[聚合反应|聚合]]物既可制备成形状不规则的颗粒，也可制备成规则的[[微珠]]。与 CAC 或其他[[吸附剂]]相比，其[[BET|比表面积]]通常极低（范围为 $1 - 1 0 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 } )$（表 5）[151–167]。最近，Pratt 等人 [246] 采用基于[[染料]]的方法计算了表面积。[[环糊精-环氧氯丙烷聚合物|ECP 材料]]的表面积介于 40.5 至 90.1 m<sup>2</sup> g−<sup>1</sup> 之间，同时取决于 pH 和组成（表 5）。对于活性炭等传统材料，这些数值与根据氮气[[孔隙率]]测定数据计算所得的数值一致。然而，对于 [[环糊精–环氧氯丙烷聚合物|ECP 材料]]，基于染料的方法所得数值较低，因为染料主要被包合在 [[环糊精|CD]] 空腔内。

尽管 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的制备及应用已广为人知，但对这些产物的核磁共振（NMR）[[材料表征|表征]]受到的关注相对较少 [124,138,174]。针对这一问题，[[Crini G|Crini]] 等人 [124] 利用固态 NMR 研究了这些[[聚合反应|聚合]]物的结构。通过采用偶极去耦的交叉极化魔角旋转（CPMAS）和高分辨率魔角旋转（HRMAS）谱，他们表明，这些材料中存在两种结构：一种是 [[环糊精|CD]] 分子与[[环氧化物]]之间发生[[交联反应]]而形成的 [[环氧氯丙烷|EPI]] [[交联]] CD，另一种是 EPI 自身均聚形成的聚合 EPI。他们通过弛豫参数（<sup>13</sup>C 自旋–晶格弛豫、旋转坐标系中的 <sup>1</sup>H 自旋–晶格弛豫）分析了这两种组分。作者表明，由于 CD 含有七个[[葡萄糖]]单元，且葡萄糖单元的 C6 位带有羟烷基，因此许多单元相互连接，使其结构或[[三维聚合物网络|聚合物网络]]十分复杂。当交联度较高时，样品主要呈无定形，且交联并不均匀。Crini 等人 [124] 表明，[[环糊精-环氧氯丙烷聚合物|ECP 材料]]含有许多侧链，这可以解释为何这些材料形成的[[配合物]][[稳定性]]低于丙烯酰基 [[环糊精聚合物|CD 聚合物]]形成的配合物，后者几乎不含未形成桥联的侧链。然而，就技术应用而言，丙烯酰基 CD 等可聚合 [[环糊精衍生物|CD 衍生物]]的制备成本过高。最近，[[Wilson LD|Wilson]] 团队 [138] 对 [[环糊精–环氧氯丙烷聚合物|ECP]] 网络报道了类似的 NMR 解析结果。

Cowie 和 Spence [168] 表明，含有三氟甲磺酸锂、三氟甲磺酸钠和三氟甲磺酸钾盐的 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]表现出值得关注的离子传导性能。[[环糊精|CD]] 网络在离子传导过程中的参与程度较低，更多地起被动作用。这对于金属–CD [[配合物]]的形成可能具有意义。

## 4. 用于环境应用的[[水不溶性]] [[β-环糊精–环氧氯丙烷聚合物|--环糊精–环氧氯丙烷聚合物]]

## 4.1. [[水不溶性]] [[环糊精–环氧氯丙烷聚合物|ˇ-环糊精–环氧氯丙烷聚合物]]的历史

[[水不溶性]] [[β-环糊精–环氧氯丙烷聚合物|--环糊精–环氧氯丙烷聚合物]]（[[环糊精-环氧氯丙烷聚合物|ECP]]）于 1964–1965 年由瑞士科学家 [[Jürg Solms]]（瑞士沃韦 [[Nestlé 集团研究实验室]]）作为“[[包合树脂]]”提出，他为这些[[聚合反应|聚合]]物的化学合成、使用方法及应用申请了专利 [169–173]。1965 年，Solms 与其同事 [[Egli]] 首次详细发表了在碱性条件下、[[环氧氯丙烷|EPI]] 存在时使 [[环糊精|CD]] 聚合的方法 [170]。他们的结果表明，具有不规则形状颗粒的聚合物对[[苯胺]]、[[硝基苯酚]]、[[苯甲醛]]、[[吡啶]]、碘、[[刚果红]]和[[亚甲基蓝]]等各种分子表现出很强的[[吸附性能]]。所有结果均以[[包合物]]的形成来解释。他们将这些结果与一种不具有包合性能的商业化 [[环氧氯丙烷交联葡聚糖|EPI–葡聚糖交联聚合物]]（[[Sephadex]]<sup>®</sup>）所得结果进行了比较。与不具有包合性能的类似物相比，[[环糊精–环氧氯丙烷聚合物|ECP 树脂]]表现出特别良好的[[吸附选择性|选择性]]。这些[[凝胶]]还被用于凝胶[[色谱法|色谱]]柱，以分离[[苯丙氨酸]]、[[色氨酸]]、硝基[[苯酚]]（邻位和对位异构体无法在 Sephadex<sup>®</sup> 上分离）、[[维生素]]和[[香料]] [171]。Solms 和 Egli 发表的结果首次证明，ECP 材料是适用于凝胶包合色谱应用的色谱载体。

为改进 [[Jürg Solms|Solms]] 提出的方法，[[Niels Wiedenhof]] 及其同事 [174–178] 于 1969 年提出了两种珠状[[聚合反应|聚合]]工艺，即在非[[极性]]有机溶剂中、[[非离子型洗涤剂]]存在下，通过控制搅拌进行乳液聚合。这些不同的工艺于 1971 年获得专利，可制得物理性能优异、形状均一规则的[[微珠]]，这些特点对于[[色谱法|色谱]]应用颇具吸引力。这些微珠易于润湿，不溶于水和有机溶剂，并且在碱性水溶液中稳定。为获得有关[[取代基]]位置和数量的信息，Wiedenhof 等人 [174] 还研究了微珠的 IR 和 NMR 光谱。只有 NMR 结果能够提供此类信息 [177]。他们的结果表明，- [[环糊精-环氧氯丙烷聚合物|ECP]] 和 --CEP [[凝胶]]在[[溶胀]]特性和耐热性方面表现出与 [[Sephadex]]<sup>®</sup> [[Sephadex G-25|G-25 树脂]]相当的色谱行为。以[[苯酚]]、[[苯甲酸]]、[[苯胺]]、[[氯苯甲酸]]和[[酪氨酸]]为溶质，实现了多种分离，而这些结果也主要通过[[络合|络合现象]]来解释。例如，苯甲酸与邻苯甲酸可以得到分离，而使用 Sephadex<sup>®</sup> 则无法实现。[[环糊精树脂|CD 树脂]]能够分离不同分子，是因为树脂中含有能够形成[[包合物]]的 [[环糊精|CD]] 空腔。Wiedenhof[175] 还引入了“包合等温线”一词，以替代“吸着等温线”。

1970 年，[[Hoffman]] [179–181] 采用 [[Jürg Solms|Solms]] 和 [[Egli]] [170] 所述的工艺，提出了用于柱[[色谱法|色谱]]的高 [[环糊精|CD]] 含量材料。这些[[凝胶]]可用于分离[[核酸]]、[[核苷酸]]、[[核苷]]和[[寡核苷酸]]。对这些结果的解释不仅涉及包合[[络合]]作用，还涉及阴离子交换相互作用的存在。同一时期，还开展了其他有关色谱分离的研究 [182–185]。结果表明，[[环糊精-环氧氯丙烷聚合物|ECP 材料]]能够有效分离各种位置异构体和光学异构体，这可通过[[包合物]]的形成来解释。

随着 [[Szejtli]] 及其同事开展的一系列颇具意义的工作 [16,17,50,51,64,72,114,186–197]，[[环糊精聚合物|CD 聚合物]]和[[共聚物]]的研究在 20 世纪 70 年代末至 80 年代初加速发展。他们发表的大量论文和专利描述了 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]的合成、[[材料表征|表征]]及应用。第一个值得关注的结果如下：作者表明，通过[[本体聚合]]制备[[不溶性聚合物]]时，所得颗粒形状不规则。将[[聚合反应|聚合]]物制备成具有特定性能，尤其是具有可控[[溶胀]]性能的规则[[微珠|球形微珠]]，具有更大的优势。在水溶液中，这些溶胀微珠能够与多种客体分子形成[[包合物]]。与均相溶液中形成的包合物相比，[[水不溶性聚合物|不溶性聚合物]]所形成的包合物具有相当高的[[稳定性]]。动力学研究表明，其包合物形成速率常数与均相体系相近，但解离速率常数比均相体系低约两个数量级。

[[络合物]]形成能力主要取决于材料的结构：在各项化学特征中，空隙浓度、桥键密度和[[交联]]类型最为重要。[[Szejtli]] 及其同事表明，掺入[[二醇|低分子量二醇]]（如[[乙二醇]]、[[丙二醇]]或[[聚乙二醇]]）可使[[聚合反应|聚合]]物结构更加疏松。次级空腔的尺寸增大，从而使[[溶胀]]速度更快、溶胀程度更高。研究还通过[[污染物]][[吸附等温线]]对聚合物及其[[凝胶]]结构进行了[[材料表征|表征]]。[[环糊精-环氧氯丙烷聚合物|ECP]] [[微珠]]经[[甲基化]]后，所得聚合物含有的[[羟基|游离羟基]]极少，几乎所有羟基都被[[疏水基团]]取代。此类产物在水中不溶胀，但在有机溶剂中显著溶胀，并在特定[[色谱法|色谱]]应用中得到使用。在物质的提取、浓缩和纯化方面，已取得许多重要成果。[[Zsadon]] 等人 [198–206] 和 [[Cserháti]] 等人 [207–211] 表明，[[环糊精|CDs]] 的刚性结构以及在固相、溶液中或主体存在于气相时所形成的[[包合物]]的[[稳定性]]，使这些[[吸附选择性|选择性]]包合过程能够广泛应用于色谱方法。

制成块状 [169–171]、薄膜状 [174]、[[微珠]]状 [174,186] 或纤维状 [186,187] 的 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]，使多种特异性包合[[色谱法|色谱]]分离成为可能，其最初的应用主要是在分析领域用于物质的分离、提取和浓缩。这些材料可用作 HPLC 或 GC 中的载体或固定相（色谱柱填料），也可用作固相萃取（SPE）的[[吸附剂]]。例如，[[Szejtli]] 等人 [186–197]、[[Zsadon]] 等人 [198–206] 和 [[Cserháti]] 等人 [207–211] 表明，具有中等[[溶胀|溶胀能力]]的规则微珠在包合色谱中具有应用优势。即使在室温下，它们也能迅速溶胀，并且易于装填和沉降。溶胀后的颗粒不会变形，且具有弹性。即使经过反复干燥和溶胀，它们仍能保持原有的形状、尺寸和性能。另一个优点是，即使在潮湿状态下，它们也能抵抗微生物的破坏，并可在湿态下长期储存而不发生分解。这些结果无疑表明，商业化 [[环糊精–环氧氯丙烷聚合物|ECP 材料]]可用作分离过程中的色谱载体，许多其他出版物也报道了其取得不同程度成功的应用效果 [21,23]。然而，需要注意的是，直到 20 世纪 80 年代，才开发出实用技术。这可归因于[[凝胶]]形式的 [[环糊精聚合物|CD 聚合物]]在长期使用中表现出效率低和机械强度差的问题。因此，人们开发了将 [[环糊精|CDs]] [[化学键合]]于[[硅胶]]上的固定相，并迅速成功实现了商业化。

此前，人们已针对 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]在化学（[[催化]]）、药学和食品技术中的特定应用开展研究。它们在直接压片体系以及采用湿法制粒制备的制剂中均是有效的片剂崩解剂 [193]，还可催化某些反应 [212–215]。例如，[[Komiyama]] 和 [[Hirai]] [214,215] 报道，[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]是用于[[吸附选择性|选择性]]合成 [[4-羟基苯甲酸]]和 [[4-羟基苯甲醛]]的有趣催化剂。对药学应用的详细讨论感兴趣的读者，可参阅 [[Frömming]] 和 [[Szejtli]] 的著作 [216]。

20 世纪 80 年代初，[[Shaw]] 及其同事 [217–224] 证明，- 和 --[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]在食品加工领域具有广泛应用的潜力，因为它们能够根据苦味成分（[[柚皮苷]]、[[柠檬苦素]]和[[诺米林]]）的分子大小和形状，轻松地将其从柑橘汁中分离出来。[[β-环糊精|ˇ-CD]] [[凝胶]]是去除葡萄柚汁中柚皮苷和柠檬苦素的最佳材料，在效率和[[吸附选择性|选择性]]方面均优于[[交联聚苯乙烯]]和 [[Amberlite XAD-4]]。然而，他们的结果表明，[[聚合反应|聚合]]方法、[[交联剂]]和[[粒径]]是重要因素，因为这些因素会影响聚合物降低葡萄柚汁和脐橙汁中苦味成分含量的能力。1991 年，[[Su]] 和 [[Yang]] [225] 在研究利用 [[环糊精–环氧氯丙烷聚合物|ECP 凝胶]]去除天然食品成分（柚皮苷、[[咖啡因]]、[[可可碱]]）时，报告了类似的结论。1996 年，[[Hicks]] 等人 [226] 表明，这些聚合物可用于抑制新鲜生苹果汁、梨汁和芹菜汁的酶促褐变。

在众多将 [[环糊精聚合物|CD 基聚合物]]用作树脂的专利中，还有另外两项专利值得一提。所有制备 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的尝试所得到的产物，要么仅具有中等的机械[[稳定性]]，要么 [[环糊精|CD]] 含量较低。此外，制备过程可能既困难又昂贵，这可能使工业用户望而却步。为克服这些问题，[[Friedman]] 和 [[West]] [227] 于 1988 年为一种利用 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]、采用间歇和连续两种技术高效去除水中[[多氯联苯|多氯联苯化合物]]的方法申请了专利。[[环糊精–环氧氯丙烷聚合物|ECP]] 珠粒对这些有毒分子表现出较高的[[吸附容量]] [228]。[[Vanzo]] [229] 也于 1991 年为一种以商业化工业规模制备环糊精球形珠粒的方法申请了专利。这些珠粒制备简单，CD 含量高，同时与当时已知的同类 ECP 材料相比，其机械性能有所改善。

同一时期，[[Kiji]] 等人 [231]、[[Chen]] 和 [[He]] [232]、[[Murai S|Murai]] 等人 [233,234] 以及 [[Shao]] 等人 [235] 发表了有机物在 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]上[[吸附]]的研究结果。Murai 等人 [233,234] 研究了[[非离子表面活性剂]]、[[离子型表面活性剂]]和[[邻苯二甲酸酯]]在 [[环糊精–环氧氯丙烷聚合物|ECP 凝胶]]上的吸附，并表明，例如，1 g 材料能够从 150 mL、含 200 ppm 非离子[[表面活性剂]]的溶液中吸附 85% 的[[烷基酚聚氧乙烯醚]]。间歇吸附实验和[[柱吸附]]实验均显示出类似的、令人关注的[[吸附容量]]。另一个值得关注的特点是，所提出的[[吸附剂]]易于再生。这些结果可由[[包合物]]的形成以及[[三维聚合物网络|聚合物网络]]中的相互作用共同解释。

20 世纪 90 年代末，我们的研究组 [124,235–240] 采用 [[Jürg Solms|Solms]] 和 [[Egli]] [170] 所述、并经 [[Hoffman]] [179–181] 改进的方法，提出了几种具有不同 [[环糊精|CD]] 含量（20% 至 80% w/w）的材料。我们对该方法进行了少量修改，即增加 [[环氧氯丙烷|EPI]] 的用量，以获得机械性能稳定的材料。由于这些材料的[[交联]]程度相对较高，因此既可用于批次实验，也可用于柱实验。所提出的方法具有吸引力，并拓宽了这些材料的潜在应用范围，因为在[[吸附]]柱中使用 [[环糊精交联凝胶|ˇ-CD 交联凝胶]]通常会受到流体动力学限制和柱堵塞的制约。这些[[凝胶]]被用作非均相体系，以吸附[[氯酚]]、[[硝基苯酚|硝基酚]]、[[萘酚]]和[[苯甲酸类化合物|苯甲酸类]]等[[污染物]]。由于 [[β-环糊精|ˇ-CD]] 能够与许多[[染料|染料分子]]（[[酸性染料]]、[[直接染料]]、媒染染料和活性染料）形成[[包合物]]，这些凝胶还具有处理纺织生产[[废水]]的潜在用途。通过引入适当的[[取代基]]，如羧甲基或氨基，还可赋予不溶性 CD 材料良好的离子交换性能。利用固态 NMR 数据，研究者提出了[[聚合反应|聚合]]物结构与其[[吸附性能]]之间的相关关系。

## 4.2. 近期文献综述

过去 60 年来，为分析用途（如包合[[色谱法|色谱]]）制备 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]的想法一直是世界各地科学家关注的焦点，但关于将其用作[[吸附剂]]以去除[[废水]]中有毒[[污染物]]的最深入研究，直到最近二十年才开始 [240]。

20 世纪 90 年代，关于 [[环糊精|CD]] 及其实际应用的综述和书籍的出版，推动了大量有关 [[环糊精基材料|CD 基材料]]及其环境应用的研究 [11–23,50–52]。许多 [[环糊精衍生物|CD 衍生物]]已可获得并被用于众多商业应用，这一事实促进了新材料的开发，包括不溶性 [[环糊精聚合物|CD 基聚合物]]，尤其用于通过以[[吸附]]为主的过程去除[[污染物]]。研究者提出并开发了多种 CD 基材料，如[[交联聚合物]]或[[水凝胶]]、[[环糊精基复合材料|CD 基复合材料]]、通过[[化学键合]]将 CD 固定于各种载体上的材料，以及近年来出现的 [[环糊精基膜|CD 基膜]]和[[分子印迹功能材料]]。在这些材料中，[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]发挥着重要作用。

针对 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]开展研究的[[污染物]]种类非常广泛，包括[[染料|染料分子]]、芳香族化合物、[[氯酚]]、萘衍生物、二苯并呋喃分子、[[多氯联苯]]、农药（除草剂、杀菌剂、杀虫剂、杀螨剂等）、[[非离子表面活性剂]]（烷基酚）和[[离子型表面活性剂]]（十二烷基苯磺酸）、洗涤剂（十二烷基硫酸锂、2-萘甲酸盐）、金属以及稀土金属离子 [50,51]。[[环糊精-环氧氯丙烷聚合物|ECP 材料]]还被用于去除水样中的致臭化合物，以及富集水溶液中的不同物种。同样，含有 [[环糊精|CD]] 分子的载体在减少环境污染方面的潜在用途，在所有情况下均基于 CD 与不需要的物质之间形成[[包合物]]。“包合”一词是指发生一种特定的空间相互作用，其中客体分子或至少其一部分被容纳于主体的空腔中，使体系达到最低能量 [61]。

在本部分中，鉴于世界各地开展相关研究的团队数量众多，我们选取了 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]用于去除[[污染物]]方面最具代表性的研究成果。

表 6 列出了部分研究者及其所研究的污染物，下文将介绍他们的研究成果 [241–277]。

[[Evans CH|Evans]] 团队发表的研究成果 [241,242] 表明，将 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]用作柱内填料以捕集流动水中的[[有机污染物]]，在水体修复和水样采集方面具有实际应用价值。他们的结果清楚地表明，[[环糊精|CD]] 基填料是一类很有前景的[[吸附剂]]，因为其表现出较强的[[吸附]]能力，并且还具有可回收[[聚合反应|聚合]]物以循环利用的额外优势。饱和吸附剂可通过萃取轻松再生，而且经过多次再生循环后，吸附剂的[[络合]]能力仍保持不变。

[[Isasi JR|Isasi]] 及其同事也深入研究了 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]作为[[吸附剂]]去除[[污染物]]的有效性 [128,142,167,262–264]。所研究的污染物包括二苯并呋喃 [167]、萘 [142,262] 和酚类衍生物 [142,264]，影响[[吸附性能]]的参数包括 [[环糊精–环氧氯丙烷聚合物|ECP]] 合成所采用的实验条件变量 [128]、[[聚合反应|聚合]]物结构 [167]、[[交联密度]]和[[溶胀]]度 [128]、[[环糊精|CD]] 含量 [128]、污染物结构 [262]、[[粒径]] [128] 以及温度响应行为 [167]。研究取得了显著成果：[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]表现出较强的[[吸附]]性能和[[吸附选择性|选择性]]。所有结果主要通过[[包合物]]的形成来解释，证实了 [[Crini G|Crini]] 团队此前发表的解释 [61,125–127]。与用于从水中提取污染物的传统吸附剂（活性炭、大孔有机树脂）相比，ECP 聚合物表现出更优的吸附性能和特性 [264]。Isasi 及其同事得出结论，ECP 是用于环境领域的高效材料。

[[Moon]] 等人提出了一种基于与 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]形成[[包合物]]的新型固相萃取技术 [259–261]。在甾体化合物试验中，采用四氢呋喃对[[聚合反应|聚合]]物所捕集的化合物进行萃取，尿液中 77 种甾体的总回收率为 82% 至 112%。与传统的基于[[疏水性]]的萃取柱相比，[[环糊精|CD]] 实验中[[极性]]甾体的萃取效率显著提高，这归因于其由分子包合和化学相互作用产生的多功能机制。

[[Li N|Li]] 等人通过批量实验 [166,249–251] 表明，[[环糊精-环氧氯丙烷聚合物|ECP 材料]]对 4-[[氯酚|氯苯酚]]、2,4-二氯[[苯酚]]和[[苯胺]]具有较高的[[吸附容量]]。[[吸附动力学]]过程迅速（达到平衡需 2–2.5 h），[[吸附]]容量较高（在 283 K、[[污染物]]初始浓度为 140 mg L−<sup>1</sup> 时，最高可达 $2 4 . 4 \mathrm { m g g ^ { - 1 } }$）。吸附容量也不受 pH 影响。以乙醇为洗涤溶剂可轻松回收这些[[聚合反应|聚合]]物。

近期，[[Wilson LD|Wilson]] 研究组 [138,244–246] 研究了环烷酸（NAs）在一系列由 [[环氧氯丙烷|EPI]] 或[[异氰酸酯]]衍生物[[交联]]的[[环糊精]]颗粒上的[[吸附]]。由 EPI 交联的 CD 获得了最佳[[去除效率]]。尽管所提出材料的[[BET|比表面积]]低于商业活性炭，作者仍认为这些材料适用于去除 NAs，尤其是在较低 pH 条件下 [244]。在所考察的实验条件下，炭材料的[[吸附容量|吸附量]]为每克[[吸附剂]] 100 至 160 mg NAs，而[[聚合反应|聚合]]物材料的吸附量为每克材料 20 至 30 mg NAs。作者认为，标准颗粒炭与 [[环糊精聚合物|CD 基聚合物]]之间的性能差异与材料[[比表面积]]及其化学性质的差异有关。以对[[硝基苯酚]]作为模型溶质的研究也得出了类似结论 [138]。在另一项研究中，[[Mohamed]] 等人 [245] 证明，基于[[染料]]吸附的分析方法是一种简便且用途广泛的方法，可用于评价 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]包合位点的可及性，并为理解含 CD 分子的吸附剂材料的吸附性质提供有益认识。所有这些研究 [138,241,245,263] 均表明，CD 大环是材料设计中的关键组分，因为[[结合位点]]的表面可及性会影响其吸附性质。

Bonenfant 等人 [243] 最近提出在[[羧甲基纤维素]]（CMC）存在下使 [[β-环糊精|ˇ-CD]] 与 [[环氧氯丙烷|EPI]] [[聚合反应|聚合]]，由此制得了用于去除水溶液中[[非离子表面活性剂]]（如[[烷基酚聚氧乙烯醚]]——NPEO）的颇具吸引力的[[吸附剂]]。实验采用含有 500 mg [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]和浓度为 12–82 mg L−<sup>1</sup> 的 NPEO 水溶液的混合物进行。结果表明，去除过程迅速，且该聚合物表现出较高的 NPEO [[吸附容量]]（每克聚合物[[吸附]] 1.1–6.8 mg NPEO）。[[Murai S|Murai]] 等人 [233] 此前使用 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]也得出了类似结论。

在我们课题组中，正在开展实验，以评估将 [[β-环糊精|ˇ-CD]] 基材料用作[[工业废水处理]][[吸附剂]]的可行性 [23,53,61,124–127,165,235–240]。我们提出将这些[[聚合反应|聚合]]物用作新型[[交联]]材料，通过[[批量吸附法|批量法]]和[[柱试验]][[吸附]]实际[[废水]]中的有机和[[无机污染物]]。这些实验表明，[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]能够与有机化合物（[[苯酚]]、--[[萘酚]]等）和[[染料|染料分子]]有效相互作用。特别是，--[[环糊精聚合物|CD 基聚合物]]在去除溶液中的[[酸性染料]]、[[直接染料]]、[[分散染料]]和活性染料方面非常高效。[[BET|比表面积]]和[[孔结构|孔结构特征]]是重要的物理化学性质。众所周知，这些特征会影响多孔聚合物材料的[[吸附性能]]，尤其是无定形和非模板法制备的材料。我们认为，[[包合物]]形成占主导地位可以解释我们的结果。除 [[环糊精–环氧氯丙烷聚合物|ECP 凝胶]]结构表面及孔内部的物理吸附外，[[环糊精|CD]] 空腔中包合物的形成在该机制中起着最重要的作用。[[Fenyvesi]] 等人此前也报道过类似结论 [193–195]。[[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]易于再生，[[柱吸附]]和[[解吸]]试验表明，吸附在[[交联聚合物]]上的[[污染物]]可通过各种醇水溶液成功释放。Zhang 等人 [252] 也报道，ˇ-CD 吸附剂对染料分子具有特异性包合识别能力。此外，这些作者提出，染料在 ECP 材料上的吸附机制包括[[三维聚合物网络|聚合物网络]]中的物理吸附和主–客体包合物的形成，其中包合作用起着最重要的作用。

[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的[[化学改性]]持续受到研究人员的关注，因为它能够赋予材料所需的性能，从而扩大可捕集[[污染物]]的范围 [23,59]。除了[[络合]]目标[[染料]] [126,127,252] 或酚类衍生物 [243] 之外，还可通过引入能够配位金属或氟离子的基团来改善其性能，Sancey 等人近期的研究已证明了这一点 [165]。例如，已知未经改性的 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]对阳离子染料的亲和力较低。为拓展其[[吸附性能]]，[[Crini G|Crini]] 团队 [126,127] 提出将羧基化学[[接枝]]到[[环糊精]]上，以赋予[[微珠|聚合物微珠]][[吸附]]阳离子染料的能力。这些[[有机吸附剂]]通过在 [[羧甲基纤维素|CMC]] 存在下[[交联]]制得。由于[[三维聚合物网络|聚合物网络]]中含有 [[羟基|OH]] 和 COOH 基团，该材料具有[[亲水性]]，易于在水中[[溶胀]]，并具有离子交换性能。结果表明，与其他传统 [[环糊精–环氧氯丙烷聚合物|ECP 材料]]相比，[[改性环糊精-环氧氯丙烷聚合物|改性 ECP 凝胶]]对水样中污染物的吸附具有更强的特异性和更高的[[吸附容量|吸附量]]。Zhang 等人 [252] 在研究含羧甲基的 ECP 对品红的吸附时，得出了类似结论。他们还指出，其机制不仅应包括 CD 空腔产生的包合作用，还应涵盖颗粒表面新引入的反应性基团所产生的[[静电相互作用]]和范德华力的影响。Bonenfant 等人 [243] 也证明，在 CMC 存在下制备的 ECP [[凝胶]]能够与水溶液中的烷基酚有效相互作用。这些作者表明，CMC 的存在可通过促进材料在水中的溶胀，提高[[聚合反应|聚合]]物中 [[β-环糊精|ˇ-CD]] 的可接近性和迁移能力。然而，他们得出结论，[[壬基酚聚氧乙烯醚]]的吸附具有很强的浓度依赖性，ECP 聚合物在低浓度下吸附的污染物要多得多。[[Fenyvesi]] 等人 [193–195] 此前报道，当 COOH 位点等离子型基团以[[共价键]]连接到[[共聚合|（共）聚合]]物上时，[[聚合物基体|基体]]与污染物之间的相互作用还会伴随成盐作用，多种相互作用同时发挥作用（例如包合、化学吸附以及[[聚合物网络]]的物理吸附）。

pH 响应性[[水凝胶]]是一类能够响应环境 pH 变化并相应改变其体积的[[凝胶]]。这些材料在制药应用中尤为引人关注，例如用于[[药物]]控释系统。近年来，具有正、负两种电荷的两性 pH 敏感性[[多糖]]基水凝胶受到特别关注，因此类水凝胶无需调节 pH 即可在酸性和[[碱性介质]]中[[溶胀]]。[[Crini G|Crini]] [273] 最近就一种制备带有离子型[[官能团]]的[[交联]]多糖和低聚糖的新方法申请了专利。在 $\mathrm { N H } _ { 4 } \mathrm { O H }$ 存在下，于适中温度下将[[聚合反应|聚合]]物或低聚物与环氧[[交联剂]]（1,4-丁[[二醇]]二缩水甘油醚，BUDGE）及 2,3-环氧丙基三甲基氯化铵（EPTAC）混合。在使用 BUDGE 进行交联的步骤中，聚合物链通过 EPTAC 实现阳离子化。所得[[交联聚合物]]含有不同取代度的[[羟基]]、叔氨基和季铵基团。该材料还具有可利用的表面积 $( 1 0 0 - 1 5 0 \mathrm { m } ^ { 2 } \mathrm { g } ^ { - 1 } )$、[[两亲性]]，并且由于其交联单元具有[[亲水性]]，在水中表现出极高的溶胀能力。对阳离子型交联材料进行氨乙基化和[[羧甲基化]]，可制得两性衍生物，有望用于处理含有表面处理行业产生的金属、纺织行业产生的[[染料]]或造纸行业产生的有机物的[[废水]]。由于[[三维聚合物网络|聚合物网络]]中主链叔胺基和侧链羧基的质子化与去质子化，所得水凝胶具有典型的两性特征。例如，我们提出将这些新型两亲性[[交联环糊精聚合物|交联 CD 聚合物]]用作[[络合]]树脂，以去除[[工业废水]]中的有机物（以化学需氧量，即 COD 参数[[材料表征|表征]]）、金属、硼和氟离子 [165]。由于其特殊的电荷特性，这些凝胶可在较宽的 pH 范围内使用。图 9 比较了未经额外后处理即排入自然环境的工业废水（[[吸附]]前），以及经吸附处理后的同一排放水（吸附后）。这些结果表明，利用具有离子交换性能的交联 [[环糊精|CD]] 材料进行吸附，是一种值得关注的工艺，可同时去除阳离子、阴离子和有机物，并在排入环境前进一步削减污染。使用后，这些材料可通过焚烧处置，从而避免繁琐且昂贵的再生过程。

少数研究表明，[[聚合物吸附剂]]也易于再生。经再生处理后，其[[吸附容量]]保持不变，这既表明了[[不溶性聚合物]]的化学[[稳定性]]，也表明了测定值的可重复性 [125,166,233–237,241,247,272]。[[Murai S|Murai]] 等人 [234] 得出结论，在实际应用中，[[环糊精-环氧氯丙烷聚合物|ECP 材料]]的反复循环使用比商业活性炭更具优势。[[Li N|Li]] 等人 [166] 和 [[Yang]] 等人 [247] 也报告了类似结论。

最后，还应指出近期关于 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]用于富集水溶液中的不同物种、去除气相中的污染组分或去除致臭化合物的应用研究 [253–255,272]。例如，Rashmawi 等人 [272] 提出使用 [[环糊精–环氧氯丙烷聚合物|ECP 凝胶]]去除引起异味和异嗅的化合物；与商用活性炭相比，其[[去除效率]]更为可观。Fourmentin 团队 [253,254] 研究了 [[环糊精-环氧氯丙烷聚合物|ECP]] 与精油中芳樟醇和樟脑的包合作用。[[Mallard Favier]] 等人 [255] 首次提出将[[交联环糊精聚合物|交联 CD 基材料]]用于捕集气相中的 VOC。他们得出结论，ECP 在[[有机污染物]]修复方面具有应用前景。然而，尽管这些结果通过[[包合物]]的形成得到了解释，仍需进一步研究以明确[[聚合反应|聚合]]物结构的作用，并研究动态 VOC 捕集过程。

## 4.3. [[吸附]]导向过程中的性能调控

根据文献数据，决定[[环糊精|CD]][[聚合反应|聚合]]物[[吸附性能]]并在其作用机制中发挥重要作用的参数包括[[交联密度]]、[[亲水性]]、[[溶胀|溶胀程度]]、CD含量、CD可及性，以及[[三维聚合物网络|聚合物网络]]中[[配体]]的存在[21,23,61,166]。众所周知，且文献中已有广泛报道，[[交联]]密度（即链间桥接的频率）是影响最终材料性能的主要参数。然而，其具体作用仍存在争议。

一般而言，用于[[吸附]]过程的 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]在水中具有极高的[[溶胀|溶胀能力]]，因此其网络能够充分扩展，使所研究的吸附质快速扩散。[[Crini G|Crini]] 研究组 [23,124–127,236,237] 表明，控制并[[材料表征|表征]][[交联反应]]条件十分重要，因为这些条件会调节[[交联密度]]和溶胀程度。他们观察到，较高的[[聚合反应|聚合]]温度有利于聚合物达到较高的溶胀程度，从而改善[[吸附性能]]，这证实了 [[Niels Wiedenhof|Wiedenhof]] 等人 [174,175] 先前发表的结果。高温也有利于 [[环氧氯丙烷|EPI]] 的自聚合，而较高的 NaOH 浓度会增加引入 [[环糊精–环氧氯丙烷聚合物|ECP 聚合物]]中的 EPI 量，这与 [[Szejtli]] 等人 [186–190] 的结果一致。Crini 研究组还利用 NMR 数据表明，[[环糊精|CD]] 分子之间较长的羟丙基醚链段有利于[[聚合物网络|大分子网络]]扩展，从而产生更高的溶胀程度 [124]。吸附结果表明，随着[[交联]]频率增加，吸附性能下降。在较高交联程度下，由于三维网络更加致密且[[疏水性]]增强，[[凝胶]]的溶胀能力较低，[[污染物]]进入[[三维聚合物网络|聚合物网络]]的可及性及其在网络中的扩散均降低。对于聚合物溶胀的控制，他们表明，最重要的因素主要是 CD/EPI [[摩尔比]]，其次是反应过程中的搅拌速度和 NaOH 浓度。Romo 等人 [128] 也报告了类似结论。

[[环糊精]]含量也是一个重要因素，尽管已发表的结论存在分歧。例如，[[Crini G|Crini]] [125]、Romo 等人 [128] 和 Yu 等人 [256] 表明，较高的 CD 含量带来了较高的[[吸附容量]]；而在某些情况下，较低的 CD 负载量反而有利于获得更好的[[吸附性能]]，正如 Vélaz 等人 [129] 最近报道的，或 [[Mocanu]] 等人 [21] 以及 Crini 和 [[Morcellet]] [23] 先前综述的那样。Romo 等人 [128] 表明，CD 含量较低的 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]具有较小的[[粒径]]和较低的[[溶胀|溶胀程度]]。总体而言，CD 含量的增加对应于[[吸附]]容量的增加，这印证了包合现象在吸附机制中起着最重要的作用。Vélaz 等人 [129] 证明，CD 含量相近的[[聚合反应|聚合]]物可以表现出不同的结构特征，尤其是由于聚合物合成时采用的[[交联]]程度不同，其溶胀程度也有所不同。CD 含量为 74% 的[[不溶性聚合物]]所具有的可用 CD 少于 CD 含量为 65% 的聚合物：作者将此归因于富含 CD 的聚合物具有更高的交联程度。然而，在该研究中，材料中的 CD 含量是通过元素分析确定的 [129]。但是，材料中的 CD 分子、桥链以及侧链均仅含有 C、O 和 H。根据基于元素分析的计算，较高交联程度会导致较高 CD 含量这一结论似乎存在争议，尤其是因为可及 CD 的浓度与这些结果并不一致。最近，Liu 等人 [248] 为了区分 [[环糊精聚合物|CD 基聚合物]]各项性质对其吸附潜力的定量贡献，采用了多元回归分析，结果表明，聚合物的表观吸附潜力主要与 CD 含量有关。

pH 和离子强度的影响也是另一个存在争议的领域。[[Shao]] 等人 [235] 在研究[[染料]]在 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]上的[[吸附]]时表明，pH 对[[吸附速率]]的影响较小，而离子强度的影响则很显著。添加阴离子[[表面活性剂]]和盐类对吸附既可能产生正面影响，也可能产生负面影响。SDS 和 NaCl 等表面活性剂和盐类是工业染色过程中常用的染色助剂。研究发现，NaCl 对 [[环糊精–环氧氯丙烷聚合物|ECP]] 的性能具有正面影响，而 SDS 则使吸附大幅降低。这被解释为染料分子被隔离在表面活性剂[[胶束]]内部，以及 SDS 与 [[环糊精|CD]] 分子之间的[[包合物]]占据主导地位。在这种情况下，胶束增溶以及 SDS 的竞争是染料分子在 ECP [[聚合反应|聚合]]物上[[吸附容量|吸附量]]降低的原因。[[Li N|Li]] 等人 [166] 在研究[[氯酚]]衍生物在 ECP 聚合物上的吸附时表明，NaCl 可使 ECP 的性能略有提高，这是因为盐能够最大限度地减少表面电荷。Pratt 等人 [246] 最近报道，ECP 聚合物的[[去除效率]]取决于[[吸附剂]]的用量和性质、温度、[[污染物]]浓度以及 pH。[[交联密度]]较高的聚合物具有更高的去除效率。在较高 pH 下，其性能也更佳，这被归因于在碱性 pH 条件下，CD [[羟基]]发生部分去质子化，由此产生的材料内部静电排斥可能使骨架[[溶胀]]。与此相反，[[Crini G|Crini]] 研究组 [125–127] 报道，[[凝胶]]的吸附容量对离子强度的依赖性大于对 pH 的依赖性。具体而言，氯化钠的存在最大限度地减少了 ECP 聚合物的表面电荷 [166]，从而提高了其性能。然而，材料和方法上的差异使研究结果难以比较，要理解 pH 和离子强度对这类 [[环糊精基材料|CD 基材料]]的作用，仍需开展大量工作。

Romo 等人 [128] 在研究二苯并呋喃（DBF）和[[苯酚]]在 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]上的[[吸附]]时，报道了一些有趣的差异。这些差异也与芳香族化合物本身的结构和[[极性]]不同有关。与苯酚相比，DBF 更容易被捕获在[[疏水性]] [[环糊精|CD]] 空腔中，而苯酚形成的[[包合物]][[稳定性]]较低（苯酚–CD 复合物的稳定性相当低，因为相对于 CD 空腔而言，该溶质的尺寸较小）。然而，对于 CD 含量较低且[[溶胀|溶胀程度]]较高的[[聚合反应|聚合]]物（由于存在长度较大的羟丙基醚链段），苯酚通过[[疏水相互作用]]和/或[[氢键]]在[[三维聚合物网络|聚合物网络]]中的[[吸附容量|吸附量]]可能高于 DBF。在这种情况下，苯酚的吸附主要取决于其与[[聚合物网络]]的相互作用。

## 4.4. [[吸附]]机理

[[环糊精|CD]] [[包合物]]的相对[[稳定性]]受多种因素支配，如[[氢键]]、[[疏水相互作用]]、液体介质中的溶剂化效应以及分子的空间填充能力。包合作用的稳定性取决于主体分子的大小、[[极性]]及其形状与 CD 空腔尺寸之间的关系 [13,14,50,66]。在[[配合物]]形成过程中，没有[[共价键]]形成或断裂，这突出了该过程的物理性质。然而，通常用于解释配合物形成的主体与客体分子（如[[污染物]]或[[药物]]）之间的结合驱动力包括[[静电相互作用]]、氢键、疏水相互作用、范德华力以及“高能水”的释放 [65,66]。这解释了为何在混合物中，一系列结构相关的被[[吸附]]物可能表现出显著不同的结合行为。这也是将 [[环糊精衍生物|CD 衍生物]]用于分离过程的基础 [11,12,50,75,76]。

为解释[[凝胶]]形式的[[水不溶性]] [[环糊精聚合物|CD 聚合物]]与化合物之间的相互作用，研究者提出了三种主要机制，涉及 (1) [[环糊精|CD]] 空腔内的相互作用（即[[包合物]]的形成），(2) [[聚合反应|聚合]]物微球内部孔隙中的相互作用，以及 (3) 表面上的相互作用（物理[[吸附]]）。一般而言，物理吸附在 [[环糊精-环氧氯丙烷聚合物|ECP]] 与[[污染物]]之间的相互作用中所起的作用很小，因为 [[环糊精基材料|CD 基材料]]的[[BET|比表面积]]很小 [21,23,256]，因此相关结果主要通过包合[[配合物]]的形成来解释。然而，文献中对此存在争议。[[Mohamed]] 等人 [138,244] 最近表明，物理化学性质和织构性质（即[[比表面积]]和孔隙结构）在吸附机制中起着重要作用。他们研究了环烷酸在 [[环糊精–环氧氯丙烷聚合物|ECP 聚合物]]上的吸附，结果表明，[[吸附容量]]随聚合物比表面积的增大而增加。

上述三种机制通过与作为非包合类似物的 [[Sephadex]]<sup>®</sup> [[凝胶]]进行比较，已成为凝胶包合[[色谱法|色谱]]法的基础。[[Jürg Solms|Solms]] 和 [[Egli]] [170] 给出的首个实例具有说明性：他们比较了两种凝胶，即 Sephadex<sup>®</sup> 和 [[环糊精-环氧氯丙烷聚合物|ECP]]，与不同溶质（[[苯胺]]、[[苯甲醛]]、[[吡啶]]、[[硝基苯酚]]）的相互作用等温线。在所有这些情况下均发现了显著差异，证实了与 [[环糊精聚合物|CD 聚合物]]之间相互作用的包合特征。由邻硝基[[苯酚]]和对硝基苯酚的等温线形状可知，这些客体分子无法在 Sephadex 上分离，而它们在 [[环糊精–环氧氯丙烷聚合物|ECP]] 载体上不同的包合相互作用则可用于实现色谱分离 [171]。[[Niels Wiedenhof|Wiedenhof]] 和 Trieling [177] 以及 Hoffmann [179–181] 根据[[氯苯甲酸]]异构体或[[核苷酸]]与 ECP [[聚合反应|聚合]]物的相互作用等温线，也得出了类似结论。例如，由等温线的斜率可知，间氯[[苯甲酸]]的相互作用最强，而对氯苯甲酸和邻氯苯甲酸的相互作用有所不同，但二者均明显较弱。此外，与 --[[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的相互作用强于与 -ECP 凝胶的相互作用，这与受 [[环糊精|CD]] 环内空腔尺寸支配的包合机制相符。数据证实了与 --ECP 凝胶之间存在较强的相互作用，并证实邻氯苯甲酸可以与苯甲酸分离，而这两种组分的峰在 Sephadex<sup>®</sup> 上则相互重叠。

基于这些数据，[[Zsadon]] 等人 [198,199] 在研究芳香族氨基酸在 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]上的分离时得出了一项总体结论：[[环糊精|CD]] 对芳香族分子具有更高的亲和力，并对其异构体具有立体特异性。通过比较相同条件下使用 --[[环糊精–环氧氯丙烷聚合物|ECP 聚合物]]和 [[Sephadex]]<sup>®</sup> 获得的[[色谱法|色谱]]图，他们的结论得到了证实。最重要的相互作用源于包合作用。然而，在另一项研究吲哚生物碱在 ECP 和 Sephadex<sup>®</sup> [[凝胶]]上分离的工作中，Zsadon 等人 [200] 得出结论认为，相互作用机制由[[包合物]]的形成或包合与[[吸附]]的联合作用所主导，具体取决于[[聚合反应|聚合]]物结构及所研究的溶质。

[[Szejtli]] 的研究小组 [186–189] 此前报道，[[交联环糊精聚合物]]能够通过与 [[环糊精|CD]] 形成[[包合物]]，以及将有机分子[[吸附]]在其网络外部，来保留不同的有机分子。这一机制，尤其是形成包合物的能力，主要取决于 [[环糊精-环氧氯丙烷聚合物|ECP]] 的结构及其[[交联]]度，这与 [[Jürg Solms|Solms]] 和 [[Egli]] [170]、[[Niels Wiedenhof|Wiedenhof]] 等人 [177] 以及 Hoffmann [179–181] 发表的结果一致。Szejtli 的研究小组 [186–189] 证明，在疏松结构中，客体分子很容易接近 CD 环。如果[[交联剂]]形成的次级空腔与 CD 环的尺寸相当，则更多客体分子可嵌入其中。这一现象使 [[环糊精-环氧氯丙烷凝胶|ECP 凝胶]]的主–客体比高于 CD 及其非[[聚合反应|聚合]]物衍生物。然而，对于高度交联的聚合物，只有颗粒的外表面能够参与包合物的形成。客体分子无法进入网络内部。这正是此类聚合物的主–客体比低于 CD 或其非聚合物衍生物的原因。然而，[[Shao]] 等人 [235] 在研究[[染料]]在 [[环糊精–环氧氯丙烷聚合物|ECP]] 上的吸附时得出了相反的结论。[[凝胶]]的性能与各自的交联度之间未观察到明确的相关性。他们发现，某些染料分子在溶液中与 -- CD 不存在特异性相互作用（可见光谱未发生变化），但仍可被 ECP 凝胶高效吸附。作者解释，凝胶对染料的吸附并非源于主–客体包合物的形成，而主要归因于[[三维聚合物网络|聚合物网络]]对染料的吸附，且与其交联度无关。

[[Crini G|Crini]] [61,125] 将[[污染物]]在 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]上的[[吸附]]机制解释为[[三维聚合物网络|聚合物网络]]中的物理吸附与[[包合物|主–客体包合物]]形成的共同作用，这与 [[Szejtli]] 等人 [186–189] 的结果一致。然而，Crini [61,125] 证明，其他相互作用，如[[氢键]]、[[疏水相互作用]]（污染物–污染物和[[聚合反应|聚合]]物–污染物相互作用）、聚集机制（存在大分子[[染料]]时）以及离子交换，也不容忽视，尤其是在 [[环糊精–环氧氯丙烷聚合物|ECP 聚合物]]经反应性基团改性时。García-Zubiri 等人 [262–264]、Bonenfant 等人 [243] 和 Pratt 等人 [246] 近期也报道了类似的解释。例如，Bonenfant 等人 [243] 表明，[[壬基酚聚氧乙烯醚]]在 ECP 聚合物中的吸附主要与形成非常稳定的包合物有关，而[[聚合物网络]]有利于该包合物的形成。这种[[吸附性能]]也可由聚合物与污染物之间形成的[[疏水性]]范德华相互作用来解释。此外，[[环氧氯丙烷|EPI]] 可通过在聚合物表面生成链来增强吸附 [124]，这些链有助于增强[[凝胶]]与污染物分子之间的相互作用。近期，Pratt 等人 [246] 得出结论，对[[硝基苯酚]]在 ECP 聚合物上的吸附不能明确归因于其与 [[环糊精|CD]] 位点形成包合物，因为由 EPI 形成的[[甘油基]]桥和二羟丙基结构单元所构成的网络似乎对材料的结构性质具有协同作用。这些作者表明，[[交联]]键和侧链含量的增加会提高[[吸附容量]]和材料的[[溶胀|溶胀能力]]，并改变聚合物的亲水–亲油平衡。

近期，Liu 等人 [248] 采用多元回归分析研究了农药在 [[环糊精聚合物|CD 基聚合物]]上的[[吸附]]，指出了 [[环糊精|CD]] 单元的主要作用。[[Li N|Li]] 等人 [166,249–251] 也提出，酚类化合物在 [[环糊精-环氧氯丙烷聚合物|ECP]] 颗粒上的吸附主要归因于 CD 分子的[[疏水空腔]]与水中有机溶质之间形成[[包合物]]。基于动力学测量，他们提出限速步骤可能是化学吸附。然而，[[聚合反应|聚合]]物结构在数据解释中也很重要。[[Moon]] 等人 [259–261] 指出了分子包合与化学相互作用（[[氢键]]等）两者的作用。

目前普遍认为，有机溶质在[[交联聚合物]]中的吸着可通过两种主要机制发生：[[环糊精|CD]] 空腔的孔穴填充和在[[三维聚合物网络|聚合物网络]]中的分配。第一种相互作用（即形成[[包合物]]）显然受到[[吸附]]质与环糊精空腔之间相容性的影响 [1,23,129]。这是决定通过该机制吸附的量的关键因素，但也不应忽视[[聚合反应|聚合]]物结构的影响，尤其是对于无法完全包合在空腔内的较大[[污染物]]。通过选择适当的[[交联剂]]，可以调节分配机制在吸着过程中的重要性 [61,263]。只要可及性未因过度[[交联]]而受到限制，交联桥形成的其他空腔也会根据其化学亲和性捕获污染物分子。[[Crini G|Crini]] [125]、Vélaz 等人 [129] 和 García-Zubiri 等人 [262] 指出，必须同时考虑 CD 空腔内的包合作用以及与网络的相互作用；不过，聚合物较低的 [[BET]] [[比表面积]]同样意味着表面物理吸着的影响可以忽略不计，这与对[[凝胶]]状[[吸附剂|吸着剂]]的预期一致。主要作用可归因于 CD 空腔的存在。García-Zubiri 等人 [263] 最近表明，吸附质在 CD 空腔内的[[主客体相互作用|主–客体相互作用]]对应于双模式方法中所考虑的孔穴填充机制，而[[聚合物网络|聚合物交联网络]]能够通过分配捕获更多的吸附质分子。他们证明，当吸着由 CD 基团内的包合作用主导时，简单的 [[Langmuir模型|Langmuir]] 等温式即可恰当地拟合数据。当吸附质为[[苯酚]]时，经典 [[Freundlich模型|Freundlich]] 方程也适用，因为苯酚与 [[β-环糊精|--CD]] 的相互作用比 1-[[萘酚]]的相互作用特异性更低。[[Fenyvesi]] 等人 [194] 也报告了类似结论。Pratt 等人 [246] 表明，系统改变材料合成所用的实验条件，尤其是 CD 和 [[环氧氯丙烷|EPI]] 的组成，可使人们对 [[环糊精-环氧氯丙烷聚合物|ECP 聚合物]]吸着溶液中对[[硝基苯酚]]的机制获得有价值的细致理解。Liu 等人 [248] 针对 [[环糊精聚合物|CD 聚合物]]去除农药（除草定、西玛津、阿特拉津）的情况，提出了类似的研究。

## 4.5. 个人看法

文献综述表明，[[环糊精|CD]] 及其衍生物易于制造且无毒，这使其大规模应用成为可能。环糊精已在制药、农用化学品和[[食品工业]]，以及[[化妆品]]、盥洗用品和化学领域得到应用。然而，除在[[分析化学]]和[[色谱法|色谱]]领域的商业应用外，CD 和 [[环糊精聚合物|CD 基聚合物]]尚未在工业规模的[[废水处理]]中得到实际应用。

然而，关于使用[[环糊精基材料]]去除[[污染物]]的出版物数量不断增加，表明人们对开发用于[[废水处理]]的新材料的兴趣日益浓厚。尽管与活性炭相比成本较高是一项缺点，但 [[环糊精–环氧氯丙烷聚合物|ECP 树脂]]在水和[[废水]]处理应用中的实用性源于其多项优势：易于合成（[[环糊精-环氧氯丙烷聚合物|ECP]] 及其衍生物均为商业化产品）、易于再生、可针对特定应用进行定制，以及对目标污染物具有较高的[[吸附容量]]和[[吸附选择性|选择性]]。对于以[[吸附]]为主的工艺，ECP 材料可能是一种值得关注的替代选择。然而，这些出版物大多并非直接面向实际应用，商业化 ECP [[吸附剂]]在这一领域也尚未得到显著应用，尽管与目前可用于去除污染物的碳材料和有机树脂相比，它们还具有更易再生等其他优势。ECP 吸附剂尚未在工业中得到广泛应用的一个原因，或许是人们对这类材料的工程应用缺乏了解。我们认为，要使新型吸附剂被工业界接受，就有必要采用多学科协作的方法，让化学家、[[生物学]]家、微生物学家、高分子科学家和工程师共同开展工作。

从高分子化学家的角度来看，研究需要探究[[三维聚合物网络|聚合物网络]]的确切作用。尽管已有多种具有不同结构和性能的 [[环糊精-环氧氯丙烷聚合物|ECP 材料]]被提出用于去除[[污染物]]，但 [[环糊精–环氧氯丙烷聚合物|ECP]] 的特性如何影响其对污染物的[[吸附]]亲和力，目前仍不明确；这一问题不仅存在于单一污染物溶液中，在多污染物混合体系中尤其如此。还需要开展研究，以更好地理[[解吸]]附机制。毫无疑问，[[β-环糊精|ˇ-CD]] 分子通过[[主客体相互作用|主–客体相互作用]]形成[[包合物]]，对[[聚合物网络]]的性能起着重要作用。然而，（改性）[[聚合反应|聚合]]物网络与污染物之间的[[氢键]]、[[疏水相互作用]]、静电力和酸–碱相互作用等其他相互作用，以及物理吸附，也参与其中。由于 ECP 的[[BET|比表面积]]较低，物理吸附这一点仍存在争议。此外，关于这些材料的再生、再生后的性能重现性，以及经过多次使用循环后材料的[[稳定性]]，目前可获得的信息也十分有限。

## 5. 结论

近年来，[[环糊精]]在去除水中[[污染物]]方面受到了广泛关注，因为其结构中的[[疏水空腔]]能够容纳疏水分子，提供理想的[[结合位点]]。然而，由于环糊精可溶于水，因此无法直接使用。为克服这一问题，文献中提出的方法之一是使用[[偶联剂]]使这些可溶性分子发生[[共聚合|（共）聚合]]，形成[[聚合物网络|不溶性交联聚合物网络]]。在所有已提出的反应中，以[[环氧氯丙烷]]为[[交联剂]]进行[[交联反应|化学交联]]是最直接的方法。该反应简单且已为人熟知，但仍持续受到科学界的关注。

文献综述表明，[[水不溶性]][[环糊精–环氧氯丙烷聚合物]]（[[环糊精-环氧氯丙烷聚合物|ECP]]）可在以[[吸附]]为主的[[废水处理]]工艺中用作[[吸附剂]]。自 2000 年代以来，围绕这一主题发表的论文日益增多。ECP 材料对包括芳香族化合物和金属在内的多种[[污染物]]表现出较高的[[吸附容量]]，相关研究主要在水溶液中开展。近期研究表明，ECP 材料对含有复杂污染物混合物的[[工业废水]]也具有良好的处理效果。目前必须开展中试规模实验，以考察工业上采用 [[环糊精|CD]] 处理多污染物[[废水]]的可行性。

尽管针对 [[环糊精-环氧氯丙烷聚合物|ECP]] 应用已开展了大量工作，未来研究仍需探究[[交联密度]]的确切作用及[[吸附]]机制。迄今为止，与其他常规材料开展的系统性比较研究仍然很少，而且仅在最近才出现。由于材料和方法存在差异，数据之间的直接比较也很困难。新材料研究往往侧重于其技术性能，而经济因素通常被忽视。用于[[废水处理]]的 [[环糊精–环氧氯丙烷聚合物|ECP]] 基本上仍处于实验室规模研究阶段，要证明其在工业规模上的应用潜力，仍需开展大量工作。
