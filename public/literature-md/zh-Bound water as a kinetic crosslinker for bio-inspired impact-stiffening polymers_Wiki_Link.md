## 摘要

开发可广泛应用于多种化学体系的高性能[[冲击硬化聚合物]]，仍然是一项关键挑战，因为现有设计依赖于精心设计的分子基元。受水在生物抗冲击性中作用的启发，我们提出了一种可推广的仿生范式。通过将[[结合水]]网络结构性地限制在富含质子的聚合物骨架中，我们将通常被视为降低性能的[[增塑剂]]——水，转变为一种主动的、[[速率敏感性|速率敏感的]]的[[交联]]剂。通过对其解离动力学进行编程，材料能够在冲击下借助[[动力学冻结]]实现急剧且可逆的[[软-刚性转变]]。该设计在基于[[聚硫辛酸]]的体系中得到验证，同时实现了优异的[[能量耗散]]、[[自修复]]和[[强粘附]]性能。尤为重要的是，它避免了从头合成专用分子基元，并适用于多种聚合物主链，从而确立了可编程水动力学作为适应性聚合物材料的通用设计原理。

## 引言

对模仿自然界智能冲击防护<sup>[1-3]</sup>——以[[蜘蛛丝]]、[[软骨]]或[[珍珠层]]为代表——的合成材料的追求，仍然是材料科学中的核心挑战。<sup>[4-8]</sup> 一条有前景的路径是设计在准静态加载下柔软但在高速冲击下迅速硬化的聚合物。<sup>[9-21]</sup> 迄今为止，这类性能主要通过引入特定的[[动态基元]]（例如[[氢键阵列]]<sup>[10-13]</sup>、[[金属-配体配位]]<sup>[14-16]</sup>或[[离子簇]]<sup>[18-20]</sup>）来实现，它们在高应变率下特定的键合动力学导致力学硬化。然而，这种策略将材料设计锁定在特定化学体系上，限制了其普适性。一种更具通用性的范式将把硬化行为与化学身份解耦，通过一个通用动态网络的可编程解离动力学来产生硬化，从而确保跨体系适用性。核心挑战在于建立一种通用且可规模化的合成方法，能够可靠地编码这种目标动力学响应。

这种范式转变的灵感来自自然界最丰富且最简单的构筑单元：[[结合水]]。在生物大分子中，结合水远非被动的溶剂；它是一个不可或缺的结构与动力学组分，在蛋白质、组织和生物聚合物内部形成广泛的[[氢键网络]]。这些网络对机械完整性、韧性和冲击[[能量耗散]]具有关键贡献。<sup>[22-33]</sup> 例如，有序的结合水网络充当内部动态支架，增强组装完整性，<sup>[30-32]</sup> 而界面水合所产生的显著熵贡献则构成对抗有害构象变化的热力学屏障<sup>[28-31]</sup>。这种从热力学稳定到结构强化的多尺度调控，正是[[软骨]]和[[丝蛋白]]等生物材料具有卓越抗冲击性能的基础。<sup>[34-37]</sup> 这种功能角色与高分子科学中的主流观点形成鲜明对比，后者通常将水视为使材料软化或损害其长期稳定性的[[增塑剂]]。尽管一些创新性研究已经开始将水作为结构性参与者加以利用（例如作为[[共聚单体]]<sup>[38-40]</sup>或[[水锁单元]]<sup>[41]</sup>），但通过合成手段编程此类结合水网络的解离动力学、使其成为抗冲击性能的主要动力学组分，这一潜力几乎仍未被探索。利用这一机制可能无需复杂的分子设计即可实现急剧的、速率依赖的力学转变，从而为下一代自适应聚合物建立一种通用且仿生的设计原则。

我们在此提出一种具有变革性和普适性的策略：不再回避水，也不为每一种新应用设计愈发复杂的合成基元，而是直接利用水自身形成[[动态氢键网络]]的本征能力，将其作为一种通用的、可编程的抗冲击增刚元件。我们证明，通过将[[结合水]]的网络结构约束在富含质子的聚合物骨架中，结合水本身可以被转化为一种主动的、[[速率敏感性|速率敏感的]]物理[[交联]]点（图1）。其受工程调控的解离动力学在冲击作用下触发快速且可逆的[[动力学冻结]]转变，从而实现数个数量级的刚度提升和优异的[[能量耗散]]。基于[[聚硫辛酸]]体系，我们同时实现了强黏附、快速[[自修复]]和完全可回收性——且无需合成专门化的超分子基元。关键在于，我们通过将该方法拓展至其他酸性聚合物，验证了其普适性，从而确立了结合水的可编程动力学作为一种基础性且不受材料种类限制的设计平台。这项工作不仅为高性能抗冲击增刚材料提供了一条通用路径，也推进了这样一种范式：瞬态水网络支配宏观力学适应性，并对仿生功能聚合物具有广泛意义。

## 结果

## [[结合水]]赋能的[[冲击硬化聚合物|抗冲击增刚聚合物]]的设计与制备

为了实现[[结合水]]作为主动动力学物理[[交联]]点的范式，我们设计了一类模型聚合物，并实施了一项核心策略：将结合水结构性地固定在富含质子的网络中。我们选择带有酸性基团的聚合物——如[[聚硫辛酸]]、[[聚丙烯酸]]和[[聚(4-苯乙烯磺酸)]]——作为通用平台。通过[[四甲基氢氧化铵五水合物]]（TMAH·5H2O）引入结构性结合水（即在聚合物网络中被拓扑约束并以[[氢键]]结合的水分子），这一过程同时使酸性基团去质子化以建立[[离子交联]]，并将这一具有动态活性的水组分输送到网络中。

[[聚硫辛酸]]（polyTA）<sup>[42-44]</sup> 被选为主要模型体系。[[单宁酸|TA]] 与 $T M A H . 5 H _ { 2 } O$ 在 $12 0 ^ { \circ } \mathsf { C }$ 条件下的一锅反应生成了目标材料 poly[TA-TMAH]，其中来自 $T M A H . 5 H _ { 2 } O$ 的结构[[结合水]]的引入、广泛[[氢键网络]]（涉及水、[[羧酸根]]和[[铵离子]]）的建立，以及通过羧酸根–TMA⁺ 离子对形成[[离子交联]]同时完成（图 1 和补充图 1）。优化的 TMAH 投料比（40 mol%）制得了高弹性材料（图 2a、d 和补充图 2），并用于所有后续研究。所得网络表现出良好的热稳定性 $( > 2 0 0 \ ^ { \circ } \mathrm { C }$ 、补充图 3、4）和低温柔韧性，[[玻璃化转变温度]] $( T _ { 9 } )$ 为 $- 2 7 . 9 5 ^ { \circ } \mathrm { C }$ （补充图 5）。

## 卓越的冲击增刚与[[能量耗散]]性能

初步观察表明，poly[TA-TMAH] 在快速冲击下发生了显著的软–刚转变（图 2 和补充视频 1）。拉伸测试显示，当拉伸速率从 50 mm/min 提高到 500 mm/min 时，杨氏模量从 0.401 MPa 飙升至 4.032 MPa（图 2b、e）。压缩测试显示，当应变速率从 0.2 mm/min 提高到 50 mm/min 时，压缩模量提升超过 3500%，能量耗散从 0.095 增加到 1.794 $M J / \mathsf { m } ^ { 3 }$ （图 2c、f）。而纯 polyTA 在拉伸或压缩测试中均未表现出任何明显的应变速率诱导增刚响应（补充图 6），这表明 poly[TA-TMAH] 的冲击增刚行为不依赖于 polyTA 内的动态二硫键和氢键。相反，poly[TA-TMAH] 网络内结构固定化结合水的引入很可能是在高冲击下观察到的软–刚转变的原因。此外，poly[TA-TMAH] 的冲击增刚性能在反复加载下仍保持稳健。通过使材料经历 10 次连续压缩循环来评价其可重复使用性。10 次循环后的应力衰减率仅为 15%（补充图 7），表明其具有优异的循环稳定性和可重复使用性，适用于长期防护应用。

流变频率扫描显示，储能模量（G′）在 0.1 到 100 Hz 范围内提高了 50 倍以上，并在 21.5 Hz 处越过损耗模量（G″），证实了其剪切增刚特性（图 2g）。时间–温度叠加给出了特征弛豫时间 ${ \bar { \mathsf { I } } } _ { 0 } ,$ ，约为 46 ms（图 2h、i），定义了黏性流动（加载慢于 ${ \sf { T } } _ { 0 } )$ ）与弹性网络“冻结”（加载快于 ${ \sf T } _ { 0 } )$ ）之间的动力学边界。循环频率扫描证明该响应完全可逆（补充图 8），凸显了网络的稳健性。分离式霍普金森压杆（SHPB）测试进一步证实了 poly[TA-TMAH] 在真实冲击条件下的冲击性能。该材料在 3238 $\mathsf { S } ^ { - 1 }$ 下实现了 557 MPa 的模量，能量吸收高达 4.9 ${ \sf M J / m } ^ { 3 }$ ，其模量比准静态条件下高出三个数量级（图 2j–m）。这些结果明确证明了 poly[TA-TMAH] 在真实冲击速率下具有数量级的模量提升，证实了其卓越的宽时间尺度能量耗散能力。

## [[结合水]]的关键作用与动态机制

是什么分子尺度的因素驱动了这种显著的速率敏感性？我们假设，由TMAH·5H2O引入的结合水所形成的动态网络是关键。首先，我们利用光谱技术寻找结合水存在的直接证据。poly[TA-TMAH]的衰减全反射傅里叶变换红外（ATR-FT-IR）光谱在3386 cm⁻¹处显示出一个宽的O–H伸缩振动带，与纯TMAH·5H2O中结合水<sup>[45]</sup>的强氢键峰（3263 cm⁻¹）相似，表明水已成功纳入强氢键网络（图3c）。低场核磁共振弛豫分析对水状态进行了定量：材料中96.81%的水处于强结合态（弛豫时间0.1–1.0 ms），几乎未检测到自由水（图3d、e）。

然而，仅凭静态结合无法解释速率敏感性。这些水分子的动态行为至关重要。poly[TA-TMAH] 在 DMSO-d6 中的 <sup>1</sup>H NMR 谱图显示，结合水质子在 7.85 ppm 处出现一个明显的宽峰（图 3b-3）。加入自由水后，该峰消失，并在 4.27 ppm 处被一个尖锐的单峰取代（图 3b-4）。这是因为所加入的 $w a t e r ,$ 显著加速了所有可交换质子（包括结合水）之间的化学交换，使信号平均至自由水的化学位移。相比之下，$T M A H . 5 H _ { 2 } O$ 与 TA 单体的简单混合物在 4.88 ppm 处显示出相对尖锐的峰，表明在约束较少的小分子体系中质子交换更快（图 3b-5）。这些结果不仅证实了结合水的存在，还证实了其在聚合物网络内受限的运动性以及可交换的动态特征。此外，离子键的形成通过 <sup>1</sup>H NMR 和 FTIR 均得到确认。<sup>1</sup>H NMR 显示羧基相邻质子持续向高场移动， polyTA 与甲基质子 $T M A H . 5 H _ { 2 } O$ （图3a、b），与特征一致 $- \mathsf { C O O ^ { - } }$ 峰位于 $1 5 5 5 ~ { \mathsf { c m } } ^ { - 1 }$ 在 FTIR 光谱中（图 3c）。

为了在固态网络中直接探测结合水的分子尺度运动并将其与宏观性质联系起来，我们采用了宽频介电谱（BDS）。聚[TA‑TMAH]的直流电导率在附近没有表现出不连续变化 $0 ~ ^ { \circ } \mathsf C$ （图4b），证实了不存在可冻结的自由水，并与水分子的结合态一致。更重要的是，在中频范围内出现了一个明显的介电弛豫峰 $( \log { \mathfrak { f } } \approx 3 { - } 4 )$ 在聚[TA-TMAH]中观察到结合水的释放 $- 1 0 0 ^ { \circ } \mathsf C ,$ 而在干燥样品（poly[TA-TMAH-Dry]）中该峰完全不存在（图4c），证实该峰源于与聚合物骨架强结合的结合水取向极化。<sup>[46]</sup> 值得注意的是，在相应聚合物制备过程中加入游离水后，该弛豫峰的形态和位置发生系统性演化。引入4 wt%游离水 $( p o l y [ T A - T M A H - H _ { 2 } O 4 \% ] )$ 导致显著的峰展宽并向较低频率移动，表明异质性增加和更 受限于聚合物链结构重排所导致的水分子运动。在12 wt%自由水条件下 $\left( | | \mathbf { o } | | \mathbf { y } [ \mathsf { T A - T M A H - H _ { 2 } O _ { 1 2 } } \mathsf { _ { / / } } ] \right)$，主峰进一步向更低频率移动（log f ≈ 1–2）并再次变窄，但呈现出不对称轮廓，在原始峰位附近残留一个肩峰（图4c）。这一模式强烈暗示动力学微相分离：部分结合水被锁定在致密化、富含聚合物的畴区内，其运动高度受限且更为均一（尖锐的低频峰），而另一部分则位于约束较弱的富水区域（原始频率附近的肩峰）$( \mathsf { F i g . 4 a } ) ^ { [ 4 7 - 4 8 ] }$。这种动力学异质性的增长破坏了氢键网络的协同响应，并与宏观上冲击增刚效应的衰减直接相关（见下文，图4f）。因此，poly[TA-TMAH]冲击增刚的关键并不在于局部水分子重新取向的绝对速度，而在于结合水介导网络整体的均一、可切换动力学。

在宽温度范围内（–100 至 60 °C，图 4d）进行的 [[宽频介电谱|BDS]] 分析进一步阐明了[[结合水]]的动态行为。随着温度升高，给定频率下的介电损耗增大，表明链运动性增强、离子迁移加剧以及结合水的取向极化被激活。值得注意的是，低频与高频下电导率的频率依赖性存在显著差异。这表明在低温下，电导率主要受限于局域质子跳跃和受约束结合水网络中的偶极弛豫；而在较高温度下，长程离子迁移成为主要的导电机制。此外，通过追踪结合水弛豫峰（补充图 9），确定结合水重新取向的[[弛豫活化能]]为 78.67 kJ/mol，远高于水中[[氢键]]重排的典型值（10–20 kJ/mol）<sup>[49-50]</sup>。这一高能垒明确证实了结合水与聚合物网络之间的强耦合，说明水的重新取向需要协同破坏多个强氢键或克服聚合物链段施加的约束。

这些观察结果进一步表明，[[结合水]]并非仅仅是被动组分，而是与聚合物形成了强耦合、动态响应的网络。在高应变速率变形下，这种紧密结合的网络无法迅速重排，导致[[动力学冻结]]和瞬时硬化——这是宏观[[冲击硬化]]行为的直接微观来源。因此，跨温度的介电响应不仅反映了结合水的状态，还与材料在冲击下耗散能量和硬化的能力直接相关。

除了上述光谱和介电证据外，对照实验进一步证实了结合水的关键作用。由于从 TMAH·5H2O 中完全去除结合水较为困难，因此使用四乙基氢氧化铵（TEAH）这一不含结合水的类似化合物来制备 poly[TA-TEAH]，以建立无结合水对照。该材料含有离子键（补充图 10、11），但未表现出冲击增稠行为（补充图 12–14），证明仅靠离子键不足以产生速率敏感性；由结合水形成的动态氢键网络不可或缺。此外，通过控制聚合时间，制备了具有不同残余结合水含量（0.3 至 4.2 wt%）的 poly[TA-TMAH] 样品（图 4e 和补充图 15）。冲击增稠性能呈火山型趋势，在约 2 wt% 的最佳含量处达到峰值，表明存在最佳动态交联密度，可在速率敏感性与网络完整性之间取得平衡。

通过考察制备过程中加入自由水的 $\mathsf { p o l y } [ \mathsf { T A - T M A H - H } _ { 2 } \mathsf { O } _ { \mathsf { x } ^ { \circ } / \mathsf { o } } ]$ 的冲击增稠性能，进一步凸显了结合水的重要性（x 表示所加自由水的重量百分比）。这些材料的冲击增稠性能逐渐且严重减弱，在 poly[TA-TMAH-H2O12%] 中加入 12% 时几乎消失（图 4a、f 和补充图 16）。红外光谱、低场核磁共振和热分析进一步揭示了加入自由水后水的不同状态。在 $3 3 9 6 ~ \mathsf { c m } ^ { - 1 }$ 处，O–H 伸缩振动移至更高波数，表明氢键作用更弱（图 4g）。同时，如低场核磁共振所示，强结合水比例从 96.8% 降至 87.1%（图 3d、e）。TGA 显示，$\mathsf { p o l y } [ \mathsf { T A - T M A H - H } _ { 2 } \mathsf { O } _ { 1 2 } \circ _ { 2 } ]$ 中的水在约 $4 0 \ ^ { \circ } \mathsf { C } ,$ 处开始蒸发，这是自由水的特征；而 poly[TA-TMAH] 中的结合水直到超过 $12 4 ^ { \circ } \mathsf { C }$ 才出现明显质量损失（图 4i、j）。相应地，前者的玻璃化转变温度 $( T _ { 9 } =$ –52.11 °C）显著低于后者 $( T _ { 9 } = - 2 7 . 9 5 ^ { \circ } \mathsf { C } )$ ，证实了自由水对聚合物链的增塑作用（图 4h）。

由结合水形成的强动态氢键网络及其在 poly[TA-TMAH] 力学性能中的关键作用，进一步通过不同应变幅值下的系统循环拉伸加载-卸载测试以及固定应变下的速率相关循环测试得到证实，并对滞后回线面积进行了详细分析（补充图 17）。在 100 mm/min 的低拉伸速率下，滞后面积随应变幅值的增加近似线性增大，从 $0 . 0 5 1 ~ \mathrm { M J } / \mathrm { m } ^ { 3 }$ 上升至 $0 . 5 0 4 ~ \mathrm { M J } / \mathrm { m } ^ { 3 } - \mathrm { a }$，接近十倍增强（补充图 17a、b）。在此区间内，结合水介导的氢键网络有足够时间进行可逆重组，表现出动态、可逆且近似线性的能量耗散，其行为以黏性耗散为主，而非冲击硬化。在固定应变条件（200% 应变）下，当拉伸速率从 100 mm/min 增加到 500 mm/min 时，滞后面积呈非线性增大，从 $0 . 5 0 4 ~ \mathrm { M J } / \mathrm { m } ^ { 3 }$ 上升至 $2 . 2 1 4 ~ \mathsf { M J } / \mathsf { m } ^ { 3 }$（补充图 17c、d）。具体而言，在低拉伸速率（100–200 mm/min）下，滞后面积仅适度增加，表明氢键网络内开始出现延迟解离。当拉伸速率达到 300 mm/min 时，材料表现出向冲击硬化状态的明显转变，并伴随滞后面积的显著跃升。这一结果揭示，在较高变形速率下，结合水氢键网络发生动力学冻结和集中解离，重组动力学显著慢于加载速率，从而导致能量耗散大幅增强。这种速率相关的放大效应表明，能量耗散主要由动态键解离控制，而非简单的黏性流动。综合来看，这些结果强调了动态结合水介导的氢键网络的存在，及其对材料速率相关力学响应的重要贡献。

综合上述多模态认识，可以得出一个统一的机理模型：在 poly[TA-TMAH] 中，结合水与聚合物羧酸根、铵离子以及其他水分子形成遍布材料的强而动态的氢键交联网络。在低应变速率加载下，这些键有足够时间发生可逆断裂与重新形成，使材料呈现柔软且黏弹性的特性，并通过黏性流动耗散能量。在高速冲击下，加载速率远超过氢键网络的特征弛豫时间。动力学较慢的动态键无法足够迅速地解离，导致整个网络发生瞬时动力学冻结，链段被刚性锁定，宏观上表现为模量急剧增加和显著硬化。冲击能量在较长的应力平台期内被有效延迟并耗散，从而显著降低峰值应力。自由水的加入会破坏这种均一、协同的动态网络，其方式是诱导微相分离，使部分结合水被固定，同时增塑聚合物基体，从而削弱材料的冲击硬化响应。

## 实际冲击防护性能与多功能性

Poly[TA-TMAH]表现出优异的实际冲击防护能力。1 mm厚的涂层可将从80 cm高度落下的16 g、32 g和50 g钢球的峰值冲击力分别降低60%、55%和50%，优于聚二甲基硅氧烷（PDMS）和聚硼硅氧烷（PBS）等传统柔性防护材料（图5b、c）。Poly[TA-TMAH]的抗冲击性能达到648.24 J/m，远高于PDMS、PBS和poly[TA-TMAH-H2O12%]（图5d）。此外，它能有效保护多种易碎物体（陶瓷、智能手机、苹果）免受损伤（图5a及补充影片2–4）。而且，poly[TA-TMAH]在热压再加工或损伤自主修复后仍保持冲击防护性能（图5f），为其长期和循环应用奠定了坚实基础。

除卓越的抗冲击性能外，poly[TA-TMAH]还因其丰富的动态化学作用（二硫键、氢键、离子键）而具备一系列附加功能。首先，这些动态键赋予其优异的自修复能力；切断的片段在室温下仅接触10 min后，即可恢复高达90%的原始强度（图5e及补充图18、19）。此外，修复后样品中应变速率相关的力学性能可完全恢复（补充图20）。修复后样品表现出与原始样品相当的性能，压缩模量从0.2 mm/min时的0.08 MPa上升至100 mm/min时的1.93 MPa。在修复材料的拉伸测试中也观察到类似的由软到刚转变。其次，这些动态相互作用使其对玻璃、钢和PMMA等多种基材具有强黏附性，且黏附强度也表现出显著的速率依赖性（图5g）。第三，该材料可通过简单热压完全再加工，并且polyTA主链可在温和碱性条件下水解，从而高效回收TA单体（约90%，补充图21）。最后，继承polyTA主链和TMAH·5H2O季铵基团固有的抗菌特性，该材料对大肠杆菌、金黄色葡萄球菌和耐甲氧西林金黄色葡萄球菌（MRSA）表现出优异的广谱抗菌活性（补充图22）。此外，poly[TA-TMAH]在环境条件下用保鲜膜存放一年后仍表现出长期稳定性。对存放一年并在CDCl3中浸泡30 min的样品，其<sup>1</sup>H NMR谱图中未观察到力学性能的显著退化，也未发现TA单体信号（补充图23）。鉴于其兼具高速率刚度、缓慢变形下的柔韧性以及多种功能，poly[TA‑TMAH]在柔性防护涂层、吸能运动装备、可穿戴防护乃至生物医学冲击缓解装置等应用中具有广阔前景。

## [[结合水]]致[[冲击硬化聚合物]]的普适性

在阐明机理之后，我们进一步评估了结合水交联平台在 polyTA 骨架之外的普适性。为此，我们将该方法扩展到两种结构不同的聚合物：聚丙烯酸（polyAA）和聚（4-苯乙烯磺酸）（polySA）。所得材料 poly[AA-TMAH] 和 poly[SA-TMAH] 均表现出显著的剪切硬化行为（图 6b、d）。流变学频率扫描显示，两种材料的储能模量（G′）在 0.1 至 100 Hz 范围内显著增加，并分别在 15.8 Hz 和 3.98 Hz 处越过各自的损耗模量（G″），与其原始聚合物对应物的速率不敏感行为形成鲜明对比。重要的是，这种结合水实现的动态响应同样可以通过添加自由水来削弱（补充图 24），遵循与 poly[TA-TMAH] 体系中观察到的相同趋势。该策略成功扩展到 polyAA 和 polySA，证实了可编程结合水网络是一种具有普适性的设计原则，在很大程度上不依赖于特定的聚合物骨架。这凸显了我们的方法在从多种富质子聚合物开发冲击硬化材料方面的广泛适用性。

## 讨论

在本研究中，我们展示了一种通过利用[[结合水]]网络动力学来工程化[[冲击硬化聚合物]]的普适性策略。该方法将结合水从被动组分转变为主动的动力学设计元素，从而能够按需定制冲击响应。成功扩展到不同聚合物骨架证实了其普适性，并强调了一条与材料无关的设计规则。除冲击防护之外，本研究还将结合水动力学确立为一种强大的分子级设计原则，其中瞬态的、水介导的相互作用支配着宏观功能响应。未来对这一网络动力学范式的探索可能解锁更广泛的动态材料类别，从而加深我们对水介导力学的基本理解，并加速先进仿生材料的开发。

## 方法

## [[聚硫辛酸|polyTA]] 的制备

[[单宁酸|TA]]粉体在$12 0 ~ ^ { \circ } \mathrm { C }$加热20 min以形成均匀混合物。随后将混合物倒入模具中，并冷却至室温，得到[[聚硫辛酸|polyTA]]。值得注意的是，对于polyTA的压缩测试，制备过程中加入了微量$C H _ { 2 } C l _ { 2 }$以减缓其[[解聚]]。

## poly[TA-TMAH]和poly[TA-TEAH]的制备

将[[单宁酸|TA]]与不同摩尔比的[[四甲基氢氧化铵五水合物]]（TMAH·5H2O）在$12 0 ~ ^ { \circ } \mathrm { C }$搅拌20 min，得到均匀混合物。所得混合物倒入模具中，并冷却至室温，得到最终产物poly[TA-TMAH]。poly[TA-[[四乙基氢氧化铵|TEAH]]]的制备过程与poly[TA-TMAH]相同。在poly[TA-TEAH]中，使用四乙基氢氧化铵（25%水溶液）（TEAH）代替四甲基氢氧化铵五水合物。

## poly[TA-TMAH-H2Ox%]的制备

将[[单宁酸|TA]]与不同摩尔比的[[四甲基氢氧化铵五水合物]]$( T M A H . 5 H _ { 2 } O )$以及额外加入的水（分别相当于总混合物质量的4、6、8和12 wt%）在$12 0 ~ ^ { \circ } \mathrm { C }$搅拌20 min，直至获得均匀混合物。随后将混合物倒入模具中冷却至室温，得到poly[T$\mathsf { A } { - } \mathsf { T M A H } { - } \mathsf { H } _ { 2 } \mathsf { O } _ { \mathsf { X } \% } ]$（其中x表示制备过程中所加水的质量相对于所用总质量的百分比）。

## 残余[[结合水]]含量的计算

在加热前先称量[[单宁酸|TA]]与四甲基氢氧化铵（[[四甲基氢氧化铵五水合物|TMAH·5H2O]]）的总质量（m0）。在不同加热时长后，再次测量样品的剩余质量（m1）。TMAH·5H2O中初始存在水的理论质量$( m _ { \mathrm { { w a t e r } } } )$根据TMAH·5H2O的化学计量关系计算（每摩尔TMAH含5摩尔H2O）。加热过程中损失的水质量假定为$m { \boldsymbol { 0 } } - m { \boldsymbol { 1 } }$（所有质量损失均归因于水分蒸发）。随后按下式计算残余[[结合水]]含量（wt%）：$[ m _ { \mathrm { w a t e r } } - ( m _ { 0 } - m _ { 1 } ) ] / \ m _ { 1 } \times 1 0 0 \%$。该计算假定在$( 1 2 0 ^ { \circ } \mathsf { C } )$的温和加热条件下，TA或TMAH分解不会造成显著质量损失，这一点已由[[TGA]]结果证实。

## [[宽频介电谱]]（BDS）

制备了直径20 mm、厚度0.3 mm的圆片状poly[TA-TMAH]、poly[TA-TMAH-Dry]、poly[$\Gamma A - T M A H - H _ { 2 } O _ { 4 \% } ]$和poly$\mathbf { T A - T M A H - H _ { 2 } O } _ { 1 2 \% }]$样品。样品两面均通过溅射涂覆导电电极。随后使用Novocontrol Technologies CONCEPT 40谱仪进行介电测量。一组测量在1至$1 0 ^ { 6 }$ Hz频率范围内进行，同时从$- 1 1 0 ^ { \circ } \mathsf C$至$- 6 0 ~ ^ { \circ } \mathsf { C }$扫描温度；另施加一种测量模式，固定频率为1 Hz，同时从$- 6 0 ~ ^ { \circ } \mathsf { C }$至$60 \%$扫描温度。
