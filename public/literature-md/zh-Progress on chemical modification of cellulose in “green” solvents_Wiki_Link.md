# [[纤维素]]在“绿色”溶剂中[[化学改性]]的进展

葛文娇，帅建波，王玉源，周宇熙，王晓慧*

[[纤维素]]因其良好的可获得性、[[可再生性]]、生物可降解性和生物相容性，是制备可持续材料的优异候选者。[[化学改性]]是拓宽纤维素利用范围的一种有吸引力的途径。然而，纤维素在水和常见有机溶剂中的低溶解性，使纤维素的化学改性被限制在非均相条件下或少数特定的体系中。近年来，在更高效、更绿色的纤维素溶剂方面取得了进展。其中一些溶剂极大改变了纤维素的化学改性，并有望对未来的纤维素工业产生影响。本综述介绍了用于溶解纤维素的新型“绿色”溶剂，包括[[离子液体]]（ILs）、[[低共熔溶剂]]（DESs）、碱/[[尿素]]水溶液和[[季铵氢氧化物]]（QOHs）水溶液。重点介绍并讨论了在这些溶剂中纤维素化学改性的最新进展，尤其是过去五年间取得的进展。

## 1. 引言

[[纤维素]]作为最丰富的生物基聚合物，广泛分布于多种天然来源中，包括植物、被囊动物和微生物。<sup>1–3</sup> 在结构上，纤维素是一种规整的线性聚合物，由通过β-1,4-糖苷键连接的D-葡萄糖亚基组成，并具有强分子间和分子内[[氢键]]（图1）。<sup>4,5</sup> 每条纤维素链都有一个表现为醛形式的还原端和一个带有仲羟基的非还原端。<sup>6</sup> 凭借[[可再生性]]、生物可降解性、生物相容性、无毒、低成本、热稳定性和化学稳定性等众多优点，<sup>7,8</sup> 纤维素被认为是生产材料、化学品和生物燃料的理想原料。<sup>9</sup> 遗憾的是，由于纤维素广泛的氢键作用和高结晶度，它几乎不溶于常见有机溶剂和水。此外，纤维素的熔点高于其降解温度。<sup>10</sup> 这两个特性严重阻碍了纤维素的利用和加工。

[[化学改性]]是改善[[纤维素]]溶解性和加工性的一种途径。<sup>8</sup> 它提供了一种在不破坏纤维素众多固有特性的前提下赋予其新性能的方法。<sup>11</sup> 在工业上，纤维素衍生物[例如，[[醋酸纤维素]]（CA）、[[羧甲基纤维素]]（CMC）、[[甲基纤维素]]（MC）、[[硝酸纤维素]]]的合成仍采用非均相反应路线。<sup>12,13</sup> 该非均相路线涉及在不良溶剂介质中直接改性纤维素，使纤维素不溶解或不完全溶解。反应过程通常仅限于纤维素表面且难以控制，并伴随不希望发生的副反应、纤维素降解、[[取代度]]（DS）有限以及大量废弃物。<sup>14</sup> 相反，均相路线有助于实现可控性更好且转化率更高的反应。<sup>8</sup> 在均相介质中，纤维素分子被认为其所有羟基对化学试剂具有完全且同等的可及性。然而，纤维素的高效溶解是进行均相反应的前提。因此，纤维素溶剂的开发既是纤维素研究领域的迫切需求，也是一项长期目标。

为此，人们进行了大量尝试，以寻找适用于[[纤维素]]溶解和改性的溶剂体系。传统的纤维素溶解溶剂包括若干类衍生化溶剂（如CS₂/NaOH）和非衍生化溶剂[如[[N-甲基吗啉-N-氧化物]]（NMMO）、N,N-二甲基乙酰胺/氯化锂（[[N,N-二甲基乙酰胺|DMAc]]/[[氯化锂|LiCl]]）、四丁基氟化铵三水合物/[[二甲基亚砜|DMSO]]（TBAF/DMSO）]。然而，这些溶剂伴随显著缺点，包括操作过程繁琐、能耗高、环境问题以及可回收性差。<sup>15,16</sup> 可持续发展推动了针对纤维素溶解更高效、更绿色替代品的研究。<sup>17</sup> 近年来，用于纤维素溶解的新型非衍生化溶剂体系已被开发出来，其可细分为两类：非水溶剂[即[[离子液体]]（ILs）、[[低共熔溶剂]]（DESs）]和水性溶剂[即碱/[[尿素]]、[[季鎓氢氧化物]]（[[季铵氢氧化物|QOHs]]）]。这些溶剂可作为纤维素衍生化的理想介质，并为构筑功能性纤维素材料提供多功能平台。本综述的主要目标是聚焦这些新型绿色溶剂在纤维素[[化学改性]]方面的最新进展。文中还将对绿色溶剂中纤维素改性的当前研究进行评述，并对未来方向给出展望。

## 2. [[纤维素]]溶解用绿色溶剂概述

[[纤维素]]含有丰富的羟基，容易形成广泛的分子间和分子内[[氢键]]。纤维素这种氢键结合的超分子结构使其难以在水溶液或常规有机溶剂中溶解。为解决这一问题，人们开发了众多纤维素溶剂体系，并将其分为衍生化溶剂和非衍生化溶剂。衍生化溶剂的溶解过程涉及衍生化纤维素中间体的形成及随后的溶解。<sup>18</sup> 衍生化溶剂的一个典型例子是 CS/NaOH 体系，该体系已在工业规模上用于生产[[粘胶纤维]]。然而，粘胶工艺伴随着大量有害副产物（如 CS、H S、重金属）的排放。<sup>19</sup> 非衍生化溶剂（如 [[N-甲基吗啉-N-氧化物|NMMO]]）可在不发生任何衍生化的情况下直接溶解纤维素。一般而言，非衍生化溶剂比衍生化溶剂更环保，因为涉及的化学反应副产物更少。<sup>20</sup> 其他将有机溶剂与盐结合的溶剂，如 [[N,N-二甲基乙酰胺|DMAc]]/[[氯化锂|LiCl]]、TBAF/[[二甲基亚砜|DMSO]]，也已得到较好发展，但存在高毒性和高挥发性等环境问题。<sup>10</sup>

溶剂在[[纤维素]]工业中至关重要。如上所述，一些常规纤维素溶剂存在若干健康和环境风险。因此，学术界持续努力，旨在以更绿色的溶剂替代它们。根据[[绿色化学]]原理，绿色溶剂应具有低废物产生、较少有害化学合成、高安全性和较小环境影响的特点。溶剂的可持续性还应与可回收性、可获得性、稳定性、可燃性、效率和成本相关。基于这些考虑，我们在这篇小型综述中主要介绍四类用于纤维素的“绿色”非衍生化溶剂，并将其细分为两类，即非水溶剂（即[[离子液体]]、[[低共熔溶剂]]）和水性溶剂（即碱/[[尿素]]、[[季铵氢氧化物]]）。

## 2.1. 用于[[纤维素]]的非水非衍生化溶剂

2.1.1. [[离子液体]]。离子液体通常被定义为熔点低于 100 $^ { \mathrm { { \circ } } } \mathrm { { C } } . ^ { 2 1 }$ 的有机熔融盐。它们一般由一个相对较大的有机阳离子（如[[咪唑鎓]]、[[吡啶鎓]]、吗啉鎓、铵、鏻和超强碱）与一个较小的无机阴离子 $( e . g . , \ \mathrm { C l ^ { - } } , \ \mathrm { B r ^ { - } }$ 以及 I<sup>−</sup>）或有机阴离子（[[六氟磷酸根]] [PF ]<sup>−</sup>、[[四氟硼酸根]] $\mathrm { [ B F _ { 4 } ] ^ { - } }$ 和羧酸根 $[ \mathrm { R C O O } ] ^ { - } ) . ^ { 2 2 - 2 5 }$ 配对组成。离子液体表现出许多有吸引力的性质，包括可忽略不计的蒸气压、良好的热稳定性和化学稳定性、不可燃性、高离子[[电导率]]、结构可调性以及显著的可回收性。<sup>26</sup> 离子液体的物理化学性质可以通过调整阳离子和阴离子的结构与排列方式来改变。<sup>27</sup> 关于[[纤维素]]在含 1-丁基-3-甲基咪唑鎓阳离子（[BMIM]<sup>+</sup>）与一系列小或大阴离子配对的咪唑基离子液体中溶解的第一篇报道由 [[Rogers]] 等人发表 $a l . ^ { 2 8 }$ 这项研究显著推动了离子液体在纤维素溶解领域的发展。<sup>29</sup> 迄今为止，已经开发出多种基于咪唑鎓、季鎓、[[吡啶]]鎓和超强碱的离子液体。<sup>30–32</sup> 通常，具有不同阳离子的离子液体的溶解能力遵循以下顺序：咪唑基离子液体 > 吡啶基离子液体 > [[铵基离子液体]]。<sup>33</sup> 由 Cl<sup>−</sup>、[OAc]<sup>−</sup>、[HCOO]<sup>−</sup> 或 $[ ( \mathrm { E t O } ) _ { 2 } \mathrm { P O } _ { 2 } ] ^ { - }$ 阴离子组成的离子液体比含有非配位阴离子（如 [PF ]<sup>−</sup> 或 [BF ]<sup>−</sup>）的离子液体是更有效的纤维素溶解溶剂。

最近，研究揭示两种单一[[离子液体]]的组合可表现出对[[纤维素]]更好的溶解能力。一种 [EMIM][Cl] 与 [EMIM][OAc] 以 30 : 70 mol/mol 混合的体系被开发出来，其溶解度（每 100 g 溶剂 40 g）与 [EMIM][Cl]、[EMIM][OAc] 和 [BMIM][Cl] 等单一离子液体相当。<sup>34</sup> 此外，研究表明，向离子液体中加入某些高偶极非质子[[共溶剂]]（如 [[二甲基亚砜|DMSO]]、[[N,N-二甲基甲酰胺|DMF]] 和 [[N,N-二甲基乙酰胺|DMAc]]）可以降低溶剂体系的黏度并促进纤维素溶解。<sup>35–41</sup> 可以预见，离子液体-共溶剂将成为未来的一个重要方向。尽管已发表大量文章和综述，但其中大多数致力于纤维素的溶解，对纤维素改性的关注仍然很少。此外，与离子液体在纤维素加工和改性中工业化相关的一些关键问题，包括对水的敏感性、回收的可行性以及高黏度，仍然需要解决。

2.1.2. 深共熔溶剂。[[低共熔溶剂|DES]] 目前正作为一类新兴的有前景的溶剂而受到关注。与由阳离子和阴离子组合而成的[[离子液体]]不同，DES 通常是由[[氢键供体]]（HBD）和[[氢键受体]]（HBA）按所需摩尔比组成的液态共熔混合物。<sup>42–44</sup> 尽管 DES 与离子液体是不同物质，但它们具有许多相似特性，包括良好的溶剂容量、低蒸气压、不可燃性、组成可调性以及良好的化学和热稳定性。<sup>45–47</sup> 与离子液体不同，DES 可以很容易地由无毒且可生物降解的组分以低成本制备。<sup>44</sup> 由于这些显著优势，DES 在[[木质纤维素]]分馏、<sup>48</sup> 溶解<sup>49</sup> 和改性<sup>50</sup> 方面引起了相当大的兴趣。在所有 DES 中，最常用的溶剂包括以[[氯化胆碱]]（ChCl）作为[[氢键]]受体，与安全且廉价的氢键供体（例如[[尿素]]、草酸、甘油）组成的混合物。<sup>49</sup> 人们发现，ChCl/间苯二酚在超声辐照（20 Hz）辅助下，于 90 °C 最多可溶解 6.10% 的[[纤维素]]。<sup>51</sup> 去年，[[Yan]] 等人设计了一种由胆碱和 L-赖氨酸盐酸盐组成的新型 DES。<sup>52</sup> 来自[[小麦秸秆]]的天然纤维素（[[聚合度|DP]] > 3000）可在 90 °C 下很好地溶解于该 DES 中，形成均匀稳定的溶液，溶解度约为 5%。<sup>52</sup> [[微晶纤维素]]（MCC）在该溶剂体系中的溶解度也可达到约 8%。[[Kuroda]] 等人于 2021 年发现，含有 5 wt% 蔗糖的[[两性离子基DES|两性离子基 DES]] 可在 120 °C 下溶解 15 wt% 的纤维素。<sup>53</sup> 这些发现激发了研究人员设计更多用于高溶解纤维素的 DES 的热情。然而，已报道的 DES 中纤维素的溶解度远低于离子液体中的溶解度。

## 2.2. [[纤维素]]的水性非衍生化溶剂

2.2.1. 水性碱/[[尿素]]体系。碱/尿素体系作为典型的[[纤维素]]水性非衍生化溶剂，因其简单、低成本、低毒性、环境友好以及易于回收而受到广泛关注。<sup>54</sup> 该溶剂体系由碱金属氢氧化物和尿素类组分组成。[[Zhang]] 等人设计并制备了多种水溶液，包括 7 wt% NaOH/12 wt% 尿素、<sup>55</sup> 4.6 wt% [[氢氧化锂|LiOH]]/15 wt% 尿素<sup>56</sup> 和 9.5 wt% NaOH/4.5 wt% [[硫脲]]。<sup>57</sup> 此类溶液经低温处理后，可在数分钟内溶解纤维素。有趣的是，溶解仅在低温下发生，这与其他溶剂体系尤为不同。通过冷却溶解纤维素的机理与纤维素大分子和溶剂组分之间快速动态自组装所驱动的纤维素—溶剂包合物的形成有关。<sup>58</sup> 该包合物在低温下相对稳定，有助于形成透明的纤维素水溶液。<sup>59</sup> 然而，这些溶剂体系对高分子量纤维素的溶解能力引起了极大关注。根据 [[Cai]] 等人的报告，<sup>60</sup> 重均分子量低于 4.12 × ${ { 1 0 } ^ { 5 } }$ 的纤维素可溶于碱/尿素体系，这应能满足大多数应用需求。

2.2.2. 季铵/季鏻氢氧化物。另一类有前景的非衍生化水性溶剂是水性 [[季铵氢氧化物|QOH]]。此类溶剂包括季铵氢氧化物 [QAHs，$e . g . ,$，四烷基氢氧化铵（TAAH），<sup>10</sup> [[四丁基氢氧化铵]]（TBAH），<sup>61</sup> [[四乙基氢氧化铵]]（TEAH），<sup>62</sup> [[四甲基氢氧化铵]]（TMAH），<sup>63</sup> [[苄基三甲基氢氧化铵]]（BTMAH）<sup>64</sup>] 和季鏻氢氧化物 [QPHs，例如[[四烷基氢氧化鏻]]（TAPH），<sup>65</sup> [[四丁基氢氧化鏻]]（TBPH）<sup>66</sup>]。与水性碱/[[尿素]]溶液相比，QOH 可在温和条件下以更高浓度溶解[[纤维素]]。2019 年，发现 TBPH 水溶液（50 wt%）可在室温下数分钟内溶解 20 wt% 纤维素。<sup>66</sup> 浓度约为 50–60 wt% 的 TBAH 水溶液可在 40 °C 下溶解纤维素，最大溶解度约为 25 wt%。<sup>67</sup> 温度在调节纤维素溶解度方面也起着关键作用。通过将温度降低至 16 $^ { \circ } \mathrm { C } ,$，可显著改善 [[微晶纤维素|MCC]] 在 40 wt% TBAH 水溶液中的溶解，证明这是一种浓度更低、更高效且更经济的溶剂。<sup>68</sup> 此外，将[[共溶剂]]（例如尿素、[[硫脲]]、[[N-甲基脲]]、冠醚、NaOH）与 QOH 结合是促进纤维素溶解、<sup>61</sup> 减少 QOH 消耗<sup>10</sup> 并提高溶剂稳定性的另一种方法。<sup>63</sup>

## 2.3. 绿色溶剂的评述与比较

[[离子液体|ILs]]、[[低共熔溶剂|DESs]]、碱/[[尿素]]和 [[季铵氢氧化物|QOH]] 是过去十年中[[纤维素]]溶解、加工和改性最常用的溶剂。与传统溶剂相比，它们都呈现出[[绿色化学]]的某些特征，例如低蒸气压、不可燃性和良好的稳定性。其中，碱/尿素体系在可得性、成本和危害潜力方面尤为突出。在该体系进入市场之前，仍有许多问题需要解决。高分子量原料相对较低的溶解度仍然是一个挑战。其他挑战来自低温处理、高能耗和特殊设备带来的工业化困难。从科学角度看，[[氢键]]网络对纤维素在碱/尿素中溶解和反应行为的影响尚不清楚。QOH 是一种更强效的纤维素水性溶剂。对 QOH 的担忧可能来自所需的高浓度，这不仅导致成本增加，还会影响其中的化学反应。例如，盐效应在许多反应中都很显著。与其他绿色溶剂相比，ILs 作为纤维素改性反应介质的研究要多得多，因为它们具有良好的稳定性和溶解能力。ILs 最有可能用于可控合成结构精确确定的纤维素衍生物。对于未来的实际应用，ILs 的成本和黏度需要大幅降低。DESs 已显示出令人振奋的潜力。DESs 的优势主要来自其低成本且易于合成。然而，关于纤维素在 DESs 中溶解和改性的研究非常少。未来应在 DESs 上投入更多的学术努力。

## 3. 绿色溶剂中[[纤维素]]的[[化学改性]]

根据其分子结构，[[纤维素]]由重复的[[脱水葡萄糖单元]]（AGU）组成，这些单元通过C4和C1碳原子上的OH基团之间的缩醛官能团共价连接。<sup>69</sup> 纤维素链的每个葡萄糖重复单元具有三个羟基，即C6位的一个伯羟基，以及C2和C3位的仲羟基。这些沿大分子链分布的羟基易于通过与官能团反应进行化学修饰，从而产生各种纤维素衍生物。此外，AGU中三个羟基的反应活性各不相同，这受固有反应能力、反应介质、试剂的空间效应以及纤维素超分子结构的空间效应影响。<sup>11</sup> 迄今为止，已在上述溶剂体系中通过[[酯化]]、[[酰化]]、[[接枝]]、醚化和氨基甲酸酯化合成了众多纤维素衍生物（如酯、醚、氨基甲酸酯、碳酸酯）。

## 3.1. [[纤维素]]在[[离子液体]]中的化学修饰

3.1.1. [[酯化]]与[[酰化]]。在最广泛的[[纤维素]]衍生物中，酯化纤维素最受关注。通常，纤维素的转化可通过两条主要途径实现，即在有无催化剂存在下，纤维素与游离酸进行酯化，以及纤维素与酰氯或酸酐进行酰化。多种纤维素酯，如脂肪族酯和芳香族酯，此前已在[[离子液体]]介质中合成。<sup>70</sup>

[[醋酸纤维素]] $( \mathrm { C A } ) ,$ 是一种常被研究的脂肪族[[纤维素]]酯，可通过纤维素与[[乙酰氯]]（AcCl）、[[乙酸酐]] $\left( \operatorname { A c } _ { 2 } \operatorname { O } \right)$ 、[[乙酸异丙烯酯]]（IpeAc）、[[乙酸乙烯酯]]（VinAc）等试剂在无催化剂或有催化剂条件下进行[[酰化|乙酰化]]合成。在这方面，反应可在多种[[离子液体]]中进行，包括[[1-烯丙基-3-甲基咪唑氯盐]]（[AMIM][Cl]）、<sup>71,72</sup> [[1-丁基-3-甲基咪唑氯盐|1-N-丁基-3-甲基咪唑氯盐]]（[BMIM][Cl]）、<sup>73,74</sup> [[1-乙基-3-甲基咪唑氯盐|1-N-乙基-3-甲基咪唑氯盐]]（[EMIM][Cl]）、<sup>73</sup> [[1-乙基-3-甲基咪唑醋酸盐]]（[EMIM][OAc]）、<sup>75,76</sup> [[三乙基辛基氯化铵]] $\left( \mathbf { N } _ { 2 2 2 8 } \mathbf { C l } \right) , ^ { 7 7 }$ 1,5-二氮杂双环[4.3.0]壬-5-烯醋酸盐 [DBNH][OAc]<sup>78,79</sup> 和1,8-二氮杂双环[5.4.0]十一碳-7-烯醋酸盐 [DBUH][OAc]。<sup>80</sup> 这些溶剂表现出良好的纤维素溶解行为，其中一些甚至可以充当[[有机催化]]剂。例如，[[Kakuchi]]等利用[EMIM][OAc]的双重功能，即溶解能力和有机催化性能，实现了纤维素的简便乙酰化（Scheme 2a）。<sup>75</sup> 在离子液体介质中与IpeAc的反应可平稳快速进行，获得高[[取代度]][[三醋酸纤维素]]（DS = 2.96）。[[Kakko]]等展示了一种超碱衍生离子液体（即[DBNH][OAc]），用于纤维素与 $\operatorname { A c } _ { 2 } \mathrm { O } ,$ IpeAc、VinAc的快速高效乙酰化。他们在温和条件下进行反应 $( 6 0 - 7 0 \ ^ { \circ } \mathrm { C } ,$ 1 h），无需催化剂辅助。<sup>78</sup> 研究发现，用IpeAc乙酰化可制得DS高达2.97的醋酸纤维素，而使用乙烯基试剂时，所得CA产物的最高DS为1.58。

除[[离子液体|单一离子液体体系]]外，研究者还将离子液体与[[共溶剂]]的二元混合物用作[[酰化]]介质。常用的共溶剂包括 [[二甲基亚砜|DMSO]]、[[N,N-二甲基甲酰胺|DMF]]、[[N,N-二甲基乙酰胺|DMAc]]、[[乙腈]]（ACN）和[[丙酮]]，这些共溶剂被认为能够促进乙酰化过程。在 [EMIM][OAc] 与 DMSO 共溶剂组合中，已实现[[多糖]]（即[[纤维素]]、[[木聚糖]]、[[糊精]]、[[普鲁兰多糖]]）[[乙酸]]酯的克级制备。<sup>76</sup> 共溶剂作为高效促进剂，提升了 ${ \mathrm { I L } } ,$ 的[[有机催化|有机催化能力]]，这主要归因于离子液体阴离子对醇类物种的[[亲核协助]]。<sup>81</sup> Jogunola 等人研究了在 [DBNH][OAc] 与分散剂（即 DMSO、DBN、ACN 和丙酮）二元溶剂中合成 [[醋酸纤维素|CA]] 的过程，$a l . ,$ 如 Scheme 2b 所示。<sup>79</sup> 在 ACN 存在下，使用 5 equiv./[[脱水葡萄糖单元|AGU]]，于 80 $^ \circ \mathbf { C } .$ 条件下，CA 的 [[取代度|DS]] 在 0.5 h 内达到 2.68。然而，如果不添加共溶剂，在相似条件下反应 3.0 h 后 DS 仅为 0.9。Hanabusa 等人制备了九种由脒和乙酸组成的[[质子型离子液体]]用于纤维素溶解，并验证 [DBUH][OAc] 对纤维素乙酰化表现出最佳催化性能。<sup>80</sup> 添加 DMSO 使 CA 的 DS 从 2.61 提高到 2.87。一种[[铵基离子液体]] $\left( \mathbf { N } _ { 2 2 2 8 } \mathbf { C l } \right)$ 与丙酮组合被用于均相乙酰化（Scheme 2c）。所得 CA 的最大 DS 值为 2.79。<sup>77</sup>

[[接枝]]。[[接枝聚合]]是一种常用的[[纤维素]]改性方法，其目的是将接枝聚合物侧链共价键合到纤维素主链上，形成具有支化结构的共聚物。这种方法在不破坏纤维素固有特性的前提下，赋予天然纤维素新的性能（例如，疏水性、敏感性、抗菌能力）。<sup>104</sup> 通常，纤维素接枝共聚物可以通过[[开环聚合]]（ROP）、[[原子转移自由基聚合]]（ATRP）和[[可逆加成-断裂链转移聚合|可逆加成-断裂链转移]]（RAFT）聚合来制备。[[离子液体]]是纤维素和接枝试剂的优良溶剂。迄今为止，以离子液体或二元离子液体/[[共溶剂]]体系作为反应介质，已经合成了具有多种侧链的接枝纤维素共聚物[例如，[[聚乳酸]]（PLA），<sup>105–107</sup> [[聚己内酯]]（PCL），<sup>105,108–110</sup> [[聚对二氧环己酮]]（PDO），<sup>111</sup> [[聚丙烯酸]]（PAA），<sup>112</sup> [[聚（N-异丙基丙烯酰胺）]]（PNIPAM），<sup>113,114</sup> 聚甲基丙烯酸甲酯（PMMA），<sup>115,116</sup> 聚（N,N-二乙基[[丙烯酰胺]]）（PDEAAm），<sup>114</sup> 聚（N,N-二甲氨基-2-乙基甲基丙烯酸酯）（PDMAEMA）<sup>117</sup>]。本课题组应用ROP策略设计并合成了一系列带有PLA、PCL和PDO链的两亲性纤维素接枝共聚物（方案3d–f）。<sup>105</sup> 反应在IL-BMIMCl介质中进行。所得共聚物能够自组装成核壳结构胶束，随后用作疏水性药物的载体，应用于药物递送和细胞成像领域。<sup>107,109,118</sup> 最近，Liu等人在[BMIM][Cl]中通过ROP合成了阳离子型两亲性纤维素共聚物。所得产物的[[取代度|DS]]最高可达1.79，表明其ROP接枝效率较高。<sup>111</sup> [[Zhang]]等人通过电子转移再生活化剂的ATRP方法合成了设计良好的纤维素接枝PMMA共聚物（方案3g）。<sup>119</sup> 在这一方面，首先以[[1-烯丙基-3-甲基咪唑氯盐|AMIMCl]]/[[N,N-二甲基甲酰胺|DMF]]为溶剂，将2-溴异丁酰基引入纤维素主链。所得大分子引发剂用于MMA的共聚，以获得最终共聚物产物。与线性PMMA薄膜相比，这些共聚物表现出相似的透明度和显著提高的拉伸韧性。Hufendiek等人在BMIMC介质中制备了纤维素大分子链RAFT试剂（cellulose-CTA）。PDEAAm和PNIPAM随后可接枝到这些cellulose-CTA上，从而得到温度响应型纤维素接枝共聚物。<sup>114</sup> 然而，关于离子液体中纤维素RAFT聚合的报道仍然有限。

3.1.4. 氨基甲[[酰化]]。一般而言，[[纤维素]]的氨基甲酰化可以在[[离子液体]]中使用异氰酸酯作为试剂进行。Heinze 团队提供了在 [BMIM][Cl] 中对三种不同聚合度（[[聚合度|DP]]）的纤维素进行氨基甲酰化的实例。该反应在无催化剂条件下使用苯基异氰酸酯进行。<sup>73</sup> 使用每 [[脱水葡萄糖单元|AGU]] 10 当量试剂，在 80 °C 下反应 4 h，制得了全取代的纤维素苯基氨基甲酸酯。该团队随后将氨基甲酰化的研究对象转向与植物纤维素差异显著的[[细菌纤维素]]（BC）（方案 3h）。<sup>120</sup> BC 氨基甲酸酯的 [[取代度|DS]] 值在 0.29–3.0 范围内，取决于反应时间和摩尔比。纤维素与 [[3,5-二甲基苯基异氰酸酯]]在 [AMIM][Cl] 中的反应合成了纤维素-三(3,5-二甲基苯基氨基甲酸酯)（CDMPC），如方案 3i 所示。<sup>121</sup> 所制备的 CDMPC 被进一步用于制备手性固定相，用于七种农药的手性拆分。<sup>121</sup> 近年来，通过简便的两步法在 [AMIM][Cl] 中合成了一系列区域选择性取代的纤维素杂化酯，即纤维素 6-苯甲酸酯-2,3-苯基氨基甲酸酯（方案 3j）。该制备过程无需保护-脱保护步骤。<sup>94</sup> 结果表明，苯环上带有给电子取代基（如 4-叔丁基）的高手性识别纤维素衍生物可与市售 Chiralcel OD 柱相媲美。<sup>94</sup> 纤维素氨基甲酸酯是一种生物基且环境友好的材料，被认为是石油基聚合物的一种有吸引力的替代品。<sup>122</sup> [[Zhang]] 等人通过在 [BMIM][Cl] 存在下使用[[尿素]]对纤维素进行原位反应挤出改性，获得了 DS 为 0.24 的纤维素氨基甲酸酯（方案 3k）。<sup>123</sup>

## 3.2. [[纤维素]]在[[低共熔溶剂]]中的[[化学改性]]

3.2.1. [[酯化]]和[[酰化]]。Abbott 等人采用基于 [[氯化胆碱|ChCl]] 的 [[低共熔溶剂|DES]]（即 ChCl/[[氯化锌|ZnCl]]）同时作为溶剂和催化剂，对单糖和[[纤维素]]进行 O-乙酰化反应（方案 4a）。该 DES 体系可获得 [[取代度|DS]] 值在 0.15–0.47 范围内的[[醋酸纤维素|乙酰化纤维素]]。<sup>124</sup> Park 等人通过将棉织物与光活性抗菌化合物 [[3,3′,4,4′-二苯甲酮四甲酸二酐]]（BPTCD）在染色机中振荡浸渍并配合轧-烘-焙工艺的联合处理，制备了新型抗菌棉（方案 4b）。<sup>125</sup> 在此情况下，ChCl/[[尿素]]和 ChCl/[[乙二醇]]（ChCl/EG）被开发为环境可接受且经济可行的处理介质。经处理的棉织物在紫外照射前后均表现出优异的抗菌活性。除基于 ChCl 的 DES 外，最近一种由咪唑和三乙基甲基氯化铵（TEMACl）组成的 DES 体系被证明是一种简单快速的反应介质，可用于以[[辛烯基琥珀酸酐]]（OSA）对[[纤维素纳米纤维]]（CNFs）薄膜和[[全纤维素复合材料]]（ACC）薄膜进行改性（方案 4c）。<sup>126</sup> 该反应在相对温和的条件下（80 °C，1 h）进行。与原始 CNF 薄膜相比，OSA 改性的 CNF 薄膜表现出更好的力学性能和更高的疏水性。

![](<../2.SCI_MD/Progress on chemical modification of cellulose in “green” solvents/images/a059dc7e5ab153d15c97bfb5159cdf5975ac6a55b2d5908cff5229d9562a7cf4.jpg>)

此外，[[低共熔溶剂|DESs]] 还被用作绿色预处理途径，与机械解离相结合生产衍生化[[纳米纤维素]]。通过[[丁二酸酐]]（SA）与[[纤维素|木材纤维素]]羟基的开环[[酯化]]反应，再经机械处理，制得了直径为 2–7 nm 的阴离子 [[纤维素纳米纤维|CNFs]]（方案 4d）。<sup>127</sup> 该反应在不降解、不溶解纤维素的[[尿素]]/[[氯化锂|LiCl]] DES 介质中于 70–110 °C 下进行 2–24 h，得到羧基含量为 0.34–0.95 mmol $\mathrm { g } ^ { - 1 }$ 的阴离子纤维素。另一种由咪唑和 TEMACl 组成的 DES 体系被报道用作[[磨木浆]]（GWP）与 SA 阴离子功能化的预处理介质（方案 4e）。<sup>128</sup> 改性后的 GWP 在 70 °C 下处理 2 h，羧基含量高达 3.34 mmol $\mathrm { g } ^ { - 1 }$ ，并形成高阴离子电荷的木材纳米纤维。这类纳米尺寸纤维可以形成具有良好力学性能的自支撑薄膜。最近，Liu 等人将一系列基于 [[氯化胆碱|ChCl]]/羧酸的 DESs 同时用作预处理介质和反应试剂，以[[阔叶木漂白硫酸盐浆]]为原料生产酯化 CNFs。$\mathrm { \ p u l p . } ^ { 2 2 }$ DES 的存在有利于纤维素的酯化和有效溶胀，从而在机械处理后得到 CNFs。所得酯化 CNFs 的产率高达 72%–88%，并仍保持纤维素 I 晶体结构。

3.2.2. 醚化。尽管 [[低共熔溶剂|DESs]] 作为反应介质表现出良好的性能，但一些 DESs 已被证明在特定条件下缺乏稳定性。因此，DESs 可以直接参与[[纤维素]]改性，尤其是纤维素的醚化。例如，开发了一种 [[氯化胆碱|ChCl]] 衍生物与[[尿素]]的共晶混合物用于纤维素的阳离子化（方案 4f）。<sup>129</sup> 该 DES 同时充当溶剂和反应试剂，能够与纤维素上所有可用的羟基反应，得到亲水性显著提高的[[阳离子纤维素衍生物]]。另一个应用于生物基絮凝剂的阳离子纤维素衍生物实例，是利用[[缩水甘油基三甲基氯化铵]]（GTAC）与[[硼酸]]的混合物对纤维素进行改性而合成的（方案 4g）。<sup>130</sup> 在这种情况下，纤维素的阳离子化无需任何额外溶剂或昂贵的增溶方法即可实现。此后，研究了一种基于[[氯代胆碱盐酸盐]]（ClChCl）/尿素的替代绿色溶剂，用于纤维素单块的阳离子功能化。<sup>131</sup> 所得材料被用作[[吸附]]剂，用于去除水中的[[酸性红 70]] 染料。此外，Sirviö 等人报道了一种反应性[[氨基磺酸]]/尿素 DES，同时作为纤维素硫酸化反应的反应介质和试剂。$a l . ^ { 1 3 2 }$ 磺化样品的电荷密度达到 1.40–3.00 mmol $\mathrm { g } ^ { - 1 }$ 的范围。硫酸基含量为 2.40 mmol $\mathrm { g } ^ { - 1 }$ 的磺化纤维素仅通过[[微流化器]]一次，即可容易地形成透明凝胶状 [[纤维素纳米纤维|CNFs]]。

3.2.3. 氨基甲酸[[酯化]]。[[尿素]]及其许多衍生物是用于[[纤维素]][[化学改性]]的有前景的化学品。<sup>133</sup> 因此，当用基于尿素的[[低共熔溶剂|DES]]处理纤维素时，可以实现氨基甲酸酯转化。Sirviö等人<sup>133</sup> 展示了一种由[[二甲基脲]]和[[氯化锌|ZnCl]]组成的反应性DES，用于合成[[取代度|DS]]为0.17的纤维素甲基氨基甲酸酯（方案4h）。氨基甲酸酯化反应在150 °C下进行3 h。产物在3% NaOH中表现出良好的碱溶性，而原始纤维素纤维即使在9% NaOH溶液中也不溶。随后，在三种不同的基于尿素的DES体系（即尿素/[[氯化胆碱|ChCl]]、尿素/[[甜菜碱盐酸盐]]和尿素/[[甜菜碱]]）中制备了纤维素氨基甲酸酯，如方案4i所示。<sup>134</sup> 反应在95–120 °C的相对较低温度下进行，无需外部溶剂。通过改变纤维素浓度和反应温度，可以容易地调节纤维素氨基甲酸酯的氮含量。

## 3.3. [[纤维素]]在碱/[[尿素]]水溶液中的[[化学改性]]

3.3.1. 醚化。由于[[纤维素]]的醚化通常在碱性环境中进行，碱/[[尿素]]水溶液体系因其初始碱性而非常适合作为合成纤维素醚的均相反应介质。迄今为止，已在碱/尿素水溶液体系中制备了纤维素醚，如[[甲基纤维素|MC]]、<sup>135</sup> [[羧甲基纤维素|CMC]]、<sup>136</sup> [[羟乙基纤维素|HEC]]、<sup>137</sup> [[羟丙基纤维素|HPC]]<sup>135</sup> 以及[[氰乙基纤维素]]（[[羧乙基纤维素|CEC]]）<sup>138,139</sup>。这些纤维素衍生物基本上是通过纤维素与醚化剂（如卤代烷、环氧化物和乙烯基化合物）反应获得的。

[[Zhang]]及其同事采用6 wt% NaOH/4 wt%[[尿素]]水溶液作为反应介质，用于合成[[烯丙基纤维素]]（AC）（方案5a）。使用烯丙基氯作为醚化剂时，达到了1.65的最大[[取代度|DS]]。<sup>140</sup> 在这种情况下，AC产物是一种良好的中间体，可通过[[硫醇-烯点击反应]]进一步与硫醇化合物[[[正十二烷基硫醇]]（NDM）、[[2-氨基乙硫醇盐酸盐]]（AET）、[[半胱氨酸]]（Cys）和[[单硫代甘油]]（MG）]反应。最近，设计了一种两亲性[[纤维素]]（[[微晶纤维素|MCC]]-C16），用于改善[[聚丙烯腈-共-丙烯酸甲酯|聚（丙烯腈-共-丙烯酸甲酯）]][[超滤膜]]的防污和分离性能。<sup>141</sup> MCC-C16的合成是通过在上述水溶液（6 wt% NaOH/4 wt%尿素）中使MCC与[[1-溴十六烷]]反应实现的，如方案5b所示。

![](<../2.SCI_MD/Progress on chemical modification of cellulose in “green” solvents/images/56d74cdd7baed94c48acf1d5149af201a380fb45b0dc08d1558ef03adafd9d7b.jpg>)  
方案5 [[纤维素]]在碱/[[尿素]]水溶液中的[[化学改性]]。

7 wt% NaOH/12 wt%[[尿素]]水溶液是引发[[纤维素]][[醚化反应]]的有利溶剂。溶解在7 wt% NaOH/12 wt%尿素水溶液中的纤维素在温和条件下、无任何催化剂的情况下与[[苄基氯]]反应（方案5c）。<sup>142</sup> [[苄基纤维素]]的[[取代度|DS]]值范围为0.29至0.54，取决于反应温度和苄基氯与[[脱水葡萄糖单元|AGU]]的摩尔比。然而，反应介质的高含水量限制了纤维素的苄基化，并使其难以获得更高的DS。<sup>143</sup>

高正电荷的[[季铵盐改性纤维素]]（QMCC）是在7% NaOH/12%[[尿素]]水溶液中制备的。<sup>144</sup>添加QMCC的[[固态聚电解质膜|碱性固态聚电解质膜]]表现出显著提高的[[电导率]]和[[拉伸强度]]，可应用于柔性[[锌–空气电池]]。使用相同溶剂，Qi等人用[[烯丙基缩水甘油醚]]（AGE）对[[纤维素]]进行改性，得到[[3-烯丙氧基-2-羟丙基纤维素]]（AHP-celluloses），其[[取代度|DS]]范围为0.32–0.67（方案5d）。<sup>145</sup>此外，由于碱/尿素水溶液对纤维素具有良好的溶解能力且本身含水量高，为制备[[纤维素基水凝胶]]提供了合适的水性环境。这些[[水凝胶]]可通过纤维素或纤维素衍生物在[[交联]]剂存在下发生化学交联来制备。Liu等人在6 wt% NaOH/4 wt%尿素水溶液中，通过纤维素与[[1,4-丁二醇二缩水甘油醚]]（BDE）的化学交联合成了纤维素水凝胶。<sup>146</sup>Tong等人报道了在NaOH/尿素水溶液中由纤维素合成[[纤维素离子水凝胶]]（CIHs）。<sup>147</sup>纤维素经AGE醚化后被赋予双键，然后通过[[自由基聚合]]进行化学交联，制得具有高伸长率和压缩性的CIHs。

得益于碱/[[尿素]]水溶液体系的碱性，乙烯基化合物在这些体系中被活化，并在无催化剂条件下与[[纤维素]]发生[[Michael加成反应]]。作为一个典型例子，纤维素与[[丙烯腈]]（AN）的[[氰乙基化]]可在7 wt% NaOH/12 wt%尿素（方案5e）<sup>138</sup>和4.5 wt% [[氢氧化锂|LiOH]]/15 wt%尿素水溶液（方案5f）中实现。<sup>139</sup>在该反应中，羟基的相对反应活性顺序为C-6 > C-2 > C-3。带有酰胺基和羧基的纤维素聚电解质在NaOH/尿素水溶液中均相合成（方案5g）。合成过程包括两个步骤：先与[[丙烯酰胺]]发生Michael加成反应，随后酰胺基[[皂化]]为羧基。<sup>148</sup>基于纤维素与丙烯酰胺和[[苄基氯]]的[[醚化反应]]，合成了一种含有疏水性苄基和亲水性羧乙基的[[两亲性纤维素衍生物]]（BCEC）（方案5h）。该反应在NaOH尿素水溶液中进行，无需额外催化剂。<sup>149</sup>考虑到BCEC的pH响应性和表面活性剂性质，通过BCEC与[[聚脲]][[交联]]形成的[[微胶囊]]被用于疏水性[[1-萘乙酸甲酯]]（MENA）的包封与可控释放。此外，选择[[亚甲基双丙烯酰胺]]（MBA）作为Michael加成试剂，在LiOH/尿素水溶液中用于纤维素交联。由此形成了坚固的[[水凝胶]]，并表现出优异的吸水能力。<sup>150</sup>

## 3.4. [[纤维素]]在[[季铵氢氧化物]]中的[[化学改性]]

3.4.1. [[醚化反应]]。与水系碱/[[尿素]]体系类似，[[季铵氢氧化物|QOH]] 水溶液表现出强碱性，能够为[[纤维素]]的均相醚化提供适宜环境。Abe 等报道了在 47% [[四丁基氢氧化鏻|TBPH]] 水溶液中用[[苄基溴]]对纤维素进行快速苄基化（Scheme 6a）。<sup>151</sup> 在 20–25 °C 下，使用每 [[脱水葡萄糖单元|AGU]] 9 当量试剂，10 分钟内即可合成具有高 [[取代度|DS]] 值（>2.5）的[[苄基纤维素]]。由于水含量较低（<50%），该溶剂体系比 NaOH/尿素水溶液体系更有利于纤维素苄基化。TBPH 溶液也被证明可用作纤维素烯丙基化的反应介质。在 25 °C 下与烯丙基溴反应 10 分钟，可快速将烯丙基引入纤维素，得到 DS 约为 1.9 的 AC 产物（Scheme 6b）。同时确认在烯丙基化过程中未观察到纤维素明显降解及烯丙基取代基之间的交联。Sirviö 与合作者开发了一系列由 TEAH 水溶液与酰胺类化合物（尿素、N-甲基脲、N-乙基脲、1,3-二甲基脲和咪唑啉酮）组成的混合溶剂，用于纤维素室温溶解与醚化。<sup>10</sup> 使用 [[缩水甘油基三甲基氯化铵|GTAC]] 进行醚化反应时，在室温（23 °C）下以 3 当量/AGU 的摩尔比均相进行 24 小时（Scheme 6c）。在所有研究的 [[四乙基氢氧化铵|TEAH]]/酰胺溶剂中制得的[[阳离子纤维素衍生物]]，与在 7 wt% NaOH/12 wt% 尿素参考溶液中获得的产物相比，表现出更高的阳离子电荷密度。[[阳离子木纳米纤维]]（CWNF）可通过在 TEAH/酰胺水溶液中使用 GTAC 对锯末进行环氧开环醚化，再进行机械解纤而制得。<sup>152</sup> 由 CWNF 制备的薄膜表现出优异的紫外阻隔、氧气阻隔及抗菌性能。Shi 等采用一种简单新颖的策略，在质量比为 2 : 3 : 5 的 [[四丁基氢氧化铵|TBAH]]/H₂O/[[二甲基亚砜|DMSO]] 三元溶剂体系中设计[[荧光纤维素薄膜]]。<sup>153</sup> 在该体系中，通过纤维素与含环氧丙氧基的荧光素分子进行醚化并随后发生[[交联]]反应来制备薄膜。所得薄膜在拉伸后表现出优异的荧光性能、pH 敏感性及偏振发射行为。<sup>153</sup>

## 4. 结论与展望

[[纤维素]]是储量最丰富的可再生材料，具有引人注目的特性。均相[[化学改性]]是将纤维素转化为高度均匀纤维素衍生物的一种高效技术。然而，纤维素的溶解是衍生化之前的关键步骤。在本综述中，我们简要概述了四类近期用于纤维素溶解的“绿色”溶剂，即[[离子液体]]（ILs）、[[低共熔溶剂]]（DESs）、水系碱/[[尿素]]体系和水系 [[季铵氢氧化物|QOH]] 体系，并总结了纤维素在这些溶剂中进行改性的近期实例。

尽管这些溶剂已成为[[纤维素]]衍生化的反应介质，但它们各有优缺点。由于优异的溶解能力和结构多样性，[[离子液体]]与纤维素化学高度契合。迄今为止，纤维素的多种[[化学改性]]类型，如[[酯化]]、醚化、[[接枝]]和 carbalination，均可在离子液体中进行。离子液体能有效溶解纤维素和反应物，为纤维素功能化提供均相反应介质。根据离子液体的结构特征，若干离子液体甚至在反应中表现出催化性能。在离子液体中可较容易地合成高[[取代度]]的纤维素衍生物。遗憾的是，大多数离子液体存在高黏度和对水高度敏感的缺点。尽管向离子液体中加入[[共溶剂]]可以适当降低黏度，但在溶解和改性过程中仍需严格控制水含量。此外，离子液体的高成本、制备困难、潜在毒性以及不可降解性仍令人担忧。

[[低共熔溶剂]]被认为是传统[[离子液体]]的无毒性或低毒性、廉价且可生物降解的替代品，因为它们兼具离子液体的优点。然而，低共熔溶剂高效溶解[[纤维素]]的例子仍然有限，且纤维素在低共熔溶剂中的溶解度远低于在离子液体中。由于纤维素溶解不充分，目前以低共熔溶剂作为反应介质的纤维素衍生化通常是在非均相条件下进行的。

就碱/[[尿素]]水体系而言，可以实现[[纤维素]]的快速溶解，但受预冷要求和纤维素分子量的限制。碱/尿素水溶液中纤维素的功能化主要集中在醚化方面。在碱/尿素水溶液体系中将纤维素转化为纤维素醚，常常受到溶剂高含水量的困扰。此外，碱/尿素水溶液中纤维素改性的研究在一定程度上局限于[[张俐娜]]课题组的工作，需要更广泛科学界的参与。

与碱/[[尿素]]水体系相比，[[季铵氢氧化物]]水溶液可以在环境温度下快速溶解[[纤维素]]。尽管文献中关于季铵氢氧化物水溶液中纤维素衍生化的研究有限，但这些结果将激励研究者在该类体系中开展更多纤维素改性尝试。

为响应[[绿色化学]]的12条原则，[[纤维素]]溶剂的高效制备、毒性评估和回收等重要问题仍需加以考虑。本简评中讨论的大多数绿色溶剂都是石油基产品。以应用最广泛的[[离子液体]]类别为例，[[咪唑鎓]]阳离子的合成需要大量化学反应步骤，其中还涉及非绿色反应。在[[碳减排]]目标的驱动下，生物来源溶剂或来自可再生资源的溶剂将成为一个重要方向。鉴于离子液体和[[低共熔溶剂]]的巨大设计空间，许多[[生物基分子]]都可被考虑用于使溶剂更加绿色。

未来亟需开展以应用为导向的研究，以实现[[纤维素]]在绿色溶剂中的改性。市场正经历从传统石油资源驱动发展向更加以生物资源驱动发展的重大转型。未来将需要更多功能性纤维素化学品与材料，这将要求纤维素改性行业在未来适应更加丰富的产品。未来的研究需要聚焦于纤维素向功能性纤维素衍生物的高效、低废物/副产物和高选择性的绿色转化。此外，还需进一步研究反应介质、反应物和改性技术的选择。
