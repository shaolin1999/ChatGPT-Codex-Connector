## ■ 引言

[[全氟和多氟烷基物质]]（PFASs）是在环境中持久存在、具有[[生物累积性]]且有毒的化学物质，由于数十年来在消费品、灭火泡沫和工业过程中的广泛使用，它们污染了水资源。<sup>1</sup> 与长期暴露于 PFAS 相关的健康影响<sup>2</sup> 促使在处理后的饮用水中实施万亿分之一（ng L<sup>−1</sup>）级别的监管限值，并引发了更多要求限制其使用的呼声。<sup>3,4</sup> 处理受 PFAS 影响水体的主流方法<sup>5</sup> 依赖于填充常规[[吸附]]材料（如[[颗粒活性炭]]（GAC）或[[阴离子交换树脂]]（AER））的分离工艺，其中[[吸附剂]]耗尽后，处理水中 PFAS 浓度会上升（即 PFAS [[穿透曲线|穿透]]），而负载 PFAS 的吸附剂通常被填埋。GAC 和 AER 昂贵且不可持续的[[再生]]技术限制了它们的重复使用，并导致这些材料的生命周期性能较差。<sup>8</sup> 在全规模[[饮用水处理|水处理]]中实现有效的 PFAS 去除，需要将 GAC 和 AER 以颗粒材料（0.5−1.7 mm）的形式部署，以尽量减少系统[[背压]]，但这会减少可用于吸附的[[BET|比表面积]]，并阻碍[[传质]]到[[吸附位点]]。<sup>9</sup> 克服颗粒基吸附剂的低效性需要施用大量吸附剂，对于平均流量为每天一百万加仑水的典型饮用水厂，推荐的吸附剂质量每年高达 40 吨，不包括定期吸附剂再生和更换所需的量。<sup>10−12</sup> 虽然 GAC 和 AER 被广泛用于 PFAS 水处理，但其长期可持续性日益受到能源密集型合成、再生和处置的挑战。<sup>8</sup> 需要处理的水源数量众多，进一步加剧了这些低效性。据估计，美国 45% 的饮用水源被一种或多种 PFAS 污染，<sup>13,14</sup> 还有更多一次性和二次污染源（例如工业设施、废水处理厂）<sup>15</sup> 将通过适当管理受益，以限制持续的地表水和[[地下水]]污染。<sup>16</sup> 因此，迫切需要能够选择性去除多种 PFAS、具有改进的穿透容量、实施简便且生命周期负担低的下一代吸附剂。新型 PFAS 吸附剂，<sup>17</sup> 包括基于[[环糊精]]聚合物、<sup>18</sup> 含氟凝胶<sup>19</sup> 或多孔有机框架<sup>20,21</sup> 的吸附剂，在实验室规模或小型中试规模系统中展现出前景。然而，它们与全规模处理工艺的兼容性仍未得到证实，特别是考虑到颗粒内传质限制、动力学受限的穿透行为以及低效的再生或更换程序等挑战。<sup>22</sup>

在此，我们证明，一种由新兴的[[环糊精]]基聚合物<sup>23</sup>组成、直接聚合到柱中的[[分层多孔整块材料|分级多孔整体材料]]，是一种高效且可[[再生]]的[[吸附剂]]，能够实现长期 [[全氟和多氟烷基物质|PFAS]] 去除。我们此前已证明，粉末状[[苯乙烯官能化环糊精]]（[[StyDex]]）聚合物在真实水基质中对 PFAS 具有选择性[[吸附]]潜力。<sup>24−26</sup> 在此，StyDex 和其他乙烯基共聚单体在[[高内相乳液]]（HIPE）<sup>27,28</sup>的连续相中聚合，以获得具有分级[[孔隙率]]的 StyDex [[整体柱]]（图1）。StyDex 整体柱通过使受 PFAS 污染的水轻易流过分级孔结构，从而接触整个材料中的[[吸附位点]]，克服了颗粒基吸附剂的[[传质]]限制。此外，HIPE 可直接在过滤器外壳内聚合，从而规避了新型吸附剂开发中常见的繁琐合成、造粒和柱填充步骤。在连续流条件下，StyDex 整体柱在单位吸附剂质量的 PFAS 去除方面显著优于 [[阴离子交换树脂|AER]] 和 [[颗粒活性炭|GAC]]。StyDex 整体柱在极短接触时间（<2 s）下也表现出良好性能，而传统吸附剂在此类条件下表现出动力学限制。仅使用 47 mg 吸附剂，我们通过处理 150 L 水达 37 天、其中含有低至十亿分之一级的 $( \mu \mathbf { g } \ \mathbf { L } ^ { - 1 } )$ PFAS 浓度，证明了整体柱的持续稳定性和 PFAS 吸附容量，这相当于每克吸附剂处理超过 3000 L 水。整体柱的分级孔隙率对于实现优异 PFAS 去除至关重要，因为将整体柱破碎并筛分至与 AER 和 GAC 相似的粒径后，其性能下降。再生性通过用简单的醇基再生溶液冲洗整体柱，并在 39 天内额外泵送 170 L 水测试第二个[[穿透曲线|穿透]]循环来证明，两个循环后 PFAS 回收率接近完全。我们设想，具有易于调控组成和 PFAS 选择性的整体吸附剂将在规模化 PFAS 处理技术中优于颗粒基吸附剂。

## ■ 结果与讨论

[[StyDex]] [[分层多孔整块材料|整体柱]]的设计、合成与表征。我们推断，理想的整体式 [[全氟和多氟烷基物质|PFAS]] [[吸附剂]]应具备以下特征：(1) [[大孔]]结构，以便水流通过时[[背压]]最小；(2) 机械强度高，能够承受施加的压力而不发生结构破坏；(3) 分级多孔，以确保[[吸附位点]]可及并最大限度减少扩散限制。利用 [[高内相乳液|HIPE]] 对聚合物形貌进行模板化，是制备互连大孔[[吸附]]剂的一种有前景的方法，因为它具有可调的[[孔隙率]]（70−95%）、机械强度以及配方灵活性，可容纳各种化学组分以实现有效的 PFAS 去除。<sup>29,30</sup> 将 [[苯乙烯官能化环糊精|StyDex]] 吸附剂的本体聚合 adapting 到 HIPE 中发生，需要确定与乳液相容的合适单体、表面活性剂和聚合条件组合。选择 [[DMF]] 作为连续相（聚合发生之处），是因为它能够溶解相对极性的 StyDex 和其他亲水性共聚单体；而选择[[十六烷]]作为致孔剂，是因为它与 [[N,N-二甲基甲酰胺|DMF]] 不互溶且对 StyDex 单体的溶剂化能力较差。<sup>31</sup> HIPE 由十六烷与 DMF 以 82:18 v:v 的混合物形成，其中 DMF 相含有单体和作为自由基引发剂的 [[偶氮二异丁腈|AIBN]]。在加入表面活性剂（[[Pluronic F-127]]）将双相混合物乳化后，使用 AIBN 在紫外光（365 nm）照射下引发聚合 10 分钟以稳定分散液滴，随后在 $8 0 ~ ^ { \circ } \mathrm { C }$ 下进一步加热 2 小时以完成反应（图 S1）。早期仅基于 StyDex 单体和（乙烯基苄基）三甲基氯化铵作为阳离子共聚单体的[[整体柱]]配方产生了大孔但脆性的整体柱（表 S1）。这些材料在 [[SEM]] 图像中显得不连续，且未能通过连续流测试（图 S2）。为提高整体柱的机械稳定性，相当一部分 DMF 溶剂被共聚单体 [[2-羟乙基甲基丙烯酸酯]]（HEMA，约占连续相体积的 50%）替代（图 S3）。HEMA 还能增溶其他共聚单体，且本身是最终整体柱中廉价的组分。采用[[实验设计]]（DoE）方法确定了单体和表面活性剂的浓度，这些浓度在十六烷高体积分数下提供了足够稳定的乳液，从而能够聚合形成高度多孔的结构（图 S4 和表 S2−S4）。尽管 HEMA 明显改善了 StyDex 整体柱的机械完整性，但 DoE 方法揭示 HEMA 降低了乳液的稳定性（图 S4）。我们通过将 DMF 中 50 vol% HEMA 条件下的 Pluronic F-127 负载量增加至 0.030 g/mL 来抵消这一效应。最终配方产生了稳定的 HIPE，通过光学显微镜测得平均液滴尺寸为 $1 3 . 1 \pm 9 . 0 \mu \mathrm { m } ,$（图 S5）。振荡剪切流变学显示其响应比粘性更具弹性（储能模量 ∼200 Pa，损耗模量 ∼10 Pa），证实了凝胶状 HIPE，其中液滴共享界面以在聚合时形成互连孔道（图 S6）。此外，HIPE 的储能模量在制备后至少一小时内未下降，确保乳液在聚合过程中有足够时间保持一致的结构（图 S6A）。这些配方提供了机械稳定的整体柱，并对其材料性能进行了表征（表 ${ \mathrm { S } } 5 ,$ 图 2 和 S7）。

所得 [[StyDex]] [[分层多孔整块材料|整块材料]]的光谱与材料表征验证了乳液模板的完全聚合、能够选择性[[吸附]] [[全氟和多氟烷基物质|PFAS]] 的单体的引入、表面活性剂的去除，以及有利于[[饮用水处理|水处理]]的孔结构。平均每个 [[β-环糊精]]（β-CD）带有 7.3 个苯乙烯单元的 [[苯乙烯官能化环糊精|StyDex]] 单体，按照我们此前的报道合成（方案 $^ { \mathrm { S 1 , } }$ 图 S8 和 S9）。<sup>24</sup> StyDex [[整体柱|整块材料]]的固态[[交叉极化魔角旋转]]（CP-MAS）$^ { 1 3 } \mathrm { C }$ [[核磁共振]]（NMR）谱中缺少对应于乙烯基碳（110−120 ppm）的共振信号，证实了 [[高内相乳液|HIPE]] 的高效聚合（图 2A），同时显示出 StyDex 的 $\beta { \mathrm { - C D } }$ 环中醚碳（73 ppm）、三甲基铵苯乙烯共聚单体的 N-甲基碳（55 ppm）以及 [[2-羟乙基甲基丙烯酸酯|HEMA]] 的羰基碳（178 ppm）的特征峰。用 [[异丙醇|iPrOH]] 洗涤后 [[Pluronic F-127]] 表面活性剂的去除，可由 [[傅里叶变换红外光谱|FT-IR]] 光谱中 $1 1 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ 处 C−O 伸缩振动的消失得到证实， 并且 Pluronic F-127 从 iPrOH 溶液中回收（Figure [[S10值|S10]]）。整块材料的碳、氢、氮和氯元素分析与预期组成一致（Table S6 和 S7），并且与在不含表面活性剂或[[十六烷]]的 [[DMF]] 中制备的模型本体聚合物相似。低堆积密度 $( 0 . 1 3 \pm 0 . 0 1$ g $\mathrm { c m } ^ { - 3 } )$ 和高[[孔隙率]] $\left( \varphi { = } 8 7 . 6 ~ \pm ~ 1 . 3 \dot { \% } \right)$ 证实了 StyDex 整块材料的[[大孔]]性（Tables S8−[[比吞吐量|S10]]）。

[[StyDex]] [[分层多孔整块材料|整块材料]]的独特材料特性及其产生的流体动力学要求精心的[[实验设计]]和适当的基准测试。<sup>35</sup> 颗粒型[[吸附剂]]中的流体流动和[[传质]]特征为：水通过不规则的颗粒间空隙发生平流流动，随后污染物从孔隙水扩散到[[吸附]]剂外表面和颗粒内表面，并最终发生吸附。相比之下，[[苯乙烯官能化环糊精|StyDex]] [[整体柱|整块材料]]表现出连续的孔网络，水通过[[大孔]]流动，这些大孔由直径明确的孔喉相互连接$( 2 . 5 ~ \pm ~ 1 . 3$ μm，图2B）。我们假设，这种相互连接的架构形成了通过比颗粒型吸附剂中颗粒间空隙更均匀路径的连通流动，而小孔与聚合物网络中[[吸附位点]]之间较短的扩散距离促进了快速传质。此外，StyDex 整块材料的堆积密度$( 0 . 1 3 \pm 0 . 0 1 \mathrm { ~ g ~ c m } ^ { - 3 } )$显著低于用于[[饮用水处理|水处理]]的传统吸附剂$\left( 0 . 6 { - } 1 . 2 \ \mathrm { g } \ \mathrm { c m } ^ { - 3 } \right)$，这进一步增加了适当基准测试的复杂性。为了考虑整块材料与颗粒型吸附剂之间的固有差异，同时能够跨不同吸附剂形态和材料进行比较，我们在柱实验中以 [[阴离子交换树脂|AER]] 和 [[颗粒活性炭|GAC]] 为对照评估了 StyDex 整块材料，首先在使用等效吸附剂质量的实验中，然后在使用等效[[固定空床接触时间]]（[[空床接触时间|EBCT]]）的实验中（图3D 和表S12）。每根柱均用超纯水（[[Milli-Q]]）进行挑战，其中加标了25种环境相关浓度的 [[全氟和多氟烷基物质|PFAS]]$( \leq 1 \mu \ g \ L ^ { - 1 } ,$ 表${ \mathrm { S 1 6 } } ,$ 图3B 和 S16），体积流速为3 mL min<sup>−1</sup>（图S18），直至观察到各种 PFAS 的[[穿透曲线|穿透]]（StyDex 整块材料柱为131−170 L 和32−39天）。由于严格的质量控制程序，六种 PFAS 被排除在穿透分析之外（表S16）。鉴于整块材料与颗粒型吸附剂之间堆积密度的差异，用[[床体积]]分析穿透实验（图S21 和 S22）对 StyDex 整块材料而言并非公平比较。因此，我们将关注的终点定义为在出水浓度超过进水浓度的10%之前，以吸附剂质量归一化的处理水体积（[[比吞吐量]]，S，L $\mathbf { g } ^ { - 1 } )$（即$S _ { 1 0 } ,$，以范围形式报告，见补充材料第V节）。<sup>36,37</sup>

我们首先将直接在色谱柱内聚合的 47 mg [[StyDex]] [[整体式吸附剂|整体材料]]与填充在相同色谱柱中的 45 mg [[阴离子交换树脂|AER]] 或 [[颗粒活性炭|GAC]] 进行了性能基准比较。[[AER PSR2+]] 和 [[GAC F600]] 经粉碎并筛分至 90−125 μm 的直径，这与我们过去[[快速小规模柱测试]]（RSSCT）中的缩放因子一致。<sup>24,25</sup> 由于 PSR2+ 和 F600 被研磨至比其商业形态（直径为 350−800 μm）更小的尺寸，我们预期与使用其市售形态的系统相比，[[吸附动力学]]将会增强。在这些条件下，[[苯乙烯官能化环糊精|StyDex]] [[整体材料]]保持了结构完整性，具有低[[背压]]（5−9 psi / 40−60 kPa，图 S17A），同时在 37 天的连续运行中从 155 L 水中完全去除了 12 种 [[全氟和多氟烷基物质|PFAS]]（图 3C、S23 和 S24）。对于未观察到[[穿透曲线|穿透]]的情况，这 12 种 PFAS 的 $S _ { 1 0 }$ 值取为大于最后收集的出水样品的比处理量（$( \mathrm { i . e . , } > 3 3 1 0 \mathrm { ~ L ~ }$ $\mathbf { g } ^ { - 1 }$，表 S19）。对于 7 种 PFAS 观察到了穿透，包括 [[GenX]] 和 [[全氟丁酸|PFBA]]，其 $S _ { 1 0 }$ 值分别为 2270−2350 L $\mathbf { g } ^ { - 1 }$ 和 $\overline { { 1 2 1 0 - 1 3 0 0 ~ \mathrm { L ~ g } ^ { - 1 } } }$。相比之下，GAC F600 对所有 19 种 PFAS 均表现出快速穿透，无论 PFAS 链长或官能团如何，总体 $S _ { 1 0 }$ 值低且相似（[[全氟丁烷磺酸|PFBS]]：220−320 $\mathrm { ~ L ~ } \hat { \mathbf { g } } ^ { - 1 }$；[[全氟辛酸|PFOA]]：390−500 L $\mathbf { g } ^ { - 1 } ;$；GenX：390−500 L g<sup>−1</sup>），表明 PFAS 去除效率低且非特异性（图 3D、S25 和 S26）。与 GAC F600 相比，AER PSR2+ 表现出较晚的 PFAS 穿透，但也未能完全去除 19 种 PFAS，且 $S _ { 1 0 }$ 值普遍较低（PFBS：1760−1860 L $\cdot \mathbf { g } ^ { - 1 } .$；PFOA：1640−1660 $\mathrm { ~ L ~ } \ : \mathbf { g } ^ { - 1 }$；GenX：840-950 L $\mathbf { g } ^ { - 1 } )$），相对于[[整体柱|整体材料]]而言（图 3D、S27 和 S28）。然而，AER PSR2+ 在去除两种含四个碳原子的 PFAS——PFBA（图 3C）和 [[PFMBA]]（图 S20）方面优于 StyDex 整体材料，具有更高的 $S _ { 1 0 }$ 值（表 S19）和更大的表观穿透容量。在 StyDex 上观察到的 PFBA 陡峭穿透斜率表明快速的[[吸附]]动力学和高效的 PFAS 去除，直到系统接近平衡，出水浓度随后迅速上升（即快速穿透）。对于几种 PFAS，我们观察到[[竞争吸附]]，其中具有更大吸附亲和力的长链 PFAS 取代了短链 PFAS（图 S19 和 S20）。吸附竞争在 PFBA 和 PFMBA 的[[突破曲线|穿透曲线]]中很明显（图 3C 和 S20），其中出水浓度超过了进水浓度（C/ $\mathrm { C } _ { 0 } > 1 )$）。在这些条件下，AER PSR2+ 表现出有效的短链 PFAS 去除，但基于 PFOA 出水浓度高于 PFBA，对长链化合物则不然。尽管如此，在匹配材料间[[吸附剂]]质量时，StyDex 整体材料明显优于粉碎的 AER 和 GAC。我们通过在与等效流动条件下测试类似制备的 StyDex 整体材料（131 L，32 天，图 S29 和 S30），进一步确认了穿透的重现性。除 GenX 和 4:2 FTS 外，两种 StyDex 整体材料的穿透结果显示出高度相似的 ${ \check { S } } _ { 1 0 }$ 值（表 S19）和重叠的穿透曲线（图 S19 和 S20），表明吸附性能可重现。总之，这些结果表明，与 AER 和 GAC 相比，StyDex 整体材料具有质量效率高、每克吸附剂 PFAS 去除性能优越以及穿透更晚的特点。

对于固定直径且[[吸附剂]]质量相等的色谱柱，[[StyDex]] [[分层多孔整块材料|整体柱]]的 [[固定空床接触时间|EBCT]] 更长（7.9 s），相比之下 [[AER PSR2+]]（1.7 s）或 [[GAC F600]]（1.5 s）更短，这是由于[[整体柱]]密度低、因而[[床体积]]更大（床高 = 2.0 cm 对 0.4 cm）（表 S12−S14）。未选择基准材料的短 [[空床接触时间|EBCT]] 来模拟饮用水中 F600（10 min）或 PSR2+（3 min）所推荐的放大 EBCT。相反，研究它们是为了突出商业基准材料的局限性。[[颗粒活性炭|GAC]] F600 的性能通常受限于向[[微孔]]中的扩散，而 [[阴离子交换树脂|AER]] 则受限于[[表面扩散]]和材料利用效率低下 $( \mathrm { i . e . , }$ 许多[[吸附位点]]溶剂不可及）。本文实验中的低 EBCT 可能加剧这些限制。因此，我们还在等效 EBCT 下对三种[[吸附]]剂进行了基准测试。我们假设 [[苯乙烯官能化环糊精|StyDex]] 整体柱在较短 EBCT 下会优于更致密的颗粒基吸附剂 $\left( 1 . { \bar { 5 } } { - } 1 . 7 ~ s \right)$，因为整体柱中更短的扩散路径（<5 um。图 2B）使 PFAS 能够快速传质到吸附位点。为使不同吸附剂的 EBCT 相匹配，我们制备了床体积等于 AER PSR2+ 和 GAC F600 柱（约 0.0785 cm<sup>3</sup>）的整体柱，其中加入的 StyDex 质量为 11.5 mg（表 S12）。减质量整体柱在连续流 20 天、处理 84 L 水期间（图 S17）也保持了结构完整性和低[[背压]]（1−6 psi $/ \ 7 { \mathrm { - } } 4 0 \ \mathrm { k P a } )$）。尽管仅使用了 25% 的吸附剂质量且 EBCT 更短，较小的整体柱在比通量高达 3300 L $\dot { \mathbf { g } } ^ { - 1 } .$ 时完全去除了 11 种 [[全氟和多氟烷基物质|PFAS]]，表明其性能与较大的整体柱（47 mg，7.9 s EBCT）相当，后者在等效通量下完全去除 12 种 PFAS 且未[[穿透曲线|穿透]]（图 S19 和 S20）。我们将这一优异去除性能归因于整体柱互连结构使扩散阻力最小化，使其在等效 EBCT 下、即使吸附剂质量更少，也能在大多数 PFAS 上优于 AER PSR2+ 和 GAC F600。到本实验结束时，减质量 StyDex 整体柱完全去除了 6 种 PFAS 且未穿透 $( S _ { 1 0 } \mathrm { ~ > ~ }$ $7 3 0 \overset { \cdot } { 0 } \mathrm { L } \ : \mathrm { g } ^ { - 1 } )$ ），并且对剩余 PFAS 始终表现出更高的 $S _ { 1 0 }$ 值（[[全氟丁烷磺酸|PFBS]]：3470−3930 ${ \check { \mathrm { ~ L ~ g ~ } } } _ { 3 } ^ { - 1 } ;$ ：[[全氟辛酸|PFOA]]：5010- 5350 L $\check { \mathbf { g } } ^ { - 1 } ;$ [[GenX]]：430−840 L $\mathbf { g } ^ { - 1 } )$，与 AER 和 GAC 相比（表 S19，图 S31 和 S32）。我们通过在等效条件下测试另一根减质量整体柱（处理 69 L，17 天）（图 S33 和 S34）确认了穿透重现性，其再次表现出相似的[[突破曲线|穿透曲线]]（图 S19 和 S20）。综上所述，这些结果支持以下结论：StyDex 整体柱的[[互连孔网络|连续孔网络]]能够克服颗粒基吸附剂的[[传质]]限制，在流通柱实验中相比 AER 或 GAC 具有更优的吸附剂质量效率。

类似粉碎[[分层多孔整块材料|整体柱]]的 [[SEM]] 图像（图 S12）表明，这种流动不均匀性很可能源于这些空隙尺寸与其孔隙网络尺寸之间存在一个数量级的差异。因此，填充柱无法将进水溶液高效分配至小孔，从而无法充分接触 [[StyDex]] [[吸附位点]]，导致其突破早于完整[[整体柱]]。即使采用最佳填充，颗粒[[吸附剂]]本质上仍涉及颗粒间和颗粒内孔隙度的不同尺度，并因颗粒排列而表现出流动变化。[[苯乙烯官能化环糊精|StyDex]] 整体柱通过促进更均匀的水流穿过其[[互连孔网络|连续孔隙网络]]，从而更高效地利用其[[吸附]]位点，规避了这一瓶颈（关于 StyDex 整体柱中水传输及所提出的 [[全氟和多氟烷基物质|PFAS]] 吸附机制的更详细描述，见图 S41）。鉴于完整与粉碎 StyDex 整体柱之间观察到的明显 PFAS 突破仅源于形态差异，我们预计应用整体柱形态可增强具有多样化学性质的新兴吸附剂的吸附位点可及性。为分离孔结构对 PFAS 去除的影响，我们制备了一根填充粉碎（90−125 μm）StyDex 聚合物的柱，该聚合物在 [[DMF]] 中合成且不含 [[高内相乳液|HIPE]] 模板（无[[十六烷]]衍生[[大孔]]）。这根具有 StyDex 但缺乏大孔隙度的柱表现出与粉碎整体柱相当的 PFAS 突破 $\dot { (  { S _ { 1 0 } } ) }$（表 S19、图 S37 和 S38）。这一发现进一步表明，PFAS 去除效率受限于颗粒吸附剂中颗粒间空隙与颗粒内（$( \mathrm { i . e . , }$ [[介孔]]和[[微孔]]）孔隙度之间不连通的流动分布。综上，这些结果凸显了互连孔结构对于促进均匀且连通的流动并充分利用吸附位点的重要性。

可[[再生]]且可重复使用的[[吸附剂]]。[[StyDex]] [[分层多孔整块材料|整体柱]]可通过简单的醇洗溶液再生，并用于第二次[[穿透曲线|穿透]]循环，表现出相当的 [[全氟和多氟烷基物质|PFAS]] [[吸附]]和穿透性能。在处理 155 L 水 37 天后（图 4A），47 mg 的 [[苯乙烯官能化环糊精|StyDex]] [[整体柱]]保持了结构完整性以及相对较低的[[背压]]（<9 psi / <60 kPa），与 AER PSR2+（1−5 psi / 7−30 kPa）和 GAC F600（2−8 psi $\mathrm { / 7 - }$ 30 kPa）相当（图 S17A−C）。我们通过以 1 mL min<sup>−1</sup> 的流速泵送 100 mL 含 20 mM [[乙酸铵]]的 [[异丙醇|iPrOH]] 与水 70:30 v:v 溶液来冲洗整体柱，并收集十个馏分（每个 10 mL），对其进行分析以确定 PFAS [[质量回收率]]。再生后的整体柱在 39 天内处理 170 L 水的第二次穿透循环中进行了评估（图 4A、图 S39）。我们观察到所有 PFAS 的[[突破曲线|穿透曲线]]相互重叠，且 $S _ { 1 0 }$ 值相似（表 S19、图 S39 和 S40）。例如，第二次循环的 $S _ { 1 0 }$ 值（[[PFPeA]]：$2 0 4 0 { - } 2 1 4 0 {  { \mathrm { ~ L ~ g } } } ^ { - 1 } ; \qquad $ [[PFMBA]]：1950−2040 L $\mathbf { g } ^ { - 1 } \mathbf { j }$ [[NFDHA]]：2330−2430 L $\bar { \mathsf { g } } ^ { - 1 } )$ 与第一次循环测定的值（PFPeA：2060-2170 $\mathrm { ~ L ~ } \ : \mathrm { g } ^ { - 1 } ;$ ；PFMBA：1960−2060 ${ \textsc { L } } { \bar { \mathbf { g } } } ^ { - 1 } ;$ NFDHA $2 3 5 0 { - } 2 4 4 0 \ \mathrm { L } \ \mathrm { g } ^ { - \mathrm { \bar { 1 } } } )$（表 S19）密切一致，表明[[吸附位点]]有效再生且未破坏整体柱的完整性。到第二次穿透循环结束时，整体柱保持了结构和化学完整性（图 S13 和 S14）。然而，我们观察到背压从 9 逐渐增加到 20 psi（60 至 140 kPa），这归因于 76 天连续运行中可能的[[孔道堵塞]]或材料劣化（图 S17G）。我们按照类似程序再次再生整体柱，并取回真空干燥的材料用于运行后表征。基于 [[SEM]]，我们观察到整体孔道结构得以保留，平均孔径和孔喉直径（分别为 22.3 ± 11.8 μm 和 $2 . 2 \pm 1 . 1 \mu \mathrm { m } ,$）与流动测试前的整体柱一致（图 S14）。光谱表征（例如 [[固相核磁共振|ssNMR]] 和 [[傅里叶变换红外光谱|FT-IR]]）表明材料组成也保持一致，表明官能团和结合位点得以保留（图 [[S10值|S10]] 和 S13）。这些结果共同证明了该整体柱能够承受大体积水，并在至少两个月的连续使用中持续去除 PFAS。

我们通过在第一和第二[[穿透曲线|穿透]]循环后使用温和的 [[异丙醇|iPrOH]] 基[[再生]]溶液从[[分层多孔整块材料|整块材料]]上解吸，完成了大多数被捕获 [[全氟和多氟烷基物质|PFASs]] 的质量平衡（图 4B）。对三次不同再生实验的 PFAS 回收率取平均，我们发现 14 种 PFASs 的[[质量回收率]]可接受（>80%），但 5 种 PFASs 除外 $( { \mathrm { e . g . , ~ } } 6 0 . 2 ~ \pm ~ 6 . 3 \%$ 对于 [[全氟丁酸|PFBA]]）（表 S23）。长链 PFASs 和 [[全氟醚羧酸|PFECAs]] 的回收效率通常较低，因为再生溶液是针对含 4−8 个碳的 [[全氟羧酸|PFCAs]] 专门优化的。我们的结果表明，大多数 PFASs 在再生溶液最初的 10 mL 内被回收，相当于每克废[[整体柱|整块材料]] 0.222 L 再生溶液的具体处理量（或 25.5 [[床体积|BV]]，图 4C）。<sup>38</sup> 长链 PFASs 近乎完全的质量平衡支持了它们在柱实验过程中被完全去除且未观察到穿透。例如，任何 [[StyDex]] 整块材料均未观察到 [[全氟辛酸|PFOA]] 超过 10% 的穿透（图 3C 和 S19），并且基于进水浓度的预期 PFOA 质量的 $1 0 4 \pm 1 2 . 5 \%$ 被回收（表 S23）。此外，我们回收了因分析变异性而被排除在穿透分析之外的六种 PFASs，表明这些化合物存在并被整块材料去除（表 S24）。考虑到 [[颗粒活性炭|GAC]] 需要能源密集的[[热再生]]，而这可能将 PFAS 重新引入空气中，而 AERs 通常是一次性材料并在[[吸附剂]]耗尽后被填埋，因此能够轻松再生废[[吸附]]剂的能力相较于传统吸附剂极具吸引力。

## ■ 结论

迫切需要能够达到严格法规限值的 [[全氟和多氟烷基物质|PFAS]] [[饮用水处理|水处理]]技术。然而，当前领先的技术以及许多正在开发的技术，依赖于包含本质上质量效率低下的颗粒基[[吸附剂]]的去除过程。[[分层多孔整块材料|整块吸附剂]]在 PFAS 水处理方法上呈现出潜在的范式转变，并对其他水污染物具有启示意义。尽管[[整体柱|整块材料]]在空气污染控制和分析分离中已有多种应用，但据我们所知，这是首次报道展示机械稳健的整块[[吸附]]剂在仅使用毫克级吸附剂量的情况下处理大体积水（>300 L）的性能。我们表明，互连的孔网络促进了快速[[传质]]和均匀水流。直接在吸附柱内轻松合成整块材料使其 adaptable 于许多潜在应用，从使用点或进入点系统到工业规模水处理。未来的工作应解决大规模合成中乳液稳定性和聚合条件的优化问题，并调整多孔结构以实现低压应用（例如重力流）。通过精心的工程设计以优化适当的吸附剂尺寸，这种整块材料可以与预处理配合应用于修复具有挑战性的水基质。我们预计，随着我们共同推进 PFAS 修复工作，整块吸附剂将成为许多新兴吸附剂化学的有吸引力的形态。
