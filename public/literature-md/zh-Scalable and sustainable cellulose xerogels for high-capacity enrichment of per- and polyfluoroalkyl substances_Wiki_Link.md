## 摘要

[[长链全氟和多氟烷基物质]]（[[全氟和多氟烷基物质|PFAS]]）的逐步淘汰加速了替代性新兴 PFAS 的应用，由此带来了持久性长链残留物及其替代物在[[水处理]]过程中归趋不明的双重污染挑战。在此，我们开发了一种可规模化的闭环策略，制备用于去除 PFAS 的[[胺化纤维素干凝胶]]（[[CNPK复合干凝胶|CNPK]]）。[[CNPK干凝胶|CNPK]] 在 [[pH]] 3 条件下表现出优异的[[机械强度]]（1.96 MPa）和出色的 PFAS [[吸附容量]]（[[全氟-2,5-二甲基-3,6-二氧杂壬酸|HFPO-TrA]] 为 3.26 g<sup>−</sup> <sup>1</sup>、[[全氟辛酸|PFOA]] 为 1.82 g<sup>−</sup> <sup>1</sup>、[[全氟（2-甲基-3-氧杂己酸）|HFPO-DA]] 为 2.14 g<sup>−</sup> <sup>1</sup>、[[全氟己酸|PFHxA]] 为 1.27 g<sup>−</sup> <sup>1</sup>、[[全氟丁酸|PFBA]] 为 1.02 g<sup>−</sup> <sup>1</sup>，以及 [[五氟丙酸|PFPrA]] 为 1.01 g<sup>−</sup> <sup>1</sup>）。其[[吸附]]数倍于自身重量的 PFAS 的能力比传统[[吸附剂]]高出数个数量级。在多组分体系中，对[[短链及超短链PFAS|短链/超短链 PFAS]] 的[[吸附动力学]]加快且亲和力增强，促进了其近乎完全的去除。这是由于优先捕获的长链物质提供了额外的范德华（vdW）相互作用，从而加速了短链/超短链物质的吸附。经过连续五次循环后，CNPK 对六种 PFAS 的[[去除效率|去除率]]仍达到 82%-99%，且可经溶解后重新制备。概念验证[[过滤柱]]对短链/[[超短链全氟和多氟烷基物质|超短链 PFAS]] 的[[去除率]]超过 95%。[[生命周期评价]]（LCA）表明，与大多数[[碳基吸附剂]]相比，[[干凝胶]]具有更低的[[碳足迹]]（161.28–161.71 kg CO eq kg<sup>−</sup> <sup>1</sup> PFAS）。总体而言，该干凝胶策略遵循[[循环经济]]原则，通过高容量富集应对亟待解决的 PFAS 污染问题。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）是一类具有优异[[化学稳定性]]和[[双疏性|双疏特性]]的合成含氟有机化合物，已广泛应用于200多个工业领域（Yang et al., 2024; Evich et al., 2022; Xiao et al., 2023）。由于其[[环境持久性]]和[[生物累积性]]（Liang et al., 2024b; Lee et al., 2023），[[长链PFAS|长链 PFAS]] $( C ~ \geq ~ 6 )$，尤其是传统的[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸盐]]（PFOS），已被列入《[[关于持久性有机污染物的斯德哥尔摩公约]]》的限制清单。然而，[[含醚键全氟和多氟烷基物质|含醚键 PFAS]]、[[短链全氟和多氟烷基物质|短链 PFAS]] $( C < 6 )$ 和[[超短链全氟和多氟烷基物质|超短链 PFAS]] $( C < 4 )$ 等新兴替代物目前仍在使用，但可能带来相似或更高的[[环境风险]]（He et al., 2024; Wee and Aris, 2023; He et al., 2025）。例如，作为 PFOA 的替代物，[[全氟（2-甲基-3-氧杂己酸）]]（[[六氟环氧丙烷二聚体酸|HFPO-DA]]）对[[人肝细胞]]的健康风险与 PFOA 相似 $( \mathrm { I C } _ { 5 0 } ; 7 . 7 7 \times 1 0 ^ { - 4 }$ M），而[[全氟-2,5-二甲基-3,6-二氧杂壬酸]]（[[六氟环氧丙烷三聚体酸|HFPO-TrA]]）（IC<sub>50</sub>：$3 . 4 2 \times 1 0 ^ { - 4 } \mathrm { M } )$ 表现出更强的[[肝毒性]]和[[雌激素效应]]（Sheng et al., 2018）。在中国，氟化工生产和纺织加工等涉氟行业的工艺用水及处理后废水是 PFAS，尤其是 PFOA 及其替代物的主要来源，其浓度范围为 ng $\mathrm { L } ^ { - 1 }$ 至 mg $\mathrm { L } ^ { - 1 }$（Liang et al., 2025; Feng et al., 2023; Zhang et al., 2024）。因此，尽管限制措施可能涵盖更广泛的 PFAS（Jiang et al., 2024a），这些化合物在环境中的普遍存在及其固有毒性仍使高效去除技术的开发成为当务之急。

[[富集技术]]可能是去除废水中 [[全氟和多氟烷基物质|PFAS]] 或浓缩 PFAS 以进行后续有效处理的一种有前景的方法（Su et al., 2025; Li et al., 2020; Lin et al., 2023）。[[颗粒活性炭]]（GAC）、[[阴离子交换树脂]]（AER）、[[金属有机框架]]（MOF）和[[共价有机框架]]（COFs）等[[吸附剂|吸附材料]]已被用于有效去除废水中的 PFAS，但由于其生产过程成本高、不可持续，以及稳定性低、对[[短链全氟和多氟烷基物质|短链 PFAS]] 的[[吸附]]效果差，其大规模应用仍面临挑战（Sasi et al., 2021; Jiang et al., 2024b; Liang et al., 2024a）。为应对这些挑战，近年来研究人员一直致力于开发[[多孔吸附剂]]。例如，一种具有可调亲水–[[疏水相互作用]]、可高效吸附 [[全氟辛酸|PFOA]] 的[[胺化聚氨酯海绵]]，克服了[[粉末吸附剂]]普遍存在的吸附后难以分离的局限（Wang, et al., 2025）。[[全氟聚醚]]（PFPE）改性的[[聚苯乙烯离子交换剂]]在去除饮用水和[[垃圾填埋场渗滤液]]中的 PFAS 方面表现优异（Yang et al., 2024; Tan et al., 2022）。然而，目前缺乏对 PFPE 的长期环境稳定性评估及适当的使用寿命终结处理策略，这可能给法规遵从和生态可持续性带来挑战。因此，开发在[[吸附容量]]、[[吸附动力学]]、稳定性、规模化应用能力和[[可回收性]]方面均表现优异的可持续富集材料至关重要。

[[纤维素]]来源于储量最丰富的可再生资源——[[木质纤维素生物质]]，具有[[生物降解性|可生物降解性]]且富含[[官能团]]，是制备 [[全氟和多氟烷基物质|PFAS]] 富集材料的优良原料（Ilango et al., 2023; Ateia et al., 2018）。目前已开发出具有可调[[含氟活性位点]]的[[纤维素基含氟水凝胶]]。然而，这类材料无法兼顾短链和[[超短链全氟和多氟烷基物质|超短链 PFAS]] 的去除，且有限的[[吸附容量]]限制了其在复杂 PFAS 污染情景修复中的实际应用潜力（Huang et al., 2025）。由纤维素和[[木质素]]制成的[[气凝胶]]已被用作微生物载体，用于 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸盐|PFOS]] 的[[吸附]]与生物修复，吸附容量分别达到 3529 mg $\mathbf { g } ^ { - 1 }$ 和 4151 $\mathfrak { m g } \ \mathfrak { g } ^ { - 1 }$，达到平衡所需的时间分别为 30 h 和 45 h（Li et al., 2022）。然而，气凝胶的生产通常能耗较高（例如[[冷冻干燥]]或超临界 $\mathrm { C O } _ { 2 }$ 干燥），且存在[[机械稳定性]]低、对疏水性较弱及链长较短的 PFAS 吸附性能差等问题。

为解决这些局限，本研究报道了一种旨在增强 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的[[纤维素干凝胶|纤维素基干凝胶]]（[[CNPK复合干凝胶|CNPK]]），采用[[硅烷偶联剂]]（[[KH560硅烷偶联剂|KH560]]）和[[聚乙烯亚胺]]（PEI）进行[[交联]]。本研究的主要目标为：（1）通过可规模化的[[常压干燥]]合成 [[CNPK干凝胶|CNPK]]，以克服[[冷冻干燥]]或超临界 $\mathrm { C O _ { 2 } }$ 干燥等制备工艺能耗高的问题；（2）协同整合[[活性位点]]，包括 [[纳米原纤化纤维素|NFC]]/KH560 网络提供的疏水区域和 PEI 高密度[[胺基]]提供的强[[静电结合位点]]，从而对广泛种类的 PFAS 形成有效亲和力；（3）建立闭环策略，通过化学溶解和再生使用后的[[干凝胶]]，解决其使用寿命终结时的处置难题。总体而言，本研究合成了一种新型 PFAS 吸附干凝胶，系统评估了其性能，揭示了其内在机制，并验证了其适用性。

## 2. 材料与方法

## 2.1. 化学品与材料。

[[全氟-2,5-二甲基-3,6-二氧杂壬酸]]（[[六氟环氧丙烷三聚体酸|HFPO-TrA]]）、[[全氟辛酸]]（PFOA）、[[全氟（2-甲基-3-氧杂己酸）]]（[[六氟环氧丙烷二聚体酸|HFPO-DA]]）、[[全氟己酸]]（PFHxA）、[[全氟丁酸]]（PFBA）和[[五氟丙酸]]（[[全氟丙酸|PFPrA]]）购自 [[Aladdin]]。[[聚乙烯亚胺]]（M.N. 70,000，50 % 水溶液）购自 [[Macklin]]（HFPO-TrA、PFOA、HFPO-DA、PFHxA、PFBA 和 PFPrA 的 log $K _ { \mathrm { o w } }$ 值分别为 $5 . 5 5 ,$ 4.81、3.91、3.48、2.14 和 1.47）。其他试剂详见支持信息中的 Text S1，均按原样使用，未经进一步纯化。

## 2.2. [[干凝胶]]的制备

首先，将 2.5 wt % 的 [[纳米原纤化纤维素|NFC]] 溶液稀释至浓度为 1 wt %（总重量：10 $g ) .$ 随后，向[[纤维素]]溶液中加入特定量的[[交联剂]] [[KH560硅烷偶联剂|KH560]]（其与纤维素溶液的比例分别为 1 %、2 %、3 %、4 % 和 5 %），并充分混合。接着，向所得悬浮液中加入 1 g [[聚乙烯亚胺|PEI]]，相当于最终[[干凝胶]]中的 8.7 wt %，并使用搅拌器以 500 rpm 搅拌 10 min，使其均匀混合。该 PEI 用量可确保提供足够的[[胺基]]，并维持[[三维网络]]的结构完整性（Ilango et al., 2023）。随后，将混合物倒入模具中，在室温下静置 10 min，形成[[水凝胶]]。之后，将水凝胶在 -30 ◦C 下[[冷冻]] 1 h。随后，将冷冻前驱体浸入[[乙醇]]中，以完全置换其中的水分。最后，将样品在环境温度下风干，制得干凝胶。根据[[交联]]剂浓度的不同，将样品分别命名为 [[CNPK-1干凝胶|CNPK-1]]、[[CNPK-2干凝胶|CNPK-2]]、[[CNPK-3干凝胶|CNPK-3]]、[[CNPK-4干凝胶|CNPK-4]] 和 [[CNPK-5干凝胶|CNPK-5]]。对于大规模样品，采用相同比例对工艺参数进行放大。此外，分别在不添加 PEI 和 KH560 的条件下合成了 CNK 和 CNP 样品，其他所有实验参数均保持不变。

## 2.3. 批量[[吸附]]实验。

使用[[超纯水]]配制 [[全氟和多氟烷基物质|PFAS]] 实验溶液（500 mg/L），随后稀释至特定浓度，用于批量[[吸附]]实验。使用[[干凝胶]]去除六种 PFAS 的实验在[[聚丙烯]]锥形瓶中进行，环境温度为 25 ◦C，振荡器转速设为 180 rpm。通过不添加[[吸附剂]]的空白对照实验验证，实验体系中 PFAS 的[[回收率]]为 97 % 至 102 %，确保了初始浓度的准确性。在不同实验中，有针对性地调整 PFAS 浓度，以最有效地回答特定研究问题。例如，采用 50 mg/L 的浓度研究 [[pH]] 和[[交联剂]]含量的影响，采用 0.1–350 mg/L 的浓度范围进行[[吸附等温线]]建模，选择 100 µg/L 用于[[吸附动力学|动力学]]研究，并选择 1 mg/L 用于多次循环再生测试。具体而言，使用 1 M $\mathrm { H } _ { 2 } S 0 _ { 4 }$ 和 [[氢氧化钠|NaOH]] 溶液将 [[pH调节|pH 调节]]至 3 至 7 的范围，以考察 [[pH值|pH]] 的影响。通过连续五次循环的吸附/解吸实验评估再生情况。在投加量为 $\mathrm { \dot { \ g } L ^ { \mathrm { - 1 } } }$ <sup>1</sup>、PFAS 初始浓度为 1 mg $\mathrm { L } ^ { - 1 }$ 的条件下，评估干凝胶的再生性能。在典型操作中，吸附后将负载 PFAS 的 [[CNPK复合干凝胶|CNPK 干凝胶]]从水相中取出，随后浸入 50 mL [[甲醇|MeOH]] 中 6 h，之后通过旋转蒸发过程同时实现 PFAS 的浓缩和甲醇的[[回收利用]] $( 3 0 \ ^ { \circ } \mathrm { C } , \ 0 . 0 5$ atm）。这种闭环溶剂管理系统显著降低了规模化操作中的化学品消耗。最后，将再生后的干凝胶进一步用于下一次循环。批量实验的其他详细步骤见补充信息中的 Text S3。

[[吸附动力学|动力学]]研究在投加量为 $\boldsymbol { 1 } \ \mathbf { g } \ \mathbf { L } ^ { - 1 }$ 的条件下进行，以[[吸附]]浓度为 100 µg $\mathrm { L } ^ { - 1 }$ 的单一/多组分 [[全氟和多氟烷基物质|PFAS]]，并分别在 0、10、30、60 和 120 min 时采集上清液样品。需要注意的是，多组分 PFAS 体系中各 PFAS 的浓度相同。等温吸附实验进行 6 h，所用 PFAS 初始浓度范围分别为：[[全氟-2,5-二甲基-3,6-二氧杂壬酸|HFPO-TrA]] 为 0.1 至 350 mg $\mathrm { L } ^ { - 1 }$；[[全氟辛酸|PFOA]]、[[全氟（2-甲基-3-氧杂己酸）|HFPO-DA]] 和 [[全氟己酸|PFHxA]] 为 0.1 至 300 mg $\mathrm { L } ^ { - 1 }$；[[全氟丁酸|PFBA]] 和 [[五氟丙酸|PFPrA]] 为 0.1 至 200 mg $\mathrm { L } ^ { - 1 }$。吸附后水中 PFAS 的浓度采用 UPLC-MS/MS（ACQULITY UPLC I-Class PLUS/XevoTQ-S）测定。色谱和离子源的仪器参数见补充信息中的表 S1，多反应监测（MRM）离子对见表 S2。

不同实验时间下 [[全氟和多氟烷基物质|PFAS]] 的[[去除效率]]采用式 (1) 计算：

$$
\text{Removal} = \left(C _ {0} - C _ {e}\right) / C _ {0} \times 100 \%\tag{1}
$$

[[吸附容量]]采用式 (2) 确定：

$$
\mathrm{q} _ {e} = (C _ {0} - C _ {e}) V / m\tag{2}
$$

其中，${ \mathrm { C } } _ { 0 }$ 分别表示 [[全氟和多氟烷基物质|PFAS]] 的初始浓度和残余浓度（mg $\mathbf { L } ^ { - 1 } )$。V 表示[[吸附质]]溶液的体积（mL），m 表示[[吸附剂]]的质量（mg）。

[[全氟和多氟烷基物质|PFAS]] 的[[吸附动力学模型]]

采用[[准一级动力学模型|准一级]]（PFO）和[[准二级动力学模型|准二级]]（PSO）模型研究[[干凝胶]]对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附动力学]]。这两种动[[力学稳定性|力学]]模型分别由式 (3)、(4) 表示。

[[准一级动力学模型|准一级模型]]：

$$
\mathbf {q} _ {\mathrm{t}} = q _ {e} \left(1 - e ^ {- k _ {1} t}\right)\tag{3}
$$

[[准二级动力学模型|准二级模型]]：

$$
\mathrm{q} _ {\mathrm{t}} = t \left(k _ {2} q _ {e} ^ {2}\right) / \left(1 + k _ {2} q _ {e} t\right)\tag{4}
$$

其中，$\mathsf { q } _ { \mathrm { t } } \left( \mathbf { m } \mathbf { g } / \mathbf { g } \right)$ 表示时间 t（min）时的[[吸附容量]]。${ \mathsf { q } } _ { \mathrm { e } }$（mg ${ \mathbf g } ^ { - 1 } )$ 表示[[平衡吸附容量]]。k<sub>1</sub> $( \mathrm { m i n ^ { - 1 } } )$ 和 $\mathbf { k } _ { 2 } ( \mathbf { g } ( \mathbf { m } \mathbf { g } \cdot \mathbf { m } \mathbf { i n } ) ^ { - 1 } )$ 为两种[[吸附动力学|动力学]]模型的[[速率常数]]。

[[全氟和多氟烷基物质|PFAS]] 的[[吸附等温线模型]]采用 [[Langmuir吸附等温线模型|Langmuir]] 和 [[Freundlich吸附等温线模型|Freundlich 模型]]描述[[吸附等温线|吸附平衡等温线]]。这两种等温线模型分别由式 (5)、(6) 表示。

[[Langmuir吸附等温线模型|Langmuir 模型]]：

$$
\mathbf {q} _ {\mathrm{e}} = q _ {m} k _ {L} C _ {e} / (1 + C _ {e} k _ {L})\tag{5}
$$

[[Freundlich吸附等温线模型|Freundlich 模型]]：

$$
\mathrm {q_ {e}} = k _ {f} C _ {e} ^ {1 / n}\tag{6}
$$

[[无量纲分离因子]]：

$$
R _ {L} = 1 / \left(1 + k _ {L} C _ {0}\right)\tag{7}
$$

其中，${ \mathsf { q } } _ { \mathrm { e } }$（mg ${ \bf g } ^ { - 1 } )$ 和 ${ \bf q } _ { \mathrm { m } } ~ ( { \bf m } { \bf g } / { \bf \Lambda g } ^ { - 1 } )$ 分别表示[[平衡吸附容量]]和[[最大吸附容量]]。k $( \mathbf { L _ { \ m g } } ^ { - 1 } )$ 为 [[Langmuir吸附等温线常数|Langmuir 吸附等温线常数]]，k（（mg $g ^ { - 1 } ) /$ $( \mathrm { m g ~ L ^ { - 1 } } ) ^ { 1 / \mathrm { n } } )$ 和 n 为 [[Freundlich常数|Freundlich 常数]]，$\mathrm { C _ { e } }$（mg $\mathbf { P \Lambda L } ^ { - 1 } )$ 表示溶液中污染物的[[平衡浓度]]。$\mathrm { R _ { L } }$ 为[[无量纲分离因子|分离因子]]，其中 $\mathrm { R _ { L } } = 0$ 表示[[吸附]]不可逆；$0 < \mathrm { R _ { L } } < 1$ 表示有利于吸附，而 $\mathrm { R _ { L } }$ > 1 则表示相反的情况。

## 2.4. 连续流[[固定床吸附|固定床]]柱[[吸附]]实验

在两级[[固定床吸附|固定床]]柱实验中，采用[[颗粒活性炭]]（GAC）和 [[CNPK-4干凝胶|CNPK-4]] [[干凝胶]]作为[[吸附剂]]，每种 [[全氟和多氟烷基物质|PFAS]] 的浓度约为 100 µg $\mathrm { L } ^ { - 1 }$，以模拟[[垃圾填埋场渗滤液]]为基质，该基质结合先前研究中的参数设计（Yang et al., 2024）。向自来水中加入指定浓度的 PFAS、有机物和重金属盐。有关[[模拟废水]]的更多详细信息见支持信息表 S3。将各 2 g 的 GAC 和干凝胶装填至串联的固定床[[吸附]]柱（内径 15 mm）中，将添加了 PFAS 的模拟垃圾填埋场渗滤液泵入柱内，并在预定时间点（48、103、218、276、389、455、554 min）收集出水，用于分析 PFAS 浓度。其中，GAC 柱作为[[预处理]]单元，用于去除模拟垃圾填埋场渗滤液中的[[基质效应|复杂基质]]成分，从而使 [[CNPK复合干凝胶|CNPK]] 能够有效靶向 PFAS。离心后，采用以下方法分析上清液： HPLC-MS/MS.

## 3. 结果与讨论

## 3.1. [[干凝胶]]的合成与表征

如图 1a 所示，设计了一种可规模化的 [[CNPK复合干凝胶|CNPK 干凝胶]]合成方法，其制备过程包括[[均质]]、[[冷冻]]、[[溶剂置换]]和[[常压干燥]]。在均质过程中，[[纳米原纤化纤维素|NFC]]（基材）、[[聚乙烯亚胺|PEI]]（功能聚合物）和 [[KH560硅烷偶联剂|KH560]]（[[交联剂]]）[[自组装|自发组装]]形成[[水凝胶]]。PEI 与 KH560 之间的[[环氧-胺偶联反应|亲核环氧-胺偶联]]形成 [[β-氨基醇|β-氨基醇桥]]（Wang et al., 2022; Gao et al., 2024），而 KH560 [[水解]]产生的[[硅醇]]（Si[[羟基|−OH]]）与 [[纳米纤维化纤维素|NFC]] 连接，形成[[交联网络]]（Sun et al., 2017）。随后将水凝胶冷冻，以形成[[冰模板法|冰模板]][[大孔]]，之后进行溶剂置换和常压干燥。

对比 [[傅里叶变换红外光谱|FT-IR]] 分析（图 1b 和图 S2）揭示的 [[CNPK复合干凝胶|CNPK 复合材料]]光谱特征表明，三种组分之间成功发生了化学反应：(i) [[纳米原纤化纤维素|NFC]]（$( C \mathrm { ~ - ~ } O \mathrm { ~ - ~ } C$ 在 1023 $\mathrm { c m } ^ { - 1 } ) _ { \mathrm { : } }$ 处的[[伸缩振动]]），(ii) [[KH560硅烷偶联剂|KH560]]（Si−O−Si 在 1157 cm $^ { - 1 } )$ 处的[[不对称振动]]）以及 (iii) [[聚乙烯亚胺|PEI]]（N − H 在 1458 cm<sup>−</sup> <sup>1</sup> 处的[[变形振动]]）（Qi et al., 2023; Zhao et al., 2024; Hu et al., 2023）。$1 3 0 0 { - } 1 5 6 0 ~ \mathrm { c m } ^ { - 1 }$ 谱带的减弱以及 $9 0 2 ~ \mathrm { c m } ^ { - 1 }$ 处峰的展宽证实了 PEI 的[[胺基]]与 KH560 的[[环氧基团]]之间发生了[[亲核开环反应]]（Li et al., 2019）。此外，从局部放大区域可以观察到，随着 KH560 含量增加，NH [[弯曲振动]]强度降低。[[拉曼光谱分析|拉曼分析]]（图 1c）进一步证实了[[交联]]的发生，显示 PEI 的 CH [[剪式振动]] $( 1 3 0 1 ~ \mathrm { c m } ^ { - 1 } )$ 和 NH [[面内弯曲振动]]（1456 $\mathrm { c m } ^ { - 1 } )$ 的强度降低（Mustafa et al., 2022）。KH560 通常会[[水解]]形成[[硅醇|活性硅醇]]，后者与 [[纳米纤维化纤维素|NFC]] 的 [[羟基|−OH]] 和 PEI 的胺基形成[[共价键]]， 同时伴随[[自缩合]]，形成 [[硅氧硅键|Si−O−Si 桥键]]。随着 KH560 的[[质量浓度]]从 [[CNPK-1干凝胶|CNPK-1]] 中的 1 % 增加至 [[CNPK-5干凝胶|CNPK-5]] 中的 5 %，其[[低聚物|自缩合低聚物]]的形成增多，导致[[自限性交联|自限性交联结构]]更加明显，从而因[[空间位阻]]而降低 PEI 的引入效率。

此外，[[KH560硅烷偶联剂|KH560]] 的添加量对[[干凝胶]]的结构具有显著影响。当添加量较低时（[[CNPK-1干凝胶|CNPK-1]]），纵向和横向结构均出现明显塌陷（图 S3a,b）。高倍图像显示，孔道壁表面存在粗糙褶皱，表明 [[聚乙烯亚胺|PEI]] [[交联]]不足导致其与 [[纳米原纤化纤维素|NFC]] 的[[界面相容性]]较差，并在[[溶剂置换]]和[[常压干燥]]过程中发生[[孔壁塌陷]]。增加[[交联剂]]的添加量可使干凝胶形貌趋于更加均匀的状态，结构规整性和厚度均有所改善（[[CNPK-2干凝胶|CNPK-2]] 见图 S3c,d，[[CNPK-3干凝胶|CNPK-3]] 见图 S3e,f）。然而，当交联剂添加量较高时（[[CNPK-5干凝胶|CNPK-5]]），[[多孔网络]]出现结构破坏（图 S3g,h），这可能是由于过量 KH560 的[[硅醇|硅醇基团]]发生[[自缩合|竞争性自缩合]]所致（Liu et al., 2021; Chen et al., 2021; Wang et al., 2021）。[[CNPK-4干凝胶|CNPK-4]] 呈现出最理想的形貌（图 1d,e），并可加工为尺寸可调（图 1f）、低密度（图 S5）且轻质的干凝胶，能够承受自身重量 40 倍的载荷（图 S6）。

为评估[[吸附动力学]]，在单一和混合 [[全氟和多氟烷基物质|PFAS]] 体系中均开展了动[[力学稳定性|力学]]研究。该[[干凝胶]]在两种体系中对具有 $C \geq 6$ 的 PFAS 均表现出超快的捕获动力学，在 10 min 内实现超过 98 % 的[[去除效率]]（图 2e）。相比之下，短链/超短链化合物 $( C < 6 )$ 在单一体系中需要长达 120 min 的平衡时间，且[[去除率|去除效率]]降至 93.7 %（[[全氟丁酸|PFBA]]）和 86.0 %（[[五氟丙酸|PFPrA]]）（图 2f）。然而，在混合体系中，该干凝胶对 PFBA 和 [[全氟丙酸|PFPrA]] 的捕获表现显著改善，平衡时间缩短了 50 %，PFBA 和 PFPrA 的去除效率分别提高至 98.4 % 和 93.4 %。可以推测，[[吸附]]在干凝胶表面的 PFAS $( C \ge 6 )$ 在范德华（vdW）力 $( \mathbf { e . g . }$ [[疏水相互作用]]和 [[氟–氟相互作用|F⋅⋅⋅F 相互作用]]）的驱动下提供了新的锚定位点，呈现出自发的类胶束组织形式。而较短链的物种 $( C < 6 )$ 由于具有优异的[[扩散]]能力和有限的疏水性，保持单分散状态，这一点已由演示模式下 [[分子动力学模拟|MD 模拟]]的最后一步所证实（图 S17）。这种差异导致混合 PFAS 体系中的协同吸附行为，其中[[长链PFAS|长链 PFAS]] 与干凝胶的快速结合通过提高其氟含量改变了干凝胶的表面特性，随后通过疏水相互作用和 $\mathrm { F } { \cdot } { \cdot } \mathrm { \cdot } \mathrm { F }$ 相互作用促进短链/超短链化合物的捕获。近期一项研究也支持了这一独特的吸附阶段，该研究表明，vdW 力驱动的[[长链全氟和多氟烷基物质|长链 PFAS]] 聚集能够提供新的[[吸附位点]]（Jrad A. et al., 2024）。使用[[准一级动力学模型|准一级]]和[[准二级动力学模型|准二级]]方程进行的动力学分析（图 S18，表 S9）表明，上述机制在酸性条件下协同控制吸附过程（Li et al., 2022, 2023; Yin and Villagran, 2022）。

## 3.3. 多尺度机制研究

为验证 [[全氟和多氟烷基物质|PFAS]] 与[[干凝胶]]的结合，[[吸附]]后的 [[SEM]]-EDS 元素映射（图 S19）显示，F 元素均匀分布于整个干凝胶网络孔道中。这种均匀性直接证实了[[吸附位点]]（[[羟基]]、[[胺基|氨基]]和疏水微区）高度可接近的结构优势，并验证了[[分级各向异性孔结构]]能够促进 PFAS 的高效[[扩散]]与结合。利用 [[傅里叶变换红外光谱|FTIR 光谱]]开展的机理研究阐明了控制 PFAS 在 [[CNPK-4干凝胶|CNPK-4]] 上吸附的界面相互作用（图 3a）。3300 cm<sup>−</sup> <sup>1</sup> 处发生 39 $\mathrm { c m } ^ { - 1 }$ 的红移，以及 $1 4 5 8 ~ \mathrm { c m } ^ { - 1 }$ 处振动峰强度的减弱，证实弱酸性的 PFAS 可与干凝胶中的 $O - H$ 和 $N - H$ 相互作用（Liu et al., 2024a）。值得注意的是，PFAS 的 $\mathrm { C F _ { 3 } }$ 和 $\mathrm { C F _ { 2 } }$ 振动特征出现在 1202–1241 $\mathrm { c m } ^ { - 1 }$ 的光谱区域内（Kebria et al., 2023; Bentel et al., 2020）。此外，羧酸盐类 PFAS 的吸附使干凝胶的羧酸盐[[不对称振动]]峰向高波数方向移动至 $1 6 7 6 ~ \mathrm { { c m } ^ { - 1 } }$，且[[长链PFAS|长链 PFAS]] 的吸附使峰强度增强（Tan et al., 2023; Min et al., 2022）。

[[吸附]]后的高分辨率 N 1 s [[XPS]] 分峰分析（图 3b）显示，与氮相关的结合能发生明显变化。对应于 $- N = ,$ −NH 和 −NH<sub>2</sub> 基团的峰均向较低结合能方向移动，表明未[[质子化]]胺上的孤对电子与 [[全氟和多氟烷基物质|PFAS]] 分子上的缺电子区域发生配位，导致氮中心周围的电子密度重新分布（Guo et al., 2024）。此外，在 \~399.59 $\mathbf { e V } ,$ 处出现了归属于 − NH<sub>3</sub><sup>+</sup> 基团的新峰，表明伯胺易于接受质子（H<sup>+</sup>）而发生质子化，从而增强其与 PFAS 的静电结合（Ateia et al., 2018）。PFAS 吸附后，[[干凝胶]]中含氧[[官能团]]的结合能和峰面积显著变化（图 3c），其中氧原子充当电子供体，与 PFAS 的氟原子形成[[氢键]]。此外，其通过与 PFAS 的羧酸盐头基形成桥联，促进电荷辅助氢键（CAHB）的形成（Ilango et al., 2023）。

我们进一步基于 [[CNPK-4干凝胶|CNPK-4]] 的静电势（ESP）映射，确定[[干凝胶]]上不同位点的贡献。如图 3d 所示，蓝色区域反映电子密度较低的区域，代表有利于 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的亲电位点。相反，红色区域对应富电子区域，这些区域通过静电排斥抑制 PFAS 结合。灰白色区域表示电中性的表面区域，表明存在[[疏水相互作用]]位点（Ilango et al., 2024a）。为定量评估吸附作用力，我们在酸性条件下对单一 PFAS 进行 [[分子动力学模拟|MD 模拟]]，并对[[质子化]]的 −COOH 基团建模，以反映占主导地位的物种。图 3e 展示了 [[CNPK复合干凝胶|CNPK]] 与 PFAS 之间的[[界面能]]量特征，表明 vdW 相互作用是结合的主要驱动力，[[全氟-2,5-二甲基-3,6-二氧杂壬酸|HFPO-TrA]]、[[全氟辛酸|PFOA]]、[[全氟（2-甲基-3-氧杂己酸）|HFPO-DA]]、[[全氟己酸|PFHxA]]、[[全氟丁酸|PFBA]] 和 [[五氟丙酸|PFPrA]] 的计算能量分别为 $- 3 1 . 2 6 , \ : \ : - 2 1 . 6 2 , \ : \ : - 2 4 . 6 0 ,$ $- 2 3 . 4 2 , - 1 4 . 7 2$ 和 −12.28 kJ $\mathrm { m o l } ^ { - 1 }$。将 [[聚乙烯亚胺|PEI]] 整合到干凝胶骨架中引入了显著的库仑静电效应，其通过结合能进行量化，[[六氟环氧丙烷三聚体酸|HFPO-TrA]]、PFOA、[[六氟环氧丙烷二聚体酸|HFPO-DA]]、PFHxA、PFBA 和 [[全氟丙酸|PFPrA]] 的结合能分别为 $- 7 . 9 0 , \ - 8 . 9 6 , \ - 9 . 4 8 ,$ $- 9 . 4 8 , \ - 7 . 5 0 .$ 和 −4.78 kJ $\mathrm { m o l } ^ { - 1 }$。与[[长链PFAS|长链 PFAS]] 相比，PFBA 和 PFPrA 的 vdW 相互作用能较低，这是因为它们与干凝胶疏水微区（例如 [[KH560硅烷偶联剂|KH560]] 中的[[烷基链]]和 [[纳米原纤化纤维素|NFC]] 微晶）接触的表面积较小。库仑静电能的降低归因于局部负电荷密度强度较低，这是由于它们自身的疏水性使其无法在界面形成集中的类半胶束聚集体。它们在单溶质 MD 模拟中呈现的单分散状态证实了这一点（图 S17）。因此，[[库仑力]]和 vdW 力的减弱直接导致[[短链及超短链PFAS|短链/超短链 PFAS]] 的总结合能降低（表 S10）。

## 3.5. [[干凝胶]]的[[环境影响]]

采用[[从摇篮到大门]]的[[生命周期评价]]（LCA）来评估 [[CNPK复合干凝胶|CNPK 干凝胶]]生产的[[环境影响]]。评价框架涵盖[[纤维素]]原料获取、[[干凝胶]]合成、能源/材料投入整合以及[[废物管理]]等过程阶段。如图 5a、b 中的量化结果所示，生产 1 kg [[CNPK干凝胶|CNPK]] 干凝胶的[[全球变暖潜势]]（GWP）为 67.84 kg CO<sub>2</sub>eq $\mathrm { k g } ^ { - 1 } ,$，其中 [[聚乙烯亚胺|PEI]]（87.64 %）和[[热能消耗]]（9.98 %）是主要贡献因素。PEI 生产依赖[[石化原料]]和高能耗的[[聚合反应|聚合过程]]，对 GWP 及其他环境影响具有显著贡献（图 S25）。由于源自[[农业废弃物]]的纤维素固定了[[生物源碳]]，[[碳抵扣]]可抵消总体 GWP 值。由于我们的工艺能耗较低，该值远低于通过传统技术（[[冷冻干燥]]和超临界 $\mathrm { C O _ { 2 } }$ 干燥，56.0–454.0 kg $\mathbf { C O _ { 2 } e q } ~ \mathbf { k g } ^ { - 1 } )$）或其他[[常压干燥|常压工艺]] $( 5 6 . 3 - 1 4 1 . 0 \mathrm { k g } \mathrm { C O _ { 2 } e q } \mathrm { k g ^ { - 1 } } ) _ { \mathrm { \Omega } }$ 生产的其他[[生物基冷冻凝胶]]；这些工艺较高的 GWP 主要源于[[乙醇]]和[[甲醇]]等溶剂的消耗（García-Castrillo et al., 2024）。具体而言，与采用[[甲壳素]]/[[壳聚糖]][[冷冻凝胶]]去除 [[全氟和多氟烷基物质|PFAS]] 的研究相比，我们的干凝胶不仅在环境影响（GWP、[[淡水水生生态毒性潜势|FATEP]]、[[海洋水生生态毒性潜势|MATEP]]、[[陆地生态毒性潜势|TEP]]、[[光化学臭氧生成潜势|POCP]]、[[酸化潜势|AP]] 和 [[富营养化潜势|EP]]）方面具有优势，而且在[[抗压强度]]、[[孔隙率]]、[[吸附容量]]和[[吸附动力学|动力学]]等固有性能方面也具有优势（图 5c）。

此外，还评估了[[干凝胶]][[吸附]] 1 kg [[全氟和多氟烷基物质|PFAS]] 的 [[全球变暖潜势|GWP]]，此时纳入了用于 [[pH调节|pH 调节]] $\mathrm { ( H _ { 2 } S O _ { 4 } ) }$ 和[[中和反应|中和]] $\left( \operatorname { C a } ( \operatorname { O H } ) _ { 2 } \right)$ 的化学品投入，以及所产生[[固体废物处置|固体废物的处置]]（如文本 S6 所述）。将这一综合评估结果与其他常规[[碳基吸附剂]]进行了比较。对于长链 [[全氟辛酸|PFOA]]（图 5d），干凝胶的 GWP（133.2 kg CO eq $\mathbf { k } { \mathbf { g } } ^ { - 1 } \ { \mathsf { P F O A } } )$ 高于 [[颗粒活性炭|GAC]]（68.66 kg CO eq kg<sup>−</sup> <sup>1</sup> PFOA）和 [[粉末活性炭|PAC]]（67.38 kg $\mathrm { C O _ { 2 } e q } \ \mathrm { k g ^ { - 1 } }$ PFOA）。相比之下，干凝胶在[[短链及超短链PFAS|短链/超短链 PFAS]] 方面表现出显著优势，其 GWP 分别为 161.28 kg $\mathrm { C O _ { 2 } e q k g ^ { - 1 } }$ [[全氟丁酸|PFBA]]（图 5e）和 161.71 kg $\mathrm { C O _ { 2 } e q k g ^ { - 1 } }$ [[五氟丙酸|PFPrA]]（图 5f）。这些 GWP 显著低于大多数碳基[[吸附剂]]（108.28–2636.54 kg CO eq $\mathbf { k g } ^ { - 1 }$ PFAS），这是因为本研究干凝胶具有较高的[[吸附容量]]，大幅降低了每去除单位质量 PFAS 所需的吸附剂质量，从而抵消了化学品投入和[[废物管理|废物处理]]带来的影响。此外，在其他生命周期影响类别（[[化石资源消耗潜势|ADP（化石）]]、[[人体毒性潜势|HTP]]、[[淡水水生生态毒性潜势|FATEP]]、[[海洋水生生态毒性潜势|MATEP]]、[[陆地生态毒性潜势|TEP]]、[[光化学臭氧生成潜势|POCP]]、[[酸化潜势|AP]] 和 [[富营养化潜势|EP]]）中，干凝胶在处理 PFBA 和 [[全氟丙酸|PFPrA]] 时也表现出具有竞争力的环境绩效（表 S16–18）。

## 4. 结论

为应对日益严格的 [[全氟和多氟烷基物质|PFAS]] 使用和排放法规，本研究开发了一种可规模化的合成策略，在常温环境下制备[[胺化纤维素干凝胶]]，该[[干凝胶]]具有优异的[[结构稳定性]]（最大[[抗压强度]]为 1.96 MPa），并在 [[pH]] 3 条件下对六种 PFAS 表现出卓越的[[吸附容量]]（3.26 $\mathbf { g } ^ { - 1 }$

[[全氟-2,5-二甲基-3,6-二氧杂壬酸|HFPO-TrA]]，1.82 $\mathbf { g } ^ { - 1 }$ [[全氟辛酸|PFOA]]，2.14 $\mathbf { g } ^ { - 1 }$ [[全氟（2-甲基-3-氧杂己酸）|HFPO-DA]]，1.27 $\mathbf { g } ^ { - 1 }$ [[全氟己酸|PFHxA]]，1.02 $\mathbf { g } ^ { - 1 } \mathbf { \mathrm { P F B A } } \mathbf { a n d } \mathbf { 1 . 0 \bar { 1 } } \mathbf { g } ^ { - 1 } \mathbf { \mathrm { P F P r A } } )$，优于 [[颗粒活性炭|GAC]]、[[阴离子交换树脂|AER]] 和 [[金属有机框架|MOFs]] 等传统[[吸附剂]]。这归因于我们材料优异的[[传质|传质性能]]与丰富的[[吸附位点]]的共同作用。[[微米计算机断层扫描|Micro-CT]] 分析揭示了具有[[各向异性]]的[[分级孔结构]]，其[[孔隙连通率|连通率]]为 84.96 %，有利于 [[全氟和多氟烷基物质|PFAS]] 快速[[扩散]]，并确保其与[[吸附]]位点有效接触，从而避免传统吸附剂中的[[孔道堵塞]]问题。[[分子动力学模拟|MD 模拟]]表明，[[干凝胶]]与 PFAS 之间[[范德华力]]和[[库仑力]]的[[界面能]]贡献是吸附的主要驱动力。此外，我们的干凝胶具有优异的循环使用性能，在五次[[吸附再生|再生循环]]后仍保留其[[吸附容量]]的 82–99 %，并且可在使用寿命接近终点时重新制备。概念验证[[过滤柱]]表现出良好的富集效果，对短链/超短链物种的[[去除效率|去除率]]达到 >95 %。需要指出的是，我们的干凝胶的吸附性能显著受 [[pH]] 影响，在酸性条件下表现最佳。该干凝胶可直接用于含 PFAS 废水呈酸性的场景，例如[[酸蚀电镀]]行业，也可在调节 [[pH值|pH]] 后用于其他场景。尽管如此，在考虑用于 [[pH调节|pH 调节]]和[[中和反应|中和]]的化学品后，[[生命周期评价|LCA]] 量化得到的[[短链及超短链PFAS|短链/超短链 PFAS]] 富集过程的[[碳足迹]]为 161.28–161.71 kg CO eq kg<sup>−</sup> <sup>1</sup> PFAS。由于我们的干凝胶具有更高的吸附容量，这一数值显著低于大多数[[碳基吸附剂]]（108.28–2636.54 kg CO<sub>2</sub>eq kg<sup>−</sup> <sup>1</sup> PFAS）。总体而言，我们利用[[可再生原料]]，成功开发了一种可规模化的制备技术，实现了优异的 PFAS 富集效果。
