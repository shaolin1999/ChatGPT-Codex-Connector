# [[冰晶]]粒间[[氧化石墨烯纳米片]]对 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]的夹层包覆

收稿日期：2024 年 8 月 13 日

接受日期：2025 年 2 月 4 日

在线发表日期：2025 年 4 月 10 日

[[Youhua Lu]]<sup>1,2,3,9</sup>, [[Ye-Guang Fang]]<sup>4,9</sup>, [[Yang Chen]]<sup>5,9</sup>, [[Han Xue]]<sup>2,6</sup>, [[Junqiang Mao]]<sup>1,2</sup>, [[Bo Guan]] <sup>1,3</sup>, [[Jie Liu]] <sup>1,3</sup>, [[Jinping Li]] <sup>5</sup>, [[Libo Li]] <sup>5</sup> , [[Chongqin Zhu]] <sup>4</sup> , [[Wei-Hai Fang]] <sup>4</sup>, [[Thomas P. Russell]] <sup>6,7</sup> & [[Jianjun Wang]]<sup>1,2,3,8</sup>

目前，用于调控[[纳米颗粒团簇]]形成的策略，需要通过复杂的化学过程对[[纳米颗粒]]进行[[表面功能化]]，以赋予其特异性和方向性，而这些过程可能改变其性质。在此，我们介绍一种非破坏性方法，无需对组分进行任何预修饰，即可将不同形状的[[纳米材料]]置于[[纳米片]]之间，形成[[纳米三明治结构]]。我们通过将[[金属有机框架]]（MOFs）和[[二氧化硅|氧化硅]] $( \mathrm { { S i O } } _ { 2 } )$ 纳米颗粒夹在[[氧化石墨烯]]（GO）纳米片之间，分别形成 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] 和 [[二氧化硅-氧化石墨烯复合材料|SiO -GO]]，展示了这一方法。对于 [[金属有机框架与氧化石墨烯复合材料|MOF-GO]]，MOF 的[[电导率]]显著提高，即使在酸性或碱性水溶液中暴露一年后，仍能保持其原有[[结晶性]]；其中，GO 有效包封 MOF，使其免受[[极性分子]]和离子的影响。研究表明，MOF-GO 能够有效捕集高湿度[[烟气]]中的 CO，同时完全保持其结晶性和[[孔隙率]]。在其他 MOF 中也发现了类似行为，包括对水敏感的 [[HKUST-1]] 和 [[MOF-5]]，这推动了 MOF 在实际应用中的使用。这种纳米颗粒夹层策略为[[材料科学]]提供了机遇，可用于设计由不同材料和形状的纳米颗粒组成、且具有预定空间排列的纳米颗粒团簇。

由一种材料的层包裹另一种核心材料而形成的[[三明治结构]]见于多个学科。例如，[[魔角扭转三层石墨烯]]可产生[[超导性]]<sup>1</sup>，而 [[β-三明治蛋白质]]能够可靠地执行多种生物学功能<sup>2</sup>。鉴于将[[纳米材料]]构筑为[[纳米三明治结构|三明治结构]]所带来的性能提升，我们在此探究：将 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]夹在 [[氧化石墨烯纳米片|GO 纳米片]]之间，即形成 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]]，能否实现类似的性能提升，例如[[电导率]]和稳定性的提高；这些性能对于[[电催化]]或用作[[超级电容器]]而言十分理想<sup>3</sup>。目前已有超过 90,000 种[[金属有机框架]]，它们具有高[[BET|比表面积]]、可调[[孔隙率]]和功能性，由此涌现出[[气体储存]]<sup>4–6</sup>、[[分离技术|分离]]<sup>7–12</sup>、[[催化]]<sup>13–19</sup>和[[传感]]<sup>20–22</sup>等应用。然而，在不进行修饰的情况下，难以精确控制这些纳米尺度构筑单元的[[共组装]]<sup>23–26</sup>，这使 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的制备面临挑战。

在此，我们展示了一种非破坏性策略，可使[[纳米颗粒]][[共组装]]形成[[纳米三明治结构]]，而无需对构筑单元进行预修饰，其示意图见图 1a。引入一种基底，使其选择性结合一种组分（记为 F），从而使已结合组分 F 仅有背向基底的一侧可用于进一步组装。另一种组分（记为 C）通过特异性或非特异性相互作用（如[[静电相互作用]]、[[偶极-偶极相互作用|偶极–偶极相互作用]]、[[π堆积|π 堆积]]和[[疏水相互作用]]）选择性结合 F<sup>27</sup>。可依次引入组分 F 和 C 以实现这种选择性，从而在去除基底后仅获得纳米[[三明治结构]]。为验证我们的策略，我们选择冰作为基底，因为 [[氧化石墨烯|GO]] 可通过特异性吸引相互作用选择性结合[[冰界面|冰表面]]<sup>28</sup>，而且[[冰晶]]粒之间的空间可提供[[限域效应|限域环境]]<sup>29,30</sup>（补充图 1）。当然，共组装后可以很容易地去除冰。我们将这一过程称为[[限域冷冻组装]]。该策略极大地促进了不受特定分子配对或识别限制的[[纳米结构材料]]的制备，也可指导其他功能材料的开发。

## [[纳米三明治结构]]的表征

对 [[ZIF-8-GO复合材料|ZIF-8-GO]] [[纳米三明治结构]]进行[[超薄切片]]并开展[[透射电子显微镜]]（TEM）研究，结果表明，典型[[金属有机框架]]（MOF）材料 [[ZIF-8]] 的[[纳米颗粒]]可与 [[氧化石墨烯纳米片|GO 纳米片]]组装（图 1c）。为进一步确证 [[ZIF-8-氧化石墨烯复合材料|ZIF-8-GO]] 纳米[[三明治结构]]的纳米结构，我们使用 TEM 进行了[[电子断层成像]]（图 1d、补充图 3 和补充视频 1）。通过[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）

成像（图 1e、补充图 4）、[[共聚焦激光扫描显微镜]]（CLSM）和[[能量色散X射线光谱|能量色散谱]]（EDS）[[元素映射]]（补充图 5 和 6），证实了 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]与 [[氧化石墨烯纳米片|GO 纳米片]]组装形成独立的 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]。与之形成鲜明对比的是，未经控制的[[随机组装]]会导致 [[金属有机框架|MOF]] 和 [[氧化石墨烯|GO]] 不均匀聚集，这与参考文献 31 一致（图 1b、补充图 4g）。为验证该方法的普适性，我们选择了四种具有代表性的 MOF，即酸敏感的 [[ZIF-8]]、碱敏感的 [[UiO-66]]，以及水敏感的 [[HKUST-1]] 和 [[MOF-5]]，用于构建不同类型的 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] [[三明治结构]]（图 1f）。除 [[金属有机框架与氧化石墨烯复合材料|MOF-GO]] [[纳米三明治结构|三明治结构]]外，还制备了 ${ \mathsf { S i O } } _ { 2 } – { \mathbf { G } } \mathbf { O }$ 三明治结构，并通过 CLSM 予以验证（补充图 7b）。请注意，这些均匀的复合[[纳米颗粒]]以 [[ABAB堆叠|ABAB 型堆叠模式]]呈现不同的堆叠程度。通过调节浓度来改变所施加[[限域效应|限域空间]]的尺寸，可以控制堆叠程度（图 1g、补充图 7）。

如补充图 8 所示，在 $c _ { \mathrm { Z I F - 8 } } = 1 . 6 1 ~ \mathrm { p M } , ~ c _ { \mathrm { Z I F - 8 } } = 2 . 1 5 ~ \mathrm { p M } ,$ 或 $c _ { \mathrm { G O } } = 3 . 2 1$ pM 时，[[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治]]的 η 介于 ≈0.4 至 0.6 之间。与之形成鲜明对比的是，计算预测，如果 [[氧化石墨烯纳米片|GO 纳米片]]与 [[金属有机框架|MOF]] 颗粒[[随机组装]]，例如在体相溶液中组装，则[[产率]]和生产率几乎为零（补充说明 1）。[[金属有机框架-氧化石墨烯复合材料|GO-MOF]] 纳米三明治的高产率和高生产率表明，通过[[限域冷冻组装]]策略，可以使 [[氧化石墨烯|GO]] 与 MOF 精确组装成[[三明治结构]]。

请注意，在 $c _ { \mathrm { Z I F } \cdot 8 } = 1 . 6 1$ pM 和 $c _ { \mathrm { Z I F } \cdot 8 } = 2 . 1 5$ pM 时，[[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治]]的[[产率]]几乎相同（图 2c），表明产率存在与 $c _ { \mathrm { G O } } \mathsf { o r } c _ { \mathrm { M O F } }$ 无关的饱和现象。我们进一步研究了 γ = 2 时，具有不同[[冰界面|冰表面]]积的体系中 $c _ { \mathrm { M O F } }$ 与 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] 纳米三明治产率之间的关系（图 2d 插图，补充图 9）。我们发现，对于所有体系，[[金属有机框架与氧化石墨烯复合材料|MOF-GO]] 纳米三明治的产率均随 $c _ { \mathrm { M O F } }$ 的增加而逐渐趋于饱和。图 2d 展示了单位冰[[表面积]]上 [[金属有机框架|MOF]]-[[氧化石墨烯|GO]] 纳米三明治的产率随 ${ \bf \dot { \omega } } _ { c _ { \mathrm { M O F } } }$ 的变化。我们发现，无论冰表面积如何，单位面积（A）的产率与 $c _ { \mathrm { M O F } }$ 之间均存在一一对应关系，进一步验证了 MOF-GO 纳米三明治是在[[冰晶]]表面形成的。

为从分子层面深入了解 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治]]的形成机制，我们计算了 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]与不同[[氧化程度]]的 [[氧化石墨烯纳米片|GO 纳米片]]组装过程的[[自由能曲线]]（free energy profile，FEP）（图 2e，补充图 10e、f）。此处采用 [[ZIF-8]] 的 (100) [[晶面]]作为代表性表面，因为它是在溶液中主要暴露的晶面<sup>32,33</sup>。对于全部三条 FEP，随着 [[金属有机框架|MOF]] 表面与 [[氧化石墨烯|GO]] 之间距离的增大，[[自由能]]先降低，并在 3 至 6 Å 范围内出现极小值，表明无论氧化程度如何，GO 均优先与 MOF 表面结合。随后，自由能升高并达到平台，表明 GO [[纳米片]]在 [[沸石咪唑酯骨架-8|ZIF-8]] 表面上的组装在热力学上是有利的，且能够自发进行。对于 ZIF-8 (110) 晶面，也可观察到类似趋势（补充图 11a）。[[经典分子动力学模拟|经典分子动力学（MD）模拟]]进一步支持了 MOF [[纳米颗粒]]与 GO 纳米片的自发组装（补充图 11b）。当 GO 纳米片最初被置于距 MOF 纳米颗粒 ≈ 10.0 Å 的位置时，它逐渐被驱动向 MOF 纳米颗粒表面移动；在 ≈ 300 ns 后，GO 纳米片与 MOF 纳米颗粒表面紧密接触。

[[氧化石墨烯|GO]] 从 [[金属有机框架|MOF]] 表面迁移至体相水中的[[能垒]]可视为 MOF 与 GO 之间的[[解离能]]。在我们的 [[分子动力学模拟|MD 模拟]]中，MOF 和 GO 均呈电中性，这意味着 GO 与 MOF 之间的相互作用主要由两个因素驱动：（1）由 GO 和 MOF 表面[[极性]]引起的[[静电相互作用]]；（2）GO 与 MOF 之间的[[疏水相互作用]]。解离能越高，表明 MOF 与 GO 之间的相互作用越强。如图 2f 所示，随着 GO 的[[氧化程度]]从 24% 增加至 36%，再增加至 48%，解离能从 4.0 增加至 8.9，再增加至 11.0 kcal mol<sup>-1</sup>。氧化程度越高，GO 的[[亲水性]]越强；然而，[[金属有机框架-氧化石墨烯复合材料|MOF-GO]] 相互作用也随之增强，这表明 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]与 [[氧化石墨烯纳米片|GO 纳米片]]的结合由静电相互作用驱动。随着 GO 氧化程度的增加，其极性增强，从而增强了静电相互作用。此外，随着 GO 氧化程度的增加，GO 上的[[氧化官能团]]增多，使 GO 与 MOF 之间的[[平衡距离]]增大。这些模拟与实验结果相吻合，即随着氧化程度的增加，稳定性先升高后降低（补充图 10，补充说明 2），同时 GO 与 MOF 表面之间的结合相互作用增强、平衡距离增大，并产生更多[[晶体缺陷|缺陷]]。在 GO 氧化程度较低时，结合相互作用占主导地位，稳定性随 GO 氧化程度的增加而升高。相比之下，在 GO 氧化程度较高时，[[材料缺陷|缺陷]]增多，导致稳定性降低。除缺陷外，平衡距离可能是稳定性降低的另一个原因，因为随着间隔距离的增大，各种[[极性分子]]和离子可能[[吸附]]到 MOF 表面。

事实上，并非所有[[纳米颗粒]]都遵循相同的[[静电相互作用]]机制。具体而言，[[氧化石墨烯|GO]] 上的[[氧化官能团]]带负电，如果界面的最外层也带负电，排斥力可能会阻碍[[自组装]]。此时，需要适宜的 [[pH]] 来调节电荷，以实现组装（补充图 12）。对于 $\mathrm { S i O } _ { 2 } ,$，我们计算了其 (111) [[晶面]]上的[[电荷分布]]，选择该晶面是因为其[[表面能]]低且稳定性高。如补充图 12b 所示，最外层原子层由 36 个 Si 原子和 72 个 O 原子组成，[[Mulliken电荷|Mulliken 总电荷]]为 +1.09 e。鉴于 GO 表面的氧化基团主要带负电，$\mathrm { S i O } _ { 2 }$ 的 (111) 晶面与 GO 之间的静电相互作用能够促进[[纳米三明治结构]]的自组装（补充图 7b）。此外，为了解 GO 片层厚度对组装和稳定性的影响，我们制备了五种不同厚度的 [[氧化石墨烯纳米片|GO 纳米片]]，如补充图 13 所示。对于常规方法获得的厚度为 0.8–1.8 nm 的 GO 片层，其[[产率]]和酸处理后的 ${ \Nu } _ { 2 }$ [[吸附]]量均较高，表明其组装效率和稳定性得到提升。这可能是因为这些[[纳米片]]能够形成紧密接触并实现有效包覆。相比之下，超薄 GO 纳米片（小于 0.7 nm）的[[结构完整性]]较差，稳定性也较低。对于较厚的 GO 片层（大于 2 nm），[[刚性]]增大、[[柔性]]降低，阻碍了紧密包覆，削弱了对 [[金属有机框架|MOFs]] 的保护作用，从而降低了稳定性（补充图 13）。这些发现凸显了 GO 厚度在实现有效组装和稳定性方面的关键作用。

基于上述实验和 [[分子动力学模拟|MD 模拟]]结果，[[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的形成机制可描述如下：在[[限域冷冻组装]]过程中，[[冰晶]]晶粒之间的 [[氧化石墨烯纳米片|GO 纳米片]]和 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]浓度逐渐升高。[[氧化石墨烯|GO]] [[纳米片]]首先通过其上的 [[羟基|OH 基团]]与[[冰界面|冰表面]]氧原子之间的[[氢键]]结合到冰晶表面<sup>34,35</sup>。随后，[[金属有机框架|MOF]] [[纳米颗粒]]通过[[静电相互作用]]结合到 GO 表面。随着组装的进行，GO 纳米片的浓度进一步升高，另一片 GO 纳米片结合到冰表面 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] 组装体的表面，形成 [[金属有机框架与氧化石墨烯复合材料|MOF-GO]] [[纳米三明治结构]]，如 $\mathsf { F i g . }$ 2g 和补充视频 2 中的示意所示。通过限域冷冻组装策略在冰晶晶粒之间组装 MOF 和 GO 的独特之处在于，由于冰晶的[[晶格参数]]与 GO 表面 OH 基团的排列相匹配，冰[[表面能]]够[[选择性吸附]] GO 纳米片<sup>36</sup>。通过调节组装温度和纳米颗粒的初始浓度，可以控制[[限域效应|限域环境]]中 GO 和 MOF 纳米颗粒的浓度，$\mathbf { e . g . }$（补充图 9）。此外，在低温下，GO 和 MOF 纳米颗粒以及水在冰晶晶粒之间的[[扩散]]非常缓慢，因此可以有效控制组装过程<sup>36</sup>。因此，可以有效避免 MOF 纳米颗粒和 GO 纳米片在冰晶晶粒之间形成不期望的[[团聚体]]（补充图 4），而这在本体溶液中难以实现。

## 稳定性提高的分子机制

作为一种典型的 [[金属有机框架|MOF]] 材料，[[ZIF-8]] 由[[四面体配位]]的[[锌离子]]通过四个 [[2-甲基咪唑酸根]][[配体|连接体]]连接而成。[[沸石咪唑酯骨架-8|ZIF-8]] 具有优异的[[碱稳定性]]，但在酸性环境中不稳定<sup>37,38</sup>。采用针对 ${ \bf M O F S } ^ { 3 9 } ,$ 的公认常用测试条件，对 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的[[化学稳定性]]进行了测试。[[粉末X射线衍射|粉末 X 射线衍射]]（PXRD）图谱和 ${ \Nu } _ { 2 }$ [[吸附]]结果表明，即使在沸水中暴露超过 7 天，或在室温下于酸性水溶液（[[pH]] = 2）中浸泡超过一年，[[金属有机框架-氧化石墨烯复合材料|MOF-GO]] [[纳米三明治结构]]中的 MOF 仍能保持其[[结晶性]]和[[多孔结构]]（图 3a、b）。有趣的是，与未形成[[三明治结构]]的 ZIF-8 相比，新制备的 [[ZIF-8-GO复合材料|ZIF-8-GO]] 纳米三明治结构的 ${ \Nu } _ { 2 }$ 吸附量增加了 ≈ 13%（图 3b），这可能是由于 MOF 与 [[氧化石墨烯|GO]] 的界面处形成了[[介孔]]（补充图 14）。请注意，在体相溶液中通过[[物理混合]]得到的 ZIF-8 和 GO [[纳米复合材料]]，在酸性环境（pH = 2）中的稳定时间不足 7 天（补充图 4）。此外，GO 铠甲的保护还可显著增强其[[机械稳定性]]和[[热稳定性]]（补充图 15–17）。

## 增强的稳定性和[[电导率]]

采用简单的[[双接触法]]<sup>41</sup>在室温下测试材料的[[电导率]]。为降低[[接触电阻]]，以[[铜网|方形铜网]]作为[[掩膜]]，在紧密填充于绝缘 $\mathrm { S i O } _ { 2 }$ 模板凹槽中的 [[ZIF-8-GO复合材料|ZIF-8-GO]] 线材上沉积[[金电极]]（图 3h 和补充图 25）。

[[氧化石墨烯|GO]] 的[[电导率]]随[[氧化程度]]的不同而显著变化，氧化程度较低的 GO [[晶体缺陷|缺陷]]更少，电导率更高。还原后的 [[ZIF-8-GO复合材料|ZIF-8-GO]] [[纳米三明治结构]]的电导率比 [[ZIF-8]] 高 5–6 个数量级（图 3i）。导电的[[还原氧化石墨烯|还原 GO]] 与 [[金属有机框架|MOF]] 表面丰富的[[孔隙]]紧密耦合，提供了大量[[电子传输通道]]。通过调节氧化程度，可以在较宽范围内调控纳米[[三明治结构]]的[[电学性能]]，使其有望用作[[化学电阻式传感器]]、[[超级电容器]]或[[电池]]。此外，[[化学稳定性]]是[[电化学]]应用中的一个关键因素<sup>42</sup>。[[ZIF-8-氧化石墨烯复合材料|ZIF-8-GO]] 纳米三明治结构在苛刻条件下处理后仍具有稳定的电导率（图 3j）。

在评估 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]在[[气体储存]]、[[分离技术|分离]]、[[催化]]和[[化学传感]]等广泛应用中的潜力之前，除对酸敏感的 [[ZIF-8]] 外，我们还通过监测相应的 [[粉末X射线衍射|PXRD 图谱]]，评估了另外三种代表性 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] [[纳米三明治结构]]的[[化学稳定性]]，即对碱敏感的 [[UiO-66]]，以及对水敏感的 [[HKUST-1]] 和 [[MOF-5]] 与 [[氧化石墨烯纳米片|GO 纳米片]]形成[[三明治结构]]后的化学稳定性。在超过一年的暴露期间，未观察到 [[UiO-66-GO复合材料|UiO-66-GO]] 和 [[HKUST-1-GO复合材料|HKUST-1-GO]] 的[[结晶度]]损失（图 4a、b）。将 UiO-66-[[氧化石墨烯|GO]] 和 HKUST-1-GO 浸泡在酸/碱溶液或水溶液中超过一年后，其 $\Nu _ { 2 }$ [[吸附能力]]和[[结构完整性]]仍得以保持，进一步证实了 [[金属有机框架与氧化石墨烯复合材料|MOF-GO]] 的化学稳定性（图 4d、e）。此外，我们通过 PXRD 和[[气体吸附测量]]评估了 [[MOF-5-GO复合材料|MOF-5-GO]] 的[[水解稳定性]]。[[金属有机框架|MOF]]-5-GO 在 75% [[相对湿度]]（RH）下放置三个月后，其结晶度和[[孔隙率]]仍得以保持，表明其具有较高的化学稳定性（图 4c、f）。相比之下，原始 MOF 在相同的苛刻环境下发生了分解（补充图 26、27）。上述结果证实，MOF-GO 纳米三明治结构能够同时在酸、碱和水环境中保持稳定。

## 讨论

综上所述，我们提出了一种[[自引导组装|自引导方法]]，可将不同形状的[[纳米材料]]夹在[[氧化石墨烯纳米片]]之间，而无需对纳米材料进行任何会改变其性质的[[表面修饰]]。这种[[三明治结构]]能够显著提升[[电导率|导电性]]和稳定性等性能，而这些性能对于 [[金属有机框架|MOF]] 等[[纳米颗粒]]而言尤为重要。与传统的完全包封策略相比，三明治策略能够改善纳米颗粒的性能，同时仍可有效发挥纳米颗粒本身的优势。纳米颗粒三明治策略为[[材料科学]]设计具有预定空间排列、由不同材料和形状的纳米颗粒组成的[[纳米颗粒团簇|团簇]]开辟了可能性。

## 方法

## 尺寸可控的 [[氧化石墨烯|GO]] 的制备

采用[[改良Hummers法|改良 Hummers 法]]<sup>44</sup>制备的 [[氧化石墨烯|GO]] [[水分散液]]（纯度 > 95%，[[横向尺寸]]为 0.1–3 μm）购自 [[Nanjing XFNANO Materials Tech Co., Ltd.]]，其[[尺寸分布]]较宽。通过[[分级离心]]，将尺寸分布较宽的 GO [[分散液]]分成多个具有特定尺寸的组分。首先，使用[[离心机]]（[[GL-20-2离心机|GL-20-2]]）在 $1 0 ^ { \circ } \mathrm { C }$ 下以 1765.1 ×g 将 GO 分散液[[离心]] 30 min，使溶液分为[[上清液]]和沉淀，以去除碳杂质。将上清液再次以 6283.2 × 离心 10 min；随后，将第二轮离心得到的上清液依次以 7013.6、10812.6、15109.4、21333.1 和 28220.7 × 各离心 10 min。为测量 [[氧化石墨烯纳米片|GO 纳米片]]的横向尺寸，将 GO 液滴滴加到[[硅片]]上并风干。通过在 [[原子力显微镜|AFM]] 图像中对每个样品的 500 片以上[[纳米片]]进行统计，获得 GO 的横向尺寸分布（补充图 1）。将以 28220.7 × 分级得到的上清液以 10812.6 × 离心 10 min，以收集沉淀（补充图 2）。如果所得 GO 的[[尺寸均一性]]不理想，可重复上述步骤以获得尺寸均一的 GO。适当的 GO 初始浓度可提高[[分离技术|分离]]效率（例如，0.1 mg mL<sup>-1</sup>）。

上述方法适用于尺寸大于 400 nm 的 [[氧化石墨烯|GO]] 片。对于尺寸较小的 GO（100 和 200 nm），我们分别使用[[截留孔径]]为 0.1 µm 和 0.22 µm 的 [[Ultracel微滤膜|Ultracel 微滤膜]]对商用 GO 进行[[过滤]]。将所得 GO 组分浸于水中，并在 4 °C 下储存以防止[[聚并]]。

## [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的制备

通过调控[[配体]]和[[表面活性剂]]的用量，制备了不同尺寸的 [[金属有机框架|MOF]]（[[ZIF-8]]，纯度 > 95%）[[纳米颗粒]]（补充图 1）<sup>45</sup>。随后将 MOF 与 [[氧化石墨烯|GO]] 进行组装。GO 片的平均尺寸约为 MOF 颗粒的 1.2 倍（补充图 1）。将 GO 和 MOF（[[沸石咪唑酯骨架-8|ZIF-8]]、[[UiO-66]]、[[HKUST-1]] 和 [[MOF-5]]）[[分散液]]（0.1 mg mL<sup>-1</sup>）的小液滴按 9:1 的体积比，从 1.5 m 高处交替滴加到超冷基底（在[[液氮]]中冷却）上，通过[[骤冷]]形成细小的[[多晶冰晶]]，随后将[[冰晶]]在较高温度 $( \mathrm { e . g . } , - 2 0 ^ { \circ } \mathrm { C } )$ 下[[退火]] 2 h。对于批量制备，将 [[氧化石墨烯纳米片|GO 纳米片]]和 [[金属有机框架纳米颗粒|MOF 纳米颗粒]]的溶液快速骤冷，以生成细小的多晶冰晶。在液氮温度下骤冷时，会发生冰的[[异相成核]]，从而产生大量细小冰晶<sup>46</sup>。在退火过程中，随着[[晶粒生长|冰晶晶粒的生长]]，冰晶之间的纳米颗粒浓度升高。在[[限域冷冻组装]]之前，尽可能保护对水分敏感的 MOF，避免其暴露于水和空气中。随后，使用[[冷冻干燥机]]（[[LGJ-10E冷冻干燥机|LGJ-10E]]）通过[[冷冻干燥]]去除冰，获得 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]。

## 不同[[氧化程度]]的 [[氧化石墨烯|GO]] 和 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的制备

不同[[氧化程度]]的[[氧化石墨烯]]均基于[[改良Hummers法|改进的 Hummers 法]]制备<sup>44</sup>。通过在各次制备过程中调整[[氧化剂]] ${ \mathsf { K M n O } } _ { 4 }$ 的用量和氧化时间，获得了四种氧化程度不同、氧含量范围尽可能宽的 GO 样品，分别标记为 GO1-4。氧化石墨烯含有[[羟基]]、[[羧基]]和[[环氧基]]等多种官能团<sup>47</sup>。新制备的氧化石墨烯尺寸不均一，且尺寸较小的氧化石墨烯具有较高的氧化程度<sup>48</sup>。因此，通过[[分级离心]]收集尺寸相对均一的 GO，用于后续实验。详细制备条件列于补充表 3。按照上述 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的制备方法，制备了具有不同氧化程度的 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] [[纳米三明治结构]]（补充图 10）。

## 不同 [[氧化石墨烯|GO]] 片层厚度的 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的制备

为了解 [[氧化石墨烯|GO]] 片层厚度对组装和稳定性的影响，我们制备了五种厚度不同的 [[氧化石墨烯纳米片|GO 纳米片]]，如补充图 13 所示。在制得不同厚度的 GO 后<sup>49</sup>，我们采用前述[[温控分级离心法]]，将其分选为尺寸相近的样品，具体方法详见上述尺寸可控 GO 的制备部分。该图中的 [[原子力显微镜|AFM]] 图像清楚地显示了厚度差异（补充图 13）。

## [[荧光标记|FITC 标记]]的聚乙二醇化 [[氧化石墨烯纳米片|GO 纳米片]]的制备

通过与聚乙二醇胺（PEG）形成共价键，对采用上述方法获得的尺寸均一（≈ 500 和 1000 nm）的 [[氧化石墨烯纳米片|GO 纳米片]]悬浮液进行功能化，以减少聚集。随后，使用可与胺基反应的染料异硫氰酸荧光素（[[异硫氰酸荧光素|FITC]]）对 PEG-[[氧化石墨烯|GO]] [[纳米片]]进行共价标记，以指示 [[金属有机框架|MOF]] 与 ${ \mathsf { G } } { \mathsf { O } } ^ { 5 0 }$ 的不同组装阶段。

## [[罗丹明B|罗丹明 B]] 染色的 [[UiO-66]] 的制备

采用常规浸渍法包封[[罗丹明B|罗丹明 B]]（RhB，≥98.0%）：将 [[UiO-66]]（纯度 > 95%）粉末（5 mg）浸入 RhB 水溶液（5 ppm，5 mL）中，在 $3 7 ^ { \circ } \mathrm { C }$ 下于振荡器中振荡 24 h。随后，将产物冷却至室温 $( 2 5 ^ { \circ } \mathrm { C } ) ,$，用去离子水超声洗涤三次，再进行[[过滤]]，直至滤液无色，以确保未包封的 RhB 被完全去除。最后，将产物 RhB-UiO-66 在 $8 0 ^ { \circ } \mathrm { C }$ 下真空干燥，得到红色粉末。

二维图像采集。使用在 200 kV 下运行的 Themis 300 [[透射电子显微镜]]（Thermo Fisher Scientific）进行成像。该配置实现了 22,500× 的放大倍数，每张显微图像的像素尺寸为 0.4493 Å。使用 Ceta S 相机，通过 Tomography 软件（Thermo Fisher Scientific），以 1° 的增量从 $- 7 0 ^ { \circ }$ 至 $+ 6 3 ^ { \circ }$ 自动采集倾转序列，离焦量保持为 $\approx - 3 . 0 \mu \mathrm { m }$，并使用从 $\boldsymbol { - 6 3 ^ { \circ } }$ 至 $+ 6 3 ^ { \circ }$、增量为 $1 ^ { \circ }$ 的倾转图像进行重建（见补充图 3）。从对齐后的图像序列和补充视频 3 中，可以观察到 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治]]位于两层 [[氧化石墨烯|GO]] 片层之间。

[[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治]]的[[电子断层成像]]。为进一步分析其结构，我们使用 IMOD 中的反投影（Back Projection，BP）算法对 [[金属有机框架-氧化石墨烯复合材料|MOF-GO]] 纳米三明治进行了电子断层重建。所得 BP 断层重建图像（见补充视频 4）和横截面切片（补充图 3b）清晰地显示出 [[金属有机框架|MOF]] 被 [[氧化石墨烯|GO]] 层包覆。使用 Amira 软件，我们进行了分割并增强了可视化效果，生成了 GO 片层覆盖 MOF 的详细图像，如补充图 3c 和补充视频 1 所示。

[[限域冷冻组装]]过程的观察。使用反应物分布的[[共聚焦激光扫描显微镜]]（CLSM）图像表征组装前后的状态。采用 CLSM（Olympus FV1000），在激发波长为 488 nm、发射波长为 568 nm 的条件下进行成像。由于镜头与冷冻台（Linkam LTS420）内样品之间的距离超过了倒置荧光显微镜的焦距，因此通过向由泡沫层隔热的铜腔中注入[[液氮]]，构建了一个恒温装置。将载有冷冻液滴的载玻片固定在该装置底部，并使用激光共聚焦显微镜进行观察。通过调节隔热层的厚度，将样品温度控制在 -40 至 $- 2 0 { } ^ { \circ } \mathrm { C }$ 之间。

将 90% v/v 的 [[异硫氰酸荧光素|FITC]]-PEG-[[氧化石墨烯|GO]] 水溶液和 10% v/v 的 RhB-[[UiO-66]] [[乙醇]]溶液的小液滴，从 1.5 m 高处交替滴落到经[[液氮]]冷却的载玻片上，以生成小[[冰晶]]。随后将该样品转移至恒温装置中，使用[[共聚焦激光扫描显微镜]]观察组装前 FITC-PEG-GO 和 RhB-UiO-66 的分布。此外，将在液氮中[[骤冷|淬冷]]的液滴置于冷冻台（Linkam LTS420）中，在 $- 2 0 { } ^ { \circ } \mathrm { C }$ 下[[退火]] 45 min。采用相同的流程观察组装后的样品。

[[ZIF-8-GO复合材料|ZIF-8-GO]] 材料的[[产率]]计算。使用[[离心机]]，以 1081.3 × [[离心]] 10 min，重复三次，在水中去除多余的 [[氧化石墨烯|GO]]。用稀盐酸（[[pH]] = 2）多次洗涤未包覆的 [[ZIF-8]]，随后使用[[微滤膜]]将其滤除。然后计算新获得的 [[ZIF-8-氧化石墨烯复合材料|ZIF-8-GO]] 纳米三明治的产率。

[[金属有机框架|MOF]] 和 [[氧化石墨烯|GO]] [[摩尔浓度]]的估算。根据 MOF 的[[质量浓度]]和[[摩尔质量]]估算 MOF（[[ZIF-8]]）[[分散液]]的摩尔浓度。首先，基于此前广泛认可的 [[沸石咪唑酯骨架-8|ZIF-8]] 结构模型估算不同尺寸 ZIF-8 的[[分子量]]；即，其结构式 $\mathrm { C _ { 1 3 4 4 } H _ { 6 7 2 } N _ { 6 7 2 } Z n _ { 1 9 2 } }$ 其中，ZIF-8 [[立方晶胞]]的分子量为 38787.072 g mol<sup>-1</sup>，各方向的尺寸均为 61.964 Å<sup>51</sup>。因此，单位体积的 ZIF-8 [[纳米颗粒]]的摩尔质量 $M _ { Z \ I F \cdot 8 , V }$ 计算为 $M _ { \mathrm { Z I F cdot 8 , } V } { = } M [ Z \mathrm { I F } { \cdot } \mathrm { 8 }$ 模型]/V[ZIF-8 模型]。这里，M[ZIF-8 模型] 和 V[ZIF-8 模型] 分别为摩尔质量和体积（单位为 nm3），对应于 $\mathrm { C _ { 1 3 4 4 } H _ { 6 7 2 } N _ { 6 7 2 } Z n _ { 1 9 2 } } ,$ 分别为。如 [[扫描电子显微成像|SEM 成像]]所示，尺寸为 500 nm 的 ZIF-8 的形状近似球形。具有一定平均尺寸的 ZIF-8 的平均摩尔质量 $M _ { \mathrm { Z I F } \cdot 8 , D }$ 随后采用以下方法计算 $M _ { Z { \mid } \mathbb { F } \cdot 8 , D } { = } 4 \pi / 3 \times ( D / 2 ) 3 \times \mathsf { M } _ { Z { \mid } \mathbb { F } \cdot 8 , \nu \cdot } L$ D 为根据 [[SEM]] 图像测得的 ZIF-8 的平均尺寸（补充图 1）。基于平均摩尔质量，摩尔浓度为 对已知质量浓度的 ZIF-8 [[水分散液]]进行了估算。

[[原子力显微镜纳米压痕|AFM 纳米压痕测试]]。采用 [[原子力显微镜|AFM]]（[[MFP-3D-SA原子力显微镜|MFP-3D-SA]], [[Asylum Research|Asylum]]），使用[[弹簧常数]]为 200 N m<sup>−1</sup> 的[[掺锑硅探针|掺锑 Si 探针]]（[[RTESPA-525探针|RTESPA-525]]）测定材料的[[杨氏模量]]。在恒定力下对颗粒进行[[压痕测试]]。[[标准差]]由 100 次压痕实验计算得出。深度低于 50 nm 时的模量值可忽略，因为该范围内较大的数据离散性是由压头尖端与样品表面接触不完善所致<sup>52</sup>。因此，仅考虑深度大于 50 nm 的压痕。采用[[赫兹接触力学|赫兹力学]]分析[[力–位移曲线]]。代表性力曲线见补充图 15。

$\mathbf { c o } _ { 2 } / \mathbf { N } _ { 2 }$ [[穿透实验]]。在自制装置中，于 298 K、1 bar 和 75% [[相对湿度|RH]] 条件下进行湿润条件下的 $\mathbf { C O } _ { 2 } / \mathbf { N } _ { 2 }$ [[分离技术|分离]]穿透实验。所有样品均在 3 MPa 下[[压实]]后进行[[破碎]]和[[造粒]]，并通过[[筛分]]获得[[粒径]]为 40–60 目的小颗粒。样品在[[高真空]] $( 1 0 ^ { - 6 }$ bar）下，于 393 K（[[ZIF-8-GO复合材料|ZIF-8-GO]]、[[UiO-66-GO复合材料|UiO-66-GO]]、[[HKUST-1-GO复合材料|HKUST-1-GO]]）或 473 K（[[MOF-5-GO复合材料|MOF-5-GO]]）[[材料活化|活化]] 6 h。将活化后的 [[ZIF-8-氧化石墨烯复合材料|ZIF-8-GO]]（0.63 g）、[[UiO-66]]-[[氧化石墨烯|GO]]（0.71 g）、[[MOF-5]]-GO（0.73 g）或 [[HKUST-1]]-GO（0.67 g）颗粒装入不锈钢柱（内部尺寸为 4 mm × 75 mm）。测试前，在 353 K 下，以 100 mL min<sup>-1</sup> 的流量用 [[氩|Ar]] 气[[气体吹扫|吹扫]][[色谱柱]] 1 h。随后，在 75% RH 条件下，以 10 mL min<sup>-1</sup> 的流量（298 K，1.01 bar）进行 $\mathbf { C O } _ { 2 } / \mathbf { N } _ { 2 }$（15/85，v/v）混合物的[[气体分离|分离]]实验。采用配备[[热导检测器]]的[[气相色谱仪]]（[[Agilent 490 Micro GC|Agilent-490 Micro GC]]）监测流出气体。对于循环次数达到或超过 100 次的实验， 每隔 5 或 10 个循环采集一次分离数据。每次循环实验前，均在室温下以 100 mL min<sup>-1</sup> 的流速向柱内通入 Ar 气体 30 min，使[[柱再生]]。

表征。使用配备 [[电荷耦合器件|CCD]]（[[DS-Ri2显微相机|DS-Ri2]]）的 [[Nikon eclipse LVDIA-N显微镜|Nikon eclipse LVDIA-N]] 显微镜拍摄数字照片。使用 [[X射线衍射仪|X 射线衍射仪]]（[[PANalytical]]，荷兰），以 $5 ^ { \circ } \mathsf { m i n } ^ { - 1 }$ 的扫描速度，在 3 至 50°（2θ）的角度范围内记录 [[粉末X射线衍射|PXRD]] 数据，所用 Cu $\mathsf { K } _ { \alpha }$ 辐射的波长为 λ = 1.54056 Å。使用 [[Hitachi S-4800场发射扫描电子显微镜|Hitachi S-4800]] [[场发射扫描电子显微镜|场发射 SEM]] 仪器，在 5 kV 下观察形貌图像。在 [[JEM-2100F电子显微镜|JEM-2100F]] 电子显微镜上，以 200 kV 的[[加速电压]]采集 [[高分辨透射电子显微镜|HRTEM]] 图像及相应的 [[能量色散X射线谱|EDX]] [[元素分布图]]。制备 [[ZIF-8-GO复合材料|ZIF-8-GO]] [[超薄切片]]以采集 HRTEM 图像。通过[[动态光散射]]（DLS，[[Zetasizer Nano ZS|Zetasizer nano ZS]]）测量[[纳米颗粒]]的[[粒径分布]]，以评估改性前后的[[粒径|平均粒径]]。将 [[ZIF-8-氧化石墨烯复合材料|ZIF-8-GO]] 粉末（≈ 10 mg）用[[树脂包埋|树脂预包埋]] 24 h，形成[[复合材料]]。使用配备[[金刚石刀]]的 Leica EM [[超薄切片机]]（[[Leica EM UC7超薄切片机|Leica EM UC7]]），从该复合材料中切取厚度为 20–50 nm 的 [[ZIF-8]]-[[氧化石墨烯|GO]] 薄片。随后将薄片转移至[[铜网]]上进行 HRTEM 观察。使用 [[UV-2800S光谱仪|UV-2800S]] 光谱仪测量 [[紫外-可见光谱|UV-vis 光谱]]。使用 [[原子力显微镜|AFM]]（[[Multimode 8原子力显微镜|Multimode 8]]，[[Bruker]]）研究 GO 的形貌和尺寸。通过[[冷冻干燥]]（[[LGJ-10E冷冻干燥机|LGJ-10E]]）去除水或[[乙醇]]。使用[[两点探针台]]（[[4200A-SCS半导体参数分析仪|4200A-SCS]]）测试 [[金属有机框架与氧化石墨烯纳米三明治结构|MOF-GO 纳米三明治结构]]的[[电导率]]。[[离心分级|通过离心对 GO 进行分级]]。使用[[离心机]]（[[GL-20-2离心机|GL-20-2]]）对 GO [[分散液]]进行[[离心]]。采用 [[BET比表面积分析法|Brunauer-Emmett-Teller]]（[[BET]]）法，根据 77 K 下的 N [[吸附–脱附等温线]]（[[Quantachrome NOVA-3000比表面积分析系统|Quantachrome NOVA-3000]] 系统）确定受测样品的[[比表面积]]。在 298 K 下测量原始和改性 [[HKUST-1]] 在水处理 7 天前后的 $\mathbf { C O } _ { 2 }$ [[吸附等温线]]（[[Quantachrome]]，[[Quantachrome Nova2000e比表面积分析仪|Nova2000e]]）。测量前，在相应 [[金属有机框架|MOF]] 的[[材料活化|活化]]条件下对样品进行活化。

[[分子动力学模拟|MD 模拟]]。我们采用了 [[ZIF-8]]（100）和（110）[[表面模型]]。该[[周期性模型]]体系的[[晶胞]]在横向（<sub>x</sub>-<sub>y</sub>）上的尺寸为 50.6 Å × 50.6 Å，在 <sub>z</sub> 方向上的尺寸为 131.2 Å。已有研究发现，[[DREIDING力场|DREIDING 力场]]能够很好地描述几种已得到充分研究的 [[金属有机框架|MOF]] 的[[体积模量]]和[[线性热膨胀系数]]<sup>53</sup>。本研究采用 DREIDING 力场描述 [[沸石咪唑酯骨架-8|ZIF-8]]。

在 [[ZIF-8]] 表面上方共放置了 3000 个[[水|水分子]]。将[[横向尺寸]]为 39.1 Å × 35.4 Å 的 [[氧化石墨烯纳米片|GO 纳米片]]浸入[[水分子]]中。[[氧化石墨烯|GO]] 的[[分子结构]]主要包含[[羟基]]和[[环氧基]]，这些基团随机分布在碳平面的两侧。片层边缘的所有碳原子均由[[羧基]]修饰。水分子采用 [[TIP3P水模型|TIP3P 模型]]描述，GO [[纳米片]]采用 [[OPLS力场|OPLS 力场]]描述<sup>54</sup>。水、[[沸石咪唑酯骨架-8|ZIF-8]] 和 GO 之间的[[交叉相互作用]]采用 Lorentz-Berthelot 规则计算。在 x、y 和 z 方向上均施加周期性边界条件，其中 z 方向垂直于表面。采用 NVT 系综，并通过 Nosé-Hoover 算法将温度控制在 300 K。[[分子动力学模拟|MD 模拟]]中的温度耦合时间常数设为 0.1 ps。长程库仑相互作用采用粒子-粒子-粒子-网格（Particle-Particle-Particle-Mesh，PPPM）算法计算<sup>55</sup>。[[经典分子动力学模拟|MD 模拟]]选用蛙跳算法对牛顿运动方程进行积分，时间步长为 2 fs。所有经典[[分子动力学]]模拟均使用大规模原子分子大规模并行模拟器（LAMMPS）软件包进行<sup>56</sup>。使用 LAMMPS 中实现的 COL-VAR 模块<sup>57</sup>计算平均力势（PMF）。

采用伞形采样（umbrella sampling，US）方法<sup>58</sup>计算 PMF，即 [[氧化石墨烯纳米片|GO 纳米片]]从体相移动至 [[ZIF-8]] 表面过程中的[[自由能]]剖面。对 [[氧化石墨烯|GO]] [[纳米片]]中的每个原子施加沿 Z 轴方向的回复力。每个窗口均进行 10 ns 的 [[分子动力学模拟|MD 模拟]]。收集最后 8 ns 的数据，并通过加权直方图分析方法（WHAM）进行分析，以获得 PMF<sup>59</sup>。

第一性原理计算。在 [[密度泛函理论计算|DFT 计算]]中，采用广义梯度近似交换-相关泛函 PBE<sup>60</sup>，并结合 Grimme 经验色散校正<sup>61</sup>。采用双 ζ 极化高斯基组<sup>62</sup>，并结合截断能为 800 Ry 的平面波表示。采用 Goedecker-Teter-Hutter（GTH）赝势<sup>63</sup>描述芯层电子。采用爬山图像微动弹性带（CI-NEB）方法<sup>64</sup>确定反应路径及其对应的过渡态。在三个方向上均采用周期性边界条件。所有第一性原理计算均使用 CP2K 程序完成<sup>65</sup>。

[[ZIF-8]] 的[[晶胞]]结构基于剑桥[[晶体结构]]数据库（Cambridge Structural Database，CSD）中的 [[XRD]] 晶体结构构建<sup>37</sup>。对该结构进行几何优化时，其[[晶格参数]]和离子位置均充分弛豫。随后，使用优化后的晶胞结构构建体相和[[表面模型]]。此处采用 (100) 表面代表 [[沸石咪唑酯骨架-8|ZIF-8]] 的典型外表面，因为该表面对酸性气体侵蚀具有较高的稳定性<sup>33</sup>。采用平板模型模拟 (100) [[晶面]]，并设置厚度约为 15 Å 的真空层，以避免周期性镜像平板之间的相互作用。ZIF-8 的 (100) 表面存在四种可能的终止方式，选取其中[[表面能]]最低的一种<sup>33</sup>。具体而言，平板模型最外层的 Zn 原子为三[[配位作用|配位]]。然而，由于实验环境处于高湿度条件下，使用[[水|水分子]]使未饱和的 Zn 原子达到配位饱和。
