# [[机器学习]]驱动的体相与[[界面水]]体系[[分子动力学]]进展

[[Ruiyu Wang]]、[[Vanessa J. Meraz]]、[[Pratyush Tiwary]]

1. [[马里兰大学]]，College Park

## 摘要

[[分子动力学|分子动力学（MD）模拟]]已被广泛应用于研究[[水溶液|水相]]和界面环境中的各种物理与化学过程，这些过程对于能源材料的设计以及理解生命本身核心的若干化学过程至关重要。然而，[[分子动力学模拟|MD 模拟]]的适用性一直受到若干固有挑战的制约，包括[[力场]]的准确性、模拟规模和时间的限制。应对这些挑战的一个有前景的方案是整合[[机器学习]]（ML）方法，既用于改进水体系中相互作用性质的描述，也用于[[增强采样]]。在本综述中，我们讨论了 ML 力场（[[机器学习力场|MLFFs]]）和 ML 增强采样方法在研究水相、[[界面水|界面体系]]中的原理、实现与应用。我们讨论了使用 MLFFs、ML 增强采样以及 ML 驱动数据分析的五类关键应用。我们首先讨论 MLFFs 如何以经典水平的计算代价为复杂水相和界面体系的大规模模拟提供量子水平的精度，然后重点说明将其与增强采样和先进数据分析（尤其是基于图的体系特征化方法）相结合，如何既能增强模拟，又能通过获得可靠的[[低维反应坐标]]来提高对高维 MD 数据的解释，从而加深对模拟的理解。所讨论的应用包括对[[体相水]]和界面水结构及动力学、[[质子转移]]、[[催化剂|催化]]、[[相变]]以及[[振动光谱预测]]的研究。在每种情况下，我们都强调了基于 ML 的方法如何使此前在计算上难以实现的模拟成为可能，并为水溶液和界面提供新的物理见解。例如，MLFFs 允许在保持[[量子化学]]精度的同时进行具有数千个原子的纳秒级模拟。此外，ML 增强采样有助于跨越较大的[[反应能垒]]，并使探索广阔的[[构型空间]]成为可能。并且，基于模拟数据训练的 ML 模型揭示了此前被忽视的因素，例如[[溶剂动力学]]在相变中的作用。MLFFs 与增强采样技术的结合使得高维[[自由能面]]的计算变得可行，显著提升了我们对化学反应的理解。最后，我们讨论了该领域当前面临的挑战，并概述了未来可能的研究方向，以进一步推动 ML 在 MD 模拟中的整合。

## 1 引言

水是地球上最普遍存在的物质之一，对于人类生命至关重要，并在无数化学和物理过程中发挥着关键作用，这些过程包括[[相变]]、[[催化剂|催化]]、[[材料设计]]、[[蛋白质折叠]]、空气中污染物的[[吸附]]、[[清洁能源|清洁能源生产]]、生命起源、药物设计等。<sup>1–9</sup> 除[[体相水|本体水]]之外，在科学和工程问题中起关键作用的往往是界面附近的水。<sup>10–15</sup> 举几个例子，与电化学催化相关的过程（如[[析氢反应]]）依赖于水的解离以及氢原子在[[金属电极表面]]上的吸附。<sup>16</sup> $\mathrm { N _ { 2 } O _ { 5 } }$（[[酸雨]]的一个关键贡献者）的吸附和水解发生在[[水-空气界面|水/空气界面]]。<sup>17</sup> 在生物化学中，水通过形成[[氢键]]来稳定蛋白质的折叠结构，从而支配蛋白质的功能，尤其是在疏水或部分溶剂化表面附近，水结构化和[[表面化学]]之间的相互作用会关键性地调节折叠和功能。<sup>18</sup>

人们已经开发并应用了大量实验技术来研究[[体相水|本体水]]和[[界面水]]的结构与动力学，这些技术包括但不限于[[红外光谱]]、[[拉曼光谱]]、[[和频产生]]（SFG）、[[原子力显微镜]]、[[X射线反射率]]、[[扫描隧道显微镜]]和[[X射线吸收光谱]]。<sup>19–27</sup> 然而，其中许多实验技术只能提供间接光谱，因此需要适当的假设和建模来解释实验观测，以便在感兴趣的微观尺度上还原真实的结构和动力学。<sup>10</sup> 此外，实验条件下存在的杂质可能引入伪影，并导致对实验观测结果的错误解释。<sup>28,29</sup> 另一方面，[[分子动力学|分子动力学（MD）模拟]]可以在原子尺度上揭示微观结构信息，并在皮秒时间尺度上揭示动力学过程。近年来，由于计算能力的进步，[[分子动力学模拟]]受到越来越多的关注。除了支持和解释实验观测结果之外，分子动力学模拟还可以用于研究实验上难以研究的化学过程。

尽管[[分子动力学|MD模拟]]具有实用性，但其固有限制阻碍了更广泛的潜在应用。[[分子动力学模拟|MD模拟]]的第一个主要挑战是根据给定构型准确重现原子的能量与力。虽然[[势能面]]可以通过高水平的[[量子化学|量子化学方法]]计算，但随之而来的高昂成本通常使MD模拟难以承受，因此MD模拟普遍采用两种方法：[[从头算分子动力学|从头算MD]]和[[经典分子动力学|经典MD]]。从头算MD模拟通常在[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）水平上进行，以降低其他高水平量子方法的高计算成本。但对于大规模模拟而言，其成本仍然高得令人望而却步。相比之下，在经典MD模拟中，力是通过基于原子几何结构（如距离、角度和二面角）的简化解析函数来计算的。这种方法被称为[[力场]]（FFs），旨在实现快速计算。然而，经典MD模拟常常忽略[[键的断裂与形成]]，以及涉及电子相互作用的更复杂原子相互作用，包括但不限于原子的偶极与极化。此外，经典MD中的振动是预先定义的或缺失的，这使得估算[[振动光谱预测|振动光谱]]变得困难。<sup>30</sup> 这些限制也使得经典MD不适合模拟化学反应。第二个主要挑战是MD模拟可达到的时间尺度有限。典型的从头算MD模拟仅跨越几皮秒并包含数百个原子，而现代经典MD模拟对于接近数百万原子的体系，其时间尺度可以达到数微秒甚至毫秒。许多与模拟体相和[[界面水]]体系相关的宏观物理和化学过程要慢得多，并且发生在更长的时间尺度上。无偏MD模拟遵循[[玻尔兹曼分布]]，但常常陷入[[亚稳态]]，从而限制了对高[[能垒]]事件的探索并浪费计算资源。此外，由此产生的高维数据需要进行[[降维]]才能有效分析。<sup>31</sup>

许多基于物理的方法已被开发出来，以应对上述两类挑战。已发展出包含键结构的高级[[力场]]，例如[[反应力场]]（Reactive Force Field, ReaxFF）、<sup>32</sup> [[MB-pol]]、<sup>33</sup> 以及[[多尺度反应分子动力学模拟]]。<sup>34</sup> 这些方法能够模拟[[水溶液|水相]]中的某些化学反应，例如[[质子转移]]。[[极化力场]]也已被开发，以提高水模型的准确性。<sup>35,36</sup> 然而，这些模型的发展主要集中在纯水和简单离子上。当模拟中存在多种物种时，多种物种力场的可迁移性和兼容性限制了它们在更复杂体系中的适用性，仍有大量工作有待完成。为克服[[稀有事件采样]]的挑战，[[增强采样]]方法被引入，以扩展[[分子动力学|分子动力学模拟]]所探索的构型范围。这些方法能够有效加速模拟或提高观察到低概率构型的可能性。<sup>37</sup> 虽然使用增强采样获得的模拟轨迹并不总是物理真实的，但可以通过适当的权重校正技术恢复准确的化学反应动力学和[[自由能面]]。<sup>38,39</sup> 某些增强采样方法，如[[伞形采样]]和[[元动力学]]，需要预先定义[[集体变量]]（collective variables, CVs）来引导采样过程。然而，人类直觉式的集体变量并不总是足以近似真实的[[反应坐标]]（Reaction Coordinates, RCs），这可能限制增强采样方法的有效性。

为应对上述剩余挑战，[[机器学习]]（machine learning, ML）引起了越来越多的关注，这得益于计算机硬件和软件的发展，它们显著加速了机器学习计算。特别是当遵循[[统计力学|统计力学原理]]时，机器学习方法可用于识别[[反应坐标]]或慢模式，从而提供对体系动力学的更深入认识，并提高[[增强采样]]的可靠性。机器学习不仅被用于增强采样，还被用于以与[[经典分子动力学]]相当的计算成本实现 [[DFT]] 级精度。为此，[[机器学习力场|基于机器学习的力场]]（ML-based force fields, MLFFs）已被开发并应用于多种体系。

将[[机器学习]]整合到[[分子动力学|分子动力学模拟]]中，对于研究[[水溶液|水相]]和[[界面水|界面体系]]尤为重要，因为这些环境具有固有的复杂性。溶剂水的显式建模通常需要大量水分子，尤其是在溶质浓度相对较低的情况下。此外，带电物种与水之间的[[长程静电相互作用]]要求模拟盒子尺寸达到数纳米量级才能收敛。许多界面过程的建模需要包含电子效应。这些效应包括但不限于：固体表面的极化、[[质子转移]]过程中[[键的断裂与形成|化学键的断裂与形成]]，以及水的振动。引入[[机器学习力场]]是为了在水相界面体系中以合理的计算成本实现 [[DFT]] 级精度。为研究[[清洁能源]]应用中的界面化学[[催化剂|催化]]，必须计算反应路径的高维[[自由能面|自由能景观]]，而这只有通过精心设计的[[增强采样|增强采样分子动力学]]模拟才能实现。

撰写这篇综述的目的，是对[[水溶液]]与界面中所开展的全原子和电子分辨计算研究的广泛领域进行概览。近年来，这些主题受到了显著关注，已有大量综述论文分别讨论[[机器学习力场|机器学习力场（MLFFs）]]或基于[[机器学习]]的[[统计力学]]（图1a），<sup>40–50</sup> 但很少在同一篇综述中将二者结合讨论。在这篇内容广泛且力求全面的综述中，我们特别聚焦于水体系和[[界面水|界面体系]]的[[分子动力学|分子动力学（MD）模拟]]，并重点介绍其在能源与材料科学中的应用。我们将展示机器学习[[力场]]、[[增强采样]]与数据分析的结合如何推动该领域的研究进展。我们首先讨论MLFFs的理论基础（第2节，图1b）以及机器学习增强采样（第3节，图1c）。随后，通过实例说明机器学习与MD在水环境和界面环境中的整合应用，包括[[体相水]]与界面水的结构和动力学（第4.1节，图1d）、[[质子转移]]（第4.2节，图1e）、[[催化剂|催化]]（第4.3节，图1f）、[[相变]]（第4.4节，图1g）以及[[振动光谱预测]]（第4.5节，图1h）。最后，我们将讨论对这一快速发展的研究领域当前状况与未来机遇的展望（第5节）。

## 2 [[机器学习]]势与[[力场]]

## 2.1 概述

[[机器学习力场|MLFF]] 近年来因对兼具 [[DFT]] 级精度与化学反应建模能力、同时达到经典级别时间尺度和体系规模模拟日益增长的需求而受到越来越多的关注。<sup>55–60</sup> 如引言部分所述，[[水溶液|水相]]与[[界面水|界面体系]]的模拟通常涉及相对大量的分子，并且在某些应用中需要纳入电子效应。MLFF 非常适合同时满足这两方面需求，能够以合理的计算成本提供量子级精度和相应信息。MLFF 的主要目标是学习分子体系的[[势能面]]（PES），由此可以导出原子间的力。除力之外，MLFF 还可以预测分子的[[偶极矩]]、[[电荷分布]]和[[电子态]]等性质。在本节中，我们将讨论基于描述符的 MLFF（第 2.2 节）、端到端 MLFF（第 2.3 节）和基于物理的 MLFF（第 2.4 节）。此外，我们还包括了用于模拟宏观过程的[[粗粒化 MLFF]]、具有[[长程相互作用]]的 MLFF 以及 MLFF [[基础模型]]的讨论。

## 2.2 基于描述符的 [[机器学习力场|MLFF]]

## 2.2.1 描述符

[[势能面|PES]] 的内禀性质对平移、旋转、反射以及相同原子交换具有不变性。[[机器学习]]模型必须从本质上考虑这种不变性，而不能依赖输入数据来显式编码这些性质。在实践中，模拟中的 PES 是根据所有原子坐标计算的，但逐原子的笛卡尔坐标并不是 [[机器学习力场|MLFF]] 的理想输入，因为它们会破坏交换不变性，即交换两个原子会改变输入。为应对这一挑战，现代 MLFF 利用从模拟构型导出的描述符，这些描述符天然保持上述对称性。此外，由于模拟中每个原子的[[配位数]]可能变化，且描述局部环境所需的近邻原子数不同，描述符必须具有足够的灵活性，以适应原子环境可变的输入数据。下面我们介绍一些常用的此类描述符。

[[原子中心对称函数]]（ACSFs）。[[对称函数]]专门设计用于将原子坐标转换为描述局部原子环境的描述符。在 [[机器学习力场|MLFF]] 中，对称函数消除了对原子顺序的依赖，从而保证交换不变性。因此，在某一[[截断距离|截断范围]]内具有相同环境的原子，其对称函数的值或向量也相同。

最初，[[Behler]] 和 [[Parrinello]] 提出了以下类型的[[原子中心对称函数|对称函数]]：<sup>61–63</sup>

$$
f _ {c, 1} (R _ {i j}) = \left\{ \begin{array}{l} 0. 5 [ \cos (\frac {\pi R _ {i j}}{R _ {c}}) + 1 ], \text {   if   } R _ {i j} <   = R _ {c} \\ 0, \text {   if   } R _ {i j} > R _ {c} \end{array} \right.\tag{1}
$$

或

$$
f _ {c, 2} (R _ {i j}) = \left\{ \begin{array}{l} \tanh ^ {3} [ 1 - \frac {R _ {i j}}{R _ {c}} ], \text {   if   } R _ {i j} <   = R _ {c} \\ 0, \text {   if   } R _ {i j} > R _ {c} \end{array} \right.\tag{2}
$$

两种[[原子中心对称函数|对称函数]]都以原子 i 与 $j ~ ( R _ { i j } )$ 之间的成对距离作为输入，当距离接近预定义截断 $R _ { c }$ 时，函数值从 1 连续降低到 0（图 2a）。[[对称函数]]的连续性保证了对 $R _ { i j }$ 的可微性，从而能够通过对[[势能面]]关于原子坐标求导来计算力。一个原子的径向对称描述符定义为[[截断距离]]内所有近邻原子上的求和：

$$
G _ {i} ^ {1} = \sum_ {j = 1} ^ {N _ {a t o m}} f _ {c} (R _ {i j})\tag{3}
$$

此处，$G _ { i } ^ { 1 }$产生一个单一的标量值。为了更全面地刻画原子环境，可以选择并计算多个截断值，以构建描述不同原子对的描述符向量。[[原子中心对称函数|对称函数]]的改进版本引入[[高斯函数]]来平滑截断区域（图 2b），并对[[对称函数]]中心进行平移（图 2c）：

$$
G _ {i} ^ {2} = \sum_ {j = 1} ^ {N _ {a t o m}} e ^ {- \eta (R _ {i j} - R _ {s}) ^ {2}} f _ {c} (R _ {i j})\tag{4}
$$

其中η表示[[高斯函数]]的宽度，用于调节[[原子中心对称函数|对称函数]]$G ^ { 2 }$随距离衰减的快慢。$R _ { s }$指定高斯中心的平移量，使[[对称函数]]能够聚焦于中心原子周围的特定区域。还可以定义描述三体相互作用的角向对称函数：

$$
G _ {i} ^ {3} = 2 ^ {1 - \xi} \sum_ {j \neq i} \sum_ {k \neq i, j} [ (1 + \lambda \cos \theta_ {j i k}) ^ {\xi} e ^ {- \eta (R _ {i j} ^ {2} + R _ {j k} ^ {2} + R _ {i k} ^ {2})} f _ {c} (R _ {i j}) f _ {c} (R _ {j k}) f _ {c} (R _ {i k}) ]\tag{5}
$$

其中$\theta _ { j i k }$是原子$i , j ,$与$k ,$之间的夹角，i表示中心原子，$\xi$是归一化参数。与径向[[原子中心对称函数|对称函数]]类似，这些角向[[对称函数]]的宽度和中心角可调，以聚焦于特定角度区域（图 2d）。

[[原子位置平滑重叠]]（SOAPs）。原子位置平滑重叠（SOAPs）描述符也可用于描述原子环境的局部相似性，并已应用于[[增强采样|增强采样分子动力学]]中以研究[[相变]]。<sup>64</sup>对于每个原子$i ,$，其局部环境的密度以其中心的[[高斯函数|高斯核]]表示：

$$
\rho^ {i, s} (\mathbf {r}) = \sum_ {j} \delta_ {s s _ {j}} \mathrm{exp} [ \frac {- | \mathbf {r} - \mathbf {r _ {i}} | ^ {2}}{2 \sigma^ {2}} ] f _ {c} (R _ {i j})\tag{6}
$$

其中s表示特定物种，$\delta _ { s s _ { j } }$是物种s的[[克罗内克δ]]，$s _ { j }$。为保持旋转不变性，式 6 使用[[球谐函数]]$Y _ { l m }$和[[径向基函数|正交径向基函数]]展开：

$$
\rho^ {i, s} (\mathbf {r}) \approx \sum c _ {n l m} ^ {i, s} G _ {n} (r) Y _ {l m} (\hat {\mathbf {r}})\tag{7}
$$

p _ {n n ^ {\prime} l} ^ {i, s s ^ {\prime}} = \frac {1}{\sqrt {2 l + 1}} \sum_ {m} (c _ {n l m} ^ {i, s}) ^ {*} c _ {n ^ {\prime} l m} ^ {i, s ^ {\prime}}\tag{9}
$$

其中i表示中心原子，s和$s ^ { \prime }$表示不同物种或元素。n和$n ^ { \prime }$表示不同的径向区域。最后，[[SOAP 描述符|SOAP]] 值，即原子环境A与$A ^ { \prime } ,$之间的相似性，定义为原子平滑密度的内积：

$$
k (A, A ^ {\prime}) = (\hat {p} ^ {i} \hat {p} ^ {i ^ {\prime}}) ^ {\zeta}\tag{10}

其中$\hat { p }$是归一化[[功率谱]]，$\hat { p } ^ { i } = p ^ { i } / \sqrt { p ^ { i } p ^ { i } } , \zeta$通常取 2 或 4，以调节$k .$的锐度。$k ( A , A ^ { \prime } )$的值介于 0 和 1 之间，分别表示不相似与完全相同。

总之，[[SOAP 描述符]]利用在径向和[[角向基函数]]中展开的近邻密度来表征原子环境，从而确保旋转不变性和[[置换不变性]]。这些展开的[[功率谱]]作为描述符，[[原子位置平滑重叠|SOAP]] 向量的归一化点积则提供了两个原子环境之间相似性的度量。

[[原子簇展开]]描述符。在原子簇展开（ACE）描述符中，原子体系的能量被建模为[[多体相互作用]]的求和：

$$
E = \sum_ {n} \frac {1}{n !} \sum V ^ {(n)}.\tag{11}
$$

对于每个原子 i，其与 K 个近邻的 α 阶相互作用由以下方式描述：$\Phi _ { \alpha \nu } = \phi _ { v _ { 1 } } ( \mathbf { r } _ { i , j _ { 1 } } ) \phi _ { v _ { 2 } } ( \mathbf { r } _ { i , j _ { 2 } } ) . . . \phi _ { v _ { 3 } } ( \mathbf { r } _ { i , j _ { K } } )$ ，其中 $\phi$ 是包含[[径向基函数]]和[[角向基函数]]的[[正交基函数]]。<sup>65</sup>

## 2.2.2 由描述符构建 [[机器学习力场|MLFF]]

在获得每个原子化学环境的描述符之后，下一步是应用 [[机器学习|ML]] 模型学习结构信息，并估计该特定原子对能量的贡献。模拟体系的总能量将是所有单个原子能量贡献的求和。此外，与 [[分子动力学|MD 模拟]]相关的其他性质，尤其是力，可以从能量对原子位置的梯度（导数）导出：

$$
F _ {\alpha} = F _ {\alpha , s} + F _ {\alpha , e l e c} = - \frac {\partial E _ {s}}{\partial \alpha} - \frac {\partial E _ {e l e c}}{\partial \alpha}\tag{12}
$$

其中，原子 α 上的力是[[短程力]] $F _ { \alpha , s }$ 与[[长程静电力]] $F _ { \alpha , e l e c }$ 之和

$$
F _ {\alpha , s} = - \sum_ {j} ^ {N _ {a t o m}} \sum_ {\mu} ^ {N _ {s y m, j}} \frac {\partial E _ {j}}{\partial G _ {j \mu}} \frac {\partial G _ {j \mu}}{\partial \alpha}\tag{13}
$$

$$
F _ {\alpha , e l e c} = \sum_ {i} ^ {N _ {a t o m}} \sum_ {j \neq i} ^ {N _ {a t o m}} \frac {Q _ {i}}{R _ {i j}} [ \frac {1}{2} \frac {\partial R _ {i j}}{\partial \alpha} \frac {Q _ {j}}{R _ {i j}} - \sum_ {k} ^ {N _ {s y m, i}} \frac {\partial Q _ {j}}{\partial G _ {i k}} \frac {\partial G _ {i k}}{\partial \alpha} ]\tag{14}
$$

短程相互作用完全取决于中心原子的坐标，可以直接由[[原子中心对称函数|对称函数]]计算得到。相比之下，[[静电力]]受[[神经网络]]赋予的部分电荷影响。为了考虑长程电荷-电荷相互作用，可以采用额外的方法，例如 [[Ewald 求和]]，同时使用原子坐标和所赋予的部分电荷，这与经典 [[分子动力学|MD 模拟]]中使用的方法类似。

最终任务是训练[[神经网络]]参数，使神经网络势能够准确重现体系的总能量。在文献中，<sup>61–63</sup> [[Behler]] 和 [[Parrinello]] 率先使用传统[[前馈神经网络]]（NNs）来实现这一目的。在该框架中，NN 由[[输入层]]、[[输出层]]和若干[[隐藏层]]组成。下一层神经元的值按下式计算：

$$
y _ {i} ^ {j} = f _ {i} ^ {j} (b _ {i} ^ {j} + \sum_ {k} ^ {N _ {j - 1}} a _ {k, i} ^ {j - 1, j} y _ {k} ^ {j - 1})\tag{15}
$$

其中 $y _ { i } ^ { j }$ 是第 j 层节点 i 的值，$f _ { i } ^ { j }$ 是[[激活函数]]，$b _ { i } ^ { j }$ 是偏置项，a 是线性缩放系数。a 和 b 是需要使用[[反向传播算法]]训练的参数。训练和验证过程通常包括以下步骤：

1. 在 [[DFT]] 或其他水平上进行[[量子 MD 模拟]]，并选择足够数量的能够代表所有可能状态的构型。

2. 迭代以下步骤：

(a) 利用上一步选择的构型、能量和力训练 [[机器学习力场|MLFF]]。

(b) 使用上一步训练得到的 [[机器学习力场|MLFF]] 进行试算 [[分子动力学|MD 模拟]]。

3. 当训练得到的 [[机器学习力场|MLFF]] 误差合理，并且在试算模拟中未观察到非物理构型时停止训练。

4. 使用训练好的 [[机器学习力场|MLFF]] 进行最终的生产 [[分子动力学|MD 模拟]]，以用于进一步分析。

在 [[Behler-Parrinello 机器学习力场]]中，[[原子中心对称函数|对称函数]]通过径向截断、高斯宽度和位移等参数预先确定，并且这些参数在整个训练过程中保持不变，可能引发问题。这一局限已在 [[DeePMD 机器学习力场]]中得到解决，其具有更高的灵活性。<sup>51</sup> 在 [[DeePMD|DeePMD 框架]]中，原子相互作用通过局部分子框架内定义的径向和角度信息来表征。随后，这些描述符被输入[[深度神经网络]]，以计算与每个原子相关的能量。在训练过程中，DeePMD 有效学习了原本在 [[Behler]]–[[Parrinello]] [[机器学习力场]]中需要人工指定的超参数。此外，DeePMD 采用具有更多层和节点的深度[[神经网络]]，显著增强了其以更高精度重现能量结果的能力。

[[Behler-Parrinello 机器学习力场]]的另一个局限是，所有原子均使用同一组[[原子中心对称函数|对称函数]]进行处理，这使得涉及多种原子类型的模拟难以开展。为解决这一问题，[[Isayev]] 及其同事开发了 [[ANI 机器学习力场|Accurate NeurAl networK engINe for Molecular Energies]]（ANI）[[机器学习力场]]。<sup>66</sup> ANI 模型用[[原子环境向量]]（AEVs）替代[[对称函数]]作为描述符。AEVs 针对每种元素类型专门构建，在仍能准确表示分子环境的同时，显著减少了所需描述符的数量。

## 2.3 [[端到端机器学习力场]]

[[端到端机器学习力场]]以笛卡尔坐标为输入，并直接从数据中生成能量和力。其中许多模型基于[[图神经网络]]（GNNs）或[[消息传递神经网络]]。在这些模型中，原子及其相互作用分别被表示为节点和边。位于指定距离[[截断距离|截断范围]]内的节点被视为相互连接，从而允许它们通过边交换节点和边特征。第 2.2 节讨论的描述符也可以纳入图模型。理论上，任何原子级特征都可以被嵌入用于[[消息传递]]。[[基于图的反应坐标构建|基于图的方法]]能够自然捕获分子构型的拓扑信息，且原子类型可以方便地编码在节点特征中。

在基于图的[[机器学习力场]]中，对应于原子 i $\left( \sigma _ { i } \right)$ 的节点通常建模为：

$$
\sigma_ {i} ^ {(t)} = (\mathbf {r} _ {i}, z _ {i}, \mathbf {h} _ {i} ^ {(t)})\tag{16}
$$

其中 r 表示坐标，z 为元素，$\mathbf { h } ^ { ( t ) }$ 为第 t 层的节点特征。通过对[[截断距离]]内相邻节点的特征执行置换不变的池化操作，生成消息 $( \mathbf { m } _ { i } ^ { ( t ) } )$。随后，该消息被用于更新下一层的节点特征：

$$
\mathbf {h} _ {i} ^ {(t + 1)} = U _ {t} (\sigma_ {i} ^ {(t)}, \mathbf {m} _ {i} ^ {(t)})\tag{17}
$$

其中 $U _ { t }$ 是更新函数，用于结合当前节点状态 $\sigma _ { i } ^ { ( t ) }$。最后，通过将更新后的节点特征映射为能量贡献，并对所有原子求和，得到体系的总能量。

一种已成功应用于[[水溶液]][[分子动力学|MD模拟]]的基于图的[[机器学习力场|MLFF]]是[[MACE 模型|MACE]]模型。<sup>67</sup>在MACE模型中，消息是利用ν体相互作用构建的，其中ν是一个可调超参数，这与传统基于[[图神经网络|GNN]]的MLFF中常用的二体消息不同（式17）。MACE中的边特征由置换不变的二体相互作用构建，表示为一组[[径向基函数]]与[[球谐函数]]的乘积。为了构建高阶特征，需计算边特征的[[张量积]]并进行对称化处理。该方法使MACE能够自然引入[[多体相互作用]]，克服了传统GNN仅限于二体相互作用的局限。在当前MACE实现中，最多已包含四阶相互作用。因此，MACE MLFF展现出优异的可扩展性和灵活性，可支持涉及多种元素的[[分子动力学模拟|MD模拟]]，使其特别适用于水溶液等复杂体系。

另一个值得注意的[[机器学习|ML]]模型是[[深度张量神经网络]]（Deep Tensor Neural Network，DTNN），它以原子间的距离矩阵及原子核电荷作为输入。<sup>68</sup>距离通过[[高斯回归模型]]展开，原子特征向量在训练过程中根据成对原子相互作用迭代更新。尽管仅显式包含成对相互作用，该模型仍能隐式学习高阶相互作用。尽管具有上述优点，早期版本的DTNN仍存在局限，例如难以对大分子建模以及无法预测力。然而，与基于描述符的方法相比，DTNN不需要为[[原子中心对称函数|对称函数]]预定义超参数，从而简化了其框架。随后，[[Tkatchenko]]等合作者提出了[[SchNet 机器学习力场|SchNet MLFF]]，克服了DTNN的部分局限，包括力预测。<sup>69</sup>[[SchNet]]采用[[连续滤波卷积]]替代离散化的网格数据，使其能够有效建模任意原子位置。其架构由分子表示层、逐原子层和相互作用层组成。与DTNN相比，SchNet显著降低了[[平均绝对误差]]，提供了更高的精度和效率。

[[长程相互作用]]也可以在基于图的[[机器学习力场|MLFF]]中单独计算。[[Unke]]等合作者开发了[[PhysNet]]，这是一种能够预测能量、力、[[偶极矩]]和部分电荷的[[机器学习]][[力场]]。<sup>70</sup>PhysNet由若干关键组件构成，包括[[嵌入层]]、[[模块化块]]、[[残差块]]、[[相互作用块]]和[[输出块]]（图3）。这些组件包括：

1. [[嵌入层]]（图3a中的紫色框）将原子元素及其位置转换为向量表征。

2. [[模块化块|模块块]]（图3b中的绿色框）通过将中心原子的性质与定义距离截断内所有相邻原子的性质相结合来处理原子特征。

3. [[残差块]]通过解决梯度消失问题，使更深层[[神经网络]]的训练成为可能。

4. [[相互作用块]]（图3c）利用原子特征x和[[径向基函数]]$\mathbf { g } ( r _ { i j } )$学习中心原子的环境。[[神经网络]]的权重（W）、偏置（b）和[[注意力掩码]]（G）为可训练参数。

5. [[输出层]]（图3d）利用学习到的原子特征预测单个原子的能量贡献。

值得注意的是，[[PhysNet]] 还可以预测原子上的部分电荷，系统的最终总能量计算如下：

$$
E = \sum_ {i} ^ {N} E _ {i} + k _ {e} \sum_ {i} ^ {N} \sum_ {j > i} ^ {N} \hat {q} _ {i} \hat {q} _ {j} \chi (r _ {i j}) + E _ {D 3}\tag{18}
$$

其中 $E _ { i }$ 是原子 i 的预测能量贡献，ˆq 是预测的部分电荷，χ 是库仑相互作用的平滑近似 $( r _ { i j } ^ { - 1 } )$ ，[[DFT-D3 色散校正|D3]] 是 [[DFT]]-[[D3 色散校正]]。<sup>71</sup> 为评估其性能，[[PhysNet]] 被应用于一个 $\mathrm { { A l a } _ { 1 0 } }$ 分子的[[分子动力学|分子动力学模拟]]。结果表明，优化构型和 [[势能面|PES]] 与参考 [[密度泛函理论|DFT]] 水平高度吻合，证明了 PhysNet 的准确性和可靠性。

## 2.4 基于物理的 [[机器学习力场|MLFF]]

上述 [[机器学习力场|MLFF]] 能够基于原子坐标学习分子体系的 [[势能面|PES]]。另一种策略是将物理原理纳入 MLFF。一个众所周知的例子是基于 [[Lennard-Jones 相互作用]]的[[力场]]，它通常表示为短程排斥和长程吸引，分别嵌入为 $r ^ { - 1 2 }$ 和 $- r ^ { - 6 }$ 项。其他物理性质包括[[键级]] <sup>72</sup> 和[[电子密度]]。<sup>73</sup> 在这些模型中，[[MB-pol 水分子力场]]将水分子的能量计算为[[多体相互作用]]之和：<sup>74</sup>

$$
E _ {N} (1, \dots , N) = \sum_ {i = 1} ^ {N} \epsilon^ {1 B} (i) + \sum_ {i <   j} ^ {N} \epsilon^ {2 B} (i, j) + \sum_ {i <   j <   k} ^ {N} \epsilon^ {3 B} (i, j, k) + \dots + \epsilon^ {N B} (1, \dots , N)
$$

其中 $\epsilon ^ { N B }$ 表示涉及 N 个原子 $( 1 , . . . , N )$ 的 N 体相互作用项，以置换不变多项式的形式表示：

$$
\epsilon^ {N B} = \sum_ {l} ^ {L} c _ {l} \eta_ {l}\tag{19}
$$

其中 $L$ 表示参数数量，$c _ { l }$ 是使用 [[机器学习|ML]] 优化的线性参数，$\eta _ { l }$ 是对应的多项式。这些系数可以通过 ML 技术拟合，包括但不限于[[核岭回归]]、[[高斯过程回归]]和[[人工神经网络]]，方法是最小化 [[机器学习力场|MLFF]] 预测的 [[势能面|PES]] 与高水平量子计算得到的 PES 之间的差异。[[Paesani]] 及其同事还开发了 [[MB-fit]] <sup>75</sup> 和 [[MBX]]<sup>76</sup> 工具，用于高效训练和应用数据驱动的 [[MB-pol 水分子力场|MB-pol MLFF]]。

另一种策略是使用 [[机器学习|ML]] 直接求解[[薛定谔方程]]。虽然解析求解的计算成本对于 [[分子动力学|MD 模拟]]而言过高，但 [[Noé|No´e]] 及其同事开发了 [[PauliNet]]，这是一种基于[[变分量子化学]]的[[深度神经网络]]（DNN）框架。与传统的[[量子蒙特卡洛]]（QMC）方法相比，DNN 在求解波函数时具有更高的灵活性，并能减少行列式数量。<sup>77</sup> 在后续工作中，他们开发了在 QMC 框架内计算薛定谔方程激发态解的方法。<sup>78</sup>

## 2.5 [[机器学习力场|MLFF]] 中的[[长程相互作用]]

上述大多数 [[机器学习力场|MLFF]] 仅基于局部环境学习原子能量，这本质上忽略了长程效应，特别是静电作用。这种电荷–电荷相互作用对于准确模拟[[水溶液]]至关重要，并且在对称性破缺的体系（如带电界面）中变得更加关键。

解决这一局限的一个策略是在 [[机器学习力场|MLFF]] 框架内为每个原子预测显式部分电荷。随后可使用标准经典方法（例如 [[Ewald 求和]]）计算[[长程静电相互作用]]。例子包括嵌入电荷预测方案，如[[电荷平衡]]（QEq）、[[核 QEq]]、[[机器学习 QEq 模型]]、<sup>79</sup> [[迭代电荷平衡]]<sup>80</sup> 以及[[变分电荷平衡模型]]。<sup>81</sup> 例如，在传统 [[Behler-Parrinello 机器学习力场|Behler–Parrinello MLFF]] 中，电荷平衡已被结合为一个辅助[[神经网络]]，在短程相互作用之外预测原子电荷，从而能够处理电荷相互作用与电荷转移。<sup>82</sup> 重要的是，这些 MLFF 中使用的“电荷”是虚构的隐变量，用于复现正确的长程能量。例如，[[Cheng]] 提出了 [[Latent Ewald 方法]]，其中每个原子被赋予一个类似于部分电荷但不受物理[[电荷分布]]约束的隐变量；模型经过训练，使对这些隐变量进行的 Ewald 求和能够复现真实的[[长程相互作用]]。<sup>83</sup> 另一种互补策略完全避免显式电荷分配，而是直接从局域原子环境学习长程相互作用。[[Ceriotti]] 及其合作者引入了一种[[长距离等变表示]]，该表示可以局域计算，却能捕捉非局域静电效应，在带电体系中优于 [[SOAP 描述符|SOAP]] 等局域描述符。<sup>84</sup>

## 2.6 [[粗粒化 MLFF]]

除了旨在以更低计算成本复现高水平[[量子化学]]计算的 [[机器学习力场|MLFF]] 之外，还发展了[[粗粒化 MLFF]]，以加速大规模[[分子动力学|分子动力学模拟]]，尤其是针对大分子和蛋白质体系。一个代表性例子是 [[Clementi]] 及其合作者提出的 [[CGnet 模型]]，其中[[损失函数]]定义为预测[[粗粒化力]]与参考[[粗粒化]]力之间的 [[L2 差异]]：

$$
L (\theta) = \langle | | \xi (\mathbf {F} (\mathbf {r})) + \nabla U (\xi (\mathbf {r}); \theta) | | ^ {2} \rangle ,\tag{20}
$$

其中 ξ 表示从原子尺度力到[[粗粒化力]]的映射，θ 表示[[神经网络]]参数。<sup>85</sup> 完整的 [[CGnet 模型|CGnet]] 架构如图 4 所示。结构特征（例如成对距离、角度和二面角）由[[粗粒化]]坐标 x 计算得到，而粗粒化势能（严格来说现在是[[自由能]]）的不变性通过变换 y 得以保持。总粗粒化能量表示为 $U ( \mathbf { x } ) = U _ { 0 } ( \mathbf { x } ) + U _ { N e t } ( \mathbf { x } )$，其中 $U _ { 0 }$ 是施加适当构型约束的物理正则化项，$U _ { N e t }$ 是神经网络估计器。所得的粗粒化力 f(x) 通过对学习到的自由能函数 U 求梯度获得。

![](<../2.SCI_MD/Machine learning driven advances in molecular dynamics of bulk and interfacial aqueous systems/images/c01570bb8185c56fc7d84f45fdaaad3318acb9b83e0ae63e7f965df1fb128d21.jpg>)  
图 4：CGnet 机器学习粗粒化力场的架构。x 表示粗粒化坐标，y 表示用于保持自由能面不变性的变换。U 和 f 分别为预测的势能和力。（版权 2019，美国化学会）

在后续工作中，同一团队提出了 [[CGSchNet]]，用[[图神经网络]]表示取代手工构建的结构特征。<sup>86</sup> 利用这些[[粗粒化 MLFF]] 模型，模拟已成功重现了 12 种蛋白质的天然态，并绘制了跨越多个[[亚稳态]]的[[蛋白质折叠|折叠路径]]。<sup>87</sup> 最近，该方法还被证明能够准确捕捉[[固有无序蛋白质]]的折叠行为。<sup>88</sup> 虽然同一模型对训练集中包含的 12 种蛋白质表现良好，但其向不同于这 12 种蛋白质的其他蛋白质的可转移性，仍是一个值得进一步研究的令人兴奋的方向。除生物化学体系外，[[机器学习|ML]] [[粗粒化力]]场还被应用于模拟水中的[[相变]]。<sup>89</sup>

## 2.7 [[机器学习力场|MLFF]] 的[[基础模型]]

如上所述，[[机器学习力场|MLFF]] 发展的目标之一是实现广泛的兼容性与可转移性，最终构建可适用于广泛 [[分子动力学|MD 模拟]]的通用[[力场]]。在此背景下，使用预训练的 MLFF 可以提供通用表示，并能针对特定体系进行高效微调，从而大幅减少通常依赖计算昂贵的[[量子化学]]计算的训练数据需求。<sup>90</sup> 最近，多个 MLFF [[基础模型]]相继问世，包括 [[CHGNet]]、<sup>91</sup> [[MACE-MP]]、[[MACE-OFF]]、<sup>92</sup> [[GRACE]]<sup>93</sup> 和 [[M3GNet]]。<sup>94</sup> 这些模型代表了面向 [[分子动力学模拟|MD 模拟]]中分子通用且可适应力场的一个新兴方向。

## 3 用于[[增强采样]]和基于 [[机器学习|ML]] 模型的模拟分析的[[反应坐标]]构建

## 3.1 概述

尽管 [[机器学习力场|MLFF]] 因其计算高效且化学精度高的模拟而日益流行，长时间尺度模拟的问题仍然存在。由于[[水溶液|水相]]和[[界面水|界面体系]]由复杂表面建模，可及时间尺度的缺乏限制了相关转变的观测以及准确的热力学/动力学测量。因此，为了充分探索[[势能面]]，有必要将[[增强采样]]方案与精确[[力场]]相结合。

更一般地说，无论模拟是否经过增强，[[分子动力学|MD 模拟]]的一个显著不足在于其高维且含噪声的输出，仅一个体系就可能轻易产生 TB 级数据。由于从原始轨迹中量化感兴趣的物理现象被认为非常困难，因此获得[[反应坐标]]（RC）的低维估计对于更易于解释变得十分必要。这种[[降维]]使得识别原本可能被掩盖的模式和特征更加可控，并已广泛用于[[元动力学]]、[[伞形采样]]（US）和[[加权系综]]等方法中。然而，在没有先验知识的情况下找到合适的 RC 是相当具有挑战性的。

通常，用于近似[[反应坐标]]（RC）的直观[[集体变量]]（CV）并不足以满足采样需求。虽然我们能够识别并赋予成对距离和二面角等参数以物理意义，但当涉及[[增强采样]]方法中的偏置时，它们并不一定是最佳变量。尽管它们能够成功地在[[自由能面]]（FES）中更好地区分不同状态，但它们并非天然为捕捉慢模式而优化。因此，需要寻找能够确实增强系统慢模式的涨落参数，从而有助于更快地收敛[[自由能]]面。在[[成核]]现象中，大量研究已经探索了有效集体变量的构建。<sup>95,96</sup> 常见做法是通过 [[Steinhardt 序参量]]来表征晶体结构，从而纳入局部键序的表示。然而，尽管它们是不同[[亚稳态]]类晶态存在的良好指标，但它们并不总能近似反应坐标，也不足以充分表示更具玻璃态或多晶型的结构。<sup>97,98</sup> 这导致要么加入其他集体变量，要么精心构造一个新的集体变量。在考虑 [[NaCl]] 离子聚集时，[[Finney]] 和 [[Salvalaglio]]<sup>99</sup> 以及 [[Giberti]] 等人<sup>100</sup> 的研究采用了一种描述体系局部密度且不预先设定晶体结构的集体变量。取而代之的是，基于[[机器学习]]的方法已被引入以促进这一过程。其中一种方法是将高维轨迹景观投影到一个正则化的低维空间，以近似反应坐标。

尽管存在众多可用的[[增强采样]]方案，但在此我们不展开讨论，而是建议读者参考 [[Tiwary]] 和 [[van de Walle]] <sup>101</sup> 的综述以了解该主题的概貌。我们转而关注这些增强采样方法构造[[反应坐标]]或分析来自[[分子动力学|分子动力学（MD）]]的高维数据时所需的输入特征。这一问题常常被忽视，即便在使用基于[[机器学习]]的方法学习反应坐标时也是如此。<sup>102</sup> 虽然构造反应坐标的方案可能基于机器学习，但关于进入机器学习模型的输入特征是如何构建的这一假设，可能对后续增强采样模拟或分子动力学分析的可靠性产生显著影响。

在本节中，我们讨论使用不同[[机器学习]]风格来学习[[反应坐标]]的不同方法，包括使用机器学习从预先选定的特征中学习反应坐标的方法，以及更近期出现的、能够自动完成特征选择本身的[[图神经网络]]方法。

## 3.2 用于预选[[集体变量]]的[[降维|降维技术]]

复杂、高维的轨迹数据在特征化时体现了[[维度灾难]]。为了在没有先验信息的情况下半自动化地选择特征，人们已经发展出若干旨在保留关键信息的[[降维|降维技术]]。作为最早实现的降维方法之一，[[主成分分析]]（principal component analysis, PCA）旨在将有噪声的轨迹数据线性变换到一个能够识别重要特征的较低维坐标系。它通过最大化前几个分量——[[协方差矩阵]]的特征向量——的方差来实现这一点。与其对应的时间尺度方法，即[[时间滞后独立成分分析]]（time-lagged independent component analysis, TICA），将在第 3.3 节中详细讨论，其最大化给定时滞下的自相关性。[[线性判别分析]]（Linear Discriminant Analysis, LDA）寻找能够最好地分离数据集类别的特征线性组合。<sup>103</sup> 尽管这些方法非常高效，但它们通常都使用线性变换处理复杂数据，这限制了模型对动力学的刻画能力。在偏置动力学中这一点尤其重要，因为线性方法可能无法充分探索[[自由能面]]。若要恢复更高分辨率的动力学模型，就需要非线性变换，这促使将[[核技巧]]应用于 LDA（[[KDA]]）<sup>104</sup> 或 TICA（[[kTICA]]）<sup>105,106</sup> 等方法，以及利用[[神经网络]]灵活性的方法，如 [[DeepLDA]]<sup>107,108</sup> 或 [[Deep-TICA]]。<sup>109</sup> 这些模型在捕捉动力学特征方面可以具有更强的表达能力。

## 3.3 [[时间滞后独立成分分析]]

[[构象动力学变分方法]]（variational approach to conformational dynamics, VAC）<sup>110</sup> 提供了一个框架，用于从[[传递算子]]的特征函数估计系统的慢模式。[[时间滞后独立成分分析|TICA]] <sup>105</sup> 是实现 VAC 的一种情形，广泛用于[[马尔可夫状态模型]]（Markov state models, MSMs）。<sup>111</sup> 在马尔可夫过程中，TICA 试图针对某个大于零的时间滞后寻找最大相关性的投影向量。它本质上通过求解如下广义[[特征值]]问题来实现这一点：

$$
C _ {\tau} \mathbf {r} = \lambda_ {i} \Sigma \mathbf {r}\tag{21}
$$

其中 $C _ { \tau }$ 是时间滞后相关矩阵，r 是具有[[特征值]] $\lambda _ { i } .$ 的投影向量。

[[时间滞后独立成分分析|TICA]] 仅限于对输入特征进行线性组合以生成[[反应坐标]]（RCs），这对于偏置[[元动力学]]方案而言是最优的，但它限制了动力学模型的可解释性。为解决这一问题，[[Schwantes]] 和 [[Pande]] <sup>106</sup> 应用了[[核技巧]]（[[kTICA]]）来构造非线性反应坐标。通过构建高维特征空间，[[时间独立成分]]（tICs）可以是原始坐标的非线性函数。核方法实现中的一个缺点是其计算相对较慢。随着系统规模 N 增大，它会变得难以处理。此外，在核空间中赋予物理意义也很困难。

## 3.4 [[VAMPnets]]

[[VAMPnets]]<sup>112</sup>实现了一种基于[[马尔可夫过程变分方法]]（VAMP）<sup>113</sup>的深度学习框架，以简化和规范从[[分子动力学|MD模拟]]数据构建[[马尔可夫状态模型|MSM]]的过程。它寻找能够优化VAMP得分的特征变换$\chi _ { 0 }$和$\chi _ { 1 }$；通常使用[[VAMP-2 得分|VAMP-2得分]]，因其适用于基于[[Koopman 算子|Koopman算子]]理论的时间序列数据。<sup>114</sup> 如式22所示，VAMP-2得分$R _ { 2 }$被定义为$n \times n$矩阵A的[[Frobenius 范数|Frobenius范数]]，其中$| | \mathbf { A } | | _ { F } ^ { 2 } = n ^ { - 1 } \Sigma _ { i , j } A _ { i j } ^ { 2 }$和$C _ { 0 0 } , C _ { 0 1 } , C _ { 1 1 }$为[[协方差矩阵]]。当最显著的Koopman奇异函数（前m个左、右奇异函数）张成相应特征$\chi _ { 0 }$和$\chi _ { 1 }$的子空间时，VAMP-2得分达到最大。

$$
R _ {2} [ \chi_ {0}, \chi_ {1} ] = | | C _ {0 0} ^ {- 1 / 2} C _ {0 1} C _ {1 1} ^ {- 1 / 2} | | _ {F} ^ {2}\tag{22}
$$

因此，最优特征$\chi _ { 0 }$和$\chi _ { 1 }$能够捕捉系统的慢动力学。与[[时间滞后独立成分分析|TICA]]类似，[[VAMPnets]]利用转移算子对特征函数进行排序，并识别系统的相关模式。

[[VAMPnets]]的架构通常由两个相同的网络分支组成，它们采用带有[[软多路输出层|softmax输出层]]的全连接网络进行[[降维]]、离散化和特征化。这两个网络分支分别被训练以学习特征$\chi _ { 0 }$和$\chi _ { 1 }$。由于softmax层提供的是离散化[[亚稳态]]状态的表示，它在某种程度上不太适合[[增强采样]]。尽管VAMPnets的主要用途是通过状态聚类来分析动力学，[[Ferguson]]等人提出了具有线性和非线性[[输出层]]的[[无状态可逆VAMPnets]]（SRVs）<sup>115</sup>。与[[时间滞后独立成分分析|TICA]]不同，该方法以转移算子方法为主要目标，无需[[核技巧]]。

## 3.5 [[状态预测信息瓶颈]]

通过从压缩数据中捕获相关或有意义的信息，基于[[信息瓶颈]]（IB）<sup>116</sup>的方法在模型准确性与复杂性之间实现最大化权衡。由此得到的正则化低维表示随后可用于近似[[反应坐标|RC]]。这里我们聚焦于[[状态预测信息瓶颈]]（SPIB）。<sup>117</sup> SPIB试图在给定时间延迟$\Delta t ,$的条件下对系统的[[亚稳态]]状态进行离散化，同时优化RC。为改善潜在空间正则化，它使用[[VampPrior]]<sup>113</sup>高斯混合作为先验分布。RC由[[集体变量|CV]]的加权组合近似，并在训练过程中实时更新。用户可以自由选择线性或非线性编码器。所优化的目标函数：

$$
\mathcal {L} _ {I B} = I (z, y) - \beta I (X, z)\tag{23}
$$

来自$\mathrm { R A V E ^ { 1 1 8 } }$的更新版本，该版本使用两个[[互信息]]之差。在式23中，$I ( z , y )$是由潜在表示z与目标预测y之间的互信息所表示的预测能力。第二项$\beta I ( X , z )$是由潜在表示与输入X之间的互信息所定义的模型复杂度。

## 3.6 [[基于图的反应坐标构建]]

作为寻找具有物理意义的集合变量（[[集体变量|CV]]）来完整而准确地描述系统这一困难任务的替代方案，[[图神经网络]]（GNNs）已成为一种解决办法。GNNs 不再使用手工设计的 CV，而是被用来自动化其选择，甚至进一步绕过对它们的需求。<sup>119,120</sup> 除这一优势外，它们还因其对原子或分子系统的直观表示而日益受到欢迎。

一个图由 V 个节点和 E 条边组成，通常记作 $\mathcal { G } ( \nu , \varepsilon )$ 。图具有三个基本组成部分：节点特征、边特征和边索引。节点特征编码每个原子或每个单元的特性，例如种类、质量、电荷或其他相关属性。在最简单的情况下，单个原子被分配到一个节点。边特征通过例如[[欧几里得距离]]度量来描述节点之间的连接。边索引或[[邻接矩阵]]表示哪些节点是相连的。[[图神经网络|GNN]] 的一个显著特点是其使用[[消息传递]]，通过节点之间的信息交换来更新模型。就其架构设计而言，它有助于在平移和旋转变换中保持对称性，并可以使其具有不变性<sup>68</sup>或等变性。<sup>121</sup>

由于原子坐标可以作为输入，已有方法利用 [[图神经网络|GNN]] 提供的灵活框架来提取系统的慢模式。<sup>122</sup> 图 5 展示了一些遵循这一目标的工作流程。图 5（a）是 [[GraphVAMPnets]] 中使用的示意图，其中系统的维度被降低，以优化 [[马尔可夫过程变分方法|VAMP]]-2 分数，从而揭示慢模式。<sup>122,123</sup> 图 5（b）显示了通过[[多层感知机]]的实现来学习[[成核]] [[集体变量|CV]] 的示意图。<sup>120</sup>

鉴于已经提出的大量[[基于图的反应坐标构建|基于图的方法]]，下面我们介绍其中一些关键方法：

1. GraphVAMPnet：作为对 [[VAMPnets]] 的一种修改，以包含图表示，[[GraphVAMPnets|GraphVAMPNets]]<sup>123</sup> 能够高效地学习系统动力学，同时有助于得到更具可解释性的马尔可夫模型。蛋白质图表示的构建会考虑蛋白质 $C _ { \alpha }$ 原子的 M 个最近邻。边嵌入由式 24 中所示的相邻节点距离表示：

$$
e _ {i j} ^ {t} = \exp \biggl (\frac {- (d _ {i j} - \mu_ {t}) ^ {2}}{\sigma^ {2}} \biggr)\tag{24}
$$

其中 $e _ { i j }$ 是高斯距离，$d _ { i j }$ 是原子 $i , j$ 之间的距离。随后按以下方式更新节点嵌入：

$$
v _ {i} ^ {k + 1} = v _ {i} ^ {k} + \Sigma_ {j \in N _ {i}} w _ {i, j} ^ {k} \odot g (z _ {i, j} ^ {k} W _ {c} ^ {k} + b _ {c} ^ {k})\tag{25}
$$

![](<../2.SCI_MD/Machine learning driven advances in molecular dynamics of bulk and interfacial aqueous systems/images/98c6f259f82a7e8c0e1e43957efc643501f3bd18c8089edf1af72378910a21d8.jpg>)

![](<../2.SCI_MD/Machine learning driven advances in molecular dynamics of bulk and interfacial aqueous systems/images/61bde56a3947f0b2ad4f74b37529115f267154775a00ccaac1151d6dfa2bc109.jpg>)  
图 5：（a）GraphVAMPnet 工作流程示意图。<sup>123</sup> 对于给定时间 t 和时间滞后 $t - \tau$，使用最近邻方案从分子结构创建相应的图结构。经过图卷积运算后，进行层次化池化以得到完整图的潜在表示，该表示将时间 t 和 $t - \tau$ 结合起来，用于优化 VAMP-2 分数。（b）用于学习成核的 GNN 模型 $\mathrm { C V s . ^ { 1 2 0 } }$。图结构同样通过最近邻算法创建。笛卡尔坐标通过多层感知机嵌入到更高维表示中，并由邻域信息进行更新。最终使用一个池化层进行最终预测。图（a）和（b）分别转载自参考文献<sup>123</sup>（版权 2022，AIP）和参考文献<sup>120</sup>（版权，CC BY）。

其中，i 表示第 $k ; ~ W _ { c }$ 层的节点，$b _ { c }$ 分别为卷积权重与偏置；$z _ { i , j } ^ { k }$ 是第 k 层节点 $i , j$ 与边嵌入 $e _ { i j } { \mathrm { : } }$ 的拼接；$w _ { i , j } ^ { k }$ 为 sigmoid 函数；$g ( \ u )$ 为边门控机制。<sup>124</sup> 随后使用[[图池化层]]来捕获整个图的嵌入。

为学习[[蛋白质折叠]]动力学中节点的特征表示，采用了 [[SchNet]]，<sup>69</sup> 一种[[连续滤波器 CNN]]。因此，边属性通过[[径向基函数]]（式 26）计算，随后输入到一个滤波器生成函数中，该函数将这些属性映射为相应的滤波器。

$$
e _ {i j} = \exp (- \gamma (d _ {i j} - \mu_ {t}) ^ {2})\tag{26}
$$

当应用于节点嵌入时，该滤波器使 [[SchNet]] 交互模块能够更新原子 i 邻域内每个原子 j 之间的[[多体相互作用]]。通过额外的[[注意力层]]，嵌入会根据赋予边嵌入的重要性进行更新。与 [[VAMPnets]] 一样，使用 [[VAMP-2 得分]]的最大化进行验证。[[自由能面|自由能景观]]的重建显示出[[亚稳态]]之间清晰的分离。

2. [[图神经网络]] - [[状态预测信息瓶颈]]：[[GNN-SPIB]] 对 SPIB 进行修改以包含基于图的输入，利用图表示的优势，无需手工选择特征输入，从而实现全自动化过程。给定一条输入轨迹，每个时间帧被定义为一个图的几何表示。因此，SPIB [[损失函数]]被修改如下：

$$
\mathcal {L} = I (z, \mathrm{S} _ {t _ {n} + \Delta t}) - \beta I (G _ {t _ {n}}, z)\tag{27}
$$

其中 G 表示时间 $t _ { n }$ 处的输入图，$\mathrm { S } _ { t _ { n } + \Delta t }$ 类似于式 23 中的目标 y。为保持 [[图神经网络|GNN]] 的[[置换不变性]]，需要遵循在[[消息传递]]中包含不变输入特征以及不变操作。鉴于这一性质，图消息传递层在选择 GNN 架构时具有灵活性。值得注意的是，考虑到[[增强采样]]方法，某些方案可能在计算上比其他方案更高效。

3. [[geom2vec]]：geom2vec<sup>125</sup> 从[[自然语言处理]]（NLP）的 [[word2vec]] 模型中获得启发，旨在通过预训练的 [[图神经网络|GNN]] 将笛卡尔坐标映射为向量表示。此外，它使用对原子坐标的去噪目标来提升性能。为确保向量表示能够随物理系统相应变换，采用了 [[ViSNet]]<sup>126</sup> 架构，这是一种等变几何图 [[Transformer]]。在该架构上预训练时，最后一个[[消息传递]]层的激活参数被用作后续任务的输入。其流程是向系统坐标中加入来自多元高斯的位移以供学习，类似于学习一个[[力场]]。由于节点级图具有高维性，训练后的计算可以通过[[粗粒化]]操作在原子子集上进行。给定原子 i 的学习表示 $\mathbf { h } _ { i }$，由式 28 定义的粗粒化表示 $\bar { \mathbf { h } } _ { S _ { m } }$ 表示平均几何信息，称为“token”。$S _ { m }$ 表示属于某个 token 的原子子集。训练好的 geom2vec 模型随后可以像 Pengmei 等人所做的那样，用 [[马尔可夫过程变分方法|VAMP]] 或 [[状态预测信息瓶颈|SPIB]] 框架进行评估，以验证系统的动力学。<sup>125</sup>

$$
\bar {\mathbf {h}} _ {S _ {m}} = \sum_ {i \in S _ {m}} \mathbf {h} _ {i}\tag{28}
$$

4. 基于图的[[成核]][[集体变量]]：早在深度 [[图神经网络|GNN]] 出现之前，以各种形式涉及图的思想就已经被广泛用于增强和分析成核现象。利用胶体系统，[[Dietrich]] 等人<sup>120</sup> 构建了一个基于图的模型来近似成核的 CV。鉴于成核是一种难以观察的复杂机制，这些 CV 通常包括[[配位数]]和[[六阶 Steinhardt 参数]] $( n ( Q 6 ) )$ 。由于 [[Steinhardt 序参量]]基于[[球谐函数]]，而球谐函数的线性组合具有旋转不变性，因此它们满足图表示的合理性。如式 29 所示，图级 CV 预测器 $\phi$ 通过 ⊕ 表示的置换不变池化来池化节点 $\mathbf { x } _ { i }$ 。

$$
f (\mathbf {X}) = \phi (\oplus \psi (\mathbf {x} _ {i}))\tag{29}
$$

为确保图的连接能够用于全局和[[节点级预测]]，对各个邻居执行类似的池化操作：

$$
f (\mathbf {X}) = \phi \bigg (\oplus \psi_ {N} \bigg [ \mathbf {x} _ {i}, \sum_ {j \in \mathcal {N} _ {i}} c _ {i j} \psi_ {E} (\mathbf {r} _ {i j}) \bigg ] \bigg) = \phi (\oplus \mathbf {h} _ {i})\tag{30}
$$

其中 E 和 N 分别表示[[边预测]]和节点预测。$\psi$ 是一个多层感知器，它映射到节点向量 $\left( \psi _ { N } \right)$ ，或进行边级预测 $( \psi _ { E } ) . ~ c _ { i j }$ 是边权重，假定为常数并设为 1。$\mathcal { N } _ { i }$ 是节点 i 的邻域。这类似于定义内部表示 $\mathbf { h } _ { i }$ ，其中包含关于其最近邻的节点信息。修改式 30 以考虑 [[集体变量|CV]] n(Q6)：

$$
f (\mathbf {X}) = \sum_ {i} \phi (\psi_ {N} [ \mathbf {x} _ {i}, (\mathbf {x} _ {j} | j \in \mathcal {N} _ {i}) ])\tag{31}
$$

其中 $\begin{array} { r } { \psi _ { N } = \sum _ { j \in \mathcal { N } _ { i } } \sum _ { m = - 6 } ^ { 6 } q _ { 6 m } ^ { * } ( i ) q _ { 6 m } ( j ) } \end{array}$ 且 $\phi ( \psi _ { N } ) = 1 \mathrm { i f } \psi _ { N }$ 高于某个阈值。由于模型预测缺乏 $\mathrm { E ( 3 ) }$ 不变性，它需要学习适当变换对 [[集体变量|CV]] 的影响。因此，在约化坐标空间中计算用于边级 $\mathbf { r } _ { i j } = \mathbf { x } _ { j } - \mathbf { x } _ { i }$ 预测的向量 $\phi _ { E }$ ，将使计算更易于处理。

## 4 基于 [[机器学习|ML]] 的 [[分子动力学|MD 模拟]]在体相和[[界面水]]体系中的应用

## 4.1 [[水溶液]]的结构与动力学

## 4.1.1 [[体相水]]

尽管带有[[机器学习力场|机器学习力场（MLFF）]]的[[分子动力学|分子动力学（MD）模拟]]近年来日益流行，用于[[体相水]]的 MLFF 实际上已经发展了相当长的时间。2002 年，[[Cho]] 等人引入了一种[[误差反向传播算法]]来增强 [[TIP4P 模型]]，使其可极化，并提高了其准确重现与实验观测一致的势能的能力。<sup>127</sup> 最近，通过使用[[路径积分 DFT-MD 模拟]]进行训练，[[DeePMD|DeePMD MLFF]] 重现了体相水的[[径向分布函数]]和[[角度分布函数]]，以及其他小有机分子的相应函数，与使用 [[SCAN 泛函]]的 [[DFT]] 模拟结果相当。<sup>51</sup> 液态水的另一个在模拟中未受到足够关注的特征是其[[介电常数|介电响应]]。水的另一个关键性质是其[[多极矩]]，它们强烈影响水环境中带电物种的行为。尽管固定电荷经典 MD 可以计算这些量，但缺乏极化会导致不准确性；因此，更倾向于使用具有 [[DFT-MD]] 级精度的计算。[[DeePMD 机器学习力场|DeePMD]] 框架可以利用 [[分子动力学模拟|MD 模拟]]中的[[最大局域 Wannier 函数|最大局域 Wannier 函数（MLWF）]]学习电子结构，从而能够预测体相水的介电常数。<sup>128,129</sup> 在具有[[周期性边界条件]]的 MD 模拟中计算介电常数，需要在纳秒时间尺度上进行模拟，以实现偶极涨落的收敛。<sup>130–133</sup> 使用 DeePMD，可以在纳秒时间尺度上高效地对 512 个水分子进行 MD 模拟，准确重现与 [[密度泛函理论|DFT-MD]] 结果一致的水的多极矩。这些模拟已在多种几何构型下开展，包括单个水分子、体相水以及半径为 4 <sup>˚</sup>A 的水空腔。<sup>134</sup> 对于体相水等简单体系，使用高水平量子数据（例如金标准 [[CCSD(T)]] 方法）训练 MLFF 是可行的，并且可以显著改善径向分布函数峰高的预测。<sup>135</sup> 然而，[[力场|经典力场]]通常在不包含极化的情况下模拟水，或依赖经验极化，这缺乏“第一性原理”方法的严谨性。因此，由经典 MD 模拟计算得到的介电常数高度依赖于所选定的、预定义的水模型，这凸显了 MLFF 在弥合这一差距方面的优势。

## 4.1.2 [[离子溶液]]

与[[体相水|本体水]]相比，在存在溶质的情况下对[[水溶液]]进行建模，给基于[[机器学习力场]]的[[分子动力学|分子动力学模拟]]带来了更大的挑战。溶质既包括简单离子，也包括分子离子，这些溶质通常带有电荷，因此即使对于最简单的离子，[[机器学习]][[力场]]也必须准确确定其部分电荷；而在模拟高价过渡金属离子时尤其如此，因为这些离子具有强极化效应和复杂的原子轨道构型。在经典力场中，一种简单的做法是对电荷进行分数缩放；然而，最优的缩放系数并不容易事先确定。利用 [[DeePMD|DeePMD 框架]]，[[Lu]] 等人研究了由 $\mathrm { M g C l _ { 2 } }$、[[NaCl]]、KCl 以及微量水组成的熔融混合物。结果表明，采用机器学习力场的[[分子动力学模拟]]在预测密度、扩散和黏度等热力学性质方面，可以达到与 [[DFT-MD]] 相当的精度。<sup>136</sup> [[Chen]] 等人使用机器学习力场研究了不同温度下 $\mathrm { L a C l _ { 3 } { - } H _ { 2 } O }$ 溶液的结构。<sup>137</sup> 类似地，基于 [[DeePMD 机器学习力场|DeePMD]] 的机器学习力场也成功以 [[DFT]] 级别的精度再现了其他高价金属离子的分子动力学模拟，包括 $\mathrm { Z n ^ { 2 + } , ^ { 1 3 8 } \ M n , ^ { 1 3 9 } \ C a ^ { 2 + } }$ 2 和 $\mathrm { M g ^ { 2 + 1 4 0 , 1 4 1 } }$。

除了计算离子的溶剂化结构之外，模拟[[水溶液]]中电解质的动力学行为既具有挑战性，也十分引人关注。要获得收敛的动力学性质，需要较大的模拟盒子和足够长的模拟时间，而这些在 [[DFT-MD]] 模拟中很难实现。这一限制使[[机器学习力场]]非常适合用于研究此类体系。目前已利用[[机器学习]][[力场]]计算了一系列在 [[DFT]] 水平上原本难以获得的典型动力学性质，包括水和离子的扩散与转动运动、[[氢键]]寿命，以及液体黏度和[[介电常数|介电响应]]等宏观性质。<sup>142</sup> [[Balasubramanian]] 等人利用 [[DeePMD 机器学习力场]]对 [[NaCl]] 和 [[CsCl]] 溶液进行了[[分子动力学|分子动力学模拟]]，该力场通过采用 [[revised PBE 交换关联泛函]]并引入 [[D3 色散校正]]的 [[密度泛函理论|DFT]] 模拟训练得到。<sup>143</sup> [[CsI]] 溶液会加速水的扩散，而 [[NaCl 溶液]]则会降低水的扩散。然而，非[[极化力场]]预测两种离子周围的水动力学都较慢，这反映出它们无法分辨依赖于离子种类的细微水合效应。[[DeePMD]] 也被用于模拟 NaCl 溶液，揭示了盐溶液随盐浓度升高而降低介电常数的机制。<sup>144,145</sup>

## 4.1.3 [[界面水]]

另一类受益于[[机器学习力场|机器学习力场（MLFFs）]]的体系是[[界面水]]，包括平面界面、缺陷表面、纳米受限环境以及一维纳米管内的水。<sup>14,131,146–152</sup> 一般而言，[[水溶液|水相]]界面在材料科学中具有关键作用，尤其是在电化学、[[催化剂|催化]]和[[清洁能源]]应用中。[[体相水]]与界面水之间存在显著差异的一个性质是降低的[[介电常数]]。尽管已提出若干假说来解释这一行为，但一个被广泛接受的观点是，固体界面有效地截断了体相水环境；液体之外缺少介电介质，抑制了长程偶极–偶极相互作用，从而降低了整体介电响应。<sup>153</sup> 这种效应在[[水-空气界面|水/空气界面]]尤为显著，因为空气一侧没有分子。依赖局域原子环境的[[机器学习]][[力场]]难以准确再现某些性质，因为学习[[长程相互作用]]并非易事。[[Limmer]] 及其合作者证明，引入显式[[静电相互作用]]的机器学习力场能够在训练难度与准确性之间取得良好平衡。<sup>154</sup> 另一个有前景的解决方案是[[自洽场神经网络]]（self-consistent field neural network, SCFNN）的发展，<sup>155</sup> 它将短程与长程相互作用分离，以克服仅依赖短程结构的机器学习力场的局限（图6a）。SCFNN 能够准确再现水在高达 $3 \ \mathrm { V / n m }$ 的均匀外电场下的介电响应。这些模拟中水的介电性质通过水取向参数 $\langle \cos \theta ( z ) \rangle$ 来表征，其中 $\theta ( z )$ 是距表面距离 z 处表面法线与水[[偶极矩]]矢量之间的夹角，⟨...⟩ 表示对所有水分子的平均。该性质也被用于估算非线性光学实验中观测到的水[[振动光谱预测|振动光谱]]信号。<sup>16</sup> 在带电表面处，界面水会屏蔽来自表面的电场，从而在体相水区域产生 $\langle \cos \theta ( z ) \rangle = 0$。在使用 SCFNN 的[[分子动力学|分子动力学模拟]]中，体相水中未观察到优先取向，这与实验观测一致。然而，[[Behler–Parrinello 分子动力学模拟]]预测体相水中存在长程取向有序，未能捕捉到预期的电场屏蔽效应（图6b）。这一发现表明，仅基于短程相互作用的机器学习力场无法完全再现长程相互作用的影响。机器学习力场也已被用于研究冰/空气界面，该界面在冰的融化及其对气候变化的影响中起着关键作用。例如，机器学习力场已被用于研究冰生长的动力学。<sup>156</sup> 当纳入[[核量子效应]]（nuclear quantum effects, NQE）时，可观察到冰的电子带隙缩小，尤其是在冰相中。这表明冰中的质子离域显著影响其物理和化学行为。<sup>157</sup>

[[机器学习力场|机器学习力场（MLFF）]]越来越多地被应用于材料表面模拟，以研究[[界面水]]的结构与动力学。例如，[[Selloni]] 及其合作者在小有机分子（如甲酸和乙酸）存在下，对水$/ \mathrm { T i O _ { 2 } }$界面进行了[[分子动力学|分子动力学模拟]]。<sup>158</sup> 这些模拟揭示了水密度和[[径向分布函数]]如何受到有机酸[[吸附]]的影响。$\mathrm { T i O _ { 2 } }$表面在材料科学中的重要性促成了其他若干[[分子动力学模拟]]研究，以探索其结构与性质。<sup>159–161</sup> 研究界面水的动力学通常需要较长的模拟时间，而由于计算成本的原因，[[DFT-MD]] 模拟难以实现这一点。例如，[[Yang]] 及其合作者研究了多种金属表面上的水，并观察到这些表面附近水分子存在超扩散转动，而它们的振动状态和平动动力学仍与[[体相水]]相似。<sup>162</sup> 除了预测结构与动力学外，使用 MLFF 的分子动力学模拟也被用于探索界面处的化学和物理性质。例子包括预测水/$\mathrm { L i M n _ { 2 } O _ { 4 } }$界面的自旋态，<sup>139</sup> 水的[[多极矩|分子多极矩]]，<sup>134</sup> [[Helmholtz 电容]]，<sup>163</sup> 以及[[水溶液]]界面处的[[能带对齐]]。<sup>164</sup> 界面水的一个众所周知的现象是其[[介电常数]]降低。为了研究这一行为的来源，[[Michaelides]] 及其合作者观察到，紧邻固体表面的第一层水分子呈反平行排列，并且其[[偶极矩]]有所减小。<sup>165</sup> 这些效应限制了水分子垂直于固体表面的取向涨落，从而导致介电常数被抑制。MLFF 还被用于研究[[碳纳米管]]内部受限的水，这种水形成独特的一维水结构，与体相水及平面界面处的水不同。[[Pham]] 及其合作者观察到碳纳米管内水沿轴向的介电常数增强，并将其归因于水偶极取向和集体相的变化。这项工作突出了 MLFF 如何有效结合从头算分子动力学的优势（如准确的电子性质）与[[经典分子动力学]]模拟的优势（后者能够高效地捕捉分子构型和动力学）。<sup>166</sup>

除了描述水全局拓扑的图特征外，局部序参量对于区分水分子的结构环境仍然至关重要。一种广泛使用的局部描述符是[[四面体序参量]]，它表征水分子[[氢键]]环境在多大程度上类似于冰状或液态结构。<sup>179</sup> 研究发现，该参量与[[水解离|水自电离]]之间存在强相关性。<sup>180</sup> 除了人类直觉可理解的描述符之外，基于[[机器学习]]的描述符，尤其是来自[[无监督学习]]的描述符，为提取有意义的结构信息提供了独特视角，并具有广泛适用性和合理的训练成本。<sup>50</sup>

对于[[机器学习]]模型而言，[[SOAP 描述符]]在区分水和晶体的相态方面应用广泛。<sup>181–184</sup> 将 [[原子位置平滑重叠|SOAP]] 描述符与[[本征维度]]估计相结合，为探测离子水合壳层的结构与动力学特征提供了稳健框架。这种组合方法还使人们对 [[Hofmeister 序列]]中所阐述的“结构形成剂”和“结构破坏剂”等经典概念进行更定量的评估成为可能。<sup>185</sup> 如第 2.2 节所述，SOAP 也被广泛用于构建[[机器学习力场]]。最近，[[Pavan]] 及其同事开发了 [[timeSOAP]]，利用时间序列 SOAP 描述符揭示局部水环境的动力学。<sup>186</sup> 在后续工作中，他们引入了一种无监督“洋葱”聚类方法，以完全数据驱动的方式识别微观环境中的涨落和动力学，从而区分冰–水界面。<sup>187–189</sup> 时间序列轨迹还被用于识别液态水的集体角跳跃<sup>190</sup>、铁电特征<sup>191</sup>以及过冷水的[[振动光谱预测|振动光谱]]。<sup>192</sup> 尽管 SOAP 是一种通用描述符，但其行为与特定序参量不同，例如[[四面体序参量|取向四面体序]]、平移四面体序、局部结构指数、到第五个氧原子的距离、[[配位数]]、[[氢键]]数目以及 Voronoi 密度。值得注意的是，SOAP 难以充分捕捉诸如氢键之类的离散结构特征，而这些特征对于理解水的局部结构至关重要，这表明序参量的通用性与特异性之间的权衡需要引起关注。<sup>193</sup> 这凸显了持续开发专门化描述符以有效捕捉水结构特定性质的必要性。

许多复杂的过程，例如生物化学中的配体结合，可以通过模型模拟来研究，比如小有机分子在特定设计的固体表面上的[[吸附]]。[[Beyerle]] 及其合作者设计了单个 [[Lennard-Jones 势|Lennard-Jones]]（LJ）粒子和 $\mathrm { C _ { 6 0 } }$ 分子吸附到球形口袋中的模拟，并发现熵和焓在解结合过程中的作用。对于 LJ 粒子，解结合主要由粒子溶剂化的变化主导，而对于较大的 $\mathrm { C _ { 6 0 } }$ 分子，则需要口袋的去润湿。此外，为了设计具有一定亲水性的材料，[[Patel]] 和 [[Shell]] 设计了[[机器学习]]模型，从特定化学官能团出发预测水在包含亲水和疏水单元的图案化表面上润湿的[[自由能]]。<sup>194,195</sup> 与无机材料建模中广泛使用的有序表面不同，这些表面极其异质，而机器学习可以很好地识别这些图案。

## 4.2 [[质子转移]]

## 4.2.1 体相溶液中的[[质子转移]]

[[体相水]]中最简单的化学反应是[[水解离|水的自电离]]，这是[[质子转移]]的一种特殊情况，对该体系的模拟已有很长的历史。<sup>196,196–201</sup> 在纯水中，$[ \mathrm { H ^ { + } } ] = [ \mathrm { O H ^ { - } } ] = 1 0 ^ { - 7 }$ 的浓度为 mol/L，对应于约 40 kJ/mol 的[[能垒]]。<sup>180</sup> 虽然此类体系中 [[DFT]] 泛函的选择长期存在争议，但一个更重要却常被忽视的限制是采样。通常，[[DFT-MD]] 模拟在几皮秒的时间尺度上进行，且模拟盒子包含约一百个水分子。因此，由于计算条件的限制，导致质子或氢氧根离子外层水合壳结构出现伪影的有限尺寸效应，削弱了 [[密度泛函理论|DFT-MD]] 中质子转移计算的准确性，因为要准确恢复类体相行为，需要长度为数纳米的模拟盒子。此外，克服与质子转移相关的较大能垒，需要使用精心设计的[[增强采样]]技术。然而，DFT-[[分子动力学|MD]] 中有限的采样使得涉及复杂集合变量（[[集体变量|CV]]）的模拟无法达到收敛，导致在使用诸如 DFT 水平下的 OH 键长或 OH [[配位数]]这类简化 CV 时，由于构象细节的丢失，质子转移过程的估算出现误差。

幸运的是，[[机器学习力场|机器学习力场（MLFF）]]有效地解决了这一问题。[[Calegari]] 等人利用 [[SCAN 泛函]]训练[[深度神经网络]]，<sup>202</sup> 在包含 64 至 1024 个水分子的模拟盒子中计算了[[水解离|水的自电离]]，<sup>203</sup> 并表明，当模拟包含 500 个或更多水分子时，预测的水自电离[[自由能]]趋于收敛。

有限尺寸效应主要影响$\mathrm { H _ { 3 } O ^ { + } }$与$\mathrm { O H } ^ { - }$的分离，精确结果所需的最小分离距离约为0.8 nm。尽管得益于不断增长的计算资源，包含数千个原子的[[DFT-MD]]模拟现已可行，但[[机器学习力场|MLFF]]使这类模拟的开展显著更为便捷。此外，MLFF还能实现跨越数十纳秒的模拟，远超传统[[密度泛函理论|DFT-MD]]可达到的时间尺度。通过分析这些更长模拟得到的轨迹，可以对[[质子转移]]机制获得更深入的物理认识。例如，[[Liu]]等人揭示了一种涉及三个质子的异步协同质子转移机制，并确定了分子内电场与质子转移过程之间的相关性。<sup>204</sup>

[[质子转移]]事件在酸性或碱性溶液中更为常见，此时[[水合氢离子]]$\mathrm { ( H _ { 3 } O ^ { + } ) }$或氢氧根离子（OH<sup>–</sup>）与抗衡离子一同被引入。<sup>2,140</sup>在这些条件下，质子转移会自发发生，导致$\mathrm { H _ { 3 } O ^ { + } }$和$\mathrm { O H } ^ { - }$在水中通过Grotthuss机制异常快速地扩散。<sup>205</sup>尽管酸性溶液中的水合氢离子已被广泛研究，但OH的扩散机制在[[机器学习]]方法下仍探索不足，尽管它与$\mathrm { H _ { 3 } O ^ { + } }$的扩散机制显著不同。<sup>206</sup>一个尤其存在争议的话题涉及水合氢离子中[[过剩质子]]的结构。它既可以归属于单个氧原子，形成Eigen离子$\mathrm { ( H _ { 3 } O ^ { + } ) }$），也可以由两个水氧原子共享，从而形成Zundel离子$\mathrm { ( H _ { 5 } O _ { 2 } ^ { + } ) }$。然而，基于OH距离的[[反应坐标]]往往无法捕捉与共享质子相关的[[亚稳态]]，这与二维[[红外光谱]]中观察到的两种振动模式相矛盾。<sup>205</sup>借助[[机器学习力场|MLFF]]，已计算出水合氢离子中质子转移的新[[自由能面]]（FES），以质子不对称势能和水合氢离子的[[氢键]]数（用氧-氧[[配位数]]表示）作为[[集体变量]]（图8b）。这些计算表明，亚稳态并非源于过剩质子的位置，而是源于氢键数的变化。对于传统的Eigen水合氢离子对$\left( H _ { 2 } O _ { a } - H ^ { + } \cdot \cdot \cdot H _ { 2 } O _ { b } \right)$，氧原子$( O _ { a } )$

提供两个[[氢键]]，而 $O _ { b }$ 通常从溶剂水中接受另一个氢键。由于 $O _ { a }$ 并未形成完整的[[四面体氢键网络]]，[[过剩质子]]更靠近它。当一个氢键供体离开 $O _ { b }$ 时，质子与 $O _ { b }$ 的结合更强，使其更容易与 $O _ { b }$ “共享”。这一变化导致[[亚稳态]]的出现和[[振动频率]]的偏移。然而，过剩质子并不位于两个氧原子的正中间，这表明完全共享的 [[Zundel 离子]]并不存在，这与以质子位置作为[[集体变量]]的[[自由能计算]]结果一致（图 8a、c 和 d）。<sup>207</sup> 通过[[无监督学习]]模型分析酸性溶液的局域环境也得出了类似结论。[[Hassanali]] 及其合作者开发了一套研究 [[HCl]] 溶液的工作流程：计算 [[SOAP 描述符]]，利用[[最近邻技术]]估计[[本征维度]]，并应用[[降维]]方法[[均匀流形近似与投影]]（UMAP），<sup>208</sup> 结果发现[[水合氢离子]]结构只有一个簇，表明 Zundel 离子和 [[Eigen 离子]]在热力学上不可区分，它们之间的相互转化由涨落驱动。<sup>208</sup>

虽然[[质子转移]]常在酸性溶液中的 $\mathrm { H _ { 3 } O ^ { + } }$ 背景下讨论，但碱性溶液中 OH<sup>–</sup> 的行为受到的关注较少，尽管其性质独特。[[Behler]] 及其合作者对稀 [[NaOH]] 溶液和饱和 NaOH 溶液进行了模拟，并识别出浓度依赖的[[水合交换路径]]。具体而言，水合水分子可以直接离开 $\mathrm { N a ^ { + } }$ 的[[配位壳层]]，也可以先发生质子转移，随后生成的 OH<sup>–</sup> 基团再解离。<sup>209</sup> 在后续工作中，利用[[环聚合物分子动力学]]模型将[[核量子效应]]纳入 [[机器学习力场|MLFF]]。研究发现，尽管核量子效应对 $\mathrm { w a t e r - N a ^ { + } }$ 相互作用的影响可以忽略，但它们显著降低了质子转移的[[能垒]]，凸显了量子效应对准确模拟 NaOH 动力学的重要性。<sup>210</sup>

## 4.2.2 界面附近的[[质子转移]]

对[[体相水]]中[[质子转移]]事件的模拟，为这些复杂过程提供了有价值的结构见解，尤其是在利用[[机器学习力场]]和模型时。从能源[[材料设计]]的角度来看，质子转移尤为重要，特别是当它发生在[[水固界面|水/固界面]][[催化剂|催化]]或[[纳米限域]]条件下时。模拟这些体系需要同时描述液态区和固态区，其中液态区必须足够大，才能在垂直于固体表面的方向上恢复类体相行为，并避免平行于固体表面方向的有限尺寸效应。这使得[[机器学习]][[力场]]非常适合此类模拟，因为它们能够高效处理所需的尺度和复杂性。纳米限域环境会影响质子转移过程的[[反应势垒]]和机制。例如，[[Ogitsu]] 及其合作者模拟了亲水性 $\mathrm { T i O _ { 2 } }$ [[狭缝孔]]内的质子转移，发现由于[[表面羟基]]的协助，[[反应能垒|反应势垒]]显著降低，这凸显了[[表面化学]]在调控反应动力学中的关键作用。<sup>211</sup>

许多能源材料基于[[水固界面|水/固界面]]，其中[[质子转移]]是一个关键过程。<sup>212</sup> 为了模拟这些体系，[[机器学习力场]]已变得越来越流行，因为与传统 [[AIMD]] 模拟相比，它们能显著降低计算成本并增强[[构型采样]]。近期研究已利用[[机器学习]][[力场]]探索了多种界面上的质子转移，包括 $\mathrm { Z n O , ^ { 2 1 3 , 2 1 4 } { \mathrm { G a P , } } ^ { 2 1 5 } { \mathrm { C o O , } } ^ { 1 6 4 } { \mathrm { S n O _ { 2 } , } } ^ { 2 1 6 } { \mathrm { C e O _ { 2 } , } } ^ { 2 1 7 } }$ 和 $\mathrm { T i O _ { 2 } . ^ { 2 1 8 , 2 1 9 } \ B y }$。在这些模拟中，固体超胞的尺寸可以扩展到数纳米，而模拟时间尺度达到纳秒量级——远超 [[DFT-MD]] 的皮秒限制。例如，[[Zhuang]] 及其合作者研究了 $\mathrm { T i O _ { 2 } }$ 不同层中的[[水离解]]，并观察到固体层性质中的[[奇偶振荡效应]]。这些因机器学习力场而得以实现的模拟，为准确模拟 $\mathrm { w a t e r / T i O _ { 2 } }$ 界面所需的最少层数提供了关键见解。<sup>219</sup>

[[二氧化硅]]、[[氧化铝]]及$\mathrm { T i O _ { 2 } }$等氧化物表面与水接触时常带有羟基（OH）基团。这些表面可与水释放或捕获质子，从而形成带电表面。带电表面在[[电化学材料]]中具有广泛应用，并在[[燃料电池]]和[[水分解]]中发挥关键作用。<sup>21</sup> 质子对固体表面的亲和力可用表面与水之间[[质子转移]]相关的[[自由能]]变化来表示，该自由能变化通过[[自由能微扰]]方法计算。<sup>220–222</sup> 然而，由于计算条件的限制，模拟盒子尺寸和水分子数量往往受到限制。随着[[机器学习力场|机器学习力场（MLFFs）]]的出现，这些模拟变得显著更容易实现，并能提供更多物理见解。<sup>223</sup> [[Cheng]] 等人基于 MLFF 对材料科学中常见的多种低指数$\mathrm { T i O _ { 2 } }$表面上的水进行了模拟，包括[[锐钛矿]]（100）、锐钛矿（110）、[[金红石]]（001）和金红石（011）。<sup>224</sup> 通过采用[[核主成分分析]]（图 9a 和 b），他们识别出不同的质子转移和[[水解离机制]]：一步、两步或两者兼有（图 9c）。这种 [[机器学习|ML]] 数据分析与 MLFF 模拟的结合为质子转移过程提供了新的见解。值得注意的是，仅使用 [[DFT-MD]] 采样的构型往往不足以支撑全面的基于 ML 的数据分析，这进一步证明了 MLFF 与 ML [[增强采样]]相结合所具有的增强采样能力和实用性。

固体表面的[[质子化状态]]对表面附近[[双电层]]的行为有显著影响。[[Zhang]] 等人使用基于 [[SCAN 泛函]]的 [[DFT-MD]] 模拟训练的 [[机器学习力场|MLFF]]，研究了[[锐钛矿（101）-水界面]]。<sup>160</sup> 他们研究了四个独立体系，以考察离子和溶液 pH 的影响：（1）纯水，（2）[[NaCl 溶液]]，（3）[[NaCl]] 与 [[NaOH]]，（4）NaCl 与 [[HCl]]。一个关键观察结果是碱性溶液中[[双电层电容]]相对较大，这突出了[[阳离子-表面相互作用]]的作用。这一发现超越了传统[[双电层理论]]的预测，并与实验观测结果高度一致。

除[[材料设计]]外，水科学中长期存在且具有争议的问题之一，是[[水-空气界面|水/空气界面]]的酸碱性。利用 [[机器学习力场|MLFFs]]，研究发现$\mathrm { H _ { 3 } O ^ { + } }$和 [[OH 离子]]都会在界面处累积，尽管它们处于不同区域。这一发现为在表面同时观测到两种离子提供了合理解释。<sup>225</sup> 除平面表面外，MLFFs 还被用于研究 OH 累积如何促进界面处$\mathrm { N _ { 2 } }$气泡的[[成核]]。<sup>226</sup> 这些研究表明，MLFFs 在促进水界面等复杂体系的 [[分子动力学|MD 模拟]]方面具有更强的能力，能够提供传统方法此前难以获得的见解。除水/空气界面外，基于 MLFFs 的模拟还揭示了[[水-石墨烯界面|水/石墨烯界面]]处的质子累积现象。<sup>227</sup>

## 4.3 [[催化剂|催化]]

[[分子动力学|MD模拟]]的一个关键应用是预测化学反应中的[[能垒]]和过渡态构型，这一领域传统上由[[DFT-MD]]主导。[[机器学习力场|MLFFs]]的使用能够在[[催化剂|催化]]过程中对多样化构型进行高效采样，显著扩展了此类研究的范围。此外，[[增强采样]]方法的发展，特别是[[机器学习]][[集体变量]]（ML CVs）的引入，极大地提高了在期望状态间采样的能力，从而能够准确、全面地确定[[自由能面]]，这对于识别过渡态构型和理解催化过程至关重要。在本综述中，我们将讨论生物化学和材料科学中的催化。前者将聚焦于均相催化，而后者将讨论多相催化。

生物化学中的[[催化剂|催化]]，尤其是[[水溶液]]中的反应，是[[机器学习力场|MLFF]]模拟的一个关键应用领域。一个值得注意的例子是磷酸酯键的形成，这是生命起源前条件下生成RNA寡核苷酸的关键步骤。此前，类似研究通常依赖于使用隐式溶剂化模型的静态能量计算，并且主要关注其逆过程——磷酸酯水解。借助MLFFs和即时概率[[增强采样]]（OPES）增强采样方法，Stirnemann及其合作者使用显式水分子进行了微秒尺度的模拟。<sup>228</sup>在该工作中，[[集体变量]]被选为亲核试剂与羟基之间P–O距离的差值，以及它们对水氢原子的[[配位数]]差值（图10a）。研究计算了二维[[自由能面]]（图10b），并通过使用committor分析的过渡路径采样验证了这些选定的集体变量（图10c和d）。该研究需要数百纳秒的模拟，而使用传统[[DFT-MD]]几乎不可能实现，尤其是采用高级别[[DFT]]方法时。MLFF模拟在生命起源中的另一个应用涉及水溶液中的肽键形成。Laage及其合作者利用过渡路径采样确定了两条不同的反应路径：中性溶液中的一般碱催化，以及酸性和碱性溶液中的直接断裂机制。<sup>229</sup>水溶液中的许多化学反应都需要水作为溶剂积极参与。例如，尿素$( \mathrm { N H _ { 2 } } ) _ { 2 } \mathrm { C O } \longrightarrow \mathrm { C N O ^ { - } } + \mathrm { N H _ { 4 } } ^ { + }$和$\mathrm { C N O ^ { - } + N H _ { 4 } ^ { + } + H _ { 2 } O \longrightarrow 2 N H _ { 3 } + C O _ { 2 } }$的分解涉及水介导的[[质子转移]]。在[[密度泛函理论|DFT]]级别下的显式水模型对于准确捕捉这些相互作用至关重要。使用良好调温的[[元动力学]]（well-tempered metadynamics），模拟阐明了水在这些反应中促进质子转移的作用。<sup>230</sup>

多相[[催化剂|催化]]在环境与材料科学中起着关键作用，而[[分子动力学|分子动力学模拟]]为这些过程提供了有价值的见解。通常，环境化学家关注分子在[[水-空气界面|水/空气界面]]上的[[吸附]]，这类吸附主导着空气污染和碳固定等过程。基于[[机器学习]]的[[分子动力学模拟]]能够以合理的计算成本研究复杂反应。<sup>45,231,232</sup> 例如，[[Limmer]] 及其合作者研究了 $\mathrm { N _ { 2 } O _ { 5 } }$ 的吸附，发现其吸收主要发生在水/空气界面，而不是在本体相中。利用[[增强采样|增强采样分子动力学]]模拟，他们探索了 $\mathrm { N _ { 2 } O _ { 5 } , \ H N O _ { 3 } }$ 和 $\mathrm { N O _ { 3 } } ^ { - }$ 在气相、液相以及界面上的相互转化。<sup>17</sup> 界面环境还会影响吸附离子的酸性，其中 $\mathrm { H N O _ { 3 } }$ 和 HCOOH 由于部分去溶剂化而酸性较弱。它们的酸性仅在离开界面几埃之后才恢复到类似本体的行为。<sup>233</sup> 另一个例子是 $\mathrm { C O } _ { 2 }$ 在[[水溶液]]中的溶解，既包括在[[体相水|本体水]]中（图 11a），也包括在纳米受限条件下（图 11b 和 c）。利用马尔可夫态模型分析 [[DFT-MD]] 数据（图 11d 和 e），Pan 及其合作者发现，在本体水中，三水分子参与的[[质子转移]]事件发生得非常快，在不到 200 fs 内完成，并遵循协同机制。然而，在两个石墨烯表面之间的纳米受限条件下，同样的质子转移需要更长时间，表明存在逐步机制。<sup>234</sup> 这项工作突出了将 [[密度泛函理论|DFT-MD]] 模拟与机器学习数据分析相结合来研究化学反应的优势。我们相信，使用[[机器学习力场]]的模拟可以生成更大的数据集，并进一步从这类方法中获益。

## 4.4 以[[成核]]为重点的[[相变]]

凝聚态物质中的[[相变]]本质上是复杂的过程，在微观尺度上涉及多个分子，并且其缓慢动力学往往跨越不止一个长度和时间尺度。<sup>239–242</sup> 这些特征使得传统实验和 [[分子动力学|MD 模拟]]成为研究相变的困难工具。大分子集合在长时间尺度上的参与，要求进行大规模和长持续时间的 [[分子动力学模拟|MD 模拟]]，从而将 [[DFT-MD]] 的适用性限制在相变的特定场景中。即使对于经典 MD 模拟，也总是需要[[增强采样]]技术来克服与液–固[[成核]]相关的高[[反应势垒]]。<sup>96</sup> 对于简单分子，沿特定 [[集体变量|CV]] 的有偏 MD 模拟仍然是研究成核的常用方法。然而，沿高维 CV 进行采样在计算上并不现实，并且依赖人类直觉的 CV 未必能保证最佳性能。为解决这些局限，基于 [[机器学习|ML]] 的 CV 已被开发出来（见第 3 节讨论），为从高维[[构型空间]]探索复杂相变机制提供了更有效的框架。

尽管[[相变]]的类型众多，这里我们首先着重讨论[[成核]]过程。人们或许会认为，对于常以 [[Lennard-Jones 势|Lennard-Jones]] 粒子建模的稀有气体氩而言，成核现象应当较为简单。<sup>243</sup> 然而，氩的成核速率与经典成核理论等理论框架的预测偏差可达数个数量级。<sup>244</sup> 研究氩成核的传统[[集体变量]]包括[[配位数]]的均值与二阶矩，它们分别表征局域密度和密度涨落。Tsai 及其合作者应用谱隙优化方法改进了成核集体变量，量化了成核过程中密度涨落变化的重要性。<sup>245</sup> 利用低频[[元动力学]]，他们计算了速率常数，并发现当考虑配位数的二阶矩和三阶矩时，结果更为准确。在[[水溶液]]中，成核过程更为复杂。Wang 等人研究了 [[NaCl]] 成核，并采用 [[状态预测信息瓶颈|SPIB]] 方法及可解释的[[机器学习]]模型，从一组描述局域离子密度、局域离子有序度和类固态离子数的序参量中分析集体变量。<sup>53,246</sup> 他们的模拟揭示，驱动 NaCl 从[[体相水|本体水]]溶液或熔体中成核的是离子局域结构和类固态离子，而非离子密度。他们提出了一种机制，即成核始于液相中离子在固态前驱体表面上的有序组装。有趣的是，在强[[纳米限域]]下，除了常见的面心立方固相（图 12a 和 c）和液相（图 12b 和 e）外，还观察到额外的非常见相，包括水合 NaCl（图 12d）和六方晶体（图 12f），这与实验结果一致。<sup>247</sup> [[自由能计算]]表明，纳米限域显著增强了固相的稳定性。这一效应归因于石墨烯表面附近离子运动受限所导致的熵抑制，类似于温度降低的效果。为了量化成核的驱动力，研究人员利用热力学可解释的人工智能及其他黑箱范式表征模型评估了模拟中由所选序参量表示的各种物理性质的重要性。<sup>248</sup> TERP 分析强调了水合水的作用，特别是从固态前驱体上的 Cl <sup>–</sup> 去除水合壳层，对成核至关重——

预测多原子分子的[[相变]]比预测 [[NaCl]] 更具挑战性，因为[[成核]]过程不仅必须考虑分子密度，还必须考虑分子的相对取向。<sup>251</sup> 尽管这些性质可以通过人类直观的描述符来捕捉，例如取向熵、<sup>98</sup> 分子序参量<sup>95</sup> 以及局部取向相似性。<sup>252,253</sup> 非参数 [[机器学习|ML]] 描述符提供了一种更通用的框架来区分晶体结构<sup>254</sup> 并分析成核过程中的动力学。<sup>255</sup> 这些描述符还可以被纳入[[增强采样]] [[分子动力学|MD 模拟]]中，以驱动可逆相变，从而实现对成核路径的系统分析。Zou 及其合作者利用基于 ML 的 [[集体变量|CV]]，包括平均分子取向、对取向熵和[[界面水]]性质，研究了尿素和甘氨酸在[[体相水|本体水]]溶液中的成核。<sup>250</sup> 这些 ML CV 使得成核过程的模拟成为可能，并促进了尿素和甘氨酸不同多晶型之间的往返相变，尤其是若干甘氨酸相，包括 α 相（图 12g）、β 相（图 12h）和 γ 相（图 12i），证明了它们在捕捉多原子分子体系的复杂动力学和结构转变方面的实用性。

研究冰相是一个重要课题，代表着物理化学中一个长期存在的问题。<sup>256</sup> 历史上，冰结构的研究在很大程度上依赖于修正的经典水模型。<sup>240,257,258</sup> 虽然 [[DFT-MD]] 提供了详细的见解，但使用 [[机器学习力场|MLFF]] 计算相稳定性效率显著更高，而一个引人关注的挑战是评估同一个 MLFF 能否在不同压力和温度下准确再现液态水和固态水的性质。<sup>259</sup> Car 及其同事采用基于 [[SCAN 泛函]]训练的 [[DeePMD]] 模拟，将种子模拟和 OPES [[增强采样]]与环境相似性 [[集体变量|CV]] 相结合。<sup>260,261</sup> 其结果成功再现了实验[[成核]]速率，并阐明了热力学性质如何影响冰的成核。基于 SCAN 泛函训练的 [[DeePMD 机器学习力场|DeePMD]] MLFF 已被用于区分六方（I<sub>h</sub>）和立方（I<sub>c</sub>）冰结构。这些模拟准确再现了[[相变]]焓和密度的实验值。<sup>262</sup> 此外，利用[[元动力学]]的重加权算法计算了不同相的[[自由能]]，展示了 MLFF 与增强采样技术相结合在捕捉相变复杂性方面的综合能力。<sup>39</sup> 其他 MLFF 也已证明其能够捕捉冰的相图。例如，数据驱动的 [[MB-pol]] 模型，基于使用高精度 [[CCSD(T)]] 方法计算的 [[分子动力学|MD 模拟]]进行训练，能够再现出非常准确的水和冰的相图。这包括在 200–300 K 温度和最高 1 GPa 压力下的液态水以及冰 I<sub>h</sub>、II、III、V 和 VI 相。<sup>33,263</sup>

表面附近的冰形成是一个备受关注的主题，尤其对于理解环境过程和气候变化具有重要意义。Debenedetti 及其同事研究了长石材料附近的冰[[成核]]，重点关注 (100)、(010) 和 (001) 表面。他们的模拟证明了 [[机器学习力场|MLFF]] 在捕捉冰成核过程中的高精度。通过使用包含约 30,000 个原子的模拟盒子，他们达到了 [[DFT-MD]] 几乎无法研究的尺度。<sup>264</sup> 另一个引人关注的研究领域涉及[[纳米限域]]下的冰，通常被称为“二维/单层冰”。MLFF 模拟通过再现二维冰的各种相（图 13a–h）、<sup>265</sup> 带有额外质子的二维冰行为（图 13i）<sup>266</sup> 以及二维冰的[[氢键网络]]，<sup>267</sup> 推进了对这些体系的理解。这些研究显著扩展了我们对异质环境下非常规冰相及其性质的认识。

除了研究水和冰之外，高压下的水是 [[机器学习|ML]] [[分子动力学|MD 模拟]]另一个日益发展的研究领域。<sup>268</sup> Debenedetti 及其合作者解决了水中液-液[[相变]]这一长期存在的问题。通过在一系列温度和压力下对液态水进行模拟，他们执行了网格搜索，并使用双态模型拟合模拟数据。他们的研究结果确定了液-液临界点 $T _ { c } = 2 2 4 \pm 3 \ : \mathrm { K }$ ，P<sub>c</sub> = 2, 687 ± 68 bar，以及 $\rho _ { c } = 1 , 0 7 2 \pm 1 6 \ k g / m ^ { 3 }$ 。<sup>269</sup> 在后续工作中，他们采用[[元动力学]]观察高密度与低密度液态状态之间的来回转变。这些模拟使他们能够计算在特定温度和压力下不同状态的相对[[自由能]]，从而更深入地理解水中的液-液相变。<sup>270</sup> 其他观测得到了不同结果。[[Paesani]] 及其合作者在使用 [[MB-pol]] 模型、体系尺寸为 1,250 个原子的模拟中，确定了 198 K 处的临界点。<sup>271</sup> 此外，[[Hassanali]] 及其合作者使用局部和全局 [[SOAP 描述符]]并结合 [[均匀流形近似与投影|UMAP]] 进行[[降维]]来计算 [[自由能面|FES]]，发现 FES 分别表现出一个或两个局部最小值。这一观测表明，高密度水和低密度水不能仅根据其局部溶剂化结构加以区分。相反，识别水密度变化的长程贡献对于理解宏观密度涨落至关重要。<sup>272</sup>

## 4.5 [[振动光谱预测|振动光谱]]的预测

本综述讨论的最后一个应用是利用 [[分子动力学|MD 模拟]]预测[[振动光谱预测|振动光谱]]。准确预测振动光谱不仅要求模拟给出正确的结构和动力学表示，还需要足够长的模拟时间以获得收敛的光谱。从实验学家的角度来看，虽然振动光谱可以在实验室中测量，但光谱的解释通常依赖其他物理理论模型，例如 EDL 理论或 [[分子动力学模拟|MD 模拟]]。准确的模拟光谱增强了 MD 模拟所提供的微观见解的可靠性，使其对希望理解背后化学过程的化学家而言更易获得且更具价值。

在传统[[经典分子动力学|经典MD模拟]]中，水振动的时间尺度远小于典型模拟时间步长，这常常导致在[[力场|经典力场]]中水OH键被固定。这种方法忽略了振动信息，限制了直接研究[[振动光谱预测|振动光谱]]的可能性。一种解决方案是根据[[分子动力学|MD模拟]]构型估计[[振动频率]]，而不依赖显式动力学或振动模式。Skinner及其合作者开发了一种利用水OH键上电场的二次函数来预测振动性质的方法。<sup>273</sup>该方法已被应用于预测[[体相水]]、<sup>274</sup>离子[[水溶液]]<sup>275</sup>以及[[水-空气界面|水/空气界面]]的红外（[[红外光谱|IR]]）、拉曼和[[和频产生]]（SFG）光谱。<sup>276</sup>该模型此后被扩展用于估计蛋白质中胺基的振动，展示了其在更广泛应用中的通用性。<sup>277</sup>现代[[机器学习|ML]]方法为增强[[分子动力学模拟|MD模拟]]中的振动预测提供了两个新方向。第一种方法是开发ML模型，以直接从经典MD结果估计振动性质。与依赖简单电场描述符不同，分子由基于局部结构的低维描述符表示，例如ACFF或几何描述符，这与[[机器学习力场|MLFF]]中使用的策略类似。包括[[主成分分析]]、[[神经网络]]和随机森林在内的多种ML模型被用作回归工具，将结构描述符映射到振动频率、[[偶极矩]]或极化率，随后可将其用于计算振动光谱。<sup>278</sup>例如，Kananenka及其合作者使用[[高斯回归模型]]预测体相水的振动性质。与二次多项式方法相比，他们的方案在保持合理计算效率的同时将RMSE降低了2倍。<sup>279</sup>为了估计蛋白质等大分子的振动，可以在较小的分子片段上进行[[DFT]]水平的计算。然后使用ML模型识别与特定蛋白质环境对应的小分子构型。这种方法允许从大分子的单体单元推断其性质，从而显著降低计算成本。<sup>280</sup>

另一种[[振动光谱预测]]方法是直接从包含振动信息的 [[分子动力学|MD]] 轨迹计算光谱。[[偶极矩]]和极化率可以在 [[DFT]] 级精度下由模拟轨迹估计，使用经典方法（例如将电荷分配到原子中心），或使用 [[机器学习|ML]] 模型学习极化率。<sup>281</sup> 一些 [[机器学习力场|MLFF]] 框架能够同时生成分子的[[力场]]和极化率，从而可以直接计算 [[红外光谱|IR]] 和 [[拉曼光谱|Raman]] 光谱。<sup>128,282,283</sup> 在界面处，[[和频产生|SFG]] 光谱主要由界面区域而非[[体相水]]贡献，包含表面特定的结构和动力学信息。<sup>25,284</sup> 在[[水-空气界面|水/空气界面]]，由于无需对空气相建模，SFG 光谱已被计算并与 [[DFT-MD]] 模拟结果进行了比较。<sup>285,286</sup> [[Selloni]] 及其合作者计算了[[锐钛矿]]（101）表面附近水的 SFG 光谱，揭示了水覆盖度如何影响与 $\mathrm { T i O _ { 2 } }$ 表面的结合，而这在实验上难以研究。<sup>159</sup> 水振动光谱的计算也扩展到冰。<sup>287</sup> Mauri 及其合作者研究了 VIII 相和 X 相冰的振动光谱，证明[[核量子效应]]降低了这些相之间[[相变]]的临界压力。<sup>288</sup> Tang 及其合作者使用 MLFF 研究了水/[[氧化铝]]界面，计算了 IR、Raman 和 SFG 光谱。他们同时采用了由 MLFF 模块导出的偶极–极化率相关函数（µ − α 方法，图 14a）和直接由模拟轨迹获得的速度–速度相关函数（VVCF，图 14b）。<sup>289</sup> 基于 ML 的计算振动光谱方法已显示出足够的准确性，并且不受水中[[质子转移]]的影响，因此具有高度通用性。这些方法扩展了振动 SFG 计算的适用性，使人们能够更深入地理解水界面，并有助于解释非线性光学实验观测。

## 5 展望与前景

在本综述中，我们讨论了具有 [[机器学习|ML]] [[增强采样]]和 [[机器学习力场|MLFF]] 的 [[分子动力学|MD 模拟]]如何使体相和[[界面水]]体系中复杂物理和化学过程的研究成为可能。

[[机器学习力场|MLFF]] 使 [[分子动力学|MD 模拟]]能够以与传统 MD 相当的计算成本达到高水平的量子精度。这一进展显著扩展了 [[分子动力学模拟|MD 模拟]]的范围，使研究人员能够处理以往难以研究的问题，包括但不限于化学反应[[自由能面]]和[[振动光谱预测|振动光谱]]的计算。然而，该领域仍存在若干挑战：

1. 训练数据的准确性：大多数 [[机器学习力场|MLFF]] 是用[[DFT|密度泛函理论]][[分子动力学]]（[[DFT-MD]]）模拟的数据训练的。然而，

[[机器学习力场|MLFF]] 的固有局限受制于训练所用 [[DFT]] 泛函的精度。若底层 [[密度泛函理论|DFT]] 计算存在系统性误差，这些不准确性将传播到 MLFF 中。例如，色散相互作用对于提高水的 DFT 模拟精度是必要的，而包含此类相互作用的 MLFF 可以改善对水密度和熔点的预测。<sup>290,291</sup>

2. [[机器学习力场|MLFF]] 通常在由 [[DFT-MD]] 模拟生成的数千个构型上进行训练。理想情况下，训练数据集应包括在使用 MLFF 进行生产运行期间可能采样到的所有可能构型。目前，[[增强采样]]方法已被纳入 [[密度泛函理论|DFT-MD]] 模拟中。然而，由于 [[DFT]]-[[分子动力学|MD]] 的时间尺度有限，必须精心准备 MLFF 的训练数据，以尽可能覆盖更广泛的[[构型空间]]。

3. 尽管 [[机器学习力场|MLFF]] 在捕捉短程相互作用方面非常有效，但它们往往难以处理[[长程相互作用]]，而长程相互作用对于准确模拟界面至关重要。

4. 早期的 [[机器学习力场|MLFF]] 在化学元素数量有限的相对简单体系上进行了测试。未来，MLFF 必须能够适应日益复杂的多元素体系。与经典 FF 类似，MLFF 的可迁移性和兼容性需要更多关注，尤其是在涉及水/固体界面的模拟中。最近，基于 LassoLars 算法的 MLFF 已被开发出来，与[[神经网络]]势相比，其在训练集之外构型上表现出更好的可迁移性和外推性能。<sup>292</sup>

当前许多[[增强采样]]方法依赖于 [[集体变量|CV]] 的选择，这些 CV 来源于从 [[分子动力学|MD 模拟]]中获得的结构描述符。通常，使用 [[机器学习|ML]] 模型进行分析时只会选择有限数量的描述符，因为对于大体系而言，包含所有可能的结构特征在计算上是不切实际的。这些选定的描述符往往基于人的直觉，这意味着 ML 模型只能分析被明确纳入 CV 的特征。例如，在从[[水溶液]]中[[成核]]生成 [[NaCl]] 的过程中，溶剂水的移除是成核的关键驱动力。然而，如果在设计 CV 时排除了溶剂效应，ML 模型可能会错误地将反离子的聚集认定为主要驱动成核的特征。<sup>53,247</sup> 尽管这种解释在给定模型内是合理的——因为溶剂的移除会形成由反离子聚集体填充的空腔——但它未能捕捉到溶剂水的关键作用。为克服这一局限，一种解决方案是开发能够自动捕捉复杂结构特征的 CV，例如基于 [[图神经网络|GNN]] 的 CV 所得到的那些特征。<sup>293,294</sup>

在整篇综述中，我们着重介绍了众多利用 [[机器学习力场|MLFF]] 或 [[机器学习|ML]] [[增强采样]]方法的 [[分子动力学|MD]] 研究。这些工具最强大的应用之一，是估算复杂过程的[[自由能面]]。然而，目前大多数研究只采用一种基于 ML 的方法，要么是 MLFF，要么是增强采样。在未来的研究中结合这些方法，具有为进一步洞察复杂体系提供更大潜力的前景。我们预计，随着 ML 技术的不断进步，这类组合模拟将变得更加普遍。此外，大多数增强采样方法侧重于计算[[自由能]]，而计算机理和动力学信息仍然具有挑战性，因为过渡路径采样可能更加昂贵。因此，针对[[界面水|水相界面]]体系中稀有事件机理研究的方法开发仍然需要持续推进。

## 6 总结

总而言之，我们在此讨论了 [[机器学习|ML]] 在[[界面水|水相界面]]体系 [[分子动力学|MD 模拟]]中的作用。我们重点关注了 ML 在这一活跃且关键研究领域中的必要性、ML [[增强采样]]方法带来的进展、ML [[力场]]的发展，以及 ML 在 [[分子动力学模拟|MD 模拟]]中的多样化应用。

我们讨论了 [[机器学习|ML]] 增强 [[分子动力学|MD 模拟]]应用中的五个关键主题。ML 增强 [[分子动力学模拟|MD 模拟]]能够更准确地预测[[体相水]]和[[界面水]]的结构与动力学，捕捉传统方法难以描述的细微行为。借助基于 ML 的 MD 模拟，[[质子转移]]过程现在可以在更长的时间尺度和更大的模拟体系中研究，使研究人员能够以前所未有的细节研究溶剂结构的影响。ML [[增强采样]]与 [[机器学习力场|MLFF]] 的结合，使得[[催化剂|催化]]过程和[[相变]][[反应能垒]]的计算变得可行。通过引入过渡路径采样和[[自由能面]]计算，ML 增强 MD 模拟还可以高精度地量化反应路径。MLFF 促进了大规模、长时间模拟，这对于准确计算[[振动光谱预测|振动光谱]]至关重要，使计算结果与实验测量相一致，并改善对实验数据的解释。尽管 ML 增强 MD 模拟功能强大，但仍有需要改进之处。例如，为了应用[[降维]]方法提取增强采样 MD 模拟的[[反应坐标]]，需要预先定义一系列可能作为反应坐标组成部分的序参量。然而，这些序参量很可能依赖于人的直觉，而目前的降维方法通常还无法找到完全正交的缺失序参量。此外，将 ML 增强采样与 MLFF 相结合，可以扩大可解决问题的范围，为复杂体系提供更深入的见解。机器学习已经彻底改变了 MD 模拟，使人们能够以前所未有的准确性和效率研究复杂的[[水溶液|水相]]和界面体系。随着 ML 方法的不断发展，我们预计将会出现新的工具和组合方法，以应对现有挑战，并开辟水相界面体系模拟的新前沿。
