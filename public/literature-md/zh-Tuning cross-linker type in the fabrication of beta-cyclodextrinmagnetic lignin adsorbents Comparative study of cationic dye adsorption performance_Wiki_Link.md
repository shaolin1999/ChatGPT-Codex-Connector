## 摘 要

本研究考察了使用三种特定[[羧酸]]——[[柠檬酸]]（[[CA 交联剂|CA]]）、[[苹果酸]]（[[MA 交联剂|MA]]）和[[酒石酸]]（[[TA 交联剂|TA]]）作为[[交联剂]]，开发兼具[[磁性硫酸盐木质素]]（[[磁性木质素|MKL]]）与 [[β-环糊精]]（β-CD）独特性质的[[水处理]][[吸附剂]]，从而提高其效率和[[吸附剂稳定性|稳定性]]。通过[[酯化反应|酯化法]]合成[[吸附]]剂，并采用多种分析技术进行[[材料表征|表征]]，包括 X 射线衍射（[[XRD]]）、[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）、场发射[[SEM|扫描电子显微镜]]（[[场发射扫描电子显微镜|FESEM]]）和振动样品磁强计（[[振动样品磁强计|VSM]]）。采用[[响应面法]]（RSM）设计实验并优化条件，以获得去除[[亚甲基蓝]]时的最佳 [[pH]]、[[接触时间]]和[[固液比]]（[[吸附剂投加量|投加量]]）参数。结果表明，在最佳条件下，即 pH 为 11、接触时间为 30 min、投加量为 $0 . 2 ~ \mathrm { g . L } ^ { - 1 } .$ 时，亚甲基蓝[[去除效率|去除率]]可达到约 97%。[[Langmuir吸附模型|Langmuir 模型]]对[[吸附平衡|平衡]]数据的拟合效果最佳，[[最大吸附容量]]为 454.54 mg.g<sup>−</sup> <sup>1</sup>。[[动力学]]分析表明，吸附过程遵循[[准二级动力学模型]]。所得结果凸显了 [[β-CD-TA-MKL]] 作为高效、可持续的亚甲基蓝去除吸附剂的优异潜力。与其他已报道的吸附剂相比，[[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 的显著优势包括更高的[[吸附容量]]、在五次[[吸附剂再生|再生循环]]中表现出卓越的稳定性且性能损失极小、快速的[[吸附动力学]]，以及使用环境友好且经济的材料。

## 1. 引言

[[芳香族污染物]]浓度升高使[[水污染]]成为一个全球性问题。这类污染物是由染整（Zuhara et al., 2023）、纺织、造纸、化妆品和皮革等行业排放的结构复杂且难以[[生物降解性|生物降解]]的化合物（Shindhal et al., 2021）。其中，[[亚甲基蓝]]（MB）是一种[[吩噻嗪盐]]，在碱性水溶液中相对稳定，并会显著降低水体透明度（Sun et al., 2021）。[[吸附|吸附技术]]因其成本低廉（Yatimzade et al., 2024）、操作简便和效率较高（Chahal et al., 2024），被广泛用于高效[[水净化]]。[[活性炭]]、[[纳米纤维]]和[[氧化石墨烯]]等多种[[吸附剂]]被用于吸附过程。然而，这些材料中的许多仍面临不可生物降解、成本高昂（Zong et al., 2018）、合成复杂及分离困难等挑战（Zhong et al., 2022）。这些局限性凸显出，人们日益需要具有高[[吸附容量]]且能快速达到[[吸附平衡]]的低成本吸附剂（Zong et al., 2018）。

日益加剧的环境问题和化石资源的枯竭，使人们对[[纤维素]]、[[壳聚糖]]和[[木质素]]等[[生物质衍生材料|天然生物质衍生材料]]的兴趣不断增加（Wu et al., 2021）。木质素是一种[[芳香族大分子]]，也是造纸和以[[多糖]]为原料的[[生物炼制]]过程的副产物（Li et al., 2021），具有尤为广阔的应用前景。其丰富的[[羟基]]使其能够进行[[化学改性]]（Zhang et al., 2023），但其复杂的[[无定形结构]]以及强烈的[[分子间氢键|分子间和分子内氢键作用]]常常导致聚集，从而降低[[吸附效率]]。所幸，[[接枝]]、[[交联]]、[[聚合]]或[[活性基团取代]]等结构改性方法可以改善其性能，以满足特定应用的需求（Wu et al., 2021）。

[[β-环糊精]]（β-CD）是一种具有[[疏水内腔]]和[[亲水外表面]]的[[大环低聚糖]]（Ghahramaninezhad and Ahmadpour, 2022），因其成本低、[[生物降解性|可生物降解]]及[[环境相容性]]好，在污染物处理领域受到了广泛关注（Zhong et al., 2022）。然而，其[[水溶性]]给实际应用中的分离和收集带来了挑战。通常可通过[[交联]]或[[固定化]]来克服这一局限（Liu et al., 2022）。Rohith 和 Girija 利用 β-CD 和莲（[[莲|Nelumbo nucifera]]）[[农业废弃物]]设计了一种多功能[[聚合物吸附剂]]，证明了其对有毒[[染料]]具有较高的[[去除效率]]和优异的[[吸附剂稳定性|稳定性]]（Rohith and Girija, 2024）。类似地，Qu 等人报道了一种[[氧化石墨烯]]/β-CD 复合材料，其对 [[亚甲基蓝|MB]] 具有较高的[[吸附]]能力和优异的[[吸附剂重复使用性|重复使用性能]]（Qu et al., 2025）。

基于[[木质素]]和 [[β-环糊精|β-CD]] 的[[磁性吸附剂]]受到关注，因为外加磁场可使其从水相体系中高效分离。[[磁铁矿]] $\left( \mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } \right)$ 因其[[生物相容性]]、[[环境稳定性]]和强[[磁性]]而被广泛使用，提升了此类复合材料的实用性。例如，木质素 $@ { \mathrm { F e } } _ { 3 } 0 _ { 4 }$ [[纳米复合材料]]在木质素与 $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ 的质量比为 1:1 时，[[亚甲基蓝|MB]] [[去除效率|去除率]]达到 55.6%，而在质量比为 20:1 时，[[去除率]]提高至 74.1%（Petrie et al., 2021）。类似地，Liu 等人合成了[[多孔磁性β-环糊精聚合物纳米球|多孔磁性 β-CD 聚合物纳米球]]，其最大 MB [[吸附容量]]为 $3 0 5 . 8 \mathrm { m g } . 8 ^ { - 1 }$，优于 β-CD 改性的 $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 }$ [[纳米颗粒]]（Liu et al., 2019）。最近，Liu 等人开发了含有氨基化 $\mathrm { F e } _ { 3 } \mathrm { O } _ { 4 } ,$ [[氧化石墨烯]]和[[羧基化交联β-环糊精聚合物|羧基化交联 β-CD 聚合物]]的复合材料，实现了 201.7 mg $\cdot g ^ { - 1 }$ 的[[吸附]]容量（Liu et al., 2024）

[[木质素]]和 [[β-环糊精|β-CD]] 的互补特性，即分别具有可参与多种相互作用的[[官能团]]和形成[[主客体包合|主–客体包合物]]的能力，使二者在[[磁性复合材料]]中的结合尤具前景。然而，利用[[生物基交联剂]]开发环境友好型[[磁性木质素]]–β-CD [[吸附剂]]的研究仍不充分。包括[[二羧酸]]和[[多羧酸]]在内的[[羧酸]]具有多个反应位点，能够通过[[酯化反应]]和分子间成键形成牢固、稳定的[[交联网络]]，因此是颇具吸引力的[[交联剂]]（Castro and Santana, 2024）。在我们此前的研究中，我们使用[[柠檬酸]]（[[CA 交联剂|CA]]）作为[[绿色交联剂]]，将 β-CD 连接到[[磁性硫酸盐木质素]]（[[磁性木质素纳米颗粒|MKL]]）上，为[[环氧氯丙烷]]提供了一种更安全的替代方案（Sabzevar et al., 2024）。尽管所得[[吸附]]剂表现出良好的[[吸附剂重复使用性|重复使用性能]]和高效的 [[亚甲基蓝|MB]] 去除能力，但其[[吸附容量]]有限，这可能是由于 CA 产生的[[空间位阻]]降低了[[活性位点可及性|活性位点的可及性]]（Altayan et al., 2023）

为克服这一局限，本研究考察了[[苹果酸]]（[[MA 交联剂|MA]]）和[[酒石酸]]（[[TA 交联剂|TA]]）作为替代性[[生物基交联剂]]的应用，与 [[CA 交联剂|CA]] 相比，它们具有更高的[[分子对称性]]和更小的[[空间位阻]]。预期这些特征能够促进[[交联]]，改善 [[β-环糊精|β-CD]] 与 [[磁性木质素|MKL]] 之间的[[聚合物网络]]，并提高[[吸附容量]]。因此，合成了 [[β-环糊精-苹果酸-磁性硫酸盐木质素吸附剂|β-CD-MA MKL]] 和 [[β-CD-TA-MKL]] [[吸附剂]]，并测试了其对 [[亚甲基蓝|MB]] 的去除性能。在这些复合材料中，β-CD 促进[[主客体包合|主–客体包合络合]]，[[交联剂]]增强[[静电相互作用]]，而 [[磁性木质素纳米颗粒|MKL]] 提供功能性结构骨架。其[[磁性]]使材料无需[[过滤]]或[[离心]]即可快速、便捷地回收。

使用 [[Design-Expert|Design-Expert 软件]]开展[[批量吸附实验]]，以研究 [[pH]]、[[吸附剂投加量|吸附剂用量]]和[[接触时间]]的影响。据我们所知，这是首次使用 [[MA 交联剂|MA]] 和 [[TA 交联剂|TA]] 作为[[交联剂]]，以 [[β-环糊精|β-CD]] 对[[磁性木质素]]进行改性的研究。结果表明，[[吸附容量]]显著提高，凸显了[[生物基交联剂|生物基可再生交联剂]]在优化绿色[[吸附剂]]设计、同时减少对有毒或昂贵材料依赖方面的潜力。

## 2. 实验部分

## 2.1. 材料与试剂

[[硫酸盐木质素]]（分子量 $\sim 1 0 , 0 0 0 \ \mathrm { g \ m o l ^ { - 1 } } )$ 和 [[β-环糊精]] $( \geq 9 7 \% )$ 购自 [[Sigma-Aldrich]]。六水合氯化铁 $( { \mathrm { F e } } ^ { 3 + } )$、七水合硫酸铁 $( \mathrm { F e } ^ { 2 + } )$、氨水（28 wt%）、磷酸二氢钾 $( \mathrm { K H _ { 2 } P O _ { 4 } } ) , \mathrm { C A } ,$、[[MA 交联剂|MA]]、[[TA 交联剂|TA]]、盐酸（[[盐酸|HCl]]，37 wt%）、氢氧化钠（NaOH）、氯化钠（[[氯化钠|NaCl]]）、[[亚甲基蓝|MB]]、[[甲基橙]]（MO）、[[罗丹明B|罗丹明 B]]（RB）、[[结晶紫]]（CV）和无水[[乙醇]] $\mathrm { ( C H _ { 3 } C H _ { 2 } O H ) }$ 购自 Merck。表 S1 列出了本研究所考察[[交联剂]]的性质。

## 2.2. 使用[[羧酸]]在 [[磁性木质素|MKL]] 上合成[[交联]] [[β-环糊精|β-CD]]

[[吸附剂]]的制备流程如示意图 1 所示。合成方法基于我们此前发表的工作（Sabzevar et al., 2024）。有关 [[磁性木质素|MKL]] 合成方法的更多细节见

补充信息（SI）的 S-1 节。本研究采用的酯化方案基于既往文献报道的方法（Jemli et al., 2024; Jiang et al., 2021; Silva et al., 2024）制定，不同之处在于调整了起始原料的用量，以适应并优化本研究的实验条件，同时改变了反应时间和所用[[交联剂]]的类型。

制备各[[吸附剂]]时，将 [[磁性木质素|MKL]]（0.1 g）、[[β-环糊精|β-CD]]（0.4 g，0.35 mmol）、0.4 g 相应的[[交联剂]]（[[CA 交联剂|CA]]、[[MA 交联剂|MA]] 或 [[TA 交联剂|TA]]）以及 $\mathrm { K H _ { 2 } P O _ { 4 } }$（0.24 g，1.7 mmol）与 15 mL 去离子（DI）水在烧杯中混合，搅拌 2 h。随后，将混合物转移至培养皿中，并置于烘箱中于 140◦C 加热 2 h。冷却后，将所得粗产物反复浸泡于水中，并用去离子水冲洗三至四次，然后借助磁铁[[过滤]]，在 60◦C 下真空干燥过夜。根据用于[[磁性硫酸盐木质素]]（[[磁性木质素纳米颗粒|MKL]]）和 β-[[环糊精]]（β-CD）[[交联]]的[[羧酸]]类型，对合成的[[吸附]]剂进行命名。具体而言，使用[[柠檬酸]]（CA）、[[苹果酸]]（MA）和[[酒石酸]]（TA）合成的吸附剂分别标记为 [[β-CD-CA-MKL]]、[[β-CD-MA-MKL]] 和 [[β-CD-TA-MKL]]。在使用及后续[[材料表征|表征]]之前，应将其置于密闭容器中，于室温下保存。

## 2.3. [[吸附剂]]的[[材料表征|表征]]

采用多种分析技术对合成的[[吸附剂]]进行[[材料表征|表征]]。采用 X 射线衍射分析（[[XRD]]，GNR Explorer X 射线衍射仪，意大利）研究[[吸附]]剂的[[晶体结构]]，2θ 范围为 5 至 70◦。采用[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]，Thermo Nicolet Avatar 370 光谱仪，美国）在 $4 0 0 { - } 4 0 0 0 ~ \mathrm { c m ^ { - 1 } }$ 范围内鉴定[[官能团]]。使用场发射[[SEM|扫描电子显微镜]]（[[场发射扫描电子显微镜|FESEM]]，Tescan Mira III LMU，捷克共和国）观察吸附剂的[[颗粒形貌|形貌]]，并结合能量色散 X 射线光谱（[[能量色散X射线光谱|EDS]]）鉴定元素。成像前，在每种吸附剂表面镀覆一层薄金层，以提高分辨率

使用 Zeta 分析仪（CAD Zeta Compact，法国）测定了[[吸附剂]]在不同 [[pH]] 值下的表面电荷。采用紫外–可见光谱法（Analytic Jena-Spekol 1300，德国）在 $\lambda _ { \operatorname* { m a x } } = 6 6 4 \mathrm { n m }$ 波长下评估污染物的[[吸附]]行为。使用振动样品磁强计（[[振动样品磁强计|VSM]]，Magnetic Danesh Pajoh Inst.，伊朗）测量吸附剂的[[磁性]]。采用以 Al K-α 辐射（1486.6 eV）为激发源的 X 射线光电子能谱（[[XPS]]）测量（Bes Tec，德国），确定吸附剂表面的化学组成和元素分布。

## 2.4. 批量[[吸附]]研究

采用 [[Design-Expert|Design-Expert 软件]]（版本 13.0.15）中的[[响应面法]]（RSM）开展[[批量吸附实验]]，以研究[[吸附剂]]去除 [[亚甲基蓝|MB]] 的能力。SI 的 S-2 节提供了对[[吸附]]实验、所用方程（式（S1）和（S2））及经验二阶多项式模型（式（S3））的更完整描述，同时还提供了用于鉴定 [[β-环糊精|β-CD]] 的技术（S-3 节）及其方程（式（S4））。

采用基于中心复合设计（CCD）的 [[响应面法|RSM]]，研究 [[pH]]（3−11）、[[吸附剂投加量]] $( 0 . 2 \mathrm { - } 0 . 6 ~ \mathrm { g . L } ^ { - 1 } )$ 和[[接触时间]]（10–30 min）这三个自变量对 [[亚甲基蓝|MB]] 去除的影响。该方法是一种常用的数学与统计设计方法，通过仔细评估实验偏差并减少过程中的系统误差，评价所研究变量对响应面的影响（Kumari et al., 2023b）。此外，与传统的单因素法（OFAT）相比，该方法所需的实验次数更少，并能更有效地揭示复杂的[[交互作用]]（Reza et al., 2024）。尽管田口法能够优化参数，但其主要关注[[线性模型|线性]]交互作用。该方法仅提供一个最优值，因此其准确性略低于 RSM；RSM 则考察所有参数组合，并使用效用函数指导实验（Tan et al., 2017）。遗传算法、人工神经网络（ANNs）和粒子群优化等其他方法各有优势和局限，其局限分别包括计算成本、解释困难以及对初始条件的敏感性（Kumari et al., 2023b）。

## 3.2. [[吸附剂]]的[[材料表征|表征]]

值得注意的是，本研究中展示的 [[磁性木质素|MKL]] 和 [[β-CD-CA-MKL]] [[吸附剂]]的[[材料表征|表征]]数据取自我们先前的研究（Sabzevar et al., 2024），因为其结构和组成保持不变。这些数据与新合成[[吸附]]剂（[[β-CD-MA-MKL]] 和 [[β-CD-TA-MKL]]）的数据一同列出，仅用于比较。

采用 [[X射线衍射|XRD 分析]]比较了 [[β-CD-CA-MKL]]（Sabzevar et al., 2024）、[[β-CD-MA-MKL]] 和 [[β-CD-TA-MKL]] 的结构信息，如图 S2 所示。位于 30.25◦、35.66◦、43.78◦、57.31◦ 和 63.07◦ 的[[衍射峰]]证实了 -CD-[[MA 交联剂|MA]]-[[磁性木质素|MKL]] 和 -CD-[[TA 交联剂|TA]]-[[磁性木质素纳米颗粒|MKL]] [[吸附剂]]中存在 [[四氧化三铁|Fe₃O₄]] 相（Petrie et al., 2021），其呈现[[面心立方结构|面心立方]]（FCC）结构。这些衍射峰也出现在我们先前工作中合成的改性前 [[磁性硫酸盐木质素|MKL]] 中（Sabzevar et al., 2024），表明[[吸附]]剂经[[交联]]后，铁的[[晶体结构]]保持不变，仅衍射峰的强度和宽度发生了变化。比较 [[β-环糊精-柠檬酸-磁性硫酸盐木质素吸附剂|β-CD-CA-MKL]]（Sabzevar et al., 2024）、[[β-环糊精-苹果酸-磁性硫酸盐木质素吸附剂|β-CD-MA-MKL]] 和 [[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 的[[衍射图谱]]可见，[[β-环糊精|β-CD]]-[[CA 交联剂|CA]]-MKL 吸附剂（Sabzevar et al., 2024）的衍射峰比另外两种吸附剂更弱、更宽。这表明其晶体更小（Wang et al., 2014）。相比之下，β-CD-[[苹果酸|MA]]-MKL 吸附剂的晶体更大，衍射峰尖锐且强度更高。这些变化表明，[[交联剂]]的类型对[[晶体生长|晶体生长过程]]具有重要影响。根据 β-CD-[[柠檬酸|CA]]-MKL（Sabzevar et al., 2024）、β-CD-MA-MKL 和 [[β-环糊精-酒石酸-磁性硫酸盐木质素吸附剂|β-CD-TA-MKL]] 的 [[XRD]] 图谱，采用 [[谢乐方程|Scherrer 方程]]（第 S-5 节中的式（S9））（Petrie et al., 2021）确定其[[微晶尺寸]]。估算的微晶尺寸分别为 4.11、10.72 和 8.60 nm。

[[FTIR]] 通常用于识别经[[羧酸]][[交联]]的[[生物材料]]中的[[酯基]]（Altayan et al., 2023）。如图 S3 和表 S4 所示，[[β-CD-CA-MKL]]（Sabzevar et al., 2024）、[[β-CD-MA-MKL]] 和 [[β-CD-TA-MKL]] 的 [[傅里叶变换红外光谱|FTIR 光谱]]呈现相似的峰位，表明不同[[交联剂]]引入的[[官能团]]基本相同。相比之下，这些[[吸附剂]]的光谱与 [[磁性木质素|MKL]] 的光谱（Sabzevar et al., 2024）存在显著差异，表明通过交联剂成功实现了 [[β-环糊精|β-CD]] [[表面改性]]。如图 S3 所示，[[β-环糊精-苹果酸-磁性硫酸盐木质素吸附剂|β-CD-MA-MKL]] 和 [[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 中分别在 $1 7 4 2 \mathrm { c m } ^ { - 1 }$ 和 $1 7 4 7 \mathrm { c m } ^ { - 1 }$ 处出现的新[[红外吸收带|吸收带]]与酯基的 C––O [[伸缩振动]]有关。这表明[[酯化反应]]已完成（Zhou et al., 2018），交联剂的[[羧基|羧酸基团]]与 -CD 和 [[磁性木质素纳米颗粒|MKL]] 的 [[羟基|OH 基团]]形成了[[酯键]]。-CD-[[CA 交联剂|CA]]-[[磁性硫酸盐木质素|MKL]]（Sabzevar et al., 2024）、-CD-[[MA 交联剂|MA]]-MKL 和 [[β-环糊精-酒石酸-磁性硫酸盐木质素吸附剂|β-CD-TA-MKL]] 之间的相似性进一步表明，交联剂的选择不会引入独有的或额外的官能团。

根据 [[场发射扫描电子显微镜|FESEM]] 图像，图 2(a) 中的 [[磁性木质素|MKL]] 颗粒（Sabzevar et al., 2024）呈球形，这与类似研究的发现一致（Cao et al., 2023）。[[接枝]] [[β-环糊精|β-CD]]（图 2(b)、(c)、(d)）改变了[[颗粒尺寸]]，但其[[颗粒形貌|形貌]]在视觉上未发生变化。我们认为，这种粒径差异可能归因于[[吸附剂]]合成中所用[[交联剂]]的结构差异。[[CA 交联剂|CA]] 具有三个[[羧基]]，能够形成更致密的[[交联]]，因此可能促进更紧凑、更致密的[[交联网络|网络结构]]形成（Pooja et al., 2025）。这可能导致粒径减小。Zhou et al. 报道，使用 [[柠檬酸|CA]] 进行交联改性后，[[淀粉纳米晶]]的尺寸减小（Zhou et al., 2016）。相比之下，[[官能团]]较少的 [[MA 交联剂|MA]] 和 [[TA 交联剂|TA]] 可能形成较疏松的网络或[[团簇|局部团簇]]，从而导致粒径增大。[[β-CD-TA-MKL]] 和 [[β-CD-MA-MKL]] 的 [[能量色散X射线光谱|EDS 谱]]（表 S5）表明，[[吸附]]剂中存在铁、碳、氧和硫。对于 [[β-CD-CA-MKL]]（Sabzevar et al., 2024），也检测到了类似的元素。

如图 2(e) 所示，[[β-CD-TA-MKL|-CD-TA-MKL]] 和 [[β-CD-MA-MKL|-CD-MA-MKL]] 的[[饱和磁化强度]]分别为 3.78 和 $8 . 4 3 \mathrm { \ e m u . g ^ { - 1 } } ;$，而 [[β-CD-CA-MKL]] 的饱和[[磁化强度]]为 2.52 emu. $\cdot { } g ^ { - 1 }$（Sabzevar et al., 2024）。因此，[[β-环糊精-苹果酸-磁性硫酸盐木质素吸附剂|β-CD-MA-MKL]] 表现出更好的[[磁性能]]。根据 [[能量色散X射线光谱|EDS]] 结果（表 S5），非[[磁性]][[有机组分]]（碳和氧）的含量在 [[β-环糊精|β-CD]]-[[MA 交联剂|MA]]-[[磁性木质素|MKL]] 中最低，在 [[β-环糊精-柠檬酸-磁性硫酸盐木质素吸附剂|β-CD-CA-MKL]] 中最高（Sabzevar et al., 2024）。[[包覆层]]的非磁性特征降低了 [[四氧化三铁纳米颗粒|Fe₃O₄ 纳米颗粒]]的饱和磁化强度；较厚的包覆层会增大其[[偶极矩]]，同时降低有效[[磁性组分]]含量，从而削弱整体磁性能（Cao et al., 2023）。这一趋势与先前的报道一致（Petrie et al., 2021; Zhou et al., 2021）。因此，[[无机组分]]含量与磁性能之间存在明确的相关性；有机组分含量增加会导致饱和磁化强度降低。此外，根据本研究的结果，饱和磁化强度的降低程度可能取决于[[交联剂]]的空间排列，以及[[吸附剂]]结构中有机部分相对于[[磁性木质素纳米颗粒]]的位置。尽管磁化强度值相对较低，这些[[吸附]]剂仍能从水介质中高效分离，这与 Liu et al.（2024）的研究结果一致。

为评估不同[[交联剂]]对[[吸附剂]]表面特性的影响，对[[吸附]]剂的[[表面电荷|电荷性质]]进行了分析。该评估包括测量吸附剂的 [[ζ电位|zeta 电位]]（图 S4），其是影响[[静电相互作用]]的关键指标（Song et al., 2024）。这些吸附剂表现出相似的 zeta 电位变化曲线，在 [[pH]] 3–11 范围内均带负电，表明其表面[[官能团]]的[[质子化]]程度较低（Jiang et al., 2021）。然而，[[β-CD-TA-MKL]] 的 zeta 电位最负，这可能归因于其表面[[含氧官能团]]含量较高（Ahmad et al., 2019）。相比之下，[[β-CD-CA-MKL]]（Sabzevar et al., 2024）和 [[β-CD-MA-MKL]] 的 zeta 电位负值程度较低。

这一发现与 Alam et al. 报道的结果一致，即[[pH|溶液 pH]] 的升高对 [[亚甲基蓝|MB]] 去除（Alam et al., 2022）和[[吸附容量|吸附量]]具有积极影响。在[[吸附]]研究中，[[吸附剂]]与[[吸附质]]之间所需的[[接触时间]]至关重要。本研究的结果（图 3(a)）表明，随着接触时间延长，MB 的[[吸附量]]也随之增加。延长接触时间可使[[染料]]分子与吸附剂表面发生更多相互作用。起初，吸附量随时间增加，但最终达到相对稳定的水平，表明达到[[吸附平衡|平衡]]。初期[[吸附速率]]的增加归因于初始阶段可用[[吸附位点|活性位点]]较多（Buenano ˜ et al., 2024）。在 pH 为 11、接触时间为 30 min 时，吸附量达到最大值。

研究了[[吸附剂投加量|吸附剂用量]] $( 0 . 2 \mathrm { - } 0 . 6 \mathrm { g . L } ^ { - 1 } )$。由 $0 . 2 \mathrm { - } 0 . 6 \mathrm { g . [[期望度函数]]的取值范围为 0（不理想）至 1（理想），用于引导优化过程，使期望度最大化（Hamouda et al., 2020）。通过[[数值优化]]，确定了使期望度函数达到最大值的条件。最高期望度值为 0.974，对应的最佳条件为：[[吸附剂投加量|吸附剂用量]]约为 $0 . 2 ~ \mathrm { g . L } ^ { - 1 }$、[[pH]] 11、[[接触时间]]为 30 min。在这些条件下，所达到的最高[[去除效率]]和[[吸附容量]]分别为 97.32% 和 $8 3 . 7 6 \mathrm { m g } . 8 ^ { - 1 }$，表明优化参数对 [[亚甲基蓝|MB]] 去除具有较高效能。为验证模型的准确性，在相同条件下又进行了两次试验。结果显示，MB [[去除率|去除效率]]分别为 96.24% 和 95.10%，[[吸附]]容量分别为 83.26 mg $g ^ { - 1 }$ 和 $8 2 . 2 7 ~ \mathrm { m g } . 8 ^ { - 1 }$（表 S9）。这些实验值与预测值高度吻合，表明模型具有较高的准确性和可靠性。观测值与预测值之间的这种一致性体现了模型的准确性和可靠性。因此，该模型可被视为一种可靠的工具，用于预测和提高实际情境下的 MB 去除效果和吸附容量。

为评估[[吸附剂]]在更贴近实际的条件下的性能，在中性 [[pH]]（pH 7）下进行了重新优化。在这些条件下，使用相同的[[吸附剂投加量|吸附剂用量]]（25 mL 中加入 0.005 g）和[[接触时间]]（30 min），获得了 91.5 % 的[[去除效率]]和 $8 1 . 2 7 ~ \mathrm { m g . g ^ { - 1 } }$ 的[[吸附容量]]。这些结果表明，该[[吸附]]剂可用于工业应用，因为其在中性 pH 条件下仍保持有效。

## 3.4. [[吸附|吸附过程]]中[[动力学]]模型的评估

为评估[[吸附速率]]，通过观察 [[β-CD-TA-MKL]] 的[[吸附容量]]随时间的变化开展了[[动力学]]实验。具体而言，在 [[pH]] 11 条件下，将 0.005 g [[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 加入 25 mL [[初始浓度]]分别为 20 和 40 mg. $\mathrm { L } ^ { - 1 }$ 的 [[亚甲基蓝|MB]] 溶液中。

以[[接触时间]]（10–30 min）为变量，评估了 [[β-CD-TA-MKL]] 的[[吸附容量]]。[[亚甲基蓝|MB]] [[吸附]]在约 30 min 时达到[[吸附平衡|平衡]]，当 MB [[初始浓度]]分别为 20 和 40 mg.L<sup>−</sup> <sup>1</sup> 时，[[去除效率|去除率]]分别高达 96.85 % 和 81.37 %，对应的吸附容量分别为 84.14 和 $1 5 8 . 8 4 ~ \mathrm { m g . g } ^ { - 1 }$。为研究[[吸附动力学]]及其潜在机制，采用了两种[[线性模型|线性]][[动力学]]模型，即准一级（PFO）和准二级（PSO）模型（Sabzevar et al., 2024）。所得拟合参数见图 S7(a) 和表 S10。根据接近 1 的 $\mathbb { R } ^ { 2 }$ 值，PSO 模型的拟合效果优于 PFO 模型。此外，实验测得的吸附容量 $( q _ { \mathrm { e , e x p } } )$ 与 PSO 模型计算得到的值 $( q _ { \mathrm { e , c a l } } )$ 高度吻合，表明 PSO 模型更适用于描述水溶液中[[染料]]的去除。基于统计指标的更详细分析（表 S10）表明，PSO 模型的误差值较低，能够更好地描述动力学结果。这些观察结果与 Hu et al.（Hu et al., 2023）和 El Haddad（El Haddad, 2016）报道的结果一致。图 S7(b) 展示了初始浓度为 20 和 40 mg $\mathrm { L } ^ { - 1 }$ 时，采用 PSO 模型拟合实验数据的结果。

## 3.6. [[吸附热力学]]

在不同温度（298–318 K）下，对 [[β-CD-TA-MKL]] [[吸附]] [[亚甲基蓝|MB]] 进行了[[热力学]]研究。采用第 S-8 节中的式（S13）至（S15）确定了吸附过程的[[热力学参数]]。在 298、308 和 318 K 下，所得[[标准吉布斯自由能变化]]值 $( \varDelta G ^ { \circ } )$ 分别为 $- 2 8 . 2 9 , - 3 0 . 1 9 ,$ 和 −32.28 kJ.mol<sup>−</sup> <sup>1</sup>。此外，[[焓变|正焓值]] $( \Delta H ^ { \circ } , 3 1 . 1 3 \mathrm { k J . m o l } ^ { - 1 } )$ 表明该吸附过程为[[吸热过程]]，这与 MB [[吸附容量]]随温度升高而增加的实验观察结果一致。ΔH◦ 值低于 $8 0 \mathrm { k J . m o l } ^ { - 1 }$ 意味着[[物理吸附]]（Tran, 2022）。然而，基于实验数据与 [[准二级动力学模型|PSO 动力学模型]]的高度吻合，[[化学吸附]]似乎是主要过程（Wei et al., 2023）。因此，[[化学相互作用]]和[[物理相互作用]]似乎均对吸附产生影响。先前的研究已记录了热力学与[[动力学]]解释之间的类似差异（Tran, 2022），这强调了为全面理[[解吸]]附过程而同时考虑热力学和动力学因素的必要性。

[[熵变|正熵值]] $( \Delta S ^ { \circ } , 1 9 9 . 3 0 \mathrm { J . m o l } ^ { - 1 } . \mathrm { K } ^ { - 1 } )$ 表明[[吸附剂]]对 [[亚甲基蓝|MB]] 分子具有较强的[[吸附亲和力|亲和力]]，这可能是由于[[吸附|吸附过程]]中[[染料]]与水分子之间的[[化学键断裂|键断裂]]，以及[[固–液界面]]处分子无序程度增加所致（Ahmadpour et al., 2023）。

## 3.7. [[吸附剂再生|吸附剂的再生]]与[[吸附剂重复使用性|重复使用性]]

用于[[水体修复|工业水体修复]]的[[吸附剂]]必须具有[[吸附剂稳定性|稳定性]]，因此，[[吸附剂再生|吸附剂的再生]]能力对其实际应用至关重要（Jia et al., 2024）。再生过程取决于[[吸附质浓度]]以及[[吸附质]]与[[吸附]]剂材料之间的作用力（Kumari et al., 2024b）。本研究考察了 $\beta { \mathrm { - } } \mathbf { C D - } \mathbf { T A - M K I }$ [[生物吸附剂]]的[[吸附剂重复使用性|重复使用性能]]，以评估其在实际[[废水染料去除]]中的应用潜力。在每个循环中，将 0.005 g 吸附剂与 [[亚甲基蓝|MB]] 溶液（20 mg. $\mathrm { L } ^ { - 1 } )$ 混合 30 min，以实现完全吸附。使用[[乙醇]]与 0.1 M [[盐酸|HCl]] 按 3:1 配制的混合液进行[[解吸]]，持续 30 min。经过五次循环后，[[β-CD-TA-MKL]] 的[[染料去除效率]]从 $9 6 . 2 4 \pm 0 . 6 7 \%$ 降至 91.10±1.13%（图 S8(a)），各循环[[标准差]]的统计详情见表 S13。[[吸附效率]]的下降可能是由于每次循环后[[吸附位点|吸附剂位点]]被 MB 分子占据而趋于饱和，导致可用于后续吸附的位点减少。第五次回收后，采用 [[傅里叶变换红外光谱|FT-IR]] 和 [[振动样品磁强计|VSM]] [[材料表征|表征]]技术对回收的吸附剂进行了分析。回收的 -CD-[[TA 交联剂|TA]]-[[磁性木质素|MKL]] 的 FT-IR 光谱显示出与新鲜吸附剂相同的[[红外特征峰|特征峰]]（图 S8(b)）。然而，观察到 [[β-环糊精|β-CD]] 在 3408、1747、1633 和 $1 0 3 5 \mathrm { c m } ^ { - 1 }$ 处的峰强度略有降低。这种降低可能源于回收过程和干燥条件等因素，这些因素可能在表层引入[[结构缺陷]]，从而降低这些峰的强度（Liu, Z. et al., 2024）。由于未检测到[[去除效率|去除率]]发生显著变化，且与[[官能团]]相关的峰在第五次回收后未发生变化，我们认为，这些峰强度的降低是由于部分位点仍与污染物分子结合，这些分子尚未被完全去除。此外，[[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 的[[饱和磁化强度]]保持相对稳定，回收后从 3.78 略微降至 3.38 emu.g<sup>−</sup> <sup>1</sup>（图 S8(c)）。

根据回收结果以及第五次循环后对[[吸附剂]]进行的分析，该[[吸附]]剂表现出适用于实际应用的良好[[吸附剂稳定性|稳定性]]和[[可回收性]]。已有研究报道了含 [[β-环糊精|β-CD]] 吸附剂的类似结果，即经过若干次回收循环后，[[去除效率]]仅略有下降（Li et al., 2022; Singh et al., 2024; Verma et al., 2022; Yang et al., 2021）。

## 3.8. [[竞争离子]]（[[氯化钠|NaCl]]）对 [[亚甲基蓝|MB]] 去除的影响

为更好地模拟真实环境中的[[共吸附]]情景，研究了 [[氯化钠|NaCl]] 浓度对 [[亚甲基蓝|MB]] 去除的影响。图 S8(d) 和表 S14 显示，[[β-CD-TA-MKL]] 对[[染料]]的[[吸附容量|吸附量]]随 NaC 浓度的增加而降低。这种降低可能是因为 Na /Cl 离子与 MB 分子[[竞争吸附|竞争可用的活性位点]]（Imessaoudene et al., 2022）。Yagub et al.（Yagub et al., 2014）和 Imessaoudene et al.（Imessaoudene et al., 2022）也报道了类似结果。有关[[吸附选择性|吸附剂选择性]]的详细信息（第 S-9 节）以及[[标准差]]的统计详情见 SI，相应的[[误差棒]]见图 S9。

## 3.9. [[吸附机理]]

[[β-CD-TA-MKL]] 在去除 [[亚甲基蓝|MB]] 方面表现出的卓越效率归因于其独特的结构和多样的[[官能团]]。如图 4 所示，本研究采用系统性方法阐明了[[吸附|吸附过程]]的关键机制。[[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 的有序结构及其优异的[[吸附性能]]归因于 [[磁性木质素|MKL]]、[[TA 交联剂|TA]] 和 [[β-环糊精|β-CD]] 之间的[[协同作用]]。为进一步验证[[吸附机理|吸附机制]]，对吸附 MB 前后的 [[β-环糊精-酒石酸-磁性硫酸盐木质素吸附剂|β-CD-TA-MKL]] 进行了 [[FTIR]] 分析，揭示了官能团的重要变化，并进一步阐明了吸附机制。

[[亚甲基蓝|MB]] 在 [[β-CD-TA-MKL]] 上的[[吸附机理|吸附机制]]涉及四种相互作用：[[氢键]]、[[静电相互作用]]、[[主客体相互作用]]和 [[π-π相互作用|π-π 相互作用]]。与 [[磁性木质素|MKL]] 相比，[[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 含有更多[[含氧官能团|含氧基团]]，这有助于提高其[[吸附性能]]。这些额外的含氧基团提供了更多[[吸附位点|活性位点]]，增强了与 MB 的相互作用，并提高了其[[吸附容量]]。[[β-环糊精-酒石酸-磁性硫酸盐木质素吸附剂|β-CD-TA-MKL]] 中的 [[羟基|-OH]] 基团作为[[氢键供体]]，促进了与[[染料]]分子的相互作用。静电相互作用在[[阳离子染料]]的[[吸附]]中起着关键作用。[[吸附剂]]上的 -OH 和 [[羧基|-COOH]] 基团可在水环境中[[电离]]，从而在吸附剂表面形成带负电荷的位点（Rohith and Girija, 2024）。- 相互作用也源于染料分子和 [[β-环糊精|β-CD]]-[[TA 交联剂|TA]]-[[磁性木质素纳米颗粒|MKL]] 中的[[芳香结构]]。具体而言，β-CD-[[酒石酸|TA]]-[[磁性硫酸盐木质素|MKL]] 中的[[芳香环]]与染料分子芳香环的 [[π电子|π 电子]]相互作用。此外，吸附剂中的 β-CD 组分含有大分子空腔，有利于与[[客体分子]]形成[[包合物]]，从而进一步增强吸附过程（Rohith and Girija, 2024）。

## 3.10. 局限性与未来工作

尽管已优化合成条件以提高[[吸附剂]]去除 [[亚甲基蓝|MB]] 的性能，但仍存在一些局限性，包括需要进一步优化[[吸附]]剂，以评估其在含有多种竞争性污染物的[[废水基质|复杂废水基质]]中的性能。未来研究可通过考察该吸附剂对更广泛污染物及在实际废水基质中的性能、提高其规模化应用能力，以及评估其对其他污染物的[[吸附剂稳定性|稳定性]]和[[吸附选择性|选择性]]，来克服这些局限性。

有关经济和环境方面的详细信息见第 S-10 节。

## 4. 结论

本研究评估了[[交联剂|环境友好型交联剂]]（[[柠檬酸]]、[[苹果酸]]和[[酒石酸]]）对[[吸附剂]]去除[[阳离子染料]]性能的影响。采用分析技术验证了[[吸附]]剂的成功合成。对所合成吸附剂的性能评估表明，在由[[磁性木质素]]和 [[β-环糊精]]组成的吸附剂中，以酒石酸为[[交联]]剂的吸附剂性能优于含苹果酸和柠檬酸的吸附剂，证实了我们的假设。使用 [[Design-Expert|Design Expert 软件]]确定了[[亚甲基蓝]][[去除效率|去除率]]达到最优（∼97%）时的条件。这些条件包括[[接触时间]]为 30 min、[[pH]] 为 11，以及[[吸附剂投加量|投加量]]为 $0 . 2 ~ \mathrm { g . L } ^ { - 1 }$ 。吸附过程遵循[[准二级动力学模型|准二级动力学]]，并符合 [[Langmuir吸附等温模型|Langmuir 等温模型]]。[[热力学]]分析表明，吸附过程为[[吸热过程]]。[[β-CD-TA-MKL]] 吸附剂表现出优异的[[吸附剂稳定性|稳定性]]和[[吸附剂重复使用性|可重复使用性]]。这些结果凸显了 [[β-环糊精-酒石酸-磁性木质素吸附剂|β-CD-TA-MKL]] 作为高效吸附剂用于工业应用的潜力。
