# [[仿竹超强纳米纤维增强复合水凝胶]]

收稿日期：2024 年 8 月 28 日

接受日期：2025 年 1 月 15 日

[[郝卓]]<sup>1,3</sup>，[[董新宇]]<sup>1,3</sup>，[[刘曲洋]]<sup>1</sup>，[[洪灵怡]]<sup>1</sup>，[[张兆龙]]<sup>2</sup>，[[龙树昌]]<sup>2</sup>，[[翟伟]]<sup>1</sup>

生物材料（如[[竹子]]）是天然优化的复合材料，具有优异的力学性能。受此类天然复合材料启发，传统方法通常从天然来源中提取纳米纤维并将其应用于复合材料中，然而这往往导致力学性能不够理想。为解决这一问题，本研究开发了一种[[自下而上的纳米纤维组装策略]]，以竹子的分级组装为灵感，构建强韧的纤维增强复合[[水凝胶]]。将自组装的[[壳聚糖-海藻酸钠纳米纤维]]（CSNFs）与作为界面[[交联]]剂的[[单宁酸]]（TA）和作为水凝胶基质的[[聚乙烯醇]]（PVA）相结合，以模拟竹子中[[纤维素-木质素-半纤维素]]的基本组成单元。这些组分官能团之间形成强界面[[静电相互作用]]和[[氢键]]。通过[[拉伸诱导取向]]构建更高阶结构，可进一步增强这些分子间相互作用。所得复合水凝胶实现了良好的力学性能，包括高达 60.2 MPa 的[[拉伸强度]]，以及同时具有 48.0 MPa 的高强度和 470% 的[[极限应变]]。该方法展示了一种分级自下而上的策略，通过有效利用基本分子间相互作用来构建强韧的复合水凝胶。通过模仿竹子高度一体化的结构组成，它为创造具有优异力学性能的先进[[仿生材料]]提供了一种有前景的解决方案。

几乎所有天然材料都是复合材料，通常具有高度组织化的提供强度的纤维、网络或片层，嵌入在异质的增韧基质中，并以分级结构排列，以优化力学性能和功能<sup>1–3</sup>。值得注意的是，[[竹子]]轻质、强韧且柔韧，兼具通常相互矛盾的力学性能<sup>4</sup>。竹子具有分级纤维结构，其基本组成包括[[纤维素]]、[[木质素]]和[[半纤维素]]（图 1a、b）。在这种组合中，结晶纤维素微纤丝作为增强单元，在植物细胞壁内提供强度；木质素填充[[纤维素原纤维|纤维素纤维]]之间的空隙，赋予刚性和抗变形能力；半纤维素作为粘合基质，将纤维素和木质素连接在一起，以增强柔韧性<sup>5,6</sup>。它们优异的化学相容性确保了有效的结合和载荷传递，使应力均匀分布并防止局部失效。尽管竹子是一种异质复合材料，但它体现了一种协同整合的结构材料，其分级结构由[[纤维素-木质素-半纤维素]]的基本组成单元组装而成。

受这些天然复合材料启发，复合化已成为增强各种材料的经典材料设计方法，

包括[[水凝胶]]等软材料<sup>7</sup>。[[纤维素]]等多糖基纤维通常从[[木质纤维素]]植物中提取，因其天然来源、生物相容性和高力学性能而作为复合材料中的增强材料受到广泛关注，天然[[纤维素原纤维|纤维素纤维]]的[[拉伸强度]]可高达1.6–3 GPa<sup>8</sup>。然而，从天然来源中提取纤维素所采用的传统自上而下工艺通常涉及复杂的机械与化学处理，这一过程容易破坏纳米纤维的界面。据Ito等人报道，刻蚀会在提取得到的[[纤维素纳米纤维]]上造成原子尺度的凹痕，从而产生缺陷，并导致最终复合材料力学性能下降<sup>9</sup>。此外，天然纤维素纳米纤维由于高度结晶而具有20–50 GPa的过高[[模量]]<sup>10</sup>，这与大多数水凝胶基体存在显著差异。这种[[模量失配]]会导致复合材料体系内出现不利的[[应力集中]]，进而损害其力学性能<sup>11–13</sup>。尽管人们在从天然来源提取纤维素纳米纤维方面做出了大量努力，但这些纤维的引入往往导致材料组合方式和力学性能不及天然对应物。由于纤维素的最初天然来源（如[[竹子]]）已经表现出高度整合的材料组成，因此一种可能更有效的策略是采用自下而上的方法直接模仿其组成和结构组织。

为了采用自下而上的方法直接模仿[[竹子]]从其基本组成单元开始的层级组装，必须实现三种组分之间的协同相互作用：纤维、基体及其界面。我们提出利用[[超声辅助分子组装|超声辅助分子组装工艺]]，以[[壳聚糖]]和[[海藻酸钠]]等组分制备多糖基纳米纤维，以此替代传统的自上而下提取方法<sup>14</sup>。这些自组装纳米纤维具有较低[[结晶度]]的结构，表现出与基体相容的[[模量]]（<1 GPa）和高强度，因而非常适合用于增强[[水凝胶]]。此外，它们无缺陷的微观结构和功能性界面使其能够与其他分子相互作用，形成构建基本组成单元所需的基体和界面。具体而言，我们提出将这些纳米纤维与[[单宁酸]]（TA）和[[聚乙烯醇]]（PVA）相结合，以模仿竹子的[[纤维素-木质素-半纤维素|纤维素–木质素–半纤维素]]单元，其中TA充当类似[[木质素]]的强[[交联]]剂，PVA则作为类似[[半纤维素]]的柔性水凝胶基体。通过组装这些基本单元，我们可以构建更高阶的层状结构，从而再现竹子的层级组织。这种自下而上的策略使得开发与竹子高度整合的结构组成高度相似的复合水凝胶成为可能，并有望获得增强的力学性能。

在此，我们开发了一种[[自下而上的纳米纤维组装策略]]，以竹启发的基元组成单元构建强韧的纤维增强复合[[水凝胶]]。在该策略中，基于多糖的纳米纤维与 [[单宁酸|TA]] 和 [[聚乙烯醇|PVA]] 结合，形成具有强分子相互作用的基元组成单元。此外，这些相互作用可以通过随后的[[拉伸诱导取向]]得到有效协调与增强<sup>15</sup>。所制备的竹启发复合水凝胶表现出优异的力学性能，包括高达 60.2 MPa 的[[拉伸强度]]。此外，由于复合水凝胶基元组成单元中取向结构与分子相互作用的协同效应，可以同时实现 48.0 MPa 的高强度和 470% 的[[极限应变]]。受[[竹子]]组成单元的启发，本工作提出了一种基于最基本分子相互作用构建强韧纤维增强复合水凝胶的分级自下而上方法。

## 结果

基元组成单元的竹启发设计 如图 1a 所示，[[竹子]]呈现一种分级结构，从其宏观中空管状构型，到[[维管束]]的微尺度组织，再进一步到[[纤维素原纤维]]在[[木质素-半纤维素基质]]中的整合。这一分级结构，包括维管束和[[纤维素]]原纤维，均沿竹子长度方向有策略地排列，以优化其力学性能。其由纤维素、[[木质素]]和[[半纤维素]]组成的基元组成单元，对于构建能够有效增强力学性能的高阶结构至关重要。在该单元内部，强分子相互作用以木质素与半纤维素之间的[[共价键]]，以及木质素与半纤维素之间、纤维素与半纤维素之间的[[氢键]]形式存在（图 1b）。这些分子相互作用是实现各组分协同整合的关键。

受[[竹子]]分级组装启发，本研究开发了一种纤维增强复合[[水凝胶]]的制备策略，即通过构建基元组成单元并形成高阶结构，从而利用其本征强度（图 1c）。与竹子中的[[纤维素原纤维]]类似，基于多糖的纳米纤维通过[[超声诱导组装]]过程制备（补充图 1）。在该方法中，[[壳聚糖]]和[[海藻酸钠]]大分子在高能声流场中发生取向和组装。两种多糖中带相反电荷基团之间的强[[静电相互作用]]导致[[壳聚糖-海藻酸钠纳米纤维]]（CSNFs，补充图 2a）的形成。这些纳米纤维具有固有功能化表面，带有壳聚糖和海藻酸钠的特征基团，包括氨基（–NH ）和羟基（–OH）。这些功能基团是设计基元组成单元内分子相互作用的重要起点。在本研究中，富含 –OH 基团的 [[聚乙烯醇|PVA]] 和 [[单宁酸|TA]] 分别用作水凝胶基质和[[交联]]剂。为制备 CSNF-

[[单宁酸|TA]]-[[聚乙烯醇|PVA]] [[水凝胶]]的制备中，先将 [[壳聚糖-海藻酸钠纳米纤维|CSNFs]] 与 PVA 溶液混合，随后将混合物浇铸并干燥。然后，将该材料在 TA 溶液中再水化，使 TA 渗入并使复合材料[[交联]]。TA 的 –OH 基团可能与 CSNFs 的 $\mathrm { - N H } _ { 2 }$ 基团以及 PVA 的 –OH 基团形成分子相互作用（图 1c）。

为初步验证上述组成单元设计，图 2a 比较了纯 [[聚乙烯醇|PVA]]（纯[[水凝胶]]基体）、[[CSNF-PVA]]（纤维增强水凝胶基体）和 [[CSNF-TA-PVA]] 水凝胶（具有界面增强的纤维增强水凝胶基体）的力学性能。经过空气干燥和再水化（在去离子水中）后，纯 PVA 水凝胶表现出 4.6 MPa 的[[拉伸强度]]和 360% 的[[极限应变]]。在纤维掺入比例为 1:20 至 1:5（[[壳聚糖-海藻酸钠纳米纤维|CSNF]] 与 PVA 之比）时，复合水凝胶的强度得到有效增强（补充图 2b）。然而，在纤维含量过高（1:1）时，CSNF-PVA 变得更刚硬，拉伸强度更低。后续实验选择 1:10 的比例，因为它在增强力学性能与 2.8 的[[溶胀比]]之间提供了平衡，接近 PVA 的 2.9 溶胀比（补充图 2c）。在该比例下，CSNF-PVA 水凝胶表现出 9.5 MPa 的拉伸强度和 480% 的极限应变，实现了强度与可拉伸性的均衡提升。在 CSNF-PVA 水凝胶中引入 [[单宁酸|TA]] 后，所得的 CSNF-TA-PVA 水凝胶达到了最高的拉伸强度 13.8 MPa（是纯 PVA 水凝胶的三倍，是 [[PVA-TA]] 水凝胶的 2.2 倍）以及 500% 的极限应变。

同时，进行了[[循环加载-卸载拉伸测试]]以评价[[水凝胶]]的[[能量耗散]]行为（补充图 2d、e）。结果表明，拉伸应力和[[能量损失系数]]均随 [[壳聚糖-海藻酸钠纳米纤维|CSNF]] 和 [[单宁酸|TA]] 的加入而增加。具体而言，[[CSNF-TA-PVA]] 水凝胶在第一次和第十次循环中的能量损失系数分别测得为 0.86 和 0.58，显著高于 [[聚乙烯醇|PVA]] 和 [[CSNF-PVA]] 水凝胶所观察到的值。CSNF、TA 与 PVA 之间的[[氢键]]促进了有效的应力传递和能量吸收，改善了整个材料的能量耗散。大多数复合水凝胶在提高刚度和强度的同时往往牺牲可拉伸性，而在 PVA 水凝胶中引入 CSNF 和 TA 则同时改善了这三项性能，凸显了材料组成设计的有效性。在 CSNF-PVA 水凝胶中，弹性的无定形 CSNFs 在力学和化学性能上与 PVA 基体高度相容。由于二者均具有 –OH 基团，它们的结合可形成大量氢键，从而实现强度和可拉伸性的同步提升。此外，TA 的加入通过提供更多 –OH 基团作为功能位点，进一步强化了基体并增强了纤维-基体界面，最终使 CSNF-TA-PVA 水凝胶获得最高的力学性能。三种组分的协同作用也通过[[原子力显微镜]]（AFM）得到证实，其中 CSNF-TA-PVA 水凝胶表现出均匀且坚固的结构，且[[模量]]高于纯 PVA 水凝胶（补充图 3）。

## 基本组成单元内的分子相互作用

对[[CSNF-TA-PVA]]组成单元内的具体分子相互作用进行了细致研究。如图2b和补充图4a、b所示，[[CSNF-PVA]]的N1s谱在400.0 eV处呈现一个峰，对应于氨基侧链的$\mathrm { - N H } _ { 2 }$基团。相比之下，[[壳聚糖-海藻酸钠纳米纤维|CSNF]]-[[单宁酸|TA]]-[[聚乙烯醇|PVA]]的N 1 s谱在400.0 eV和401.9 eV处显示出两个特征峰，分别对应$\mathbf { t o } - \mathsf { N H } _ { 2 }$和–NH <sup>+</sup>基团。这表明，除TA的酚羟基与CSNF的–NH基团之间的[[氢键]]外，弱酸性TA还可释放酚氧阴离子，与CSNF的$\boldsymbol { - } \boldsymbol { \mathsf { N } } \boldsymbol { \mathsf { H } } _ { 3 } { } ^ { + }$基团形成[[静电相互作用]]。

同时，[[单宁酸|TA]]的酚羟基也被认为可与[[聚乙烯醇|PVA]]形成[[氢键]]。为验证这一点，图2c和补充图4c比较了TA、PVA、[[CSNF-PVA]]和[[CSNF-TA-PVA]]的[[FTIR]]光谱。在[[壳聚糖-海藻酸钠纳米纤维|CSNF]]-TA-PVA中，TA的C = O振动从1697 cm<sup>−1</sup>移至1708 cm<sup>−1</sup>，表明由于与氢供体相互作用，C = O键的振动能增强<sup>16,17</sup>。此外，对应于芳香C–O不对称伸缩振动的1170 cm<sup>−1</sup>和1308 cm<sup>−1</sup>处的峰分别略微移至1187 cm<sup>−1</sup>和1315 cm<sup>−1</sup>。C–O–C伸缩振动峰也从1007 cm<sup>−1</sup>移至1021 cm<sup>−1</sup>。值得注意的是，CSNF-TA-PVA中3258 cm<sup>−1</sup>处羟基伸缩振动的变宽（补充图4d）表明形成了更多新的无序氢键。这种变宽效应表明氢键异质性增加，并归因于TA的引入破坏了PVA中已有的氢键网络，同时形成了额外的、非均匀的氢键相互作用。这些[[XPS]]和[[傅里叶变换红外光谱|FTIR]]结果揭示了TA与CSNF和PVA均具有良好的结合能力，这主要由氢键、[[范德华力]]和[[CH-π相互作用]]等次级相互作用驱动<sup>18</sup>。

复合[[水凝胶]]中分子环境的变化也通过[[拉曼光谱]]分析得到了揭示。如补充图 4e 所示，[[CSNF-TA-PVA]] 中 –CH 伸缩振动（1441 cm<sup>−1</sup>）强度的降低以及拉曼光谱中 –CH 伸缩振动（2914 cm<sup>−1</sup>）的减弱，都是 [[聚乙烯醇|PVA]] [[结晶度]]降低的有力指标。PVA 中的这些峰原本尖锐且轮廓清晰，反映了聚合物链的有序和规整堆积。随着结晶度降低，分子排列变得更加无序，导致这些峰发生展宽。这一转变表明 PVA 链的规整堆积受到破坏，从而使无定形组分比例升高。此外，C = O 伸缩振动峰（1712 cm<sup>−1</sup>）强度下降，表明分子环境发生了变化（形成了强[[氢键]]），进一步支持了 PVA 规整堆积的破坏以及由 [[单宁酸|TA]] 促进的氢键网络增强。

为了进一步验证上述观察到的分子相互作用并理解其形成机制，进行了[[密度泛函理论|密度泛函理论（DFT）计算]]，以确定 [[单宁酸|TA]] 与 [[壳聚糖-海藻酸钠纳米纤维|CSNF]] 和 [[聚乙烯醇|PVA]] 的结合能。计算使用 [[B3LYP]]/[[6-311G(d, p)|6-311 G(d, p)]] 基组进行。选择[[壳聚糖]]分子代表 CSNF 表面，并使用 TA 的多酚侧链作为其代表性单元。优化后的结构以及各单元的计算[[静电势]]（ESP）分布展示于图 2d 和补充图 5 中。

一方面，[[单宁酸|TA]] 可分别通过[[静电相互作用]]和[[氢键]]作用与 [[壳聚糖-海藻酸钠纳米纤维|CSNF]] 的 $\mathrm { - N H } _ { 3 } ^ { + }$ 和 $\mathrm { - N H } _ { 2 }$ 基团发生结合。TA 与 CSNF 单元的 [[静电势|ESP]] 图显示出强静电相互作用，吸引势集中在 TA 的苯氧基氧原子（117.3 kcal/mol）和 CSNF 氨基阳离子的氢原子（−141.8 kcal/mol，补充图 6 和表 1）上。该相互作用的结合能高达 −27.9 kcal/mol（补充图 7）。此外，中性 CSNF 与 TA 之间的结合能经计算为 −17.7 kcal/mol（图 2e 和补充表 2），表明存在非常强的氢键。另一方面，TA 中带负电的氧原子与 [[聚乙烯醇|PVA]] 中带正电的氢原子形成氢键，TA 与 PVA 之间的结合能经计算为 −13.0 kcal/mol（图 2f）。值得注意的是，TA 与 CSNF 及 PVA 之间的氢键结合能均高于 PVA 分子自身 –OH 基团之间的氢键结合能，后者仅为 −8.3 kcal/mol（图 2g）。这些计算结果证实了上述分子表征，并验证了 [[CSNF-TA-PVA]] 组成单元中所提出的分子相互作用设计。加入 TA 后，其首先通过静电相互作用和氢键与 CSNF 结合，随后通过氢键与 PVA 结合。在此过程中，TA 作为氢键受体连接 CSNF 与 PVA，而后两者中的氢原子作为供体。这些分子相互作用将三种组分良好地整合为一个协同整体，从而提升了复合[[水凝胶]]的整体力学性能。

## 纳米晶体结构的演变

在纯 [[聚乙烯醇|PVA]] [[水凝胶]]中，PVA 分子间的[[氢键]]对纳米晶区的形成至关重要，而这些晶区有助于提升力学性能<sup>19,20</sup>。由于 [[单宁酸|TA]] 的引入在 PVA 基体内诱导了更强的氢键，因此研究了其对纳米晶体结构的影响。

如图 3a 中[[差示扫描量热法]]（DSC）结果所示，纯 [[聚乙烯醇|PVA]] [[水凝胶]]在 $2 2 5 ^ { \circ } \mathrm { C }$ 处出现结晶峰（即熔融温度 Tm<sup>21</sup>），而 [[CSNF-PVA]] 则表现出更低的 Tm，为 $2 2 0 ^ { \circ } \mathrm { C } .$。[[壳聚糖-海藻酸钠纳米纤维|CSNF]] 的引入破坏了 PVA 的有序结构，导致[[结晶度]]降低。这种结构破坏使 Tm 向较低温度移动。此外，由于 PVA 分子间的键被 [[单宁酸|TA]] 与 PVA 之间形成的更强[[氢键]]所取代，强氢键数量的增加进一步破坏了晶区，并降低了分子链的热稳定性，这导致 [[CSNF-TA-PVA]] 水凝胶中的 Tm 最低，为 $2 1 3 ^ { \circ } \mathrm { C } ^ { 2 2 }$。这一变化证实了上述 [[密度泛函理论|DFT 计算]]结果，即 TA-PVA 氢键强于 PVA-PVA 氢键，并通过竞争效应取代了 PVA 晶区。

采用[[小角X射线散射]]（SAXS）以理解[[聚乙烯醇|PVA]]结晶的演变。如图3b、c所示，在PVA和[[CSNF-PVA]][[水凝胶]]中分别于$0 . 0 6 4 \dot { \mathring { \mathbf { A } } } ^ { - 1 }$和0.07 Å<sup>−1</sup>处观察到PVA结晶峰。然而，由于内部相互作用的重新配置，[[CSNF-TA-PVA]]水凝胶中未识别出任何峰。利用与峰强度对应的临界矢量$q _ { m a x } ,$，通过[[Bragg方程|Bragg表达式]]$\mathsf { L } = 2 \pi / q _ { m a x } ,$估算晶域之间的平均距离，结果汇总于补充表3。[[壳聚糖-海藻酸钠纳米纤维|CSNF]]-PVA水凝胶中的平均距离为9.8 nm，相较纯PVA水凝胶中的9.0 nm略有增加。在CSNF-[[单宁酸|TA]]-PVA水凝胶中，虽然SAXS未检测到PVA晶域，但可通过低q区关系${ \bf l } ( { \bf q } ) \approx { \bf q } ^ { - \alpha }$获得结构因子α信息。具体而言，$0 . 0 4 \substack { - 0 . 1 3 \mathring { \mathbf { A } } ^ { - 1 } }$区域表现出幂律行为，斜率为−2.1，表明二维纳米结构<sup>23</sup>。

为进一步量化结晶形态的演变，进行了[[XRD|X射线衍射]]（[[X射线衍射|XRD]]）测量。纯[[聚乙烯醇|PVA]][[水凝胶]]在$2 6 = 1 9 . 7 ^ { \circ }$处显示出强衍射峰（图3d），对应于半结晶PVA的典型(10¹1)反射面<sup>24</sup>。[[单宁酸|TA]]的引入导致PVA结晶峰显著降低，表明TA与PVA之间的强[[氢键]]抑制了PVA链的结晶。[[晶域尺寸]]通过[[Scherrer方程]]$\mathsf { D } { = } k \mathcal { N } ( \beta c o s \theta ) ^ { 2 }$近似评估，其中D为晶域平均尺寸，β为半高全宽，k为随晶域实际形状变化的无量纲形状因子（设为1），λ为X射线衍射波长，θ为Bragg角。详细数据汇总于图3e和补充表3。加入[[壳聚糖-海藻酸钠纳米纤维|CSNF]]和TA后，晶域平均尺寸从3.29 nm显著降低至1.14 nm。PVA晶域尺寸的减小与[[小角X射线散射|SAXS]]结果一致，即[[CSNF-TA-PVA]]水凝胶的PVA结晶峰可忽略不计。

这些结果表明，[[壳聚糖-海藻酸钠纳米纤维|CSNF]]、[[单宁酸|TA]]和[[聚乙烯醇|PVA]]之间的强相互作用优于PVA分子间的[[氢键]]。TA与PVA分子间形成氢键的同时破坏了PVA链间的氢键，从而减小了PVA[[晶域尺寸]]及其间的平均距离。

## 复合[[水凝胶]]的仿生高阶取向结构

[[竹子]]的力学性能源于其层级结构。[[纤维素纳米纤维]]、[[半纤维素]]和[[木质素]]作为基本组分整合在细胞壁内。细胞沿竹长方向排列，形成[[维管束]]的微尺度排列。整体壁结构与这些组分的精确取向相结合，对于分散机械应力和维持竹子的结构完整性至关重要。由于上述结果揭示了受竹启发的[[CSNF-TA-PVA]]组成单元内强分子相互作用的特征和效应，下一步是研究这些相互作用能否被用于构建高阶结构，从而以类似竹子层级组装的方式进一步增强力学性能。

[[壳聚糖-海藻酸钠纳米纤维|CSNF]]/[[PVA-TA]][[水凝胶]]通过[[拉伸诱导取向]]在其微观结构中进行后处理。在被拉伸至两倍长度并风干后，该水凝胶被重新溶胀并在[[硫酸钠|硫酸钠溶液]]中固定，这可以使分子硬化并保持取向。

图4a–c中的SEM图像揭示了取向CSNF-TA-PVA水凝胶的微观结构。它在宏观尺度上表现出高度取向的结构，整个样品中呈现应力诱导的平行褶皱（图4a）。在介观尺度上，由于风干过程，观察到了均匀的层状结构（图4b）。不同组分之间没有观察到清晰的边界，表明这些组分通过分子相互作用的精细设计被良好地整合为一个协同复合材料。因此，在微观尺度上，只有纤维束可以从复合水凝胶中有意分离出来（图4c）。这些纤维束是由多个取向的基本组成单元聚集形成的。

此外，进行了[[小角X射线散射|二维（2D）SAXS]]测试以定量评估取向。在取向[[CSNF-TA-PVA]][[水凝胶]]中观察到了椭圆散射环图案（图4d）。在对2D SAXS结果进行方位角分析后，取向[[壳聚糖-海藻酸钠纳米纤维|CSNF]]-[[单宁酸|TA]]-[[聚乙烯醇|PVA]]水凝胶表现出$f _ { c }$为0.64的[[Herman取向因子]]，表明其具有高度各向异性结构（图4e）。同时，在[[硫酸钠|硫酸钠溶液]]中固定前后，复合水凝胶中的相互作用或晶体结构在[[FTIR]]、[[XRD]]和SAXS分析中没有显著变化（补充图8a–c）。因此，盐处理主要影响[[交联]]网络的密度，而不改变复合水凝胶中已有的分子相互作用或结晶区域。

如图4f所示，取向[[CSNF-TA-PVA]][[水凝胶]]表现出48.0 MPa的高[[拉伸强度]]，[[极限应变]]为470%。值得注意的是，其强度是未取向复合水凝胶的4倍，而拉伸性仅有极小的降低。这表明高度取向不仅使[[壳聚糖-海藻酸钠纳米纤维|CSNF]]对齐，还使CSNF、[[单宁酸|TA]]和[[聚乙烯醇|PVA]]分子的官能团在这种取向排列下更加接近，从而增加了它们界面处的[[氢键]]。这些综合效应使水凝胶能够在保持其拉伸性的同时承受更高的应力。相比之下，取向[[CSNF-PVA]]和取向[[PVA-TA]]水凝胶的力学性能均低于取向CSNF-TA-PVA（补充图8d）。具体而言，取向CSNF-PVA水凝胶实现了40.0 MPa的拉伸应力和296%的极限应变，而取向PVA-TA水凝胶的拉伸应力为29.7 MPa，极限应变为278%。这些发现证明了复合单元之间增强相互作用的协同效应。此外，当拉伸后在更高浓度的盐溶液中固定时，通过过度硬化水凝胶，取向CSNF-TA-PVA水凝胶的强度可达到60.2 MPa（应变为250%）（补充图8e）。该水凝胶表现出显著的各向异性，在垂直于其取向方向上表现出19.5 MPa的强度和670%的断裂伸长率。

图 4g 总结了通过首先组装基本 CSNF-TA-PVA 组成单元所实现的强度逐步提升，以及将它们排列成取向结构后更为显著的提高。整体力学性能的大幅增强凸显了受竹材多级组装启发而提出的设计策略的有效性。因此，取向 CSNF-TA-PVA 水凝胶在文献报道的其他 PVA 水凝胶中脱颖而出，兼具高强度与良好的拉伸性（图 4h 和补充表 4）。这些优异的力学性能有望拓展水凝胶在力学要求苛刻场景中的潜在应用。如图 4i 所示，一小块复合水凝胶可以提起重达 20 kg（为其自身重量的 50,000 倍）的重物而不断裂。

## 通过强分子相互作用实现协同增强与增韧机制

与纯 [[聚乙烯醇|PVA]] [[水凝胶]]相比，取向 [[CSNF-TA-PVA]] 复合水凝胶在刚度、强度和拉伸性方面均表现出显著提升（图 5a）。因此，其韧性（以吸收的总机械能计算）从纯 PVA 水凝胶的 $6 . 2 4 \mathrm { M J } / \mathrm { m } ^ { 3 }$ 提高约 20 倍，达到 122.4 MJ/m<sup>3</sup>（图 5b 和补充表 5）。同时，计算得到的断裂韧性为 14.3 MJ/m<sup>3</sup>（补充图 8f）。为了理解强度与韧性的协同增强，研究人员考察了取向复合水凝胶在微观、纳米和分子尺度特征的影响。

在微观尺度上，对不同[[水凝胶]]的断裂面进行了分析（补充图 9）。纯 [[聚乙烯醇|PVA]] 水凝胶表现出光滑、平直的断裂面，而 [[CSNF-PVA]] 和取向 [[CSNF-TA-PVA]] 水凝胶均呈现出不平整的断裂面。[[壳聚糖-海藻酸钠纳米纤维|CSNF]] 作为异质增强相的引入可以阻碍并偏转 PVA 基体中的快速裂纹扩展。此外，取向 CSNF-[[单宁酸|TA]]-PVA 水凝胶表现出阶梯式断裂行为，裂纹在其层间发生偏转，进一步增强了[[能量耗散]]和整体韧性。除了 CSNF 本身的固有强度外，这些机制还通过竹材启发的分子相互作用设计实现了各组分间的有效协同。

## Discussion

总之，本研究开发了一种受竹材层级组织启发的自下而上纳米纤维组装策略。自组装的基于多糖的纳米纤维具有匹配的力学性能和固有功能化表面，与作为界面[[交联]]剂的 [[单宁酸|TA]] 以及作为[[水凝胶]]基质的 [[聚乙烯醇|PVA]] 结合，形成基本组成单元。详细的分子和纳米尺度表征揭示了组分之间强烈的界面[[静电相互作用]]和[[氢键]]作用，这些作用克服并破坏了 PVA 基质中原本的纳米晶结构。与纯 PVA 水凝胶相比，[[CSNF-TA-PVA]] 复合水凝胶同时实现了强度和拉伸性的提升，分别从 4.6 MPa 提高至 13.8 MPa，以及从 360% 提高至 500%。此外，在[[拉伸诱导取向]]作用下，强度进一步提高至 48.0 MPa，[[极限应变]]为 470%，并实现了 60.2 MPa 的最高强度。这种力学改进展现了与竹材中相似的原理，即基本组成单元的固有强度通过取向高阶结构得到有效利用和优化。界面静电相互作用与氢键的协同效应使仿竹复合水凝胶能够在保持柔韧性的同时承受较高机械载荷。因此，本研究提出了一种在分子、纳米和微米尺度上整合化学工程与结构工程以构筑仿生复合水凝胶的模型策略。多尺度表征与分析也为未来研究更好地理解和利用基本分子相互作用以制备强韧复合材料提供了有价值的见解。

## 方法

## 材料

[[壳聚糖]]（CS，脱乙酰度 95%，平均分子量 $\mathsf { M } _ { \mathrm { w } } = 5 0 , 0 0 0$ ，黏度 = 100–200 mPa∙s）、[[海藻酸钠]]（SA，黏度 = 200 ± 20 mPa∙s）和 [[聚乙烯醇|PVA]]（99 + % 水解，Mw = 146,000 \~ 186,000）购自 [[Sigma-Aldrich]]。本研究涉及的其他试剂均为分析纯，未经进一步纯化直接使用。

## [[壳聚糖-海藻酸钠纳米纤维|壳聚糖-海藻酸钠纳米纤维（CSNF）]]的制备

将 1.0 g [[壳聚糖|CS]] 溶解于 49 g 乙酸溶液（去离子水中 1 wt%）中，制备 2 wt% CS 溶液。将 1.0 g [[海藻酸钠|SA]] 溶解于 49 g 去离子水中，制备 2 wt% SA 溶液。将 50 g CS 溶液与 50 g SA 溶液按 1:1 比例混合。随后使用[[超声均质机]]（JY92-IIDN，900 W，25 kHz，[[宁波新芝生物科技股份有限公司]]）对混合物超声处理 2 h，获得[[壳聚糖-海藻酸钠纳米纤维|壳聚糖-海藻酸钠纳米纤维（CSNF）]]悬浮液。

## [[CSNF-TA-PVA]] 复合[[水凝胶]]的制备

将10 g [[聚乙烯醇|PVA]]溶解于90 g去离子水中，制得10 wt%的PVA溶液。将[[壳聚糖-海藻酸钠纳米纤维|CSNF]]悬浮液与PVA溶液按1∶10的质量比混合，得到[[CSNF-PVA]]混合物。随后，对该混合物进行脱气处理，将其浇铸于培养皿（直径90 mm）中，并在空气中干燥，制得CSNF-PVA复合膜。将干燥后的CSNF-PVA复合膜在30 wt%的[[单宁酸|TA]]溶液中再溶胀两天，得到[[CSNF-TA-PVA]][[水凝胶]]。作为对照，将干燥的PVA和CSNF-PVA复合膜分别浸入去离子水中2天，得到纯PVA水凝胶和CSNF-PVA水凝胶。将干燥的PVA浸入TA溶液（30 wt%）中2天，得到[[PVA-TA]]水凝胶。

取向[[CSNF-TA-PVA]]复合[[水凝胶]]的制备。将[[PVA-TA]]-[[壳聚糖-海藻酸钠纳米纤维|CSNF]]水凝胶拉伸至100%应变，并在空气干燥过程中保持该应变。待完全干燥后，将复合材料固定，并在[[硫酸钠|硫酸钠溶液]]（20～30 wt%）中再溶胀。所有样品的[[溶胀率]]均通过溶胀体积比 $\begin{array} { r } { Q { \boldsymbol { v } } = V _ { \mathrm { s w o l l e n } } / V _ { 0 } , } \end{array}$ 确定，其中 $V _ { \mathsf { s w o l l e n } }$ 和 $V _ { 0 }$ 分别表示水凝胶在溶液中浸泡后的平衡体积及其干燥状态的初始体积。

## 表征

采用[[场发射扫描电子显微镜|场发射扫描电子显微镜（FE-SEM）]]对微观形貌进行表征，所用仪器为[[Hitachi Regulus 8230]]和[[Hitachi S4800]]。[[X射线衍射|X射线衍射测试]]使用[[Bruker D8]]衍射仪进行。[[zeta电位]]采用[[Malvern Zetasizer Nano ZS90]]测量。[[原子力显微镜|AFM]]图像使用[[Bruker MultiMode 8]]扫描探针显微镜（SPM，VEECO）在轻敲模式下获取。相位图像通过[[压电响应力显微镜]]（PFM，MFP-3D，[[Asylum Research]]，Oxford，UK）获得。[[傅里叶变换红外光谱|傅里叶变换红外光谱（FTIR）]]采用ATR-[[FTIR]]表征，仪器为[[Agilent CARY 660]]。拉曼分析使用配备TEM单频激光器（λ = 532 nm，激光功率 = 40 mW）的[[共聚焦拉曼显微镜]]（[[Alpha300R]]，[[WITec GmbH]]）进行。采用[[差示扫描量热法|DSC]]表征熔融与结晶性能。[[X射线光电子能谱|X射线光电子能谱（XPS）]]使用[[Thermo Scientific Nexsa]]进行测试，激发源为Al∙Kα（1486.68 eV）。

## [[X射线计算机断层扫描|X射线计算机断层扫描（micro-CT）]]

采用[[X射线计算机断层扫描|X射线计算机断层扫描（micro-CT）]]系统（[[Skyscan 1272]]，Bruker，Germany）进行测试。本研究中用于图示的[[竹子]]采集自中国四川省。使用前，对竹子进行清洗和切片。样品在micro-CT测试前经冷冻干燥处理。

## 力学测试

力学性能在 [[Instron 5500]] 万能试验机上测量，配备 1000 N 力传感器，恒定加载速度为 1 mm/s。[[水凝胶]]样品被裁切成哑铃形（长度：15 mm，宽度：2 mm，厚度：0.30 mm），用于单轴拉伸测试。韧性定义为断裂前吸收的能量，按拉伸应力-应变曲线下方的积分面积计算。[[循环加载-卸载拉伸测试]]在 2 mm/s 的恒定加载速度下进行（最大应变为 150%）。能量损耗系数（η）由以下公式计算：$\eta = W _ { l o s s } / W _ { i n p u t } ,$，其中 $W _ { l o s s }$ 为耗散能量，$W _ { i n p u t }$ 为加载阶段输入的总能量。无缺口和单缺口凝胶样品（预制缺口长度为样品宽度的三分之一）用于评价断裂韧性。带缺口样品被拉伸直至裂纹扩展发生，并记录临界应变（ε）。断裂韧性通过对无缺口样品从零至由带缺口样品所得临界应变 $( \varepsilon _ { \mathrm { c } } )$ 的应力-应变曲线积分确定。

## [[分离式霍普金森压杆|分离式霍普金森压杆（SHPB）]]实验

本研究中使用的 [[分离式霍普金森压杆|SHPB]] 装置包括撞击杆、入射杆、透射杆、吸收杆和数据采集系统。撞击杆通过释放压缩空气加速。当撞击杆撞击入射杆时，产生一个穿过试样的弹性压缩波。数据采集系统随后捕捉入射、反射和透射脉冲，并对其进行分析以确定材料的力学性能。

试样的应力（σ(t)）、应变速率 $( \varepsilon ^ { \cdot } ( \mathfrak { t } ) )$ 和应变历史（ε(t)）可由以下方程确定：

$$
\sigma (t) = E _ {0} \frac {A}{A _ {0}} \varepsilon_ {t} (t)\tag{1}
$$

$$
\varepsilon (t) = - 2 \frac {C _ {0}}{L} \varepsilon_ {r} (t)\tag{2}
$$

$$
\varepsilon (t) = - \frac {2 C _ {0}}{L} \int_ {0} ^ {t} \varepsilon_ {r} (t) d t\tag{3}
$$

其中 $E _ { O }$ 为入射杆的弹性[[模量]]，A 和 $A _ { O }$ 分别表示试样和入射杆的横截面积。L 表示试样的原始长度，而 $C _ { O }$ 表示弹性波在杆中的速度。项 $\varepsilon _ { r } ( t )$ 和 $\varepsilon _ { t } ( t )$ 分别指反射和透射应变脉冲。

## [[水凝胶]]的[[落球冲击测试]]

为评价[[水凝胶]]的防护性能，将制备好的水凝胶置于载玻片上作为防护层。一个重 32 g 的钢球从 1.5 m 的固定高度自由落下，直接冲击被水凝胶覆盖的载玻片。该测试用于评估水凝胶吸收冲击能量并保护玻璃的能力。

## X 射线散射测量

[[小角X射线散射|小角 X 射线散射（SAXS）]]测试使用 [[Xeuss 3.0]] 进行，配备无窗 [[Eiger2 R 1 M Dectris]] 混合像素硅传感器。样品-探测器距离为 500 mm。所用 X 射线能量为 30 W，波长为 1.54 Å。曝光时间设定为 600 s。对于[[广角X射线散射|原位广角 X 射线散射（WAXS）]]测量，测试了取向的 [[CSNF-TA-PVA]] [[水凝胶]]在 0%、50% 和 150% 应变下的状态，样品-探测器距离为 70 mm。2D SAXS 和 WAXS 图像采用 [[FIT2D]] 进行校正处理。方位角强度分布曲线由 FIT2D 软件分析。取向程度通过 [[Herman取向因子|Herman’s 取向参数]] $( f _ { c } ) ^ { 3 1 }$ 评价：

$$
f _ {c} = \frac {1}{2} [ 3 (\cos^ {2} \varphi) - 1 ]\tag{4}
$$

$$
\cos^ {2} \varphi = \frac {\int_ {0} ^ {\pi / 2} I (\varphi) \cos^ {2} \varphi \sin \varphi d \varphi}{\int_ {0} ^ {\pi / 2} I (\varphi) \sin \varphi d \varphi}\tag{5}
$$

其中 $\varphi$ 为方位角，$c o s ^ { 2 } \varphi$ 为取向 [[CSNF-TA-PVA]] [[水凝胶]]方位角余弦平方的平均值，$I ( \varphi )$ 为随 $\dot { \varphi } .$ 变化的一维强度分布

## [[密度泛函理论|密度泛函理论（DFT）计算]]

[[密度泛函理论|DFT 计算]]使用 [[Gaussian 16]]（Revision A.03）计算软件包和 [[GaussView 6|GaussView]] ${ { 6 } ^ { 3 2 } }$ <sup>2</sup> 完成。采用 [[B3LYP]] 泛函<sup>33</sup> 和 $6 { \cdot } 3 1 1 \mathrm { g } ( \mathrm { d } , \mathsf { p } ) ^ { 3 4 }$ 基组，通过 counterpoise 基组重叠误差校正<sup>35</sup> 和 Grimme 经验色散校正的 D3 版本<sup>36</sup>，进行几何优化、能量计算和频率计算。应用水的导体类可极化连续介质溶剂化模型（CPCM）和超细积分网格。所有几何结构均优化至最小值，并在同一理论水平上进行频率计算，以确认不存在虚频。每个原子的[[静电势]]（ESP）分布由 [[Multiwfn]] 计算<sup>37,38</sup>。优化结构和复合物的可视化使用 [[VESTA 3]] 处理<sup>39</sup>。
