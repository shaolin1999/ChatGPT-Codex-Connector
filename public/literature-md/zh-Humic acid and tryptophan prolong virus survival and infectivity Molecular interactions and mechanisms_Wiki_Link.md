## 摘要

病毒引起的感染性疾病是全球公共卫生面临的最重大威胁之一。[[溶解性有机质]]（DOM）是水环境的重要组成部分，由于其独特的结构和性质，常常影响微生物的环境行为。然而，该领域的研究仍然有限，尤其是关于溶解性有机质（DOM）对水中病毒持久性影响的研究。本研究系统考察了[[腐殖酸]]（HA）和[[色氨酸]]（Try）对[[病毒聚集]]与存活特性的影响，并利用[[分子对接]]技术在分子水平上揭示了腐殖酸（HA）和色氨酸（Try）延长[[噬菌体 MS2]] 存活时间（$\mathrm { T _ { 9 9 } }$值增大）的潜在机制。分子对接结果表明，腐殖酸（HA）和色氨酸（Try）分子可通过[[氢键]]、[[范德华力]]等多种分子间作用力，稳定结合于[[噬菌体MS2|噬菌体 MS2]] [[衣壳蛋白]]的特定位点。[[结合能]]（HA：−6.93至−10.73 kcal/mol；Try：−4.33至−5.14 kcal/mol）表明这是一种自发的、热力学有利的相互作用。这种紧密结合直接干扰并破坏了维持噬菌体 MS2 衣壳蛋白天然构象的氢键网络，导致衣壳蛋白中[[α-螺旋]]和[[β-折叠]]减少，促进衣壳蛋白[[二级结构]]的[[去折叠]]。因此，它增强了病毒颗粒的聚集并延长了病毒的存活时间。总之，本研究为降低水源性病原体相关健康风险提供了有价值的理论见解和实践启示。

## 1. 引言

随着全球城市化进程的加快，[[污水]]处理与[[再生水回用]]已成为缓解水资源短缺的重要途径。在六大洲 62 个城市的污水样品中，已检测出超过 2500 种病毒类型（Worp et al., 2025）。病毒已在多种水环境中被广泛检出，包括原污水、二级出水和[[再生水]]（Liang et al., 2025; Ma et al., 2024），并常以不同形态和聚集状态存在。[[肠道病毒]]、[[轮状病毒]]和[[诺如病毒]]等可引发人类多种疾病，包括[[胃肠炎]]和[[呼吸道感染]]，对公共卫生构成直接威胁（Gerba and Betancourt, 2017）。这些病毒可能通过[[饮用水]]、受污染的农产品，或在灌溉或地表水补给后接触娱乐水体而传播，从而增加感染风险（Zhu and Ye, 2025）。因此，病毒在水环境中的存活与传播受到多种因素的影响，研究其环境行为与归趋具有十分重要的意义。

[[溶解性有机质|DOM]] 是指能够通过孔径为 0.45 μm 或 0.22 μm 微滤膜的有机质，普遍存在于各类水环境中（Zhang et al., 2023; Dutta et al., 2017）。DOM 对水环境中发生的生物化学变化具有显著影响（Wang and Chen, 2018; Jiang et al., 2018; Chen et al., 2018）。已有报道指出，DOM 的分解可导致水环境缺氧甚至无氧，从而造成水质恶化和二次污染（Song et al., 2020）。据报道，DOM 同时存在于原[[污水]]和二级出水中，分布广泛，且浓度差异显著。即使经过深度处理，[[再生水]]中仍残留有 DOM。已有报道测定，用于地下回灌的再生水中 DOM 含量为 12.4 mg/L（Lin et al., 2022）。

[[再生水]]利用过程中，病毒可能对人体健康构成威胁。这些病毒的存活与感染性很可能受到再生水中 [[溶解性有机质|DOM]] 的影响。许多研究发现，[[腐殖酸|HA]] 是再生水中 DOM 的典型组分（Wang et al., 2024; Reungoat et al., 2012; Conde-Gonz´alez et al., 2025）。此外，已有研究基于[[荧光光谱]]的[[三维激发-发射矩阵]]分析评价了再生水中的 DOM。通过[[荧光区域积分法]]测定了各区域 DOM 的浓度，结果表明再生水中 DOM 的典型组分为 HA 和 [[色氨酸|Try]]（Wang et al., 2025）。关于 HA 对病毒的影响，现有研究主要集中于 HA 对病毒去除效率的干扰（Cheng et al., 2019; Wang et al., 2026）以及 HA 对分子方法检测病毒的抑制作用（Cao et al., 2015; Wang et al., 2016）。另外，类 Try DOM 可能在影响河水中植物病毒丰度方面发挥关键作用，进一步实验发现，类 Try DOM 在模拟自然条件下可以保护植物病毒。这种保护现象归因于类 Try DOM 对紫外光的有效吸收，从而帮助植物病毒避免紫外线辐射和自由基的有害影响（Wang et al., 2025）。另一项研究表明，[[病毒聚集]]体可提高病毒在环境中的存活率，并增强其对消毒剂的抗性（Gerba and Betancourt, 2017）。然而，现有大多数研究关注的是 DOM 整体或单个 DOM 组分对病毒去除或检测的影响，鲜有报道涉及 HA 和 Try 如何通过分子水平相互作用直接影响病毒聚集与感染性。此外，HA 和 Try 延长病毒存活的具体分子机制仍有待阐明。

本研究旨在考察典型 [[溶解性有机质|DOM]] 对病毒存活的影响及其机制。选择[[噬菌体 MS2]] 作为模型病毒（Shi et al., 2016）。[[噬菌体MS2|噬菌体 MS2]] 是[[世界卫生组织]]推荐使用的病毒替代物（[[US EPA]], 2015），并已在以往有关 DOM 对噬菌体 MS2 富集影响机制的研究中使用，具有良好的可比性。通过 [[zeta 电位]]和[[水动力学直径]]测定分析了 [[腐殖酸|HA]] 和 [[色氨酸|Try]] 对[[病毒聚集]]的影响。利用[[圆二色光谱]]（CD）和[[二维相关红外光谱]]（[[二维相关光谱|2D-COS]]）表征了表面微观结构变化，同时采用[[分子对接]]方法考察了 HA/Try 不同结构与噬菌体 MS2 之间的相互作用机制。

## 2. 材料与方法

## 2.1. [[噬菌体 MS2]] 制备

[[噬菌体 MS2]] 按照已有方案制备（Konarev et al., 2024; Zhu et al., 2025; Kyungho et al., 2025）。简言之，用初始浓度为 10¹¹ [[噬菌斑形成单位|PFU]]/mL 的[[噬菌体MS2|噬菌体 MS2]]（ATCC 15,597-B1）储备液感染[[大肠杆菌]]（ATCC 15,597），并在 37 ℃ 下培养 14 h。将悬液在 4000 × g 下离心 15 min 以去除细菌碎片，收集上清液。

向上述上清液中加入10%（w/v）[[聚乙二醇]]（PEG 6000, [[Sigma-Aldrich]]）和0.5 M NaCl，并将混合物在$4 ~ ^ { \circ } \mathrm { C }$下孵育过夜，以沉淀病毒（Konarev et al., 2024）。通过在8000 × g下离心30 min收集沉淀，并将沉淀重悬于35 mL [[PBS 缓冲液|PBS缓冲液]]（pH 7.2）中。进行氯仿萃取以去除PEG 6000和细胞碎片。经充分混合和分相后，将混合物在3000 × g下离心10 min。将含有病毒的水相转移至新管中，并在温和氮气流下蒸发残余氯仿（Dika et al., 2013）。

随后使用Amicon超滤离心装置（100 kDa截留分子量，[[Merck]]，UFC9100）在4000 × g离心条件下对水相样品进行浓缩。[[聚乙二醇|PEG 6000]]通过滤膜进入滤液，而病毒被截留在膜上。截留的病毒用[[PBS 缓冲液|PBS缓冲液]]洗涤三次，以去除残留的PEG和小分子杂质，然后收集截留液。病毒颗粒洗脱步骤详见补充信息Text S1。纯化后的病毒随后通过0.1 μm[[聚偏二氟乙烯膜]]（[[Millipore]]）过滤，以去除任何残留的细菌碎片和大聚集体（Pisharody et al., 2021; Radu et al., 2022）。最终病毒储备液保存于4 ℃。

病毒颗粒浓度通过标准[[噬菌斑形成单位]]（PFU）测定法确定（Zhu et al., 2025; Kyungho et al., 2025; Anderson et al., 2026）。感染性以PFU/mL表示。通过系列稀释确定检测限为1 PFU/mL。每个稀释度制备三个平行平板。

## 2.2. 水样制备

[[噬菌体MS2]]储备液${ ( 1 0 ^ { 9 } }$ [[噬菌斑形成单位|PFU]]/mL）通过向100 mL超纯水中加入1 mL原始噬菌体悬浮液$( 1 0 ^ { 1 1 } \mathrm { P F U / m L } )$制备。高浓度储备液用于[[三维荧光光谱]]（EEM）、[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）和[[紫外-可见吸收光谱]]（UV–Vis）等表征实验，以确保检测信号的灵敏度。对于噬菌体MS2存活实验、[[ζ电位|zeta电位]]分析和[[动态光散射]]（详细信息见补充材料Text S2），将该储备液进一步稀释至终浓度$1 0 ^ { 3 } – 1 0 ^ { 4 }$ PFU/mL。噬菌体MS2衰减动力学分析见补充材料Text S3。

分别称取[[腐殖酸|HA]]（[[Sigma-Aldrich]]，德国，53,680）和[[色氨酸|Try]]（[[Merck]]，德国，86,197）并溶解于超纯水中，以制备储备液。所有表征实验中使用的HA和Try终浓度分别为4 mg/L和0.5 mg/L。在[[噬菌体MS2]]存活实验中，分别向噬菌体MS2储备液中加入HA和Try储备液，使其终浓度范围分别为0–5 mg/L和0–0.9 mg/L。

使用0.1 mol/L HCl或0.1 mol/L NaOH将混合溶液的pH调节至7.4 ± 0.1。所有样品均为新鲜制备，每个实验条件设置三个平行样品。在每个时间间隔取1 mL样品用于检测[[噬菌体MS2]]的浓度。所有实验均在室温及自然光条件下进行，以无菌[[PBS 缓冲液|PBS缓冲液]]（pH 7.4）作为阴性对照，以已知浓度的噬菌体MS2作为阳性对照。每个实验重复三次。

## 2.3. [[紫外-可见吸收光谱|UV–Vis]]光谱分析

使用[[Shimadzu UV-2600]]分光光度计（日本）在200–400 nm波长范围内以0.5 nm的扫描间隔采集[[紫外-可见吸收光谱|UV–Vis]]光谱。$1 \times 1 0 ^ { 9 }$ [[噬菌斑形成单位|PFU]]/mL[[噬菌体MS2]]被分为两组，一组作为未处理对照，另一组加入[[腐殖酸|HA]]和[[色氨酸|Try]]溶液。

## 2.4. [[三维荧光光谱|EEM]]分析

为研究[[腐殖酸|HA]]和[[色氨酸|Try]]与[[噬菌体MS2]]结合对其结构微环境形成的影响，对该体系进行了[[三维荧光光谱|EEM]][[荧光光谱]]分析。荧光测量使用配备150 W氙灯的荧光分光光度计（[[FP-6500]]，[[Jasco]]，日本）进行。

以激发波长350 nm、发射波长范围380–410 nm处超纯水的拉曼峰面积作为归一化因子对样品光谱进行归一化，从而校正仪器波动及不同测量批次之间的差异（Lawaetz和Stedmon，2009；Li等，2022a）。为在荧光分析前降低内滤效应，含有[[腐殖酸|HA]]和[[色氨酸|Try]]的样品用去离子水稀释10倍。所有[[三维荧光光谱|EEM]]光谱均减去超纯水的空白光谱（与样品相同条件下采集）以去除背景信号，详见补充信息Text S4。

## 2.5. [[圆二色光谱|CD光谱]]分析

为在${ 2 5 ~ ^ { \circ } \mathrm { C } } ,$获取[[圆二色光谱|CD光谱]]，使用配备光电倍增管检测器和光谱管理器的[[Jasco 1500]]（J-1500）分光光度计。使用光程为1 mm的石英比色皿，以100 nm/min的扫描速率进行扫描获得CD光谱。该比色皿带宽为1 nm，响应时间为0.25 s，测量范围为190–250 nm。[[二级结构]]比例使用[[CDNN]]程序确定，该程序通过分析CD光谱变化间接评估[[溶解性有机质|DOM]]是否引起构象变化或改变病毒蛋白的稳定性（Korajkic等，2021；Li等，2022b）。

## 2.6. [[傅里叶变换红外光谱|FTIR光谱]]分析

将1 mg冷冻干燥样品与100 mg KBr（红外级）混合物压制成片，然后使用[[傅里叶变换红外光谱|FTIR光谱]]仪（[[IR Prestige-21]]，[[Nicolet 6700]]，[[Thermo Fisher Scientific]]，英国）对该混合物进行研磨和均质化处理，从而获得[[FTIR]]光谱（Yu等，2012，2011）。[[二维相关光谱|2D-COS]]分析是一种强大的光谱分辨技术，能够揭示体系内各基团在外部扰动下的顺序响应，从而推断[[溶解性有机质|DOM]]对病毒蛋白结构变化的影响（Yu等，2011）。在进行2D分析之前，通过分别对$4 0 0 0 { \ - } 4 0 0 \ \mathrm { c m } ^ { - 1 }$处的吸光度求和并乘以1000对FTIR光谱进行归一化。随后，使用[[主成分分析]]对归一化后的FTIR光谱进行分析，以降低噪声水平（Babamoradi等，2013）。最后，使用2D shige软件进行二维相关光谱分析。

## 2.7. [[飞行时间质谱]]（TOF-MS）分析

使用[[飞行时间质谱]]仪（[[LCMS-IT-TOF]]，[[岛津]]，日本）对[[腐殖酸|HA]]与[[色氨酸|Try]]及[[噬菌体MS2]]相互作用过程中产生的中间产物进行鉴定的分析条件，详见补充信息文本S5。

## 2.8. [[分子对接]]

通过[[分子对接|分子对接模拟]]研究了[[腐殖酸|HA]]和[[色氨酸|Try]]与[[噬菌体MS2]]的结合构型。用于对接的整个噬菌体MS2衣壳的三维结构（pdb\_00009q1b）取自[[蛋白质数据库]]。从结构文件中去除多余的水分子，仅保留纯蛋白分子。使用[[AutoDock Vina]]将六种不同的HA结构（参考文献S1-S6）和两种不同的Try结构（参考文献S8，S9）与整个噬菌体MS2衣壳进行对接（见图S1和图S2）。分子结构式采用[[Chemdraw]]软件绘制，并使用[[Chem3D]]软件进行能量优化，详见补充信息Text S6。

## 2.9. 统计分析

本研究中的所有实验数据均使用 [[Origin 2018]] 和 [[Excel 2021]] 软件进行分析。[[腐殖酸|HA]] 和 [[色氨酸|Try]] 的化学结构使用 [[Chemdraw]] 22.0.0 进行可视化。统计分析使用 [[SPSS]] 软件 v. 25.0（[[IBM]]，Armonk，USA）完成。采用 t 检验判断数据集之间是否存在显著差异。p 值<0.05 表示具有统计学意义。

## 3. 结果与讨论

3.1. 典型 [[溶解性有机质|DOM]] 对[[噬菌体 MS2]] 存活特性的影响

从拟合曲线可以看出，[[指数模型]]（Claudeet et al., 2020）的决定系数（R²）高于 [[fermi 模型]]（Babamoradi et al., 2013）（图 S3、图 S4）。由指数模型得到的曲线与实测值更为接近，并表现出更优的拟合性能。因此，本研究选择指数模型来描述[[噬菌体 MS2]] 在不同水样中的衰减动力学特征。

研究了[[腐殖酸|HA]]浓度对[[噬菌体MS2]]存活时间的影响（图1a）。当HA浓度为4 mg/L和5 mg/L时，第63天仍可检测到噬菌体MS2。研究了[[色氨酸|Try]]浓度对噬菌体MS2存活时间的影响（图1c）。当Try浓度大于0.5 mg/L时，第7天仍可检测到噬菌体MS2。拟合结果见表S3。结果表明，尽管HA和Try均能延长噬菌体MS2的存活时间，但在HA存在下噬菌体MS2的存活时间更长。

[[zeta 电位|Zeta 电位]]与[[噬菌体 MS2]] 颗粒的稳定性密切相关，是评估胶体颗粒稳定性的关键指标。一般而言，[[zeta电位|zeta 电位]]值越高，[[噬菌体MS2|噬菌体 MS2]] 颗粒的稳定性越强（Zhang et al., 2022）。本研究考察了 [[腐殖酸|HA]] 和 [[色氨酸|Try]] 浓度对噬菌体 MS2 颗粒 zeta 电位的影响（图 1b 和 1d）。可以看出，加入 HA 和 Try 后，zeta 电位绝对值降低，表明水样中 HA/Try 与噬菌体 MS2 颗粒之间发生了[[静电吸引]]。值得注意的是，[[天然有机物]]（[[天然有机质|NOM]]）与病毒之间的相互作用存在不同机制。一些研究报道，当 NOM [[吸附]]在病毒表面时，可增强颗粒间的排斥力，从而抑制聚集（Watts et al., 2020）。然而，在本研究中，HA 和 Try 的加入导致 zeta 电位绝对值降低，促进了[[病毒聚集]]，这与 [[DLVO 理论]]的预测一致（Gutierrez and Nguyen, 2012; Abe et al., 2016）。

为确认[[腐殖酸|HA]]和[[色氨酸|Try]]对[[噬菌体MS2]]表面化学结构变化的影响，通过比较加入HA和Try前后的[[傅里叶变换红外光谱|FTIR光谱]]，评估了噬菌体MS2表面的化学性质（图3d、g）。[[FTIR]]光谱中的主要吸收带及其归属列于表S4。FTIR光谱显示，噬菌体MS2、HA和Try在$3 4 4 8 ~ \mathrm { c m } ^ { - 1 }$和$1 2 4 0 \mathrm { c m } ^ { - 1 }$处均具有相似峰，分别表示羟基和羧基。加入HA和Try后，在$1 7 3 5 ~ \mathrm { c m } ^ { - 1 }$（酯基）附近出现新峰，表明HA和Try与噬菌体MS2的表面结构发生了化学反应。这种化学相互作用归因于羟基与羧基之间的[[酯化反应]]。

通过将[[噬菌体MS2]]、噬菌体MS2-[[腐殖酸|HA]]复合物和噬菌体MS2-[[色氨酸|Try]]复合物的[[同步荧光光谱]]转化为[[二维相关光谱]]（[[二维相关红外光谱|2D-COS]]）（Chen et al., 2015），如图3(e、f、h和i)所示。在同步光谱中（图3），沿对角线在1735、1240和3448 cm⁻¹处识别出三个[[自相关峰]]，表明这些官能团对HA/Try与噬菌体MS2之间的相互作用具有显著响应。所有[[交叉峰]]均为正值，表明这些官能团的光谱变化在相互作用过程中沿相同方向发生。

根据 [[Noda规则|Noda 规则]]（Noda 和 Ozaki，2004），从异步谱[[交叉峰]]符号推导[[噬菌体 MS2]]-[[腐殖酸|HA]] 体系中官能团的响应顺序为：3448 $\mathrm { c m ^ { - 1 } } > 1 2 4 0 \ \mathrm { c m ^ { - 1 } } > 1 7 3 5 \ \mathrm { c m ^ { - 1 } }$ ，[[噬菌体MS2|噬菌体 MS2]]-[[色氨酸|Try]] 体系中官能团的响应顺序为：3448 cm $^ { - 1 } > 1 7 3 5 \mathrm { c m } ^ { - 1 } >$ $1 2 4 0 \ \mathrm { c m } ^ { - 1 } \ ( \mathrm { T a b l e \ 1 } )$ 。结合 HA 和 Try 的 [[二维相关光谱|2D-COS]] 分析结果，两者与噬菌体 MS2 相互作用中的光谱峰变化顺序均由羟基引导，表明通过羟基形成[[氢键]]实现复合物的初始稳定是共同的启动机制。然而，随后的官能团响应顺序表现出显著差异。在噬菌体 MS2-HA 体系中，羧基先于酰胺基团和酯基响应，揭示[[静电吸引]]是核心驱动力，这与观测到的 [[zeta 电位]]绝对值降低高度一致（Maguey-Gonzalez ´ 等，2023；Pham 等，2009；Mylon 等，2009）。而在噬菌体 MS2-Try 体系中，酯基先于酰胺基团和羧基响应，羧基最后响应，表明氢键和[[疏水相互作用]]是相互作用中的主导力，静电吸引在后期发挥稳定作用。这种机制差异表明，尽管不同 [[溶解性有机质|DOM]] 组分都能通过分子间相互作用延长病毒存活，但其作用途径和官能团的时间贡献存在根本差异，这为理解实际水体中 DOM 组成多样性对病毒环境行为的影响提供了分子层面的理论基础。

3.5 [[腐殖酸|HA]] 和 [[色氨酸|Try]] 与[[噬菌体 MS2]] 的拟议相互作用机制

图5阐明了HA、Try与噬菌体MS2之间的相互作用机制。ATR-FTIR分析显示，相互作用后出现了新的峰$( 1 7 3 5 \mathrm { c m } ^ { - 1 }$酯基），这表明HA/Try的表面结构与噬菌体MS2之间发生了化学反应。这种化学相互作用归因于羟基与酰胺基之间的席夫碱型反应，以及羟基与羧基之间的酯化反应。分子对接证实，HA和Try通过氢键和范德华力与噬菌体MS2衣壳蛋白稳定结合。结合能（HA：−6.93至−10.73 kcal/mol；Try：−4.33至−5.14 kcal/mol）表明，这是一种自发的、热力学有利的相互作用。

图5. HA和Try与噬菌体MS2的拟议相互作用机制。（a）噬菌体MS2与HA之间的相互作用；（b）噬菌体MS2与Try之间的相互作用。

[[圆二色光谱|CD分析]]表明，与[[腐殖酸|HA]]和[[色氨酸|Try]]相互作用后，[[α-螺旋]]和[[β-折叠]]的含量减少。这种变化破坏了[[噬菌体MS2]]的[[二级结构]]，导致其[[衣壳蛋白]][[去折叠]]。这种结构去折叠具有两个关键的后续效应：（1）[[疏水区域]]的暴露和表面电荷的改变。原本包裹在天然结构中的疏水性氨基酸残基暴露于分子表面，蛋白质表面的电荷分布也可能发生变化，从而增强了病毒颗粒之间的[[疏水相互作用]]和[[静电相互作用]]，进而促进聚集。（2）结构稳定性的降低。衣壳蛋白结构的去折叠可能会降低其对环境胁迫（如蛋白水解和热扰动）的抵抗力。

总之，我们认为，[[溶解性有机质|DOM]]诱导的[[病毒聚集]]是病毒存活时间延长的首要机制。聚集体提供物理保护，将内部病毒粒子与环境灭活因子（如[[活性氧]]、酶等）隔离开来，从而形成一种微保护环境。尽管单个衣壳的稳定性可能下降，但整体聚集效应占主导地位，导致$\mathrm { T } _ { 9 9 }$值升高，病毒存活时间延长。

以往研究报道了其他潜在的病毒-[[溶解性有机质|DOM]]相互作用机制。二价阳离子可以通过[[阳离子桥联]]显著促进病毒在[[天然有机物|NOM]]包覆表面上的[[吸附]]、沉积和聚集。当$\mathrm { C a } ^ { 2 + } \mathrm { o r } \mathrm { M g } ^ { 2 + }$浓度高于0.3 mM时，[[噬菌体MS2]]表现出增强的附着效率。而[[轮状病毒]]需要高达30 mM的$\mathsf { \Pi } _ { \mathsf { C a } } \bar { 2 } +$或高达70 mM的$\mathrm { M g } ^ { 2 + }$临界浓度才能达到[[临界凝聚浓度]]。这些结果凸显了在高二价阳离子条件下，阳离子桥联在病毒界面行为中的主导作用（Pham et al., 2009; Gutierrez and Nguyen, 2012）。本研究（低离子强度、未添加二价阳离子、无固体表面）缺乏这些必要条件。因此，在我们的实验条件下，阳离子桥联并非主导结合机制。

此外，Armanious et al.（2016）指出，[[腐殖酸|HA]]与病毒相互作用时其构象会发生变化。这一机制的重要意义得到充分认同，但本研究主要关注病毒的构象变化。[[溶解性有机质|DOM]]的构象变化是未来值得深入探索的方向。

## 4. 结论

本研究以[[腐殖酸]]（HA）和[[色氨酸]]（Try）作为典型[[溶解性有机质]]（DOM）组分、以[[噬菌体 MS2]] 作为病毒模型，表明 HA 和 Try 可显著延长病毒在[[污水]]和[[再生水]]中的存活时间。机制分析揭示，HA 和 Try 通过 C–H 键、[[氢键]]、[[范德华力]]、[[π–σ相互作用|π–σ 相互作用]]及[[氨基–π堆积|氨基–π 堆积]]与[[噬菌体MS2|噬菌体 MS2]] 表面基团发生相互作用，导致 [[α-螺旋]]和 [[β-折叠]]含量降低、[[衣壳蛋白]][[去折叠]]以及[[病毒聚集]]增强。这些结果表明，HA 和 Try 作为常见天然基质组分，可通过分子相互作用促进病毒在水中的持久性，并可能影响[[再生水回用]]中的传播风险。进一步研究复杂 DOM 组成对病毒存活的影响，以及 DOM–病毒复合物在污水出水和再生水中的迁移，对[[健康风险评估]]具有重要意义。DOM 对病毒存活的延长效应也应在[[基于废水的流行病学]]中予以考虑，因为它直接影响病毒的时空分布和传播潜力。
