# 用于增强[[选择性]]去除水中阴离子[[PFAS]]的两亲性氟胺功能化[[水凝胶]]

收稿日期：2025年4月29日

接受日期：2025年10月2日

[[Kaixing Fu]] <sup>1</sup>， [[Fang Luo]]<sup>1</sup>， [[Zhuoya Fang]]<sup>1</sup>， [[Hengzhi Liu]] <sup>2</sup>， [[Xiaolong Liu]]<sup>3</sup>， [[Shiqing Zhou]]<sup>4</sup> & [[Jinming Luo]] <sup>1</sup>

在线发表日期：2025年11月19日

检查更新

以经济可行的方式有效处理[[全氟和多氟烷基物质]]（[[PFAS]]）以满足严格的水保护标准的需求十分迫切。本文中，我们介绍了一种[[氟胺双位点水凝胶]]（[[QFgel]]），其设计旨在结构上匹配两亲性PFAS分子，促进[[选择性]]相互作用，从而有效去除水中的PFAS。具体而言，QFgel中季铵化官能团与[[氟化官能团]]的[[协同效应]]可促进与PFAS末端全氟烷基链和阴离子头基的[[静电-亲氟双位点相互作用]]。由此，这些双位点相互作用实现了高选择性（[[吸附系数]]范围为1.75至4.0）和超高[[吸附容量]]（最高达2，835 mg g<sup>-1</sup>），在实际水体中环境相关浓度下对17种PFAS的去除率超过95.6%。值得注意的是，中试规模应用中，千克级QFgel[[中试规模吸附器|吸附器]]在[[突破点]]前可有效处理多达12，400和9，215[[床体积]]的PFAS污染饮用水（即[[自来水]]）（[[全氟辛烷磺酸]]（PFOS）和[[全氟辛酸]]（PFOA）突破点， [PFAS] = 约0.35 µg L<sup>-1</sup>， 每天2 m<sup>3</sup>）。连续运行46天后，使用[[盐水]]-[[甲醇]]混合[[洗脱液]]对[[吸附]]器进行[[再生]]，实现了96.5%的[[解吸率]]和高达1，633倍的PFAS富集，同时与商业[[吸附剂]]相比将洗脱液用量减少了70%。该工作通过提供一种可扩展、经济高效的解决方案推进了PFAS修复，并有助于可持续水资源保护。

[[PFAS]] 是持久性人为化学品，以其显著的生物生态毒性而闻名，[[全氟和多氟烷基物质|PFAS]] 的安全且经济高效的处理已成为环境研究的重要焦点<sup>1</sup>。在过去十年中，研究工作主要集中在水生环境中长链 PFAS 的去除<sup>2,3</sup>。然而，随着全球在生产、使用和贸易方面法规的演变，当代社会正在见证工业应用中从长链 PFAS 向短链和支链 PFAS 的转变<sup>4–6</sup>。尽管存在这种转变，由于技术限制，长链 PFAS 在某些行业仍然不可或缺，例如[[全氟辛酸]]（PFOA）在纺织印染行业中的持续使用<sup>6–8</sup>。因此，水体系统中的 PFAS 污染如今呈现为长链、短链和支链变体的复杂混合物，浓度范围从万亿分之一到十亿分之一<sup>9,10</sup>。为了解决混合链 PFAS 污染问题，[[吸附]]和[[膜分离]]被认为是最有效的技术<sup>11–13</sup>，其中吸附因其可定制的[[选择性]]和富集性能而具有更大的前景<sup>14,15</sup>。以往的[[吸附剂]]，如[[活性炭]]、[[树脂]]以及各种新型材料，主要依赖尺寸排阻、[[疏水相互作用]]和[[氢键]]等机制<sup>16–18</sup>。然而，这些方法使它们容易受到干扰力的影响，例如排斥性静电力、π-π 堆积和色散相互作用<sup>19–21</sup>。因此，吸附剂往往存在[[吸附动力学]]欠佳、容量降低和选择性差的问题。此外，缓慢的[[解吸]]速率、高[[洗脱液]]用量以及[[再生]]所需的频繁更换，进一步使这些材料的实际应用复杂化<sup>22–24</sup>。因此，开发能够高效去除水资源中 PFAS，同时促进快速且低成本解吸的新型实用吸附剂，对于推进可持续[[水处理]]技术至关重要。

在水性环境中，[[PFAS]] 的含氧头基会解离为离子形式（如磺酸根和羧酸根）<sup>17,25</sup>，并倾向于被正电性位点吸引。为改进[[吸附剂]]，研究者们致力于接枝带电基团（如酰胺基、亚胺基），但这些方法对阴离子 [[全氟和多氟烷基物质|PFAS]] 仍表现出非特异性吸引<sup>26,27</sup>。[[天然水体]]系统通常含有大量竞争性阴离子、阳离子和[[溶解性有机质]]（[[有机质|DOM]]），其浓度可比 PFAS 高出六个数量级以上<sup>28</sup>。这些组分可能通过静电中和、双电层效应和空间位阻等方式阻碍 PFAS 的[[吸附]]<sup>17</sup>。PFAS 与共污染物的非[[选择性]]吸附不仅使 PFAS 去除过程更加复杂，也给[[吸附剂再生]]和浓缩 PFAS 的后处理带来挑战。为应对这些问题，吸附剂设计策略开始强调基于这些化合物中全氟碳尾部的[[亲氟相互作用]]，特别是 [[F···F相互作用|F···F 相互作用]]，以实现 PFAS 的选择性捕获<sup>29–31</sup>。根据 [[Pauling原理|Pauling 原理]]，氟（F）原子具有较低的原子极化率和较弱的色散力，因而倾向于自聚集，同时尽量减少与非氟物质的相互作用<sup>32,33</sup>。目前已开发出多种含氟吸附剂，包括含氟无孔笼<sup>34</sup>、含氟骨架<sup>30,35</sup>和含氟环糊精聚合物<sup>36,37</sup>，与非氟化对照材料相比，其[[去除效率]]提高了约 10–90%。尽管这些材料对环境干扰具有更强的抵抗能力，但仍面临一个重要挑战：单一[[氟化位点]]的工作范围较短，相互作用能较弱（6.3–16.7 kJ mol<sup>−1</sup>）<sup>29,38</sup>，导致其对 [[全氟辛烷磺酸|PFOS]] 和 [[全氟辛酸|PFOA]] 的[[吸附容量]]不理想（低于 200 mg g<sup>−1</sup>）<sup>34,37,39–43</sup>。虽然有研究报道了同时引入氟化基团和胺化基团的吸附剂，但并未重点关注这些官能团在吸附剂中的均匀分布，这可能导致[[协同效应]]有限并降低[[吸附性能]]。这些局限性阻碍了实际应用，也限制了吸附过程中的抗干扰能力。在实际场景中，这可能造成吸附柱提前穿透，需要频繁更换串联或并联模式运行的吸附剂填充柱，从而增加资本投入和运行成本。

基于 [[PFAS]] 的[[两亲特性]]，我们提出了一种结构匹配的氟胺双[[吸附位点]]设计策略。这类双位点[[吸附剂]]能够利用 [[全氟和多氟烷基物质|PFAS]] 的两亲性，同时作用于其亲氟尾部和阴离子头基，从而[[选择性]]捕获 PFAS。以季铵氟凝胶（[[氟胺双位点水凝胶|QFgels]]）作为概念验证，我们通过调整单体选择与合成本优化这些位点：改变氨基和氟结构以构建有利于 PFAS 扩散与[[吸附]]的微观结构。值得注意的是，[[自由基共聚]]可确保氟胺双位点在凝胶基质中的均匀分布，这是其[[协同效应]]和增强选择性吸附的关键，优于此前的氟胺共修饰吸附剂。这种双重机制将长程[[静电相互作用]]与短程[[亲氟性]]结合起来，优化了 PFAS 的扩散与选择性结合。这些氟胺基元通过非活化酯键共价连接至聚合物链，赋予 QFgels 足够的水解稳定性，从而保障处理水安全。QFgels 使用源自药用植物残渣的[[纤维素]]及其他低成本商业原料，在温和条件下经[[一锅法]]合成，优于大多数依赖复杂合成、昂贵有毒溶剂和苛刻条件的现有氟化吸附剂。[[QFgel]] 的实际可扩展性已通过公斤级生产和中试规模[[水处理]]原型（每天 2 m³）得到验证。此外，氟胺位点适中的结合强度有利于 PFAS [[解吸]]，降低了[[再生]]时对[[洗脱液]]的需求，从而实现低成本、可持续的重复使用。本研究为设计具有特异性结合和高效解吸能力的位点提供了思路，也为实用、可持续的 PFAS 修复提供了一条有前景的路径。

## 结果

## 合成与表征

合成的主要目标是构建氟胺修饰平台以提高 [[PFAS]] 捕获效率。前期结果表明，在各种含 N 基团（即 -NH、=NH、-N(CH<sub>3</sub>) 和 -N<sup>+</sup>(CH<sub>3</sub>)<sub>3</sub>）中，[[季铵基团]]对 [[全氟和多氟烷基物质|PFAS]] 的静电[[吸附]]特别有效（补充图 1–8），原因在于它们在水环境中始终保持正电荷<sup>17</sup>。利用[[自由基共聚]]，我们合成了一系列具有不同化学结构的 [[氟胺双位点水凝胶|QFgels]]（图 1a 和补充图 1–4），其中引入了[[甲基丙烯酰氧乙基三甲基氯化铵]]（[[MTAC]]）和[[含氟单体]]（即 F6、F8、F9 和 F12；化学细节见补充方法 1）。这些 QFgels 分别标记为 QF6、QF8、QF9 和 QF12，并设计为具有均匀的静电-亲氟微网络。通过梯度引入含氟单体，可精确调控 QFgels 中的理论 F 含量，这是决定其[[亲氟性]]的关键因素。在对 PFAS 去除性能进行初步评估后（补充图 5–8），选择这些 F 含量相同（2.57–2.62 mmol mL<sup>−1</sup>）的 QFgels，以进一步优化含氟单体类型。同时合成了一种非氟季铵[[水凝胶]]（[[QA]]）作为性能比较的对照样品（补充图 4）。

[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）显示，[[QA]] 中聚合物颗粒呈现无定形形貌并发生团聚，这可能是由于[[交联]]网络过度溶胀后突然塌缩所致（图 1b 和补充图 9）<sup>44,45</sup>。相比之下，所有 [[氟胺双位点水凝胶|QFgels]] 均表现出由分散纤维组成的高度互穿孔结构（图 1c 和补充图 10–13），有利于水分渗透和污染物在网络内的传输。对这些毫米级[[水凝胶]]的[[孔径分布]]进行统计分析，发现其具有一致的微米级孔隙，直径范围为 2.01 至 3.68 μm。同时，[[Brunauer-Emmett-Teller分析|Brunauer-Emmett-Teller]]（[[BET]]）分析显示，与 QA 相比，QFgels 具有更宽的介孔分布（2.0–24.0 nm）（图 1d、1e 和补充图 14–16）。这些结果突出了 QFgels 的多孔结构特征，即同时具有微米级通道和介孔（图 1f）。[[热重分析]]（TGA）和压缩应力-应变测试进一步证明了这些水凝胶良好的热稳定性和机械稳定性（图 1g 和补充图 17、18），表明其在不同操作条件下具有应用潜力。此外，水[[接触角]]（α）测试表明，引入氟结构提高了 QFgels 的[[亲氟性]]和疏水性（图 2a），这有利于氟类物质的聚集。

基于[[Langmuir模型]]拟合，[[QFgel]]对[[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]]、[[全氟丁烷磺酸|PFBS]]和[[GenX]]的理论[[吸附容量]]$( Q _ { \mathrm { m } } )$分别确定为2835.0、2150.2、1231.0和$4 9 6 . 2 \mathrm { m g g ^ { - 1 } } ,$，约为[[QA]]的1.21–3.35倍（图3b及补充图34和表5）。相应地，[[氟胺双位点水凝胶|QFgel]]与大多数商用[[吸附剂]]（如[[树脂]]、[[活性炭]]）和创新[[吸附]]剂的[[PFAS]]容量总体对比见补充表6。除[[六氟环氧丙烷二聚酸|GenX]]外，[[Freundlich模型]]对[[吸附等温线]]的拟合优于[[Langmuir]]模型，表明[[吸附位点]]能量分布不均且存在多层吸附行为。值得注意的是，[[全氟和多氟烷基物质|PFAS]]吸附过程可能因吸附质-吸附质相互作用而涉及PFAS分子的自组装。然而，GenX的支化结构和醚键阻碍了其在凝胶内的扩散与传输。在如此低的固相浓度下未形成GenX胶束，这可能是导致其吸附容量相对较低的原因。与前述两种模型相比，采用[[Sips模型]]拟合GenX等温曲线具有更高的稳健性（补充图35和表7），表明表面覆盖不均匀且单层与多层吸附并存<sup>52</sup>。温度效应结果进一步证实了PFAS的多层吸附（补充图36），因为较低温度不仅诱导$\mathsf { P F A S } ^ { 5 3 }$的显著自聚集，从而带来更高的PFAS容量，而且促进了吸附剂上氟化结构与PFAS之间的相互作用，导致吸附剂表面发生额外的共聚集。包括标准[[吉布斯自由能]]$( \Delta G ^ { \circ } )$、[[焓变]]（ΔH°）和[[熵变]]（ΔS°）在内的热力学参数已计算并汇总于补充表8。$\Delta G ^ { \circ }$和$\Delta S ^ { \circ }$为负值表明PFAS吸附在热力学上有利，并伴随吸附剂界面无序度降低。ΔH°为负值表明吸附过程放热，与较低温度下更高的PFAS容量一致，说明PFAS去除为焓驱动过程<sup>54</sup>。

通常，背景阴离子和[[有机质]]可能通过位点竞争、双电层效应和空间位阻屏蔽[[吸附位点]]。因此，我们在[[去离子水]]体系中两种不同初始[[PFAS]]浓度下评估了共存阴离子和[[溶解性有机质|DOM]]对[[全氟和多氟烷基物质|PFAS]]去除的环境影响。在初始PFAS浓度为$0 . 3 \mu \ g \mathrm { L } ^ { - 1 }$时，即使存在Cl⁻、${ \mathsf { N O } } _ { 3 } { } ^ { - } , { \mathsf { S O } } _ { 4 } { } ^ { 2 - }$和[[腐殖酸]]（[[HA]]），[[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]]和[[全氟丁烷磺酸|PFBS]]的[[去除效率]]仍分别保持在97.5%、95.6%和94.6%以上（补充图37a、b）。当初始PFAS浓度为1.0 μg L<sup>−1</sup>时，可观察到类似现象，但去除效率更高（PFOS、PFOA和PFBS分别为98.7%、98.2%和96.6%）（图3c和补充图37c）。这与图2h中的结果一致，即即使在真实[[自来水]]和[[湖水]]基质中，三种PFAS的去除也未受到明显影响。对于[[GenX]]，在这些干扰物种存在下去除效率降至71.0%–91.1%，明显低于去离子水中的96.0%（图2h），表明[[六氟环氧丙烷二聚酸|GenX]]在[[QFgel]]上的[[吸附]]受到削弱。这种下降不能归因于氟碳单元减少或疏水性降低，因为氟碳单元更少且疏水性更低的PFBS仍被有效去除。相反，短链PFAS，尤其是带有羧基官能团的短链物质，其吸附更易受共存阴离子的影响<sup>55</sup>。此外，GenX的支[[链结构]]可能阻碍其通过凝胶孔道向吸附位点迁移，尤其在有机质造成的污染效应下更是如此。因此，具有经过精心调控孔结构的平台以容纳GenX分子，可能进一步提高其在复杂环境中的去除效果。此外，还在[[pH]] 4.0至10.0范围内进一步评估了去离子水和湖水中PFAS的去除性能。如图3d所示，在整个测试pH范围内，[[氟胺双位点水凝胶|QFgel]]对PFOS、PFOA和PFBS保持了93.5%以上的高去除效率，而对GenX则保持了62.0%以上的中等去除效率。在不同pH下未受影响的表现突显了双位点相互作用相对于静电力的关键作用，因为在$\mathrm { \ p H > \mathsf { p H } _ { \mathrm { p z c } } . }$时，表面电荷被中和，静电力应当减弱。在此背景下，将QFgel用于[[水处理]]时无需调节pH，显著提高了其实际应用价值。

可重复使用性是 [[PFAS]] [[吸附剂]]实际应用中的关键因素。在已报道的各种[[洗脱液]]中，特定比例的 [[氯化钠|NaCl]] 与[[甲醇]]（MeOH）混合物在[[吸附剂再生]]方面表现出最大的潜力。原则上，具有高[[辛醇-水分配系数]] $( K _ { \mathrm { o w } } )$ 的 [[全氟和多氟烷基物质|PFAS]] 倾向于溶解在极性 MeOH 中，MeOH 作为“桥梁”增强 PFAS 在混合洗脱液中的溶解度。NaCl 的引入通过竞争[[吸附]]或静电屏蔽作用破坏吸附剂与 PFAS 之间的[[静电相互作用]]。因此，MeOH/NaCl 混合物可能同时削弱双位点上的静电和[[亲氟相互作用]]，从而促进 PFAS 从我们的两亲性平台中[[解吸]]。我们首先在单次洗脱过程中使用不同 MeOH/NaCl 混合物评估了预负载 PFAS 的 [[QFgel]] 的[[再生性能]]。如补充图 38 所示，使用 1.0% NaCl 与 MeOH 溶液（30:70，v/v）几乎可将所有 PFAS 从 [[氟胺双位点水凝胶|QFgel]] 中解吸。偏离该最佳比例会导致解吸效率下降 10–80%。因此，在循环测试中采用该混合物[[再生]] QFgel。如图 3e 和补充图 39 所示，无论使用的洗脱液体积如何（10、20 或 100 mL），在全部六个循环中 PFAS [[去除效率]]均保持较高水平。值得注意的是，即使仅使用 10 mL 洗脱液，经过六个循环后 [[全氟辛酸|PFOA]] 去除效率仍高达 99.9%，而 [[全氟辛烷磺酸|PFOS]]、[[全氟丁烷磺酸|PFBS]] 和 [[GenX]] 的去除效率超过 91.5%，证明了 QFgel 的可重复使用性。此外，QFgel 保持了较高的结构稳定性，六个循环后微观形貌变化极小（补充图 40）。总体而言，适度的 F···F 作用力以及两亲性平台中双位点的位点区分有助于提高洗脱液的利用效率。这一改进实现了材料的可持续再利用，同时将 PFAS 有效浓缩于溶液中。

随后，在对 [[QFgel]] 与四种阴离子 [[PFAS]] 的性能进行基准测试之后，进一步在[[去离子水]]（[[DW]]）和[[湖水]]（LW）中开展了测试，水样中添加了化学结构多样的 17 种传统与新兴 [[全氟和多氟烷基物质|PFAS]] 混合物，浓度处于环境相关水平（0.4–1.5 μg L<sup>−1</sup>）。这些 PFAS 的化学信息详见补充图 41–43 和表 9。[[QA]] 和 [[氟胺双位点水凝胶|QFgel]] 在 DW 中均表现出较高的[[去除效率]]（补充图 44），分别达到 95.6%–99.6% 和 97.2%–100.0%。然而，在 LW 中，QFgel 显著优于 QA（图 3f），对所有 PFAS 均保持了较高去除效率：短链 PFAS 超过 96.5%，长链 PFAS（[[全氟辛酸|PFOA]]、[[全氟壬酸]]（PFNA）和 [[全氟辛烷磺酸|PFOS]]）超过 99.0%，醚类 PFAS（[[GenX]]、[[4,8-二氧杂-3H-全氟壬酸酯]]（ADONA）和 6:2 氯代多氟醚磺酸盐（6:2 Cl-PFESA，商品名 F-53B））超过 97.5%。对于含九个及以上全氟碳单元的 [[全氟烷基羧酸|PFCA]]（[[全氟癸酸]]（PFDA）、[[全氟十一酸]]（PFUdA）、[[全氟十二酸]]（PFDoA）），去除效率略低，但仍超过 95.6%。相比之下，QA 在 LW 中的性能明显较低，去除效率范围为 4.5%–41.5%。动力学分析表明，在碳原子数相同的情况下，[[全氟烷基磺酸|PFSA]] 比 PFCA 被[[吸附]]得更高效、更迅速（补充图 45–47 和表 10），这可能是由于其更高的[[亲氟性]]所致。这些结构—吸附关系与已有研究的结论一致<sup>55,56</sup>。此外，QFgel 与典型商业[[吸附剂]]（如[[颗粒活性炭]]（GAC）、[[IRA-410]]、[[A520E]] 和 [[PFA694E]]）之间的进一步性能比较表明，QFgel 对这些结构多样的 PFAS 具有更高的去除效率（补充图 48），凸显了这种两亲性[[水凝胶]]策略性设计所带来的技术优势。

为量化 [[QA]] 和 [[QFgel]] 对各类 [[PFAS]] 的[[吸附]]亲和力，利用现有数据计算了[[吸附系数]]（logK）值。在 [[DW]] 中，两种[[水凝胶]]的 logK 值相近，QA 的范围为 1.64–2.98，[[氟胺双位点水凝胶|QFgel]] 的范围为 1.75–4.0（图 3g）。值得注意的是，在真实 [[湖水|LW]] 基质中，两种水凝胶的 logK 分布呈现出显著差异。在这种具有挑战性的条件下，QFgel 对 [[全氟和多氟烷基物质|PFAS]] 表现出较强的结合能力，logK 值范围为 1.64–3.60。相比之下，QA 的 $\mathsf { I o g } K _ { \mathrm { D } }$ 值范围为 −1.03 至 0.15，表明其在实际应用中效果不佳。$\mathsf { l o g } K _ { \mathrm { D } }$ 值的详细分解见补充图 49。这些结果证实了 QFgel 在处理 PFAS 污染天然水方面的巨大潜力，同时强调双位点策略在增强对 PFAS 污染物亲和力方面的有效性。

[[选择性]]高效去除 [[PFAS]] 的机理认识 为阐明 [[全氟和多氟烷基物质|PFAS]] 去除的主客体结合机制，我们开展了系统表征。以阴离子型 [[全氟辛烷磺酸|PFOS]] 和 [[全氟辛酸|PFOA]] 作为代表性 PFAS，研究其在 [[QFgel]] 中两亲位点上的[[吸附]]相互作用（图 4a 和图 4b）。N 1s 谱的 [[XPS]] 分析表明，PFAS 吸附后，[[氟胺双位点水凝胶|QFgel]] 上 $\left. - \mathsf { N } ^ { + } ( \mathsf { C } \mathsf { H } _ { 3 } ) _ { 3 } \right.$ 基团的结合能上移约 0.21 eV（图 4c 和补充图 50），表明其参与了 PFAS 去除过程。然而，尽管 PFAS 在 QFgel 上显著富集，[[X射线光电子能谱|XPS]] F 1s 谱中未观察到明显的结合能位移（图 4d）。这一现象符合 [[Pauling 原则]]，即 F 核具有低极化率和高电负性，能够紧紧束缚其电子云，因此即使发生相互作用，也难以引起结合能的显著变化<sup>29</sup>。固态 <sup>19</sup>F MAS [[核磁共振|NMR]] 谱中 <sup>19</sup>F 化学位移的完整归属表明，PFAS 被 QFgel 捕获后，其 F 原子处于不同的化学环境<sup>57</sup>，这从 PFAS 各 F 原子化学位移的变化中得到了证实（图 4e 和补充图 51）。这些结果意味着 PFAS 与 QFgel 之间存在 [[F···F相互作用|F···F 相互作用]]。值得注意的是，a-F 原子（即 PFOS 中离磺酸基最近的 F 原子）的化学位移变化最为显著（–0.45 ppm），表明其在所有 F 原子中化学环境变化最大。结合 XPS N 1s 谱分析可以推断，阴离子磺酸基与 $\mathsf { Q F g e l } ^ { 5 8 }$ 的[[季铵基团]]发生[[静电相互作用]]。在[[双位点平台]]设计中，–N<sup>+</sup>(CH ) 基团对 PFAS 的阴离子头基提供静电吸引，而氟结构则通过 F···F 相互作用与 PFAS 的氟碳尾部发生作用。尽管如此，仍需注意 F···F 相互作用的工作范围有限且相互作用能较低，这使其识别更加复杂，并可能影响整体吸附效能。

为更深入地探究，我们进一步使用了二维 ${ } ^ { 1 9 } \mathsf { F - } ^ { 1 9 } \mathsf { F }$ 交换[[核磁共振]]谱（[[2D NOESY]]），其中交叉峰表示空间邻近的 F 原子之间的空间偶极–偶极相互作用<sup>59</sup>。对[[吸附]] [[PFAS]] 的 [[QFgel]] 进行 [[二维核磁共振谱|2D NOESY]] 实验，生成了多个可分辨的 $^ { 1 9 } \mathsf { F }$ 信号以及多组位于不同位置的 F 原子之间的交叉峰。具体而言，我们在图 4f 中观察到两个显著的交叉峰，位于 (δ\_F1, δ\_F2) = (– 79.2ppm, – 86.0ppm) 和 (– 79.2ppm, – 125.6 ppm)，揭示了 [[氟胺双位点水凝胶|QFgel]] 与 [[全氟辛烷磺酸|PFOS]] 之间的紧密相互作用。化学位移归属表明，这种紧密相互作用来源于 PFOS 的 – ${ \bf - C F _ { 2 } C F _ { 3 } }$（即 (ii–vi)-F 和 viii-F）与 QFgel 的 $- \mathbf { C F } _ { 3 }$（即 γ-F）之间的 [[F···F相互作用|F···F 相互作用]]（补充图 52）。通过降低谱图中的强度阈值，还进一步观察到归属于较弱相互作用的额外交叉峰（例如 β-F 与 viii-F，α-F 与 vii-F）。此外，在吸附 [[全氟辛酸|PFOA]] 的 QFgel 的 2D NOESY 中发现的一系列交叉峰，为 PFOA 去除过程中的紧密 F···F 相互作用提供了证据（图 4g 和补充图 53），与 PFOS 中观察到的情况相似。需要注意的是，[[全氟和多氟烷基物质|PFAS]] 与 QFgel 的 F 原子化学位移在 – 114.0 至 – 128.9ppm 范围内的重叠，使峰的详细去卷积变得复杂<sup>57</sup>；因此，吸附质与[[吸附剂]]之间可能还存在尚未被识别的额外 F···F 接触。

季铵化和[[氟化位点]]对[[选择性]]高效去除[[PFAS]]的功能已得到证实；然而，这两种活性位点的贡献尚未被充分理解。为区分[[季铵化位点]]和氟化位点在[[吸附]]过程中的作用，我们利用[[分子动力学]]（[[分子动力学模拟|MD]]）模拟研究了[[全氟和多氟烷基物质|PFAS]]在单位点体系（即纯氟链或季铵链）和双位点体系（即氟胺链）中的扩散行为。MD快照显示，PFAS能够在短时间内快速吸附到氟胺链上（补充图54和55），并形成多链聚集体。相比之下，PFAS在氟链和季铵链上的吸附速率较慢，尤其在氟链上更为明显。这是由于短程F···F相互作用限制了PFAS的初始积累。基于[[均方位移]]（MSD）曲线（图4i），对PFAS[[扩散系数]]（D）的定量计算表明，在平台中引入氟结构可显著增强PFAS吸附。这一效应对[[全氟辛烷磺酸|PFOS]]尤为明显，其D值下降至原始值的四分之一（补充图56a）。这种下降主要归因于PFOS中较高的全氟碳含量，其通过更强的F···F相互作用稳定体系。与单位点体系相比，吸附在双位点上的PFAS的D值显著更低，表明这些双位点与PFAS形成更稳定的吸附复合物。这一观察结果与[[径向分布函数]]（RDF）分析结果一致（图4j和补充图56b）。利用[[DFT]]计算，我们进一步研究了PFAS在氟胺两亲位点上的主客体相互作用。[[分子静电势]]（[[静电势|ESP]]）表面显示PFOS、[[全氟辛酸|PFOA]]、[[全氟丁烷磺酸|PFBS]]和[[GenX]]整体呈负电荷分布（补充图57），在阴离子羧酸根或磺酸根基团附近存在更强的负电区域。这种电荷分布促进了静电吸引，从而增强PFAS吸附，其中PFAS和[[吸附剂]]分别充当电子供体和受体（补充图58和表11）。四种PFAS在氟胺链上的优化配位复合物显示出协同吸附构型，其中氟化位点和季铵化位点分别与氟尾和阴离子头基相互作用（补充图59）。计算得到的[[吸附能]]$( E _ { \mathrm { a d } } )$范围为$- 0 . 2 \mathrm { t o } - 0 . 3 5 \mathrm { e V }$，表明PFAS在氟胺链上的吸附在能量上是有利的（图4k）。有趣的是，尽管PFOS在氟胺链上的$E _ { \mathrm { a d } }$比在季铵链上更负，但随着全氟烷基链长度缩短，这种差异逐渐减小。我们将这种转变主要归因于季铵化位点和氟化位点与PFAS相互作用强度的变化，这通过比较四种PFAS在季铵链和氟链上的吸附能趋势得以证实。实验上，[[QFgel]]对PFBS的[[吸附容量]]高于[[六氟环氧丙烷二聚酸|GenX]]，这与[[密度泛函理论|DFT]]计算得到的$E _ { \mathrm { a d } }$值相矛盾。这种差异表明GenX的支[[链结构]]阻碍了其在凝胶孔道内的扩散。为了更好地可视化吸附体系中的相互作用区域，我们基于[[Hirshfeld 分区|Hirshfeld]]划分$( { \mathsf { I G M H } } ) ^ { 6 0 }$进行了[[独立梯度模型]]分析，IGMH 等值面图和散点图清晰显示出显著的蓝色尖峰和–<sup>+</sup>$( \mathrm { C H } _ { 3 } ) _ { 3 }$基团以及阴离子$\cdot { \bf S 0 } _ { 3 } ^ { - }$或$\cdot { \bf C O } _ { 2 } ^ { - } \left( { \bf F i g s . } 4 { \bf l - n } \right.$，以及补充图60–62），证实了四种PFAS在氟胺链上吸附时存在强[[静电相互作用]]。此外，氟化位点与全氟碳尾部之间的绿色尖峰和等值面区域表明存在相对较弱的E.…E相互作用和[[范德华力|vdW力]]。这些发现与通过带ESP着色的分子间vdW表面穿透图得到的结果一致（补充图63）。

## Discussion

尽管全球都在努力减轻[[PFAS]]污染，但含[[全氟和多氟烷基物质|PFAS]][[消费品]]（如[[纺织品]]、[[消防设备]]和[[锂离子电池]]（LIBs）<sup>6–8,66</sup>）的广泛使用以及[[工业废水]]排放，仍通过各种途径持续污染淡水。[[长链PFAS]]虽在逐步淘汰，但在特定行业中依然存在，导致具有不同化学性质的复杂PFAS污染。这凸显了开发高效、稳定且可持续技术以实现水中PFAS全面去除的必要性。就[[饮用水处理]]而言，两个关键因素需要考虑：成本与安全性。为了有效去除PFAS，与[[吸附]]相对应的技术是[[反渗透]]（RO）和[[纳滤]]（NF）。虽然这些技术的资本成本通常相近，但其运行费用差异显著。RO和NF属于[[能耗密集型过程]]，能耗为3–10 kWh m<sup>−3</sup>，而吸附通常需要的能耗低于1.5 kWh m<sup>−3</sup><sup>67–69</sup>。此外，RO/NF过程产生的[[浓盐水]]处置也会增加总体处理成本。值得注意的是，如前所述，吸附过程相比RO/NF表现出更高的[[富集因子]]（EFs）。尽管[[树脂]]和[[活性炭]]在[[水处理]]中仍是相对昂贵的选择，但降低[[吸附剂]]成本有望使吸附技术成为更具吸引力的PFAS去除方案。这表明，借助具有成本效益的吸附剂，吸附法可能成为更广泛采用的饮用水PFAS处理方法。

结合这一点以及[[PFAS]]的[[两亲特性]]，我们开发了具有成本效益的[[氟胺双位点平台]]，以实现广谱[[全氟和多氟烷基物质|PFAS]]去除。通过多功能[[水凝胶]]合成，我们制备了[[QFgel]]，该材料具有丰富且均匀的[[吸附位点]]、[[高吸水性]]和[[互穿多孔结构]]。[[氟胺双位点水凝胶|QFgel]]在不同[[pH]]值、[[离子强度]]和[[天然水体]]基质中均表现出强大的[[吸附性能]]，实现了[[快速动力学]]、高[[吸附容量]]、[[选择性]]、[[深度去除]]和可行的[[再生性能]]。机理研究揭示了[[氟化位点]]与[[季铵化位点]]的[[协同效应]]，强调了[[静电-亲氟主客体相互作用]]在增强PFAS选择性方面的重要性。为评估QFgel在水生应用中的安全性，我们进行了额外实验和表征，证实在pH范围为$5 { - } 9$的水体中应用时，不存在[[氟化片段]]或[[季铵盐]]二次泄漏的风险（补充图69）。此外，我们进一步测试了QFgel在处理实际[[纺织废水]]和[[市政废水]]中的性能，这些废水的条件比天然水体更为复杂（补充表14和15）。结果表明，QFgel仍能有效降低PFAS水平，对这两种废水的[[去除效率]]分别高于98.6%和98.7（补充图70和71），进一步凸显了其[[工业适用性]]。

我们还将 [[QFgel]] 集成到一种紧凑、便携的[[吸附装置]]中（包括[[终端使用装置]]），旨在为缺乏净化基础设施的农村或偏远地区提供[[清洁水源]]。基于 [[氟胺双位点水凝胶|QFgel]] 的[[吸附]]装置在处理受 [[PFAS]] 污染的[[自来水]]方面表现出实用性，其[[解吸]]与[[再生]]仅需约 7.4 倍[[床体积]]的[[盐水]]–[[甲醇]]混合液，从而降低了运行成本（约 \$0.038 m<sup>−3</sup>）。据推测，[[洗脱液]]中 MeOH 和 [[氯化钠|NaCl]] 的高可回收性将最大限度减少试剂消耗和[[危险废物]]产生<sup>24</sup>。此外，通过高效解吸获得的亚 ppm 级浓 [[全氟和多氟烷基物质|PFAS]] 溶液有望通过液相分解技术进行降解<sup>70</sup>，从而克服[[高级氧化]]或[[还原工艺]]在修复 PFAS 污染[[天然水体]]方面的局限性。

[[PFAS]] 修复的未来发展将受益于拓展[[双位点平台]]的应用范围，以捕获更广泛的 [[全氟和多氟烷基物质|PFAS]] 类型，包括[[两性离子型PFAS|两性离子型]]和[[非离子型PFAS|非离子型]] PFAS，以及[[双全氟烷基磺酰亚胺|双全氟烷基磺酰亚胺类]] $( { \tt b i s - F A S l s } ) ^ { 6 6 }$ ，这是一类氮基[[阴离子氟化表面活性剂]]，在新兴[[锂离子电池]]技术中的应用日益增多。这些新兴 PFAS 在[[自然水体系统]]中越来越普遍，引发了日益增长的关注，亟需加以应对。有针对性的位点调节结合[[多尺度流体动力学模拟]]，可进一步优化[[孔隙结构]]以强化[[传质]]。此外，提高氟位点的可及性和[[亲氟性]]对于提高[[位点利用率]]至关重要；表征亲氟特性并调整[[链结构]]，可在尽量少用氟的前提下保持高亲氟性。[[吸附剂]]粒径和形状的[[可控合成]]将有助于更广泛的应用。模块化、均匀的[[造粒]]可以简化合成过程，并解决床层内[[流体分布]]不均等实际问题。最后，适当的[[溶胀比]]和[[颗粒刚性]]可以缓解长时间[[水力应力]]和升高的[[柱压]]造成的[[颗粒破碎]]，从而维持稳定的[[水处理]]过程并延长[[吸附剂使用寿命]]。总体而言，本工作通过利用 PFAS 的[[两亲特性]]，为开发高性能[[氟胺双位点吸附剂]]提供了思路。我们希望本工作能够激发面向污染物的[[吸附]]剂设计的进一步创新，通过可持续策略应对日益复杂的[[环境污染物]]。

## 两亲性[[氟胺双位点水凝胶|QFgels]]的合成

两亲性[[氟胺双位点水凝胶|QFgels]]通过在[[引发剂]]和[[交联剂]]存在下，使[[季铵单体]]和[[含氟单体]]共聚合成。为增强[[水凝胶]]的力学性能，将[[CNF]]引入网络中，其提取过程在补充方法3中描述。为合成QFgels，将[[MTAC]]和含氟单体、[[N,N’-亚甲基双丙烯酰胺|N，N’-亚甲基双丙烯酰胺]]以及[[过硫酸铵]]在CNF悬浮液中混合制成溶液。该混合物在$7 0 ^ { \circ } \mathrm { C }$下经历[[热引发自由基聚合]]，形成两亲性QFgels。这些QFgels浸入[[DW]]中充分溶胀，切成小颗粒（约5 mm），并用[[去离子水|DW]]反复浸泡和洗涤5次。最后，将QFgels在[[电热干燥箱]]中干燥48 h，获得最终[[吸附剂]]颗粒。公斤级QFgels的合成通过将反应放大50倍并使用数十个平行合成反应器实现。[[吸附]]剂制备的详细信息见补充方法3。

## 批量[[吸附]]实验

等温[[吸附]]实验通过在[[恒温振荡器]]中改变反应温度（10、25和$4 0 ^ { \circ } \mathrm { C } )$）进行。不同浓度的[[PFAS]]实验溶液通过稀释相应储备液获得。用于探究[[全氟和多氟烷基物质|PFAS]]在[[水凝胶]]网络内吸附和扩散的动力学实验在$\mathbf { a t } \sim 1 5 . 0 \mu \mathbf { g } \mathbf { L } ^ { - 1 }$的PFAS条件下进行。环境因素（如[[pH]]）的影响通过逐滴加入$0 . 1 \mathrm { m o l } \mathrm { L } ^ { - 1 }$ [[HCl]]或[[NaOH]]调节溶液pH来评估。[[离子强度]]和背景有机物的影响通过向吸附体系中加入两组浓度的阴离子和[[DOMs]]进行考察，包括$( 0 . 5 \mathrm { m m o l L ^ { - 1 } }$的阴离子和$1 0 \mathrm { m g L ^ { - 1 } }$的[[HA]]）以及$( 5 \mathrm { m m o l } \mathrm { L } ^ { - 1 }$的阴离子和$1 0 0 \mathrm { m g L ^ { - 1 } }$的[[腐殖酸|HA]]）。批量吸附实验在恒温振荡器中以恒定搅拌（180 rpm）进行，以减小[[传质阻力]]。所有实验均设置三个平行样，图中的误差棒表示数据的[[标准偏差]]。更多实验细节见补充方法4。本研究中生成的实验数据提供于补充信息和源数据文件中。

为了评估 [[PFAS]] [[吸附性能]]，[[吸附容量]] $( Q _ { \mathrm { e } } , \mathsf { m g } \{ \mathsf { g } ^ { - 1 } \}$ 、[[去除效率]]（%）以及分配系数的对数转换值 $( \mathrm { l o g } K _ { \mathrm { D } } )$ 通过以下公式计算：

$$
Q _ {\mathrm{e}} = \frac {V (C _ {0} - C _ {\mathrm{e}})}{m}\tag{1}
$$

$$
\text{Removal efficiency} = \frac {(C _ {0} - C _ {\mathrm{e}})}{C _ {0}} \times 100 \%\tag{2}
$$

$$
\log K _ {\mathrm{D}} = \log \left(\frac {(C _ {0} - C _ {\mathrm{e}})}{C _ {\mathrm{e}}} \times \frac {V}{1 0 0 0 \times m}\right)\tag{3}
$$

其中 V 为 [[PFAS]] 溶液体积（mL），为[[吸附剂]]质量 $( \mathbf { g } ) , C _ { 0 }$ ，$C _ { \mathrm { e } }$ 分别为 [[全氟和多氟烷基物质|PFAS]] 的初始浓度和平衡浓度（μg L<sup>−1</sup>），$K _ { \mathrm { D } }$ 为分配系数 $( \mathsf { L } \mathsf { g } ^ { - 1 } )$ 。其他[[吸附模型]]，包括 [[Langmuir]]、[[Freundlich模型|Freundlich]]、Sips、[[传质]]和热力学方法，见补充方法 5。

## 中试规模[[水处理]]工艺

为验证 [[QFgel]] 在接近实际条件下连续净化 [[PFAS]] 污染水的能力，我们设计了一套分散式、全集成移动[[吸附]]处理系统，日处理能力为 $2 \mathsf { m } ^ { 3 }$ 。吸附柱（即 [[氟胺双位点水凝胶|QFgel]] [[中试规模吸附器|吸附器]]）填充 11.8 千克 QFgel [[吸附剂]]（直径约 5 mm），并在吸附器顶部和底部各铺设 8 cm 厚的石英砂层（粒径 5–10 mm）。吸附循环期间，[[全氟和多氟烷基物质|PFAS]] 加标母液和原水经静态混合器泵送均质后，以升流模式进入吸附柱。[[再生]]循环期间，原水泵和母液泵关闭，洗脱泵开启，[[吸附剂再生|再生]]溶液沿相同流路通过吸附柱。环境温度通过室内空调维持在 $2 5 \pm 3 ^ { \mathrm { o } } \mathrm { C }$ 。吸附器尺寸及其他操作条件汇总于补充表 12。

## [[DFT]] 计算与 [[分子动力学模拟|MD]] 模拟

针对 $E _ { \mathrm { a d } } ,$ 、[[吸附]]构型和 [[分子静电势|ESP]] 的 [[DFT]] 计算用于揭示吸附机制以及氟亲和-静电双位点之间的协同作用，计算采用 Gaussian 16 软件包（Revision C. 01）。吸附几何构型和单点能在 CAM-B3LYP/6-31 + G (d, p) 水平下计算<sup>55,71</sup>。选用该杂化泛函是因为其改进的长程性质，能更好地描述带电阴离子和阳离子物种的电子效应。计算中加入了色散校正，采用 Grimme 等人的 D3 校正方法，并配合 Gaussian 16 软件包中实现的 Becke-Jonson（BJ）阻尼<sup>72</sup>。采用可极化连续介质模型的自洽反应场计算以考虑水的溶剂效应。[[密度泛函理论|DFT]] 计算和 [[分子动力学模拟|MD]] 模拟的细节见补充方法 6 和 7。优化后的 DFT 模型和 MD 模拟数据已提供于补充数据 1。
