## 摘 要

长链[[全氟及多氟烷基物质]]（[[全氟化合物|PFAS]]）具有高度持久性和[[生物累积性]]，对健康和环境构成严重风险，亟需从水体系统中予以去除。传统[[沸石咪唑酯骨架-8]]（[[ZIF-8]]）虽然[[孔隙率]]很高，但缺乏特异性的亲氟[[结合位点]]，限制了其在实际捕获 [[全氟和多氟烷基物质|PFAS]] 方面的效能。为此，本研究采用[[溶剂辅助法]]在室温下合成了一种新型氟化 ZIF-8（[[F-ZIF-8]]）。结构表征证实了–CF 基团的引入以及骨架的高度完整性。与传统 ZIF-8 相比，[[氟化金属有机框架|F-ZIF-8]] 对长链 PFAS 的[[吸附]]性能显著提升。例如，对[[全氟辛烷磺酸]]（PFOS）和[[全氟壬酸]]（PFNA）的[[去除率]]分别达到 88.72% 和 90.43%，是 ZIF-8（39.71% 和 43.28%）的两倍以上。对[[全氟辛酸]]、PFOS、PFNA 和[[全氟壬烷磺酸]]的[[吸附容量|最大吸附容量]]分别为 529.64、585.33、1135.18 和 1346.72 mg g<sup>–1</sup>。值得注意的是，新兴 PFAS [[六氟环氧丙烷四聚体酸]]表现出 1484.28 mg g<sup>–1</sup> 的最大吸附容量。吸附过程遵循[[准二级动力学]]，并能较好地用 [[吸附等温线|Langmuir 和 Freundlich 等温线]]描述，表明其中涉及表面化学相互作用和多层吸附。[[分子动力学]]和[[DFT|密度泛函理论]]计算证实了[[F-F非共价相互作用|氟-氟非共价相互作用]]在增强吸附中的关键作用。此外，F-ZIF-8 在较宽的 pH 范围（最佳为 7–9）、不同[[离子强度]]以及真实水基质（[[饮用水]]、[[自来水]]、[[海水]]和[[水产养殖废水]]）中均保持较高的吸附性能。经过四次[[吸附循环|再生循环]]后，吸附衰减低于 10%。这些结果表明，F-ZIF-8 是一种高效、稳定且可重复使用的[[吸附剂]]，可用于从复杂水基质中去除长链 PFAS。

## 1. 引言

随着人类社会的加速发展，环境压力也同步加剧。[[全氟及多氟烷基物质|全氟和多氟烷基物质]]（[[全氟化合物|PFAS]]）是一类广泛分布于多种环境介质中的[[新型污染物]]，已引起科学界的高度关注[1]。这些物质由全氟或部分氟化的碳链与各类官能团组成，包括羧酸、磺酸、膦酸、次膦酸、磺酰胺、醚羧酸和醚磺酸等官能团[2,3]。由于其拒水拒油特性及优异的稳定性，[[全氟和多氟烷基物质|PFAS]]被广泛用于工业产品和消费品中[4]。因此，这些化合物已在多个环境分区中普遍存在，尤其是在水体生态系统中[5,6]。PFAS中的[[碳-氟键|碳-氟（C-F）键]]具有很高的键能，使其成为“[[永久性化学品]]”[7]。此外，其强烈的[[生物累积性|生物累积潜力]]对生态和人类健康构成严重威胁[8]。目前已识别出超过12,000种PFAS，包括[[全氟辛酸]]（PFOA）、[[全氟辛烷磺酸]]（PFOS）和[[GenX]][9,10]。认识到其环境风险后，[[欧盟]]（EU）等监管机构已实施严格的控制措施。例如，[[欧盟饮用水指令]]（EU 2020/2184）规定[[饮用水]]中PFAS总限值为500 $\mathrm { n g } \mathrm { L } ^ { - 1 }$ [11]。此外，附件III B部分所列20种优先物质PFAS的总浓度不得超过100 ng $\mathrm { L } ^ { - 1 }$。相比之下，[[中国《生活饮用水卫生标准》]]（GB 5749–2022）规定PFOA限值为$8 0 ~ \mathrm { { n g ~ L ^ { - 1 } } }$，PFOS限值为40 $\mathrm { { n g ~ L ^ { - 1 } } }$ [12]。这些监管框架凸显了开发有效PFAS[[水处理]]技术的迫切需求。

[[全氟化合物|PFAS]]处理方法大致分为四类：[[高级氧化与还原工艺]]、[[膜分离]]、[[泡沫蒸馏]]和[[吸附]][13–15]。其中，前三种方法需要高能耗和昂贵设备。相比之下，吸附因其低能耗和高效率而被认为是缓解水体环境中[[全氟及多氟烷基物质|PFAS]]污染的最佳方法之一[16,17]。目前，[[活性炭]]和[[离子交换树脂]]是应用最广泛的吸附技术[18–21]。然而，这些材料存在诸多局限性，尤其是吸附床更换频繁和再生困难。此外，这些[[吸附剂]]的后处理过程通常涉及焚烧，且其对[[全氟和多氟烷基物质|PFAS]]捕集效果有限，这促使人们寻找更具选择性和更高能效的吸附材料[22–24]。

[[金属有机框架]]（MOFs）因其独特的多孔结构、[[高比表面积]]和可调性质，已成为处理[[持久性有机污染物]]（包括[[全氟化合物|PFAS]]）的有前景候选材料[25–27]。然而，传统MOFs面临显著局限性，包括[[吸附容量]]有限、选择性不足以及在复杂水体环境中稳定性差。这些局限性主要源于传统MOFs缺乏特定靶向位点，例如氟化官能团，因此只能依赖较弱的物理或[[静电相互作用]]。这类非特异性弱相互作用不足以结合[[全氟及多氟烷基物质|PFAS]]高度疏水且刚性的C-F链。因此，在复杂水体环境中，这些相互作用很容易被普遍存在的背景离子和天然有机物竞争并破坏，导致[[吸附]]效率显著下降[28]。此外，许多传统MOFs在水体环境中稳定性差，源于其金属-配体配位键固有的脆弱性。水分子，尤其是在不同pH条件下，可作为竞争配体，诱导这些配位键发生水解和断裂，最终导致框架坍塌和[[孔隙率]]丧失[29,30]。传统MOFs表面官能团对[[全氟和多氟烷基物质|PFAS]]的弱选择性吸附在含多种PFAS的混合体系中尤为不利，导致去除效率降低。总体而言，这些局限性阻碍了MOFs在PFAS修复中的大规模应用[31]。为应对这些挑战，引入功能化配体和精确调控金属节点结构等方法可显著改善MOFs的表面化学性质[32]。含有氟或极性基团的功能化配体可以增强MOFs与PFAS分子氟碳链之间的[[疏水相互作用]]、[[静电吸引]]以及F-F非共价键合[33,34]。近期研究表明，氟化材料，特别是表面富氟的[[氟化金属有机框架|氟化MOFs]]，可显著增强与PFAS分子的相互作用，从而提升吸附性能[35]。开发氟化MOFs为PFAS去除提供了一种新途径，因为其表面氟-氟（F-F）相互作用和疏水力能够与PFAS中的氟碳链形成更强的物理化学键，从而提高吸附效率[36]。值得注意的是，[[沸石咪唑酯骨架-8|沸石咪唑酯骨架（ZIFs）]]因其优异的稳定性、明确的孔结构和出色的吸附性能而受到广泛关注[37,39]。其中，[[ZIF-8]]表现出显著的PFAS吸附性能；然而，其缺乏特异性亲氟[[结合位点]]，限制了其在实际PFAS捕获中的效能[40]。因此，开发新型氟化ZIF-8（[[F-ZIF-8]]）材料以改善表面相互作用，将成为提高水体环境中PFAS去除效率的关键方向。

在本研究中，我们开发并合成了一种新型氟化 [[金属有机框架|MOF]]，[[F-ZIF-8]]，使用 [[2-(三氟甲基)-1H-咪唑]]作为有机配体，锌离子 $( Z \mathrm { n } ^ { 2 + } )$ 作为金属中心。[[氟化金属有机框架|F-ZIF-8]] 表面丰富的 ${ \mathrm { - C F } } _ { 3 }$ 基团显著改善了材料与 [[全氟化合物|PFAS]] 分子之间的[[疏水相互作用]]和 [[非共价相互作用|F-F 非共价相互作用]]。我们系统优化了合成参数，并通过多种表征方法成功制备了该材料。针对不同链长和官能团的 [[全氟及多氟烷基物质|PFAS]] 化合物，严格评估了所合成材料的[[吸附]]性能。结果表明，其选择性和[[吸附容量]]显著高于非氟化对照材料。其对[[全氟和多氟烷基物质|长链 PFAS]] $\left( \mathrm { C } > 8 \right)$ 的吸附容量尤为突出，[[全氟壬酸]]（PFNA）、[[全氟壬烷磺酸]]（[[全氟壬磺酸|PFNS]]）和六氟环氧丙烷四聚酸（[[HFPO-TeA]]）的吸附容量均超过 1100 mg $\mathbf { g } ^ { - 1 }$ 。此外，我们在混合 PFAS 体系中考察了材料在不同条件下的吸附行为，包括[[离子强度]]、pH 和复杂水相基质的变化，证明了其卓越的稳定性和适应性。此外，还评估了该材料在实际应用中的可重复使用性和耐久性，表明其具有优异的再生潜力和结构完整性。通过结合吸附实验、[[分子动力学]]（MD）模拟和[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）计算的综合方法，我们阐明了 F-F 非共价相互作用在提高 PFAS 吸附效率方面的关键作用。这些结果为开发用于 PFAS 污染修复的高性能[[吸附剂]]提供了有价值的见解。

## 2. 材料与方法

## 2.1. 化学品与试剂

[[全氟丁酸]]（PFBA）、[[全氟丁烷磺酸]]（PFBS）、[[全氟己酸]]（PFHxA）、[[全氟己烷磺酸]]（PFHxS）、[[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]]、[[全氟壬酸|PFNA]]、[[全氟壬烷磺酸|PFNS]]、[[六氟环氧丙烷二聚酸]]（HFPO-DA）和 [[HFPO-TeA]]，纯度均 > 98%，购自 [[Alta Scientific Co.|Alta Scientific]] $\mathrm { { C o . } }$ （中国天津）。其他化学品，包括[[氢氧化钠]] $\left( \mathrm { N a O H ; } \ > \ 9 8 \% \right)$ 、[[氢氧化铵]]（NH ⋅H O；25%–28%）、[[乙酸钠]] $( \mathrm { N a O A c ; } > 9 8 \% )$ 、[[三乙胺]]（TEA）（> 98%）、[[六水合硝酸锌]] $( > 9 8 \% )$ 、[[2-甲基咪唑]]（> 98%）、[[2-(三氟甲基)-1H-咪唑]]（> 98%）、[[氯化钠]]（NaCl；> 98%）、[[硫酸钠]] $\left( \mathrm { N a _ { 2 } S O _ { 4 } } ; > 9 8 \% \right)$ 、[[氯化镁]] $( \mathrm { M g C l _ { 2 } ; > 9 8 \% ) }$ 和[[硫酸镁]] $( \mathrm { M g S O _ { 4 } ; \mathrm { ~ > ~ } 9 8 \% ) }$ ，购自 [[Macklin]]（中国上海）。液相色谱-质谱级[[甲醇]]由 [[Merck]]（德国达姆施塔特）提供。[[高效液相色谱]]级[[乙酸铵]]购自 [[Sigma-Aldrich]]（美国密苏里州圣路易斯）。所有溶液均使用[[去离子水]]（DI water）配制。

## 2.2. [[F-ZIF-8]] 的制备

[[F-ZIF-8]] 在室温下以[[甲醇]]为溶剂、采用[[溶剂辅助法]]合成。所用金属源为[[六水合硝酸锌]] $[ \mathrm { Z n } ( \mathrm { N O } _ { 3 } ) _ { 2 } { \cdot } 6 \ \mathrm { H } _ { 2 } \mathrm { O } ]$ ，有机配体为 [[2-(三氟甲基)-1H-咪唑|2-三氟甲基-1H-咪唑]]（[[2-三氟甲基咪唑|2-TFMI]]）。以 [[氢氧化钠|NaOH]] 水溶液作为[[去质子化剂]]。各组分按摩尔比 $\mathrm { Z n } ( \mathrm { N O } _ { 3 } ) _ { 2 } { : } 2 \cdot$ -TFMI:NaOH:$\mathrm { M e O H } \ = \ 1 { : } 8 { : } 1 . 5 { : } 2 0 0$ 混合。混合物在 500 rpm 下搅拌 30 min，并在室温下静置 8 h。随后将所得悬浮液在 8000 rpm 下离心收集沉淀，再于 80 ℃ 真空干燥。基于产率评价标准，进一步优化了[[去质子化]]剂的种类和用量。详细实验步骤见补充材料 Text S1。

## 2.3. 表征与分析方法

采用[[衰减全反射傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FT-IR]]，[[Thermo Fisher Scientific]]，[[Nicolet iS50]]，美国）分析膜表面在 4000 至 400 cm<sup>–1</sup> 范围内的化学变化。利用配备能量色散 X 射线光谱（[[能量色散X射线光谱|EDS]]）的[[场发射扫描电子显微镜]]（FE-[[SEM]]，[[ZEISS Sigma 300]]，德国）表征 [[F-ZIF-8]] 的形貌和元素分布。通过 X 射线衍射（[[XRD]]，[[Rigaku]]，[[SmartLab SE]]，日本）进行结构分析。利用 X 射线光电子能谱仪（[[XPS]]，[[Thermo Fisher Scientific K-Alpha]]，美国）评价化学组成。采用全自动[[BET|比表面积]]分析仪（[[Micromeritics]]，[[ASAP 2020]]，美国），通过[[氮气吸附-脱附实验]]，基于 [[Brunauer-Emmett-Teller]]（BET）和 [[t-plot方法|t-plot]] 方法分析[[比表面积]]和孔道特征。

## 2.4. [[吸附]]实验

在 [[F-ZIF-8]] 优化实验中，将 8 mg 新制备的 [[氟化金属有机框架|F-ZIF-8]] 加入到 40 mL 浓度为 1 µmol $\mathrm { L } ^ { - 1 }$ 的 [[全氟辛酸|PFOA]] 溶液中。混合物在恒温摇床中 $2 5 \pm 0 . 5 ^ { \circ } \mathsf { C }$ 连续振荡 24 h。在 0.5、4、8、12 和 24 h 从每个容器中采集等分试样 $( 5 0 0 ~ \mu \mathrm { L } )$。经 12,000 rpm 离心后，上清液通过 0.22 µm 滤膜过滤，并采用[[液相色谱-串联质谱]]（LC-MS/MS）分析测定 PFOA 浓度。

为研究[[吸附动力学]]，在相同条件下分别使用 [[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]]、[[全氟壬酸|PFNA]]、[[全氟壬烷磺酸|PFNS]] 和 [[HFPO-TeA]] 的单一溶液进行实验。在预定时间间隔（0.5、1、2、4、8、12、24 和 48 h）取样测定浓度。随后在保持其他实验参数不变的条件下，对相同[[全氟和多氟烷基物质|长链 PFAS]] $\left( \mathbf { C } ~ \geq ~ 8 \right)$ 在 1–20 μmol $\mathbf { L } ^ { - 1 } { \boldsymbol { \mathbf { \mathit { \Phi } } } }$ 浓度范围内测定[[吸附等温线]]。

此外，还考察了溶液组成对[[吸附]]的影响。在加入 [[F-ZIF-8]] 前，用 0.1 M HCl 或 [[氢氧化钠|NaOH]] 将 [[全氟化合物|PFAS]] 溶液调节至 pH 3、5、7、9 和 11，以评价 pH 的影响。同时，通过向 [[全氟及多氟烷基物质|PFAS]] 溶液中加入 10 mM 不同盐类（[[氯化钠|NaCl]]、$\mathrm { N a _ { 2 } S O _ { 4 } , M g C l _ { 2 } , }$ 和 $\mathrm { M g } { \bf S } \mathrm { O } _ { 4 } )$）评价[[离子强度]]的影响。除另有说明外（在优化、动力学和等温线实验中），所有其他吸附测试均使用含 10 种 [[全氟和多氟烷基物质|PFAS]] 化合物（[[全氟丁酸|PFBA]]、[[全氟己酸|PFHxA]]、[[全氟辛酸|PFOA]]、[[全氟壬酸|PFNA]]、[[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]]、[[全氟辛烷磺酸|PFOS]]、[[全氟壬烷磺酸|PFNS]]、[[六氟环氧丙烷二聚酸|HFPO-DA]] 和 [[HFPO-TeA]]）的 1 µmol $\mathrm { ~ \bar { ~ } L ^ { - 1 } ~ }$ 混合溶液进行。吸附时间统一为 8 h，其余条件保持不变。

## 2.5. [[液相色谱-串联质谱|LC-MS/MS]] 分析

[[全氟化合物|PFAS]] 采用[[高效液相色谱]]（HPLC）系统（[[Shimadzu Prominence LC-20ADXR]]）与 [[5500 QTRAP 混合三重四极杆质谱仪]]（[[Sciex]]）联用进行分析，质谱仪在[[电喷雾电离|负电喷雾电离模式]]下运行。所用分析方法改编自本研究团队先前建立的方法 [41]。更多细节见表 S1。

## 2.6. 真实水环境中的[[吸附]]实验

为评估该[[吸附]]系统的实际适用性，使用[[饮用水]]、[[自来水]]、[[海水]]和[[水产养殖废水]]开展了对比吸附实验。饮用水为市售商品，自来水取自中国青岛市市政供水。海水采集自[[黄海]][[胶州湾]]，水产养殖废水则取自蛤类养殖过程。本研究所用水样的初始理化性质见表 S2，且所有水样中 [[全氟化合物|PFAS]] 的背景浓度均低于[[检出限]]（LOD）。其余实验条件均与第 2.4 节所述一致，吸附实验使用 1 µmol $\mathrm { L } ^ { - 1 }$ 混合溶液进行，该溶液在四种水基质中分别配制，含十种 [[全氟及多氟烷基物质|PFAS]] 化合物。

## 2.7. [[F-ZIF-8]] 的再生与重复使用

为评估 [[F-ZIF-8]] 的可重复使用性，在初始[[吸附]]实验后开展了一系列重复使用测试。这些测试所用方法与第 2.4 节所述一致。吸附后的 [[氟化金属有机框架|F-ZIF-8]] 通过离心收集，随后在含 10 mM [[乙酸铵]]的 80% [[甲醇]]溶液中以 160 rpm 振荡 2 h 进行再生。再生后，F-[[ZIF-8]] 用[[去离子水]]充分冲洗，并在 $7 0 \ \textdegree$ 下干燥 12 h。干燥后的 F-[[沸石咪唑酯骨架-8|ZIF-8]] 随后重新用于 [[全氟化合物|PFAS]] 吸附，并评价其吸附效率。每个再生—重复使用循环计作一个重复使用周期，共进行了四个重复使用周期。

## 2.8. 理论计算

通过 [[密度泛函理论|DFT 计算]]和 [[分子动力学模拟|MD 模拟]]阐明 [[全氟化合物|PFAS]] 在 [[F-ZIF-8]] 上的[[吸附]]行为，并研究其动态吸附形态。[[全氟及多氟烷基物质|PFAS]] 分子在 [[氟化金属有机框架|F-ZIF-8]] 上的吸附能采用下式计算：

$$
\text { Eadsorption } = \mathrm{E} _ {\mathrm{MOF/PFAS}} - \mathrm{E} _ {\mathrm{MOF}} - \mathrm{E} _ {\mathrm{PFAS}}
$$

其中 $E _ { a d s o r p t i o n } ,$ E<sub>[[金属有机框架|MOF]]/[[全氟化合物|PFAS]]</sub>、E<sub>MOF</sub> 和 E<sub>[[全氟及多氟烷基物质|PFAS]]</sub> 分别表示[[吸附]]能、吸附后状态的总能量以及[[吸附剂]]和吸附质各自的能量。[[密度泛函理论|DFT 计算]]采用 [[Gaussian 16]] 隐式溶剂化模型进行，[[分子动力学模拟|MD 模拟]]使用 [[Materials Studio 2023]]。详细计算见补充信息 Text S2。[[独立梯度模型]]（IGM）分析使用 [[MultiWfn]] 软件进行 [42,43]。

## 2.9. 质量保证

所有实验均使用[[聚丙烯]]样品瓶和离心管进行，以尽量减少 [[全氟化合物|PFAS]] 因[[吸附]]到容器表面而造成的损失 [44]。使用前，这些 PP 容器均经[[甲醇]]充分洗涤并风干，所有实验均进行三次重复。在无 [[F-ZIF-8]] 条件下进行的对照实验证实，[[全氟及多氟烷基物质|PFAS]] 在容器壁上的损失低于 2%，目标化合物的回收率为 98% 至 110%。

定量分析采用[[内标法]]结合校准曲线进行。校准曲线在 0.1–30 nmol $\mathbf { L } ^ { - 1 } { } _ { : }$ 浓度范围内表现出优异的线性，相关系数 $( r ) > 0 . 9 9 5$ 。[[检出限]]如下：[[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]]、[[全氟壬酸|PFNA]] 和 [[全氟壬烷磺酸|PFNS]] 为 0.06 nmol $\mathrm { L } ^ { - 1 }$ ；[[全氟丁酸|PFBA]]、[[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]] 和 HFPO-TDA 为 0.09 nmol $\mathrm { L } ^ { - 1 }$ ；[[全氟己酸|PFHxA]] 和 [[HFPO-TeA]] 为 0.12 nmol $\mathrm { L } ^ { - 1 }$ 。

## 3.1. [[F-ZIF-8]] 合成条件的优化

在合成筛选之后，对这四种 [[F-ZIF-8]] 材料在 24 h 内的 [[全氟辛酸|PFOA]] [[吸附]]性能进行了比较（图 1a）。[[氢氧化钠|NaOH]] 合成的材料不仅产率高，而且表现出最快、最有效的吸附，在 4 h 内即达到最大吸附量。相反，使用 [[三乙胺|TEA]] 合成的材料吸附速率较慢，需要 20 h。这种优异性能可归因于 NaOH 的强碱性，它加速了配体[[去质子化]]并促进快速[[成核]]。这一过程通常产生更小的[[微晶]]，具有更短的[[颗粒内扩散]]路径。与 TEA 等弱碱介导的较慢[[结晶]]相比，它可能产生富含缺陷的结构，从而显著增强[[传质]]和对大体积 PFOA 分子的可及性。根据这些结果，选择 300 μL 1 M NaOH 作为最佳去[[质子化]]条件，兼顾高产率与高效吸附。

接下来，在优化后的[[氢氧化钠|NaOH]]条件下，评价了[[金属与配体摩尔比]]对[[吸附]]性能的影响[46, 47]。研究了1:2、1:4、1:8和1:16 $( \mathrm { Z n } ^ { 2 + }$ 对[[2-(三氟甲基)-1H-咪唑|2-TFMI]]）的配比（图1b），并比较了它们的[[全氟辛酸|PFOA]]吸附效率。如图1b所示，反应8 h后，吸附效率从摩尔比1:2时的64.01%提高到1:4时的72.36%，在1:8时达到峰值94.01%，随后在1:16时下降至80.31%。1:8组还在4 h内达到其[[吸附容量|最大吸附容量]]，在所有测试配比中表现出最快的快速吸附速率。这些结果表明，1:8的配比提供了最有利的结构平衡。在较低配比下，骨架形成不完全会减少可用的吸附位点数量，而过高的配比则会产生过于致密的骨架，阻碍PFOA向孔内扩散。

这些结果共同表明，[[F-ZIF-8]]的最佳合成条件为300 μL 1 M [[氢氧化钠|NaOH]]和1:8的金属与配体比。因此，在该条件下制备的材料被用于后续所有表征与性能评价。

值得注意的是，高氟化 [[全氟化合物|PFAS]]（包括 [[全氟辛烷磺酸|PFOS]] 和 [[全氟壬酸|PFNA]]）对 [[F-ZIF-8]] 表现出异常牢固的结合，[[吸附]]效率超过 88%。这些数值比 [[ZIF-8]] 所观察到的数值高出一倍以上。这些发现表明，引入[[氟化配体]]不仅改善了材料的整体吸附性能，还赋予其对高度氟化 [[全氟及多氟烷基物质|PFAS]] 分子的选择性亲和力 [54, 55]。

## 3.3.2. [[吸附动力学]]与等温线

[[吸附动力学]]和等温线对于理解水溶液中污染物去除的速率、容量和机制至关重要。动力学通常使用准一级（[[准一级模型|PFO]]）和准二级（[[准二级模型|PSO]]）模型进行描述 [57]。PFO 模型假设[[吸附]]速率与平衡容量和 t 时刻吸附量之间的差值成正比。相反，PSO 模型假定速率与该差值的平方成正比，并且通常与表面控制的吸附过程相关。同时，[[吸附等温线]]定量描述吸附质分子与[[吸附剂]]表面之间的平衡相互作用，提供最大吸附量和亲和常数等关键参数 [58,59]。总体而言，动力学和等温线分析为吸附过程提供了互补的认识，阐明了其动态行为和平衡特征。

图 6a-b 展示了 PFOA、PFOS、PFNA、PFNS 和 HFPO-TeA 在 F-ZIF-8 上吸附的 PFO 和 PSO 动力学拟合结果。相应的拟合方程和参数汇总于表 S6。所有研究的 PFAS 均在 12 h 内达到吸附平衡。动力学数据更符合 PSO 模型，其相关系数 $( \mathrm { R } ^ { 2 } = 0 . 9 9 4  – 0 . 9 9 8 )$ 高于 PFO 模型 $( \mathsf { R } ^ { 2 } = 0 . 9 7 2 \mathrm { - } 0 . 9 8 1 )$ 。PSO 模型拟合更优表明，吸附主要受表面化学相互作用控制，而非仅由传质或扩散过程主导。观察到的吸附行为可归因于 F-ZIF-8 表面的 -CF<sub>3</sub> 基团与 PFAS 分子氟化链段之间的非共价 F-F 相互作用，例如弱卤键或偶极-偶极相互作用。值得注意的是，磺酸类 PFAS（PFOS 和 PFNS）的相关系数 $( \mathrm { R } ^ { 2 } \approx 0 . 9 9 8 )$ 略高于其羧酸类类似物（PFOA 和 PFNA）。这一差异主要源于磺酸类化合物中更高的总氟含量，从而增强了上述 F-F 相互作用。对 HFPO-TeA 获得的强 PSO 拟合也支持这一解释。尽管 HFPO-TeA 结构独特，但其氟化程度较高，进一步证实氟含量是吸附动力学中的决定性因素。

## 3.4. 复杂水体条件下 [[全氟化合物|PFAS]] 混合物的[[吸附]]

## 3.4.1. pH 的影响

水溶液的 pH 值显著影响[[吸附剂]]的[[吸附]]效率[70]。本研究评估了 [[F-ZIF-8]] 在 pH 3–11 范围内对 [[全氟化合物|PFAS]] 的吸附性能。如图 8 所示，[[氟化金属有机框架|F-ZIF-8]] 在中性至弱碱性条件（pH 7–9）下表现出最佳吸附性能，尤其是对分子量更高、氟化程度更高的 [[全氟及多氟烷基物质|PFAS]]。值得注意的是，在 pH 7 时，F-[[ZIF-8]] 对大多数 [[全氟和多氟烷基物质|PFAS]] 达到了最大[[去除率]]，长链分子如 [[全氟壬烷磺酸|PFNS]]（97.98%）和 [[全氟壬酸|PFNA]]（90.43%）几乎被完全吸附。这表明中性 pH 为最大化吸附提供了最佳条件，这可能得益于 F-[[沸石咪唑酯骨架-8|ZIF-8]] 的[[氟化配体]]与 PFAS 分子之间有利的相互作用。值得注意的是，[[HFPO-TeA]] 在整个 pH 范围内表现出接近完全的吸附（98.94%）且变化极小，反映出其与 F-ZIF-8 之间具有强且不依赖 pH 的亲和力。相反，在强酸性和强碱性条件下观察到吸附显著降低，这强调了保持中性至弱碱性环境以获得最佳性能的必要性。在酸性条件（pH 3）下，所有 PFAS 分子的吸附效率均下降，尤其是短链化合物，如 [[全氟丁酸|PFBA]]（7.83%）、[[全氟丁烷磺酸|PFBS]]（11.45%）和 [[全氟己酸|PFHxA]]（20.23%）。这种下降可能是由于 [[金属有机框架|MOF]] 表面的[[质子化]]削弱了其与 PFAS 的相互作用，并改变了 PFAS 的电荷状态[71]。在强碱性条件（pH 11）下，较大 PFAS 分子（如 [[全氟辛烷磺酸|PFOS]] 和 PFNA）的吸附也有所降低。PFNA 的下降尤为明显，从 pH 7 时的 90.43% 降至 pH 11 时的 80.86%。这种降低可能源于极端 pH 条件下 F-ZIF-8 结构完整性的受损以及表面性质的改变[72]。

为了进一步理解这种 pH 依赖的[[吸附]]行为，测量了 [[F-ZIF-8]] 在不同 pH 下的 [[zeta 电位]]。在 pH $5 , 7 ,$ 9 和 11 时，zeta 电位值分别为 +18.5、−12.3、−3.2 和 $- 6 3 . 5 \mathrm { m V } ,$。这些结果表明，[[零电荷点]] $( p H _ { p z c } )$ 位于 pH 5 和 7 之间。这证实了 [[氟化金属有机框架|F-ZIF-8]] 的表面电荷在酸性介质中为正，在中性和碱性条件下转变为负。随着 pH 值升高，表面逐渐带更多负电荷[73]。鉴于 [[全氟化合物|PFAS]] 因其较低的 [[pKa]] 值在水溶液中主要以阴离子形式存在，通常预期带负电的[[吸附剂]]表面会[[静电排斥]]这些阴离子。然而，实验观察表明，[[全氟及多氟烷基物质|PFAS]] 在 F-[[ZIF-8]] 上的吸附从酸性到弱碱性条件（pH 3–9）有所增加，随后在 pH 11 时下降。这一趋势表明，尽管静电排斥在强碱性 pH（pH 11 时为 −63.5 mV）下占主导地位并导致吸附受到抑制，但它并不是 pH 3–9 范围内控制吸附的主要因素，这进一步支持了 [[非共价相互作用|F-F 非共价相互作用]]的主导作用。

为验证这一假设，考察了[[F-ZIF-8]]在暴露于极端pH后的结构稳定性。[[氟化金属有机框架|F-ZIF-8]]在pH 3和pH 11溶液中暴露8 h后的[[SEM]]图像（图S4a-b）显示出其晶体结构可观察到损伤。相应的[[XRD]]图谱（图S5）表明，尽管由于严苛条件主峰强度严重降低，但仍保留尖锐的衍射峰，且峰位置完全未变。这表明，尽管存在一定表面劣化，材料的核心体相[[结晶]]性在极端pH环境中仍得以保留，说明性能损失主要源于表面化学变化，而非骨架完全坍塌。总之，F-[[ZIF-8]]在pH 7–9范围内表现出最高的[[全氟化合物|PFAS]]去除效率，尤其对[[全氟壬烷磺酸|PFNS]]、[[全氟壬酸|PFNA]]和[[HFPO-TeA]]等长链、高度氟化分子更为显著。这些结果使F-[[沸石咪唑酯骨架-8|ZIF-8]]成为一种有前景的[[吸附剂]]，可用于去除长链[[全氟及多氟烷基物质|PFAS]]，特别是在pH可控制在这一有利范围内的环境中。

## 3.4.2. [[无机盐]]离子的影响

通过在含有不同[[无机盐]]（[[氯化钠|NaCl]]、$\mathrm { N a _ { 2 } S O _ { 4 } , M g C l _ { 2 } } ,$和$\mathbf { M g S O _ { 4 } } .$）的水溶液中测试[[F-ZIF-8]]，评价了离子组成对[[全氟化合物|PFAS]][[吸附]]的影响。结果表明，吸附效率受[[离子强度]]和具体盐类型调控（图8；表S8）。

对大多数[[全氟化合物|PFAS]]而言，与[[去离子水]]相比，[[氯化钠|NaCl]]或$\mathrm { N a _ { 2 } S O _ { 4 } }$溶液的存在仅略微降低[[吸附容量]]。例如，[[全氟丁酸|PFBA]]的[[去除率]]从去离子水中的21.02%降至NaCl溶液中的19.45%，[[全氟丁烷磺酸|PFBS]]的去除率从26.60%降至23.07%。然而，对于[[全氟辛烷磺酸|PFOS]]、[[全氟壬酸|PFNA]]和[[全氟壬烷磺酸|PFNS]]等长链[[全氟及多氟烷基物质|PFAS]]分子，它们在这些介质中保持相对较高的[[吸附]]效率，表明NaCl和$\mathrm { N a _ { 2 } S O _ { 4 } }$的干扰有限。

相反，含有$\mathrm { M g } ^ { 2 + }$离子$( \mathbf { M g C l } _ { 2 }$和$\mathrm { M g } { \bf S } \mathrm { O } _ { 4 } )$的溶液显著增强了长链[[全氟化合物|PFAS]]分子的[[吸附]]。例如，[[全氟辛烷磺酸|PFOS]]的[[去除率]]从[[去离子水]]中的88.72%提高至$\mathrm { M g } \mathrm { S O } _ { 4 }$溶液中的91.46%，[[全氟壬酸|PFNA]]在$\mathbf { M g C l } _ { 2 }$溶液中从90.43%提高至93.71%。这些结果表明，$\mathrm { M g } ^ { 2 + }$离子可能促进[[F-ZIF-8]]骨架与[[全氟及多氟烷基物质|PFAS]]分子之间更强的相互作用，从而增强吸附。高度氟化的[[HFPO-TeA]]在所有测试溶液中均表现出近乎完全的吸附，在$\mathrm { M g } \mathrm { S O } _ { 4 }$溶液中观察到最高吸附效率98.98%，进一步凸显其对[[氟化金属有机框架|F-ZIF-8]]强烈且不受离子影响的亲和力。

总之，[[F-ZIF-8]]在[[无机盐]]存在下表现出对长链[[全氟化合物|PFAS]]的稳健[[吸附]]，特别是在含有$\mathrm { M g } ^ { 2 + }$的盐存在时。$\mathrm { N a ^ { + } }$基盐的轻微影响和$\mathrm { M g } ^ { 2 + }$的积极作用强调了离子组成在精细调控吸附性能中的作用。这凸显了[[氟化金属有机框架|F-ZIF-8]]在不同水体化学条件下用于[[全氟及多氟烷基物质|PFAS]]去除的潜力。

## 3.4.3. 水体基质组成的影响

[[F-ZIF-8]] 的[[吸附]]性能在四种不同水体基质中进行了评估：[[饮用水]]、[[自来水]]、[[海水]]和[[水产养殖废水]]。如补充表 S2 所述，从饮用水到水产养殖废水，这些基质的复杂性逐步增加，表现为[[电导率]]显著上升、无机离子组成发生变化以及[[总有机碳]]（TOC）和[[浊度]]增加。总体而言，去除效率按以下顺序降低：饮用水 > 自来水 > 海水 > 水产养殖废水（图 8）。这一下降可归因于更复杂基质中共存竞争离子和溶解性有机物浓度的增加，它们可能占据活性位点或堵塞孔道，从而抑制 [[全氟化合物|PFAS]] 的吸附 [48]。这种基质干扰程度与 [[全氟及多氟烷基物质|PFAS]] 的分子结构密切相关。短链化合物（[[全氟丁酸|PFBA]] 和 [[全氟丁烷磺酸|PFBS]]）表现出显著敏感性并出现明显效率损失，而 [[全氟壬烷磺酸|PFNS]] 等长链物质则表现出更强的耐受性。这一趋势在 [[HFPO-TeA]] 中最为突出，其去除效率降幅不足 10%，这归因于其支化结构和丰富的 $\mathrm { - C F _ { 3 } }$ 基团。这些结果印证了第 3.3.1 节讨论的趋势，证实了由更高氟含量驱动的增强型 [[非共价相互作用|F-F 相互作用]]能够有效减轻背景污染物的[[竞争性抑制]] [74]。

[[F-ZIF-8]] 在所有测试水体中对[[全氟和多氟烷基物质|长链 PFAS]] 和高氟化 [[全氟化合物|PFAS]] 均表现出强效且优先的[[吸附]]能力。[[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]]、[[全氟壬酸|PFNA]]、[[全氟壬烷磺酸|PFNS]] 和 [[HFPO-TeA]] 等化合物即使在产养殖废水中也能始终保持较高的吸附效率，其优异性能可归因于其较大的分子尺寸和较高的氟含量。这些特征导致其与氟化 [[金属有机框架|MOF]] 骨架之间产生更强的[[疏水相互作用]]和 [[非共价相互作用|F-F 相互作用]]。在复杂基质中持续保持的高去除效率，特别是[[水产养殖废水]]中 [[全氟壬磺酸|PFNS]] 和 [[六氟环氧丙烷三乙胺盐|HFPO-TeA]] 的表现，凸显了 [[氟化金属有机框架|F-ZIF-8]] 的实际应用潜力。这种在污染物富集、真实环境中保持性能的能力——而传统[[吸附剂]]往往在此类环境中失效——使 F-[[ZIF-8]] 成为靶向 [[全氟及多氟烷基物质|PFAS]] 修复的有前景的候选材料 [75]。

## 3.4.4. 循环再生评估

通过多个[[吸附循环|再生循环]]评估了 [[F-ZIF-8]] 的可重复使用性。如表 S9 和图 8 所示，该[[吸附剂]]在连续四个[[吸附-脱附循环]]中均能有效去除混合物中的[[全氟和多氟烷基物质|长链 PFAS]]。值得注意的是，选择四个循环是为了进行标准评估，并不反映该材料耐久性的实际上限 [40,76]。在采用含 10 mM [[乙酸铵]]的 80% [[甲醇]]-水溶液再生后，[[HFPO-TeA]] 的[[吸附]]效率从 98.98% 略微下降至 89.88%。相比之下，其他 [[全氟化合物|PFAS]] 的吸附效率几乎保持不变。[[六氟环氧丙烷三乙胺盐|HFPO-TeA]] 出现的轻微下降很可能是因为其与氟化吸附剂之间的亲和力特别强，导致再生过程中[[脱附]]不完全。为进一步评估该材料的结构稳定性并探索其实际使用寿命，开展了重复使用后的表征。[[氟化金属有机框架|F-ZIF-8]] 经过四个循环后的 [[XRD]] 图谱和 [[SEM]] 图像（图 S6-7）表明，其晶体骨架和形貌特征保持良好，未观察到明显降解。鉴于这种稳健的结构完整性以及大多数 [[全氟及多氟烷基物质|PFAS]] 组分的稳定性能，预计 F-[[ZIF-8]] 的最大循环寿命将大幅超过所测试的四个循环，随后才可能出现明显的结构疲劳或容量损失。即使经过反复再生和重复使用循环，F-[[沸石咪唑酯骨架-8|ZIF-8]] 仍保持了对 PFAS 混合物的吸附能力，从而提高了成本效益，并凸显了其在实际应用中的潜力。

## 3.6. [[DFT]]计算

为进一步阐明潜在的 F–F [[非共价相互作用]]，开展了 [[密度泛函理论|DFT 计算]]，以评估 [[全氟辛酸|PFOA]] 在 [[F-ZIF-8]] 上的不同[[吸附]]构型及其[[结合能]]。计算结果表明，PFOA 的全氟碳链与 [[氟化金属有机框架|F-ZIF-8]] 的 $\mathrm { - C F _ { 3 } }$ 基团紧密排列的构型具有明显优先性。值得注意的是，PFOA 中氟原子与 [[金属有机框架|MOF]] 单元中氟原子之间的最小距离确定为 2.204 $\mathring { \mathsf { A } } ,$，与 [[径向分布函数|RDF]] 分析结果一致。相反，其他构型中的 F–F 距离则显著更大。在非共价相互作用范畴中，小于 $\sim 3 . 5 \mathring \mathrm { A }$ 的 F–F 距离通常被归类为 $" \mathrm { h i t " } ,$，表明存在特定的吸引性相互作用 [81]。已有文献记载，[[三氟甲磺酸]]中的氟原子可以与其他含氟化合物中的氟原子在 2.96 Å 的 F–F 距离上发生非共价相互作用。Alkorta 等人计算了多种含氟有机化合物中的 F–F 距离，其数值范围为 2.423 至 2.864 $\mathring { \mathsf { A } } ,$，均属于被归类为非共价相互作用的范围 [82]。本研究中观察到的短程作用力归因于 F–F 非共价相互作用；重要的是，这些相互作用既不是[[静电吸引]]，也不是[[氢键]]。PFOA 和 F-[[ZIF-8]] 中的氟原子不能被电离或[[质子化]]，因此排除了氟碳链之间发生[[静电相互作用|静电吸引]]的可能性。然而，值得注意的是，虽然中性氟原子之间排除了静电吸引，但阴离子型 PFOA 头基与 MOF 金属节点之间仍存在强静电相互作用，表明整体结合依赖于协同机制 [83]。此外，氟原子的[[疏水性]]使水分子难以靠近，阻碍了 F 原子之间形成氢键桥和氢键。

在本研究中，涉及 F-F 的[[非共价相互作用]]主要归因于[[色散力]]。这些作用力在氟原子中常被低估，因为这类力通常被认为在大分子之间更为显著。氟原子表现出强[[吸电子特性]]，导致有机氟周围具有较高的[[电子密度]]。对 [[全氟化合物|PFAS]] 表面电子云分布的计算分析支持这一论断 [84]。色散力的大小随着局域电子密度的增加而增大。当氟原子靠近其他原子时，它们可以形成二元复合物，增强分子间相互作用，提高电子浓度，并促进氟在表面的聚集。此外，色散力显著影响[[吸附]]过程中的能量变化。色散力可以显著提高体系内的吸附能，从而促进更高的稳定性。此外，计算了不同吸附构型的[[吸附结合能]] $\operatorname { ( E _ { a d s } ) }$，结果表明，当 [[全氟辛酸|PFOA]] 的 C-F 链接近 [[F-ZIF-8]] 的氟化链段时，$\operatorname { E } _ { \mathrm { a d s } }$ 的绝对值达到最大值 $( - 3 9 7 . 1 4 \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 } )$，显著超过其他构型 $( - 2 1 5 . 0 7 \mathrm { k J } { \cdot } \mathrm { m o l } ^ { - 1 } )$；图 10a-b）。此外，采用相同的计算方法，还计算了 PFOA 在原始 [[ZIF-8]] 上的吸附能，得到数值 $\mathbf { o f \_ } 1 1 4 \mathbf { k J \ m o l } ^ { - 1 }$。该绝对值显著低于本研究中对 [[氟化金属有机框架|F-ZIF-8]] 所得的数值，表明氟化改性在提高 [[沸石咪唑酯骨架-8|ZIF-8]] 对 [[全氟及多氟烷基物质|PFAS]] 的吸附能力方面发挥了积极作用（吸附构型见图 S8）。此外，图 10c 直观描绘了 PFOA 分子与 [[金属有机框架|MOFs]] 之间的弱原子间作用力（[[独立梯度模型|IGM]]）等值面，其中蓝色区域表示 F-F 非共价相互作用。这表明 F-F 非共价相互作用的形成是放热的，且在热力学上有利。由 PFOA 的 C-F 链与 MOFs 有机氟化链段之间的相互作用所产生的吸附构型，其稳定性显著高于其他分子间相互作用所产生的构型。这种提高的稳定性可能源于 F-F 非共价相互作用的本质，其主要由色散力驱动。至关重要的是，F-F 非共价相互作用的主导作用得到了[[孔隙率]]分析的有力佐证。尽管 N<sub>2</sub> 吸附-[[脱附]]分析表明，F-ZIF-8 的孔隙率降低——由于引入的 -CF<sub>3</sub> 基团的[[空间位阻]]效应，其 [[BET 比表面积]]相较于原始 ZIF-8 几乎减少一半——但其对目标[[全氟和多氟烷基物质|长链 PFAS]] 的吸附能力却显著增强。这种明显对比——物理孔隙率降低伴随吸附性能增强——提供了有力的宏观证据，表明优异的 PFAS 摄取并非由常规的物理孔填充所主导。相反，这进一步支持特定的纳米尺度 F-F 非共价相互作用是吸附的主要驱动力，从而有效使 F-ZIF-8 克服了孔隙率降低的限制。

![](<../2.SCI_MD/Enhancing long-chain per- and polyfluoroalkyl substances removal from water through fluorinated metal-organic frameworksSelectivity, reusability, and adsorption mechanism/images/ffd070e02a0bb4599704a8bdc3b866acfec552472074466ea371854a40091a77.jpg>)  
图 11. PFOA 在 F-ZIF-8 上协同吸附机理示意图，突出纳米尺度 F-F 相互作用、疏水效应和静电吸引之间的协同作用。

总体而言，[[F-ZIF-8]] 的高[[吸附]]效能源于一种协同机制，其中纳米尺度上特定的 [[非共价相互作用|F-F 相互作用]]作为主要驱动力，并辅以静电作用、[[疏水性]]和孔道限域等宏观尺度作用力。为了进一步阐明这一复杂过程，图 11 提出了详细的机理示意图。该示意图系统展示了占主导地位的 F-F 非共价相互作用，以及[[疏水相互作用]]和可能的静电贡献的协同作用。此外，表 S5 对 [[氟化金属有机框架|F-ZIF-8]] 与近期文献报道的其他代表性多孔材料的主要吸附机理进行了比较。

## 4. 结论

本研究介绍了 [[F-ZIF-8]]，一种[[氟化沸石咪唑酯骨架]]，作为用于选择性去除[[全氟和多氟烷基物质|长链 PFAS]] 的先进[[吸附剂]]。引入 -CF 配体显著提高了[[吸附选择性]]和容量，主要通过一种协同机制实现，该机制涉及增强的[[疏水效应]]，以及最为重要的特定 [[非共价相互作用|F-F 非共价相互作用]]。因此，在[[去离子水]]中，对高氟化 [[全氟化合物|PFAS]]（如 [[全氟壬烷磺酸|PFNS]] 和 [[HFPO-TeA]]）的去除效率超过 98%。[[氟化金属有机框架|F-ZIF-8]] 的[[吸附容量|最大吸附容量]]范围从 [[全氟辛酸|PFOA]] 的 529.64 mg g<sup>–1</sup> 到 [[六氟环氧丙烷三乙胺盐|HFPO-TeA]] 的 1484.28 mg g<sup>–1</sup>，显著高于传统 [[ZIF-8]]。此外，F-[[沸石咪唑酯骨架-8|ZIF-8]] 在各种水基质中表现出较强的稳定性，并在连续四次[[吸附-脱附循环]]中保持高性能，凸显了其实际应用潜力。该材料在多次循环使用后以及在极端 pH 条件下的结构和形貌完整性进一步证实了其实际耐久性。此外，在实际基质（[[水产养殖废水]]和[[海水]]）中实现的高效 [[全氟及多氟烷基物质|PFAS]] 去除表明，其对复杂[[天然有机质]]（NOM）和竞争离子的干扰具有很强的抵抗能力。来自[[吸附]]实验、[[分子动力学模拟|MD 模拟]]和 [[密度泛函理论|DFT 计算]]的综合证据一致指向一种协同吸附机制，其中 F-F 非共价相互作用被确定为主要贡献因素。然而，短链 PFAS 的去除效果较差，可能是由于其较低的[[疏水性]]和较弱的 F-F 相互作用。因此，未来研究将侧重于优化 F-ZIF-8 的结构，以增强其对这些短链 PFAS 的亲和力。将在一系列较高浓度下进行吸附评价，以实验验证模型推导的最大容量，并评估接近饱和的情况。将针对特定 NOM 组分（如[[腐殖酸]]）的竞争吸附开展专门的机理研究。将采用[[实验设计|实验设计方法]]，系统优化合成参数及其相互作用，以用于潜在的放大应用。总体而言，F-ZIF-8 代表了一个有前景且可持续的平台，可用于缓解水生环境中的 PFAS 污染，并为合理设计用于[[环境修复]]的先进功能材料提供了策略框架。
