# [[全氟和多氟烷基物质]]（PFAS）在[[活性炭]]上的[[竞争吸附]]：活性炭与PFAS性质的影响

![](<../2.SCI_MD/Competitive adsorption of per- and polyfluoroalkyl substances (PFAS) on activated carbonImpact of activated carbon and PFAS properties/images/a2ebfa563ceb41fe7c3f0649691a9d22f6583ede492afc7340cb977f3a141f6e.jpg>)

## 亮点

• [[活性炭]][[孔容]]和[[疏水性]]强烈影响[[全氟和多氟烷基物质|PFAS]][[吸附]]。

• [[天然有机物|NOM]]与[[疏水性]]较低的[[全氟和多氟烷基物质|PFAS]]竞争并减少其[[吸附]]。

## 摘要

[[活性炭]]（AC）已被证明是一种有效的[[吸附剂]]，可用于去除受污染水体中的[[全氟和多氟烷基物质]]（PFAS）。为辅助有效活性炭的开发与选择，本研究考察了[[全氟辛酸]]（PFOA）、[[全氟辛烷磺酸]]（[[全氟辛磺酸|PFOS]]）和[[全氟丁烷磺酸]]（PFBS）在六种具有不同原料来源和性质的活性炭上单独及混合[[吸附]]行为，并研究了添加[[苏万尼河天然有机质]]（[[天然有机物|NOM]]）后的影响。单一PFAS平衡吸附数据采用[[Freundlich模型|Freundlich]]和[[Langmuir 吸附模型|Langmuir]]等温模型拟合，PFAS混合物数据采用三种基于[[Langmuir模型|Langmuir]]的[[多组分吸附]]模型拟合。所有活性炭均表现出PFOS、PFOA、PFBS依次递减的吸附顺序。[[疏水性]]更强且[[孔容]]更大的活性炭实现了最佳的PFAS去除效果，而孔容较大但疏水性较低的活性炭则表现出显著较低的吸附量。通过[[Spearman秩相关|Spearman秩相关分析]]，每种PFAS的吸附与若干活性炭性质之间呈现单调关系，表明吸附性能并非仅取决于某一项活性炭特征。在混合物中，竞争对PFOS和PFOA的吸附影响极小，但当固相负荷超过14–44 mg/g时，PFBS的吸附量降低。类似地，来自[[天然有机质|NOM]]的竞争对PFBS的影响远大于对PFOS和PFOA的影响，PFBS的吸附平均降低15–35%，而

[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]仅降低6–7%。这些结果表明，[[疏水性]]更强的[[全氟和多氟烷基物质|PFAS]]优先[[吸附]]于[[活性炭]]上，且竞争物质对疏水性较弱的PFAS影响更大。

## 1. 引言

[[全氟和多氟烷基物质]]（PFAS）涵盖一类化合物，由完全或部分氟化的[[疏水性|疏水]]碳链和亲水“头部”基团组成。受污染的饮用水是人类接触 PFAS 的主要途径之一，这促使[[美国环境保护署]]（EPA）制定了 [[国家初级饮用水法规|PFAS 国家初级饮用水法规]]（NPDWR），其[[最大污染物水平]]（MCLs）为：[[全氟辛烷磺酸]]（[[全氟辛磺酸|PFOS]]）4 纳克/升（ng/L 或 ppt）、[[全氟辛酸]]（PFOA）4 ppt、[[全氟己烷磺酸]]（PFHxS）10 ppt、[[六氟环氧丙烷二聚酸]]（HFPO-DA 或 GenX）10 ppt、[[全氟壬酸]]（PFNA）10 ppt，并对 PFHxS、PFNA、HFPO-DA 和[[全氟丁烷磺酸]]（PFBS）中两种或两种以上物质的混合物设定 1.0（无量纲）的[[危害指数]] [1]。由于 MCL 极低且 PFAS 暴露存在诸多健康风险 [2,3]，必须采用有效且高效的处理工艺从水中去除 PFAS。[[吸附]]既可以作为单一工艺，也可以作为综合水处理系统的一部分，是针对 PFAS 污染水体的原位和异位处理中一种成熟且经济高效的选择 [4–6]。[[活性炭]]（AC）被美国环境保护署列为“[[最佳可行技术]]”，并且由于操作简便、PFAS 吸附性能稳定，目前是 PFAS 去除应用中最常用的[[吸附剂]] [6–9]。活性炭单位成本为 $2.75 to \$4.41 每千克，也比许多其他吸附剂（如[[离子交换树脂]]，$14.33 to \$17.60 每千克）更为便宜 [7,10,11]。活性炭的多种形式（例如[[颗粒状活性炭|颗粒状]]、[[粉末状活性炭|粉末状]]、胶体状）使其可用于不同场景下的 PFAS 吸附，包括饮用水、[[地下水]]和废水处理。

[[活性炭]]通常由碳含量高且矿物质含量低的有机材料制成，包括煤、木材、椰子壳、泥炭和生物质 [12]。活性炭可通过化学或物理工艺制备，二者均涉及高温处理 [13,14]。碳的[[活化|物理活化]]通常包括两个步骤：[[碳化|炭化]]和活化。在炭化过程中，原料在惰性气氛中经受高温，使有机物挥发并富集碳含量 [14]。活化步骤是形成大部分孔隙体积的阶段，涉及碳化材料在高温（>600°C）下的氧化，最常使用蒸汽或二氧化碳 [12,14]。相比之下，化学活化仅需一个步骤，炭化和活化同时进行 [12,13]。在化学活化过程中，先将化学试剂施加到材料上，再使其暴露于高温，通常在 500 至 800°C 之间 [15]。活化后，所得活性炭通常具有大量内部孔隙和较大的[[BET|比表面积]]（[[BET比表面积|SSA]]），这两者都有助于其对 [[全氟和多氟烷基物质|PFAS]] 的[[吸附容量]] [9]。孔径可从[[微孔]]（0–20 Å）到[[中孔]]（20–500 Å）再到[[大孔]]（>500 Å）不等 [16]，大多数活性炭在三个尺寸范围内都具有孔隙 [17]，[[比表面积|SSA]] 可在 600 至 3000 m<sup>2</sup>/g 之间变化 [18,19]。源材料类型和活化工艺会影响所得活性炭的物理和化学性质 [20]。

许多研究已证明[[疏水相互作用]]是[[全氟和多氟烷基物质|PFAS]]在[[活性炭]]上[[吸附]]的主导机制，因此众所周知，活性炭容易吸附长链PFAS，但对[[碳链长度|短链]]PFAS的效果可能较差[7, 21–27]。此外，若干研究报告称，与[[全氟烷基羧酸]]（PFCAs）相比，[[全氟烷基磺酸]]（PFSAs）在活性炭上的吸附更强，这被归因于[[磺酸头基]]具有更高的[[疏水性]][11,25,28,29]。基于使用八种PFAS混合物和四种活性炭进行的[[批次吸附|批量吸附]]试验及[[快速小规模柱试验]]（RSSCTs），[[Cantoni]]等人（2021）报告称，PFAS在活性炭上吸附的最大影响因素是PFAS本身的疏水性，而非活性炭的任何特定性质[26]。这一效应被归因于疏水性化合物与水相之间的排斥作用是活性炭上吸附的主要驱动力，而不是化合物对固相的亲和力[26,27]。然而，基于[[方差分析]]，Cantoni等人（2021）确定活性炭的[[BET|比表面积]]和[[表面电荷]]在PFAS吸附中发挥了显著作用，并且活性炭表面电荷（以[[零电荷点]][[pH]]值$\mathrm { ( p H _ { P Z C } ) ) }$表示）与带负电的PFAS头基之间的相互作用是控制PFAS吸附的主要因素[26]。[[Park]]等人（2020）同样证明了活性炭表面电荷对PFAS吸附的重要性[27]。两项研究均得出结论：对于疏水性较小、分子较小的PFAS，[[微孔率]]是影响[[吸附容量]]的更重要因素；相反，对于疏水性较强、分子较大的PFAS，[[介孔率]]的重要性逐渐增加。此外，更高的[[微孔]]或[[介孔]][[比表面积]]分别提高了疏水性较小和疏水性较强的PFAS的吸附容量。

虽然已有若干研究记录了在[[全氟和多氟烷基物质|PFAS]]混合体系中，较长链PFAS和磺酸盐相对于较[[碳链长度|短链]]PFAS和羧酸盐的优先[[吸附]][23–28]，以及长链PFAS置换短链PFAS的能力[26,27]，但很少有研究应用多组分等温线模型来描述PFAS在[[活性炭]]上的[[竞争吸附]]。多组分等温线模型已被用于多种污染物，包括磷酸盐、硅酸盐、氟化物和重金属，以预测吸附过程中竞争化合物之间的相互作用。尽管关于多组分等温线模型用于PFAS吸附的研究工作很少，但[[Singh]]等人（2024）评估了若干多组分模型，并通过采用修正的[[竞争性 Langmuir 模型|竞争性Langmuir模型]]，获得了与[[全氟丁烷磺酸|PFBS]]、[[全氟己烷磺酸|PFHxS]]、[[全氟辛烷磺酸|PFOS]]和[[全氟辛酸|PFOA]]在[[胶体活性炭]]（[[CAC]]）上的竞争吸附数据拟合较为合理的预测结果[30]。

溶液中其他物种的存在也会对[[活性炭]]（AC）[[吸附]][[全氟和多氟烷基物质|PFAS]]产生竞争性影响。[[Cantoni]]等人（2021）和[[Park]]等人（2020）发现，[[天然有机质]]（[[天然有机物|NOM]]）通过与PFAS竞争并引起[[孔堵塞]]，降低了使用AC的[[快速小规模柱试验]]（[[快速小规模柱测试|RSSCT]]）中PFAS的吸附[26,27]。在此情况下，与[[苏万尼河天然有机质|NOM]]的竞争对[[碳链长度|短链]]PFAS吸附的影响大于对长链PFAS的影响，但NOM引起的孔堵塞对长链PFAS吸附的阻碍可能大于对短链PFAS的阻碍。研究还证明，NOM引起的孔堵塞对[[微孔]]AC（微孔体积占比>50%的AC）的影响大于对[[中孔]]AC的影响。[[Hakimabadi]]等人（2023）研究了多种溶解性有机物种对PFAS在AC上吸附的影响，观察到[[二乙二醇丁醚]]（DGBE）、[[苏万尼河富里酸|Suwannee河富里酸]]、苯和[[三氯乙烯]]（TCE）会与PFAS[[竞争吸附]]位点，而其他物种（如乙醇和[[1,4-二氧六环]]）对PFAS吸附没有影响[25]。此外，竞争物种对PFAS吸附的影响存在差异；Suwannee河富里酸同时降低了[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]的吸附，而苯和TCE降低了[[全氟辛磺酸|PFOS]]的吸附，但对PFOA的吸附没有影响或反而增强了其吸附[25]。

为推进[[活性炭|AC]]的开发，本研究的目标是评估六种由不同原料制成且具有一系列物理化学性质的AC，以进一步研究有助于从污染水中[[吸附]][[全氟和多氟烷基物质|PFAS]]的AC性质以及竞争物种对PFAS吸附的影响。对这六种AC进行了[[粒径分布]]、[[碘值]]、[[pH]]、[[孔隙率]]、[[BET|比表面积]]和体相组成的表征。随后，使用六种AC和单一PFAS物种（[[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]]和[[全氟丁烷磺酸|PFBS]]）开展了一系列[[批量吸附实验|批次吸附实验]]，以考察吸附与AC性质以及PFAS链长和头基之间的关系。利用所得吸附数据，采用[[Spearman秩相关]]和[[随机森林|随机森林算法]]进行统计分析，以评估AC性质与PFAS吸附之间的关系。为评估PFAS混合物的[[竞争吸附]]行为，又在三种不同原料（[[褐煤]]、[[烟煤]]和[[椰壳]]）的AC上开展了PFOA、[[全氟辛磺酸|PFOS]]和PFBS的[[双组分体系|双组分]]和[[三组分体系|三组分]]混合物的另一系列批次吸附实验。利用多组分批次吸附实验获得的数据，对多组分[[Langmuir 吸附模型|Langmuir]]吸附模型进行了评估。为研究[[天然有机物|NOM]]的竞争吸附效应——[[天然有机质|NOM]]是AC性能最常见的抑制因素[31]，且常存在于受PFAS影响的水体中[32]——第三组批次吸附实验在存在和不存在[[苏万尼河天然有机质|NOM]]的条件下，对全部六种AC使用PFOA、PFOS和PFBS的混合物进行。

虽然许多研究已经考察了 [[全氟和多氟烷基物质|PFAS]] 在[[活性炭]]上的[[吸附]]，但其中大多数研究集中于一种活性炭或小样本量的 $\mathsf { A C } s ,$，且这些样品往往性质相似，并呈粉末或颗粒形态。本研究旨在通过考察六种具有不同性质的[[胶体活性炭]]，进一步理解活性炭性质如何影响其对 PFAS 的吸附性能和[[吸附容量]]，研究对象既包括[[单溶质吸附|单一溶质]]体系，也包括 PFAS 混合溶液体系。此外，尽管此前已有少量研究证明与天然有机物的竞争可能会降低 PFAS 在活性炭上的吸附，本研究将进一步探究特定活性炭性质与天然有机物竞争对 PFAS 吸附影响程度之间的关系，以及某些性质是否可能使活性炭对天然有机物竞争具有更强的抵抗力。本研究还旨在填补以下研究空白：通过评估常见[[多组分吸附]]等温线模型能否捕捉观测到的趋势，并将模型参数与 PFAS 混合物在活性炭上吸附观测结果的物理意义联系起来，考察这些模型的适用性。

## 2. 材料与方法

## 2.1. 化学品

[[全氟辛烷磺酸|PFOS]]（CAS 号 307–34–6）、[[全氟辛酸|PFOA]]（CAS 号 335–67–1）和 [[全氟丁烷磺酸|PFBS]]（CAS 号 375–73–5）的盐形式购自 [[Sigma-Aldrich]]（美国密苏里州圣路易斯）。来自 Suwannee 河的天然有机物购自[[国际腐殖质协会]]（参考样品 2R101N）（美国明尼苏达州圣保罗）。使用[[合成地下水]]作为背景电解质溶液，其配制使用[[氯化钾]]（[[Avantor Performance Materials]]，美国宾夕法尼亚州 Center Valley）、[[氯化钙]]（[[Thermo Fisher Scientific]]，美国马萨诸塞州 Waltham）、[[硫酸镁]]（[[Fisher Scientific]]）和[[碳酸氢钠]]（Fisher Scientific），使[[总溶解固体]]浓度达到 373 mg/L，对应离子强度为 8.54 mM。水溶液使用经 [[Milli-Q净化系统|Milli-Q® 净化系统]]（[[MilliporeSigma]]，美国马萨诸塞州 Burlington）处理的去离子水配制。

## 2.2. [[活性炭]]

本研究评价了六种由不同原料合成的[[活性炭]]，原料包括[[椰壳]]、[[褐煤]]、[[烟煤]]和[[精制烟煤]]。所用基础活性炭均在 [[Union Process湿式球磨机|Union Process 湿式球磨机]]中研磨至中位粒径 0.8–1.2 µm，以获得[[胶体碳]]产品。胶体碳产品由活性炭水分散体和专有分散剂组成，具有微米级[[粒径分布]]。该胶体碳产品设计用于在低压注入过程中流经天然含水层介质并在注入过程中附着，从而形成[[原位渗透吸附屏障]]，用于固定 [[全氟和多氟烷基物质|PFAS]]。出于本研究目的，实验中使用的胶体碳产品样品不含分散剂。

## 2.3. [[活性炭]]表征

使用 [[Micromeritics Saturn DigiSizer II]]（Atlanta，GA）测定各[[活性炭]]（AC）的[[粒径分布]]。按照 [[ASTM]] 方法对活性炭进行[[热重分析]]（TGA）：D2866–94 用于测定[[灰分|灰分含量]]，D2867–09 用于测定[[水分含量]]，D5832–98 用于测定[[挥发性有机物含量]]。各活性炭的[[碘值]]按照 ASTM D4607–2014 测定。采用 [[Micromeritics 3Flex表面分析仪|Micromeritics 3Flex 表面分析仪]]获得[[氮气吸附等温线]]，并使用[[DFT|密度泛函理论]]（[[密度泛函理论|DFT]]）模型确定[[孔体积分布]]，使用 [[Brunauer-Emmett-Teller模型|Brunauer-Emmett-Teller（BET）模型]]确定[[BET|比表面积]]。使用与 [[Pfeiffer Thermostar质谱仪|Pfeiffer Thermostar 质谱仪]]（Aßlar，Germany）联用的 [[TA Instruments]] [[差示扫描量热仪]]（DSC）[[SDT Q600]]（New Castle，DE）测定活性炭的[[表面含氧官能团]]含量（Thermal Analysis Laboratory，2021）。

## 2.4. [[批量吸附实验]]

最初的[[批量吸附实验|批量反应器吸附实验]]使用六种[[活性炭]]（AC）中的每一种，以及添加了[[单溶质吸附|单一溶质]]（[[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]] 或 [[全氟丁烷磺酸|PFBS]]）的[[合成地下水]]，在 10–10,000 µg/L 浓度范围内的 7 个[[进水浓度|初始浓度]]下进行。选择 PFOA 和 [[全氟辛磺酸|PFOS]] 是因为它们是环境中两种最常用和检出最多的 [[全氟和多氟烷基物质|PFAS]]，而选择 PFBS 是因为它是环境中最常检出的[[碳链长度|短链]] PFAS 之一 [33,34]。这三种 PFAS 化合物也都受到 [[国家初级饮用水法规|PFAS 国家初级饮用水法规]]的管控。选择这些初始浓度是为了使平衡水相浓度能够覆盖环境相关条件，同时也能够在较高浓度下测定[[吸附容量|最大吸附容量]]。随后进行了第二组[[批次吸附|批量吸附]]实验，使用 PFOA、PFOS 和 PFBS 的[[双组分体系|双组分]]和[[三组分体系|三组分]]混合物，并选用三种活性炭（L、B 和 C），分别代表[[褐煤]]、[[烟煤]]和[[椰壳]]原料。每种混合物中 PFAS 的质量浓度相等，在每种 10–10,000 µg/L 范围内的 7 个初始浓度下进行。第三组批量[[吸附]]实验使用含有等质量浓度 PFOA、PFOS 和 PFBS 的混合物，在存在或不存在 [[苏万尼河天然有机质|Suwannee River NOM]]（12 mg/L）的条件下进行，其[[溶解有机碳]]（[[溶解性有机碳|DOC]]）含量为 10.1 mg/L，浓度范围为 $1 0 { - } 1 0 { , } 0 0 0 \mu \mathrm { g / L }$ 。对于每种活性炭，将 2 mL 的储备 [[胶体活性炭|CCP]] 浆液稀释至 50 mL，使碳浓度约为 2%（2 mg/mL）。活性炭含量通过干燥每种浆液并测定重量变化来确定。对于每个批量吸附实验，将 9 mL 添加了单一溶质 PFAS 或 PFAS 混合物的合成[[地下水]]与 1 mL 稀释后的 [[胶体碳|CCP]] 浆液在 15 mL [[聚丙烯离心管]]（[[Thermo Fisher Scientific]]，Waltham，MA）中混合。为每个 PFAS 浓度准备三份平行活性炭批量反应器和三份平行无活性炭对照。反应器在 [[Multi-Purpose Tube Rotators]]（Thermo [[Fisher Scientific]]）上以 30 rpm 混合 7 天。对于 PFOA、PFOS 和 PFBS，在动力学吸附测试期间，[[吸附平衡]]在 12 ${ \bf h } ,$ 内建立，并且在含有活性炭的反应器和无活性炭的对照中，在 12 小时和 7 天之间未观察到其他过程或随时间的变化（图 S1）。无活性炭对照在动力学吸附测试中未表现出随时间变化的损失，但对照中的任何潜在损失都在计算含活性炭批次反应器的[[吸附质]]量时予以考虑。混合 7 天后，每个反应器的内容物使用 [[Eppendorf 5804 R离心机|Eppendorf 5804 R 离心机]]（Enfield，CT）在 4000 rpm 下离心 30 分钟进行分离。然后将 2 mL 上清液转移至[[微量离心管]]（Thermo Fisher Scientific），并在 [[Eppendorf 5424离心机|Eppendorf 5424 离心机]]（Framingham，MA）中以 15,000 rpm 离心 15 分钟。离心后，将上清液转移至 2 mL 透明玻璃小瓶（[[Waters]]，Milford，MA）中，必要时稀释，并加入[[内标]]

## 2.5. [[全氟和多氟烷基物质|PFAS]] 分析

[[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]] 和 [[全氟丁烷磺酸|PFBS]] 的定量分析在 [[Waters]] [[超高效液相色谱|Acquity UPLC]]® 系统与 Waters $\mathtt { X e v o ^ { T M } }$ 微型三重四极杆（TQ）[[气相色谱-质谱联用|质谱仪]]联用装置上进行。分析物分离采用 [[Acquity UPLC BEH C18色谱柱|Acquity UPLC BEH C18 色谱柱]]（2.1 mm×50 mm $\textbf { x } 1 . 7$ μm），柱温为 50◦C。流动相组成为：（A）含 2 mM [[乙酸铵]]的 5% [[甲醇]]溶液和（B）含 2 mM 乙酸铵的 100% 甲醇溶液。洗脱梯度为：10% B 保持 1.0 min，随后在 1.0 至 5.0 min 内由 10% B 线性升至 85% B，再经 0.1 min 线性升至 100% B 并保持至 7.0 min。在 0.5 min 内线性恢复至初始条件，并在 7.5 至 10.0 min 保持该条件，以便在下一次进样前实现平衡。经认证的 [[全氟和多氟烷基物质|PFAS]] 标准品和同位素标记参考标准品购自 [[Wellington Laboratories]]（Overland [[Park]], KS）。每分析 20 个样品后重新进样一次校准标准品，以确保整个运行过程中准确性得以维持。定量分析时，对校准标准品进行系列稀释，构建七点校准曲线。

## 2.6. [[单溶质吸附|单溶质]][[吸附]]建模

使用 Python 中的非线性[[最小二乘回归|最小二乘回归程序]]，将六种[[活性炭]]各自的[[单溶质吸附|单溶质]] [[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]] 和 [[全氟丁烷磺酸|PFBS]] [[吸附]]数据拟合到两种非线性吸附模型，即 [[Freundlich等温线模型|Freundlich 等温线模型]]和 [[Langmuir 等温线模型]]。[[Freundlich模型|Freundlich]] 等温线模型：

$$
C _ {s} = K _ {f} C _ {w} ^ {n}\tag{1}
$$

是一种基于非均质[[吸附剂]]表面的经验模型，可以容纳多层[[吸附]] [35,36]。[[Langmuir 等温线模型]]：

$$
C _ {s} = \frac {S _ {\max} b C _ {w}}{1 + b C _ {w}}\tag{2}
$$

假定[[吸附剂]]表面达到最大或极限覆盖，[[吸附位点]]是均质的，并且被[[吸附]]分子之间不存在相互作用 [37]。此处，$C _ { s } \left( \mu \mathbf { g } / \mathbf { g } \right)$ 和 $C _ { w } \left( \mu \mathrm { g / L } \right)$ 分别是固相和水相中的平衡浓度。$K _ { f } ( { ( \mu \mathbf { g } / \mathbf { g } ) ( \mathrm { L } / \mu \mathbf { g } ) ^ { \mathrm { n } } } )$ 是 [[Freundlich模型|Freundlich]] 分布系数，n 是吸附常数。$S _ { m a x } \ \left( \mu \mathbf { g } / \mathbf { g } \right)$ 是最大固相浓度或极限容量，$b ~ \left( \mathrm { L } / \mu \mathrm { g } \right)$ 是 [[Langmuir 吸附常数]]。

## 2.7. [[多组分吸附]]建模

使用[[活性炭]] L、B 和 C 对 [[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]] 和 [[全氟丁烷磺酸|PFBS]] 的[[双组分体系|双组分]]及[[三组分体系|三组分]]混合液进行了[[批量吸附实验]]，以研究[[竞争吸附]]行为。选择这些活性炭是为了代表三种不同的活性炭原料：[[褐煤]]、[[烟煤]]和[[椰壳]]。将每种活性炭的双组分和三组分[[吸附]]数据拟合到三种[[多组分吸附]]模型：[[多组分竞争Langmuir模型|未修正的竞争 Langmuir 模型]]、[[扩展Langmuir等温线|扩展 Langmuir 等温线]]和修正的竞争 [[Langmuir等温线模型|Langmuir 等温线]]。

[[多组分竞争Langmuir模型|未修正的竞争 Langmuir 模型]]与 [[Langmuir 等温线模型]]相似，但适用于发生[[竞争吸附]]的 N 个组分：

$$
C _ {s, i} = \frac {S _ {\max , i} b _ {i} C _ {w , i}}{1 + \sum_ {j = 1} ^ {N} b _ {j} C _ {w , j}}\tag{3}
$$

其中 $S _ { \mathrm { m a x } , i }$ 和 $b _ { i }$ 组分 i 的[[极限吸附容量]] $\boldsymbol { \mathrm { ( \mu g / g ) } }$ 和组分的 [[Langmuir 吸附常数]] $i ~ \left( \mathrm { L } / \mu \mathrm { g } \right) ,$ 分别。 $S _ { \mathrm { m a x } , i }$ a 和 b 由相应[[单组分吸附|单组分]] [[Langmuir等温线模型|Langmuir 等温线]]的实验数据拟合计算得出。 $C _ { s , i }$ 然后可以为一组值计算 $C _ { w , i }$ 系统中每个N组分数的数值[38,39]。

[[扩展 Langmuir 模型|扩展Langmuir模型]]假设[[吸附剂]]上的[[活性位点]]是均匀的、同等可及的，并且具有均匀的[[吸附]]能，吸附分子之间不发生相互作用 $[ 3 8 , 4 0 , 4 1 ]$ :

$$
C _ {s, i} = \frac {S _ {\max} b _ {i} C _ {w , i}}{1 + \sum_ {j = 1} ^ {N} b _ {j} C _ {w , j}}\tag{4}
$$

在这里， $N$ 是组分数， $S _ { \mathrm { m a x } }$ 是[[极限吸附容量|总体极限吸附容量]] $\boldsymbol { \mathrm { ( \mu g / g ) } }$ 和 $b _ { i }$ 是组分 [[Langmuir 吸附常数]] $i ( \mathrm { L } / \mu \mathrm { g } )$ . 数值 $S _ { \mathrm { m a x } }$ 并通过拟合系统中各组分的多组分实验[[吸附]]数据得到 a<sub>i</sub> 和 b<sub>i</sub>。 $( C _ { s , i }$ 和 $C _ { w , i } )$ 对等温线进行拟合，并通过[[非线性回归分析]]使误差最小化。 $C _ { s , i }$ 然后可以为一组数据计算这些值。 $C _ { w , \ l }$ 利用获得的组分数量 N 的各数值 $S _ { \mathrm { m a x } }$ 并给出 b<sub>i</sub> 值 [38,41]。

[[修正的竞争性 Langmuir 等温线]]考虑了溶液中各组分之间发生的相互作用。相互作用项 $\eta _ { i } ,$ 会调整每种[[吸附质]]的浓度，以计入其他[[吸附]]质的竞争效应，并且依赖于溶液中其他组分的浓度 [38, 41–43]。修正的竞争性 [[Langmuir等温线模型|Langmuir 等温线]]写为：

$$
C _ {s, i} = \frac {S _ {\max , i} b _ {i} (C _ {w , i} / \eta_ {i})}{1 + \sum_ {j = 1} ^ {N} b _ {j} (C _ {w , j} / \eta_ {j})}\tag{5}
$$

在此，N 为组分数， $S _ { \mathrm { m a x } , i }$ 是组分i的[[极限吸附容量]] $\mathbf { \xi } ( \mu \mathbf { g } / \mathbf { g } ) , b _ { i }$ 是组分 [[Langmuir 吸附常数]] $\operatorname { i } \left( \operatorname { L } / \mu \mathbf { g } \right) ;$ ，η 是每个组分 i 的交互项。 $S _ { \mathrm { m a x } , i }$ 其中 a 和 b 通过拟合相应[[单组分吸附|单组分]] [[Langmuir等温线模型|Langmuir 等温线]]的实验数据计算得到。相互作用项， $\eta _ { i } ,$ 是通过对体系中每个组分的多组分实验[[吸附]]数据进行拟合而获得的 $( C _ { s , i }$ 和 $C _ { w , i } )$ 并使用[[非线性回归分析]]最小化该误差。其数值 $S _ { \mathrm { m a x } , i } , b _ { i } ,$ 和 η 随后可用于计算 $C _ { s , i }$ 一系列 $C _ { w , i }$ 数值 [38,39]。还测试了两种基于 [[Freundlich模型|Freundlich]] 的[[多组分吸附]]模型，即[[扩展 Freundlich 模型]]和 [[Sheindorf-Rebuhn-Sheintuch 模型|Sheindorf-Rebuhn-Sheintuch（SRS）模型]]，但其对吸附数据的拟合效果较差。

各[[多组分吸附]]等温线的等温线参数，通过在 Mac 版 [[Microsoft Excel|Microsoft Excel 2021]] 中使用“[[规划求解]]”函数，最小化 [[Marquardt 百分标准偏差]]（[[平均百分比偏差|MPSD]]）[44] 来确定。MPSD 写为

$$
M P S D = 1 0 0 \sqrt {\frac {1}{n _ {m} - n _ {p}} \sum_ {i = 1} ^ {n} \left(\frac {G _ {s , i , \exp} - G _ {s , i , c a l}}{C _ {s , i , \exp}}\right) ^ {2}}\tag{9}
$$

其中 $n _ { m }$ 为实验数据点数量，$n _ { p }$ 为等温线方程中的参数数量 [39]。

## 3.3. [[全氟和多氟烷基物质|PFAS]] [[吸附]]的统计分析

每种 [[活性炭|AC]] 对[[单溶质吸附|单一溶质]]的[[吸附]]顺序相同，其中 [[全氟辛烷磺酸|PFOS]] 的吸附量最大，其次是 [[全氟辛酸|PFOA]]，[[全氟丁烷磺酸|PFBS]] 的吸附量最小。这一吸附行为与其他 AC 上 [[全氟和多氟烷基物质|PFAS]] 吸附的研究结果一致，并与其他研究得出的结论一致，即 PFAS 的[[疏水性]]是吸附到 $\mathsf { A C s } \ [ 2 6 , 2 7 ]$ 的最大因素。[[Hakimabadi]] 等（2023）在使用 [[CAC]] 进行的单溶质[[批量吸附实验]]中获得了吸附顺序为 [[全氟辛磺酸|PFOS]] > [[氟调聚物磺酸|6:2 氟调聚物磺酸]] $( \mathrm { F T S } ) > \mathrm { P F H x S } > \mathrm { P F O A } > \mathrm { P F B S } >$ [[全氟戊酸]]（PFPeA）> [[全氟丁酸]]（PFBA）[25]。类似地，Zhang 等（2023）在单溶质动力学吸附实验中报告了 PFOS > 8:2 FTS > PFOA $> \mathrm { P F B S } > 4 { \div } 2 \ \mathrm { F T S } > \mathrm { P F B A }$ 的吸附趋势 [57]。Ochoa-Herrera 和 Sierra-Alvarez（2008）在使用 [[Calgon Filtrasorb 400|Calgon Filtrasorb 400 GAC]] 进行的[[批次吸附|批量吸附]]实验中也观察到 PFOS 的吸附量最大，其次是 PFOA，然后是 PFBS [22]。

为阐明特定[[活性炭]]特性与高、低浓度下[[全氟和多氟烷基物质|PFAS]][[吸附]]之间可能存在的单调关系，对每种[[单溶质吸附|单一溶质]]PFAS与活性炭性质进行了[[Spearman秩相关]]统计分析。将每种PFAS获得的[[Freundlich模型|Freundlich]]参数$K _ { f }$和$n ,$用作高浓度下在$\mathsf { A C }$上吸附的指标，将[[线性等温线]]参数$K _ { d } ,$用作低浓度下的指标，统计显著性定义为$p < 0 . 1 5$。对于Spearman相关，零假设是假定变量之间不存在单调相关关系[58]。表S3显示了[[全氟辛烷磺酸|PFOS]]在高浓度下的计算Spearman ρ值，[[全氟辛酸|PFOA]]和[[全氟丁烷磺酸|PFBS]]在高浓度下的Spearman ρ值分别见表S4和${ \mathrm { S 5 } } ,$。这三种PFAS均显示出$K _ { f } ,$（即$\mathrm { A C } ,$[[吸附容量]]的指标）与若干活性炭性质之间的单调关系。[[全氟辛磺酸|PFOS]]的$K _ { f }$与[[碘值]]、[[微孔|微孔体积]]和[[BET比表面积|BET SSA]]之间获得了正相关（表S3）。高[[比表面积|SSA]]和碘值是相关性质，由于可能提供更多可用[[吸附位点]]而允许更大的PFOS吸附，这一点也已被先前研究在多种[[吸附剂]]上证明[59，60]。相比之下，许多研究发现，由于PFOS分子尺寸较大且存在微[[孔堵塞]]风险，微孔体积对[[碳链长度|短链]]PFAS吸附更为重要[8，26，27，48，49]，因此这一结果出乎意料，但表明在本研究测试的活性炭中，PFOS造成的微孔堵塞并不常见。发现PFOA的吸附与[[固定碳|固定碳含量]]呈正相关，而与[[浆料pH]]和[[灰分|灰分含量]]呈负相关（表S4）。PFOA吸附随浆料[[pH]]降低而增加，这与[[Cantoni]]等人（2021）和[[Park]]等人（2020）得出的结论不一致，他们报道[[表面电荷]]是PFAS吸附的主要因素，且表面带正电的活性炭表现出更大的PFAS吸附[26，27]。然而，由于本研究中测试的各活性炭浆料pH都同样较高，难以充分确定表面电荷对吸附性能的差异。PFBS吸附随[[中孔|小介孔体积]]和[[热重分析|TGA失重]]的增加而降低（表S5）。TGA失重降低表明表面[[疏水性]]增加，从而增加吸附。我们预期TGA失重与这三种PFAS均呈负相关，但这一关系仅对PFBS具有统计显著性。这可能是因为一些疏水性较高的活性炭具有其他会降低PFOA和PFOS吸附的特性。例如，与疏水性较低的活性炭（如AC C）相比，对PFOA和PFOS吸附均较低的活性炭PB-3，其[[孔隙率]]也低得多。

在较低浓度下，[[全氟辛烷磺酸|PFOS]]（表 S6）和 [[全氟辛酸|PFOA]]（表 S7）与 [[活性炭|AC]] 性质之间表现出与较高浓度下 PFOA 相同的单调关系：与[[固定碳|固定碳含量]]呈正相关，与[[浆料pH|浆液 pH]] 和[[灰分|灰分百分比]]呈负相关。发现 [[全氟丁烷磺酸|PFBS]]（表 S8）在低浓度下与 [[热重分析|TGA 失重]]呈负相关，与较高浓度下的情况相似，表明 AC [[疏水性]]在 PFBS [[吸附]]中的重要性。在较低浓度下，[[全氟辛磺酸|PFOS]] 与[[碘值]]、[[微孔|微孔体积]]和 [[BET比表面积|SSA]] 之间缺乏在较高浓度下观察到的单调关系，这表明在低浓度下 AC 孔体积的相关性较低，而表面化学更为重要。在较高浓度下，由于需要[[吸附位点]]来容纳高 [[全氟和多氟烷基物质|PFAS]] 负载，总孔体积在 AC 性能中变得更加重要。

为了对影响每种 [[全氟和多氟烷基物质|PFAS]] [[吸附]]的 [[活性炭|AC]] 性质的重要性进行排序，还使用[[随机森林|随机森林算法]]进行了多变量分析。该分析使用了与高、低浓度下 Spearman 秩相关相同的吸附指标。对于 [[全氟辛烷磺酸|PFOS]]，随机森林分析表明，在高浓度下，[[BET比表面积|SSA]]、总孔体积和[[碘值]]是影响吸附最显著的性质，而在低浓度下，[[灰分|灰分百分比]]和[[固定碳|固定碳含量]]最为显著。这一发现进一步强调了上述趋势，即表面化学在较低浓度下具有更大重要性，而孔体积在较高浓度下具有更大重要性。正如 Spearman 秩相关所示，固定碳含量和[[灰分含量]]被确定为在高、低浓度下均与 [[全氟辛酸|PFOA]] 具有最强关系，而[[挥发物|挥发物含量]]和 [[热重分析|TGA 失重]]（[[疏水性]]）在较低浓度下也表现出强关系。同样与 Spearman 秩相关一致的是，TGA 失重（疏水性）被确定为对 [[全氟丁烷磺酸|PFBS]] 吸附影响最强，其次是在高浓度下的[[中孔|小介孔体积]]。对于低浓度，总[[介孔]]体积和 TGA 失重（疏水性）对 PFBS 吸附表现出相似的影响。介孔体积对 PFBS 吸附的重要性，尤其是在低浓度下，是出乎意料的，因为介孔体积的作用通常与较长链 PFAS 的吸附相关。总体而言，该分析表明 AC 的吸附性能取决于多种性质，不能由单一 AC 性质来定义，尤其是对于不同的 PFAS。

## 3.5. 在 [[天然有机物|NOM]] 存在下 [[全氟和多氟烷基物质|PFAS]] 的[[吸附]]

对于 [[全氟辛酸|PFOA]]、[[全氟辛烷磺酸|PFOS]] 和 [[全氟丁烷磺酸|PFBS]] 的混合物，[[天然有机物|NOM]] 的存在对[[吸附]]的影响因每种 [[全氟和多氟烷基物质|PFAS]] 和每种 [[活性炭|AC]] 而异。图 6 比较了在三种不同[[进水浓度|初始浓度]]下，存在和不存在 [[天然有机质|NOM]]（12 mg/L，[[溶解性有机碳|DOC]] = 10.1 mg/L）时每种 PFAS 在六种 AC 上的吸附情况。在 PFOA、[[全氟辛磺酸|PFOS]] 和 PFBS 初始浓度均为 100 µg/L（总浓度 300 µg/L）时，在六种 AC 上，不存在 [[苏万尼河天然有机质|NOM]] 时 PFOA 和 PFOS 的吸附平均高出 6%，不存在 NOM 时 PFBS 的吸附平均高出 15%。NOM 的存在对 PFBS [[吸附容量]]的影响在较高浓度下大于较低浓度，其表现为：在初始浓度为 10,000 µg/L（总浓度 30,000 µg/L）时，PFBS 吸附平均降低 35%，而在初始浓度为 1000 µg/L（总浓度 3000 µg/L）时降低 25%，在初始浓度为 100 µg/L（总浓度 300 µg/L）时降低 15%。随着浓度增加，NOM 对 PFBS 竞争效应的增强，很可能是由于所有竞争物种之间对[[吸附位点]]的竞争更加激烈。在较低初始浓度下，有足够的位点容纳溶液中的物种，因此对位点的竞争很小。随着 PFAS 浓度增加，[[疏水性]]更强的物种（PFOA 和 PFOS）在大多数 $\mathsf { A C s } ,$ 上[[竞争吸附]]位点的能力强于疏水性较弱的物种（PFBS 和 NOM），这体现在除 ACs L 和 PB-3 外，PFOA 和 PFOS 的吸附降低幅度很小。随着 PFAS 浓度继续增加，并且 PFOA 和 PFOS 占据更多吸附位点，可供 PFBS 和 NOM 使用的剩余位点数量将继续减少，从而导致更激烈的竞争。由于本研究中使用的 NOM 是疏水性的 [67]，它可以与 PFBS 竞争剩余吸附位点，从而与不含 NOM 的体系相比，导致 PFBS 吸附降低幅度更大。与 PFBS 相反，NOM 对 PFOA 和 PFOS 吸附的影响要小得多，并且与初始浓度无关。在三个初始浓度中的每一个下，PFOA 的吸附平均降低 6–7%，PFOS 的吸附平均降低 6%。

此外，与其它[[活性炭]]相比，[[天然有机物|NOM]] 的存在对 ACs L 和 PB-3 上 [[全氟辛烷磺酸|PFOS]]、[[全氟辛酸|PFOA]] 和 [[全氟丁烷磺酸|PFBS]] [[吸附]]的影响更大，在三种[[进水浓度|初始浓度]]下，[[天然有机质|NOM]] 的存在分别使 PFOA 的吸附降低 14–22 % 和 17–20 %，使 [[全氟辛磺酸|PFOS]] 降低 15 % 和 20 %，使 PFBS 降低 36–73 % 和 10–21 %。这一影响与 L 和 PB-3 在[[单溶质吸附|单一溶质]]实验中对三种 [[全氟和多氟烷基物质|PFAS]] 表现出的较差吸附性能一致（图 1–3）。[[苏万尼河天然有机质|NOM]] 对[[总孔容]]最低的 AC PB-3 影响更大，可能是由于其[[吸附位点]]数量较少，导致竞争更加激烈。NOM 的存在对 PFOA 和 PFOS 在 ACs C、PB-1 和 PB-2 上的吸附没有影响或影响极小，而这些活性炭均具有较大的总[[孔容]]，并且对单一溶质 PFOA 和 PFOS 均表现良好，表明较高的总孔容使[[疏水性]]更强的 PFAS 分子（PFOA 和 PFOS）与 NOM 之间的竞争更少。NOM 的存在对 PFOA 和 PFOS 在 AC B 上的吸附也影响极小，AC B 的总孔容并不是非常大，但除[[微孔]]外还具有足够数量的[[中孔]]（43 %），使其不易受到 NOM 的竞争和[[孔堵塞]]影响，正如 [[Cantoni]] 等（2021）和 [[Park]] 等（2020）所述 [26,27]。这些结果表明，特定的活性炭性质能够指示其对 NOM 竞争具有更强的抵抗能力，例如对于更偏微孔的活性炭（≥ 63 %），需要足够的总孔容 $( \geq 0 . 6 6 \mathrm { c m } ^ { 3 } / \mathrm { g } )$ 和 [[BET比表面积|SSA]] $( \geq 1 1 5 3 \mathrm { m } ^ { 2 } / \mathrm { g } )$；对于总孔容较小的活性炭，则需要相对均衡的微孔和[[介孔|中孔]]分布（两者均在 40 % 至 60 % 之间）。ACs PB-1 和 PB-2 在混合物中对三种 PFAS 均表现出更高的吸附，也可能是因为除 C 外，它们相对于其它活性炭具有较大的总孔容。然而，AC C 非常偏微孔，使其更可能遭受大分子 NOM 以及潜在较大 PFAS 分子的孔堵塞，从而导致吸附较低。

## 3.6. 多组分体系[[吸附]]建模

由于我们在[[单溶质吸附|单一溶质]][[吸附]]测试中获得了三种 [[全氟和多氟烷基物质|PFAS]] 在几乎所有[[活性炭]]上的[[吸附容量|最大吸附容量]]，因此将 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]]、PFOA 和 [[全氟丁烷磺酸|PFBS]]、或 [[全氟辛磺酸|PFOS]] 和 PFBS 的[[双组分体系|双组分]]吸附数据，以及 PFOA、PFOS 和 PFBS 在三种活性炭上的[[三组分体系|三组分]]吸附数据，拟合到第 2.7 节所述的三种基于 [[Langmuir 吸附模型|Langmuir]] 的[[多组分吸附]]模型：[[扩展 Langmuir 等温线模型]]、[[非修正竞争 Langmuir 等温线模型]]和[[修正竞争 Langmuir 等温线模型]]。双组分体系的多组分参数值以及实验值与计算 $C _ { s }$ 值之间的 [[Marquardt 百分标准偏差|MPSD]] 值列于表 S9，三组分体系列于表 S10。图 7 展示了在三种活性炭上不同二元混合物中 PFBS 的实验与计算 $C _ { s }$ 值的对比图。

## 4. 结论

本研究考察了六种不同[[活性炭]]（ACs）对单一全氟和多组分全氟及多氟烷基物质（[[全氟和多氟烷基物质|PFAS]]）混合物的[[吸附]]性能，从而进一步阐明特定活性炭性质与PFAS吸附性能之间的关系，以助于活性炭的开发以及针对特定PFAS应用场景的活性炭筛选。在[[单溶质吸附|单一溶质]]研究中，所有活性炭对[[全氟辛烷磺酸|PFOS]]的吸附量最大，其次为[[全氟辛酸|PFOA]]，再次为[[全氟丁烷磺酸|PFBS]]，这与既往研究所报道的[[碳链长度|较长碳链]]PFAS及[[磺酸头基]]相对于较短碳链PFAS及[[羧酸头基]]具有更高吸附亲和力的结果一致。单一溶质[[吸附等温线]]表明活性炭[[疏水性]]和[[总孔容]]对PFAS吸附的重要性。活性炭的疏水性是PFAS吸附中的关键性质，这一点可从具有[[大孔]]容但较低疏水性的活性炭相较于具有较低[[孔容]]但较高疏水性的活性炭表现出更差性能得到印证。基于对三种PFAS各自吸附影响最大的活性炭性质，可以推断：对于以长链PFAS为主的水体，需要具有足够大孔容和[[BET|比表面积]]（[[BET比表面积|SSA]]）的活性炭；而对于以短链PFAS为主的水体，则更适合采用高疏水性且不过分依赖大孔容的活性炭。

对于多组分[[全氟和多氟烷基物质|PFAS]]混合物，采用三种多组分[[Langmuir模型]]对[[活性炭]]L、B和C的[[双组分体系|双组分]]及[[三组分体系|三组分]]PFAS[[吸附]]数据进行拟合，其中修正竞争[[Langmuir 吸附模型|Langmuir]]模型对吸附数据的表征效果最佳，该模型通过交互项（η）能够反映PFAS之间的非均一竞争效应。多组分体系表现出[[全氟辛烷磺酸|PFOS]]相对于[[全氟辛酸|PFOA]]和[[全氟丁烷磺酸|PFBS]]的优先吸附，且这一现象不受活性炭原料及具体性质的影响。在较高浓度（>1000 µg/L）下观察到PFAS之间的竞争，其中对PFBS吸附的影响最大，而对PFOA和[[全氟辛磺酸|PFOS]]的影响较小。在混合物实验中，具有较大[[总孔容]]以及[[微孔]]和[[中孔]]分布相对均等的活性炭，表现出较小的PFBS吸附下降幅度以及更高的总PFAS吸附量。

在[[天然有机物|NOM]]存在的情况下，[[全氟丁烷磺酸|PFBS]]的[[吸附]]受到的影响同样大于[[全氟辛酸|PFOA]]和[[全氟辛烷磺酸|PFOS]]，尤其是在较高的初始[[全氟和多氟烷基物质|PFAS]]浓度下。PFOA和[[全氟辛磺酸|PFOS]]的吸附平均下降幅度在所有[[进水浓度|初始浓度]]下为6–7 %，而PFBS的吸附平均下降幅度从初始浓度为100 µg/L（总浓度300 µg/L）时的15 %增加到初始浓度为1000 µg/L（总浓度3000 µg/L）时的25 %，其中一些[[活性炭]]受[[天然有机质|NOM]]竞争的影响比其他活性炭更大。虽然本研究中使用的[[苏万尼河天然有机质|NOM]]浓度代表了自然水体中较高的范围，但这些结果表明，对于NOM含量较高的PFAS污染水体，选择具有高[[疏水性]]并且要么具有较大[[总孔容]]$( \geq 0 . 6 6 \mathrm { c m } ^ { 3 } / \mathrm { g } )$和[[BET比表面积|SSA]]$( \geq 1 1 5 3 \mathrm { m } ^ { 2 } / \mathrm { g } )$的更多[[微孔]]活性炭，要么在总[[孔容]]较小（0.57 ≤ 且 < 0.66）时具有更均匀的微孔和[[中孔]]分布（二者均在40 %至60 %之间）的活性炭，将可实现最佳的PFAS去除性能。此外，由于NOM竞争对[[碳链长度|短链]]PFAS的影响更大，尤其是对于孔容较低或微孔与[[介孔|中孔]]分布不均匀的活性炭，在NOM和短链PFAS浓度均较高的场地，可能有必要采用预处理或使用[[离子交换树脂]]或[[粉末活性炭|PAC]]进行分级吸附。

总体而言，这些结果更详细地揭示了[[活性炭]]性质如何影响[[全氟和多氟烷基物质|PFAS]]作为[[单溶质吸附|单一溶质]]以及在竞争性PFAS和[[天然有机物|NOM]]存在条件下的[[吸附]]。然而，本研究未考虑潜在的[[pH]]效应、PFAS污染水中可能存在的其他共污染物的影响、[[吸附动力学]]的影响（例如非平衡或流通条件与批式条件的差异）或液相中可能出现的非理想性效应。此外，本研究中获得的等温线有助于确定活性炭性能并理解PFAS在活性炭上吸附的机理，但将等温线外推至[[监管浓度]]水平（即4–10 ng/L）时应谨慎。

## 环境影响

本研究考察了[[活性炭]]（AC）性质和竞争效应对[[全氟和多氟烷基物质]]（PFAS）[[吸附]]的影响，以支持开发用于处理PFAS污染水体的更有效活性炭。吸附性能与活性炭[[疏水性]]和[[孔容]]呈正相关。[[碳链长度|短链]]PFAS的吸附在长链PFAS存在时降低，尤其是在较高负荷下，而[[全氟辛烷磺酸|PFOS]]的吸附不受竞争效应影响。一种包含相互作用项的修正[[竞争性 Langmuir 模型|竞争性Langmuir模型]]对混合物中PFAS吸附的预测最为准确。
