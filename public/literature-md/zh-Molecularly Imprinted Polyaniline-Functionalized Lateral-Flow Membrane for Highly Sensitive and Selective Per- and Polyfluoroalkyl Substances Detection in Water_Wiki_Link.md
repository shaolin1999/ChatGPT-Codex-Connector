## 1. 引言

[[全氟和多氟烷基物质]]（[[PFAS]]）是一类多样化的、包含超过14,000种持久性、可迁移性和生物累积性合成化学物质的群体，已在世界各地的多种环境和水体中被广泛检出。<sup>1</sup> 其在环境中的广泛分布和持久性引发了显著的健康关切。<sup>2</sup> 据报道，PFAS暴露与人体多种健康状况相关，<sup>3</sup> 包括前列腺癌和肾癌、<sup>4</sup> 甲状腺疾病、<sup>5</sup> 以及糖尿病。<sup>6</sup> 为减轻PFAS暴露及相关健康风险，全球范围内已实施大规模监测行动，以追踪不同环境介质中的PFAS浓度，从而评估其分布、归趋和迁移。<sup>7,8</sup> 近年来，相关法规已为若干PFAS制定了[[饮用水]]限值，例如在[[澳大利亚]]，[[全氟辛酸]]（[[PFOA]]）的限值低至200 ng $\mathrm { L } ^ { - 1 }$，[[全氟辛烷磺酸]]（PFOS）为8 ng $\mathrm { L } ^ { - 1 }$；在[[中国]]，PFOS为40 ng L<sup>−1</sup>，PFOA为80 ng $\mathrm { L } ^ { - 1 }$；在美国，PFOS和PFOA均为4 ng $\mathrm { L } ^ { - 1 }$。<sup>9–11</sup> 此类痕量PFAS化合物的准确定量在很大程度上依赖于实验室液相色谱-串联质谱（[[液相色谱-串联质谱|LC-MS/MS]]），该方法需要系统的样品前处理以及由经验丰富的人员完成MS数据整合与解析，因而限制了及时[[现场监测]]与合规筛查。<sup>12</sup> 当前迫切需要便携、[[选择性]]好且超灵敏的方法，能够在真实水体基质中实现PFAS的快速现场定量。

为满足这一需求，大量研究致力于通过将便携式换能器与能够耐受样品复杂性的识别化学相结合，开发新型[[PFAS]][[传感器]]。<sup>13</sup> 其中，电化学方法已

因其简单性、小型化潜力与低成本而受到特别关注，同时还能提供定量或半定量结果。<sup>14</sup>例如，已有研究在裸多晶铂宏观电极上实现了[[PFAS]]的直接检测，对[[全氟辛烷磺酸|PFOS]]的[[检出限]]达到0.1 nM。<sup>15</sup>该信号来源于PFOS通过静电作用和范德华力结合时，界面电化学响应因[[吸附]]引起的变化。然而，有研究指出，[[电化学传感器]]面临的关键挑战包括实现分子[[选择性]]以及克服[[全氟和多氟烷基物质|PFAS]]固有的电化学惰性。<sup>16</sup>相应地，为增强选择性和信号转导，已采用两种主要策略，包括工程化识别界面<sup>17</sup>和[[导电聚合物]]。<sup>18</sup>对于前者，基于吸附的预富集和受体层方法已被用于提高[[灵敏度]]与选择性。在这方面，[[分子印迹聚合物]]（molecularly imprinted [[Polymers|polymers]]，MIPs）提供了一种有前景的手段，可构建以模板为导向的空腔，使空腔在尺寸、形状和功能上与目标物互补，从而通过“锁-钥”识别机制使功能界面能够选择性地结合分析物。<sup>19</sup>在典型的基于MIP的电化学[[传感器]]中，通常使用[[氧化还原探针]]（一般为二茂铁衍生物）来报告结合事件，并通过[[差分脉冲伏安法]]或[[电化学阻抗谱]]进行定量，所测信号与PFAS浓度成正比。<sup>20,21</sup>为避免对外部探针的需求，此前研究已探索利用溶解的环境氧作为基于MIP的电化学传感器的天然探针，从而能够检测天然水体中的[[PFOA]]<sup>22</sup>和PFOS<sup>23</sup>。另一种避免外部探针的策略则引入了自报告机制，即由导电单体和2,2,6,6-四甲基哌啶-1-氧基（TEMPO）合成具有氧化还原活性的MIP。<sup>24</sup>在该设计中，通过分析物的再结合实现检测，这一过程阻碍了TEMPO的氧化还原过程，从而降低电流密度。然而，对高性能[[恒电位仪]]的依赖可能限制其在实际现场部署中的应用，特别是在资源有限的地区。<sup>25</sup>最近，一种导电聚合物方法被展示用于PFAS检测，即利用[[聚苯胺]]（[[PANI]]），观察到[[电导率]]信号发生显著变化，这种变化源于PANI[[翠绿亚胺碱]]形式的[[质子酸掺杂]]，使其立即转化为高导电性的[[翠绿亚胺盐]]形式。<sup>26</sup>尽管取得了这些进展，但实现对单个PFAS的化合物特异性检测，尤其是在复杂水基质中，仍然具有挑战性。

在本工作中，我们开发了一种新型 [[PFAS]] 传感平台，采用[[分子印迹]] [[PANI]] 功能化薄膜并结合[[侧流膜|侧向流膜]]，实现了现场单分析物 [[全氟和多氟烷基物质|PFAS]] 检测。以 [[PFOA]] 为模板，[[分子印迹空腔|印迹空腔]]能够在检测线上富集分析物，羧基官能团在此诱导局部酸化，使 [[聚苯胺|PANI]] 从[[翠绿亚胺碱]]转变为高导电性的[[翠绿亚胺盐]]，并通过简单的[[四点探针|四点电导探针]]读取，无需外部氧化还原报告分子或台式[[恒电位仪]]。本文报道了 [[MIP-PANI]] 检测膜和基于[[侧向流]]的卡盒的制备方案，以及为稳定水合作用和[[毛细传输]]所考察的操作条件。此外，还测定了定量分析性能，包括[[检测限]]、[[动态范围]]、对结构相关 PFAS 的[[选择性]]、对常见离子干扰物的耐受性，以及在[[饮用水]]、[[河水]]和[[湖水]]中的表现。本工作展示了一种简单、低成本且便携的电化学传感平台，可用于不同水体中高灵敏、高选择性的 PFAS 检测，能够为现场[[环境监测]]中的快速 PFAS 检测提供重要支持。

## 2.3. [[MIP-PANI]] 的合成

[[MIP-PANI]] 按照改良的常规方案<sup>27</sup>，以第 2.2 节所述 [[PANI]] 聚合物为原料制备。简言之，将[[翠绿亚胺盐]]形式的[[聚苯胺]]（PANI-ES）分散在[[乙腈]]（15 mL）和[[甲苯]]（2.5 mL）的混合溶剂中。另将 [[PFOA]]（1 mM）和[[丙烯酰胺]]（AAm）（5 mM）溶解于 3 mL [[N,N-二甲基甲酰胺]]中。AAm 作为功能单体，用于与 [[全氟辛酸|PFOA]] 模板建立特定的非共价相互作用。在预组织阶段，AAm 的酰胺基团与 PFOA 的羧酸根基团形成[[氢键]]，促进电聚合 PANI 基质中模板导向识别位点的形成。将两种溶液合并并搅拌 1 h，以确保均匀性。随后将混合物转移至 100 mL 圆底烧瓶中，在氩气氛和持续搅拌下加入[[偶氮二异丁腈]]（AIBN）（0.1 mM）和[[三羟甲基丙烷乙氧基化物二甲基丙烯酸酯]]（TMPEDMA）（20 mM）。聚合反应在 70 °C 油浴中进行 12 h（Figure 1b）。冷却后，通过离心收集产物，并用去离子（DI）水洗涤三次，得到含 PFOA 模板的 [[分子印迹聚苯胺|MIP-PANI]]。使用甲醇/乙酸（9:1, v/v）进行反复超声处理（8 min）和离心（8 min，4400 rpm）以去除模板，直至检测不到残留模板（见第 3 节 [[FTIR]]）。通过 0.1 M 氨水溶液去质子化，得到[[翠绿亚胺碱]]形式（[[分子印迹聚合物|MIP]]-PANI-EB）。作为对照，在不加入 PFOA 的条件下以相同条件合成[[非印迹聚合物]]（[[NIP-PANI]]）。

## 2.4. 侧向层析 [[MIP-PANI]] [[传感器]]的制备

将 20 mg 粉末状材料在 1 mL [[去离子水]]中超声处理 1 h，制得 [[MIP-PANI]]-EB 分散液。将所得水分散液沉积到硝酸[[纤维素]]（NC）膜（以及在注明情况下的滤纸）上，形成作为测试线的聚合物薄膜。膜厚使用 [[奥林巴斯|Olympus]] OLS5000 激光显微镜测定。在环境条件下干燥 2 h 后，所得基于 NC 的功能性[[侧向层析膜]]用于测量。[[PFOA]] 响应采用[[四点探针]]配置进行定量（图 1c）。

## 2.5. [[侧向层析膜]]平台的配置

为确保测量可靠，采用[[四点探针]]配置和标准化薄膜性能建立了可重复的[[电导率]]读数。如图 1c 所示，通过外侧电极（P1 和 P4）施加 100 nA（用于 pM 级测量）和 1 μA（用于 nM 级和 μM 级测量）的恒定电流，以在测试线上建立均匀电场，同时记录内侧电极（P2 和 P3）之间的电压降。随后利用欧姆定律及适当的几何校正因子（详见文本 S3）计算方块电阻（R）和电导率（σ）。为确保可重复性和材料均一性，仅使用第 3.1 节所报道厚度窗口内的测试线。对于每种条件，在每条测试线上的匹配位置进行多次测量，并在独立制备的测试线之间取平均。

## 2.6. 实际水样测试

使用采集自[[黄金海岸]]和[[布里斯班]]的实际水样（图 S2）对该传感平台作进一步评估，包括[[黄金海岸饮用水]]（GC-Water）、[[布里斯班饮用水]]（BN-Water）、[[黄金海岸湖水]]（GC-Lake）和[[机场附近黄金海岸溪水]]（GC-Creek）。分析前，每个水样经 0.22 μm [[聚醚砜]]膜过滤以去除颗粒物，然后加入规定浓度的 [[PFOA]]。过滤器和注射器预先用 5 mL 水样润洗。随后使用经认证的甲醇标准品向水样中加入规定浓度的 [[全氟辛酸|PFOA]]。定量使用侧向层析 [[MIP-PANI]] [[传感器]]并采用[[标准加入法]]进行。所有测量均重复三次。通过比较三种水体中测得和加入的 PFOA 浓度计算[[回收率]]。

## 3.1. 合成聚合物的表征

为确保[[电导率]]测量准确，还使用 [[奥林巴斯|OLS-5000]] 显微镜对测试线厚度进行了定量，得到平均厚度为 $3 0 . 3 6 \pm 1 . 0 3$ μm（n = 10）（图 3d 和 S4），对应的变异系数约为 3.4%。这种均匀性将厚度引起的[[薄层电阻]]变化限制在同一数量级 $\begin{array} { r } { ( { \bf R } _ { s } \propto \frac { 1 } { { \bf t } } , } \end{array}$ t 指厚度），在匹配的水合条件下支持[[传感器]]间的[[重现性]]。同时，对 [[PANI]]、[[TE-MIP-PANI]]、TC-[[MIP-PANI]] 和 [[NIP-PANI]] 测量了[[接触角|静态水接触角]]（[[座滴法]]），以评估表面润湿性。如图 3e 所示，所有涂层均表现出低接触角，表明表面总体为亲水性。值得注意的是，TC-[[分子印迹聚苯胺|MIP-PANI]] 显示出最高接触角（45.4°），表明表面润湿性降低。这一增加与 [[PFOA]] 模板印迹所带来的含氟基团的存在一致，含氟基团可降低有效表面极性。这种润湿性有利于应用，因为它有助于含 [[PFAS]] 水样在[[侧向流]]动过程中快速扩散，从而促进分析物与导电传感层之间的紧密接触。

## 3.2. 传感原理

[[MIP-PANI]] 功能化[[侧向流]]传感平台的传感原理（图 4）依赖于 [[分子印迹聚苯胺|MIP-PANI]] 薄膜内[[分子印迹空腔|印迹空腔]]对 [[PFAS]] 的[[选择性]]富集，随后[[聚苯胺]]发生[[质子酸掺杂]]（式 1），其中聚苯胺[[翠绿亚胺碱]]（EB）由测量介质提供的质子质子化，生成导电的[[翠绿亚胺盐]]（ES），而结合的分析物阴离子在空腔界面处充当抗衡离子，即

$$
\mathrm{PANI} _ {\mathrm{EB}} + \mathrm{nPFAS} ^ {-} + \mathrm{nH} ^ {+} \leftrightarrow \mathrm{PANI} _ {\mathrm{ES}} ^ {\mathrm{n+}} (\mathrm{PFAS} ^ {-}) _ {\mathrm{n}}\tag{1}
$$

此外，由于该薄膜本身具有亲水性（详见第 3.1 节），水性样品会润湿薄膜，从而促进离子进入聚合物并在其中进行屏蔽。在此过程中，[[分子印迹空腔|印迹空腔]]的分数占据可用 [[Langmuir 等温线]]描述，<sup>39</sup>

$$
\theta_ {\mathrm{PFAS}} = \frac {\mathrm{K} \cdot \mathrm{C} _ {\mathrm{PFAS}}}{1 + \mathrm{K} \cdot \mathrm{C} _ {\mathrm{PFAS}}}\tag{2}
$$

其中 $\mathrm { C } _ { \mathrm { P F A S } }$ 是样品中的 [[PFAS]] 浓度，K 表示亲和常数。当水样存在于 [[MIP-PANI]] 功能化的[[侧流免疫层析|侧流膜]]上时，毛细力驱动样品穿过功能化薄膜，特定的 [[全氟和多氟烷基物质|PFAS]] 结合到空穴中并发生局部[[质子掺杂]]，其程度与位点占有率成正比，因此

$$
\alpha_ {\mathrm{film}} = \gamma \theta_ {\mathrm{PFAS}} + \alpha_ {0}\tag{3}
$$

其中 $\alpha _ { \mathrm { f i l m } }$ 是薄膜上的局部掺杂分数，$\alpha _ { 0 }$ 是薄膜的背景质子化程度，γ 为质子化常数。需要指出的是，薄膜[[电导率]]（σ）同时反映[[载流子密度]]与[[迁移率]]，其关系由下式控制：

$$
\sigma = \mathrm{e} (\mathrm {n_ {b}} \mu_ {\mathrm{b}} + \mathrm {n_ {p}} \mu_ {\mathrm{p}})\tag{4}
$$

其中 e 为[[元电荷]]， ${ \mathfrak { n } } _ { \mathfrak { p } }$ 和 $\mathbf { n _ { b } }$ 是局域化的[[极化子]]与[[双极化子]]密度，以及 $\mu _ { \mathrm { p } }$ 和 $\mu _ { \mathrm { b } }$ 是相应的[[迁移率|迁移率因子]]。对于给定的 [[MIP-PANI]] [[侧向层析膜]]，在受控的读数窗口内（详见第 3.3 节），[[迁移率加权电导率]]， $\mathrm { i . e . , }$ σ 在公式中 $^ { 4 , }$ 可以近似认为与[[局域掺杂比例]]成正比；因此，我们可以有

$$
\begin{array}{r l} & {\sigma_ {\mathrm{PFAS}} = \sigma_ {\mathrm{f}} + \kappa \cdot \alpha_ {\mathrm{film}}} \\ & {\quad = \sigma_ {\mathrm{f}} + \kappa (\gamma \theta_ {\mathrm{PFAS}} + \alpha_ {0})} \\ & {\quad = \sigma_ {\mathrm{f}} + \kappa \bigg [ \gamma \cdot \frac {\mathrm{K} \cdot \mathrm{C} _ {\mathrm{PFAS}}}{1 + \mathrm{K} \cdot \mathrm{C} _ {\mathrm{PFAS}}} + \alpha_ {0} \bigg ]} \end{array}\tag{5}
$$

其中 $\sigma _ { \mathrm { f } }$ 是薄膜的[[基线电导率]]，κ 是综合了基本电荷及测量条件下平均[[迁移率]]的常数。在低 [[PFAS]] 浓度下的适度掺杂中，有理由认为 $\mathrm { K } { \cdot } \bar { \mathrm { C } } _ { \mathrm { P F A S } } \ll 1$ ，因此[[全氟和多氟烷基物质|PFAS]]引起的[[电导率]]变化可表示为

$$
\Delta \sigma = \sigma_ {\mathrm{PFAS}} - \sigma_ {0} \approx \kappa \cdot \gamma \cdot \mathrm{K} \cdot \mathrm{C} _ {\mathrm{PFAS}} = \varphi \mathrm{C} _ {\mathrm{PFAS}}\tag{6}
$$

哪里 $\sigma _ { 0 }$ 是薄膜在[[去离子水]]下的[[电导率]]，并且 $\varphi$ 是比例常数。因此，通过测量电导率的变化，可利用式 6 确定 [[PFAS]] 浓度。

3.4.3. [[选择性]]、[[抗干扰性]]与[[重现性]]。为了能够在复杂环境基质中准确定量 [[PFOA]]，传感材料必须具有足够的分子选择性。为此，对 [[MIP-PANI]] 功能化侧流传感平台在 10 nM 浓度下对五种结构相关 [[PFAS]] 化合物（包括 [[全氟辛酸|PFOA]]、[[PFNA|全氟壬酸]]（PFNA）、[[PFBS|全氟丁磺酸]]（PFBS）、[[PFPeA|全氟戊酸]]（PFPeA）和[[PFBA|全氟丁酸]]（PFBA））的[[电导率]]响应进行了评估。如图 7a 和 S9−S11 所示，原始 [[PANI]] 在两个浓度下对五种分析物均表现出相当的$\Delta \sigma$，表明其[[分子区分能力]]可忽略不计，并证实原始 [[聚苯胺|PANI]] 功能化[[侧流免疫层析|侧流膜]]对 PFOA 缺乏选择性。与之形成鲜明对比的是，[[TE-MIP-PANI]] 功能化[[侧流膜]]在两个剂量（10 pM 和 10 nM）下对 PFOA 的电导率响应均显著强于其他 [[全氟和多氟烷基物质|PFAS]] 化合物（图 7a）。这种显著的选择性来源于[[分子印迹]]过程，其中 PFOA 分子作为模板，在[[聚合物基质]]中生成[[互补识别位点]]。这些空腔不仅有利于 PFOA 分子的精确嵌入，而且在结合时促进[[聚合物主链]]的[[局部质子化]]，从而引起显著的电导率变化。相比之下，PFNA、PFBS、PFPeA 和 PFBA，无论其[[全氟烷基链]]长如何，都无法在 PFOA [[分子印迹空腔|印迹空腔]]内实现相同的[[空间和化学互补性]]，因而电导率变化极小。尽管 PFNA 具有相似的全氟链长，但分子尺寸和[[分子几何结构]]的细微差异可能导致其在[[印迹空腔]]内的匹配度欠佳，从而降低[[结合亲和力]]并减弱[[传感器]]响应。为进一步证实[[分子印迹技术|分子印迹]]的关键作用，在相同条件下使用 [[NIP-PANI]] 功能化侧流膜测量了对同一组 PFAS 的电导率响应。五种 PFAS 物种之间未出现显著信号差异，这支持了 [[分子印迹聚苯胺|MIP-PANI]] 功能化侧流膜的高分子选择性完全来源于印迹识别位点，而非[[导电聚合物]]的固有性质。
