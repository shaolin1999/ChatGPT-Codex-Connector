# 通过仿生多功能[[木质纤维素]]纳米框架实现可持续[[环境修复]]

[[Jinghao Li]]<sup>1,2,3</sup>, [[Xiaohan Li]]<sup>1,2</sup>, [[Yabin Da]]<sup>4</sup>, [[Jiali Yu]]<sup>1,2</sup>, [[Bin Long]] <sup>1,2</sup>, [[Peng Zhang]]<sup>1,2</sup>, [[Christopher Bakker]]<sup>3</sup>, [[Bruce A. McCarl]]<sup>4</sup>, [[Joshua S. Yuan]]<sup>5</sup> & [[Susie Y. Dai]] <sup>1,2✉</sup>

化学污染威胁着人类健康和生态系统的可持续性。[[全氟和多氟烷基物质]]（PFAS）等[[持久性有机污染物]]（POPs）一旦排放，清除成本便十分高昂。目前迫切需要创新性的协同策略，但工艺整合和成本效益仍面临挑战。本研究开发了一种 PFAS [[原位修复]]系统，利用植物来源的[[仿生纳米框架]]，协同实现高效[[吸附]]及后续[[真菌生物转化]]。该多组分框架被命名为[[用于原位微生物环境修复的可再生人工植物]]（Renewable Artificial Plant for In-situ Microbial Environmental Remediation，[[RAPIMER]]）。RAPIMER 对 PFAS 化合物表现出较高的[[吸附容量]]，并对[[共存污染物]]具有多样化的吸附能力。随后，RAPIMER 为通过[[真菌]][[乳白耙齿菌]]（Irpex lacteus）开展的[[原位生物修复]]提供底物和污染物，并促进 PFAS [[解毒]]。RAPIMER 源自廉价的[[木质纤维素|木质纤维素原料]]，能够对可持续性产生更广泛的影响，并为低成本污染物修复提供一种途径。

[[持久性有机污染物|持久性有机化学物质]]（POPs）造成的污染严重威胁人类和生态系统健康1。环境威胁人类和生态系统健康¹。POPs 的[[环境修复]]是一项全球性挑战<sup>2,3</sup>，且通常涉及昂贵、复杂的多步骤工艺<sup>4</sup>。迄今为止，修复方法通常采用涵盖[[污染物吸附]]<sup>5</sup>、[[解毒]]以及后续[[材料降解]]<sup>6</sup>的处理工艺链。然而，现有实践劳动密集、成本高昂，各环节往往相互脱节，并会产生[[二次污染]]<sup>7</sup>。因此，开发整合良好、成本低廉、环境友好、可持续且有效的协同策略至关重要<sup>8,9</sup>。

对于[[全氟和多氟烷基物质]]（PFAS）等常见且广泛存在的 POP 类物质，尤其需要高效、一体化的修复方案10。PFAS 极难降解，对人类和野生动物健康造成严重损害，且普遍存在，甚至在北冰洋等偏远地区也被检测到<sup>11</sup>。在人类中，研究发现 PFAS 会增加癌症、出生缺陷和免疫系统受损的发生率<sup>12–14</sup>。PFAS 分子有 9000 多种不同形式，[[美国环境保护署]]（U.S. EPA）已认识到其风险，正在针对两种 PFAS——[[全氟辛酸]]（PFOA）和[[全氟辛烷磺酸]]（PFOS）——制定饮用水法规<sup>15</sup>。目前，唯一商业化的 PFAS 修复方法涉及成本高昂且不可持续的[[热分解]]<sup>16</sup>。尽管已有许多[[吸附剂]]被用于[[环境修复]]研究<sup>17–21</sup>，但其应用受到需要使用高成本金属或聚合物基材料以及产生[[二次污染]]的限制<sup>7,22</sup>。虽然研究人员已对更可持续、成本更低的[[壳聚糖]]、[[生物炭]]、[[微生物生物质]]及[[生物吸附剂|农业废弃物基生物吸附剂]]开展研究，但它们仍缺乏工业应用所需的性能<sup>23</sup>。[[生物修复]]已被探索用于 PFAS 修复，但受到效率低、处理时间长以及无法去除[[痕量污染物]]等问题的限制<sup>24,25</sup>。因此，亟须采用创新、可持续、高效、一体化且具有成本效益的解决方案，应对[[吸附]]剂、生物修复及处理链整合方面的挑战。

在此，我们展示了一种[[仿生设计|仿生系统设计]]，通过利用可再生工程化纳米材料依次[[吸附]]污染物、将其储存以进行[[生物修复]]、为微生物提供栖息载体以将有毒物质降解为危害较小的形式，并最终使材料自身降解，从而应对上述挑战。通过[[纳米结构]]与功能设计，我们利用经[[化学改性]]的[[木质纤维素|木质纤维素生物质]]构建了[[用于原位微生物环境修复的可再生人工植物]]（Renewable Artificial Plant for In-Situ Microbial Environmental Remediation，[[RAPIMER]]）。RAPIMER 凭借若干重要特性，克服了[[吸附剂]]、生物修复及处理链整合方面的挑战。首先，它以低成本且来源广泛的[[纤维素]]和[[木质素]]为原料，利用二者的[[亲水性|亲水]]性和[[疏水性|疏水]]性构建[[两亲性]]环境，从而实现 [[全氟和多氟烷基物质|PFAS]] 的高效吸附。其次，RAPIMER 为[[细菌]]和[[真菌生长]]提供了天然基质，[[白腐真菌]]可在其上协同分解 PFAS，随后分解 RAPI-MER 本身，且不产生[[二次污染]]物。特别是，RAPIMER 能使有毒底物具有高得多的[[生物可利用性]]，从而提高修复效率并实现痕量 PFAS 修复，以独特的方式整合处理链。第三，以木质素这一天然且难降解的底物为基础，RAPIMER 可支持[[氧化还原酶]]的表达，将 PFAS 降解为无害物质。因此，RAPIMER 是一种能够在自身内部实现整个处理链的单一[[植物基纳米材料]]。如下所示，它具有很高的[[吸附容量]]，能够促进有毒物质的高效降解以及原始材料的最终降解，而且由低成本材料制成。因此，它提供了一种具有成本效益且可持续的 PFAS 修复途径，并可更广泛地用于 [[持久性有机污染物|POPs]] 的修复。

## 结果

用于[[吸附]]和[[生物降解]]的 [[RAPIMER]] 组分设计。如前所述，基于 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 的修复依赖于一种材料设计，该设计能够：(1) 高效吸附 [[持久性有机污染物|POPs]]/[[全氟和多氟烷基物质|PFAS]]，(2) 将 PFAS 保持在高浓度状态，(3) 作为实施[[生物修复]]的[[白腐真菌]]的基质，以及 (4) 刺激[[生物降解酶]]的表达，以实现快速、高效的降解（图 1 和补充图 1）。为此，研究设计了[[多功能复合材料]]，将[[天然生物聚合物]][[木质素]]和[[纤维素]]整合为能够实现有效吸附和修复的形式（补充图 1）。这些天然生物聚合物确保了吸附与生物修复的无缝衔接，因为 RAPIMER 可作为承载白腐[[真菌]]进行生物降解的基质<sup>26,27</sup>（图 1）。同时，木质素和纤维素均取自[[玉米秸秆]]，这是一种来源广泛的[[农业残余物]]（详细步骤见方法部分）。

在[[纤维素]]组分的设计中，采用 [[TEMPO氧化|TEMPO 氧化处理]]制备[[纤维素纳米原纤]]，其直径显著小于原料[[纤维素纤维]]（补充图 2）。此外，与纤维素纤维相比，[[纤维素纳米原纤维|纤维素纳米原纤]]表现出更好的[[水稳定性]]（补充图 3）和更大的[[BET|比表面积]]（补充表 1）。因此，选择纤维素纳米原纤作为构建 [[RAPIMER]] 纳米框架的组分。对于[[木质素]]组分，从纤维素制造残液中纯化得到的木质素对 [[全氟和多氟烷基物质|PFAS]] 不具有[[结合亲和力]]（补充表 2）。因此，为提高亲和力，并考虑到 PFAS 的正电荷，通过[[化学接枝|接枝]][[聚乙烯亚胺]]（PEI）对木质素进行改性（图 1a），因为聚乙烯亚胺具有[[生物相容性]]，且能够引入阳[[离子相互作用]]以增强[[吸附]]<sup>28</sup>。这种改性产生了带正电荷的[[木质素颗粒]]<sup>29</sup>，其通过与带负电荷的 PFAS 分子相互作用来增强吸附。

随后，通过[[冷冻干燥]]和[[烘箱固化]]，将[[化学改性]]的[[木质素]]与[[纤维素纳米原纤]]制成稳定的 [[RAPIMER|RAPIMER 复合材料]]（图 1c）（详细步骤见方法部分）。所得 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 具有[[三维纳米结构|三维（3D）纳米结构]]（图 2），具备用于[[吸附]] [[全氟和多氟烷基物质|PFAS]] 的大表面积、能够吸引 PFAS 的带正电荷木质素，以及可容纳[[生物降解]]微生物的空间。随后，通过[[吸附动力学]]和[[保留试验]]进行的分析（图 1d）表明，RAPIMER 具有较高的[[吸附容量]]和效率。（详细步骤见方法部分）。进一步的[[生物降解测定]]表明，RAPIMER 可作为[[真菌生长]]的基质（图 1e），并促进所储存的 PFAS [[生物转化]]为两种[[毒性]]较低的短链产物 $( \mathrm { C } _ { 7 } \mathrm { H F } _ { 1 3 } \mathrm { O }$ 和 $\mathrm { C } _ { 6 } \mathrm { H F } _ { 1 1 } \mathrm { O } _ { 2 } ) ^ { 3 0 }$

[[RAPIMER]] 的 3D 结构与多功能设计。如上所述，3D 结构设计对于高效[[吸附]] [[全氟和多氟烷基物质|PFAS]] 至关重要。与[[纤维素纤维]]相比，[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 具有更精细的纳米尺度纤维结构（图 2a、b 和补充图 2），并形成了用于高效吸附 PFAS 的[[空间晶格结构]]。所得[[纤维素纳米原纤]]的平均[[纤维直径]]为 2.35 nm，而原始[[纤维素]]纤维的平均直径为 11.57 µm（图 2c）。这使[[BET|比表面积]]增至原来的 13 倍（补充表 1）。

将 [[RAPIMER]] 的[[三维纳米结构]]与其他复合材料进行了比较（图 2d–i）。具体而言，[[纤维素纤维]]中未受束缚的羟基数量有限，而 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 中分布均匀的[[纤维素纳米原纤维]]之间存在丰富的[[氢键]]，因此形成了[[三维晶格支架|片状三维晶格支架]]（图 2g）。相比之下，[[纤维素]]纤维呈管状结构。RAPIMER 的[[纳米结构]]增大了表面积，显著提高了[[水稳定性]]，并为高容量 [[全氟和多氟烷基物质|PFAS]] [[吸附]]提供了水稳定性框架。

基于[[逆向工程]]原理，将[[化学改性]][[木质素]]嵌入[[纤维素纳米原纤维泡沫]]中，形成作为仿生基质的 [[RAPIMER]]，以实现高效[[吸附]]与[[生物修复]]的一体化。由于木质素具有[[疏水性|疏水]]性，[[聚乙烯亚胺改性木质素]]仍保留其疏水性。补充图 4a、b 展示了木质素和[[改性木质素]]的典型 [[SEM]] 图像，两者具有相似的形貌。然而，[[能量色散X射线光谱|能量色散 X 射线]]（EDX）[[元素映射]]图像表明，与未改性木质素相比，改性木质素的氮含量有所增加（从 0.2 wt% 增至 24.2 wt%）。还采用 [[FTIR]] 表征了木质素化学改性后的结构变化。未改性木质素的光谱在约 3400 cm<sup>−1</sup> 处呈现吸收带（羟基），在 1650 cm<sup>−1</sup> 处呈现吸收带（共轭 C–O 振动），在 1598 cm<sup>−1</sup>、1510 cm<sup>−1</sup> 和 1423 cm<sup>−1</sup> 处呈现吸收带（芳香环振动），在 1460 cm<sup>−1</sup> 附近呈现吸收带（C–H 弯曲振动），并在 1218 cm<sup>−1</sup> 和 1120 cm<sup>−1</sup> 处呈现吸收带（C–O 键的伸缩振动）。与[[聚乙烯亚胺]]进行[[化学接枝]]后，改性木质素的光谱在约 3380 cm<sup>−1</sup> 处出现[[胺基]]峰，并在 $2 9 4 0 { - } 2 8 3 0 \mathrm { c m } ^ { - 1 }$ 和 1463 cm<sup>−1</sup> 处分别出现 C–H 伸缩振动和剪式振动吸收带，这与聚乙烯亚胺的光谱一致。化学改性后最显著的变化是在 1656 cm<sup>−1</sup> 和 1599 cm<sup>−1</sup> 附近出现了峰，这些峰被归属于伴有 O = C 伸缩振动的酰胺 I 和酰胺 II。这些吸收带表明，聚乙烯亚胺已成功接枝到木质素结构的芳香环上，在改性[[木质素颗粒]]上引入了丰富的胺基。[[XPS]] 分析进一步证实了化学改性反应的成功（图 2k 和补充图 5）。在改性木质素的光谱中，约 400 eV 处检测到了对应于 N1s 的信号。因此，聚乙烯亚胺接枝使木质素和 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 上具有丰富的带正电荷的胺基，可吸附 [[全氟和多氟烷基物质|PFAS]] 等带负电荷的分子。

对[[纤维素纳米原纤维]]、[[纤维素纤维与木质素复合材料|纤维素纤维/木质素复合材料]]以及 [[RAPIMER|RAPIMER 复合材料]]（[[纤维素纳米原纤维与改性木质素复合材料|纤维素纳米原纤维/改性木质素复合材料]]）的 [[傅里叶变换红外光谱|FTIR 光谱]]的进一步分析见补充图 6。在 [[FTIR]] 光谱中，位于 $1 7 \dot { 2 } 0 \mathrm { c m } ^ { - 1 }$ 处的 COOH 峰（在[[纤维素纳米原纤]]维和[[纤维素纳米原纤维与木质素复合材料|纤维素纳米原纤维/木质素复合材料]]的光谱中均存在）在 [[用于原位微生物环境修复的可再生人工植物|RAPI-MER]] 光谱中完全消失。结果表明，[[改性木质素]]中带正电的[[胺基]]与[[纤维素]]纳米原纤维中带负电的羧基发生了反应。因此，纤维素纳米原纤维在 1720 cm<sup>−1</sup> 处的峰在 RAPIMER 光谱中移至 1600 cm<sup>−1</sup>。这一峰的变化可归因于羧酸/胺盐的形成<sup>31</sup>。因此，纤维素纳米原纤维的 C6 位羧基提供了与[[聚乙烯亚胺改性木质素|改性木质素]]胺基结合的锚定位点，并形成了稳定的三维复合结构（图 1c）。由于这些化学和结构变化，RAPIMER 还表现出优异的[[热稳定性]]，直至温度达到 200 °C 才会分解（补充图 7）。总之，RAPIMER 的[[三维纳米结构]]具有独特性：带负电的纤维素纳米原纤维（[[亲水性|亲水]]性）与带正电的[[木质素]]（[[疏水性|疏水]]性）共同构建了[[两亲性]]环境和具有大表面积的[[空间晶格结构|三维晶格结构]]，从而实现对 [[全氟和多氟烷基物质|PFAS]] 的高效[[吸附]]。

组分[[吸附]]实验表明，[[改性木质素]]是吸附 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的主要组成材料（蓝色菱形），而[[纤维素]]未发挥吸附作用（图 3a、b，绿色方形和三角形）。不同组成的实验表明，[[RAPIMER]] 中[[聚乙烯亚胺改性木质素|聚乙烯亚胺接枝木质素]]与[[纤维素纳米原纤维]]的比例为 1:1 时，[[吸附容量]]最大。带负电荷的[[纤维素纳米原纤]]维可能提供了三维结构骨架，用于固定结合后的 [[全氟和多氟烷基物质|PFAS]]。仅按[[木质素]]质量折算，[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 中木质素组分对 PFOA 和 PFOS 的吸附容量较改性[[木质素颗粒]]分别提高了 71.9% 和 95%，其性能超过了以往研究中的任何类型 PFAS [[吸附剂]]（补充表 3）。

[[RAPIMER]] 的[[吸附]]具有 [[pH值|pH]] 依赖性，在 pH 小于 8 的范围内，[[全氟和多氟烷基物质|PFAS]] [[吸附量]]降低（图 3c 和补充说明 3）。然而，[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 的零电荷点为 8.22，这使其能够广泛应用于[[水处理]]（图 3d）。因此，RAPIMER 的[[三维纳米结构]]设计既提高了 PFAS [[吸附容量]]，也增强了对 pH 变化的适应能力。在含有混合 PFAS 分子（[[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 的质量比为 1:1）的流动溶液中测试了 RAPIMER 对 PFAS 的吸附性能。将 RAPIMER 材料填装到流动系统的[[在线过滤器]]中（补充图 8），用于过滤浓度为 1 µg/L 的 PFAS 溶液。该浓度低于许多环境相关条件下的浓度，在这些条件下，检测到的 PFAS 浓度可高达 20 µg/L，甚至更高<sup>32</sup>。采用较低浓度是为了充分测试其在低浓度下的吸附能力。最终对 PFOA 的[[吸附率]]超过 99.90%，对 PFOS 的吸附率为 100%（图 3e），表明 RAPIMER 在去除痕量 [[持久性有机污染物|POPs]] 方面具有巨大潜力<sup>33</sup>。这种去除痕量 PFAS 的能力独特地实现了与[[生物修复]]的整合。

此外，在存在 [[全氟和多氟烷基物质|PFAS]] 潜在[[共存污染物]]的更接近实际的条件下，对 [[RAPIMER]] 的[[水处理]]性能进行了测试。收集雨水，经过滤后加入 PFAS、[[重金属]]及另一种有机污染物的混合物。图 3f 显示，使用同一流动系统（补充图 8）时，PFAS 及其他五种污染物均具有较高的[[去除效率]]（即一种[[阴离子染料|阴离子染料分子]]、铬（[[铬|Cr]]）、镉（[[镉|Cd]]）、铜（[[铜|Cu]]）和铅（[[铅|Pb]]），雨水中每种污染物的浓度均为 1 mg/L）。结果表明，所有污染物均有约 99% 被填装 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 的过滤器[[吸附]]（图 3f）。

[[RAPIMER]] 高[[吸附容量]]及[[共存污染物]]去除的机制。通过[[计算建模]]和[[材料表征]]，揭示 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 高[[吸附]]容量的机制。利用[[吸附等温线]]试验数据（图 4a、b），分别采用 [[Langmuir吸附等温模型|Langmuir]] 和 [[Freundlich吸附等温模型|Freundlich 模型]]进行拟合，结果列于补充表 4。根据所得的 $\mathtt { R } ^ { 2 }$，[[Langmuir模型|Langmuir]] 模型对数据的拟合效果更好（补充表 4）。这表明，由于 [[全氟和多氟烷基物质|PFAS]] 与[[改性木质素]]之间静电吸引和[[疏水相互作用]]的共同作用，吸附很可能发生在 RAPIMER 表面的单分子层上。具体而言，PFAS 的羧基或硫酸基带负电且具有[[亲水性|亲水]]性，而 C-F 链则具有更强的[[疏水性|疏水]]性。因此，[[聚乙烯亚胺改性木质素|改性木质素]]上带正电的氨基提供了更多不受限制的位点，通过静电力吸引带负电的 PFAS 分子。此外，改性[[木质素]]保留了其木质素前体的疏水性。这种疏水性使其能够与 PFAS 的 C-F 链相互作用，进一步稳定 PFAS 的吸附。具有[[空间晶格结构]]且带负电的[[纤维素纳米原纤维]]提供了独立的构筑单元，用于容纳吸附在改性木质素上的 PFAS 分子，从而防止这些 PFAS 释放，并提高总吸附容量。因此，[[聚乙烯亚胺]]改性引入的正电荷、[[纤维素纳米原纤]]维的负电荷以及木质素的疏水骨架共同构成了促进 PFAS 吸附的[[三维两亲性多孔纳米框架]]。与此前报道的[[吸附剂]]相比，RAPIMER 的独特设计显著提高了 PFAS [[吸附量]]（补充表 3）。

[[SEM]]（图 4c、e）和 [[能量色散X射线光谱|EDX]]（图 4d、f）分析进一步证实了上述[[吸附机制]]。氮和氟（N，蓝色；F，紫色，见图 4d、f）分别由[[聚乙烯亚胺]][[化学接枝|接枝]]和 [[全氟和多氟烷基物质|PFAS]] [[吸附]]引入，可作为[[木质素]]和 PFAS 定位的探针。如图 4d、f 所示，蓝色与紫色的重叠区域表明，[[改性木质素]]（氮来自聚乙烯亚胺）与 PFAS（氟来自 PFAS）发生了相互作用，这一结果与等温线建模结果一致。因此，[[RAPIMER]] 的高[[吸附容量]]源于带正电的[[聚乙烯亚胺改性木质素|改性木质素]]颗粒在[[疏水性|疏水]]且带负电的三维纳米框架中的广泛分布。

关于[[共存污染物]]的[[吸附]]，形貌和[[化学元素]]分析（图 4g）表明，[[RAPIMER]] 的[[双电性与两亲性结构|三维双电性/两亲性结构]]设计提供了独立的构筑单元，用于吸附 [[全氟和多氟烷基物质|PFAS]]、金属和[[有机染料]]分子。[[SEM]] 图像显示，中心的 [[CSML]] 颗粒被 [[CSCNF]] 网络包围。此外，[[能量色散X射线光谱|EDX]] 图像显示，氟和金属被 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 的不同组分（CSML 和 CSCNF）捕获。考虑到 PFAS 是唯一含氟的化学物质，氟分布图（图 4g）表明，PFAS 主要吸附于图像中心所示的 CSML 上。[[阴离子染料|阴离子有机染料]]和带正电荷的[[金属离子]]的吸附则更广泛地分布于 RAPIMER 中。EDX 分析表明，这种多样化的吸附能力可归因于三维双电性/[[两亲性]]结构设计，该设计具有从复杂基质中去除 PFAS，并在实际条件下修复多种环境污染物的潜力。

[[FTIR]] 和 [[XPS]] 分析提供了有关 [[全氟和多氟烷基物质|PFAS]] [[吸附机制]]的更多信息。[[傅里叶变换红外光谱|FTIR]] 分析（图 2j）显示了[[改性木质素]][[吸附]] [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 后的光谱变化。[[胺基]]谱带（约 $3 3 8 0 \mathrm { c m } ^ { - 1 } )$ 消失，且 $\mathrm { - C F } _ { 2 } , \mathrm { - C F } _ { 3 }$ 的主要峰出现在约 $1 2 \dot { 3 } \dot { 8 } \mathrm { c m } ^ { - 1 }$ $1 2 0 5 \mathrm { c m } ^ { - 1 , }$ 和 $1 1 5 0 \mathrm { c m } ^ { - 1 } .$ 同时，在吸附 PFOA 和 PFOS 后的[[木质素]]光谱中观察到了 $- \mathrm { C O O ^ { - } }$ $( 1 6 8 1 \mathrm { c m } ^ { - 1 }$，对应于 PFOA）和 - $\cdot \mathrm { S O } _ { 3 } ^ { - } \ : ( 1 2 1 5 \mathrm { c m } ^ { - } )$，对应于 PFOS）的峰。因此，该分析进一步证实，[[聚乙烯亚胺改性木质素|改性木质素]]中的胺基是通过[[静电相互作用]]捕获 PFAS 的主要[[官能团]]。改性木质素在吸附 PFAS 前后的 [[X射线光电子能谱|XPS]] 光谱也证实了材料与 PFAS 之间的相互作用（图 2k 和 S7）。689 eV 处的主峰（吸附 PFAS 后的改性木质素光谱中的 F1s 峰）表明，改性木质素与 PFAS 之间存在稳定而牢固的相互作用。总体而言，这些结果凸显了 [[RAPIMER]] 的[[纳米结构]]和化学设计的有效性，能够构建一种独特的[[纳米多孔复合材料|两亲性纳米多孔复合材料]]，通过静电相互作用结合 PFAS，并借助[[疏水相互作用]]和带负电荷的环境进一步稳定这种结合。[[纤维素纳米原纤维|纤维素纳米纤丝]]骨架的大[[BET|比表面积]]进一步提高了[[吸附容量]]，使其达到已报道的最高吸附容量。随后，我们评估 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 是否能够被微生物消耗，从而整合[[生物修复]]过程。

进一步在经不同浓度 [[全氟和多氟烷基物质|PFAS]]（10、100、1000 和 10,000 µg/L，详细步骤见“方法”）处理的 [[RAPIMER|RAPI-MER]] 复合材料上评估了[[真菌生长]]状况。[[真菌活力测定]]表明，[[乳白耙齿菌|I. lacteus]] 在经上述四种浓度处理的 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 上均生长良好，在中等 PFAS 浓度（100 和 1000 µg/L——图 5b）下表现更佳。[[数字显微镜]]观察还显示，[[真菌]]菌丝良好地附着于 RAPIMER 材料表面（图 5d）。总体而言，研究发现 RAPIMER 能有效维持真菌细胞生长，并将富集的 PFAS 提供给真菌进行[[生物修复]]。

[[RAPIMER]] 中的 [[全氟和多氟烷基物质|PFAS]] 降解。要用于修复，[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 需要促进 PFAS 降解。[[真菌]]在富集 PFAS 的 RAPIMER 上生长，表明其具有降解能力。采用[[高分辨率质谱|高分辨率质谱分析]]对生长溶液中的 PFAS 衍生产物进行定量测定。在为期两周的评估期间，鉴定出两种由降解产生的[[生物转化产物]] $( \mathrm { C } _ { 7 } \mathrm { H F } _ { 1 3 } \mathrm { O }$ 和 $\mathrm { C } _ { 6 } \mathrm { H F } _ { 1 1 } \mathrm { O } _ { 2 } )$。这两种化合物可能分别为[[全氟庚醛]]（C7）和[[全氟己酸]]（PFHA，C6）（[[质荷比|M/Z]] 分别为 346.9839 和 312.9723）。[[Mahapatra]] 等人及其他研究者此前的研究表明，链长较短的 [[全氟丁酸|PFBA]]（C4）、[[PHPA]]（C5）和 PFHA（C6）的[[毒性]]远低于 [[全氟辛酸|PFOA]]（C8），这表明本研究检测到的降解产物的毒性可能低于 [[全氟辛烷磺酸|PFOS]] 和 $\mathrm { P F O A } ^ { 3 0 , 3 7 }$。这些结果凸显了利用 RAPIMER 将[[吸附]]与后续[[生物修复]]整合为连续处理流程，以处理受 PFAS 严重污染介质的可行性。

[[RAPIMER]] 修复的环境效益。我们采用多维度[[生命周期评价]]（LCA），将 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 与其他商业化使用的 [[全氟和多氟烷基物质|PFAS]] [[吸附剂]]进行比较，以研究使用 RAPIMER 的[[环境影响]]（见方法和补充表 5）。我们考虑的 PFAS [[吸附]]剂包括[[活性炭]]和[[离子交换树脂]]<sup>41</sup>。我们的 LCA 分析考察了[[酸化]]、[[温室气体排放]]、[[人体毒性]]（致癌和非致癌）、[[生态毒性]]、[[臭氧消耗]]、[[颗粒物]]和[[近地面臭氧形成]]。具体而言，我们以[[归一化]]方式比较结果；即考察使用各种吸附剂处理 1 m<sup>3</sup> PFAS 污染[[地下水]]（浓度为 0.21 μg/ L）所产生的环境影响（请注意，我们还进行了以生产 1 kg 吸附剂为基准的比较，见补充图 9）。在进行归一化时，我们考虑了不同吸附剂的[[吸附容量]]差异（补充说明 6）。例如，我们发现 RAPIMER 对 PFAS 的吸附容量约为活性炭的 3–10 倍<sup>42,43</sup>，为离子交换树脂的 1–3 倍（补充表 6）。归一化比较表明，相较于活性炭，RAPIMER 显著降低了 [[二氧化碳|CO₂]] 净排放量（使用 RAPIMER 处理每 1 m<sup>3</sup> 地下水时排放 1.4e-7 kg CO，而使用活性炭时为 4.5e-6 kg），相较于离子交换树脂（3.4e-7 kg），则实现了适度减排。图 6 还展示了其他环境类别的结果，并与活性炭和离子交换树脂的相应结果进行了比较。图 6 的结果显示，与活性炭相比，使用 RAPIMER 大幅降低了所有环境影响类别中的环境影响。在[[人体致癌毒性]]和臭氧消耗方面，使用 RAPIMER 的表现也显著优于离子交换树脂。为进一步研究这一点，我们开展了[[贡献分析]]，结果表明，所需化学品以及[[纤维素纳米原纤维|纤维素纳米纤丝]]组分的生产是 RAPIMER 环境影响的主要贡献来源（即在大多数类别中占比超过 70%）。相比之下，能源投入（即用电量）的作用较小，例如，其占温室气体[[全球变暖潜势|全球变暖总潜势]]的 3.9%。

[[RAPIMER]] 的可降解性、[[全氟和多氟烷基物质|PFAS]] 的降解以及无[[二次污染]]带来了额外的环境效益，而这些效益尚未纳入本次 [[生命周期评价|LCA]] 分析<sup>44</sup>。相较于现有实践，能耗更低且无显著的 PFAS 再释放也是其优势<sup>45</sup>。此外，其自降解特性减少了对额外设备的需求，并减轻了相关的额外环境负担。

## 讨论

本研究设计了一种可再生[[仿生复合材料]] [[RAPIMER]]，它能够以独特的方式[[吸附]] [[全氟和多氟烷基物质|PFAS]]、将其固定并使其可供降解，从而在一种植物基材料中实现完整的修复处理链。此外，与其他[[吸附剂]]相比，[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 对 PFAS 具有前所未有的[[吸附容量]]，并对其他[[共存污染物]]具有广泛的吸附能力。它由廉价的[[木质素]]和[[纤维素]]原料制成，具有可持续性且对环境友好。它是一种耐热、耐水、[[可生物降解性|可生物降解]]、可再生且成本低廉的多功能材料，整合了整个处理链。此外，与涉及吸附剂或燃烧的传统 PFAS 处理所造成的其他环境后果相比，RAPIMER 相较于涉及燃烧的传统 PFAS 处理所造成的环境后果，带来了显著的环境和可持续性效益。

因此，[[RAPIMER]] 在 [[全氟和多氟烷基物质|PFAS]] [[生物修复]]和其他[[共存污染物]]去除方面具有巨大潜力。这种仿生材料不需要稀缺且昂贵的化学品，并具有高效率和较大的修复容量。它克服了生物修复效率低的问题，维持微生物生长，并可在原位发挥作用，而不会引入次生危害。[[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 还可通过仿生底物诱导[[氧化还原酶]][[蛋白质过表达|过表达]]，并在高浓度有毒物质存在的条件下维持微生物细胞生长，从而提供额外的[[解毒]]机制。这种纳米材料设计也为未来的进一步发展提供了可能。我们利用[[玉米秸秆]]中的[[纤维素]]和[[木质素]]制备 RAPIMIER，以优化[[纤维素纤维]]的氧化程度和[[BET|比表面积]]，同时最大限度地增强[[离子相互作用]]，从而提高稳定性、[[吸附]]性能和生物修复能力。[[亲水性|亲水]]但带负电荷的[[纤维素纳米原纤维]]与[[疏水性|疏水]]且带正电荷的[[改性木质素]]共同形成了独特的[[两亲性]]和双电荷环境，减少 PFAS [[解吸]]并最大限度地提高[[吸附效率]]。总体而言，RAPIMER 构建了一个独特、环境友好且高效的 PFAS 修复平台。除这些独特优势外，制备 RAPIMER 所采用的[[逆向工程]]原理、处理链整合以及[[共底物]]分子机制，也为更广泛的修复应用提供了可能。这些原理和机制可广泛用于多种其他有害化学物质的修复。

[[木质素]]与[[纤维素]]的分离。采用碱法从[[玉米秸秆]]中分离木质素和[[纤维素纤维]]。具体而言，将 100 g 干燥玉米秸秆加入装有 1000 mL [[氢氧化钠]]溶液（1% w/v）的 2 L 烧瓶中，随后使用 Amsco LG 250 Laboratory Steam Sterilizer（Steris，美国）在 120 °C 下加热 1.5 h。冷却至室温后，用 1 级 waterman 滤纸分离纤维素纤维，再用蒸馏水洗涤至 [[pH值|pH]] 呈中性。将所得纤维素纤维储存在 4 °C 冰箱中，以供进一步处理。保留残余木质素溶液，用于木质素回收。

[[纤维素纳米原纤维]]的制备。采用 TEMPO 氧化法制备[[玉米秸秆]]基[[纤维素纳米原纤]]维。通过碱性[[木质纤维素]]浆处理制备，具体步骤为：将 4 g [[纤维素纤维]]分散在含有 0.06 g TEMPO 和 0.4 g NaBr 的蒸馏水中，持续 30 min，随后加入含 20 mmol NaClO 的溶液（13%，w/w）。接着，通过添加 0.5 M [[氢氧化钠|NaOH]] 溶液将 [[pH值|pH]] 控制在 10，并使其扩散 1 h。随后过滤氧化后的[[纤维素]]纤维，并用蒸馏水洗涤至 pH 呈中性。之后，使用高压均质机对纤维进行进一步处理。将所得 0.6%（w/w）纤维素纳米原纤维悬浮液储存在 4 °C 冰箱中，以供进一步加工。

从残余[[木质素]]溶液中回收木质素。首先，使用 1000 MW 透析管对 500 mL 残余木质素溶液进行透析。透析后，加入 [[盐酸|HCl]] 溶液（0.5 mol/L）使木质素沉淀，直至 [[pH值|pH]] 达到 2。随后，将所得液体以 6000 rpm [[离心]] 5 min，并过滤，得到约 5 g 木质素沉淀。分离该木质素，并用 pH 为 2 的[[酸化]]水洗涤。随后真空[[冷冻干燥]]约 24 h，直至恒重。将最终所得[[玉米秸秆]]木质素样品储存在干燥器中，以供进一步表征或使用。对于[[改性木质素]]，首先使用 1000mw 透析管对 500 ml 木质素含量为 1% 的残余木质素溶液透析 3 天，以去除多余的小分子糖类，随后使用 [[二氧化碳|CO2]] 将 pH 调节至 6.5，以进行 Mannich 反应。然后，在 60 °C 水浴条件下，将 40 ml [[聚乙烯亚胺|PEI]] 溶液（10% w/v）和 40 ml [[甲醛]]（37% w/v）逐渐加入装有 500 ml 残余木质素溶液的 1 L 三颈烧瓶中，反应 5 h。反应过程中，PEI [[化学接枝|接枝]][[木质素颗粒]]逐渐沉淀。过滤沉淀物，随后用蒸馏水洗涤至 pH 呈中性。将玉米秸秆[[聚乙烯亚胺改性木质素|改性木质素]]（[[CSML]]）样品真空冷冻干燥，随后储存在干燥器中，以供进一步表征和使用。

复合材料制备。为制备 [[RAPIMER|RAPIMER 复合材料]]，将[[柠檬酸]]（0.06 g）加入一个装有 100 mL 先前制备的[[纤维素纳米原纤维]]（0.6 wt%）悬浮液的 250 mL 烧杯中，混合 1 h。随后加入 0.6 g [[改性木质素]]。将所得混合物（[[纤维素]]原纤维与[[聚乙烯亚胺改性木质素|改性木质素]]的质量比为 1:1，w/w）搅拌 1 h，然后置于 4 °C 冰箱中冷却过夜。随后将预冷的[[水凝胶]]在 −80 °C 下冷冻 20 min，并将所得冷冻样品置于[[冷冻干燥]]机中，在冷凝器温度为 −50.0 °C、真空度为 0.0004 mbar 的条件下冷冻干燥两天。冷冻干燥后，将 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 复合材料置于 80 °C 真空烘箱中固化 4 h，并储存在干燥器中备用。本研究还采用从冰箱冷却到固化的上述工艺制备[[纤维素纤维]]、[[纤维素纳米原纤]]维和[[纤维素纤维与木质素复合材料|纤维素纤维/木质素复合材料]]，以供比较。为评估复合材料的[[可生物降解性|生物降解性]]，对纤维素纳米原纤维/改性[[木质素]]组成进行了测试，其中纳米原纤维与改性木质素的质量比（w/w）分别为 2:1、1:1 和 1:2。选择最佳比例（1:1）制备 RAPIMER 复合材料。

[[污染物吸附]]实验。使用 50 mL 聚丙烯瓶配制 [[全氟和多氟烷基物质|PFAS]] 溶液，在 [[pH值|pH]] 为 7.0 ± 0.1（用[[氢氧化钠]]调节）的条件下进行批次[[吸附]]和降解试验。配制不同浓度的 [[全氟辛酸|PFOA]] 和 [[全氟辛烷磺酸|PFOS]] 溶液。称取所制备的材料，加入 PFAS 溶液中，然后在室温下置于轨道摇床上以 150 rpm 振荡。随后收集吸附了 PFAS 的材料，经[[冷冻干燥]]或高压蒸汽灭菌后备用。使用 HPLC-MS 检测 PFOA 和 PFOS 的浓度，使用光密度（OD）测量法测定[[阴离子染料]]浓度，并使用 ICP-MS 检测在线流动测试中进水和出水的 [[铜|Cu]]、[[铅|Pb]]、[[铬|Cr]] 和 [[镉|Cd]] 浓度。采用能量色散光谱（[[能量色散X射线光谱|EDS]]），在 15 kV [[加速电压]]下测定吸附试验后 [[RAPIMER]] 的元素组成，包括 C、N、O、F、S、Na、Cl、Cu、Pb、Cr 和 Cd。针对不同试验配制不同浓度的 PFOA 和 PFOS 溶液，补充的 PFAS 吸附测试、PFAS 定量分析以及 PFAS 污染实际水体模拟试验的详细信息见补充说明 1、2、3、4 和 5。

[[全氟和多氟烷基物质|PFAS]] 降解实验。为准备降解实验，将[[白腐真菌]] [[乳白耙齿菌|Irpex lacteus]]（最初分离自中国湖北神农自然保护区）<sup>46</sup>置于组织培养板（VWR 10861-554）中的 5 mL 马铃薯[[葡萄糖]]肉汤培养基内，在 28 °C 下预培养 7 天。培养条件遵循文献<sup>27</sup>中的程序。在接种至不同材料之前，用去离子水清洗[[菌丝体|真菌菌丝体]]三次，然后将其分散于 5 mL 不含葡萄糖的 [[Kirk 培养基]]<sup>26</sup>中。随后，将所制备的材料放入 12 孔板中含有 5 mL 不含葡萄糖的 Kirk 培养基的孔内，以监测[[真菌生长]]。在此情况下，所制备的复合材料作为[[真菌]]生长的唯一[[碳源]]。使用含葡萄糖的 Kirk 培养基作为对照，以比较真菌在所制备材料上的生长情况。将[[上清液]]过滤后，通过高分辨率 LCMS 分析检测 PFAS 降解产物。

[[材料表征]]。在制备过程的多个阶段对材料进行表征，以确定其化学及其他特性。使用 [[Bruker Dimension Icon 原子力显微镜]]（[[原子力显微镜|AFM]]）对[[纤维素纳米原纤]]和[[纤维素纤维]]进行 AFM 分析，并基于 AFM 图像使用 [[ImageJ|ImageJ v1.53 s]] 软件分析[[纤维直径]]。为检测[[官能团|化学官能团]]的存在，使用 [[Thermo Nicolet 380 傅里叶变换红外光谱仪|Thermo Nicolet 380 FTIR 光谱仪]]在 400 至 4000 cm<sup>−1</sup> 的[[波数]]范围内采集[[FTIR|傅里叶变换红外光谱]]（[[傅里叶变换红外光谱|FTIR]]）。使用配备 [[Argus 检测器]]和 [[Omicron DAR 400 X射线源|Omicron DAR 400 双 Al X 射线源]]（功率为 300 W）的 Omicron CPS/UPS 系统采集 [[X射线光电子能谱|X 射线光电子能谱]]（[[XPS]]），以分析[[化学元素]]和[[化学键]]。使用 [[Tescan FERA-3 Model GMH 聚焦离子束显微镜]]，在 5 kV [[加速电压]]下采集[[SEM|扫描电子显微镜]]（[[扫描电子显微镜|SEM]]）图像。通过 XPS 和 [[能量色散X射线光谱|EDS]] 测定样品中 C、N、O、F、S 等主要元素的[[原子数比]]和[[元素质量比]]。使用 [[TA Instruments TGA 5500 热重分析仪|TA instrument TGA 5500]]（[[TA Instruments]]）[[热重分析仪]]进行[[热重分析]]（TGA）测试。在 N 气氛下，以 10 °C 的[[升温速率]]将约 5.0 mg 样品从室温加热至 700 °C。根据[[固体密度]]（[[纤维素纳米原纤维|纤维素纳米原纤]]的密度为 1.45 g/cm<sup>3</sup>，[[纤维素]]纤维的密度为 1.6 g/cm<sup>3</sup>）及其体积计算这些[[复合泡沫]]密度和[[孔隙率]]的方法已有报道<sup>47–49</sup>。根据[[羧基含量]]和[[阳离子需求量]]计算纤维素纤维和纤维素纳米原纤的[[BET|比表面积]]<sup>50</sup>。所有数据均使用 [[Origin|Origin 2021]] 软件处理。

[[真菌活性测定]]。通过评估不同材料上可提取的[[蛋白质|真菌蛋白质]]来评价[[真菌活性]]。收集培养液后，使用 [[SpeedVac 真空离心浓缩系统|SpeedVac]] 去除[[真菌生长]]材料中的液体溶液。随后向材料中加入 100 µL 0.5 M [[氢氧化钠|NaOH]]。将所得材料与溶液的混合物煮沸 5 min。之后，加入 100 µL 0.5 M [[盐酸|HCl]]，再以 12,000 rpm [[离心]]，获得含蛋白质的[[上清液]]。将 50 µL 上清液加入 1 mL [[Bradford 试剂|Bradford 溶液]]中，用于 OD₅es 测量和[[标准曲线]]构建，以定量测定[[蛋白质浓度]]。将 1.5 µL [[去离子水|DI 水]]加入 1 mL Bradford 溶液中作为对照进行比较。对于 [[Bradford 蛋白质定量法|Bradford 蛋白质定量测定]]，将 0.1 mg/mL、0.2 mg/mL、0.4 mg/mL、0.6 mg/mL、0.8 mg/mL 和 1 mg/mL 的 [[牛血清白蛋白|BSA]] 溶液分别加入 1 mL Bradford 溶液中，充分混匀以构建校准曲线。对于生长在不同材料上的[[真菌]]活性，在第 1、3、7 和 14 天收集真菌样品，以评估蛋白质浓度。对于不同 [[全氟和多氟烷基物质|PFAS]] 浓度下富集 PFAS 的 [[RAPIMER]] 上的真菌活性，在第 1、3、7、10 和 14 天收集真菌样品，以测定蛋白质浓度。采用经 10 µg/L、100 µg/L、1000 µg/L、10,000 µg/L 的 [[全氟辛酸|PFOA]]/[[全氟辛烷磺酸|PFOS]] 混合溶液处理的 [[用于原位微生物环境修复的可再生人工植物|RAPIMER]] 复合材料，分析 PFAS 浓度对真菌生长的影响。在真菌活性测定中，使用含[[葡萄糖]]的 [[Kirk 培养基]]作为对照。

从[[真菌]]中提取[[蛋白质]]用于[[蛋白质组学分析]]。将生长在工程材料上的[[菌丝体]]以 5008 × g [[离心]]收集，用 [[去离子水|DI H O]] 洗涤两次，并用吸水纸吸干。每份收集的菌丝体样品取 100 mg 用于[[蛋白质提取]]。在[[液氮]]中研磨后，将菌丝体粉末与 1 mL [[碱性SDS缓冲液|碱性 SDS 缓冲液]]（5% [[十二烷基硫酸钠|SDS]]；50 mM [[Tris-HCl 缓冲液|Tris-HCl]]，[[pH值|pH]] 8.5；0.15 M [[氯化钠|NaCl]]；0.1 mM [[乙二胺四乙酸|EDTA]]；1 mM MgCl；50 mM [[二硫苏糖醇]]）混合，煮沸 10 min<sup>51</sup>。将煮沸后的样品以 3019×g 离心 10 min，所得[[上清液]]与预冷的 100% [[三氯乙酸]]（TCA）按 4:1 的比例混合，随后在 −20 °C 孵育 2 h。通过离心（4 °C 下以 15596 × g 离心 30 min）收集含蛋白质样品的沉淀，用 1 mL 预冷[[丙酮]]洗涤两次，然后风干，并溶解于含有 7 M [[尿素]]、2 M [[硫脲]]、40 mM [[Trizma碱|Trizma 碱]]和 1% [[C7BzO|3-(4-庚基)苯基-3-羟丙基二甲基铵丙磺酸盐]]（C7BzO）的溶解缓冲液中。提取的蛋白质样品在 [[液相色谱串联质谱|LC-MS/MS]] 分析前储存于 −80 °C。

采用基于 [[多维蛋白质鉴定技术|MudPIT]] 的[[鸟枪法蛋白质组学]]进行[[蛋白质]]分析。采用基于 MudPIT 的鸟枪法[[蛋白质组学]]对提取的蛋白质进行分析。简而言之，首先将 100 μg 蛋白质与[[胰蛋白酶]]（质谱级，[[Promega]]，WI，USA）按 1:40 的质量比（w/w）在 37 °C 下[[酶解]] 24 h。使用 [[Sep-Pak Plus C18 柱]]（[[Waters Limited]]，ON，Canada）对酶解后的[[肽段]]进行[[脱盐]]，随后将其上样至定制的[[双相毛细管柱]]。按照 [[Washburn]] 等人<sup>52</sup>所述的方法，该柱包含 5 cm 的 [[C18反相树脂|C18 反相树脂]]（[[C18-AQ]]，[[The Nest Group Inc]]，MA，USA）和 3 cm 的[[强阳离子交换]]（SCX）树脂 [[Pol - SULFOETHYL A]]（The Nest Group Inc，MA，USA），用于对肽段进行[[二维分离]]。使用 [[Thermo Fisher Orbitrap Velos Pro 质谱仪]]（[[Thermo Fisher Scientific]]，San Jose，CA）检测肽段。[[质谱仪]]设置为在 300–1700 [[质荷比|m/z]] 范围内记录肽段。随后对丰度最高的五个离子进行[[串联质谱]]（MS/MS）分析。使用 [[Xcalibur]] 软件（Thermo Fisher Scientific，San Jose，CA）控制 [[液相色谱质谱联用|LC-MS]] 系统并采集数据。

[[蛋白质组学]]数据分析。从原始文件中提取[[串联质谱]]，并转换为 [[MS2文件格式|MS2 文件]]。从 [[MycoCosm]]<sup>53</sup> 获取 [[乳白耙齿菌|Irpex lacteus]] 的[[蛋白质组]]及[[功能注释]]。将 MS2 文件与筛选后的模型进行检索匹配，这些模型包含 I. lacteus [[基因组]]中 15,319 个[[基因模型]]每个[[基因座]]的一个代表性[[蛋白质]]<sup>53</sup>。使用 [[Texas A&M 高性能研究计算集群]]<sup>54</sup>，采用[[前体离子质量容差|前体离子容差]]为 50 ppm 的 [[ProLuCID]]（ProLuCID 1.3.5）算法进行数据检索。采用[[目标-诱饵策略]]，使用半监督机器学习算法 Percolator 对[[肽段]]-谱图匹配（PSMs）进行筛选，假发现率阈值设为 0.1<sup>55</sup>。通过 crux 的 spectral counts 函数计算每种检出蛋白质的谱图计数<sup>56</sup>。使用 R Bioconductor 软件包“DEP”，基于原始谱图计数进行蛋白质差异表达分析<sup>57</sup>。保留在至少两个样本中表达的蛋白质。分别采用“knn”方法和“MinProb”方法对随机缺失和非随机缺失的缺失值进行估算。采用方差稳定化[[归一化]]方法，对 4,876 种检出蛋白质的行计数进行归一化。以校正后 p 值 < 0.1 且倍数变化 > 2 为标准，鉴定显著[[差异表达蛋白]]质。使用蛋白质归一化后的 log2 谱图 1/3 计数表示其在各条件下的表达水平。差异表达蛋白质的倍数变化和校正后 p 值的详细信息列于补充 Excel 表 1。在检出蛋白质背景下，使用 Cytoscape 3.9.1 中的 BiNGO 对差异表达蛋白质进行基因本体（GO）富集分析<sup>58,59</sup>。

环境评估。使用 OpenLCA 1.10.3 软件（https://www.openlca.org/）开展多维度生命周期评价（LCA）分析。系统边界定义为从摇篮到大门。所用清单数据主要取自 Ecoinvent 3.7 数据库。我们指定了两个功能单位，以便与其他[[吸附剂]]进行比较：（1）每生产 1 kg [[吸附]]材料的[[环境影响]]；以及（2）处理 1 m<sup>3</sup> 受 [[全氟和多氟烷基物质|PFAS]] 污染的[[地下水]]的环境影响。详见补充说明 6。
